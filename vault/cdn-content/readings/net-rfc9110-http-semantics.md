# RFC 9110 — HTTP Semantics

The standards-track source of truth for methods, status codes, fields,
representations, conditional requests, intermediaries, and content negotiation.
It is long; use the cards to choose sections instead of reading linearly.

**Extract on read:**
- Distinguish safe, idempotent, and cacheable semantics.
- Treat status codes and representation metadata as behavior, not decoration.
- Trace which fields are end-to-end and which decisions an intermediary may make.
