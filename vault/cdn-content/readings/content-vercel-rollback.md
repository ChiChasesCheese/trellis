# Rolling back a Vercel production deployment

The complete operational guide for confirming a bad release, switching back, and proving that service recovered.

**Extract on read:**
- Rollback restores a prior deployment before root-cause work continues.
- Logs and deployment identity establish which version caused the change.
- Recovery requires post-switch verification, not merely a successful CLI command.
