贡献法要求每个“元素属于某对象”的关系被 {{c1::恰好计数一次}}。

总价值等于每个对象价值之和，也等于每个元素对所有对象的贡献之和；每个对象-元素关系恰好被计数一次；左右选择数量相乘得到包含该位置的对象数
