若 n 含有平方质因子，则 {{c1::μ(n)=0}}。

μ(1)=1；含平方质因子的数 μ=0；其余为 (-1)^不同质因子数；对 n>1，所有 d|n 的 μ(d) 之和为 0

**Evidence**

§1.11 莫比乌斯函数
