# raw/ — 原始材料

一来源一文件，不整理、不改写；每条带 **URL + 日期 + 一句话它说了什么**。上游的 `02-process.md` / `01-company-brief.md` 里每个结论都要能指回这里的一条。

建议文件：

- `emails.md` — 邀请邮件原文（复制全文，含截止时间与平台名）
- `official.md` — 官方：careers 页、JD 原文、价值观 / Code of Conduct、工程博客、最新财报 / 新闻稿
- `forums_en.md` — Blind / Reddit / LeetCode Discuss / Glassdoor / Levels.fyi
- `forums_cn.md` — 一亩三分地 / 小红书 / 知乎
- `aggregators.md` — tryexponent / prepfully / prachub / interviewdb / linkjob（置信度默认 low–medium）

置信度约定：**high** = 一手候选人原帖或官方页；**medium** = 聚合站但细节与一手一致；**low** = SEO / AI 改写站，只信题型不信数字。
