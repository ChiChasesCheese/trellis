Whenever a statement names a limit, the hidden tests contain the value {{c1::exactly at the limit}}, the one {{c2::one unit below}} and the one one unit above — a count threshold of 3 is probed with 2, 3 and 4 fraudulent charges. The rule generalizes: every `<`, `>`, `<=`, `>=` in your code {{c3::is a test the grader has already written}}, so write the equality case yourself before submitting.

## zh
