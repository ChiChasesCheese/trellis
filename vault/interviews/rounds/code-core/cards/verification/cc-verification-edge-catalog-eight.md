Run the same eight shapes against every part before you submit: {{c1::empty}}, {{c1::single}}, duplicate, out-of-order, {{c2::zero}}, {{c2::negative}}, exactly-at-threshold, and maximum. It costs about {{c3::60}} seconds per part and finds the class of bug a worked example structurally cannot.

## zh
提交前，用同样这八种形态跑一遍每个 part：{{c1::空}}、{{c1::单条}}、重复、乱序、{{c2::零}}、{{c2::负数}}、恰好在阈值上、以及最大值。每个 part 大约花 {{c3::60}} 秒，能抓到样例在结构上不可能抓到的那类 bug。
