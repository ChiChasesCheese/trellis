The bespoke-spec assessment: one problem in {{c1::3–5}} parts that unlock in sequence, each extending the same program; roughly {{c2::17–25}} hidden tests; a {{c3::60}}-minute hard stop; no score shown, and partial credit advances. It is not a set of independent puzzles — the state you choose in part 1 is the state part 4 has to live in.

## zh
定制题面型笔试的形态：一道题分 {{c1::3–5}} 个依次解锁的 part，每个 part 都在扩展同一个程序；大约 {{c2::17–25}} 个隐藏测试；{{c3::60}} 分钟硬性截止；不显示分数，部分通过也能晋级。它不是一组互相独立的谜题 —— 你在 part 1 选定的状态，就是 part 4 必须住进去的那个状态。
