## Q
You have just finished an assessment. Before you forget it, what is the first thing you do with each problem — and what is the mistake?

## A
**Ask what general skill each problem instantiates, and file the lesson under that skill.** "Once-per-group aggregation." "Strict versus non-strict threshold." "A reversal that un-applies an earlier event." "Byte-exact output with a sentinel for the empty case."

- The mistake is filing the lesson under the *problem*. A note titled after one company's question is unsearchable in six months and transfers to nothing.
- If a problem instantiates a skill you have no heading for, that is a gap in your map and it earns a new heading ([[cc-transfer-playbook-gap-grows-the-map]]).
- Do it the same day. The specific reason a test failed is gone within 48 hours; only the general rule survives, and only if you write it down.

## Q zh
你刚考完一场笔试。在忘掉之前，你对每道题做的第一件事是什么？错误的做法是什么？

## A zh
**问每道题实例化了哪个通用技能，并把经验归档到那个技能之下。**「按组只计一次的聚合。」「严格与非严格阈值。」「撤销先前事件的冲正。」「空结果用哨兵词的逐字节精确输出。」

- 错误做法是把经验归档到*那道题*下面。以某家公司的题目命名的笔记，半年后搜不到，也迁移不到任何地方。
- 如果某道题实例化的技能你还没有标题可放，那就是你地图上的一个缺口，它值得一个新标题（[[cc-transfer-playbook-gap-grows-the-map]]）。
- 当天就做。某个测试失败的具体原因 48 小时内就没了；只有通用规则能留下来，而且只有你写下来才留得下。
