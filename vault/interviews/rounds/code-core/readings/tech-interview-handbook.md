# Tech Interview Handbook

A maintained, opinionated guide to the mechanics of the hiring process rather
than to algorithms: what each round format is for, how to behave in a live
coding session, how the questions are graded, and what to ask. Use it as a map
of the process — the algorithm content is available in better form elsewhere,
but the sections on round formats, the coding-interview rubric and behavioural
preparation are exactly the meta-skill this branch is about.

**Extract on read:**
- The differences between an online assessment, a phone screen and an onsite,
  and what a grader can observe in each ([[cc-transfer-oa-shape]]).
- The "during the coding interview" checklist: clarify, state the approach,
  then code — and narrate decisions rather than syntax.
- The self-introduction and question-asking sections, which are the cheapest
  points available in any round.
