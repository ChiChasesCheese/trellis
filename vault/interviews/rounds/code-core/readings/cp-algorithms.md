# cp-algorithms

The best free reference for the algorithm patterns a coding round draws from,
with each page structured the same way: the idea, a correctness argument, a
clean implementation, and the complexity. Use it as the place you look a pattern
up rather than as something to read front to back — the value is that the
implementations are correct at the boundaries, which is precisely where a
half-remembered binary search or Dijkstra goes wrong.

**Extract on read:**
- The graph section (BFS, DFS, topological sort, Dijkstra, Bellman-Ford) as one
  vocabulary with shared notation.
- The dynamic-programming and combinatorics sections for the state-and-transition
  wording you can say out loud in an interview.
- Every page's complexity line — the number you need before you commit to an
  approach ([[cc-performance-budget-from-n]]).
