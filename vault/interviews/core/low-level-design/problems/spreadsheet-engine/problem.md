# 电子表格引擎（Spreadsheet Engine）

你在写一个迷你电子表格的内核：格子里可以放数字，也可以放引用别的格子的公式。改一个格子，所有依赖它的格子要跟着变，而且不能把整张表重算一遍。不需要界面，只要一个 `Spreadsheet` 类。

**分关要求**（做完一关再看下一关）
- 第 1 关（约 30 分钟）：字面量、求和公式、环检测。
  - `set(cell: str, raw: str) -> None`：`raw` 是数字字面量（`"42"`、`"-3.5"`）、以 `=` 开头的公式，或 `""` 表示清空。公式只有用 `+` 连起来的数字和格子引用，如 `"=A1+B2+3"`（`+` 两边可以有空格，数字不带负号），用 `split` 解析即可。
  - `get(cell: str) -> float`：返回格子的值；空格子是 `0.0`。
  - 格子名只接受一个大写字母加 1 到 3 位行号（`A1` 到 `Z999`，行号不以 0 开头），否则 `set` 和 `get` 都抛 `InvalidCellError`。
  - 公式或字面量写错抛 `InvalidFormulaError`，且那个格子保持原样。公式里也只能引用合法格子名。
  - 会让公式互相依赖成环的 `set`（含 `A1` 引用自己）抛 `CycleError`，整张表保持原样，之后照常工作。菱形、同一个格子被引用两次都不是环；改线之后不能残留旧边造成误判。
  - 例：`set("A1","2")`、`set("B1","3")`、`set("C1","=A1+B1+3")`，`get("C1") == 8`；之后 `set("A1","1")`，`get("C1") == 7`。
  - 公式可以先于它引用的格子写下：`set("C1","=A1+B1")` 时 A1、B1 为空，`get("C1") == 0`。
- 第 2 关（约 15 分钟）：完整表达式。
  - 公式支持 `+ - * /`、括号、一元负号，乘除先于加减、同级左结合，如 `"=-(A1+B1)*2"`、`"=A1+-3"`；换成分词加递归下降解析器。写错抛 `InvalidFormulaError`，格子保持原样。
  - 除以零不在 `set` 时抛：`get` 这个格子（和依赖它的格子）抛 `EvalError`；把除数改好之后值恢复。
  - 环检测对括号、乘除里的引用同样有效。
- 第 3 关（约 15 分钟）：按依赖顺序重算。
  - 属性 `eval_count: int`：公式被求值的累计次数（字面量不计）。
  - `set` 之后，只有这个格子和它的下游被重新求值，每格恰好一次，且上游先于下游；`get` 只读结果，不求值。
  - 例：`A1=1`，`B1==A1+1`，`C1==A1+2`，`D1==B1+C1`（菱形）。`set("A1","10")` 使 `eval_count` 增加恰好 3，`get("D1") == 23`。
  - 被拒绝的环不求值任何格子；出错的格子把 `EvalError` 传给下游，修好上游后全部恢复；把公式换成字面量后，旧的依赖不能留下。
- 第 4 关（选做）：区间函数。
  - 公式里可用 `SUM(A1:B3)`、`MIN(...)`、`MAX(...)`，区间必须是左上到右下，否则抛 `InvalidFormulaError`。
  - 区间忽略空格子（`MIN` 不把空格子当 0）；区间内全空时三个函数都得 `0.0`；之后有人填上区间里的空格子，结果要跟着变。
  - 区间里的格子都算依赖，参与环检测，区间内任一格出错则整个函数出错。

**评分点**
- 公式在 `set` 时一次解析成语法树，语法错误当场抛出，而不是在 `get` 时才发现；第 1 关的 `split` 解析和第 2 关的递归下降共用同一套语法树。
- 依赖用两张边表（我读谁、谁读我），改一个格子只沿"谁读我"往下走。
- 环检测发生在改动状态之前，失败时表格没有半成品。
- 重算按拓扑序，每格一次；能说清菱形为什么不会算两次。
- 空格子也能有下游（先写公式、后填引用），清空和改线都要同步两张边表。
- 出错状态可传播、可恢复，不是用异常中断整个重算。
- 第 1 关的惰性递归求值和第 3 关的缓存重算共用同一套解析与求值（求值函数与"怎么读格子"解耦）。
- 能说出表格规模很大时的代价：深链递归的栈深、一次改动波及面。
