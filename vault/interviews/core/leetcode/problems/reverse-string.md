## Q
**LC 344 反转字符串**｜Easy

编写函数把字符数组 `s` 反转。必须**原地**修改输入数组，只用 `O(1)` 额外空间，不要另外分配数组。`1 <= s.length <= 10^5`，`s[i]` 都是 ASCII 可打印字符。例：`["h","e","l","l","o"]` → `["o","l","l","e","h"]`；`["H","a","n","n","a","h"]` → `["h","a","n","n","a","H"]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 对撞双指针（two pointers）原地交换。

**一句话。** 左右指针从两端向中间走，每步交换两个字符，相遇即停。

**识别。** 「原地」「`O(1)` 额外空间」「首尾对称」= 对撞双指针；`n = 10^5`，`O(n)`。

**推导。** 另开数组倒序复制再拷回，空间 `O(n)`，违反要求。反转后第 `i` 个字符一定是原来第 `n - 1 - i` 个，所以只要对每一对 `(i, n - 1 - i)` 交换一次，走到一半就够了。

```python
def reverse_string(s: list[str]) -> None:
    left, right = 0, len(s) - 1
    while left < right:  # 相遇或交错就停：奇数长度时中间字符不用动
        s[left], s[right] = s[right], s[left]  # 元组交换，不需要临时变量
        left += 1
        right -= 1
```

运行：`["h","e","l","l","o"]` → `["o","l","l","e","h"]`；`["H","a","n","n","a","h"]` → `["h","a","n","n","a","H"]`；单个字符 `["x"]` 不变；`["a","b"]` → `["b","a"]`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 工程里直接 `s.reverse()`，同样原地、`O(n)`、`O(1)` 额外空间；`s[:] = s[::-1]` 先生成了反转副本，额外空间 `O(n)`，不满足 `O(1)` 空间的要求。

**易错点。**
- `s = s[::-1]` 只是让局部变量指向新列表，调用方的 `["h","e","l","l","o"]` 原样不变；必须用切片赋值或逐元素交换修改原对象。
- 循环条件写成 `left <= right` 虽然不会出错（中间字符和自己交换），但写成 `left != right` 在偶数长度时指针交错后永远不相等，越界报 `IndexError`。
- 返回值：题目要求原地修改，函数不需要返回列表。

**同模式。** LC 345 反转字符串中的元音字母、LC 541 反转字符串 II、LC 557 反转字符串中的单词 III、LC 125 验证回文串。
