## Q
**LC 344 反转字符串**｜Easy

原地反转字符数组 `s`，额外空间 `O(1)`。

## A
**一句话。** 左右指针从两端向中间走，每步交换，相遇即停。

```python
def reverse_string(s):
    l, r = 0, len(s) - 1
    while l < r:
        s[l], s[r] = s[r], s[l]
        l += 1
        r -= 1
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 写成 `s = s[::-1]`：只是让局部变量指向新列表，调用方的数组原样不变；要用 `s[:] = s[::-1]` 或逐个交换。
- 循环条件写成 `l != r`：偶数长度时指针交错后永不相等，`IndexError`。

**追问。**
- 只反转元音（LC 345）？：双指针各自跳过非元音再交换。
- 反转每个单词（LC 557）？：按空格切段，段内用同样的双指针。

**同模式。** LC 345 反转字符串中的元音字母、LC 541 反转字符串 II、LC 557 反转字符串中的单词 III、LC 125 验证回文串
