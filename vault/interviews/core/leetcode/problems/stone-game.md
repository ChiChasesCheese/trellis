## Q
**LC 877 石子游戏**｜Medium

偶数堆石子排成一行，两人轮流从行首或行尾取一整堆，先手 Alice 先取，石子总数为奇数，取得多者赢。两人都用最优策略，Alice 能否获胜？

## A
**一句话。** 区间 DP：`f(i, j)` 是先手在 `[i, j]` 里能领先对手的最大分差，取左或取右再让对手面对子问题，最后看 `f(0, n-1)` 是否大于 0。

```python
def stone_game(piles):
    @cache
    def f(i, j):                      # 先手在 [i, j] 领先多少
        if i == j:
            return piles[i]
        return max(piles[i] - f(i + 1, j),
                   piles[j] - f(i, j - 1))
    return f(0, len(piles) - 1) > 0
```

**复杂度。** 时间 `O(n²)`，空间 `O(n²)`。

**易错点。**
- 直接比较取左取右的堆大小：贪心不对，要考虑取完后对手的最优回应。
- 对手的得分用加法：用「差值」形式，自己取 `p` 再减去对手在剩余里的领先，不要分别记两个人的分数。
- `i == j` 的边界：只剩一堆时先手全取，返回 `piles[i]`。

**追问。**
- 有没有直接结论？：堆数为偶、总数为奇时先手必胜，因为先手可以固定取所有偶数下标堆或所有奇数下标堆，两者和不等，选大的一组即可，所以直接 `return True`。
- 为什么总数奇数？：保证不会平局，所以不是真的需要 DP，这是面试里的陷阱题。
