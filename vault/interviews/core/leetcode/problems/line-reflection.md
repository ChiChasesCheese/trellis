## Q
**LC 356 直线镜像**｜Medium

平面上有 `n` 个点（可能重复）。判断是否存在一条与 `y` 轴平行的直线，使所有点关于它对称（点的集合在反射后不变）。

## A
**一句话。** 对称轴只可能是 `x = (最小 x + 最大 x) / 2`；每个点 `(x, y)` 的镜像 `(最小 x + 最大 x - x, y)` 必须也在点集里。

```python
def is_reflected(points):
    pts = {(x, y) for x, y in points}      # 去重
    s = min(x for x, _ in pts) + max(x for x, _ in pts)
    return all((s - x, y) in pts for x, y in pts)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 用除以 2 的中点：可能出现小数，用 `最小 x + 最大 x` 的和做镜像（`s - x`）避免浮点。
- 不去重：重复点会让集合与列表的大小不一致，但判断「镜像是否存在」用集合即可，重复点不影响结果。
- 只检查 `x` 坐标：镜像点的 `y` 必须相同。

**追问。**
- 为什么对称轴一定是最小与最大 x 的中点？：对称会把最左的点映射成最右的点。
- 空点集呢？：认为对称，`min` 会报错，要先判空。

**同模式。** LC 149 直线上最多的点数、LC 1232 缀点成线、LC 593 有效的正方形、LC 973 最接近原点的 K 个点
