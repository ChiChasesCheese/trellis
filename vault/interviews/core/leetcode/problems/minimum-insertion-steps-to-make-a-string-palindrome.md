## Q
**LC 1312 让字符串成为回文串的最少插入次数**｜Hard

每步可在字符串 `s` 的任意位置插入任意字符。求使 `s` 成为回文串的最少插入次数。

## A
**一句话。** 区间 DP：`f(i, j)` 是把 `s[i..j]` 变回文的最少插入数，两端相等就缩进去，不等则在某一端补一个对应字符再算剩下的。

```python
def min_insertions(s):
    @cache
    def f(i, j):                       # s[i..j] 变回文的最少插入数
        if i >= j:
            return 0                   # 空串或单字符已是回文
        if s[i] == s[j]:
            return f(i + 1, j - 1)     # 两端相同，不用插
        return min(f(i + 1, j), f(i, j - 1)) + 1
    return f(0, len(s) - 1)
```

**复杂度。** 时间 `O(n²)`，空间 `O(n²)`。

**易错点。**
- 两端不等时只试一边：补在左边或右边都可能，要取两者的最小值。
- 递归边界写成 `i == j`：`i > j` 也会出现（如 `f(i+1, j-1)` 越过），用 `i >= j`。
- 用 `LCS(s, s)` 当最长回文子序列：它恒等于 `n`，应是 `s` 与其反转串的 LCS。

**追问。**
- 为什么等于 `n - 最长回文子序列`？：保留的最长回文子序列不用动，其余每个字符各需要补一个对称字符。
- 想要具体插入后的串？：沿着 `f` 的决策回溯，相等取一对，不等则补在代价小的一侧。

**同模式。** LC 516 最长回文子序列、LC 1143 最长公共子序列、LC 132 分割回文串 II、LC 5 最长回文子串
