## Q
**LC 91 解码方法**｜Medium

`"1"→A … "26"→Z`，给只含数字的字符串 `s`（可能有前导零），求解码方案数，无合法解码返回 `0`。

## A
**一句话。** 线性 DP：末位单独成码（非 `'0'`）加 `f[i-1]`，末两位成码（`10`~`26`）加 `f[i-2]`，用两个变量滚动。

```python
def num_decodings(s):
    a, b = 0, 1        # 解码 s[:i-2]、s[:i-1] 的方案数
    for i, c in enumerate(s):
        cur = 0
        if c != "0":   # 单独成码
            cur += b
        if i and "10" <= s[i-1:i+1] <= "26":   # 两位成码
            cur += a
        a, b = b, cur
    return b
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 两位判断只写 `<= 26`：漏了下界 `10`，`"06"` 得 `1`，应为 `0`。
- `'0'` 也允许单独成码：`"10"` 会得 `2`，应为 `1`；`'0'` 只能跟在 `1`、`2` 后。

**追问。**
- 自顶向下怎么写？：`ways(i)` 表示解码 `s[i:]` 的方案数，加 `@cache`。
- 带通配符 `*`（LC 639）？：每位的合法个数代替 `0/1`，结果对 `10^9+7` 取模。

**同模式。** LC 70 爬楼梯、LC 639 解码方法 II、LC 131 分割回文串
