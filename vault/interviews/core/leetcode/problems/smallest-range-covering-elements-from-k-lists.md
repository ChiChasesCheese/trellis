## Q
**LC 632 最小区间**｜Hard

给 `k` 个非递减排序的整数列表。找一个最小的区间 `[a, b]`，使每个列表中至少有一个数在其中。区间长度相同时取 `a` 较小的。

## A
**一句话。** 小顶堆装每个列表的当前元素，堆顶是区间左端、已见的最大值是右端；每次弹出堆顶后换成它所在列表的下一个元素，同时更新最窄区间，直到某个列表耗尽。

```python
def smallest_range(nums):
    h = [(a[0], i, 0) for i, a in enumerate(nums)]
    heapify(h)                           # 每个列表一个代表
    hi = max(a[0] for a in nums)
    best = [h[0][0], hi]
    while True:
        lo, i, j = heappop(h)
        if hi - lo < best[1] - best[0]:  # 更窄才更新
            best = [lo, hi]
        if j + 1 == len(nums[i]):
            return best                  # 一个列表用完，无法再覆盖
        v = nums[i][j + 1]
        hi = max(hi, v)
        heappush(h, (v, i, j + 1))
```

**复杂度。** 时间 `O(N log k)`（`N` 为元素总数），空间 `O(k)`。

**易错点。**
- 忘了维护当前最大值：区间右端是各代表中最大的，要在每次加入新元素时更新。
- 同样窄时也更新：题目要 `a` 较小的，而左端单调增，第一次出现的最窄区间 `a` 最小，所以只在严格更窄时更新。
- 某个列表用完还继续：该列表再没有元素，区间不可能再覆盖到它。

**追问。**
- 还能怎么做？：把所有元素标上所属列表，合并排序，在这个序列上做滑动窗口，窗口覆盖全部 `k` 种标签。
- 为什么弹最小的是对的？：要缩小区间只能提高左端，左端是堆顶，必须换掉它。

**同模式。** LC 23 合并 K 个升序链表、LC 378 有序矩阵中第 K 小的元素、LC 719 找出第 K 小的数对距离、LC 76 最小覆盖子串
