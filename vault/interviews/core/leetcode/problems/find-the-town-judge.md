## Q
**LC 997 找到小镇的法官**｜Easy

小镇有 `n` 个人（编号 `1..n`），`trust[i] = [a, b]` 表示 `a` 信任 `b`。法官不信任任何人，且其他所有人都信任他，且这样的人唯一。返回法官编号，不存在返回 `-1`。

## A
**一句话。** 把信任关系看成有向图：法官的入度是 `n-1`、出度是 `0`，用 `入度 - 出度` 当分数，满足 `n-1` 的就是法官。

```python
def find_judge(n, trust):
    score = [0] * (n + 1)
    for a, b in trust:
        score[a] -= 1               # a 信任别人：不可能是法官
        score[b] += 1               # b 被信任
    for i in range(1, n + 1):
        if score[i] == n - 1:
            return i
    return -1
```

**复杂度。** 时间 `O(n + |trust|)`，空间 `O(n)`。

**易错点。**
- 只看入度等于 `n-1`：法官自己不能信任别人，入度够但出度非零的人不是法官，所以分数要减出度。
- `n = 1` 且 `trust` 为空：唯一的人就是法官，`score[1] = 0 = n - 1`，循环能正确返回。

**追问。**
- 为什么答案最多一个？：法官被其他所有人信任，而法官自己不信任任何人，两个法官会互相矛盾。
- 名人问题（LC 277）有何不同？：那题关系只能通过 `knows(a, b)` 询问，要用「淘汰」把询问降到 `O(n)`。

**同模式。** LC 277 搜寻名人、LC 133 克隆图
