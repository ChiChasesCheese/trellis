## Q
**LC 4093 至多 K 次数字重排后的最大和**｜Medium

一次操作可任意重排某个元素的十进制数字。求至多 `k` 次操作后数组元素之和的最大值。

## A
**一句话。** 每个数的最优重排是数字降序，收益互相独立，原和加上最大的 `k` 个收益。

```python
def max_sum(nums, k):
    # 收益 = 数字降序后的值 - 原值（>= 0）
    gains = [int("".join(sorted(str(x), reverse=True))) - x
             for x in nums]
    return sum(nums) + sum(nlargest(k, gains))
```

**复杂度。** 时间 `O(n log k)`，空间 `O(n)`。

**易错点。**
- 按数值而非收益挑元素：`[91,19]`、`k=1` 选了收益为 `0` 的 `91`，得 `110`，应为 `182`。
- 重排成最小或随意顺序：要的是最大，必须降序。

**追问。**
- 同一元素能叠加收益吗？：不能，一次已是最大，再操作没有增益，只能在 `k` 个不同元素里选。
- 只能交换两个数字（LC 670）？：贪心找最左的可换位置，与最右的最大数字交换。

**同模式。** LC 670 最大交换、LC 2231 按奇偶性交换后的最大数字、LC 179 最大数
