## Q
**LC 906 超级回文数**｜Hard

一个正整数本身是回文，且它的平方也是回文，就叫超级回文数。给两个整数字符串 `left`、`right`（`<= 10^18`），求闭区间内超级回文数的个数。

## A
**一句话。** 平方 `<= 10^18` 意味着根 `<= 10^9`，而根必须是回文：只枚举回文根（由前半 `<= 10^5` 个数生成），再检查它的平方是不是回文，不必扫 `10^18`。

```python
def super_palindromes(left, right):
    lo, hi = int(left), int(right)
    ans = 0
    for half in range(1, 10 ** 5):
        s = str(half)
        # 偶数长度、奇数长度（中间字符不重复）两种回文根
        for x in (int(s + s[::-1]), int(s + s[-2::-1])):
            sq = x * x
            if lo <= sq <= hi:
                t = str(sq)
                ans += t == t[::-1]
    return ans
```

**复杂度。** 时间 `O(√(√R)·log R)`，约 `10^5` 个前半各做一次平方与回文判断，空间 `O(1)`。

**易错点。**
- 生成奇数长度回文时写成 `s + s[::-1]`：中间那位被重复，只生成了偶数长度。
- 逐个枚举 `[√L, √R]` 的整数：上界 `10^9`，会超时，必须只枚举回文。

**追问。**
- 为什么只要 `half < 10^5`？：根 `<= 10^9`，回文根最多 9 位，前半最多 5 位。
- 能再剪枝吗？：超级回文数的根只含数字 0、1、2、3（平方不进位才可能保持回文），可以只在这四个数字上生成前半。
