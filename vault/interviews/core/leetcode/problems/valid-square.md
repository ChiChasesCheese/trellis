## Q
**LC 593 有效的正方形**｜Medium

给平面上四个点（顺序不保证），判断能否构成正方形。

## A
**一句话。** 看顺序无关的 6 个两两平方距离，排序后必须是 `[s, s, s, s, 2s, 2s]` 且 `s > 0`。

```python
def valid_square(p1, p2, p3, p4):
    def d2(a, b):
        return (a[0] - b[0])**2 + (a[1] - b[1])**2

    d = sorted(d2(a, b) for a, b in
               combinations((p1, p2, p3, p4), 2))
    # 四条边相等且 > 0，两条对角线是边平方的 2 倍
    return (d[0] > 0 and d[0] == d[3]
            and d[4] == d[5] == 2 * d[0])
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 漏掉 `d[0] > 0`：四点重合时 6 个距离全是 `0`，会错判 `True`。
- 只查四条边相等：菱形 `[0,0],[2,9],[9,2],[11,11]` 四边相等，对角线不等，应为 `False`。

**追问。**
- 给 `n` 个点找是否有正方形？：点放集合，枚举两点当一条边，旋转 `90°` 算另两点并查集合，`O(n²)`。
- 坐标是浮点数呢？：比较带容差，或换成整数。

**同模式。** LC 939 最小面积矩形、LC 963 最小面积矩形 II、LC 1232 缀点成线
