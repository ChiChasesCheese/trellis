## Q
**LC 2208 将数组和减半的最少操作次数**｜Medium

每次操作可选数组中任意一个数并将它减半（可重复选，减半后不取整）。求让数组总和至少减少一半所需的最少操作次数。

## A
**一句话。** 每次把当前最大的数减半，因为它减掉的量最多；用大顶堆维护，直到减少量达到总和的一半。

```python
def halve_array(nums):
    h = [-x for x in nums]
    heapify(h)                         # 大顶堆：存负数
    total = left = sum(nums)
    ops = 0
    while left > total / 2:            # 还没减掉一半
        x = -heappop(h) / 2            # 最大的减半
        left -= x
        heappush(h, -x)
        ops += 1
    return ops
```

**复杂度。** 时间 `O(n + k log n)`（`k` 为操作次数），空间 `O(n)`。

**易错点。**
- 把减半后的数取整：题目不取整，要保留小数（用浮点或分数）。
- 每次减半的是剩下的和还是被减的量：`left -= x` 里 `x` 是减半后的值，也等于本次减少的量。
- 判断写成 `>=`：减少「至少」一半即 `left <= total/2` 时停，循环条件是 `left > total/2`。

**追问。**
- 浮点误差担心怎么办？：把数乘上 `2^k` 变成整数，或用 `Fraction`；一般浮点够用。
- 为什么贪心？：每次减少量是该数的一半，选最大的减少最多，没有比它更好的选择。
