## Q
**LC 1021 删除最外层的括号**｜Easy

合法括号串拆成若干原语（不能再拆的非空合法串），去掉每个原语最外层的一对括号后拼起来。

## A
**一句话。** 深度计数：`(` 在深度 `0` 时、`)` 回到深度 `0` 时是最外层，跳过，其余照抄。

```python
def remove_outer_parentheses(s):
    out, depth = [], 0
    for ch in s:
        if ch == ')':
            depth -= 1          # 先减：回到 0 的是外层右括号
        if depth:
            out.append(ch)
        if ch == '(':
            depth += 1          # 后加：从 0 出发的是外层左括号
    return ''.join(out)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`（输出）。

**易错点。**
- 加减和判断顺序相同：左括号要先判断后加，右括号要先减后判断，否则外层括号会被保留。
- 先切出每个原语再去首尾：能做，但要多记一个起点，容易错位。

**追问。**
- 为什么深度回到 `0` 就是一个原语结束？：合法串的前缀里左括号不少于右括号，第一次平衡就是最短的合法前缀。
- 最大嵌套深度（LC 1614）？：同一个计数器，取最大值。

**同模式。** LC 20 有效的括号、LC 1614 括号的最大嵌套深度、LC 921 使括号有效的最少添加
