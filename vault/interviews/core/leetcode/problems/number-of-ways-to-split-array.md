## Q
**LC 2270 分割数组的方案数**｜Medium

整数数组 `nums`，长度 `n`。若下标 `i`（`0 <= i < n - 1`）满足前 `i + 1` 个元素之和大于等于后 `n - i - 1` 个元素之和，就是一次有效分割。求有效分割的个数。

## A
**一句话。** 总和一次算出，扫描时维护前缀和，后半和 = 总和 - 前缀和，比较即可。

```python
def ways_to_split_array(nums):
    total = sum(nums)
    pre = ans = 0
    for x in nums[:-1]:               # 后半部分不能为空
        pre += x
        if pre >= total - pre:
            ans += 1
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`（切片），可改下标循环做到 `O(1)`。

**易错点。**
- 把最后一个下标也算上：后半部分会为空，不合法。
- 比较写成 `>`：题目是大于等于。

**追问。**
- 分成三段、要求和相等呢？：见 LC 1013，总和必须被 `3` 整除，再数前缀等于 `s/3` 和 `2s/3` 的位置。

**同模式。** LC 1013 将数组分成和相等的三个部分、LC 724 寻找数组的中心下标、LC 1991 找到数组的中间位置
