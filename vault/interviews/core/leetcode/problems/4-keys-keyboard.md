## Q
**LC 651 四个键的键盘**｜Medium

键盘有四个键：打印一个 `A`；全选；复制；粘贴（追加复制的内容）。给定按键次数 `n`，求屏幕上最多能有几个 `A`。

## A
**一句话。** 要么只按「打印 A」，要么在第 `j` 步之后连按「全选、复制」（占 2 步），再粘贴若干次；`dp[i] = max(dp[i - 1] + 1, dp[j] · (i - j - 1))`。

```python
def max_a(n):
    dp = list(range(n + 1))      # 全按 A 的基础解
    for i in range(3, n + 1):
        for j in range(1, i - 2):
            # 第 j 步后全选+复制，之后 i-j-2 次粘贴，共 i-j-1 倍
            dp[i] = max(dp[i], dp[j] * (i - j - 1))
    return dp[n]
```

**复杂度。** 时间 `O(n^2)`，空间 `O(n)`。

**易错点。**
- 倍数算成 `i - j - 2`：全选复制之后屏幕上已有 `dp[j]` 个，再粘贴 `i - j - 2` 次，总共是原来的 `1 + (i - j - 2) = i - j - 1` 倍。
- `j` 取到 `i - 2`：至少要留 3 步（全选、复制、一次粘贴）才有意义，`j` 最大 `i - 3`。
- 只考虑粘贴一次：多次粘贴更划算，所以要枚举 `j`。

**追问。**
- 状态机怎么做？：状态 `(屏幕数, 剪贴板数)`，每步四个转移，搜索 `n` 步，指数级，但可用 DP 压缩。
- 最优策略长什么样？：先打一些 `A`，之后反复「全选、复制、粘贴约 3 次」，每 5 步乘 4。

**同模式。** LC 650 只有两个键的键盘、LC 70 爬楼梯、LC 279 完全平方数、LC 322 零钱兑换
