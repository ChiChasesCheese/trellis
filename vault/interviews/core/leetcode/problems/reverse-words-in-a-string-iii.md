## Q
**LC 557 反转字符串中的单词 III**｜Easy

反转每个单词内部的字符，保留空格和单词顺序；单词间恰好一个空格。

## A
**一句话。** 按空格切开，每个词切片反转，再用空格拼回。

```python
def reverse_words(s):
    return ' '.join(w[::-1] for w in s.split(' '))
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 整串反转：单词顺序也反了，`"ab cd"` 得 `"dc ba"`，应为 `"ba dc"`。
- 有多个空格时用 `split()`：会吞掉连续空格；这里保证单空格，两者等价。

**追问。**
- 原地（字符数组）？：双指针找每个词的边界，词内首尾交换。
- 反转单词顺序（LC 151）？：`' '.join(reversed(s.split()))`，或整体反转再逐词反转。

**同模式。** LC 151 反转字符串中的单词、LC 344 反转字符串、LC 541 反转字符串 II
