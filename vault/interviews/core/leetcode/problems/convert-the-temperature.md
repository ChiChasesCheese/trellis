## Q
**LC 2469 温度转换**｜Easy

把摄氏度 `celsius` 转成 `[开氏度, 华氏度]`：`K = C + 273.15`，`F = C × 1.80 + 32.00`。

## A
**一句话。** 两条线性公式直接代入，误差允许 `10^-5`。

```python
def convert_temperature(celsius):
    return [celsius + 273.15, celsius * 1.80 + 32.00]
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 顺序写反：要求先开氏度、后华氏度。
- 华氏度写成 `(C + 32) × 1.8`：先乘后加。

**追问。**
- 浮点输出 `309.65000000000003` 算错吗？：题目按 `10^-5` 误差判，不算。
- 精确输出两位小数？：用 `Decimal` 或 `round(x, 2)`。

**同模式。** LC 2413 最小偶倍数、LC 2235 两整数相加
