## Q
**LC 1266 访问所有点的最小时间**｜Easy

平面上有 `n` 个整数点 `points`，按给定顺序访问。每秒可走：竖直一格、水平一格，或斜着跨一格（相当于水平加竖直各一格）。求访问所有点的最少秒数。

## A
**一句话。** 相邻两点之间可以斜走，所需时间是切比雪夫距离 `max(|dx|, |dy|)`，全部相加。

```python
def min_time_to_visit_all_points(points):
    return sum(max(abs(x1 - x2), abs(y1 - y2))
               for (x1, y1), (x2, y2) in pairwise(points))
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 用曼哈顿距离：斜着走一秒同时改变两个坐标，曼哈顿距离会多算。
- 忘了严格按顺序：点要依次访问，不能重排。

**追问。**
- 为什么是切比雪夫距离？：先斜走 `min(|dx|, |dy|)` 步消掉短的那一维，剩下的直走，总共 `max` 步。
- 访问顺序可以自选怎么办？：就变成旅行商问题了。

**同模式。** LC 1232 缀点成线、LC 573 松鼠模拟、LC 296 最佳的碰头地点
