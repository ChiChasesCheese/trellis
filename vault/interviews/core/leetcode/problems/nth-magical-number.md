## Q
**LC 878 第 N 个神奇数字**｜Hard

正整数是神奇的，如果它能被 `a` 或 `b` 整除。返回第 `n` 个神奇数字，对 `10^9 + 7` 取模。

## A
**一句话。** 二分答案：不超过 `x` 的神奇数字个数是 `x // a + x // b - x // lcm(a, b)`（容斥），找最小的、个数不少于 `n` 的 `x`。

```python
def nth_magical_number(n, a, b):
    l = lcm(a, b)
    lo, hi = min(a, b), n * min(a, b)   # 答案一定在这个范围
    while lo < hi:
        mid = (lo + hi) // 2
        if mid // a + mid // b - mid // l >= n:
            hi = mid             # 个数够了，答案不大于 mid
        else:
            lo = mid + 1
    return lo % (10 ** 9 + 7)
```

**复杂度。** 时间 `O(log(n · min(a, b)))`，空间 `O(1)`。

**易错点。**
- 容斥时不减公倍数：既能被 `a` 又能被 `b` 整除的数被数了两次。
- 取模后再二分：模运算要放在最后，二分过程中用真实值比较。
- 上界取得太小：第 `n` 个一定不超过 `n · min(a, b)`。

**追问。**
- 为什么二分的结果一定是神奇数字？：个数从 `n - 1` 跳到 `n` 的位置恰好是一个能被 `a` 或 `b` 整除的数。
- 周期做法？：每 `lcm(a, b)` 为一个周期，周期内神奇数字个数固定，先整除再在最后一个周期内找。
