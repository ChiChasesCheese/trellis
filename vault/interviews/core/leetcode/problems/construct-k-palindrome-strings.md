## Q
**LC 1400 构造 K 个回文字符串**｜Medium

字符串 `s` 和整数 `k`，判断能否用 `s` 的**全部**字符构造出恰好 `k` 个非空回文串。

## A
**一句话。** 每个回文串至多一个出现奇数次的字母，所以出现奇数次的字母种数是下限；每个串至少一个字符，`k` 不能超过 `len(s)`。

```python
def can_construct(s, k):
    odd = sum(v % 2 for v in Counter(s).values())  # 奇数次字母种数
    return odd <= k <= len(s)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了 `k <= len(s)`：每个回文串至少 1 个字符，`k` 太大会造不出非空串。
- 把奇数次的字母数当成总字符数：每种奇数次字母必须各占一个回文串的中心，数「种数」。
- 要求 `odd == k`：`odd < k` 时可以把某个回文串拆开，偶数个相同字符可以拆成两个单字符回文。

**追问。**
- 为什么 `odd <= k` 之后总能凑到 `k` 个？：把偶数次字母成对放到不同回文串两侧，或把字符拆成单字符回文，直到数量够。
- 判断一个串能否重排成回文的条件？：奇数次字母种数不超过 1。

**同模式。** LC 409 最长回文串、LC 266 回文排列
