## Q
**LC 2948 交换得到字典序最小的数组**｜Medium

给你一个下标从 `0` 开始的正整数数组 `nums` 和一个正整数 `limit`。一次操作可以选任意两个下标 `i`、`j`，若 `|nums[i] - nums[j]| <= limit` 就交换 `nums[i]` 和 `nums[j]`。返回执行任意次操作后能得到的**字典序最小**的数组。`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^9`，`1 <= limit <= 10^9`。例：`nums = [1,5,3,9,8]`, `limit = 2` → `[1,3,5,8,9]`；`nums = [1,7,6,18,2,1]`, `limit = 3` → `[1,6,7,18,1,2]`；`nums = [1,7,28,19,10]`, `limit = 3` → `[1,7,28,19,10]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 排序 + 分组（连通分量）+ 组内贪心：值排序后相邻差 `<= limit` 的元素连成一组。

**一句话。** 按值排序，相邻差不超过 `limit` 的连成一组，同一组内的元素可以任意换位；每组把最小的值放到最靠前的位置，依次类推。

**识别。** 「任意次交换、条件只看两个值的差」= 能互换的元素构成连通块，问「字典序最小」就是每个块内部排序；`n = 10^5` 要求 `O(n log n)`，不能 BFS 建完全图。

**推导。** 暴力：枚举所有交换序列，指数级。关键有两步：一，可交换关系是**可传递**的——`a` 与 `b`、`b` 与 `c` 能交换，则 `a`、`c` 也能经 `b` 换位（先换 `a,b`，再换 `b,c`，再换 `a,b`），所以每个连通块内可以任意排列；二，把值按大小排好，两个值能连通当且仅当它们之间每一对相邻值的差都 `<= limit`，连通块就是排序序列上的一段连续区间，一次扫描即可切出。块内字典序最小就是把小的值放到小的下标。

```python
def lexicographically_smallest_array(nums: list[int], limit: int) -> list[int]:
    n = len(nums)
    order = sorted(range(n), key=nums.__getitem__)  # 下标按对应的值升序排列
    ans = nums[:]
    i = 0
    while i < n:
        # 值排序后，相邻差 <= limit 的连成一组；组内任意两数可经一串交换互换
        j = i + 1
        while j < n and nums[order[j]] - nums[order[j - 1]] <= limit:
            j += 1
        group = order[i:j]  # 这一组的下标，按值升序
        # 组内的位置从小到大，依次放组内从小到大的值：靠前的位置拿到最小的值
        for pos, idx in zip(sorted(group), group):
            ans[pos] = nums[idx]
        i = j
    return ans
```

运行：三个示例依次得到 `[1,3,5,8,9]`、`[1,6,7,18,1,2]`、`[1,7,28,19,10]`；`([5,3,1], 2)` → `[1,3,5]`；`([4], 1)` → `[4]`。

**复杂度。** 时间 `O(n log n)`（两次排序），空间 `O(n)`。

**易错点。**
- 整个数组直接排序：`[1,7,6,18,2,1]`, `limit = 3` 会得到 `[1,1,2,6,7,18]`，正确是 `[1,6,7,18,1,2]`，`18` 与其他数差超过 `limit`，不能动。
- 分组时拿「组内第一个值」比较而不是「相邻值」：`[5,3,1]`, `limit = 2` 会把 `5` 单独分出去，得到 `[5,1,3]`，正确是 `[1,3,5]`（`5-3`、`3-1` 都 `<= 2`，三个数连通）。
- 组内位置不排序、直接把值按顺序写回 `group` 里的下标：`[1,5,3,9,8]`, `limit = 2` 原样返回，正确是 `[1,3,5,8,9]`。
