## Q
**LC 1390 四因数**｜Medium

整数数组 `nums`（`<= 10^4` 个数，每个 `<= 10^5`）。对恰好有四个正因数的数，把它的四个因数加起来；返回这些和的总和，没有这样的数返回 `0`。

## A
**一句话。** 对每个数试除到 `√x`，成对统计因数 `d` 和 `x/d`，因数个数一超过 4 就提前停，恰好为 4 才累加因数和。

```python
def sum_four_divisors(nums):
    ans = 0
    for x in nums:
        cnt = total = 0
        d = 1
        while d * d <= x and cnt <= 4:   # 超过 4 个就不用再数
            if x % d == 0:
                cnt += 1
                total += d
                if d * d != x:           # 平方根只算一个因数
                    cnt += 1
                    total += x // d
            d += 1
        if cnt == 4:
            ans += total
    return ans
```

**复杂度。** 时间 `O(n√M)`，空间 `O(1)`。

**易错点。**
- 完全平方数把 `√x` 记两次：`d * d == x` 时只算一个因数。
- 漏掉 1 和 `x` 本身：`p·q` 的四个因数是 `1, p, q, pq`，试除要从 `d = 1` 开始。

**追问。**
- 恰有四个因数的数长什么样？：要么是 `p·q`（两个不同质数），要么是 `p³`，可以用筛法预处理所有数的最小质因子，每个数 `O(1)` 判断。
- 有重复数字怎么加速？：用字典缓存每个值的结果。

**同模式。** LC 507 完美数、LC 1952 三除数、LC 204 计数质数
