## Q
**LC 260 只出现一次的数字 III**｜Medium

数组里恰有两个元素只出现一次，其余都出现两次，找出这两个，要求线性时间、常数空间。

## A
**一句话。** 全体异或得 `a^b`，按其最低位的 `1` 把数分两组，各组异或得到 `a` 和 `b`。

```python
def single_number_iii(nums):
    both = 0
    for x in nums:
        both ^= x       # a ^ b，非零
    low = both & -both  # a、b 在这一位不同
    a = 0
    for x in nums:
        if x & low:     # 只异或这一位为 1 的一组
            a ^= x
    return [a, both ^ a]
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 随手按 `x & 1` 分组：`[1,2,1,3,2,5]` 的 `a^b = 110`，第 0 位相同，分不开，得 `[6,0]`，应为 `[3,5]`。
- 只扫一遍就返回 `a`：另一个要用 `both ^ a` 补上。

**追问。**
- 为什么三个落单数不行？：异或只给一个等式，分不开三个数。
- 其余出现三次、落单一个（LC 137）？：按位计数模 `3`。

**同模式。** LC 136 只出现一次的数字、LC 137 只出现一次的数字 II、LC 268 丢失的数字、LC 389 找不同
