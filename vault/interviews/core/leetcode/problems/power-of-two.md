## Q
**LC 231 2 的幂**｜Easy

判断整数 `n` 是否是 `2` 的幂。

## A
**一句话。** 正数是 `2` 的幂当且仅当二进制只有一个 `1`，`n & (n-1)` 清掉最低位的 `1`，结果为 `0` 即是。

```python
def is_power_of_two(n):
    return n > 0 and n & (n - 1) == 0
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 漏掉 `n > 0`：`0 & -1 == 0`，`n = 0` 会误返回 `True`。
- 跨语言的优先级：C++ / Java 里 `==` 高于 `&`，必须写 `(n & (n-1)) == 0`。

**追问。**
- 怎么判断 `4` 的幂？：再要求 `n & 0x55555555 != 0`，保证唯一的 `1` 在偶数位。
- 不用位运算呢？：`2^30 % n == 0`，因为 `2^30` 的约数都是 `2` 的幂。

**同模式。** LC 191 位 1 的个数、LC 342 4 的幂、LC 326 3 的幂、LC 338 比特位计数
