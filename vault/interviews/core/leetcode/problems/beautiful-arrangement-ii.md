## Q
**LC 667 优美的排列 II**｜Medium

构造 `1..n` 的一个排列，使相邻差的绝对值恰好有 `k` 个不同的值，返回任意一个。

## A
**一句话。** 前 `k+1` 个数在 `1..k+1` 里一头一尾交替取，相邻差为 `k, k-1, ..., 1`，其余递增接上。

```python
def construct_array(n, k):
    ans = []
    lo, hi = 1, k + 1
    while lo <= hi:
        ans.append(lo)
        lo += 1
        if lo <= hi:        # 两端相遇时别重复加
            ans.append(hi)
            hi -= 1
    ans.extend(range(k + 2, n + 1))  # 只产生差 1
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`（不计输出）。

**易错点。**
- 交替取数铺满整个 `1..n`：`n = 5`、`k = 2` 得 `[1,5,2,3,4]`，差集合有 `3` 种。
- 漏掉后面的 `extend`：`n = 5`、`k = 2` 只返回 `[1,3,2]`，长度不足。

**追问。**
- 怎么验证结果？：排序后等于 `1..n`，且相邻差集合大小为 `k`。
- 有别的构造吗？：先递增放 `1..n-k-1`，再在 `[n-k, n]` 上交替取两端。

**同模式。** LC 526 优美的排列、LC 932 漂亮数组、LC 31 下一个排列
