## Q
**LC 3693 爬楼梯 II**｜Medium

台阶编号 `0..n`，从 `i` 只能跳到 `i+1`、`i+2`、`i+3`，跳到 `j` 的成本是 第 `j` 级的成本加 `(j-i)^2`（第 `j` 级的成本存在 `costs[j-1]`）。求从 `0` 到 `n` 的最小总成本，`n <= 10^5`。

## A
**一句话。** 线性 DP：枚举最后一跳的步长 `d`，`dp[j] = costs[j-1] + min(dp[j-d] + d^2)`，`d` 取 `1..3`。

```python
def climb_stairs(n, costs):
    dp = [0] * (n + 1)      # dp[j] = 到第 j 级的最小成本
    for j in range(1, n + 1):
        # 最后一跳的步长 d 只有 1、2、3 三种
        dp[j] = costs[j - 1] + min(
            dp[j - d] + d * d
            for d in (1, 2, 3) if j >= d)
    return dp[n]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 跳跃成本写成 `d` 而不是 `d^2`：`n=3, costs=[9,8,3]` 得 `6`，应为 `12`。
- 第 `j` 级的成本取 `costs[j]`：数组从第 `1` 级开始存，应取 `costs[j-1]`，否则 `j=n` 越界。
- 漏掉 `j >= d`：`dp[-1]` 在 Python 里不报错，悄悄读到数组末尾。

**追问。**
- 空间压到 `O(1)`？：只依赖前三项，滚动三个变量。
- 步长上限变成 `k`？：内层枚举 `1..k`，时间 `O(nk)`。
