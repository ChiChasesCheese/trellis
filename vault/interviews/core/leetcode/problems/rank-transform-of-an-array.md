## Q
**LC 1331 数组序号转换**｜Easy

给你一个整数数组 `arr`，把每个元素替换为它排序后的序号。序号从 `1` 开始；元素越大序号越大；相等的元素序号相同；每个数的序号应尽可能小。`0 <= arr.length <= 10^5`，`-10^9 <= arr[i] <= 10^9`。例：`[40,10,20,30]` → `[4,1,2,3]`；`[100,100,100]` → `[1,1,1]`；`[37,12,28,9,100,56,80,5,12]` → `[5,3,4,2,8,6,7,1,3]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 离散化（coordinate compression）：去重 + 排序 + 哈希映射。

**一句话。** 去重后排序，第 `r` 小的值排名 `r`，再按原顺序查表替换。

**识别。** 「用名次替换原值」「相等同名次」「名次尽可能小」= 把值域压缩成 `1..k`（离散化）；`n = 10^5` 允许 `O(n log n)`。

**推导。** 暴力：对每个元素数「有多少个不同的值比它小」再加 `1`，`O(n^2)`。排序后名次就是在去重后的有序序列里的位置，只需排序一次、建一张映射表，之后每个元素 `O(1)` 查表。

```python
def array_rank_transform(arr: list[int]) -> list[int]:
    # 去重（保证"相等同名次、名次尽可能小"）再排序，第 r 小的不同值名次就是 r
    rank = {v: r for r, v in enumerate(sorted(set(arr)), 1)}
    return [rank[v] for v in arr]  # 按原顺序查表替换
```

运行：`[40,10,20,30]` → `[4,1,2,3]`；`[100,100,100]` → `[1,1,1]`；`[37,12,28,9,100,56,80,5,12]` → `[5,3,4,2,8,6,7,1,3]`；`[]` → `[]`。

**复杂度。** 时间 `O(n log n)`（排序），空间 `O(n)`。

**拓展优化。**
- 不建字典：`u = sorted(set(arr))`，名次是 `bisect_left(u, v) + 1`，每次 `O(log n)`；离散化后的名次常用来给树状数组（Fenwick tree）做下标，例如 LC 315。

**易错点。**
- 排序后不去重直接枚举：`{v: r for r, v in enumerate(sorted(arr), 1)}` 对 `[100,100,100]` 返回 `[3,3,3]`，正确是 `[1,1,1]`；`[37,12,28,9,100,56,80,5,12]` 里的两个 `12` 也会拿到 `4` 而不是 `3`。
- 名次从 `0` 开始：`enumerate(sorted(set(arr)))` 少传起始值 `1`，`[40,10,20,30]` 返回 `[3,0,1,2]`。
- 空数组：`arr = []` 应返回 `[]`，上面的写法自然成立。

**同模式。** LC 506 相对名次、LC 1365 有多少小于当前数字的数字、LC 315 计算右侧小于当前元素的个数、LC 912 排序数组。
