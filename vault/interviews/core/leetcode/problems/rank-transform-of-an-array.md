## Q
**LC 1331 数组序号转换**｜Easy

把数组每个元素替换为它排序后的序号：从 `1` 开始，相等元素序号相同，序号尽可能小。

## A
**一句话。** 去重排序后建「值 → 名次」表，再按原顺序查表。

```python
def array_rank_transform(arr):
    # 先去重，相等的数才同名次且名次最小
    rank = {v: r for r, v in enumerate(sorted(set(arr)), 1)}
    return [rank[v] for v in arr]
```

**复杂度。** 时间 `O(n log n)`，空间 `O(n)`。

**易错点。**
- 排序后不去重：`[100,100,100]` 得 `[3,3,3]`，应为 `[1,1,1]`。
- 名次从 `0` 开始：忘了 `enumerate` 的起始值 `1`，`[40,10,20,30]` 得 `[3,0,1,2]`。

**追问。**
- 不许用哈希表？：排序后二分查原值的位置。

**同模式。** LC 506 相对名次、LC 1365 有多少小于当前数字的数字、LC 315 计算右侧小于当前元素的个数、LC 912 排序数组
