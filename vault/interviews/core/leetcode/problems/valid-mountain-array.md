## Q
**LC 941 有效的山脉数组**｜Easy

判断数组 `arr` 是否是山脉：长度至少 `3`，先严格上升到山顶，再严格下降到末尾。例：`[3,5,5]` → `false`，`[0,3,2,1]` → `true`。

## A
**一句话。** 先爬坡到不能再升，再下坡到不能再降，山顶不能是起点或终点，最后恰好走到末尾才是山脉。

```python
def valid_mountain_array(arr):
    n = len(arr)
    i = 0
    while i + 1 < n and arr[i] < arr[i + 1]:    # 上坡
        i += 1
    if i == 0 or i == n - 1:    # 没有上坡或没有下坡
        return False
    while i + 1 < n and arr[i] > arr[i + 1]:    # 下坡
        i += 1
    return i == n - 1
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 没检查山顶位置：`[0,1,2,3]` 爬完 `i = n - 1`，直接 `return i == n - 1` 得 `True`，应为 `False`。
- 上坡条件用 `<=`：`[1,2,2,1]` 平台被当上坡，得 `True`，应为 `False`。

**追问。**
- 允许平台（非严格）？：条件改 `<=`、`>=`，但要保证至少一段严格上升和一段严格下降。
- 最少删几个元素成为山脉（LC 1671）？：需要最长递增子序列，从两端各算一遍。

**同模式。** LC 845 数组中的最长山脉、LC 852 山脉数组的峰顶索引、LC 1095 山脉数组中查找目标值、LC 162 寻找峰值
