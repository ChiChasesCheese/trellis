## Q
**LC 470 用 Rand7() 实现 Rand10()**｜Medium

只能调用均匀的 `rand7()`（`1..7`），实现均匀的 `rand10()`（`1..10`）。

## A
**一句话。** 拒绝采样：两次 `rand7` 拼成 `1..49` 的均匀数，只保留 `1..40`，再取模映射到 `1..10`。

```python
def rand10():
    while True:
        idx = (rand7() - 1) * 7 + rand7()   # 1..49 均匀
        if idx <= 40:                       # 丢掉 41..49 重来
            return (idx - 1) % 10 + 1
```

**复杂度。** 时间 期望 `O(1)`（平均 `2.45` 次 `rand7`，无最坏上界），空间 `O(1)`。

**易错点。**
- `rand7() + rand7()`：和的分布中间高两头低，不均匀。
- 拼接写成 `rand7() * 7 + rand7()`：范围变成 `8..56`，要用 `(rand7() - 1) * 7 + rand7()`。
- 取模前不过滤：`1..49` 里结果 `10` 只有 4 个格子，概率是 `4/49`，不是 `0.1`。

**追问。**
- 怎么减少 `rand7` 调用次数？：被拒的 `41..49` 是 `1..9` 上的均匀数，复用它再拼一次，期望降到约 `2.19`。
- 反过来用 `rand10` 造 `rand7`？：反复抽，`<= 7` 就返回，否则重抽。
