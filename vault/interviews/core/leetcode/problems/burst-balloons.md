## Q
**LC 312 戳气球（Burst Balloons）**｜Hard

有 `n` 个气球，编号 `0` 到 `n - 1`，每个气球上标有数字，存在数组 `nums` 中。现在要求你戳破所有的气球。戳破第 `i` 个气球，你可以获得 `nums[i - 1] * nums[i] * nums[i + 1]` 枚硬币；如果 `i - 1` 或 `i + 1` 超出了数组的边界，那么就当它是一个数字为 `1` 的气球。求所能获得硬币的最大数量。`n == nums.length`，`1 <= n <= 300`，`0 <= nums[i] <= 100`。例：`nums = [3,1,5,8]` → `167`（`[3,1,5,8] -> [3,5,8] -> [3,8] -> [8] -> []`，`3*1*5 + 3*5*8 + 1*3*8 + 1*8*1 = 167`）；`nums = [1,5]` → `10`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 区间 DP（interval DP）：枚举区间里**最后一个**被戳破的气球，把区间拆成两个互不影响的子区间。

**一句话。** `dp[i][j]` 表示只戳开区间 `(i, j)` 里的气球（`i`、`j` 本身保留当边界）的最大硬币；枚举其中最后戳破的 `k`，此时 `k` 的邻居正是 `i` 和 `j`，答案是 `dp[i][k] + a[i]*a[k]*a[j] + dp[k][j]`。

**识别。** 「删除元素的收益取决于它当时的相邻元素」且 `n = 300`、要最大总收益：区间 DP，`O(n³)`。删除顺序难以枚举（`n!`），换成「最后删除谁」把依赖固定下来。

**推导。** 暴力枚举戳破顺序 `O(n!)`。如果按「第一个戳谁」划分：戳掉 `k` 后左右两边变成相邻，两个子问题互相影响，无法拆开。反过来想「最后戳谁」：设区间 `(i, j)` 里最后戳 `k`，那时 `(i, k)` 和 `(k, j)` 里的气球早已戳完，`k` 的左右邻居只剩 `i`、`j`；而戳 `(i, k)` 里的气球时，右边界 `k` 一直在，和 `(k, j)` 毫不相干。两端补上虚拟气球 `1` 统一边界。区间按长度从小到大填表，大区间依赖更短的区间。

```python
def max_coins(nums: list[int]) -> int:
    a = [1] + nums + [1]                          # 两端补虚拟气球 1，统一边界
    m = len(a)
    # dp[i][j]：只考虑开区间 (i, j) 里的气球，全部戳破的最大硬币数（a[i]、a[j] 是留着不戳的边界）
    dp = [[0] * m for _ in range(m)]
    for length in range(2, m):                    # 区间跨度 j - i，从小到大：大区间依赖更小的区间
        for i in range(m - length):
            j = i + length
            for k in range(i + 1, j):             # 枚举 (i, j) 里「最后一个」戳破的气球 k
                # 此时 k 的左右邻居正是 a[i]、a[j]；k 把区间切成互不影响的 (i, k) 和 (k, j)
                dp[i][j] = max(dp[i][j], dp[i][k] + a[i] * a[k] * a[j] + dp[k][j])
    return dp[0][m - 1]
```

运行：`[3,1,5,8]` → `167`，`[1,5]` → `10`，`[7]` → `7`，`[0,0]` → `0`。

**复杂度。** 时间 `O(n³)`（约 `n³ / 6` 次内层更新，`n = 300` 约 460 万次），空间 `O(n²)`。

**拓展优化。**
- 自顶向下记忆化（memoization）：同一个状态定义，用 `@cache` 写递归，更贴近「枚举最后一个」的思路；递归深度不超过区间长度 `n + 2`。

```python
from functools import cache


def max_coins_memo(nums: list[int]) -> int:
    a = [1] + nums + [1]

    @cache
    def best(i: int, j: int) -> int:              # 开区间 (i, j) 的最大硬币数
        return max((best(i, k) + a[i] * a[k] * a[j] + best(k, j) for k in range(i + 1, j)), default=0)

    return best(0, len(a) - 1)
```

**易错点。**
- 贪心先戳最小的气球：`[3,1,5,8]` 得到 `78`，正确 `167`；局部最优会破坏相邻关系。
- 按「第一个戳谁」定义子问题：戳掉 `k` 后其左右气球变成邻居，左右两半互相影响，无法独立求解。
- 区间长度从大到小填表：大区间先算，读到的小区间还是初始值 `0`，示例一得到 `8`，正确 `167`。长度必须从小到大。
