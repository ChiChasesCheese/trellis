## Q
**LC 312 戳气球**｜Hard

戳破气球 `i` 得 `nums[i-1]*nums[i]*nums[i+1]` 枚硬币，越界按 `1` 算。求戳破所有气球的最大硬币数。

## A
**一句话。** 区间 DP：枚举开区间 `(i, j)` 里最后戳破的 `k`，它的邻居固定是 `i` 和 `j`，左右两半互不影响。

```python
def max_coins(nums):
    a = [1] + nums + [1]           # 两端补虚拟气球
    m = len(a)
    dp = [[0] * m for _ in range(m)]  # 开区间 (i, j) 的最大值
    for length in range(2, m):     # 区间从小到大
        for i in range(m - length):
            j = i + length
            for k in range(i + 1, j):   # k 是最后戳的
                dp[i][j] = max(dp[i][j],
                    dp[i][k] + a[i]*a[k]*a[j] + dp[k][j])
    return dp[0][m-1]
```

**复杂度。** 时间 `O(n³)`，空间 `O(n²)`。

**易错点。**
- 枚举「第一个戳谁」：戳掉 `k` 后左右变邻居，两半互相影响，没法拆。
- 区间长度从大到小填：读到的小区间还是 `0`，`[3,1,5,8]` 得 `8`，应为 `167`。

**追问。**
- 为什么贪心先戳最小的不行？：局部最优会改变邻居关系，`[3,1,5,8]` 贪心得 `78`，正确是 `167`。
- 为什么「最后戳」能拆分？：最后戳的 `k` 把区间切成两段，段内的邻居不再受对方影响。
