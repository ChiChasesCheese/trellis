## Q
**LC 2444 统计定界子数组的数目**｜Hard

给你一个整数数组 `nums` 和两个整数 `minK`、`maxK`。`nums` 的定界子数组是满足下述条件的一个子数组：子数组中的最小值等于 `minK`，最大值等于 `maxK`。返回定界子数组的数目。`2 <= nums.length <= 10^5`，`1 <= nums[i], minK, maxK <= 10^6`。例：`nums = [1,3,5,2,7,5], minK = 1, maxK = 5` → `2`（`[1,3,5]` 和 `[1,3,5,2]`）；`nums = [1,1,1,1], minK = 1, maxK = 1` → `10`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 以每个右端点结尾统计合法左端点个数；用三个「最近下标」代替窗口。

**一句话。** 固定右端点 `i`，合法左端点必须在最近一个越界元素之后、同时不晚于最近的 `minK` 和最近的 `maxK`，个数是 `max(0, min(last_min, last_max) - bad)`。

**识别。** 「最大值和最小值都恰好等于给定值的子数组个数」：直接维护窗口最大 / 最小很麻烦，改成「范围内 + 同时含有 `minK` 和 `maxK`」两个条件；`n = 10^5` 排除 `O(n^2)`。

**推导。** 暴力枚举所有子数组求最大最小，`O(n^3)`，累计优化也是 `O(n^2)`。子数组合法当且仅当：(1) 不含任何小于 `minK` 或大于 `maxK` 的元素；(2) 至少含一个 `minK`；(3) 至少含一个 `maxK`。对右端点 `i`，令 `bad` 为最近越界元素的下标，`last_min` / `last_max` 为最近的 `minK` / `maxK` 的下标，则左端点 `j` 合法当且仅当 `bad < j <= min(last_min, last_max)`。三个下标都只用 `O(1)` 更新，总共一遍扫描。

```python
def count_subarrays(nums: list[int], min_k: int, max_k: int) -> int:
    ans = 0
    bad = last_min = last_max = -1          # 最近的越界元素、minK、maxK 的下标；-1 表示还没出现
    for i, x in enumerate(nums):
        if x < min_k or x > max_k:
            bad = i                         # 越界元素：包含它的子数组都非法，左端点只能在它右边
        if x == min_k:
            last_min = i
        if x == max_k:
            last_max = i
        # 左端点 j 需满足 bad < j <= min(last_min, last_max)；若 min(...) <= bad，说明还没凑齐，贡献 0
        ans += max(0, min(last_min, last_max) - bad)
    return ans
```

运行：`([1,3,5,2,7,5], 1, 5)` → `2`，`([1,1,1,1], 1, 1)` → `10`，`([7,7], 1, 5)` → `0`，`([5,1], 1, 5)` → `1`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 等价的分段写法：按越界元素把数组切成若干段，在每段内统计「同时含 `minK` 和 `maxK`」的子数组，与上面是同一个计数。
- `minK == maxK` 不需要特判：这时 `last_min == last_max`，公式自然退化成「连续的 `minK` 段内所有子数组」。

**易错点。**
- 漏掉 `max(0, …)`：`min(last_min, last_max)` 可能 `<= bad`，会加上负数。`[1,7,5]`、`minK = 1`、`maxK = 5` 得到 `-3`（正确 `0`）。
- 把 `if x == max_k` 写成 `elif`：`minK == maxK` 时同一个元素要同时更新 `last_min` 和 `last_max`，`[1,1,1,1]` 会得到 `0`（正确 `10`）。
- `bad` 和 `last_*` 的初值用 `0` 而不是 `-1`：下标 0 开头的子数组会被少算 1，`[1,1,1,1]` 得到 `6`（正确 `10`）。

**追问。**
- 只要求最大值等于 `maxK`（不限最小值）：只需 `bad`（大于 `maxK` 的最近下标）和 `last_max`，每步累加 `max(0, last_max - bad)`。
- 约束改成「最大值 − 最小值 `<= k`」（LC 2762 不间断子数组）：固定边界的三个下标不再适用，用两个单调双端队列维护窗口最大、最小值，`O(n)`。
- 数据是在线到来的流：只保留三个下标和累计答案，天然 `O(1)` 空间。

**同模式。** LC 2762 不间断子数组、LC 713 乘积小于 K 的子数组、LC 992 K 个不同整数的子数组、LC 930 和相同的二元子数组。
