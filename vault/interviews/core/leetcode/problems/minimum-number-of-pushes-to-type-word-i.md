## Q
**LC 3014 输入单词需要的最少按键次数 I**｜Easy

九宫格电话键盘，数字 `2` 到 `9` 共 `8` 个键可以重新映射字母，每个字母映射到一个键，一个键可以放多个字母；按第 `i` 次放到该键的字母需要按 `i` 下。给定由**互不相同**的小写字母组成的 `word`，求输入它所需的最少按键次数。

## A
**一句话。** 前 `8` 个字母放在各键第一位（`1` 下），接下来 `8` 个放第二位（`2` 下）……，第 `i` 个字母（从 `0` 起）要 `i // 8 + 1` 下。

```python
def minimum_pushes(word):
    return sum(i // 8 + 1 for i in range(len(word)))
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 把键数当成 `9`：数字 `1` 不能映射字母，只有 `8` 个键。
- 一个键上字母越多越好：同键字母要按不同次数，尽量平均分摊。

**追问。**
- 字母有重复呢？：见 LC 3016，按频率降序分配，频率高的放前面。
