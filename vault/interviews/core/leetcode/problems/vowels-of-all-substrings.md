## Q
**LC 2063 所有子字符串中的元音**｜Medium

字符串 `word`。求它所有子字符串中元音字母（`a e i o u`）个数的总和，注意结果可能很大。

## A
**一句话。** 按贡献拆：下标 `i` 的元音出现在 `(i + 1) × (n - i)` 个子串里（左端点 `i + 1` 种、右端点 `n - i` 种），累加即可。

```python
def count_vowels(word):
    n = len(word)
    return sum((i + 1) * (n - i)           # 以 i 为元音的子串数
               for i, c in enumerate(word) if c in 'aeiou')
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 枚举全部子串：`O(n²)` 甚至 `O(n³)` 会超时。
- 乘数写成 `i * (n - i)`：左端点可以取 `0..i` 共 `i + 1` 种。

**追问。**
- 这个套路叫什么？：贡献法，把"所有子串的某个量"拆成"每个元素在多少子串里"。

**同模式。** LC 2104 子数组范围和、LC 907 子数组的最小值之和、LC 1456 定长子串中元音的最大数目、LC 2262 字符串的总引力
