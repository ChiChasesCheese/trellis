## Q
**LC 1247 交换字符使得字符串相同**｜Medium

`s1`、`s2` 只含 `x`、`y`。每次在两个不同字符串中各选一个字符互换。求让两串相同的最少交换次数，做不到返回 `-1`。

## A
**一句话。** 只统计两串不同的位置，分 `xy` 和 `yx` 两类，同类两个换一次，一对异类换两次。

```python
def minimum_swap(s1, s2):
    xy = yx = 0         # xy：s1 是 x 而 s2 是 y 的位置数
    for a, b in zip(s1, s2):
        if a != b:
            if a == "x":
                xy += 1
            else:
                yx += 1
    if (xy + yx) % 2:   # 不同位置为奇数，无解
        return -1
    return xy // 2 + yx // 2 + 2 * (xy % 2)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 答案写成不同位置数的一半：`("xy", "yx")` 得 `1`，应为 `2`。
- 异类配对漏乘 `2`：一个 `xy` 配一个 `yx` 要两次交换。

**追问。**
- 允许交换同一字符串内部的字符呢？：异类一对只要一次，答案变成 `(xy + yx) // 2`。
- 为什么 `xy` 和 `yx` 奇偶一致？：不同位置总数为偶才有解，故 `xy % 2 == yx % 2`。

**同模式。** LC 1790 仅执行一次字符串交换能否使两个字符串相等、LC 854 相似度为 K 的字符串、LC 1963 使字符串平衡的最小交换次数
