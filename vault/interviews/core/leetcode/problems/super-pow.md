## Q
**LC 372 超级次方**｜Medium

计算 `a^b mod 1337`，其中 `a` 是正整数，`b` 是用数组表示的超大正整数（每个元素一位十进制数字，高位在前）。

## A
**一句话。** 按十进制逐位处理 `b`：`a^(10x+d) = (a^x)^10 · a^d`，每读一位就把当前结果十次方再乘上 `a^d`，全程取模。

```python
def super_pow(a, b):
    MOD = 1337
    res = 1
    for d in b:                   # 高位到低位
        res = pow(res, 10, MOD) * pow(a, d, MOD) % MOD
    return res
```

**复杂度。** 时间 `O(len(b)·log 10)`，即 `O(len(b))`，空间 `O(1)`。

**易错点。**
- 把 `b` 先转成整数再 `pow`：位数极大时不现实，要按位拆。
- 忘了取模：`pow(res, 10, MOD)` 的第三个参数不能少，否则数值爆炸。
- 用欧拉定理降指数：`1337 = 7×191` 合数，实现麻烦，逐位拆更直接。

**追问。**
- 手写快速幂怎么做？：`res·a^d` 的 `a^d` 用平方取模，`^10` 可写成 `x⁸·x²`。
- 为什么 `10x + d` 的拆法成立？：`a^(10x+d) = a^(10x) · a^d = (a^x)^10 · a^d`，从高位读入时 `b` 每多一位就是 `x → 10x + d`。

**同模式。** LC 50 Pow(x, n)、LC 29 两数相除、LC 1922 统计好数字的数目、LC 69 x 的平方根
