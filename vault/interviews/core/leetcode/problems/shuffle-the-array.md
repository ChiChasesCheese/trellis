## Q
**LC 1470 重新排列数组**｜Easy

长度为 `2n` 的数组 `nums = [x1,...,xn,y1,...,yn]`，返回 `[x1,y1,x2,y2,...,xn,yn]`。

## A
**一句话。** 前半和后半两两配对（`zip`），依次放入结果。

```python
def shuffle(nums, n):
    ans = []
    for x, y in zip(nums[:n], nums[n:]):   # 前半和后半配对
        ans += [x, y]
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 就地交换：下标 `i` 与 `2i` 互换会覆盖未读取的值，要么另开数组，要么用位运算打包。
- 切片边界错：前半是 `nums[:n]`，后半是 `nums[n:]`。

**追问。**
- 能原地做吗？：值域 `≤ 1000`（10 位），把一个数打包进另一个数的高位，读出再解包，`O(1)` 额外空间。
- 另一种写法？：`ans[::2] = nums[:n]`，`ans[1::2] = nums[n:]`。

**同模式。** LC 1929 数组串联、LC 88 合并两个有序数组、LC 189 轮转数组
