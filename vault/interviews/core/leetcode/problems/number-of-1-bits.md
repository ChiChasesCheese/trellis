## Q
**LC 191 位 1 的个数（Number of 1 Bits）**｜Easy

给定正整数 `n`，返回其二进制表示中 `1` 的个数（汉明重量）。

## A
**一句话。** 反复执行 `n &= n - 1` 清掉最低位的 `1`，执行次数就是答案（Kernighan）。

```python
def hamming_weight(n):
    cnt = 0
    while n:
        n &= n - 1      # 清掉最低位的 1
        cnt += 1
    return cnt
```

**复杂度。** 时间 `O(k)`（`k` 为 `1` 的个数），空间 `O(1)`。

**易错点。**
- 写成 `n & -n`：它是保留最低位的 `1`，`n` 永不归零，死循环。
- 输入为负数：Python 负数高位无限延伸，`n &= n - 1` 不会到 0；先 `n & 0xFFFFFFFF`。

**追问。**
- 多次调用怎么优化？：预建 256 项的 `table[x] = table[x >> 1] + (x & 1)`，把 `n` 拆成 4 个字节各查一次相加。
- 为什么只清掉最低位的 1？：`n - 1` 把最低位 `1` 变 `0`、其右侧的 `0` 全变 `1`，相与后这一段全为 `0`，高位不变。

**同模式。** LC 338 比特位计数、LC 461 汉明距离、LC 231 2 的幂、LC 136 只出现一次的数字
