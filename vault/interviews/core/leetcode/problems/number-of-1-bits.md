## Q
**LC 191 位 1 的个数（Number of 1 Bits）**｜Easy

给定一个正整数 `n`，编写函数获取其二进制表达式中设置位（值为 `1` 的位）的个数（也称汉明重量）。`1 <= n <= 2^31 - 1`。进阶：如果多次调用这个函数，你将如何优化你的算法？例：`n = 11`（`1011`）→ `3`；`n = 128`（`10000000`）→ `1`；`n = 2147483645`（`1111111111111111111111111111101`）→ `30`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 位运算：`n & (n - 1)` 清除最低位的 1（Brian Kernighan 算法）。

**一句话。** 每执行一次 `n &= n - 1` 就清掉最低位的一个 `1`，直到 `n` 为 0，执行的次数就是 `1` 的个数。

**识别。** 「统计二进制里 1 的个数」是位运算基础题；逐位检查要循环位数次，Kernighan 只循环 `1` 的个数次。`n < 2^31`，两者都是 `O(1)` 级别。

**推导。** 逐位检查：`count += n & 1; n >>= 1`，循环到 `n == 0`，最多 31 次。优化：`n - 1` 会把最低位的 `1` 变成 `0`，并把它右边的全 `0` 变成 `1`，`n & (n - 1)` 正好清掉这个最低位的 `1`，其余位不变，所以每次循环恰好消除一个 `1`。

```python
def hamming_weight(n: int) -> int:
    count = 0
    while n:
        n &= n - 1                                # 清掉最低位的 1：循环次数 = 1 的个数
        count += 1
    return count
```

运行：`11` → `3`，`128` → `1`，`2147483645` → `30`，`1` → `1`，`2147483647` → `31`。

**复杂度。** 时间 `O(k)`，`k` 是 `1` 的个数（至多 31）；空间 `O(1)`。

**拓展优化。**
- Python 3.10+ 有内置 `int.bit_count()`，C 实现；先写手动版，再说内置版。多次调用时可以预先算 8 位或 16 位的查表，每次调用 2 到 4 次查表。

```python
def hamming_weight_builtin(n: int) -> int:
    return n.bit_count()                          # Python 3.10+ 内置，C 实现
```

**易错点。**
- 把 `n & (n - 1)` 写成 `n & -n`：它保留的是最低位的 `1` 而不是清掉它，`n` 永远不为 0，死循环。
- 输入可能是负数时用 `while n:`：Python 的负整数最高位无限延伸，`n &= n - 1` 永不到 0，死循环；先用 `n & 0xFFFFFFFF` 截成 32 位无符号。题目保证 `n` 是正数。
- 用 `bin(n).count("1")` 是对的，但面试官通常要求展示位运算，先写 Kernighan 再提内置做法。

**同模式。** LC 338 比特位计数、LC 461 汉明距离、LC 136 只出现一次的数字、LC 231 2 的幂。
