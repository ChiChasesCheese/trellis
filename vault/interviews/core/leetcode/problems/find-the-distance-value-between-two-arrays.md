## Q
**LC 1385 两个数组间的距离值**｜Easy

给你两个整数数组 `arr1`、`arr2` 和一个整数 `d`，返回两个数组之间的距离值。距离值定义为符合以下要求的元素数目：对于元素 `arr1[i]`，不存在任何元素 `arr2[j]` 满足 `|arr1[i] - arr2[j]| <= d`。`1 <= arr1.length, arr2.length <= 500`，`-10^3 <= arr1[i], arr2[j] <= 10^3`，`0 <= d <= 100`。

例：`arr1 = [4,5,8]`，`arr2 = [10,9,1,8]`，`d = 2` → `2`（`4` 和 `5` 与 `arr2` 的所有元素都相差超过 2；`8` 与 `10`、`9`、`8` 相差不超过 2，不符合）；`arr1 = [1,4,2,3]`，`arr2 = [-4,-3,6,10,20,30]`，`d = 3` → `2`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 排序 + 二分查找下界（lower bound）：把「不存在元素落在某区间内」变成一次区间存在性查询。

**核心题。**

- LC 35 搜索插入位置（Hot 100、Top Interview 150）：同一个 lower bound：这里多一步检查落点的值是否超出区间上界

**一句话。** `|x - y| <= d` 就是 `y` 落在闭区间 `[x - d, x + d]` 内；把 `arr2` 排序，找到第一个 `>= x - d` 的元素，它不存在或大于 `x + d`，`x` 就符合要求。

**识别。** 「不存在任何元素满足 `|a - b| <= d`」：绝对值不等式可以拆成一个区间；「任意一个元素」只需要一次存在性判断，而有序数组上问「区间内有没有元素」正是二分。

**推导。** 直接做是双重循环，对每个 `x` 扫一遍 `arr2`，`O(n * m)`。浪费在于：判断区间 `[x - d, x + d]` 内有没有元素，并不需要看完所有 `y`。`arr2` 有序后，只要看区间左端点右侧的第一个元素：连它都超出右端点，后面更大的元素也都超出。

```python
from bisect import bisect_left


def find_the_distance_value(arr1: list[int], arr2: list[int], d: int) -> int:
    arr2 = sorted(arr2)                       # 不改动入参；有序后才能二分
    count = 0
    for x in arr1:
        i = bisect_left(arr2, x - d)          # 第一个 >= x - d 的位置，即区间内最小的候选
        if i == len(arr2) or arr2[i] > x + d:  # 没有候选，或最小的候选也超出 x + d：区间为空
            count += 1
    return count
```

运行：`arr1 = [4,5,8]`，`arr2 = [10,9,1,8]`，`d = 2` → `2`；`arr1 = [1,4,2,3]`，`arr2 = [-4,-3,6,10,20,30]`，`d = 3` → `2`；`arr1 = [2,1,100,3]`，`arr2 = [-5,-2,10,-3,7]`，`d = 6` → `1`；`arr1 = [5]`，`arr2 = [5]`，`d = 0` → `0`；`arr1 = [5]`，`arr2 = [6]`，`d = 0` → `1`。

**复杂度。** 设 `n = len(arr1)`，`m = len(arr2)`。时间 `O((n + m) log m)`：排序 `O(m log m)`，每个 `x` 二分一次 `O(log m)`；空间 `O(m)`：排序后的副本。

**易错点。**
- 用 `bisect_right(arr2, x - d)`：跳过了恰好等于 `x - d` 的元素。`arr1 = [3]`，`arr2 = [1]`，`d = 2` 得到 `1`，正确是 `0`（`|3 - 1| = 2 <= d`）。
- 只从 `x` 往右看：`i = bisect_left(arr2, x)` 再判断 `arr2[i] - x > d`，漏掉比 `x` 小的元素。`arr1 = [5]`，`arr2 = [4,10]`，`d = 1` 得到 `1`，正确是 `0`。
- 忘记判断 `i == len(arr2)`：`x - d` 比所有元素都大时下标越界。`arr1 = [5]`，`arr2 = [1]`，`d = 1` 抛 `IndexError`，正确是 `1`。

**同模式。** LC 34 在排序数组中查找元素的第一个和最后一个位置、LC 475 供暖器、LC 658 找到 K 个最接近的元素、LC 2300 咒语和药水的成功对数。
