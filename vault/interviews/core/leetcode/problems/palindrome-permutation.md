## Q
**LC 266 回文排列**｜Easy

给字符串 `s`，判断它的某个排列能否成为回文串。

## A
**一句话。** 回文串里至多一个字符出现奇数次（放在正中间），其余都成对。

```python
def can_permute_palindrome(s):
    odd = sum(v & 1 for v in Counter(s).values())
    return odd <= 1              # 奇数次的字符不超过一种
```

**复杂度。** 时间 `O(n)`，空间 `O(字符集)`。

**易错点。**
- 要求所有字符都出现偶数次：长度为奇数的回文串中间那个字符可以出现奇数次。
- 判断 `odd == 1`：全是偶数次（`odd == 0`）同样合法。

**追问。**
- 不用计数表怎么做？：用集合，字符出现就切换成员资格，最后集合大小不超过 1。
- 要求构造出回文呢？：LC 267，对一半字符做全排列，再拼上镜像和中间字符。

**同模式。** LC 409 最长回文串、LC 242 有效的字母异位词、LC 125 验证回文串
