## Q
**LC 9 回文数**｜Easy

判断整数 `x` 是不是回文数（负数不是）。进阶：不转字符串。

## A
**一句话。** 转成字符串与反转比较，负号反过来跑到末尾，天然不相等。

```python
def is_palindrome(x):
    s = str(x)
    return s == s[::-1]
```

**复杂度。** 时间 `O(log x)`，空间 `O(log x)`。

**易错点。**
- 取绝对值再比较：`-121` 会被判成 `True`。
- 数位版本漏掉以 `0` 结尾：`x=10` 会判 `True`，要先排除 `x % 10 == 0 and x != 0`。
- 数位版本奇数位只比 `x == rev`：`121` 停在 `x=1, rev=12`，还要比 `x == rev // 10`。

**追问。**
- 不转字符串怎么做？：反转后一半数位，与前一半比较（`x == rev` 或 `x == rev // 10`）。
- 为什么只反转一半？：整个反转在 32 位下会溢出，一半永远不超过原数。

**同模式。** LC 125 验证回文串、LC 234 回文链表、LC 7 整数反转、LC 5 最长回文子串
