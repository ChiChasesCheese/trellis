## Q
**LC 720 词典中最长的单词**｜Easy

给字符串数组 `words`，找出最长的单词，要求它的每个前缀也都在 `words` 里。有多个答案返回字典序最小的，没有返回 `""`。

## A
**一句话。** 排序后遍历：单词去掉最后一个字符的前缀已「可构造」，它就可构造；长度严格更长才更新答案。

```python
def longest_word(words):
    built, best = {""}, ""
    for w in sorted(words):          # 字典序：前缀一定先出现
        if w[:-1] in built:
            built.add(w)
            if len(w) > len(best):   # 严格大于：同长保留字典序小的
                best = w
    return best
```

**复杂度。** 时间 `O(L log n)`（`L` 为字符总数），空间 `O(L)`。

**易错点。**
- 更新用 `>=`：同长时会被字典序更大的覆盖。
- 不排序：长单词先于它的前缀出现，判断时前缀还没加入集合。

**追问。**
- 用字典树怎么做？：全部插入，从根 DFS，只沿「结点是单词结尾」的边走，最深且字典序最小的就是答案。
- 为什么排序后只看 `w[:-1]`？：`w[:-1]` 已可构造就意味着它的所有更短前缀都可构造。
