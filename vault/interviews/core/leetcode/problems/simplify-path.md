## Q
**LC 71 简化路径**｜Medium

把 Unix 绝对路径化成规范形式：`.` 当前目录，`..` 上一级（根目录留在根），多个 `/` 合并，`...` 是合法目录名。

## A
**一句话。** 按 `/` 切分后用栈：`..` 弹栈，空串和 `.` 忽略，其余入栈，最后拼回去。

```python
def simplify_path(path):
    stack = []
    for part in path.split('/'):
        if part == '..':
            if stack:            # 根目录没有上一级
                stack.pop()
        elif part and part != '.':
            stack.append(part)   # '...' 是合法名字
    return '/' + '/'.join(stack)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- `..` 不判栈空：`"/../"` 抛 `IndexError`，应得 `"/"`。
- 用 `startswith('.')` 判特殊段：`"/.../a/../b"` 丢掉 `...`，只有恰好等于 `.` 和 `..` 才特殊。

**追问。**
- 相对路径怎么办？：栈空或栈顶也是 `..` 时保留 `..`，结果为空返回 `.`。
- 符号链接怎么办？：`a/b/..` 不一定是 `a`，词法化简和真实解析（`realpath`）是两回事。

**同模式。** LC 20 有效的括号、LC 150 逆波兰表达式求值、LC 394 字符串解码、LC 1047 删除字符串中的所有相邻重复项
