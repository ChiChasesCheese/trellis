## Q
**LC 2673 使二叉树所有路径值相等的最小代价**｜Medium

`n` 个节点的满二叉树（节点 `i` 的孩子是 `2i`、`2i+1`），`cost[i-1]` 是节点 `i` 的值，每次操作可给任一节点加 `1`。求让根到所有叶子的路径值相等的最少操作数。

## A
**一句话。** 自底向上：每个节点补上两个孩子路径值之差，补在较小的一侧，再把较大路径值上传。

```python
def min_increments(n, cost):
    c = [0] + cost               # 改成 1 下标
    ans = 0
    for i in range(n // 2, 0, -1):   # 从最后一个非叶子往上
        left, right = c[2 * i], c[2 * i + 1]
        ans += abs(left - right)
        c[i] += max(left, right)     # c[i] 变成 i 到叶子的路径值
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 把增量补在叶子上：`(7,[1,5,2,2,3,3,1])` 得 `9`，应为 `6`，补在子树根能同时抬高其下所有叶子。
- 只比较孩子自己的值、不累加路径：`(7,[1,2,3,4,5,6,7])` 得 `3`，应为 `5`。
- 方向从上往下：还不知道子树的路径值，无法比较。

**追问。**
- 想省空间？：直接在 `cost` 上累加，`O(1)` 额外空间，代价是修改输入。
- 要输出具体怎么加？：每个非叶子处，较小孩子的编号和差值就是一次操作，记下即可。

**同模式。** LC 124 二叉树中的最大路径和、LC 979 在二叉树中分配硬币、LC 968 监控二叉树、LC 337 打家劫舍 III
