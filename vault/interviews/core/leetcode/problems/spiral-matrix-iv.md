## Q
**LC 2326 螺旋矩阵 IV**｜Medium

给整数 `m`、`n` 和一个链表 `head`。创建 `m × n` 矩阵，从左上角开始按顺时针螺旋顺序依次填入链表的值，剩余位置填 `-1`。

## A
**一句话。** 方向数组加「撞墙或撞到已填格就右转」：先沿当前方向前进，下一格越界或已填就换下一个方向。

```python
def spiral_matrix(m, n, head):
    res = [[-1] * n for _ in range(m)]
    dirs = ((0, 1), (1, 0), (0, -1), (-1, 0))  # 右下左上
    i = j = d = 0
    while head:
        res[i][j] = head.val
        head = head.next
        x, y = i + dirs[d][0], j + dirs[d][1]
        if not (0 <= x < m and 0 <= y < n
                and res[x][y] == -1):
            d = (d + 1) % 4          # 撞墙或撞到已填格，右转
            x, y = i + dirs[d][0], j + dirs[d][1]
        i, j = x, y
    return res
```

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`（输出）。

**易错点。**
- 用 `-1` 作「未填」的标记：链表值非负，所以能区分；换成别的哨兵也行，但要保证与链表值不冲突。
- 链表走完后再多走一步：循环条件是 `while head`，下标更新不会越界取值。
- 转向后不重新算下一格：旧的 `x, y` 已经不可用。

**追问。**
- 不用已填标记还能做吗？：维护上下左右四条边界，走完一条边收缩对应边界。
- 链表比格子多怎么办？：题目保证结点数不超过 `mn`。
