## Q
**LC 1175 质数排列**｜Easy

把 `1` 到 `n` 排成一个排列，要求质数必须放在质数下标（下标从 1 开始）的位置上。求合法排列数，对 `1e9+7` 取模。

## A
**一句话。** 质数数 `p` 个，质数下标也恰有 `p` 个，质数在质数位置全排列 `p!`，其余数在其余位置 `(n - p)!`，两部分相乘。

```python
def num_prime_arrangements(n):
    MOD = 10 ** 9 + 7
    p = sum(all(i % d for d in range(2, isqrt(i) + 1))
            for i in range(2, n + 1))     # 1..n 里质数个数
    return factorial(p) * factorial(n - p) % MOD
```

**复杂度。** 时间 `O(n√n)`，空间 `O(1)`。

**易错点。**
- 把 `1` 当成质数：`1` 不是质数，枚举从 `2` 开始。
- 下标从 0 算：题目下标从 1 开始，质数位置的个数就是 `1..n` 里质数的个数。
- 阶乘逐步取模：Python 大整数不会溢出，最后取一次模即可。

**追问。**
- `n` 更大怎么办？：用埃氏筛求 `p`，阶乘在循环里边乘边取模。
- 为什么两部分相互独立？：质数只占质数位，其余数只能去其余位，两边的排列互不影响。

**同模式。** LC 204 计数质数、LC 2523 范围内最接近的两个质数
