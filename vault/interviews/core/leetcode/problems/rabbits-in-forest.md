## Q
**LC 781 森林中的兔子**｜Medium

每只被问到的兔子回答「还有几只其它兔子与我同色」，`answers` 收集了部分兔子的回答，求森林中兔子的最少数量。

## A
**一句话。** 回答 `x` 的兔子同色成组，每组恰 `x+1` 只，回答相同的 `count` 只需要 `ceil(count/(x+1))` 组。

```python
def num_rabbits(answers):
    total = 0
    for x, count in Counter(answers).items():
        groups = -(-count // (x + 1))   # 向上取整
        total += groups * (x + 1)       # 每组按满员计
    return total
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 每只兔子都另起一组：`[10,10,10]` 得 `33`，应为 `11`。
- 向下取整：`[1,1,1]` 得 `2`，应为 `4`，第三只要另起一组。
- 只返回 `len(answers)`：漏掉没被问到的同色兔子，`[1,1,2]` 得 `3`，应为 `5`。

**追问。**
- 数据是流、不能先计数？：每个回答值记「当前组剩余名额」，没名额就新开一组，总数加 `x+1`。
- 为什么不同回答值一定不同色？：同色的兔子回答一定相同。

**同模式。** LC 135 分发糖果、LC 455 分发饼干、LC 134 加油站、LC 621 任务调度器
