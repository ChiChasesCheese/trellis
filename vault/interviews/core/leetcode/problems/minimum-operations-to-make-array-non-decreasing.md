## Q
**LC 3914 使数组非递减需要的最小累计值**｜Medium

每次选一个子数组，给每个元素加同一个正整数 `x`。求把数组变成非递减时所有 `x` 之和的最小值。

## A
**一句话。** 看相邻差 `d[i] = nums[i] - nums[i-1]`：一次操作只抬高子数组左端那一个差（抬高 `x`），所以答案至少是所有下降量之和；对每个下降处加一次后缀就能取到。

```python
def min_operations(nums):
    ans = 0
    for a, b in pairwise(nums):
        if a > b:
            ans += a - b   # 给 b 及其后缀整体加 a - b
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 把每个位置需要抬高的量相加：`[5,1,2,3]` 抬高量是 `[0,4,3,2]`，相加得 `9`，但一次后缀加 `4` 就够，答案 `4`。
- 只给下降处那一个元素加：后面的元素会相对变小，产生新的下降。

**追问。**
- 为什么是下界？：操作 `[l, r]` 加 `x` 只让 `d[l]` 变大 `x`，`d[r+1]` 变小；每个负的 `d` 都要单独被抬回 `0`。
- 变成指定目标数组（LC 1526）？：差分里正的部分之和。

**同模式。** LC 1526 形成目标数组的子数组最少增加次数、LC 3229 使数组等于目标数组所需的最少操作次数、LC 1094 拼车
