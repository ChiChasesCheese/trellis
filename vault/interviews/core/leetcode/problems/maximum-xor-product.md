## Q
**LC 2939 最大异或乘积**｜Medium

给定 `a`、`b`、`n`，选 `0 <= x < 2^n`，求 `(a XOR x) * (b XOR x)` 的最大值，对 `10^9+7` 取余。

## A
**一句话。** 第 `n` 位以上 `x` 改不了；低 `n` 位从高到低贪心：两数该位相同就都变成 1，不同就把 1 给当前较小的那个，让两数之和不变时尽量接近。

```python
def maximum_xor_product(a, b, n):
    ax = a >> n << n            # 高位固定不变
    bx = b >> n << n
    for i in range(n - 1, -1, -1):
        bit = 1 << i
        if (a & bit) == (b & bit):
            ax |= bit           # 同为 0 或同为 1：都取 1
            bx |= bit
        elif ax > bx:
            bx |= bit           # 不同：1 给较小者
        else:
            ax |= bit
    return ax * bx % (10**9 + 7)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 先取模再比较大小：`ax > bx` 必须用真实值比，取模只在最后一步。
- 忘了保留第 `n` 位以上的原值：`x < 2^n` 改不到高位。

**追问。**
- 为什么给较小者？：该位两数一个 1 一个 0，和固定，差越小乘积越大。
- 为什么高位相同时要都取 1？：`x` 在这一位取 0 或 1 能让两数同时变成 1，两数都变大，乘积一定更大。

**同模式。** LC 136 只出现一次的数字、LC 421 数组中两个数的最大异或值
