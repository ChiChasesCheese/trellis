## Q
**LC 999 可以被一步捕获的棋子数**｜Easy

`8 × 8` 的棋盘上有一个白车 `R`，若干白象 `B`、黑卒 `p`，其余是 `.`。车可沿上下左右移动，直到碰到棋盘边界或任何棋子。统计车一步能捕获的卒的数量（碰到的第一个棋子是 `p` 才行）。

## A
**一句话。** 找到车的位置，向四个方向各走到第一个非空格：是 `p` 则计数，是 `B` 或出界则这个方向结束。

```python
def num_rook_captures(board):
    for i in range(8):
        for j in range(8):
            if board[i][j] != "R":
                continue
            ans = 0
            for dx, dy in ((1, 0), (-1, 0),
                           (0, 1), (0, -1)):
                x, y = i + dx, j + dy
                while 0 <= x < 8 and 0 <= y < 8:
                    if board[x][y] != ".":     # 遇到第一个棋子
                        ans += board[x][y] == "p"
                        break
                    x += dx
                    y += dy
            return ans
```

**复杂度。** 时间 `O(1)`（固定 `8 × 8`），空间 `O(1)`。

**易错点。**
- 越过象继续找：被己方棋子挡住后这个方向就结束，不能再数后面的卒。
- 一个方向数多个卒：车只能捕获碰到的第一个棋子，数到就 `break`。
