## Q
**LC 229 多数元素 II**｜Medium

找出数组中所有出现次数超过 `⌊n/3⌋` 的元素，顺序任意。

## A
**一句话。** 哈希计数后留下次数 `> n // 3` 的值，答案最多两个。

```python
def majority_element(nums):
    limit = len(nums) // 3
    cnt = Counter(nums)
    return [x for x in cnt if cnt[x] > limit]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 用 `>=`：`[1,2,3]` 中 `n // 3 = 1`，会返回 `[1,2,3]`，应为 `[]`。
- 套用 LC 169 只返回一个：`[1,2]` 中 `n // 3 = 0`，应返回 `[1,2]`。

**追问。**
- 怎么做到 `O(1)` 空间？：两候选摩尔投票，三个不同的数一起抵消，最后再数一遍确认。
- 推广到超过 `n/k`？：保留 `k-1` 个候选（Misra-Gries），空间 `O(k)`。

**同模式。** LC 169 多数元素、LC 347 前 K 个高频元素、LC 2404 出现最频繁的偶数元素
