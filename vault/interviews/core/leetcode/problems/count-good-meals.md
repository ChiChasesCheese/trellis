## Q
**LC 1711 大餐计数**｜Medium

`deliciousness[i]` 是第 `i` 道菜的美味程度。选两道不同的菜，若美味程度之和是 `2` 的幂，就是一顿大餐。求大餐的数量，结果对 `10^9 + 7` 取模。

## A
**一句话。** 两数之和的升级版：一次遍历，对每个数枚举所有 `2` 的幂 `t`，查哈希表里 `t - x` 出现过几次。

```python
def count_pairs(deliciousness):
    M = 10 ** 9 + 7
    cnt = {}
    ans = 0
    for x in deliciousness:
        for k in range(22):               # 和最大 2^21
            ans += cnt.get((1 << k) - x, 0)
        cnt[x] = cnt.get(x, 0) + 1        # 先查后存，不会配到自己
    return ans % M
```

**复杂度。** 时间 `O(21n)`，空间 `O(n)`。

**易错点。**
- 幂次范围写小：`2^20 + 2^20 = 2^21`，`k` 要到 `21`。
- 先存后查：同一道菜会和自己配成一对。
- 只取模最后一步：Python 不溢出，可以最后再取模；其他语言每次累加都要取模。

**追问。**
- 值很大但个数很少怎么办？：枚举的是幂次而不是值，复杂度只和 `n` 与幂次个数有关。

**同模式。** LC 1 两数之和、LC 1679 K 和数对的最大数目、LC 167 两数之和 II - 输入有序数组、LC 2824 统计和小于目标的下标对数目
