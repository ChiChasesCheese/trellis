## Q
**LC 397 整数替换**｜Medium

给正整数 `n`：偶数就换成 `n / 2`；奇数可以换成 `n + 1` 或 `n - 1`。求把 `n` 变成 1 的最少替换次数。

## A
**一句话。** 偶数必除 2；奇数看末两位：以 `...01` 结尾减 1（会多出一串可连续除的 0），以 `...11` 结尾加 1（进位后能连续除 2），特例 `n = 3` 减 1。

```python
def integer_replacement(n):
    steps = 0
    while n != 1:
        if n % 2 == 0:
            n //= 2
        elif n == 3 or n % 4 == 1:
            n -= 1               # ...01：减 1 后末位多个 0
        else:
            n += 1               # ...11：加 1 进位成一串 0
        steps += 1
    return steps
```

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- 奇数一律加 1 或一律减 1：`3` 应减 1（`3→2→1`），`7` 应加 1，要看二进制末两位。
- `n = 2^31 - 1` 时 `n + 1` 溢出：Python 无此问题，其他语言要用长整型。
- 忘了 `n = 3` 特例：`3 % 4 == 3` 会走加 1 分支，多一步。

**追问。**
- 记忆化搜索怎么做？：`f(n) = 1 + min(f(n + 1), f(n - 1))`（奇数），状态数只有 `O(log n)`。
- 为什么贪心正确？：目标是尽可能多除 2，`...11` 加 1 能产生至少两个连续的零，`...01` 减 1 同理，选能产生更多除 2 的方向。
