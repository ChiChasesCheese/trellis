## Q
**LC 190 颠倒二进制位**｜Easy

颠倒一个 32 位无符号整数的二进制位。

## A
**一句话。** 循环 32 次，结果左移一位并补上 `n` 的最低位，再把 `n` 右移一位。

```python
def reverse_bits(n):
    res = 0
    for _ in range(32):
        res = (res << 1) | (n & 1)   # 接上 n 的最低位
        n >>= 1
    return res
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 用 `while n:` 循环：前导零没处理，`43261596` 得 `15065253`，应为 `964176192`。
- 先 `res |= n & 1` 再 `res <<= 1`：最后一轮多左移一位，结果翻倍。
- 字符串版漏了 `zfill(32)`：同样丢掉前导零。

**追问。**
- 多次调用怎么优化？：预先算好 `256` 个字节的反转表，把 `n` 拆成 4 个字节查表。
- 不循环 32 次？：分治交换，依次交换相邻 `16/8/4/2/1` 位的块，`5` 步完成。

**同模式。** LC 191 位 1 的个数、LC 338 比特位计数、LC 7 整数反转、LC 461 汉明距离
