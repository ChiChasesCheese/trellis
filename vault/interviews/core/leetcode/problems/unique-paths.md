## Q
**LC 62 不同路径**｜Medium

`m x n` 网格，机器人从左上角出发，每次只能向下或向右一步，求走到右下角的不同路径数。

## A
**一句话。** 网格 DP 计数：`dp[i][j]` 等于从上方和从左方到达的路径数之和。

```python
def unique_paths(m, n):
    # dp[i][j]：从左上角走到 (i, j) 的路径数
    dp = [[1] * n for _ in range(m)]   # 首行首列都只有 1 条
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
    return dp[m-1][n-1]
```

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。

**易错点。**
- 全表初始化为 `0`：递推全是 `0`，`(3, 7)` 得 `0`。
- 只把第一行设为 `1`、第一列留 `0`：`(3, 7)` 得 `21`，应为 `28`。

**追问。**
- 有没有 `O(1)` 空间的公式？：共走 `m+n-2` 步，选 `m-1` 步向下，答案 `comb(m+n-2, m-1)`。
- 有障碍物（LC 63）？：障碍格置 `0`，不能再用组合公式。
- 必须经过某个格子？：拆成两段，路径数相乘。

**同模式。** LC 63 不同路径 II、LC 64 最小路径和、LC 120 三角形最小路径和、LC 980 不同路径 III
