## Q
**LC 2124 检查是否所有 A 都在 B 之前**｜Easy

字符串 `s` 只含 `'a'` 和 `'b'`。判断是否每个 `'a'` 都排在每个 `'b'` 之前。

## A
**一句话。** 把"全局有序"换成"相邻不逆序"：只要没有子串 `"ba"`，所有 `a` 就都在 `b` 前面。

```python
def check_string(s):
    # 有 b 在某个 a 前面，中间必有一处相邻的 "ba"
    return 'ba' not in s
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 没有 `a` 或没有 `b`：条件自动成立，返回 `True`，不要特判成 `False`。
- 写成比较首个 `b` 和首个 `a` 的位置：`"aba"` 会误判，要比的是最后一个 `a` 和第一个 `b`。

**追问。**
- 不用子串查找，一次遍历怎么写？：记 `seen_b`，见到 `b` 置真，之后再见到 `a` 就返回 `False`。
- 字符换成任意字母，判断是否非递减？：同一个思路，检查每对相邻字符 `s[i] <= s[i+1]`。

**同模式。** LC 28 找出字符串中第一个匹配项的下标、LC 1784 检查二进制字符串字段、LC 896 单调数列
