## Q
**剑指 Offer 10- II 青蛙跳台阶问题**｜Easy

青蛙每次跳 1 级或 2 级，求跳上 `n` 级台阶的不同跳法数，结果对 `1000000007` 取模。

## A
**一句话。** 最后一跳是 1 级或 2 级，`f(n) = f(n-1) + f(n-2)`，用两个变量滚动。

```python
def num_ways(n):
    MOD = 1_000_000_007
    a, b = 1, 1              # a = f(i), b = f(i+1)
    for _ in range(n):
        a, b = b, (a + b) % MOD
    return a
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 初值写成 `0, 1`：`n = 0` 得 `0`，应为 `1`；`n = 2` 得 `1`，应为 `2`。
- 忘了每步取模：Java / C++ 中间值会溢出。

**追问。**
- 每次可跳 `1..n` 级？：`f(n) = 2^(n-1)`，每个中间级「落或不落」。
- `n` 到 `10^18`？：矩阵快速幂，`[[1,1],[1,0]]` 的 `n` 次方，`O(log n)`。

**同模式。** LC 70 爬楼梯、LC 509 斐波那契数、LC 746 使用最小花费爬楼梯、LC 91 解码方法
