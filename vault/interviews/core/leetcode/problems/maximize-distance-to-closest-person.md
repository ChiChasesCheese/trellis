## Q
**LC 849 到最近的人的最大距离**｜Medium

给你一个数组 `seats` 表示一排座位，`seats[i] = 1` 代表有人坐在第 `i` 个座位上，`seats[i] = 0` 代表座位是空的。至少有一个空座位，且至少有一人已经坐在座位上。亚历克斯希望坐在一个空座位上，使他与离他最近的人之间的距离达到最大化，返回这个最大距离。`2 <= seats.length <= 2 * 10^4`。例：`seats = [1,0,0,0,1,0,1]` → `2`（坐 `seats[2]`）；`seats = [1,0,0,0]` → `3`；`seats = [0,1]` → `1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 双指针 / 扫描「相邻已坐座位」之间的空档。

**一句话。** 答案只由连续空位段决定：两端的段（只有一侧有人）距离是段长，中间的段（两侧有人）距离是段长的一半向上取整，取所有段的最大值。

**识别。** 「到最近的人的最大距离」是对一维点集求最大空隙的中点；`n = 2 * 10^4` 时对每个空位算最近距离的 `O(n^2)` 也能过，但一遍扫描更直接。

**推导。** 暴力：对每个空座位向左右找最近的人，`O(n^2)`。一个空位段 `[l, r]` 夹在两个人 `l - 1` 和 `r + 1` 之间，最优位置是中点，距离 `(r + 1 - (l - 1)) // 2 = (相邻两人下标差) // 2`；开头的段只能贴着右边的人，距离是第一个人的下标；结尾同理。扫描时记上一个人的下标 `prev` 即可。

```python
def max_dist_to_closest(seats: list[int]) -> int:
    prev = -1                              # 上一个有人的座位下标；-1 表示左边还没有人
    best = 0
    for i, s in enumerate(seats):
        if s == 1:
            # 左边没人：贴着第 i 个人坐在最左端，距离 i；否则坐在两人中间，距离 (i - prev) // 2
            best = max(best, i if prev < 0 else (i - prev) // 2)
            prev = i
    return max(best, len(seats) - 1 - prev)    # 最后一段：坐在最右端，距离到最后一个人
```

运行：`[1,0,0,0,1,0,1]` → `2`，`[1,0,0,0]` → `3`，`[0,1]` → `1`，`[1,0,0,1]` → `1`，`[0,0,1]` → `2`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 用 `itertools.groupby` 把连续的 `0` 分段，再按段在两端还是中间套公式，思路相同，更贴近「空位段」的描述。
- 二维版本（到最近的人的最大曼哈顿距离）要用多源 BFS，见 LC 1162 地图分析。

**易错点。**
- 两端的段不能除以 2：`[1,0,0,0]` 坐最右端距离是 `3`，写成 `3 // 2 = 1` 会得到 `1`。
- 中间的段是 `(i - prev) // 2`（下标差的一半）而不是空位个数的一半：`[1,0,0,0,1]` 空位 `3`、下标差 `4`，答案是 `2`，用 `3 // 2` 会得到 `1`。
- 全是 `0` 开头 / 结尾时 `prev` 的初值要区分「还没见到人」，不能设成 `0`，否则 `[0,0,1]` 的开头段会按中间段算成 `1`（正确 `2`）。
