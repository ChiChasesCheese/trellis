## Q
**LC 2144 打折购买糖果的最小开销**｜Easy

买两个糖果可免费拿一个，免费糖果价格不能超过那两个中的较小价格。给定 `cost`，求买下所有糖果的最小花费。

## A
**一句话。** 价格降序排序，每三个一组：前两个付钱，第三个免费（它不会超过前两个的较小值）。

```python
def minimum_cost(cost):
    cost.sort(reverse=True)
    # 下标 2, 5, 8... 的免费，其余付钱
    return sum(c for i, c in enumerate(cost) if i % 3 != 2)
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`。

**易错点。**
- 升序排序：免费拿到的是最便宜的，节省最少。
- 剩下不足三个：最后一组两个或一个都要付钱，下标取模自然处理。

**追问。**
- 为什么贵的配贵的？：免费的价格有上限，让免费的是尽可能贵的候选，才省得多。

**同模式。** LC 881 救生艇、LC 1877 数组中最大数对和的最小值、LC 455 分发饼干
