## Q
**LC 172 阶乘后的零**｜Medium

求 `n!` 末尾有多少个零（要求对数时间）。

## A
**一句话。** 零的个数等于因子 `5` 的个数（`2` 总比 `5` 多），即 `n//5 + n//25 + n//125 + ...`。

```python
def trailing_zeroes(n):
    cnt = 0
    while n:
        n //= 5        # n//5^k：1..n 中 5^k 的倍数个数
        cnt += n
    return cnt
```

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- 只数 `n // 5`：`n=25` 得 `5`，漏了 `25` 的第二个 `5`，应为 `6`。
- 真的去算 `n!`：位数巨大，转字符串还会超默认上限，也不是对数时间。

**追问。**
- 为什么只数 5？：`2` 的个数是 `n//2 + n//4 + ...`，总不少于 `5` 的，成对的 `2×5` 数量由 `5` 决定。
- `n!` 在 `b` 进制下末尾几个零？：分解 `b` 的质因数 `p^e`，取各 `p` 在 `n!` 中的指数除以 `e` 的最小值。

**同模式。** LC 793 阶乘函数后 K 个零、LC 204 计数质数、LC 50 Pow(x, n)
