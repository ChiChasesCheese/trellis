## Q
**LC 2390 从字符串中移除星号**｜Medium

字符串 `s` 含小写字母和 `*`。每个 `*` 会删掉它左边最近的一个非星号字符以及它自己。返回处理完所有星号后的字符串（输入保证每个 `*` 左边都有字符可删）。

## A
**一句话。** 栈：字母入栈，遇到 `*` 就弹出栈顶，最后栈里的字符就是答案。

```python
def remove_stars(s):
    st = []
    for ch in s:
        if ch == "*":
            st.pop()             # 删掉左边最近的字符
        else:
            st.append(ch)
    return "".join(st)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 反复 `s.replace` 或字符串拼接删除：每次 `O(n)`，总共 `O(n^2)`。
- 把 `*` 也压栈：星号应被立即消耗，不进栈。

**追问。**
- 不想用额外空间？：从右往左扫，用计数器记还要删多少个，遇到 `*` 计数加 1，遇到字母若计数非零就跳过并减 1。
- 为什么是栈？：「删除最近的一个」是后进先出的操作。

**同模式。** LC 844 比较含退格的字符串、LC 1047 删除字符串中的所有相邻重复项、LC 1209 删除字符串中的所有相邻重复项 II、LC 1021 删除最外层的括号
