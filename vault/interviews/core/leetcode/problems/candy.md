## Q
**LC 135 分发糖果**｜Hard

`n` 个孩子站一排，`ratings[i]` 是评分。每人至少 1 颗糖，相邻两人中评分更高者必须糖更多。求最少总糖数。

## A
**一句话。** 约束分左右两个方向，各扫一遍并在第二遍取 `max`（两遍扫描）。

```python
def candy(ratings):
    n = len(ratings)
    give = [1] * n
    for i in range(1, n):            # 左到右：比左邻居高就多一颗
        if ratings[i] > ratings[i - 1]:
            give[i] = give[i - 1] + 1
    for i in range(n - 2, -1, -1):   # 右到左：比右邻居高就多一颗
        if ratings[i] > ratings[i + 1]:
            give[i] = max(give[i], give[i + 1] + 1)
    return sum(give)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 只扫一遍：`[1,0,2]` 只左到右得 `4`，应为 `5`。
- 第二遍直接赋值不取 `max`：`[1,2,3,1]` 会把 `3` 的糖压低，破坏第一遍的结果，应为 `7`。
- 评分相等也要求更多：条件必须是严格大于，`[2,2,2]` 应为 `3`。

**追问。**
- `O(1)` 额外空间？：一遍扫上坡 / 下坡，记上坡长、下坡长、坡顶糖数，下坡比坡顶长时给坡顶补 `1`。
- 孩子站成环？：先找评分最小的孩子，从他把环切开成线性问题。
