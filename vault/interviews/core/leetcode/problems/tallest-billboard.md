## Q
**LC 956 最高的广告牌**｜Hard

钢筋 `rods`（至多 20 根，总长 `≤ 5000`），分到左右两侧（可不用），两侧等高，求最大高度。

## A
**一句话。** 状态压成「高度差」：`f[d]` 是两侧差为 `d` 时较短一侧的最大高度；每根钢筋可丢弃、加到高侧、加到矮侧。

```python
def tallest_billboard(rods):
    f = {0: 0}                  # 高度差 -> 较短一侧最大高度
    for x in rods:
        g = dict(f)             # 不用这根
        for d, low in f.items():
            # 加到高侧：差变大，矮侧不变
            g[d + x] = max(g.get(d + x, -1), low)
            # 加到矮侧：矮侧涨 min(d, x)
            nd = abs(d - x)
            g[nd] = max(g.get(nd, -1), low + min(d, x))
        f = g
    return f[0]
```

**复杂度。** 时间 `O(n·S)`，空间 `O(S)`，`S` 为总长。

**易错点。**
- 在 `f` 上边遍历边更新：同一根钢筋会被用多次，要基于旧表写新表。
- 加到矮侧时矮侧加 `x`：若 `x > d`，矮侧变成高侧，新的矮侧是原高侧，即 `low + d`。

**追问。**
- 折半搜索？：每半边 `3^10` 种分法，按差值存最大高度，两边差值相同的配对，`O(3^(n/2))`。
- 为什么记较短一侧？：差固定时，较短一侧越高，最终等高时越高。

**同模式。** LC 416 分割等和子集、LC 494 目标和、LC 1049 最后一块石头的重量 II
