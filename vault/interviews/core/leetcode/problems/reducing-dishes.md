## Q
**LC 1402 做菜顺序**｜Hard

每道菜耗时 1，like-time 系数 = 完成时刻 × 满意度。可以任意排序、放弃一些菜，求系数总和的最大值。

## A
**一句话。** 满意度从大到小考虑，每次把一道菜加到最前面：已选的菜都往后推 1，总和增加「已选菜满意度之和」；这个前缀和一旦不为正就停。

```python
def max_satisfaction(satisfaction):
    satisfaction.sort(reverse=True)
    ans = s = 0                # s：已选菜的满意度之和
    for x in satisfaction:
        s += x                 # 新菜放最前，其他菜都晚 1
        if s <= 0:
            break              # 再加只会让总和变小
        ans += s
    return ans
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`（不计排序）。

**易错点。**
- 一遇到负数就停：负数菜放最前面能把后面的正数菜推迟，只要前缀和仍为正就值得做。
- 选定菜后按原顺序做：一定是满意度升序做，大的放最后乘最大的时刻。

**追问。**
- 为什么总和增加的是前缀和？：`Σ (t_i + 1)·x_i - Σ t_i·x_i = Σ x_i`，再加上新菜自己的 `1·x`。
- DP 写法？：排序后 `f[i][j]` 为前 `i` 道里做 `j` 道的最大值，`O(n²)`，贪心是它的简化。

**同模式。** LC 274 H 指数、LC 2285 道路的最大总重要性、LC 1589 所有排列中的最大和
