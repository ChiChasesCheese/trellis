## Q
**LC 527 单词缩写**｜Hard

给一组互不相同的单词，给每个单词一个缩写：首字母 + 省略的字母数 + 末字母。若多个单词缩写相同，则把相同缩写的单词都多保留一位前缀，直到互不相同；缩写不比原词短就保留原词。返回各单词的缩写。

## A
**一句话。** 每个词的前缀长度从 1 开始，有重复的缩写就让它们的前缀都加 1，重复检查每轮对全体做，直到没有重复为止。

```python
def words_abbreviation(words):
    n = len(words)
    k = [1] * n                      # 每个词保留的前缀长度
    def abbr(w, p):
        a = w[:p] + str(len(w) - p - 1) + w[-1]
        return a if len(a) < len(w) else w
    res = [abbr(w, 1) for w in words]
    while True:
        cnt = Counter(res)
        bad = [i for i in range(n) if cnt[res[i]] > 1]
        if not bad:
            return res
        for i in bad:                # 重复的一起加长前缀
            k[i] += 1
            res[i] = abbr(words[i], k[i])
```

**复杂度。** 时间 `O(n · L^2)`（最多 `L` 轮，每轮生成缩写 `O(nL)`），空间 `O(nL)`。

**易错点。**
- 只让重复中的某一个加长：重复的所有单词必须一起加长，否则结果不唯一或不是最短。
- 缩写不短于原词时仍然使用缩写：这种情形应原样保留单词。
- 只比较缩写字符串而不分组：长度、末字母相同才可能撞，字符串相等已隐含这一点，不必再单独分组。

**追问。**
- 怎样更快？：按（长度，末字母）分组，组内排序后只比较相邻单词的最长公共前缀，每个词的前缀长度为它与左右邻居公共前缀的较大值加 1。
- 为什么按轮同步加长是正确的？：只有前缀相同才会撞缩写，同步加一位后撞的仍是同一批，不会漏掉也不会多加。
