## Q
**LC 1217 玩筹码**｜Easy

`position[i]` 是第 `i` 个筹码的位置。把一个筹码移动 2 格代价为 0，移动 1 格代价为 1。求把所有筹码移到同一位置的最小代价。

## A
**一句话。** 移动偶数距离免费，所以所有奇数位置的筹码可免费聚到一点，偶数位置同理；最后只需把较少的一堆挪 1 格，代价是奇偶两堆数量的较小值。

```python
def min_cost_to_move_chips(position):
    odd = sum(p % 2 for p in position)       # 奇数位置的筹码数
    return min(odd, len(position) - odd)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 去算每个目标位置的总代价：位置可以很大，而奇偶性只有两种，只看奇偶即可。
- 把代价当成距离：只有「差 1」要付 1，差 2 免费，所以只与奇偶有关。

**追问。**
- 为什么答案是较小的一堆？：把少的一堆各花 1 挪到多的一堆旁边，再免费聚拢。
- 为什么两堆内部免费？：同奇偶之间的距离是偶数，可拆成若干个 2。

**同模式。** LC 1029 两地调度、LC 1005 K 次取反后最大化的数组和、LC 455 分发饼干
