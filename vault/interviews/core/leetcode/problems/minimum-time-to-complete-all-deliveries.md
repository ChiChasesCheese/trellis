## Q
**LC 3733 完成所有送货任务的最少时间**｜Medium

两架无人机各要送 `d1`、`d2` 次，每次 1 小时，同一小时只能有一架送；无人机 `i` 在 `r_i` 的倍数小时充电不能送。求最少总小时数。`d` 到 `10^9`。

## A
**一句话。** 二分答案 `T`：无人机 `i` 可用 `T - T//r_i` 小时，至少一架可用的小时是 `T - T//lcm`；两个各自够、合起来也够就可行（Hall 定理）。

```python
def minimum_time(d, r):
    (d1, d2), (r1, r2) = d, r
    l = lcm(r1, r2)

    def ok(t):          # 各自够 + 合起来也够
        return (t - t // r1 >= d1 and t - t // r2 >= d2
                and t - t // l >= d1 + d2)

    lo, hi = 0, 2 * (d1 + d2)   # lo 不可行，hi 一定可行
    while lo + 1 < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid
        else:
            lo = mid
    return hi
```

**复杂度。** 时间 `O(log(d1 + d2))`，空间 `O(1)`。

**易错点。**
- 只检查各自可用小时：两架共享同一个小时，`d = [1,3], r = [2,2]` 要 `7` 小时，不检查总量会得 `6`。
- 总量用 `T - T//r1 - T//r2`：两架同时充电的小时被减了两次，要加回 `T//lcm`。

**追问。**
- 为什么三个条件就够？：小时与无人机的二分图匹配，Hall 定理只需检查每个子集，这里只有 `{1}`、`{2}`、`{1,2}`。
- 上界为什么是 `2(d1+d2)`？：`r ≥ 2`，任一架至少一半小时可用。

**同模式。** LC 875 爱吃香蕉的珂珂、LC 2187 完成旅途的最少时间、LC 878 第 N 个神奇数字
