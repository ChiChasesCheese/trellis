## Q
**LC 70 爬楼梯**｜Easy

每次爬 `1` 或 `2` 阶，爬到第 `n` 阶有多少种方法。

## A
**一句话。** 最后一步来自 `n-1` 或 `n-2`，`f(n) = f(n-1) + f(n-2)`，斐波那契滚动两个变量。

```python
def climb_stairs(n):
    prev, cur = 1, 1             # f(0) = 1, f(1) = 1
    for _ in range(n - 1):
        prev, cur = cur, prev + cur
    return cur
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 初值用 `f(0)=0, f(1)=1`：整体错一位，`n=3` 得 `2`，应为 `3`。
- 循环 `n` 次而不是 `n-1` 次：多推一项，`n=2` 返回 `3`。

**追问。**
- `n` 到 `10^18`（取模）怎么办？：`2x2` 矩阵快速幂 `[[1,1],[1,0]]^n`，`O(log n)`。
- 一次可爬 `1..k` 阶？：`f(n)` 是前 `k` 项之和，滑动窗口维护，`O(n)`。

**同模式。** LC 746 使用最小花费爬楼梯、LC 198 打家劫舍、LC 509 斐波那契数、LC 62 不同路径
