## Q
**LC 88 合并两个有序数组**｜Easy

把有序的 `nums2` 原地合并进尾部留有 `n` 个空位的有序 `nums1`（前 `m` 个有效）。

## A
**一句话。** 三指针从后往前填：每次把两数组末尾较大的放到 `nums1` 最后的空位。

```python
def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1
    while j >= 0:                 # nums2 放完，nums1 余下的已在位
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
```

**复杂度。** 时间 `O(m+n)`，空间 `O(1)`。

**易错点。**
- 从前往后原地写：`[1,2,3,0,0,0]` 与 `[2,5,6]` 得 `[1,2,2,2,5,6]`，`3` 被覆盖丢失。
- 用 `nums1 = sorted(...)` 重新赋值：调用者的 `nums1` 没变，要写 `nums1[:] = ...`。
- `m = 0` 时 `i = -1`：必须先判 `i >= 0`，否则 `nums1[-1]` 读到末尾。

**追问。**
- 偷懒写法？：`nums1[m:] = nums2` 再 `sort()`，Timsort 识别两段有序段后近似线性。
- 输入是链表或 `k` 个数组？：LC 21 双指针合并；LC 23 用堆。
