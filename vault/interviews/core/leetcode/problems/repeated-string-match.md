## Q
**LC 686 重复叠加字符串匹配**｜Medium

把字符串 `a` 重复叠加若干次，使字符串 `b` 成为其子串，返回最少叠加次数；不可能则返回 `-1`。

## A
**一句话。** 先叠到长度刚好不小于 `b` 的最少份数 `k`；`b` 起点可能错位，所以再多叠一份还不行就无解。

```python
def repeated_string_match(a, b):
    k = -(-len(b) // len(a))             # 向上取整：至少这么多份
    s = a * k
    if b in s:
        return k
    if b in s + a:                       # 起点错位，再多一份
        return k + 1
    return -1
```

**复杂度。** 时间 `O(|a|·k + |b|)`（取决于子串搜索实现），空间 `O(|a|·k)`。

**易错点。**
- 只试 `k` 份：`b` 的起点不一定在 `a` 的开头，`a = "abcd"`、`b = "cdabcdab"` 需要 `k + 1` 份。
- 叠 `k + 2` 份或更多：多余，`k + 1` 份已覆盖所有起点错位，再多只会重复。
- 向上取整写成 `len(b) // len(a) + 1`：整除时会多算一份，应是 `-(-x // y)`。

**追问。**
- 为什么最多 `k + 1`？：`b` 的起点落在某个 `a` 的内部，之后连续跨过的份数不超过 `⌈|b|/|a|⌉ + 1`。
- 想要更快的匹配？：用 KMP 或滚动哈希搜索，`O(|a|·k + |b|)`。
