## Q
**LC 605 种花问题**｜Easy

花坛 `flowerbed` 中 `1` 已种花，花不能种在相邻地块，问还能否再种入 `n` 朵。

## A
**一句话。** 从左到右扫，自己和左右邻居都空就立刻种上，越靠左种留给后面的空间越多。

```python
def can_place_flowers(flowerbed, n):
    bed = [0, *flowerbed, 0]       # 两端补 0，免边界特判
    for i in range(1, len(bed) - 1):
        if bed[i - 1] == bed[i] == bed[i + 1] == 0:
            bed[i] = 1             # 种上，影响下一格
            n -= 1
    return n <= 0
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 种完不把 `bed[i]` 改成 `1`：`([0,0], 2)` 两格都被判可种，返回 `True`，应为 `False`。
- 不补零直接读 `flowerbed[i - 1]`：`i = 0` 时下标 `-1` 悄悄读到最后一个元素。

**追问。**
- 为什么贪心最优？：每个空位尽量靠左种，对右边的约束最小。
- 要求 `O(1)` 空间？：不补零，改成对两端单独判断，且不改输入时用 `prev` 变量记前一格。
