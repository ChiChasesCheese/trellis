## Q
**LC 58 最后一个单词的长度**｜Easy

字符串 `s` 由字母和空格组成，至少有一个单词，返回最后一个单词的长度。

## A
**一句话。** 从末尾先跳过空格，再向前数字母，数到空格或开头为止。

```python
def length_of_last_word(s):
    i = len(s) - 1
    while s[i] == " ":           # 题目保证有单词，不会越界
        i -= 1
    end = i
    while i >= 0 and s[i] != " ":
        i -= 1
    return end - i
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 直接从 `s[-1]` 数字母：`"a "` 数出 `0`，应为 `1`。
- 数字母时不检查 `i >= 0`：`"Hello"` 的下标减到 `-1` 后绕回末尾，数错或死循环。

**追问。**
- 一行怎么写？：`len(s.split()[-1])`；`split()` 不带参数才会丢弃空串。

**同模式。** LC 151 反转字符串中的单词、LC 557 反转字符串中的单词 III、LC 14 最长公共前缀
