## Q
**LC 387 字符串中的第一个唯一字符**｜Easy

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的下标；如果不存在，返回 `-1`。`1 <= s.length <= 10^5`，`s` 只包含小写字母。例：`s = "leetcode"` → `0`；`s = "loveleetcode"` → `2`；`s = "aabb"` → `-1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 频次表（frequency table）+ 两遍扫描。

**一句话。** 第一遍数每个字符出现的次数，第二遍按原顺序找第一个次数为 1 的字符。

**识别。** 「第一个 / 唯一 / 只出现一次」：唯一性要先看全局，所以必须先统计再判断；「第一个」靠第二遍按原顺序扫描保证。`n = 10^5` 排除对每个字符再扫整串的 `O(n^2)`。

**推导。** 对每个下标 `i` 用 `s.count(s[i])` 判断是否唯一，每次 `O(n)`，总共 `O(n^2)`，`10^10` 次字符比较会超时。浪费在于同一个字符的次数被反复重数；一次性统计成表，之后每次查询 `O(1)`。

```python
def first_uniq_char(s: str) -> int:
    cnt = Counter(s)                   # 第一遍：每个字符出现的总次数
    for i, ch in enumerate(s):         # 第二遍：保持原顺序，第一个次数为 1 的就是答案
        if cnt[ch] == 1:
            return i
    return -1                          # 没有任何字符只出现一次
```

运行：`"leetcode"` → `0`，`"loveleetcode"` → `2`，`"aabb"` → `-1`，`"z"` → `0`。

**复杂度。** 时间 `O(n)`，两遍扫描；空间 `O(1)`，字符集只有 26 个小写字母。

**拓展优化。**
- 不额外开表：对 26 个字母各做一次 `find` 与 `rfind`，两者相等说明只出现一次，取最小下标，空间 `O(1)` 且全部是 C 层扫描：

```python
def first_uniq_char_find(s: str) -> int:
    best = len(s)
    for c in string.ascii_lowercase:
        i = s.find(c)                  # 第一次出现的位置，没有则 -1
        if i != -1 and i == s.rfind(c):    # 第一次和最后一次是同一处：只出现一次
            best = min(best, i)
    return best if best < len(s) else -1
```

- 字符串是数据流、读不回去时：用字典记每个字符第一次的下标，重复出现就标成 `-1`，最后在非负值里取最小。

**易错点。**
- 返回的是**下标**不是字符：`"leetcode"` 应返回 `0`，返回 `'l'` 就错了。
- 不能用「次数最少」代替「第一个次数为 1」：`"loveleetcode"` 里 `l` 出现 2 次、`v` 出现 1 次，要按位置取最早的 `v`（下标 2），而不是任意一个次数为 1 的字符。
- 判断必须等整串统计完：边扫边判断会把「目前只出现一次」当成「全局只出现一次」，`"aabc"` 在第一个 `a` 处就会误返回 `0`，正确答案是 `2`。

**同模式。** LC 383 赎金信、LC 242 有效的字母异位词、LC 409 最长回文串、LC 451 根据字符出现频率排序。
