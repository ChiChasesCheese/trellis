## Q
**LC 455 分发饼干**｜Easy

孩子胃口 `g[i]`，饼干尺寸 `s[j]`，`s[j] >= g[i]` 才能满足，每人至多一块，求最多满足的孩子数。

## A
**一句话。** 排序加双指针贪心：饼干从小到大，每块给胃口最小的未满足孩子，不够就丢掉。

```python
def find_content_children(g, s):
    g.sort()
    child = 0
    for size in sorted(s):
        if child < len(g) and size >= g[child]:
            child += 1
    return child
```

**复杂度。** 时间 `O(n log n + m log m)`，空间 `O(m)`。

**易错点。**
- 不排序、按输入顺序发：`g = [1,2]`、`s = [2,1]` 时大饼干被小胃口拿走，得 `1`，应为 `2`。
- 每次给最大的饼干：`g = [1,2]`、`s = [1,2]` 得 `1`，大饼干浪费在小胃口上。

**追问。**
- 反过来贪心行吗？：孩子从大胃口到小，用当前最大饼干试，够就配对，同样正确。
- 每条船最多两人、载重 `limit`（LC 881）？：排序后左右双指针，最重的人必上船，能带上最轻的就一起走。

**同模式。** LC 2410 运动员和训练师的最大匹配数、LC 881 救生艇、LC 870 优势洗牌、LC 826 安排工作以达到最大收益
