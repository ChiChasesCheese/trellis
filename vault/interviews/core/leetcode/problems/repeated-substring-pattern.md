## Q
**LC 459 重复的子字符串**｜Easy

判断字符串 `s` 能否由它的某个子串重复多次（至少两次）拼成。

## A
**一句话。** 把 `s` 拼成 `s+s` 再去掉首尾字符，如果 `s` 还能在里面找到，说明 `s` 绕一圈移位后能与自己重合，即有周期。

```python
def repeated_substring_pattern(s):
    return s in (s + s)[1:-1]   # 去头去尾，仍含 s 就有周期
```

**复杂度。** 时间 `O(n)`（取决于子串搜索实现），空间 `O(n)`。

**易错点。**
- 不去掉首尾：`s` 总是出现在 `s+s` 的开头，永远为真。
- 只枚举长度整除 `n` 的前缀：可行，但要逐个拼接比较，比拼接法慢。
- 单个字符 `"a"`：`(s+s)[1:-1]` 是空串，不含 `s`，正确返回 `False`。

**追问。**
- 怎么用 KMP 做？：算出失配数组 `next[n-1]`，若 `n % (n - next[n-1]) == 0` 且 `next[n-1] > 0`，最小周期就是 `n - next[n-1]`。
- 为什么拼接法成立？：`s` 在 `s+s` 偏移 `k` 处出现，意味着 `s` 循环右移 `k` 位不变，`k` 因此是周期的倍数。

**同模式。** LC 28 找出字符串中第一个匹配项的下标、LC 1071 字符串的最大公因子、LC 686 重复叠加字符串匹配、LC 214 最短回文串
