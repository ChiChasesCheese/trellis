## Q
**LC 258 各位相加**｜Easy

非负整数 `num` 反复把各位数字相加，直到只剩一位，返回这一位。要求 `O(1)`。

## A
**一句话。** 数字根：各位和不改变模 9 的余数（`10 ≡ 1 (mod 9)`），所以答案是 `1 + (num - 1) % 9`，`0` 单独为 `0`。

```python
def add_digits(num):
    if num == 0:
        return 0
    return 1 + (num - 1) % 9   # 余数 0 要映射成 9
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 直接 `num % 9`：`num = 9` 得 `0`，应为 `9`。
- 忘了 `num = 0`：`1 + (-1) % 9` 在 Python 里得 `9`，应为 `0`。

**追问。**
- 为什么各位和与原数同余？：`num = Σ d·10^k`，`10^k ≡ 1 (mod 9)`，所以 `num ≡ Σ d`。
- 不用公式？：`while num >= 10: num = sum(map(int, str(num)))`，每轮位数降到对数级。

**同模式。** LC 202 快乐数、LC 9 回文数、LC 1281 整数的各位积和之差
