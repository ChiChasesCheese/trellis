## Q
**LC 856 括号的分数**｜Medium

平衡括号串：`()` 得 `1`；`AB` 得 `A + B`；`(A)` 得 `2 * A`。求总分。

## A
**一句话。** 栈保存每一层已累计的分数，遇 `)` 弹出内层分数 `v`，把 `max(2v, 1)` 加给外层。

```python
def score_of_parentheses(s):
    stack = [0]     # stack[-1] 是当前层已累计的分数
    for ch in s:
        if ch == "(":
            stack.append(0)
        else:
            inner = stack.pop()
            stack[-1] += max(2 * inner, 1)  # "()" 内为 0，记 1
    return stack[0]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 漏掉 `()` 特判，写成 `2 * inner`：`"()"` 得 `0`，应为 `1`。
- 外层用赋值而不是累加：`"()()"` 第二个会覆盖第一个，得 `1`，应为 `2`。

**追问。**
- 怎么做到 `O(1)` 空间？：只数深度，遇到 `()` 时加 `1 << depth`，`depth` 是此 `)` 弹出后剩下的层数。
- 分数会溢出吗？：长度 50 时最大约 `2^24`，不会；Python 本来就是大整数。

**同模式。** LC 394 字符串解码、LC 726 原子的数量、LC 224 基本计算器、LC 20 有效的括号
