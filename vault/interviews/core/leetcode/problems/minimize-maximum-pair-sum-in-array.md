## Q
**LC 1877 数组中最大数对和的最小值**｜Medium

偶数长度数组 `nums`，把元素两两配对（每个元素恰好属于一对）。数对和的最大值要尽量小，返回这个最小值。

## A
**一句话。** 排序后最小的配最大的、次小的配次大的，这样大数都被小数「压住」，最大数对和最小。

```python
def min_pair_sum(nums):
    nums.sort()
    n = len(nums)
    best = 0
    for i in range(n // 2):
        best = max(best, nums[i] + nums[n - 1 - i])  # 首尾配对
    return best
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`（不计排序）。

**易错点。**
- 相邻配对：最大数和次大数配在一起，数对和显然最大。
- 返回数对和的总和或平均：答案是各数对和里的最大值。

**追问。**
- 为什么首尾配对是最优？：交换论证，若最大数 `M` 配了某个 `x`，而最小数 `m` 配了 `y`，把配对改成 `(M, m)`、`(x, y)` 后最大和不增。
- 值域小可以更快吗？：计数排序，`O(n + 值域)`。
