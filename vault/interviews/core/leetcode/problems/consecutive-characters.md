## Q
**LC 1446 连续字符**｜Easy

字符串的「能量」是只含一种字符的最长非空子串的长度。返回 `s` 的能量。

## A
**一句话。** 扫描一遍，和前一个字符相同就把当前连续长度加 1，否则重置为 1，同时维护最大值。

```python
def max_power(s):
    best = run = 1
    for i in range(1, len(s)):
        run = run + 1 if s[i] == s[i - 1] else 1
        best = max(best, run)    # 每步更新最大值
    return best
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只在字符变化时才更新最大值：末尾的一段会漏掉，应每步都更新。
- 初值设成 `0`：非空字符串至少为 1。

**追问。**
- 用滑动窗口怎么写？：右指针前进，左指针在字符不同时跳到右指针，窗口宽度的最大值即答案。
- 要同时返回那个字符？：更新 `best` 时顺便记下 `s[i]`。

**同模式。** LC 674 最长连续递增序列、LC 485 最大连续 1 的个数、LC 1456 定长子串中元音的最大数目
