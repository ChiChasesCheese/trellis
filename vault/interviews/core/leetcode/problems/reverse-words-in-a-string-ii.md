## Q
**LC 186 反转字符串中的单词 II**｜Medium

字符数组 `s` 里单词之间用单个空格分隔，没有首尾空格。原地反转单词的顺序（每个单词内部的字符顺序不变），要求 `O(1)` 额外空间。

## A
**一句话。** 先把整个数组反转，这样单词顺序对了但每个单词是倒的；再逐个单词各自反转一次。

```python
def reverse_words(s):
    def rev(l, r):               # 原地反转 s[l..r]
        while l < r:
            s[l], s[r] = s[r], s[l]
            l += 1
            r -= 1
    rev(0, len(s) - 1)           # 整体反转
    start = 0
    for i in range(len(s) + 1):
        if i == len(s) or s[i] == " ":
            rev(start, i - 1)    # 每个单词再反转回来
            start = i + 1
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 用切片 `s[::-1]` 或 `split`：会产生新对象，空间 `O(n)`，题目要求原地。
- 忘了处理最后一个单词：末尾没有空格，要用 `i == len(s)` 触发。
- 先反转单词再反转整体：结果相同，但容易漏掉最后一个单词。

**追问。**
- 为什么两次反转就对？：整体反转后单词顺序对了、字符全倒；每个单词内部再倒一次就还原。
- 有多个空格或首尾空格呢？：就是 LC 151，先清理空格再做。

**同模式。** LC 151 反转字符串中的单词、LC 189 轮转数组、LC 344 反转字符串、LC 557 反转字符串中的单词 III
