## Q
**LC 1105 填充书架**｜Medium

`books[i] = [厚度, 高度]`，必须按给定顺序摆放，每层书的厚度之和不超过 `shelf_width`；每层的高度是该层最高的书。返回书架的最小总高度。

## A
**一句话。** `dp[i]` 是摆好前 `i` 本书的最小总高度；枚举最后一层从第几本书开始，只要厚度没超就累计这一层的最大高度。

```python
def min_height_shelves(books, shelf_width):
    n = len(books)
    dp = [0] + [inf] * n
    for i in range(1, n + 1):
        w = h = 0
        for j in range(i, 0, -1):    # 最后一层是 books[j-1..i-1]
            w += books[j - 1][0]
            if w > shelf_width:
                break
            h = max(h, books[j - 1][1])
            dp[i] = min(dp[i], dp[j - 1] + h)
    return dp[n]
```

**复杂度。** 时间 `O(n^2)`，空间 `O(n)`。

**易错点。**
- 允许改变书的顺序：题目要求顺序固定，最后一层只能是一段连续的书。
- 超宽后还继续往前加：厚度超过就 `break`，更早的书只会更宽。
- 层高取第一本的高度：层高是该层最高的书，要随着加入的书更新。

**追问。**
- 为什么贪心「能放就放」不对？：把一本很高的书放在当前层可能抬高整层，换到下一层反而更省。
- 和 LC 410 分割数组有什么共同点？：都是把序列切成连续段、段的代价由段内元素决定，用「最后一段从哪开始」做转移。

**同模式。** LC 1043 分隔数组以得到最大和、LC 410 分割数组的最大值、LC 68 文本左右对齐、LC 1335 工作计划的最低难度
