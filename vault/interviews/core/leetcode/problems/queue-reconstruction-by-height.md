## Q
**LC 406 根据身高重建队列**｜Medium

`people[i] = [h, k]`：身高 `h`，队列中排在他前面且身高不低于 `h` 的人恰有 `k` 个。给打乱的数组，还原出队列。

## A
**一句话。** 先按身高从高到低、`k` 从小到大排序，再依次把每个人插到下标 `k` 处：矮的人插入不会影响高的人的 `k`。

```python
def reconstruct_queue(people):
    people.sort(key=lambda p: (-p[0], p[1]))  # 高的先，同高 k 小的先
    res = []
    for h, k in people:
        res.insert(k, [h, k])          # 前面已有的都不比他矮
    return res
```

**复杂度。** 时间 `O(n²)`（`insert` 要移动元素），空间 `O(n)`。

**易错点。**
- 按身高升序处理：先放矮的会被后插入的高个子挤乱位置，必须从高到低。
- 同高时 `k` 大的先插：`k` 小的要排在前面，所以同高要 `k` 升序。
- 把 `k` 当作绝对位置：插入时前面全是不矮于他的人，下标 `k` 恰好满足定义，这是贪心成立的原因。

**追问。**
- 为什么矮的后插不影响？：`k` 只数「不矮于自己」的人，后插的人更矮，对已放好的高个子没有贡献。
- 想要 `O(n log n)`？：用树状数组找第 `k+1` 个空位，从矮到高放置。

**同模式。** LC 135 分发糖果、LC 455 分发饼干、LC 179 最大数、LC 1029 两地调度
