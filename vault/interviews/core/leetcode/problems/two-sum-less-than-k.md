## Q
**LC 1099 小于 K 的两数之和**｜Easy

求数组中两个不同位置的数之和严格小于 `k` 的最大值，没有则返回 `-1`。

## A
**一句话。** 排序后对撞双指针：和小于 `k` 就记录并右移左指针，否则左移右指针。

```python
def two_sum_less_than_k(nums, k):
    nums.sort()
    l, r = 0, len(nums) - 1
    best = -1
    while l < r:
        s = nums[l] + nums[r]
        if s < k:
            best = max(best, s)   # l 与更小的 r 只会更小，排除 l
            l += 1
        else:
            r -= 1                # r 与更大的 l 只会更大，排除 r
    return best
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`。

**易错点。**
- 条件写成 `s <= k`：要严格小于，`[10,20,30]`、`k=30` 得 `30`，应为 `-1`。
- `best` 初值取 `0`：无合法数对时应返回 `-1`。
- 找到合法和后两个指针一起动：漏掉 `l` 与更小 `r` 的搭配，`[1,2,3]`、`k=11` 得 `4`，应为 `5`。

**追问。**
- 统计和小于 `k` 的数对个数？：`s < k` 时 `l` 与 `l+1..r` 都合法，一次加 `r - l`，再 `l += 1`。
- 不排序能做吗？：值域小（`<=1000`）时可用计数数组，否则只能排序。

**同模式。** LC 1 两数之和、LC 167 两数之和 II、LC 15 三数之和、LC 259 较小的三数之和
