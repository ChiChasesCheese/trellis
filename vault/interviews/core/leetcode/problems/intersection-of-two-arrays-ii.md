## Q
**LC 350 两个数组的交集 II**｜Easy

给两个整数数组 `nums1`、`nums2`，返回它们的交集：每个元素出现的次数等于它在两个数组中出现次数的较小值，结果顺序任意。

## A
**一句话。** 用计数器记下 `nums1` 每个值的出现次数，扫 `nums2`，遇到还有剩余次数的就收下并减一。

```python
def intersect(nums1, nums2):
    cnt = Counter(nums1)
    res = []
    for x in nums2:
        if cnt[x] > 0:
            res.append(x)
            cnt[x] -= 1                # 每个值最多取到它的次数
    return res
```

**复杂度。** 时间 `O(m + n)`，空间 `O(min(m, n))`（对较短的数组计数更省）。

**易错点。**
- 用集合交集：会丢掉重复次数，`[1,2,2,1]` 与 `[2,2]` 应得 `[2,2]`。
- 没减计数就加入结果：`nums2` 里多出的重复值也会被收下。
- `cnt[x]` 访问不存在的键：`Counter` 对缺失键返回 0，不会报错，换成普通字典要用 `get`。

**追问。**
- 两个数组已经有序呢？：双指针，相等就收下并同时前进，否则小的前进，`O(1)` 额外空间。
- 一个数组放不进内存呢？：对小数组计数，大数组分块或流式读入，逐个匹配并递减。
