## Q
**LC 2384 最大回文数字**｜Medium

数字字符串 `num`。从中选出若干个数字（每个下标至多用一次）重新排列，拼成最大的回文整数，不能有前导零（`"0"` 本身除外），返回字符串。

## A
**一句话。** 数字从 `9` 到 `0` 取成对的作左半边；左半边去掉前导零；中间放剩余数字中最大的一个（若有）。左半边为空时，只能返回中间数字，或 `"0"`。

```python
def largest_palindromic(num):
    cnt = Counter(num)
    half = ''.join(d * (cnt[d] // 2) for d in '9876543210')
    half = half.lstrip('0')                  # 不能有前导零
    mid = max((d for d in cnt if cnt[d] % 2), default='')
    if not half:                             # 只剩中间一位
        return mid or '0'
    return half + mid + half[::-1]
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 不去前导零：`"00009"` 会得到 `"00900"`，应为 `"9"`。
- 左半边为空时返回空串：至少要返回 `"0"`，如 `num = "00"`。
- 中间选第一个奇数次的数字：要选其中最大的。

**追问。**
- 为什么只处理左半边的前导零？：回文首尾相同，首位不是 `0`，整个数就没有前导零。

**同模式。** LC 409 最长回文串、LC 266 回文排列、LC 3518 最小回文排列 II
