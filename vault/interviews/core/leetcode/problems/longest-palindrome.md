## Q
**LC 409 最长回文串**｜Easy

用字符串 `s` 的字母（每个至多用一次，可重排，区分大小写）构造回文串，返回最长长度。

## A
**一句话。** 回文是成对字母加正中间至多一个单字母：每种字母取 `次数 // 2 * 2`，还有剩的再加 `1`。

```python
def longest_palindrome(s):
    pairs = sum(v // 2 * 2 for v in Counter(s).values())
    return pairs + (pairs < len(s))   # 有剩余字母就放一个在中间
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`（52 种字母）。

**易错点。**
- 偶数次全加、奇数次只取最多的一种：`"aaabbbcc"` 得 `5`，应为 `7`，奇数次的也要取成对的部分。
- 每个奇数次字母都加 `1`：`"abc"` 得 `3`，应为 `1`，中间只能放一个。

**追问。**
- 要返回回文串本身？：拼出一半 `half` 和中间字母 `mid`，答案 `half + mid + half[::-1]`。
- 只判断能否重排成回文（LC 266）？：奇数次的字母种数 `<= 1`。

**同模式。** LC 266 回文排列、LC 2131 连接两字母单词得到的最长回文串、LC 1400 构造 K 个回文字符串
