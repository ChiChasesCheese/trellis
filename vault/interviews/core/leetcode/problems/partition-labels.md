## Q
**LC 763 划分字母区间（Partition Labels）**｜Medium

给你一个字符串 `s`。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，`"ababcc"` 能够被分为 `["abab", "cc"]`，但 `["aba", "bcc"]` 或 `["ab", "ab", "cc"]` 是非法的。划分结果按顺序连接，得到的字符串仍然是 `s`。返回一个表示每个字符串片段的长度的列表。`1 <= s.length <= 500`，`s` 仅由小写英文字母组成。例：`s = "ababcbacadefegdehijhklij"` → `[9,7,8]`（`"ababcbaca"`、`"defegde"`、`"hijhklij"`）；`s = "eccbbbbdec"` → `[10]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 贪心（greedy）+ 区间合并：每个字母的「最后出现位置」决定当前片段必须延伸到哪里。

**一句话。** 记录每个字母最后出现的下标；从左扫描，当前片段的右边界 `end` 取片段内所有字母最后位置的最大值，扫到 `i == end` 时切一刀。

**识别。** 「每个字母只能在一个片段、片段尽量多」：片段越短越好，但必须包含片段内每个字母的所有出现位置。字符集 26，`O(n)` 一遍扫描。

**推导。** 把每个字母看成区间 `[第一次出现, 最后一次出现]`，同一个字母的区间必须在同一个片段里，相交的区间必须合并，合并后的每一块就是一个片段（合并区间的变体）。不需要真的建区间：从左往右维护 `end`，片段内每出现一个字母就把 `end` 推到它的最后位置；走到 `end` 时，片段内所有字母都已经出现完，这里就是最早的合法切点。

```python
def partition_labels(s: str) -> list[int]:
    last = {ch: i for i, ch in enumerate(s)}      # 每个字母最后一次出现的位置
    ans: list[int] = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])                  # 片段里出现了 ch，就必须延伸到 ch 的最后一次出现
        if i == end:                              # 走到必须到达的最远处，里面所有字母都不会再出现：在这里切
            ans.append(end - start + 1)
            start = i + 1
    return ans
```

运行：`"ababcbacadefegdehijhklij"` → `[9, 7, 8]`，`"eccbbbbdec"` → `[10]`，`"a"` → `[1]`，`"abc"` → `[1, 1, 1]`，`"abab"` → `[4]`。

**复杂度。** 时间 `O(n)`，空间 `O(Σ)`，`Σ = 26`。

**易错点。**
- `end` 直接赋成当前字母的最后位置，不取 `max`：后出现的字母会把边界拉回去，`"abab"` 得到 `[3, 1]`（`"aba"` 和 `"b"` 里 `b` 重复），正确 `[4]`；示例一得到 `[6, 2, 1, ...]`。
- 切分后忘记 `start = i + 1`：之后每个片段长度都从 0 号位置算起，长度偏大。

**同模式。** LC 56 合并区间、LC 55 跳跃游戏、LC 45 跳跃游戏 II、LC 435 无重叠区间。
