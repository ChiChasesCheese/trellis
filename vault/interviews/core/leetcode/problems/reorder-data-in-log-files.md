## Q
**LC 937 重新排列日志文件**｜Medium

每条日志是「标识符 + 空格 + 内容」。内容全是小写字母的是字母日志，全是数字的是数字日志。字母日志排在数字日志之前；字母日志按内容字典序排序，内容相同按标识符排序；数字日志保持原相对顺序。

## A
**一句话。** 给每条日志一个排序键：字母日志是 `(0, 内容, 标识符)`，数字日志是 `(1,)`；Python 的排序是稳定的，数字日志之间自然保持原序。

```python
def reorder_log_files(logs):
    def key(log):
        ident, rest = log.split(" ", 1)
        if rest[0].isdigit():
            return (1,)               # 数字日志排后，且稳定
        return (0, rest, ident)
    return sorted(logs, key=key)
```

**复杂度。** 时间 `O(n · L · log n)`（比较字符串要 `O(L)`），空间 `O(n · L)`。

**易错点。**
- 用 `split(" ")` 不限次数：内容里的空格会被拆开，要 `split(" ", 1)`。
- 对数字日志也按内容排序：数字日志必须保持原顺序。
- 内容相同时忘了比标识符：这是题目明确的第二关键字。

**追问。**
- 为什么只看 `rest[0]` 就能判类型？：题目保证同一条日志内容要么全是字母要么全是数字。
- 不能依赖稳定排序的语言怎么办？：给数字日志的键加上原下标 `(1, idx)`。
