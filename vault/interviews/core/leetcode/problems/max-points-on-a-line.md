## Q
**LC 149 直线上最多的点数**｜Hard

给你一个数组 `points`，其中 `points[i] = [x_i, y_i]` 表示 X-Y 平面上的一个点。求最多有多少个点在同一条直线上。`1 <= points.length <= 300`，`points[i].length == 2`，`-10^4 <= x_i, y_i <= 10^4`，`points` 中的所有点互不相同。例：`points = [[1,1],[2,2],[3,3]]` → `3`；`points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]` → `4`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 几何：固定一个点，按「方向向量约分后的斜率」分组计数；用整数代替浮点数。

**一句话。** 枚举每个点作为基点，把它到其余点的方向向量用 `gcd` 约分并规范方向，用哈希表统计每种斜率的点数，同一斜率的点与基点共线，答案是其中最大计数加 1。

**识别。** 「共线点的最大个数」：两点确定一条直线，固定一点后，其余点中斜率相同的就与它共线。`n = 300`，`O(n^2)` 即 `9 * 10^4` 次，`O(n^3)` 的三重循环也勉强可行但不理想。

**推导。** 暴力：枚举两点确定直线，再检查所有其它点是否共线，`O(n^3)`。固定基点 `i` 后，只需数每种斜率出现几次，一次循环 `O(n)`，总共 `O(n^2)`。斜率不要用浮点除法：竖线斜率无穷，浮点数还会有精度风险；改用约分后的整数对 `(dx, dy)`，并把方向规范到 `dx > 0`（或 `dx == 0` 时 `dy > 0`），这样 `(1, 2)` 与 `(-1, -2)` 视为同一斜率。只往后看 `j > i`：与更早基点的共线关系已经在前面统计过。

```python
def max_points(points: list[list[int]]) -> int:
    n = len(points)
    if n <= 2:
        return n
    best = 1
    for i in range(n):
        x1, y1 = points[i]
        slopes: Counter[tuple[int, int]] = Counter()
        for j in range(i + 1, n):
            dx, dy = points[j][0] - x1, points[j][1] - y1
            g = math.gcd(dx, dy)                    # 点互不相同，所以 g > 0；gcd 返回非负数
            dx, dy = dx // g, dy // g               # 约分：(2, 4) 与 (1, 2) 是同一斜率
            if dx < 0 or (dx == 0 and dy < 0):      # 规范方向：dx 为正，竖线时 dy 为正
                dx, dy = -dx, -dy
            slopes[dx, dy] += 1
        if slopes:
            best = max(best, max(slopes.values()) + 1)   # +1：基点自己
    return best
```

运行：`[[1,1],[2,2],[3,3]]` → `3`，`[[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]` → `4`，`[[0,0]]` → `1`，`[[0,0],[1,1]]` → `2`，`[[1,1],[0,0],[2,2]]` → `3`，竖线 `[[0,0],[0,1],[0,5]]` → `3`。

**复杂度。** 时间 `O(n^2)`（含 `gcd` 的对数因子），空间 `O(n)`。

**拓展优化。**
- 剪枝：若已有 `best >= n - i`（后面剩余的点不够超过当前最优），直接结束。
- 浮点斜率在这个数据范围内碰巧可行（任意两个不同的分数相差不小于 `1 / (2 * 10^4)^2`），但竖线要单独处理，面试中整数对更稳妥。

**易错点。**
- 不规范方向：基点 `(1,1)` 与 `(0,0)`、`(2,2)`：向量 `(-1,-1)` 和 `(1,1)` 被当成两种斜率，`[[1,1],[0,0],[2,2]]` 得到 `2`（正确 `3`）。
- 竖线 `dx == 0` 做除法会 `ZeroDivisionError`，用约分整数对就不会出现。
- 忘了 `+ 1`：计数的是基点之外的点，`[[1,1],[2,2],[3,3]]` 会得到 `2`（正确 `3`）。

**同模式。** LC 447 回旋镖的数量、LC 356 直线镜像、LC 1232 缀点成线、LC 976 三角形的最大周长。
