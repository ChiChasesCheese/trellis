## Q
**LC 940 不同的子序列 II**｜Hard

求字符串 `s` 的不同非空子序列个数，对 `10^9 + 7` 取余。

## A
**一句话。** `dp[i]` 为前 `i` 个字符的不同子序列数（含空串）：翻倍，再减去该字符上次出现前造过的重复。

```python
def distinct_subseq_ii(s):
    MOD = 10**9 + 7
    dp = [1] * (len(s) + 1)       # 含空串
    last = {}                     # 字符 -> 上次位置（从 1 起）
    for i, ch in enumerate(s, 1):
        dp[i] = 2 * dp[i - 1] % MOD
        if ch in last:            # 接 ch 的串里有一批已造过
            dp[i] = (dp[i] - dp[last[ch] - 1]) % MOD
        last[ch] = i
    return (dp[-1] - 1) % MOD     # 去掉空串
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 不去重直接 `2^n - 1`：`"aba"` 得 `7`，应为 `6`。
- 下标差一：减的是 `dp[last[ch] - 1]`，写成 `dp[last[ch]]` 会让 `"aaa"` 得 `1`。
- 忘了去掉空串：`"abc"` 得 `8`，应为 `7`。

**追问。**
- 空间能降到 `O(26)` 吗？：只记「以每个字母结尾的不同子序列数」，新字符的值等于当前总数加一。
- 统计恰好等于目标串 `t` 的子序列个数（LC 115）？：二维 DP，`dp[i][j]` 是 `s[:i]` 里 `t[:j]` 的出现次数。

**同模式。** LC 115 不同的子序列、LC 1987 不同的好子序列数目、LC 730 统计不同回文子序列
