## Q
**LC 539 最小时间差**｜Medium

给 24 小时制时间列表（`"HH:MM"`），返回列表中任意两个时间的最小分钟差，时间在一天内首尾相接（`23:59` 与 `00:00` 相差 1 分钟）。

## A
**一句话。** 转成分钟排序，答案必在相邻两项之间；把最小的时间加 1440 追加到末尾，处理首尾相接。

```python
def find_min_difference(timePoints):
    if len(timePoints) > 1440:
        return 0                      # 鸽巢原理：必有重复
    t = sorted(int(s[:2]) * 60 + int(s[3:])
               for s in timePoints)
    t.append(t[0] + 1440)             # 首尾相接成环
    return min(b - a for a, b in zip(t, t[1:]))
```

**复杂度。** 时间 `O(n log n)`，空间 `O(n)`。

**易错点。**
- 漏掉首尾之差：`23:59` 与 `00:00` 只差 1 分钟，不把第一项加 1440 就会算成 1439。
- 两两比较：`O(n²)`，且排序后只需看相邻项。
- 重复的时间点：差为 `0`，排序后相邻相等自然得到 `0`。

**追问。**
- 怎么做到 `O(n)`？：桶排序，一天只有 1440 个分钟桶，用布尔数组标记再扫一遍。
- 为什么超过 1440 个直接返回 0？：一天只有 1440 个不同的分钟，多于它就一定有重复。

**同模式。** LC 164 最大间距、LC 1154 一年中的第几天、LC 1185 一周中的第几天
