## Q
**LC 160 相交链表**｜Easy

给两个无环单链表的头，返回相交的起始节点（同一个节点对象，不是值相等），不相交返回 `null`。要求 `O(1)` 额外空间。

## A
**一句话。** 双指针各走完自己再走对方的链表，两者路程相等，会在交点相遇，不相交则同时到 `None`。

```python
def get_intersection_node(a, b):
    p, q = a, b
    while p is not q:            # 比节点本身，不比值
        p = p.next if p else b   # 走完换到另一条的表头
        q = q.next if q else a
    return p                     # 交点，或同时为 None
```

**复杂度。** 时间 `O(m+n)`，空间 `O(1)`。

**易错点。**
- 比较 `val`：两个不同节点值相同就误停，不相交时还会读到 `None.val`。
- 走到末尾直接置 `None` 结束：长度不同则永远对不齐。
- 换表头的条件写成 `p.next is None`：指针永不为 `None`，不相交时死循环；要走出末尾再换。

**追问。**
- 只判断是否相交？：比较两条链的最后一个节点是否同一个对象。
- 链表可能有环？：先各自判环（LC 141/142）；一有一无必不相交，都有环则看入环点是否在同一环上。

**同模式。** LC 141 环形链表、LC 142 环形链表 II、LC 234 回文链表、LC 236 二叉树的最近公共祖先
