## Q
**LC 1752 检查数组是否经排序和轮转得到**｜Easy

判断 `nums` 能否由某个非递减数组轮转若干位置（含 0）得到，可有重复项。

## A
**一句话。** 把数组看成环，有序轮转后环上「前一个大于后一个」的下降最多一次。

```python
def check(nums):
    n = len(nums)
    # 环上相邻对，含最后一对 nums[-1] -> nums[0]
    drops = sum(nums[i] > nums[(i + 1) % n]
                for i in range(n))
    return drops <= 1
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 漏掉首尾那一对：`[2,1,3,4]` 只数线性相邻会得 `True`，应为 `False`。
- 下降用了 `>=`：`[1,1,1]` 数出 3 次而返回 `False`。
- 判断写成 `drops == 1`：`[1,1,1]` 零次下降也合法。

**追问。**
- 严格递增且无重复时有更简单的判法吗？：同样数下降，最多一次即可。

**同模式。** LC 153 寻找旋转排序数组中的最小值、LC 33 搜索旋转排序数组、LC 896 单调数列、LC 189 轮转数组
