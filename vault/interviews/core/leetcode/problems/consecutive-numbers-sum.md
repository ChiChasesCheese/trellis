## Q
**LC 829 连续整数求和**｜Hard

求有多少组连续正整数之和等于 `n`（单个数也算一组，`n <= 10^9`）。

## A
**一句话。** 设 `k` 项、首项 `a`，则 `n = k·a + k(k-1)/2`；枚举 `k`，看剩余部分能否被 `k` 整除。

```python
def consecutive_numbers_sum(n):
    cnt = 0
    k = 1                      # 项数
    while k * (k + 1) // 2 <= n:   # 首项 >= 1 时的最小和
        if (n - k * (k - 1) // 2) % k == 0:
            cnt += 1
        k += 1
    return cnt
```

**复杂度。** 时间 `O(√n)`，空间 `O(1)`。

**易错点。**
- 循环写成 `k <= n`：线性枚举 `10^9` 次超时。
- 条件放宽成 `k(k-1)/2 <= n`：首项可能为 `0`，`n=3` 得 `3`，应为 `2`。
- 用浮点除法：大数上有精度问题，全程用 `//` 和 `%`。

**追问。**
- 为什么答案等于 `n` 的奇因数个数？：每个奇因数 `d` 对应一种拆法，奇偶性保证首项是整数。
- 要输出具体序列？：对合法的 `k` 输出 `range(a, a + k)`。

**同模式。** LC 204 计数质数、LC 372 超级次方、LC 400 第 N 位数字
