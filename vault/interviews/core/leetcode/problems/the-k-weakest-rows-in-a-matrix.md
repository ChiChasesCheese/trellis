## Q
**LC 1337 矩阵中战斗力最弱的 K 行**｜Easy

`mat` 的每行由若干 `1`（士兵）后接若干 `0`（平民）组成。第 `i` 行比第 `j` 行弱，当且仅当士兵更少，或士兵数相同且 `i < j`。返回最弱的 `k` 行的下标，按从弱到强排序。

## A
**一句话。** 战斗力就是每行 `1` 的个数；按「个数」排序，排序稳定，个数相同的自然保持下标顺序。

```python
def k_weakest_rows(mat, k):
    # sorted 稳定：士兵数相同的按下标从小到大
    rows = sorted(range(len(mat)),
                  key=lambda i: sum(mat[i]))
    return rows[:k]
```

**复杂度。** 时间 `O(mn + m log m)`，空间 `O(m)`。

**易错点。**
- 平局时下标反了：必须用稳定排序或把 `(士兵数, 下标)` 当键。
- 返回行本身而不是下标：题目要的是下标。

**追问。**
- 每行 `1` 在前 `0` 在后，能更快吗？：每行二分找第一个 `0`，求战斗力降到 `O(log n)`。
- 只要前 `k` 个，能不排序吗？：用大小为 `k` 的堆，`O(m log k)`。

**同模式。** LC 1351 统计有序矩阵中的负数、LC 215 数组中的第 K 个最大元素、LC 347 前 K 个高频元素
