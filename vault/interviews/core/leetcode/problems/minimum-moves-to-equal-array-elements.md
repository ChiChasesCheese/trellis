## Q
**LC 453 最小操作次数使数组元素相等**｜Medium

每次操作使 `n - 1` 个元素加 `1`，求让所有元素相等的最少操作次数。

## A
**一句话。** 「其余 `n-1` 个加 `1`」等价于「被排除的那个减 `1`」，所以每个数降到最小值，次数为 `sum - n·min`。

```python
def min_moves(nums):
    return sum(nums) - min(nums) * len(nums)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 与 LC 462 混淆取中位数：`[1,2,3]` 得 `2`，应为 `3`。
- 目标取平均数或最大值：目标是 `min + 次数`，不是固定的已有值。
- 把最小值当成 `nums[0]`：`[3,1,2]` 得 `-3`，应为 `3`。

**追问。**
- 每次只改一个数 ±1（LC 462）？：目标取中位数，次数为到中位数的距离和。
- 为什么是「相对」减一？：只关心元素间的差，全体加 `1` 不改变差。
