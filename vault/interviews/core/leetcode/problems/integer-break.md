## Q
**LC 343 整数拆分**｜Medium

把正整数 `n` 拆成至少两个正整数之和，求乘积的最大值。

## A
**一句话。** 一维 DP：切下第一块 `j`，剩下的 `i-j` 要么不再拆，要么继续拆，取最大。

```python
def integer_break(n):
    dp = [0] * (n + 1)     # dp[i]：拆成至少两份的最大乘积
    for i in range(2, n + 1):
        for j in range(1, i):
            dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
    return dp[n]
```

**复杂度。** 时间 `O(n²)`，空间 `O(n)`。

**易错点。**
- 只写 `j * (i - j)`（只切两块）：`n=10` 得 `25`，应为 `36`。
- 只写 `j * dp[i - j]`：`dp[1]` 无意义，`n=2` 得 `0`，应为 `1`。

**追问。**
- 有数学解吗？：尽量拆成 `3`。余 `0` 取 `3^(n/3)`，余 `1` 取 `3^(n//3-1)·4`，余 `2` 取 `3^(n//3)·2`，`n<=3` 取 `n-1`。
- 为什么拆 `3` 最优？：`3` 拆成 `1×2` 变小，而 `>=5` 的数拆开乘积更大，`4` 拆成 `2×2` 不变。

**同模式。** LC 279 完全平方数、LC 322 零钱兑换、LC 1808 好因子的最大数目
