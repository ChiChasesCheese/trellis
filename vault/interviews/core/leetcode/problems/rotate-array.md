## Q
**LC 189 轮转数组**｜Medium

把 `nums` 向右轮转 `k` 位，原地修改，`k` 非负。

## A
**一句话。** 三次翻转：整体翻转，再分别翻转前 `k` 个和其余部分。

```python
def rotate(nums, k):
    n = len(nums)
    k %= n                   # k 可能大于 n
    def rev(i, j):
        while i < j:
            nums[i], nums[j] = nums[j], nums[i]
            i, j = i + 1, j - 1
    rev(0, n - 1)            # 后 k 个到最前，但是倒序
    rev(0, k - 1)
    rev(k, n - 1)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了 `k %= n`：`[1,2]`、`k = 3` 时 `rev(0, 2)` 越界。
- 分界点写成 `n - k`：`[1..7]`、`k = 3` 得 `[4,5,6,7,1,2,3]`，那是左移。
- `nums = nums[-k:] + nums[:-k]`：只改了局部变量，要写 `nums[:] = ...`。

**追问。**
- 向左轮转？：等价于向右轮转 `n - k`，或把分界点改成 `k` 再翻转。
- 链表版本？：先连成环，在第 `n - k % n` 个节点后断开。

**同模式。** LC 61 旋转链表、LC 796 旋转字符串、LC 151 反转字符串中的单词
