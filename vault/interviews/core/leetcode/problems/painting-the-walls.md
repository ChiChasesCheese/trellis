## Q
**LC 2742 给墙壁刷油漆**｜Hard

`cost[i]`、`time[i]` 是第 `i` 面墙由付费油漆匠粉刷的费用和时间。另有一个免费油漆匠，粉刷任意一面墙需要 `1` 单位时间，但只有付费油漆匠在工作时才能工作。求粉刷所有墙的最小费用。

## A
**一句话。** 付费匠刷第 `i` 面墙时，免费匠能同时刷 `time[i]` 面；所以选一个付费集合，要求 `Σ(time[i] + 1) >= n`，最小化总费用，是 01 背包。

```python
def paint_walls(cost, time):
    n = len(cost)
    dp = [0] + [inf] * n         # dp[j]：至少刷完 j 面墙的最小费用
    for c, t in zip(cost, time):
        for j in range(n, 0, -1):  # 倒序，每面墙只选一次
            dp[j] = min(dp[j], dp[max(j - t - 1, 0)] + c)
    return dp[n]
```

**复杂度。** 时间 `O(n²)`，空间 `O(n)`。

**易错点。**
- 把 `time` 当作"刷的墙数"：付费匠自己刷 `1` 面，免费匠刷 `time[i]` 面，共 `time[i] + 1` 面。
- 下标 `j - t - 1` 不夹到 `0`：用 `max(…, 0)`，刷多了也算完成。
- 正序遍历 `j`：同一面墙会被选多次。

**追问。**
- 为什么条件是 `Σ(time + 1) >= n`？：付费匠总工作时间 `Σ time`，免费匠在这段时间内最多刷 `Σ time` 面，付费匠自己刷选中的几面，合起来要覆盖全部 `n` 面。
