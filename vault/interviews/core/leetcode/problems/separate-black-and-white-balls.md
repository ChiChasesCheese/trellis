## Q
**LC 2938 区分黑球与白球**｜Medium

`0/1` 串，`1` 是黑球、`0` 是白球，每次交换相邻两球，求把黑球都移到右边的最少步数。

## A
**一句话。** 每个 `0` 要和它左边的每个 `1` 交换一次，扫描时累加已见的 `1` 的个数。

```python
def minimum_steps(s):
    ones = ans = 0
    for ch in s:
        if ch == '1':
            ones += 1
        else:
            ans += ones          # 这个 0 要越过左边所有 1
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 数的是 `1` 右边的 `0` 却在遇到 `1` 时加：方向弄反时要从右往左扫。
- 答案用 32 位整数：`n = 10^5` 时可到 `2.5·10^9`。

**追问。**
- 为什么是最少？：一次相邻交换最多消掉一个逆序对，答案就是 `(1, 0)` 逆序对数。
- 一般数组的逆序对？：归并排序或树状数组，`O(n log n)`。
