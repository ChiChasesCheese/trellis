## Q
**LC 462 最小操作次数使数组元素相等 II**｜Medium

每次操作把数组中一个元素加 `1` 或减 `1`。求让所有元素相等的最少操作数。

## A
**一句话。** 排序后以中位数为目标，答案是各数到中位数的距离之和。

```python
def min_moves2(nums):
    nums.sort()
    mid = nums[len(nums) // 2]     # 偶数长度取哪个中位数都行
    return sum(abs(x - mid) for x in nums)
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`。

**易错点。**
- 目标取平均数：`[1,0,0,8,6]` 得 `16`，正确是 `14`（目标取 `1`）。
- 没排序就取中间下标：`[3,1,2]` 取到 `1`，得 `3`，正确是 `2`。

**追问。**
- 为什么是中位数？：首尾配对的每对代价至少是两数之差，中位数落在每对之间，全部取到下界。
- 能更快吗？：用快速选择（quickselect）找中位数，期望 `O(n)`。
