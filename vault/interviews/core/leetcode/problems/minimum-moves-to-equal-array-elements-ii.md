## Q
**LC 462 最小操作次数使数组元素相等 II**｜Medium

给你一个长度为 `n` 的整数数组 `nums`，返回使所有数组元素相等需要的最小操作数。一次操作可以使数组中的一个元素加 `1` 或者减 `1`。`n == nums.length`，`1 <= nums.length <= 10^5`，`-10^9 <= nums[i] <= 10^9`，测试用例保证答案在 32 位整数范围内。例：`nums = [1,2,3]` → `2`（`[1,2,3] → [2,2,3] → [2,2,2]`）；`nums = [1,10,2,9]` → `16`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 中位数性质（绝对差之和最小）：把所有数变成同一个值的总代价是 `sum(|x - t|)`，取 `t` 为中位数时最小。

**核心题。**

- LC 295 数据流的中位数（Blind 75、NeetCode 150、LeetCode Hot 100、Top Interview 150）：都要求中位数但这里是静态数组且用它最小化绝对差之和

**一句话。** 排序后取中位数作为目标值，答案是每个数到中位数的距离之和。

**识别。** 每次只改一个数 `±1`，所以一个数变到目标 `t` 恰好要 `|x - t|` 次，各个数互不影响；问题化成「选一个 `t` 使 `sum(|x - t|)` 最小」，这是中位数的标准信号。`n <= 10^5` 和值域 `10^9` 排除了枚举目标值。

**推导。** 枚举目标值要 `O(n · 值域)`，而且平均数并不是最优（它最小化的是平方差之和）。排序后把最小和最大的数配成一对：`t` 落在这对数之间时，这对的代价恒为两数之差，这是下界；所有配对的区间一层套一层，中位数落在每一层里，所以每一对同时取到下界。

```python
def min_moves2(nums: list[int]) -> int:
    nums = sorted(nums)
    # 首尾配对的区间层层嵌套，中位数在每一层内，每对的代价都取到下界（两数之差）
    # 偶数长度时两个中位数之间任取一个，答案相同，这里取靠右的那个
    median = nums[len(nums) // 2]
    return sum(abs(x - median) for x in nums)   # 每个数各自走到目标，互不影响
```

运行：`[1,2,3]` → `2`；`[1,10,2,9]` → `16`；`[5]` → `0`；`[-3,0,4]` → `7`；`[1,0,0,8,6]` → `14`。

**复杂度。** 时间 `O(n log n)`（排序），只求中位数用快速选择（quickselect）可降到期望 `O(n)`；空间 `O(n)`（`sorted` 复制一份）。

**易错点。**
- 目标取平均数：`[1,0,0,8,6]` 的平均数约 `3`，得到 `16`，正确是 `14`（目标取中位数 `1`）。
- 忘记排序就取中间下标：`[3,1,2]` 取到 `1`，得到 `3`，正确是 `2`。
- 与 LC 453 混淆，套用 `sum(nums) - n * min(nums)`：`[1,10,2,9]` 得到 `18`，正确是 `16`（那题每次让 `n - 1` 个数一起加 `1`，这里每次只改一个数，还可以减）。

**同模式。** LC 453 最小操作次数使数组元素相等、LC 2033 获取单值网格的最小操作数、LC 296 最佳的碰头地点、LC 2448 使数组相等的最小开销。
