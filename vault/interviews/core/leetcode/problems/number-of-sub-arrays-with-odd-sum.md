## Q
**LC 1524 和为奇数的子数组数目**｜Medium

给整数数组 `arr`，统计和为奇数的子数组个数，结果对 `10^9 + 7` 取余。

## A
**一句话。** 前缀和只看奇偶：以当前位置结尾的奇数和子数组数，等于之前奇偶性与当前前缀相反的前缀个数。

```python
def num_of_subarrays(arr):
    MOD = 10**9 + 7
    cnt = [1, 0]   # 前缀和为偶 / 奇的个数，含空前缀
    pre = ans = 0
    for x in arr:
        pre ^= x & 1           # 只维护奇偶
        ans += cnt[pre ^ 1]    # 奇偶相反才差出奇数
        cnt[pre] += 1
    return ans % MOD
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 漏了空前缀 `cnt = [1, 0]`：从下标 0 开头的子数组漏掉，`[1]` 得 `0`，应为 `1`。
- 找同奇偶的前缀：同奇偶相减是偶数，数出来的是偶数和子数组。

**追问。**
- 偶数和子数组有多少？：总数 `n(n+1)/2` 减奇数和个数，或改查 `cnt[pre]`。
- 和能被 `k` 整除的子数组？：把奇偶换成 `pre % k`，用长度 `k` 的计数数组，即 LC 974。

**同模式。** LC 560 和为 K 的子数组、LC 974 和可被 K 整除的子数组、LC 930 和相同的二元子数组、LC 523 连续的子数组和
