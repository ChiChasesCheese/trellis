## Q
**LC 989 数组形式的整数加法**｜Easy

整数的数组形式是按从左到右数位组成的数组（如 `1321` 是 `[1,3,2,1]`）。给 `num` 的数组形式和整数 `k`，返回 `num + k` 的数组形式。

## A
**一句话。** 模拟竖式加法：从低位开始，把 `num` 的当前位加进 `k`，让 `k` 同时充当进位，每步取个位。

```python
def add_to_array_form(num, k):
    ans = []
    i = len(num) - 1
    while i >= 0 or k:
        if i >= 0:
            k += num[i]            # k 兼作进位
            i -= 1
        k, d = divmod(k, 10)
        ans.append(d)
    return ans[::-1]
```

**复杂度。** 时间 `O(max(n, log k))`，空间 `O(1)`（不计输出）。

**易错点。**
- 把数组转成整数再加：`num` 可长达 `10^4` 位，转成整数在别的语言里会溢出，这里要按位模拟。
- 循环只看 `i >= 0`：`k` 比 `num` 更长或最后还有进位时，要继续处理 `k`。
- 最后忘了反转：结果是从低位到高位生成的。

**追问。**
- 两个数组相加（LC 2）？：同样的竖式，换成两个指针和一个进位变量。
- 为什么 `k` 可以兼作进位？：每轮 `k // 10` 就是留给下一位的进位加上 `k` 剩下的高位，二者本来就要继续相加。

**同模式。** LC 66 加一、LC 415 字符串相加、LC 2 两数相加
