## Q
**LC 371 两整数之和**｜Medium

不使用 `+` 和 `-`，计算两整数之和。

## A
**一句话。** 反复做 `a, b = a ^ b, (a & b) << 1`（无进位和、进位），直到进位为 `0`，并用 32 位掩码模拟补码。

```python
def get_sum(a, b):
    MASK, MAX = 0xFFFFFFFF, 0x7FFFFFFF
    a &= MASK
    b &= MASK
    while b:
        a, b = (a ^ b) & MASK, ((a & b) << 1) & MASK
    return a if a <= MAX else ~(a ^ MASK)   # 还原负数
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 不加掩码：`a = -1`、`b = 1` 时进位永不消失，死循环。
- 结尾直接 `return a`：`a = 1`、`b = -2` 返回 `4294967295`，应为 `-1`。
- 循环条件写成 `while a`：该看进位 `b`，`a = 0`、`b = 5` 会返回 `0`。

**追问。**
- 为什么循环至多 32 次？：每轮进位至少左移一位，32 位后必为 `0`。
- 相减怎么做？：`a - b = a + (~b + 1)`，复用同一个加法。

**同模式。** LC 67 二进制求和、LC 2 两数相加、LC 415 字符串相加、LC 191 位 1 的个数
