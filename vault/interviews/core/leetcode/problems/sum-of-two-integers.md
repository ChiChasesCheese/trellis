## Q
**LC 371 两整数之和**｜Medium

给你两个整数 `a` 和 `b`，**不使用**运算符 `+` 和 `-`，计算并返回两整数之和。`-1000 <= a, b <= 1000`。例：`a = 1`, `b = 2` → `3`；`a = 2`, `b = 3` → `5`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 位运算做加法：异或 = 不带进位的加，与再左移一位 = 进位；Python 要自己模拟 `32` 位补码。

**一句话。** 反复做「`a, b = a ^ b, (a & b) << 1`」，直到进位 `b` 为 `0`，此时 `a` 就是和。

**识别。** 「不能用加减」= 用二进制竖式加法的两步拆开：各位相加不进位（`^`）、进位（`&` 再左移一位）；`a, b` 范围很小，循环至多 `32` 次。

**推导。** 逐位相加：同位 `0+0=0`、`0+1=1`、`1+1=0` 且进位 `1`，也就是异或给出不带进位的和，与给出哪些位产生进位，进位要加到更高一位，所以左移一位。把"和"与"进位"再相加，同样的方法重复，直到没有进位。Python 的整数没有宽度，负数是无限多个前导 `1`，进位永远不会消失，所以要用 `0xFFFFFFFF` 截成 `32` 位；结束时若最高位（符号位）是 `1`，再还原成 Python 的负数。

```python
def get_sum(a: int, b: int) -> int:
    MASK = 0xFFFFFFFF  # 32 位掩码：Python 整数无限宽，用它模拟 32 位补码
    MAX = 0x7FFFFFFF   # 32 位有符号整数的最大值
    a &= MASK
    b &= MASK
    while b:
        a, b = (a ^ b) & MASK, ((a & b) << 1) & MASK  # 无进位和；进位左移一位，截成 32 位
    # 符号位为 1 说明是负数：a ^ MASK 取反低 32 位，再 ~ 变回 Python 的负数
    return a if a <= MAX else ~(a ^ MASK)
```

运行：`(1, 2)` → `3`；`(2, 3)` → `5`；`(1, -2)` → `-1`；`(-1, 1)` → `0`；`(-1000, -1000)` → `-2000`。

**复杂度。** 时间 `O(1)`（循环至多 `32` 次），空间 `O(1)`。

**拓展优化。**
- 同样的思路做减法：`a - b = a + (-b)`，而 `-b` 的补码是 `~b + 1`，所以 `a - b` 即 `get_sum(a, get_sum(~b, 1))`，仍然不用 `+` 和 `-`。

**易错点。**
- 不加掩码：`a = -1`, `b = 1` 时每轮 `a` 变成 `-2`、`-4`、`-8`……，`b` 变成 `2`、`4`、`8`……，进位永远不会消失，死循环。
- 结尾直接 `return a`：`a = 1`, `b = -2` 返回 `4294967295`，正确是 `-1`；必须把符号位为 `1` 的 `32` 位值还原成负数。
- 循环条件写成 `while a`：应该看进位 `b` 是否为 `0`；`a = 0`, `b = 5` 时循环一次都不进，返回 `0`，正确是 `5`。

**同模式。** LC 67 二进制求和、LC 2 两数相加、LC 415 字符串相加、LC 191 位 1 的个数。
