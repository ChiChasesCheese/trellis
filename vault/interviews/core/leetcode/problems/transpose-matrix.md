## Q
**LC 867 转置矩阵**｜Easy

返回矩阵的转置，即 `res[j][i] = matrix[i][j]`。

## A
**一句话。** `zip(*matrix)` 把各行按位置配对，每一对就是原矩阵的一列。

```python
def transpose(matrix):
    return [list(col) for col in zip(*matrix)]
```

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。

**易错点。**
- 结果写成 `[[0] * m] * n`：各行是同一个列表，`[[1,2,3],[4,5,6]]` 得 `[[3,6],[3,6],[3,6]]`。
- 直接返回 `zip` 的元素：是元组，要转成列表。
- 非方阵想原地：形状从 `m × n` 变 `n × m`，必须开新矩阵。

**追问。**
- 方阵怎么原地？：`i` 从小到大、`j` 从 `i + 1` 起只换上三角；`j` 从 `0` 起每对换两次等于没换。
- 顺时针旋转 90 度（LC 48）？：先转置，再翻转每一行。

**同模式。** LC 48 旋转图像、LC 54 螺旋矩阵、LC 566 重塑矩阵、LC 73 矩阵置零
