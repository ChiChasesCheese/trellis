## Q
**LC 1154 一年中的第几天**｜Easy

给格式为 `YYYY-MM-DD` 的日期字符串，返回它是当年的第几天。

## A
**一句话。** 把前面各月的天数累加，再加上当月的日；闰年的二月是 29 天。

```python
def day_of_year(date):
    y, m, d = map(int, date.split('-'))
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if y % 400 == 0 or (y % 4 == 0 and y % 100 != 0):
        days[1] = 29                   # 闰年二月
    return sum(days[:m - 1]) + d
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 闰年判断漏掉整百年：能被 100 整除但不能被 400 整除的不是闰年（如 `1900`），`2000` 是。
- 加上当前月的天数：只累加前 `m-1` 个月，再加 `d`。
- 月份下标：`days[:m-1]` 才是前几个月，别写成 `days[:m]`。

**追问。**
- 用标准库怎么写？：`datetime.date(y, m, d).timetuple().tm_yday`，面试一般要求手写。
- 两个日期之间相差几天？：各自换成「从某个基准年起的天数」再相减，见一周中的第几天。

**同模式。** LC 1185 一周中的第几天、LC 2409 统计共同度过的日子数、LC 539 最小时间差、LC 1360 日期之间隔几天
