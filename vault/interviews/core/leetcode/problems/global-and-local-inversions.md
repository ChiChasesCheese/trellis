## Q
**LC 775 全局倒置与局部倒置**｜Medium

`nums` 是 `0` 到 `n-1` 的一个排列。全局倒置是满足 `i < j` 且 `nums[i] > nums[j]` 的对数，局部倒置是满足 `nums[i] > nums[i+1]` 的 `i` 的个数。判断两者数量是否相等。

## A
**一句话。** 局部倒置一定是全局倒置，两者相等当且仅当没有「相隔 2 以上的倒置」，排列里每个数离自己的下标最多差 1。

```python
def is_ideal_permutation(nums):
    # 只允许相邻交换：每个数最多偏离原位 1
    return all(abs(x - i) <= 1 for i, x in enumerate(nums))
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 真的去数全局倒置：`O(n²)` 或归并排序，思路绕远了；等价条件一行判断。
- 写成 `abs(x - i) < 1`：相邻交换后的数恰好偏离 `1`，必须允许。

**追问。**
- 为什么偏离 2 就一定多出全局倒置？：`x ≥ i+2` 时比 `x` 小的值有 `x` 个，而 `i` 前面只有 `i` 个位置，至少两个在它后面，其中必有一个不相邻。
- 等价写法？：`nums[i] > min(nums[i+2:])` 就是非局部倒置，扫一遍维护后缀最小值。

**同模式。** LC 493 翻转对、LC 315 计算右侧小于当前元素的个数、LC 912 排序数组
