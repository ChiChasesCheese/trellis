## Q
**LC 639 解码方法 II**｜Hard

字母 `A..Z` 对应 `1..26`。给只含数字和 `*` 的字符串 `s`，`*` 可以代表 `1..9` 的任一数字。返回解码方式数，对 `10^9 + 7` 取模。

## A
**一句话。** 与 LC 91 同样的线性 DP：`dp[i]` 是前 `i` 个字符的解码数，它等于「最后一个字符单独成字母」乘它的可选数，加上「最后两个字符成一个字母」乘它的可选数。

```python
def num_decodings(s):
    MOD = 10 ** 9 + 7
    def one(c):                  # 单个字符能代表几个字母
        return 9 if c == "*" else (0 if c == "0" else 1)
    def two(a, b):               # 两个字符能代表几个 10..26
        if a == "*" and b == "*":
            return 15            # 11~19 和 21~26
        if a == "*":
            return 2 if b <= "6" else 1   # 1b 一定行，2b 看 b
        if b == "*":
            return 9 if a == "1" else (6 if a == "2" else 0)
        return int(10 <= int(a + b) <= 26)
    n = len(s)
    dp = [0] * (n + 1)
    dp[0] = 1
    dp[1] = one(s[0])
    for i in range(2, n + 1):
        a = dp[i - 1] * one(s[i - 1])
        b = dp[i - 2] * two(s[i - 2], s[i - 1])
        dp[i] = (a + b) % MOD
    return dp[n]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`（可滚动成 `O(1)`）。

**易错点。**
- `**` 当成 `9 × 9`：两位 `**` 能表示的 10..26 只有 15 个（`11~19`、`21~26`），不能乘。
- `*` 当成 `0..9`：`*` 只能是 `1..9`，所以单字符 `*` 有 9 种。
- 前导 `0` 的两位组合如 `"06"`：值为 6 小于 10，不是合法的两位编码，`two` 要返回 0。

**追问。**
- 如何滚动数组？：只用到 `dp[i - 1]`、`dp[i - 2]`，用两个变量交替。
- 与 LC 91 的关系？：没有 `*` 时 `one`、`two` 退化为 0/1，就是 LC 91。

**同模式。** LC 91 解码方法、LC 70 爬楼梯、LC 62 不同路径、LC 1220 统计元音字母序列的数目
