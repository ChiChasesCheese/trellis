## Q
**LC 442 数组中重复的数据**｜Medium

长度 `n` 的数组，每个数在 `[1, n]` 内且出现一次或两次，找出所有出现两次的数，要求 `O(n)` 时间、常数额外空间。

## A
**一句话。** 数组当哈希表：读到 `x` 时看 `nums[x-1]` 的符号，已为负说明 `x` 见过，否则取负做标记。

```python
def find_duplicates(nums):
    res = []
    for x in nums:
        i = abs(x) - 1       # x 可能已被取负
        if nums[i] < 0:
            res.append(abs(x))
        else:
            nums[i] = -nums[i]
    return res
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 读 `x` 不取绝对值：负下标不报错，悄悄绕到尾部，`[2,1,1]` 返回 `[-1]`，应为 `[1]`。
- 结果里直接 `append(x)`：同样会得到负数。

**追问。**
- 输入只读怎么办？：用集合 / 布尔数组 `O(n)` 空间，或排序后比较相邻元素。
- 要还原输入？：再扫一遍 `nums[i] = abs(nums[i])`。
- 找消失的数字（LC 448）？：同样取负标记，最后仍为正的下标加一就是缺失值。

**同模式。** LC 448 找到所有数组中消失的数字、LC 287 寻找重复数、LC 41 缺失的第一个正数、LC 268 丢失的数字
