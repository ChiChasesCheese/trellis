## Q
**LC 905 按奇偶排序数组**｜Easy

把整数数组 `nums` 的偶数移到前面、奇数放后面，返回任一满足条件的数组。

## A
**一句话。** 对撞双指针原地分区：左指针找奇数、右指针找偶数，左奇右偶就交换。

```python
def sort_array_by_parity(nums):
    l, r = 0, len(nums) - 1
    while l < r:
        if nums[l] % 2 == 0:
            l += 1                  # 左边已是偶数
        elif nums[r] % 2 == 1:
            r -= 1                  # 右边已是奇数
        else:                       # 左奇右偶：交换
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
    return nums
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 每轮无条件移动两个指针，只在左奇右偶时交换：放错的元素被跳过，`[2,3,1,4]` 原样返回，`3` 仍在 `4` 前面。
- 判奇写成 `x % 2 == 1`：Java / C++ 里 `-3 % 2 == -1`，要写 `!= 0`；本题值非负不受影响。

**追问。**
- 要求稳定（保持相对顺序）？：`sorted(nums, key=lambda x: x % 2)`，或两个列表推导拼接，多 `O(n)` 空间。
- 快慢指针写法？：`write` 指向下一个偶数的位置，`read` 遇到偶数就与 `nums[write]` 交换，偶数部分保持原顺序。
- 三类分区（0 / 1 / 2）？：荷兰国旗三指针（LC 75）。
