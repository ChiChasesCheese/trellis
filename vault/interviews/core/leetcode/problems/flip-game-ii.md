## Q
**LC 294 翻转游戏 II**｜Medium

两人轮流把字符串中连续的 `"++"` 翻成 `"--"`，无法操作者输。判断先手是否必胜。

## A
**一句话。** 极小化极大的博弈搜索：存在一步翻转使对手面对必败局面，就是必胜，用局面字符串做记忆化。

```python
def can_win(currentState):
    @cache
    def win(s):                    # 轮到的人面对 s 是否必胜
        for i in range(len(s) - 1):
            if s[i:i+2] == "++":
                if not win(s[:i] + "--" + s[i+2:]):
                    return True    # 让对手必败
        return False
    return win(currentState)
```

**复杂度。** 时间 `O(局面数·n)`，空间 `O(局面数·n)`。

**易错点。**
- 忘了取反：翻转后轮到对手，要写 `not win(新局面)`。
- 不记忆化：同一局面被不同走法顺序反复到达，搜索量爆炸。

**追问。**
- 要返回先手第一步？：在 `win` 里记录使对手必败的位置。
- 规则改成三个连续 `+++`？：状态不变，只改枚举和翻转的长度。

**同模式。** LC 293 翻转游戏、LC 464 我能赢吗、LC 486 预测赢家、LC 877 石子游戏
