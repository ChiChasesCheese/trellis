## Q
**LC 896 单调数列**｜Easy

数组单调递增（`nums[i] <= nums[j]`，`i <= j`）或单调递减（`>=`）时是单调的。判断 `nums` 是否单调。

## A
**一句话。** 一遍扫描相邻对：出现下降就不可能递增，出现上升就不可能递减，最后只要有一个标志还成立。

```python
def is_monotonic(nums):
    inc = dec = True
    for a, b in pairwise(nums):
        if a > b:
            inc = False             # 出现下降：不可能是递增
        if a < b:
            dec = False             # 出现上升：不可能是递减
    return inc or dec
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 把相等当成违反：全相等的数组既是递增也是递减，比较要用严格的 `>`、`<`。
- 只比较前两个元素定方向：开头可能有相等的一段，方向要等到出现第一个不相等才能确定。

**追问。**
- 只遍历一次且不用两个标志？：记录第一次不相等的方向，之后遇到反方向就返回 `False`。
