## Q
**LC 3360 移除石头游戏**｜Easy

一堆 `n` 个石头，Alice 先手且第一次必须拿 10 个；之后每人必须拿「对方上一次的数量减 1」个。轮到谁拿不够谁输。问 Alice 能否获胜。

## A
**一句话。** 每步拿多少是定死的，没有选择，直接模拟 10、9、8… 拿到不够为止，成功拿了奇数次就是 Alice 赢。

```python
def can_alice_win(n):
    take = 10
    while take > 0 and n >= take:   # 够拿就拿
        n -= take
        take -= 1
    # 已拿 10 - take 次；奇数次说明卡住的是 Bob
    return (10 - take) % 2 == 1
```

**复杂度。** 时间 `O(1)`（最多 10 步），空间 `O(1)`。

**易错点。**
- 当成博弈 DP：玩家没有选择，局面只有一条路，不需要必胜态分析。
- 胜负看反：循环停下时轮到的人输，已拿次数为奇数时轮到的是 Bob。
- 漏了 `take > 0`：`n ≥ 55` 时会拿到 0 个、负数个，死循环。

**追问。**
- 第一次拿 `k` 个、`n` 很大，怎么 `O(1)`？：拿 `t` 次共需 `t(2k−t+1)/2` 个，解不等式（或二分）求最大的 `t ≤ k`，看 `t` 的奇偶。
- 如果每次可以拿 1 到 `m` 个呢？：有选择了，变成巴什博弈，`n % (m+1) != 0` 先手必胜。
