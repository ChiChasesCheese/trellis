## Q
**LC 1679 K 和数对的最大数目**｜Medium

每次操作从数组中取出两个和为 `k` 的数。返回最多能做多少次操作。

## A
**一句话。** 一遍扫描，哈希表记下还没配对的数；当前数 `x` 若能找到 `k - x` 就配成一对并消耗它，否则自己留着等别人。

```python
def max_operations(nums, k):
    waiting = Counter()          # 还没配对的数
    ops = 0
    for x in nums:
        if waiting[k - x] > 0:
            waiting[k - x] -= 1  # 配成一对，各用一次
            ops += 1
        else:
            waiting[x] += 1
    return ops
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 配对时不消耗：同一个数被反复用，结果偏大。
- 用 `in` 判断而不是计数：重复值需要计数，`x = k / 2` 时要两个相同的数才能成一对。

**追问。**
- 不想用额外空间？：排序后双指针，和等于 `k` 就两端同时收，和大了右指针左移，和小了左指针右移，`O(n log n)`。
- 为什么贪心配对不会少配？：每个数都只有唯一可配对的值 `k - x`，先到先配不影响总数。

**同模式。** LC 1 两数之和、LC 167 两数之和 II - 输入有序数组、LC 11 盛最多水的容器、LC 454 四数相加 II
