## Q
**LC 865 具有所有最深节点的最小子树**｜Medium

给二叉树，深度最大的节点称为最深节点。返回包含所有最深节点的最小子树的根（即所有最深节点的最近公共祖先）。

## A
**一句话。** 后序递归返回（子树最大深度，该子树里所有最深节点的汇合点）：哪边更深就用哪边的汇合点，一样深则当前节点就是汇合点。

```python
def subtree_with_all_deepest(root):
    def dfs(node):                   # (最大深度, 最深节点的汇合点)
        if not node:
            return 0, None
        ld, ln = dfs(node.left)
        rd, rn = dfs(node.right)
        if ld > rd:
            return ld + 1, ln        # 最深的全在左边
        if ld < rd:
            return rd + 1, rn
        return ld + 1, node          # 两边一样深：node 汇合
    return dfs(root)[1]
```

**复杂度。** 时间 `O(n)`，空间 `O(h)`。

**易错点。**
- 只比较深度不带节点：要返回的是节点，必须同时向上传递汇合点。
- 深度相等也走向左边：两边一样深说明最深节点分布在两侧，应取当前节点。
- 空节点深度记 `-1` 或 `1`：与叶子的深度混用会让比较出错，这里空为 `0`、叶为 `1`。

**追问。**
- 先求深度再求 LCA 的两遍写法？：一遍求最大深度，一遍找包含所有该深度节点的最近公共祖先，思路清楚但要两遍。
- 只有一个最深节点呢？：汇合点就是它自己，递归里左右深度从不相等。

**同模式。** LC 1123 最深叶节点的最近公共祖先、LC 1302 层数最深叶子节点的和、LC 236 二叉树的最近公共祖先、LC 104 二叉树的最大深度
