## Q
**LC 1962 移除石子使总数最小**｜Medium

给石子堆数组 `piles`，恰好进行 `k` 次操作：选一堆，移除 `floor(piles[i] / 2)` 颗石子（可重复选同一堆）。返回 `k` 次后剩余石子总数的最小值。

## A
**一句话。** 每次都对当前最大的一堆操作，因为它能一次减掉最多；用大顶堆维护最大值。

```python
def min_stone_sum(piles, k):
    h = [-p for p in piles]
    heapify(h)                         # 大顶堆：存负数
    for _ in range(k):
        x = -h[0]
        heapreplace(h, -(x - x // 2))  # 剩下 ceil(x/2)，弹出再压入
    return -sum(h)
```

**复杂度。** 时间 `O(n + k log n)`，空间 `O(n)`。

**易错点。**
- 剩下的石子写成 `x // 2`：移除的是 `floor(x/2)`，剩下 `x - x // 2`，即向上取整的一半。
- 堆里存正数：Python 是小顶堆，要存负数才能取最大。
- 每次对堆排序：`O(k·n log n)`，用堆是 `O(log n)` 每次。

**追问。**
- 为什么贪心？：操作对象越大，减少的量越多；一次操作后它仍可能最大，所以会连续操作同一堆。
- `k` 很大时？：堆里最大值降到 1 就不再变，可在全是 1 时提前停止。

**同模式。** LC 1046 最后一块石头的重量、LC 2208 将数组和减半的最少操作次数、LC 2530 执行 K 次操作后的最大分数、LC 1167 连接棒材的最低费用
