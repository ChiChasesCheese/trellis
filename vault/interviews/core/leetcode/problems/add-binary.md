## Q
**LC 67 二进制求和（Add Binary）**｜Easy

给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。`1 <= a.length, b.length <= 10^4`，`a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成，字符串如果不是 `"0"`，就不含前导零。例：`a = "11"`，`b = "1"` → `"100"`；`a = "1010"`，`b = "1011"` → `"10101"`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 逐位加法（grade-school addition）：从低位到高位，维护进位 `carry`。

**一句话。** 两个指针从字符串末尾向前走，每位加上进位，`divmod(total, 2)` 得到新的进位和这一位的结果，最后把结果反转。

**识别。** 「字符串形式的大整数相加」且长度 `10^4`：不能转成固定位宽整数，按位模拟。两串长度可能不同，所以循环条件是「任意一串没走完或还有进位」。

**推导。** 直接用 `int(a, 2) + int(b, 2)` 在 Python 里能行，但面试官考的是进位逻辑，通常会禁止；位模拟 `O(max(m, n))`。每一位的和只可能是 `0..3`（两个数位加进位），`divmod(total, 2)` 同时给出进位和当前位。

```python
def add_binary(a: str, b: str) -> str:
    i, j, carry = len(a) - 1, len(b) - 1, 0
    out: list[str] = []                           # 从低位到高位逐位产出
    while i >= 0 or j >= 0 or carry:
        total = carry
        if i >= 0:
            total += int(a[i])
            i -= 1
        if j >= 0:
            total += int(b[j])
            j -= 1
        carry, bit = divmod(total, 2)             # total 是 0..3：满二进一
        out.append(str(bit))
    return "".join(reversed(out))
```

运行：`("11", "1")` → `"100"`，`("1010", "1011")` → `"10101"`，`("0", "0")` → `"0"`，`("1" * 10000, "1")` → `"1"` 后面跟 `10000` 个 `"0"`（总长 `10001`）。

**复杂度。** 时间 `O(max(m, n))`，空间 `O(max(m, n))`。

**拓展优化。**
- 追问「不用加号」：异或是不进位的和，按位与再左移一位是进位，反复迭代直到没有进位。

```python
def add_binary_xor(a: str, b: str) -> str:
    x, y = int(a, 2), int(b, 2)
    while y:                                      # 不用 + 号：异或是不进位的和，与再左移一位是进位
        x, y = x ^ y, (x & y) << 1
    return bin(x)[2:]
```

**易错点。**
- 循环条件漏掉 `or carry`：最高位的进位丢失，`("11", "1")` 得到 `"00"`，正确 `"100"`。
- 忘记反转：结果是从低位到高位产出的，直接拼接是反序，`("11", "1")` 得到 `"001"`，正确 `"100"`。
- 在 C++/Java 里用 `int` 转换：长度 `10^4` 远超 64 位，必须逐位处理。

**同模式。** LC 66 加一、LC 2 两数相加、LC 415 字符串相加、LC 43 字符串相乘。
