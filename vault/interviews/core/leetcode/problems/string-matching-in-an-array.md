## Q
**LC 1408 数组中的字符串匹配**｜Easy

字符串数组 `words`（互不相同），返回所有是其他某个单词子串的单词，顺序任意。

## A
**一句话。** 对每个单词看是否被另一个单词包含，用 `in` 判断子串。

```python
def string_matching(words):
    return [w for w in words
            if any(w != v and w in v for v in words)]
```

**复杂度。** 时间 `O(n² · L)`，空间 `O(1)`（不计输出）。

**易错点。**
- 单词和自己比较：`w in w` 恒为真，要排除 `w == v`。
- 重复添加：同一个单词被多个单词包含时，用 `any` 只会加一次。

**追问。**
- 单词很多时怎么办？：把所有单词用分隔符拼成一个长串建后缀自动机，或用 AC 自动机批量匹配。
- 为什么只需要和更长的单词比？：子串不会比原串更长，可按长度排序后只与后面的比。
