## Q
**LC 1017 负二进制转换**｜Medium

给非负整数 `n`，返回它在基数 `-2` 下的表示（只含 `0`、`1`，除 `"0"` 外没有前导零）。

## A
**一句话。** 像十进制转二进制一样反复取余：每次取最低位 `n & 1`（只会是 0 或 1），再用 `(n - r) // -2` 得到下一个 `n`。

```python
def base_neg2(n):
    if n == 0:
        return "0"
    ans = []
    while n:
        r = n & 1                     # 余数只会是 0 或 1
        ans.append(str(r))
        n = (n - r) // -2             # 扣掉余数后恰好整除 -2
    return "".join(reversed(ans))
```

**复杂度。** 时间 `O(log n)`，空间 `O(log n)`。

**易错点。**
- 直接用 `n % -2`：Python 中余数符号跟除数，可能得到 `-1`，用 `n & 1` 取最低位更稳。
- 忘了反转：低位先产生，输出时要倒过来。
- `n = 0` 没有特判：循环不执行，会返回空串。

**追问。**
- 为什么 `n & 1` 对负的 `n` 也对？：二进制补码下最低位的奇偶性与十进制一致，`n - r` 一定是偶数。
- 其他负基数（`-k`）怎么做？：余数取 `n % k` 在 `[0, k)`，再 `(n - r) // -k`。
