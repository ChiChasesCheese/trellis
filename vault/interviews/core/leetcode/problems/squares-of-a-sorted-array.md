## Q
**LC 977 有序数组的平方**｜Easy

给非递减数组 `nums`，返回各数平方后同样非递减的数组，要求 `O(n)`。

## A
**一句话。** 最大平方一定在两端之一，对撞双指针比较两端平方，较大者从结果末尾往前填。

```python
def sorted_squares(nums):
    n = len(nums)
    res = [0] * n
    l, r = 0, n - 1
    for pos in range(n - 1, -1, -1):   # 从后往前填
        if nums[l] ** 2 > nums[r] ** 2:
            res[pos] = nums[l] ** 2
            l += 1
        else:
            res[pos] = nums[r] ** 2
            r -= 1
    return res
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 从前往后填：较大的平方放在开头，结果是降序，`[-4,-1,0,3,10]` 得 `[100,16,9,1,0]`。
- 比较原值而不是平方：`-4 < 3` 会选右边，得 `[16,1,0,9,100]`。
- 循环写成 `while l < r`：`n = 1` 时一次不执行，结果停在 `[0]`。

**追问。**
- 对有序数组套二次函数 `ax^2+bx+c` 再排序？：`a >= 0` 同样从两端取最大填后面，`a < 0` 取最小填前面（LC 360）。
- 输入没排序呢？：先平方再排序，`O(n log n)`。

**同模式。** LC 360 有序转化数组、LC 88 合并两个有序数组、LC 167 两数之和 II、LC 15 三数之和
