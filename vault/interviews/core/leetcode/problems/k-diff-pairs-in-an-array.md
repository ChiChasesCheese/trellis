## Q
**LC 532 数组中的 k-diff 数对**｜Medium

给整数数组 `nums` 和整数 `k`，返回数组中不同的 k-diff 数对的数目：数对 `(a, b)` 满足 `|a - b| == k`，两个元素来自不同下标，数对按值去重。

## A
**一句话。** 计数后分两种情况：`k = 0` 时数出现至少两次的值，`k > 0` 时对每个不同的值 `x` 看 `x + k` 是否也存在（只看加，不会重复计数）。

```python
def find_pairs(nums, k):
    cnt = Counter(nums)
    if k == 0:
        return sum(c > 1 for c in cnt.values())  # 同值出现两次以上
    return sum(x + k in cnt for x in cnt)        # 只往大的方向找
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- `k = 0` 时用 `x + k in cnt`：每个值都会匹配到自己，要求至少出现两次才算一对。
- 同时检查 `x + k` 与 `x - k`：同一数对会被数两次，只看一个方向。
- 对数组而不是对去重后的值遍历：重复值会被重复计数，要遍历 `cnt` 的键。

**追问。**
- 数组已排序时？：双指针，`O(1)` 额外空间，注意跳过重复值。
- 为什么 `k < 0` 返回 0？：绝对值不会是负数，题目保证 `k ≥ 0`，若不保证要先判。

**同模式。** LC 1 两数之和、LC 1200 最小绝对差、LC 888 公平的糖果交换
