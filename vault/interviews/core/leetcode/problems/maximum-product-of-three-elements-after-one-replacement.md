## Q
**LC 3732 一次替换后的三元素最大乘积**｜Medium

整数数组 `nums`（元素在 `[-10^5, 10^5]`），必须把恰好一个元素换成 `[-10^5, 10^5]` 内任意整数，再选三个不同下标，求乘积的最大值。

## A
**一句话。** 把替换的那个元素当作三个之一，设成 `±10^5`（符号与另两个数之积相同），乘积就是 `10^5 × |a·b|`；不用它也不会更大，因为第三个数的绝对值不超过 `10^5`。所以答案是绝对值最大的两个数之积乘 `10^5`。

```python
def max_product(nums):
    a, b = nlargest(2, map(abs, nums))   # 绝对值最大的两个
    return a * b * 10**5       # 第三个数换成同号的 ±10^5
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 按原值取最大的两个：`[-5, 7, 0]` 要用 `-5` 和 `7`，配 `-10^5` 得 `3500000`。
- 以为必须分正负讨论：替换值的符号可以任选，只看绝对值。

**追问。**
- 为什么不替换别的位置会更好？：任意三个原数之积绝对值 `<= |a·b|·10^5`，换掉其中一个成 `±10^5` 只会更大或相等。
- 不允许替换时三个数的最大积？：排序后比较「最大三个之积」和「最小两个与最大一个之积」，就是 LC 628。

**同模式。** LC 152 乘积最大子数组、LC 628 三个数的最大乘积
