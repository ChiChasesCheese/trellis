## Q
**LC 657 机器人能否返回原点**｜Easy

机器人从原点出发，字符串 `moves` 中每个字符是 `U`、`D`、`L`、`R` 之一，表示上下左右移动一步。判断走完后是否回到原点。

## A
**一句话。** 回到原点等价于上下步数相等且左右步数相等，数一数即可。

```python
def judge_circle(moves):
    return (moves.count('U') == moves.count('D')
            and moves.count('L') == moves.count('R'))
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只检查总步数是偶数：`UL` 步数是偶数但没回原点，必须按方向分别配对。
- 模拟坐标没问题，但别用 `if` 链漏掉某个方向：用计数更简洁。
- 把「回到原点」理解成中途不能离开：题目只看最终位置。

**追问。**
- 机器人按指令无限重复，会不会在圆里转？：走一轮后若在原点则回原点；否则若方向不再朝北，四轮后必回原点，否则越走越远，见 LC 1041。
- 加上障碍物呢？：要真的模拟坐标并查障碍集合，见 LC 874。

**同模式。** LC 1041 困于环中的机器人、LC 874 模拟行走机器人、LC 2069 模拟行走机器人 II
