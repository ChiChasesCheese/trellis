## Q
**LC 678 有效的括号字符串**｜Medium

字符串只含 `(`、`)`、`*`，`*` 可当 `(`、`)` 或空串。判断它是否括号有效。

## A
**一句话。** 贪心维护未配对 `(` 个数的可能区间 `[lo, hi]`，`hi < 0` 即失败，最后看 `lo == 0`。

```python
def check_valid_string(s):
    lo = hi = 0                      # 未配对 '(' 数的区间
    for ch in s:
        lo += 1 if ch == "(" else -1   # '*' 当 ')'，lo 减一
        hi += 1 if ch != ")" else -1   # '*' 当 '('，hi 加一
        if hi < 0:                   # 全当 '(' 也配不上
            return False
        lo = max(lo, 0)              # 多出的 '*' 当空串
    return lo == 0
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了把 `lo` 截到 `0`：`"*("` 里 `lo` 先到 `-1` 再回 `0`，误判有效，应为 `False`。
- `hi < 0` 留到最后才查：`")*"` 开头的 `)` 就已无解。
- 终点判 `hi == 0`：`hi` 是最乐观上界，`"(((*"` 的 `hi` 是 `4`，要判 `lo == 0`。

**追问。**
- 能还原具体配对吗？：用两个栈分别存 `(` 和 `*` 的下标，`)` 先配 `(` 再配 `*`。
- 括号有多种（`[]{}`）？：区间贪心不再成立，退回区间 DP。

**同模式。** LC 20 有效的括号、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号、LC 32 最长有效括号
