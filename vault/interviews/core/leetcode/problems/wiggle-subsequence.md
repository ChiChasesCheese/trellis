## Q
**LC 376 摆动序列**｜Medium

相邻元素之差严格正负交替的序列叫摆动序列。给整数数组 `nums`，返回其最长摆动子序列（不必连续）的长度。

## A
**一句话。** 只记「以上升结尾」和「以下降结尾」的最长长度；每遇到一个上升就接在下降后，遇到下降就接在上升后，等价于数峰谷。

```python
def wiggle_max_length(nums):
    up = down = 1                   # 以 上升/下降 结尾的最长摆动长度
    for i in range(1, len(nums)):
        if nums[i] > nums[i - 1]:
            up = down + 1           # 上升接在下降之后
        elif nums[i] < nums[i - 1]:
            down = up + 1
    return max(up, down)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 把相等也当作转折：差为 `0` 不算摆动，既不更新 `up` 也不更新 `down`。
- 用 `up = up + 1`：必须是接在对方后面，同方向连续上升只算一个峰。
- 初始化为 `0`：单个元素也是长度 `1` 的摆动序列。

**追问。**
- 为什么贪心正确？：一段连续上升中只保留最后一个才不影响后面的下降，相当于取每个峰和谷。
- 想要记录方案？：保留每个转折处的元素，或回溯 `up/down` 的来源。

**同模式。** LC 300 最长递增子序列、LC 674 最长连续递增序列、LC 978 最长湍流子数组、LC 1671 得到山形数组的最少删除次数
