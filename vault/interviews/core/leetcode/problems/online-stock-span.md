## Q
**LC 901 股票价格跨度**｜Medium

设计 `next(price)`：返回从今天往前连续股价都 `≤` 今天的天数（含今天）。

## A
**一句话。** 单调递减栈存 `(价格, 跨度)`：新价格把不高于它的栈顶都吞掉，并把它们的跨度加到自己身上。

```python
class StockSpanner:
    def __init__(self):
        self.st = []                 # (价格, 跨度)，价格递减

    def next(self, price):
        span = 1
        while self.st and self.st[-1][0] <= price:
            span += self.st.pop()[1]  # 它覆盖的天今天也能覆盖
        self.st.append((price, span))
        return span
```

**复杂度。** 均摊 `O(1)` 每次，空间 `O(n)`。

**易错点。**
- 弹栈条件写成 `<`：相等的价格也要计入跨度，`[5, 5]` 第二天应为 `2`。
- 栈里只存价格：弹出后丢了它覆盖的天数，只能存下标再用当天下标相减。

**追问。**
- 存下标的写法？：栈存 `(下标, 价格)`，跨度 = 今天下标 - 弹完后栈顶下标，栈空则为今天下标 + 1。
- 为什么均摊 `O(1)`？：每个价格只入栈、出栈各一次。

**同模式。** LC 739 每日温度、LC 84 柱状图中最大的矩形、LC 1475 商品折扣后的最终价格
