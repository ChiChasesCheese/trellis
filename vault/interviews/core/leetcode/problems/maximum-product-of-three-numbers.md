## Q
**LC 628 三个数的最大乘积**｜Easy

在数组中选三个数，求最大乘积（数可能为负）。

## A
**一句话。** 答案只可能是「最大的三个数」或「最小的两个数乘最大的一个」。

```python
def maximum_product(nums):
    big = nlargest(3, nums)        # 降序
    small = nsmallest(2, nums)     # 升序
    return max(big[0] * big[1] * big[2],
               small[0] * small[1] * big[0])   # 两负得正
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只取最大的三个：`[-10,-10,1,3,2]` 得 `6`，应为 `300`。
- 扫描法里最大值初值设成 `0`：`[-1,-2,-3]` 得 `0`，应为 `-6`。

**追问。**
- 选 `k` 个数呢？：排序后两端各取一对，枚举取几对。
- 乘积最大的子数组？：换成同时维护最大与最小的 DP（LC 152）。

**同模式。** LC 152 乘积最大子数组、LC 414 第三大的数、LC 1464 数组中两元素的最大乘积
