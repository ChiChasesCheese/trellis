## Q
**LC 80 删除有序数组中的重复项 II**｜Medium

升序数组 `nums` 原地删除，使每个值最多出现两次，返回新长度。

## A
**一句话。** 写指针 `w`：读到 `x` 时只要它不等于结果里倒数第二个元素，就写入。

```python
def remove_duplicates(nums):
    w = 0                          # nums[:w] 是已合法的结果
    for x in nums:
        if w < 2 or x != nums[w - 2]:
            nums[w] = x
            w += 1
    return w
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 与原数组 `nums[i-2]` 比：它可能已被覆盖，`[1,1,1,2,2]` 得 `[1,1,2]`，应为 `[1,1,2,2]`。
- 与 `nums[w-1]` 比：每个值只留一个，`[1,1,1,2,2,3]` 得 `[1,2,3]`。
- 去掉 `w < 2`：`nums[w-2]` 取到负下标。

**追问。**
- 每个值至多保留 `k` 个？：条件改成 `w < k or x != nums[w-k]`，`k=1` 就是 LC 26。
- 无序数组呢？：不能靠相邻比较，用 `Counter` 记每个值已留几个，额外 `O(n)` 空间。
