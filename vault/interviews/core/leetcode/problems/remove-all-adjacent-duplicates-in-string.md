## Q
**LC 1047 删除字符串中的所有相邻重复项**｜Easy

反复删除字符串中两个相邻且相同的字母，直到不能再删，返回最终字符串。

## A
**一句话。** 逐字符入栈，与栈顶相同就弹栈，否则入栈，最后栈里拼起来就是答案。

```python
def remove_duplicates(s):
    st = []
    for c in s:
        if st and st[-1] == c:
            st.pop()               # 一对一起消掉
        else:
            st.append(c)
    return "".join(st)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 只扫一遍、相邻相同就跳两个：`"abbaca"` 得 `"aaca"`，删 `bb` 后新出现的 `aa` 被漏掉，应为 `"ca"`。
- 没判栈空就读 `st[-1]`：第一个字符就 `IndexError`。

**追问。**
- 改成连续 `k` 个相同才删（LC 1209）？：栈里存（字符，连续个数），计数到 `k` 就弹出。
- 为什么栈能解决连锁消除？：删除后新相邻的字符正好是新栈顶与下一个字符。
