## Q
**LC 1497 检查数组对是否可以被 k 整除**｜Medium

长度为偶数的整数数组 `arr` 和整数 `k`，判断能否把数组分成 `n/2` 个数对，使每对的和都能被 `k` 整除。

## A
**一句话。** 统计各余数的个数：余数 `r` 只能和余数 `k - r` 配对，所以两者个数必须相等；余数 `0`（以及偶数 `k` 的 `k/2`）只能自己内部配，个数要为偶数。

```python
def can_arrange(arr, k):
    cnt = Counter(x % k for x in arr)     # Python 取模保证非负
    if cnt[0] % 2:
        return False                      # 余数 0 只能自己配对
    if k % 2 == 0 and cnt[k // 2] % 2:
        return False                      # 余数 k/2 也只能自己配对
    return all(cnt[r] == cnt[k - r]
               for r in range(1, (k + 1) // 2))
```

**复杂度。** 时间 `O(n + k)`，空间 `O(k)`。

**易错点。**
- 负数取模：`-1 % 5` 在别的语言可能是 `-1`，要先换成 `[0, k)` 的余数。
- 忘了余数 `0` 和 `k/2`：它们的配对对象是自己，个数必须为偶数，不能比较 `cnt[r]` 与 `cnt[k - r]`。
- 范围写成 `range(1, k)`：每对余数检查了两遍，到 `(k + 1) // 2` 即可。

**追问。**
- 为什么余数配对就够了？：`a + b ≡ 0 (mod k)` 当且仅当 `a % k + b % k` 等于 `0` 或 `k`。
- 同类题？：LC 1010 总持续时间可被 60 整除的歌曲对，数「对数」而不是「能否完全配对」。

**同模式。** LC 1010 总持续时间可被 60 整除的歌曲、LC 974 和可被 K 整除的子数组、LC 1 两数之和
