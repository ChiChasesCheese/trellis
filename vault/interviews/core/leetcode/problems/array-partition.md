## Q
**LC 561 数组拆分**｜Easy

`2n` 个整数分成 `n` 对，每对取较小值，求这些较小值之和的最大值。

## A
**一句话。** 排序后相邻两两配对，取偶数下标的数：最小的数总要当较小值，让它配次小的，浪费最少。

```python
def array_pair_sum(nums):
    nums.sort()
    return sum(nums[::2])   # 每对 (nums[2i], nums[2i+1]) 的较小值
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`（不计排序）。

**易错点。**
- 取了 `nums[1::2]`：那是每对的较大值，`[1,4,3,2]` 得 `6`，应为 `4`。
- 首尾配对（大配小）：那是 LC 1877 最小化最大数对和的做法，这里会把大数浪费掉。

**追问。**
- 交换论证？：若最小值 `a` 配的不是次小值 `b`，把 `b` 换过来，较小值之和不减。
- 值域只有 `[-10^4, 10^4]`？：计数排序可做到 `O(n + V)`。

**同模式。** LC 455 分发饼干、LC 881 救生艇、LC 1877 数组中最大数对和的最小值
