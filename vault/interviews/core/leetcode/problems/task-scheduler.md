## Q
**LC 621 任务调度器**｜Medium

任务 `tasks`（大写字母），同种任务之间必须间隔至少 `n` 个时间单位，每单位执行一个任务或待命。求完成所有任务的最短时间。

## A
**一句话。** 最多的任务定骨架：`(peak - 1)` 个长 `n + 1` 的周期加末段并列最多的任务，与总任务数取较大者。

```python
def least_interval(tasks, n):
    counts = Counter(tasks).values()
    peak = max(counts)
    ties = sum(c == peak for c in counts)   # 并列最多的种类数
    return max(len(tasks), (peak - 1) * (n + 1) + ties)
```

**复杂度。** 时间 `O(T)`，空间 `O(1)`。

**易错点。**
- 漏掉 `ties`：`["A","A","B","B"]`、`n=2` 应为 `5`，只加 `1` 得 `4`。
- 漏掉与 `len(tasks)` 取最大：`["A","A","B","B","C","C"]`、`n=1` 公式给 `5`，实际 `6`。
- 周期写成 `n`：任务自己占一格，要 `n + 1`。

**追问。**
- 要输出具体排程？：堆加冷却队列模拟，或按周期把次数从多到少依次填入。
- 不同任务冷却时间不同？：公式失效，只能堆模拟。
