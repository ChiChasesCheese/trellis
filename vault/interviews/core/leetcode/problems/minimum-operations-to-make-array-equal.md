## Q
**LC 1551 使数组中所有元素相等的最小操作数**｜Medium

数组 `arr[i] = 2 * i + 1`（长度 `n`）。一次操作选两个下标 `x`、`y`，令 `arr[x] -= 1`、`arr[y] += 1`。求让所有元素相等的最少操作数。

## A
**一句话。** 总和不变，所有元素最终都等于平均值 `n`；每次操作把「一个多出来的 1」从大数搬到小数，所以答案是小于平均值的那一半元素与 `n` 的差之和。

```python
def min_operations(n):
    total = 0
    for i in range(n // 2):       # 小于平均值 n 的那一半
        total += n - (2 * i + 1)  # 每个要补的量
    return total                  # 等价于 n * n // 4
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`；直接返回 `n * n // 4` 为 `O(1)`。

**易错点。**
- 把平均值算成别的数：`2i + 1` 的平均值是 `n`。
- 奇偶长度分不清：`n` 为奇数时中间的元素恰好等于平均值，不需要补，循环到 `n // 2` 自然排除。
- 把操作数算成两倍：一次操作同时完成一处「减」和一处「加」，只数补的一边。

**追问。**
- 公式 `n * n // 4` 怎么来？：补的量 `n - 1, n - 3, …` 是等差数列，求和得 `⌊n²/4⌋`。
- 一般数组呢？：每个元素到平均值的距离之和的一半，要求总和能被 `n` 整除。
