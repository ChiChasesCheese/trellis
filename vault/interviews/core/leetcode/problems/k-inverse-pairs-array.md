## Q
**LC 629 K 个逆序对数组**｜Hard

求 `1..n` 的排列中恰有 `k` 个逆序对的个数（`n, k <= 1000`），对 `10^9+7` 取余。

## A
**一句话。** 把 `i` 插进 `1..i-1` 的排列，放在倒数第 `t` 个位置新增 `t` 个逆序对（`0 <= t <= i-1`），所以 `f[i][j]` 是上一行 `f[i-1][j-i+1 .. j]` 的窗口和，边扫边维护。

```python
def k_inverse_pairs(n, k):
    MOD = 10**9 + 7
    # f[i][j]：1..i 的排列中恰有 j 个逆序对的个数
    f = [[0] * (k + 1) for _ in range(n + 1)]
    f[0][0] = 1
    for i in range(1, n + 1):
        win = 0                 # f[i-1][j-i+1 .. j] 的和
        for j in range(k + 1):
            win += f[i - 1][j]
            if j >= i:
                win -= f[i - 1][j - i]   # 移出窗口
            f[i][j] = win % MOD
    return f[n][k]
```

**复杂度。** 时间 `O(nk)`，空间 `O(nk)`。

**易错点。**
- 直接三重循环求和：`O(n²k)` 会超时，要用窗口和。
- 窗口宽度写成 `i+1`：新增逆序对只有 `0..i-1` 共 `i` 种。

**追问。**
- 为什么插入最大的数而不是最小的？：插最大数时它和后面每个数都构成逆序对，新增个数只看位置，与原排列无关。
- 只求 `k <= n(n-1)/2` 以外？：`k` 超过 `n(n-1)/2` 直接为 0，可提前返回。
