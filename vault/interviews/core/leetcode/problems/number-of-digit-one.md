## Q
**LC 233 数字 1 的个数**｜Hard

给整数 `n`，统计所有小于等于 `n` 的非负整数中，数字 `1` 出现的总次数。

## A
**一句话。** 逐位统计：看每一位（个位、十位……）上出现 `1` 的数有多少个，高位、当前位、低位三段分情况相加。

```python
def count_digit_one(n):
    ans, p = 0, 1                      # p 是当前位的权重
    while p <= n:
        high = n // (p * 10)           # 当前位左边的数
        cur = n // p % 10              # 当前位
        low = n % p                    # 当前位右边的数
        if cur == 0:
            ans += high * p
        elif cur == 1:
            ans += high * p + low + 1
        else:
            ans += (high + 1) * p
        p *= 10
    return ans
```

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- `cur == 1` 时忘了 `+ low + 1`：当前位恰为 1，右边那一截可取 `0..low`，共 `low+1` 个。
- `cur == 0` 误加 `(high+1)*p`：当前位为 0 时高位不能取到 `high` 本身，只有 `high` 种。
- 把 `p` 乘到溢出：C++/Java 里用 `long`，Python 没有这个问题。

**追问。**
- 统计其他数字 `d`（`1~9`）怎么改？：把 `1` 换成 `d`，`cur == d` 分支同上，`cur > d` 与 `cur < d` 对应原来的两支。
- 想换成数位 DP？：状态 `(位置, 已有几个 1, 是否贴上界)`，更通用，能处理「不含某数字」等限制。

**同模式。** LC 400 第 N 位数字、LC 600 不含连续 1 的非负整数、LC 902 最大为 N 的数字组合、LC 357 统计各位数字都不同的数字个数
