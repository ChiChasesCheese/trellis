## Q
**LC 326 3 的幂**｜Easy

给整数 `n`，判断它是否是 3 的幂，即是否存在整数 `x` 使 `n == 3^x`。

## A
**一句话。** 32 位整数里最大的 3 的幂是 `3^19`；3 是质数，所以 `3^19` 的因子恰好都是 3 的幂，`n` 是正数且整除 `3^19` 就是答案。

```python
def is_power_of_three(n):
    return n > 0 and 3**19 % n == 0   # 3 是质数，因子只能是 3 的幂
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 忘了 `n > 0`：`n = 0` 会除零，负数不是 3 的幂。
- 对非质数底数照搬：4 的幂用这个办法不对（`4^k` 的因子里有 2 的幂但不是 4 的幂），只对质数底数成立。
- 用对数 `log(n)/log(3)`：浮点误差会让 `243` 这类值判错，要用整数方法。

**追问。**
- 不用技巧时怎么做？：循环 `while n % 3 == 0: n //= 3`，最后看 `n == 1`，`O(log n)`。
- 范围换成 64 位呢？：最大的 3 的幂换成 `3^39`，原理不变。

**同模式。** LC 231 2 的幂、LC 342 4的幂、LC 263 丑数
