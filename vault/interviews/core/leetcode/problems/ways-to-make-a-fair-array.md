## Q
**LC 1664 生成平衡数组的方案数**｜Medium

整数数组 `nums`。恰好删掉一个元素后，剩余元素重新编号，若偶数下标元素之和等于奇数下标元素之和，数组就是平衡的。求有多少个下标，删掉它能得到平衡数组。

## A
**一句话。** 删掉位置 `i` 后，左边下标奇偶不变，右边的奇偶互换；用左边前缀和与（总和 - 左边 - 自己）算右边即可。

```python
def ways_to_make_fair(nums):
    tot = [0, 0]                       # 偶、奇下标的总和
    for i, x in enumerate(nums):
        tot[i % 2] += x
    left = [0, 0]
    ans = 0
    for i, x in enumerate(nums):
        right = [tot[0] - left[0], tot[1] - left[1]]
        right[i % 2] -= x               # 去掉自己
        # 右边奇偶互换：右边的奇下标和并入偶下标
        if left[0] + right[1] == left[1] + right[0]:
            ans += 1
        left[i % 2] += x
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了右边奇偶互换：删掉一个元素后右侧下标都减一。
- 右边总和没去掉当前元素：把被删的数又算进去了。

**追问。**
- 为什么右边奇偶要互换？：右侧每个元素的下标减一，原来的奇数下标变成偶数下标。

**同模式。** LC 724 寻找数组的中心下标、LC 238 除了自身以外数组的乘积、LC 560 和为 K 的子数组、LC 1991 找到数组的中间位置
