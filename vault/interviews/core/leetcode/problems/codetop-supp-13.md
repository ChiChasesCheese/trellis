## Q
**补充题 13 中文数字转阿拉伯数字**｜Medium

把表示非负整数的中文数字串（如 `"一亿两千三百万零五"` → `123000005`）转成整数；规范书写，`十二` 即 `12`，`两` 等同 `二`。

## A
**一句话。** 从左到右扫，维护 `num`（待乘单位的数字）、`section`（万级块内）、`total`（已结算），`万` 只结算本块，`亿` 乘全部。

```python
def chinese_to_int(s):
    D = {"零": 0, "一": 1, "二": 2, "两": 2, "三": 3, "四": 4,
         "五": 5, "六": 6, "七": 7, "八": 8, "九": 9}
    U = {"十": 10, "百": 100, "千": 1000}
    total = section = num = 0
    for ch in s:
        if ch in D:
            num = D[ch]
        elif ch in U:      # "十二" 省略了前面的一
            section += (num or 1) * U[ch]
            num = 0
        elif ch == "万":   # 只结算这一块
            total += (section + num) * 10_000
            section = num = 0
        else:              # 亿：前面攒下的全部乘 1 亿
            total = (total + section + num) * 10**8
            section = num = 0
    return total + section + num
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- `万` 和 `亿` 一样乘全部累计：`"一亿两千三百万零五"` 得 `1000023000005`。
- 十前省略的 `一` 没补：`"十"` 得 `0`，要用 `(num or 1)`。
- 结尾忘了加剩下的 `section + num`：`"一百零五"` 返回 `0`。

**追问。**
- 反过来阿拉伯数字转中文？：四位一组，组内处理千百十，组间按是否出现 `0` 补 `零`。
- 口语 `一百一` 表示 `110`？：末尾单独的数字补上比它低一级的单位。
