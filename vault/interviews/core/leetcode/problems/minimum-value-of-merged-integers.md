## Q
**LC 4097 合并整数后的最小值**｜Easy

偶数长度数组 `nums` 按 `(0,1)(2,3)…` 两两配对，每对把后一个的数位接在前一个后面，返回所有拼出整数的最小值。

## A
**一句话。** 步长 2 配对，用字符串拼接后转 `int`，取数值最小。

```python
def min_merged(nums):
    return min(int(f"{a}{b}")
               for a, b in zip(nums[::2], nums[1::2]))
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 拼完直接比字符串：`"347"` 与 `"1111"` 字典序 `"1111"` 更小，得 `1111`，应为 `347`。
- 拼接顺序反了：`[9,20]` 得 `209`，应为 `920`。

**追问。**
- 想让拼出的数尽量大呢？：比较 `a+b` 与 `b+a`，即 LC 179 的排序技巧。

**同模式。** LC 179 最大数、LC 2160 拆分数位后四位数字的最小和、LC 2578 最小和分割
