## Q
**LC 120 三角形最小路径和**｜Medium

给三角形 `triangle`，自顶向下每步只能走到下一行的相邻位置（第 `i` 列或第 `i+1` 列），求最小路径和。

## A
**一句话。** 自底向上的二维 DP：每个格子等于自己加下方两个相邻格中较小的，答案是顶点。

```python
def minimum_total(triangle):
    n = len(triangle)
    dp = [row[:] for row in triangle]   # (i,j) 到底边的最小和
    for i in range(n - 2, -1, -1):      # 最底行就是基础行
        for j in range(i + 1):
            dp[i][j] += min(dp[i + 1][j], dp[i + 1][j + 1])
    return dp[0][0]
```

**复杂度。** 时间 `O(n²)`，空间 `O(n²)`。

**易错点。**
- 贪心每步选下一行较小的：`[[-1],[2,3],[1,-1,-3]]` 贪心得 `0`，最优是 `-1`。
- 自顶向下时写 `dp[i-1][j-1]`：`j=0` 会回绕到末尾，不报错但结果悄悄出错。

**追问。**
- 怎么输出路径本身？：整张表在手，从 `(0,0)` 起每步走到 `dp` 更小的后继。
- 每步可走左、中、右三个位置呢？：就是 LC 931，转移多一项。

**同模式。** LC 64 最小路径和、LC 931 下降路径最小和、LC 62 不同路径、LC 118 杨辉三角
