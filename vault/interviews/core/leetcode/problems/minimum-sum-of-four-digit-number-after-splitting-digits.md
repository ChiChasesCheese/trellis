## Q
**LC 2160 拆分数位后四位数字的最小和**｜Easy

四位正整数 `num`（可能含 `0`）。把它的四个数位拆成两个新整数 `new1`、`new2`（允许有前导零，数位全部用上），求 `new1 + new2` 的最小值。

## A
**一句话。** 数位排序后，最小的两位放十位，较大的两位放个位：`d[0]d[2] + d[1]d[3]`。

```python
def minimum_sum(num):
    d = sorted(str(num))
    return int(d[0] + d[2]) + int(d[1] + d[3])
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 拆成一个三位数和一个一位数：十位上放大数会把和拉高，应两个两位数。
- 两位数里把大的放十位：十位权重大，放最小的两位。

**追问。**
- 位数不固定怎么办？：见 LC 2578，把排序后的数位交替分给两个数。

**同模式。** LC 2578 最小和分割、LC 179 最大数
