## Q
**LC 1850 邻位交换的最小次数**｜Medium

数字字符串 `num`（长度 `<= 1000`）。比 `num` 大的排列里第 `k` 小的叫美丽数。求把 `num` 变成它所需的最少相邻字符交换次数。

## A
**一句话。** 两步：对 `num` 连续做 `k` 次下一个排列得到目标；再从左到右贪心，把目标位置上的字符从后面第一个相同字符处一路冒泡过来，累加距离。

```python
def get_min_swaps(num, k):
    a = list(num)
    b = a[:]
    for _ in range(k):             # 下一个排列，做 k 次
        i = len(b) - 2
        while b[i] >= b[i + 1]:    # 从右找第一个升序处
            i -= 1
        j = len(b) - 1
        while b[j] <= b[i]:        # 从右找第一个比它大的
            j -= 1
        b[i], b[j] = b[j], b[i]
        b[i + 1:] = b[i + 1:][::-1]  # 后缀翻成最小
    ans = 0
    for i in range(len(a)):
        j = i
        while a[j] != b[i]:        # 取最近的同字符，保证交换最少
            j += 1
        a.insert(i, a.pop(j))      # 冒泡到位，花 j - i 次
        ans += j - i
    return ans
```

**复杂度。** 时间 `O(kn + n²)`，空间 `O(n)`。

**易错点。**
- 取最远的同字符来换：重复字符里必须取最近的那个，否则多出无谓的交换。
- 只求一次下一个排列：第 `k` 小要连做 `k` 次，每次基于上一次的结果。

**追问。**
- 为什么贪心取最近的同字符？：相同字符之间的相对顺序保持不变时交换次数最少，等价于把 `a` 变成 `b` 的逆序对数。
- 换成逆序对怎么算？：给 `b` 里每个字符按出现顺序编号，映射成排列后数逆序对，可用树状数组 `O(n log n)`。
