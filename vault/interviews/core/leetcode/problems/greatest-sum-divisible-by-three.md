## Q
**LC 1262 可被三整除的最大和**｜Medium

从整数数组 `nums` 中选一些数（可不选），使和能被 `3` 整除，求最大和。

## A
**一句话。** 以「和模 3 的余数」为状态的 DP：每个数选或不选，选 `x` 从余数 `(r-x)%3` 转来。

```python
def max_sum_div_three(nums):
    n = len(nums)
    NEG = -10**18                 # 该余数凑不出
    # dp[i][r]：前 i 个数、和模 3 为 r 的最大和
    dp = [[NEG] * 3 for _ in range(n + 1)]
    dp[0][0] = 0
    for i, x in enumerate(nums, 1):
        for r in range(3):
            dp[i][r] = max(dp[i-1][r],             # 不选
                           dp[i-1][(r - x) % 3] + x)  # 选
    return dp[n][0]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 初值全写 `0`：等于承认空集余 `1`、`2` 也可达，`[4]` 得 `4`，应为 `0`。
- 贪心「删最小的余几的数」：`[2,6,8]` 总和余 `1` 无数可删，应删 `2` 与 `8` 得 `6`。

**追问。**
- 被一般的 `k` 整除呢？：状态变 `k` 个，`O(nk)`，转移不变。
- 有 `O(1)` 空间的贪心吗？：总和余 `r`，删最小的一个余 `r` 的数或最小的两个余 `3-r` 的数，取损失小的。
