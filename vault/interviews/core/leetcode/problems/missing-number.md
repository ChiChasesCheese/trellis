## Q
**LC 268 丢失的数字**｜Easy

长度为 `n` 的数组 `nums` 含 `[0, n]` 中互不相同的 `n` 个数，找出缺失的那个，要求线性时间、常数空间。

## A
**一句话。** 把 `0..n` 与数组所有元素异或，成对抵消，剩下的就是缺失数。

```python
def missing_number(nums):
    ans = len(nums)          # 下标只到 n-1，先放入 n
    for i, x in enumerate(nums):
        ans ^= i ^ x
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了初值 `n`：`[0,1]` 得 `0`，应为 `2`。
- 只异或值不异或下标：`[3,0,1]` 得 `1`，应为 `2`。

**追问。**
- 不用异或还能怎么做？：`n(n+1)/2 - sum(nums)`，大数语言要注意溢出。
- 数组有序呢？：二分找第一个 `nums[i] > i` 的位置。

**同模式。** LC 136 只出现一次的数字、LC 287 寻找重复数、LC 448 找到所有数组中消失的数字、LC 41 缺失的第一个正数
