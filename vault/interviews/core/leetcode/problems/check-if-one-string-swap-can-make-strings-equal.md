## Q
**LC 1790 仅执行一次字符串交换能否使两个字符串相等**｜Easy

两个等长字符串 `s1`、`s2`。最多对其中一个字符串做一次交换（交换同一个串里的两个下标处的字符）。问能否让两个串相等。

## A
**一句话。** 收集两串不同的位置：没有就已相等，恰好两处且交叉相等（`s1[i] == s2[j]` 且 `s1[j] == s2[i]`）才行。

```python
def are_almost_equal(s1, s2):
    diff = [(x, y) for x, y in zip(s1, s2) if x != y]
    return not diff or (len(diff) == 2 and
                        diff[0] == diff[1][::-1])
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只数不同位置的个数：`"ab"` 和 `"cd"` 也是两处不同，但交叉不相等，换不过来。
- 已相等的两个串：一次交换不是必须做的，返回 `True`。

**追问。**
- 允许最多 `k` 次交换呢？：变成最少交换次数问题，用 BFS 或按环计数。

**同模式。** LC 1247 交换字符使得字符串相同、LC 854 相似度为 K 的字符串、LC 1963 使字符串平衡的最小交换次数、LC 242 有效的字母异位词
