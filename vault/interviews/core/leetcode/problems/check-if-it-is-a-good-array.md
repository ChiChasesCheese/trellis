## Q
**LC 1250 检查「好数组」**｜Hard

给正整数数组 `nums`，从中选任意子集，每个数乘以任意整数（可正可负），再求和。若能使总和等于 `1`，数组就是「好数组」。判断 `nums` 是否好。

## A
**一句话。** 裴蜀定理：整数线性组合能表示的正数里最小的是它们的最大公约数，所以答案是全体数的 `gcd == 1`。

```python
def is_good_array(nums):
    return gcd(*nums) == 1       # 裴蜀定理：能凑出 1 当且仅当 gcd 为 1
```

**复杂度。** 时间 `O(n log max)`，空间 `O(1)`。

**易错点。**
- 想着挑子集：子集的 `gcd` 只会不小于全体的 `gcd`，用全体检查就够了。
- 以为只能用乘正系数：系数可以是负的，所以是整数线性组合，不是凑硬币。
- 提前 `break` 在 `gcd == 1`：可以，`gcd` 一旦为 1 就不会再变。

**追问。**
- 为什么能表示的最小正数是 `gcd`？：扩展欧几里得算法给出一组整系数使 `a·x + b·y = gcd(a, b)`，反过来任意组合都是 `gcd` 的倍数。
- 水壶问题（LC 365）怎么套？：能量出 `target` 当且仅当 `target` 是两壶容量 `gcd` 的倍数且不超过总容量。

**同模式。** LC 365 水壶问题、LC 780 到达终点、LC 1071 字符串的最大公因子
