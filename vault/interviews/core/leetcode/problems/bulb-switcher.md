## Q
**LC 319 灯泡开关**｜Medium

`n` 个灯泡初始全灭，第 `i` 轮切换编号为 `i` 的倍数的灯泡，`n` 轮后还亮几个？`n` 到 `10^9`。

## A
**一句话。** 灯泡 `j` 被切换的次数是 `j` 的因子个数，只有完全平方数有奇数个因子，答案是 `⌊√n⌋`。

```python
def bulb_switch(n):
    return isqrt(n)    # 1..n 里完全平方数的个数
```

**复杂度。** 时间 `O(1)`（视开方为常数），空间 `O(1)`。

**易错点。**
- 用 `int(n ** 0.5)`：浮点误差在大数上可能少 1，整数开方用 `isqrt`。
- 去模拟 `n` 轮：`n = 10^9` 时 `O(n log n)` 超时。

**追问。**
- 为什么平方数因子个数是奇数？：因子 `d` 与 `j/d` 成对，只有 `d = √j` 时两者重合。
- 哪些灯亮着？：编号 `1, 4, 9, …`，即所有不超过 `n` 的完全平方数。
