## Q
**LC 338 比特位计数**｜Easy

对 `0..n` 的每个 `i` 求二进制中 `1` 的个数，返回长度 `n+1` 的数组，要求 `O(n)`。

## A
**一句话。** DP：`i` 去掉最低位就是 `i >> 1`，已算过，`ans[i] = ans[i >> 1] + (i & 1)`。

```python
def count_bits(n):
    ans = [0] * (n + 1)
    for i in range(1, n + 1):
        ans[i] = ans[i >> 1] + (i & 1)
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`（不计输出）。

**易错点。**
- 数组长度写成 `[0] * n`：要覆盖 `0..n`，`n=2` 时 `ans[2]` 越界。
- 用 `/` 取一半：`ans[i / 2]` 是浮点下标，抛 `TypeError`。

**追问。**
- 还有别的递推吗？：`ans[i] = ans[i & (i-1)] + 1`，去掉最低位的 `1`。
- 为什么 `bin(i).count("1")` 不行？：结果对但是 `O(n log n)`，且违反不用内置位计数的要求。

**同模式。** LC 191 位 1 的个数、LC 231 2 的幂、LC 461 汉明距离、LC 1356 根据数字二进制下 1 的数目排序
