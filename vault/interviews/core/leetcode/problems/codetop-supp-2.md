## Q
**补充题 2 圆环回原点问题**｜Medium

圆环上有 `n` 个点（`0` 与 `n - 1` 相邻），从 `0` 出发每步走到相邻点，求恰好 `k` 步回到 `0` 的方案数，对 `10^9 + 7` 取模。

## A
**一句话。** 动态规划：`ways[i]` 是停在 `i` 的方案数，每步由 `i - 1` 与 `i + 1` 的方案数相加，下标取模首尾相接。

```python
def ring_ways(n, k):
    MOD = 10**9 + 7
    ways = [0] * n
    ways[0] = 1
    for _ in range(k):
        # 一次产生新列表，下标取模 = 首尾相接
        ways = [(ways[i - 1] + ways[(i + 1) % n]) % MOD
                for i in range(n)]
    return ways[0]
```

**复杂度。** 时间 `O(nk)`，空间 `O(n)`。

**易错点。**
- 原地更新：同一步里已更新的值被后面的下标读到，`(3, 2)` 得 `0`，应为 `2`。
- `k = 0` 提前返回 `0`：已在原点，答案是 `1`。
- C++ / Java 里 `i - 1` 要写 `(i - 1 + n) % n`。

**追问。**
- `k` 到 `10^9`？：矩阵快速幂 `O(n^3 log k)`。
- 有闭式吗？：`j` 步顺时针满足 `(2j - k) % n == 0`，答案是对这些 `j` 的 `C(k, j)` 求和。

**同模式。** LC 70 爬楼梯、LC 62 不同路径、LC 576 出界的路径数、LC 935 骑士拨号器
