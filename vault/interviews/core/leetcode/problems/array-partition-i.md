## Q
**LC 561 数组拆分 I**｜Easy

把长度 `2n` 的数组分成 `n` 对，使各对较小值之和最大，返回这个和。

## A
**一句话。** 贪心：排序后相邻配对，答案是偶数下标元素之和。

```python
def array_pair_sum(nums):
    nums = sorted(nums)
    return sum(nums[::2])    # 每对较小者落在偶数下标
```

**复杂度。** 时间 `O(n log n)`，空间 `O(n)`。

**易错点。**
- 最大配最小：`[1,4,3,2]` 配成 `(1,4), (2,3)` 只得 `3`，应为 `4`。
- 切片写成 `nums[1::2]`：取到较大者，`[1,4,3,2]` 得 `6`。

**追问。**
- 怎么做到 `O(n)`？：值域只有 `2*10^4 + 1` 种，计数排序后交替取值。
- 改成每组 `k` 个？：排序后答案 `sum(nums[::k])`。

**同模式。** LC 881 救生艇、LC 1877 数组中最大数对和的最小值、LC 455 分发饼干、LC 2144 打折购买糖果的最小开销
