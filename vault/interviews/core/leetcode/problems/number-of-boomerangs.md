## Q
**LC 447 回旋镖的数量**｜Medium

平面上 `n` 个互不相同的点。「回旋镖」是有序三元组 `(i, j, k)`，满足 `i` 到 `j` 的距离等于 `i` 到 `k` 的距离。返回回旋镖的数量。

## A
**一句话。** 枚举作为「顶点」的点 `i`，用哈希表统计其他点到 `i` 的距离出现次数，距离相同的 `c` 个点可组成 `c·(c-1)` 个有序对。

```python
def number_of_boomerangs(points):
    ans = 0
    for x, y in points:
        cnt = Counter((x - a) ** 2 + (y - b) ** 2
                      for a, b in points)    # 到当前点的距离平方
        ans += sum(c * (c - 1) for c in cnt.values())
    return ans
```

**复杂度。** 时间 `O(n²)`，空间 `O(n)`。

**易错点。**
- 用平方根算距离：浮点误差会让相同距离的键不相等，直接用距离的平方（整数）。
- 把无序对当有序对：三元组 `(i, j, k)` 有序，`j` 与 `k` 交换算两个，所以是 `c·(c-1)` 而不是 `C(c, 2)`。
- 把自己也算进去：到自己的距离是 0，只有一个点，`c = 1` 贡献 `0`，不会出错。

**追问。**
- 为什么哈希表每个顶点重建一次？：不同顶点的距离分布互不相同，不能复用。
- 想优化吗？：最坏情况的 `O(n²)` 无法避免，因为要看遍所有点对的距离。

**同模式。** LC 149 直线上最多的点数、LC 2013 检测正方形、LC 939 最小面积矩形、LC 1 两数之和
