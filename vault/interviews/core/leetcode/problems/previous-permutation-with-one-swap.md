## Q
**LC 1053 交换一次的先前排列**｜Medium

给正整数数组 `arr`（可含重复），恰好交换两个数一次，得到字典序比 `arr` 小的最大排列；做不到就返回原数组。

## A
**一句话。** 从右往左找第一个下降位 `i`（`arr[i] > arr[i+1]`），再在它右边挑小于 `arr[i]` 的最大值（相同取最左）与之交换。

```python
def prev_perm_opt1(arr):
    n = len(arr)
    for i in range(n - 2, -1, -1):
        if arr[i] > arr[i + 1]:           # 最靠右的下降位
            j = i + 1
            for k in range(i + 2, n):
                # 右边小于 arr[i] 的最大值，相同取最左
                if arr[j] < arr[k] < arr[i]:
                    j = k
            arr[i], arr[j] = arr[j], arr[i]
            break
    return arr
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 重复值取最右：相同的值要取最左的，换到前面才能让结果更大，用严格 `<` 更新。
- 找最左的下降位：要改动尽量靠右的位置，字典序损失才最小，所以从右往左扫。
- 右边没有比 `arr[i]` 小的就交换：第一个下降位保证 `arr[i+1] < arr[i]`，所以一定有解。

**追问。**
- 下一个排列（LC 31）怎么做？：对称：从右找第一个上升位，换右边刚好更大的，再反转后缀。
- 为什么交换位置越靠右越好？：高位保持不变，只在尽量低的位变小。

**同模式。** LC 31 下一个排列、LC 556 下一个更大元素 III、LC 60 排列序列
