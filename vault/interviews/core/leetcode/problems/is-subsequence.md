## Q
**LC 392 判断子序列**｜Easy

判断字符串 `s` 是否为 `t` 的子序列（删去 `t` 的部分字符、不改变顺序能得到 `s`）。

## A
**一句话。** 双指针贪心：扫描 `t`，遇到 `s` 正在等的字符就匹配，指针前进。

```python
def is_subsequence(s, t):
    i = 0                      # s[:i] 已在 t 里按序匹配
    for ch in t:
        if i < len(s) and ch == s[i]:
            i += 1             # 越早匹配，留给后面的越多
    return i == len(s)
```

**复杂度。** 时间 `O(|t|)`，空间 `O(1)`。

**易错点。**
- 只看字符是否出现、不看顺序：`s="aec"`, `t="abcde"` 会错判 `True`。
- 去掉 `i < len(s)`：`s` 匹配完后继续访问 `s[i]` 越界。

**追问。**
- 有海量 `s` 要查同一个 `t`？：预处理 `t` 每个字符的下标列表，每个 `s` 对每个字符二分找下一个位置。
- 数子序列出现的方案数？：贪心不够，用 `dp[i][j]` 二维 DP（LC 115）。

**同模式。** LC 792 匹配子序列的单词数、LC 524 通过删除字母匹配到字典里最长单词、LC 1143 最长公共子序列
