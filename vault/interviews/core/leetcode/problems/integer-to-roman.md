## Q
**LC 12 整数转罗马数字**｜Medium

把 `1 <= num <= 3999` 转成罗马数字，4、9 类用减法形式（`IV`、`IX`、`XL`、`XC`、`CD`、`CM`）。

## A
**一句话。** 把六个减法形式也当符号，排成 13 项降序表，对每项贪心取个数。

```python
ROMAN = [(1000, "M"), (900, "CM"), (500, "D"),
         (400, "CD"), (100, "C"), (90, "XC"), (50, "L"),
         (40, "XL"), (10, "X"), (9, "IX"), (5, "V"),
         (4, "IV"), (1, "I")]

def int_to_roman(num):
    res = []
    for value, sym in ROMAN:      # 必须按面值降序
        count, num = divmod(num, value)
        res.append(sym * count)
    return "".join(res)
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 表里漏了减法形式：只放七个基本符号，`4` 会写成 `IIII`，应为 `IV`。
- 表没按面值降序：`(4,"IV")` 排在 `(5,"V")` 前，`8` 变成 `IVIV`，应为 `VIII`。

**追问。**
- 反过来罗马转整数？：从左到右，当前符号比右邻小就减，否则加。
- 不用大表怎么写？：按十进制位拆开，千、百、十、个位各一张 0–9 的表，各查一次。

**同模式。** LC 13 罗马数字转整数、LC 273 整数转英文表示、LC 168 Excel 表列名称
