## Q
**圆环上走 n 步回到原点的方案数**｜Medium

环上 `10` 个点（编号 `0` 到 `9`），从 `0` 出发，每步顺时针或逆时针走一格。求恰好 `n` 步回到 `0` 的走法数，对 `10^9 + 7` 取模。例：`n = 2` → `2`，`n = 4` → `6`。

## A
**一句话。** 动态规划：`ways[p]` 是停在 `p` 的走法数，每步新 `ways[p]` 等于旧 `ways[p-1] + ways[p+1]`（环取模），走 `n` 步后取 `ways[0]`。

```python
def ring_walks(n, size=10, mod=10**9 + 7):
    ways = [1] + [0] * (size - 1)
    for _ in range(n):
        # p - 1 为负时 Python 自动绕回；整体生成新数组
        ways = [(ways[p - 1] + ways[(p + 1) % size]) % mod
                for p in range(size)]
    return ways[0]
```

**复杂度。** 时间 `O(10n)`，空间 `O(10)`。

**易错点。**
- 更新时覆盖旧数组：原地改会让后面的 `p` 读到本步新值，`n = 2` 得 `0`，应为 `2`。
- `(p + 1)` 忘了取模：`p = 9` 时下标越界；C++/Java 里 `p - 1` 还要写 `(p - 1 + size) % size`。

**追问。**
- `n` 到 `10^18`？：转移是固定的 `10 x 10` 矩阵，用矩阵快速幂。
- 有没有闭式？：顺时针 `j` 步使净位移 `2j - n` 是 `10` 的倍数，答案是对这些 `j` 的 `C(n, j)` 求和。

**同模式。** LC 70 爬楼梯、LC 576 出界的路径数、LC 1269 停在原地的方案数、LC 935 骑士拨号器
