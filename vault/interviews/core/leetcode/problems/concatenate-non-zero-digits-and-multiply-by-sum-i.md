## Q
**LC 3754 连接非零数字并乘以其数字和 I**｜Easy

把 `n` 中非零数字按原顺序连成整数 `x`（没有则 `x = 0`），返回 `x` 乘以 `x` 的各位数字之和。

## A
**一句话。** 逐位扫描：非零数字接到 `x` 末尾（`x = x·10 + d`），同时累加数字和。

```python
def sum_and_multiply(n):
    x = s = 0
    for ch in str(n):
        d = int(ch)
        if d:
            x = x * 10 + d      # 只接非零数字
            s += d
    return x * s
```

**复杂度。** 时间 `O(log n)`，空间 `O(log n)`。

**易错点。**
- `int(''.join(...))` 在全零时对空串报错：`n = 0` 要得 `0`。
- 从低位用 `% 10` 拆：顺序是反的，要么反转，要么从高位扫。

**追问。**
- 很多子串查询（LC 3756）？：前缀维护「拼接值」和「非零个数」，`x = val[r+1] - val[l]·10^cnt`。
- 不转字符串？：先 `% 10` 拆出数字列表再倒序拼。
