## Q
**LC 283 移动零**｜Easy

给定数组 `nums`，把所有 `0` 移到数组末尾，同时保持非零元素的相对顺序。必须**原地**操作，不能复制数组。`1 <= nums.length <= 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。例：`[0,1,0,3,12]` → `[1,3,12,0,0]`；`[0]` → `[0]`。进阶：能否尽量减少完成的操作次数？

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 快慢双指针（read / write pointer）原地分区：把「满足条件的元素」稳定地压到数组前部。

**一句话。** `read` 扫描，`write` 指向下一个非零元素该去的位置；遇到非零就和 `write` 处交换，`write` 前进。

**识别。** 「原地」「保持相对顺序」「把某类元素集中到一端」是快慢指针的标准信号；`n` 只有 `10^4`，但原地要求排除了新建列表。同一骨架还能解 LC 27 移除元素、LC 26 删除有序数组重复项。

**推导。** 先想到「删掉 0 再在末尾补 0」：`list.remove` 每次 `O(n)`，总共 `O(n^2)`，且删除会整体平移。浪费在平移上；其实只要知道每个非零元素的最终位置，就是它前面非零元素的个数，用一个计数器 `write` 即可，一趟扫描搞定。

```python
def move_zeroes(nums: list[int]) -> None:
    write = 0  # 不变式：nums[:write] 是已放好的非零元素（保持原顺序），nums[write:read] 全是 0
    for read in range(len(nums)):
        if nums[read] != 0:
            nums[write], nums[read] = nums[read], nums[write]  # 非零换到 write 处；被换走的一定是 0
            write += 1
```

运行：`[0,1,0,3,12]` → `[1,3,12,0,0]`；`[0]` → `[0]`；`[1,2,3]`（没有 0）→ `[1,2,3]`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 进阶「减少操作次数」：`write == read` 时（前缀全是非零）交换是空操作，加一句 `if write != read` 即可跳过；写入次数降到「非零元素需要前移的个数」。
- 另一种写法是先把非零元素依次覆盖到前部，再把 `nums[write:]` 填 0：写入总数是 `n`，交换版最多 `n` 次交换（每次两次写入）。

**易错点。**
- 只覆盖不补零：`[0,1,0,3,12]` 会停在 `[1,3,12,3,12]`，漏掉了把尾部填成 `0` 这一步。
- 用 `for x in nums: if x == 0: nums.remove(x)` 边遍历边删，会跳过紧邻的元素，且是 `O(n^2)`。

**同模式。** LC 27 移除元素、LC 26 删除有序数组中的重复项、LC 75 颜色分类（三路分区）、LC 443 压缩字符串。
