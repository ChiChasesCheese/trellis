## Q
**LC 137 只出现一次的数字 II**｜Medium

`nums` 中除一个数只出现一次外，其余都恰出现三次。找出那个数，要求线性时间、常数空间。

## A
**一句话。** 按位统计：每一位上 1 的个数模 3，出现三次的数抵消，剩下的就是答案在这一位的值。

```python
def single_number(nums):
    ans = 0
    for i in range(32):
        if sum(x >> i & 1 for x in nums) % 3:
            ans |= 1 << i
    # Python 整数无上限：第 31 位为 1 要还原成负数
    return ans - (1 << 32) if ans >> 31 else ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了处理符号：`[-4,1,1,1]` 返回 `4294967292`，应为 `-4`。
- 模 3 写成模 2（异或思路）：`[2,2,3,2]` 得 `1`，应为 `3`。

**追问。**
- 不循环 32 位，一次扫描行不行？：用两个变量 `ones`、`twos` 做三进制计数的状态机，`twos` 要用更新后的 `ones`。
- 其余数出现 `k` 次？：每位对 `k` 取余，同样适用。

**同模式。** LC 136 只出现一次的数字、LC 260 只出现一次的数字 III、LC 169 多数元素、LC 268 丢失的数字
