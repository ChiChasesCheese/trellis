## Q
**LC 1013 将数组分成和相等的三个部分**｜Easy

整数数组 `arr`，判断能否把它分成三个非空的连续部分，使三部分的和相等。

## A
**一句话。** 总和必须能被 3 整除；一遍扫描累加，每凑够 `总和/3` 就算一份并重新累计，凑够至少三份即可。

```python
def can_three_parts_equal_sum(arr):
    s = sum(arr)
    if s % 3:
        return False
    target, cur, parts = s // 3, 0, 0
    for x in arr:
        cur += x
        if cur == target:             # 凑够一份，重新累计
            parts += 1
            cur = 0
    return parts >= 3                 # 目标为 0 时可能不止三份
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 要求恰好 `3` 份：目标和为 `0` 时（如 `[0,0,0,0]`）会凑出更多份，多出的并入最后一份，`>= 3` 才对。
- 凑够两份就返回：第三份的和由总和决定，但必须非空，所以要数到第三份才算。

**追问。**
- 为什么 `parts >= 3` 就一定能分？：把前两份取出，剩余的和为 `target`，且它非空，因为已经数出第三份。
- 前缀和写法？：找两个下标，使前缀和分别为 `s/3` 和 `2s/3`，且第二个下标在第一个之后。
