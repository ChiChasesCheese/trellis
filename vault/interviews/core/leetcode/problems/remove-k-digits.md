## Q
**LC 402 移掉 K 位数字**｜Medium

数字字符串 `num`，移掉 `k` 位使剩下的数最小，结果去前导零，空则返回 `"0"`。

## A
**一句话。** 单调栈：栈顶比当前数字大且还有额度就弹出，扫完后额度没用完就从末尾删。

```python
def remove_kdigits(num, k):
    st = []
    for d in num:
        while k and st and st[-1] > d:   # 高位变小
            st.pop()
            k -= 1
        st.append(d)
    st = st[:len(st) - k]    # 不能写 [:-k]，k=0 会清空
    return "".join(st).lstrip("0") or "0"
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 截断写成 `stack[:-k]`：`k` 用完为 `0` 时得空表，`("1432219",3)` 返回 `"0"`，应为 `"1219"`。
- 相等也弹出（`>=`）：白白浪费额度，`("112",1)` 得 `"12"`，应为 `"11"`。
- 忘了去前导零：`("10200",1)` 得 `"0200"`，应为 `"200"`。

**追问。**
- 保留 `m` 位使数最大？：条件改成 `st[-1] < d`，额度为 `len(num) - m`。
- 去除重复字母使字典序最小（LC 316）？：同样单调栈，加「已在栈里」「后面还会出现」两个条件。

**同模式。** LC 316 去除重复字母、LC 1673 找出最具竞争力的子序列、LC 321 拼接最大数、LC 739 每日温度
