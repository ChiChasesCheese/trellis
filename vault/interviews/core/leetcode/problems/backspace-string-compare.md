## Q
**LC 844 比较含退格的字符串**｜Easy

`#` 表示退格，空文本上退格仍为空。判断 `s` 和 `t` 输入编辑器后的结果是否相同。

## A
**一句话。** 用栈模拟编辑器：字母入栈，`#` 时栈非空就弹出，最后比较两个栈。

```python
def backspace_compare(s, t):
    def build(x):
        st = []
        for c in x:
            if c != "#":
                st.append(c)
            elif st:
                st.pop()       # 空栈遇到 # 什么也不做
        return st
    return build(s) == build(t)
```

**复杂度。** 时间 `O(n + m)`，空间 `O(n + m)`。

**易错点。**
- 空栈时也 `pop()`：`"#a"` 这样的输入会抛 `IndexError`。
- 把 `#` 当普通字符入栈后再处理：退格应立刻删掉前一个字符。

**追问。**
- `O(1)` 空间？：从后往前双指针，各记一个待跳过的 `skip`，遇 `#` 加一，遇字母且 `skip > 0` 就跳过，找到真正留下的字符后再比较。
- 为什么从后往前？：一个字符是否被删只取决于它右边的 `#`，从右扫才能当场确定。

**同模式。** LC 20 有效的括号、LC 1047 删除字符串中的所有相邻重复项、LC 2390 从字符串中移除星号
