## Q
**LC 293 翻转游戏**｜Easy

字符串 `current_state` 只含 `+` 和 `-`。一次操作把两个连续的 `++` 翻成 `--`。返回走一步之后所有可能的字符串（任意顺序）。

## A
**一句话。** 扫描每个相邻位置，遇到 `++` 就把这两位换成 `--` 得到一个新字符串。

```python
def generate_possible_next_moves(current_state):
    s = current_state
    return [s[:i] + "--" + s[i + 2:]       # 只换这两个字符
            for i in range(len(s) - 1)
            if s[i:i + 2] == "++"]
```

**复杂度。** 时间 `O(n^2)`（每个结果拼接 `O(n)`），空间 `O(n^2)`（结果）。

**易错点。**
- 循环到 `len(s)`：最后一个位置没有后继，应到 `len(s) - 1`。
- 原地改 `s`：Python 字符串不可变，要用切片拼新串；且每个结果都基于原始串。

**追问。**
- 后续的 LC 294 怎么做？：对每个后继递归判断对手是否必败，配合记忆化。
- 没有可走的步时返回什么？：空列表。

**同模式。** LC 294 翻转游戏 II、LC 292 Nim 游戏
