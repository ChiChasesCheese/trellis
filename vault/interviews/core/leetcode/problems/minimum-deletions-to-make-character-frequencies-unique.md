## Q
**LC 1647 字符频次唯一的最小删除次数**｜Medium

字符串 `s` 中若没有两个不同字符出现次数相同，称它是「优质字符串」。返回使 `s` 成为优质字符串需要删除的最少字符数。

## A
**一句话。** 贪心：频次从大到小处理，若某个频次已被占用，就一个个往下删到没人占的频次（或 0），记下删除次数。

```python
def min_deletions(s):
    seen, ans = set(), 0                # seen：已被占用的频次
    for f in sorted(Counter(s).values(), reverse=True):
        while f and f in seen:          # 被占用，少留一个
            f -= 1
            ans += 1
        seen.add(f)
    return ans
```

**复杂度。** 时间 `O(n + k²)`，其中 `k ≤ 26` 为字符种类数，空间 `O(k)`。

**易错点。**
- 把频次降到 0 之后仍然「占用」0：多个字符可以都被删光，`0` 不算冲突，循环条件要带 `f` 非零。
- 只对频次排序一次却从小到大处理：大的先占位更省删除，要从大到小。
- 删除字符而不是减少频次：只关心频次，不必真的操作字符串。

**追问。**
- 为什么贪心正确？：每个频次至少要降到一个未被占用的更小值，降到最近的空位删得最少，从大到小保证大频次先选最好的位置。
- 数据规模很大时？：字符种类固定 26，复杂度仍是线性。
