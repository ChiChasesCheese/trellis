## Q
**LC 1344 时钟指针的夹角**｜Medium

给你两个数 `hour` 和 `minutes`，返回时钟上由这个时间的时针和分针构成的**较小角**的度数（一圈 `360` 度），与标准答案误差在 `10^-5` 以内都算对。`1 <= hour <= 12`，`0 <= minutes <= 59`。例：`hour = 12`, `minutes = 30` → `165`；`hour = 3`, `minutes = 30` → `75`；`hour = 3`, `minutes = 15` → `7.5`；`hour = 4`, `minutes = 50` → `155`；`hour = 12`, `minutes = 0` → `0`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 数学建模：把两根指针各自换算成相对 `12` 点的角度，再取较小的夹角。

**一句话。** 分针角度 `6 * minutes`，时针角度 `30 * (hour % 12) + 0.5 * minutes`，两者之差 `diff`，答案是 `min(diff, 360 - diff)`。

**识别。** 「时钟」「夹角」= 各指针的角速度：分针每分钟 `360 / 60 = 6` 度，时针每小时 `30` 度、每分钟 `0.5` 度；`O(1)` 公式题，细节在时针会随分钟移动，以及夹角要取较小的那个。

**推导。** 分针每分钟走 `6` 度，`minutes` 分钟就是 `6 * minutes` 度。时针每小时走 `30` 度，且在这个小时内随分钟匀速移动，每分钟 `30 / 60 = 0.5` 度，所以是 `30 * (hour % 12) + 0.5 * minutes`（`12` 点按 `0` 算）。两个角度之差可能超过 `180`，较小角就是 `min(diff, 360 - diff)`。

```python
def angle_clock(hour: int, minutes: int) -> float:
    minute_angle = minutes * 6  # 分针：每分钟 6 度
    hour_angle = (hour % 12) * 30 + minutes * 0.5  # 时针：每小时 30 度，加上本小时内随分钟走的部分
    diff = abs(hour_angle - minute_angle)
    return min(diff, 360 - diff)  # 两个夹角之和是 360，取较小的
```

运行：五个示例依次得到 `165.0`、`75.0`、`7.5`、`155.0`、`0.0`；`(1, 50)` → `115.0`；`(6, 0)` → `180.0`。

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**拓展优化。**
- 全程整数、避免浮点：角度乘 `2`（单位是半度），时针 `60 * (hour % 12) + minutes`，分针 `12 * minutes`，差和 `720 - 差` 取小，最后除以 `2`。结果恒为 `0.5` 的整数倍，浮点本来就精确。

**易错点。**
- 时针忽略分钟的偏移（只用 `30 * hour`）：`hour = 3`, `minutes = 30` 得到 `90`，正确是 `75`。
- 不取较小角：`hour = 1`, `minutes = 50` 得到 `245`，正确是 `115`。
- 用整数除法 `minutes // 2` 代替 `minutes * 0.5`：`hour = 3`, `minutes = 15` 得到 `7`，正确是 `7.5`。
