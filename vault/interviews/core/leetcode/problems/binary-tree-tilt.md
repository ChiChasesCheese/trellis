## Q
**LC 563 二叉树的坡度**｜Easy

节点的坡度是其左子树节点值之和与右子树节点值之和之差的绝对值。返回整棵树所有节点坡度之和。

## A
**一句话。** 后序递归返回子树和，在每个节点用左右子树和的差累加坡度。

```python
def find_tilt(root):
    ans = 0
    def dfs(node):                       # 返回子树节点值之和
        nonlocal ans
        if not node:
            return 0
        l, r = dfs(node.left), dfs(node.right)
        ans += abs(l - r)                # 当前节点的坡度
        return l + r + node.val
    dfs(root)
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(h)`。

**易错点。**
- 对每个节点单独再求一次子树和：`O(n²)`，应在后序里顺便返回。
- 返回坡度而不是子树和：父节点要用的是子树和，坡度只累加到答案里。
- 空节点返回 `None`：差运算会报错，要返回 `0`。

**追问。**
- 为什么是后序？：节点的坡度依赖左右子树的和，孩子必须先算完。
- 和「分裂二叉树的最大乘积」有什么相同？：都靠一次后序算出每棵子树的和，再据此做判断。
