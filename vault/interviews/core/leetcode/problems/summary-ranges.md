## Q
**LC 228 汇总区间**｜Easy

升序无重复数组，返回恰好覆盖所有数字的最小区间列表，`a != b` 写 `"a->b"`，否则写 `"a"`。

## A
**一句话。** 双指针找每一段极长连续整数，`j` 向右延伸到断开，输出后令 `i = j + 1`。

```python
def summary_ranges(nums):
    ans, i = [], 0
    while i < len(nums):
        j = i       # [i, j] 是当前连续段
        while (j + 1 < len(nums)
               and nums[j+1] == nums[j] + 1):
            j += 1
        ans.append(str(nums[i]) if i == j
                   else f"{nums[i]}->{nums[j]}")
        i = j + 1
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 下一段起点写 `i += 1`：`[0,1,2,4,5,7]` 会输出 `0->2`、`1->2`、`2`，段被重复。
- 单元素段写成 `"7->7"`：要判 `i == j`。
- `j + 1 < len(nums)` 放在 `and` 右边：`nums[j+1]` 越界。

**追问。**
- 反过来输出缺失区间（LC 163）？：取相邻元素之间的间隙。
- 还有别的写法吗？：连续整数的「值减下标」相同，按它分组取首尾。

**同模式。** LC 163 缺失的区间、LC 56 合并区间、LC 352 将数据流变为不相交区间、LC 128 最长连续序列
