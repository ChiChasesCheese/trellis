## Q
**LC 8 字符串转换整数 (atoi)**｜Medium

实现 `myAtoi(s)`：丢弃前导空格，读一个可选的正负号，读数字直到非数字，结果截断到 32 位有符号整数范围，没读到数字返回 `0`。

## A
**一句话。** 一个只向前走的下标依次过「空格、符号、数字」三段，数字段边读边判上限。

```python
def my_atoi(s):
    i, n = 0, len(s)
    while i < n and s[i] == " ":     # 只跳 ' '
        i += 1
    sign = 1
    if i < n and s[i] in "+-":       # 至多一个符号
        sign = -1 if s[i] == "-" else 1
        i += 1
    limit = 2**31 - 1 if sign == 1 else 2**31
    num = 0
    while i < n and "0" <= s[i] <= "9":
        num = num * 10 + int(s[i])
        if num >= limit:             # 只增不减，到上限就返回
            return sign * limit
        i += 1
    return sign * num
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 负数下界当成 `-(2^31-1)`：`"-2147483648"` 应为 `-2147483648`，别两边都用 `INT_MAX`。
- 符号写成循环：`"+-12"` 应为 `0`，符号只读一次。
- 用 `isdigit()` 判数字：全角数字、`²` 也返回真，要写 `"0" <= ch <= "9"`。

**追问。**
- 固定位宽语言怎么不溢出？：累加前检查 `num > (INT_MAX - d) // 10`，不能先乘再判。
- 小数、科学计数法（LC 65）呢？：同样的状态机，状态更多，写成转移表。

**同模式。** LC 65 有效数字、LC 7 整数反转、LC 394 字符串解码、LC 224 基本计算器
