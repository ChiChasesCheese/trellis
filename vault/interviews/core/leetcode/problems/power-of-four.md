## Q
**LC 342 4的幂**｜Easy

给整数 `n`，判断它是否是 4 的幂。

## A
**一句话。** 4 的幂一定是 2 的幂（二进制只有一个 1），而且这个 1 落在偶数位：`n & (n-1) == 0` 保证只有一个 1，再与 `0x55555555`（偶数位全 1）相与非零。

```python
def is_power_of_four(n):
    # 只有一个 1，且在偶数位 (第 0、2、4… 位)
    return (n > 0 and (n & (n - 1)) == 0
            and (n & 0x55555555) != 0)
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 只判断是 2 的幂：`2`、`8` 也满足，要再看 1 的位置，`0x55555555 = 0101…01`。
- 忘了 `n > 0`：`n = 0` 时 `n & (n-1)` 为 `0`，会被误判。
- 位运算优先级：C/Java 里 `==` 比 `&` 优先级高，必须加括号；Python 里恰好相反，但加括号总是安全的。

**追问。**
- 不用位掩码还能怎么判？：`n % 3 == 1` 且是 2 的幂（`4^k ≡ 1 mod 3`，而 `2·4^k ≡ 2`）。
- 位掩码为什么是 `0x55555555`？：32 位整数偶数位是第 0、2、…、30 位，对应二进制 `0101…01`。

**同模式。** LC 231 2 的幂、LC 326 3 的幂、LC 191 位1的个数
