## Q
**LC 256 粉刷房子**｜Medium

一排 `n` 栋房子，每栋可刷红、蓝、绿三色之一，`costs[i][c]` 是第 `i` 栋刷颜色 `c` 的花费。相邻两栋颜色不能相同，求刷完所有房子的最小花费。

## A
**一句话。** `f(i, c)` 表示第 `i` 栋刷颜色 `c` 时，从它到最后的最小花费：加上下一栋在另外两种颜色里取小的那个。

```python
def min_cost(costs):
    n = len(costs)
    @cache
    def f(i, c):                       # 第 i 栋刷 c，往后的最小花费
        if i == n:
            return 0
        nxt = [f(i + 1, d) for d in range(3) if d != c]
        return costs[i][c] + min(nxt)  # 下一栋换另外两色
    return min(f(0, c) for c in range(3))
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 贪心每栋选最便宜的颜色：会和前一栋冲突，或为眼前省钱而让后面更贵，必须记住上一栋的颜色。
- 另外两种颜色写成 `c-1`、`c+1`：越界，用 `d != c` 过滤更稳。
- 终止条件：`i == n` 返回 `0`，最后一栋只加自己的花费。

**追问。**
- 颜色数是 `k` 呢？：枚举法 `O(n·k²)`，记住上一栋的最小和次小花费可降到 `O(n·k)`，即 LC 265。
- 想改成自底向上？：`dp[i][c] = costs[i][c] + min(dp[i-1][d])`，只依赖上一行，可用三个变量滚动。

**同模式。** LC 265 粉刷房子 II、LC 1473 粉刷房子 III、LC 1411 给 N x 3 网格图涂色的方案数、LC 198 打家劫舍
