## Q
**LC 933 最近的请求次数**｜Easy

设计 `RecentCounter`：`ping(t)` 记录时间 `t` 的一次请求（`t` 严格递增），返回 `[t-3000, t]` 内的请求总数，含本次。

## A
**一句话。** 时间戳进队列，每次从队头弹掉小于 `t-3000` 的，剩下的长度即答案。

```python
class RecentCounter:
    def __init__(self):
        self.q = deque()

    def ping(self, t):
        self.q.append(t)
        while self.q[0] < t - 3000:   # 窗口 [t-3000, t]
            self.q.popleft()
        return len(self.q)
```

**复杂度。** 时间 `ping` 均摊 `O(1)`，空间 `O(3000)`（窗口内最多 3001 个）。

**易错点。**
- 边界写成 `<=`：`t-3000` 这一刻的请求要算，`ping(3001)` 里 `1` 仍在窗口内。
- 先弹再入队：队空时 `q[0]` 会越界，先入队再弹，本次请求自己永不会被弹出。

**追问。**
- 同一时刻有多次请求呢？：题目保证 `t` 严格递增；若不保证就存 `(t, 次数)`，再维护总数。
- 窗口很大、请求极多怎么办？：队列大小等于窗口内请求数，可以改成按秒分桶的环形数组，内存与流量无关。

**同模式。** LC 362 敲击计数器、LC 359 日志速率限制器、LC 346 数据流中的移动平均值
