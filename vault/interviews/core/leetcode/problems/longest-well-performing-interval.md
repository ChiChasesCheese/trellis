## Q
**LC 1124 表现良好的最长时间段**｜Medium

`hours[i]` 是第 `i` 天工作小时数，超过 8 小时的天是「劳累的一天」。时间段内劳累的天数严格多于不劳累的天数，就是表现良好的时间段。返回最长的表现良好时间段的长度。

## A
**一句话。** 劳累的天记 `+1`、其余记 `-1`，问题变成「和大于 0 的最长子数组」；前缀和每步只变 1，所以只要记每个前缀值第一次出现的位置。

```python
def longest_wpi(hours):
    s, best = 0, 0
    first = {}                     # 前缀和 -> 第一次出现的下标
    for i, h in enumerate(hours):
        s += 1 if h > 8 else -1
        if s > 0:
            best = i + 1           # 整段前缀就合格
        else:
            first.setdefault(s, i)
            if s - 1 in first:     # 找最早的更小前缀
                best = max(best, i - first[s - 1])
    return best
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 记最后一次出现的位置：要让区间最长，必须取最早的位置。
- 找 `s - 1` 而不是 `s`：和要严格大于 0，起点的前缀必须严格更小，即至少差 1。
- 当 `s > 0` 时漏掉整段前缀的情形：这时答案是 `i + 1`，不必查表。

**追问。**
- 为什么只需查 `s - 1`？：前缀和每步变化 `±1` 且从 0 出发，第一次低于 `s` 的位置一定恰好等于 `s - 1`。
- 单调栈怎么做？：对前缀和用栈存递减的候选起点，从右往左扫终点，和 LC 962 最大宽度坡同一思路。

**同模式。** LC 525 连续数组、LC 962 最大宽度坡、LC 560 和为 K 的子数组
