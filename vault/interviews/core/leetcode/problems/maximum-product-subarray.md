## Q
**LC 152 乘积最大子数组**｜Medium

给整数数组 `nums`，求乘积最大的非空连续子数组的乘积。

## A
**一句话。** Kadane 同时维护以当前位置结尾的最大和最小乘积，负数会让最小变最大。

```python
def max_product(nums):
    best = hi = lo = nums[0]      # 以当前位置结尾的最大/最小积
    for x in nums[1:]:
        cand = (x, hi * x, lo * x)    # 重新开始 / 接最大 / 接最小
        hi, lo = max(cand), min(cand)
        best = max(best, hi)
    return best
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只维护最大值：`[-2,3,-4]` 得 `3`，应为 `24`。
- `best` 初值写 `0`：`[-2]` 得 `0`，应为 `-2`。

**追问。**
- 有不用最小值的写法吗？：非零段内最优解必含首或尾元素，前后缀乘积各扫一遍取最大，遇 `0` 重置为 `1`。
- 要返回子数组本身？：同时记 `hi`、`lo` 的起点。

**同模式。** LC 53 最大子数组和、LC 238 除自身以外数组的乘积、LC 713 乘积小于 K 的子数组、LC 1567 乘积为正数的最长子数组
