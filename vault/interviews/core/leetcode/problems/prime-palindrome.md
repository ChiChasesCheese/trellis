## Q
**LC 866 回文质数**｜Medium

求大于等于 `n` 的最小回文质数（`1 ≤ n ≤ 10^8`）。

## A
**一句话。** 偶数位回文都被 `11` 整除，只有 `11` 是质数；只枚举奇数位回文（前半加镜像），从小到大找第一个质数。

```python
def prime_palindrome(n):
    def prime(x):
        if x < 2:
            return False
        i = 2
        while i * i <= x:
            if x % i == 0:
                return False
            i += 1
        return True
    if 8 <= n <= 11:
        return 11             # 偶数位回文被 11 整除，11 是唯一例外
    for half in range(1, 10 ** 5):
        s = str(half)
        p = int(s + s[-2::-1])    # 奇数位回文：前半 + 镜像
        if p >= n and prime(p):
            return p
```

**复杂度。** 时间 `O(√n · 候选个数)`，空间 `O(1)`。

**易错点。**
- 逐个数判断回文：到 `10^8` 要扫上亿个数，会超时；按回文生成才快。
- 漏掉 `11`：它是偶数位，但是质数，`8 ≤ n ≤ 11` 要单独返回。
- 镜像拼接重复中心位：`s + s[-2::-1]` 跳过最后一位，否则变成偶数位回文。

**追问。**
- 为什么偶数位回文被 `11` 整除？：`abba = 1001a + 110b = 11(91a + 10b)`，一般形式同理。
- 为什么 `half` 上限是 `10^5`？：答案最大是 `100030001`，前半只有 5 位。

**同模式。** LC 204 计数质数、LC 2523 范围内最接近的两个质数、LC 1175 质数排列
