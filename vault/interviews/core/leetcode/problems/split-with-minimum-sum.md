## Q
**LC 2578 最小和分割**｜Easy

正整数 `num`。把它的数位拆成两个非负整数 `num1`、`num2`（数位全部用上，允许前导零），求 `num1 + num2` 的最小值。

## A
**一句话。** 数位升序排序后交替分给两个数：越小的数位放在越高位，两个数位数尽量均衡。

```python
def split_num(num):
    d = sorted(str(num))
    return int(''.join(d[::2])) + int(''.join(d[1::2]))
```

**复杂度。** 时间 `O(k log k)`（`k` 为位数），空间 `O(k)`。

**易错点。**
- 只给一个数分配所有数位：另一个数为 `0`，和更大，要均衡位数。
- 降序排序：大数位会落在高位。

**追问。**
- 只有一位怎么办？：题目保证至少 `10`，两个数都有数位。

**同模式。** LC 2160 拆分数位后四位数字的最小和、LC 179 最大数
