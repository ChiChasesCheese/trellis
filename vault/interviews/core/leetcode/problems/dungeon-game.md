## Q
**LC 174 地下城游戏**｜Hard

地下城是 `m x n` 的房间网格，骑士从**左上角**出发，要走到**右下角**救公主，每次只能向右或向下移动一步。骑士的健康点数是正整数，任何时刻降到 `0` 或以下他就立即死亡。进入房间时，`dungeon[i][j]` 为负表示失去那么多点（恶魔），为 `0` 表示空房间，为正表示获得那么多点（魔法球）；起点和终点房间同样会影响健康点数。返回骑士能到达终点所需的**最低初始健康点数**。`m == dungeon.length`，`n == dungeon[i].length`，`1 <= m, n <= 200`，`-1000 <= dungeon[i][j] <= 1000`。例：`dungeon = [[-2,-3,3],[-5,-10,1],[10,30,-5]]` → `7`（路径 右 -> 右 -> 下 -> 下）；`dungeon = [[0]]` → `1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 二维 DP（网格路径），**从终点倒推**：`dp[i][j]` 是进入 `(i, j)` 之前至少要有的血量。

**一句话。** 从右下角往回走：进入 `(i, j)` 前需要的血量 = `max(1, 下一步所需血量的较小者 - dungeon[i][j])`。

**识别。** 「只能向右 / 向下」「最少初始值，且过程中必须一直为正」= 网格 DP，但"过程中不能 `<= 0`"让正向 DP 失效；`m, n <= 200`，`O(mn)`。

**推导。** 正向 DP 想记录"到 `(i, j)` 时的最大血量"和"路上出现过的最低点"两个量，二者互相牵制：血量多的路径可能最低点更低，选哪条取决于后面的格子，无法局部最优（反例见易错点）。倒推就没有这个问题：定义 `dp[i][j]` 为"站在 `(i, j)` 之前至少需要多少血量才能走到终点"，只依赖右边和下边两个已算好的值。离开 `(i, j)` 时需要的血量是 `min(dp[i+1][j], dp[i][j+1])`，进入这格后的变化是 `dungeon[i][j]`，所以进入前至少要 `需要 - dungeon[i][j]`，同时至少要是 `1`。终点之后相当于需要 `1` 点血，在哨兵位置放 `1`。

```python
from math import inf


def calculate_minimum_hp(dungeon: list[list[int]]) -> int:
    m, n = len(dungeon), len(dungeon[0])
    # dp[i][j]：进入 (i, j) 之前至少要有多少血量才能走到终点；多开一圈当哨兵
    dp = [[inf] * (n + 1) for _ in range(m + 1)]
    dp[m][n - 1] = dp[m - 1][n] = 1  # 越过终点时至少剩 1 点；只有终点的右边和下边是 1，其余哨兵是 inf（走出网格的路不能选）
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            need = min(dp[i + 1][j], dp[i][j + 1]) - dungeon[i][j]  # 离开这格时要有的血量，倒推回进入前
            dp[i][j] = max(1, need)  # 血量至少为 1：房间是魔法球时 need 可能 <= 0
    return dp[0][0]
```

运行：示例 1 → `7`；示例 2 `[[0]]` → `1`；`[[5]]` → `1`；`[[-5]]` → `6`；`[[-6,-1,6],[1,1,2]]` → `7`。

**复杂度。** 时间 `O(m * n)`，空间 `O(m * n)`。

**拓展优化。**
- 空间可以压到 `O(n)`：见 Python 工具箱「DP 降维」。
- 另一种思路：二分初始血量，用正向模拟判定"能否走到终点"，`O(mn log 值域)`，倒推 DP 更简单。

**易错点。**
- 按"总和最大的路径"走：`[[-6,-1,6],[1,1,2]]` 总和最大的路径是 右 -> 右 -> 下，途中会掉到 `-7`，需要 `8`；另一条 右 -> 下 -> 右 总和更小，最低点只有 `-6`，需要 `7`，正确答案是 `7`。
- 倒推时漏掉 `max(1, ...)`：遇到魔法球 `need` 可能是 `0` 或负数，初始血量不能 `<= 0`；`[[5]]` 本该返回 `1`，会返回 `-4`。
- 哨兵整圈都放 `1`：最后一行 / 最后一列会借道不存在的格子，示例 1 返回 `6`，正确是 `7`；只有终点的右边和下边是 `1`，其余哨兵必须是 `inf`。

**同模式。** LC 64 最小路径和、LC 62 不同路径、LC 120 三角形最小路径和、LC 741 摘樱桃。
