## Q
**LC 174 地下城游戏**｜Hard

骑士从网格左上走到右下（只能向右或向下），每格 `dungeon[i][j]` 加减血量，血量任何时刻必须 `>= 1`。求最低初始血量。

## A
**一句话。** 从右下角倒推 DP：进入 `(i,j)` 前至少需要 `max(1, 后继所需的较小者 - dungeon[i][j])`。

```python
def calculate_minimum_hp(dungeon):
    m, n = len(dungeon), len(dungeon[0])
    # dp[i][j]：进入 (i,j) 前至少要有的血量；多一圈哨兵
    dp = [[inf] * (n + 1) for _ in range(m + 1)]
    dp[m][n - 1] = dp[m - 1][n] = 1   # 仅终点的右、下是 1
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            need = (min(dp[i+1][j], dp[i][j+1])
                    - dungeon[i][j])
            dp[i][j] = max(1, need)   # 魔法球时 need 可能 <= 0
    return dp[0][0]
```

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。

**易错点。**
- 走总和最大的路径：`[[-6,-1,6],[1,1,2]]` 总和最大的路径要 `8`，另一条只要 `7`。
- 漏掉 `max(1, ...)`：`[[5]]` 应得 `1`，会得 `-4`。
- 哨兵整圈放 `1`：边上的格子借道不存在的格子，示例 1 得 `6`，应为 `7`。

**追问。**
- 为什么不能正向 DP？：正向要同时记「当前血量」和「路径最低点」两个量，互相牵制；倒推只需一个量。
- 要输出路径？：每格比较两个后继，记下较小者的方向。

**同模式。** LC 64 最小路径和、LC 62 不同路径、LC 120 三角形最小路径和、LC 741 摘樱桃
