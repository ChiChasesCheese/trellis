## Q
**LC 280 摆动排序**｜Medium

原地重排 `nums`，使 `nums[0] <= nums[1] >= nums[2] <= nums[3] ...`，任一合法排列都行。

## A
**一句话。** 先排序，再交换 `(1,2)`、`(3,4)`、`(5,6)` 这几对相邻元素。

```python
def wiggle_sort(nums):
    nums.sort()
    for i in range(1, len(nums) - 1, 2):
        nums[i], nums[i+1] = nums[i+1], nums[i]  # 奇数位成峰
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`。

**易错点。**
- 交换 `(0,1)`、`(2,3)`：`[1,2,3,4]` 得 `[2,1,4,3]`，开头 `2 <= 1` 不成立。
- 循环写成 `range(1, len(nums), 2)`：`n` 为偶数时 `i + 1` 越界。

**追问。**
- 能 `O(n)` 吗？：一趟扫描，奇数位小于前一个就交换，偶数位大于前一个就交换。
- 严格摆动（LC 324）呢？：相等元素会破坏严格关系，要把排序后的前后两半各自倒序再交错放。

**同模式。** LC 324 摆动排序 II、LC 376 摆动序列、LC 75 颜色分类、LC 922 按奇偶排序数组 II
