## Q
**LC 1922 统计好数字的数目**｜Medium

长度为 `n` 的数字串，偶数下标处必须是偶数，奇数下标处必须是质数（`2, 3, 5, 7`）。求好数字串个数，对 `10^9 + 7` 取模，`n` 可到 `10^15`。

## A
**一句话。** 偶数下标有 `5` 种选择（`0,2,4,6,8`），奇数下标有 `4` 种；两类位置数是 `⌈n/2⌉` 和 `⌊n/2⌋`，用快速幂求 `5^⌈n/2⌉ · 4^⌊n/2⌋`。

```python
def count_good_numbers(n):
    M = 10 ** 9 + 7
    # 偶数下标 (n+1)//2 个，奇数下标 n//2 个
    return pow(5, (n + 1) // 2, M) * pow(4, n // 2, M) % M
```

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- 把偶数下标个数写成 `n // 2`：下标从 `0` 开始，偶数下标比奇数下标多或相等，是 `(n + 1) // 2`。
- 循环累乘：`n` 到 `10^15`，必须用快速幂。

**追问。**
- 不用内置 `pow`？：手写二分幂，指数每次折半，`O(log n)`。

**同模式。** LC 50 Pow(x, n)、LC 372 超级次方、LC 29 两数相除、LC 509 斐波那契数
