## Q
**LC 714 买卖股票的最佳时机含手续费**｜Medium

可多次交易、同时最多持一股，每笔交易（买入并卖出）付一次手续费 `fee`，求最大利润。

## A
**一句话。** 状态机 DP：每天结束只有「不持股」「持股」两种状态，卖出时扣手续费。

```python
def max_profit(prices, fee):
    n = len(prices)
    # dp[i][0] 不持股，dp[i][1] 持股
    dp = [[0, 0] for _ in range(n)]
    dp[0][1] = -prices[0]
    for i in range(1, n):
        dp[i][0] = max(dp[i-1][0],
                       dp[i-1][1] + prices[i] - fee)
        dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
    return dp[-1][0]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 照搬 LC 122 逐天贪心：每段上涨各付一次费，`[1,3,2,8,4,9]`、`fee=2` 得 `7`，应为 `8`。
- 买入和卖出都扣手续费：`[1,3,2,8,4,9]`、`fee=2` 得 `4`，只扣一次。
- 第 0 天持股初值写 `0`：等于白送一股，`[5,4,3]`、`fee=1` 得 `3`，应为 `0`。

**追问。**
- 空间能压吗？：每天只依赖前一天，两个变量即可，`O(1)`。
- 加冷冻期（LC 309）或限 `k` 笔（LC 188）？：前者买入从 `dp[i-2][0]` 转移；后者状态加一维交易笔数。

**同模式。** LC 122 买卖股票的最佳时机 II、LC 309 买卖股票的最佳时机含冷冻期、LC 123 买卖股票的最佳时机 III、LC 188 买卖股票的最佳时机 IV
