## Q
**LC 66 加一**｜Easy

数组 `digits` 从高位到低位表示一个无前导零的大整数，返回加一后的数字数组。

## A
**一句话。** 从最低位找第一个非 `9` 加一并结束，途中的 `9` 变 `0`，全是 `9` 就在最前补 `1`。

```python
def plus_one(digits):
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0            # 9 + 1：本位写 0，进位
    return [1] + digits          # 全是 9
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 漏掉全 `9`：`[9,9,9]` 循环结束全是 `0`，必须在前面补 `1`。
- 加一后不 `return` 继续循环：前面的数字也被加一。

**追问。**
- 链表表示的大整数怎么办（LC 369）？：先反转、加一再反转，或找最后一个非 `9` 的节点。
- 不能改入参怎么办？：先拷贝一份，全 `9` 时结果本来就比输入长一位。

**同模式。** LC 989 数组形式的整数加法、LC 67 二进制求和、LC 2 两数相加、LC 415 字符串相加
