## Q
**LC 684 冗余连接（Redundant Connection）**｜Medium

树可以看成是连通且无环的无向图。给定一个图，该图从一棵 `n` 个节点（节点值 `1..n`）的树中添加一条边后获得。添加的边的两个不同顶点编号在 `1` 到 `n` 中间，且这条附加的边不属于树中已存在的边。图的信息记录于长度为 `n` 的二维数组 `edges`，`edges[i] = [ai, bi]` 表示图中在 `ai` 和 `bi` 之间存在一条边。请找出一条可以删去的边，删除后可使得剩余部分是一个有着 `n` 个节点的树。如果有多个答案，则返回数组 `edges` 中最后出现的那个。`n == edges.length`，`3 <= n <= 1000`，`1 <= ai < bi <= edges.length`，`ai != bi`，`edges` 中无重复元素，给定的图是连通的。例：`edges = [[1,2],[1,3],[2,3]]` → `[2,3]`；`edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]` → `[1,4]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 并查集（union-find / disjoint set union）检测无向图中的环。

**一句话。** 按输入顺序逐条加边，第一条两端已经连通的边就是闭合环的那条边，也就是答案。

**识别。** 「树上多一条边」「找成环的那条边」「动态合并连通块」：并查集。`n <= 1000`，DFS 判环也能过，但并查集更短，且恰好给出「最后出现」的边。

**推导。** 对每条边尝试删除再检查是否为树：`O(n²)`。并查集：每加入一条边先看两端是否已经在同一个集合里，是就说明这条边会闭合出环。树加一条边只有唯一的环，环上的边按输入顺序，**最后一条**被加入时才第一次发现两端连通，这正是题目要求的「最后出现的那个」。

```python
def find_redundant_connection(edges: list[list[int]]) -> list[int]:
    parent = list(range(len(edges) + 1))          # 并查集，节点编号 1..n
    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]         # 路径折半，让后续查找更快
            x = parent[x]
        return x

    for a, b in edges:
        ra, rb = find(a), find(b)
        if ra == rb:                              # a、b 早已连通：这条边闭合成环，删掉它剩下就是树
            return [a, b]
        parent[ra] = rb                           # 否则合并两个连通块
    return []
```

运行：`[[1,2],[1,3],[2,3]]` → `[2, 3]`，`[[1,2],[2,3],[3,4],[1,4],[1,5]]` → `[1, 4]`。

**复杂度。** 时间 `O(n · α(n))`（`α` 是反阿克曼函数，近似常数），空间 `O(n)`。

**易错点。**
- 并查集数组按 `0..n-1` 建（`list(range(n))`）：节点编号是 `1..n`，`edges = [[1,2],[1,3],[2,3]]` 会访问下标 `3`，抛 `IndexError`；数组长度要 `n + 1`。
- 在环里随便返回一条边（比如 DFS 发现的第一条回边）：`[[1,2],[2,3],[3,4],[1,4],[1,5]]` 环里有 `[1,2]`、`[2,3]`、`[3,4]`、`[1,4]`，返回 `[1,2]` 是错的，题目要求输入中最后出现的 `[1,4]`。
- 合并时直接 `parent[a] = b` 而不是根：连通块被拆散，后面的连通性判断出错。

**同模式。** LC 261 以图判树、LC 323 无向图中连通分量的数目、LC 685 冗余连接 II、LC 547 省份数量。
