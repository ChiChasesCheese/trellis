## Q
**LC 53 最大子数组和**｜Medium

给整数数组 `nums`，求和最大的连续子数组（至少一个元素），返回这个和。

## A
**一句话。** Kadane（动态规划）：`cur` 是以当前元素结尾的最大和，接在前面或自己重新开始，取较大者。

```python
def max_sub_array(nums):
    best = cur = nums[0]         # 以 nums[0] 起步，不是 0
    for x in nums[1:]:
        cur = max(x, cur + x)    # 接前面，或从 x 重新开始
        best = max(best, cur)
    return best
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 用 `0` 初始化：全负数时返回 `0`，`[-3,-1,-2]` 应为 `-1`。
- 直接返回 `cur`：它只是以最后一个元素结尾的最大和，`[3,-5]` 得 `-2`，应为 `3`。

**追问。**
- 要返回子数组位置？：`cur + x < x` 时把起点 `start` 移到当前下标，刷新 `best` 时一并记下起止。
- 分治怎么做？：每段维护（总和、最大前缀、最大后缀、最大子段），合并取左、右、左后缀加右前缀的最大值。
- 环形数组（LC 918）？：答案取 `max(Kadane, 总和 - 最小子数组和)`，全为负时只取 Kadane。

**同模式。** LC 121 买卖股票的最佳时机、LC 152 乘积最大子数组、LC 918 环形子数组的最大和、LC 560 和为 K 的子数组
