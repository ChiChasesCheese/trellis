## Q
**LC 448 找到所有数组中消失的数字**｜Easy

长为 `n` 的数组，每个数都在 `[1, n]`。返回 `[1, n]` 中没有出现在数组里的所有数，要求 `O(1)` 额外空间。

## A
**一句话。** 把数组本身当哈希表：数 `x` 出现过，就把下标 `x-1` 处的数变成负数，最后仍为正的下标就是消失的数。

```python
def find_disappeared_numbers(nums):
    n = len(nums)
    for x in nums:
        i = abs(x) - 1              # 当前值可能已被标负
        if nums[i] > 0:
            nums[i] = -nums[i]      # 标记：值 i+1 出现过
    return [i + 1 for i in range(n) if nums[i] > 0]
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`（不计返回值）。

**易错点。**
- 忘了取绝对值：被标负的数当下标会出现负数或越界，必须 `abs(x)`。
- 重复标记翻转符号：同一个值出现两次，不判 `> 0` 就把标记又翻回正数，要先判断。
- 把答案当成下标：仍为正的下标是 `i`，消失的数是 `i + 1`。

**追问。**
- 不允许改输入呢？：另开布尔数组，空间 `O(n)`；或用 `set(range(1, n+1)) - set(nums)`。
- 找出现两次的数？：标记时遇到下标处已为负，说明这个数重复了，就是 LC 442。

**同模式。** LC 442 数组中重复的数据、LC 41 缺失的第一个正数、LC 287 寻找重复数、LC 268 丢失的数字
