## Q
**LC 274 H 指数**｜Medium

给你一个整数数组 `citations`，其中 `citations[i]` 表示研究者的第 `i` 篇论文被引用的次数，计算并返回该研究者的 h 指数。h 指数的定义：至少发表了 `h` 篇论文，并且至少有 `h` 篇论文被引用次数大于等于 `h`；如果 `h` 有多种可能的值，h 指数是其中最大的那个。`n == citations.length`，`1 <= n <= 5000`，`0 <= citations[i] <= 1000`。例：`citations = [3,0,6,1,5]` → `3`；`citations = [1,3,1]` → `1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 计数排序（counting sort / bucket）；答案是单调条件下的最大 `h`。

**一句话。** 论文数是 `n`，所以 `h` 不会超过 `n`：把引用数 `>= n` 的都归到同一桶，从大到小累加「引用数 `>= h` 的论文数」，第一个满足 `>= h` 的 `h` 就是答案。

**识别。** 「最大的 h 使得至少 h 篇 >= h」：条件对 `h` 单调（`h` 越大越难满足），可以排序，也可以二分，也可以计数。`h <= n` 这个上界是桶排序的钥匙。

**推导。** 暴力：对每个 `h = 0..n` 数一遍有多少篇 `>= h`，`O(n^2)`。把引用数降序排好，第 `i` 篇（从 0 起）引用数 `c` 说明「至少有 `i + 1` 篇 `>= c`」，只要 `c > i` 就仍然成立，数出这样的最长前缀就是 `h`，`O(n log n)`。再看排序也不必要：`h <= n`，引用数超过 `n` 的截断成 `n`，用长度 `n + 1` 的桶计数，`O(n)`。

**简单解法。** 排序后找最长满足 `citations[i] > i` 的前缀：

```python
def h_index_sort(citations: list[int]) -> int:
    cs = sorted(citations, reverse=True)       # 降序：第 i 篇之前（含）共有 i+1 篇引用数 >= cs[i]
    h = 0
    while h < len(cs) and cs[h] > h:           # 第 h 篇（从 0 起）引用数 >= h+1，说明 h+1 篇满足
        h += 1
    return h
```

`O(n log n)`，`n <= 5000` 完全够用。

最优解：

```python
def h_index(citations: list[int]) -> int:
    n = len(citations)
    bucket = [0] * (n + 1)                     # bucket[c]：引用数为 c 的论文数，>= n 的并入 bucket[n]
    for c in citations:
        bucket[min(c, n)] += 1
    papers = 0                                 # 引用数 >= h 的论文总数
    for h in range(n, 0, -1):                  # h 从大到小，第一个满足条件的就是最大值
        papers += bucket[h]
        if papers >= h:
            return h
    return 0                                   # h = 0 恒成立
```

运行：`[3,0,6,1,5]` → `3`，`[1,3,1]` → `1`，`[0]` → `0`，`[100]` → `1`，`[0,0,0]` → `0`。

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 桶下标不截断：引用数可达 `1000`，而 `n` 可能只有 `1`，`bucket[c]` 会越界；用 `min(c, n)`。
- `h` 是「篇数」不是「引用数」：`[100]` 的答案是 `1`，返回 `100` 就错了。
- 排序版的条件是 `cs[h] > h` 而不是 `>=`：`[1,3,1]` 降序为 `[3,1,1]`，写成 `>=` 会得到 `2`（正确 `1`）。

**同模式。** LC 275 H 指数 II（已排序，二分）、LC 169 多数元素、LC 1122 数组的相对排序、LC 347 前 K 个高频元素（桶排序）。
