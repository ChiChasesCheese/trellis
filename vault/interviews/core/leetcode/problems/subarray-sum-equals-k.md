## Q
**LC 560 和为 K 的子数组**｜Medium

统计整数数组 `nums`（含负数）中和为 `k` 的连续子数组个数。

## A
**一句话。** 前缀和加哈希表：以当前位置结尾的合法子数组数，等于此前前缀和 `pre - k` 出现的次数。

```python
def subarray_sum(nums, k):
    seen = Counter({0: 1})    # 前缀和 -> 次数，空前缀和为 0
    pre = ans = 0
    for x in nums:
        pre += x
        ans += seen[pre - k]  # 先查
        seen[pre] += 1        # 后存
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 漏掉 `{0: 1}`：从下标 `0` 起的子数组数不到，`[3]`、`k=3` 得 `0`，应为 `1`。
- 先存后查：`k=0` 时把空子数组算进去，`[1]`、`k=0` 得 `1`，应为 `0`。
- 用滑动窗口：有负数时窗口不单调，`[1,-1,1]`、`k=1` 只数到 `2`，应为 `3`。

**追问。**
- 和能被 `k` 整除（LC 974）？：用 `pre % k` 当键。
- 二维矩阵里和为 `k` 的子矩阵（LC 1074）？：固定上下边，把每列压成一维再套同样做法。

**同模式。** LC 523 连续的子数组和、LC 525 连续数组、LC 974 和可被 K 整除的子数组、LC 1 两数之和
