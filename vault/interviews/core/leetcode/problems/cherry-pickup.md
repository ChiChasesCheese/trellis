## Q
**LC 741 摘樱桃**｜Hard

网格 `grid` 中 `1` 是樱桃、`0` 是空格、`-1` 是荆棘。从 `(0,0)` 向下 / 右走到 `(n-1,n-1)`，再向上 / 左走回来，摘过的樱桃消失，求最多摘多少，无通路返回 `0`。

## A
**一句话。** 返程反过来看就是第二条向下 / 右的路，两人同步走，状态 `(k, r1, r2)`，同格樱桃只算一次。

```python
def cherry_pickup(grid):
    n = len(grid)
    @cache
    def dfs(k, r1, r2):          # 走了 k 步，从这里到终点的最大值
        c1, c2 = k - r1, k - r2
        if max(r1, r2, c1, c2) >= n \
                or grid[r1][c1] < 0 or grid[r2][c2] < 0:
            return -inf
        if k == 2 * (n - 1):
            return grid[r1][c1]
        gain = grid[r1][c1]
        if r1 != r2:             # 同格只摘一次
            gain += grid[r2][c2]
        return gain + max(dfs(k + 1, r1, r2),
                          dfs(k + 1, r1 + 1, r2),
                          dfs(k + 1, r1, r2 + 1),
                          dfs(k + 1, r1 + 1, r2 + 1))
    return max(0, dfs(0, 0, 0))
```

**复杂度。** 时间 `O(n^3)`，空间 `O(n^3)`。

**易错点。**
- 先摘最优路径、再摘剩下的：`[[1,1,0],[0,1,1],[1,1,0]]` 得 `5`，应为 `6`，两条路要一起优化。
- `r1 == r2` 时樱桃加两次：`[[1,1],[1,1]]` 得 `5`，应为 `4`。
- 无通路时 `-inf` 不截断成 `0`：不通会被当成负数答案。

**追问。**
- 为什么列号可以省掉？：两人同步走，走了 `k` 步时 `c = k - r`。
- 能改成自底向上吗？：按 `k` 递增填表 `dp[k][r1][r2]`，滚动 `k` 可省空间。
