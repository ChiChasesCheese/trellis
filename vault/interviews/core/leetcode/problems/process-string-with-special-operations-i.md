## Q
**LC 3612 用特殊操作处理字符串 I**｜Medium

从左到右处理 `s`：字母追加到结果末尾；`*` 删末尾字符（若有）；`#` 把结果复制一份接在后面；`%` 反转结果。`|s| ≤ 20`。

## A
**一句话。** 按规则模拟，结果用列表：`append`、`pop`、`+=` 自身副本、`reverse`。

```python
def process_str(s):
    res = []
    for ch in s:
        if ch == '*':
            if res:            # 空时什么都不做
                res.pop()
        elif ch == '#':
            res += res[:]      # 复制一份接在后面
        elif ch == '%':
            res.reverse()
        else:
            res.append(ch)
    return ''.join(res)
```

**复杂度。** 时间 `O(2^n)`（`#` 可让长度翻倍），空间 `O(2^n)`；`n ≤ 20`。

**易错点。**
- `*` 不判空：空列表 `pop` 报错。
- 用字符串反复拼接：每次 `O(len)`，列表更直接。

**追问。**
- 只问最终结果第 `k` 个字符（LC 3614）？：先正着算每步之后的长度，再倒着把 `k` 映射回去：`#` 时 `k` 落在后半就减去一半长度，`%` 时 `k = len - 1 - k`。
- 长度会不会爆？：`n ≤ 20`，最多约 `2^20` 个字符，可以接受；长度到 `10^15` 时只能倒推。
