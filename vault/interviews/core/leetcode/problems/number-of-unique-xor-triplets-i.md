## Q
**LC 3513 不同 XOR 三元组的数目 I**｜Medium

`1` 到 `n` 的排列 `nums`。求不同的 `nums[i] XOR nums[j] XOR nums[k]`（`i <= j <= k`）的个数。

## A
**一句话。** `n` 较小时直接是 `n`（`n <= 2`）；`n >= 3` 时三个数可凑出 `0` 到 `2^m - 1` 的所有值（`m` 是 `n` 的二进制位数），答案是 `2^m`。

```python
def unique_xor_triplets(nums):
    n = len(nums)
    if n <= 2:
        return n                   # n=1 得 1，n=2 得 {1, 2}
    return 1 << n.bit_length()     # 能凑出 [0, 2^m)
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- `n <= 2` 不特判：公式在 `n = 1, 2` 时给出 `2, 4`，实际只有 `1, 2` 个值。
- 暴力枚举三元组：`O(n³)`，`n` 到 `10^5` 会超时。

**追问。**
- 为什么答案是 `2^m`？：任何三个数的异或都小于 `2^m`，至多这么多种；`n >= 3` 时恰好能凑出其中每一个值。

**同模式。** LC 136 只出现一次的数字、LC 3514 不同 XOR 三元组的数目 II、LC 1442 形成两个异或相等数组的三元组数目
