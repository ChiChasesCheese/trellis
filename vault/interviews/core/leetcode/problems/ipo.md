## Q
**LC 502 IPO（IPO）**｜Hard

LeetCode 即将开始 IPO，希望在 IPO 之前开展一些项目增加资本，但最多只能完成 `k` 个不同的项目。给你 `n` 个项目，项目 `i` 有纯利润 `profits[i]` 和启动所需的最小资本 `capital[i]`。最初资本为 `w`，完成一个项目获得的纯利润会加到总资本中。从给定项目中选择最多 `k` 个不同项目，最大化最终资本，输出最终可获得的最多资本。答案保证在 32 位有符号整数范围内。`1 <= k <= 10^5`，`0 <= w <= 10^9`，`n == profits.length == capital.length`，`1 <= n <= 10^5`，`0 <= profits[i] <= 10^4`，`0 <= capital[i] <= 10^9`。例：`k = 2`，`w = 0`，`profits = [1,2,3]`，`capital = [0,1,1]` → `4`；`k = 3`，`w = 0`，`profits = [1,2,3]`，`capital = [0,1,2]` → `6`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 贪心 + 双堆思想（排序 + 大根堆）：在「做得起」的项目里每次选利润最大的。

**一句话。** 项目按启动资本排序；每一轮把所有资本已够的项目的利润放进大根堆，取堆顶（最大利润）去做，资本变大后再放入新做得起的项目，重复 `k` 轮。

**识别。** 「最多做 `k` 个，每个有门槛，做完收益累加并放宽门槛」：每一步选当前可行集合里收益最大的，这是贪心；可行集合只增不减（资本只增不减），用堆动态维护。`n, k = 10^5`，要 `O(n log n)`。

**推导。** 每轮扫全部项目找「做得起且利润最大」：`O(kn)`，`10^10` 次，超时。贪心为什么对：资本只会增加，任何一轮选利润最大的项目，不会让后面可选集合变小，选更小利润的项目得到的资本不会更多（交换论证）。实现：先按资本升序排序，用指针把「现在做得起」的项目依次推进堆，堆里只保存利润。

```python
import heapq


def find_maximized_capital(k: int, w: int, profits: list[int], capital: list[int]) -> int:
    projects = sorted(zip(capital, profits))      # 按启动资本升序
    afford: list[int] = []                        # 当前做得起的项目的利润（取负，大根堆）
    i = 0
    for _ in range(k):
        while i < len(projects) and projects[i][0] <= w:     # 资本涨了，把新做得起的项目都放进堆
            heapq.heappush(afford, -projects[i][1])
            i += 1
        if not afford:                            # 一个也做不起，后面资本也不会再涨
            break
        w -= heapq.heappop(afford)                # 贪心：做利润最大的
    return w
```

运行：`(2, 0, [1,2,3], [0,1,1])` → `4`，`(3, 0, [1,2,3], [0,1,2])` → `6`，`(1, 0, [1,2,3], [1,1,2])` → `0`（一个都做不起），`(5, 0, [1,2,3], [0,1,2])` → `6`（`k` 大于项目数）。

**复杂度。** 时间 `O(n log n + k log n)`，空间 `O(n)`。

**易错点。**
- 每次选资本要求最低的项目而不是利润最大的：`k = 2`，`w = 0`，`profits = [1,2,3]`，`capital = [0,1,1]` 得到 `3`，正确 `4`。
- 堆为空时不 `break`：`(1, 0, [1], [1])` 对空堆 `heappop`，抛 `IndexError`；资本不够时直接结束。
- 只在循环开始前把做得起的项目放进堆一次：示例一得到 `1`（第二轮堆空就结束），正确 `4`；每做完一个项目资本变大，要重新推进指针把新解锁的项目放进堆。

**同模式。** LC 215 数组中的第 K 个最大元素、LC 295 数据流的中位数、LC 373 查找和最小的 K 对数字、LC 871 最低加油次数。
