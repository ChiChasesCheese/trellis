## Q
**LC 309 买卖股票的最佳时机含冷冻期**｜Medium

可多次买卖一支股票，但卖出后第二天不能买入，求最大利润。

## A
**一句话。** 状态机 DP：每天处于持有、刚卖出（冷冻）、空仓可买三态之一，只依赖前一天。

```python
def max_profit(prices):
    n = len(prices)
    # 0 持有；1 今天刚卖出；2 空仓可买
    dp = [[0] * 3 for _ in range(n)]
    dp[0][0] = -prices[0]
    for i in range(1, n):
        dp[i][0] = max(dp[i-1][0], dp[i-1][2] - prices[i])
        dp[i][1] = dp[i-1][0] + prices[i]
        dp[i][2] = max(dp[i-1][2], dp[i-1][1])
    return max(dp[n-1][1], dp[n-1][2])
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 买入也从「刚卖出」转移：等于没有冷冻期，`[1,2,3,0,2]` 得 `4`，应为 `3`。
- 答案只取空仓态：最后一天刚卖出的利润被漏掉，`[1,2]` 得 `0`。
- `dp[0][0]` 设成 `0`：等于白拿一股，`[3,2]` 得 `2`，应为 `0`。

**追问。**
- 空间能压吗？：只依赖前一天，三个变量滚动，`O(1)`。
- 最多 `k` 笔（LC 188）？：状态再加一维交易次数。
