## Q
**LC 2571 将整数减少到零需要的最少操作数**｜Medium

给你一个正整数 `n`，你可以执行下述操作任意次：`n` 加上或减去 2 的某个幂。返回使 `n` 等于 `0` 需要执行的最少操作数。如果 `x == 2^i` 且其中 `i >= 0`，则数字 `x` 是 2 的幂。`1 <= n <= 10^5`。例：`n = 39` → `3`（`39 + 1 = 40`，`40 - 8 = 32`，`32 - 32 = 0`）；`n = 54` → `3`（`54 + 2 = 56`，`56 + 8 = 64`，`64 - 64 = 0`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 位运算上的贪心（greedy）：二进制里一段连续的 1 用「进位」比逐位减更省。

**一句话。** 看最低位的 1：如果它上面紧挨着还有 1（一段连续的 1），就加上它（进位，一次消掉整段）；否则减去它。每次操作消掉最低的一个 1，操作数就是这个过程的步数。

**识别。** 「加减 2 的幂」把数表示成若干 `±2^i` 之和，要最少项：这是带符号二进制表示（NAF）。位运算题的信号：`n & -n` 取最低位的 1，`n <= 10^5` 只有约 17 位。

**推导。** 只做减法需要的步数是 `n` 的二进制 1 的个数：`39 = 100111` 要 4 步，但答案是 3。`111...1`（一段 `k` 个 1）如果逐个减要 `k` 步，而「先加 1 变成 `1000...0`（进位），再减掉那个 2 的幂」只要 2 步。所以看最低位 1 `lb`：若下一位也是 1（在一段连续的 1 里），加上 `lb` 让整段进位；若下一位是 0（孤立的 1），减去 `lb` 最合适。每次操作都消掉最低位的一个 1，直到 `n = 0`。

**简单解法。** 递归 + 记忆化，不需要贪心的结论：偶数除以 2（最低位是 0，操作与最低位无关）；奇数必须动一次 ±1，两种都试：

```python
from functools import cache


@cache
def min_operations_dp(n: int) -> int:
    if n <= 1:
        return n                                # 0 不需要操作；1 本身是 2 的幂，一步
    if n % 2 == 0:
        return min_operations_dp(n // 2)        # 偶数：整体除以 2，操作数不变
    return 1 + min(min_operations_dp(n - 1), min_operations_dp(n + 1))   # 奇数：加一或减一，各试一次
```

每层只有两个状态（`n - 1`、`n + 1`），总状态 `O(log n)`。

最优解（贪心，迭代）：

```python
def min_operations(n: int) -> int:
    ops = 0
    while n:
        low = n & -n                       # 最低位的 1（对应的 2 的幂）
        if n & (low << 1):                 # 它上面紧挨着还有 1：属于一段连续的 1，加上它让整段进位
            n += low
        else:                              # 孤立的 1：直接减掉
            n -= low
        ops += 1
    return ops
```

运行：`39` → `3`，`54` → `3`，`1` → `1`，`3` → `2`，`7` → `2`，`100000` → `6`。

**复杂度。** 时间 `O(log n)`（每次操作至少消掉一个最低位的 1），空间 `O(1)`。

**拓展优化。**
- 闭式：最少操作数就是 `n` 的带符号二进制表示（NAF，不含相邻非零位）中非零位的个数，等于 `(3 * n ^ n).bit_count()`，一行 `O(1)`；知道原理才值得写，面试里先给上面的贪心。

**易错点。**
- 只做减法：`n = 39` 得到 `4`（二进制 1 的个数），正确 `3`。
- 一律「加」（只有 2 的幂才减）：`n = 5 = 101` 的两个 1 都是孤立的，应当减 `1` 再减 `4` 共 `2` 步，一律加会走 `5 -> 6 -> 8 -> 0` 共 `3` 步。判断依据是最低位的 1 上面紧挨着的那一位是不是 1。

**追问。**
- 为什么贪心对：一段连续的 `k` 个 `1`（`k >= 2`）逐个减要 `k` 步，进位成 `1 0...0` 再减只要 `2` 步，不会更差；孤立的 `1` 加上去只是把它挪到高一位，`1` 的个数没减少，白花一步。可以用上面的记忆化递归在 `n <= 10^5` 内逐个对拍。
- `n` 是大整数（上千位）：贪心每步 `O(位数)`，总 `O(位数^2)`；用 `(3 * n ^ n).bit_count()` 是 `O(位数)`。
- 要输出具体的操作序列：贪心里每步记录 `+low` 或 `-low` 即可。

**同模式。** LC 397 整数替换、LC 191 位 1 的个数、LC 342 4 的幂、LC 1404 将二进制表示减到 1 的步骤数。
