## Q
**LC 2571 将整数减少到零需要的最少操作数**｜Medium

正整数 `n`，每次操作可以加上或减去一个 2 的幂。求使 `n` 变为 `0` 的最少操作次数。

## A
**一句话。** 看最低位的 `1`：它上面紧挨着还有 `1` 就加上它（整段进位），否则减去它（贪心）。

```python
def min_operations(n):
    ops = 0
    while n:
        low = n & -n             # 最低位的 1
        if n & (low << 1):       # 上面紧挨着还有 1：整段进位
            n += low
        else:                    # 孤立的 1：直接减
            n -= low
        ops += 1
    return ops
```

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- 只做减法：`n = 39` 得 `4`（二进制 `1` 的个数），应为 `3`。
- 一律做加法：`n = 5 = 101` 两个 `1` 都孤立，减 `1` 再减 `4` 共 `2` 步，一律加要 `3` 步。

**追问。**
- 为什么贪心对？：连续 `k >= 2` 个 `1` 逐个减要 `k` 步，进位后只要 `2` 步；孤立的 `1` 加上去只是挪到高位，白花一步。
- 有没有一行解？：答案是 `n` 的 NAF（带符号二进制）非零位数，即 `(3 * n ^ n).bit_count()`。

**同模式。** LC 397 整数替换、LC 191 位 1 的个数、LC 342 4 的幂、LC 1404 将二进制表示减到 1 的步骤数
