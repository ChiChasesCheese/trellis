## Q
**LC 1137 第 N 个泰波那契数**｜Easy

`T0 = 0`、`T1 = 1`、`T2 = 1`，且 `Tn = T(n-1) + T(n-2) + T(n-3)`。返回 `Tn`。

## A
**一句话。** 每项只依赖前三项，用三个变量滚动，不开数组。

```python
def tribonacci(n):
    a, b, c = 0, 1, 1             # T0, T1, T2
    for _ in range(n):
        a, b, c = b, c, a + b + c  # 窗口整体右移一格
    return a
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 返回 `c`：循环 `n` 次后 `a` 才是 `Tn`，`n = 0` 时 `a = 0` 也自然正确。
- 更新写成逐条赋值：`a = b` 之后 `a + b + c` 就用了新值，要用元组同时赋值。

**追问。**
- 能比 `O(n)` 更快吗？：3×3 矩阵快速幂，`O(log n)`。
- 为什么能滚动？：转移只用前三项，旧项不会再被用到。
