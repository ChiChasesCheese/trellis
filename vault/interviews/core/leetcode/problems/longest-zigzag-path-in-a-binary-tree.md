## Q
**LC 1372 二叉树中的最长交错路径**｜Medium

交错路径：任选起点和第一步方向，之后每一步都与上一步方向相反（左、右、左…）。求二叉树中最长交错路径的边数。

## A
**一句话。** 后序给每个结点返回两个数：先向左走的最长交错边数、先向右走的最长交错边数；先左的值来自左孩子「先右」的值加 1。

```python
def longest_zigzag(root):
    best = 0
    def dfs(node):     # 返回 (先向左, 先向右) 的最长边数
        nonlocal best
        if not node:
            return -1, -1      # 空孩子使对应方向算 0
        left = dfs(node.left)[1] + 1    # 走左，下一步该右
        right = dfs(node.right)[0] + 1  # 走右，下一步该左
        best = max(best, left, right)
        return left, right
    dfs(root)
    return best
```

**复杂度。** 时间 `O(n)`，空间 `O(h)`。

**易错点。**
- 连续两次同方向仍累加：方向必须交替，换方向才能接着用孩子的值，同方向要从 0 重算。
- 数结点而不是数边：单个结点的路径长度是 `0`。
- 只从根出发：最长路径可以从任何结点开始，要在每个结点更新 `best`。

**追问。**
- 为什么空结点返回 `-1`？：这样 `-1 + 1 = 0`，没有该方向的孩子时长度正好是 0，免去单独判断。
- 能改成自顶向下传参吗？：可以，递归时带上「当前方向、当前长度」，换方向加 1，同方向重置为 1。
