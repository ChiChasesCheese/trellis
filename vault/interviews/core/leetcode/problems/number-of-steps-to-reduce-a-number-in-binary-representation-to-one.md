## Q
**LC 1404 将二进制表示减到 1 的步骤数**｜Medium

二进制字符串 `s` 表示一个正整数。偶数除以 2，奇数加 1，求变成 `1` 的步数。

## A
**一句话。** 从最低位向最高位扫，带着进位：偶数一步（除 2），奇数两步（加 1 再除 2）并产生进位，最高位最后单独处理。

```python
def num_steps(s):
    steps = carry = 0
    for c in reversed(s[1:]):         # 最高位的 1 留到最后
        if int(c) + carry == 1:       # 当前是奇数
            steps += 2                # 加 1（进位）再除 2
            carry = 1
        else:                         # 当前是偶数
            steps += 1                # 只需除 2
    return steps + carry              # 最高位被进位变成 10：再除一次
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 转成整数再模拟：`s` 可长达 500 位，别的语言会溢出，位运算更通用。
- 进位后位值判断错：`int(c) + carry` 为 `1` 才是奇数，为 `2`（`1 + 进位`）时当前位变 `0`，仍是偶数。
- 最后漏加 `carry`：最高位 `1` 加上进位变成 `10`，还要多除一次。

**追问。**
- 为什么奇数一步加 1 会产生进位？：奇数末位是 1，加 1 后这位变 0 并向高位进 1。
- 进位一直保持为 1 吗？：一旦出现奇数，之后所有位都带着进位，遇到 0 变成 1（奇数）、遇到 1 变成 0（偶数）。
