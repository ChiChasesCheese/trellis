## Q
**LC 792 匹配子序列的单词数**｜Medium

给字符串 `s` 和单词数组 `words`，统计其中是 `s` 的子序列的单词个数。

## A
**一句话。** 多指针同时扫：每个单词按「正在等的下一个字符」放进桶，扫 `s` 的每个字符就把等它的单词各推进一格，推进到末尾就计一个。

```python
def num_matching_subseq(s, words):
    wait = defaultdict(list)         # 字符 -> 等它的 (单词, 已配数)
    for w in words:
        wait[w[0]].append((w, 0))
    ans = 0
    for c in s:
        todo, wait[c] = wait[c], []  # 取出等 c 的，桶清空
        for w, i in todo:
            i += 1
            if i == len(w):
                ans += 1             # 整个单词匹配完
            else:
                wait[w[i]].append((w, i))
    return ans
```

**复杂度。** 时间 `O(|s| + 所有单词长度和)`，空间 `O(单词个数)`。

**易错点。**
- 对每个单词都扫一遍 `s`：`O(|s|·单词数)` 会超时，要让所有单词共同扫一遍。
- 取出桶后不清空：同一批单词会被重复推进，必须先把桶换成空列表。
- 推进后又放回同一个桶：单词的下一个字符也是 `c` 时，要放进已清空的新桶，下一个 `c` 才处理，不能在本轮继续处理。

**追问。**
- 另一种思路？：为 `s` 建「字符到下标列表」的索引，每个单词用二分跳到下一个出现位置，`O(Σ|w|·log|s|)`。
- 有重复单词怎么办？：先用 `Counter` 去重，匹配一次再按个数累加。

**同模式。** LC 392 判断子序列、LC 524 通过删除字母匹配到字典里最长单词、LC 1143 最长公共子序列
