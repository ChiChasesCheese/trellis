## Q
**LC 566 重塑矩阵**｜Easy

把 `m×n` 矩阵 `mat` 重塑成 `r×c`，元素按原来的行优先顺序填入；元素总数不等时返回原矩阵。

## A
**一句话。** 把二维下标拉平成行优先的一维编号 `k`，原矩阵里它在 `(k // n, k % n)`，新矩阵里它在 `(k // c, k % c)`。

```python
def matrix_reshape(mat, r, c):
    m, n = len(mat), len(mat[0])
    if m * n != r * c:
        return mat                     # 总数不同，不能重塑
    res = [[0] * c for _ in range(r)]
    for k in range(m * n):             # k 是行优先的编号
        res[k // c][k % c] = mat[k // n][k % n]
    return res
```

**复杂度。** 时间 `O(mn)`，空间 `O(rc)`（返回值）。

**易错点。**
- 用 `[[0] * c] * r` 建行：所有行是同一个列表，改一处全变，要用推导式。
- 取模、整除用错维度：旧矩阵除以 `n`，新矩阵除以 `c`。
- 总数不等时返回新矩阵：要返回原矩阵。

**追问。**
- 想省掉乘除？：双指针 `(i, j)` 走新矩阵，旧矩阵的指针每次列加一，到 `n` 换行。
- 原地重塑？：只有形状兼容时可能，通常要借助一维展开再填回。

**同模式。** LC 54 螺旋矩阵、LC 498 对角线遍历、LC 311 稀疏矩阵的乘法、LC 48 旋转图像
