## Q
**LC 63 不同路径 II**｜Medium

网格里 `1` 是障碍，机器人从左上角每步只能向下或向右走到右下角，求不碰障碍的路径数。

## A
**一句话。** 二维 DP：空格的路径数 = 上方 + 左方，障碍记 `0`，多开一行一列当哨兵。

```python
def unique_paths_with_obstacles(g):
    m, n = len(g), len(g[0])
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    dp[0][1] = 1                 # 哨兵：让起点得 1
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if g[i-1][j-1] == 0:  # 障碍格保持 0
                dp[i][j] = dp[i-1][j] + dp[i][j-1]
    return dp[m][n]
```

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。

**易错点。**
- 照搬 LC 62 把首行首列全设 `1`：`[[0,1,0]]` 错成 `1`，应为 `0`，障碍后的边界格不可达。
- 起点是障碍：哨兵写法里 `dp[1][1]` 被 `if` 跳过保持 `0`，不必特判。

**追问。**
- 空间能压吗？：能压成一行，`dp[j] += dp[j-1]`，障碍格清零。
- 没有障碍怎么办？：直接 `comb(m+n-2, m-1)`。

**同模式。** LC 62 不同路径、LC 64 最小路径和、LC 120 三角形最小路径和、LC 174 地下城游戏
