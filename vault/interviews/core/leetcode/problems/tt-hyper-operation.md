## Q
**手写超运算**｜Hard

实现 `hyper(n, a, b)`：`n = 0` 是后继 `b + 1`，`n = 1` 加法，`n = 2` 乘法，`n = 3` 幂，`n >= 4` 迭代幂。统一定义：`b = 0` 时 `hyper(1,a,0) = a`、`hyper(2,a,0) = 0`、`hyper(n,a,0) = 1`（`n >= 3`），否则 `hyper(n-1, a, hyper(n, a, b-1))`。只有 `n = 0` 能直接用 `+1`。

## A
**一句话。** 三条规则照抄成递归：每层是把下一层迭代 `b` 次，`b = 0` 取该层基值。

```python
def base(n, a):                 # hyper(n, a, 0)
    return a if n == 1 else 0 if n == 2 else 1

def hyper(n, a, b):
    if n == 0:
        return b + 1
    if b == 0:
        return base(n, a)
    return hyper(n - 1, a, hyper(n, a, b - 1))
```

**复杂度。** 调用次数和递归深度都随结果增长，`hyper(3,2,3) = 8` 要 `49` 次调用，只适合小输入。

**易错点。**
- 基值全写 `1`：`hyper(1,3,4)` 得 `5`（应 `7`），`hyper(2,3,4)` 得 `5`（应 `12`）。
- `n >= 3` 的基值写 `0`：`hyper(3,2,3)` 得 `0`，应为 `8`。
- `a = 0` 的塔：`hyper(4,0,b)` 对 `b = 0..5` 依次是 `1,0,1,0,1,0`，`0 ** 0` 要当 `1`。

**追问。**
- 怎么改成实用写法？：递归只沿 `n` 走，沿 `b` 改循环（深度 `<= n`），`n <= 3` 用内置运算。
- 结果太大怎么办？：先用 `bit_length()` 估大小，超限就拒绝；不能用 `len(str(x))`，超过 4300 位会抛 `ValueError`。
