## Q
**LC 746 使用最小花费爬楼梯**｜Easy

`cost[i]` 是离开第 `i` 级要付的费用，每次爬一级或两级，可从下标 `0` 或 `1` 出发，求到达顶部（下标 `n`）的最低花费。

## A
**一句话。** 线性 DP：`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`，起点 `dp[0] = dp[1] = 0`，滚动两个变量。

```python
def min_cost_climbing_stairs(cost):
    a = b = 0                   # dp[i-2], dp[i-1]
    for i in range(2, len(cost) + 1):
        a, b = b, min(b + cost[i - 1], a + cost[i - 2])
    return b
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 把 `dp[i]` 定义成「已付 `cost[i]`」却返回 `dp[n-1]`：`[10,15,20]` 得 `30`，应为 `15`。
- 终点写成 `n - 1`：顶部是越过最后一级，下标是 `n`。
- 以为必须从下标 `0` 出发：起点可以是 `0` 或 `1`，两者初始花费都是 `0`。

**追问。**
- 每次最多爬 `k` 级？：`dp[i]` 取前 `k` 项最小，朴素 `O(nk)`，单调队列可到 `O(n)`。
- 要输出具体路线？：记录每个 `i` 的前驱，从 `n` 往回走再反转。

**同模式。** LC 70 爬楼梯、LC 198 打家劫舍、LC 509 斐波那契数、LC 322 零钱兑换
