## Q
**LC 4092 二进制位得分**｜Easy

`s1`、`s2` 为 `a`、`b` 二进制中 `1` 的个数；若 `s1 >= s2` 得分 `s1 * s2`，否则得分 `s2 // s1`。返回得分。

## A
**一句话。** 用 `bit_count()` 数出置位，按 `s1 >= s2` 分支返回乘积或整除商。

```python
def binary_digit_score(a, b):
    s1, s2 = a.bit_count(), b.bit_count()
    return s1 * s2 if s1 >= s2 else s2 // s1
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 条件写成 `s1 > s2`：相等时落进除法，`(10, 12)` 得 `1`，应为 `4`。
- 用 `/` 代替 `//`：`(5, 15)` 返回 `2.0`，`s1 = 2, s2 = 3` 还会得 `1.5`。

**追问。**
- Python 3.10 以前怎么数置位？：`bin(a).count("1")`，或 `n &= n - 1` 循环。

**同模式。** LC 191 位 1 的个数、LC 338 比特位计数、LC 461 汉明距离、LC 762 二进制表示中质数个计算置位
