## Q
**长度至少为 2 的子数组，最大化 min + max**｜Easy

正整数数组 `nums`，在长度至少为 `2` 的连续子数组里，求「最小值 + 最大值」的最大值。例：`[5,12,9,6,4]` → `21`（`[12,9]`）。

## A
**一句话。** 答案就是相邻两数之和的最大值：任何长度至少为 `2` 的子数组，其 min + max 不超过其中某对相邻元素之和。

```python
def max_min_plus_max(nums):
    return max(a + b for a, b in pairwise(nums))
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 取最大的两个数相加：`[100,1,99]` 得 `199`，但中间隔着 `1`，最优是 `101`。
- 允许长度为 `1`：`[10,1]` 若含 `[10]` 得 `20`，应为 `11`。
- 推广到长度至少 `3`：`[5,12,9,6,4]` 最优是 `18`，不是 `21`，相邻论证只对下界 `2` 成立。

**追问。**
- 长度至少为 `k`（`k >= 3`）？：结论不再成立，枚举左端点向右滚动维护最小最大，`O(n^2)`。
- 要返回具体子数组？：记下取最大和的下标 `i`，答案是 `nums[i:i + 2]`。

**同模式。** LC 53 最大子数组和、LC 907 子数组的最小值之和、LC 2104 子数组范围和、LC 239 滑动窗口最大值
