## Q
**LC 2357 使数组中所有元素都等于零**｜Easy

每次选不超过最小正数的 `x`，把所有正数都减 `x`，求全变成 `0` 的最少操作次数。

## A
**一句话。** 每次减去最小正数恰好消掉一种值，答案就是不同正数的个数。

```python
def minimum_operations(nums):
    return len(set(nums) - {0})   # 不同的正数个数
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 把 `0` 也算一种：`[0]` 应为 `0`。
- 去模拟每一步：能过但没必要，`O(n·种类)`。

**追问。**
- 为什么不能更少？：一次操作后，原来不同的两个正数仍然不同，种类最多减少一种。
- 每次可以选任意子集减？：问题变了，要看二进制位或其他结构。

**同模式。** LC 217 存在重复元素、LC 2441 与对应负数同时存在的最大正整数
