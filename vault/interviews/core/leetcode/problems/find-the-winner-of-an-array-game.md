## Q
**LC 1535 找出数组游戏的赢家**｜Medium

互不相同的整数数组 `arr`，每轮比较前两个数，较大者留在最前，较小者放到队尾。某个数连续赢 `k` 轮时游戏结束，返回它。

## A
**一句话。** 不用真的移动：维护当前擂主和连胜场数，新的一个数更大就换擂主、连胜记为 1，赢够 `k` 场返回；绕完一遍还没结束，最大值必是答案。

```python
def get_winner(arr, k):
    champ, wins = arr[0], 0
    for x in arr[1:]:
        if x > champ:
            champ, wins = x, 1        # 新擂主，刚赢了这一场
        else:
            wins += 1                 # 擂主又赢一场
        if wins == k:
            return champ
    return champ                      # 一圈打完：最大值永远不败
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 真的用队列模拟 `k` 轮：`k` 可达 `10^9`；数组中最大值赢不了就是它不败，最多 `n - 1` 轮就能确定最大值。
- 新擂主的连胜写成 `0`：刚打败了旧擂主，已经赢了一场。
- 返回时忘了一圈打完的情况：最大值永远不败，答案就是 `champ`。

**追问。**
- 为什么最多 `n - 1` 轮后答案确定？：此时擂主已是最大值，之后永远不败，不管 `k` 多大都是它。
- `k = 1` 时呢？：前两个中较大者立刻赢，循环第一轮就返回。
