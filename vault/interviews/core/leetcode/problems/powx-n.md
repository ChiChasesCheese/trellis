## Q
**LC 50 Pow(x, n)**｜Medium

实现 `pow(x, n)`，计算浮点数 `x` 的整数 `n` 次幂（`n` 可为负）。

## A
**一句话。** 快速幂：指数按二进制拆开，底数每轮平方，当前位为 1 就乘进结果，负指数先取倒数。

```python
def my_pow(x, n):
    if n < 0:                # x^-n = (1/x)^n
        x, n = 1 / x, -n
    res = 1.0
    while n:
        if n & 1:
            res *= x
        x *= x
        n >>= 1
    return res
```

**复杂度。** 时间 `O(log|n|)`，空间 `O(1)`。

**易错点。**
- 负指数不先转非负：Python 里 `-1 >> 1 == -1`，`while n` 死循环。
- 先平方右移再判最低位：`my_pow(2.0, 3)` 得 `4.0`，应为 `8.0`。
- `n = -2^31` 取负溢出：C++/Java 的 32 位 `int` 要先转 `long`。

**追问。**
- 递归写法呢？：`half = my_pow(x, n // 2)` 只算一次再平方，写成两次调用相乘会退化成 `O(n)`。
- 整数取模幂？：同样的循环，每步乘完 `% m`，或直接 `pow(a, b, m)`。
