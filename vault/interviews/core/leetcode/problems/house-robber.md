## Q
**LC 198 打家劫舍**｜Medium

一排房屋，`nums[i]` 是第 `i` 间的现金，不能偷相邻的两间，求最多能偷多少。

## A
**一句话。** 线性 DP：每间房偷或不偷，只依赖前两项，两个变量滚动。

```python
def rob(nums):
    skip = take = 0       # 不偷 / 偷当前房的最优
    for x in nums:
        skip, take = max(skip, take), skip + x
    return max(skip, take)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 贪心取奇数位或偶数位：`[2,1,1,2]` 奇偶和都是 `3`，最优是 `4`。
- 两个状态分两句更新：`take` 用到新的 `skip`，等于允许连续偷，`[1,2,3,1]` 得 `7`，应为 `4`。

**追问。**
- 房屋围成一圈？：首尾相邻，取 `max(rob(nums[1:]), rob(nums[:-1]))`，单间特判。
- 要输出偷了哪几间？：保留完整 `dp` 数组，按值回溯。

**同模式。** LC 213 打家劫舍 II、LC 337 打家劫舍 III、LC 740 删除并获得点数、LC 746 使用最小花费爬楼梯
