## Q
**LC 1200 最小绝对差**｜Easy

给你一个整数数组 `arr`，其中每个元素都不相同。找到所有具有最小绝对差的元素对，并按升序返回；每对 `[a, b]` 满足 `a < b`，且 `b - a` 等于 `arr` 中任意两个元素的最小绝对差。`2 <= arr.length <= 10^5`，`-10^6 <= arr[i] <= 10^6`。例：`arr = [4,2,1,3]` → `[[1,2],[2,3],[3,4]]`；`arr = [1,3,6,10,15]` → `[[1,3]]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 排序后只看相邻元素。

**一句话。** 排序之后，差最小的两个数一定相邻，所以扫一遍相邻差，先求最小值，再收集等于最小值的数对。

**识别。** 「任意两个元素的最小差」：排序把全局最近对变成相邻对。`n = 10^5` 排除 `O(n^2)` 的两两比较。

**推导。** 暴力枚举所有 `(i, j)` 是 `O(n^2)`。若 `a < c < b`，则 `b - a > c - a`，非相邻的数对永远不可能比夹在中间的相邻对更近；排序后只要比较相邻元素，`O(n log n)`。结果天然按升序排好。

```python
def minimum_abs_difference(arr: list[int]) -> list[list[int]]:
    arr = sorted(arr)                                    # 不改动调用者的数组
    best = min(b - a for a, b in pairwise(arr))          # 第一遍：相邻差的最小值
    return [[a, b] for a, b in pairwise(arr) if b - a == best]   # 第二遍：收集所有等于最小值的数对
```

运行：`[4,2,1,3]` → `[[1, 2], [2, 3], [3, 4]]`，`[1,3,6,10,15]` → `[[1, 3]]`，`[3,8,-10,23,19,-4,-14,27]` → `[[-14, -10], [19, 23], [23, 27]]`，`[5, 1]` → `[[1, 5]]`。

**复杂度。** 时间 `O(n log n)`（排序主导），空间 `O(n)`（排序副本，结果最坏也是 `O(n)`）。

**拓展优化。**
- 值域只有 `2 * 10^6 + 1`：计数排序（或布尔数组）代替比较排序，`O(n + 值域)`，`n` 很大而值域不大时更快。
- 一遍扫描：遇到更小的差就清空结果列表，相等就追加，省掉第二遍。

**易错点。**
- 数对只取最小值那一组，不能把所有相邻对都返回：`[1,3,6,10,15]` 返回全部相邻对会得到 4 对（正确只有 `[[1, 3]]`）。
- 最小差可能并列：`[4,2,1,3]` 三对差都是 `1`，必须全部收集，不能在第一个最小处停止。
- 用 `arr.sort()` 会修改调用者传入的数组，面试里最好用 `sorted`。
