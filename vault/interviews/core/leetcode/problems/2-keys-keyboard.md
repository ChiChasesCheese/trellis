## Q
**LC 650 只有两个键的键盘**｜Medium

记事本上有一个 `'A'`，每次只能「复制全部」或「粘贴」，求得到恰好 `n` 个 `'A'` 的最少操作数。

## A
**一句话。** 答案是 `n` 的所有质因数（含重复）之和：因子 `p` 对应一次复制加 `p-1` 次粘贴，共 `p` 步。

```python
def min_steps(n):
    steps, d = 0, 2
    while n > 1:
        while n % d == 0:    # d 一定是质数
            steps += d
            n //= d
        d += 1
    return steps
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 算成质因数个数或乘积：`n=9` 应为 `6`，不是 `2`。
- 内层 `while` 写成 `if`：`n=4` 只除一次 `2`，剩下的 `2` 除不尽，死循环。

**追问。**
- 允许只复制部分字符呢？：状态要带剪贴板长度，改用 BFS。
- 怎么把时间降到 `O(√n)`？：`d*d <= n` 时枚举，剩下的 `n > 1` 本身是质数，直接加上。

**同模式。** LC 651 四个键的键盘、LC 279 完全平方数、LC 343 整数拆分、LC 204 计数质数
