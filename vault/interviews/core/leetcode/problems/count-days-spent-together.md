## Q
**LC 2409 统计共同度过的日子数**｜Easy

Alice 和 Bob 计划分别去罗马开会。给你四个字符串 `arriveAlice`、`leaveAlice`、`arriveBob`、`leaveBob`：Alice 在日期 `arriveAlice` 到 `leaveAlice` 之间在城市里（闭区间），Bob 在 `arriveBob` 到 `leaveBob` 之间在城市里（闭区间）。每个字符串含 5 个字符，格式 `"MM-DD"`。返回 Alice 和 Bob 同时在罗马的天数。

所有日期在同一个自然年且不是闰年，每个月份的天数依次为 `[31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]`。所有日期格式均为 `"MM-DD"`；到达日期早于或等于离开日期；日期都是非闰年的有效日期。

例：`arriveAlice = "08-15"`，`leaveAlice = "08-18"`，`arriveBob = "08-16"`，`leaveBob = "08-19"` → `3`（8 月 16、17、18 日）；`arriveAlice = "10-01"`，`leaveAlice = "10-31"`，`arriveBob = "11-01"`，`leaveBob = "12-31"` → `0`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 区间交集长度：把日期映射成一维整数，再用 `max(0, min(右端) - max(左端) + 1)`。

**核心题。**

- LC 56 合并区间（Blind 75、NeetCode 150、Hot 100、Top Interview 150）：同一个重叠判定：两区间相交当且仅当 `max(左端) <= min(右端)`

**一句话。** 把 `"MM-DD"` 换算成「一年中的第几天」，两个闭区间的交集长度就是 `max(0, min(两个离开日) - max(两个到达日) + 1)`。

**识别。** 两个闭区间求重叠天数，是区间交集的标准形式；日期不能直接相减，所以先用月份天数的前缀和把日期变成整数。非闰年、同一年，说明不用处理跨年和 2 月 29 日。

**推导。** 直接做：逐天枚举 365 天，数两人都在的天数，同样通过但啰嗦。更直接的看法：交集的起点是两个到达日的较晚者，终点是两个离开日的较早者，闭区间长度 `终点 - 起点 + 1`，起点超过终点时没有重叠，长度取 `0`。日期换算：`before[m]` 是前 `m` 个月的总天数（前缀和），所以某月某日是第 `before[月 - 1] + 日` 天。

```python
def count_days_together(arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    before = [0, *accumulate(days)]          # before[m]：前 m 个月的总天数，before[0] = 0

    def day_of_year(s: str) -> int:
        # "MM-DD" -> 一年中的第几天：前面月份的天数 + 当月的日
        return before[int(s[:2]) - 1] + int(s[3:])

    start = max(day_of_year(arriveAlice), day_of_year(arriveBob))   # 交集的起点：较晚的到达
    end = min(day_of_year(leaveAlice), day_of_year(leaveBob))       # 交集的终点：较早的离开
    return max(0, end - start + 1)           # 闭区间要 +1；没有重叠时 end < start，取 0
```

运行：示例 1 → `3`；示例 2 → `0`；`("01-01", "01-05", "03-01", "03-02")` → `0`；`("12-31", "12-31", "12-31", "12-31")` → `1`；`("01-01", "12-31", "01-01", "12-31")` → `365`。

**复杂度。** 时间 `O(1)`（月份数固定为 12），空间 `O(1)`。

**易错点。**
- 闭区间漏掉 `+ 1`：示例 1 得到 `2`，正确是 `3`。
- 不取 `max(0, ...)`：`("01-01", "01-05", "03-01", "03-02")` 得到 `-54`，正确是 `0`。
- 前缀和下标错位：用 `before[month]` 而不是 `before[month - 1]`，日期被整体多加了当月前的天数，跨月时起点和终点错位：`("01-31", "02-01", "01-31", "02-01")` 得到 `0`，正确是 `2`。

**同模式。** LC 986 区间列表的交集、LC 1154 一年中的第几天、LC 1360 日期之间隔几天、LC 1185 一周中的第几天。
