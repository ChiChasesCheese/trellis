## Q
**LC 136 只出现一次的数字**｜Easy

非空数组中除一个元素只出现一次外，其余都恰好出现两次。找出那个元素，要求线性时间、常数空间。

## A
**一句话。** 全部异或：`a ^ a = 0`、`0 ^ x = x`，成对的抵消，剩下的就是答案。

```python
def single_number(nums):
    ans = 0
    for x in nums:
        ans ^= x
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 对 `set(nums)` 异或：成对的合成一份，没有抵消，`[4,1,2,1,2]` 得 `7`，应为 `4`。
- 其余数出现三次：`x ^ x ^ x = x`，XOR 失效，`[2,2,2,3]` 得 `1`。

**追问。**
- 其余数出现三次（LC 137）？：每一位上 `1` 的个数模 `3`，余下的位拼成答案。
- 有两个数只出现一次（LC 260）？：先异或得 `a ^ b`，用其中一个为 `1` 的位把数组分成两组分别异或。

**同模式。** LC 137 只出现一次的数字 II、LC 260 只出现一次的数字 III、LC 268 丢失的数字、LC 389 找不同
