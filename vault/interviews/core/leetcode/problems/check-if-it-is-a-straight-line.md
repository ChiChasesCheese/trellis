## Q
**LC 1232 缀点成线**｜Easy

给出平面上若干点的坐标，判断这些点是否都在同一条直线上。

## A
**一句话。** 用前两个点定方向，其余每个点与第一个点的连线都要与这个方向平行，用叉积判断，避免除法和斜率不存在。

```python
def check_straight_line(coordinates):
    (x0, y0), (x1, y1) = coordinates[:2]
    dx, dy = x1 - x0, y1 - y0
    for x, y in coordinates[2:]:
        if dx * (y - y0) != dy * (x - x0):   # 叉积不为 0 就偏离
            return False
    return True
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 用斜率 `dy / dx`：竖直线 `dx = 0` 会除零，浮点数还有精度问题。
- 只看前三个点：必须检查每一个点。

**追问。**
- 为什么叉积为 0 就共线？：叉积等于两向量围成的平行四边形面积，为 0 说明两向量方向相同或相反。
- 要找共线点最多的一组呢？：LC 149，对每个点把其他点按约分后的方向分组计数。

**同模式。** LC 149 直线上最多的点数、LC 593 有效的正方形、LC 356 直线镜像、LC 836 矩形重叠
