## Q
**LC 240 搜索二维矩阵 II**｜Medium

在 `m x n` 矩阵 `matrix` 中搜索目标值 `target`。矩阵每行的元素从左到右升序，每列的元素从上到下升序。`m == matrix.length`，`n == matrix[i].length`，`1 <= n, m <= 300`，`-10^9 <= matrix[i][j], target <= 10^9`。例：`matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]`，`target = 5` → `true`，`target = 20` → `false`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 利用二维有序性的阶梯搜索（staircase search）：从一个角出发，每步排除一整行或一整列。

**一句话。** 从右上角开始：当前值大于目标就左移（排除这一列），小于目标就下移（排除这一行）。

**识别。** 「行升序 + 列升序」但**不是**整体展平有序（下一行开头不一定大于上一行末尾），所以不能把矩阵当一维数组做二分。`m, n <= 300`，`O(mn)` 也能过，面试要的是 `O(m + n)`。

**推导。** 暴力扫描 `O(mn)`；逐行二分 `O(m log n)`。要更快，需要一个位置，一次比较就能排除一整行或一整列。右上角恰好是所在行的最大值、所在列的最小值：比目标大，则整列都比目标大；比目标小，则整行都比目标小。左下角同理，左上、右下角不行（两个方向都是「变大」，无法决定往哪走）。

```python
def search_matrix(matrix: list[list[int]], target: int) -> bool:
    row, col = 0, len(matrix[0]) - 1  # 从右上角出发：它是所在行的最大值、所在列的最小值
    while row < len(matrix) and col >= 0:
        x = matrix[row][col]
        if x == target:
            return True
        if x > target:
            col -= 1  # x 是这一列最小的，整列都 >= x > target，排除这一列
        else:
            row += 1  # x 是这一行最大的，整行都 <= x < target，排除这一行
    return False
```

运行：上面的 `5×5` 矩阵，`target = 5` → `True`，`target = 20` → `False`；`[[1]]` 中找 `1` → `True`，找 `2` → `False`。

**复杂度。** 时间 `O(m + n)`（每步排除一行或一列），空间 `O(1)`。

**拓展优化。**
- 逐行二分：对每一行用 `bisect_left`，`O(m log n)`，在 `m` 远小于 `n` 时更快，代码也更短，可以作为备选。

**易错点。**
- 把它当成 LC 74（展平后整体有序）做二分：这个矩阵里 `10`（第 4 行开头）小于 `22`（上一行末尾），展平后不是有序的，二分会漏解。
- 从左上角出发：右移和下移都会变大，无法决定该排除什么。
- 边界写成 `col > 0`：会漏掉第 `0` 列，应该是 `col >= 0`。

**追问。**
- 返回位置而不是布尔：命中时 `return (row, col)`，其余不变。
- 统计 `<= target` 的个数（LC 378 的计数子程序）：同一个阶梯，每行先把 `col` 左移到 `matrix[row][col] <= target`，再累加 `col + 1`，`O(m + n)`。
- 左下角起步也行：它是所在列的最大值、所在行的最小值，比目标大就上移、比目标小就右移，与右上角完全对称。

**同模式。** LC 74 搜索二维矩阵、LC 378 有序矩阵中第 K 小的元素、LC 11 盛最多水的容器、LC 167 两数之和 II。
