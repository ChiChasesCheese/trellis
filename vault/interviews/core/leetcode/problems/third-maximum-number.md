## Q
**LC 414 第三大的数**｜Easy

返回数组中第三大的**不同**数字；不存在则返回最大的数。

## A
**一句话。** 一遍扫描，维护目前最大的至多 3 个不同值，最后够 3 个取第三个，否则取最大。

```python
def third_max(nums):
    top = []                      # 最大的至多 3 个不同值，降序
    for x in nums:
        if x in top:              # 重复的不占名次
            continue
        top.append(x)
        top.sort(reverse=True)    # 最多 4 个元素，O(1)
        del top[3:]
    return top[2] if len(top) == 3 else top[0]
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 不去重直接取第三个：`[2,2,3,1]` 降序 `[3,2,2,1]`，返回 `2`，应为 `1`。
- 用 `-2^31` 当「空」：`[1,2,-2147483648]` 的第三大恰好是 `-2^31`，被误判为不存在。
- 不存在时返回的是最大值，不是第二大。

**追问。**
- 推广到第 `k` 大不同值？：大小为 `k` 的最小堆加集合去重，`O(n log k)`。
- 一行写法？：`heapq.nlargest(3, set(nums))`。

**同模式。** LC 215 数组中的第 K 个最大元素、LC 703 数据流中的第 K 大元素、LC 628 三个数的最大乘积
