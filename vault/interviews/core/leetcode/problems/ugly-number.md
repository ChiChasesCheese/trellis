## Q
**LC 263 丑数**｜Easy

丑数是只含质因数 `2`、`3`、`5` 的正整数（`1` 也算）。判断整数 `n` 是否为丑数。例：`14` → `false`。

## A
**一句话。** 非正数直接返回 `False`，否则把 `2`、`3`、`5` 依次除干净，剩下 `1` 就是丑数。

```python
def is_ugly(n):
    if n <= 0:              # 0 还会让循环永不停止
        return False
    for p in (2, 3, 5):
        while n % p == 0:   # 把因子 p 除干净
            n //= p
    return n == 1
```

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- 漏掉 `n <= 0`：`n = 0` 时 `0 % 2 == 0` 永远成立，`while` 死循环。
- 用 `/` 而不是 `//`：`n` 变成浮点数。

**追问。**
- 第 `n` 个丑数（LC 264）？：三指针动态规划，`O(n)`。
- 质因数换成任意给定列表（LC 313）？：多指针或最小堆。

**同模式。** LC 264 丑数 II、LC 313 超级丑数、LC 1201 丑数 III、LC 326 3 的幂
