## Q
**LC 2081 k 镜像数字的和**｜Hard

十进制和 `k` 进制（`2 <= k <= 9`）下都是回文的正整数叫 `k` 镜像数字。求最小的 `n`（`<= 30`）个之和。

## A
**一句话。** 不逐个枚举整数，而是按长度、再按前半从小到大构造十进制回文（天然递增），逐个检查它在 `k` 进制下是否回文，凑够 `n` 个就停。

```python
def k_mirror(k, n):
    def is_pal_k(x):           # x 在 k 进制下是否回文
        d = []
        while x:
            d.append(x % k)
            x //= k
        return d == d[::-1]

    ans, length = 0, 1
    while True:
        half = (length + 1) // 2
        for p in range(10 ** (half - 1), 10 ** half):
            s = str(p)
            x = int(s + s[:length // 2][::-1])  # 十进制回文
            if is_pal_k(x):
                ans += x
                n -= 1
                if n == 0:
                    return ans
        length += 1
```

**复杂度。** 时间约 `O(10^{L/2}·L)`（`L` 为第 `n` 个答案的位数），空间 `O(L)`。

**易错点。**
- 从 1 往上逐个判断两种回文：第 30 个答案可达 `10^{11}` 量级，必然超时。
- 偶数长度和奇数长度混在一起生成：同一长度内按前半递增才有序，要先按长度分组。

**追问。**
- 为什么同长度内按前半递增就是递增？：位数相同的回文由前半唯一决定，前半大则整个数大。
- 反过来在 `k` 进制下构造回文再检查十进制？：也行，`k` 小时 `k` 进制回文更稠密，候选更多，通常更慢。

**同模式。** LC 9 回文数、LC 564 寻找最近的回文数、LC 906 超级回文数
