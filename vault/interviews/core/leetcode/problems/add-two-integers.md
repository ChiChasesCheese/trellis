## Q
**LC 2235 两整数相加**｜Easy

给定两个整数，返回它们的和。

## A
**一句话。** 直接返回 `num1 + num2`；追问「不用 `+`」时用异或加与左移循环到没有进位。

```python
def sum_of_two(num1, num2):
    return num1 + num2
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 位运算版不加掩码：Python 负数有无限个前导 1，`while b:` 永远不结束。
- 还原负数写成 `-a`：32 位下 `a > 0x7FFFFFFF` 表示负数，要用 `~(a ^ mask)`。

**追问。**
- 不用 `+`、`-` 怎么加（LC 371）？：`a ^ b` 是无进位和，`(a & b) << 1` 是进位，重复到进位为 `0`。
- 两个任意长的数字字符串怎么加？：逐位加并带进位（LC 415）。

**同模式。** LC 371 两整数之和、LC 415 字符串相加、LC 2 两数相加、LC 67 二进制求和
