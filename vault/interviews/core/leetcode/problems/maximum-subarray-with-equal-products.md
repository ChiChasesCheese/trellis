## Q
**LC 3411 最长乘积等价子数组**｜Easy

正整数数组 `nums`（长度 ≤ 100，元素 ≤ 10）。子数组满足 `乘积 == gcd × lcm` 就叫乘积等价，求最长的这种子数组的长度。

## A
**一句话。** 枚举左端点，右端点向右走时顺手维护乘积、gcd、lcm，三者相等关系成立就更新答案；乘积超过 `gcd × lcm` 的上界就提前停。

```python
def max_length(nums):
    n = len(nums)
    ans = 0
    for i in range(n):
        p, g, l = 1, 0, 1       # gcd(0, x) = x
        for j in range(i, n):
            x = nums[j]
            p, g, l = p * x, gcd(g, x), lcm(l, x)
            if p > 25200:       # lcm ≤ 2520，gcd ≤ 10
                break           # 乘积只增不减，再也追不平
            if p == g * l:
                ans = max(ans, j - i + 1)
    return ans
```

**复杂度。** 时间 `O(n² log U)`，空间 `O(1)`，`U` 是元素上界。

**易错点。**
- gcd 初值写成 `1`：`gcd(1, x)` 永远是 `1`，要用 `0`（`gcd(0, x) = x`）；lcm 的初值才是 `1`。
- 等式不成立就 `break`：`[1,2,1,2,1,1,1]` 从下标 1 起，长度 1 的 `[2]` 不成立，长度 2 之后又成立；只能在乘积越界时停。
- 每个子数组重新算一遍三个量：变成 `O(n³)`，右端点扩一格只需各更新一次。

**追问。**
- 等式到底在说什么？：对每个质数，指数之和等于最大指数加最小指数。长度 2 恒成立；长度 ≥ 3 时等价于元素两两互质。
- `n` 到 `10⁵` 怎么做？：按「两两互质」做滑动窗口，每个数记它含哪些质因数，窗口内质因数不重复；答案和 `2` 取最大。
- 其他语言乘积溢出怎么办？：靠 `p > 25200` 提前停，乘积到不了溢出的大小。

**同模式。** LC 149 直线上最多的点数、LC 2447 最大公因数等于 K 的子数组数目、LC 2470 最小公倍数为 K 的子数组数目、LC 2401 最长优雅子数组
