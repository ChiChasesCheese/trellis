## Q
**LC 645 错误的集合**｜Easy

`1..n` 的集合里一个数被复制成另一个数，于是丢了一个数、多了一个重复数。给出错后的 `nums`，返回 `[重复, 丢失]`。

## A
**一句话。** 求和做差：原和减去集合和是重复值，`1..n` 的和减去集合和是丢失值。

```python
def find_error_nums(nums):
    n, uniq = len(nums), set(nums)
    dup = sum(nums) - sum(uniq)          # 重复值多算了一次
    miss = n * (n + 1) // 2 - sum(uniq)  # 完整和减去出现过的不同值
    return [dup, miss]
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 只用 `n(n+1)/2 - sum(nums)`：它是「丢失 - 重复」，`[1,2,2,4]` 得 `1`，应为 `3`。
- 返回顺序写反：要 `[重复, 丢失]`，不是 `[3,2]`。

**追问。**
- 要 `O(1)` 空间？：遍历时把 `nums[abs(x)-1]` 取负，遇到已为负的就是重复值，最后仍为正的下标 `+1` 是丢失值。
- 为什么异或也行？：`nums` 与 `1..n` 全部异或得 `dup ^ miss`，按某个为 1 的位分组再异或，分出两个数。

**同模式。** LC 442 数组中重复的数据、LC 448 找到所有数组中消失的数字、LC 287 寻找重复数、LC 268 丢失的数字
