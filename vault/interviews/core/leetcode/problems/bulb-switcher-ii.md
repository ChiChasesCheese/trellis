## Q
**LC 672 灯泡开关 Ⅱ**｜Medium

`n` 个灯泡初始全亮，有 4 个按钮：翻转全部、翻转偶数编号、翻转奇数编号、翻转编号 `3k + 1` 的灯（`k ≥ 0`）。恰好按 `presses` 次（可重复），问最终有多少种不同的灯的状态。

## A
**一句话。** 4 个按钮之间有关系（前三个任意两个之和等于第三个），灯的状态只取决于前 3 个灯，所以结果由 `n`（最多当 3）和 `presses`（0、1、2、≥3）直接查表。

```python
def flip_lights(n, presses):
    n = min(n, 3)                # 3 个灯之后状态重复
    if presses == 0:
        return 1
    if n == 1:
        return 2
    if n == 2:
        return 3 if presses == 1 else 4
    if presses == 1:
        return 4
    return 7 if presses == 2 else 8
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 枚举所有按键序列：`4^presses` 太多，要用「同一个按钮按两次抵消」化简。
- `n` 很大时直接枚举灯：灯的状态由前 3 个灯决定，其余灯只是重复。
- `n = 2` 时按一次是 3 种而不是 4 种：奇偶按钮的组合与全翻转有重合。

**追问。**
- 为什么只看前 3 个灯？：每个按钮对灯的作用以 6 为周期，而按钮的组合差异在前 3 个灯上已经全部体现。
- 怎样验证表？：对 `n ≤ 3`、`presses ≤ 3` 用位掩码暴力搜索，各个按钮按奇偶次数组合共 16 种。

**同模式。** LC 319 灯泡开关、LC 292 Nim 游戏、LC 390 消除游戏
