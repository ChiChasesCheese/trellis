## Q
**LC 974 和可被 K 整除的子数组**｜Medium

给整数数组 `nums` 和 `k`，数有多少个非空连续子数组的和能被 `k` 整除。

## A
**一句话。** 前缀和取模加哈希表：两个前缀余数相同，夹在中间的子数组和就能被 `k` 整除。

```python
def subarrays_div_by_k(nums, k):
    seen = Counter({0: 1})       # 空前缀的余数是 0
    pre = ans = 0
    for x in nums:
        pre = (pre + x) % k      # Python 的 % 保证 [0, k)
        ans += seen[pre]         # 每个同余前缀对应一个子数组
        seen[pre] += 1
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(min(n,k))`。

**易错点。**
- 漏了 `{0: 1}`：从开头起的子数组丢掉，`[4,5,0,-2,-3,1]`、`k=5` 得 `6`，应为 `7`。
- 余数出现负数：C++/Java 的 `%` 对负数返回负余数，`-1` 与 `4` 被当成两类，要写 `((s % k) + k) % k`。

**追问。**
- 和恰好等于 `k`（LC 560）？：键换成前缀和本身，查 `seen[pre - k]`。
- 长度至少为 2（LC 523）？：字典记每个余数第一次出现的下标，同余时检查下标差 `>= 2`。

**同模式。** LC 560 和为 K 的子数组、LC 523 连续的子数组和、LC 525 连续数组、LC 1590 使数组和能被 P 整除
