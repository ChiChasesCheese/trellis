## Q
**面试题 08.13 堆箱子**｜Hard

箱子 `[宽, 深, 高]` 不可翻转，下面的箱子三个维度都必须严格大于上面的。求箱堆的最大总高度。

## A
**一句话。** 按宽度排序后做三维严格递增的最大高度和子序列 DP，`dp[i]` 为以第 `i` 个箱子为底的最大高度。

```python
def pile_box(box):
    boxes = sorted(box)
    dp = [0] * len(boxes)        # 以 boxes[i] 为底的最大高度
    for i, (w, d, h) in enumerate(boxes):
        above = 0
        for j in range(i):
            wj, dj, hj = boxes[j]
            if wj < w and dj < d and hj < h:
                above = max(above, dp[j])
        dp[i] = above + h
    return max(dp)
```

**复杂度。** 时间 `O(n²)`，空间 `O(n)`。

**易错点。**
- 排序后只比深度和高度：宽度相同也会排前面，`[[1,1,1],[1,2,2]]` 错成 `3`，应为 `2`。
- 按个数做 LIS 再乘高度：`dp` 存的必须是高度和，`[[1,1,1],[2,2,2],[3,3,3],[5,1,100]]` 应取单个 `[5,1,100]` 得 `100`。
- 不排序直接 DP：能放上面的箱子出现在后面，算 `dp[i]` 时还没算到，`[[3,3,3],[2,2,2],[1,1,1]]` 得 `3`，应为 `6`。

**追问。**
- 怎么还原箱堆？：开 `prev[i]` 记转移来源，从 `argmax(dp)` 回溯。
- 允许旋转、用 `<=`（LC 1691）？：每个长方体三边升序后整体排序，同样的 DP。
- 二维信封（LC 354）？：宽升序、同宽高降序，对高做 `O(n log n)` 的 LIS。

**同模式。** LC 300 最长递增子序列、LC 354 俄罗斯套娃信封问题、LC 1691 堆叠长方体的最大高度、LC 368 最大整除子集
