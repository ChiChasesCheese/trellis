## Q
**LC 2243 计算字符串的数字和**｜Easy

数字串 `s` 和整数 `k`（`k ≥ 2`）：只要 `len(s) > k`，就把 `s` 每 `k` 位切一组（末组可短），每组换成它的数字和的十进制串，再拼起来。返回最后的 `s`。

## A
**一句话。** 按题意模拟：`while len(s) > k`，步长 `k` 切片求和，`str` 后 `join` 成新串。

```python
def digit_sum(s, k):
    while len(s) > k:            # 等于 k 就停
        s = "".join(
            str(sum(map(int, s[i:i + k])))  # 一组的和
            for i in range(0, len(s), k))
    return s
```

**复杂度。** 时间 `O(n)` 每轮，轮数很少（`n ≤ 100`）；空间 `O(n)`。

**易错点。**
- 条件写成 `>= k`：`"000"`、`k = 3` 会再算一轮得 `"0"`，应为 `"000"`。
- 组和只取个位或数字根：`346` 要换成 `"13"` 两位，不是 `"4"`。

**追问。**
- 为什么不会死循环？：满组和的位数不超过组长；若长度没变，每个满组的和都 ≥ 10，数字总和严格变小，两者不能同时停住。
- 能用数字根一步算出吗？：不能，下一轮按新串重新分组，组和必须展开成十进制位。

**同模式。** LC 202 快乐数、LC 258 各位相加、LC 1945 字符串转化后的各位数字之和
