## Q
**LC 652 寻找重复的子树**｜Medium

给二叉树根节点，返回所有重复子树（结构和节点值都相同）；对每一类重复子树只返回其中任意一棵的根节点。

## A
**一句话。** 后序遍历把每棵子树序列化成字符串（空节点记 `#`），用哈希表计数，某个字符串第二次出现时收下该节点。

```python
def find_duplicate_subtrees(root):
    seen = defaultdict(int)
    ans = []
    def dfs(node):
        if not node:
            return '#'                 # 空节点要记，结构才唯一
        s = f'{node.val},{dfs(node.left)},{dfs(node.right)}'
        seen[s] += 1
        if seen[s] == 2:               # 恰好第二次才收，避免重复
            ans.append(node)
        return s
    dfs(root)
    return ans
```

**复杂度。** 时间 `O(n²)`（字符串拼接，最长 `O(n)`），空间 `O(n²)`。

**易错点。**
- 不记空节点：`1,2` 的左孩子和右孩子无法区分，结构不同会被判相同。
- 序列化时没有分隔符：`1` 和 `11`、`11` 与 `1,1` 会混淆，值之间要用逗号。
- 出现第三次又收一次：用 `== 2` 而不是 `>= 2`，每类只收一个。

**追问。**
- 怎么降到 `O(n)`？：给每个不同的子树结构分配一个整数 id，用 `(val, id_左, id_右)` 三元组作键，每步 `O(1)`。
- 为什么要后序？：父节点的序列依赖左右子树的结果，只有后序时孩子先算完。

**同模式。** LC 297 二叉树的序列化与反序列化、LC 572 另一棵树的子树、LC 606 根据二叉树创建字符串、LC 100 相同的树
