## Q
**LC 757 设置交集大小至少为2**｜Hard

整数闭区间 `[start, end]` 若干，求一个最小的整数集合，使每个区间里至少有两个数属于它。

## A
**一句话。** 按右端升序（右端相同按左端降序）处理，只记已选的最大两个点 `a < b`；区间一个都没覆盖就选 `end-1, end`，只覆盖了 `b` 就补一个 `end`，点尽量靠右以便覆盖后面的区间。

```python
def intersection_size_two(intervals):
    intervals.sort(key=lambda x: (x[1], -x[0]))
    ans = 0
    a, b = -1, -1              # 已选的最大两点，a < b
    for s, e in intervals:
        if s > b:              # 两点都不在区间里
            ans += 2
            a, b = e - 1, e
        elif s > a:            # 只有 b 在区间里
            ans += 1
            a, b = b, e
    return ans
```

**复杂度。** 时间 `O(n log n)`，空间 `O(1)`（不计排序）。

**易错点。**
- 右端相同时按左端升序：短区间排在后面，先处理长区间选的点可能放不进短区间，要让被包含的短区间先处理。
- 补点时选 `s` 而不是 `e`：点越靠右，越可能被后面的区间用上。

**追问。**
- 至少 `k` 个呢？：同样按右端排序，对每个区间数出已有的点，不足就从右端往左补没选过的点，就是 LC 2589 的做法。
- 为什么只记两个点？：区间按右端递增，最右的两个点是最可能落在后续区间里的，更左的点不会比它们更有用。

**同模式。** LC 452 用最少数量的箭引爆气球、LC 435 无重叠区间、LC 2589 完成所有任务的最少时间
