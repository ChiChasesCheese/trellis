## Q
**LC 1010 总持续时间可被 60 整除的歌曲**｜Medium

给歌曲时长数组 `time`，数有多少对 `i < j` 满足 `time[i] + time[j]` 能被 60 整除。

## A
**一句话。** 只看时长对 60 的余数，边扫边用长 60 的计数数组查互补余数已出现几次。

```python
def num_pairs_divisible_by_60(time):
    seen = [0] * 60              # seen[r]：前面余数为 r 的歌数
    pairs = 0
    for t in time:
        r = t % 60
        pairs += seen[(60 - r) % 60]   # r=0 的搭档也是 0
        seen[r] += 1             # 先查后登记，不会自己配自己
    return pairs
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 搭档写成 `60 - r`：`r=0` 时下标 `60` 越界，要再取模。
- 先登记再查询：`[30]` 会自己配自己得 `1`，应为 `0`。

**追问。**
- 三首歌总时长被 60 整除？：固定一首，剩下用计数套两数之和，`O(n^2)`。
- 数据流式到来？：本解本来就在线，每首 `O(1)`。

**同模式。** LC 1 两数之和、LC 1497 检查数组对是否可以被 k 整除、LC 974 和可被 K 整除的子数组、LC 560 和为 K 的子数组
