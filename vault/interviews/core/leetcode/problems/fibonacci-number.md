## Q
**LC 509 斐波那契数**｜Easy

`F(0)=0`，`F(1)=1`，`F(n)=F(n-1)+F(n-2)`，求 `F(n)`（`n <= 30`）。

## A
**一句话。** 按定义递归，加缓存让每个 `F(i)` 只算一次（记忆化）。

```python
def fib(n):
    @cache                 # 每个 i 只算一次
    def f(i):
        if i < 2:
            return i
        return f(i - 1) + f(i - 2)

    return f(n)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 基准写成 `F(0)=F(1)=1`：`n=4` 得 `5`，应为 `3`。
- 不加缓存：调用数指数增长，`n=50` 约 `4×10¹⁰` 次。
- `n` 超过约 `1000`：递归栈溢出，要改成循环。

**追问。**
- `n` 到 `10¹⁸` 怎么算？：`2×2` 矩阵快速幂或快速倍增，`O(log n)`，结果取模。
- 为什么不用通项公式？：浮点数在 `n` 约 `70` 以后精度不够。

**同模式。** LC 70 爬楼梯、LC 1137 第 N 个泰波那契数、LC 746 使用最小花费爬楼梯、LC 198 打家劫舍
