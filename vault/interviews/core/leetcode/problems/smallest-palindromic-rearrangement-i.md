## Q
**LC 3517 最小回文排列 I**｜Medium

给一个回文串 `s`，返回它重排后字典序最小的回文串。

## A
**一句话。** 回文只需决定左半；`s` 的左半正好是每种字符的一半，排序后接上中间字符（奇数长时）和左半的反转。

```python
def smallest_palindrome(s):
    n = len(s)
    half = ''.join(sorted(s[:n // 2]))   # 左半已含每种字符的一半
    mid = s[n // 2] if n % 2 else ''     # 唯一的奇数次字符
    return half + mid + half[::-1]
```

**复杂度。** 时间 `O(n log n)`（计数排序可 `O(n)`），空间 `O(n)`。

**易错点。**
- 把整个 `s` 排序再找回文：多此一举，还容易把中间字符放错。
- 中间字符取错：原串是回文，正中间的字符就是出现奇数次的那个。

**追问。**
- `n` 到 `10^5`，想要 `O(n)`？：对左半计数，按字母顺序展开。
- 第 `k` 小的回文排列（LC 3518）？：对左半按位试字母，用多重组合数数「这一位放它时有几种」，超过 `k` 就定下。

**同模式。** LC 409 最长回文串、LC 2384 最大回文数字、LC 3518 最小回文排列 II
