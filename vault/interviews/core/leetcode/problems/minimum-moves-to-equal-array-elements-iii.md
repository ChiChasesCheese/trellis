## Q
**LC 3736 最小操作次数使数组元素相等 III**｜Easy

给你一个整数数组 `nums`。在一步操作中，你可以将任意单个元素 `nums[i]` 的值增加 `1`。返回使数组中的所有元素都相等所需的最小总操作次数。`1 <= nums.length <= 100`，`1 <= nums[i] <= 100`。例：`nums = [2,1,3]` → `3`（`nums[0]` 加 `1` 次，`nums[1]` 加 `2` 次，全部变成 `3`）；`nums = [4,4,5]` → `2`（两个 `4` 各加 `1` 次，全部变成 `5`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 单向操作下的目标值选择（只增不减，目标就是最大值）+ 总和差公式：总次数 = 目标总和 - 实际总和。

**核心题。**

- LC 268 丢失的数字（Blind 75、NeetCode 150）：同样用「目标总和减实际总和」一步算出答案

**一句话。** 只能加，所以所有数都抬到最大值，次数 = `max(nums) * n - sum(nums)`。

**识别。** 操作只有 `+1` 这一个方向，且每步只动一个数，所以各元素的次数互不影响；问的是总次数，于是只需要确定目标值。

**推导。** 直接想法是枚举目标值 `t`，算 `sum(t - x)`。但只增不减要求 `t >= max(nums)`，而总次数 `n * t - sum(nums)` 随 `t` 严格增大，所以最优的 `t` 就是 `max(nums)`，不用枚举。

```python
def min_moves(nums: list[int]) -> int:
    # 只能加：目标值不能低于最大值；再往上每抬 1，总次数多 n，所以目标就取最大值
    # 每个数要加 max - x 次，求和即「目标总和 - 实际总和」
    return max(nums) * len(nums) - sum(nums)
```

运行：`[2,1,3]` → `3`；`[4,4,5]` → `2`；`[7]` → `0`；`[100,100,...,100,1]`（`99` 个 `100` 加 `1` 个 `1`）→ `99`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 与 LC 462 混淆，把目标取成中位数：`[2,1,3]` 得到 `2`，正确是 `3`（那题能减，这里 `3` 降不下来）。
- 与 LC 453 混淆，套用 `sum(nums) - min(nums) * n`：`[4,4,5]` 得到 `1`，正确是 `2`（那题是其余 `n - 1` 个数一起加，等价于一个数减）。
- 没排序却把最大值写成 `nums[-1]`：`[3,1,2]` 得到 `0`，正确是 `3`。

**同模式。** LC 453 最小操作次数使数组元素相等、LC 462 最小操作次数使数组元素相等 II、LC 1551 使数组中所有元素相等的最小操作数、LC 2448 使数组相等的最小开销。
