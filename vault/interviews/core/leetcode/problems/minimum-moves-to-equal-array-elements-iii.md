## Q
**LC 3736 最小操作次数使数组元素相等 III**｜Easy

每步可把任一元素加 `1`，求使数组所有元素相等的最少步数。

## A
**一句话。** 只能加，目标取最大值，步数是 `max*n - sum`。

```python
def min_moves(nums):
    return max(nums) * len(nums) - sum(nums)
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 目标取中位数（混淆 LC 462）：`[2,1,3]` 得 `2`，应为 `3`，`3` 降不下来。
- 套 LC 453 的 `sum - min*n`：`[4,4,5]` 得 `1`，应为 `2`。

**追问。**
- 每步改成「加 `1` 或减 `1`」呢？：目标取中位数（LC 462）。

**同模式。** LC 453 最小操作次数使数组元素相等、LC 462 最小操作次数使数组元素相等 II、LC 1551 使数组中所有元素相等的最小操作数
