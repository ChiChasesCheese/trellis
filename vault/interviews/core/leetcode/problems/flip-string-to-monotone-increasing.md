## Q
**LC 926 将字符串翻转到单调递增**｜Medium

二进制串 `s` 每次可翻转任一位，求使它变成「若干 `0` 后跟若干 `1`」的最少翻转次数。

## A
**一句话。** 扫描时维护已见 `1` 的个数 `ones` 和当前前缀的最少翻转 `flips`，遇到 `0` 取 `min(flips + 1, ones)`。

```python
def min_flips_mono_incr(s):
    ones = flips = 0
    for ch in s:
        if ch == "1":
            ones += 1           # 追加 '1' 不破坏单调
        else:                   # 翻成 '1'，或前面的 '1' 全翻成 '0'
            flips = min(flips + 1, ones)
    return flips
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 贪心「第一个 `1` 之后的 `0` 全翻」：`"100000"` 得 `5`，应为 `1`。
- `ones` 用整串的 `1` 个数：只能翻已出现的 `1`，要用扫描到当前的。
- 只翻一个方向：`0 → 1` 和 `1 → 0` 都允许，`min` 的两项分别对应。

**追问。**
- 前缀和写法？：枚举分界点 `k`，代价是左边的 `1` 数加右边的 `0` 数，容易讲清分界点。
- 要返回翻转后的串？：先求最优分界点，再翻掉左边的 `1` 和右边的 `0`。

**同模式。** LC 1653 使字符串平衡的最少删除次数、LC 2483 商店的最少代价、LC 1888 使二进制字符串字符交替的最少反转次数
