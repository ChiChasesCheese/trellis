## Q
**LC 887 鸡蛋掉落**｜Hard

`k` 枚鸡蛋、`n` 层楼，存在临界层 `f`，求最坏情况下确定 `f` 的最少操作次数。

## A
**一句话。** 倒过来问：`m` 次操作、`j` 枚蛋最多能确定几层，`f(m,j) = f(m-1,j-1) + f(m-1,j) + 1`，逐行填到 `>= n`。

```python
def super_egg_drop(k, n):
    # dp[m][j]：m 次操作、j 枚蛋最多能确定的层数
    dp = [[0] * (k + 1)]          # 0 次操作什么也确定不了
    while dp[-1][k] < n:
        m = len(dp)
        dp.append([0] * (k + 1))
        for j in range(1, k + 1):
            # 碎了 + 没碎 + 被扔的这一层
            dp[m][j] = dp[m-1][j-1] + dp[m-1][j] + 1
    return len(dp) - 1
```

**复杂度。** 时间 `O(k·m)`（`m` 为答案），空间 `O(k·m)`。

**易错点。**
- 当二分查找：`k=2`、`n=100` 得 `50`，应为 `14`；蛋少时靠递减步长。
- 转移读本行 `dp[m][j-1]`：同一次操作用了两次，`k=3`、`n=14` 得 `3`，应为 `4`。
- 漏掉 `+ 1`：表全是 `0`，`while` 永不结束。

**追问。**
- 怎么压空间？：每行只依赖上一行，`j` 倒序更新一维数组，`O(k)`。
- 蛋足够多时？：退化为二分，答案 `ceil(log2(n+1))`，可先 `k = min(k, n.bit_length())`。
- `n` 到 `10^18`？：`f(m,k) = Σ C(m,i)`（`i=1..k`），对 `m` 二分。
