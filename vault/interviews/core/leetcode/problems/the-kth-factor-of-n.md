## Q
**LC 1492 n 的第 k 个因子**｜Medium

把 `n` 的所有因子升序排列，返回第 `k` 个，不足 `k` 个返回 `-1`。

## A
**一句话。** 因子成对出现：`i` 从 1 枚举到 `√n` 得到升序的小因子，再把 `i` 倒着枚举，`n // i` 就是升序的大因子。

```python
def kth_factor(n, k):
    i = 1
    while i * i <= n:            # 小因子，升序
        if n % i == 0:
            k -= 1
            if k == 0:
                return i
        i += 1
    i -= 1
    if i * i == n:               # 平方根只算一次
        i -= 1
    while i > 0:                 # 大因子 n // i，升序
        if n % i == 0:
            k -= 1
            if k == 0:
                return n // i
        i -= 1
    return -1
```

**复杂度。** 时间 `O(√n)`，空间 `O(1)`。

**易错点。**
- 完全平方数的平方根算两次：`n = 4` 的因子是 `1, 2, 4`，不是 `1, 2, 2, 4`。
- 第二段正着枚举 `i`：`n // i` 会变成降序。

**追问。**
- `n ≤ 1000` 的直接写法？：`i` 从 1 到 `n` 逐个试，`O(n)`。
- 很多次查询不同的 `n`？：线性筛出最小质因子，分解后按指数生成所有因子再排序。

**同模式。** LC 204 计数质数、LC 319 灯泡开关
