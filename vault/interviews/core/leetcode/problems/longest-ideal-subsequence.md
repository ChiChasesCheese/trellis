## Q
**LC 2370 最长理想子序列**｜Medium

小写字母字符串 `s` 和整数 `k`。"理想"子序列要求相邻两个字母在字母表中的位置之差的绝对值不超过 `k`。求最长理想子序列的长度。

## A
**一句话。** 按结尾字母做 DP：`dp[c]` 表示以字母 `c` 结尾的最长理想子序列，遇到字母 `c` 时从 `dp[c - k .. c + k]` 取最大再加 `1`。

```python
def longest_ideal_string(s, k):
    dp = [0] * 26                       # 以各字母结尾的最长长度
    for ch in s:
        c = ord(ch) - 97
        lo, hi = max(0, c - k), min(25, c + k)
        dp[c] = max(dp[lo:hi + 1]) + 1  # 接在任一相近字母后面
    return max(dp)
```

**复杂度。** 时间 `O(26n)`，空间 `O(26)`。

**易错点。**
- 窗口不夹到 `[0, 25]`：下标越界或取到错误位置。
- 用 `dp[c] += ...` 累加：应当是取最大值再加 `1`，不是累加。

**追问。**
- 为什么 `k` 很大也不慢？：字母表只有 `26`，窗口最多 `26`。

**同模式。** LC 300 最长递增子序列、LC 1647 字符频次唯一的最小删除次数、LC 2423 删除字符使频率相同
