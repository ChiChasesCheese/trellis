## Q
**LC 279 完全平方数**｜Medium

给整数 `n`，求和为 `n` 的完全平方数的最少个数（同一个数可重复使用）。

## A
**一句话。** 一维 DP：枚举最后一个平方数 `j²`，`dp[i] = 1 + min(dp[i - j²])`。

```python
def num_squares(n):
    dp = [0] + [inf] * n      # dp[i]：和为 i 的最少平方数个数
    for i in range(1, n + 1):
        dp[i] = 1 + min(dp[i - j*j]
                        for j in range(1, isqrt(i) + 1))
    return dp[n]
```

**复杂度。** 时间 `O(n√n)`，空间 `O(n)`。

**易错点。**
- 贪心取最大平方数：`12` 得 `9+1+1+1` 共 `4` 个，应为 `3`（`4+4+4`）。
- 用 `int(n ** 0.5)` 开方：大数上浮点误差会差 `1`，用 `isqrt`。
- `dp[0]` 写成 `inf`：任何完全平方数都凑不出来。

**追问。**
- 有更快的做法吗？：四平方和定理，答案至多 `4`；去掉因子 `4` 后模 `8` 余 `7` 则为 `4`，否则按是否为平方数、两平方和判 `1`、`2`、`3`，`O(√n)`。
- BFS 怎么做？：从 `n` 每层减一个平方数，第一次到 `0` 的层数即答案，每层用集合去重。
