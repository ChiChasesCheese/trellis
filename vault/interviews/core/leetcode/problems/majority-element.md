## Q
**LC 169 多数元素**｜Easy

返回数组中出现次数大于 `⌊n/2⌋` 的元素（保证存在）。进阶：`O(n)` 时间、`O(1)` 空间。

## A
**一句话。** 摩尔投票（Boyer-Moore）：同值计数加一、异值减一，计数归零就换候选，多数元素必然剩下。

```python
def majority_element(nums):
    cand, cnt = nums[0], 0
    for x in nums:
        if cnt == 0:           # 票数抵消光了，换候选
            cand = x
        cnt += 1 if x == cand else -1
    return cand
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 不保证存在多数元素还直接返回：`[1,2,3]` 得 `3`，要再扫一遍验证 `count > n // 2`。
- 阈值写成 `>=`：`[1,1,2,2]` 每个数恰好一半，不算多数。

**追问。**
- 超过 `⌊n/3⌋` 的元素（LC 229）？：最多两个，维护两个候选和两个计数，最后验证；推广到 `1/k` 用 `k-1` 个候选。
- 还有哪些解法？：哈希计数 `O(n)` 空间；排序取 `nums[n//2]`；随机抽一个验证，期望两次命中。

**同模式。** LC 229 多数元素 II、LC 1150 检查一个数是否在数组中占绝大多数、LC 136 只出现一次的数字
