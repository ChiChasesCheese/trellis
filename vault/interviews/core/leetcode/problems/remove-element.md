## Q
**LC 27 移除元素**｜Easy

原地移除数组中所有等于 `val` 的元素（顺序可变），返回剩余个数 `k`，前 `k` 个位置放保留的元素。

## A
**一句话。** 读指针扫整个数组，不等于 `val` 的元素写到写指针处。

```python
def remove_element(nums, val):
    k = 0       # nums[:k] 是已保留的元素
    for x in nums:
        if x != val:
            nums[k] = x     # 写位置不会超过读位置
            k += 1
    return k
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 遍历中 `nums.remove(val)` 或 `del`：`[3,2,2,3]` 这类相邻重复会跳过元素，且每次删除 `O(n)`。
- 只返回计数、没把保留元素放到前 `k` 位：评测检查 `nums[:k]`。

**追问。**
- 被移除的元素很少时怎么省写？：对撞指针，遇到 `val` 就用末尾元素覆盖并缩小范围，写次数等于 `val` 的个数。
- 覆盖法里为什么不能直接前进？：末尾换过来的元素还没检查过，可能仍等于 `val`。
