## Q
**LC 1526 形成目标数组的子数组最少增加次数**｜Hard

初始数组全为 `0`，每次操作可选任意子数组把其中每个元素加 `1`。求把它变成 `target` 的最少操作次数。

## A
**一句话。** 差分思路：每个位置只要比左邻高出多少，就需要新开多少次从这里起头的操作，把所有「上升量」加起来。

```python
def min_number_operations(target):
    ans, prev = 0, 0
    for x in target:
        ans += max(0, x - prev)       # 比左边高出的部分，要新开操作
        prev = x
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- `prev` 初值取 `target[0]`：第一个元素也要从 `0` 抬上去，`prev = 0`，让第一项贡献 `target[0]`。
- 加上所有绝对差：下降段不需要新操作（前面的操作自然在那里结束），只加上升量。
- 把每个最大值单独处理：分治解法可行，但差分一遍扫描更简洁。

**追问。**
- 为什么只看上升？：从左到右，覆盖到当前位置的操作数至少要有 `target[i]` 个；比前一个多出来的，必须是在这里新起头的。
- 减少操作（每次减 1，求变成全 0）的对称题？：答案相同。

**同模式。** LC 1094 拼车、LC 1109 航班预订统计、LC 3229 使数组等于目标数组所需的最少操作次数
