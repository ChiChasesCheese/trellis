## Q
**LC 237 删除链表中的节点**｜Easy

只给要删除的节点 `node`（不是尾节点），拿不到头节点，删除它。

## A
**一句话。** 删不掉自己就冒充后继：把后继的值复制过来，再跳过后继。

```python
def delete_node(node):
    nxt = node.next
    node.val, node.next = nxt.val, nxt.next
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 写 `node = node.next`：只改局部变量，链表没变。
- 只复制值不跳过后继：`[4,5,1,9]` 删 `5` 会变成 `[4,1,1,9]`。

**追问。**
- `node` 是尾节点怎么办？：没有后继可搬，只能从 `head` 找前驱，`O(n)`。
- 外部还持有后继的引用呢？：被跳过的是后继对象，外部引用指向已脱链节点，这个技巧不能用。

**同模式。** LC 203 移除链表元素、LC 19 删除链表的倒数第 N 个结点、LC 83 删除排序链表中的重复元素
