## Q
**LC 507 完美数**｜Easy

正整数 `num`（`<= 10^8`）若等于除自身外所有正因子之和，就是完美数。判断 `num` 是否完美数。

## A
**一句话。** 因子成对出现，`d` 与 `num / d`，只枚举 `d <= √num` 并把两个都加上，注意平方根只加一次、`num` 自身不算。

```python
def check_perfect_number(num):
    if num == 1:
        return False           # 1 没有真因子
    total, d = 1, 2            # 1 一定是真因子
    while d * d <= num:
        if num % d == 0:
            total += d
            if d != num // d:
                total += num // d  # 成对的另一个因子
        d += 1
    return total == num
```

**复杂度。** 时间 `O(√n)`，空间 `O(1)`。

**易错点。**
- 平方数的 `√num` 加两次：`d == num // d` 时只能加一次。
- `num = 1` 时返回 `True`：从 1 起累加会得到 `1 == 1`，要特判。

**追问。**
- 更快？：已知的偶完美数都是 `2^(p-1)·(2^p - 1)`（`2^p - 1` 为质数），`10^8` 以内只有 6、28、496、8128、33550336。
- 求 `1..n` 所有数的因子和？：埃氏筛的思路，对每个 `d` 给它的倍数加 `d`，`O(n log n)`。

**同模式。** LC 69 x 的平方根、LC 1952 三除数、LC 1390 四因数
