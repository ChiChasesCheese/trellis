## Q
**LC 931 下降路径最小和**｜Medium

`n × n` 的整数矩阵。下降路径从第一行任一元素出发，每步走到下一行的正下方、左下方或右下方，直到最后一行。求路径元素和的最小值。

## A
**一句话。** `f[i][j]` 是走到 `(i, j)` 的最小路径和，等于该格的值加上上一行相邻三格中的最小值。

```python
def min_falling_path_sum(matrix):
    n = len(matrix)
    f = [row[:] for row in matrix]    # f[i][j]：到 (i,j) 的最小和
    for i in range(1, n):
        for j in range(n):
            # 上一行的 j-1、j、j+1，切片自动处理边界
            f[i][j] += min(f[i - 1][max(j - 1, 0):j + 2])
    return min(f[-1])
```

**复杂度。** 时间 `O(n²)`，空间 `O(n²)`。

**易错点。**
- 切片左端写成 `j - 1`：`j = 0` 时变成 `-1`，会取到最后一列，必须用 `max(j - 1, 0)`。
- 返回 `f[n-1][0]`：终点可以在最后一行的任意一列，要取整行的最小值。

**追问。**
- 路径本身怎么还原？：同时记录每格的前驱列，从最后一行最小处回溯。
- 可以原地改输入吗？：可以，把 `f` 直接用 `matrix`，省下 `O(n²)` 空间。

**同模式。** LC 120 三角形最小路径和、LC 64 最小路径和
