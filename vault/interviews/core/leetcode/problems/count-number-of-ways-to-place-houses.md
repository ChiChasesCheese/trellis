## Q
**LC 2320 统计放置房子的方式数**｜Medium

街道两侧各有 `n` 个地块，编号 `1` 到 `n`。同一侧相邻地块不能都盖房，两侧互不影响，空着也算一种方案。求总方案数，对 `10^9 + 7` 取模。

## A
**一句话。** 两侧独立，只需算一侧的方案数 `f(n)`（相邻不能同选，即打家劫舍的计数版，`f` 是斐波那契），总数是 `f(n)²`。

```python
def count_house_placements(n):
    M = 10 ** 9 + 7
    a, b = 1, 2                 # f(0) = 1, f(1) = 2
    for _ in range(n - 1):
        a, b = b, (a + b) % M   # f(i) = f(i-1) + f(i-2)
    return b * b % M
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 把两侧当作一排 `2n` 个地块：两侧互不影响，是乘法而不是一条链。
- `f(1) = 2`：空着或盖房，不是 `1`。

**追问。**
- `n` 到 `10^18` 呢？：矩阵快速幂求斐波那契。

**同模式。** LC 198 打家劫舍、LC 213 打家劫舍 II、LC 740 删除并获得点数
