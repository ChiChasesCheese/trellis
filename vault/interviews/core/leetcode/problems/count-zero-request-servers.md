## Q
**LC 2747 统计没有收到请求的服务器数目**｜Medium

给你一个整数 `n`，表示服务器的总数目，再给你一个下标从 0 开始的二维整数数组 `logs`，其中 `logs[i] = [server_id, time]` 表示 id 为 `server_id` 的服务器在 `time` 时收到了一个请求。同时给你一个整数 `x` 和一个下标从 0 开始的整数数组 `queries`。请你返回一个长度等于 `queries.length` 的数组 `arr`，其中 `arr[i]` 表示在时间区间 `[queries[i] - x, queries[i]]` 内没有收到请求的服务器数目（闭区间）。

`1 <= n <= 10^5`，`1 <= logs.length <= 10^5`，`1 <= queries.length <= 10^5`，`logs[i].length == 2`，`1 <= logs[i][0] <= n`，`1 <= logs[i][1] <= 10^6`，`1 <= x <= 10^5`，`x < queries[i] <= 10^6`。

例：`n = 3, logs = [[1,3],[2,6],[1,5]], x = 5, queries = [10,11]` → `[1,2]`（`[5,10]` 内服务器 1、2 收到请求，只剩 3；`[6,11]` 内只有 2 收到请求）。`n = 3, logs = [[2,4],[2,1],[1,2],[3,1]], x = 2, queries = [3,4]` → `[0,1]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 离线查询（offline queries）+ 滑动窗口计数不同元素（按时间排序后双指针维护窗口内各服务器的请求数）。

**核心题。**

- LC 3 无重复字符的最长子串（Blind 75、Hot 100）：同一个「窗口 + 计数表」模型：这里窗口由排好序的查询推动而不是由条件推动

**一句话。** 日志按时间排序、查询按时间排序，两个指针维护时间落在 `[q - x, q]` 的日志窗口，用计数表维护窗口内「至少有一次请求的服务器数」`busy`，答案是 `n - busy`，按原下标写回。

**识别。** 很多查询、每个查询是一段等长的时间区间、问区间内「不同元素个数」：区间之间可以任意顺序回答，排序后左右端点都单调右移，就是滑动窗口。

**推导。** 每个查询扫一遍日志是 `O(q · m)`，`10^10` 超时。不同元素个数不能用前缀和相减（同一服务器在两段都出现会算错），但如果查询按时间递增，窗口的左右边界都只会往右走，每条日志恰好进出窗口各一次；计数表从 0 变 1 时 `busy` 加 1，从 1 变 0 时减 1，于是总共 `O(m + q)` 次移动。

```python
def count_servers(n: int, logs: list[list[int]], x: int, queries: list[int]) -> list[int]:
    logs = sorted(logs, key=lambda log: log[1])                    # 日志按时间排序
    order = sorted(range(len(queries)), key=lambda i: queries[i])  # 离线：按时间回答查询，记住原下标
    cnt = [0] * (n + 1)          # cnt[s]：服务器 s 在当前窗口内的请求数
    busy = 0                     # 窗口内至少收到一次请求的服务器数
    ans = [0] * len(queries)
    left = right = 0             # 窗口 = logs[left:right]，两个指针都只右移
    for i in order:
        q = queries[i]
        # 右端：时间 <= q 的日志进窗口
        while right < len(logs) and logs[right][1] <= q:
            s = logs[right][0]
            if cnt[s] == 0:
                busy += 1        # 0 -> 1：多一台忙的服务器
            cnt[s] += 1
            right += 1
        # 左端：时间 < q - x 的日志出窗口（闭区间，恰好等于 q - x 的要留下）
        while left < right and logs[left][1] < q - x:
            s = logs[left][0]
            cnt[s] -= 1
            if cnt[s] == 0:
                busy -= 1        # 1 -> 0：这台服务器在窗口里没有请求了
            left += 1
        ans[i] = n - busy        # 按原下标写回
    return ans
```

运行：例 1 → `[1, 2]`；例 2 → `[0, 1]`；例 1 把查询换成 `[11,10]` → `[2, 1]`。

**复杂度。** 时间 `O(m log m + q log q + n)`（`m` 条日志、`q` 个查询，排序为主，两指针共移动 `O(m)` 次），空间 `O(n + q)`。

**易错点。**
- 左端用 `<= q - x` 出窗口，把恰好在区间左端点的请求丢掉：例 2 得到 `[2, 2]`，正确是 `[0, 1]`。
- 按排序后的顺序直接 `append` 答案而不写回原下标：查询 `[11,10]` 得到 `[1, 2]`，正确是 `[2, 1]`。
- 用前缀和数「区间内的请求数」代替「不同服务器数」：同一台服务器的多次请求会被重复计数。

**同模式。** LC 1851 包含每个查询的最小区间、LC 1697 检查边长度限制的路径是否存在、LC 2070 每一个查询的最大美丽值、LC 438 找到字符串中所有字母异位词。
