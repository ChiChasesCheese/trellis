## Q
**环上棋子汇聚到一点的最少步数**｜Medium

环上有 `n` 个节点 `0 … n-1`，相邻距离 1，节点 `i` 上有 `cnt[i]` 枚棋子。选一个节点，把所有棋子沿环上最短路移过去，求总步数的最小值。

## A
**一句话。** 拆环成链复制三份，目标 `t` 取中间那份，左边 `n // 2` 个、右边其余节点各走直线；用「个数」和「个数 × 下标」两个前缀和 `O(1)` 算出每个 `t` 的代价。

```python
def min_gather_cost(cnt):
    n = len(cnt)
    a = cnt * 3               # 拆环：三份首尾相接，t 取中间
    P, Q = [0], [0]           # 个数、个数×下标 的前缀和
    for j, x in enumerate(a):
        P.append(P[-1] + x)
        Q.append(Q[-1] + x * j)
    h = n // 2                # 左边走 <= h 步，右边 <= n-1-h 步
    best = float("inf")
    for t in range(n, 2 * n):
        lo, hi = t - h, t + n - 1 - h    # 恰好 n 个节点
        left = t * (P[t + 1] - P[lo]) - (Q[t + 1] - Q[lo])
        right = (Q[hi + 1] - Q[t + 1]
                 - t * (P[hi + 1] - P[t + 1]))
        best = min(best, left + right)
    return best
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 左右各取 `n // 2` 个：`n` 为偶数时正对面的节点被算两次，右边只能取 `n - 1 - h` 个。
- 只复制一份：`t` 两侧的窗口会越出数组，要三份让 `t` 落在中间。

**追问。**
- 节点间距不等（周长 `L`）？：前缀和改用坐标，左右分界改成「顺时针距离 `<= L / 2`」，随 `t` 右移用双指针推分界。
- 要把棋子均分到每个节点？：环形均分纸牌：前缀差 `S_i` 取中位数作切口，答案是 `Σ|S_i - 中位数|`。

**同模式。** LC 2602 使数组元素全部相等的最少操作次数、LC 1685 有序数组中差绝对值之和、LC 462 最小操作次数使数组元素相等 II
