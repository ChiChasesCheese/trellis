## Q
**LC 541 反转字符串 II**｜Easy

对字符串 `s`，从头开始每 `2k` 个字符为一组，反转每组的前 `k` 个字符；若剩余不足 `k` 个则全部反转，剩余在 `k` 到 `2k` 之间则反转前 `k` 个。

## A
**一句话。** 步长 `2k` 遍历起点，每个起点反转 `[i, i+k)`，切片越界时自动取到末尾，不足 `k` 个就全部反转。

```python
def reverse_str(s, k):
    a = list(s)
    for i in range(0, len(a), 2 * k):    # 每 2k 一组
        a[i:i + k] = a[i:i + k][::-1]    # 反转前 k 个；越界自动截断
    return ''.join(a)
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 把每个 `k` 一组都反转：只反转每个 `2k` 窗口的前 `k` 个，后 `k` 个保持。
- 手动判断越界：Python 切片会自动截断，`a[i:i+k]` 到末尾时不会报错。
- 对不可变字符串原地修改：先转成列表。

**追问。**
- 原地做的版本？：双指针对 `[i, min(i+k, n)-1]` 交换，`O(1)` 额外空间（对字符数组）。
- 改成反转每组的后 `k` 个呢？：起点换成 `i + k`，其余相同。
