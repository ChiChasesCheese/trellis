## Q
**固定窗口排一次序使字典序最大**｜Medium

给数组 `a` 和窗口长 `k`（`k <= len(a)`），恰好选一个长为 `k` 的连续区间按降序重排一次，返回能得到的字典序最大的数组。

## A
**一句话。** 字典序只看第一个能变大的位置 `p`：它是第一个「右边 `k - 1` 格内有更大数」的下标，用单调栈求下一个更大元素找到它，再把从 `min(p, n - k)` 开始的窗口降序。

```python
def sort_window_once(a, k):
    n = len(a)
    nxt = [n] * n             # 右侧第一个更大元素的下标
    st = []
    for i in range(n - 1, -1, -1):
        while st and a[st[-1]] <= a[i]:
            st.pop()
        if st:
            nxt[i] = st[-1]
        st.append(i)
    for p in range(n):
        if nxt[p] - p < k:    # 窗口够得着更大的数
            s = min(p, n - k) # 越界就整体左移
            return (a[:s] + sorted(a[s:s + k], reverse=True)
                    + a[s + k:])
    return a[:]               # 每个窗口本来就是降序
```

**复杂度。** 时间 `O(n + k log k)`，空间 `O(n)`。

**易错点。**
- 弹栈条件写成 `<`：相等的数被当成「更大」，`[2, 2, 1, 3]`、`k = 2` 会在下标 0 排一个不变的窗口就返回，应得 `[2, 2, 3, 1]`。
- 窗口直接从 `p` 开始：`p > n - k` 时越界，要用 `n - k` 开头的窗口，它在 `p` 之前的数已是降序，排完不变。

**追问。**
- 为什么从 `p` 开始的窗口最好？：所有窗口最早变化的位置都不早于 `p`；从 `p` 开始的窗口覆盖的后续数最多，降序后不比任何别的窗口差。
- 必须按升序排、求字典序最小？：对称，找第一个右边 `k - 1` 格内有更小数的位置。

**同模式。** LC 739 每日温度、LC 496 下一个更大元素 I、LC 670 最大交换、LC 1053 交换一次的先前排列
