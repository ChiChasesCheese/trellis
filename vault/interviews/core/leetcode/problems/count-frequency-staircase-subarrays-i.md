## Q
**LC 4094 统计频次阶梯子数组的数目 I**｜Medium

给你一个整数数组 `nums`。把一个子数组中的所有不同值按**首次出现的顺序**排列；若其中有 `k` 个不同值，且第一个不同值恰好出现 `1` 次，第二个恰好出现 `2` 次，……，第 `k` 个恰好出现 `k` 次，则称该子数组为「频次阶梯」。返回 `nums` 中频次阶梯子数组的数量（子数组是连续且非空的一段）。`1 <= nums.length <= 1500`，`1 <= nums[i] <= 10^5`。例：`nums = [5,8,8,2,2,2]` → `9`（6 个单元素，加 `[5,8,8]`、`[8,2,2]` 和整个数组）；`nums = [6,6,9,9]` → `5`（4 个单元素，加 `[6,9,9]`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 枚举左端点 + 向右扩展时增量维护判定条件（`O(n^2)` 子数组计数）。

**核心题。**

- LC 560 和为 K 的子数组（Hot 100）：同样数满足条件的子数组：这里是它的暴力版固定左端点后向右增量维护状态

**一句话。** 固定左端点向右扩展，用「名次」给不同值编号（首次出现的先后），维护「当前计数恰好等于 名次+1 的名次个数 `good`」，每步 `O(1)` 更新，`good` 等于不同值个数就是频次阶梯。

**识别。** `n <= 1500` 直接指向 `O(n^2)`；条件依赖「首次出现的顺序」，而这个顺序只由左端点和已读元素决定，向右扩展时不会改变，所以按左端点分组是自然的。

**推导。** 每个子数组单独检查是 `O(n^3)`。固定左端点 `l` 后扩展右端点 `r`，新加入的元素 `x` 只改变它自己名次 `k` 的计数（新值则新开一个名次），其他名次的状态不变，所以只需要在这一个名次上更新「是否满足」。不能在第一次不满足时退出：`[5,8]` 不满足，`[5,8,8]` 又满足。

```python
def count_staircase_subarrays(nums: list[int]) -> int:
    n = len(nums)
    ans = 0
    for left in range(n):
        rank: dict[int, int] = {}      # 值 -> 首次出现的名次（从 0 数）
        cnt: list[int] = []            # cnt[k]：名次 k 的值在 nums[left..right] 中出现的次数
        good = 0                       # 满足 cnt[k] == k + 1 的名次个数
        for x in nums[left:]:
            if x not in rank:
                rank[x] = len(cnt)     # 新值排在最后，名次 = 目前不同值的个数
                cnt.append(0)
            k = rank[x]
            if cnt[k] == k + 1:
                good -= 1              # 先撤销旧状态，再加 1 后重新判断
            cnt[k] += 1
            if cnt[k] == k + 1:
                good += 1
            if good == len(cnt):       # 每个名次都恰好是 名次+1 次：频次阶梯
                ans += 1
    return ans
```

运行：`[5,8,8,2,2,2]` → `9`；`[6,6,9,9]` → `5`；`[2,3,4,4,3,4]` → `8`；`[7]` → `1`。

**复杂度。** 时间 `O(n^2)`（`n = 1500` 时约 `10^6` 次更新），空间 `O(n)`。

**易错点。**
- 一旦不满足就 `break`：`[5,8,8,2,2,2]` 得到 `6`，正确是 `9`，因为后续元素能把不满足补成满足。
- 只检查频次的多重集合等于 `{1..k}`，不检查顺序：`[6,6,9]` 的整段频次是 `{2, 1}`，得到 `4`，正确是 `3`（先出现的 `6` 必须只出现 `1` 次）。
- 名次按值的大小排而不是首次出现的先后，名次与计数错位。

**同模式。** LC 992 K 个不同整数的子数组、LC 1248 统计优美子数组、LC 2537 统计好子数组的数目、LC 2262 字符串的总引力。
