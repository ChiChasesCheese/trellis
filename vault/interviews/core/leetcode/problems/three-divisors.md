## Q
**LC 1952 三除数**｜Easy

给整数 `n`（`<= 10^4`），判断它是否恰好有三个正因数。

## A
**一句话。** 因数成对出现（`d` 与 `n/d`），个数是奇数当且仅当 `n` 是完全平方；恰好三个时只能是 `1, p, p²`，所以 `n` 是质数的平方。

```python
def is_three(n):
    r = int(n ** 0.5)
    if r * r != n or r < 2:          # 必须是完全平方，且根不是 1
        return False
    # 根 r 必须是质数，否则 r 的因数还会带来更多 n 的因数
    return all(r % d for d in range(2, int(r ** 0.5) + 1))
```

**复杂度。** 时间 `O(n^{1/4})`，空间 `O(1)`。

**易错点。**
- 只判断完全平方：`36 = 6²` 有九个因数，根还要是质数。
- 漏掉 `n = 1`：`r = 1` 时只有一个因数，必须排除。

**追问。**
- 恰有 `k` 个因数的数怎么判断？：按质因数分解 `n = p1^a1·p2^a2…`，因数个数是 `(a1+1)(a2+1)…`，等于 `k` 就行。
- 能不做开方吗？：直接试除到 `√n`，数因数个数，`O(√n)`。

**同模式。** LC 507 完美数、LC 1390 四因数、LC 204 计数质数
