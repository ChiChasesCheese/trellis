## Q
**LC 1944 队列中可以看到的人数**｜Hard

人们从左到右排队，身高互不相同。一个人能看到右边某人，当且仅当两人之间的人都比两人矮。求每个人在右侧能看到的人数。

## A
**一句话。** 从右往左扫单调栈（自底向上递减）：弹出的每个矮人都看得到，栈里剩下的第一个更高的人也看得到。

```python
def can_see_persons_count(heights):
    n = len(heights)
    ans = [0] * n
    st = []                        # 高度自底向上递减
    for i in range(n - 1, -1, -1):
        h = heights[i]
        while st and st[-1] < h:
            st.pop()               # 比我矮：看得到，之后被我挡住
            ans[i] += 1
        if st:
            ans[i] += 1            # 第一个比我高的也看得到
        st.append(h)
    return ans
```

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**易错点。**
- 漏掉栈里第一个更高的人：`[10,6,8,5,11,9]` 得 `[2,0,1,0,1,0]`，应为 `[3,1,2,1,1,0]`。
- 从左往右扫：栈里变成左边的人，算的是左侧可见人数。

**追问。**
- 身高有重复怎么改？：弹出条件改成「不高于」才挡，规则落在弹栈判断里。
- 为什么是 `O(n)`？：每个人只入栈、出栈一次。
