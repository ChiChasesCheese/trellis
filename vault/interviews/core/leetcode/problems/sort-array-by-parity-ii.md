## Q
**LC 922 按奇偶排序数组 II**｜Easy

整数数组一半是偶数、一半是奇数。重排使得下标为偶数的位置放偶数，下标为奇数的位置放奇数，返回任意一种。

## A
**一句话。** 双指针原地交换：一个指针扫偶数下标，遇到放了奇数的，就去奇数下标里找放了偶数的，两者互换。

```python
def sort_array_by_parity_ii(nums):
    j = 1                              # 扫奇数下标
    for i in range(0, len(nums), 2):   # 扫偶数下标
        if nums[i] % 2:                # 偶数位上是奇数
            while nums[j] % 2:         # 找奇数位上的偶数
                j += 2
            nums[i], nums[j] = nums[j], nums[i]
    return nums
```

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- `j` 每次都从 `1` 开始：`O(n²)`，`j` 只增不减，整体只走一遍。
- 步长写成 `+1`：下标奇偶性会乱，两个指针都要 `+2`。
- 新开两个数组再合并：能过但不是原地，面试常问空间。

**追问。**
- 为什么 `j` 一定找得到？：奇数个数等于偶数个数，偶数位有几个奇数，奇数位就恰有几个偶数。
- 要保持原有相对顺序呢？：先分出奇偶两个列表，再按奇偶下标交叉放入，用 `O(n)` 额外空间。
