## Q
**LC 738 单调递增的数字**｜Medium

当且仅当相邻数位满足 `x ≤ y` 时，一个整数是单调递增的。给整数 `n`，返回小于或等于 `n` 的最大的单调递增整数。

## A
**一句话。** 从右往左找第一处下降 `d[i-1] > d[i]`，把 `d[i-1]` 减 1，其右边全部变成 `9`；多处下降时从右往左连续处理，取最靠左的位置。

```python
def monotone_increasing_digits(n):
    d = list(str(n))
    mark = len(d)                     # 从 mark 起全变 9
    for i in range(len(d) - 1, 0, -1):
        if d[i - 1] > d[i]:
            d[i - 1] = str(int(d[i - 1]) - 1)   # 前一位退一
            mark = i                  # 右边都补 9
    for i in range(mark, len(d)):
        d[i] = '9'
    return int(''.join(d))
```

**复杂度。** 时间 `O(log n)`，空间 `O(log n)`。

**易错点。**
- 只处理一次下降：`332` 退位后变成 `322`，仍然下降，必须继续向左检查，所以是从右往左一路扫。
- 把 `9` 补到错误的位置：要补到最靠左的下降处的右边，用 `mark` 记最后一次出现的位置。
- 先转整数再减：要在数位上操作，退位后还要保证左边不变。

**追问。**
- 为什么右边补 `9` 最优？：在已确定高位的前提下，剩下的位越大越好，且 `9` 总满足递增。
- 从左往右能做吗？：能，但需要回退，从右往左一次扫描更简单。

**同模式。** LC 670 最大交换、LC 556 下一个更大元素 III、LC 402 移掉 K 位数字、LC 1081 不同字符的最小子序列
