## Q
**LC 836 矩形重叠**｜Easy

矩形用 `[x1, y1, x2, y2]` 表示（左下角、右上角，边平行于坐标轴）。两个矩形的交集面积为正才算重叠，只在边或角相接不算。判断是否重叠。

## A
**一句话。** 重叠等价于在 `x` 轴和 `y` 轴上的投影区间都严格相交：一个的左边界小于另一个的右边界，反过来也成立。

```python
def is_rectangle_overlap(rec1, rec2):
    x_cross = rec1[0] < rec2[2] and rec2[0] < rec1[2]
    y_cross = rec1[1] < rec2[3] and rec2[1] < rec1[3]
    return x_cross and y_cross   # 两个方向的投影都严格相交
```

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**易错点。**
- 用 `<=`：边或角相接时面积为 0，必须用严格不等号。
- 只比较一个方向：两个方向都相交才算重叠。

**追问。**
- 为什么先想「不重叠」更简单？：不重叠就是一个在另一个的左、右、上、下，四种情形取反即得上式。
- 要算交集面积？：`max(0, min(x2, x2') - max(x1, x1')) × max(0, min(y2, y2') - max(y1, y1'))`。

**同模式。** LC 223 矩形面积、LC 1232 缀点成线、LC 593 有效的正方形
