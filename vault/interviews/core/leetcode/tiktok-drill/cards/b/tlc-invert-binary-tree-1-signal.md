## Q
**LC 226 翻转二叉树**｜Easy · CodeTop 国内累计 26 次 · 最近 2026-03-29（CodeTop）

给二叉树的根节点 `root`，把整棵树左右镜像翻转，返回根节点。节点数在 `[0, 100]`，`-100 <= Node.val <= 100`。例：`[4,2,7,1,3,6,9]` → `[4,7,2,9,6,3,1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「对整棵树的每个节点做同一件事」→ 树的遍历 + 局部操作；子问题和原问题同形，用递归（DFS，深度优先）最自然。
- 返回的是**同一棵树的根**，要求原地改指针 → 交换 `left` / `right`，不是新建树。
- `n <= 100`：深度至多 `100`，递归安全，不用担心 Python 的递归上限。

**推导链。**
1. 暴力：先把树按层序读出来，每层反转，再重建一棵新树。要额外存储，还要写建树。
2. 浪费：镜像其实只是每个节点把两个孩子对调，树的形状信息不需要拆开再重装。
3. 洞察：翻转 = 对每个节点交换左右指针；顺序不重要——先序、后序、层序都行，因为各节点的交换互不依赖。
4. 递归写法：翻转左右子树后再换位，空树返回 `None`；每个节点访问一次，`O(n)`。
