## Q
**LC 2845 统计趣味子数组的数目**｜正确性

为什么查询的键是 `(pre - k) % modulo`？为什么哈希表里要先放一个空前缀 `{0: 1}`？把条件写成 `cnt == k`（不取模）会在哪个输入上出错？

## A
**不变量。** 处理完第 `i` 个元素后，`pre` 是前 `i` 个元素中被标记元素个数对 `modulo` 的余数；`seen` 里记录了前缀长度 `0..i-1` 各自对应的余数出现了多少次。

**为什么键是 `(pre - k) % modulo`。** 子数组 `(l, r]` 的标记个数 `cnt = P[r] - P[l]`（`P` 是未取模的前缀和）。要求 `cnt % modulo == k`，也就是 `(P[r] - P[l]) ≡ k (mod modulo)`，即 `P[l] ≡ P[r] - k (mod modulo)`。哈希表里存的是 `P[l] % modulo`，所以查询 `(pre - k) % modulo`。

**为什么有空前缀。** 从下标 `0` 开始的子数组对应 `l = 0`，前缀和为 `0`。不放 `{0: 1}`，这类子数组永远查不到。

**反例一：没有空前缀。** `nums = [3,2,4]`，`modulo = 2`，`k = 1`：三个趣味子数组都从下标 `0` 开始，去掉 `{0: 1}` 之后一个都统计不到，得到 `0`，正确是 `3`。

**反例二：条件写成 `cnt == k`。** 只统计 `cnt` 恰好等于 `k` 的子数组：`nums = [1,1,1]`，`modulo = 2`，`k = 1`：
- 三个元素都被标记。长度 `1` 的子数组 `cnt = 1`，共 `3` 个；长度 `3` 的子数组 `cnt = 3`，`3 % 2 == 1` 也满足。
- `cnt == k` 的写法只算到 `3` 个，漏掉整体；正确是 `4`。

**反例三：`(pre - k)` 不取模。** `[1,1,1]`，`modulo = 2`，`k = 1`：`pre = 0` 时查 `-1`，没有这个键，同样漏算，得到 `3`。
