## Q
**LC 113 路径总和 II**｜Medium · CodeTop 国内累计 42 次 · 最近 2026-07-24（CodeTop）

给二叉树的根节点 `root` 和整数 `targetSum`，找出所有从根节点到叶子节点、路径上节点值之和等于 `targetSum` 的路径，以节点值列表的形式返回（叶子是没有子节点的节点）。

约束：节点数在 `[0, 5000]`，`-1000 <= Node.val <= 1000`，`-1000 <= targetSum <= 1000`。例：`root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22` → `[[5,4,11,2],[5,8,4,5]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「根到叶的**所有**路径」→ 要列举，不是求一个值 → DFS + 回溯：共享一条当前路径，进入节点 `append`，离开 `pop`。
- 「叶子」→ 终止条件是左右孩子都为空，命中时才检查和。
- 节点值可为负 → 不能因「和已超过目标」提前剪枝。
- 递归最直观；节点数 `5000`，链状树深度 5000 → 超出 CPython 默认约 1000 层的递归上限，需要提高上限或改显式栈。

**推导链。**
1. 暴力：先生成所有根到叶路径，再对每条求和，`O(n·h)`。
2. 浪费：相邻路径共享前缀，每次重新求和是重复劳动。
3. 洞察：DFS 时带着 `rest = 目标 - 路径和`，叶子处只要判断 `rest == 0`；命中时拷贝 `path[:]`。
4. 最优：递归 DFS，函数头 `append`、返回前 `pop` 完成回溯，`O(n)` 遍历加命中路径的拷贝；显式栈版本用 `None` 退出标记驱动回溯。

**同模式的题**：LC 112 路径总和、LC 257 二叉树的所有路径、LC 437 路径总和 III、LC 129 求根到叶子节点数字之和。
