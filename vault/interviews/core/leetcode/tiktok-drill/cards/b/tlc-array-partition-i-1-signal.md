## Q
**LC 561 数组拆分 I**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-04-15（CodeTop）

给长度为 `2n` 的整数数组 `nums`，把它分成 `n` 对 `(a_1, b_1), …, (a_n, b_n)`，使 `min(a_1, b_1) + … + min(a_n, b_n)` 最大，返回这个最大和。`1 <= n <= 10^4`，`nums.length == 2n`，`-10^4 <= nums[i] <= 10^4`。例：`[1,4,3,2]` → `4`（`(1,2), (3,4)`），`[6,2,6,5,1,2]` → `9`（`(1,2), (2,5), (6,6)`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「把元素两两配对」+「最大化每对 `min` 之和」→ **排序 + 贪心配对**，用交换论证确定规则。
- 「每对只算较小者」→ 较大者被浪费，目标等价于「让被浪费的总量最小」。
- `2n <= 2·10^4` → `O(n log n)` 排序足够；值域只有 `[-10^4, 10^4]`，还能计数排序到 `O(n)`。

**推导链。**
1. 暴力：枚举所有配对方式，`(2n - 1)!! = (2n-1)(2n-3)…1` 种，指数级。
2. 浪费：大量配对方式显然不优，例如把最小的数配给最大的数，等于白白浪费最大值。
3. 洞察：最小的 `x_1` 无论配谁都只贡献 `x_1`，配给第二小的 `x_2` 浪费最少；把 `x_1` 原来的伙伴和 `x_2` 交换，总和不会变小。
4. 最优：排序后相邻配对，答案是偶数下标元素之和，`O(n log n)`。

**同模式的题**：LC 881 救生艇、LC 1877 数组中最大数对和的最小值、LC 455 分发饼干。
