## Q
**LC 114 二叉树展开为链表**｜Medium · CodeTop 国内累计 26 次 · 最近 2026-06-14（CodeTop）

给二叉树的根节点 `root`，原地把它展开成单链表：仍用 `TreeNode`，`right` 指向下一个节点，`left` 始终为 `null`，顺序与先序遍历相同。节点数在 `[0, 2000]`，`-100 <= Node.val <= 100`。进阶：`O(1)` 额外空间。例：`[1,2,5,3,4,null,6]` → `[1,null,2,null,3,null,4,null,5,null,6]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「展开成先序顺序的链表」→ 先序遍历（根、左、右）；链表的下一个节点就是先序的下一个节点。
- 「原地」→ 不新建节点，在原树上改指针；不需要先把节点收进列表，子树自己就能展开成链。
- 子树展开后仍是先序，整棵树只需在根处把「左链、右链」按顺序接起来 → 树形递归（分治）。
- 进阶「`O(1)` 额外空间」→ 沿树本身移动指针（Morris 遍历的思路），放到追问；`n <= 2000`：递归深度可达 `2000`，超过 Python 默认递归上限 `1000`，要留意。

**推导链。**
1. 暴力：先序遍历收集所有节点到列表，再依次 `nodes[i].right = nodes[i + 1]`、`left = None`，`O(n)` 时间、`O(n)` 空间。
2. 浪费：额外列表只是为了记住顺序，而顺序其实藏在树的结构里：左子树整体排在右子树前面。
3. 洞察：假设左、右子树都已经展开成链，整棵树的先序 = 根 + 左链 + 右链：把原右子树挂到左链的尾，再把左链搬到 `node.right`，`node.left` 置空。
4. 让递归返回链尾，拼接是 `O(1)`，整体 `O(n)` 时间，`O(h)` 递归栈；要 `O(1)` 空间时改成沿右链走的迭代版。
