## Q
**LC 523 连续的子数组和**｜正确性

LC 523 的字典为什么只记录每个余数第一次出现的下标，而不是每次都更新？给出一个每次更新就会出错的输入。

## A
**不变量。** 扫描到 `i` 时，字典里每个余数对应的是它**最早**出现的前缀下标。对当前余数，最早的下标给出最长的候选子数组，最有机会满足「长度 `>= 2`」。

**为什么不更新。** 同一个余数每次都覆盖成最新下标，等于总拿最近的前缀去配对，距离永远最短，会把本可以满足长度要求的配对丢掉。

**反例。** `nums = [5,0,0]`，`k = 7`：前缀余数依次为 `5, 5, 5`。
- 正确做法：`first_seen[5] = 0`；到 `i = 2` 时，`2 - 0 = 2 >= 2`，返回 `true`（子数组 `[0,0]`，和为 0）。
- 每次覆盖：`i = 1` 时 `1 - 0 = 1` 不够，把 5 的下标改成 1；`i = 2` 时 `2 - 1 = 1` 仍不够，最终返回 `false`。

另外 `{0: -1}` 的初值同样重要：它代表空前缀，缺了它，`[2,4]`、`k = 6` 会得到 `false`。
