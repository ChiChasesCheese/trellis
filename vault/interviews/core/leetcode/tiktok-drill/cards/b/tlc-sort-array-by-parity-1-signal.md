## Q
**LC 905 按奇偶排序数组**｜Easy · CodeTop 国内累计 4 次 · 最近 2026-03-02（CodeTop）

给整数数组 `nums`，把所有偶数移到前面、奇数放在后面，返回满足条件的任一数组。`1 <= nums.length <= 5000`，`0 <= nums[i] <= 5000`。例：`[3,1,2,4]` → `[2,4,3,1]`（`[4,2,1,3]` 等也对）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按一个是 / 否条件把元素分到两边」→ **分区**（partition），快速排序的那一步，不需要真正排序。
- 「返回任一数组」→ 不要求稳定，可以随意交换 → **对撞双指针**原地交换。
- `n <= 5000` 任何解法都能过；面试考点是 `O(n)` 时间、`O(1)` 额外空间。

**推导链。**
1. 暴力：按 `x % 2` 排序，`O(n log n)`；或开两个列表收集再拼接，`O(n)` 时间、`O(n)` 空间。
2. 浪费：排序比较了不必比较的顺序；两个列表多用了一份内存。
3. 关键：从两端往中间扫，左边的偶数、右边的奇数已经在对的一侧，只有「左奇右偶」这一对放错，一次交换让两个都归位。
4. 最优：`left` 左边全偶、`right` 右边全奇，相遇即结束，`O(n)`、`O(1)`。
