## Q
**LC 3441 变成好标题的最少代价**｜Hard · LC TikTok 热度 62/100

字符串 `caption`，每个字符都位于连续出现至少 3 次的一组里才算好标题。每次操作把一个位置的字符改成前一个或后一个字母（`'a'` 不能再往前，`'z'` 不能再往后）。求变成好标题的最少操作次数；最优结果有多个时返回字典序最小的；做不到返回 `""`。

约束：`1 <= caption.length <= 5 * 10^4`，只含小写字母。例：`"cdcd"` → `"cccc"`；`"aca"` → `"aaa"`；`"bc"` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「改成相邻字母、每次一步」→ 把一个位置改成字母 `x` 的代价是字母差 `|caption[i] - x|`，总代价逐位相加，可以用 DP 按位累计。
- 「每个字符在长度 `>= 3` 的连续组里」→ 约束只依赖上一位的字母和当前连续长度，状态记 `min(长度, 3)`，即 `1`、`2`、`>= 3` 三档。
- 「最少代价，并列取字典序最小」→ 两步法：先反向 DP 算出每个状态的最小补完代价，再正向逐位贪心重建；前缀唯一决定状态，贪心无需回溯。
- `n = 5 * 10^4`、26 个字母 → 每位 `26 * 3` 个状态，`O(26n)`。

**推导链。**
1. 暴力：枚举所有好标题，取代价最小再取字典序最小，`26^n`。
2. 浪费：约束只看上一位和连续长度，前面的细节没用；设 `h[i][c][r]` 为补完右边的最小代价。
3. 洞察：换字母要求上一段长度已达 3，且新字母必须不同；在 25 个字母里取最小用「最小和次小」摊成 `O(1)`。
4. 最优：反向 DP 得 `h`，正向对每一位从 `'a'` 到 `'z'` 试，第一个使「已花 + 本位 + `h` = 全局最小」的字母就是答案的那一位，`O(26n)`。

**同模式的题**：LC 1473 粉刷房子 III、LC 2478 完美分割的方案数、LC 1220 统计元音字母序列的数目。
