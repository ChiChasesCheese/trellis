## Q
**LC 229 求众数 II**｜Medium · CodeTop 国内累计 1 次 · 最近 2025-12-22（国内 CodeTop）

给大小为 `n` 的整数数组 `nums`，找出其中所有出现次数**超过** `⌊n / 3⌋` 的元素（顺序任意）。`1 <= n <= 5 * 10^4`，`-10^9 <= nums[i] <= 10^9`。进阶：时间 `O(n)`、空间 `O(1)`。例：`[3,2,3]` → `[3]`，`[1]` → `[1]`，`[1,2]` → `[1,2]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「出现次数超过某个阈值」→ **哈希计数**（`Counter`），一遍数完。
- 「超过 `⌊n / 3⌋`」→ 鸽巢原理：至多 2 个答案。这条结论让 `O(1)` 空间成为可能。
- 「进阶 `O(1)` 空间」→ 不能存所有值的次数，只能存常数个候选 → **摩尔投票**的两候选版本。
- `n <= 5 * 10^4` → `O(n^2)` 约 `2.5 * 10^9`，不行。

**推导链。**
1. 暴力：对每个元素再扫一遍数次数，`O(n^2)`。
2. 浪费：同一个值被反复数。
3. 主解：一遍 `Counter`，留下次数 `> n // 3` 的，`O(n)` 时间、`O(n)` 空间。
4. 进阶：答案至多 2 个，只维护 2 个候选及计数；遇到第三个不同的数就三者各减一次（抵消）。超过 `n / 3` 的值抵消不完，必留在候选里；最后再数一遍确认。

**同模式的题**：LC 169 多数元素、LC 347 前 K 个高频元素、LC 1150 检查一个数是否在数组中占绝大多数。
