## Q
**LC 617 合并二叉树**｜Easy · CodeTop 国内累计 7 次 · 最近 2025-10-29（CodeTop）

给两棵二叉树 `root1` 和 `root2`。把其中一棵盖到另一棵上，重叠的节点值相加，只在一棵树里存在的节点原样保留；合并必须从两棵树的根节点开始，返回合并后的二叉树。两棵树的节点数都在 `[0, 2000]`，`-10^4 <= Node.val <= 10^4`。例：`root1 = [1,3,2,5]`，`root2 = [2,1,3,null,4,null,7]` → `[3,4,5,5,4,null,7]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两棵树按位置一一对应」→ **同步遍历**（parallel traversal）：两个指针同时走，对应节点配对处理，同类有 LC 100、LC 101。
- 「一棵树里有、另一棵没有的节点原样保留」→ 遇到一边为空，**整棵子树直接复用**，不必再往下走。
- 节点数最多 `2000`，树可能退化成一条链 → 递归深度可达 2000，超过 Python 默认 1000；写递归要想到这一点，调高递归上限或改显式栈。

**推导链。**
1. 朴素：把两棵树展开成数组再按下标相加。树形不规则，下标对不上，这条路走不通。
2. 递归：`merge(a, b)`，一边为空返回另一边，否则值相加并递归合并左右孩子；每个重叠节点访问一次。
3. 浪费与风险：只有一边存在的子树无需再遍历，递归入口返回即可；而递归栈深度等于树高，2000 层的链会 `RecursionError`。
4. 最优：就是这个递归，`O(min(n1, n2))`；树很深时改成显式栈存「一对对应节点」，只有两边孩子都存在才入栈，否则直接挂接。

**同模式的题**：LC 100 相同的树、LC 101 对称二叉树、LC 226 翻转二叉树、LC 572 另一棵树的子树。
