## Q
**LC 260 只出现一次的数字 III**｜Medium · CodeTop 国内累计 7 次 · 最近 2022-08-08（CodeTop）

整数数组 `nums` 里恰好有两个元素只出现一次，其余都出现两次，找出这两个，顺序任意，线性时间、常数额外空间。`2 <= nums.length <= 3 * 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。例：`[1,2,1,3,2,5]` → `[3,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「其余成对」→ 异或抵消，同 LC 136。
- 「落单的有**两个**」→ 全部异或只能得到 `a ^ b`，一个等式分不出两个数，要**把数组拆成两个子问题**，每个子问题只含一个落单数。
- 「线性时间 + 常数空间」→ 不能用哈希表；`n` 在 `3 * 10^4` 只是说明逐个扫描即可。

**推导链。**
1. 暴力：`Counter` 数次数，`O(n)` 时间 `O(n)` 空间，违反空间。
2. 全部异或得 `x = a ^ b`，`a != b` 所以 `x != 0`。
3. `x` 的某一位是 1 → `a`、`b` 在这位不同。按这一位把所有数分两组：`a`、`b` 必进不同组；成对的相同数每位都相同，必进同一组。
4. 每组 = 一个落单数 + 若干对 → 各自异或就是 LC 136。最低位的 1 用 `x & -x` 取。

**同模式的题**：LC 136 只出现一次的数字、LC 137 只出现一次的数字 II、LC 268 丢失的数字。
