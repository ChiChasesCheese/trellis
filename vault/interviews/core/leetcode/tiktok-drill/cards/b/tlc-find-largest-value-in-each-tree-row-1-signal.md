## Q
**LC 515 在每个树行中找最大值**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-06-21（CodeTop）

给二叉树的根 `root`，返回每一层节点值的最大值（从上到下）。节点数在 `[0, 10^4]` 内，`-2^31 <= Node.val <= 2^31 - 1`。例：`[1,3,2,5,3,null,9]` → `[1,3,9]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每一层 / 每一行」→ **层序遍历**（BFS 按层），或 DFS 带深度参数。
- 值域是完整的 32 位整数、包含负数 → 每层的初始最大值不能是 `0`，直接对整层取 `max`。
- 节点数 `10^4` → 链状树深度 `10^4`，超过 Python 默认递归上限约 `1000` → 迭代。

**推导链。**
1. 暴力：先求树高 `h`，再对每个深度 `d` 从根往下收集第 `d` 层，`O(nh)`，链状树是 `O(n^2)`。
2. 浪费：每一层都从根重新走一遍。
3. 关键：第 `d+1` 层恰好是第 `d` 层节点的全部孩子，所以手里拿着一层就能直接生成下一层。
4. 最优：用列表保存「当前层」，取 `max` 后用列表推导生成下一层，每个节点只处理一次，`O(n)`。
