## Q
**LC 129 求根到叶子节点数字之和**｜正确性

求根到叶子数字之和的 DFS 里，叶子必须写成「左右孩子都为空」。如果写成「到空节点才返回 `acc`」，或写成「任一孩子为空就返回」，各会得到什么错误结果？

## A
**不变量。** 调用 `dfs(node, acc)` 时，`acc` 是从根到 `node` 的父节点所形成的数；返回值是以 `node` 为根的子树中，所有根到叶子路径的数之和（数的前缀是 `acc`）。每条根到叶子的路径恰好在它的叶子处被计一次。

**错误写法一：到空节点才返回。** 写成 `if node is None: return acc`，没有叶子判断。树 `[1,2]`（根 `1` 只有左孩子 `2`）：
- 正确：唯一的叶子是 `2`，路径 `12`，答案 `12`。
- 错误：走到 `2` 的两个空孩子各返回 `12`，再加上根 `1` 的空右孩子返回的 `1`，得到 `25`。一个叶子被算了两次，一个非叶子的缺口被算成了路径。

**错误写法二：任一孩子为空就当叶子。** 写成 `if node.left is None or node.right is None: return acc`：
- 同样的树 `[1,2]`，根只有一个孩子，被误判为叶子，直接返回 `1`，答案错成 `1`，正确是 `12`。

**结论。** 只有「左右孩子都为空」的节点是路径终点；只有一个孩子的节点必须继续向存在的那一侧走，另一侧是空节点，由递归函数最前面的 `if node is None: return 0` 贡献 `0`。
