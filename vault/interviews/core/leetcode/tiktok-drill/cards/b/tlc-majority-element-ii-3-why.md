## Q
**LC 229 求众数 II**｜正确性

为什么出现次数超过 `⌊n / 3⌋` 的元素至多有 2 个？比较时用 `>` 还是 `>=`，用 `n // 3` 还是 `n / 3`？给出用错比较符会出错的输入。

## A
**至多 2 个（鸽巢原理）。** 次数是整数，`c > ⌊n / 3⌋` 等价于 `c >= ⌊n / 3⌋ + 1 > n / 3`。若有 3 个不同的值都满足，它们的次数之和 `> 3 · (n / 3) = n`，超过数组长度，矛盾。所以至多 2 个。

**比较的写法。**
- 必须严格大于：题目是「超过」。
- `c > n // 3` 与 `c > n / 3` 对整数 `c` 等价：`c > n / 3` 时 `c > ⌊n / 3⌋` 显然；反过来 `c >= ⌊n / 3⌋ + 1`，而 `⌊n / 3⌋ + 1 > n / 3`。用整数除法可以避开浮点。

**反例：用 `>=`。** `[1,2,3]`，`n // 3 = 1`，每个值都出现 1 次。
- `>=` 返回 `[1, 2, 3]`：3 个答案，直接违反上面的「至多 2 个」。
- 正确答案 `[]`：没有值出现超过 1 次。

「至多 `k - 1` 个」也是进阶摩尔投票只需 2 个候选的原因：超过 `n / 3` 的值每被抵消一次，都要消耗另外两个不同的值，次数撑不到被抵消完。
