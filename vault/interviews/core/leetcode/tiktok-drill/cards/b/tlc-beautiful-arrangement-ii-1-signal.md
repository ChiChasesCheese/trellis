## Q
**LC 667 优美的排列 II**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 2 次 · 最近 2026-04（国内面试记录）

给整数 `n`、`k`，构造一个由 `1` 到 `n` 共 `n` 个不同正整数组成的列表，使相邻元素差的绝对值中**恰好有 `k` 个不同的整数**，返回任意一个即可。`1 <= k < n <= 10^4`。例：`n = 3`，`k = 2` → `[1,3,2]`（差为 `2`、`1`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「构造一个满足条件的排列」且「任意一个都行」→ **构造题**：不搜索，找一个规律模板。
- 约束是「差值的种类数恰好为 `k`」→ 先看两个极端：`k = 1` 是递增排列，`k = n - 1` 是 `1, n, 2, n-1, ...` 的头尾交替；模板就在这里。
- `n` 到 `10^4`，`n!` 枚举不可行，要求 `O(n)` 的直接构造。

**推导链。**
1. 暴力：枚举全部排列，逐个检查差的种类数，`O(n! * n)`。
2. 观察：递增接上去只产生差 `1`；想增加新的差，必须「跳」。
3. 头尾交替：在 `[1, k+1]` 里取 `1, k+1, 2, k, ...`，相邻差依次是 `k, k-1, ..., 1`，用 `k + 1` 个数恰好得到 `k` 个不同的差。
4. 剩下的数 `k+2..n` 递增接在后面，只产生差 `1` 以及一个介于 `1` 和 `k` 之间的接缝差，种类数不变，总共 `O(n)`。

**同模式的题**：LC 526 优美的排列、LC 932 漂亮数组、LC 31 下一个排列、LC 667 的各种构造变体。
