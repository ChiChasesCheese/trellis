## Q
**LC 680 验证回文字符串 Ⅱ**｜Easy · CodeTop 国内累计 11 次 · 最近 2026-04-15（CodeTop）

给字符串 `s`，**最多删除一个字符**，判断能否让它成为回文串。`1 <= s.length <= 10^5`，`s` 只含小写英文字母。例：`"abca"` → `true`（删 `'c'`），`"abc"` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**回文**」→ 首尾对称，天然是两端向中间的**对撞双指针**（two pointers）。
- 「**最多删一个**」→ 失配只能容忍一次；第一次失配处只有「删左」「删右」两个分支，分支数是常数，不是 `n`。
- `n` 到 `10^5` → 枚举每个删除位置再整串判回文是 `O(n^2)`，过不了，必须 `O(n)`。
- 字符全是小写字母 → 不需要处理大小写、空格、标点。

**推导链。**
1. 暴力：枚举删哪个字符（`n + 1` 种，含不删），每种 `O(n)` 判回文 → `O(n^2)`。
2. 浪费：回文判断本来就从两端向中间比，外层已匹配的部分在每种删法里都被重复检查；真正出问题的只有**第一个失配的位置**。
3. 洞察：第一次失配在 `(l, r)`，要删的只可能是 `s[l]` 或 `s[r]`；删外层已匹配的字符并不更好（删除位置可以挪到 `l`，得到同一个串）。
4. 最优：双指针走到失配，各用一次 `O(n)` 判断「删左后 / 删右后」的剩余闭区间是否回文 → `O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 125 验证回文串、LC 5 最长回文子串（中心扩展）、LC 1216 验证回文串 III、LC 234 回文链表。
