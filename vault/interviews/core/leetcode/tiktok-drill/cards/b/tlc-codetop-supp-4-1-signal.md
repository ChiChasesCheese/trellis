## Q
**补充题4 手撕快速排序**｜Medium · CodeTop 国内累计 65 次 · 最近 2026-06-01（国内 CodeTop）

给一个整数数组 `nums`，自己实现排序算法把它升序排列并返回（不能调用内置排序）。要求原地、平均 `O(n log n)`。`1 <= nums.length <= 50000`，`-50000 <= nums[i] <= 50000`，可能有大量重复元素。例：`nums = [5,1,1,2,0,0]` → `[0,0,1,1,2,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「手撕排序」+「原地」→ **快速排序**：分治加原地划分，不需要归并排序的 `O(n)` 辅助空间。
- 「可能有大量重复元素」→ 两路划分遇到相同元素会退化，要用**三路划分**（荷兰国旗）。
- `n` 到 `5 * 10^4` → 退化到 `O(n^2)` 或递归深度 `n` 都不可接受：要**随机基准**、要**控制递归深度**。
- 面试的追问套路：基准怎么选、重复怎么办、最坏情况、稳定性、与归并 / 堆排序比较。

**推导链。**
1. 暴力：冒泡或插入排序 `O(n^2)`，约 `2.5 * 10^9`，超时。
2. 朴素快排：取最后一个为基准、两路划分。有序或全相同的输入下，每轮只切掉一个元素，`O(n^2)`，递归深度 `n`，会触发 `RecursionError`。
3. 修正一：随机基准，期望时间与输入顺序无关。修正二：三路划分，把等于基准的元素一次性放到位，全相同数组一轮结束。
4. 修正三：递归较短的一侧，较长的一侧用循环继续，栈深不超过 `log n`。最终：期望 `O(n log n)` 时间，`O(log n)` 栈空间，原地。
