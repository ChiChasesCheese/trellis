## Q
**LC 887 鸡蛋掉落**｜写出 Python 实现

`k` 枚相同的鸡蛋，`n` 层楼，高于某层 `f` 扔下会碎、`f` 及以下不会。求最坏情况下确定 `f` 的最少操作次数。`1 <= k <= 100`，`1 <= n <= 10^4`。要求在 `k = 100`、`n = 10^4` 下瞬间返回。

## A
**思路。** 设 `floors[j]` 是“用 `j` 枚蛋、已经操作了 `m` 次”最多能确定的楼层数。再多一次操作：碎了用 `j-1` 枚蛋覆盖下面，没碎用 `j` 枚蛋覆盖上面，再加这一层，所以 `floors[j] += floors[j-1] + 1`。每轮 `m += 1`，直到 `floors[k] >= n`。

```python
def super_egg_drop(k: int, n: int) -> int:
    floors = [0] * (k + 1)                  # floors[j]: 用 j 颗蛋、当前操作次数最多能确定的楼层数
    moves = 0
    while floors[k] < n:
        moves += 1
        for j in range(k, 0, -1):           # 倒序：floors[j - 1] 还是上一轮的值
            floors[j] += floors[j - 1] + 1
    return moves
```

运行：`(1, 2)` → `2`，`(2, 6)` → `3`，`(3, 14)` → `4`，`(1, 1)` → `1`，`(2, 100)` → `14`，`(100, 10**4)` → `14`，`(2, 10**4)` → `141`。

**复杂度。** 时间 `O(k · m)`，`m` 是答案：`k = 1` 时 `m = n`，`k = 100`、`n = 10^4` 时 `m = 14`，几十次运算；空间 `O(k)`。

**写法要点。** 一维数组原地滚动，倒序遍历 `j`，保证右边的 `floors[j - 1]` 仍是上一轮的值（和 0/1 背包的倒序同理）；`floors[0]` 恒为 `0`（没有蛋什么也确定不了），自然作为边界；`while floors[k] < n` 同时承担“循环到够为止”和“统计 `moves`”，不需要二分外层。
