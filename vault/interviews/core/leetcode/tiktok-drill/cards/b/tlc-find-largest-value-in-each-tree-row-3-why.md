## Q
**LC 515 在每个树行中找最大值**｜正确性

「整层换整层」的 BFS 每轮保持什么不变量？很多人写 `m = 0` 再逐个 `m = max(m, val)`，什么输入会出错？

## A
**不变量。** 第 `d` 轮循环开始时，`level` 恰好是深度为 `d` 的全部节点（从左到右），`ans` 恰好是深度 `0..d-1` 的最大值。初始时 `level = [root]` 是第 0 层；第 `d+1` 层的每个节点都是第 `d` 层某个节点的孩子、反过来第 `d` 层每个节点的非空孩子都在第 `d+1` 层，所以列表推导生成的正是下一层。某层为空时，更深的层也都为空，循环结束，`ans` 完整。

**初始化为 `0` 的问题。** `max` 的初值必须是「比任何可能的值都小」或「这一层的某个真实值」。值域是 `[-2^31, 2^31 - 1]`，`0` 比所有负数都大，一层全是负数时最大值会被错写成 `0`。
- `[-3,-5]`：错误版本返回 `[0, 0]`；正确是 `[-3, -5]`。
- 初值写成 `-2^31` 恰好也对（等于值域下界），但写成 `-10^9` 之类「看起来够小」的数，遇到 `-2^31` 的层就会出错。

**修法。** 对整层直接 `max(node.val for node in level)`，不需要哨兵；手写循环时用 `float('-inf')` 或该层第一个节点的值做初值。
