## Q
**面试题 17.24 最大子矩阵**｜Hard · CodeTop 国内累计 8 次 · 最近 2026-09-02（国内 CodeTop）

给一个由正整数、负整数和 `0` 组成的 `N × M` 矩阵，找出元素总和**最大**的子矩阵，返回 `[r1, c1, r2, c2]`（左上角行列号、右下角行列号），有多个时返回任意一个。`1 <= matrix.length, matrix[0].length <= 200`。例：`matrix = [[-1,0],[0,-1]]` → `[0,1,0,1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「和最大的**子矩形**」= 二维的「最大子数组」；元素有负数 → 滑动窗口、双指针都不适用。
- 降维套路：**固定两条水平边**，把中间各行按列求和，矩阵变成一维数组，剩下的左右边界就是**最大子段和**（Kadane）。
- `200 × 200` → `O(R^2 · C) = 8 * 10^6` 可行；枚举四条边的 `O(R^2 C^2) = 1.6 * 10^9` 不行。
- 要返回坐标 → Kadane 要同时记起点。

**推导链。**
1. 暴力：枚举左上、右下两个角并求和，`O(R^3 C^3)`。
2. 二维前缀和让求和 `O(1)`，总计 `O(R^2 C^2)`，仍超时。
3. 洞察：上下边界固定后，每一列贡献一个数，左右边界只依赖这些列和 → 一维最大子段和，`O(C)` 而不是 `O(C^2)`。
4. 最优：`bottom` 下移一行，只把新行加进列和数组 `O(C)`；总计 `O(R^2 · C)`，空间 `O(C)`。行数多于列数时先转置，改为 `O(min^2 · max)`。

**同模式的题**：LC 53 最大子数组和、LC 363 矩形区域不超过 K 的最大数值和、LC 1074 元素和为目标值的子矩阵数量、LC 85 最大矩形。
