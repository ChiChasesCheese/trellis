## Q
**LC 50 Pow(x, n)**｜Medium · 字节高频｜正确性

快速幂的循环为什么对？不变量是什么？给出一个「先平方并右移，再检查最低位」导致错误的输入，以及不先处理负指数会发生什么。

## A
**不变量。** 每轮循环开始时，答案等于 `result * x^n`（`x` 和 `n` 是当前的底数和剩余指数）。
- `n` 为奇数：`x^n = x * (x^2)^((n - 1) / 2)`。把一个 `x` 乘进 `result`，再令 `x = x^2`、`n = (n - 1) // 2`，不变量保持。
- `n` 为偶数：`x^n = (x^2)^(n / 2)`，只换底数和指数。
- `n` 变成 `0` 时答案就是 `result * x^0 = result`。

**反例一：检查顺序。** 把循环写成「先 `x *= x; n >>= 1`，再 `if n & 1: result *= x`」，`my_pow(2.0, 3)`：第一轮 `x = 4`、`n = 1`，乘进 `result = 4`；第二轮 `x = 16`、`n = 0`，结束，返回 `4.0`；正确答案 `8.0`。原因是最低位在右移之前就被丢掉了，`2^1` 这一份从没被乘进去。

**反例二：负指数。** 不先转成非负，直接 `my_pow(2.0, -2)`：`-2 >> 1 == -1`，`-1 >> 1 == -1`，`n` 永远不为 `0`，`while n` 死循环。先 `x, n = 1 / x, -n`，再按非负指数处理，得到 `0.25`。
