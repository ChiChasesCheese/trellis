## Q
**LC 165 比较版本号**｜Medium · LC TikTok 热度 53/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 71 次 · 最近 2026-07-27（面试记录）

给两个版本号字符串 `version1` 和 `version2`，比较它们。版本号由被点 `'.'` 分开的修订号组成，修订号的值是转换为整数并忽略前导零的结果；从左到右依次比较，缺失的修订号视为 `0`。`version1 < version2` 返回 `-1`，`version1 > version2` 返回 `1`，否则返回 `0`。`1 <= version1.length, version2.length <= 500`，只含数字和 `'.'`，修订号都能存进 32 位整数。例：`"1.2"` 与 `"1.10"` → `-1`；`"1.0"` 与 `"1.0.0.0"` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「由 `.` 分开的若干段，从左到右逐段比较」→ **分段 + 对齐**：先 `split`，再把两个列表逐位配对。
- 「缺失的修订号视为 `0`」→ 对齐时短的一边**补 `0`**，用 `itertools.zip_longest(fillvalue="0")`。
- 「修订号的值是整数、忽略前导零」→ 必须按**数值**比较，`int()` 自带去前导零；字符串字典序会得出 `"2" > "10"`。
- 长度只有 `500`：任何线性做法都足够，考点是对齐规则，不是性能。

**推导链。**
1. 暴力一：整串当字符串比较，`"1.2" > "1.10"`，错。
2. 暴力二：当浮点数比较，`1.10 == 1.1`，错。
3. 洞察：每段是一个独立的整数。从左到右第一个不相等的段决定大小；段数不同时缺的当作 `0`，所以 `"1.0"` 与 `"1.0.0.0"` 相等，不需要事先去掉末尾的 `0`。
4. 最优：`split` 后用 `zip_longest` 对齐，逐段 `int` 比较，第一个差异就返回。`O(m + n)` 时间。想要 `O(1)` 额外空间，可以直接在字符串上用双指针逐段解析。
