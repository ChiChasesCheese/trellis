## Q
**面试题 16.01 交换数字**｜正确性

逐步写出异或交换中两个变量的值，说明为什么正确。把它写成通用的 `swap(nums, i, j)` 时，什么输入会出错？

## A
**逐步推导**（`x`、`y` 是两个位置，初值 `a`、`b`）：
- `x ^= y`：`x = a ^ b`，`y = b`；
- `y ^= x`：`y = b ^ (a ^ b) = a`（`b ^ b = 0`，`0 ^ a = a`）；
- `x ^= y`：`x = (a ^ b) ^ a = b`。
用到的只有 `t ^ t = 0`、`t ^ 0 = t` 以及交换律、结合律，对任何整数（包括负数、相等的值）都成立。

**关键前提：`x` 和 `y` 是两个不同的存储位置。** 推导默认改 `x` 时 `y` 不变。

**反例：同一个位置。** `swap(nums, 0, 0)`，`nums = [5,9]`：
- `nums[0] ^= nums[0]` → `nums[0] = 0`，原值已经丢了；
- 后两步都是 `0 ^ 0`，结果 `[0,9]`，正确应该是 `[5,9]`。

在排序、洗牌这类算法里 `i == j` 很常见，所以通用版本要先写 `if i == j: return`。值相等但位置不同不受影响：`[7,7]` 交换后仍是 `[7,7]`。
