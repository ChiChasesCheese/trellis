## Q
**LC 63 不同路径 II**｜Medium · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 9 次 · 最近 2026-03-31（国内 CodeTop）

`m x n` 的网格 `obstacleGrid` 里，`1` 是障碍、`0` 是空格。机器人从左上角出发，每步只能**向下或向右**走一格，要到右下角，路径上不能有障碍格。返回不同路径的数量；保证答案不超过 `2 * 10^9`。`1 <= m, n <= 100`，格子值为 `0` 或 `1`。例：`[[0,0,0],[0,1,0],[0,0,0]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「只能向下或向右」→ 网格是**有向无环图**（DAG），行优先遍历就是拓扑序，可以做 DP。
- 「求路径**数量**」而不是列出每条路径 → **计数 DP**：把各个来源的方案数加起来，不需要回溯。
- `m, n <= 100` → `O(mn) = 10^4`，二维表完全放得下。
- 有障碍 → 障碍格是「不可达」，方案数恒为 `0`。

**推导链。**
1. 暴力：从起点 DFS，每步两个分支，路径条数指数级（无障碍时是 `C(m+n-2, m-1)`，100 x 100 时约 `10^58`）。
2. 浪费：到达 `(i, j)` 之后怎么走与之前怎么到的无关，同一个格子被不同前缀反复展开。
3. 关键：最后一步只可能来自上方或左方，两类路径互不重叠，所以 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`；障碍格保持 `0`。
4. 最优：多开一行一列做哨兵，`dp[0][1] = 1` 让起点自然得到 `1`，一遍双重循环，`O(mn)`。

**同模式的题**：LC 62 不同路径、LC 64 最小路径和、LC 120 三角形最小路径和、LC 174 地下城游戏。
