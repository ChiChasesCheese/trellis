## Q
**LC 3387 两天自由外汇交易后的最大货币数**｜Medium · 近一年被问：美国 3 次、国内 0 次 · 最近 2026-01-05（面试记录）

你有 `1.0` 单位的 `initialCurrency`。第 1 天可按 `pairs1`、`rates1` 兑换任意次，第 2 天按 `pairs2`、`rates2` 兑换任意次；每个 `[start, target]` 的汇率是 `rate`，反向兑换的汇率是 `1 / rate`。返回两天后最多能拥有的 `initialCurrency` 数量。保证每天的汇率图内部没有矛盾和环。`1 <= pairs1.length, pairs2.length <= 10`，`1.0 <= rate <= 10.0`，货币名 `1` 到 `3` 个大写字母，输出最大 `5 * 10^10`。例：`initialCurrency = "NGN"`，`pairs1 = [["NGN","EUR"]]`，`rates1 = [9.0]`，`pairs2 = [["NGN","EUR"]]`，`rates2 = [6.0]` → `1.5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「汇率图」+「保证无矛盾、无环」→ 每个连通分量是树，任意两种货币的换算比**唯一**，DFS / BFS 一次传播汇率即可，不需要最短路或 Floyd。
- 「每条边还有 `1 / rate` 的反向」→ 无向图，边权为乘法的倒数。
- 「两天，第 2 天用另一张图」→ 两阶段，中间货币 `c` 是衔接点：第 1 天换到 `c`，第 2 天从 `c` 换回初始货币。
- 货币数极少（至多 `20` 种）→ 枚举中转货币毫无压力。

**推导链。**
1. 暴力：枚举第 1 天结束时持有的货币 `c`，再枚举 `c` 在第 2 天换回初始货币的所有路径。
2. 简化：图无矛盾，任意路径换算相同，只要从初始货币出发 DFS 一次，就得到它到每种货币的比率。
3. 第 1 天：`day1[c]` = `1` 个初始货币能换到的 `c` 的数量。第 2 天：`day2[c]` = 同样从 `1` 个初始货币出发在第 2 天图上能换到的 `c` 的数量，所以 `1` 个 `c` 能换回 `1 / day2[c]` 个初始货币。
4. 答案是对两张图都包含的货币 `c`，取 `day1[c] / day2[c]` 的最大值（`c` 就是初始货币时为 `1.0`，对应什么都不换）。
