## Q
**LC 96 不同的二叉搜索树**｜Medium · CodeTop 国内累计 20 次 · 最近 2026-04-19（国内 CodeTop）

给整数 `n`，求恰由 `n` 个节点组成、节点值为 `1` 到 `n` 互不相同的二叉搜索树有多少种。`1 <= n <= 19`。例：`n = 3` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「有多少种树」只要**个数**，不要树本身 → 计数 DP，不是搜索 / 回溯。
- BST 的定义：根固定后，左边全是更小的、右边全是更大的 → 选根把问题拆成**互相独立**的左右两个同类子问题 → 乘法原理。
- 形状只与节点数有关，与具体值无关 → 状态是「节点数」`G(m)`，一维 DP。
- `n <= 19`：这个范围是因为 `G(19) = 1767263190` 还在 32 位整数内；`O(n^2)` 绰绰有余。

**推导链。**
1. 暴力：生成所有 BST 再数（LC 95），树的个数是卡特兰数，指数增长。
2. 浪费：只要数量，生成树是浪费；左右子树的方案互不影响。
3. 洞察：根取第 `i` 个值时，左子树有 `i - 1` 个节点、右子树有 `size - i` 个节点，方案数 `G(i - 1) * G(size - i)`；对 `i` 求和得 `G(size)`；空树为 `1`。
4. 自底向上算 `G(0..n)`，`O(n^2)`；也可以直接用卡特兰数公式 `comb(2n, n) // (n + 1)`，`O(n)`。

**同模式的题**：LC 95 不同的二叉搜索树 II、LC 22 括号生成（同为卡特兰数）、LC 241 为运算表达式设计优先级、LC 1130 叶值的最小代价生成树。
