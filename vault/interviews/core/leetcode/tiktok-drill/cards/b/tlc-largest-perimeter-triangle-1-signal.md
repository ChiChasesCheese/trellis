## Q
**LC 976 三角形的最大周长**｜Easy · CodeTop 国内累计 5 次 · 最近 2025-12-19（国内 CodeTop）

数组 `nums` 里是若干正数，表示线段长度。从中选三条组成**面积不为零**的三角形，返回最大周长；组不成任何三角形时返回 `0`。`3 <= nums.length <= 10^4`，`1 <= nums[i] <= 10^6`。例：`[2,1,2]` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「三条边组成三角形」→ 三角形不等式；**排序后**只需检查「两条短边之和 > 最长边」。
- 「最大周长」→ 从大往小**贪心**，第一个成立的就是答案。
- 「面积不为零」→ 严格大于，等号时退化成线段。
- `n = 10^4` → 三重枚举约 `1.7 × 10^11` 不可行，排序 `O(n log n)` 足够。

**推导链。**
1. 暴力：枚举三元组 `O(n^3)`。
2. 浪费：固定最长边 `a` 后，只需看能凑出的最大两数和。
3. 关键：降序排序后，`a` 后面紧挨着的 `b, c` 就是最大的两数和；`b + c <= a` 则 `a` 不可能做最长边，丢掉。
4. 最优：降序扫描相邻三元组，第一个 `b + c > a` 即答案，`O(n log n)`。
