## Q
**剑指 Offer 51 数组中的逆序对**｜Hard · CodeTop 国内累计 23 次 · 最近 2026-08-10（CodeTop）

数组 `record` 记录一段时间内的股票价格。如果前一天的价格**高于**后一天的价格，这一对就是一个「交易逆序对」，即满足 `i < j` 且 `record[i] > record[j]` 的 `(i, j)`。返回逆序对总数。`0 <= record.length <= 50000`。例：`[9, 7, 5, 4, 6]` → `8`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`i < j` 且 `a[i] > a[j]` 的对数」→ **逆序对**：典型的"排序过程中计数"，归并排序是首选。
- `n = 5 * 10^4`：`O(n^2)` 约 `1.25 * 10^9` 次比较，超时 → 需要 `O(n log n)`。
- 另一族做法：把元素按值离散化，用**树状数组**（Fenwick tree）统计"前面已经出现了多少个更大的"，同样 `O(n log n)`。
- 「严格大于」→ 相等的元素不算逆序，合并和计数时要小心取等号。

**推导链。**
1. 暴力：双重循环数每一对，`O(n^2)`。
2. 浪费：对左边每个元素，都重新扫描右边全部元素。
3. 洞察：若左右两半各自有序，用双指针一遍就能数出所有跨越两半的逆序对——取出一个左元素时，已取走的右元素个数就是比它小的个数。
4. 归并排序天然产生"左右各自有序"的合并步骤：左半内部 + 右半内部 + 跨越两半，递归 `log n` 层，每层 `O(n)`。

**同模式的题**：LC 315 计算右侧小于当前元素的个数、LC 493 翻转对、LC 327 区间和的个数、LC 912 排序数组。
