## Q
**LC 416 分割等和子集**｜正确性

为什么数组 DP 里循环必须从大到小？位集写法 `bits |= bits << x` 为什么天然保证每个数只用一次？给出正着更新出错的输入。

## A
**不变量。** 处理完前 `i` 个数后，`dp[j]`（或 `bits` 的第 `j` 位）为真，当且仅当前 `i` 个数里存在一个子集的和是 `j`。

**为什么倒序。** 处理数 `x` 时，`dp[j]` 要读 `dp[j − x]` 在「处理 `x` 之前」的值。若 `j` 从小到大，较小的 `dp[j − x]` 已经被本轮更新过，相当于允许 `x` 被再用一次，变成完全背包（每个数可用无限次）。倒序时 `dp[j − x]`（下标更小）还没被本轮改动，读到的是旧值。

**位集为什么天然正确。** `bits << x` 先用旧 `bits` 算出新的整数，再与旧 `bits` 取或后赋值；没有「边读边写」，每个和只加了一次 `x`。

**反例。** `nums = [1, 5]`，总和 `6`，目标 `3`，正确答案 `False`（子集和只有 `0, 1, 5, 6`）。
- 正着更新：处理 `x = 1`：`dp[1] = dp[0] = True`，接着 `dp[2] = dp[1] = True`（用了第二个 `1`），`dp[3] = dp[2] = True`。`dp[3]` 为真，返回 `True`，错误。
- 倒着更新：`j = 3` 时读的是更新前的 `dp[2] = False`，`dp[3]` 保持 `False`，处理 `5` 后仍为 `False`，返回 `False`，正确。

**总和奇数的剪枝依据。** 两个子集和相等意味着每个都是 `S/2`，`S` 必须是偶数。正整数的和是整数，奇数无法对半分。
