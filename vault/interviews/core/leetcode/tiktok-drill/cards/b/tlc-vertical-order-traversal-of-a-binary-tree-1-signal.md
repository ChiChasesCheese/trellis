## Q
**LC 987 二叉树的垂序遍历**｜Hard · CodeTop 国内累计 3 次 · 最近 2024-09-25（CodeTop）

二叉树节点位置 `(row, col)`：根在 `(0, 0)`，左孩子在 `(row + 1, col - 1)`，右孩子在 `(row + 1, col + 1)`。垂序遍历从最左列到最右列，每列按 `row` 从小到大排；同一行同一列的节点按值从小到大排。返回每列一个列表的结果。节点数在 `[1, 1000]`，`0 <= Node.val <= 1000`。例：`[1,2,3,4,5,6,7]` → `[[4],[2],[1,5,6],[3],[7]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每个节点有坐标」+「按坐标分组输出」→ **遍历收集坐标，再排序分组**，而不是边遍历边输出。
- 「先按列、再按行、同位置按值」是三级排序 → 把 `(col, row, val)` 放进元组，**元组的字典序**就是这个顺序。
- 分列输出 → 排序后同一列连续，`groupby` 按列切段。
- 遍历顺序无所谓，递归 DFS 最直观；节点数 `1000` 且可能是链时递归深度会超过 CPython 默认上限约 `1000`，要调高上限或改显式栈。

**推导链。**
1. 暴力：遍历得到所有 `(row, col, val)`；对每个列号，扫描全部节点挑出该列的，再排序，`O(n * 列数)`。
2. 浪费：每列都重新扫一遍全部节点。
3. 关键：要求的输出顺序 = `(col, row, val)` 的字典序，一次 `sort()` 就满足全部三级条件。
4. 排序后用 `groupby(nodes, key=col)` 按列切成一段一段，只保留值，整体 `O(n log n)`。
