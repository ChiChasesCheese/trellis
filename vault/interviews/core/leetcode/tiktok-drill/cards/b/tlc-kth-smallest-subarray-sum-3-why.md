## Q
**LC 1918 第 K 小的子数组和**｜正确性

为什么判定条件是 `count_le(mid) >= k`，而不是 `> k`？为什么上界必须是 `sum(nums)`？为什么这个双指针要求元素为正？

## A
**不变量。** 二分过程中，答案始终在 `[lo, hi]` 内；`count_le(x)` 关于 `x` 单调不减，第 `k` 小的值 `v` 满足 `count_le(v) >= k` 且 `count_le(v - 1) < k`，也就是"最小的满足 `count_le(x) >= k` 的 `x`"。

**为什么是 `>=`。** 当 `count_le(mid) == k`，说明恰好有 `k` 个子数组和不超过 `mid`，第 `k` 小就在 `mid` 或更小，不能舍弃 `mid`，所以收缩 `hi = mid`。写成 `> k` 会在恰好等于 `k` 时抬高下界，跳过正确答案。

**反例一：严格大于。** `nums = [2,1,3]`，`k = 4`：
- 子数组和升序 `1, 2, 3, 3, 4, 6`。`count_le(3) = 4`（`1, 2, 3, 3`），`count_le(4) = 5`。
- 严格大于版本在 `mid = 3` 处认为 `4 > 4` 为假，抬高下界，最终得到 `4`；正确是 `3`。

**反例二：上界取最大元素。** `nums = [2,1,3]`，`k = 6`：第 `6` 小是整个数组的和 `6`，但 `max(nums) = 3`，二分在 `[1, 3]` 上结束，返回 `3`，错误。答案最大可达 `sum(nums)`。

**为什么要求元素为正。** 双指针依赖「窗口和随右端点前进、随左端点前进而单调」：右端前进只增不减，左端前进只减不增。含负数时窗口和不单调，收缩左端后可能还需要扩张，`right - left + 1` 就不再等于"以 `right` 结尾、和不超过 `x` 的个数"。
