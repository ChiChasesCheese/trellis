## Q
**LC 567 字符串的排列**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 11 次 · 最近 2026-04（面试记录）

给字符串 `s1`、`s2`，判断 `s2` 是否包含 `s1` 的排列（`s1` 的某个排列是 `s2` 的子串）。`1 <= s1.length, s2.length <= 10^4`，只含小写字母。例：`s1 = "ab"`，`s2 = "eidbaooo"` → `true`（`"ba"`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「排列」= 字符的多重集相同 → 比较**字符计数**，与顺序无关。
- 「子串」= 连续，而且目标长度固定为 `len(s1)` → **定长滑动窗口**。
- 字符只有 26 个小写字母 → 计数用长度 26 的数组，比较是常数。
- `n` 到 `10^4`，`O(n * m)` 勉强能过，但面试要求线性：窗口滑动时增量更新。

**推导链。**
1. 暴力：对 `s2` 的每个长度 `m` 的子串，排序后与排序的 `s1` 比较，`O(n * m log m)`。
2. 浪费：相邻两个窗口只相差「进来一个字符、出去一个字符」。
3. 改进：维护 `cnt = s1 的计数 - 窗口的计数`，滑动时只改两个槽位；窗口是排列 ⇔ 26 个槽位全为 `0`。
4. 再改进：不用每步检查 26 个槽，维护 `diff`（非零槽位的个数），更新槽位时按「是否由零变非零、由非零变零」调整，`diff == 0` 即成功，每步 `O(1)`，总计 `O(m + n)`。

**同模式的题**：LC 438 找到字符串中所有字母异位词、LC 76 最小覆盖子串、LC 30 串联所有单词的子串、LC 242 有效的字母异位词。
