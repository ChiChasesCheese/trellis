## Q
**螺旋矩阵（O(1) 额外空间、不改输入）**｜正确性

为什么下边必须在 `top < bottom` 时才走、左边必须在 `left < right` 时才走？循环的不变量是什么？给出缺少守卫时出错的具体输入。

## A
**不变量。** 每圈开始时，矩形 `[top..bottom] x [left..right]` 里的元素恰好是还没有输出的元素，其余元素都已按螺旋顺序输出。一圈结束后四条边界各收一格，外圈的所有元素都已输出，不变量保持；矩形为空（`top > bottom` 或 `left > right`）时循环结束，所有元素都已输出，每个元素恰好一次。

**为什么要守卫。** 上边走了第 `top` 行的 `left..right`，右边走了第 `right` 列的 `top+1..bottom`。如果矩形只有一行（`top == bottom`），那一行已经被上边走完，下边是同一行的倒序，会重复；如果只有一列（`left == right`），右边已经覆盖了这一列，左边会重复。

**反例一：缺 `top < bottom`。** 输入 `[[1,2,3]]`：
- 上边输出 `1, 2, 3`；右边 `top + 1 > bottom`，空。
- 没有守卫，下边倒着再走第 `0` 行的 `c = 1, 0`，追加 `2, 1`。
- 得到 `[1, 2, 3, 2, 1]`，正确是 `[1, 2, 3]`。

**反例二：缺 `left < right`。** 输入 `[[1],[2],[3]]`：
- 上边输出 `1`；右边输出 `2, 3`；下边因为 `top < bottom` 走，范围是空的。
- 没有守卫，左边从 `bottom - 1 = 1` 走到 `top + 1 = 1`，追加第 `1` 行的 `2`。
- 得到 `[1, 2, 3, 2]`，正确是 `[1, 2, 3]`。
