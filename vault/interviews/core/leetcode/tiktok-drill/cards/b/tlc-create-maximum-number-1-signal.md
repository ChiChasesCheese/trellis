## Q
**LC 321 拼接最大数**｜Hard · CodeTop 国内累计 6 次 · 最近 2026-05-21（国内 CodeTop）

两个整数数组 `nums1`、`nums2`，长度分别为 `m`、`n`，每个元素是一个数字。从两个数组中一共取 `k` 个数字，拼成一个长度为 `k` 的**最大的数**，**同一数组中取出的数字必须保持原来的相对顺序**，返回这个数的各位组成的数组。`1 <= m, n <= 500`，`0 <= nums1[i], nums2[i] <= 9`，`1 <= k <= m + n`，两个数组都没有前导 0。例：`nums1 = [3,9]`, `nums2 = [8,9]`, `k = 3` → `[9,8,9]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「保持相对顺序」+「挑若干位使数最大」→ **单调栈**（monotonic stack）挑固定长度的最大子序列，LC 402 的反向。
- 「两个数组」→ 拆成两步：枚举每边各取几个（`i` 与 `k - i`），再**合并**。
- 合并时首位相同要看后面 → 比较**剩余后缀**的字典序。
- `m, n <= 500`、`k <= 1000` → 枚举 `i` 的 `O(k)` 乘以线性的挑选与合并可行。

**推导链。**
1. 暴力：枚举两边取哪些位置并交错合并，指数级。
2. 拆解：固定 `i` 后，每一边取同长度里**字典序最大**的子序列一定不亏，因为合并结果对每边单调。
3. 每边：单调栈，遇到更大的数字就弹掉栈顶，最多弹 `len - t` 次，`O(len)`。
4. 合并：每步取剩余后缀更大的那边的首位；所有 `i` 的结果取 `max`。

**同模式的题**：LC 402 移掉 K 位数字、LC 316 去除重复字母、LC 1673 找出最具竞争力的子序列、LC 1754 构造字典序最大的合并串。
