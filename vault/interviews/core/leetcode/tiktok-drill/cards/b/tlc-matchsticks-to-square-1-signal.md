## Q
**LC 473 火柴拼正方形**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 3 次 · 最近 2024-04-09（国内 CodeTop）

整数数组 `matchsticks`，`matchsticks[i]` 是第 `i` 根火柴的长度。用**所有**火柴拼成正方形：不能折断，可以首尾相连，每根恰好用一次。能拼成返回 `true`。`1 <= matchsticks.length <= 15`，`1 <= matchsticks[i] <= 10^8`。例：`[1,1,2,2,2]` → `true`，`[3,3,3,3,4]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「把全部元素分成若干组，每组和相等」→ **子集划分**（k-way partition）；和 LC 416（分成 2 份）同族，但 `k = 4` 没有多项式的背包做法。
- `n <= 15` → 允许指数级：**回溯** `4^15 ≈ 10^9`（需要剪枝），或**状态压缩 DP** `2^15 · 15`。
- `matchsticks[i]` 高达 `10^8` → 不能按「长度」做背包 DP，只能搜索 / 状态压缩。
- 「必须全部用上」→ 总和必须被 `4` 整除，每根不能超过边长。

**推导链。**
1. 暴力：每根火柴放进 4 条边之一，`4^15` 种，检查四边相等。
2. 前置剪枝：总和不被 `4` 整除，或最长火柴 `>` 边长，直接 `False`。
3. 顺序剪枝：从长到短放，长的限制多，错得早。边长上限剪枝：放进去超过边长就换一条。
4. 对称剪枝：当前几条边已有长度相同时，放进哪条结果等价，只试一次。尤其第一根火柴，四条边都是 `0`，只需要试一次。
5. 备选：状压 DP，`dp[mask]` 为用掉 `mask` 里的火柴后，当前这条边的已拼长度（取模）。`O(2^n · n)`。

**同模式的题**：LC 698 划分为k个相等的子集、LC 416 分割等和子集、LC 1723 完成所有工作的最短时间、LC 2305 公平分发饼干。
