## Q
**LC 1477 找两个和为目标值且不重叠的子数组**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-07-15（CodeTop）

整数数组 `arr` 和 `target`：找两个互不重叠、和都等于 `target` 的子数组，使长度之和最小，没有则 `-1`。`1 <= arr.length <= 10^5`，`1 <= arr[i] <= 1000`，`1 <= target <= 10^8`。例：`[3,2,2,4,3]`，`target = 3` → `2`；`[4,3,2,6,2,3,4]`，`target = 6` → `-1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子数组和等于 `target`」+「元素全为**正**」→ 和随窗口扩大单调增 → **滑动窗口**，`O(n)`；元素有负数或零时要改前缀和 + 哈希表。
- 「**两个互不重叠**」→ 用位置把问题一分为二：当前子数组作为右段，左段来自它左边的**前缀**，用 `best[i]` 存前缀最优值。
- 求长度之和的**最小值** → 对左边只保留最短的一个；以 `right` 结尾的目标子数组至多一个（元素为正），不会爆炸。
- `n = 10^5`、`target` 到 `10^8` → 要 `O(n)`；时间轴很大不影响，因为只操作下标。

**推导链。**
1. 暴力：枚举所有和为 `target` 的子数组，再两两检查不重叠，最坏 `O(n^2)` 个子数组。
2. 浪费：每个目标子数组左边只需要一个最短搭档，其他都没用。
3. 洞察：元素为正，以每个 `right` 结尾的目标子数组至多一个，用滑动窗口找出；扫描顺序保证 `best[left]`（前 `left` 个元素里的最短目标子数组）已算好。
4. 最优：窗口找到 `[left, right]` 时更新 `ans = min(ans, best[left] + 长度)` 和 `best[right + 1]` → `O(n)` 时间、`O(n)` 空间。

**同模式的题**：LC 560 和为 K 的子数组、LC 209 长度最小的子数组、LC 1031 两个非重叠子数组的最大和、LC 2054 两个最好的不重叠活动。
