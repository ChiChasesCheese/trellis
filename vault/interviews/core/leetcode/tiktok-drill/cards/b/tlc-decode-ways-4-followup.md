## Q
**LC 91 解码方法**｜追问

面试官接着问：（1）自顶向下的记忆化写法？（2）字符串很长，答案要对 `10^9 + 7` 取模？（3）要求列出所有解码结果而不是个数？（4）字符里出现通配符 `*`（LC 639）？

## A
1. **记忆化**：`ways(i)` 表示解码 `s[i:]` 的方案数，到末尾返回 `1`，遇到 `'0'` 返回 `0`，否则加上"取 1 位"和（若两位 `<= 26`）"取 2 位"。`functools.cache` 保存结果，递归深度 `n`，`n <= 100` 安全。

```python
from functools import cache

def num_decodings_memo(s: str) -> int:
    @cache
    def ways(i: int) -> int:               # 解码 s[i:] 的方案数
        if i == len(s):
            return 1
        if s[i] == "0":
            return 0
        total = ways(i + 1)
        if i + 1 < len(s) and s[i:i + 2] <= "26":
            total += ways(i + 2)
        return total

    return ways(0)
```

`"12"` → `2`，`"226"` → `3`，`"06"` → `0`，`"11106"` → `2`。
2. **取模**：每次加法后 `% (10**9 + 7)`；Python 整数不会溢出，但取模保持数字规模，避免长串（`n` 很大）时出现超大整数；C++ / Java 要用 `long`。
3. **列出所有解码**：回溯，当前位置选 1 位或 2 位（合法时），到末尾把路径拼成字符串加入结果；结果数量可能是指数级（斐波那契），所以只能用于很小的输入。字母用 `chr(ord("A") + code - 1)`。
4. **通配符 `*`（LC 639）**：`*` 可以代表 `1`~`9`；`f[i]` 的两项系数变成"单字符的合法取值个数"（`'*'` 是 `9`）和"两个字符组合的合法取值个数"（如 `*` 后接 `'6'` 是 `2` 种：`16`、`26`），其余转移相同，结果取模。

**Python 提醒**：`s[i:i + 2] <= "26"` 用字符串比较，只有两边等长时才等价于数值比较。所以必须先保证 `i + 1 < len(s)`；否则末位的一字符切片会按字典序比较（`"3" <= "26"` 为 `False`，`"1" <= "26"` 为 `True`），结果与数值无关。前导零已经被 `s[i] == "0"` 的分支排除，这里只需要检查上界。`@cache` 需要 Python 3.9 及以上，参数必须可哈希。
