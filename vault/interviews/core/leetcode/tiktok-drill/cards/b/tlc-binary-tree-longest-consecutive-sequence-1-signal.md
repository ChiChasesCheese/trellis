## Q
**LC 298 二叉树最长连续序列**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 2 次 · 最近 2025-03-13（CodeTop）

给二叉树根节点 `root`，求最长连续序列路径的长度：路径依次递增 `1`，从任意节点出发，只能沿「父 → 子」向下走。节点数在 `[1, 3 * 10^4]`，`-3 * 10^4 <= Node.val <= 3 * 10^4`。例：`[1,null,3,2,4,null,null,null,5]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树上的路径」+ 方向固定（只能父到子）→ **自顶向下的 DFS**，状态可以顺着往下传。
- 条件只涉及相邻两个节点（子值 = 父值 + 1）→ 状态就是一个整数：**以当前节点结尾的连续长度**。
- 「可以从任意节点开始」→ 不需要显式找起点：子节点不满足条件时长度重置为 `1`，相当于从它重新开始。
- `n = 3 · 10^4` 且树可能是一条链：Python 默认递归深度约 `1000`，递归会爆；改**显式栈**。

**推导链。**
1. 暴力：对每个节点，向下找最长连续路径，链状树上 `O(n^2)`。
2. 浪费在哪：节点 `v` 的结果完全由父节点的长度决定，却被重复向下探索。
3. 洞察：`length(v) = length(parent) + 1` 当 `v.val == parent.val + 1`，否则 `1`。自顶向下把 `length` 传下去，每个节点只算一次。
4. 最优：栈里存 `(节点, 长度)`，弹出时更新答案，把左右孩子带着新长度压栈。`O(n)` 时间，深度不受递归限制。
