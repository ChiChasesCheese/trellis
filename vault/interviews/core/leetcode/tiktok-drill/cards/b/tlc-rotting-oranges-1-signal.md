## Q
**LC 994 腐烂的橘子**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 2 次 · 最近 2022-05-03（国内 CodeTop）

`m x n` 网格，`0` 空、`1` 新鲜橘子、`2` 腐烂橘子；每分钟腐烂橘子会让上下左右相邻的新鲜橘子腐烂。求直到没有新鲜橘子所需的最少分钟数，不可能则返回 `-1`。`1 <= m, n <= 10`，`grid[i][j]` 为 `0`、`1` 或 `2`。例：`[[2,1,1],[1,1,0],[0,1,1]]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「同时从多个腐烂橘子向外蔓延」「每分钟扩散一圈」→ **多源 BFS**：所有源头一起入队，层数 = 分钟数。
- 「最小分钟数」→ 最短时间，DFS 不保证先到的是最早，必须 BFS。
- 「不可能返回 `-1`」→ 结束后检查是否还有新鲜橘子（被空格或边界隔开的）。
- “本来没有新鲜橘子”→ 答案是 `0`，边界要处理好，不能多算一分钟。
- `m, n <= 10`：规模很小，考的是层数和边界的细节。

**推导链。**
1. 暴力：每分钟扫整个网格，标记相邻的新鲜橘子，直到不再变化，`O((mn)^2)`。
2. 浪费：每分钟都重扫所有格子，而真正会感染别人的只有“刚腐烂”的那批。
3. 洞察：刚腐烂的橘子入队，只从它们出发感染邻居；按层出队，一层 = 一分钟；用 `fresh` 计数判断是否清空，并提前停止。
4. 最优：BFS `O(mn)`，结束时 `fresh > 0` 返回 `-1`。
