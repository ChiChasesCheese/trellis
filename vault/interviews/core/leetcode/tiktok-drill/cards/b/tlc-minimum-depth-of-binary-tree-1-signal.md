## Q
**LC 111 二叉树的最小深度**｜Easy · CodeTop 国内累计 8 次 · 最近 2025-12-02（国内 CodeTop）

给二叉树的根 `root`，求从根到**最近叶子**（没有子节点的节点）的最短路径上的节点数。节点数在 `[0, 10^5]` 内，`-1000 <= Node.val <= 1000`。例：`[3,9,20,null,null,15,7]` → `2`；`[2,null,3,null,4,null,5,null,6]` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最小深度」=「最近的叶子」→ 树上的**最短路**，边无权 → **BFS 按层**，第一个遇到的叶子就是答案。
- 「叶子 = 没有子节点」→ 只有一个孩子的节点**不是**叶子，空孩子不能当作深度 `0` 的终点。
- 节点数到 `10^5` → 链状树的递归深度 `10^5`，Python 默认上限约 `1000`，要用迭代。

**推导链。**
1. 暴力：DFS 枚举所有根到叶的路径，取最短，`O(n)`，必须走完整棵树。
2. 浪费：最浅的叶子可能在第 2 层，DFS 仍要遍历深处的所有节点。
3. 关键：BFS 按深度递增访问节点；第一次弹出叶子时，所有更浅的节点都已检查过，没有更浅的叶子。
4. 最优：队列存 `(节点, 深度)`，遇到叶子立刻返回，最坏 `O(n)`、通常提前结束，且无递归深度问题。
