## Q
**LC 129 求根到叶子节点数字之和**｜Medium · CodeTop 国内累计 59 次 · 最近 2026-04-09（CodeTop）

给二叉树的根节点 `root`，每个节点存一个 `0` 到 `9` 的数字。每条从根到叶子的路径代表一个数（路径 `1 -> 2 -> 3` 表示 `123`），返回所有这些数之和。叶子是没有子节点的节点。节点数在 `[1, 1000]`，`0 <= Node.val <= 9`，树的深度不超过 `10`。例：`root = [4,9,0,5,1]` → `1026`（`495 + 491 + 40`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「根到叶子的**路径**」+「每条路径算一个量再求和」→ **自顶向下 DFS**，路径信息随递归向下传。
- 数是沿路径逐位拼出来的 → 状态只有一个整数 `acc`，转移 `acc * 10 + val`，不用保存整条路径。
- 深度不超过 `10`、`n <= 1000` → 递归栈和复杂度都不是问题，重点是叶子的判断。

**推导链。**
1. 暴力：先把所有根到叶子的路径收集成列表，再逐条拼成整数求和，`O(n * h)` 时间并存下全部路径。
2. 浪费：一个节点的前缀被所有经过它的路径各存一份、各转一次。
3. 观察：前缀数只依赖祖先，下一层的前缀数 = 当前前缀数 × 10 + 当前值，作为递归参数传下去，不需要存路径。
4. 到叶子（左右孩子**都**为空）返回 `acc`；否则返回左右子树的结果之和。每个节点访问一次，`O(n)`，空间 `O(h)`。

**同模式的题**：LC 112 路径总和、LC 113 路径总和 II、LC 257 二叉树的所有路径、LC 1022 从根到叶的二进制数之和。
