## Q
**LC 92 反转链表 II**｜Medium · LC TikTok 热度 38/100 · CodeTop 国内累计 80 次 · 最近 2026-05-12（国内 CodeTop）

给单链表的头指针 `head` 和两个整数 `left`、`right`（`left <= right`），反转从位置 `left` 到位置 `right` 的链表节点（位置从 `1` 开始），返回反转后的链表。节点数 `1 <= n <= 500`，`-500 <= Node.val <= 500`，`1 <= left <= right <= n`。例：`head = [1,2,3,4,5]`，`left = 2`，`right = 4` → `[1,4,3,2,5]`。进阶：一趟扫描完成。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「反转**一段**」→ 反转链表（LC 206）的区间版：只改区间内的 `next` 指针，前后两端要接回去。
- `left` 可以等于 `1` → 头节点可能改变 → 用**哑节点**，让每个节点都有「前一个节点」。
- 「一趟扫描」→ 不先去找右端点再反转，而是边走边反转：**头插法**。
- `n <= 500`：线性解法随便跑，考点是指针操作的正确性。

**推导链。**
1. 暴力：取出区间的值，反转后写回。可行，但改的是值，不是节点。
2. 三段法：找到 `pre` 和区间两端，反转区间，再把反转后的头接到 `pre`、尾接到区间后面。要保存多个端点，接头接尾最容易漏。
3. 洞察：区间里原来的第一个节点 `cur` 反转后正好是区间的尾，不用移动。依次把它后面的节点摘下来插到 `pre` 后面，`cur` 就被挤到末尾，`cur.next` 始终指向未处理的部分。
4. 最优：`pre` 走到第 `left - 1` 个节点，做 `right - left` 次头插，`O(n)` 时间，`O(1)` 空间，一趟完成，不用再接尾。

**同模式的题**：LC 206 反转链表、LC 25 K 个一组翻转链表、LC 24 两两交换链表中的节点、LC 234 回文链表。
