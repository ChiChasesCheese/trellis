## Q
**LC 71 简化路径**｜Medium · LC TikTok 全时段热度 62/100 · CodeTop 国内累计 14 次 · 最近 2025-01-14（国内 CodeTop）

给一个 Unix 风格的绝对路径 `path`，化成规范路径：`'.'` 是当前目录，`'..'` 是上一级（根目录没有上一级），连续的 `'/'` 视为一个，`'...'` 之类是合法目录名；结果以 `'/'` 开头，目录间一个 `'/'`，末尾不带 `'/'`（根目录除外）。`1 <= path.length <= 3000`，`path` 由字母、数字、`'.'`、`'/'`、`'_'` 组成。例：`"/home//foo/"` → `"/home/foo"`，`"/../"` → `"/"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`..` 回到上一级」「进入目录、退出目录」→ 后进先出 → **栈**。
- 「多个斜杠、结尾斜杠」→ 按 `'/'` 切分后，空串直接丢弃，一次处理完。
- 「`...` 是合法名字」→ 只有**恰好**等于 `'.'` 或 `'..'` 的段才特殊，别用前缀判断。
- 「根目录没有上一级」→ `..` 遇到空栈要忽略（边界条件）。
- `n <= 3000`：没有性能压力，一趟 `O(n)` 即可，考察的是规则覆盖。

**推导链。**
1. 暴力：反复做字符串替换（去 `//`、`/./`、`/x/../`），每次替换重扫整串，边界极易漏。
2. 浪费：多次扫描 + 字符串拷贝；根目录、`...` 等边界用替换规则很难表达。
3. 洞察：每一段只与栈顶有关：名字入栈、`..` 弹栈、`.` 与空串无效。
4. 最优：`split('/')` 后一趟扫描，最后 `'/' + '/'.join(stack)`，`O(n)`。

**同模式的题**：LC 20 有效的括号、LC 394 字符串解码、LC 1047 删除字符串中的所有相邻重复项、LC 1598 文件夹操作日志搜集器。
