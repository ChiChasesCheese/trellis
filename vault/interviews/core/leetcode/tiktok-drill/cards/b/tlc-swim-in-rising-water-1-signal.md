## Q
**LC 778 水位上升的泳池中游泳**｜Hard · TikTok 高频

`n x n` 矩阵 `grid`，`grid[i][j]` 是平台高度，时间 `t` 时水位为 `t`。相邻（上下左右）两个平台在水位同时淹没它们时才能游过去，移动不耗时。从 `(0, 0)` 出发，求到达 `(n-1, n-1)` 的最少时间。`1 <= n <= 50`，`0 <= grid[i][j] < n^2`，高度互不相同。例：`[[0,2],[1,3]]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「路径」+「路径上的**最大值**要最小」→ **瓶颈路径 / minimax**：不是最短路径和，而是最小化最大值。
- 三种同源解法：Dijkstra 把 `+` 换成 `max`；对水位二分、每次 BFS 判断连通；并查集按高度从小到大加点。
- 高度互不相同且是 `0..n^2-1` 的排列 → 可以按高度直接定位每个格子，并查集不用排序。
- `n <= 50`：`2500` 个格子，`O(n^2 log n)` 毫无压力。

**推导链。**
1. 暴力：对每个水位 `t = 0, 1, ...` 做一次 BFS，看高度 `<= t` 的格子里起点终点是否连通，`O(n^4)`。
2. 观察：水位越高越容易连通，答案具有单调性，可以对 `t` 二分，`O(n^2 log n)`。
3. 更直接：堆里存 `(到该格所需的最低水位, 格子)`，每次弹出最小的；邻格的所需水位 = `max(当前水位, 邻格高度)`。路径的瓶颈值沿路径单调不减，正好满足 Dijkstra 的条件。
4. 第一次弹出终点时的键就是答案，每格入堆一次，`O(n^2 log n)`。

**同模式的题**：LC 1631 最小体力消耗路径、LC 1102 得分最高的路径、LC 743 网络延迟时间、LC 1514 概率最大的路径。
