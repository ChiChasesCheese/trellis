## Q
**LC 16 最接近的三数之和**｜Medium · LC 字节 热度 50/100 · CodeTop 国内累计 23 次 · 最近 2026-05-06（CodeTop）

给长度为 `n` 的整数数组 `nums` 和整数 `target`，从中选三个不同下标的整数，使其和与 `target` 最接近，返回这个和。假定每组输入恰有一个解。

约束：`3 <= nums.length <= 1000`，`-1000 <= nums[i] <= 1000`，`-10^4 <= target <= 10^4`。例：`[-1,2,1,-4], target = 1` → `2`；`[0,0,0], target = 1` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「选三个数、和与目标比较」→ 3Sum 家族：排序后固定一个数，其余两个用对撞双指针（two pointers）。
- 「最接近」而不是「等于」→ 每一步都要更新最优（用 `abs(和 - target)` 比较），而不只是判断是否命中；恰好命中时可以提前返回。
- `n <= 1000` → `O(n^3)` 约 `10^9` 超时，`O(n^2)` 约 `10^6` 正好。
- 「不同下标」而非"不同值"→ 重复的数值可以同时被选，去重只是优化，不是正确性的要求。

**推导链。**
1. 暴力：三重循环，`O(n^3)`。
2. 浪费：固定第一个数后，内层是在有序数组里找两数之和逼近某个值，不需要两重循环。
3. 洞察：和偏小则排除左端点（它与任何更小的右端搭配只会更小），和偏大则排除右端点；每步排除一个，内层 `O(n)`。
4. 最优：排序 + 外层枚举 + 内层双指针，总 `O(n^2)`。

**同模式的题**：LC 15 三数之和、LC 18 四数之和、LC 259 较小的三数之和、LC 167 两数之和 II。
