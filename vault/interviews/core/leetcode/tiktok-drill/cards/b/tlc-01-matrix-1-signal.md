## Q
**LC 542 01 矩阵**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-04-14（CodeTop）

给由 `0` 和 `1` 组成的 `m x n` 矩阵 `mat`，返回同样大小的矩阵，每个格子的值是该位置到最近的 `0` 的距离；上下左右相邻的两个格子距离为 `1`。`1 <= m, n <= 10^4`，`1 <= m * n <= 10^4`，`mat[i][j]` 是 `0` 或 `1`，`mat` 中至少有一个 `0`。例：`mat = [[0,0,0],[0,1,0],[1,1,1]]` → `[[0,0,0],[0,1,0],[1,2,1]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格里每个点到**最近的**某类点的距离」+ 每步代价都是 1 → **BFS**（无权最短路）。
- 「最近的**任意一个** 0」→ **多源 BFS**（multi-source BFS）：把所有 `0` 同时入队当作第 0 层，反向从目标出发，一次搜索覆盖整张图。
- `m * n <= 10^4`（`m` 或 `n` 可达 `10^4`）→ 目标 `O(mn)`；对每个 `1` 各搜一次是 `O((mn)^2)` 约 `10^8`，太慢。

**推导链。**
1. 暴力：对每个 `1` 做一次 BFS 找最近的 `0`，`O((mn)^2)`。
2. 浪费：每次 BFS 都从头扩张，相邻格子的搜索范围大量重叠。
3. 洞见：反过来，从所有 `0` 同时出发——距离 0 的是所有 `0`，距离 1 的是它们的邻居，……这是一次以 `0` 的集合为起点的 BFS 分层。
4. 最优：队列初始放入所有 `0`，弹出一个格子就给未访问邻居赋 `dist + 1` 并入队，每格一次，`O(mn)`。

**同模式的题**：LC 994 腐烂的橘子、LC 286 墙与门、LC 1162 地图分析、LC 1091 二进制矩阵中的最短路径。
