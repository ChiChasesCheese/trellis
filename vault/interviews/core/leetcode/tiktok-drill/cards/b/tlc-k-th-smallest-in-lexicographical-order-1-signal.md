## Q
**LC 440 字典序的第 K 小数字**｜Hard · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 40 次 · 最近 2026-10-28（国内 CodeTop）

给定整数 `n` 和 `k`，返回 `[1, n]` 中字典序第 `k` 小的数字。

约束：`1 <= k <= n <= 10^9`。例：`n = 13, k = 2` → `10`（字典序是 `[1, 10, 11, 12, 13, 2, 3, …, 9]`）；`n = 1, k = 1` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「字典序」→ 数字当字符串比较，等价于十叉前缀树（Trie）的先序遍历：`x` 的孩子是 `10x..10x+9`。
- 「第 `k` 小」→ 在有序结构里按子树大小定位：整棵子树占先序里连续的一段，能整段跳过。
- `n` 到 `10^9` → 不能排序，也不能一个一个走 `k` 步（`O(k)` 太慢）；必须 `O(log^2 n)` 这样的量级。
- 子树大小 → 逐层区间 `[lo, hi)` 与 `[1, n]` 求交，最多十层，一个小循环。

**推导链。**
1. 暴力：`sorted(range(1, n + 1), key=str)`，`O(n log n)` 时间、`O(n)` 空间；`n = 10^9` 不可行。
2. 改进：按"字典序下一个数"规则迭代 `k` 步，`O(k)`，`k` 同样可能是 `10^9`。
3. 洞察：以 `cur` 为根的子树里有 `size` 个数。若 `size <= 剩余步数`，整棵跳过到 `cur + 1`；否则下钻到 `cur * 10`，消耗 1 步。
4. 最优：`count(prefix)` 逐层累加 `min(n + 1, hi) - lo`，每次 `O(log n)`；跳转次数 `O(log n)`，总 `O(log^2 n)`。

**同模式的题**：LC 386 字典序排数、LC 60 排列序列、LC 668 乘法表中第 k 小的数、LC 378 有序矩阵中第 K 小的元素。
