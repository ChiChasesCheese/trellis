## Q
**LC 260 只出现一次的数字 III**｜正确性

为什么按「`a ^ b` 里为 1 的某一位」分组，能保证两个落单数进不同组、成对的数进同一组？如果随手取了一位（比如最低位 `x & 1`）会怎样？

## A
**不变量。** 分组依据是位 `p`，满足 `(a ^ b)` 的第 `p` 位为 1，也就是 `a`、`b` 在第 `p` 位**一个 0 一个 1**。
- `a`、`b` 一个第 `p` 位是 1、一个是 0 → 进不同的组。
- 成对的两个数值相同，第 `p` 位也相同 → 进同一组，且两份都在，组内异或后抵消。
- 因此每组异或的结果恰是该组的那个落单数。

**反例：随手取第 0 位。** `[1,2,1,3,2,5]`：`a = 3`，`b = 5`，`a ^ b = 6`（`110`），第 0 位是 0，说明 `3`（`011`）与 `5`（`101`）在第 0 位相同（都是 1）。按 `x & 1` 分组：第 0 位为 1 的是 `1, 1, 3, 5`，异或 `3 ^ 5 = 6`；为 0 的是 `2, 2`，异或 `0`。输出 `[6, 0]`，正确 `[3, 5]`。两个落单数被分到同一组，那一组仍是两个落单数的异或，没拆开。
