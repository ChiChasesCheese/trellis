## Q
**LC 1997 访问完所有房间的第一天**｜Medium · 字节 高频

有 `n` 个房间，编号 `0` 到 `n - 1`，日期从 `0` 开始，每天访问一个房间，第 `0` 天访问房间 `0`。给定 `nextVisit`：今天访问房间 `i`，算上今天访问 `i` 的总次数为奇数时，第二天去 `nextVisit[i]`；为偶数时，第二天去 `(i + 1) mod n`。返回第一次访问完所有房间的日期，对 `10^9 + 7` 取余。`2 <= n <= 10^5`，`0 <= nextVisit[i] <= i`。例：`[0,0,2]` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「答案对 `10^9 + 7` 取余」→ 天数指数级增长，**不能逐天模拟**，要找递推。
- 「`nextVisit[i] <= i`，只往回跳」→ 状态有层次：到达房间 `i` 之前，更小的房间都已经走过，可以按"第一次到达第 `i` 个房间的日期"做一维 DP。
- 「奇数次回跳、偶数次前进」→ 每个房间要被访问**两次**才能前进，来回的路程可以复用之前算过的结果。
- `n <= 10^5`：`O(n)` 递推。

**推导链。**
1. 暴力：逐天模拟，天数可达 `2^n` 量级。
2. 浪费：回跳之后重走的路，和第一次走的完全一样。
3. 洞察：第一次到房间 `i` 时，所有更小的房间都已被访问偶数次（状态归零）。回到 `nextVisit[i]` 后重走到 `i` 的路程等于 `first[i] - first[nextVisit[i]]`。
4. 递推：`first[i+1] = first[i] + 1 + (first[i] - first[nextVisit[i]]) + 1`，答案 `first[n-1]`，`O(n)`。

**同模式的题**：LC 70 爬楼梯、LC 509 斐波那契数、LC 1137 第 N 个泰波那契数、LC 198 打家劫舍。
