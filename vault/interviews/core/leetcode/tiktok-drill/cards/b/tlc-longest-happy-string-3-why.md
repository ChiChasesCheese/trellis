## Q
**LC 1405 最长快乐字符串**｜正确性

为什么每次放剩余最多的字母是对的？当它已经连着两个时，为什么要垫次多的字母而不是直接结束？

## A
**不变量。** 每一步都把「剩余最多的字母」放在可行的位置；任何一个最优解都可以通过交换变成按此顺序构造（交换论证）。

**为什么先放最多的。** 字母越多，越需要被其它字母隔开：一个字母 `x` 若有 `m` 个，至少需要 `⌈m/2⌉ - 1` 个别的字母把它们隔成每段 `<= 2`。先放它相当于尽早消耗这个最紧的资源；如果先放少的字母，到最后只剩多的字母时，连续上限会迫使字符串提前结束。

**为什么垫而不是结束。** 「连着两个」只说明这一步不能放它，别的字母仍然可以放；垫一个次多的字母后，末尾变了，最多的字母又可以放。只有在没有别的字母可垫时才不得不结束，此时也是最长的。

**反例。** `a = 1, b = 1, c = 7`：
- 遇到上限直接结束：`cc` 之后停止，长度 `2`；
- 不管连续个数永远取最多的：`ccccccabc`，含 `ccc`；
- 垫字母但忘记放回 `c`：`ccab`，长度 `4`；
- 正确的贪心：`cc` `a` `cc` `b` `cc`，共 `8` 个，用满所有 `a`、`b` 作隔板，`c` 放了 `6` 个，这就是最长。
