## Q
**LC 2196 根据描述创建二叉树**｜Medium · TikTok 高频

给二维整数数组 `descriptions`，`descriptions[i] = [parent_i, child_i, isLeft_i]` 表示 `parent_i` 是 `child_i` 的父节点，各节点的值互不相同；`isLeft_i == 1` 时 `child_i` 是左子节点，`isLeft_i == 0` 时是右子节点。按描述构造二叉树并返回根节点，保证构造出的是有效二叉树。`1 <= descriptions.length <= 10^4`，`1 <= parent_i, child_i <= 10^5`，`0 <= isLeft_i <= 1`。例：`[[1,2,1],[2,3,0],[3,4,1]]` → 层序 `[1,2,null,null,3,4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 树以「边的列表」给出且顺序任意 → 先建节点再连边，用哈希表 `值 -> 节点`，不依赖输入顺序。
- 「节点值互不相同」→ 值本身就是键，不需要额外编号。
- 「保证是有效二叉树」→ 恰好有一个节点没有父亲，根 = 入度为 `0` 的节点。
- `n <= 10^4`、值 `<= 10^5`：`O(n)` 的单遍扫描足够，不需要排序。

**推导链。**
1. 暴力：反复扫描描述，只在父节点已经建好时才挂子节点，直到全部处理完，最坏 `O(n^2)`；或先拓扑排序再建，多一个排序的代价。
2. 浪费：这些做法都在为「父亲还没出现」绕路。
3. 洞察一：节点在第一次被提到（无论作为父还是子）时就创建，之后连边与顺序无关。
4. 洞察二：每条描述同时给出一个父和一个子；把所有父收成集合 `parents`，所有子收成集合 `children`，根 `= parents - children`。
5. 最优：一遍扫描，字典加两个集合，`O(n)` 时间、`O(n)` 空间，没有递归。
