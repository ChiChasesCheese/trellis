## Q
**LC 343 整数拆分**｜Medium · CodeTop 国内累计 9 次 · 最近 2026-06-04（CodeTop）

给正整数 `n`，把它拆成 `k` 个**正整数**的和（`k >= 2`），使这些整数的乘积最大，返回最大乘积。`2 <= n <= 58`。例：`n = 10` → `36`（`3 + 3 + 4`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「把 `n` 拆成若干份、求乘积最大」→ **拆分型 DP**：第一块切掉后，剩余部分是同一问题的更小规模。
- `n <= 58` → `O(n^2)` 绰绰有余；这个小范围也暗示答案会很大（`n = 58` 时约 `1.5 * 10^9`），Python 整数无需担心溢出。
- 「最大乘积」加「正整数」→ 最优解里有规律（尽量多的 `3`），是**数学 / 贪心**的信号，可以作为 `O(1)` 的优化。

**推导链。**
1. 暴力：枚举所有整数划分，数量指数级增长。
2. 浪费：不同的前缀会反复求同一个剩余值的最优拆分。
3. 洞察：`dp[i] = max(j * (i - j), j * dp[i - j])`，对 `j` 取最大；`i - j` 可以整块保留，也可以继续拆。
4. 最优：`O(n^2)` 的一维 DP；再观察到最优解里只有 `2`、`3`、`4`，推出「拆 `3`」的 `O(1)` 公式。
