## Q
**LC 561 数组拆分 I**｜正确性

为什么「排序后相邻配对」是最优的？用交换论证说明，并给出「最大配最小」这种直觉配对出错的输入。

## A
**交换论证。** 排序后 `x_1 <= x_2 <= … <= x_2n`。
- 任意配对中，`x_1` 所在的对贡献的一定是 `x_1`。设最优解里 `x_1` 配的是 `x_j`（`j != 2`），而 `x_2` 配的是 `y`。
- 交换成 `(x_1, x_2)` 和 `(x_j, y)`：原来两对贡献 `x_1 + min(x_2, y) = x_1 + x_2`（因为 `x_2 <= x_j`、`x_2 <= y`，`x_2` 是这三个里最小的）；交换后贡献 `x_1 + min(x_j, y) >= x_1 + x_2`。不会变差。
- 所以存在最优解包含 `(x_1, x_2)`；去掉这两个数，对剩下的 `2n - 2` 个数用同样的论证，得到 `(x_3, x_4), …`。

**不变量。** 每一步都保证「存在一个最优解，它包含目前已经确定的所有对」。

**反例：最大配最小。** 排序后让 `x_1` 配 `x_2n`、`x_2` 配 `x_2n-1`……
- `[1,4,3,2]`：`(1,4), (2,3)`，和为 `1 + 2 = 3`；正确 `(1,2), (3,4)` 得 `4`。
- `[6,2,6,5,1,2]`：`(1,6), (2,6), (2,5)` 得 `5`；正确 `(1,2), (2,5), (6,6)` 得 `9`。
