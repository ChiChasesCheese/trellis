## Q
**LC 772 基本计算器 III**｜正确性

为什么「项列表 + 括号栈」能同时处理优先级和嵌套？`)` 弹出后为什么把括号的值交给原来的运算符，而不是直接追加？

## A
**不变量。** 扫描到任一位置时：`terms` 是当前括号层里已经确定的「加法项」（其中最后一项可能还会被后续的 `*` / `/` 改写）；`op` 是即将与 `num` 结合的运算符；`saved` 栈从底到顶是外层各层的现场。

**优先级。** 加法项之间只有加减；`*` 与 `/` 总是和紧挨着的前一项结合，所以立刻改写 `terms[-1]`，而 `+` / `-` 只是决定下一项的符号。这样乘除天然先于加减，不需要比较优先级。

**嵌套。** 括号里的内容是一个独立的、自包含的表达式，求值结果是一个整数。`(` 时保存的 `(terms, op)` 正是「括号之前外层的状态 + 括号前的运算符」；`)` 后恢复它，括号的值像普通数字一样等待下一个运算符（或 `)`）触发 `apply`，于是 `6-(1+2)` 里的值 `3` 会按保存的 `-` 并入外层。

**反例。**
- 直接追加括号值而不用保存的运算符：`6-(1+2)` 得 `9`，正确是 `3`；`2*(3+4)` 得 `2+7 = 9`，正确是 `14`。
- 从左到右不分优先级：`6-4/2` 得 `1`，正确是 `4`。
- 除法用 `//`：`(0-3)/2` 得 `-2`，向零截断应得 `-1`。
