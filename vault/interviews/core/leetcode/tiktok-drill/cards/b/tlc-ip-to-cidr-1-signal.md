## Q
**LC 751 IP 到 CIDR**｜Medium · CodeTop 国内累计 1 次 · 最近 2023-12-16（CodeTop）

IPv4 地址是 32 位无符号整数，按 8 位一组用点分隔。**CIDR 块** `基础IP/k` 覆盖前 `k` 位与基础 IP 相同的全部地址，共 `2^(32-k)` 个。给起始地址 `ip` 和数量 `n`，用**最少**的 CIDR 块恰好覆盖 `[ip, ip + n - 1]`，不能覆盖范围外的地址。`7 <= ip.length <= 15`，`ip` 有效，`1 <= n <= 1000`，范围内地址都有效。例：`ip = "255.0.0.7"`，`n = 10` → `["255.0.0.7/32","255.0.0.8/29","255.0.0.16/32"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少的块」+「每块大小是 2 的幂且起点对齐」→ **二进制低位贪心**：每次切出能切的最大块。
- IP 与整数互相转换 → 先把四段合成一个 32 位整数 `x`，所有运算在整数上做，最后再格式化。
- 合法块的条件：大小 `2^j`，起点 `x` 的低 `j` 位全为 `0`；`x & -x` 正好给出 `x` 能对齐到的最大块。
- `n <= 1000` → 块数很少，不需要任何复杂数据结构。

**推导链。**
1. 暴力：每个地址一个 `/32`，合法但不是最少。
2. 想合并：最大的合法块要同时满足两个上限——不超过剩余数量 `n`（`1 << (n.bit_length() - 1)`），以及起点对齐（`x & -x`）。
3. 贪心：从 `x` 开始必然要有一个块，选最大的合法块不会更差，剩下是同类的更短问题。
4. 循环：`x += size`，`n -= size`，直到 `n == 0`；前缀长度 `33 - size.bit_length()`。起点为 `0` 时 `x & -x == 0`，要当作不受对齐限制。

**同模式的题**：LC 468 验证 IP 地址、LC 93 复原 IP 地址、LC 191 位 1 的个数、LC 231 2 的幂。
