## Q
**面试题 16.07 最大数值**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-06-08（国内 CodeTop）

写一个方法，找出两个整数 `a` 和 `b` 中较大的那个，**不得使用 if-else 或其他比较运算符**（`<`、`>`、`==` 等，也不能调用 `max`）。例：`a = 1, b = 2` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「不得使用 if-else 或比较运算符」→ 把比较换成**算术/位运算**：大小关系可以从 `a - b` 的**符号**读出来。
- 「得到一个 0/1 的开关再选值」→ **无分支选择**（branchless select）：`result = a - neg * (a - b)`，`neg` 是 0 或 1。
- 语言差异是考点：Python 整数无限精度、不会溢出；C++/Java 的 `a - b` 可能溢出，要先升到 `long`，右移位数也要按位宽写。

**推导链。**
1. 直接写 `max(a, b)` 或三目运算符：被题目禁止。
2. 代数：`max = (a + b + |a - b|) / 2`。依赖 `abs`（灰色地带），而且 `/` 会产生浮点数，大数精度丢失。
3. 洞见：比较的信息全在 `diff = a - b` 的符号里；Python 对负数右移是算术右移，足够大的右移位数能把符号变成 `-1` 或 `0`。
4. 最优：`neg = (diff >> diff.bit_length()) & 1`，返回 `a - neg * diff`，`O(1)`、无分支、无比较。

**同模式的题**：LC 371 两整数之和、LC 29 两数相除、LC 136 只出现一次的数字、LC 190 颠倒二进制位。
