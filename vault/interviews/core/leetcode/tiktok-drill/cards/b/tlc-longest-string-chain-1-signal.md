## Q
**LC 1048 最长字符串链**｜Medium · TikTok 高频

给小写单词数组 `words`。在 `wordA` 的任意位置添加恰好一个字母（不改变其他字符的顺序）能得到 `wordB`，则 `wordA` 是 `wordB` 的前身。词链是每个单词都是下一个单词前身的序列（单个单词的长度为 `1`）。返回词链的最长可能长度。`1 <= words.length <= 1000`，`1 <= words[i].length <= 16`。例：`["a","b","ba","bca","bda","bdca"]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「链」+「相邻单词满足前身关系」→ DAG 上的**最长路径**，与最长递增子序列同构，用 **动态规划**。
- 前身关系要求长度恰好差 `1` → 单词按长度分层，**按长度排序**后依赖关系只指向更短的词。
- 长度上限 `16` → 对每个词，"删去一个字母"至多 `16` 个候选，用**哈希表**直接查，比两两判断关系便宜得多。
- `N <= 1000` → `O(N * L^2)` 毫无压力。

**推导链。**
1. 暴力：对每对单词判断前身关系，再做 LIS 式 DP，`O(N^2 * L)`。
2. 浪费：一个单词的前身最多 `L` 个候选（删去第 `i` 个字母），却和另外 `N` 个词逐个比较。
3. 关键：`dp[w] = 1 + max(dp[w 删去一个字母])`，候选不在表里按 `0` 处理。
4. 排序：先按长度升序处理所有词，保证候选（更短）已经算好。答案 `max(dp.values())`。
