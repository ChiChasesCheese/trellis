## Q
**LC 221 最大正方形**｜正确性

为什么 `dp[i][j] = min(上, 左, 左上) + 1`？如果只取「上」和「左」的最小值会错在哪？给出具体输入。

## A
**不变量。** `dp[i][j]` 是以 `(i, j)` 为右下角、全由 `'1'` 组成的最大正方形的边长 `s`。一个边长 `s` 的正方形去掉最外圈的最后一行和最后一列后，需要同时满足：
- 它的上方邻居 `(i-1, j)` 能撑起边长 `s-1` 的正方形（覆盖右上那一块），
- 它的左方邻居 `(i, j-1)` 能撑起边长 `s-1` 的正方形（覆盖左下那一块），
- 它的左上邻居 `(i-1, j-1)` 能撑起边长 `s-1` 的正方形（覆盖左上那一块）。

三块合起来再加上 `(i, j)` 自己，恰好铺满 `s×s`，所以 `s - 1` 不能超过三者中最小的那个，且取最小值时一定成立。

**反例：漏掉左上。** 矩阵
```
1 1 1
1 0 1
1 1 1
```
- 右下角 `(2, 2)` 的上邻居 `dp = 1`，左邻居 `dp = 1`，左上邻居是中间的 `0`，`dp = 0`。
- 只取上、左的最小值会得到 `1 + 1 = 2`，面积 `4`。
- 正确是 `min(1, 1, 0) + 1 = 1`，面积 `1`：中间的 `0` 在任何 `2×2` 正方形里都会出现。

**另一个常见错误。** 返回最大边长而不是面积：题面例 1 的最大边长是 `2`，答案应是 `4`。
