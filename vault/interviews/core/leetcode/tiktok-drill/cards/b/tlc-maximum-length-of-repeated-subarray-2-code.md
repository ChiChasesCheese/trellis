## Q
**LC 718 最长重复子数组**｜写出 Python 实现

两个整数数组 `nums1`、`nums2`，长度都在 `[1, 1000]`，值在 `[0, 100]`。返回两个数组公共的最长**连续**子数组的长度，要求 `O(m·n)` 时间，空间尽量小。

## A
**思路。** `dp[i][j]` 是以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的最长公共子数组长度。第 `0` 行、第 `0` 列表示空前缀，全为 `0`。逐行逐列填表：两个元素相等，`dp[i][j] = dp[i-1][j-1] + 1`（接在上一对后面）；不相等，保持 `0`（子数组在这里断开）。同时维护全表最大值。

```python
def find_length(nums1: list[int], nums2: list[int]) -> int:
    m, n = len(nums1), len(nums2)
    # dp[i][j]：以 nums1[i-1] 和 nums2[j-1] 结尾的最长公共子数组长度；第 0 行 / 第 0 列是空前缀，全为 0
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    best = 0
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if nums1[i - 1] == nums2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1    # 左上角加一：把这一对接在上一对后面
                best = max(best, dp[i][j])
            # 不相等：dp[i][j] 保持 0，子数组必须连续，到此断开
    return best                                    # 答案是全表最大值，不是 dp[m][n]
```

运行：`([1,2,3,2,1], [3,2,1,4,7])` → `3`，`([0]*5, [0]*5)` → `5`，`([1], [2])` → `0`，`([1,2,3], [1,3])` → `1`；两个 `1000` 个元素的随机数组约 `0.02` 秒，全零数组约 `0.05` 秒。

**复杂度。** 时间 `O(m·n)`，约 `10^6` 次比较；空间 `O(m·n)`，整张表。

**写法要点。** `[[0] * (n + 1) for _ in range(m + 1)]` 每行是独立的列表，多留的第 `0` 行、第 `0` 列是哨兵，让 `dp[i-1][j-1]` 在 `i = 1` 或 `j = 1` 时指向空前缀；去掉哨兵、表开成 `m × n` 时，`i = 0` 或 `j = 0` 的 `dp[i-1][j-1]` 会用负下标回绕到最后一行 / 最后一列，不报错但悄悄出错：`([0], [0,0])` 得到 `2`，正确是 `1`。下标整体错开一位，所以比较的是 `nums1[i - 1]` 和 `nums2[j - 1]`。不相等的格子不用写，保持建表时的 `0`；`best` 只在匹配时更新。
