## Q
**LC 1493 删掉一个元素以后全为 1 的最长子数组**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-03-30（国内 CodeTop）

二进制数组 `nums`，必须删除一个元素，求删除后仅含 `1` 的最长非空子数组长度，没有则返回 `0`。`1 <= nums.length <= 10^5`，`nums[i]` 为 `0` 或 `1`。例：`[0,1,1,1,0,1,1,0,1]` → `5`；`[1,1,1]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连续**子数组」+「**最长**」+ 窗口内某类元素不超过 `k` 个 → **可变长滑动窗口**，这里 `k = 1`（`0` 的个数）。
- 「删除一个元素」→ 等价于「窗口里允许有一个 `0`」，然后窗口长度减 `1`。
- `n = 10^5` → 需要 `O(n)`；枚举删除位置再扫描是 `O(n^2)`。
- 「必须删」→ 全是 `1` 的数组答案是 `n - 1`，不是 `n`，这是边界。

**推导链。**
1. 暴力：枚举删除位置（`n` 种），每种扫描求最长连续 `1`，`O(n^2)`。
2. 浪费：删一个元素只影响它两侧的连续 `1`，其余部分重复扫描。
3. 洞察：删一个元素后的最长全 `1` 段 = 原数组「至多一个 `0` 的最长窗口」的长度减 `1`（窗口里那个 `0` 被删；没有 `0` 时也得删一个，也是减 `1`）。
4. 最优：右端扩张，`0` 的个数超过 `1` 就收缩左端，`best = max(best, right - left)` → `O(n)`。

**同模式的题**：LC 1004 最大连续 1 的个数 III、LC 487 最大连续 1 的个数 II、LC 424 替换后的最长重复字符、LC 3 无重复字符的最长子串。
