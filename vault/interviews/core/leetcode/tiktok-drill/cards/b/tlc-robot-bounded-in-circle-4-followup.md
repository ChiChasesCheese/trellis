## Q
**LC 1041 困于环中的机器人**｜追问

面试官接着问：（1）有障碍物，机器人遇到障碍就不动，怎么判断？（2）要求输出机器人走过的最远欧氏距离的平方？（3）能不能不用向量，用方位编号做？

## A
1. **障碍物**：`G` 之前先检查 `(x + dx, y + dy)` 是否在障碍集合里，是则原地不动。此时一轮不再是固定的「旋转加平移」（结果取决于出发位置），上面的 4 轮结论失效，只能直接模拟：每轮结束记录状态 `(x, y, 朝向)` 放进集合，出现重复状态就说明进了环；一旦远离所有障碍的范围，行为就退回到无障碍的情形。
2. **最远距离**（无障碍）：模拟 4 轮，每走一步更新 `max(x*x + y*y)`，4 轮之后的轨迹只是重复。有障碍的版本是 LC 874，障碍用 `set[tuple[int, int]]`，查询 `O(1)`。
3. **方位编号**：`dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]`，`d = 0` 朝北；`L`：`d = (d - 1) % 4`；`R`：`d = (d + 1) % 4`；`G`：`x += dirs[d][0]` 等。最后判断 `d != 0`。Python 的 `%` 对负数返回非负余数，所以 `(0 - 1) % 4 == 3` 不用特判。

**Python 提醒**：用复数当向量很短：`pos += d`；`L` 是 `d *= 1j`，`R` 是 `d *= -1j`。小整数在浮点里精确，可以放心比较；但整数向量更直观、也不会引入精度疑虑，面试里优先用元组。
