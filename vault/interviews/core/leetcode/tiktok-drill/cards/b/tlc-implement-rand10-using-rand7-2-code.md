## Q
**LC 470 用 Rand7() 实现 Rand10()**｜写出 Python 实现

已给 `rand7()`，等概率返回 `[1, 7]` 内的整数；只用它写 `rand10()`，等概率返回 `[1, 10]` 内的整数。`rand10()` 会被调用至多 `10^5` 次。

## A
**思路。** 两次 `rand7()` 拼成 `[1, 49]` 上的均匀整数；`idx > 40` 就丢弃重抽，`idx <= 40` 时每个结果对应恰好 `4` 个 `idx`，取模得到 `[1, 10]`。

```python
import random


def rand7() -> int:                    # 题目提供：[1, 7] 上的均匀随机整数
    return random.randint(1, 7)


def rand10() -> int:
    while True:
        idx = (rand7() - 1) * 7 + rand7()   # 两次调用拼成 1..49 上的均匀分布
        if idx <= 40:                       # 只保留 40 个，拒绝 41..49 后重来
            return (idx - 1) % 10 + 1       # 40 = 4 * 10，每个结果恰好 4 个 idx
```

运行：`49` 个有序对 `(a, b)` 里，`idx <= 40` 的有 `40` 个，`1..10` 各恰好 `4` 个，`9` 个被拒绝；`random.seed(0)` 后调用 `rand10()` `10^5` 次，`1..10` 出现的次数依次是 `10258, 9994, 9876, 10026, 9929, 10150, 9862, 9986, 9735, 10184`，最小值 `1`、最大值 `10`，平均每次消耗 `2.45028` 次 `rand7()`。

**复杂度。** 期望时间 `O(1)`：每轮 `2` 次调用、成功概率 `40/49`，期望 `2 × 49/40 = 2.45` 次 `rand7()`；最坏情况无上界，但连续 `k` 轮被拒的概率是 `(9/49)^k`；空间 `O(1)`。

**写法要点。** `(a - 1) * 7 + b` 是「七进制两位数 + 1」，把有序对一一映射到 `1..49`，先减一让低位从 `0` 起算。`while True` 加 `return` 比「先抽一次、再 `while idx > 40` 重抽」少一份重复代码。`(idx - 1) % 10 + 1` 先减一把区间移到 `0` 起点，取模后再加回。`random.randint(a, b)` 两端都包含，`random.randrange(a, b)` 不含右端，写 stub 时别混。
