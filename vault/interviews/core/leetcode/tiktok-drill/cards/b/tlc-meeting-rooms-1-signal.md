## Q
**LC 252 会议室**｜Easy · LC TikTok 热度 50/100 · CodeTop 国内累计 3 次 · 最近 2022-03-09（国内 CodeTop）

给会议时间数组 `intervals`，`intervals[i] = [start_i, end_i]`。判断一个人能否参加所有会议（任意两个会议不重叠；在时间 `t` 结束的会议和在时间 `t` 开始的会议不重叠）。`0 <= intervals.length <= 10^4`，`0 <= start_i < end_i <= 10^6`。例：`[[0,30],[5,10],[15,20]]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「区间是否重叠 / 合并 / 调度」→ 区间题的统一入口：**先排序**（按起点）。
- 排序后，重叠只可能发生在**相邻**区间之间——把「任意两个」变成「相邻两个」。
- 「在 `t` 结束和在 `t` 开始不重叠」→ 边界相接算不重叠，比较要写 `prev_end <= cur_start`。
- `n <= 10^4`：`O(n^2)` 两两比较约 `5 · 10^7` 次，Python 里偏慢；`O(n log n)` 轻松。

**推导链。**
1. 暴力：对每一对会议判断 `a.start < b.end and b.start < a.end`，`O(n^2)`。
2. 浪费在哪：大多数会议对相距很远，不可能重叠，但仍被比较。
3. 洞察：按起点排序后，如果第 `i` 个与后面第 `j` 个重叠（`start_j < end_i`），那么第 `i+1` 个的起点 `start_{i+1} <= start_j < end_i`，也与第 `i` 个重叠。所以只要有重叠，必有相邻的重叠对。
4. 最优：排序 + 一趟扫描相邻对，`O(n log n)`。
