## Q
**LC 416 分割等和子集**｜Medium · TikTok 高频

给一个只含正整数的非空数组 `nums`，判断能否分成两个子集使两个子集的元素和相等。`1 <= nums.length <= 200`，`1 <= nums[i] <= 100`。例：`[1,5,11,5]` → `true`，`[1,2,3,5]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「分成两个子集，和相等」→ 总和 `S` 必须是偶数，等价于**选一个子集，和恰为 `S/2`**。
- 「每个数用或不用，各一次」→ **0/1 背包**（0/1 knapsack）的可行性版本：问的是「能否恰好装满容量 `S/2`」。
- 约束 `n <= 200`、`nums[i] <= 100` → `S <= 20000`，`n · S/2 ≈ 2 · 10^6`，可以用 **`O(n · S)`** 的 DP；指数级的子集枚举（`2^200`）不可能。
- 正整数 → 不用担心零或负数让「和」单调性失效。

**推导链。**
1. 暴力：枚举所有子集看和是否等于 `S/2`，`2^n`。
2. 回溯 + 记忆化：状态 `(i, 剩余目标)`，只有 `n · S/2` 个。
3. 自底向上：`dp[j]` = 能否凑出和 `j`。每个数 `x`，`dp[j] |= dp[j − x]`，`j` 必须**从大到小**，保证 `x` 只用一次。
4. 再进一步：`dp` 是 0/1 序列，用一个大整数的各个二进制位表示。「所有已有的和加上 `x`」就是 `bits << x`，再与原值取或：`bits |= bits << x`。位运算按机器字并行，`O(n · S / 64)`。

**同模式的题**：LC 494 目标和、LC 1049 最后一块石头的重量 II、LC 474 一和零、LC 698 划分为k个相等的子集。
