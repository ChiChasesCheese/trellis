## Q
**补充题 13 中文数字转阿拉伯数字**｜Medium · 字节高频｜写出 Python 实现

把规范书写的中文数字字符串（字符集 `零一二两三四五六七八九十百千万亿`，长度 `1` 到 `30`，结果 `0` 到 `10^12`）转成整数。要求一次扫描。

## A
**思路。** 三个累加器：`num`（未乘单位的个位数字）、`section`（当前万级块内的值）、`total`（已结算部分）。数字存进 `num`；遇到 `十百千`，把 `(num or 1) × 单位` 加进 `section`；遇到 `万`，把 `(section + num) × 10^4` 加进 `total`；遇到 `亿`，把 `total + section + num` 整体乘 `10^8`。最后返回三者之和。

```python
DIGITS = {"零": 0, "一": 1, "二": 2, "两": 2, "三": 3, "四": 4,
          "五": 5, "六": 6, "七": 7, "八": 8, "九": 9}
UNITS = {"十": 10, "百": 100, "千": 1000}


def chinese_to_int(s: str) -> int:
    total = 0       # 已结算的部分（万、亿级别的块）
    section = 0     # 当前块内（千位以内）已经算完的数
    num = 0         # 刚读到、还没乘单位的个位数字
    for ch in s:
        if ch in DIGITS:
            num = DIGITS[ch]
        elif ch in UNITS:                       # 十百千：乘到当前数字上；「十二」省略了前面的一
            section += (num or 1) * UNITS[ch]
            num = 0
        elif ch == "万":                         # 万：只结算上次万/亿以来的这一块
            total += (section + num) * 10_000
            section = num = 0
        else:                                    # 亿：前面攒下的全部都乘 1 亿
            total = (total + section + num) * 100_000_000
            section = num = 0
    return total + section + num
```

运行：`"一亿两千三百万零五"` → `123000005`，`"零"` → `0`，`"十"` → `10`，`"十二"` → `12`，`"两千零二"` → `2002`，`"三十亿零七"` → `3000000007`，`"一万亿"` → `1000000000000`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`（映射表是常数大小）。

**写法要点。** 用两个字典分别放数字和块内单位，`ch in DIGITS` 先判断类别，比一长串 `if ch == "一" or ...` 清楚；`(num or 1)` 利用 `0` 为假，一次补上省略的 `一`；`10_000` 和 `100_000_000` 用下划线分组，读起来不会数错零；最后的 `else` 只可能是 `亿`，因为输入保证合法。
