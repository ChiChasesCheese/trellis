## Q
**LC 976 三角形的最大周长**｜正确性

为什么降序排序后只检查**相邻**的三条边就够了？第一个成立的三元组为什么一定周长最大？只看最大三条边会错在哪？

## A
**丢弃最长边的理由。** 降序后 `a = nums[i]`，紧随其后的 `b, c` 是比 `a` 短（或相等）的边中最大的两条，`b + c` 是 `a` 能配到的最大两边和。若 `b + c <= a`，任何两条更短的边加起来也 `<= a`，`a` 不可能做最长边，可以永久丢掉。

**第一个成立即最大。** 扫描到 `i` 时，比 `a` 更长的边都已被丢掉，所有可行三角形的最长边 `<= a`；最长边为 `nums[j]`（`j >= i`）的三角形周长不超过 `nums[j] + nums[j+1] + nums[j+2]`，又不超过 `a + b + c`。

**反例：只看最大三条。** `[2,3,4,10]`：最大三条 `10,4,3` 因 `4 + 3 <= 10` 失败，只看这一组就返回 `0`；丢掉 `10` 后 `4,3,2` 满足 `3 + 2 > 4`，正确答案 `9`。
