## Q
**LC 140 单词拆分 II**｜Hard · LC TikTok 热度 62/100 · CodeTop 国内累计 6 次 · 最近 2026-04-01（国内 CodeTop）

给字符串 `s` 和字典 `wordDict`，在 `s` 中插入空格，使每个单词都在字典中，以任意顺序返回所有可能的句子。同一个单词可重复使用。`1 <= s.length <= 20`，`1 <= wordDict.length <= 1000`，`1 <= wordDict[i].length <= 10`，只含小写字母，字典中的词互不相同。例：`"catsanddog"` + `["cat","cats","and","sand","dog"]` → `["cats and dog","cat sand dog"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**方案」→ **回溯 / 搜索**，复杂度由输出规模决定，不是只求个数。
- 「同一个后缀会被不同的前缀拆法反复到达」→ **记忆化**（memoization）：`sentences(i)` 只依赖 `i`。
- `s.length <= 20`，单词长度 `<= 10` → 枚举第一个词的结束位置只需看至多 `10` 个；输出最多约 `2^19` 个句子，是预期的规模。
- 单词可重复使用 → 递归下一层不用排除已用的词。
- 「句子」要用空格拼接 → 末尾的空后缀不能多加空格。

**推导链。**
1. 暴力：从位置 `0` 开始，枚举所有能匹配字典的前缀，递归处理剩下的部分，走到末尾收集句子。
2. 浪费：不同前缀拆法会走到同一个位置 `j`，`s[j:]` 被一遍遍重新搜；如果 `s[j:]` 根本拆不了，每次到达都白搜整棵子树。
3. 洞察：`s[j:]` 的全部拆法与怎么走到 `j` 无关 → 每个位置只算一次，结果缓存（拆不了就缓存空）。
4. 最优：`@cache` 的 `sentences(i)`，返回元组；时间 `O(n · L)` 加上输出规模。

**同模式的题**：LC 139 单词拆分、LC 472 连接词、LC 93 复原 IP 地址、LC 131 分割回文串、LC 17 电话号码的字母组合。
