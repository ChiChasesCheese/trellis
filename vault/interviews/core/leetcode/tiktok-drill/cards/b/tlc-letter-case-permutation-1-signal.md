## Q
**LC 784 字母大小写全排列**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-03-14（CodeTop）

给字符串 `s`，把其中每个字母任意变成大写或小写（数字不变），返回能得到的**所有**字符串，顺序任意。`1 <= s.length <= 12`，`s` 只含大小写英文字母和数字。例：`"a1b2"` → `["a1b2","a1B2","A1b2","A1B2"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**可能」→ 枚举 / 回溯（backtracking）；输出有 `2^m` 个（`m` 为字母数），任何算法都至少是输出规模。
- `n <= 12` → 指数级 `2^12 = 4096` 完全可以接受，题目就是在考怎样干净地枚举。
- 每一位的选择互相独立（字母二选一、数字只有一种）→ 决策树按位置展开，等价于各位选项的笛卡尔积（Cartesian product）。

**推导链。**
1. 暴力：对 `n` 位都枚举大小写，`2^n` 个候选，再用集合去重。
2. 浪费：数字位的两个分支生成同一个字符串，数字越多重复越多。
3. 洞察：只在字母处分叉，数字直接下一位；不同的叶子至少在一个字母位上大小写不同，结果天然不重复。
4. 最优：回溯 + 原地修改字符列表，叶子处 `join` 一次，`O(2^m · n)`，等于输出总长度。
