## Q
**LC 2021 街上最亮的位置**｜正确性

为什么右端事件要放在 `pos + rng + 1`？为什么答案一定出现在某个事件坐标上，且严格大于才更新就能保证坐标最小？

## A
**不变量。** 处理完所有坐标不大于 `x` 的事件后，`cur` 等于位置 `x` 的亮度：灯的区间 `[l, r]` 在 `l` 处贡献 `+1`，到 `r + 1` 才撤销，所以 `l <= x <= r` 时恰好计入一次。两个相邻事件坐标之间亮度是常数，因此最大亮度必在某个事件坐标处首次达到，那个坐标是这个亮度值出现的最小位置。从小到大扫描、只在严格更大时更新，保留的就是最先达到最大值的坐标。

**反例（错误写法一）：右端事件放在 `pos + rng`。** 区间是闭区间，右端点本身仍被照亮。`[[1,0],[0,1]]`：第一盏灯的 `+1` 和 `-1` 都落在坐标 `1`，互相抵消，坐标 `1` 的亮度从没被记成 `2`；最大亮度 `1` 先在 `-1` 处出现，答案变成 `-1`，正确答案是 `1`（两盏灯都照到）。

**反例（错误写法二）：并列时用 `>=` 更新。** `[[5,0],[1,0]]`：坐标 `1` 和 `5` 亮度都是 `1`，`>=` 会把答案换成较大的 `5`；正确答案是 `1`。
