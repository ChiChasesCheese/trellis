## Q
**LC 1539 第 k 个缺失的正整数**｜Easy · TikTok 高频

给严格升序的正整数数组 `arr`（`1 <= arr.length <= 1000`，`1 <= arr[i] <= 1000`）和整数 `k`（`1 <= k <= 1000`），找出缺失的第 `k` 个正整数。进阶：时间复杂度小于 `O(n)`。例：`arr = [2,3,4,7,11]`，`k = 5` → `9`；`arr = [1,2,3,4]`，`k = 2` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「严格升序」+「第 `k` 个」+「进阶低于 `O(n)`」→ 二分查找（binary search）。
- 「缺失个数」可以用下标表示：`arr[i]` 之前缺失的正整数个数是 `arr[i] - (i + 1)`，它随 `i` 单调不减 → 二分的判定函数。
- `n <= 1000` 时线性也能过，但进阶明确要二分；这类“在单调函数上找第一个 `>= k`”的写法会在很多题里重复出现。
- 答案可能落在数组末尾之后 → 下标范围要含 `n`（`lo` 可以等于 `n`）。

**推导链。**
1. 暴力：从 `1` 开始逐个判断是否在数组里，数到第 `k` 个缺失的，`O(arr[-1] + k)`。
2. 线性：`for x in arr: if x <= k: k += 1`，数组里每个不超过当前答案的数让答案后移一位，`O(n)`。
3. 洞察：`miss(i) = arr[i] - (i + 1)` 单调不减；设 `lo` 是第一个 `miss(lo) >= k` 的下标，第 `k` 个缺失数在 `arr[lo - 1]` 和 `arr[lo]` 之间。
4. 答案前面有 `lo` 个数属于 `arr`，所以第 `k` 个缺失数是 `k + lo`。

**同模式的题**：LC 268 丢失的数字、LC 41 缺失的第一个正数、LC 34 在排序数组中查找元素的第一个和最后一个位置、LC 704 二分查找。
