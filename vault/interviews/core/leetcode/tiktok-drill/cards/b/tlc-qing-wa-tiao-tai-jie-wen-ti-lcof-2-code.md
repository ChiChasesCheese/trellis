## Q
**剑指 Offer 10- II 青蛙跳台阶问题**｜写出 Python 实现

平台有 `n` 个格子（`0 <= n <= 100`），每次跳 1 格或 2 格，求跳完的方法数，对 `1000000007` 取模。要求 `O(n)` 时间、`O(1)` 空间。

## A
**思路。** `f(n) = f(n - 1) + f(n - 2)`，`f(0) = f(1) = 1`。用 `a, b` 表示相邻两项，循环 `n` 次，每次整体右移一位并取模，最后 `a` 就是 `f(n)`。

```python
def num_ways(n: int) -> int:
    MOD = 1_000_000_007
    a, b = 1, 1                      # a = f(i)，b = f(i + 1)；从 f(0) = f(1) = 1 开始
    for _ in range(n):
        a, b = b, (a + b) % MOD      # 右边先全部求值，再一起赋给左边
    return a
```

运行：`n = 0` → `1`，`1` → `1`，`2` → `2`，`5` → `8`，`45` → `836311896`（未取模是 `1836311903`），`100` → `782204094`。

**复杂度。** 时间 `O(n)`：循环 `n` 次；空间 `O(1)`：只有两个变量。

**写法要点。** 元组赋值 `a, b = b, (a + b) % MOD` 先算出右边两个值再同时赋值，不需要临时变量，也不会用到已被覆盖的 `a`；`1_000_000_007` 用下划线分组，一眼看出位数；循环变量不用时写 `_`。
