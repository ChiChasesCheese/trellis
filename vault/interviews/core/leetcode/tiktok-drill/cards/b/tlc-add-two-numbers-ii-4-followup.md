## Q
**LC 445 两数相加 II**｜追问

面试官接着问：（1）不能用栈，要 `O(1)` 额外空间怎么做？（2）链表长到 `10^5`，递归写法会怎样？（3）要把 `k` 条这样的链表相加呢？

## A
1. **`O(1)` 额外空间**：先把两条输入链表各自反转（原地改指针），变成低位在前，再用标准的 LC 2 做法逐位加并生成新链表（新链表低位在前，再反转一次得到高位在前），最后把输入链表反转回去还原。时间仍是 `O(n + m)`；代价是中途会改动输入，进阶明确禁止翻转时不能这么做。
2. **递归写法**：先数出两条链表长度，较长的链表先走「长度差」步，之后两边对齐，递归到底，回溯时加进位。递归深度等于长度；长度 `10^5` 时会超出 Python 默认递归深度上限 `1000`，抛 `RecursionError`。所以长链表用栈 + 迭代，或者把递归改成显式栈。
3. **`k` 条链表**：每条压成一个栈，列表 `stacks`；每轮对所有非空栈弹出一个值，累加进位，直到全空且无进位。时间 `O(总长度)`，进位最大约为 `9 * k`，所以 `carry` 可以大于 `9`，要用 `divmod(carry, 10)` 而不是 `carry = 1 if ... else 0`。
4. 结果不需要链表、只要数：`int("".join(map(str, digits)))`；但这等于绕开了题目考的链表和进位，面试里只在被明确允许时才说。

**Python 提醒**：`while l1:` 靠结点对象的真值判断结束，这对自定义类没问题（默认为真，`None` 为假）；但如果类实现了 `__len__` 或 `__bool__`，就不能这样写，要显式 `is not None`。
