## Q
**LC 263 丑数**｜追问

面试官接着问：（1）求第 `n` 个丑数（LC 264，`n <= 1690`）？（2）质因数换成任意给定的列表（LC 313）？（3）只判断一个数是不是 3 的幂（LC 326）？

## A
1. **第 `n` 个丑数**：丑数都是更小的丑数乘 2、3 或 5 得来的。三个指针分别指向「下一个要乘 2 / 3 / 5 的丑数」，每步取三个乘积的最小值，**相等的指针都前进**以去重，`O(n)`。

```python
def nth_ugly_number(n: int) -> int:
    ugly = [1] * n
    i2 = i3 = i5 = 0
    for k in range(1, n):
        a, b, c = ugly[i2] * 2, ugly[i3] * 3, ugly[i5] * 5
        ugly[k] = nxt = min(a, b, c)
        i2 += a == nxt               # 布尔值当 0 / 1 用：相等的指针都前进
        i3 += b == nxt
        i5 += c == nxt
    return ugly[-1]
```

`n = 10` → `12`，`n = 1690` → `2123366400`。
2. **任意质因数列表（LC 313）**：指针数组版本同上；或最小堆，每次弹出最小值、乘上每个质数压回去，用集合去重，`O(n · m log(n · m))`。
3. **3 的幂**：`n > 0 and 1162261467 % n == 0`，`3^19 = 1162261467` 是 32 位内最大的 3 的幂；只对质数的幂成立。

**Python 提醒**：`heapq` 只有最小堆；多个指针同值时都要前进，否则同一个数会重复出现。
