## Q
**LC 239 滑动窗口最大值**｜正确性

为什么可以把队尾比新数小的下标直接丢掉？队首为什么就是窗口最大值？用 `if` 而不是 `while` 弹出过期队首为什么够？

## A
**不变量。** 每步结束后，队列里的下标严格递增，对应的值严格递减，并且队列包含了「当前窗口中所有可能成为某个未来窗口最大值的候选」。

**为什么可以丢。** 设下标 `j < i` 且 `nums[j] <= nums[i]`，现在处理到 `i`。以后每个右端 `>= i` 的窗口，只要包含 `j`，就一定也包含 `i`（`j < i` 且窗口连续），而 `nums[i] >= nums[j]`，所以 `j` 不可能是它们的唯一最大值；右端 `< i` 的窗口都已经输出过了。因此处理 `i` 时丢掉 `j` 是安全的。

**队首是最大值。** 队列值递减，队首值最大；过期的队首被弹出，所以队首在窗口内。

**为什么 `if` 就够。** 窗口每步右移一格，每步至多一个下标过期（`i - k`），而队列里下标严格递增，过期的只可能是队首的那一个。

**反例。** `nums = [3,2,2,1,3]`, `k = 2`：窗口最大值 `[3,2,2,3]`。存值并用 `<=` 弹掉相等的值，队列里只剩一个 `2`，当它被当作滑出的值弹出时，另一个 `2` 早已被丢掉，得 `[3,2,1,3]`。存下标则每个 `2` 各自过期。
