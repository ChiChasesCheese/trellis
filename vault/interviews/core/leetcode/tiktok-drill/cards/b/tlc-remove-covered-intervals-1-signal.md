## Q
**LC 1288 删除被覆盖区间**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-04-13（CodeTop）

区间列表 `intervals`，区间 `[a,b)` 被 `[c,d)` 覆盖当且仅当 `c <= a` 且 `b <= d`；删除所有被其他区间覆盖的区间，求剩余数量。`1 <= intervals.length <= 1000`，`0 <= intervals[i][0] < intervals[i][1] <= 10^5`，区间互不相同。例：`[[1,4],[3,6],[2,8]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「区间 + 包含 / 重叠 / 合并」→ 先**排序**再线性扫描，排序把二维的覆盖关系变成一维的顺序关系。
- 覆盖条件 `c <= a` 且 `b <= d` 有两个维度 → 排序固定一个维度（起点），扫描时用一个量（**最大终点**）概括「前面所有区间」。
- 起点相同的区间怎么排 → 终点**降序**，让长的在前、短的被识别为被覆盖。
- `n <= 1000` → `O(n^2)` 两两比较可过，但排序 + 扫描更简洁，也是面试预期。

**推导链。**
1. 暴力：每个区间与其他所有区间比较，`O(n^2)`。
2. 浪费：覆盖需要起点和终点两个维度，两两比较没有利用顺序。
3. 洞察：按起点升序后，只有排在前面的区间可能覆盖当前区间；前面所有区间能否覆盖当前区间，只取决于它们的**最大终点**是否 `>=` 当前终点。起点相同的要让长的排前面。
4. 最优：`sort(key=(起点, -终点))`，扫一遍，终点超过 `max_end` 才保留 → `O(n log n)`。

**同模式的题**：LC 56 合并区间、LC 435 无重叠区间、LC 452 用最少数量的箭引爆气球、LC 986 区间列表的交集。
