## Q
**LC 169 多数元素**｜Easy · CodeTop 国内累计 21 次 · 最近 2022-03-24（国内 CodeTop）

给大小为 `n` 的数组 `nums`，返回其中的多数元素：出现次数**大于** `⌊n/2⌋` 的元素；数组非空且一定存在多数元素。`1 <= n <= 5 * 10^4`，`-10^9 <= nums[i] <= 10^9`。例：`[2,2,1,1,1,2,2]` → `2`。进阶：`O(n)` 时间、`O(1)` 空间。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「出现次数超过一半」→ 多数元素的票数比其余元素的总和还多 → 可以"成对抵消"：每次让两个不同的数同归于尽，多数元素必然留到最后（摩尔投票，Boyer-Moore voting）。
- 进阶「`O(1)` 空间」→ 排除哈希计数（`O(n)` 空间）；「`O(n)` 时间」→ 排除排序（`O(n log n)`）。
- 「保证存在多数元素」→ 投票结束后不必验证；没有这个保证就要多扫一遍。
- 值域到 `10^9`：不能用计数数组，用哈希表或投票。

**推导链。**
1. 暴力：对每个元素数出现次数，`O(n^2)`。
2. 哈希表 `Counter` 计数，`O(n)` 时间、`O(n)` 空间；或排序后取下标 `n // 2` 的元素，`O(n log n)`。
3. 洞察：多数元素出现次数 `> n/2`，用它去换掉任意一个别的数，剩下的仍是多数；候选人 + 计数实时记录"尚未被抵消的票"。
4. 遇到相同值计数加一，不同值计数减一，计数为零换候选人；一遍扫描，常数空间。

**同模式的题**：LC 229 求众数 II、LC 1150 检查一个数是否在数组中占绝大多数、LC 136 只出现一次的数字、LC 215 数组中的第 K 个最大元素。
