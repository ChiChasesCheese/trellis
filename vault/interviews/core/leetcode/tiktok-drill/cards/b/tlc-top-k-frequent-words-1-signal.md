## Q
**LC 692 前K个高频单词**｜Medium · LC TikTok 全时段热度 25/100 · CodeTop 国内累计 1 次 · 最近 2026-07-22（国内 CodeTop）

给单词列表 `words` 和整数 `k`，返回出现次数最多的前 `k` 个单词：按次数从高到低，次数相同的按字典序。`1 <= words.length <= 500`，`1 <= words[i].length <= 10`，小写字母，`k` 在 `[1, 不同单词的数量]` 内。进阶：`O(n log k)` 时间、`O(n)` 空间。例：`["i","love","leetcode","i","love","coding"], k = 2` → `["i","love"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「出现次数最多的前 k 个」→ **哈希计数 + Top-K 选择**（排序或堆）。
- 「次数相同按字典序」→ 排序键要编码**两个相反方向**：次数降序、单词升序 → 复合键 `(-次数, 单词)`。
- `n <= 500` → 直接排序 `O(m log m)` 足够；「进阶 `O(n log k)`」→ 大小为 `k` 的堆。

**推导链。**
1. 暴力：重复 `k` 次，每次扫全部 `m` 个不同单词找「当前最好」的一个，`O(km)`。
2. 浪费：每一轮都重新比较所有单词，前几轮的比较结果没有复用。
3. 关键：所有轮次用的是同一个全序（次数大优先、平局字典序小优先），一次排序就把它定下来，`O(m log m)`。
4. 只要前 `k` 个：大小为 `k` 的堆只保留当前最好的 `k` 个，`O(m log k)`；`heapq.nsmallest(k, ..., key=...)` 就是这个实现。

**同模式的题**：LC 347 前 K 个高频元素、LC 451 根据字符出现频率排序、LC 973 最接近原点的 K 个点、LC 215 数组中的第 K 个最大元素。
