## Q
**LC 815 公交路线**｜Hard · TikTok 高频

`routes[i]` 是第 `i` 辆公交车循环行驶经过的车站序列。从车站 `source` 出发（一开始不在车上），只能乘公交，要到车站 `target`，求最少乘坐的公交车数量，到不了返回 `-1`。`1 <= routes.length <= 500`，`1 <= routes[i].length <= 10^5`，同一条线路里车站互不相同，`sum(routes[i].length) <= 10^5`，车站编号与 `source`、`target` 都在 `[0, 10^6)`。例：`[[1,2,7],[3,6,7]]`，`1 -> 6` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少乘坐几辆车」：每乘一辆代价相同 → **无权最短路 → BFS**，层数就是换乘次数加一。
- 代价单位是**线路**，不是车站：同一条线路上任意两站，坐一辆车都能到 → 把“一整条线路”当成一个整体展开。
- `routes[i].length` 到 `10^5`，总长 `<= 10^5`，编号到 `10^6` → 不能做站点两两连边（`10^10`），不能开 `10^6` 的数组做邻接表以外的事 → 用字典建「站 → 线路」反查表。
- “一开始不在车上”→ `source == target` 时答案是 `0`，不用乘车（边界）。
- 线路很多、站很多 → 必须保证**每条线路只展开一次**，否则会被不同的站重复扫描。

**推导链。**
1. 暴力：以车站为结点，只在相邻两站连边，答案是站数而不是车数，不对；改为同线路任意两站连边，边数 `L^2`，线路长 `10^5` 放不下。
2. 浪费：同一条线路被它上面每个已到达的站各展开一次，重复扫描。
3. 洞察：线路被乘过一次，它上面所有站都已进入“这一层”；之后再碰到它没意义，标记即可。
4. 最优：BFS 同时维护已访问的站和已展开的线路；每条线路展开一次，总共 `O(sum(len))`。

**同模式的题**：LC 127 单词接龙、LC 752 打开转盘锁、LC 1129 颜色交替的最短路径、LC 1091 二进制矩阵中的最短路径、LC 787 K 站中转内最便宜的航班。
