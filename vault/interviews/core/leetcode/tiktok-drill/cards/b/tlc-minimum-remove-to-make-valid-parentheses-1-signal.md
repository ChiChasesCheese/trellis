## Q
**LC 1249 移除无效的括号**｜Medium · TikTok 高频

给由 `'('`、`')'` 和小写字母组成的字符串 `s`（`1 <= s.length <= 10^5`）。删除最少数目的括号（可以在任意位置），使剩下的括号有效，返回任意一个合法结果；有效指空串、`AB`（`A`、`B` 有效）、`(A)`（`A` 有效）。例：`"lee(t(c)o)de)"` → `"lee(t(c)o)de"`；`"a)b(c)d"` → `"ab(c)d"`；`"))(("` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号是否匹配」→ 栈（stack）：`(` 入栈，`)` 找最近的 `(` 配对。
- 「删除最少」+「返回任意一个」→ 不需要搜索：每个多余的括号都是被迫删除的，贪心配对就能得到最少。
- 需要知道**删哪个位置** → 栈里存下标而不是字符。
- `n = 10^5` → `O(n)` 的一遍扫描；枚举子集 `O(2^n)` 不可能。

**推导链。**
1. 暴力：枚举删除哪些括号，验证有效性，`O(2^n · n)`。
2. 有效的条件：任何前缀里 `)` 不多于 `(`，且整体个数相等。
3. 扫描时一个 `)` 前面如果没有可配的 `(`，它永远配不上，必须删。
4. 扫完仍没配上的 `(`，后面没有 `)` 可配，也必须删。
5. 被迫删除的个数是下界，删完恰好有效，所以达到下界。

**同模式的题**：LC 921 使括号有效的最少添加、LC 301 删除无效的括号、LC 20 有效的括号、LC 32 最长有效括号。
