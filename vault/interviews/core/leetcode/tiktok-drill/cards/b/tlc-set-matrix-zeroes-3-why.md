## Q
**LC 73 矩阵置零**｜正确性

为什么要先单独保存第 `0` 行、第 `0` 列原来的状态？为什么三个阶段的顺序不能换？给出顺序或保存写错时的具体输入。

## A
**不变量。** 阶段一结束后，对内部格子 `(i, j)`（`i, j >= 1`）有：`matrix[i][0] == 0` 当且仅当第 `i` 行的内部或第 `0` 列有原始的 `0`（标记也可能来自第 `0` 列本身的原始 `0`，这正是需要单独保存的原因）；`matrix[0][j] == 0` 同理。阶段二只读第 `0` 行和第 `0` 列，只写内部，所以标记在阶段二里不会被破坏。阶段三用阶段一之前保存的布尔值，决定第 `0` 行 / 列是否整体清零。

**为什么要单独保存。** 第 `0` 行 / 列的格子既是数据又是标记。写了标记之后，无法再区分「原来就是 `0`」和「被标记成 `0`」，必须在写标记前就记下来。

**反例一：不保存，用 `matrix[0][0]` 一个值代替两个布尔。** `[[1,0],[1,1]]`：
- 原始的 `0` 在第 `0` 行第 `1` 列，第 `0` 行含 `0`，第 `0` 列没有。
- 标记阶段把 `matrix[0][0]` 写成 `0`（表示第 `0` 行要清零）；最后一步看到 `matrix[0][0] == 0`，把第 `0` 行和第 `0` 列都清零。
- 得到 `[[0,0],[0,0]]`，正确是 `[[0,0],[1,0]]`。

**反例二：先清第 `0` 行 / 列，再清内部。** `[[1,0,1],[1,1,1],[1,1,1]]`：
- 第 `0` 行含 `0`，先把第 `0` 行整体清零，标记 `matrix[0][j]` 全部变成 `0`。
- 清内部时每一列都被当成「要清零」，结果 `[[0,0,0],[1,0,0],[1,0,0]]`。
- 正确是 `[[0,0,0],[1,0,1],[1,0,1]]`，只有第 `1` 列要清零。
