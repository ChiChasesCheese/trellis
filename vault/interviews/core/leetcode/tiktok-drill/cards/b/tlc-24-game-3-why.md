## Q
**LC 679 24 点游戏**｜正确性

为什么「每次任选两个数合并」就能覆盖所有括号结构？这个解法里哪三处最容易写错？各给一个出错的输入。

## A
**不变量。** 递归的每一层持有的数，代表一个「已经算好的子表达式」的值。每个带括号的表达式都是一棵二叉树：叶子是四张牌，内部结点是运算。树的最底层必有一个内部结点的两个孩子都是叶子，相当于「选两个原始数合并」；把它当作一个新数，问题就规约成三个数，归纳下去。所以枚举所有「选哪两个、做哪种运算」的序列，就等价于枚举了所有表达式树。

**错误 1：只试一个方向的减法 / 除法。** 减法和除法不可交换，`a - b` 与 `b - a` 是不同的值。`cards = [1,2,4,6]`：`4 * 6 * (2 - 1) = 24`，需要先得到 `2 - 1`，而数列顺序里 `1` 在 `2` 前面，只试 `a - b` 只能得到 `1 - 2 = -1`。只试 `a - b`、`a / b`（漏掉 `b - a`、`b / a`）的版本返回 `False`，正确答案 `True`。

**错误 2：浮点比较 `== 24`。** `cards = [3,3,8,8]`：`8 / (3 - 8 / 3)` 在浮点里等于 `23.99999999999999`，`== 24` 为假，版本返回 `False`；用 `Fraction`（精确 `24`）或误差阈值得到 `True`。

**错误 3：整数除法。** 用 `//` 会把 `1 / 5` 截成 `0`。`cards = [1,5,5,5]`：`5 * (5 - 1 / 5) = 24`，需要真实的 `1/5`；整数除法版本返回 `False`，正确答案 `True`。

**还有一类：只做左到右的链式运算。** `((a op b) op c) op d` 只是五种括号形状之一，`cards = [1,3,4,6]` 需要 `6 / (1 - 3 / 4) = 24`，链式版本得到 `False`。
