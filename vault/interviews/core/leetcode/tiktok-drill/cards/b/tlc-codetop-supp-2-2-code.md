## Q
**补充题 2 圆环回原点问题**｜写出 Python 实现

圆环上有 `n` 个点（编号 `0..n-1`，`3 <= n <= 1000`），首尾相邻。从 `0` 号点出发，每步走到相邻点，求恰好走 `k` 步（`0 <= k <= 1000`）回到 `0` 号点的方案数，对 `10^9 + 7` 取模。

## A
**思路。** `ways` 列表长度为 `n`，初始只有 `ways[0] = 1`。每一步用列表推导式生成新的 `ways`：新的 `ways[i]` 来自旧的 `ways[i - 1]` 与 `ways[(i + 1) % n]`。`k` 步之后返回 `ways[0]`。

```python
MOD = 10**9 + 7


def ring_ways(n: int, k: int) -> int:
    ways = [0] * n                               # ways[i]：当前走了若干步后停在 i 号点的方案数
    ways[0] = 1                                  # 起点：0 号点，0 步
    for _ in range(k):
        # 下一步停在 i，只能从 i-1（顺时针走来）或 i+1（逆时针走来）；下标取模就是"首尾相接"
        ways = [(ways[i - 1] + ways[(i + 1) % n]) % MOD for i in range(n)]
    return ways[0]
```

**运行。** `(3, 2)` → `2`；`(4, 2)` → `2`；`(5, 3)` → `0`；`(5, 5)` → `2`；`(3, 0)` → `1`；`(1000, 1000)` → `159835831`。

**复杂度。** 时间 `O(nk)`：每步一次长度 `n` 的列表推导；空间 `O(n)`，每步新列表替换旧列表。

**写法要点。** 列表推导式一次性读取旧 `ways`、产生新 `ways`，保证"同一步里不会读到刚更新的值"；`ways[i - 1]` 在 `i = 0` 时是 `ways[-1]`，Python 的负下标恰好是环上的前一个点；`(i + 1) % n` 处理最后一个点的后继；每一步取模，数值始终小于 `10^9 + 7`；`MOD` 写成模块级常量，避免魔法数字。
