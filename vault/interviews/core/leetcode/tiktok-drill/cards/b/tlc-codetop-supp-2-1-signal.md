## Q
**补充题 2 圆环回原点问题**｜Medium · 字节高频

圆环上有 `n` 个点，按顺时针依次编号 `0` 到 `n - 1`，`n - 1` 号点与 `0` 号点相邻。小明从 `0` 号点出发，每一步走到相邻的点（顺时针或逆时针）。求恰好走 `k` 步后回到 `0` 号点的方案数，对 `10^9 + 7` 取模。

约束：`3 <= n <= 1000`，`0 <= k <= 1000`。例：`n = 3, k = 2` → `2`；`n = 5, k = 5` → `2`；`n = 5, k = 3` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「固定步数、数方案数」→ 计数 DP：状态是 `(走了几步, 停在哪)`。
- 「环」→ 位置下标对 `n` 取模，首尾相接，邻居是 `i - 1` 和 `(i + 1) % n`。
- 「每步只有两种选择」→ 每个状态只从两个邻居转移而来，方案数相加。
- 「对 `10^9 + 7` 取模」→ 方案数指数增长，每步取模。`n, k <= 1000` → `O(nk)` 够用。

**推导链。**
1. 暴力：DFS 枚举每一步顺 / 逆时针，`2^k` 种，不可行。
2. 浪费：走到同一个 `(步数, 位置)` 的不同走法，后面的走法完全一样，没必要分开算。
3. 洞察：`ways_{s+1}[i] = ways_s[i - 1] + ways_s[(i + 1) % n]`，只依赖上一步。
4. 最优：滚动数组，`k` 步每步 `O(n)`，`O(nk)` 时间 `O(n)` 空间；答案是 `ways[0]`。

**同模式的题**：LC 70 爬楼梯、LC 576 出界的路径数、LC 935 骑士拨号器、LC 62 不同路径。
