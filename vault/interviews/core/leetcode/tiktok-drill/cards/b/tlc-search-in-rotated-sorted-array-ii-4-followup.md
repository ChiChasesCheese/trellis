## Q
**LC 81 搜索旋转排序数组 II**｜Medium · 字节高频｜追问

面试官接着问：（1）有重复元素对时间复杂度有什么影响，为什么？（2）如果改成求旋转数组中的**最小值**（LC 154）？（3）如果要返回 `target` 最左边的下标？

## A
1. **复杂度**：无重复时每轮丢掉一半，`O(log n)`。有重复时，三个端点相同的那一轮只缩两格，不丢掉一半；输入是 `[1] * 2500 + [2] + [1] * 2499` 找 `3`，绝大多数轮都落在这个分支，约 `n / 2` 轮，`O(n)`。这个下界是真实的：一个值 `x` 藏在全是 `1` 的数组里，任何算法都得逐个看。
2. **最小值**：比较 `nums[mid]` 和 `nums[hi]`。`<` 则最小值在左半（含 `mid`），`hi = mid`；`>` 则在右半，`lo = mid + 1`；`==` 时无法判断，`hi -= 1`。同样最坏 `O(n)`。
3. **最左下标**：先用上面的最小值找到断点 `p`，数组被切成两段有序区间 `[0, p)` 和 `[p, n)`，分别 `bisect_left(nums, target, lo, hi)`，在两段里找到的下标中取较小的那个（先确认命中）。

**Python 提醒**：`bisect_left` 必须作用在有序区间上，对整个旋转数组调用会得到无意义的位置；`bisect_left(nums, x, lo, hi)` 的 `hi` 是开区间右端，不是最后一个下标。
