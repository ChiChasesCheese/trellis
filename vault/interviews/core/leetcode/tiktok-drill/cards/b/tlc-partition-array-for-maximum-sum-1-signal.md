## Q
**LC 1043 分隔数组以得到最大和**｜Medium · TikTok 高频

给整数数组 `arr`，把它分隔成若干段**连续**子数组，每段长度**至多**为 `k`。分隔后，每段中的所有值都变成该段的最大值。求变换后数组元素之和的最大值（测试保证答案在 32 位整数范围内）。

约束：`1 <= arr.length <= 500`，`0 <= arr[i] <= 10^9`，`1 <= k <= arr.length`。

例：`arr = [1,15,7,9,2,5,10], k = 3` → `84`（变成 `[15,15,15,9,10,10,10]`）；`arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4` → `83`；`arr = [1], k = 1` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「分隔成**连续**子数组」+「每段按规则计价」+「求总和最大」→ **线性分段 DP**，状态是前缀长度 `i`。
- 「每段长度**至多** `k`」→ 转移只需枚举最后一段的长度 `1..k`，转移范围有界。
- `n ≤ 500` 且 `k ≤ n` → `O(n·k)` 甚至 `O(n^2)` 都可行；段的价值依赖段内最大值，所以要在枚举段长时**滚动维护最大值**。

**推导链。**
1. 暴力：递归枚举每段的长度，`O(k^n)`。
2. 浪费：切完前 `i` 个元素后，后半段的最优解只取决于 `i`，却被不同前缀重复算。
3. 洞察：无后效性 → `dp[i] = max_j dp[i-j] + j × max(arr[i-j..i-1])`，`j ∈ [1, min(k, i)]`。
4. 最优：外层 `i`，内层 `j` 从 1 递增并滚动更新段最大值，转移 `O(1)`，总 `O(n·k)`。
