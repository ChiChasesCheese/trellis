## Q
**LC 50 Pow(x, n)**｜Medium · 字节高频｜追问

面试官接着问：（1）改成递归怎么写，会踩什么坑？（2）如果要求结果对一个整数 `m` 取模（`a` 和 `b` 都是整数）？（3）`n` 是 `-2^31` 时有什么要注意？

## A
1. **递归**：`half = my_pow(x, n // 2)`，返回 `half * half * (x if n % 2 else 1)`，`n == 0` 返回 `1.0`；递归深度 `log n`，约 32 层，不会爆栈。坑：写成 `my_pow(x, n // 2) * my_pow(x, n // 2)` 会在每层调用两次，退化成 `O(n)`。
2. **取模**：在每次乘法后 `% m`，其余结构不变。Python 直接用内置 `pow(a, b, m)`，`O(log b)`；`b` 为负时要求 `a` 与 `m` 互质，返回模逆元的幂。
3. **`n = -2^31`**：取负得 `2^31`，在 32 位有符号整数里溢出，C++ / Java 要用 `long`，或先对 `n + 1` 求幂、最后多乘一个 `1 / x`。Python 整数不溢出，直接可用。

**Python 提醒**：`pow(3, -1, 7)` 是 `5`（模逆元）；`pow(0, -1, 7)` 抛 `ValueError`。`pow(0.0, -1)` 和 `0.0 ** -1` 都抛 `ZeroDivisionError`，`my_pow` 里的 `1 / x` 同理；题面保证这种输入不会出现。
