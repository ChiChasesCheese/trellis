## Q
**LC 77 组合**｜Medium · TikTok 高频

给两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合，顺序任意。`1 <= n <= 20`，`1 <= k <= n`。例：`n = 4, k = 2` → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**组合」→ 输出是 `C(n, k)` 个，只能**回溯**（backtracking）枚举，不存在多项式解。
- `n <= 20`：`2^20 ≈ 10^6`，指数枚举可行；这类限制就是在暗示回溯。
- 「**组合**」不计顺序 → 必须规定选取顺序（只选比上一个更大的数），否则 `[1,2]` 和 `[2,1]` 会重复。

**推导链。**
1. 暴力：枚举全部 `2^n` 个子集，留下大小为 `k` 的。
2. 浪费在哪：大小已超过 `k` 的分支还在继续，大小永远凑不够 `k` 的分支也在继续。
3. 洞察一：路径长度达到 `k` 立刻收集并返回；洞察二：还差 `need` 个数时，起点 `x` 必须满足 `n - x + 1 >= need`，否则后面的数不够用。
4. 最优回溯：`dfs(start)` 从 `start` 到 `n - need + 1` 逐个尝试，选了 `x` 就递归到 `x + 1`。每个叶子都是一个合法组合，几乎没有死分支。

**同模式的题**：LC 216 组合总和 III、LC 39 / 40 组合总和、LC 78 / 90 子集、LC 17 电话号码的字母组合。
