## Q
**LC 62 不同路径**｜正确性

为什么"新一行是上一行的前缀和"？为什么组合数是 `C(m + n - 2, m - 1)` 而不是 `C(m + n, m)`？

## A
**不变量。** `row[j]` 是到达当前行第 `j` 列的路径数。到达 `(i, j)` 的最后一步要么从上方来（路径数 `dp[i-1][j]`），要么从左边来（`dp[i][j-1]`），所以 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。展开左边的项：`dp[i][j] = dp[i-1][j] + dp[i-1][j-1] + … + dp[i-1][1] + dp[i][0]`，而 `dp[i][0] = 1 = dp[i-1][0]`，所以它正是上一行第 `0` 到第 `j` 列的和，即前缀和。

**组合数。** 从 `(0, 0)` 到 `(m-1, n-1)` 恰好走 `(m - 1) + (n - 1) = m + n - 2` 步，其中向下 `m - 1` 步，选哪几步是向下的就决定了整条路径，所以是 `C(m + n - 2, m - 1)`。起点本身不是一步。

**反例（错误写法一）：步数写成 `m + n`。** `comb(m + n, m)` 在 `(3, 7)` 给出 `120`，正确是 `28`。**反例（错误写法二）：滚动数组初值全 `0`。** `row = [0] * n` 后做累加，永远是 `0`，`(3, 7)` 得 `0`，正确是 `28`；第一行（和第一列）的每个格子都有恰好 `1` 条路。
