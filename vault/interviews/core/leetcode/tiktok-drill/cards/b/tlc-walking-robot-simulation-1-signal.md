## Q
**LC 874 模拟行走机器人**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-03-07（CodeTop）

机器人从 `(0, 0)` 出发面向北，命令 `-2`（左转 `90` 度）、`-1`（右转 `90` 度）、`1..9`（向前走这么多格）。网格上有障碍，遇到障碍就停在前一格并继续下一条命令。返回行走过程中到原点的最大欧氏距离的平方。`1 <= commands.length <= 10^4`，`0 <= obstacles.length <= 10^4`，坐标 `-3 * 10^4 .. 3 * 10^4`，答案小于 `2^31`。例：`[4,-1,3]` 无障碍 → `25`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按命令逐步执行，有朝向和位置」→ 状态机模拟：状态是 `(x, y, 朝向)`，每条命令更新状态。
- 「朝向每次转 `90` 度」→ 把四个方向编号 `0..3`，配一张方向向量表，转向就是下标 `+1 / -1` 取模，不用写四种情况的 `if`。
- 「障碍物」+ `obstacles.length <= 10^4`、总步数至多 `9 * 10^4` → 每步查询障碍必须 `O(1)`，用哈希集合；线性扫描是 `9 * 10^8`，超时。
- 「最大距离」是过程量 → 不是最终位置，要在过程中持续更新；且只需要平方，别开根号。

**推导链。**
1. 暴力：每走一格，遍历障碍列表判断是否被挡，`O(步数 * m)`。
2. 浪费：障碍是静态的，每次都在重复同样的线性查找。
3. 洞察：障碍放进 `set`（坐标转元组才可哈希），查询 `O(1)`。
4. 最优：逐格模拟，被挡就停；每条前进命令结束更新 `x * x + y * y` 的最大值，总 `O(9C + m)`。

**同模式的题**：LC 657 机器人能否返回原点、LC 489 扫地机器人、LC 54 螺旋矩阵、LC 2069 模拟行走机器人 II。
