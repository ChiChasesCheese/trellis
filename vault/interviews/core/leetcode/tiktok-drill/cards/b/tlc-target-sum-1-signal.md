## Q
**LC 494 目标和**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-09（国内面试记录）

给非负整数数组 `nums` 和整数 `target`，在每个数前添加 `+` 或 `-` 后串联成表达式，返回运算结果等于 `target` 的不同表达式的数目。`1 <= nums.length <= 20`，`0 <= nums[i] <= 1000`，`0 <= sum(nums[i]) <= 1000`，`-1000 <= target <= 1000`。例：`nums = [1,1,1,1,1]`，`target = 3` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每个数二选一（`+`/`-`）+ 统计方案数」→ 子集划分 / 01 背包计数，而不是求最优值。
- `sum <= 1000`：值域很小，可以拿「和」当 DP 的维度；`n <= 20`：`2^20` 的暴力勉强能过，说明考点是更好的做法。
- `nums[i] >= 0` 是变换成立的前提：只有非负，「加的那堆」和「减的那堆」才都是子集和。

**推导链。**
1. 暴力：DFS 每个数试 `+`、`-`，到末尾检查结果，`O(2^n)`。
2. 浪费：不同符号序列会走到同一个 `(下标, 当前和)`，状态数只有 `n * (2S + 1)`，记忆化可以降到 `O(n * S)`。
3. 洞察：设加号那堆之和为 `P`，总和 `S`，则 `P - (S - P) = target`，`P = (S + target) / 2`。符号的选择就是选一个子集，和为 `P`。`S + target` 为奇数或为负、或 `target > S` 时无解。
4. 最优：二维表 `dp[i][j]` 表示从前 `i` 个数里选出和为 `j` 的子集数，`dp[i][j] = dp[i-1][j] + dp[i-1][j-x]`，读上一行保证每个数只用一次，`dp[0][0] = 1`，答案是 `dp[n][P]`，`O(n * P)` 时间和空间。
