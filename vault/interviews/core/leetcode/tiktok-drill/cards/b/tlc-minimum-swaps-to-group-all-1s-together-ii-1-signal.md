## Q
**LC 2134 最少交换次数来组合所有的 1 II**｜Medium · LC TikTok 全时段热度 25/100

「交换」指选中数组中两个互不相同的位置，交换它们的值。「环形数组」把第一个和最后一个元素视为相邻。给二进制环形数组 `nums`（`1 <= nums.length <= 10^5`，元素是 `0` 或 `1`），返回在任意位置把所有 `1` 聚集在一起的最少交换次数。例：`[0,1,0,1,1,0,0]` → `1`；`[1,1,0,0,1]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「把所有 `1` 聚集在一起」→ 最终 `1` 占一段长度固定为 `k`（`1` 的总数）的连续区间 → 固定长度的滑动窗口。
- 「最少交换」→ 窗口外的每个 `1` 与窗口内的某个 `0` 配对交换一次，次数 = 窗口里 `0` 的个数 → 转成“窗口里 `1` 最多”。
- 「环形」→ 窗口可以跨越末尾，下标取模；或者把数组拼接两遍。
- `n = 10^5` → 需要 `O(n)`，窗口每次右移 `O(1)` 更新。

**推导链。**
1. 暴力：枚举聚集的起点（`n` 个），每个统计窗口里的 `0`，`O(n · k)`。
2. 观察：窗口确定后，窗口外有多少个 `1`，就需要多少次交换，一次交换恰好把一个 `1` 换进窗口。
3. 窗口外的 `1` 数 = `k` − 窗口内的 `1` 数，所以要窗口内 `1` 最多。
4. 窗口右移一格：加入新元素、减去旧元素，`O(1)`。
5. 环：起点遍历 `0..n-1`，右端与左端的下标都对 `n` 取模。
