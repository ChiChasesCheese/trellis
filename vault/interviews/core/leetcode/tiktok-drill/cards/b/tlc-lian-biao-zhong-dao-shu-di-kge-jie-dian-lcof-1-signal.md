## Q
**剑指 Offer 22 链表中倒数第k个节点**｜Easy · CodeTop 国内累计 40 次 · 最近 2026-08-04（国内 CodeTop）

给定头节点为 `head` 的单链表，查找并返回倒数第 `cnt` 个节点。

约束：`1 <= head.length <= 100`，`0 <= head[i] <= 100`，`1 <= cnt <= head.length`。例：`head = [2,4,7,8], cnt = 1` → 返回值为 `8` 的节点。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「单链表 + 倒数第 `k` 个」→ 不能反向走，也不知道总长 → 快慢指针（two pointers）保持固定间距。
- 「倒数第 `cnt` 个」= 「距离末尾 `None` 恰好 `cnt` 步」→ 快指针先走 `cnt` 步，再同步走到末尾。
- `cnt` 保证合法、长度 `<= 100` → 数据很小，两遍扫描也能过，但面试要求一遍扫描。
- 只返回节点、不修改链表 → `O(1)` 空间即可。

**推导链。**
1. 暴力：遍历一遍得长度 `n`，再走 `n - cnt` 步，两遍扫描。
2. 浪费：为了得到 `n` 多走一整遍。
3. 洞察：只需要两个指针之间隔 `cnt` 步；快指针到末尾时，慢指针刚好落在倒数第 `cnt` 个。
4. 最优：快指针先走 `cnt` 步，然后同步走，一遍扫描，`O(n)` 时间 `O(1)` 空间。
