## Q
**PercentileFinder：实时维护数字并返回第 p 百分位**｜正确性

最近秩法的名次公式 `max(1, ceil(p * N / 100))` 为什么这样写？`p = 0` 和 `p = 100` 为什么不会越界？给出把公式写错时的具体输入和输出。

## A
**定义。** 最近秩法：第 `p` 百分位是排序后，名次 `r` 满足 `r / N >= p / 100` 的最小整数 `r`，也就是 `r = ceil(p * N / 100)`。`p = 100` 时 `r = N`，是最大值，下标 `N - 1` 不越界。`p = 0` 时公式得 `0`，但名次从 `1` 开始，所以要夹到 `1`，取最小值。

**整数向上取整。** `-(-p * N // 100)` 利用整数地板除对负数向下取整的性质，得到 `ceil(p * N / 100)`，全程整数，没有浮点误差。

**有序性的不变量。** 每次 `addNums` 之后 `_data` 都是升序：`insort` 把元素插到二分位置；`extend + sort` 重排整个列表。所以 `_data[r - 1]` 就是第 `r` 小。

**反例一：漏掉 `max(1, ...)`。** 数据 `[15,20,35,40,50]`，`p = 0`：
- 名次公式得 `0`，下标 `0 - 1 = -1`，Python 的负下标取到最后一个元素。
- 返回 `50`；正确是最小值 `15`。

**反例二：向下取整。** 同样数据，`p = 40`，下标取 `int(40 / 100 * 5) = 2`：
- 得到 `35`。
- 正确：`ceil(40 * 5 / 100) = 2`，第 `2` 小是 `20`。
- `p = 100` 时下标是 `5`，直接 `IndexError`。
