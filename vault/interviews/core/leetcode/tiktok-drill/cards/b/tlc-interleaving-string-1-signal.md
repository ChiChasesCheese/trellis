## Q
**LC 97 交错字符串**｜Medium · 字节 高频

给三个字符串 `s1`、`s2`、`s3`，判断 `s3` 能否由 `s1` 和 `s2` **交错**组成：`s1`、`s2` 各自切成若干非空子串（段数相差不超过 `1`）后交替拼接，各自内部字符顺序不变。`0 <= s1.length, s2.length <= 100`，`0 <= s3.length <= 200`，由小写英文字母组成。例：`s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"` → `true`；`s3 = "aadbbbaccc"` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个序列各自保序、合并成第三个，问**是否**可能」→ **双序列 DP**（与 LCS、编辑距离同族）。
- `s3` 已经给定 → 用掉 `s1` 的 `i` 个、`s2` 的 `j` 个字符时，`s3` 的位置必是 `i + j`，状态只需要 `(i, j)` 两维。
- `s1`、`s2` 最多 `100` → `O(mn) = 10^4`，轻松；进阶只让用 `O(len(s2))` 空间 → 滚动数组。
- 长度先判：`len(s1) + len(s2) != len(s3)` 直接 `false`。

**推导链。**
1. 暴力：每一步从 `s1` 或 `s2` 取下一个字符，两个分支，最坏 `2^(m+n)`。
2. 贪心行不通：能从 `s1` 取就取，会在 `s1 = "aa"`、`s2 = "ab"`、`s3 = "aaba"` 上误判（取错来源后无法回头）。
3. 洞察：同一个 `(i, j)` 会被不同取法重复到达，答案只取决于 `(i, j)` → `dp[i][j]`，`O(mn)`。
4. 转移：`dp[i][j] = (dp[i-1][j] 且 s1[i-1] == s3[i+j-1])` 或 `(dp[i][j-1] 且 s2[j-1] == s3[i+j-1])`；第 `i` 行只依赖上一行 → 压成一维 `O(n)`。

**同模式的题**：LC 72 编辑距离、LC 1143 最长公共子序列、LC 115 不同的子序列、LC 44 通配符匹配。
