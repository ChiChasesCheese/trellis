## Q
**补充题23 检测循环依赖**｜Medium · 字节 高频

有 `n` 个模块，编号 `0` 到 `n - 1`。`deps[k] = [a, b]` 表示模块 `a` 依赖模块 `b`（构建 `a` 前必须先构建 `b`）。判断依赖里是否存在循环依赖：沿着依赖走能回到出发的模块，自依赖也算。`1 <= n <= 10^5`，`0 <= len(deps) <= 2 * 10^5`，`0 <= a, b < n`，依赖对可能重复。例：`n = 3`，`deps = [[0,1],[1,2],[2,0]]` → `True`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「依赖 / 必须先于」→ **有向图**：`a` 依赖 `b` 就是一条边（`b -> a` 或 `a -> b`，方向统一即可）。
- 「是否存在循环」→ **有向图判环**：拓扑排序能否排完所有点，或 DFS 三色标记。
- `n` 到 `10^5`、依赖链可以很长 → 递归 DFS 会超出 Python 默认的递归上限，选**迭代的 Kahn 算法**（入度表加队列）。
- 「自依赖也算」「依赖对可能重复」→ 自环一定入度不为 `0`；重复的边入度按次数计，扣减也按次数，不会出错。
- 方向不能丢：无向图判环（并查集）会把有向无环图误判成有环。

**推导链。**
1. 暴力：对每个模块做一次 DFS，看能否回到自己，`O(n * (n + m))`，超时。
2. 观察：入度为 `0`（没有前置依赖）的模块一定不在环上，可以直接“构建完成”。
3. 完成它之后，依赖它的模块入度减一；减到 `0` 的又成为新的可构建模块。每条边只处理一次。
4. 全部模块都能被取走 → 无环；剩下取不走的模块就是在环上或依赖环的那些。
5. 判断条件是 `取走的数量 < n`，时间 `O(n + m)`。
