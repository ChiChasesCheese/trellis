## Q
**LC 2402 会议室 III**｜Hard · LC TikTok 全时段热度 62/100

`n` 个会议室（编号 `0..n-1`），`meetings[i] = [start_i, end_i]` 是半闭区间 `[start_i, end_i)` 的会议，所有 `start_i` 互不相同。每场会议用未占用且编号最小的房间；没有空房间就延期到有房间空出，持续时间不变；空出时原开始时间更早的会议优先。返回举办次数最多的房间编号，并列取编号最小的。`1 <= n <= 100`，`1 <= meetings.length <= 10^5`，`0 <= start_i < end_i <= 5 * 10^5`。例：`n = 2`，`[[0,10],[1,5],[2,7],[3,4]]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按规则逐个分配资源」→ **事件模拟**，按会议开始时间排序后依次处理。
- “编号最小的空房间”→ 空闲房间的**最小堆**；“最早空出来的房间”→ 占用房间按 `(结束时间, 编号)` 的**最小堆**。**双堆**是这类模拟的标准结构。
- “原开始时间更早的优先”+ `start_i` 互不相同 → 排序后顺序处理就满足，不需要额外等待队列。
- “半闭区间 `[a, b)`”→ 结束时间等于另一场会议的开始时间，房间视为已空（`<=` 回收）。
- `M = 10^5`，`n <= 100` → 堆 `O(M log n)`；`O(M · n)` 的扫描也可行，但堆更稳。

**推导链。**
1. 暴力：按时间逐秒推进，每秒检查所有房间和待办会议，时间跨度 `5 * 10^5`，太慢。
2. 浪费：绝大多数时刻没有事件发生；真正要决策的只有“某场会议开始”。
3. 洞察：会议排好序，逐个处理；处理前把已结束的房间放回空闲堆。有空房间取最小编号；否则取最早结束的房间，结束时间 = 空出时刻 + 原时长。
4. 最优：两个堆 + 计数数组，`O(M log M)`；答案用 `max(range(n), key=count.__getitem__)` 取编号最小的最大者。

**同模式的题**：LC 253 会议室 II、LC 1834 单线程 CPU、LC 1882 使用服务器处理任务、LC 2406 将区间分为最少组数。
