## Q
**LC 213 打家劫舍 II**｜Medium · LC TikTok 全时段热度 41/100 · CodeTop 国内累计 14 次 · 最近 2026-07-21（国内 CodeTop）

沿街的房屋**围成一圈**，每间房有现金 `nums[i]`（`1 <= n <= 100`，`0 <= nums[i] <= 1000`），相邻的两间不能同时偷，求能偷到的最高金额。例：`[2,3,2]` → `3`，`[1,2,3,1]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「相邻不能同时选，求最大总和」→ 线性 DP，每间房只有「偷 / 不偷」两种状态，当前状态只依赖前两间。
- 「围成一圈」→ 首尾相邻，是直线版（LC 198）外加一条约束；套路是**破环成链**：分类讨论首尾哪个不选。
- `n <= 100` → 复杂度不是瓶颈，重点是建模正确；`O(n)` 的 DP 远超需要。
- `nums[i] >= 0` → 多偷不会变少，可以放心用 `max(不偷, 偷)` 的转移，不用考虑负数。

**推导链。**
1. 暴力：每间偷或不偷共 `2^n` 种，再检查相邻（含首尾）是否冲突。
2. 浪费：同一后缀被不同前缀反复重算；直线版里 `dp[i]`（前 `i` 间的最优）只依赖 `dp[i-1]` 与 `dp[i-2]`，`O(n)`。
3. 洞察：环的约束只有「第一间与最后一间不同时偷」，所以合法方案必属于「不含第一间」或「不含最后一间」之一。
4. 最优：两条直线 `nums[1:]`、`nums[:-1]` 各跑一遍直线版，取最大；`n == 1` 单独处理。
