## Q
**LC 402 移掉 K 位数字**｜Medium · LC TikTok 热度 41/100 · CodeTop 国内累计 36 次 · 最近 2025-09-24（国内 CodeTop）

给以字符串表示的非负整数 `num` 和整数 `k`，从中移除 `k` 位数字，使剩下的数最小，以字符串返回（不能有前导零，全部移掉返回 `"0"`）。

约束：`1 <= k <= num.length <= 10^5`，`num` 仅由数字组成，除 `0` 本身外不含前导零。例：`("1432219", 3)` → `"1219"`；`("10200", 1)` → `"200"`；`("10", 2)` → `"0"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「删 `k` 位，剩下最小」，位数固定 → 数的大小等价于字符串字典序，高位越小越好 → 贪心：优先让靠前的位变小。
- 「前面的数字比后面的大就删前面的」→ 回头删栈顶 → 单调栈（monotonic stack），栈内非递减。
- `k` 是删除**额度** → 弹栈时消耗额度，额度为 `0` 就不能再弹。
- `n = 10^5` → `O(n)`；数字很长，不能转整数比较。

**推导链。**
1. 暴力：枚举保留哪些位，`C(n, k)` 种。
2. 贪心：重复 `k` 次，每次删第一个"比后一位大"的数字（没有就删最后一位），`O(nk)`。
3. 洞察：每次都从头找下降位置是重复劳动；用栈维护"目前为止最优的非递减前缀"，新数字比栈顶小就弹栈。
4. 最优：一次扫描，每个数字最多入栈 / 出栈一次，`O(n)`；扫完额度没用完就删末尾，再去前导零。
