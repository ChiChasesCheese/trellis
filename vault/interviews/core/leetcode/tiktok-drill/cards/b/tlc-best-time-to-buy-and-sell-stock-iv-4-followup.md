## Q
**LC 188 买卖股票的最佳时机 IV**｜追问

最多 `k` 笔交易的股票问题已经用 `buy`/`sell` 两张二维表做到 `O(n·k)`。面试官接着问：（1）恰好 `k` 笔？（2）每次卖出要付手续费，或者卖出后有一天冷冻期？（3）`k` 很大、`n` 也很大时怎么办？（4）要输出具体的买卖日期？

## A
1. **恰好 `k` 笔**：`sell[0] = 0`，其余 `sell[j]` 初值改成 `-inf`（没完成 `j` 笔就是不合法状态），`buy` 不变；答案仍然取 `sell[k]`。要先保证 `k <= n // 2`，否则无解。
2. **手续费**：卖出时减去手续费，`sell[j] = max(sell[j], buy[j] + p - fee)`；**冷冻期**（LC 309）：买入只能用前天的 `sell`，要多保留一个“前一天的 `sell`”。
3. **`k` 和 `n` 都很大**：`O(n·k)` 不可行。用「谷到峰」的分段：把价格拆成若干上涨段，用栈合并相邻的段，得到所有候选交易的利润，取前 `k` 大求和，`O(n log n)`；也可以用凸性加 Lagrange 乘子（aliens trick）对交易次数二分，`O(n log C)`，面试里说明思路即可。
4. **输出买卖日期**：完整的二维表保留了每格的转移来源，从 `sell[n][k]` 沿着决策往回走就能反推出买卖日期；更直接的做法是对「谷到峰」分段的版本记录每段的起止下标。
5. 空间可以压到 O(k)：见 Python 工具箱「DP 降维」。

**Python 提醒**：建二维表要写 `[[-inf] * (k + 1) for _ in range(n + 1)]`；写成 `[[-inf] * (k + 1)] * (n + 1)` 会得到 `n + 1` 个指向同一行的引用，改一格全表跟着变。`[-inf] * (k + 1)` 里的元素是不可变的 `float`，所以一行内部没问题。`itertools.pairwise` 需要 Python 3.10+。
