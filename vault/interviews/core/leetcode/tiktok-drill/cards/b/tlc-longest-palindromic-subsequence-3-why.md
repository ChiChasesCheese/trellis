## Q
**LC 516 最长回文子序列**｜正确性

`s[i] == s[j]` 时直接取 `dp[i+1][j-1] + 2`，为什么不用再和 `dp[i+1][j]`、`dp[i][j-1]` 比较？两端不同时如果写成 `dp[i+1][j-1]`，错在哪？给出出错的输入。

## A
**不变量。** 填到 `dp[i][j]` 时，所有更短的区间（`[i+1, j-1]`、`[i+1, j]`、`[i, j-1]`）都已是正确答案；`dp[i][j]` 等于 `s[i..j]` 里最长回文子序列的长度。

**两端相同时为什么直接 +2（交换论证）。** 设 `P` 是 `s[i..j]` 里任意一个回文子序列。若 `P` 没用 `s[i]` 和 `s[j]`，它整个在 `s[i+1..j-1]` 里，长度不超过 `dp[i+1][j-1]`，比 `dp[i+1][j-1] + 2` 小。若 `P` 只用了其中一个（比如 `s[i]` 和某个内部的 `s[k]` 配对），把 `s[k]` 换成 `s[j]`（同一个字母，位置更靠外）仍是合法回文，长度不变，于是又回到两端都用的情况。所以最优解一定可以让 `s[i]`、`s[j]` 做最外层，答案就是 `dp[i+1][j-1] + 2`。

**两端不同时。** `s[i]` 和 `s[j]` 不能互相配对，答案里至少有一个不出现：要么答案在 `s[i+1..j]` 里，要么在 `s[i..j-1]` 里，取 `max`。

**错误版本：不等时取 `dp[i+1][j-1]`。** 它假设两端都要丢，可往往只需要丢一端。`"bbbab"`：两端都是 `b`，答案 = 区间 `[1, 3]`（`"bba"`）的值 + 2。`"bba"` 两端 `b`、`a` 不同，错误版本只看中间的 `"b"`，得 `1`，漏掉了只丢右端得到的 `"bb"`（长度 2）。于是最终答案错成 `1 + 2 = 3`；正确是 `2 + 2 = 4`（`"bbbb"`）。
