## Q
**LC 1151 最少交换次数来组合所有的 1**｜正确性

为什么「窗口里 `0` 的个数」恰好等于「需要的交换次数」？以及为什么必须尝试**所有**长度为 `w` 的窗口，而不能只看以第一个 `1` 开头的那一个？给出具体输入。

## A
**不变量。** 固定目标窗口 `[i, i + w)`。窗口外共有 `w - (窗口内的 1)` 个 `1`，窗口内共有同样多的 `0`（窗口宽度 `w` 减去窗口内的 `1`）。每次交换可以把一个窗口外的 `1` 与一个窗口内的 `0` 对调，使窗口内的 `0` 减少一个；一次交换最多减少一个，所以至少需要这么多次，同时这样配对恰好够用。

**反例：只试第一个 `1` 开头的窗口。** `data = [1,0,0,0,1,1,1]`，`w = 4`。
- 以第一个 `1`（下标 0）开头的窗口是 `[1,0,0,0]`，里面 `3` 个 `0`，需要 `3` 次交换。
- 但窗口 `[0,1,1,1]`（下标 3 到 6）里只有 `1` 个 `0`：把下标 0 的 `1` 与下标 3 的 `0` 交换一次，得到 `[0,0,0,1,1,1,1]`。
- 正确答案是 `1`；只试第一个窗口会给出 `3`。

**为什么不会数少或数多。** 窗口宽度恒为 `w`，所以窗口内的 `1` 与 `0` 之和固定，窗口内 `1` 越多，`0` 越少，最大化 `1` 就是最小化 `0`。窗口从 `0` 滑到 `n - w`，覆盖了所有可能的目标位置，取最优即可。
