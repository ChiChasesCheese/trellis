## Q
**LC 188 买卖股票的最佳时机 IV**｜Hard · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 14 次 · 最近 2025-10-22（国内 CodeTop）

给整数数组 `prices`（第 `i` 天的价格）和整数 `k`，最多完成 `k` 笔交易（一次买入加一次卖出算一笔），再次买入前必须先卖出手上的股票，求最大利润。`1 <= k <= 100`，`1 <= len(prices) <= 1000`，`0 <= prices[i] <= 1000`。例：`k = 2`，`prices = [3,2,6,5,0,3]` → `7`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最多 `k` 笔交易、不能同时持有」→ 买卖股票的状态机 DP：状态是（第几笔交易，手上有没有货）。
- `k <= 100`、`n <= 1000`：`O(n·k)` 只有 `10^5`，完整的二维表就够。
- 「`k` 足够大时限制失效」→ `k >= n // 2` 时（每笔至少占两天）退化成不限次数的 LC 122：累加所有正的相邻价差。

**推导链。**
1. 暴力：枚举最多 `k` 段互不相交的买卖区间，指数级。
2. 浪费：同一个「第 `i` 天、已用 `j` 笔、有没有货」被不同的买卖序列反复到达，真正不同的状态只有 `n·k·2` 个。
3. 洞察：拆成两张表，`buy[i][j]`（第 `i` 天结束时持有第 `j` 笔的股票）和 `sell[i][j]`（最多完成 `j` 笔、手上没货）；第 `i` 行只来自第 `i - 1` 行，`buy[i][j]` 由 `sell[i-1][j-1]` 转移而来（上一笔必须已经完成）。
4. 最优：填满两张 `(n+1)×(k+1)` 的表，`O(n·k)` 时间、`O(n·k)` 空间；`k >= n // 2` 时是 `O(n)` 的贪心。

**同模式的题**：LC 121 买卖股票的最佳时机、LC 122 买卖股票的最佳时机 II、LC 123 买卖股票的最佳时机 III、LC 309 含冷冻期、LC 714 含手续费。
