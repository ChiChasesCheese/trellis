## Q
**LC 875 爱吃香蕉的珂珂**｜正确性

二分答案能成立靠的是什么性质？判定里的小时数为什么必须向上取整？给出向下取整时会出错的输入，写出错误输出和正确输出。

## A
**不变量。** 记 `hours(k) = Σ ceil(p / k)`。`k` 变大时每一项都不增，所以 `hours(k)` 单调不增，可行（`hours(k) <= h`）的速度构成一个上端的连续区间。循环中始终保持：`hi` 是可行的，`lo` 以下全部不可行；每轮把区间缩小到包含第一个可行值的一半，`lo == hi` 时就是最小可行速度。

**为什么向上取整。** 规则是“一小时只吃一堆，不足 `k` 根也占掉这一小时”。向下取整 `p // k` 会把不足 `k` 根的零头当成零小时。

**反例。** `piles = [3,6,7,11]`，`h = 8`，正确答案 `4`。
- 速度 `3` 时真实小时数是 `1 + 2 + 3 + 4 = 10 > 8`，不可行。
- 向下取整算出 `1 + 2 + 2 + 3 = 8 <= 8`，误判为可行，函数返回 `3`。

再看 `[30,11,23,4,20]`、`h = 5`：五堆每堆至少一小时，恰好 `5` 小时，速度必须 `>= 30`；向下取整的版本返回 `12`，因为 `12` 时 `2 + 0 + 1 + 0 + 1 = 4 <= 5`，把小于 `12` 的堆当成不占时间。
