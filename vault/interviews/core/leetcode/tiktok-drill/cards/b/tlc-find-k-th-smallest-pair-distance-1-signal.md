## Q
**LC 719 找出第 k 小的距离对**｜Hard · CodeTop 国内累计 2 次 · 最近 2025-11-18（国内 CodeTop）

整数数组 `nums`（`2 <= n <= 10^4`，`0 <= nums[i] <= 10^6`）和整数 `k`（`1 <= k <= n * (n - 1) / 2`）。数对 `(nums[i], nums[j])`（`i < j`）的距离是 `|nums[i] - nums[j]|`，返回所有数对距离中第 `k` 小的。例：`[1,3,1]`，`k = 1` → `0`；`[1,6,1]`，`k = 3` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「第 `k` 小」+ 候选集是 `O(n^2)` 个隐式的数对 → 不要把候选全部列出来；考虑**二分答案**（binary search on the answer value）：猜一个距离，数一数有多少对不超过它。
- 「距离不超过 `d` 的数对个数」→ 排序后可用滑动窗口 / 双指针 `O(n)` 数出，且随 `d` 增大不减 → 单调，满足二分条件。
- `n <= 10^4` → 数对约 `5 * 10^7`，全部生成再排序不可行；值域 `<= 10^6` → 二分约 `20` 轮，每轮 `O(n)`。
- `k` 可以大到 `n(n-1)/2` → 用堆弹 `k` 次的方法在 `k` 大时不行。

**推导链。**
1. 暴力：生成所有数对距离，排序取第 `k` 个，`O(n^2 log n)`。
2. 浪费：为一个名次排序了全部距离；而「有多少个距离 `<= d`」可以不列举就数出来。
3. 洞察：排序后固定右端点，满足 `x - nums[left] <= d` 的左端点是一个连续区间，`left` 只增不减，一趟 `O(n)` 得到 `count(d)`；`count` 单调，第 `k` 小的距离就是最小的 `d` 使 `count(d) >= k`。
4. 最优：排序 + 在 `[0, max - min]` 上二分，每轮双指针计数，`O(n log n + n log V)`。
