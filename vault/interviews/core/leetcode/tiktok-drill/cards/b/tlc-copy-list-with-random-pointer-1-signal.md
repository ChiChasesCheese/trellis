## Q
**LC 138 随机链表的复制**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 27 次 · 最近 2026-09-06（国内 CodeTop）

链表每个节点除了 `next` 外还有一个 `random` 指针，可指向链表中任意节点或 `null`。构造它的**深拷贝**：恰好 `n` 个全新节点，值相同，新节点的 `next` 和 `random` 都指向新链表里的节点，不能指向原链表的节点。`0 <= n <= 1000`，`-10^4 <= Node.val <= 10^4`。例：`[[1,1],[2,1]]` → `[[1,1],[2,1]]`（全新节点）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「深拷贝」且指针**可以指向任意节点** → 需要「旧节点 → 新节点」的映射；`random` 可能指向还没创建的后面节点，所以要先建点、后连线。
- 「不能指向原链表的节点」→ 所有指针必须翻译成新节点，不能直接复制。
- 「`O(1)` 额外空间」(常见进阶) → 把映射藏进链表结构本身：新节点紧跟在原节点后面。
- `n <= 1000`：`O(n^2)` 也过得去，但哈希表 `O(n)` 才是标准答案。

**推导链。**
1. 暴力：边走边复制，遇到 `random` 就从头数下标再找新链表对应位置，每个 `random` 一次 `O(n)` 查找，总 `O(n^2)`。
2. 浪费：每次都重新找「原节点对应哪个新节点」。
3. 洞察：先遍历一遍，字典 `原节点 -> 新节点`；再遍历一遍，`新.next = 字典[旧.next]`、`新.random = 字典[旧.random]`，每次查表 `O(1)`。
4. 字典预置 `{None: None}`，空指针也能直接查，省掉 `if`。进阶把映射改成「交织」：`A -> A' -> B -> B'`，空间 `O(1)`。
