## Q
**剑指 Offer 10- II 青蛙跳台阶问题**｜正确性

递推 `f(n) = f(n - 1) + f(n - 2)` 为什么不重不漏？初值为什么是 `f(0) = 1` 而不是 `0`？写成斐波那契的 `a, b = 0, 1` 会怎样？

## A
**不重不漏。** 任意一种跳法，最后一跳要么是 1 格、要么是 2 格，二者必居其一，且不会同时成立。最后一跳是 1 格的方案，去掉这一跳后正好是跳完 `n - 1` 格的方案，一一对应；2 格同理。所以总数是两类之和。

**`f(0) = 1`。** `f(0)` 表示「已经在终点，什么都不用跳」，这是一种方案（空方案）。它让 `f(2) = f(1) + f(0) = 2` 成立，对应「1+1」和「2」两种。

**反例。** 照搬斐波那契的初值 `a, b = 0, 1`，相当于 `f(0) = 0, f(1) = 1`：`n = 2` 返回 `1`（正确 `2`），`n = 0` 返回 `0`（正确 `1`），整列结果都向前错一位。
