## Q
**LC 135 分发糖果**｜Hard · 字节高频

`n` 个孩子站成一排，`ratings[i]` 是第 `i` 个孩子的评分。给每个孩子分糖果：每人至少 `1` 颗；相邻两个孩子中评分更高的那个必须获得更多糖果。求最少需要准备多少颗。`1 <= n <= 5 * 10^4`，`0 <= ratings[i] <= 5 * 10^4`。例：`[1,0,2]` → `5`，`[1,2,2]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「相邻比较」且每个孩子**同时**受左邻居和右邻居的约束 → 把两个方向拆开，各做一遍单向扫描（两遍贪心）。
- 「最少」+ 约束只会让某个值**变大** → 每个位置取满足所有约束的最小值（下界），总和自然最小。
- 评分**相等**的相邻孩子没有约束 → 比较用严格大于。
- `n <= 5 * 10^4`：`O(n)` 或 `O(n log n)`；反复调整的 `O(n^2)` 太慢。

**推导链。**
1. 暴力：全部先发 `1` 颗，反复扫描，遇到违反约束的相邻对就给评分高的加 `1`，直到没有违反。最坏轮数很多，`O(n^2)`。
2. 浪费：同一个孩子的糖数被反复微调。每个孩子的最小值其实可以由「左边连续上升了多久」和「右边连续下降了多久」直接得出。
3. 洞察：左到右扫一遍，只满足"比左邻居评分高就多一颗"；右到左扫一遍，只满足"比右邻居评分高就多一颗"，并与第一遍结果取最大值。
4. 两遍之后两个方向的约束都满足，每个值又都是所需的最小，`O(n)` 时间。进阶可用上坡 / 下坡计数做到 `O(1)` 空间。
