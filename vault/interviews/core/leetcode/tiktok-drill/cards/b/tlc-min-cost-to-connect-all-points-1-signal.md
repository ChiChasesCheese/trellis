## Q
**LC 1584 连接所有点的最小费用**｜Medium · TikTok 高频

二维平面上有点数组 `points`（`1 <= points.length <= 1000`，`-10^6 <= xi, yi <= 10^6`，两两不同）。连接两点的费用是曼哈顿距离 `|xi - xj| + |yi - yj|`。返回把所有点连接的最小总费用，要求任意两点之间有且仅有一条简单路径。例：`[[0,0],[2,2],[3,10],[5,2],[7,0]]` → `20`；`[[0,0],[1,1],[1,0],[-1,1]]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连接所有点」+「有且仅有一条简单路径」→ 生成树（无环、连通）；「总费用最小」→ 最小生成树（MST）。
- 没有给边，任意两点都能连 → 完全图，边数 `n(n - 1) / 2`，`n = 1000` 时约 `5 × 10^5`。
- 稠密图 → Prim 数组版 `O(n^2)`，不用堆，不用建边；稀疏图才偏向 Kruskal。
- 费用是曼哈顿距离，满足三角不等式，但与 MST 的选边无关，可以直接按定义计算。

**推导链。**
1. 暴力：枚举所有生成树，`n^(n-2)` 棵，不可行。
2. 割性质：把点分成已选和未选两部分，连接两部分的最小边一定属于某棵 MST，贪心安全。
3. Prim：从点 `0` 出发，每轮把离已选集合最近的点加入，累加那条边的权重。
4. 实现：数组 `dist[i]` 维护 `i` 到已选集合的最短距离；每轮线性扫描取最小，再用新点更新其余点的 `dist`，总共 `n` 轮、每轮 `O(n)`。
5. 若改用 Kruskal：先建 `5 × 10^5` 条边排序，`O(n^2 log n)`，在这里比 Prim 慢。
