## Q
**补充题 1 排序奇升偶降链表**｜Medium · CodeTop 国内累计 45 次 · 最近 2026-03-04（国内 CodeTop）

单链表位置从 `1` 开始数，奇数位上的值从头到尾升序，偶数位上的值从头到尾降序。把整条链表按值升序排好，要求 `O(n)` 时间、`O(1)` 额外空间。`0 <= 链表长度 <= 5 * 10^4`，`-10^5 <= Node.val <= 10^5`。例：`1 -> 8 -> 3 -> 6 -> 5 -> 4 -> 7 -> 2` → `1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「奇升偶降」→ 链表是**两条已经有序的子序列交错**而成 → 先**拆分**，再把它们拼回去，用不着通用排序。
- 偶数位降序、奇数位升序 → 一条需要**反转**，另一条保持 → 反转链表 + 合并两个有序链表，两个必会的基本操作。
- `O(n)` 时间 + `O(1)` 空间 → 不能抄数组排序（`O(n)` 空间），不能归并排序（`O(n log n)`）。
- `n` 到 `5 * 10^4`：`O(n log n)` 也不会超时，但这道面试题考的是有没有利用结构。

**推导链。**
1. 暴力：值取出来排序再写回，`O(n log n)` 时间、`O(n)` 空间；或链表归并排序 `O(n log n)`。
2. 浪费：每个子序列已经有序，却当作无序重排。
3. 洞察：按位置拆成奇链、偶链；偶链用**头插法**边拆边反转，变成升序。
4. 最优：拆（含反转）一趟 `O(n)`，合并一趟 `O(n)`；拆完要切断奇链尾部的旧指针。

**同模式的题**：LC 206 反转链表、LC 21 合并两个有序链表、LC 328 奇偶链表、LC 148 排序链表、LC 143 重排链表。
