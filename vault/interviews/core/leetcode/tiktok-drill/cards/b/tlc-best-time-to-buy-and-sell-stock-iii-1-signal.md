## Q
**LC 123 买卖股票的最佳时机 III**｜Hard · CodeTop 国内累计 21 次 · 最近 2026-06-03（CodeTop）

数组 `prices` 的第 `i` 个元素是某股票第 `i` 天的价格。最多完成**两笔**交易，求最大利润；不能同时参与多笔交易（必须先卖出才能再买入）。`1 <= prices.length <= 10^5`，`0 <= prices[i] <= 10^5`。例：`[3,3,5,0,0,3,1,4]` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最多 `k` 笔交易」「不能同时持有」→ **状态机 DP**：状态是（完成了几笔，当前是否持有股票）。
- `k = 2`：状态只有四个（买 1、卖 1、买 2、卖 2），四个变量滚动即可。
- 「最大利润」+ 每天的选择只依赖前一天的状态 → 一遍扫描，`O(n)`。
- `n <= 10^5`：`O(n^2)` 枚举分界点不行。

**推导链。**
1. 暴力：枚举所有的买入卖出下标组合，最多四个下标，`O(n^4)`；或者枚举分界日，两段各做一笔最优交易，`O(n^2)`。
2. 浪费：每个分界日都重新计算前缀和后缀的最大利润。
3. 洞察一：前缀最优、后缀最优各扫一遍预先算出，分界日直接相加，`O(n)` 时间、`O(n)` 空间。
4. 洞察二：把四个状态当成"手里最多的现金"逐天更新，`buy1 → sell1 → buy2 → sell2` 依次由前一个状态转移而来，`O(1)` 空间；推广到 `k` 笔只需要多几组状态。

**同模式的题**：LC 121 买卖股票的最佳时机、LC 188 买卖股票的最佳时机 IV、LC 309 含冷冻期、LC 714 含手续费。
