## Q
**LC 321 拼接最大数**｜正确性

合并两个子序列时，为什么首位相同时必须比较**整个剩余后缀**，不能随便取一边？单调栈挑子序列时，为什么必须限制弹出次数？各给一个反例。

## A
**合并的不变量。** 每一步取出的数字，都使「已输出部分 + 剩余部分最好的合并」最大。两边首位不同，取大的显然最好；首位相同时，取哪边决定了下一步还能用到哪些数字：取了后缀较大那边的首位，较大的后续数字更早露出来。

**反例（合并）。** `[2,5]` 与 `[2,6]`：只比首位、相等取左边，先拿左边的 2，下一步面对 `5` 和 `2`，取 5，得 `[2,5,2,6]`。比较后缀 `[2,6] > [2,5]`，先拿右边的 2，接着 `6`，得 `[2,6,2,5]`，这才是最大。

**单调栈的不变量。** 栈里加上还没处理的元素，总数始终 `>= t`，所以 `drop = len - t` 是弹出次数的上限。

**反例（不限次数）。** `pick([1,2,3], 2)`：不限次数时 2 弹掉 1、3 再弹掉 2，只剩 `[3]`，长度不够；限制 `drop = 1` 后只弹掉 1，得到 `[2,3]`。
