## Q
**LC 1405 最长快乐字符串**｜Medium · LC TikTok 全时段热度 68/100 · CodeTop 国内累计 1 次 · 最近 2021-04-14（国内 CodeTop）

如果字符串中不含 `'aaa'`、`'bbb'`、`'ccc'` 这样的子串，就称它是「快乐字符串」。给三个整数 `a`、`b`、`c`，返回**任意一个**满足下列全部条件的字符串 `s`：`s` 是尽可能长的快乐字符串；`s` 中最多有 `a` 个 `'a'`、`b` 个 `'b'`、`c` 个 `'c'`；`s` 只含 `'a'`、`'b'`、`'c'`。如果不存在这样的字符串，返回 `""`。

约束：`0 <= a, b, c <= 100`，`a + b + c > 0`。

例：`a = 1, b = 1, c = 7` → `"ccaccbcc"`（`"ccbccacc"` 也对）；`a = 2, b = 2, c = 1` → `"aabbc"`；`a = 7, b = 1, c = 0` → `"aabaa"`（唯一答案）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「同一字母不能连续出现 3 次」+「各字母个数有限」+「求最长」→ 每步都在**选一个字母**，个数最多的字母是最危险的（最容易被迫连续）→ **贪心 + 堆**。
- 只有三种字母、总数 `<= 300` → 堆很小，朴素的 `sorted` 也可以；关键是贪心的正确性与边界。
- 暴力 / DP 的状态是 `(a, b, c, 末尾字母, 连续次数)`，`100^3 × 6` 太大 → 需要贪心。

**推导链。**
1. 暴力：DFS 枚举每一位，指数级；记忆化后状态约 `6 × 10^6` 级，也不理想。
2. 贪心直觉：剩余最多的字母最容易导致连续超限，所以应该优先放它，并用别的字母去隔开。
3. 洞察：每步取最多的字母；若它已经连续两个，就垫一个次多的字母（用完再放回最多的）；没有别的字母可垫时结束。
4. 最优：大小至多 3 的最大堆（Python 用负数），每放一个字符 `O(log 3)`，总 `O(N)`。

**同模式的题**：LC 767 重构字符串、LC 984 不含 AAA 或 BBB 的字符串、LC 621 任务调度器、LC 1054 距离相等的条形码、LC 358 K 距离间隔重排字符串。
