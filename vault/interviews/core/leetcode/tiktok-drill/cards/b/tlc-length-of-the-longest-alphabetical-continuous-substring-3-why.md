## Q
**LC 2414 最长的字母序连续子字符串的长度**｜正确性

为什么延续的条件是“后一个字符恰好比前一个大 `1`”，而不是“后一个比前一个大”？为什么只比较相邻两个字符就够了？给出把条件写成“递增”的错误输出。

## A
**不变量。** 处理到下标 `i` 时，`run` 是“以 `s[i]` 结尾的最长字母序连续子串的长度”。

**为什么只看相邻两个。** 一个子串是字母序连续的，当且仅当它里面每一对相邻字符都满足“后一个恰好是前一个的下一个字母”。所以以 `s[i]` 结尾的最长连续子串，要么只含 `s[i]` 自己，要么是“以 `s[i-1]` 结尾的最长连续子串”再接上 `s[i]`（要求 `s[i]` 恰好是 `s[i-1]` 的下一个字母）。不接得上时，任何更长的串都会在 `s[i-1]`、`s[i]` 这一对上违反条件，所以只能从自己重新开始。这样 `run` 的递推只依赖前一个状态。

**为什么必须是“恰好差 `1`”。** 字母序连续要求字母在字母表里挨着，中间不能跳过字母。“递增”只说明顺序，不要求紧邻。

**反例 `"acd"`。** 正确答案 `2`（`"cd"`）；`"ac"` 不是连续串，因为 `a` 和 `c` 之间还有 `b`。
- 条件写成 `cur > prev`：`a -> c` 递增，`run = 2`；`c -> d` 递增，`run = 3`，返回 `3`，错。
- 条件写成 `ord(cur) - ord(prev) == 1`：`a -> c` 差 `2`，`run` 重置为 `1`；`c -> d` 差 `1`，`run = 2`，返回 `2`，对。

**环形的 `z -> a`。** `ord('a') - ord('z') = -25`，不等于 `1`，所以 `"za"` 不会被当作连续串，与题意一致。
