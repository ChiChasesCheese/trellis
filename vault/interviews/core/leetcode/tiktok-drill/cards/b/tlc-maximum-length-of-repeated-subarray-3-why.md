## Q
**LC 718 最长重复子数组**｜正确性

为什么不匹配时必须把 `dp` 清零，而子序列版本不需要？一维压缩时内层为什么必须倒序？各给一个出错的具体输入。

## A
**不变量。** 处理完 `nums1` 的前 `i` 个元素后，`dp[j]` 恰好等于"以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的最长公共子数组长度"，两个元素不相等时是 `0`（以它们结尾的公共子数组不存在）。

**为什么清零。** 子数组要求连续：只有 `nums1[i-1] == nums2[j-1]` 时，才能把"以 `nums1[i-2]`、`nums2[j-2]` 结尾"的那段延长一格。一旦这一对不相等，以它们结尾的子数组长度就是 `0`，不能沿用以前的值。子序列可以跳过元素，所以才用 `max(dp[i-1][j], dp[i][j-1])` 继承。

**反例 1：当成子序列。** `nums1 = [1,2,3]`、`nums2 = [1,3]`：
- 子序列版 `max(...)` 得到 `2`（`1, 3` 不连续）。
- 子数组版得到 `1`，因为 `[1,3]` 在 `nums1` 里不连续。

**反例 2：不匹配时不清零。** 不写 `else: dp[j] = 0`：
- `nums1 = [0,1,0]`、`nums2 = [0,0,0]`：遇到 `1` 时 `dp` 仍保留着上一行的 `1`，下一个 `0` 又把它接上，得到 `2`。
- 正确是 `1`（`nums1` 里的两个 `0` 被 `1` 隔开了）。

**反例 3：内层正序。** `j` 从小到大时，`dp[j-1]` 已被本行更新：
- `nums1 = [0,0,1]`、`nums2 = [0,0,0]`：第一行就把 `dp` 变成 `[0,1,2,3]`（同一个 `0` 被反复接续），答案 `3`。
- 正确是 `2`，因为 `nums1` 里只有两个 `0`。
