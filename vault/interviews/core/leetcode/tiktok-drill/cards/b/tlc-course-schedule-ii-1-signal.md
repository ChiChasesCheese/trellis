## Q
**LC 210 课程表 II**｜Medium · LC TikTok 全时段热度 88/100 · CodeTop 国内累计 13 次 · 最近 2026-09-15（国内 CodeTop）

共有 `numCourses` 门课，编号 `0` 到 `numCourses - 1`。先修关系 `prerequisites[i] = [a, b]` 表示学 `a` 之前必须先学 `b`。返回一个能学完所有课程的顺序，多个答案返回任意一个，学不完返回空数组。`1 <= numCourses <= 2000`，`0 <= prerequisites.length <= numCourses * (numCourses - 1)`，`prerequisites[i].length == 2`，`0 <= a, b < numCourses`，`a != b`，先修对互不相同。例：`2, [[1,0]]` → `[0,1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「满足先后依赖的一个顺序」→ 拓扑排序（topological sort）；「学不完返回空」→ 判环，两件事用同一个算法完成。
- 「多个答案返回任意一个」→ 不需要字典序，普通队列即可；要最小字典序才换堆。
- 边数可达约 `4 * 10^6`：用邻接表一次建好，Kahn 算法 `O(V + E)`。

**推导链。**
1. 暴力：枚举排列检查先后关系，`O(n!)`；或每轮扫描全部课程找"先修课都学完"的课，`O(V^2 + VE)`。
2. 浪费：每轮重新找可学的课。
3. 洞察：维护每门课还差几门先修（入度）。学完一门课，只把它的后继入度减一，减到 0 的立刻入队。
4. 出队顺序天然是合法顺序；有环时环上的课入度降不到 0，出队总数不足，返回 `[]`。

**同模式的题**：LC 207 课程表、LC 269 火星词典、LC 1203 项目管理、LC 444 序列重建。
