## Q
**LC 104 二叉树的最大深度**｜正确性

为什么「按层数轮数」就是最大深度？递归写法里，空节点返回 `0` 而不是 `1`，写错会怎样？给出具体的错误输出。

## A
**不变量。** 第 `k` 轮开始时，`level` 恰好是深度为 `k` 的所有节点（根的深度是 `1`）。每个节点只有一个父节点，所以它只会进入父节点的下一层，不重不漏。当深度 `k` 的层非空而深度 `k + 1` 的层为空时，最深的节点深度就是 `k`，循环做了 `k` 轮，`depth == k`。

**递归等价形式。** `depth(node) = 1 + max(depth(左), depth(右))`，`depth(None) = 0`。这里的 `1` 计入当前节点，`0` 表示「这一侧什么都没有」。

**反例 1：空节点返回 `1`。** 示例 `[3,9,20,null,null,15,7]`：叶子 `9` 变成 `1 + max(1, 1) = 2`，`15`、`7` 同样是 `2`，`20` 是 `3`，根 `3` 是 `4`。输出 `4`，正确是 `3`。每个叶子被多算了一层空节点。

**反例 2：把 `max` 写成 `min`。** `[1,null,2]`：根的左孩子为空，`min(0, 1) = 0`，根深度 `1`。输出 `1`，正确是 `2`。这正是「最小深度」要专门处理单孩子节点的原因：空的一侧不是叶子。

**反例 3：只数左链。** `[1,null,2]` 沿左孩子走只有 `1`，丢了右侧的链。
