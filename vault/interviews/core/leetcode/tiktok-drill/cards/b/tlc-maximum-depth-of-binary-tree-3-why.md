## Q
**LC 104 二叉树的最大深度**｜正确性

为什么 `1 + max(depth(左), depth(右))` 就是最大深度？空节点返回 `0` 而不是 `1`，写错会怎样？给出具体的错误输出。

## A
**不变量。** 对每个结点，`depth(node)` 是以它为根的子树的最大深度。归纳：`depth(None) = 0`；非空结点的最长路径必须先经过自己，再整条落在左子树或右子树里，所以等于 `1 + max(depth(左), depth(右))`。这里的 `1` 计入当前节点，`0` 表示「这一侧什么都没有」。每个节点只被它的父节点调用一次，不重不漏。

**反例 1：空节点返回 `1`。** 示例 `[3,9,20,null,null,15,7]`：叶子 `9` 变成 `1 + max(1, 1) = 2`，`15`、`7` 同样是 `2`，`20` 是 `3`，根 `3` 是 `4`。输出 `4`，正确是 `3`。每个叶子被多算了一层空节点。

**反例 2：把 `max` 写成 `min`。** `[1,null,2]`：根的左孩子为空，`min(0, 1) = 0`，根深度 `1`。输出 `1`，正确是 `2`。这正是「最小深度」要专门处理单孩子节点的原因：空的一侧不是叶子。

**反例 3：只数左链。** `[1,null,2]` 沿左孩子走只有 `1`，丢了右侧的链。
