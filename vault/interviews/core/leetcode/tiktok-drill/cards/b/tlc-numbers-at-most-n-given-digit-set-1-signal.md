## Q
**LC 902 最大为 N 的数字组合**｜Hard · TikTok·字节 高频

给一个按非递减顺序排列的数字字符数组 `digits`（`1 <= digits.length <= 9`，元素是 `'1'` 到 `'9'` 的单个字符且互不相同），每个数字可以使用任意多次来拼数。返回能拼出的、小于或等于整数 `n` 的正整数个数，`1 <= n <= 10^9`。例：`digits = ["1","3","5","7"]`，`n = 100` → `20`；`digits = ["7"]`，`n = 8` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「小于等于 `N`、由给定数字拼成的数有多少个」→ 数位 DP（digit DP）/ 数位计数：按位处理，状态是“是否仍然紧贴 `n` 的前缀”。
- `n <= 10^9`，答案可达 `4 × 10^8` 量级 → 不能逐个枚举，结果必须靠乘法和幂算出来。
- `digits` 已按非递减排序 → “比 `n[i]` 小的数字有几个”可以用二分查找（`bisect_left`）直接得到。
- 数字集合只含 `1..9`，没有 `0` → 不用处理前导零；位数不同的数不会混淆。

**推导链。**
1. 暴力：枚举 `1..n`，检查每位是否都在 `digits` 里，`O(n · L)`，约 `10^10`。
2. 浪费：大多数数从某一位起就已经小于 `n`，剩下的每一位有 `d` 种选法，个数是 `d` 的幂，不用一个个数。
3. 按“与 `n` 第一次不同的位置”给数分类，类与类不重叠：
   - 位数比 `n` 少的：`Σ d^len`；
   - 位数相同、第 `i` 位更小：`(比 n[i] 小的数字个数) × d^(L-1-i)`；
   - 与 `n` 完全相同：`n` 每一位都在 `digits` 里就再加 `1`。
4. 往后贴着 `n` 走的前提是 `n[i]` 在 `digits` 里，否则立刻停止。

**同模式的题**：LC 233 数字 1 的个数、LC 600 不含连续 1 的非负整数、LC 2376 统计特殊整数、LC 357 统计各位数字都不同的数字个数。
