## Q
**LC 80 删除有序数组中的重复项 II**｜Medium · CodeTop 国内累计 8 次 · 最近 2026-09-04（CodeTop）

给一个升序数组 `nums`，**原地**删除重复项，使每个元素**最多出现两次**，返回新长度；必须满足 `O(1)` 额外空间。`1 <= nums.length <= 3 * 10^4`，`-10^4 <= nums[i] <= 10^4`，`nums` 已按升序排列。例：`nums = [1,1,1,2,2,3]` → 返回 `5`，前五个元素 `[1,1,2,2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**原地**」+「`O(1)` 额外空间」+「返回新长度」→ **快慢指针**：读指针扫描，写指针记录结果的末尾。
- 「**有序**」→ 相同的值相邻，判断「已经出现几次」不需要哈希表，只看结果末尾的元素。
- 「最多两次」→ 比较对象是结果里**倒数第二个**元素；把 `2` 换成 `k` 就是通用解。
- `n` 到 `3 * 10^4` → `O(n^2)` 也许能过，但要求的是 `O(n)`。

**推导链。**
1. 暴力 A：`Counter` 计数，另建数组保留前两个；违反 `O(1)` 空间。
2. 暴力 B：发现多余的元素就删除并把后面整体前移，每次 `O(n)`，总 `O(n^2)`。
3. 洞察：不必真的删，只要把要保留的元素依次写到前面；写指针之前就是合法结果。
4. 判断：新元素 `x` 若等于 `nums[w - 2]`，升序保证 `nums[w - 1]` 也是 `x`，说明已有两个，丢弃；否则写入。一次扫描，`O(n)`、`O(1)`。
