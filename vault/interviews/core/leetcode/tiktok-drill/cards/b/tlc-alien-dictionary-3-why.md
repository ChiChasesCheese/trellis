## Q
**LC 269 火星词典（Alien Dictionary）**｜正确性

为什么只比较相邻单词就够？为什么前缀违例必须单独判断？拓扑排序取不完为什么就等于"没有合法顺序"？

## A
**不变量。** 列表在某个字母顺序下有序，当且仅当每一对相邻单词满足 `a <= b`；不相邻的比较由传递性保证，不会提供新约束。相邻的 `a <= b` 恰好等价于：要么 `a` 是 `b` 的前缀（含相等），要么在第一个不同的位置 `a[i] < b[i]`。前者与字母顺序无关，后者就是一条边。所以所有约束都已经在图里；若存在拓扑序，按它排列字母，列表有序；若图有环，任何线性顺序都会违反环上某条边，无解。

**为什么前缀要单独判断。** `a` 是 `b` 的真前缀且 `a` 更长（即 `b` 是 `a` 的真前缀却排在后面），不管字母顺序如何，`b` 都必须排在 `a` 前面，所以无解；这种情况 `zip` 找不到不同的字母，不会产生边，也不会形成环，只能显式检查。

**反例（错误写法一）：漏掉前缀检查。** `["abc","ab"]`：没有边，三个字母入度都是 `0`，返回 `"abc"`；正确答案是 `""`。

**反例（错误写法二）：不给重复边去重。** `["ab","ac","xb","xc"]`：边 `b → c` 出现两次，入度被加到 `2`，但邻接集合只有一条边，Kahn 里只减一次，`c` 永远到不了 `0`，错误返回 `""`；合法答案如 `"abcx"`。
