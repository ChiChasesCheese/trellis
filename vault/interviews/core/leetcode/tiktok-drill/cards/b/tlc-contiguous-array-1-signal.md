## Q
**LC 525 连续数组**｜Medium · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 9 次 · 最近 2026-05-06（国内 CodeTop）

给一个二进制数组 `nums`（每个元素不是 `0` 就是 `1`），求含有**相同数量的 `0` 和 `1`** 的最长连续子数组的长度。`1 <= nums.length <= 10^5`。例：`[0,1,1,1,1,1,0,0,0]` → `6`（`[1,1,1,0,0,0]`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连续**子数组」+「两类元素**个数相等**」→ 把 `0` 记成 `-1`，条件变成「子数组和为 0」→ **前缀和 + 哈希表**（prefix sum + hash map）。
- 求「**最长**」→ 哈希表存每个前缀和**最早**出现的下标。
- `n` 到 `10^5` → 需要 `O(n)`，`O(n^2)` 的区间枚举不行。
- 近似信号「最长子数组」容易让人想到滑动窗口，但元素有正有负，窗口合法性不单调，窗口用不上。

**推导链。**
1. 暴力：枚举区间再计数，`O(n^3)`；固定左端点向右累计，`O(n^2)`。
2. 浪费：每个左端点都把同一段前缀重新累计一遍。
3. 关键：设 `bal` 为前缀里 1 的个数减 0 的个数，区间 `(j, i]` 合法当且仅当两端前缀的 `bal` 相等。
4. 最优：扫描时用字典存「`bal` 值 → 第一次出现的下标」，每个右端点 `O(1)` 查到最远的左端点，总计 `O(n)`。

**同模式的题**：LC 560 和为 K 的子数组、LC 325 和等于 k 的最长子数组、LC 1124 表现良好的最长时间段。
