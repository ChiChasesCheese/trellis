## Q
**LC 1262 可被三整除的最大和**｜Medium · 字节高频｜正确性

DP 的初值为什么必须是 `dp[0] = [0, 不可达, 不可达]`？写成 `[0, 0, 0]` 会错在哪里？为什么对每个余数只保留最大和就够了？

## A
**不变量。** `dp[i][r]` 是前 `i` 个数的所有子集里，和模 `3` 等于 `r` 的最大和；子集不存在时是「不可达」。

**为什么只保留最大和。** 所有数都是正数，且转移只依赖余数：同余数下两个不同的和 `s1 < s2`，之后接上同样的元素，`s2` 的结果总是更大，所以 `s1` 永远不会成为最优。

**初值的含义。** 只用前 `0` 个数，唯一的子集是空集，和为 `0`，余数 `0`；余数 `1` 和 `2` 凑不出来，必须是不可达。

**反例：初值全 `0`。** 这等于说「不选任何数也能得到余数 `1`、`2`，和为 `0`」。`nums = [4]`：`dp[1][0] = max(dp[0][0], dp[0][(0 - 4) % 3] + 4) = max(0, dp[0][2] + 4) = 4`，把一个本不存在的余数 `2` 状态加上 `4`，得出答案 `4`，但 `4` 除以 `3` 余 `1`；正确答案是 `0`。用 `-(10 ** 18)` 作不可达后，`dp[0][2] + 4` 仍是极小的负数，不会被选中。
