## Q
**LC 1162 地图分析**｜Medium · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 1 次 · 最近 2025-12-24（国内 CodeTop）

`n x n` 的网格 `grid`，`0` 是海洋，`1` 是陆地。找一个海洋格，使它到**最近**陆地格的距离**最大**，返回这个距离；网格上只有陆地或只有海洋时返回 `-1`。距离是曼哈顿距离（Manhattan distance）`|x0 - x1| + |y0 - y1|`。`1 <= n <= 100`，`grid[i][j]` 是 0 或 1。例：`[[1,0,0],[0,0,0],[0,0,0]]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「到**最近**的陆地」+「网格、四方向」→ **多源 BFS**（multi-source BFS）：所有源点一起作为第 0 层。
- 「在所有海洋格里取**最大**」→ BFS 最后被到达的那一层的层数。
- 网格无障碍 → 四方向最少步数 = 曼哈顿距离，所以层数就是题目要的距离。
- `n <= 100`，共 `10^4` 格 → `O(n^2)` 足够，`O(n^4)` 约 `10^8` 次运算不可取。

**推导链。**
1. 暴力：每个海洋格对所有陆地求最小距离，再取最大，`O(n^4)`。
2. 每个海洋格单独 BFS 找最近陆地：仍是 `O(n^4)`，各次搜索重复走同一片格子。
3. 关键：反过来让所有陆地同时向外扩散，每个海洋格第一次被扩到时，扩到它的就是最近的陆地。
4. 最优：多源 BFS，每格入队一次，`O(n^2)`；最后一层的层数即答案。

**同模式的题**：LC 542 01 矩阵、LC 994 腐烂的橘子、LC 286 墙与门。
