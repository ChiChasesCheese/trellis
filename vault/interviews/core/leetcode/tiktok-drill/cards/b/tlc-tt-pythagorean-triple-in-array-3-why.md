## Q
**整数数组中的勾股三元组**｜正确性

双指针为什么不会漏掉合法的 `(i, j)`？为什么必须先平方再排序、并且不能用集合去重？给出对应的错误输入。

## A
**双指针的不变量。** 固定 `k`，在有序数组 `sq[0..k-1]` 上，若存在合法的一对 `(a, b)`，且 `a < b`（下标），则任何时刻 `i <= a` 且 `j >= b`。证明：假设 `i` 先走到 `a`、`j` 还在 `b` 右边，则 `sq[a] + sq[j] > sq[a] + sq[b] = sq[k]`，会移动 `j` 而不是 `i`；对称地，`j` 先走到 `b`、`i` 还在 `a` 左边时，`sq[i] + sq[b] < sq[k]`，会移动 `i`。所以指针不会越过合法的一对。

**为什么要平方后再排序。** 平方的大小顺序和原值的大小顺序不一致（负数）。排序和比较必须在同一个量上：平方。

**为什么不能去重。** 题目只要求下标不同。`0` 和重复值会产生合法三元组，去重会丢掉它们。

**反例一：没平方就排序。** `[-5,3,4]`：
- 按原值排序是 `[-5,3,4]`，最大的是 `4`，把 `4` 当斜边，直角边只能来自 `-5` 与 `3`，`25 + 9 = 34 ≠ 16`。
- 最终返回 `False`，正确是 `True`（`3^2 + 4^2 = (-5)^2`）。

**反例二：值去重。** `[0,0,0]`：
- 去重后只剩一个 `0`，数组长度不足 `3`，返回 `False`。
- 正确是 `True`：三个不同下标上的值都是 `0`，`0 + 0 = 0`。

`[5,0,5]` 去重成 `{0,5}`，只有一个 `5`，也找不到 `0^2 + 5^2 = 5^2`，同样误判为 `False`，正确是 `True`。
