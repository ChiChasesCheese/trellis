## Q
**LC 498 对角线遍历**｜正确性

为什么按 `i + j` 分组、再按奇偶决定是否反向，就等价于题目的"先右上、再左下交替"？奇偶写反或者忘记反向，各自会得到什么？

## A
**不变量。** 向右上走一步是 `(i - 1, j + 1)`，向左下走一步是 `(i + 1, j - 1)`，两种走法都保持 `i + j` 不变；到边界拐弯后进入的位置（右移一格或下移一格）使 `i + j` 恰好加一。所以遍历路径依次经过 `i + j = 0, 1, 2, …` 的每一条反对角线，不重不漏，每条线内部的顺序由当前的方向决定。

**方向与奇偶。** `d = 0` 只有一个元素；之后第 `d = 1` 条是从 `(0, 1)` 向左下走到 `(1, 0)`（题目先向右上到边界，拐到 `(0, 1)`），所以奇数条是**左下方向**，对应行号递增，也就是分组里的原顺序；偶数条是**右上方向**，行号递减，需要反转。

**反例 1：完全不反向。** `[[1,2,3],[4,5,6],[7,8,9]]`：
- 得到 `[1,2,4,3,5,7,6,8,9]`。
- 正确是 `[1,2,4,7,5,3,6,8,9]`，`d = 2` 那条（`3,5,7`）应该倒着走。

**反例 2：奇偶写反。** 奇数条反向、偶数条原序：
- 同一个矩阵得到 `[1,4,2,3,5,7,8,6,9]`。
- 第一步就走错：应先到 `2` 再到 `4`。

**边界情形。** 单行 `[[1,2,3]]`：每条对角线只有一个元素，反不反向都一样，结果 `[1,2,3]`；单列同理。分组法不需要为这些情形写任何额外判断，这是它比模拟法稳的地方。
