## Q
**LC 793 阶乘函数后 K 个零**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-05-07（CodeTop）

`f(x)` 是 `x!` 末尾零的个数（`0! = 1`）。给定 `k`（`0 <= k <= 10^9`），返回使 `f(x) = k` 的非负整数 `x` 的个数。例：`k = 0` → `5`；`k = 5` → `0`；`k = 3` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`x!` 末尾零的个数」→ 数 `5` 的因子（`2` 的因子总是更多），`f(x) = x//5 + x//25 + x//125 + ...`，一个 `O(log x)` 的小函数。
- `f` 随 `x` 单调不减 → 「求满足 `f(x) = k` 的 `x`」可以对 `x` **二分**；「等于 `k` 的个数」写成 `第一个 f >= k+1 的位置 - 第一个 f >= k 的位置`。
- `k` 高达 `10^9` → `x` 约为 `4 * 10^9`，逐个枚举不可行；二分 `x` 只要约 `33` 轮。
- 答案只可能是 `0` 或 `5`：`f` 只在 `5` 的倍数处变化，相等的 `f` 值占连续 `5` 个 `x`。

**推导链。**
1. 暴力：从 `0` 起算每个 `f(x)`，数等于 `k` 的个数，`O(k)` 级别次计算。
2. 浪费：`f` 单调，等于 `k` 的 `x` 是一段连续区间，不必逐个检查。
3. 洞察：区间左端是第一个 `f(x) >= k`，右端是第一个 `f(x) >= k + 1`，个数相减；上界 `5 * (k + 1)` 一定够，因为 `f(5m) >= m`。
4. 最优：两次对 `x` 的二分，每轮调用 `O(log x)` 的 `f`，总 `O(log^2 k)`。
