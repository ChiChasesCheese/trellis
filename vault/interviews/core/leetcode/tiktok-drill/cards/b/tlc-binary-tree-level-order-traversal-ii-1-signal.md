## Q
**LC 107 二叉树的层序遍历 II**｜Medium · 字节 高频

给二叉树的根结点 `root`，返回结点值**自底向上的层序遍历**：从叶子所在层到根所在层逐层，每层从左到右。树中结点数在 `[0, 2000]`，`-1000 <= Node.val <= 1000`。例：`root = [3,9,20,null,null,15,7]` → `[[15,7],[9,20],[3]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**层序**」→ **广度优先搜索（BFS）**，按层逐层处理。
- 「**自底向上**」→ 只是 LC 102 的结果反转，不是新算法：先自顶向下收集，再整体倒过来。
- 「输出按层分组」→ 需要知道**每层的边界**：用一个列表代表一整层，处理完再生成下一层，比「队列 + 记录层大小」更不容易错。
- 结点数到 `2000` → DFS 递归深度可能到 `2000`，超过 Python 默认递归上限 `1000`；BFS 没有这个风险。

**推导链。**
1. 暴力：DFS 带深度，放进「深度 → 列表」，最后按深度倒序输出。思路对，但链形的树会触发 `RecursionError`。
2. 洞察：BFS 天然一层接一层。让 `level` 表示当前层的所有结点，一次推导出值列表和下一层。
3. 下一层 = 当前层每个结点的非空左右孩子，用一个嵌套列表推导式写出。
4. 收集完的 `ans` 自顶向下，最后 `ans[::-1]`。每个结点处理一次，`O(n)`；反转的是外层列表，只需 `O(层数)`。

**同模式的题**：LC 102 二叉树的层序遍历、LC 103 之字形层序遍历、LC 199 二叉树的右视图、LC 429 N 叉树的层序遍历。
