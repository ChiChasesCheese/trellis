## Q
**LC 1151 最少交换次数来组合所有的 1**｜Medium · LC TikTok 全时段热度 75/100 · CodeTop 国内累计 1 次 · 最近 2022-07-28（国内 CodeTop）

给二进制数组 `data`，通过交换**任意两个位置**的元素，把数组中所有的 `1` 组合到一起（连成一段），返回所需的最少交换次数。`1 <= data.length <= 10^5`，`data[i]` 为 `0` 或 `1`。例：`[1,0,1,0,1]` → `1`（交换后 `[1,1,1,0,0]`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「所有的 `1` 聚成一段」→ 最终这些 `1` 占据的区间**长度固定**，等于 `1` 的总数 `w` → **定长滑动窗口**。
- 「交换任意两个位置」→ 交换不限相邻，一次交换可以把窗口外的一个 `1` 换进窗口、把窗口里的一个 `0` 换出去 → 代价只看「窗口里还缺几个 `1`」，不看距离。
- `n` 到 `10^5` → 需要 `O(n)`，不能对每个窗口重新数。
- 数组只含 `0/1` → 窗口内 `1` 的个数就是窗口元素之和，增量更新极简单。

**推导链。**
1. 暴力：枚举每个起点的窗口 `[i, i + w)`，数里面的 `0`，`O(nw)`。
2. 浪费：相邻两个窗口只差「出一个、进一个」，重新数整个窗口是重复劳动。
3. 关键：窗口里每个 `0` 恰好对应一次交换（换一个窗口外的 `1` 进来），所以代价 = 窗口里 `0` 的个数 = `w - 窗口里 1 的个数`；要最少，就让窗口里的 `1` 最多。
4. 滑动窗口增量更新 `cur += data[i] - data[i - w]`，一遍扫完取最大值，答案 `w - best`，`O(n)`。
