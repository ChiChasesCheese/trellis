## Q
**LC 726 原子的数量**｜Hard · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 8 次 · 最近 2026-09-21（国内 CodeTop）

给一个字符串化学式 `formula`，返回每种原子的数量。原子名是一个大写字母加 `0` 个或多个小写字母；数量大于 `1` 时原子后跟数字，等于 `1` 时省略；括号括起的化学式后可跟倍数。按原子名字典序输出，数量为 `1` 则不写数字。`1 <= formula.length <= 1000`，由字母、数字、`(`、`)` 组成，保证有效。例：`"Mg(OH)2"` → `"H2MgO2"`；`"K4(ON(SO3)2)2"` → `"K4N2O14S4"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**嵌套括号** + 倍数」→ **栈**，每层括号对应一个栈帧（同族：LC 394 字符串解码、LC 224 基本计算器）。
- 倍数在 `)` **后面**：读到 `(` 时还不知道倍数 → 每层各自累计，弹出时再统一乘。
- 原子名 = 一个大写 + 若干小写、数字可省略 → 用**正则 / 手写扫描**切 token。
- 「按字典序输出」→ 最后对原子名 `sorted`。
- `n <= 1000` → 线性或平方都可以；但**展开括号**会指数膨胀，不可取。

**推导链。**
1. 暴力：把括号展开成一长串原子再计数；`"((((H2)2)2)2)2"` 这类嵌套倍数相乘是指数增长，展开会爆炸。
2. 浪费：每层只需要「原子 → 个数」的表，不需要内容本身。
3. 洞察：遇到 `(` 开一张新表；原子累加到当前表；遇到 `)` 弹出这张表，乘倍数后并入上一张表。
4. 最后对栈底这张表按名字排序拼接。每个 `)` 合并一层要遍历该层的种类数，总计 `O(n · k)`，`k` 是原子种类数。

**同模式的题**：LC 394 字符串解码、LC 224 基本计算器、LC 772 基本计算器 III、LC 439 三元表达式解析器。
