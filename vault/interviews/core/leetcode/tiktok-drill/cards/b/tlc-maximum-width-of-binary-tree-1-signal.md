## Q
**LC 662 二叉树最大宽度**｜Medium · LC TikTok 全时段热度 38/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 54 次 · 最近 2026-09-01（国内面试记录）

给二叉树的根节点 `root`，返回树的**最大宽度**：每层宽度是该层最左与最右非空节点之间的长度，两端点之间的 `null` 节点也计入（把树视作同结构的满二叉树）；最大宽度是各层宽度的最大值，答案在 32 位带符号整数范围内。节点数在 `[1, 3000]`，`-100 <= Node.val <= 100`。例：`root = [1,3,2,5,null,null,9,6,null,7]` → `7`（第 4 层的 `6` 与 `7` 之间隔着 5 个空位）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每一**层**的宽度」→ **层序遍历（BFS）**，每层处理完再进下一层。
- 「中间的 `null` 也计入」→ 光数节点个数不对，要知道每个节点在满二叉树里的**位置编号**；满二叉树的编号有公式：根 `0`，左孩子 `2i`，右孩子 `2i + 1`（和堆的下标一致）。
- 节点数 `<= 3000` 但深度可能达到 3000 → 不能真把树补成满二叉树（`2^3000` 个位置）；宽度只取决于每层的**首尾**两个节点。
- 「答案保证在 32 位内」→ 编号会逐层翻倍，其他语言会溢出，需要归零。

**推导链。**
1. 暴力：补成满二叉树，逐层扫描首尾非空位置。空间 `O(2^深度)`，链状树不可行。
2. 浪费：空位占了几乎全部空间，宽度只需要每层最左、最右两个非空节点的位置。
3. 位置用编号表示：父编号 `idx` → 孩子 `2 * idx`、`2 * idx + 1`；BFS 时队列里带着编号。
4. 每层宽度 = 最右编号 - 最左编号 + 1；每层处理前把编号减去本层最左编号，编号不再随深度爆炸。
5. 每个节点入队一次，`O(n)`。
