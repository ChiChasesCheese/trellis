## Q
**LC 1171 从链表中删去总和值为零的连续节点**｜Medium · LC 字节 全时段热度 59/100 · CodeTop 国内累计 4 次 · 最近 2024-09-10（国内 CodeTop）

给链表头节点 `head`，反复删去链表中总和为 `0` 的连续节点序列，直到没有这样的序列，返回最终链表的头节点；答案不唯一，返回任意合法结果即可。

约束：链表有 `1` 到 `1000` 个节点，`-1000 <= node.val <= 1000`。例：`[1,2,-3,3,1]` → `[3,1]`（`[1,2,1]` 也对）；`[1,2,3,-3,4]` → `[1,2,4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续一段和为 `0`」→ 两个位置的前缀和相等（prefix sum + 哈希表）。
- 「删除链表里的一段」→ 改前驱的 `next`；头节点可能被删，所以要哨兵（dummy）。
- 「反复删，直到没有」→ 听上去要循环，但对每个前缀和取**最后**出现的节点，一次跳到最远，嵌套与相邻的零和段一并处理。
- 节点数 `1000` → `O(n^2)` 能过，目标是 `O(n)`。

**推导链。**
1. 暴力：每轮枚举所有连续段找和为 `0` 的，删掉后重来，`O(n^3)`。
2. 浪费：每轮都重新计算段和；被删段和为 `0`，不改变保留节点的前缀和。
3. 洞察：前缀和相同的两个节点之间（左开右闭）和为 `0`；同一前缀和取最后出现的节点，删得最彻底。
4. 最优：第一遍建「前缀和 → 最后节点」表；第二遍每个节点的 `next` 指向同前缀和最后节点的 `next`，两遍 `O(n)`。
