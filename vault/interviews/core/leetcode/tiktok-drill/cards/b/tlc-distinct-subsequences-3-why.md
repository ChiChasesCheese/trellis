## Q
**LC 115 不同的子序列**｜正确性

转移 `f[i][j] = f[i-1][j] + (s[i-1] == t[j-1]) * f[i-1][j-1]` 为什么不会重复计数也不会漏？压成一维以后，`j` 为什么必须倒序？给出正序出错的输入。

## A
**不变量。** `f[i][j]` 是 `s[:i]` 中等于 `t[:j]` 的子序列的下标选法总数。

**转移为什么对。** 看 `s[i - 1]` 有没有被用上，两类选法互斥且完备：
- **没有用** `s[i - 1]`：这些选法就是 `s[:i - 1]` 中等于 `t[:j]` 的选法，共 `f[i-1][j]`；
- **用了** `s[i - 1]`：它必须配 `t` 的最后一个字符 `t[j - 1]`，所以要求 `s[i - 1] == t[j - 1]`；前面 `j - 1` 个字符由 `s[:i - 1]` 配出，共 `f[i-1][j-1]`。
按「是否用最后一个字符」分类，同一种下标选法只会落在一类，不会重复也不会漏。

**一维为什么倒序。** 一维 `dp[j]` 在处理字符 `ch` 之前存的是 `f[i-1][j]`，处理之后应是 `f[i][j]`；更新用到 `f[i-1][j-1]`，即**未被 `ch` 更新过**的 `dp[j-1]`。倒序（`j` 从大到小）时，更新 `dp[j]` 时 `dp[j - 1]` 还没轮到，保持旧值。

**反例：正序遍历。**
- `s = "a"`，`t = "aa"`：只有一个 `a`，不可能凑出两个，正确答案 `0`。正序时：`j = 1` 更新 `dp[1] = 1`；`j = 2` 用刚更新的 `dp[1] = 1` 得到 `dp[2] = 1`，同一个字符被用了两次，输出 `1`。
- `s = "aaa"`，`t = "aa"`：正确是 `C(3, 2) = 3`，正序版本输出 `6`。

**初值。** `dp[0] = 1`：空串是任何前缀的子序列，恰有一种选法（什么都不选），它是所有计数的起点。
