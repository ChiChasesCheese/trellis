## Q
**LC 1186 删除一次得到子数组最大和**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-10-08（国内 CodeTop）

给整数数组 `arr`，返回它的某个**非空**子数组（连续元素）在执行**至多一次**删除（可选）后能得到的最大元素和：可以从原数组选出一个子数组，并决定是否从中删掉一个元素；删除后子数组仍必须至少有一个元素。

约束：`1 <= arr.length <= 10^5`，`-10^4 <= arr[i] <= 10^4`。

例：`arr = [1,-2,0,3]` → `4`（选整个数组，删掉 `-2`，得 `[1,0,3]`）；`arr = [1,-2,-2,3]` → `3`（直接取 `[3]`）；`arr = [-1,-1,-1,-1]` → `-1`（删除后不能为空，所以不能靠删除得到 `0`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子数组最大和」→ **Kadane**：以 `i` 结尾的最优只依赖以 `i-1` 结尾的最优，`max(prev, 0) + x`。
- 「至多一次删除 / 一次可选操作」→ 给 DP 加一个维度表示**操作用没用过**（状态机），每个位置存两个值。
- `n = 10^5`、元素含负数 → 要 `O(n)`；删除后必须非空 → 全负数组的答案是最大的那个负数，不是 `0`。

**推导链。**
1. 暴力：枚举子数组，再枚举删哪个元素，`O(n^3)`；用前缀和压成 `O(n^2)`。
2. 浪费：相邻右端点的最优子数组大量共享前缀，没必要重新枚举。
3. 洞察：定义两个状态——`keep`（以 `i` 结尾、没删）和 `skip`（以 `i` 结尾、至多删一个）；`skip` 的来源是「接上 `x`」「删掉 `x`（取上一格的 `keep`）」「重新开始」。
4. 最优：一遍扫描同时更新两个状态，答案取全程最大，`O(n)` 时间 `O(1)` 空间。

**同模式的题**：LC 53 最大子数组和、LC 918 环形子数组的最大和、LC 121 / 122 / 123 / 188 买卖股票系列、LC 1749 任意子数组和的绝对值的最大值。
