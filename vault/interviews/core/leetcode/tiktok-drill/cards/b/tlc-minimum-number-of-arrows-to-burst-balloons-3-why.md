## Q
**LC 452 用最少数量的箭引爆气球**｜正确性

为什么「按右端点排序，新箭射在当前气球的右端点」是最优的？条件里的 `start > last` 写成 `start >= last` 会错在哪？按左端点排序又会怎样？

## A
**不变量。** 扫描到任一位置时，已经射出的箭数是「引爆已处理气球所需的最少箭数」，且 `last` 是在这个最少箭数下，最后一支箭所能到达的最右位置。

**为什么射在右端点是最优（交换论证）。** 排序后，当前未被射爆的第一个气球 `b` 的右端点是剩余气球里最小的。必须有一支箭射中 `b`，设它射在 `x`（`b.start <= x <= b.end`）。其余任何气球若包含 `x`，它的右端点不小于 `b.end`，所以也包含 `b.end`。把箭移到 `b.end`，射爆的气球集合不会变小，因此射在 `b.end` 不会比其他位置差。

**反例 1：`start >= last`。** 区间是闭的，端点相接的气球共用一支箭。`points = [[1,2],[2,3],[3,4],[4,5]]`：
- `>=` 版本按右端点排序后：`[1,2]` 射一支，`last = 2`；`[2,3]` 的 `start = 2 >= 2`，被当作够不着，又射一支，`last = 3`；`[3,4]`、`[4,5]` 同理，共射 `4` 支；
- 正确：箭射在 `2`（射爆 `[1,2]`、`[2,3]`）和 `4`（射爆 `[3,4]`、`[4,5]`），共 `2` 支。

**反例 2：按左端点排序、边界不收缩。** `points = [[1,10],[2,3],[4,5]]`：
- 按左端点排序后，第一个气球 `[1,10]`，边界取 `10`；`[2,3]`、`[4,5]` 的左端点都不超过 `10`，被误认为都能被同一支箭射到，输出 `1`；
- 实际上 `[2,3]` 与 `[4,5]` 不相交，无法被一支箭同时射中，正确答案 `2`。按左端点排序时必须在每个被合并的气球处把边界收缩成 `min(边界, end)`；按右端点排序天然避免这个问题。
