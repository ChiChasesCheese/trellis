## Q
**LC 1062 最长重复子串**｜正确性

为什么可以对长度二分？为什么中点要用 `(lo + hi + 1) // 2`（上取整）？两次出现允许重叠这一点如果漏掉，会得到什么错误输出？

## A
**单调性。** 设 `P(L)` 表示「存在长度 `L` 的重复子串」。若 `P(L)` 成立，取其中一个重复子串去掉最后一个字符，得到长度 `L - 1` 的子串，它仍然出现在原来的两处，所以 `P(L - 1)` 成立。`P` 对 `L` 先真后假，二分找到最大的真值。`L = 0` 恒为真（空串），所以下界 `0` 合法。

**不变量。** 每次循环，答案始终落在 `[lo, hi]` 内：`lo` 是已知可行的长度，`hi` 是可能可行的最大长度。

**为什么上取整。** 更新规则是 `lo = mid`（可行时保留 `mid`）和 `hi = mid - 1`。若中点下取整：`lo = 2`、`hi = 3` 时 `mid = 2`，长度 `2` 可行则 `lo = 2` 不变，区间不再收缩，死循环。上取整时 `mid = 3`，要么 `lo = 3`，要么 `hi = 2`，区间必然缩小。

**反例：误以为两次出现不能重叠。** `s = "aaaa"`：
- 长度 `3` 的子串 `"aaa"` 出现在下标 `0` 和下标 `1`，两次出现重叠（共用中间两个 `a`），按题意它是重复子串，答案是 `3`；
- 如果判定里要求两个出现的起点相差至少 `L`，长度 `3` 被拒绝，`"aa"` 出现在下标 `0` 和 `2`（不重叠）通过，最终得到 `2`，比正确答案少 `1`。

**边界。** `s` 长度为 `1` 时 `hi = 0`，循环不执行，返回 `0`；没有任何长度 `1` 的字符重复（如 `"abcd"`）时，`has_repeat(1)` 为假，一路收缩到 `0`。
