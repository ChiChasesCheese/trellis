## Q
**LC 3474 字典序最小的生成字符串**｜Hard · TikTok 高频

字符串 `str1`（长度 `n`，只含 `'T'`、`'F'`）和 `str2`（长度 `m`，小写字母）。长度 `n + m - 1` 的 `word` 满足：`str1[i] == 'T'` 时 `word[i..i+m-1] == str2`，`str1[i] == 'F'` 时 `word[i..i+m-1] != str2`。返回字典序最小的合法 `word`，不存在返回 `""`。

约束：`1 <= n <= 10^4`，`1 <= m <= 500`，`str1` 仅由 `'T'`、`'F'` 组成，`str2` 仅由小写字母组成。例：`("TFTF", "ab")` → `"ababa"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- `'T'`：窗口必须等于 `str2` → 等式约束，可以**直接铺**，重叠处冲突则无解。
- `'F'`：窗口不能等于 `str2` → 不等式约束，只要有一位不同就满足，通常是「默认满足，偶尔需要修补一位」。
- 「字典序最小」→ 贪心：自由位全部取 `'a'`；必须改时，改得越靠右、改得越小越好（`'a'` 改成 `'b'`）。
- `n·m <= 5 * 10^6` → 每个窗口直接做 `O(m)` 切片比较即可。

**推导链。**
1. 暴力：`26^(n+m-1)` 个候选，或逐位回溯并检查已写完的窗口，最坏指数级。
2. 浪费：`'T'` 已经钉死一部分位置，其余位置在没有约束时都应取 `'a'`，根本不需要搜索。
3. 洞察：`'F'` 窗口只有恰好等于 `str2` 时才需要处理，处理方式是改动窗口内最靠右的自由位为 `'b'`。
4. 最优：铺 `'T'` → 填 `'a'` → 扫 `'F'` 逐个修补，`O(n·m)`；窗口里没有自由位可改就无解。

**同模式的题**：LC 767 重构字符串、LC 316 去除重复字母、LC 936 戳印序列、LC 1202 交换字符串中的元素。
