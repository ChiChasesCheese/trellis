## Q
**LC 11 盛最多水的容器**｜Medium · TikTok·字节 高频

长度为 `n` 的整数数组 `height`，第 `i` 条垂线的端点是 `(i, 0)` 和 `(i, height[i])`。选两条线，使它们与 `x` 轴围成的容器盛水最多，返回最大水量；容器不能倾斜。

约束：`2 <= n <= 10^5`，`0 <= height[i] <= 10^4`。例：`[1,8,6,2,5,4,8,3,7]` → `49`；`[1,1]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「选两个下标使 `min(h[i], h[j]) * (j - i)` 最大」→ 面积 = 短板 × 宽度，两个因素互相牵制。
- 宽度随指针靠拢单调变小 → 从最宽开始，每次丢弃一个不可能更优的端点：双指针（two pointers）收缩。
- `n = 10^5` → 需要 `O(n)`，`O(n^2)` 的暴力超时。
- 「水位取短板」→ 移动哪一侧有明确的理由：只有换掉短板，水位才可能上升。

**推导链。**
1. 暴力：枚举所有两条线，`O(n^2)`。
2. 浪费：固定短板 `h[l]` 后，和更近的线配对，水位不超过 `h[l]`，宽度更小，面积更小，这些组合完全没必要看。
3. 洞察：当前一对 `(l, r)` 中，短板那一侧的线已经没有更优的搭档，可以淘汰。
4. 最优：每次淘汰短板一侧，`left < right` 时循环，每步更新最大面积，`O(n)`。

**同模式的题**：LC 42 接雨水、LC 167 两数之和 II、LC 15 三数之和、LC 16 最接近的三数之和。
