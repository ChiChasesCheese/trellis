## Q
**LC 91 解码方法**｜Medium · 字节高频

消息由字母 `A`-`Z` 编码成数字：`"1"` → `A`，…，`"26"` → `Z`。给只含数字的非空字符串 `s`（可能有前导零），求解码方法的总数，没有合法解码返回 `0`。`1 <= s.length <= 100`，答案保证在 32 位整数内。例：`"226"` → `3`；`"06"` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「求有多少种解码 / 拆分方式」→ **线性计数 DP**，状态是前缀长度。
- 每一段只能是 1 位或 2 位，所以 `f[i]` 只依赖 `f[i-1]` 和 `f[i-2]`——和爬楼梯同构，只是每步多了合法性判断。
- 合法性规则：单独成码要求不是 `'0'`；两位成码要求在 `10`~`26`（含前导零的 `"06"` 不合法）。
- `n <= 100`，答案保证在 32 位内：回溯会指数爆炸，DP 轻松过。

**推导链。**
1. 暴力：回溯，每个位置试 1 位和 2 位，不合法就返回 `0`。方案数是斐波那契级，大量重复子问题。
2. 浪费：解码 `s[i:]` 的方案数只与 `i` 有关，却被不同前缀重复计算。
3. 洞察：`f[i] = (s[i-1] != '0' ? f[i-1] : 0) + (10 <= int(s[i-2:i]) <= 26 ? f[i-2] : 0)`，`f[0] = 1`。
4. 只用前两项，两个变量滚动，`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 70 爬楼梯、LC 639 解码方法 II、LC 746 使用最小花费爬楼梯、LC 198 打家劫舍。
