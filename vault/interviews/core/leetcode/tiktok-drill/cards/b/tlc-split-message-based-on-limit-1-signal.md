## Q
**LC 2468 根据限制分割消息**｜Hard · LC TikTok 热度 50/100

给字符串 `message`（只含小写字母和空格，`1 <= 长度 <= 10^4`）和正整数 `limit`（`1 <= limit <= 10^4`）。把 `message` 分割成若干段，每段结尾是 `"<a/b>"`（`a` 为编号从 `1` 起，`b` 为总段数）；除最后一段长度可以小于等于 `limit` 外，其余每段长度都必须等于 `limit`；去掉结尾后按顺序拼接得到 `message`；段数要尽量少，无法分割返回空数组。例：`("short message", 15)` → `["short mess<1/2>","age<2/2>"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「段数尽量少」+「后缀里含总段数 `b`」→ 先确定总段数，再构造；`b` 变大，后缀变长，每段装的字符变少。
- 后缀长度只随数字位数变化（`1..9` 一位，`10..99` 两位…）→ 容量可以按位数分组用算术算出，不必真的切。
- `n <= 10^4` → 每段至少装 `1` 个字符，所以 `b <= n`，枚举 `b` 只有 `10^4` 种。
- 「无法分割返回空数组」→ 要明确的无解判据：连最后一段（编号位数最多）都装不下一个字符。

**推导链。**
1. 暴力：对每个 `b` 实际构造并验证，每个 `O(n)`，总 `O(n^2)`。
2. 浪费：判断某个 `b` 是否可行只需要总容量。
3. 容量：第 `a` 段可装 `limit - 3 - len(a) - len(b)` 个字符，求和得 `b · (limit - 3 - len(b)) - Σ len(a)`。
4. `Σ len(a)` 每增加一个 `b` 只多一项，`O(1)` 更新；第一个容量 `>= n` 的 `b` 就是最短的总段数。
5. 确定 `b` 后后缀长度固定，按 `limit - len(后缀)` 逐段切，最后一段取剩余。

**同模式的题**：LC 68 文本左右对齐、LC 6 Z 字形变换、LC 1055 形成字符串的最短路径、LC 2109 向字符串添加空格。
