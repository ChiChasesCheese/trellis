## Q
**LC 3161 物块放置查询**｜追问

面试官接着问：（1）坐标上限变成 `10^9`，线段树开不下，怎么办？（2）还要支持**删除障碍物**？（3）能不能离线处理，把线段树换成更简单的结构？（4）没有 `SortedList` 或 `TreeSet` 时，前驱 / 后继怎么找？

## A
1. **坐标很大**：这是离线题（所有操作已知），先收集所有出现过的 `x`，排序去重后离散化为 `0..m-1`，线段树建在压缩后的下标上。有序列表里仍存真实坐标，线段树的值仍是真实距离，只是下标用压缩后的位置。
2. **支持删除**：删除障碍物 `x` 时，把它的后继的空隙改回 `succ - pred`（变大），再把线段树里 `x` 的位置清 `0`。线段树本身支持任意单点覆盖，所以不需要改结构；有序列表删除用 `obstacles.pop(index)`。
3. **离线倒序**：先把所有障碍物都放上，倒着回放操作，「建」变成「删」，空隙只会变大。变大的更新只需「取大」，所以线段树可以换成树状数组做前缀最大值；前驱用并查集（每个删除的位置指向它左边一格）查找，不再需要有序列表。常数更小，代码也不长，但只能用于离线。
4. **没有有序集合**：Python 标准库没有。常用做法是 `bisect` 加普通列表：`insert` 是 `O(k)` 的内存搬移，`k <= 5 * 10^4` 时很快；离线时也可以像第 3 点那样用并查集代替前驱查找。

**Python 提醒**：`bisect_left(a, x)` 返回第一个 `>= x` 的位置，`bisect_right(a, x)` 返回第一个 `> x` 的位置；找「`<= x` 的最后一个元素」用 `a[bisect_right(a, x) - 1]`，列表头部放哨兵可以保证下标不会变成 `-1`。
