## Q
**LC 1209 删除字符串中的所有相邻重复项 II**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 3 次 · 最近 2024-09-13（CodeTop）

给字符串 `s`，每次可以选 `k` 个相邻且相等的字母删除，两侧连起来，重复直到无法继续，返回最终字符串（答案唯一）。`1 <= s.length <= 10^5`，`2 <= k <= 10^4`，`s` 只含小写英文字母。例：`("deeedbbcccbdaa", 3)` → `"aa"`（先删 `eee`、`ccc`，再删 `bbb`，最后删 `ddd`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「删除后左右两侧连在一起，可能产生新的重复」→ 栈（stack）：删除总是发生在最近处，后进先出，级联自然发生。
- 「`k` 个相邻相等」→ 栈里每项要带一个**连续计数**，达到 `k` 就整项弹出。
- `n = 10^5`，`k` 到 `10^4` → 排除“每次删完从头再找”的 `O(n^2)`；一遍扫描加栈 `O(n)`。
- 「答案保证唯一」→ 删除顺序不影响结果，可以边扫边删。

**推导链。**
1. 暴力：反复在字符串里找连续 `k` 个相同字符，删掉，再从头找，每次删除要复制字符串。
2. 浪费：删除只影响删除点附近，却每次从头找。
3. 洞察：栈顶是已处理前缀最右边的一段连续相同字符及其长度；新字符要么延长它，要么另起一段。
4. 一段长度达到 `k` 就整段消失，露出下面的一段，下一个字符可能与它接上，级联删除不需要任何额外代码。
5. 最后把每项 `(字符, 次数)` 还原成 `字符 * 次数`。

**同模式的题**：LC 1047 删除字符串中的所有相邻重复项、LC 2390 从字符串中移除星号、LC 735 小行星碰撞、LC 71 简化路径。
