## Q
**LC 1062 最长重复子串**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-08-05（CodeTop）

给字符串 `s`，找出并返回**最长重复子串**的长度：在 `s` 中出现至少两次的连续子串（两次出现可以重叠），不存在则返回 `0`。`1 <= s.length <= 2000`，`s` 只含小写英文字母。例：`s = "abbaba"` → `2`；`s = "aabcaabdaab"` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最长**」+「出现至少两次」→ 答案长度有**单调性**：长度 `L` 的重复子串去掉最后一个字符，长度 `L - 1` 的仍然重复 → **二分答案**。
- 判定「长度 `L` 的子串有没有重复」→ 把所有窗口放进**集合**，遇到已有的就是重复。
- `n = 2000` → `O(n^2)` 或 `O(n^2 log n)` 都可行；不需要滚动哈希（LC 1044 才需要，`n = 3 * 10^4`）。
- 另一条路：最长公共后缀的 **DP**（`dp[i][j]`，`i < j`），`O(n^2)`。

**推导链。**
1. 暴力：长度从大到小、起点逐个、集合查重，`O(n^3)`。
2. 浪费：逐个长度试。单调性 → 对 `L` 二分，只需 `log n` 个长度。
3. 每个长度 `L` 扫描所有窗口 `s[i:i+L]`，放进集合，已存在就返回真，`O(n · L)`。
4. 总计 `O(n^2 log n)`；中点要上取整，避免 `lo = mid` 时死循环。

**同模式的题**：LC 1044 最长重复子串、LC 718 最长重复子数组、LC 1143 最长公共子序列、LC 187 重复的DNA序列。
