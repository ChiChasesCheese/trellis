## Q
**LC 123 买卖股票的最佳时机 III**｜正确性

四个变量各自代表什么，为什么每天的更新顺序不影响结果？为什么买入的初值是 `-prices[0]` 而不是 `0`？为什么"先取最佳一笔，再取剩余区间的最佳一笔"的贪心是错的？给出具体输入。

## A
**不变量。** 处理完前 `i` 天后：
- `buy1` = 完成 `0` 笔、当前持有股票时的最大现金 = `-min(prices[:i])`。
- `sell1` = 至多完成 `1` 笔、当前不持有时的最大现金（单笔最大利润）。
- `buy2` = 已完成至多 `1` 笔、再次买入后持有时的最大现金。
- `sell2` = 至多完成 `2` 笔、不持有时的最大现金，也是答案。
每一个都是"到目前为止所有合法操作序列里手里现金的最大值"，每天最多多做一次买或卖，所以由前一天的值转移。

**更新顺序。** 同一天先更新 `sell1` 再更新 `buy2`，相当于允许今天卖出后立刻买入，这笔操作不会赚钱（同一天买卖利润为 `0`），所以结果与使用前一天旧值的写法完全一致。

**初值。** `buy` 状态表示"已经花钱买了股票"，现金为 `-价格`；写成 `0` 等于凭空持有股票而没有成本。

**反例 1：买入初值为 `0`。** `[7,6,4,3,1]`：每天 `buy1 = max(0, -p) = 0`，于是 `sell1 = max(sell1, 0 + p)` 取到最高价 `7`，输出 `7`；正确是 `0`（价格一路下跌，不应交易）。

**反例 2：贪心。** `[1,5,2,10]`：
- 最佳的单笔是 `1 → 10`，利润 `9`，它的左右两侧没有剩余区间可再交易，贪心答案 `9`。
- 最优是拆成两笔：`1 → 5`（`4`）加 `2 → 10`（`8`），共 `12`。
- 把一笔大的拆成两笔小的，总和可能更大，局部最优不是全局最优。
