## Q
**LC 263 丑数**｜正确性

为什么「把 2、3、5 除干净后剩 1」等价于「是丑数」？为什么 `n <= 0` 必须单独处理？

## A
**等价性。** 由算术基本定理，正整数 `n` 唯一分解为 `2^a · 3^b · 5^c · r`，`r` 不含 2、3、5 这三个因子。循环把 `2^a`、`3^b`、`5^c` 全部除掉，剩下的正是 `r`。`r == 1` 说明没有别的质因数，即丑数；`r > 1` 说明 `r` 含有 7 或更大的质因数。

**不变量。** 每次 `n //= p` 只在 `p` 整除 `n` 时执行，所以除法是精确的，`n` 始终是原数去掉若干个 2、3、5 后的结果，不会引入或丢失其他因子。

**为什么单独处理 `n <= 0`。** 丑数按定义是正整数，`0` 和负数都不是。更要紧的是 `0`：`0 % 2 == 0` 永远成立，`0 // 2` 还是 `0`，没有守卫时 `is_ugly(0)` 会死循环。负数如 `-6` 除完剩 `-1`，结果碰巧是 `False`，但靠的是巧合，应由守卫明确返回。
