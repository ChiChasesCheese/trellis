## Q
**LC 862 和至少为 K 的最短子数组**｜Hard · CodeTop 国内累计 15 次 · 最近 2026-09-03（CodeTop）

给整数数组 `nums` 和整数 `k`，找出 `nums` 中**和至少为 `k` 的最短非空子数组**（连续的一段），返回它的长度；不存在则返回 `-1`。`1 <= nums.length <= 10^5`，`-10^5 <= nums[i] <= 10^5`，`1 <= k <= 10^9`。例：`nums = [2,-1,2], k = 3` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最短**子数组 + 和**至少** `k`」像滑动窗口（LC 209），但 `nums` 有**负数**：扩大窗口和可能变小，双指针的单调性不成立，直接用窗口会漏解。
- 带负数的区间和 → 转成**前缀和**：要找 `j - i` 最小且 `pre[j] - pre[i] >= k`。
- 对每个 `j`，要在更早的起点里快速找「前缀和足够小的最近起点」，候选集会随 `j` 前进而淘汰劣者 → **单调双端队列**（与 LC 239 滑动窗口最大值同一套结构）。
- `n = 10^5` → 需要 `O(n)` 或 `O(n log n)`。

**推导链。**
1. 暴力：枚举 `(i, j)` 并求和，`O(n^3)`；用前缀和 `O(1)` 求区间和，仍是 `O(n^2)`。
2. 浪费 1：起点 `i` 一旦和某个 `j` 配对成功，更大的 `j` 只会更长，这个 `i` 可以永久丢弃（队首弹出）。
3. 浪费 2：若 `i1 < i2` 且 `pre[i1] >= pre[i2]`，`i2` 更晚且前缀和更小，对所有后续 `j` 都不差，`i1` 永远不是最优（队尾弹出）。
4. 最优：队列里前缀和严格递增，队首最容易满足条件；每个下标入队出队各一次，`O(n)`。

**同模式的题**：LC 209 长度最小的子数组、LC 239 滑动窗口最大值、LC 1438 绝对差不超过限制的最长连续子数组、LC 1425 带限制的子序列和。
