## Q
**LC 17 电话号码的字母组合**｜Medium · 字节 高频

给一个只含数字 `2-9` 的字符串 `digits`，返回它能表示的所有字母组合（任意顺序）。映射和电话按键相同：`2` 对应 `abc`，`3` 对应 `def`，`4` 对应 `ghi`，`5` 对应 `jkl`，`6` 对应 `mno`，`7` 对应 `pqrs`，`8` 对应 `tuv`，`9` 对应 `wxyz`。`1 <= digits.length <= 4`。例：`digits = "23"` → `["ad","ae","af","bd","be","bf","cd","ce","cf"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**组合」+「每一位从固定候选集里选一个」→ **回溯**（等价于多个集合的笛卡尔积）。
- `digits.length <= 4` → 最多 `4^4 = 256` 个结果，指数级输出无法避免；复杂度由答案大小决定，没有剪枝空间。
- 层数（数字个数）不固定 → 写不出固定层数的嵌套循环，只能用递归或逐位迭代。
- 近似信号：LC 22 括号生成（有合法性约束，要剪枝）、LC 78 子集（选或不选）。

**推导链。**
1. 暴力：`n` 层嵌套循环，第 `t` 层枚举第 `t` 个数字的字母。`n` 不固定，无法直接写。
2. 浪费：如果每层都复制一份当前字符串，会有大量无用拷贝。
3. 洞察：递归深度 = 位数；用一个共享的 `path` 列表，选一个字母就 `append`，递归返回后 `pop` 撤销（回溯）。
4. 叶子处才 `"".join(path)` 一次，总时间 `O(n · 4^n)`，额外空间只有递归栈 `O(n)`。

**同模式的题**：LC 22 括号生成、LC 78 子集、LC 46 全排列、LC 39 组合总和。
