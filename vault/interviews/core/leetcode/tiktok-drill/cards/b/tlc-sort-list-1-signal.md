## Q
**LC 148 排序链表**｜Medium · LC TikTok 全时段热度 38/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 70 次 · 最近 2026-09-27（国内 CodeTop）

给链表的头结点 `head`，将其按升序排列并返回排序后的链表。链表中节点的数目在 `[0, 5 * 10^4]` 内，`-10^5 <= Node.val <= 10^5`。例：`head = [4,2,1,3]` → `[1,2,3,4]`；`head = [-1,5,3,4,0]` → `[-1,0,3,4,5]`。进阶：`O(n log n)` 时间、常数级空间。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「链表」+「排序」→ **归并排序**：链表没有随机访问，快排、堆排不便；合并两个有序链表只改指针，`O(1)` 空间。
- 「`O(n log n)`」→ 分治：每层把链表对半分，深度 `log n`，每层 `O(n)`。
- 「常数级空间」（进阶）→ 递归栈也要省掉 → **自底向上**归并，用循环代替递归。
- `n <= 5 * 10^4`：`O(n^2)` 约 `2.5 * 10^9`，超时；递归深度仅 `log n ≈ 16`，不会爆栈。

**推导链。**
1. 暴力一：取值、`sorted`、写回：`O(n log n)` 时间但 `O(n)` 额外空间，也没有真正重排节点。
2. 暴力二：插入排序或冒泡排序：`O(n^2)`，超时。
3. 洞察：归并排序需要的两个操作，链表上都很便宜：快慢指针找中点 `O(n)`；合并两段有序链表 `O(n)`、`O(1)` 空间。
4. 最优：找中点、断开、递归排序两半、合并。时间 `O(n log n)`，递归栈 `O(log n)`；改成自底向上，段长 `1, 2, 4, …` 两两合并，空间降到 `O(1)`。
