## Q
**LC 647 回文子串**｜Medium · CodeTop 国内累计 8 次 · 最近 2026-03-03（国内 CodeTop）

给字符串 `s`，统计其中**回文子串**的个数（子串连续；位置不同的相同子串分别计数）。`1 <= s.length <= 1000`，`s` 只含小写英文字母。例：`"aaa"` → `6`（三个 `"a"`、两个 `"aa"`、一个 `"aaa"`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「回文」→ 中心对称：`s[l..r]` 是回文当且仅当两端相等且 `s[l+1..r-1]` 是回文，于是有**中心扩展**和**区间 DP** 两条路。
- 「子串、计数」→ 要把所有回文子串数一遍，答案最多 `n(n+1)/2`，`O(n^2)` 是自然的目标。
- `n <= 1000` → `O(n^2) = 10^6` 可以，`O(n^3) = 10^9` 不行。

**推导链。**
1. 暴力：枚举 `O(n^2)` 个子串，每个反转比较 `O(n)`，共 `O(n^3)`。
2. 浪费：判断 `s[l..r]` 时，`s[l+1..r-1]` 的比较已经做过了。
3. 洞察：同一中心的回文一层套一层，从中心向外扩，每步只比新的两端；一旦不等，以它为中心的更长子串都不是回文。
4. 最优：枚举 `2n - 1` 个中心（字符和间隙），每次成功外扩计数加一，`O(n^2)` 时间、`O(1)` 空间。

**同模式的题**：LC 5 最长回文子串、LC 131 分割回文串、LC 516 最长回文子序列。
