## Q
**LC 739 每日温度**｜Medium · LC TikTok 热度 63/100 · CodeTop 国内累计 26 次 · 最近 2025-09-19（CodeTop）

给整数数组 `temperatures`，`answer[i]` 是第 `i` 天之后要等多少天才会遇到更高的温度，没有则为 `0`。`1 <= temperatures.length <= 10^5`，`30 <= temperatures[i] <= 100`。例：`[73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每个元素右边**第一个更大**的元素」→ **单调栈**（next greater element）的标准题型。
- 要的是「几天后」→ 距离，所以栈里存**下标**，温度用下标去数组里取。
- `n = 10^5` → 需要 `O(n)` 或 `O(n log n)`；`O(n^2)` 的逐个向右扫不行。
- 「更高」是严格的 → 弹栈条件是 `<`，相等的温度不算。
- 温度只有 `30..100` → 额外的小范围特征，可以走「每个温度最近下标」的另一条路。

**推导链。**
1. 暴力：对每个 `i` 向右扫到第一个更高的，递减序列时 `O(n^2)`。
2. 浪费：很多位置都在等「同一个更高的数」，各自重复扫同一段。
3. 洞察：从左到右扫，新来的温度会一次性解决栈里所有比它低的下标；没被解决的下标温度一定不增（否则早被解决了）→ 维护一个单调（不增）栈。
4. 最优：弹出的下标 `j` 记 `answer[j] = i - j`，每个下标进出各一次，`O(n)`。
