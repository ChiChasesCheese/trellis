## Q
**LC 402 移掉 K 位数字**｜写出 Python 实现

数字字符串 `num`（长度 `1..10^5`，除 `0` 本身外无前导零）和整数 `k`（`1..len(num)`）。移除 `k` 位数字，使剩下的数最小，以字符串返回，结果不含前导零，全部移除返回 `"0"`。要求 `O(n)`。

## A
**思路。** 用列表当栈。每个新数字入栈前，只要还有额度、栈非空、栈顶大于它，就弹栈并消耗额度。扫完后，若额度还有剩，栈必然是非递减的，从末尾砍掉剩余的额度。最后去掉前导零，空串变成 `"0"`。

```python
def remove_kdigits(num: str, k: int) -> str:
    stack: list[str] = []
    for d in num:
        while k and stack and stack[-1] > d:     # 前面的数字比当前大：删掉它，高位变小
            stack.pop()
            k -= 1
        stack.append(d)
    stack = stack[: len(stack) - k]              # 还没删够说明整体非递减，从末尾删；不能写 [:-k]，k=0 会清空
    return "".join(stack).lstrip("0") or "0"     # 去前导零；全删光时返回 "0"
```

**运行。** `("1432219", 3)` → `"1219"`；`("10200", 1)` → `"200"`；`("10", 2)` → `"0"`；`("112", 1)` → `"11"`；`("9", 1)` → `"0"`；`("12345", 2)` → `"123"`。

**复杂度。** 时间 `O(n)`：每个数字至多入栈、出栈各一次；空间 `O(n)`。

**写法要点。** 数字字符之间直接用 `>` 比较，与数值大小一致（`'0' < … < '9'`），不用转 `int`；`while k and stack and stack[-1] > d` 把"额度、栈非空、单调性"三个条件放进同一行；`stack[: len(stack) - k]` 避免 `[:-k]` 在 `k == 0` 时清空的陷阱；`lstrip("0") or "0"` 一句同时处理前导零和空串；`k` 既是参数又是计数器，直接递减即可。
