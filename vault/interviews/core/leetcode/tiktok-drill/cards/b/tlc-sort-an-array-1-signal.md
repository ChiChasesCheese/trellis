## Q
**LC 912 排序数组**｜Medium · LC TikTok 全时段热度 26/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 2 次 · 最近 2026-08-26（国内面试记录）

给整数数组 `nums`，升序排列并返回；**不使用任何内置函数**，时间 `O(n log n)`，空间尽可能小。`1 <= nums.length <= 5 * 10^4`，`-5 * 10^4 <= nums[i] <= 5 * 10^4`。例：`[5,1,1,2,0,0]` → `[0,0,1,1,2,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式**
- 「不使用内置函数」：要手写比较排序，考的是对排序算法的掌握。
- 「`O(n log n)`」：分治（归并 / 快排）或堆；`n = 5 * 10^4` 时 `O(n^2)` 约 `2.5 * 10^9` 次操作，必超时。
- 「空间尽可能小」：要原地；归并要 `O(n)` 额外空间，快排栈 `O(log n)`，堆排 `O(1)`。
- 值可以重复，且值域很小（`10^5 + 1` 种）：重复值会拖垮朴素快排；小值域让计数排序（counting sort）成为非比较排序的合法选项。

**推导链**
1. 选择 / 冒泡 / 插入排序：`O(n^2)`，被 `n` 排除。
2. 浪费：选择排序每轮重新扫描找最大值，没有保留信息；归并和快排把问题折半，堆保留「谁最大」。
3. 三个 `O(n log n)`：归并稳定但要 `O(n)` 空间；快排平均最快，最坏 `O(n^2)`；堆排最坏 `O(n log n)`、原地、不稳定。
4. 取堆排作为主答案，因为最坏有保证且空间 `O(1)`；快排要说明随机基准和三路划分。
