## Q
**LC 714 买卖股票的最佳时机含手续费**｜正确性

无手续费时，「把每天的上涨都吃掉」是对的。为什么有了手续费，`sum(max(0, b - a - fee) for a, b in pairwise(prices))` 就错了？状态 DP 守住的是什么？

## A
**不变量。** `dp[i][0]`（`dp[i][1]`）是「只看前 `i + 1` 天、第 `i` 天结束时不持股（持股）」的所有合法操作序列里的最大利润。任何操作序列在第 `i` 天结束时必然处于两种状态之一，而它到达该状态的最后一步只有两种（保持或买 / 卖），转移把两种都取了 `max`，所以不变量逐天成立。

**为什么逐天贪心错。** 那个式子把每一对相邻天的上涨都当成一笔独立交易，每笔各付一次 `fee`。连续上涨本该一笔做完、只付一次费，拆开后多付了手续费，还会因为单日涨幅不够 `fee` 而直接放弃。

**反例 `prices = [1,3,2,8,4,9], fee = 2`。**
- 逐天贪心：`3 - 1 - 2 = 0`，`8 - 2 - 2 = 4`，`9 - 4 - 2 = 3`，合计 `7`。
- 正确做法：`1` 买 `8` 卖（跨过中间的回落 `3 → 2`），`4` 买 `9` 卖：`5 + 3 = 8`。
- 状态 DP 允许「持股跨过回落」：第 2 天价格 `2` 时，`dp[2][1] = max(dp[1][1], dp[1][0] - 2) = max(-1, -2) = -1`，继续持有第 0 天买的那股，到第 3 天卖出得 `8 - 1 - 2 = 5`。
