## Q
**LC 122 买卖股票的最佳时机 II**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 48 次 · 最近 2026-05-12（CodeTop）

给整数数组 `prices`，`prices[i]` 是某股票第 `i` 天的价格。每天你可以决定买入和 / 或卖出，任何时候**最多持有一股**；可以在同一天先卖再买。返回能获得的最大利润。

约束：`1 <= prices.length <= 3 * 10^4`，`0 <= prices[i] <= 10^4`。

例：`prices = [7,1,5,3,6,4]` → `7`（第 2 天买、第 3 天卖赚 `4`；第 4 天买、第 5 天卖赚 `3`）；`prices = [1,2,3,4,5]` → `4`；`prices = [7,6,4,3,1]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「不限交易次数」「同一天可以多次买卖」「最多持有一股」→ 股票系列中**约束最少**的一档，贪心 / 差分就够。
- 「最大利润」+ 价格序列 → 先想状态机 DP（`cash` / `hold`），再看约束能否把状态化简。
- `n = 3·10^4` → `O(n)` 即可；数据范围提示不需要任何优化。

**推导链。**
1. 暴力：DFS 每天选买 / 卖 / 不动，指数级；记忆化后是 `O(n)` 状态的 DP。
2. DP：`cash`、`hold` 两个状态逐日更新，`O(n)` 时间 `O(1)` 空间。
3. 洞察：不限次数时，一段上涨 `a→b→c→d` 的利润 `d - a` 等于逐日差之和；下跌的差不会被选。
4. 最优：答案是所有正的相邻差之和，一行 `sum(max(b - a, 0) for a, b in pairwise(prices))`。

**同模式的题**：LC 121 买卖股票的最佳时机、LC 123 / 188 买卖股票的最佳时机 III / IV、LC 309 含冷冻期、LC 714 含手续费。
