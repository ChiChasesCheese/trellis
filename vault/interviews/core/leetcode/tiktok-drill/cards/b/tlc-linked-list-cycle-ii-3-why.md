## Q
**LC 142 环形链表 II**｜正确性

为什么相遇后「一个从表头、一个从相遇点，同速前进」会在入环点相遇？快慢指针一定会在环里相遇，而不会互相跳过吗？

## A
**不变量。** 设表头到入环点 `a` 步，入环点到相遇点 `b` 步，相遇点沿环回到入环点 `c` 步，环长 `L = b + c`。

**一定相遇。** 两个指针都进环后，快指针相对慢指针每步多走 1，二者之间的距离（沿环）每步减少 1，必然减到 0，不会跳过。

**为什么汇合在入环点。** 相遇时慢指针走了 `a + b`，快指针走了 `a + b + kL`（多绕 `k` 圈），且快的步数是慢的两倍：`2(a + b) = a + b + kL`，得 `a + b = kL`，即 `a = kL - b = (k - 1)L + c`。从相遇点前进 `c` 步到入环点，再绕 `k - 1` 圈仍在入环点；从表头前进 `a` 步恰好到入环点。所以两个指针各走 `a` 步在入环点汇合。

**反例。** 题面例 `[3,2,0,-4]`, `pos = 1`（尾部连回值 `2` 的结点）：`a = 1`，`b = 2`，`c = 1`，入环点值是 `2`，但快慢指针第一次相遇在值 `-4` 的结点。直接返回相遇点得 `-4`，正确是 `2`；用第二阶段，表头出发的指针走 `a = 1` 步到值 `2`，相遇点出发的走 `c = 1` 步（`-4` 的 `next` 就是值 `2`）也到值 `2`，汇合在 `2`。
