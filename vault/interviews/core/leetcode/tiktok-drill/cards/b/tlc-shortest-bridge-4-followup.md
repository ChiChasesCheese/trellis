## Q
**LC 934 最短的桥**｜追问

面试官接着问：（1）要输出具体翻哪些格子？（2）翻不同水格的代价不同怎么办？（3）有 `k` 座岛、要全部连通呢？

## A
1. **输出方案**：给每个入队的水格记前驱 `parent[(a, b)] = (x, y)`（用字典）。碰到岛 B 的那个邻居 `(a, b)` 时，从当前格 `(x, y)` 沿 `parent` 一路回溯到岛 A 的格子，途经的水格就是要翻的格子，共 `flips` 个。额外空间 `O(n^2)`，时间不变。
2. **代价不同**：边权不再相同，BFS 的「按层即最短」失效。水格代价是非负整数时用 Dijkstra（`heapq`），起点是岛 A 的所有格子、距离 `0`；代价只有 `0/1` 时用 0-1 BFS（双端队列 `deque`：代价 `0` 的边从队首插入，代价 `1` 的边从队尾插入），`O(n^2)`。
3. **`k` 座岛**：先给每座岛标号（DFS 洪水填充），再对每座岛做一次多源 BFS 得到它到其它每座岛的最短距离，得到一个带权完全图，求最小生成树（Kruskal / Prim）。如果允许借助其它水格作为公共枢纽，问题变成 Steiner 树，是 NP 难的，面试里一般不会要求。

**Python 提醒**：往 `set` 里放坐标要用元组 `(i, j)`（可哈希），不能放列表；遍历一个 `set` 的同时往里加元素会抛 `RuntimeError: Set changed size during iteration`，所以 BFS 里「当前层」和「下一层」要分成两个列表，而不是边遍历 `seen` 边加。`frontier = list(seen)` 是在第一座岛固定之后复制出来的快照。
