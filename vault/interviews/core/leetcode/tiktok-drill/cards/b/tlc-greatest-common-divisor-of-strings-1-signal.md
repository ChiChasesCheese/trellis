## Q
**LC 1071 字符串的最大公因子**｜Easy · TikTok 高频

字符串 `s` 和 `t`，只有 `s = t + t + … + t`（`t` 连接一次或多次）时才说 `t` 能除尽 `s`。给定 `str1`、`str2`（长度 `1..1000`，大写英文字母），返回最长的同时除尽两者的字符串 `x`，没有就返回 `""`。例：`("ABABAB", "ABAB")` → `"AB"`；`("LEET", "CODE")` → `""`；`("AAAAAB", "AAA")` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「能除尽」「最大公因子」→ 数论的类比：长度取最大公约数（`gcd`），内容由前缀决定。
- 「由某个串重复若干次得到」→ 周期性（periodicity）：两个串同属一个周期，等价于两种拼接顺序结果相同。
- 长度只有 `1000` → `O(n^2)` 的枚举也能通过，但题目考的是能不能识别出 `O(n)` 的拼接技巧。
- 返回“最长”→ 在所有候选长度里取最大；而所有可能长度都是 `gcd` 的约数，最大的就是 `gcd` 本身。

**推导链。**
1. 暴力：长度 `L` 从 `min(len1, len2)` 往下，只看同时整除两个长度的 `L`，取前缀重复校验。
2. 若公因子串 `x` 存在：`str1 = x^a`，`str2 = x^b`，所以 `str1 + str2 = str2 + str1 = x^(a+b)`。
3. 反过来，两种拼接顺序相同，说明二者是同一个原串的幂，公因子串存在。
4. 存在时，最长的公因子串长度就是 `gcd(len1, len2)`，取 `str1` 的前这么多个字符。
