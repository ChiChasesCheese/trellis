## Q
**LC 735 小行星碰撞**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 1 次 · 最近 2022-03-03（国内 CodeTop）

数组 `asteroids` 表示同一行上的小行星：绝对值是大小，正数向右、负数向左，速度相同。相撞时较小的爆炸，大小相同都爆炸，同向永不相撞。返回碰撞结束后剩下的小行星。`2 <= asteroids.length <= 10^4`，`-1000 <= asteroids[i] <= 1000`，`asteroids[i] != 0`。例：`[3,5,-6,2,-1,4]` → `[-6,2,4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「相邻元素相互作用、会相互消除、后来者先和最近的先来者作用」→ 栈（后进先出）。
- 方向由符号编码：只有「左边向右（正）、右边向左（负）」才相向而行；同向、背向都不会相撞 → 碰撞条件是 `stack[-1] > 0 and a < 0`。
- 一颗大行星能连续撞毁多颗 → 用 `while` 反复弹栈，不是 `if`。
- `n <= 10^4`：反复模拟 `O(n^2)` 勉强，栈的 `O(n)` 最稳。

**推导链。**
1. 暴力：反复找相邻的 `(正, 负)` 对并处理，直到没有，每轮 `O(n)`，最多 `O(n)` 轮。
2. 浪费：每次碰撞后都从头找，而碰撞只发生在刚变化的位置附近。
3. 洞察：从左到右处理，已处理部分形如「若干向左的、后跟若干向右的」，向左的再也不会被撞。新来的向左者只会碰栈顶最近的向右者，后进先出。
4. 每颗入栈一次、出栈至多一次，`O(n)`。
