## Q
**面试题 16.01 交换数字**｜Medium · CodeTop 国内累计 1 次 · 最近 2025-12-19（CodeTop）

编写一个函数，不使用临时变量，直接交换 `numbers = [a, b]` 中 `a` 与 `b` 的值并返回。`numbers.length == 2`，`-2147483647 <= numbers[i] <= 2147483647`。 例：`[1,2]` → `[2,1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「不用临时变量交换」→ 用**可逆运算**把两个值合进一个变量再剥离：**异或**（自逆）或**加减**（互逆）。
- 「值到 `±(2^31 - 1)`」→ 32 位语言里加法可能溢出，异或不会；面试官想听你主动提这一点。
- 位运算的三条性质：`x ^ x = 0`、`x ^ 0 = x`、满足交换律和结合律。

**推导链。**
1. 常规：`t = a; a = b; b = t`，用了临时变量，不符合要求。
2. 加减：`a = a + b`（合并）→ `b = a - b`（剥出原 `a`）→ `a = a - b`（剥出原 `b`）。有溢出顾虑。
3. 异或：`a ^= b` → `b ^= a`（得原 `a`）→ `a ^= b`（得原 `b`），不会溢出。
4. 补上边界：两个位置是同一个变量时异或会清零，要先判断。

**同模式的题**：LC 136（只出现一次的数字）、LC 268（丢失的数字）、LC 371（两整数之和）。
