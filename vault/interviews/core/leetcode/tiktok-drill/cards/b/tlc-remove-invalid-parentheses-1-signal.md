## Q
**LC 301 删除无效的括号**｜Hard · LC TikTok 热度 50/100 · CodeTop 国内累计 12 次 · 最近 2025-05-16（国内 CodeTop）

给由括号和小写字母组成的字符串 `s`，删除最少数量的无效括号使其有效，返回所有可能的结果（任意顺序）。`1 <= s.length <= 25`，`s` 由小写字母和 `(`、`)` 组成，至多含 `20` 个括号。例：`"()())()"` → `["(())()","()()()"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**可能的结果」+ 括号数 `<= 20` → **回溯**（backtracking）：每个括号选删或留，`2^20 ≈ 10^6` 可行。这个上限就是题目给的暗示。
- 「删除**最少**」→ 把最少删除数当成**预算**先算出来，用它剪枝；或者 **BFS** 按删除个数分层，第一次出现有效串的那层就是最少。
- 括号匹配的有效性：只有一种括号时，一个计数器 `balance`（未配对的左括号数）就够，不需要栈；`balance < 0` 立即无效。
- 「去重」：不同位置删同样的括号得到相同的字符串，要用集合。

**推导链。**
1. 暴力：枚举全部子序列，检查有效并保留最长的，`O(2^n · n)`，没用上「最少」。
2. BFS：每层删一个字符，遇到有效串就停。正确，但每层生成大量重复串。
3. 洞察：一趟扫描就能算出最少要删多少个 `(` 和 `)`：遇 `(` 计数；遇 `)` 先抵消一个 `(`，抵消不了的 `)` 必删。
4. 最优：带预算的 DFS。每个括号「删（预算减一）」或「留（更新 `balance`）」；预算为负、`balance < 0`、剩余字符不够删就剪枝；到末尾要求预算归零且 `balance == 0`；结果存集合。

**同模式的题**：LC 20 有效的括号、LC 22 括号生成、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号。
