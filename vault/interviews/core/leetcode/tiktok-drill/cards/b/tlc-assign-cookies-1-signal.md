## Q
**LC 455 分发饼干**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-03-16（国内 CodeTop）

每个孩子最多分到一块饼干。孩子 `i` 的胃口值是 `g[i]`，饼干 `j` 的尺寸是 `s[j]`，`s[j] >= g[i]` 时饼干 `j` 能满足孩子 `i`。求最多能满足多少个孩子。`1 <= g.length <= 3 * 10^4`，`0 <= s.length <= 3 * 10^4`，`1 <= g[i], s[j] <= 2^31 - 1`。 例：`g = [1,2,3], s = [1,1]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两组对象**一对一**配对」+「配对条件是一个阈值 `s[j] >= g[i]`」+「**最大化**配对数」→ 两组都排序，**贪心 + 双指针**。
- 阈值是单调的：能满足胃口 `x` 的饼干一定能满足比 `x` 小的胃口 → 小饼干先给小胃口，可以用交换论证说明不亏。
- 长度 `3 * 10^4`、值到 `2^31 - 1` → 排序 `O(n log n)`，不能按值开数组。

**推导链。**
1. 暴力：枚举每个孩子拿哪块饼干，指数级；当二分图最大匹配也太重。
2. 观察一：满足不了胃口最小的孩子的饼干，对谁都没用，直接扔掉。
3. 观察二：能满足时，给胃口最小的孩子；若最优解把它给了别人、而让这个孩子吃更大的饼干，两者互换后人数不变。
4. 两组排序后，饼干指针逐个前进，孩子指针在配对成功时前进，`O(n log n + m log m)`。

**同模式的题**：LC 2410（运动员和训练师的最大匹配数）、LC 881（救生艇）、LC 870（优势洗牌）。
