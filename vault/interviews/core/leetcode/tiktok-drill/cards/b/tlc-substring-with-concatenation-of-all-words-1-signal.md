## Q
**LC 30 串联所有单词的子串**｜Hard · CodeTop 国内累计 7 次 · 最近 2026-10-24（国内 CodeTop）

字符串 `s` 和**等长**单词数组 `words`；串联子串是 `words` 所有单词按任意顺序首尾相接得到的子串（重复单词按次数都用）。返回所有起始下标，顺序任意。`1 <= s.length <= 10^4`，`1 <= words.length <= 5000`，`1 <= words[i].length <= 30`，全部小写英文字母。例：`s = "barfoothefoobarman"`，`words = ["foo","bar"]` → `[0,9]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「所有单词等长」→ 可以按固定步长 `w` 切分，把字符串当作「单词序列」，单词是大字母。
- 「任意顺序拼接」→ **多重集相等**（`Counter` 相等），不用枚举排列。
- 串联子串总长固定 `k * w` → **定长滑动窗口**，只是窗口按单词为单位滑。
- `s <= 10^4`、`w <= 30`：`O(n * w)` 只有 `3 * 10^5`；`words.length` 到 5000，`k!` 排列显然不行。

**推导链。**
1. 暴力：枚举全排列再找位置，`k!`。
2. 改成对每个起点切出 `k` 个单词，用 `Counter` 比较，`O(n * k * w)`，约 `10^8`。
3. 浪费：起点 `i` 与 `i + w` 的窗口共享 `k - 1` 个单词。起点按余数分成 `w` 个序列，每个序列里窗口每次右移一个单词。
4. 每个偏移上一个单词吃进一次、吐出一次，超额就吐、遇到非法单词就清空，总计 `O(n * w)`。

**同模式的题**：LC 76 最小覆盖子串、LC 438 找到字符串中所有字母异位词、LC 567 字符串的排列。
