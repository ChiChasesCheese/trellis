## Q
**有效括号字符串：判断，并输出全部方案**｜Medium · TikTok 高频

字符串 `s` 只含 `'('`、`')'` 和 `'*'`，`'*'` 可以当作 `'('`、`')'` 或空串。第一问：判断 `s` 能否变成有效括号字符串（`1 <= len(s) <= 100`）。第二问：输出所有不同的有效字符串，按字典序返回（`1 <= len(s) <= 20`）。例：`"(*)"` 有效，方案 `["()"]`；`"(**)"` 方案 `["(())", "()", "()()"]`；`"*("` 无效。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`'*'` 有三种取值」→ 逐个枚举是 `3^k`；判断问题只关心「未匹配左括号数」，`'*'` 之后它是一段连续整数 → 用区间 `[lo, hi]` 贪心，`O(n)`。
- 「输出**所有**方案」→ 回溯 / 记忆化搜索，输出规模本身是指数级；`len <= 20` 在暗示这一点。
- 「不同的」→ 不同取法会产生同一个字符串（`"***"` 里 `"()*"` 与 `"*()"` 的取法都得到 `"()"`），必须去重。
- 括号配对的两个约束：任何前缀里右括号不多于左括号，结尾时数量相等。

**推导链。**
1. 暴力（判断）：枚举 `3^k` 种替换，每种 `O(n)` 检查。
2. 浪费：许多替换在同一个位置得到相同的未匹配数，检查完全重复。
3. 洞察：状态只有（位置，未匹配数）。判断用 `[lo, hi]`；`hi < 0` 失败，`lo` 对 `0` 取大，结束要 `lo == 0`。输出方案用 `tails(i, bal)` 记忆化返回后缀集合，集合自动去重。
4. 最优：判断 `O(n)`；输出 `O(状态数 × 输出规模)`，`bal` 超过剩余字符数时剪枝。

**同模式的题**：LC 678 有效的括号字符串、LC 20 有效的括号、LC 22 括号生成、LC 301 删除无效的括号、LC 32 最长有效括号。
