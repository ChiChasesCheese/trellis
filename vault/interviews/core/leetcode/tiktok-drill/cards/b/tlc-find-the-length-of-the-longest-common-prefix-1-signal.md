## Q
**LC 3043 最长公共前缀的长度**｜Medium · TikTok·字节 高频

给两个正整数数组 `arr1`、`arr2`（长度 `1..5 * 10^4`，元素 `1..10^8`）。正整数的前缀是它最左边的一位或多位数字组成的整数（`123` 是 `12345` 的前缀，`234` 不是）。在 `arr1` 的 `x` 和 `arr2` 的 `y` 组成的所有数对里，求最长公共前缀的位数，没有返回 `0`；同一数组内部不考虑。例：`arr1 = [1,10,100]`，`arr2 = [1000]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「前缀」+「公共」+「两组数」→ 前缀集合（hash set of prefixes）或字典树（trie）：一边建索引，另一边查询。
- 值域 `10^8` → 每个数最多 `9` 位，只有 `9` 个前缀，总前缀数 `n · 9` 不到 `5 × 10^5`，用集合装得下。
- 数字的前缀 = 反复整除 `10` 去掉末位 → 不需要转成字符串。
- `n · m = 2.5 × 10^9` → 不能做所有数对的两两比较。

**推导链。**
1. 暴力：所有数对逐位比较，`O(n · m · 9)`。
2. 浪费：许多数对比较的是同一个前缀。
3. 洞察：`x`、`y` 有公共前缀 `c` ⇔ `c` 既是 `x` 的前缀，也是 `y` 的前缀。
4. 把 `arr1` 每个数的所有前缀放进集合；对 `arr2` 的每个数，从最长的前缀（它自己）往短处找，第一个命中的就是与 `arr1` 的最长公共前缀。
5. 插入时一个前缀已经在集合里，则它的更短前缀也都在，提前结束。
