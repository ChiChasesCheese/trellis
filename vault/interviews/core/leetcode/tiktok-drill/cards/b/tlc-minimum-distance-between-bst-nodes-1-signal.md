## Q
**LC 783 二叉搜索树节点最小距离**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-05-26（国内 CodeTop）

给二叉搜索树（BST）的根节点 `root`，返回树中任意两个不同节点值之差的最小值（差取绝对值，是正数）。节点数在 `[2, 100]`，`0 <= Node.val <= 10^5`。例：`root = [4,2,6,1,3]` → `1`，`root = [1,0,48,null,null,12,49]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「二叉搜索树」→ 第一反应是**中序遍历有序**：左子树 < 根 < 右子树，中序依次产出升序序列。
- 「任意两数的最小差」→ 在有序序列里只需看**相邻**两个数，不必两两比较。
- 节点数 `<= 100` → 递归深度至多 100，递归写法安全。

**推导链。**
1. 暴力：收集所有值，两两求差取最小，`O(n^2)`。
2. 改进：收集后排序，再比较相邻元素，`O(n log n)`。
3. 洞察：BST 的中序遍历已经是有序的，排序是多余的；比较也只需要「当前值 − 上一个值」。
4. 最优：中序遍历时维护 `prev`，每访问一个节点就用 `node.val - prev` 更新答案，`O(n)` 时间、`O(h)` 栈空间。
