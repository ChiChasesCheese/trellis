## Q
**量水问题：最短操作序列**｜追问

两个水壶问题已经能用 BFS 输出最短操作序列。面试官接着问：（1）只要判断能不能做到（LC 365），有 `O(1)` 的方法吗？（2）为什么 BFS 很快，状态数是多少？（3）需要输出每一步之后两个壶的水量？（4）增加第三个水壶？

## A
1. **只判断可行性**：`z <= x + y and z % gcd(x, y) == 0`，`O(log)`，不需要搜索。依据是裴蜀定理（Bézout）：`a·x + b·y = z` 有整数解当且仅当 `gcd(x, y)` 整除 `z`；操作序列本质上就是在构造这样的线性组合。
2. **状态数**：虽然状态空间是 `(x + 1)(y + 1)`，但每次操作之后至少有一个壶是空的或满的，所以可达状态至多 `2(x + y + 2)` 个，BFS 是 `O(x + y)`；`x = 99`、`y = 100`、`z = 50` 的最短序列有 `197` 步，也是瞬间完成。
3. **输出中间状态**：回溯时把 `state` 一起收集，或者按得到的操作序列再模拟一遍（模拟函数只需要六个分支）。
4. **三个壶**：状态变成三元组 `(a, b, c)`，操作是“灌满、倒空、任意两个壶之间互倒”，BFS 同理，状态数上升到 `O(xyz)` 量级，需要先估算再决定是否可行。

**Python 提醒**：用元组做字典键和集合元素（可哈希），不要用列表；`math.gcd` 接受任意多个参数（3.9+），三个壶时 `gcd(x, y, w)` 直接可用；区分 `None` 和 `[]`，判断结果时用 `is None`，不要写 `if not result`。
