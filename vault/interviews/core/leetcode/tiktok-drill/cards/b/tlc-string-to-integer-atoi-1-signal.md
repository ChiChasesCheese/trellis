## Q
**LC 8 字符串转换整数 (atoi)**｜Medium · CodeTop 国内累计 29 次 · 最近 2025-09-08（CodeTop）

实现 `myAtoi(s)`：丢弃前导空格 `" "`；读一个可选的 `'+'` / `'-'`；读数字直到遇到非数字或结尾（没读到数字则为 `0`）；结果超出 `[-2^31, 2^31 - 1]` 就截断到边界。`0 <= s.length <= 200`，`s` 由英文字母、数字、`' '`、`'+'`、`'-'`、`'.'` 组成。例：`" -042"` → `-42`；`"4193 with words"` → `4193`；`"0-1"` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「依次：空格、符号、数字、截断」→ **有限状态机**（解析器）：阶段只前进，每个阶段最多经过一次，一个下标 `i` 走到底。
- 「遇到非数字就停」「没读到数字返回 `0`」→ 解析在第一个不合法字符处终止，后面的内容完全忽略（`"0-1"` → `0`）。
- 「32 位范围」→ 要在累加过程中判断溢出；下界 `-2^31` 的绝对值比上界大一，正负要分别处理。
- `n <= 200`：无复杂度压力，考的是边界的完整性。

**推导链。**
1. 暴力：`int(s)` 对 `"4193 with words"` 抛异常，也不会截断，不可用。
2. 取巧：`strip` + 正则 `[+-]?\d+`，能做，但面试官想看手写的解析流程。
3. 手写：跳空格 → 读符号 → 读数字。符号确定后设 `limit`（正 `2^31 - 1`，负 `2^31`）。
4. 累加 `num = num * 10 + digit`，一旦 `num >= limit` 就返回 `sign * limit`；循环自然结束则返回 `sign * num`。

**同模式的题**：LC 65 有效数字、LC 7 整数反转、LC 394 字符串解码、LC 224 基本计算器。
