## Q
**LC 528 按权重随机选择**｜Medium · TikTok 高频

给一个下标从 0 开始的正整数数组 `w`，`w[i]` 是下标 `i` 的权重。实现 `pickIndex()`：每次随机返回 `[0, w.length - 1]` 内的一个下标，返回 `i` 的概率是 `w[i] / sum(w)`。`1 <= w.length <= 10^4`，`1 <= w[i] <= 10^5`，`pickIndex` 至多调用 `10^4` 次。例：`w = [1, 3]` 时下标 `0` 的概率是 `25%`，下标 `1` 是 `75%`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按权重抽样」而可用的只有均匀随机数 → 把权重变成数轴上的区间长度，均匀取点再反查属于哪一段。
- `pickIndex` 会被调用很多次 → 构造时预处理，每次抽取要快；每次 `O(n)` 扫描总共 `10^4 × 10^4 = 10^8`，不行，`O(log n)` 足够。
- `w[i] >= 1` → 前缀和（prefix sum）严格递增，每个下标至少占一个整数位置，可以二分查找（binary search）。

**推导链。**
1. 暴力：把下标 `i` 重复 `w[i]` 次展开成数组，均匀取一个；数组长度 `sum(w)` 最大 `10^9`，放不下。
2. 每次现算：取随机数 `r`，从左到右累减权重直到用完，每次 `O(n)`。
3. 浪费：展开数组里连续一段都是同一个下标，只需要记每段的右端点，也就是前缀和。
4. 洞察：`r` 落在哪一段，就是第一个满足 `prefix[i] > r` 的 `i`，在严格递增的数组上二分，`O(log n)`。
