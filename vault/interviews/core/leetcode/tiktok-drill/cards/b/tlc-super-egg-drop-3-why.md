## Q
**LC 887 鸡蛋掉落**｜正确性

为什么 `f(m, k) = f(m-1, k-1) + f(m-1, k) + 1`？一维数组为什么必须倒序更新？再给出“每次从中间扔”的错误策略的反例。

## A
**不变量。** `f(m, k)` 是“最坏情况下，用至多 `m` 次操作、`k` 枚蛋，能分辨出 `f` 的楼层区间的最大长度”。

**为什么转移成立。** 第一次从某层 `x` 扔下，只有两种结果：
- 碎了：`f` 在 `x` 以下，剩 `m-1` 次、`k-1` 枚蛋，最多能处理 `f(m-1, k-1)` 层，所以 `x - 1 <= f(m-1, k-1)`。
- 没碎：`f` 在 `x` 及以上，剩 `m-1` 次、`k` 枚蛋，最多再处理 `f(m-1, k)` 层。

要让两种结果都能在 `m` 次内解决，`x` 取到最大即 `f(m-1, k-1) + 1`，总共覆盖 `f(m-1, k-1) + 1 + f(m-1, k)` 层，与 `x` 的具体位置无关。

**为什么倒序。** 转移用到上一轮的 `floors[j-1]`。正序遍历 `j` 时，`floors[j-1]` 已经被本轮更新过，相当于同一次操作用了两次。`k = 3, n = 14`：正序更新得到 `3`，正确是 `4`（`3` 次操作只能覆盖 `7` 层）。

**反例：每次从中间扔。** `k = 2, n = 100`：从 `50` 层扔，碎了就只剩 `1` 枚蛋，必须从 `1` 层逐层试到 `49`，最坏 `1 + 49 = 50` 次。正确策略第一次扔 `14` 层，碎了逐层扫 `13` 层，没碎则下一次只上升 `13` 层，每次的步长递减一，最坏总共 `14` 次。
