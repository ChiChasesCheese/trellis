## Q
**LC 64 最小路径和**｜正确性

滚动成一维数组以后，为什么内层循环必须从左到右？`dp[j]` 与 `dp[j-1]` 此刻各代表什么？

## A
**不变量。** 处理第 `i` 行、更新到列 `j` 之前：`dp[k]`（`k < j`）已经是本行 `(i, k)` 的最小路径和，`dp[k]`（`k >= j`）还是上一行 `(i-1, k)` 的值。因此更新 `dp[j]` 时，`dp[j]` 是「从上面来」的候选，`dp[j-1]` 是「从左边来」的候选，取小再加上 `row[j]` 恰好是 `(i, j)` 的最小路径和。第一列 `dp[0]` 在循环前单独累加，因为它只有「上」一个来源。

**反例（错误写法一）：内层从右往左。** `grid = [[1,1,1],[9,1,1]]`：从右往左时，`dp[j-1]` 还是上一行的值，等于把「左边」错用成「上一行的左边」。`dp[2]` 取到 `min(3, 2) + 1 = 3`（用的是上一行第 1 列的 `2`，不是本行第 1 列），最后返回 `3`，这条"路径"根本不存在；正确答案是 `4`（右、右、下）。

**反例（错误写法二）：贪心地每步选较小的邻格。** `grid = [[1,3,1],[1,5,1],[4,2,1]]`：先走下（`1 < 3`），再走下（`4 < 5`），总和 `9`；正确答案是 `7`（先右、右、再下、下）。局部最小不等于全局最小。
