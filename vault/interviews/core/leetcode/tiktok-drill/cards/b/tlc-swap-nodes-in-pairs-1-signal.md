## Q
**LC 24 两两交换链表中的节点**｜Medium · LC TikTok 全时段热度 41/100 · CodeTop 国内累计 31 次 · 最近 2026-04-16（国内 CodeTop）

给一个链表，两两交换其中相邻的节点，返回交换后链表的头节点。不能修改节点内部的值，只能交换节点本身。链表中节点的数目在 `[0, 100]` 内，`0 <= Node.val <= 100`。例：`[1,2,3,4]` → `[2,1,4,3]`；`[]` → `[]`；`[1]` → `[1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「链表」+「改变节点顺序」→ 指针重连；头节点会变，所以用哑节点（dummy node）统一处理头部。
- 「两两」→ 每次处理一对，步长为 `2`；节点数可能是奇数，最后一个落单就保持原样。
- 「不能修改节点内部的值」→ 只能改 `next`，不能交换 `val`。
- `n <= 100` → 递归、迭代都行；面试里迭代的 `O(1)` 空间更好，并且能推广到 K 个一组翻转。

**推导链。**
1. 暴力：读出所有值、交换、再写回，违反“不能改值”；另建新链表要 `O(n)` 空间。
2. 一次交换涉及三个指针：`prev.next`、`a.next`、`b.next`（`prev → a → b → rest`）。
3. 先保住 `b.next`（后面链表的入口），再重连成 `prev → b → a → rest`；Python 的元组赋值先求值右边再赋值，一行搞定。
4. 完成后 `a` 是这一对的尾部，`prev = a`；循环条件是 `prev` 后面至少还有两个节点。

**同模式的题**：LC 25 K 个一组翻转链表、LC 206 反转链表、LC 92 反转链表 II、LC 143 重排链表、LC 328 奇偶链表。
