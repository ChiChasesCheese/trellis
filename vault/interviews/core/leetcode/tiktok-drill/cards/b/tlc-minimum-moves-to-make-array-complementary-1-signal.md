## Q
**LC 1674 使数组互补的最少操作次数**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-04-30（CodeTop）

长度为偶数 `n` 的数组 `nums` 和 `limit`；每次操作可把一个元素改成 `[1, limit]` 内的任意整数；要使所有对称位置之和 `nums[i] + nums[n-1-i]` 相同，求最少操作次数。`2 <= n <= 10^5`，`1 <= nums[i] <= limit <= 10^5`。例：`[1,2,4,3]`，`limit = 4` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「对称位置两两配对」→ 把数组拆成 `n/2` 个独立的**对**，每对的两个数可以一起考虑。
- 「所有对的和要相同」→ 枚举统一的**目标和 `s`**，目标和只有 `2 * limit - 1` 种。
- 每对让和变成 `s` 的代价只有 `0 / 1 / 2`，并且按 `s` 分成**连续的几段** → 分段常函数 → **差分数组 + 前缀和**，每对只改几个端点。
- `n`、`limit` 都到 `10^5` → `O(n * limit)` 的逐 `s` 逐对计算不行，要 `O(n + limit)`。

**推导链。**
1. 暴力：枚举目标和 `s`，对每对算代价，`O(limit * n)`。
2. 浪费：每对的代价对绝大多数 `s` 取同一个值，只在 `a+b`、`lo+1`、`hi+limit` 附近变化。
3. 洞察：一对 `(a, b)`，改一个数可达的和是 `[lo + 1, hi + limit]`；`s == a + b` 代价 `0`，在区间内代价 `1`，区间外代价 `2`。
4. 最优：每对用 `diff` 做 `O(1)` 区间更新（默认 `2`，区间内 `-1`，`a+b` 处再 `-1`），最后 `accumulate` 得到每个 `s` 的总代价，在 `[2, 2*limit]` 上取最小 → `O(n + limit)`。

**同模式的题**：LC 1109 航班预订统计、LC 370 区间加法、LC 1094 拼车、LC 253 会议室 II。
