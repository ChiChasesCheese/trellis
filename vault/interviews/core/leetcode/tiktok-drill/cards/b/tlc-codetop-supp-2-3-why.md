## Q
**补充题 2 圆环回原点问题**｜正确性

为什么每步必须整体换一个新列表，不能原地更新？为什么走奇数步、`n` 为偶数时答案一定是 `0`？

## A
**不变量。** 第 `s` 步结束后，`ways[i]` 恰好是"走 `s` 步停在 `i`"的方案数。第 `s + 1` 步的每个值都要用**第 `s` 步**的两个邻居值计算；若原地更新，`ways[i]` 算出新值后，后面的 `ways[i + 1]` 读到的 `ways[i]` 已经是第 `s + 1` 步的值，等于同一步里走了不止一次，状态被污染。列表推导式先读后写，保证了每个新值只依赖旧列表。

**奇偶性。** 每一步位置的奇偶性翻转一次（`n` 为偶数时，顺时针或逆时针一步都改变编号奇偶，环上取模不破坏奇偶）。走奇数步后一定在奇数编号，回不到 `0`，所以答案是 `0`，如 `n = 4, k = 3` → `0`。

**反例（错误写法）：原地更新。** `for i in range(n): ways[i] = ways[i - 1] + ways[(i + 1) % n]`：`(n, k) = (3, 2)` 得 `0`，正确是 `2`；`(5, 5)` 得 `0`，正确是 `2`。
