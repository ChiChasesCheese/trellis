## Q
**LC 403 青蛙过河**｜Hard · LC TikTok 热度 50/100 · CodeTop 国内累计 1 次 · 最近 2021-03-14（CodeTop）

升序的石子位置 `stones`，青蛙从第一块（位置 `0`）出发，**第一步只能跳 `1`**；上一步跳了 `k`，下一步只能跳 `k − 1`、`k`、`k + 1`；只能向前，不能落水。能否到达最后一块石子？`2 <= stones.length <= 2000`，`0 <= stones[i] <= 2^31 - 1`，`stones[0] == 0`，严格升序。例：`[0,1,3,5,6,8,12,17]` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「能不能到达」+ 下一步的选择**取决于上一步**的跳跃长度 → 动态规划的状态必须包含**两个**量：`(所在石子, 上一跳长度)`。
- 位置可达 `2^31`，不能开数组 → 用**位置当字典的键**；石子只有 `2000` 块。
- `n = 2000`：`O(n^2)` 个状态（`4 · 10^6`）可行，`O(n^3)` 不行；转移只有 3 种。
- 石子升序、只能向前 → 可以**按位置从左到右**自底向上推进，一块石子的来源在处理它之前已确定。

**推导链。**
1. 暴力：DFS 从 `(0, 0)` 出发，每步尝试 3 种跳法，指数级。
2. 浪费在哪：同一个 `(pos, k)` 会被不同路径重复搜索。
3. 洞察：状态数其实只有 `O(n^2)`——第 `i` 块石子上的最后一跳长度不超过 `i`。记忆化或自底向上 DP 即可。
4. 最优：`jumps[pos]` 存「能以哪些最后一跳长度站上 `pos`」；按石子从左到右，对每个 `k` 推 `k − 1, k, k + 1`，要求落点是石子且步长为正；终点的集合非空就是答案。

**同模式的题**：LC 55 / 45 跳跃游戏、LC 1871 跳跃游戏 VII、LC 1306 跳跃游戏 III、LC 1654 到家的最少跳跃次数。
