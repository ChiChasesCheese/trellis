## Q
**LC 974 和可被 K 整除的子数组**｜Medium · TikTok·字节 高频

给整数数组 `nums` 和整数 `k`，返回元素之和可被 `k` 整除的非空连续子数组的个数。`1 <= nums.length <= 3 * 10^4`，`-10^4 <= nums[i] <= 10^4`，`2 <= k <= 10^4`。例：`nums = [4,5,0,-2,-3,1]`，`k = 5` → `7`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**子数组的个数**」+「和满足条件」→ **前缀和加哈希表**：把“区间和”变成“两个前缀值的关系”，边扫描边统计之前出现过多少个。
- 数组含**负数** → 滑动窗口失效（窗口和不单调），只能用前缀和。
- 「可被 `k` 整除」→ 取模：`(pre[j+1] - pre[i]) % k == 0` 等价于 `pre[j+1] % k == pre[i] % k`，条件变成「余数相等」，只需要统计每个余数出现的次数。
- `n = 3 * 10^4` → `O(n^2)` 约 `4.5 * 10^8`，Python 超时，目标 `O(n)`。

**推导链。**
1. 暴力：枚举全部起点终点，求和后判断整除，`O(n^3)`；用前缀和差 `O(n^2)`。
2. 浪费：固定终点后对每个起点逐一判断，其实只关心“有多少个起点的前缀余数与终点相同”。
3. 哈希表 `seen[r]` 记前缀余数 `r` 的出现次数；处理每个元素时，当前余数已有 `c` 个，就新增 `c` 个合法子数组，再把计数加一。
4. 初始化 `seen = {0: 1}`：空前缀的余数是 `0`，保证从开头开始的子数组被计入。
5. `O(n)` 时间，`O(k)` 空间。

**同模式的题**：LC 560 和为 K 的子数组、LC 523 连续的子数组和、LC 525 连续数组、LC 1590 使数组和能被 P 整除。
