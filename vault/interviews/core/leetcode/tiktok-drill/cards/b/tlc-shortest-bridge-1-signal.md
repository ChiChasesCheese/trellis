## Q
**LC 934 最短的桥**｜Medium · LC TikTok 全时段热度 56/100

给 `n x n` 的二元矩阵 `grid`，`1` 表示陆地，`0` 表示水域。岛是由四面相连的 `1` 形成的一个最大组；`grid` 中恰好存在两座岛。可以将任意数量的 `0` 变为 `1`，使两座岛连接成一座岛，返回必须翻转的 `0` 的最小数目。`n == grid.length == grid[i].length`，`2 <= n <= 100`，`grid[i][j]` 为 `0` 或 `1`，恰有两个岛。例：`[[0,1,0],[0,0,0],[0,0,1]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少翻转多少个 `0` 才能连通」→ 两座岛之间的**最短距离**；网格、每步代价相同 → **BFS**（广度优先搜索）。
- 起点是**一整座岛**，而不是某个点 → **多源 BFS**：把岛的所有格子同时放进队列作为第 0 层。
- 「恰好两座岛」→ 先要把其中一座岛**圈出来**（DFS / BFS 洪水填充，flood fill），另一座岛无需标记，BFS 碰到的第一个未标记的 `1` 就属于它。
- `n <= 100` → 一万个格子，`O(n^2)` 远远够用。

**推导链。**
1. 暴力：把两座岛的格子都找出来，枚举所有格子对，答案是曼哈顿距离最小值减 `1`。
2. 浪费：只需要最近的一对，却比较了所有对。
3. 关键：从第一座岛出发向外一圈一圈扩，扩出来的每一圈都是水格（需要翻转），最先碰到第二座岛的那一圈决定最短距离。
4. 实现：DFS 找出第一座岛作为初始 `frontier`；循环里把未访问的邻居逐层推进，碰到陆地就返回已推进的层数。

**同模式的题**：LC 542 01 矩阵（多源 BFS）、LC 994 腐烂的橘子、LC 1091 二进制矩阵中的最短路径、LC 827 最大人工岛。
