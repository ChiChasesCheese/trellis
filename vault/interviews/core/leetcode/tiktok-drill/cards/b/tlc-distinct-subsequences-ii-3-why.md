## Q
**LC 940 不同的子序列 II**｜Hard · 字节高频｜正确性

为什么重复的串恰好有 `dp[last[ch] - 1]` 个？如果减的是 `dp[last[ch]]`，或者干脆不减，会在什么输入上出错？

## A
**不变量。** `dp[i]` 是 `s[:i]` 的不同子序列集合的大小（含空串）。

**为什么恰好是 `dp[j - 1]`。** 设 `j` 是字符 `ch` 上一次出现的位置，`i` 是这次。新集合 = 旧集合 `S` ∪ `{x + ch : x ∈ S}`。其中 `x` 取自 `s[:i - 1]` 的子序列。若 `x` 同时是 `s[:j - 1]` 的子序列，那么 `x + ch` 在位置 `j` 就已经出现在旧集合里了，是重复；若 `x` 必须用到 `j` 或之后的字符，则 `x + ch` 必然不在旧集合里（旧集合里以 `ch` 结尾的串，其去掉末尾后的部分只来自 `s[:j - 1]`）。所以重复数 `= |s[:j - 1] 的子序列| = dp[j - 1]`。

**反例一：不去重。** `"aaa"`：`dp = [1, 2, 4, 8]`，答案 `7`；实际只有 `a, aa, aaa` 三种，正确 `3`。

**反例二：减 `dp[j]`。** `"aba"`：`dp[3] = 2 * 4 - dp[1] = 6`，答案 `5`；正确是 `dp[3] = 8 - dp[0] = 7`，减去空串得 `6`。`"aaa"` 用 `dp[j]` 得 `1`，正确 `3`。
