## Q
**LC 14 最长公共前缀**｜Easy · LC TikTok 热度 50/100 · CodeTop 国内累计 24 次 · 最近 2026-01-16（国内 CodeTop）

编写函数查找字符串数组中的最长公共前缀；如果不存在公共前缀，返回 `""`。

约束：`1 <= strs.length <= 200`，`0 <= strs[i].length <= 200`，`strs[i]` 非空时仅由小写英文字母组成。例：`["flower","flow","flight"]` → `"fl"`；`["dog","racecar","car"]` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「所有字符串的公共前缀」→ 要让所有串在同一位置同时对齐，**纵向扫描**（按列比较）：某一列不齐就停。
- 前缀从第 0 位开始、必须连续 → 只要一列不同，之后的列都不用看，可以提前终止。
- 字符串可能为空、长度不同 → 前缀不能超过最短串；`zip` 在最短串耗尽时自动结束。
- 数据规模小（`200 x 200`）→ 任何线性于总字符数的写法都够，重点是写得简洁、无越界。

**推导链。**
1. 横向：以 `strs[0]` 为初始前缀，依次与每个后续串求公共前缀并缩短，最坏比较所有字符。
2. 纵向（手写）：外层列、内层串，逐个比较，要自己处理越界与空串。
3. 洞察：`zip(*strs)` 是"转置 + 在最短串处停止"，每一列就是一个元组，`len(set(列)) == 1` 判断是否全相同。
4. 最优：循环里统计通过的列数，返回 `strs[0][:size]`，`O(S)` 时间，不额外拼接字符串。
