## Q
**LC 1262 可被三整除的最大和**｜Medium · CodeTop 国内累计 5 次 · 最近 2026-03-09（CodeTop）

给整数数组 `nums`，从中选出一些元素（可以一个都不选，和为 `0`），使它们的和能被 `3` 整除，返回这个最大和。`1 <= nums.length <= 4 * 10^4`，`1 <= nums[i] <= 10^4`。例：`nums = [3,6,5,1,8]` → `18`（选 `3, 6, 1, 8`）；`nums = [4]` → `0`；`nums = [1,2,3,4,4]` → `12`（选 `1, 3, 4, 4`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「选一些数」+「和满足条件」+「最大」→ **0-1 选择型 DP**：每个数选或不选。
- 条件只涉及「能否被 `3` 整除」→ 状态只需要记**余数**（3 种），不用记具体的和（最大 `4 * 10^8`）。
- `n = 4 * 10^4` → 需要 `O(n)` 或 `O(n log n)`；`2^n` 的子集枚举不行。
- 每个数 `>= 1`、没有负数 → 选得越多和越大，所以对同一个余数只保留最大的和即可。

**推导链。**
1. 暴力：枚举所有子集，计算和，挑出被 `3` 整除的最大值，`O(2^n)`。
2. 浪费：不同的子集会落到同一个余数；只有每个余数下的最大和有用。
3. 洞察：`dp[i][r]` = 用前 `i` 个数、余数为 `r` 的最大和；选 `x` 时前一个余数是 `(r - x) % 3`。
4. 最优：`3 * n` 个状态，每个 `O(1)`，总共 `O(n)`。另一条路是贪心：总和余几，删最小的一个同余数或两个互补余数。
