## Q
**LC 263 丑数**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-02-05（国内 CodeTop）

丑数是只包含质因数 `2`、`3`、`5` 的**正**整数（`1` 没有质因数，也算丑数）。给整数 `n`，判断它是否为丑数。`-2^31 <= n <= 2^31 - 1`。例：`14` → `false`（含质因数 `7`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「只包含质因数 2、3、5」→ 把这几个因子**反复整除**干净，看剩下的是不是 1。
- 「**正**整数」+ 范围含负数和 0 → 先判 `n <= 0` 返回 `False`；0 不处理会死循环。
- `|n| < 2^31` → 每次整除至少减半，最多 31 次。

**推导链。**
1. 暴力：完整质因数分解，试除到 `sqrt(n)`，约 `4.6 × 10^4` 次。
2. 浪费：只关心有没有「别的」质因数，不需要知道它是什么。
3. 关键：除干净 2、3、5 后剩下的数，是 1 当且仅当没有别的质因数。
4. 最优：三个 `while` 整除，`O(log n)`。

**同模式的题**：LC 264 丑数 II、LC 313 超级丑数、LC 326 3 的幂。
