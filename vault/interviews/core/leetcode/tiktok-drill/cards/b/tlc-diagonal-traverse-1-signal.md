## Q
**LC 498 对角线遍历**｜Medium · LC TikTok 全时段热度 25/100 · CodeTop 国内累计 21 次 · 最近 2026-04-20（国内 CodeTop）

给 `m x n` 的矩阵 `mat`，按对角线遍历的顺序返回所有元素：从左上角出发，先向右上走，到边界后进入下一条对角线，改向左下走，交替进行。`1 <= m, n <= 10^4`，`1 <= m * n <= 10^4`，`-10^5 <= mat[i][j] <= 10^5`。例：`[[1,2,3],[4,5,6],[7,8,9]]` → `[1,2,4,7,5,3,6,8,9]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「沿对角线走，方向交替」→ 矩阵遍历：找**不变量**——同一条反对角线上 `i + j` 是常数，共 `m + n - 1` 条，奇偶决定方向。
- 「到边界后拐弯」→ 模拟法需要处理四种边界；按 `i + j` 分组可以绕开所有边界判断。
- `m·n <= 10^4`，但 `m` 或 `n` 单独可到 `10^4`：矩阵可能是一行或一列，不能假设"方阵"。
- 线性 `O(m·n)` 即可，没有性能压力，考点是正确处理边界与方向。

**推导链。**
1. 暴力：模拟行走，维护方向，撞到上 / 右 / 下 / 左边界时分别决定下一个位置，右上角和左下角还要特判。
2. 浪费：每一步都在判断边界，分支多、容易漏。
3. 洞察：`i + j == d` 的元素组成第 `d` 条对角线；行优先扫描时每组按行号递增，即从右上到左下。
4. `d` 为偶数时要向右上走（从左下到右上），把该组反过来；`d` 为奇数时保持原样。按 `d` 从 `0` 到 `m + n - 2` 依次输出。

**同模式的题**：LC 54 螺旋矩阵、LC 59 螺旋矩阵 II、LC 1329 将矩阵按对角线排序、LC 48 旋转图像。
