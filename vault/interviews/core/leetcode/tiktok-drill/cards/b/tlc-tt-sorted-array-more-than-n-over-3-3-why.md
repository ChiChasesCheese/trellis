## Q
**有序数组中出现次数超过 n/3 的数**｜正确性

为什么只检查 `0, step, 2*step, ...` 这些下标上的值就不会漏掉答案？为什么阈值必须是严格大于？给出只查一个位置、或把「大于」写成「大于等于」时出错的具体输入。

## A
**不变量与证明。** 设值 `v` 的出现次数大于 `n / 3`，则次数 `c` 满足 `c >= n // 3 + 1 = step + 1`（`3c > n` 等价于 `c > n / 3`，而 `c` 是整数）。数组有序，`v` 占据一段连续下标 `[l, l + c - 1]`，长度 `>= step + 1`。任意 `step + 1` 个连续整数里恰好含一个 `step` 的倍数，所以这段下标里至少有一个下标 `j = m * step`，此时 `nums[j] = v`，`v` 出现在候选里。候选之外的值不可能满足条件，所以没有遗漏；候选再用二分精确计数，不会误收。

**候选个数。** 下标 `0, step, 2*step, ...` 不超过 `n - 1`，个数是 `ceil(n / step)`；`n = 3*step + r`（`0 <= r <= 2`）时它等于 `3 + ceil(r / step)`，在 `n >= 3` 时不超过 `5`，是常数。

**反例一：写成 `>=`。** `[1,1,2,2,3,3]`，`n = 6`，每个值恰好出现 `2 = n / 3` 次：
- `>=` 版本收下 `1, 2, 3`，输出 `[1, 2, 3]`。
- 题目要求严格大于，没有任何值满足，正确是 `[]`。

**反例二：只查 `nums[n // 3]`。** `[1,1,2,4,4]`，`n = 5`，`n // 3 = 1`：
- 只验证 `nums[1] = 1`，`1` 出现 `2` 次，`3 * 2 = 6 > 5`，收下，得到 `[1]`。
- `4` 也出现 `2` 次，同样满足，漏掉了它；正确是 `[1, 4]`。超过 `n/3` 的值最多两个，抽样要覆盖整个数组。
