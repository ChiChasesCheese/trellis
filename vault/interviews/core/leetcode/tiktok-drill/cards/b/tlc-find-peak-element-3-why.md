## Q
**LC 162 寻找峰值**｜正确性

为什么「`nums[mid] < nums[mid + 1]` 就丢掉左半」不会漏掉所有峰？下坡时为什么只能 `hi = mid` 而不能 `hi = mid - 1`？

## A
**不变量。** 每轮开始时，闭区间 `[lo, hi]` 内至少有一个峰（相对整个数组的峰：`lo - 1` 处和 `hi + 1` 处的元素要么越界视为 `-∞`，要么在区间之外且「朝着区间内部下坡」）。

**为什么往右。** `nums[mid] < nums[mid + 1]`，从 `mid + 1` 起向右看：若一直上升，则会到达 `hi`，而 `hi` 的右边 `nums[hi + 1]` 要么是 `-∞`，要么按不变量比 `nums[hi]` 小，所以 `nums[hi]` 是峰；若中途下降，下降前的那个点是峰。所以 `[mid + 1, hi]` 内有峰。

**为什么下坡保留 `mid`。** `nums[mid] > nums[mid + 1]` 时，`mid` 的右邻居更小，`mid` 本身可能就是峰（取决于左邻居）。往左看同理，要么有一个上坡转折点，要么一路下降到 `lo`，`nums[lo - 1]` 比它小或是 `-∞`，故 `[lo, mid]` 内有峰，且 `mid` 不能排除。

**反例。** `nums = [1,2,1]`：`lo = 0, hi = 2, mid = 1`，`2 > 1` 下坡。写成 `hi = mid - 1 = 0` 后区间 `[0, 0]`，返回下标 `0`（值 `1`，不是峰）；正确写法 `hi = mid = 1`，返回下标 `1`（值 `2`，是峰）。
