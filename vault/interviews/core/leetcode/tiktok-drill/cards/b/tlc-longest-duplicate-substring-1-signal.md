## Q
**LC 1044 最长重复子串**｜Hard · 字节 高频

给一个字符串 `s`，考虑它的所有**重复子串**：连续子串，在 `s` 中出现 `2` 次或更多次，出现之间**可能重叠**。返回任意一个长度最长的重复子串，没有则返回 `""`。`2 <= s.length <= 3 * 10^4`，`s` 由小写英文字母组成。例：`s = "banana"` → `"ana"`；`s = "abcd"` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最长**」+「重复子串」+ `n = 3 * 10^4` → `O(n^2)` 个子串都装进集合不行；需要 `O(n log n)`。
- 答案长度有**单调性**：长度 `L` 的重复子串去掉末尾一个字符，长度 `L - 1` 的仍然重复 → **二分答案**。
- 判定「长度 `L` 的窗口有没有重复」→ **滚动哈希**（Rabin-Karp）：窗口右移一格 `O(1)` 更新哈希，整次判定 `O(n)`。
- 允许重叠，所以只需要两个窗口起点不同，不用比较是否相交。

**推导链。**
1. 暴力：枚举所有子串放进集合，`O(n^2)` 个子串，每个切片和哈希 `O(n)`，总计 `O(n^3)`。
2. 浪费 1：逐个长度试。单调性 → 二分，只需 `log n` 次判定。
3. 浪费 2：每次判定对每个窗口都切片 `O(L)`。滚动哈希：`h = h * base - 出去 * base^L + 进来`，`O(1)`。
4. 哈希可能碰撞：哈希相同时再比较真实子串；随机底数 + `2^61 - 1` 大模数，验证期望常数次。总时间 `O(n log n)`。

**同模式的题**：LC 1062 最长重复子串、LC 718 最长重复子数组、LC 187 重复的DNA序列、LC 28 找出字符串中第一个匹配项的下标。
