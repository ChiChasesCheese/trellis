## Q
**LC 2523 范围内最接近的两个质数**｜Medium · TikTok 高频

给两个正整数 `left`、`right`，在 `[left, right]` 内找两个质数 `num1 < num2`，使 `num2 - num1` 最小；差相同时取 `num1` 最小的一对；凑不出两个质数就返回 `[-1, -1]`。

约束：`1 <= left <= right <= 10^6`。例：`left = 10, right = 19` → `[11, 13]`；`left = 4, right = 6` → `[-1, -1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「范围内的质数」+ 上界 `10^6` → 埃氏筛（Sieve of Eratosthenes）：一次预处理得到全部质数，比逐个试除便宜得多。
- 「差最小的一对」→ 把候选排好序以后只比较**相邻**元素；夹着第三个质数的两个质数，差一定更大。
- 「差相同取 `num1` 最小」→ 按从小到大的顺序扫，只在**严格更小**时更新答案（或用 `min` 取第一个最小者）。
- `R = 10^6` → 允许 `O(R log log R)` 的筛，不允许 `O(R√R)`（约 `10^9`）。

**推导链。**
1. 暴力：对区间内每个数试除到 `√x` 判质，再枚举所有质数对，`O(R√R + P²)`。
2. 浪费一：每个数都在重复分解小因子；改用筛法，从 `p²` 起划掉 `p` 的倍数，总共 `O(R log log R)`。
3. 浪费二：不必枚举所有质数对；质数有序，差最小的一对必然相邻，线性扫一遍。
4. 最优：筛 + 相邻对扫描，并列时取先出现的一对。

**同模式的题**：LC 204 计数质数、LC 762 二进制表示中质数个数的数字、LC 866 回文质数、LC 1175 质数排列。
