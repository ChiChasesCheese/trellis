## Q
**LC 772 基本计算器 III**｜Hard · LC TikTok 全时段热度 66/100 · CodeTop 国内累计 7 次 · 最近 2026-03-10（国内 CodeTop）

实现一个基本的计算器来计算简单的表达式字符串。表达式只包含非负整数，算符 `+`、`-`、`*`、`/`，左括号 `(` 和右括号 `)`。整数除法需要**向下截断**（截去小数部分，如 `-3 / 2` 得 `-1`）。你可以假定给定的表达式总是有效的，所有中间结果的范围均在 `[-2^31, 2^31 - 1]`。不能使用任何把字符串当表达式求值的内置函数，比如 `eval()`。

约束：`1 <= s <= 10^4`（表达式字符串长度），`s` 由整数、`'+'`、`'-'`、`'*'`、`'/'`、`'('`、`')'` 组成，`s` 是有效的表达式。

例：`s = "1+1"` → `2`；`s = "6-4/2"` → `4`；`s = "2*(5+5*2)/3+(6/2+8)"` → `21`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「四则运算 + 括号」的表达式求值 → **优先级**（`* /` 高于 `+ -`）和**嵌套**（括号）两件事要同时处理；用「项列表」处理优先级，用栈处理嵌套。
- `s` 长度到 `10^4`，括号可嵌套上千层 → 递归会超出 Python 的递归上限（默认 1000），要用显式栈。
- 「整数除法向下截断」「中间结果可为负」→ Python 的 `//` 向下取整，对负数不同于截断，必须自己处理符号。

**推导链。**
1. 暴力：先把括号逐层展开成子串递归求值，再用 LC 227 的方法算平层，思路清楚但每次都要找匹配括号，最坏 `O(n²)`。
2. 洞察一（优先级）：把表达式看成「项」之和——`+` / `-` 开新项（`-` 记成负项），`*` / `/` 立刻并入上一项。
3. 洞察二（嵌套）：括号内是独立的子表达式，求完就是一个普通整数；`(` 时保存外层现场，`)` 时求和并恢复。
4. 最优：一遍扫描，栈保存 `(外层项列表, 括号前运算符)`，每个字符常数处理，`O(n)`；除法写成向零截断。
