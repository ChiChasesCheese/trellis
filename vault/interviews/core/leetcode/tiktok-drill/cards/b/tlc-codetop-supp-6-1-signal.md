## Q
**补充题 6 手撕堆排序**｜Medium · CodeTop 国内累计 19 次 · 最近 2026-03-24（CodeTop）

给整数数组 `nums`，把它按升序排列。要求手写**堆排序**：原地排序，不调用 `sorted`、`list.sort`，也不使用 `heapq`。`1 <= nums.length <= 50000`，`-50000 <= nums[i] <= 50000`。例：`nums = [5,1,1,2,0,0]` → `[0,0,1,1,2,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 题面直接点名「堆排序」→ **数组表示的完全二叉树**：下标 `i` 的孩子是 `2i + 1`、`2i + 2`；操作只有一个：下沉（sift down）。
- 「升序」+「原地、不借额外数组」→ **大根堆**：把当前最大值换到数组末尾，已排好的尾部不再参与堆。
- `n = 5 * 10^4` → `O(n log n)` 足够，`O(n^2)` 的选择排序（约 `1.25 * 10^9` 次比较）不行；值域只有 `10^5` 种，计数排序 `O(n + 值域)` 是常见追问。

**推导链。**
1. 暴力：选择排序，每轮扫描找最大值放到末尾，`O(n^2)`。
2. 浪费：每轮都从头扫，没有保留上一轮比较的结果。
3. 洞见：堆能 `O(1)` 取最大值、`O(log n)` 修复；堆可以直接放在原数组里，不用额外空间。
4. 最优：先从 `n // 2 - 1` 向前下沉建大根堆（`O(n)`），再循环 `n - 1` 次「堆顶换到末尾、堆缩小、堆顶下沉」，共 `O(n log n)`。

**同模式的题**：LC 215 数组中的第 K 个最大元素、LC 347 前 K 个高频元素、LC 23 合并 K 个升序链表、LC 148 排序链表。
