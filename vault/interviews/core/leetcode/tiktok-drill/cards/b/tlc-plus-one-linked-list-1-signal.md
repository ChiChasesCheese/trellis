## Q
**LC 369 给单链表加一**｜Medium · CodeTop 国内累计 1 次 · 最近 2025-11-12（国内 CodeTop）

链表表示一个非负整数，最高位在头节点，每个节点一位数字（节点数 `1..100`，`0 <= Node.val <= 9`，不含前导零，除了零本身）。把它加上 `1`，返回结果链表的头。例：`[1,2,3]` → `[1,2,4]`；`[0]` → `[1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「链表表示的数」+「最高位在头」→ 加法的进位方向（从低位到高位）与单链表的遍历方向（从头到尾）相反：要么反转、要么借助栈、要么利用"加一"的特殊性。
- 「加一」（不是任意加法）→ 进位只会沿着末尾连续的 `9` 传播，遇到第一个非 `9` 就停；于是只要定位「最后一个非 `9` 的节点」。
- 「最高位可能新增」（`999 + 1 = 1000`）→ 链表头可能要变，套路是**哑节点**（dummy node）。
- `n <= 100`、节点值一位 → 转成整数也能过，但不是考点；要 `O(1)` 空间的链表解法。

**推导链。**
1. 暴力：遍历成整数，加一，再按位建新链表，`O(n)` 空间。
2. 浪费：整数转换绕开了链表本身，并且每次都重建整条链。
3. 洞察：只有末尾的那串 `9` 会变 `0`，它前面的第一个非 `9` 数字加一；其余节点保持不变。
4. 最优：一趟遍历记录最后一个非 `9` 节点（以哑节点起头应对全 `9`），加一并把它后面的节点置零，`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 66 加一、LC 2 两数相加、LC 445 两数相加 II、LC 2816 翻倍以链表形式表示的数字。
