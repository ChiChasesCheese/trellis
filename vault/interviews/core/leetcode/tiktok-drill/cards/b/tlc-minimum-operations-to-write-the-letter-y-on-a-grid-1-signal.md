## Q
**LC 3071 在矩阵上写出字母 Y 所需的最少操作次数**｜Medium · TikTok 高频

`n x n` 的矩阵 `grid`（`3 <= n <= 49`，`n` 为奇数），每个值是 `0`、`1` 或 `2`。字母 `Y` 由三条线组成：左上角到中心的对角线、右上角到中心的对角线、中心到底部边界的竖直线。写出 `Y` 要求：`Y` 上的单元格值都相等，`Y` 外的单元格值都相等，两个值不同。每次操作可以把任意单元格改成 `0`、`1` 或 `2`。求最少操作次数。例：`[[1,2,2],[1,1,0],[0,1,0]]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 值域只有 `{0, 1, 2}` → 目标值的组合只有有限种：`Y` 内取 `a`，`Y` 外取 `b`，`a != b` 共 `6` 种 → 计数（`Counter`）加枚举。
- 「改成目标值的代价」= 当前不等于目标的格数 → 只需要知道各区域各个值有多少个。
- 「`n` 是奇数，`Y` 由三条线组成」→ 有明确的中心 `mid = n // 2`；`Y` 的判定是纯几何：中心及以上看两条对角线，中心以下看竖线。
- `n <= 49` → 数据极小，不是复杂度题；考点是判定条件不出错，以及 `a != b`。

**推导链。**
1. 暴力：对每个 `(a, b)` 组合扫一遍矩阵逐格比较，`6 · n^2`。
2. 优化：扫一遍统计两个计数器 `in_y`、`out_y`，之后每个组合 `O(1)` 计算。
3. 代价：`Y` 内需要改的格数 = `Y` 的大小 − `in_y[a]`，`Y` 外需要改的格数 = 其余格数 − `out_y[b]`，合起来是 `n * n − in_y[a] − out_y[b]`。
4. 在 `a != b` 的 `6` 种组合上取最小。
