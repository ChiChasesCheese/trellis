## Q
**LC 2816 翻倍以链表形式表示的数字**｜Medium · 近一年被问：美国 0 次、国内 1 次 · 最近 2026-09-15（国内面试记录）

链表从高位到低位表示一个非负整数，每个节点一位，无前导零（`0` 本身除外）。把这个数翻倍并返回结果链表的头。节点数在 `[1, 10^4]`，`0 <= Node.val <= 9`。例：`[1,8,9]` → `[3,7,8]`，`[9,9,9]` → `[1,9,9,8]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「链表表示的数字 + 算术」→ 进位问题。关键是**进位方向**：手算从低位到高位，链表头却是高位。
- 「翻倍」不是通用加法：每位 `d*2` 加进位最多 `19`，进位恒为 `0` 或 `1`，而且只由**右邻居**是否 `>= 5` 决定 → 可以从左往右一趟前瞻，不必反转。
- 位数 `10^4`：Python 的 `int(str)` 有 4300 位的默认上限，转整数的暴力解直接 `ValueError`。

**推导链。**
1. 暴力：链表 → 字符串 → `int` → 乘 2 → 回链表。`10^4` 位触发上限报错，且空间 `O(n)`。
2. 常规：反转 → 从低位带 `carry` 翻倍 → 再反转。`O(n)` 时间、`O(1)` 空间，但要动链表结构两次。
3. 浪费：进位只可能是 `0/1`，且等价于「右边那位 `>= 5`」，不必从低位传上来。
4. 最优：哑头（值 0）+ 单趟：`val = (val*2 + (next.val >= 5)) % 10`；最高位进位落在哑头上。

**同模式的题**：LC 2 两数相加、LC 445 两数相加 II、LC 66 加一、LC 43 字符串相乘。
