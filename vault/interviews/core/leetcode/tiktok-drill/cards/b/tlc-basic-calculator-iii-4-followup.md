## Q
**LC 772 基本计算器 III**｜追问

面试官接着问：（1）加入一元负号和空格（如 `"-(2 + 3) * 4"`）？（2）加入幂运算 `^`（右结合）？（3）怎么把词法分析和语法分析分开，支持变量和小数？

## A
1. **一元负号 / 空格**：空格直接 `continue`；遇到 `-` 时，如果它前面是表达式开头或 `(`（前一个非空字符不是数字或 `)`），当作 `0 - ...`：在 `num = 0` 的基础上继续即可，因为 `0 - x` 的 `apply` 已经能处理。
2. **幂运算 `^`**：优先级比 `* /` 还高，且右结合 `2^3^2 = 2^9`。栈法里 `terms[-1] **= num` 不再正确（右结合要先算后面的）。改用**递归下降**或**调度场（shunting-yard）**：用两个栈（数栈、运算符栈），为每个运算符设优先级和结合性，弹栈条件对右结合运算符用严格小于。
3. **词法 / 语法分离**：先用 `re.findall(r"\d+\.?\d*|[-+*/()^]|[A-Za-z_]\w*", s)` 切成 token 列表，解析器只处理 token；数值用 `Fraction` 或 `Decimal` 避免浮点误差。这样加运算符只改语法部分。

**Python 提醒**：`int(a / b)` 看似向零截断，但 `a / b` 是浮点除法，`|a|` 超过 `2^53` 就不精确；这里中间结果在 32 位内所以碰巧可用，面试里仍应写成整数运算：`q = abs(a) // abs(b)` 再补符号。`ch.isdigit()` 对 `'²'`、全角数字也返回 `True`，用 `"0" <= ch <= "9"` 更保险。
