## Q
**LC 2850 将石头分散到网格图的最少移动次数**｜Medium · LC TikTok 全时段热度 50/100

给 `3 * 3` 的整数矩阵 `grid`（`0 <= grid[i][j] <= 9`），格子里是石头数，总共恰好 `9` 个石头。每次操作把一个石头移动到有公共边的相邻格子。返回让每个格子恰好有一个石头的最少移动次数。例：`[[1,1,0],[1,1,1],[1,2,1]]` → `3`；`[[1,3,0],[1,0,0],[1,0,3]]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`3 × 3`」+「总数恰好 `9`」+「每格一个」→ 供需一一对应：多余的石头数等于空格数 → 匹配问题（assignment problem）。
- 「每次移动到相邻格子」→ 一颗石头走到目标格的最少步数是曼哈顿距离。
- 数据极小（空格最多 `8` 个）→ `8! = 40320` 的排列枚举完全够；规模大了才需要状压 DP 或匈牙利算法。
- 「最少移动次数」不需要模拟路径 → 只求匹配的最小总距离。

**推导链。**
1. 暴力：状态是 `9` 个格子的石头分布（`C(17, 8) = 24310` 个），每步移一颗石头到相邻格子，BFS 到全 `1`。
2. 浪费：BFS 把路径细节都搜了一遍，而最终只关心“多余的石头各自去了哪个空格”。
3. 洞察：多余石头与空格数相同，每颗多余石头对应一个空格；从 A 到 B 至少曼哈顿距离步，沿途可以让别的石头接力，总步数不增加。
4. 所以答案 = 多余石头与空格的最小代价完美匹配；枚举空格的排列，按顺序与多余石头配对，取距离之和最小。

**同模式的题**：LC 1066 校园自行车分配 II、LC 1947 最大兼容性评分和、LC 2172 数组的最大与和、LC 1879 两个数组最小的异或值之和。
