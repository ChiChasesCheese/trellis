## Q
**LC 968 监控二叉树**｜Hard · TikTok 高频

在二叉树的节点上安装摄像头，每个摄像头可以监视它的父节点、自己和直接子节点。求监控树上所有节点所需的最少摄像头数。节点数在 `[1, 1000]`，每个节点的值都是 `0`。例：`[0,0,null,0,0]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树 + 每个节点都要被覆盖 + 最少选点」→ **树上覆盖**问题（最小支配集），用**树形 DP** 或**自底向上贪心**。
- 摄像头只影响父、自己、子（局部）→ 状态只与相邻层有关，可以后序一次合并。
- 节点数 `1000` 且可能是链 → 递归会超过 Python 默认深度，写成迭代后序。

**推导链。**
1. 暴力：枚举节点子集，`2^n`。
2. 树形 DP：每个节点三种状态——自己装、被孩子覆盖、等父亲覆盖，`O(n)`。
3. 贪心洞察：摄像头装在叶子上浪费；装在叶子的父亲上，既覆盖叶子又覆盖更高一层。所以叶子应当「未被监控」，由父亲处理。
4. 因此自底向上，一个节点只在**不得不**（有孩子未被监控）时才装摄像头，状态压缩成三个值：`0` 未监控、`1` 已监控无摄像头、`2` 有摄像头；空节点算已监控；最后检查根。

**同模式的题**：LC 337 打家劫舍 III、LC 979 在二叉树中分配硬币、LC 543 二叉树的直径、LC 124 二叉树中的最大路径和。
