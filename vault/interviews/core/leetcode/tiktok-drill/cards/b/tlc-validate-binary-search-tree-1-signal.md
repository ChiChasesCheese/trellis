## Q
**LC 98 验证二叉搜索树**｜Medium · 字节高频

给二叉树的根结点 `root`，判断它是否是有效的二叉搜索树：左子树只含严格小于当前结点的值，右子树只含严格大于当前结点的值，且左右子树自身也是 BST。结点数在 `[1, 10^4]`，`-2^31 <= Node.val <= 2^31 - 1`。例：`[5,1,4,null,null,3,6]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「二叉搜索树」+「验证」→ **中序遍历**应该严格递增；或者自顶向下带**区间**（`lo < val < hi`）。两者都是一次 `O(n)` 遍历。
- 定义里「**整个**子树」都要小于 / 大于 → 约束是从祖先一路传下来的，不能只比较父子。
- 「严格」→ 相等也失败，比较用 `<=` 判错。
- 结点数 `10^4` + Python → 链状树深度 `10^4`，递归超过默认的约 `1000` 层，要用**显式栈**迭代。
- 值域恰为 `int32` 全范围 → 不能用 `-2^31` / `2^31 - 1` 当哨兵，用 `None` 或 `inf`。

**推导链。**
1. 暴力：每个结点检查左子树全部小于它、右子树全部大于它，最坏 `O(n^2)`。
2. 浪费：每个结点都重新扫一遍子树；而祖先的约束其实可以随递归向下传。
3. 洞察：中序序列严格递增 ⇔ 是 BST。于是不用检查区间，只需要和「上一个访问的值」比较。
4. 最优：迭代中序，栈 + `prev`，`O(n)` 时间、`O(h)` 空间。

**同模式的题**：LC 230 BST 中第 K 小的元素、LC 99 恢复二叉搜索树、LC 530 BST 的最小绝对差、LC 94 二叉树的中序遍历。
