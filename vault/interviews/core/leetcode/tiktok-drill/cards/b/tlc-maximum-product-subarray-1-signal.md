## Q
**LC 152 乘积最大子数组**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 40 次 · 最近 2026-10（国内面试记录）

给整数数组 `nums`，找出乘积最大的非空连续子数组，返回它的乘积。答案保证在 32 位整数内。`1 <= nums.length <= 2 * 10^4`，`-10 <= nums[i] <= 10`，任何子数组的乘积都在 32 位整数内。例：`nums = [2,3,-2,4]` → `6`；`nums = [-2,0,-1]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子数组」+「最大」→ **以当前位置结尾的 DP**（最大子数组和 Kadane 的同类）。
- 「乘积」+ 元素有**负数**和 **0** → 与加法不同，乘一个负数会让大小颠倒，所以光记最大值不够，要同时记**最小值**；`0` 会清零，等价于“重新开始”。
- `n = 2 * 10^4` → `O(n^2)` 约 `2 * 10^8` 次，Python 超时，目标 `O(n)`。
- 「答案在 32 位内」→ 不用考虑溢出和大整数。

**推导链。**
1. 暴力：固定起点向右累乘，所有起点取最大，`O(n^2)`。
2. 套用 Kadane：`cur = max(x, cur * x)`。失败：`[-2,3,-4]` 里，以 `3` 结尾的最大乘积是 `3`，乘上 `-4` 得 `-12`，但以 `3` 结尾的**最小**乘积 `-6` 乘上 `-4` 得 `24`。
3. 修正：对每个结尾位置同时维护最大 `hi` 和最小 `lo`。
4. 新的 `hi`、`lo` 来自三个候选：`x`（重新开始）、`hi * x`、`lo * x`，取最大和最小。
5. 全局答案是所有位置的 `hi` 的最大值；`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 53 最大子数组和、LC 1567 乘积为正数的最长子数组、LC 238 除自身以外数组的乘积、LC 713 乘积小于 K 的子数组。
