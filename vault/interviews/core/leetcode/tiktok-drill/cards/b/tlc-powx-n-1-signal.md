## Q
**LC 50 Pow(x, n)**｜Medium · LC TikTok 全时段热度 25/100 · CodeTop 国内累计 15 次 · 最近 2026-03-24（国内 CodeTop）

实现 `pow(x, n)`，计算浮点数 `x` 的整数 `n` 次幂。`-100.0 < x < 100.0`，`-2^31 <= n <= 2^31 - 1`，`n` 是整数；要么 `x` 不为零，要么 `n > 0`；结果满足 `-10^4 <= x^n <= 10^4`。例：`x = 2.0, n = -2` → `0.25`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`x` 的 `n` 次幂」+ `n` 可达 `2^31` → 逐个乘要 `2 * 10^9` 次，必须 `O(log n)`；指数规模是「二分 / 倍增」的信号。
- 乘法满足结合律：`x^(a+b) = x^a * x^b` → 可以把指数拆成两半或按二进制位拆开 → **快速幂**。
- `n` 为负 → 只是边界：`x^-n = (1 / x)^n`，先变成非负指数。
- 「要么 `x` 不为零，要么 `n > 0`」排除了 `0` 的负次幂，不必处理除零。

**推导链。**
1. 暴力：循环乘 `n` 次，`O(n)`，`n = 2^31` 时超时。
2. 浪费：`x^8` 不需要 8 次乘法，`x^2 → x^4 → x^8` 三次平方即可，已算出的中间结果被丢掉了。
3. 洞察：`x^n = (x^(n // 2))^2`，`n` 为奇数时再多乘一个 `x`；指数每步减半。
4. 最优：按二进制位从低到高，位为 1 就把当前底数乘进结果，底数每轮平方，共 `O(log n)` 轮。
