## Q
**LC 881 救生艇**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-03-27（国内 CodeTop）

数组 `people` 中 `people[i]` 是第 `i` 个人的体重；船的数量不限，每艘船最大载重 `limit`，每艘船**最多同时载两人**，且这两人的体重之和不超过 `limit`。返回载所有人所需的最少船数。`1 <= people.length <= 5 * 10^4`，`1 <= people[i] <= limit <= 3 * 10^4`。例：`people = [3,2,2,1], limit = 3` → `3`（`(1,2)`、`(2)`、`(3)`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每艘船**最多两人**」+「最少船数」→ **排序 + 配对贪心**；若可载任意多人就是装箱问题（NP 难），「至多两人」是能贪心的关键。
- 「两个数之和不超过上限」且要尽量两两配成对 → **对撞双指针**（左端最轻、右端最重）。
- `n = 5 * 10^4`、`people[i] <= 3 * 10^4` → 排序 `O(n log n)` 足够；值域小，也可计数排序到 `O(n + limit)`。

**推导链。**
1. 暴力：枚举所有可能的配对方案，指数级；状态压缩 DP 也只能处理很小的 `n`。
2. 浪费：配对的好坏只取决于两端——最重的人最难找到搭档，应该最先处理。
3. 洞见（交换论证）：最重的人必占一艘船；最轻的人配不上他就没人配得上；配得上就带上，不会更差。
4. 最优：排序后对撞双指针，每轮最重的下船、能配就带走最轻的，`O(n log n)`。

**同模式的题**：LC 167 两数之和 II、LC 11 盛最多水的容器、LC 455 分发饼干、LC 1099 小于 K 的两数之和。
