## Q
**LC 80 删除有序数组中的重复项 II**｜写出 Python 实现

升序整数数组 `nums`（长度 `1` 到 `3 * 10^4`，元素在 `-10^4` 到 `10^4`）。原地修改，使每个值最多出现两次，返回新长度 `w`，调用者读取 `nums[:w]`。额外空间 `O(1)`。

## A
**思路。** 写指针 `w` 表示结果的长度，`nums[:w]` 始终合法。读指针遍历每个 `x`：结果不足两个，或者 `x` 与结果里倒数第二个元素不同，就写入并推进 `w`。

```python
def remove_duplicates(nums: list[int]) -> int:
    w = 0                                  # 写指针：nums[:w] 是已经合法的结果
    for x in nums:
        if w < 2 or x != nums[w - 2]:      # 与结果里倒数第 2 个比：不等说明 x 至多出现过 1 次
            nums[w] = x
            w += 1
    return w
```

运行：`[1,1,1,2,2,3]` → `5`，`nums[:5]` 是 `[1,1,2,2,3]`；`[0,0,1,1,1,1,2,3,3]` → `7`，`nums[:7]` 是 `[0,0,1,1,2,3,3]`；`[1]` → `1`；`[1,1,1,1]` → `2`，`nums[:2]` 是 `[1,1]`。

**复杂度。** 时间 `O(n)`：只扫一遍；空间 `O(1)`：只有 `w` 和 `x`。

**写法要点。** `for x in nums` 遍历的同时写 `nums[w]`：因为 `w <= 当前读位置`，写入位置永远不会超过读指针，不会覆盖尚未读到的元素（Python 的列表迭代器按下标取值，所以修改已读过的前缀是安全的）；条件 `w < 2 or ...` 利用 `or` 的短路，避免在 `w < 2` 时访问 `nums[w - 2]`；推广到「最多 `k` 个」只需把两处 `2` 换成 `k`。
