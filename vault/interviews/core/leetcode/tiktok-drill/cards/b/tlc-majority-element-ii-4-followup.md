## Q
**LC 229 求众数 II**｜追问

面试官接着问：（1）进阶要求 `O(1)` 空间怎么做？（2）为什么投票结束后还要再数一遍？（3）推广到「超过 `n / k`」？

## A
1. **两候选摩尔投票**：思路是「三个互不相同的数一起抵消」。维护 `cand1, cand2` 和计数：等于某个候选就给它加一；否则若有计数为 0 的空位就占位；否则两个计数各减一（加上当前数，正好三个不同的数被抵消）。超过 `n / 3` 的值每被抵消一次就消耗两个别的数，不可能被抵消完，所以一定留在候选里。

```python
def majority_element_vote(nums: list[int]) -> list[int]:
    cand1, cand2, cnt1, cnt2 = 0, 1, 0, 0      # 两个候选初值不同，避免一开始就相等
    for x in nums:
        if x == cand1:
            cnt1 += 1
        elif x == cand2:
            cnt2 += 1
        elif cnt1 == 0:
            cand1, cnt1 = x, 1
        elif cnt2 == 0:
            cand2, cnt2 = x, 1
        else:                                  # 三个互不相同的数：一起抵消
            cnt1 -= 1
            cnt2 -= 1
    # 第二遍：候选只是「可能」超过 n/3，必须数一遍确认
    return [c for c in (cand1, cand2) if nums.count(c) > len(nums) // 3]
```

`[3,2,3]` → `[3]`，`[1,2]` → `[2, 1]`，`[1,1,1,2,2,2,3]` → `[2, 1]`。分支顺序要先判「等于候选」再判「计数为 0」：反过来写，`[2,2]` 会让两个候选都变成 `2`，返回 `[2, 2]`，正确是 `[2]`。
2. **必须再数一遍**：候选只保证「若有答案，必在候选中」，不保证候选就是答案。`[1,0,1]` 投票后候选是 `1` 和 `0`，计数都为正；不确认会返回 `[0, 1]`，正确是 `[1]`。
3. **超过 `n / k`**：保留 `k - 1` 个候选（Misra-Gries），用字典存；遇到新值且字典已满时，所有计数减一并删掉减到 0 的。时间 `O(nk)`，空间 `O(k)`，结束后同样要再数一遍。

**Python 提醒**：`list.count` 每次是 `O(n)`，对 2 个候选调用两次仍是 `O(n)`；但别在循环里对每个元素调用它，那会退化成 `O(n^2)`。
