## Q
**LC 105 从前序与中序遍历序列构造二叉树**｜Medium · LC TikTok 热度 62/100 · CodeTop 国内累计 62 次 · 最近 2026-06-29（国内 CodeTop）

给两个整数数组 `preorder`（二叉树前序遍历）和 `inorder`（同一棵树的中序遍历），构造并返回这棵二叉树。`1 <= preorder.length <= 3000`，`inorder.length == preorder.length`，`-3000 <= preorder[i], inorder[i] <= 3000`，两个数组都无重复元素，输入保证合法。例：`preorder = [3,9,20,15,7]`，`inorder = [9,3,15,20,7]` → `[3,9,20,null,null,15,7]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「给两种遍历序列，还原树」→ **分治**：前序的第一个是根，这个根在中序里把序列切成左右两段。单一遍历序列不能唯一确定树，所以必须两种一起给。
- 「**无重复元素**」→ 值可以当哈希表的键，用 `值 → 中序下标` 在 `O(1)` 内找到根的位置；有重复值时根的位置不唯一。
- `n` 到 3000 → 每层线性找根的 `O(n^2)` 勉强能过，但最优是 `O(n)`；树可能是 3000 层的链，要留意递归深度。

**推导链。**
1. 暴力：取前序首元素当根，`inorder.index(root)` 找位置，切片得到左右子树的前序和中序，递归。找根 `O(n)`，切片复制 `O(n)`，总共 `O(n^2)`。
2. 浪费：根的位置每次从头找；数组每次重新复制。
3. 修正：先建 `值 → 下标` 字典；递归只传中序区间 `[lo, hi)`，不复制数组。
4. 关键观察：前序里根后面紧跟整个左子树，再是整个右子树。不必算左子树的大小，只要「先建左、后建右」，让一个前序迭代器逐个吐出值，每次吐出的恰好就是当前区间的根。
5. 每个节点创建一次、查字典一次 → `O(n)`。
