## Q
**LC 385 迷你语法分析器**｜Medium · TikTok 高频

给字符串 `s`，表示整数的嵌套列表，解析并返回 `NestedInteger`（`NestedInteger()` 是空列表，`NestedInteger(v)` 是单个整数，`add(x)` 追加元素）。`1 <= s.length <= 5 * 10^4`，`s` 只含数字、`[`、`]`、`-`、`,`，保证可解析，数值在 `[-10^6, 10^6]`。例：`"[123,[456,[789]]]"` → 含 `123` 和 `[456,[789]]` 两个元素的列表。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号嵌套的字符串 → 结构」→ **栈**：遇到 `[` 开新层，遇到 `]` 收一层。
- `s.length` 到 `5 * 10^4` → 嵌套最深约 `25000` 层，递归下降在 Python 里会 `RecursionError`，用显式栈。
- 含多位数和负号 → 数字要整体作为一个记号，不能逐字符当数字，**先分词再解析**。

**推导链。**
1. 暴力：递归下降，`parse(i)` 读到 `[` 就循环解析子元素直到 `]`，需要共享下标并递归。
2. 问题：递归深度等于括号嵌套层数，最坏 `25000`，超过默认深度 `1000`。
3. 关键：栈顶永远是「正在填的列表」。`[` 压入新列表，整数 `add` 进栈顶，`]` 弹出并 `add` 进新的栈顶；栈空时弹出的就是最外层，即结果。
4. 分词交给正则 `re.findall(r"\[|\]|-?\d+", s)`，主循环只剩三种记号，`O(n)`；整串只是一个整数的情形先单独处理。
