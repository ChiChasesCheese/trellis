## Q
**LC 287 寻找重复数**｜正确性

为什么数组一定对应一条"带环的链"，环的入口为什么恰好是重复数？阶段二为什么从起点 `0` 与相遇点同速前进就能到达入口？如果阶段二的起点写错、或者用求和的办法，会错在哪里？

## A
**不变量与结构。** 值落在 `[1, n]`，所以每一步 `x → nums[x]` 都落在合法下标里，不会越界；没有任何元素的值是 `0`，所以没有边指向 `0`，`0` 不在环里。路径无限延伸而下标只有 `n + 1` 个，必然进入一个环。每个出现一次的值入度恰为 `1`，下标 `0` 入度为 `0`，只有重复数 `d`（出现 `k ≥ 2` 次）入度 `≥ 2`。环的入口 `v` 一定有两条入边——一条来自尾巴的最后一个节点（尾长 `a ≥ 1`，因为 `0` 在环外），一条来自环里的前一个节点——所以入度 `≥ 2`，`v = d`。

**阶段二的证明。** 设尾巴长 `a`（从 `0` 到入口），入口到相遇点的距离 `b`，环长 `c`。阶段一相遇时：慢指针走了 `a + b`，快指针走了 `2(a + b)`，快比慢多走整数圈：`2(a + b) − (a + b) = a + b = k·c`。于是 `a = k·c − b`：从相遇点继续走 `a` 步，等于绕环 `k` 圈后退 `b` 步，正好回到入口；而从 `0` 走 `a` 步也到入口。所以两个指针同速前进，会在入口相遇。

**反例 1：阶段二从 `nums[0]` 起步。**
- `[1,3,4,2,2]`：把 `slow` 重置成 `nums[0] = 1`，`fast` 留在相遇点。
- 两者的距离不再满足 `a = k·c − b`，永远不相遇，循环不会停止。

**反例 2：用求和相减。** `sum(nums) − n(n+1)/2` 只在重复数恰好出现两次时等于它：
- `[3,3,3,3,3]`（`n = 4`）：`15 − 10 = 5`，输出 `5`。
- 正确是 `3`。题目明确说重复数可以出现两次或多次。

**起点。** 起点用下标 `0`：它在环外，尾长 `a ≥ 1`，上面的追及关系才成立。
