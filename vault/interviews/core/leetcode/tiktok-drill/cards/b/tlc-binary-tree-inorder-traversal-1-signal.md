## Q
**LC 94 二叉树的中序遍历**｜Easy · 字节高频

给二叉树的根结点 `root`，返回中序（左、根、右）遍历的结果。结点数在 `[0, 100]`，`-100 <= Node.val <= 100`。进阶：用迭代代替递归。例：`[1,null,2,3]` → `[1,3,2]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树的遍历」+「中序」→ 访问顺序是左、根、右：根要**等左子树全部处理完**才能访问。
- 「进阶：递归很简单，迭代呢」→ 面试官要你**自己维护调用栈**：显式栈代替系统栈。
- 空树是合法输入（结点数下界是 `0`）→ 循环要能直接处理 `root = None`。
- 结点数很小（`<= 100`），递归也不会爆栈；但更大的链状树就会，这是迭代版值得掌握的现实理由。

**推导链。**
1. 暴力（递归）：`inorder(left)`、访问、`inorder(right)`，三行。
2. 问题：深度等于树高，退化成链时递归栈很深；而且进阶要求不用递归。
3. 洞察：递归在做的事就是「沿左链下潜；回来时访问；再转右」。下潜时经过的结点正是需要等待的祖先，放进显式栈即可。
4. 最优：`while node or stack`：内层一路向左压栈，弹出访问，转向右孩子；每个结点入栈出栈各一次，`O(n)`。
