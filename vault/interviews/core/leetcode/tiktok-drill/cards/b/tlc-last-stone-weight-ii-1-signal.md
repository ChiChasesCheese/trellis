## Q
**LC 1049 最后一块石头的重量 II**｜Medium · 字节 高频

有一堆石头，`stones[i]` 是第 `i` 块的重量。每回合**任选**两块粉碎：重量 `x <= y`，相等则两块都消失，否则剩下一块重量 `y - x`。最后最多剩一块，返回它**最小的可能重量**（没有则为 `0`）。`1 <= stones.length <= 30`，`1 <= stones[i] <= 100`。例：`stones = [2,7,4,1,8,1]` → `1`；`stones = [31,26,33,21,40]` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**任选**两块相撞，剩下**差**」→ 每块石头最终贡献 `+w` 或 `-w`，最终重量是 `|Σ ±w|`；碰撞顺序无关，只关心分组。
- 「最小的可能重量」→ 把石头分成两堆，使重量差最小 → **0/1 背包 / 子集和**。
- 对比 LC 1046（每次砸最重的两块）：那里按规则取最重，用堆；这里任选，贪心不最优。
- `n <= 30`、重量 `<= 100` → 总重 `<= 3000`，背包容量 `<= 1500`，`O(n · total)` 极小；符号枚举 `2^30` 不可行。

**推导链。**
1. 暴力：枚举碰撞顺序（阶乘）或每块石头的符号（`2^n`，`n = 30` 约 `10^9`）。
2. 洞察 1：最终剩余 = `|S1 - S2|`，`S1`、`S2` 是两堆的重量和，最小差的分组总能通过合适的碰撞顺序实现。
3. 洞察 2：`S1 + S2 = total`，`|S1 - S2| = total - 2 * min(S1, S2)`，要最小就让较小的一堆尽量大且不超过 `total // 2`。
4. 用布尔 0/1 背包求「不超过 `total // 2` 的最大可达子集和」，答案 `total - 2 * best`。

**同模式的题**：LC 416 分割等和子集、LC 494 目标和、LC 474 一和零、LC 1046 最后一块石头的重量。
