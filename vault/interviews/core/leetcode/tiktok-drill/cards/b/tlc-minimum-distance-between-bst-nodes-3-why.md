## Q
**LC 783 二叉搜索树节点最小距离**｜正确性

为什么在中序序列里只看相邻两个值就够了？只比较「父节点和子节点」的差为什么不对？给出反例。

## A
**为什么相邻就够。** 中序序列 `a_1 < a_2 < … < a_n` 严格升序（BST 中值互不相同）。对任意 `i < j`，`a_j - a_i = (a_j - a_(j-1)) + … + (a_(i+1) - a_i)`，是若干个相邻差之和，每一项都为正，所以 `a_j - a_i >= a_(i+1) - a_i`。最小差一定是某个相邻差。

**不变量。** 访问到某节点时，`prev` 是中序序列里紧挨在它前面的值，`best` 是已访问前缀里所有相邻差的最小值。

**反例：只比父子。** 树 `[5,1,null,null,4]`：根 `5`，左孩子 `1`，`1` 的右孩子是 `4`。
- 父子差：`5 - 1 = 4`，`4 - 1 = 3`，最小 `3`。
- 中序序列 `1, 4, 5`，相邻差 `3` 和 `1`，正确答案 `1`。`4` 和 `5` 是祖孙关系，中序上却相邻：一个节点在中序里的前驱是其左子树的最右节点，或者某个祖先，未必是父节点。
