## Q
**LC 1073 负二进制数相加**｜正确性

为什么负二进制加法的进位是 `-(x >> 1)` 而不是二进制里的 `x >> 1`？进位会是哪些值，循环为什么一定会结束？

## A
**不变量。** 处理完第 `i` 位后：已写下的低位数字所表示的值 + `carry · (-2)^(i+1)` = 两个输入低 `i + 1` 位之和。

**进位的推导。** 第 `i` 位的本位和是 `x`，即 `x · (-2)^i`。写下 `d = x & 1`（0 或 1），剩下的 `x - d` 是偶数，记作 `2c`（`c = x >> 1`）。`2c · (-2)^i = -c · (-2)^(i+1)`，所以向高位进 `-c`。不变量因此保持。

**进位的范围。** 若进位在 `{-1, 0, 1}`，`x = a + b + carry` 落在 `[-1, 3]`，对应的新进位分别是：`x = -1` → `1`，`0` 或 `1` → `0`，`2` 或 `3` → `-1`，仍在 `{-1, 0, 1}`。输入走完后，进位 `1` 写一位就结束；进位 `-1` 写 `1`、再进 `1`，再写 `1` 结束，所以至多多出 2 位。

**反例：用二进制的进位 `x >> 1`。** `[1] + [1]`：`x = 2`，写 0、进 1，得到 `[1,0]`，表示 `-2`。正确是 `1 + 1 = 2 = 4 - 2`，即 `[1,1,0]`。
