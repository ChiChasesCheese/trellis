## Q
**LC 2456 最流行的视频创作者**｜Medium · LC TikTok 全时段热度 62/100

三个等长数组 `creators`、`ids`、`views` 描述 `n` 个视频的创作者、id 和播放量。创作者的流行度是其所有视频播放量之和。找出流行度最高的创作者（并列全返回）以及其播放量最大的视频 id（并列取字典序最小）。`1 <= n <= 10^5`，`creators[i]` 和 `ids[i]` 长度 `1..5`，只含小写字母，`0 <= views[i] <= 10^5`。例：示例 1 → `[["alice","one"],["bob","two"]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按创作者分组，每组求总和」→ **哈希表聚合**（`defaultdict(int)`）。
- 「每组里取最优视频：播放量最大，并列取 id 字典序最小」→ **多关键字比较**：用元组 `(-播放量, id)`，取最小即可，一次比较同时处理两个条件。
- 「流行度最高的有多个都要返回」→ 先求最大值，再收集所有等于最大值的创作者，不能只用 `max()` 取一个。
- `n = 10^5`，创作者名和 id 都很短 → 一趟扫描 `O(n)`，不需要排序。
- 数组等长且下标对应 → 用 `zip` 同时遍历。

**推导链。**
1. 暴力：对每个创作者扫全数组求总和和最佳视频，`O(n · k)`。
2. 浪费：每个创作者都重新扫描整个数组。
3. 洞察：一趟扫描，累加流行度的同时，用 `(-views, id)` 更新该创作者的最佳视频。
4. 最优：扫完取 `max(popularity.values())`，输出所有等于它的创作者及对应最佳 id，`O(n)`。

**同模式的题**：LC 692 前 K 个高频单词、LC 347 前 K 个高频元素、LC 1636 按频率排序、LC 49 字母异位词分组。
