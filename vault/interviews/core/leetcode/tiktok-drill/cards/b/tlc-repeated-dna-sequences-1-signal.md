## Q
**LC 187 重复的DNA序列**｜Medium · CodeTop 国内累计 2 次 · 最近 2025-11-01（国内 CodeTop）

DNA 序列由字符 `'A'`、`'C'`、`'G'`、`'T'` 组成。给字符串 `s`，返回所有在 `s` 中出现**不止一次**的、长度为 `10` 的子串，顺序任意（每个只返回一次）。`0 <= s.length <= 10^5`，`s[i]` 是 `A`、`C`、`G`、`T` 之一。例：`"AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"` → `["AAAAACCCCC","CCCCCAAAAA"]`，`"AAAAAAAAAAAAA"` → `["AAAAAAAAAA"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「长度固定为 10 的子串」→ **定长滑动窗口**，一共 `n - 9` 个窗口。
- 「出现不止一次」→ 哈希计数（`Counter`），第二次出现时收集。
- 「字符只有 `ACGT`」→ 每个字符 2 位，10 个字符 20 位，可以**整数编码**并滚动更新。
- `n <= 10^5` → `O(n)` 或 `O(nL)` 都行，`O(n^2)` 两两比较不行。

**推导链。**
1. 暴力：所有长度 10 的子串两两比较，`O(n^2 · L)`。
2. 改进：哈希表数切片，`O(nL)`；`L = 10` 时能过，但每个窗口都新建字符串、整段哈希。
3. 洞察：相邻窗口只差一头一尾，编码可以由上一个推出：左移 2 位、或上新字符、与上 `2^20 - 1` 去掉最老的字符。
4. 最优：滚动 20 位编码做 `Counter` 的键，`O(n)` 时间，键是小整数，省内存。

**同模式的题**：LC 1044 最长重复子串、LC 28 找出字符串中第一个匹配项的下标（Rabin-Karp）、LC 1316 不同的循环子字符串。
