## Q
**LC 440 字典序的第 K 小数字**｜另一种解法

不数子树大小，直接一步一步走字典序的"下一个数"怎么写？它的复杂度是多少，什么时候用它？

## A
**思路。** 字典序的下一个数有固定规则：能向下一层（`cur * 10 <= n`）就先向下；否则回到右邻兄弟——如果已到末尾（`cur >= n`）先退回上一层，然后 `cur + 1`，再把末尾的 `0` 全部去掉（进位说明这一层走完了，要回退）。从 `1` 走 `k - 1` 步就是第 `k` 个。

```python
def find_kth_number_walk(n: int, k: int) -> int:
    cur = 1
    for _ in range(k - 1):                       # 从 1 开始，一步一步走到字典序的下一个数
        if cur * 10 <= n:
            cur *= 10                            # 能往下一层就先往下
        else:
            if cur >= n:
                cur //= 10                       # 已是 n 或不能再加：先回到上一层
            cur += 1                             # 右邻兄弟
            while cur % 10 == 0:                 # 进位到 0 说明这一层走完了，继续回退
                cur //= 10
    return cur
```

`(13, 2)` → `10`；`(1, 1)` → `1`；`(13, 13)` → `9`。

**取舍。** 时间 `O(k)`，空间 `O(1)`。`k` 到 `10^9` 时太慢，但代码极短、几乎不会出错，且直观：就是在模拟先序遍历。当 `k` 较小（比如不超过 `10^6`），或者要输出字典序的前一段数（LC 386）时，直接用它；`k` 大时必须用"跳过整棵子树"的 `O(log^2 n)` 解法。写完正式解法后，用它在 `n` 不大的输入上对照，是最快的自检方法。
