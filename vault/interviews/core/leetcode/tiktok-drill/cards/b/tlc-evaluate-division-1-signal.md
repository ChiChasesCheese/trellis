## Q
**LC 399 除法求值**｜Medium · TikTok 高频

已知若干等式 `Ai / Bi = values[i]`（变量是字符串），再给若干查询 `Cj / Dj = ?`。返回每个查询的答案；无法确定，或变量没有在等式里出现过，答案是 `-1.0`。输入有效，没有除零，也没有矛盾。

约束：`1 <= equations.length, queries.length <= 20`，`0.0 < values[i] <= 20.0`，变量名长度 `1..5`，由小写字母与数字组成。例：`equations = [["a","b"],["b","c"]], values = [2.0,3.0]`，查询 `a/c` → `6.0`，`b/a` → `0.5`，`a/e` → `-1.0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 等式可以串起来（`a/b` 与 `b/c` 得 `a/c`）→ 变量是结点、除法是带权边，乘法有传递性 → 图连通性。
- 「同一个连通块里任意两点的比值唯一」→ 每个结点只需要记相对于代表元的比值 → 带权并查集（weighted union-find）。
- 「变量没出现 / 不连通返回 `-1.0`」→ 并查集里"不在同一集合"。
- `20` 个方程、`20` 个查询 → 图搜索也能过；面试里要能讲出并查集和 DFS / BFS 两种，并说明取舍。

**推导链。**
1. 暴力：建双向图（权 `v` 和 `1 / v`），每个查询从起点 DFS / BFS 累乘到终点。
2. 浪费：同一连通块的查询反复搜索，路径乘积其实由两端相对代表元的比值决定。
3. 洞察：`ratio[x] = x / parent[x]`；路径压缩时累乘到根；合并 `a / b = v` 时挂根并算出两根之比。
4. 最优：查询 `c / d` 时同根则 `ratio[c] / ratio[d]`，每次 `O(α)`。

**同模式的题**：LC 990 等式方程的可满足性、LC 547 省份数量、LC 721 账户合并、LC 684 冗余连接。
