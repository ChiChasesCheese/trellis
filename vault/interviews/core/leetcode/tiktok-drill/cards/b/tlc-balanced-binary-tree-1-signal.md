## Q
**LC 110 平衡二叉树**｜Easy · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 29 次 · 最近 2026-09-24（国内 CodeTop）

判断一棵二叉树是否**高度平衡**：每个节点的左右子树高度差的绝对值都不超过 `1`。节点数在 `[0, 5000]`，`-10^4 <= Node.val <= 10^4`。例：`root = [1,2,2,3,3,null,null,4,4]` → `false`；`root = []` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**每个**节点都满足与左右子树高度有关的条件」→ **树形递归，后序遍历**：先拿到孩子的信息（高度），再在当前节点判断。
- 判断需要的量（高度）同时要往上传 → 一个函数同时做“求高度”和“报告失败”，用特殊值 `-1` 作为失败标记。
- 节点数 `<= 5000`、树可能退化成链 → 注意递归深度；也要避免重复求高度的 `O(n^2)`。

**推导链。**
1. 暴力（自顶向下）：对每个节点求左右子树高度再比较，递归地对左右子树重复同样的检查。
2. 浪费：节点的高度被它的每个祖先的检查重新计算，链状树 `O(n^2)`。
3. 观察：求高度本来就是后序的，孩子的高度算出来后，父节点比较时直接复用。
4. 自底向上：`height(node)` 返回高度；左右高度差 `> 1` 就返回 `-1`，上层看到 `-1` 立刻返回 `-1`。
5. 根返回 `-1` 即不平衡。每个节点访问一次，`O(n)`；空间是递归深度 `O(h)`。

**同模式的题**：LC 104 二叉树的最大深度、LC 543 二叉树的直径、LC 124 二叉树中的最大路径和、LC 968 监控二叉树。
