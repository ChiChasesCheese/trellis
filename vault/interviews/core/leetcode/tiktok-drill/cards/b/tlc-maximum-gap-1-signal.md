## Q
**LC 164 最大间距**｜Hard · CodeTop 国内累计 8 次 · 最近 2026-01-29（CodeTop）

无序整数数组 `nums`（`1 <= n <= 10^5`，`0 <= nums[i] <= 10^9`），返回排序后相邻元素的最大差值，不足两个元素返回 `0`。要求线性时间、线性额外空间。例：`[3,6,9,1]` → `3`，`[10]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「线性时间」+「排序后相邻差」→ 比较排序的下界是 `O(n log n)`，所以不能排序；要用**非比较**的做法：桶（bucket）、基数排序（radix sort），或者利用鸽巢原理省掉排序。
- 「最大」的间隔 → 间隔总和固定为 `hi - lo`，`n - 1` 个间隔，最大的一个不可能小于平均值：这是鸽巢原理（pigeonhole principle）的标志。
- `nums[i] <= 10^9`，`n <= 10^5` → 值域远大于 `n`，计数排序（开 `10^9` 的数组）不可行；但可以把值域按平均间隔切成约 `n` 个桶。
- `n < 2` 返回 `0` → 边界要先处理；全部相等时也是 `0`。

**推导链。**
1. 暴力：`sorted` 后扫描相邻差，`O(n log n)`。
2. 浪费：排序给出了全部元素的次序，但只需要「最大的相邻差」这一个数。
3. 洞察：最大间隔 `>= (hi - lo) / (n - 1)`；桶宽取这个值（向下取整、至少 `1`），桶内的差都比它小，所以答案只出现在相邻非空桶之间。
4. 最优：每个桶只存最小 / 最大值，线性扫描比较「本桶最小 - 前一个非空桶最大」，`O(n)` 时间和空间。
