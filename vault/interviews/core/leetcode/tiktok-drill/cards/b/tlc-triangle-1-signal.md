## Q
**LC 120 三角形最小路径和**｜Medium · 字节高频

给三角形 `triangle`，求自顶向下的最小路径和。每一步只能移动到下一行中相邻的结点：当前在第 `i` 列，下一步到下一行的第 `i` 列或第 `i + 1` 列。`1 <= triangle.length <= 200`，`triangle[0].length == 1`，`triangle[i].length == triangle[i - 1].length + 1`，`-10^4 <= triangle[i][j] <= 10^4`。进阶：只用 `O(n)` 额外空间。例：`[[2],[3,4],[6,5,7],[4,1,8,3]]` → `11`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「路径和最小」+「每步只能去相邻的两个位置」→ **网格 / 三角形 DP**：到达某格的最优值只依赖相邻的前驱（或后继）。
- 「自顶向下的路径」，但答案要的是整条路径的总和 → 反过来**自底向上**算"从这里走到底的最小和"，没有两端的边界特判，答案在 `dp[0][0]`。
- 进阶「`O(n)` 空间」→ 先写完整的二维表 `dp[i][j]`（空间 `O(n^2)`），压缩是最后一步，见 Python 工具箱「DP 降维」。
- `n <= 200`：格子数约 `2 * 10^4`，`O(n^2)` 绰绰有余；暴力 DFS 的路径数 `2^199` 不可行。

**推导链。**
1. 暴力：DFS 枚举所有路径，`2^(n-1)` 条。
2. 浪费：不同路径经过同一格时，从该格往下的最小和是相同的，被重复求解。
3. 洞察：`dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])`，`O(n^2)`。
4. 自底向上让每个格子都有恰好两个后继；最底行是基础行 `dp[n-1][j] = triangle[n-1][j]`，往上逐行填表，答案是 `dp[0][0]`。

**同模式的题**：LC 64 最小路径和、LC 931 下降路径最小和、LC 62 不同路径、LC 118 杨辉三角。
