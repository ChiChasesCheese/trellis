## Q
**LC 1071 字符串的最大公因子**｜正确性

为什么“两种拼接顺序相同”就足以说明公因子串存在，并且最长的恰好是长度的最大公约数？只取 `gcd` 长度的前缀、不做拼接比较会在哪里出错？

## A
**不变量。** 设 `a = str1`，`b = str2`。`a + b == b + a` 时，二者是同一个串的幂（这是字符串的经典引理：两个串可交换当且仅当它们是同一个串的幂）。设这个原串为 `x`（取最短的），则 `a = x^p`，`b = x^q`，`x` 的长度整除 `len(a)` 与 `len(b)`，所以整除 `g = gcd(len(a), len(b))`。长度为 `g` 的前缀 `a[:g]` 是 `x` 重复 `g / |x|` 次，仍然能除尽 `a` 和 `b`，且没有比 `g` 更长的候选，因为公因子的长度必须整除两个长度。

**不做拼接比较会错。** `gcd` 只告诉我们长度，不保证内容合法。
- `("LEET", "CODE")`：`gcd(4, 4) = 4`，取前缀得 `"LEET"`，但它除不尽 `"CODE"`；正确结果是 `""`。
- `("AAAAAB", "AAA")`：`gcd(6, 3) = 3`，取前缀得 `"AAA"`，它能除尽 `"AAA"`，却除不尽 `"AAAAAB"`；正确结果是 `""`。

拼接比较把“内容上是否同源”这件事一次性排除，之后 `gcd` 长度才可信。
