## Q
**LC 283 移动零**｜Easy · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 22 次 · 最近 2026-01-16（国内 CodeTop）

给数组 `nums`，把所有 `0` 移到末尾，同时保持非零元素的相对顺序；必须原地操作，不能复制数组。`1 <= nums.length <= 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。进阶：尽量减少操作次数。例：`[0,1,0,3,12]` → `[1,3,12,0,0]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**原地**」+「不能复制数组」→ 额外空间 `O(1)`，只能在数组内部倒腾。
- 「**保持相对顺序**」→ 划分必须**稳定**（stable），所以用**同向快慢指针**；头尾对撞指针会打乱顺序。
- 「把一类元素挪到一侧」→ 双指针划分：`read` 负责读，`write` 负责写入「保留的元素」。
- 进阶「减少操作次数」→ 能不写就不写，`write == read` 时元素已在位。

**推导链。**
1. 暴力一：新数组装非零再补零，`O(n)` 空间，违反原地。
2. 暴力二：遇到零就 `pop` 再 `append(0)`，每次 `O(n)`，总 `O(n^2)`。
3. 洞察：每个非零元素的最终下标，等于它前面非零元素的个数——正是 `write` 指针的值。
4. 一趟扫描：`read` 遇到非零，就放到 `write`（与它交换，把零换到 `read`），`write` 加一。`O(n)` 时间、`O(1)` 空间。
5. 进阶：`write == read` 说明前面全是非零，自己和自己交换是浪费，跳过。
