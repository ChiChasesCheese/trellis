## Q
**LC 365 水壶问题**｜正确性

为什么能量出的水量恰好是 `gcd(x, y)` 的倍数且不超过 `x + y`？为什么只检查 `target % gcd == 0` 不够？

## A
**必要性。** 倒水不改变两壶总量；装满使总量增加 `x` 或 `y` 的某个量，倒空使总量减少。可以证明总量永远等于 `a·x + b·y`（`a, b` 为整数）。`g = gcd(x, y)` 整除 `x` 和 `y`，所以也整除任何 `a·x + b·y`，因此总量必须是 `g` 的倍数。总量也不会超过 `x + y`。

**充分性（裴蜀定理）。** 存在整数 `a, b` 使 `a·x + b·y = g`，推广到所有 `g` 的倍数 `k·g`。具体操作序列：反复把 `x` 壶装满倒进 `y` 壶，`y` 壶满就清空，这样总量以 `x`（模 `y`）的步长变化，遍历所有 `g` 的倍数。

**反例：漏掉容量条件。** `x = 1, y = 2, target = 4`：`4 % gcd(1, 2) = 4 % 1 = 0`，只检查整除会返回 `True`；两个壶合计最多 `3` 升，正确答案是 `False`。

**反例：整除条件本身。** `x = 2, y = 6, target = 5`：`gcd = 2`，`5` 是奇数，不是 `2` 的倍数，量不出来，答案 `False`（与示例 2 一致）。

**为什么 `(6, 9, 3)` 是真。** `gcd(6, 9) = 3`，`3 <= 15`。操作：装满 `9` 壶倒进 `6` 壶，`9` 壶剩 `3`。
