## Q
**LC 1669 合并两个链表**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-02-02（国内 CodeTop）

链表 `list1`（长度 `3..10^4`）、整数 `a <= b`（`1 <= a <= b < list1.length - 1`）、链表 `list2`（长度 `1..10^4`）。删除 `list1` 中下标 `a` 到 `b` 的节点，把 `list2` 接在原位置，返回头节点。例：`list1 = [10,1,13,6,9,5]`，`a = 3, b = 4`，`list2 = [1000000,1000001,1000002]` → `[10,1,13,1000000,1000001,1000002,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「删除一段、接上另一段」→ 链表指针重连：只需要被删段**前一个**和**后一个**节点两个锚点，不必碰中间的节点。
- 约束 `1 <= a`、`b < n - 1` → 前驱和后继都保证存在，可以不加空指针判断；但链表题的稳妥习惯是加**哑节点**（dummy node），连删头也不用特判。
- `n, m <= 10^4` → 一次遍历 `O(n + m)` 足够；递归会有 `10^4` 层，Python 默认递归上限 `1000`，所以只用迭代。
- 「返回头指针」→ 头节点没被删（`a >= 1`），返回原头即可；用哑节点则统一返回 `dummy.next`。

**推导链。**
1. 暴力：转成数组、切片拼接、重建链表，`O(n + m)` 时间与空间。
2. 浪费：重建了所有节点，而题目只要求改中间一小段的连接。
3. 洞察：只有两条指针需要改——`before.next` 指向 `list2` 的头，`list2` 的尾指向 `after`。
4. 最优：走 `a` 步找 `before`，再走 `b - a + 2` 步找 `after`，遍历 `list2` 找尾，改两条指针，`O(n + m)` 时间、`O(1)` 空间。
