## Q
**LC 128 最长连续序列**｜Medium · LC TikTok 热度 66/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 42 次 · 最近 2026-10-17（国内面试记录）

给一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。要求设计并实现时间复杂度 `O(n)` 的算法。

约束：`0 <= nums.length <= 10^5`，`-10^9 <= nums[i] <= 10^9`。

例：`nums = [100,4,200,1,3,2]` → `4`（`[1,2,3,4]`）；`nums = [0,3,7,2,5,8,4,6,0,1]` → `9`；`nums = [1,0,1,2]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最长连续序列」是**数值**上连续，与下标无关 → 不是滑动窗口，而是要能 `O(1)` 回答「`x+1` 在不在」→ **哈希集合**。
- 「要求 `O(n)`」→ 排序（`O(n log n)`）被排除；值域 `±10^9` → 不能开数组计数。
- 有重复元素、序列会共享前缀 → 需要保证每个序列只被数一遍 → 只从**起点**（`x - 1` 不存在）开始数。

**推导链。**
1. 暴力：每个数 `x` 往右一个个查 `x+1, x+2, …`，`O(n²)`。
2. 排序后扫描：`O(n log n)`，不满足题目的 `O(n)` 要求。
3. 洞察：序列 `[1,2,3,4]` 里从 `2`、`3`、`4` 开始数都是对 `1` 的重复劳动 → 只在 `x - 1` 不存在时才数。
4. 最优：集合去重和 `O(1)` 查询，遍历集合，仅对起点向右数，每个数至多被数一次，`O(n)`。

**同模式的题**：LC 674 最长连续递增序列、LC 298 / 549 二叉树最长连续序列、LC 1 两数之和（哈希查询模式）、LC 217 存在重复元素。
