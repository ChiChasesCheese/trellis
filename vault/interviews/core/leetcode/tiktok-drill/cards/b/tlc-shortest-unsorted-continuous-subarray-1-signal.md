## Q
**LC 581 最短无序连续子数组**｜Medium · TikTok 高频

给整数数组 `nums`，找一个连续子数组，把它升序排序后整个数组都变成升序，返回满足条件的**最短**子数组的长度。`1 <= nums.length <= 10^4`，`-10^5 <= nums[i] <= 10^5`。进阶：`O(n)`。例：`[2,6,4,8,10,9,15]` → `5`（排序 `[6,4,8,10,9]`），`[1,2,3,4]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「排序一个子数组使整体有序」→ 换个问法：哪些位置不在排序后的最终位置上，边界就是第一个和最后一个。
- `n <= 10^4` 且进阶要 `O(n)` → 排序副本做对比（`O(n log n)`）是能接受的答案，但要继续往线性走：前缀最大值、后缀最小值。
- 「整体有序」是全局条件，却能拆成每个位置的局部条件：左边有比它大的数，或右边有比它小的数。

**推导链。**
1. 暴力：枚举 `[l, r]`，排序后检查整体是否有序，`O(n^3 log n)`。
2. 排序一份副本，与原数组逐位比较，第一个和最后一个不同的下标就是边界，`O(n log n)`。
3. 浪费：排序只是为了知道“谁不在原位”，并不需要真的排好。
4. 洞察：位置 `i` 必须在排序段里 ⇔ 它左边有更大的数，或右边有更小的数。从左扫，维护前缀最大值，最后一个“比前缀最大值小”的位置是右端；从右扫，维护后缀最小值，最前一个“比后缀最小值大”的位置是左端。`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 769 / 768 最多能完成排序的块、LC 42 接雨水、LC 238 除自身以外数组的乘积。
