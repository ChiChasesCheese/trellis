## Q
**LC 2414 最长的字母序连续子字符串的长度**｜Medium · TikTok 高频

字母序连续字符串是字母表 `"abcdefghijklmnopqrstuvwxyz"` 的任意子字符串（`"abc"` 是，`"acb"` 和 `"za"` 不是）。给仅由小写英文字母组成的字符串 `s`，返回它最长的字母序连续子字符串的长度。`1 <= s.length <= 10^5`。例：`"abacaba"` → `2`，`"abcde"` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最长**连续**子串」+ 条件只涉及**相邻两个字符**（后一个比前一个大 `1`）→ **线性扫描 / 一维 DP**：以第 `i` 个字符结尾的最长长度只依赖第 `i - 1` 个。
- `n = 10^5` → 不能 `O(n^2)` 枚举子串，一趟 `O(n)`。
- 条件是“恰好差 `1`”，不是“递增” → 用 `ord(cur) - ord(prev) == 1`；`z` 到 `a` 不连续。
- `s` 非空，单个字符就是长度 `1` 的合法答案 → 初值为 `1`。
- 连续段互不重叠，被断点分隔 → 可以按“段”分组，也可以滚动计数。

**推导链。**
1. 暴力：枚举所有子串并检查，`O(n^3)`；固定起点向右扩、遇断点就停，`O(n^2)`。
2. 浪费：同一个断点之前的起点们重复走同一段。
3. 洞察：每个字符只属于一个连续段；新字符接得上就 `run + 1`，接不上就从自己开始 `run = 1`。
4. 最优：一趟扫描，`best = max(best, run)`，`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 674 最长连续递增序列、LC 485 最大连续 1 的个数、LC 1446 连续字符、LC 978 最长湍流子数组。
