## Q
**LC 242 有效的字母异位词**｜正确性

计数解法只在「某个计数变成负数」时返回 `False`，最后并没有检查所有计数都是 0。为什么这样够？去掉开头的长度判断会出什么错？

## A
**论证。** 设 `c[x]` 是 `s` 里 `x` 的次数减去 `t` 里 `x` 的次数。扫完 `t` 后，所有 `c[x]` 之和等于 `len(s) - len(t)`。
- 有长度判断时，这个和是 `0`；扫描过程中没出现负数，说明每个 `c[x] >= 0`。一组非负数之和为 0，只能每个都是 0，即两个多重集相同。
- 所以「长度相等 + 从不为负」⇔「每个计数为 0」，不必再遍历一遍检查。

**反例：去掉长度判断。** `s = "ab", t = "a"`：扫 `t` 时 `c["a"]` 从 1 变成 0，没出现负数，返回 `True`；但 `c["b"] = 1` 还没归零，正确答案是 `False`。

**另一个诱人的错误：比较集合。** `set("aab") == set("abb")` 是 `True`，因为集合丢掉了次数；正确答案是 `False`（`"aab"` 有两个 `a`，`"abb"` 只有一个）。
