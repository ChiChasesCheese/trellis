## Q
**LC 1330 翻转子数组得到最大的数组值**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-07-02（CodeTop）

给整数数组 `nums`，「数组值」定义为所有 `0 <= i < nums.length - 1` 的 `|nums[i] - nums[i+1]|` 之和。你可以选择任意一个子数组并把它翻转，但**只能操作一次**。返回可能得到的最大数组值。`2 <= nums.length <= 3 * 10^4`，`-10^5 <= nums[i] <= 10^5`，答案保证在 32 位整数范围内。例：`nums = [2,3,1,5,4]` → `10`（翻转 `[3,1,5]` 得 `[2,5,1,3,4]`，数组值 `3 + 4 + 2 + 1 = 10`）；`nums = [2,4,9,24,2,1,10]` → `68`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「翻转**一次**子数组」+「相邻差绝对值之和」→ 翻转只改变**子数组两端**的两条相邻差，内部的 `|a - b|` 不变。问题从「选一个子数组」缩成「选两个边界」。
- 要最大化的是「增益」：翻转后的数组值减原数组值，增益只依赖四个元素，可以 `O(1)` 算。
- `n = 3 * 10^4` → `O(n^2)` 的配对枚举偏慢（约 `4.5 * 10^8` 对），目标是 `O(n)` 或 `O(n log n)`。
- 「绝对值」→ 想到拆符号、或者几何化为数轴上的线段，把配对的 `max` 拆成两个独立的最值。

**推导链。**
1. 暴力：枚举 `(l, r)`，翻转后重算，`O(n^3)`。
2. 观察：增益 `= |a[l-1] - a[r]| + |a[l] - a[r+1]| - |a[l-1] - a[l]| - |a[r] - a[r+1]|`，`O(1)`，总共 `O(n^2)`。
3. 洞察：把相邻对看成线段 `[min, max]`；两条不相交的线段间隔 `g`，增益是 `2g`；所以中间情形取 `2 * (max lo - min hi)`。
4. 最优：再单独处理贴着数组左端或右端的翻转（只改一条边），三种情形取最大，`O(n)`。
