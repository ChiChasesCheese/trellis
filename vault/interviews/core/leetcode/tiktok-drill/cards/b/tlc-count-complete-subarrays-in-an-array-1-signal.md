## Q
**LC 2799 统计完全子数组的数目**｜Medium · LC TikTok 热度 62/100

给一个正整数数组 `nums`。若某个子数组的不同元素个数等于整个数组的不同元素个数，它就是完全子数组（子数组是连续非空序列）。返回完全子数组的数目。

约束：`1 <= nums.length <= 1000`，`1 <= nums[i] <= 2000`。例：`[1,3,1,2,2]` → `4`；`[5,5,5,5]` → `10`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子数组」+「不同元素个数」→ 滑动窗口（sliding window），用计数表维护窗口里的种类数。
- 「个数 `>= total`」是**单调**条件：窗口只增不减地向右扩，种类数只增不减 → 对每个左端点，合法的右端点是一个后缀区间，可以一次数一批。
- 「数有多少个」→ 每个左端点贡献一个数，累加，而不是更新最长 / 最短。
- `n <= 1000` → `O(n^2)` 也能过，但目标是 `O(n)`；`nums[i] <= 2000` 说明值域不大，用 `dict` 或 `Counter` 都行。

**推导链。**
1. 暴力：枚举所有子数组，每个再数一遍不同元素，`O(n^3)`。
2. 固定左端点，向右扩并用集合记录，凑齐 `total` 种就停，后面的右端点全部合法，一次加 `n - j`：`O(n^2)`。
3. 浪费：`left` 换成 `left + 1` 后又从头扩。若 `[left+1, r]` 完全，则 `[left, r]` 也完全，所以最小右端不会回退。
4. 最优：双指针，`right` 只进不退，`O(n)`。

**同模式的题**：LC 992 K 个不同整数的子数组、LC 3 无重复字符的最长子串、LC 930 和相同的二元子数组、LC 713 乘积小于 K 的子数组。
