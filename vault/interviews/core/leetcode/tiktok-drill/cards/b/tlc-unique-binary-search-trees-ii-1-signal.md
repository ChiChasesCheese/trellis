## Q
**LC 95 不同的二叉搜索树 II**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-01-15（国内 CodeTop）

给整数 `n`，生成所有由 `1` 到 `n` 这 `n` 个不同值组成的、结构不同的二叉搜索树，任意顺序返回。`1 <= n <= 8`。例：`n = 3` → 5 棵：`[1,null,2,null,3]`、`[1,null,3,2]`、`[2,1,3]`、`[3,1,null,null,2]`、`[3,2,null,1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「生成**所有**」→ 必须构造出每一个结果，不是计数 → **分治 / 回溯**。
- 「二叉搜索树 + 值是 `1..n`」→ 选定根后，左子树的值恰好是比根小的那段区间、右子树是比根大的那段，两边**独立** → 子问题是**值域区间**，结果是左右两组的**笛卡尔积**。
- `n <= 8` → 输出是卡特兰数 `C_8 = 1430` 棵，指数级输出，算法与输出同阶即可。
- 不同根会请求相同区间 → **记忆化**，子树可共享。

**推导链。**
1. 暴力：枚举 `n!` 个插入顺序逐个建 BST，再按结构去重，`n = 8` 有 `40320` 个排列，大量重复。
2. 浪费：多个插入顺序生成同一棵树；按插入顺序枚举本身就是错的维度。
3. 关键：按「谁是根」枚举，结构一一对应，无重复；左右子树分别来自 `[lo, root-1]` 和 `[root+1, hi]`，组合即可。
4. 最优：`build(lo, hi)` 加 `@cache`，空区间返回 `[None]`；每个区间只新建根节点，总量 `O(C_n)`。

**同模式的题**：LC 96 不同的二叉搜索树、LC 241 为运算表达式设计优先级、LC 894 所有可能的真二叉树、LC 22 括号生成。
