## Q
**LC 1466 重新规划路线**｜Medium · LC TikTok 热度 50/100

`n` 座城市（编号 `0..n-1`）之间有 `n - 1` 条有向路线 `connections[i] = [a, b]`（从 `a` 到 `b`），任意两座城市之间只有唯一一条路线可走。要重新规划方向，使每座城市都能到达城市 `0`，求需要变更方向的最少路线数。`2 <= n <= 5 * 10^4`，`connections.length == n - 1`。例：`n = 5`，`connections = [[1,0],[1,2],[3,2],[3,4]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`n` 个点、`n - 1` 条边、两两之间唯一一条路线」→ 树。
- 「每个城市都能到达 `0`」→ 以 `0` 为根，所有边都应该朝向根；每条边是否要反转由它的原方向与“靠近根的一端”决定。
- 路线是有向的，但可达性问题要看整棵树 → 把有向边建成**双向**邻接，每个方向带一个“是否要反转”的标记。
- `n = 5 × 10^4` → `O(n)` 遍历，递归 DFS 即可；一条链的深度就是 `n`，超过 Python 默认递归上限，要调高上限或改迭代。

**推导链。**
1. 暴力：对每条边去掉后遍历，看 `0` 在哪一侧，`O(n^2)`。
2. 浪费：从 `0` 出发遍历一次，就知道每条边哪端更近。
3. 洞察：边第一次被走到时，先到的是父，后到的是子；原方向「父 → 子」要反转，「子 → 父」不用。
4. 建图时就把标记写进去：`a → b` 方向的邻接项标 `1`，`b → a` 方向标 `0`；遍历到新节点时累加标记。

**同模式的题**：LC 1971 寻找图中是否存在路径、LC 310 最小高度树、LC 1376 通知所有员工所需的时间、LC 834 树中距离之和。
