## Q
**LC 940 不同的子序列 II**｜Hard · CodeTop 国内累计 2 次 · 最近 2026-04-02（CodeTop）

给字符串 `s`，求 `s` 的**不同非空子序列**的个数，结果对 `10^9 + 7` 取余。子序列是从原字符串删去一些（也可以不删）字符、不改变剩余字符相对顺序得到的新字符串，例如 `"ace"` 是 `"abcde"` 的子序列，`"aec"` 不是。`1 <= s.length <= 2000`，`s` 仅由小写英文字母组成。例：`"abc"` → `7`（`a, b, c, ab, ac, bc, abc`）；`"aba"` → `6`（`a, b, ab, ba, aa, aba`）；`"aaa"` → `3`（`a, aa, aaa`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子序列」+「计数」+「对 `10^9 + 7` 取余」→ **子序列计数 DP**：`dp[i]` 是前 `i` 个字符的方案数，逐字符递推。
- 「**不同**」→ 难点是去重：不同的选法可能产生同一个字符串，要找出重复的那一批并扣掉；标准手段是**按末尾字符分类**或记录该字符上一次出现的位置。
- `n = 2000`、字符集 26 → `O(n^2)` 可以，`O(n)` 或 `O(26n)` 更好；枚举 `2^n` 个子序列不行。

**推导链。**
1. 暴力：枚举 `2^n` 个选法，放进集合去重，只在 `n <= 20` 时可用。
2. 无重复字符时：每个新字符让方案数翻倍，`dp[i] = 2 * dp[i - 1]`（含空串）。
3. 去重：字符 `ch` 上一次出现在位置 `j`，那时已经造过「`s[:j - 1]` 的每个子序列接 `ch`」；现在再造一遍，重复数是 `dp[j - 1]`，减掉。
4. 最优：`dp[i] = 2 * dp[i - 1] - dp[last[ch] - 1]`，最后 `dp[n] - 1`，`O(n)`。

**同模式的题**：LC 115 不同的子序列、LC 1987 不同的好子序列数目、LC 730 统计不同回文子序列、LC 300 最长递增子序列。
