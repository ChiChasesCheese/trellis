## Q
**LC 1330 翻转子数组得到最大的数组值**｜Hard · 字节高频｜正确性

为什么中间情形的最大增益是 `2 * (max lo - min hi)`？为什么还要单独处理贴着数组端点的翻转？漏掉它会在什么输入上出错？

## A
**不变量。** 翻转 `nums[l..r]` 后，内部的相邻差一个不变，只有边界对 `(l-1, l)` 和 `(r, r+1)` 被换成 `(l-1, r)` 和 `(l, r+1)`。

**中间情形的增益。** 设左边界相邻对是线段 `P = [lo_p, hi_p]`，右边界相邻对是线段 `Q = [lo_q, hi_q]`，且 `lo_q > hi_p`（`Q` 整个在 `P` 右边）。新的两项都是「右边的数减左边的数」，其和等于 `(lo_q + hi_q) - (lo_p + hi_p)`；旧的两项之和是两条线段的长度 `(hi_q - lo_q) + (hi_p - lo_p)`。相减得 `2 * (lo_q - hi_p)`；`Q` 在 `P` 左边时同理，得 `2 * (lo_p - hi_q)`。两线段相交时增益不会为正。因此对所有相邻对取最大的 `lo` 和最小的 `hi` 即可，同一条线段取自己时 `lo - hi <= 0`，无害。

**贴端翻转。** 翻转 `nums[0..r]` 或 `nums[l..n-1]` 时只有一个边界，没有「第二条线段」，上面的公式不适用，必须单独算：增益是 `|nums[0] - nums[i]| - |nums[i-1] - nums[i]|` 或对称的另一端。

**反例：漏掉贴端。** `[1,5,4]`：原数组值 `4 + 1 = 5`；相邻对线段是 `[1,5]` 和 `[4,5]`，`max lo = 4`，`min hi = 5`，中间情形增益 `2 * (4 - 5) < 0`，只算它得 `5`。翻转前缀 `[1,5]` 得 `[5,1,4]`，数组值 `4 + 3 = 7`，正确答案 `7`。
