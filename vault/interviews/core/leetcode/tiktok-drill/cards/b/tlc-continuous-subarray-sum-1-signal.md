## Q
**LC 523 连续的子数组和**｜Medium · CodeTop 国内累计 7 次 · 最近 2026-04-08（CodeTop）

给整数数组 `nums` 和整数 `k`，判断是否存在一个**好的子数组**：它是连续的，长度**至少为 2**，元素总和是 `k` 的倍数（0 也算 `k` 的倍数）。存在返回 `true`，否则 `false`。`1 <= nums.length <= 10^5`，`0 <= nums[i] <= 10^9`，`0 <= sum(nums[i]) <= 2^31 - 1`，`1 <= k <= 2^31 - 1`。例：`nums = [23,2,4,6,7], k = 6` → `true`（`[2,4]` 的和为 6）；`nums = [23,2,6,4,7], k = 13` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子数组」+「和满足条件」→ **前缀和**（prefix sum）；区间和 = 两个前缀和之差，把二维的 `(i, j)` 问题变成对每个 `j` 查一次。
- 「和是 `k` 的倍数」→ 前缀和**对 `k` 取余**：差是倍数，当且仅当余数相同，于是用哈希表查「同余的前缀」。
- `n = 10^5` → `O(n^2)`（约 `5 * 10^9` 对）不行，要 `O(n)` 或 `O(n log n)`。
- 「长度至少 2」→ 哈希里存**最早**出现的下标，下标差 `>= 2` 才算数。

**推导链。**
1. 暴力：枚举所有起点终点，累加求和再判断整除，`O(n^3)`；用前缀和取区间和降到 `O(n^2)`。
2. 浪费：对每个终点 `j`，其实只关心「前面是否存在余数相同、距离足够远的前缀」，却把所有起点都试了一遍。
3. 洞见：`(P[j] - P[i]) % k == 0` 等价于 `P[j] % k == P[i] % k`；余数相同的前缀里，最早的下标最容易满足间隔 `>= 2`。
4. 最优：字典记「余数 → 最早下标」，初始 `{0: -1}`；一趟扫描，每步查一次字典，`O(n)`。
