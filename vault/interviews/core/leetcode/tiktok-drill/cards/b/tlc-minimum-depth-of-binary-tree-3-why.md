## Q
**LC 111 二叉树的最小深度**｜正确性

为什么 BFS 碰到的第一个叶子就是答案？把最大深度的递归 `1 + max(...)` 直接改成 `1 + min(左, 右)` 错在哪？给出出错的输入。

## A
**BFS 的不变量。** 队列里节点的深度单调不减，且相邻节点深度最多差 1；因此节点按深度从小到大被弹出。第一次弹出叶子时，所有深度更小的节点都已弹出并确认不是叶子，所以不存在更浅的叶子。

**递归版的定义。** `f(node)` = 以 `node` 为根的子树里，从 `node` 到最近**叶子**的节点数。空树没有叶子，`f(None) = 0` 只是递归的边界值，不代表「这里有一个叶子」。

**`1 + min(左, 右)` 的错误。** 一个节点只有一个孩子时，空的那一侧返回 `0`，被 `min` 选中，等于把「没有孩子的那一侧」当成了一条通往叶子的路径，可那个节点本身并不是叶子。
- `[1,2]`：根有左孩子 `2`、没有右孩子。错误版本得到 `1 + min(1, 0) = 1`；正确是 `2`（唯一的叶子是 `2`）。
- `[2,null,3,null,4,null,5,null,6]`：根只有右孩子，左侧为空，错误版本得到 `1 + min(0, 右侧的值) = 1`；正确是 `5`。

**修法。** 只有一个孩子时只走那一侧：`if root.left is None: return 1 + f(root.right)`，右侧同理；两个孩子都在才取 `min`。最大深度没有这个问题，因为空孩子的 `0` 永远不会被 `max` 选中。
