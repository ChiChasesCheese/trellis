## Q
**补充题 9 36进制加法**｜Medium · CodeTop 国内累计 24 次 · 最近 2025-04-08（国内 CodeTop）

给两个非负的 36 进制数，用字符串 `num1`、`num2` 表示：`0`~`9` 表示 0 到 9，小写字母 `a`~`z` 表示 10 到 35，除 `"0"` 外没有前导零，`1 <= len(num1), len(num2) <= 10^4`。返回它们的和（同样是 36 进制字符串）。不能用内置的进制转换把整个数一次转成整数。例：`"zz" + "1"` → `"100"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「字符串表示的数」+「加法」+「长度到 `10^4`」→ **大数加法**：逐位模拟竖式，不转成整数。
- 「36 进制」→ 只改两处：字符与数值的映射（查表），以及进位的基数（`divmod(total, 36)`）；结构与十进制字符串相加（LC 415）完全相同。
- 「两个串长度不同」→ 双指针从末尾向前，短的用完后只处理另一个和进位。
- 「最后可能多出一位」→ 循环条件要包含 `carry`。

**推导链。**
1. 暴力：把两个串各转成整数，相加，再转回 36 进制字符串。在 Python 里 `int(s, 36)` 对超过 `4300` 位的串会抛 `ValueError`，而且面试官通常明确禁止。
2. 浪费：整数转换把"每一位独立"的结构抹掉了，反而变成了 `O(n^2)` 的大数运算。
3. 洞察：每一位的和 `≤ 35 + 35 + 1 = 71 < 72`，所以进位只有 `0` 或 `1`；`carry, digit = divmod(total, 36)` 一次得出进位和本位。
4. 数字从低位到高位产生，放进列表，最后反转并连接，`O(max(m, n))`。

**同模式的题**：LC 415 字符串相加、LC 67 二进制求和、LC 2 两数相加、LC 43 字符串相乘。
