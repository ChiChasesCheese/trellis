## Q
**LC 856 括号的分数**｜追问

面试官接着问：（1）能不能 `O(1)` 空间？（2）输入不保证平衡，要怎么处理？（3）字符串长到 `10^5`，分数会不会溢出？

## A
1. **`O(1)` 空间**：答案是所有 `()` 的 `2^外层层数` 之和，只需一个深度计数。遇到 `)` 先把深度减一，再看它前一个字符是不是 `(`；是，说明刚闭合了一个 `()`，加 `1 << depth`。

```python
def score_by_depth(s: str) -> int:
    ans = depth = 0
    for i, ch in enumerate(s):
        if ch == "(":
            depth += 1
        else:
            depth -= 1
            if s[i - 1] == "(":             # 只有紧挨着的 "()" 才贡献分数
                ans += 1 << depth           # 2 ** 它外面的括号层数
    return ans
```

   `"(()(()))"` → `6`，`"()()"` → `2`。
2. **不平衡输入**：扫描时 `depth` 变成负数就是多出右括号，结束时 `depth != 0` 就是多出左括号，直接返回 `-1` 或抛 `ValueError`。栈版本则看 `stack` 是否在弹出后变空、结束时是否只剩一格。
3. **超长字符串**：分数最大是 `2^(n/2 - 1)`，`n = 10^5` 时约 `2^49999`。Python 的 `int` 是任意精度，不会溢出，只是大数加法、移位的代价随位数增长；Java、C++ 题目通常会要求对某个数取模，每次累加后取模即可。

**Python 提醒**：`1 << depth` 与 `2 ** depth` 对整数结果相同，位移更直接地表达“乘以 2 的幂”。`s[i - 1]` 在 `i == 0` 时会读到最后一个字符，平衡串的第一个字符一定是 `(` 所以此处没问题，但对不平衡的输入会静默读错，处理第 (2) 问时要先校验。
