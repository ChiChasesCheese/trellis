## Q
**LC 442 数组中重复的数据**｜正确性

为什么「`nums[x − 1]` 为负」就等价于「`x` 之前出现过」？为什么读元素时必须取绝对值？不取绝对值会错在哪里？

## A
**不变量。** 在任意时刻，对每个值 `v ∈ [1, n]`：`nums[v − 1]` 为负，当且仅当 `v` 作为元素值已经被处理过一次。

**为什么成立。** 初始所有元素为正，没有记号。每个值 `v` 只会在读到它时翻转 `nums[v − 1]` 的符号，且只翻转一次（第二次读到 `v` 时是读取而不是翻转，因为它此时已是负数）。每个值最多出现两次，所以「第二次读到时记号位已是负数」恰好识别出所有重复值，一次都不会漏、也不会多报。

**为什么要 `abs`。** 被标记的位置，其元素值被取负了。遍历到这个位置时 `x` 是负数，`x − 1` 成了负下标，而 Python 的负下标合法，会悄悄访问列表尾部的元素，得到错误结果而不是异常。

**反例。** 去掉两处 `abs`：
- `[2,1,1]`，正确答案 `[1]`。读 `2`：`nums[1]` 取负变成 `-1`。下一个元素读到的是 `-1`，`i = -2`，`nums[-2]` 即 `nums[1] = -1` 为负，于是把 `-1` 当成重复值加入结果，输出 `[-1]`。
- `[4,3,2,7,8,2,3,1]`，正确 `[2,3]`；去掉 `abs` 得 `[-2,3]`。
- 保留 `abs`：第二个元素此时已被标成 `-1`，`abs(-1) − 1 = 0`，`nums[0] = 2` 为正，按值 `1` 的第一次出现处理并取负；第三个元素 `1` 读到 `nums[0]` 已是负数，识别为重复。返回 `[1]`，正确。

**为什么不会把两次出现的值多次上报。** 每个值最多两次，第三次读到的情形不存在，所以每个重复值只被加入结果一次。
