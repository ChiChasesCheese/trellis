## Q
**LC 112 路径总和**｜Easy · CodeTop 国内累计 47 次 · 最近 2026-04-14（国内 CodeTop）

给二叉树的根结点 `root` 和整数 `targetSum`，判断树中是否存在**根结点到叶子结点**的路径，使路径上所有结点值之和等于 `targetSum`。叶子结点是没有子结点的结点。

约束：结点数在 `[0, 5000]`，`-1000 <= Node.val <= 1000`，`-1000 <= targetSum <= 1000`。

例：`root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22` → `true`（`5→4→11→2`）；`root = [1,2,3], targetSum = 5` → `false`（两条路径和分别为 `3` 和 `4`）；`root = [], targetSum = 0` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**根到叶子**的路径」+「和等于目标」→ 树的 DFS，沿路径累计；叶子的定义（无左右孩子）是终止条件。
- 值可为负 → 不能用「超过目标就剪枝」；必须走到叶子才能判断。
- 「某条路径满足」= 「左子树或右子树里满足 `remain` 的子问题成立」→ 递归；结点数 `5000`、树可以退化成链，递归深度可达 `5000`，超过 Python 默认递归上限，面试里要说明，并给出显式栈的备选（见追问）。

**推导链。**
1. 暴力：枚举所有根到叶子的路径，逐条求和，`O(n·h)`。
2. 浪费：相邻路径共享前缀，前缀的和被重复计算。
3. 洞察：向下携带「还差多少」`remain`；到叶子只需检查 `remain == 0`，每个结点 `O(1)`。
4. 最优：递归 DFS，`remain` 作参数向下传，叶子处判断 `remain == 0`，非叶子用 `or` 合并左右，`O(n)` 时间、`O(h)` 空间。

**同模式的题**：LC 113 路径总和 II、LC 437 路径总和 III、LC 129 求根到叶子节点数字之和、LC 257 二叉树的所有路径、LC 124 二叉树中的最大路径和。
