## Q
**LC 781 森林中的兔子**｜正确性

为什么「回答值相同的兔子尽量同色、不同的一定不同色」就能得到最少的数量？为什么要向上取整、而且每组按满员 `x + 1` 计？

## A
**不变量。** 一只兔子回答 `x`，说明它所在的颜色组总共 `x + 1` 只。所以同色的兔子回答必然相同；回答不同的兔子必然不同色，各回答值的计数互相独立。对某个回答值 `x`，一个颜色组最多容纳 `x + 1` 只回答了 `x` 的兔子，`count` 只兔子至少要 `ceil(count / (x + 1))` 组；每一组无论实际被问到几只，这个颜色在森林里就有 `x + 1` 只。把这个下界逐组取到，而且可以构造（依次填满每组），所以它既是下界也是可达的最少值。

**反例（错误写法一）：每只兔子独占一组。** `[10,10,10]`：写成 `sum(x + 1 for x in answers)` 得到 `33`；三只回答 `10` 的兔子可以同色，共 `11` 只，正确是 `11`。

**反例（错误写法二）：向下取整。** `[1,1,1]`：`3 // 2 * 2 = 2`，只算了两只；第三只回答 `1` 的兔子装不进那一组，必须另开一组，共 `2 + 2 = 4`，正确是 `4`。

**反例（错误写法三）：忘了没被问到的同色兔子。** `[1,1,2]`：返回 `len(answers) = 3`；回答 `1` 的两只同色，回答 `2` 的那只所在颜色共 `3` 只，一共 `2 + 3 = 5`，正确是 `5`。
