## Q
**LC 18 四数之和**｜Medium · CodeTop 国内累计 14 次 · 最近 2026-06-17（CodeTop）

给由 `n` 个整数组成的数组 `nums` 和目标值 `target`，返回所有和为 `target` 且**不重复**的四元组 `[nums[a], nums[b], nums[c], nums[d]]`，要求 `a`、`b`、`c`、`d` 互不相同；两个四元组元素一一对应就算重复；答案顺序不限。`1 <= nums.length <= 200`，`-10^9 <= nums[i] <= 10^9`，`-10^9 <= target <= 10^9`。例：`nums = [1,0,-1,0,-2,2], target = 0` → `[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「找 k 个数使和为目标」+「结果不能重复」→ **排序 + 固定外层 + 双指针**（和三数之和同源），排序让相同值相邻，去重只需和前一个比较。
- `n <= 200` → `O(n^3)`（约 `8 * 10^6`）可以，`O(n^4)`（`1.6 * 10^9`）不行；出题人就是按 `n^3` 设的上限。
- 值域 `10^9`、`target` 也到 `10^9` → 不能用计数数组或桶，只能比较和双指针；Python 整数无溢出之忧。

**推导链。**
1. 暴力：四层循环枚举下标，把有序四元组放进集合去重，`O(n^4)`。
2. 浪费：最里面两层只是在找「和为定值的两个数」，却用 `O(n^2)` 去找。
3. 洞见：排序后这一问可以用对撞双指针 `O(n)` 解决；排序也让重复值相邻，去重变成「和前一个相同就跳过」。
4. 最优：两层循环固定前两个数（各自去重，并加上最小/最大和的剪枝），内层双指针，`O(n^3)`。

**同模式的题**：LC 1 两数之和、LC 15 三数之和、LC 16 最接近的三数之和、LC 454 四数相加 II。
