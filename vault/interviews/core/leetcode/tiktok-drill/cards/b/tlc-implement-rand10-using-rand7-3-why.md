## Q
**LC 470 用 Rand7() 实现 Rand10()**｜正确性

为什么丢掉 `41..49` 之后，剩下的 `1..40` 仍然是等概率的？为什么不能把 `41..49` 也直接取模折回去？给出不过滤直接取模的错误输出。

## A
**不变量。** 每一轮循环里，两次调用得到的有序对 `(a, b)` 是 `49` 个等概率结果，`idx = (a - 1) * 7 + b` 与它们一一对应，所以 `idx` 在 `1..49` 上均匀。「只保留 `idx <= 40`」是对这个均匀分布做条件化：每个保留格子的概率都是 `(1/49) / (40/49) = 1/40`，彼此仍然相等。每个结果 `r` 恰好对应 `4` 个格子（`r, r+10, r+20, r+30`），概率 `4/40 = 1/10`。重试之间相互独立，所以最终输出就是这个条件分布。

**反例：不过滤直接取模。** 把 `if idx <= 40` 去掉，直接返回 `(idx - 1) % 10 + 1`：

- `1..49` 里，结果 `1..9` 各对应 `5` 个格子（比如结果 `1` 对应 `idx = 1, 11, 21, 31, 41`），结果 `10` 只对应 `4` 个格子（`10, 20, 30, 40`）。
- 所以 `P(10) = 4/49 ≈ 0.082`，其余每个值是 `5/49 ≈ 0.102`。正确的概率处处是 `0.1`。

问题的根子是：`49` 不能被 `10` 整除，多出来的 `9` 个格子必须作为一个整体丢弃，而不是折回前面的结果。折回去等于给 `1..9` 多发了一份票。

**推论。** 想让丢弃最少，保留的格子数必须是目标范围大小的最大整数倍：`49 - 49 % 10 = 40`。
