## Q
**LC 242 有效的字母异位词**｜Easy · CodeTop 国内累计 6 次 · 最近 2026-04-16（国内 CodeTop）

判断字符串 `t` 是否是 `s` 的字母异位词（字符种类和每种字符的次数都相同，顺序可不同）。`1 <= s.length, t.length <= 5 * 10^4`，只含小写字母；进阶：含 Unicode 字符时怎么办？例：`"anagram", "nagaram"` → `true`，`"rat", "car"` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「次数相同、顺序无关」→ 比较两个**多重集**（multiset）→ **计数**：哈希表或固定大小数组。
- 「只含小写字母」→ 26 格数组可行，常数最小；「Unicode 进阶」→ 字典计数，与字符集大小无关。
- `n` 到 `5 * 10^4` → `O(n log n)` 排序也能过，`O(n)` 计数更好。

**推导链。**
1. 暴力：`t` 的每个字符到 `s` 里找一个没用过的同字符，`O(n^2)`。
2. 排序后比较 `sorted(s) == sorted(t)`：`O(n log n)`，正确但多做了「排好序」这件不需要的事。
3. 关键：只需要每种字符的次数。一张表，`s` 加一、`t` 减一。
4. 先比长度，再在减的过程中遇到负数就提前返回，`O(n)` 时间、`O(Σ)` 空间。

**同模式的题**：LC 49（异位词分组）、LC 438（找所有异位词子串）、LC 567（字符串的排列）、LC 383（赎金信）。
