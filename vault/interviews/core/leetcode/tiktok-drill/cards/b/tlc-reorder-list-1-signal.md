## Q
**LC 143 重排链表**｜Medium · LC TikTok 热度 62/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 91 次 · 最近 2026-07-21（国内面试记录）

给单链表 `L` 的头节点 `head`，表示为 `L0 → L1 → … → Ln-1 → Ln`。把它重排成 `L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …`。不能只改节点里的值，必须真正地交换节点。链表长度在 `[1, 5 * 10^4]` 内，`1 <= node.val <= 1000`。例：`head = [1,2,3,4,5]` → `[1,5,2,4,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「头、尾、头、尾」交替 → 要从**尾部往前**取节点；单链表不能倒着走 → 把**后半段翻转**，让「从尾往前」变成「从头往后」。
- 「不能只改值，要交换节点」→ 只允许改 `next` 指针，原地操作，`O(1)` 空间。
- 链表题的**组合拳**：找中点（快慢指针）+ 翻转链表 + 交替合并，三个基本操作串起来。
- 长度到 `5 * 10^4`：递归深度会超过 Python 默认上限 1000，用迭代。

**推导链。**
1. 暴力：所有节点放进数组，左右下标交替连接。`O(n)` 时间，`O(n)` 额外空间。
2. 浪费：数组只是为了「倒着读后半段」，而翻转后半段就能做到，不用数组。
3. 洞察：快慢指针找到中点，在中点处**断开**（否则前半段尾巴仍连着后半段，翻转后会成环）；翻转后半段；两段交替拼接。
4. 最优：三次线性扫描，`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 876 链表的中间结点、LC 206 反转链表、LC 234 回文链表、LC 148 排序链表（找中点后合并）。
