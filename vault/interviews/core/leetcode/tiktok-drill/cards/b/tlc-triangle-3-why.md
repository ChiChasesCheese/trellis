## Q
**LC 120 三角形最小路径和**｜正确性

为什么自底向上的 DP 是对的，而"每步选下一行里较小的那个"的贪心是错的？给出让贪心出错的具体输入。

## A
**不变量。** 填完第 `i` 行后，`dp[i][j]` 是"从格子 `(i, j)` 出发，走到最底行的最小路径和"，第 `i` 行以下的所有行都已填好。

**为什么对。** 从格子 `(i, j)` 出发只能进入 `(i+1, j)` 或 `(i+1, j+1)`，之后的选择与怎么到达 `(i, j)` 无关（无后效性），所以从 `(i, j)` 出发的最优值是 `triangle[i][j]` 加上两个后继的最优值中较小的那个。最优子结构成立，自底向上逐行计算，第 `i` 行的值只用到第 `i+1` 行已算好的结果。

**为什么贪心错。** 局部较小的下一格，不代表它通向的后续路径更好：为了拿到一个很小的数，可能被锁进一条后面都很大的路线；而较大的一格后面可能有极小的数。

**反例。** `triangle = [[-1],[2,3],[1,-1,-3]]`：
- 贪心：从 `-1` 出发，下一行选较小的 `2`；`2` 的后继是 `1` 和 `-1`，选 `-1`。路径和 `-1 + 2 + (-1) = 0`。
- 最优：`-1 → 3 → -3`，路径和 `-1 + 3 + (-3) = -1`。
- 自底向上 DP：基础行 `dp[2] = [1,-1,-3]`，填第 `1` 行得 `dp[1] = [2 + min(1,-1), 3 + min(-1,-3)] = [1, 0]`，填顶行得 `dp[0][0] = -1 + min(1, 0) = -1`。

**基础行。** 递推从最底行开始，最底行没有后继，`dp[n-1][j]` 必须直接等于 `triangle[n-1][j]`。若建表后忘了给它赋值，最底行全是 `0`，`[[2],[3,4],[6,5,7],[4,1,8,3]]` 填出 `dp[0][0] = 10`，正确是 `11`（路径 `2 → 3 → 5 → 1` 少加了最后的 `1`）。

**边界。** 自底向上时，每个格子 `j` 恰好有后继 `j` 和 `j + 1`，下一行比当前行多一个元素，不会越界；自顶向下时每行两端只有一个前驱，需要特判，容易写出 `dp[i - 1][j - 1]` 在 `j = 0` 时取到 `dp[i - 1][-1]`（Python 的负下标不会报错而是回绕）。
