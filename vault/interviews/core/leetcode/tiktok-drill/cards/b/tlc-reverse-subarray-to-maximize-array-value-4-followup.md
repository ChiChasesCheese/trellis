## Q
**LC 1330 翻转子数组得到最大的数组值**｜Hard · 字节高频｜追问

面试官接着问：（1）返回具体的翻转区间 `(l, r)`？（2）不用几何，怎么系统地把绝对值拆开推出这个公式？（3）`n` 到 `10^6`？

## A
1. **返回区间**：中间情形记录取到最大左端点的线段下标 `q` 和取到最小右端点的线段下标 `p`，翻转 `[min(p, q) + 1, max(p, q)]`（线段 `i` 是 `(nums[i], nums[i+1])`）；贴端情形记录取到最大值的 `i`，翻转 `[0, i - 1]` 或 `[i, n - 1]`。三种情形里哪个增益最大，就返回哪个区间；增益为 `0` 就是不翻转。
2. **拆绝对值**：`|x| = max(x, -x)`。增益里两个带正号的绝对值各有两种符号，共 4 种组合，每种组合都能写成「只含 `i` 的部分」加「只含 `j` 的部分」。两种异号组合最多为 `0`；两种同号组合化简后恰好是 `2 * (lo_i - hi_j)` 和 `2 * (lo_j - hi_i)`。对 `j` 扫描时维护前面所有 `i` 的最值即可，`O(n)`。这是「配对的绝对值之和」一类题的通用手法。
3. **`n = 10^6`**：本解法已经是 `O(n)` 时间、`O(1)` 空间，只要保证 `pairwise` 的几趟扫描不建中间列表；唯一的限制是 Python 循环的常数。

**Python 提醒**：`pairwise` 返回迭代器，只能遍历一次；本解法为 `total`、`lo`、`hi` 各创建一个新的 `pairwise(nums)`，不要把同一个迭代器复用三次，第二次开始它已经是空的。
