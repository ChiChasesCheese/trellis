## Q
**LC 1405 最长快乐字符串**｜追问

面试官接着问：（1）推广到 `k` 种字母、每种最多连续 `r` 个？（2）只要最长长度，能不能 `O(1)` 算出来？（3）改成相邻字符必须不同（LC 767）？

## A
1. **`k` 种、上限 `r`**：堆里放 `k` 种；判断「末尾是否连续 `r` 个同一字母」，是就改取次多的。每步 `O(log k)`，总 `O(N log k)`。注意上限 `r = 1` 就是相邻不同的情形。
2. **只要长度**：设三个数从大到小为 `x ≥ y ≥ z`。最大的字母每放 2 个需要 1 个别的字母来隔，可隔数量最多是 `y + z`；于是它最多放 `min(x, 2(y + z + 1))`。总长 = `min(x, 2(y + z + 1)) + y + z`。例 `1,1,7`：`x=7, y=1, z=1`：`min(7, 6) + 2 = 8`。面试里可以用它检查堆的答案。
3. **相邻不同（LC 767）**：每步取最多的字母，但不能与末尾相同；若最多的字母个数超过 `⌈N/2⌉` 则无解。堆做法与此处相同，上限变成 `1`。

**Python 提醒**：`heapq` 没有最大堆，惯例是存相反数；元组 `(-n, ch)` 在 `n` 相同时比较 `ch`，字母都是 `str` 所以安全，但若第二项是不可比较的对象（例如结点）会在并列时抛 `TypeError`，要加一个递增的序号当第二项。
