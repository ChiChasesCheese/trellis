## Q
**LC 112 路径总和**｜正确性

为什么叶子上才能判断 `remain == 0`？为什么值可能为负时不能用 `remain < 0` 剪枝？

## A
**不变量。** 弹出 `(node, remain)` 时，`remain = target_sum - (根到 node 的路径上所有结点值之和)`，包括 `node` 自己。

**为什么只看叶子。** 题目要求的是「根到叶子」的完整路径；路径在非叶子结点处还可以继续向下，所以那里凑够目标并不是一条合法路径。

**为什么不能剪枝。** 值在 `[-1000, 1000]`，后面的结点可以是负数把和拉回来：当前 `remain` 为负，下面的负数结点会让 `remain` 重新变成 `0`。剪枝只在全部值非负时才成立。

**反例。**
- 不检查叶子：`root = [1, 2]`, `targetSum = 1`。根结点值就是 `1`，不检查叶子会返回 `true`；根有孩子，唯一的根到叶子路径 `1→2` 和为 `3`，正确是 `false`。
- 负数剪枝：`root = [-2, null, -3]`, `targetSum = -5`。根处 `remain = -3 < 0`，被剪掉，返回 `false`；正确路径 `-2 → -3` 和为 `-5`，应为 `true`。
