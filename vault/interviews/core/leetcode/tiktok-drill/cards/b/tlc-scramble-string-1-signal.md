## Q
**LC 87 扰乱字符串**｜Hard · CodeTop 国内累计 2 次 · 最近 2026-05-29（CodeTop）

扰乱算法：长度为 1 时停止；长度大于 1 时，在某个位置把字符串切成两个非空子串 `x`、`y`（`s = x + y`），随机决定保持 `x + y` 或交换成 `y + x`，再对 `x`、`y` 分别递归执行。给两个长度相等的字符串 `s1`、`s2`，判断 `s2` 能否由 `s1` 扰乱得到。`s1.length == s2.length`，`1 <= s1.length <= 30`，只含小写字母。 例：`s1 = "great", s2 = "rgeat"` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「切成两段、可交换、再对两段**递归**」→ 过程是一棵二叉树，原问题拆成两个同类的更短子问题 → **区间 DP / 记忆化搜索**。
- 子问题「`s1` 的一段能否扰乱成 `s2` 的一段」由 `(i, j, L)` 三个数决定 → 状态 `O(n^3)`。
- `n <= 30` → `O(n^4)` 约 `8 * 10^5`，可以；指数级的枚举不行。
- 扰乱不改变字符的多重集 → 计数不同可立即判否，是天然的剪枝。

**推导链。**
1. 暴力：生成 `s1` 的所有扰乱结果再查 `s2`，数量指数级。
2. 改成判定：枚举 `s1` 第一刀的位置 `k`；不交换时 `s2` 也在 `k` 处对应，交换时 `s2` 在 `L - k` 处对应。
3. 浪费：同一对子串 `(i, j, L)` 会在不同的切法里反复出现 → `@cache` 记忆化，每个状态只算一次。
4. 加上计数剪枝，`O(n^3)` 个状态 × `O(n)` 次切分 = `O(n^4)`。
