## Q
**LC 125 验证回文串**｜Easy · CodeTop 国内累计 14 次 · 最近 2026-04-25（CodeTop）

把所有大写字母转成小写、并移除所有非字母数字字符之后，字符串正着读和反着读都一样，就称它是回文串（空串也算）。给字符串 `s`，判断它是不是回文串。`1 <= s.length <= 2 * 10^5`，`s` 只由可打印的 ASCII 字符组成。例：`"race a car"` → `false`（清洗后是 `"raceacar"`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「正着读 = 反着读」→ 回文判定，用**两端向中间的双指针**：第 `i` 个对倒数第 `i` 个。
- 「忽略大小写、忽略非字母数字」是**预处理条件**，不改变回文的判定方式；可以在指针移动中就地处理，省掉清洗后的新串。
- `n` 到 `2 * 10^5` → 需要 `O(n)`；任何 `O(n^2)` 的枚举都不行（本来也不需要枚举）。

**推导链。**
1. 暴力：清洗成新串 `t`，比较 `t == t[::-1]`。`O(n)` 时间，但清洗和反转各多一份 `O(n)` 的拷贝。
2. 浪费：回文只需要两端逐对比较，不需要真的构造反转串。
3. 洞察：左右指针各自跳过无效字符，在**有效字符**上逐对比较。
4. 最优：每个下标最多被访问一次，`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 680 验证回文串 II、LC 5 最长回文子串、LC 234 回文链表、LC 9 回文数。
