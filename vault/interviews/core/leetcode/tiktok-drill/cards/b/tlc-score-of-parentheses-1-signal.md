## Q
**LC 856 括号的分数**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 2 次 · 最近 2025-09-18（国内 CodeTop）

给平衡括号字符串 `S`，按规则计分：`()` 得 `1` 分；`AB` 得 `A + B` 分；`(A)` 得 `2 * A` 分，其中 `A`、`B` 都是平衡括号字符串。返回 `S` 的分数。`S` 只含 `(` 和 `)` 且平衡，`2 <= S.length <= 50`。例：`"(())"` → `2`，`"()()"` → `2`，`"(()(()))"` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 括号嵌套 + 「按层结算」→ 栈（stack）：每遇到 `(` 开一层，遇到 `)` 结算一层并交给外层。
- 规则本身是递归定义（`(A) = 2A`，`AB = A + B`）→ 用栈把递归展开成一遍扫描。
- `S.length <= 50` → 不是复杂度题，考的是把文法翻成状态更新；答案最大 `2^24`，不会溢出。
- 「`AB` 相加、`(A)` 翻倍」→ 加法对应同一层里并列的部分，翻倍对应外面多包一层。

**推导链。**
1. 暴力：递归，找到第一个匹配的右括号把 `S` 拆成 `A`、`B`，或剥掉最外层，`O(n^2)`。
2. 浪费：每次拆分都重新扫描找匹配位置。
3. 洞察一：一遍扫描，栈里每一格是“这一层已累计的分数”；`)` 闭合时内层的值 `v` 已定，`v == 0` 是 `()` 得 `1`，否则得 `2v`，加到外层。
4. 洞察二：每个 `()` 的贡献等于 `2^(外面包的层数)`，答案是所有 `()` 贡献之和，只需要一个深度计数，`O(1)` 空间。
