## Q
**LC 1360 日期之间隔几天**｜Easy · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-02-21（美国面试记录）

编写程序计算两个日期之间隔了多少天。日期格式 `YYYY-MM-DD`，保证在 `1971` 年到 `2100` 年之间且有效。例：`date1 = "2020-01-15"`，`date2 = "2019-12-31"` → `15`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个日期相差几天」→ 统一换算成**绝对天数**（距固定起点的天数），再整数相减。
- 日期范围 `1971` 到 `2100` 很窄 → 逐年累加天数就足够快；同时范围包含 `2100`，它不是闰年，是**闰年规则**的考点（4 年一闰，100 年不闰，400 年又闰）。
- 输入是字符串 → 先 `split("-")` 再转 `int`。
- 日期顺序不固定 → 结果取绝对值。

**推导链。**
1. 暴力：从较早的日期开始逐日往后走，直到到达较晚日期，约 `47000` 步，可行但进位逻辑繁琐。
2. 换算：天数 = 整年天数（每年 `365` 或 `366`）+ 当年整月天数（闰年 `2` 月多一天）+ 日。
3. 两个日期各换算一次，`abs` 相减。
4. 闰年判断必须写全：能被 `4` 整除，且（不能被 `100` 整除，或者能被 `400` 整除）。

**同模式的题**：LC 1154 一年中的第几天、LC 1185 一周中的第几天、LC 2409 统计共同度过的日子数、LC 1118 一月有多少天。
