## Q
**LC 230 二叉搜索树中第 K 小的元素**｜正确性

为什么递归中序里「数当前节点」的顺序就是升序？计数如果放在「进入节点时」而不是「左子树返回之后」会错在哪里？给出具体输出。

## A
**不变量。** 轮到数节点 `x` 时，所有比它小的节点都已经被数过。理由：BST 满足「左子树所有值 < 根 < 右子树所有值」。数 `x` 之前，`dfs(x.left)` 已经返回，左子树里的节点（都比 `x` 小）全部数完；`x` 的祖先中值比 `x` 小的，是那些「`x` 在其右子树里」的祖先，它们在进入右子树之前就已经被数过。计数顺序因此严格升序，第 `k` 次计数就是第 `k` 小。

**为什么能提前停。** 前 `k` 次计数已经确定了答案；找到后每一层都直接返回，后面的节点不会影响结果。

**反例 1：进入节点时计数。** 树 `[5,3,6,2,4,null,null,1]`，`k = 3`。
- 如果先 `k -= 1` 再 `dfs(node.left)`，计数顺序是 `5, 3, 2, 1`，第 `3` 个数到的节点是 `2`。
- 输出 `2`，正确答案是 `3`（升序为 `1, 2, 3, 4, 5, 6`）。
- 这样数出来的是「先序」位置，只有左子树返回之后再计数才是中序。

**反例 2：先序后取第 `k` 个。** 同一棵树的先序是 `5, 3, 2, 1, 4, 6`，第 `3` 个也是 `2`，错。
