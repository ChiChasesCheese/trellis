## Q
**一个骰子掷出更大点数的概率**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-04（面试记录）

两个公平的骰子 `A`、`B`，各有若干个面，每面写一个整数（面数可以不同，数字可以重复）。各掷一次，求 `A` 的点数严格大于 `B` 的概率（精确分数）。`1 <= 面数 <= 10^5`，面上的数在 `[-10^9, 10^9]`。例：`A = [2,2,6]`，`B = [1,5,5]` → `5/9`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「公平骰子各掷一次」→ `p·q` 种组合等可能，概率 = **满足 `a > b` 的数对个数** / `p·q`，变成计数题。
- 面数 `10^5` → 数对有 `10^10`，不能逐对比较。
- 「对每个 `a` 数有多少 `b < a`」→ **排序 + 二分**（`bisect_left`），或两边都排序后**双指针**。
- 「精确的分数」→ 用 `Fraction` 或返回分子分母，不用浮点。

**推导链。**
1. 暴力：双重循环逐对比较，`O(pq)`，最坏 `10^10`。
2. 浪费：每个 `a` 都把 `B` 整个扫一遍；而「`B` 中小于 `a` 的个数」只取决于 `a` 在有序 `B` 里的插入位置。
3. 洞察：`B` 排序一次，`bisect_left(sorted_b, a)` 正好等于严格小于 `a` 的个数，`O(log q)`。
4. 最优：对 `A` 每一面二分并求和，`O((p + q) log q)`；或 `A` 也排序，分界点只右移，扫描部分 `O(p + q)`。

**同模式的题**：LC 2300 咒语和药水的成功对数、LC 2563 统计公平数对的数目、LC 1855 下标对中的最大距离、LC 315 计算右侧小于当前元素的个数。
