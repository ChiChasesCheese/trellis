## Q
**LC 3161 物块放置查询**｜Hard · LC TikTok 热度 88/100（近 3 个月）

数轴从原点 `0` 起沿正方向无限延伸。给二维数组 `queries`，有两种操作：`[1, x]` 在距离原点 `x` 处建一个障碍物（保证此处原本没有）；`[2, x, sz]` 判断能否在 `[0, x]` 内完整放下一个长度为 `sz` 的物块，不能与障碍物重合，可以恰好接触，只询问不放置，查询相互独立。返回每个类型 2 操作的布尔结果。`1 <= queries.length <= 15 * 10^4`，`1 <= x, sz <= min(5 * 10^4, 3 * queries.length)`，至少有一个类型 2 操作。例：`[[1,2],[2,3,3],[2,3,1],[2,2,2]]` → `[false,true,true]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 修改（建障碍物）和查询（能否放下）**交替**出现，`q` 到 `1.5 * 10^5` → 需要每次操作 `O(log)` 的**数据结构**。
- 「`[0, x]` 内最大的空隙」→ **区间（前缀）最大值**：线段树或树状数组；空隙是由相邻障碍物决定的。
- 「`x` 左边最近的障碍物」→ **有序集合的前驱 / 后继**；Python 没有，用有序列表加 `bisect`。
- 坐标不超过 `5 * 10^4` → 坐标可直接当下标，不用离散化。

**推导链。**
1. 暴力：每个查询扫 `[0, x]` 内所有障碍物，找最大空隙，`O(q · k)`，最坏约 `7.5 * 10^9`。
2. 观察一：空隙只取决于相邻两个障碍物。插入 `x` 只让一个空隙裂成两个，只有两个值变化：`x` 的左空隙（新建）和后继的左空隙（变小）。
3. 观察二：查询只看 `[0, x]`。`x` 以左的完整空隙不受 `x` 影响，只有最后一段 `[p, x]`（`p` 是 `x` 左边最近的障碍物）被截短，单独算 `x - p`。
4. 最优：把「障碍物 `p` 的左空隙」存在线段树的位置 `p` 上，查询是前缀最大值 `max(query(0..p), x - p) >= sz`，每个操作 `O(log M)`。
