## Q
**LC 921 使括号有效的最少添加**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-19（美国面试记录）

括号字符串有效：空串，或 `AB`（`A`、`B` 有效），或 `(A)`（`A` 有效）。给只含 `'('` 和 `')'` 的字符串 `s`，每次可在任意位置插入一个括号，返回使 `s` 有效的最少插入次数。`1 <= s.length <= 1000`。例：`"())"` → `1`；`"((("` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号匹配」+「最少操作」→ **栈 / 计数器**扫描；只有一种括号时，栈里全是 `(`，栈深就够了，可以用一个整数代替。
- 「任意位置插入」→ 没匹配上的 `)` 可以在它前面补 `(`，没匹配上的 `(` 可以在它后面补 `)`，两类互不干扰，各自计数。
- `n <= 1000` → 线性扫描就够，不必搜索。

**推导链。**
1. 暴力：BFS 枚举每次插入一个括号后的所有字符串，直到出现有效串，指数级。
2. 贪心匹配：能配对的括号一定配对，不会更差；剩下的没有配上的括号，每一个必须独立补一个。
3. 用栈做：遇 `(` 入栈，遇 `)` 若栈非空则出栈，栈空则计一个无法匹配的 `)`；扫完栈里剩的 `(` 也是无法匹配的。
4. 栈里只有 `(`，所以只需 `open_cnt`：`(` 加一；`)` 时有就减一，没有就 `add += 1`。答案 `add + open_cnt`，`O(n)`、`O(1)`。

**同模式的题**：LC 20 有效的括号、LC 32 最长有效括号、LC 678 有效的括号字符串、LC 1249 移除无效的括号。
