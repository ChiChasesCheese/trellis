## Q
**LC 1247 交换字符使得字符串相同**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2025-11-20（美国面试记录）

两个长度相同的字符串 `s1`、`s2`，只含 `'x'` 和 `'y'`。每次可以交换 `s1[i]` 与 `s2[j]`（必须来自不同的字符串，不能交换同一个字符串内部的字符）。返回使两串相同的最少交换次数，不可能则返回 `-1`。`1 <= s1.length, s2.length <= 1000`，`s1.length == s2.length`。例：`s1 = "xy"`，`s2 = "yx"` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「只含两种字符」+「求最少交换」→ 不模拟交换，对**不匹配位置分类计数**，再用组合规则算次数（计数 + 贪心配对）。
- 限制「只能在两个字符串之间交换」→ 这是和"随意交换"的最大区别，决定了异类配对要多花一次。
- 「做不到返回 `-1`」→ 先看守恒量：每个不匹配位置恰有一个 `x`，`x` 的总数必须是偶数才可能让两串的 `x` 个数相等。

**推导链。**
1. 暴力：BFS 搜索所有可能的交换，状态是一对字符串，指数级。
2. 观察：两串相同的位置不用动；不匹配的位置只有两类：`xy`（`s1` 是 `x`，`s2` 是 `y`）和 `yx`。
3. 两个同类位置 `i`、`j`：交换 `s1[i]` 与 `s2[j]`，一次修好两个位置。
4. 剩下的只可能是一个 `xy` 加一个 `yx`：先交换其中一个位置的 `s1[i]` 与 `s2[i]`，把它变成另一类，再用一次同类配对，共 `2` 次。
5. 不匹配位置总数为奇数则无解。答案 `xy // 2 + yx // 2 + 2 * (xy % 2)`。

**同模式的题**：LC 1790 仅执行一次字符串交换能否使两个字符串相等、LC 854 相似度为 K 的字符串、LC 2193 得到回文串的最少操作次数、LC 1963 使字符串平衡的最小交换次数。
