## Q
**长度至少为 2 的子数组，最大化 min + max**｜Easy · 近一年被问：美国 1 次、国内 0 次 · 最近 2025-11-26（面试记录）

给 `n` 个正整数的数组 `nums`，找长度至少为 `2` 的连续子数组，使该子数组的最小值与最大值之和最大，返回这个和。`2 <= n <= 10^5`，`1 <= nums[i] <= 10^9`。先写暴力，再要求线性时间。例：`[5, 12, 9, 6, 4]` → `21`（子数组 `[12, 9]`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子数组 + `min` + `max`」→ 先怀疑单调队列 / 滑动窗口，但目标不是「窗口内满足约束的最长」，而是一个简单表达式的最大值：先找结构性质。
- 「长度至少为 `2`」→ 下界恰好是最小的合法长度，通常意味着最优解可以缩到这个下界。
- 「先写暴力、再要求线性」→ 暗示最终答案有很简单的形式。
- `n = 10^5`：`O(n^2)` 的滚动暴力超时，必须线性。

**推导链。**
1. 暴力：枚举每个子数组再求 `min`、`max`，`O(n^3)`。
2. 滚动维护：固定左端点向右扩，边扩边更新最小、最大，`O(n^2)`。
3. 观察：窗口变大时 `max` 变大、`min` 变小，两项相互抵消，没有明显的单调性可用。
4. 洞察：子数组里最大值所在位置一定有邻居（长度至少为 `2`），邻居不小于子数组的最小值，所以这个子数组的 `min + max` 不超过「最大值加邻居」，而这一对相邻元素本身就是合法子数组。
5. 最优：答案是所有相邻对之和的最大值，一遍扫描，`O(n)`。

**同模式的题**：LC 53 最大子数组和、LC 907 子数组的最小值之和、LC 2104 子数组范围和、LC 239 滑动窗口最大值。
