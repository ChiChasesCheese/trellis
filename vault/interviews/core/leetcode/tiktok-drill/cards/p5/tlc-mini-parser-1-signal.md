## Q
**LC 385 迷你语法分析器**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-02-27（面试记录）

给字符串 `s`，表示整数的嵌套列表，解析并返回 `NestedInteger`（`NestedInteger()` 是空列表，`NestedInteger(v)` 是单个整数，`add(x)` 追加元素）。`1 <= s.length <= 5 * 10^4`，`s` 只含数字、`[`、`]`、`-`、`,`，保证可解析，数值在 `[-10^6, 10^6]`。例：`"[123,[456,[789]]]"` → 含 `123` 和 `[456,[789]]` 两个元素的列表。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号嵌套的字符串 → 结构」→ 结构本身是递归定义的（元素 = 整数，或 `[` 加若干元素加 `]`），最直觉的是**递归下降**；备选是栈：遇到 `[` 开新层，遇到 `]` 收一层。
- `s.length` 到 `5 * 10^4` → `O(n)` 解析；嵌套最深约 `25000` 层，递归下降在 Python 里会超过默认递归上限，面试里要说出来，并给出显式栈的备选（见追问）。
- 含多位数和负号 → 数字要整体作为一个记号，不能逐字符当数字，**先分词再解析**。

**推导链。**
1. 朴素：逐字符扫描，自己拼多位数、处理负号，容易出错。
2. 洞察一：先用正则分词 `re.findall(r"\[|\]|-?\d+", s)`，整数（含负号）成为一个整体记号，只剩 `[`、`]`、整数三种。
3. 洞察二：递归下降。`parse(tok)` 遇到整数直接返回，遇到 `[` 就新建列表，循环读后续记号交给 `parse`，读到 `]` 结束；记号放进一个共享迭代器，每层自然接着读，`O(n)`。
4. 问题：递归深度等于括号嵌套层数，最坏 `25000`，超过默认深度 `1000`；备选是显式栈：栈顶永远是「正在填的列表」，`[` 压入新列表，整数 `add` 进栈顶，`]` 弹出并 `add` 进新的栈顶。
