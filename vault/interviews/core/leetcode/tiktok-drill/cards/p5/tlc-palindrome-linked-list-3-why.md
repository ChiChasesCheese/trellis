## Q
**LC 234 回文链表**｜正确性

偶数和奇数长度时，快慢指针结束后 `slow` 分别停在哪里？为什么从 `slow` 开始反转、比较时以后半段为准是对的？如果从 `slow.next` 开始反转会错在哪里？给出具体输入。

## A
**不变量。** 循环结束时，`slow` 前面的节点个数等于 `⌊n/2⌋`。偶数 `n = 2k`：`slow` 是第 `k + 1` 个节点，后半段正好 `k` 个；奇数 `n = 2k + 1`：`slow` 是正中间第 `k + 1` 个节点，后半段（含中间）`k + 1` 个。

**为什么对。** 回文等价于第 `i` 个节点等于倒数第 `i` 个节点，`i = 1..⌊n/2⌋`。反转 `slow` 起的后半段后，`right` 依次是倒数第 `1, 2, …` 个节点，`left` 依次是第 `1, 2, …` 个节点，成对比较。奇数长度时后半段多出的中间节点排在 `right` 的最后一个，它的"对手"是 `left` 走到的中间节点自己（前半段最后一个节点的 `next` 仍指向它），自己等于自己，不影响结果。所以只要 `right` 走完，所有成对关系都比较过了。

**反例：从 `slow.next` 开始反转。** 输入 `[1,2,3,1]`（偶数长度）：
- 快慢指针结束时 `slow` 在第 `3` 个节点（值 `3`）。
- 从 `slow.next` 开始反转，后半段只剩 `[1]`，只比较了第一对 `1 == 1`。
- 输出 `True`，正确是 `False`（`2` 和 `3` 没有被比较）。
- 从 `slow` 开始反转得到 `[1, 3]`，第二对 `2 != 3`，输出 `False`。

**反例：忘记还原。** 不还原时，前半段的最后一个节点仍然指向原来的中点，而中点现在是反转后那条链的尾巴，它的 `next` 是空：从 `head` 遍历会在中点处提前结束，后半段全部丢失。
