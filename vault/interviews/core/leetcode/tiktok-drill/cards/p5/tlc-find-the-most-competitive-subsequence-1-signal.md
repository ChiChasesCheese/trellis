## Q
**LC 1673 找出最具竞争力的子序列**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-10-12（CodeTop）

给整数数组 `nums` 和正整数 `k`，返回长度为 `k` 且最**具竞争力**的 `nums` 子序列（子序列 = 删去若干元素、保持相对次序）。在两个等长子序列 `a`、`b` 第一个不同的位置上，若 `a` 的数更小，则 `a` 比 `b` 更具竞争力（即字典序最小）。

约束：`1 <= nums.length <= 10^5`，`0 <= nums[i] <= 10^9`，`1 <= k <= nums.length`。

例：`nums = [3,5,2,6], k = 2` → `[2,6]`；`nums = [2,4,3,3,5,4,9,6], k = 4` → `[2,3,3,4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子序列」+「字典序最小」→ 前面的位置权重大，应让靠前的数尽可能小；贪心从左到右，想用后来的小数顶掉前面的大数。
- 「固定长度 `k`」→ 一共要丢掉 `n - k` 个元素，丢弃有**额度**；这是单调栈的限制条件。
- `n = 10^5` → 需要 `O(n)`；每个元素入栈一次出栈一次，摊还线性，是单调栈的典型规模。

**推导链。**
1. 暴力：枚举所有 `C(n, k)` 个子序列，取字典序最小，不可行。
2. 贪心：第一位只能在 `nums[0..n-k]` 中选最小（最左的），然后在其右侧重复，每步 `O(n)`，总 `O(nk)`。
3. 洞察：所有这些选择可以合成一次扫描——新来的 `x` 比栈顶小，就把栈顶换掉（前提是丢弃额度还有）。
4. 最优：单调栈 + 额度 `drop = n - k`；扫完后取栈的前 `k` 个，`O(n)`。
