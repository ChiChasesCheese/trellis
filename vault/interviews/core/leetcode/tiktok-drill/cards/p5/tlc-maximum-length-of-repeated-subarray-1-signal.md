## Q
**LC 718 最长重复子数组**｜Medium · CodeTop 国内累计 26 次 · 最近 2026-09-11（CodeTop）

给两个整数数组 `nums1` 和 `nums2`，返回两个数组中公共的、长度最长的**子数组**（必须连续）的长度。`1 <= nums1.length, nums2.length <= 1000`，`0 <= nums1[i], nums2[i] <= 100`。例：`nums1 = [1,2,3,2,1]`、`nums2 = [3,2,1,4,7]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个序列」+「公共」→ **二维 DP**，状态是两个下标 `(i, j)`。
- 「子数组（连续）」→ 状态必须是"**以** `i`、`j` **结尾**"，而不是"前 `i`、前 `j` 个里的最优"；不匹配就清零，匹配才在左上角基础上加一。
- 对比「子序列」（可以跳过元素，LC 1143）：用 `max(dp[i-1][j], dp[i][j-1])`；一字之差，转移完全不同。
- `m, n <= 1000`：`O(m·n) = 10^6` 个状态正好；`O(m·n·min(m, n))` 的暴力 `10^9` 不行。

**推导链。**
1. 暴力：枚举 `(i, j)` 为起点，向后比较直到不等，最坏 `O(m·n·min(m, n))`。
2. 浪费：从 `(i, j)` 起的比较里重复包含 `(i+1, j+1)` 起的比较。
3. 洞察：`dp[i][j]` = 以 `nums1[i-1]`、`nums2[j-1]` 结尾的公共后缀长度；相等则 `dp[i-1][j-1] + 1`，不等则 `0`。
4. 第 `0` 行和第 `0` 列是空前缀，全为 `0`；逐行填表，答案是所有 `dp` 的最大值，时间和空间都是 `O(m·n)`。
