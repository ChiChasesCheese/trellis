## Q
**LC 508 出现次数最多的子树元素和**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-11（面试记录）

给二叉树的根结点 `root`，返回出现次数最多的**子树元素和**，并列最多的全部返回（顺序不限）。子树元素和是以某个结点为根的子树里所有结点（含自己）的值之和。节点数在 `[1, 10^4]`，`-10^5 <= Node.val <= 10^5`。例：`root = [5,2,-5]` → `[2]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子树的和」→ **后序遍历**（自底向上）：父节点的值由两个孩子的值合成。
- 「出现次数」「并列都要」→ **哈希计数**（`Counter`），先求最大次数，再过滤出所有等于它的和。
- 节点数 `10^4`、树可能是链 → 递归会超过 Python 默认深度，写成迭代后序。
- 值可以是负数 → 子树和可正可负，不能用数组下标计数，用字典。

**推导链。**
1. 暴力：每个节点单独遍历自己的子树求和，链状树上 `O(n^2)`，再计数。
2. 浪费：父节点的子树和 = 自身 + 左子树和 + 右子树和，孩子的和早就算过了。
3. 关键：后序一遍，每个节点只算一次，算出来立刻 `freq[s] += 1`。
4. 为了不递归：用栈得到先序序列，倒序遍历即孩子先于父亲。最后 `max(freq.values())` 找出最大次数，再收集所有等于它的和，`O(n)`。

**同模式的题**：LC 563 二叉树的坡度、LC 543 二叉树的直径、LC 1339 分裂二叉树的最大乘积、LC 437 路径总和 III。
