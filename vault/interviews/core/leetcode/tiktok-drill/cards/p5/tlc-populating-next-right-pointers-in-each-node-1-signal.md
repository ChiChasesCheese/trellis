## Q
**LC 116 填充每个节点的下一个右侧节点指针**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-01-06（面试记录）

给一棵完美二叉树（叶子在同一层，非叶子节点都有两个孩子），节点有 `val`、`left`、`right`、`next`。填充每个 `next`，让它指向同一层右边紧邻的节点，最右边节点的 `next` 为 `None`；初始所有 `next` 都是 `None`。节点数在 `[0, 2^12 - 1]`，`-1000 <= node.val <= 1000`。进阶：只用常量额外空间。例：`[1,2,3,4,5,6,7]` 中 `4 -> 5 -> 6 -> 7 -> None`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「同一层的下一个节点」→ 层序遍历（BFS）的天然产物：队列里相邻的同层节点互连。
- 「完美二叉树」→ 每个节点要么是叶子、要么左右孩子齐全，并且 `node.next` 存在时 `node.next.left` 一定存在，连线时不用判空。
- 「常量额外空间」→ 排除 BFS 队列；要利用结构本身：上一层的 `next` 链已经是现成的「本层链表」。
- 节点数最多 `4095`（高度 `12`）：递归也安全，但进阶要的是 `O(1)` 空间。

**推导链。**
1. 暴力：BFS，每层依次取出节点，前一个节点的 `next` 指向后一个，队列最宽时 `n/2` 个节点，`O(n)` 空间。
2. 浪费：队列只是为了按层取节点；处理第 `d` 层时，第 `d` 层的 `next` 链其实已经连好了。
3. 洞察一：沿第 `d` 层的 `next` 链走，给第 `d + 1` 层连线：同父亲的两个孩子 `left.next = right`；跨父亲 `right.next = node.next.left`。
4. 洞察二：第 `d + 1` 层的起点就是第 `d` 层最左节点的左孩子，一路向下，直到叶子层。
5. 最优：两层循环，外层逐层，内层沿 `next` 横走，`O(n)` 时间、`O(1)` 空间。
