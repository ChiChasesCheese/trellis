## Q
**LC 306 累加数**｜Medium · CodeTop 国内累计 6 次 · 最近 2026-09-03（CodeTop）

累加数是一个字符串，组成它的数字能形成累加序列：至少 `3` 个数，除开头两个数外，每个数等于前两个数之和。给一个只含 `'0'-'9'` 的字符串 `num`（`1 <= num.length <= 35`），判断是否是累加数。序列里的数除了 `0` 本身不会以 `0` 开头。例：`"112358"` → `true`（`1, 1, 2, 3, 5, 8`）；`"199100199"` → `true`（`1, 99, 100, 199`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「把字符串切成满足**递推关系**的数列」→ 乍看是**回溯切分**（像 LC 93 复原 IP 地址）。
- 但递推关系 `c = a + b` 让后面的数由前两个**唯一确定** → 只需枚举**前两个数**的长度，其余是确定性校验。
- `n <= 35` → `O(n^2)` 种前两数的选择，每种 `O(n)` 校验，`O(n^3)` 完全可行。
- 数字最多 `35` 位 → 会超出 64 位整数，要用大整数或字符串加法（Python 的 `int` 直接可用）。
- 规则细节：多位数不能有前导零；至少三个数。

**推导链。**
1. 暴力：回溯地枚举每个数的结束位置，再检查整条序列是否满足递推，指数级。
2. 浪费：第三个数开始，每个数的值和长度都已由前两个决定，没有选择。
3. 洞察：只枚举 `(i, j)`——第一个数 `num[:i]`、第二个数 `num[i:j]`；之后 `a, b = b, a + b`，把 `str(b)` 与 `num` 当前位置核对。
4. 剪枝：第三个数的位数至少是 `max(i, j - i)`，所以 `max(i, j - i) <= n - j`；全部核对通过且恰好用完字符串即为 `True`。

**同模式的题**：LC 842 将数组拆分成斐波那契序列、LC 93 复原 IP 地址、LC 282 给表达式添加运算符。
