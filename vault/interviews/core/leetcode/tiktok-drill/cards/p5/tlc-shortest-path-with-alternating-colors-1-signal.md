## Q
**LC 1129 颜色交替的最短路径**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-09-21（CodeTop）

有向图有 `n` 个结点（`0` 到 `n - 1`），每条边是红色或蓝色，可能有自环和平行边。给定红边数组 `red_edges` 和蓝边数组 `blue_edges`，返回数组 `answer`，`answer[x]` 是从结点 `0` 到 `x` 的红蓝边**交替**出现的最短路径长度，不存在为 `-1`。`1 <= n <= 100`，两个边数组长度都 `<= 400`。例：`n = 3, red_edges = [[0,1],[1,2]], blue_edges = []` → `[0,1,-1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最短**路径」+ 边无权（每条边长度 `1`）→ **BFS**。
- 「颜色必须**交替**」→ 一条边能不能走，取决于**上一条边的颜色** → 结点不是完整状态，要带上「下一条边必须的颜色」，即**拆点 / 带状态的 BFS**（每个结点 × 2）。
- 「可能有自环和平行边」→ 图里有环，DFS 枚举路径会无限长；BFS 加状态去重天然避开。
- `n <= 100`、边 `<= 800` → 规模很小，考的是**状态设计**，不是优化。

**推导链。**
1. 暴力：DFS 枚举所有交替路径，有环就无穷，必须加长度上限，还会指数爆炸。
2. 错误捷径：普通 BFS 只按结点标记已访问。同一结点以红边到达与以蓝边到达，后续能走的边不同，先到的会挡掉另一种。
3. 洞察：状态 `(结点, 下一条边的颜色)`，共 `2n` 个；走一条颜色 `c` 的边，进入 `(终点, 1 - c)`。
4. 起点两种颜色状态都入队（第一条边任选）；每个状态只入队一次；结点首次出队的步数就是答案。`O(n + e)`。
