## Q
**LC 698 划分为k个相等的子集**｜Medium · CodeTop 国内累计 6 次 · 最近 2026-10-07（CodeTop）

给整数数组 `nums` 和正整数 `k`，判断能否把数组分成 `k` 个**非空**子集，使它们的元素和都相等（每个元素恰属于一个子集）。

约束：`1 <= k <= len(nums) <= 16`，`0 < nums[i] < 10000`，每个元素的出现次数在 `[1, 4]` 范围内。

例：`nums = [4,3,2,3,5,2,1], k = 4` → `true`（`(5)`、`(1,4)`、`(2,3)`、`(2,3)`，和都是 `5`）；`nums = [1,2,3,4], k = 3` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「划分成 `k` 个和相等的子集」→ 每桶目标和 `target = sum / k` 固定；总和不能整除 `k` 就直接无解（可行性剪枝）。
- `len(nums) ≤ 16` → `2^16 = 65536` 个子集状态可全枚举，是**状态压缩 DP** 或带剪枝回溯的信号；若 `n` 上百，就要找别的结构（DP 背包等）。
- 每个数只能用一次、桶之间没有区别 → 一桶一桶填，状态只需记「用了哪些数」；当前桶装了多少由已用数之和对 `target` 取模得到。

**推导链。**
1. 暴力：每个数选一个桶，`k^n`，且桶无标号，大量重复。
2. 浪费：同一个「已用数集合」会被不同的放法反复到达，后面的计算完全相同。
3. 洞察：一桶一桶填，前面的桶都已装满，状态就是已用数集合 `mask`，当前桶余量由 `sum(mask) % target` 决定。
4. 最优：`dp[mask]` 记当前桶已装的量（`-1` 不可达）；数组升序，装不下就 `break`；`dp[全集] == 0` 即答案。`O(n·2^n)`。
