## Q
**LCP 13 寻宝**｜Hard · CodeTop 国内累计 2 次 · 最近 2026-08-01（国内 CodeTop）

迷宫是字符串数组：`S` 唯一入口，`T` 唯一宝藏，`M` 是机关（所有机关都被触发才能拿到宝藏），`O` 是石堆（石头无限，但一次只能搬一块；触发机关要把石头放到它上面），`#` 是墙，`.` 可通行；`S`、`T`、`M`、`O` 也可通行。每步上下左右移动一格，搬起 / 放下不算步数。求最少步数，无法拿到宝藏返回 `-1`。迷宫最大 `100 × 100`，`0 <= M 的数量 <= 16`，`0 <= O 的数量 <= 40`，有 `M` 时至少有一个 `O`。例：`["S#O","M..","M.T"]` → `16`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「至多 `16` 个**必须全部访问**的点 + 最少总步数」→ **状态压缩 DP（TSP 旅行商）**，`16` 个机关用 `2^16` 个集合状态。
- 迷宫里两点的最短路 → **BFS**（无权网格）。
- 「一次只能搬一块石头」→ 每个机关的触发都是「走到石堆拿石头 → 走到机关」的一次往返，可以压缩成机关之间的边权。
- 网格最大 `100 × 100`：在 `(行, 列, 已触发集合, 是否搬石头)` 上直接搜索约 `10^4 * 2^16 * 2` 个状态，太大 → 必须先压缩成关键点图。

**推导链。**
1. 暴力：在完整状态上做 Dijkstra / BFS，小迷宫可行，`100 × 100` 不行。
2. 洞察 1：搬石头永远是「石堆 → 机关」，其余路程只提供距离，所以只有 `S`、`T`、`M`、`O` 是关键点，两两距离用 BFS 得到。
3. 洞察 2：石堆无限，所以机关 `i` → 机关 `j` 的最优代价是 `min(石堆) 距离(i, 石堆) + 距离(石堆, j)`，与其他机关的状态无关，预计算 `hop[i][j]`；起点同理 `first[j]`。
4. TSP：`dp[mask][j]` = 已触发集合 `mask`、站在机关 `j` 的最少步数，`O(2^k · k^2)`；最后加 `机关 j → T` 的距离。没有机关时直接 `BFS(S → T)`。

**同模式的题**：LC 847 访问所有节点的最短路径、LC 943 最短超级串、LC 1125 最小的必要团队、LC 526 优美的排列。
