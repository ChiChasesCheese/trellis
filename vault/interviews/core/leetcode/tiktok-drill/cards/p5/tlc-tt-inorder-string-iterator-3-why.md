## Q
**二叉树中序字符迭代器**｜正确性

栈里到底存什么，才能保证按中序出字符？为什么 `hasNext()` 必须是 `while` 循环并负责换节点？给出写错时的具体输入。

## A
**栈的不变量。** 任何时刻，栈里从底到顶依次是一串「还没有访问自己，也没有访问右子树」的祖先，栈顶是当前子树里最靠左、还没访问的节点。弹出栈顶 `x` 时，`x` 的整个左子树已经访问完（它的左链已压栈并先弹出），所以接下来该访问 `x` 自己；之后再访问 `x` 的右子树，所以弹出 `x` 时要立刻把 `x.right` 的整条左链压栈，下一个弹出的恰好是右子树里最靠左的节点。栈的深度不超过树高。

**游标的不变量。** `_s` 是当前正在读的节点字符串，`_i` 是已读位置。`hasNext()` 返回 `True` 当且仅当 `_i < len(_s)`；为 `False` 时栈一定是空的，也就是所有节点都访问过了。这条性质让 `hasNext()` 重复调用结果相同。

**为什么是 `while`。** 弹出的节点可能是空串，换过去之后 `_i = 0 >= len(_s)` 仍不成立，要继续换下一个，一次换节点可能要跳过任意多个空串节点。

**反例一：`hasNext()` 只看栈。** 树只有一个节点 `""`：
- 栈非空，`hasNext()` 返回 `True`，但没有字符可读，`next()` 无法返回。
- 正确是 `False`。

**反例二：弹出节点时不压右子树。** 根 `"ab"`，左孩子 `"c"`，右孩子 `"de"`：
- 只会读出 `c, a, b`，右子树永远没有进栈。
- 正确是 `c, a, b, d, e`。
