## Q
**量水问题：最短操作序列**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-05-08（面试记录）

两个容量分别为 `x`、`y` 升的水壶，水源无限。操作有三种：把任一水壶灌满；把任一水壶倒空；把一个壶的水倒进另一个，直到倒的壶空了或另一个壶满了。要得到恰好 `z` 升水（默认指两个壶里的水量之和，也可以是某一个壶里），输出操作次数最少的操作序列，做不到返回 `None`。`1 <= x, y <= 10^3`，`0 <= z <= 2 * 10^3`。例：`x = 3`，`y = 5`，`z = 4`（两壶之和）→ `7` 步。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少操作次数」+「状态是两个壶的水量」→ 隐式图上的最短路：状态 `(a, b)` 是点，六种操作是边，每条边代价为 `1`，用 BFS。
- 「输出操作序列」→ BFS 入队时记录前驱和操作名，到达目标后回溯再反转。
- 「能不能做到」→ 数论判据：`z` 必须是 `gcd(x, y)` 的倍数且不超过上限；不可能的情形不用搜。
- 「`z` 是两壶之和还是某一壶」→ 影响目标判定函数，要先和面试官确认。

**推导链。**
1. 暴力：DFS 随便找一条操作序列，不保证最短，还会在环里打转。
2. 浪费：DFS 没有利用“每步代价相同”，无法保证最短。
3. 洞察：BFS 按操作次数分层，第一次到达目标的路径最短；每次操作之后总有一个壶是空的或满的，可达状态至多 `2(x + y + 2)` 个。
4. 最优：数论预判加 BFS，时间与空间 `O(x + y)`，路径用 `parent` 字典还原。
