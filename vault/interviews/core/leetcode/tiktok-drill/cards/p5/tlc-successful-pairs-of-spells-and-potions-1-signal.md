## Q
**LC 2300 咒语和药水的成功对数**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2025-12-13（美国面试记录）

给正整数数组 `spells`（长度 `n`）和 `potions`（长度 `m`），以及整数 `success`。一个咒语和一瓶药水的能量相乘大于等于 `success`，就是一对成功的组合。返回数组 `pairs`，`pairs[i]` 是与第 `i` 个咒语成功组合的药水数量。`1 <= n, m <= 10^5`，`1 <= spells[i], potions[j] <= 10^5`，`1 <= success <= 10^10`。例：`spells = [5,1,3]`，`potions = [1,2,3,4,5]`，`success = 7` → `[4,0,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「对每个咒语，统计满足阈值的药水个数」→ **排序 + 二分**：把药水排序，一个咒语对应的成功药水是一个后缀。
- 条件是乘积 `>= success`，所有数为正 → 乘积随药水单调不减，才能二分。
- `n = m = 10^5` → 两两枚举 `10^10` 次不可行，目标 `O((n + m) log m)`。
- `success` 最大 `10^10`，Python 整数不会溢出；其他语言的乘积要用 64 位。

**推导链。**
1. 暴力：对每个咒语扫描所有药水，`O(n * m)`。
2. 观察：药水排序后，`p * s >= success` 的药水集中在末尾，是一段后缀。
3. 找后缀起点：药水下限是 `ceil(success / s)`，在有序药水里二分第一个不小于它的位置；或者直接对乘积 `p * s` 做二分。
4. 个数 = `m - 起点`。排序 `O(m log m)`，每个咒语一次二分 `O(log m)`。

**同模式的题**：LC 1498 满足条件的子序列数目、LC 475 供暖器、LC 744 寻找比目标字母大的最小字母、LC 2389 和有限的最长子序列。
