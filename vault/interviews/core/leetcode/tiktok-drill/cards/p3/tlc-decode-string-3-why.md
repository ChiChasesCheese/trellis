## Q
**LC 394 字符串解码**｜正确性

栈解法里，进入 `[` 时为什么要把 `(cur, num)` 一起压栈并把两者清零？只压次数，或者次数读一位就覆盖，会错在哪？各给一个具体输入。

## A
**不变量。** 扫描到任意位置时，`cur` 是「当前最内层括号里已经读到的部分」，栈里自底向上依次是每个外层括号**进入时**的前缀和它的重复次数，`num` 是正在读的下一个次数。`]` 到来时，栈顶正好对应与它配对的 `[`。

**反例一：只压次数，丢了前缀。** `s = "ab2[c]"`。
- `a`、`b` 先读进 `cur = "ab"`，遇到 `[` 如果只压次数 `2` 并清空 `cur`，前缀 `"ab"` 就丢了。
- 读完 `c` 遇到 `]` 得 `cur = "cc"`，结果是 `"cc"`；正确是 `"abcc"`。

**反例二：次数只取一位。** `s = "10[a]"`。
- 写成 `num = int(ch)`：先读 `1`，再读 `0` 时 `num` 被覆盖成 `0`，内层 `"a"` 重复 0 次，结果是空串 `""`。
- 正确答案是 `"aaaaaaaaaa"`。累加写法 `num = num * 10 + int(ch)` 才对。

**反例三：进入 `[` 后不清零 `num`。** `s = "3[a]2[bc]"`。
- `3[a]` 结束后 `num` 仍是 `3`，读到 `2` 变成 `32`，`bc` 被重复 32 次。
- 输出长度是 `67`，正确的 `"aaabcbc"` 长度是 `7`。
