## Q
**LC 22 括号生成**｜Medium · LC TikTok 热度 63/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 67 次 · 最近 2026-09（面试记录）

数字 `n` 代表生成括号的对数，设计一个函数，生成所有可能的并且有效的括号组合。`1 <= n <= 8`。例：`n = 3` → `["((()))","(()())","(())()","()(())","()()()"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「生成**所有**……」→ 输出是指数规模，必须枚举 → **回溯**（backtracking）：一位一位地放，递归下去，再撤销。
- 「**有效的**括号」→ 有效的充要条件是「任意前缀里左括号不少于右括号，且总数各 `n` 个」，可以变成**放置规则**，边放边剪枝。
- `n <= 8`：结果数是卡特兰数 `C(8) = 1430`，规模很小，`O(n · C(n))` 完全可以。

**推导链。**
1. 暴力：枚举所有 `2^(2n)` 个由 `(` 和 `)` 构成的串，逐个判断有效；`n = 8` 时 `65536` 个。
2. 浪费：大多数串的前缀已经无效（右括号多于左括号），却还要继续往后展开。
3. 洞察：放左括号的条件是 `opened < n`；放右括号的条件是 `closed < opened`（只能闭合已有的左括号）。这两条规则保证每个前缀合法，走到长度 `2n` 的叶子一定有效。
4. 最优：搜索树里没有废枝，叶子数恰是卡特兰数 `C(2n, n) / (n + 1)`；先试左括号、再试右括号，结果自然按字典序排列。
