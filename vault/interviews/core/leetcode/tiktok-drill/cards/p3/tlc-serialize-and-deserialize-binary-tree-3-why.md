## Q
**LC 297 二叉树的序列化与反序列化**｜正确性

为什么序列化时必须把空孩子也写成 `"null"`？反序列化为什么能凭这样的序列无歧义地还原？给出具体的两棵树。

## A
**不变量。** 一棵子树的编码是「根的值 + 左子树的编码 + 右子树的编码」，空子树的编码是单个 `#`。每段编码自己就说明了它在哪里结束：读到 `#` 就结束，读到值就必须再读完左、右两段编码。反序列化递归 `build()` 与序列化递归 `dfs()` 的顺序一致，所以左子树恰好吃掉它自己的标记，右子树从下一个标记接着读，树与字符串一一对应。

**反例：不标空位。** 两棵不同的树：
- 树 A：根 `1`，只有左孩子 `2`，即 `[1,2]`。
- 树 B：根 `1`，只有右孩子 `2`，即 `[1,null,2]`。
- 只记录非空节点的值时，两棵树都变成 `"1,2"`，反序列化无法决定 `2` 是左孩子还是右孩子。
- 标空位后，A 是 `"1,2,#,#,#"`，B 是 `"1,#,2,#,#"`，互不相同，可以还原。

**反例：空树。** `root = None` 时序列化为 `"#"`。若序列化时对空根不输出占位符，得到空字符串，`"".split(",")` 是 `['']`，`int('')` 抛出 `ValueError: invalid literal for int()`。

**还有一个隐含前提。** 值之间用 `,` 分隔，值本身不含逗号，所以多位数和负数不会被拆开。如果值可能是任意字符串，需要转义分隔符或写成「长度 + 内容」的格式。
