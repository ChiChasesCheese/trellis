## Q
**LC 79 单词搜索**｜Medium · LC TikTok 热度 75/100（近 6 个月） · CodeTop 国内累计 41 次 · 最近 2026-06-03（国内 CodeTop）

给 `m x n` 的字符网格 `board` 和字符串 `word`，判断 `word` 是否存在于网格中。单词必须按字母顺序，通过水平或竖直相邻的单元格连成，同一个单元格在一条路径里不能重复使用。`m == board.length`，`n == board[i].length`，`1 <= m, n <= 6`，`1 <= word.length <= 15`，`board` 和 `word` 仅由大小写英文字母组成。例：`board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]`，`word = "ABCB"` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格里沿相邻格子拼出一个序列」+「同一格不能重复使用」→ 网格回溯（DFS with backtracking）：走过的格子标记，退出时还原。
- 要的是**路径**，不是连通块：同一格可以出现在不同的路径里，所以不能像数岛屿那样永久标记。
- `m, n <= 6`、`word.length <= 15`：每步至多 3 个方向（不回头），搜索量可承受；进阶提示"搜索剪枝"。

**推导链。**
1. 暴力：枚举所有路径，指数级。
2. 浪费：字符对不上还继续往下走。
3. 洞察一：每走一步先比较字符，不匹配立刻返回，只有匹配的分支才会展开。
4. 洞察二：用原地标记（改成 `"#"`）保证同一格不重复用，返回前还原。
5. 进阶剪枝：棋盘上某个字母的数量少于单词需要的，直接 `False`；首尾字母里哪个在棋盘上更少就从哪端开始匹配。
