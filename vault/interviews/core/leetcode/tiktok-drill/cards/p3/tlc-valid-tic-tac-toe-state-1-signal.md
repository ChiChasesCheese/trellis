## Q
**LC 794 有效的井字游戏**｜Medium · LC TikTok 全时段热度 25/100 · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-10-13（美国面试记录）

给你字符串数组 `board` 表示 `3 x 3` 的井字棋盘，字符为 `'X'`、`'O'` 或 `' '`（空位）。玩家 1 总是放 `'X'` 且先手，玩家 2 总是放 `'O'`，轮流把字符放入空位；有 3 个相同的非空字符连成行、列或对角线时游戏结束，所有位置非空也结束；结束后不允许再放。当且仅当棋盘有可能在游戏过程中出现时返回 `true`。例：`["XOX"," X ","   "]` → `false`（没有轮流）；`["XOX","O O","XOX"]` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「当且仅当棋盘有可能出现」→ **可达性判断**：不必造出落子顺序，从规则推出必要条件，再说明它们也充分。
- 「轮流」「X 先手」→ 子数不变量：任何时刻 `O <= X <= O + 1`。
- 「有人连线后游戏结束」→ 终局约束：谁连线，谁就是最后落子的人，连线之后再没有任何落子，这决定了两方子数的差。
- 棋盘固定 `3 x 3`（`3^9 = 19683` 种）→ 搜索可行，但没有必要；`O(1)` 的条件检查就够。

**推导链。**
1. 暴力：从空棋盘 BFS / DFS 枚举所有合法落子序列，得到全部可达盘面，再查表；对 `3 x 3` 可行，对大棋盘不可行。
2. 浪费：我们只关心「是否可达」，不关心怎么到达，搜索把所有路径都走了一遍。
3. 洞察：不合法只有三种原因——子数不对、`X` 连线后 `O` 还在落子、`O` 连线后 `X` 还在落子；两方同时连线是后两条的矛盾推论。
4. 最优：数 `X`、`O`，找出两方是否连线，三条判断，`O(1)`。
