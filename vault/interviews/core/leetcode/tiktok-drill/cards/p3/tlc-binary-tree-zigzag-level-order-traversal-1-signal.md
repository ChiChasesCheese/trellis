## Q
**LC 103 二叉树的锯齿形层序遍历**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 189 次 · 最近 2026-09-15（CodeTop）

给二叉树的根节点 `root`，返回其节点值的**锯齿形层序遍历**：第一层从左往右，第二层从右往左，之后交替。树中节点数在 `[0, 2000]` 内，`-100 <= Node.val <= 100`。例：`root = [3,9,20,null,null,15,7]` → `[[3],[20,9],[15,7]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**按层**输出，每层一个列表」→ **广度优先搜索**（BFS）：队列或「当前层 / 下一层」两个列表，一次处理一整层。
- 「从左往右、再从右往左交替」→ 只改变**输出顺序**，不改变遍历顺序；层号的奇偶就是开关。
- `n <= 2000`：`O(n)` 已是下界（每个节点至少看一次），不需要更聪明的结构；链状树深度可达 2000，所以 BFS 比递归更稳。

**推导链。**
1. 朴素想法：队列两头进出（`deque` 的 `appendleft` / `pop`），每层换一次方向。
2. 浪费：方向一换，出队端、入队端、左右孩子的入队次序都要同时翻转，三件事缠在一起，容易错。
3. 洞察：遍历顺序和输出顺序可以分开。遍历一律从左到右，每层的节点列表保持原样。
4. 最优：每层先取出值列表 `vals`，奇数层写入 `vals[::-1]`。每个节点入队一次、反转一次，`O(n)` 时间，`O(w)` 额外空间（`w` 为最宽一层）。
