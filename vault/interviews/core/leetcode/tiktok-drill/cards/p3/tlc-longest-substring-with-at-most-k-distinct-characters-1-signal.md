## Q
**LC 340 至多包含 K 个不同字符的最长子串**｜Medium · LC TikTok 热度 46/100（近 3 个月） · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 12 次 · 最近 2026-09-04（美国面试记录）

给字符串 `s` 和整数 `k`，返回至多包含 `k` 个不同字符的最长子串的长度。`1 <= s.length <= 5 * 10^4`，`0 <= k <= 50`。例：`s = "eceba"`，`k = 2` → `3`（`"ece"`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连续子串**」+「最长」+ 窗口内容的约束（不同字符种类数 `<= k`）→ **可变长滑动窗口**。
- 约束有**单调性**：窗口变大种类数不会减少，变小不会增加；所以右端前进时左端只前进、不回退。
- 约束是“种类数”而不是“有无重复” → 需要**计数器**（`Counter` / 字典）记每个字符在窗口里出现几次，缩窗口时才知道某种字符是否真的离开了窗口。
- `n = 5 * 10^4`、`k <= 50` → `O(n)` 或 `O(n * k)` 都可以，`O(n^2)` 不行。

**推导链。**
1. 暴力：枚举所有子串，用集合数种类，`O(n^3)`；固定起点向右扩，`O(n^2)`。
2. 浪费：每换一个起点都从头扩；窗口 `[left, right]` 已经合法，再看 `right + 1` 时只需要增量更新。
3. 滑动窗口：右端吃进字符，计数加一；种类数 `len(count) > k` 时缩左端，计数减一，**减到 `0` 就删键**；直到种类数回到 `k`。
4. 每步用 `right - left + 1` 更新答案。
5. 每个下标进出窗口各一次，`O(n)`；计数器至多 `k + 1` 个键，空间 `O(k)`。
