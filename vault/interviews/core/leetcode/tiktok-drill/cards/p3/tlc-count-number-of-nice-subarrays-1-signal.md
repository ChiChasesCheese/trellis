## Q
**LC 1248 统计「优美子数组」**｜Medium · LC TikTok 热度 50/100（近 30 天） · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-06-26（面试记录）

给整数数组 `nums` 和整数 `k`，连续子数组中**恰好**有 `k` 个奇数就称为「优美子数组」，返回优美子数组的数目。`1 <= nums.length <= 50000`，`1 <= nums[i] <= 10^5`，`1 <= k <= nums.length`。例：`nums = [1,1,2,1,1]`，`k = 3` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「数**子数组的个数**」+「恰好 `k` 个满足条件的元素」→ **前缀计数**：把元素映射成 `0/1`（奇数为 `1`），问题就是“和恰好为 `k` 的子数组个数”（LC 560）。
- 「**恰好**」在滑动窗口里难直接做 → 用 `至多 k` 减 `至多 k - 1`。
- 元素的具体数值无关，只看奇偶 → 前缀里的奇数个数是一个单调不减、取值 `0..n` 的整数，可以用定长数组计数。
- `n = 5 * 10^4` → `O(n^2)` 约 `10^9`，超时，目标 `O(n)`。

**推导链。**
1. 暴力：枚举所有子数组，数奇数，`O(n^3)`；预处理前缀奇数个数后 `O(n^2)`。
2. 固定右端点，左端点的前缀奇数个数必须是 `odd - k`；问题变成“之前有多少个前缀的奇数个数等于 `odd - k`”。
3. `seen[j]` 记录前缀奇数个数为 `j` 的次数，扫描时累加 `seen[odd - k]`，再 `seen[odd] += 1`。
4. 空前缀有 `0` 个奇数，`seen[0] = 1`。
5. 一趟 `O(n)`，空间 `O(n)`。备选：`at_most(k) - at_most(k - 1)` 的滑动窗口，`O(1)` 空间。

**同模式的题**：LC 560 和为 K 的子数组、LC 930 和相同的二元子数组、LC 974 和可被 K 整除的子数组、LC 992 K 个不同整数的子数组。
