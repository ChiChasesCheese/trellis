## Q
**LC 51 N 皇后**｜Hard · LC TikTok 热度 75/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 14 次 · 最近 2026-08-10（CodeTop）

把 `n` 个皇后放在 `n x n` 的棋盘上，使她们互不攻击（同一行、同一列、同一斜线都算攻击），返回所有不同的摆法；每种摆法是 `n` 个字符串，`'Q'` 为皇后，`'.'` 为空位。`1 <= n <= 9`。例：`n = 4` → 两种摆法，如 `[".Q..","...Q","Q...","..Q."]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「放置若干个、互不冲突、求**所有**方案」→ 回溯（backtracking），逐步放置，冲突就回退。
- `n <= 9`：指数级搜索可行（`9!` 约 `3.6 * 10^5`）。
- 「同一斜线」→ 给对角线编号：主对角线上 `r - c` 相同，副对角线上 `r + c` 相同，冲突检测变成集合查找。

**推导链。**
1. 暴力：在 `n^2` 个格子里选 `n` 个，`n = 9` 约 `2.6 * 10^11` 种，不可行。
2. 第一次缩减：每行恰好一个皇后（同行不能有两个，而 `n` 个皇后放进 `n` 行，所以每行刚好一个），只需决定每行的列，`n^n`。
3. 第二次缩减：每列也恰好一个，列是一个排列，`n!`。
4. 剪枝：一行一行放，放之前检查列、主对角线、副对角线是否被占用，冲突立刻放弃这个分支；放满 `n` 行就记录一个解，回溯时撤销标记。

**同模式的题**：LC 52 N 皇后 II（只数个数）、LC 37 解数独、LC 46 全排列、LC 79 单词搜索。
