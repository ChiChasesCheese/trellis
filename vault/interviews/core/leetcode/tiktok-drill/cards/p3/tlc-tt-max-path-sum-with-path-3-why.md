## Q
**二叉树最大路径和（并输出路径）**｜正确性

求二叉树的最大路径和，每个节点算 `gain = val + max(0, 左 gain, 右 gain)`，在节点处用 `val + max(0, 左 gain) + max(0, 右 gain)` 更新答案。为什么向父亲只能返回一条臂、答案处却可以用两条？不放弃负分支、向父亲返回两条臂、答案初值取 `0`，各会错成什么样？

## A
**不变量。** `gain[v]` 是以 `v` 为最高点、只向下走一条链的最大路径和。任何路径都有唯一的最高节点（拐点）；以 `v` 为拐点的最优路径，是 `v` 加上左子树里最好的单链（若为正）和右子树里最好的单链（若为正）。把所有节点当作拐点取最大，就覆盖了所有路径。向父亲返回的 `gain[v]` 只能是一条链：路径一旦在 `v` 分叉成左右两条臂，就不能再通过 `v` 向上连到父亲。

**反例一：不放弃负分支。** `1 -> (-5, 3)`：不做 `max(0, …)`，在根处得到 `1 + (-5) + 3 = -1`，答案变成 `3`（根或右孩子本身最大）；正确是丢掉 `-5`，路径 `1 -> 3`，和为 `4`。

**反例二：向父亲返回两条臂。** `1 -> (2 -> (3, 3))`：`2` 处的 `val + 左 + 右 = 8`，若把它作为 `gain` 返回给根，根处得到 `1 + 8 = 9`，对应的“路径”是 `3 - 2 - 3` 再接上 `1`，在 `2` 处分叉后又回头，不是合法路径；正确答案是 `8`（路径 `[3, 2, 3]`）。

**反例三：答案初值取 `0`。** 全负的树 `-3` 得到 `0`（相当于选了空路径），`-3 -> (-1, -2)` 也得到 `0`；题目要求路径非空，答案应当是 `-3` 和 `-1`，初值要取根的值或负无穷。

**反例四：路径展开时左臂不反转。** 拐点 `20`，左臂 `[15]`，右臂 `[7]` 看不出问题；左臂多于一个节点时，从拐点往下收集得到 `[x1, x2]`（离拐点近的在前），拼成路径需要先反转成 `[x2, x1]`，否则路径在拐点处“折回”，相邻两个节点不相连。
