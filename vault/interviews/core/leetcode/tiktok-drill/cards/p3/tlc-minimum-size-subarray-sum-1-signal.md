## Q
**LC 209 长度最小的子数组**｜Medium · LC TikTok 热度 53/100（近 6 个月） · 近一年被问：美国 1 次、国内 1 次 · CodeTop 国内累计 51 次 · 最近 2026-08-06（国内面试记录）

给含 `n` 个**正整数**的数组 `nums` 和正整数 `target`，返回和大于等于 `target` 的长度最小的连续子数组的长度，不存在则返回 `0`。`1 <= target <= 10^9`，`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^4`。进阶：做出 `O(n)` 之后，再设计一个 `O(n log n)` 的解。例：`target = 7`，`nums = [2,3,1,2,4,3]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连续**子数组」+「和 `>= target`」+「**最短**」→ **可变长滑动窗口**：右端扩张凑够和，左端收缩求最短。
- 「**正整数**」是命门：窗口越大和越大，满足条件的窗口向两个方向都有单调性，所以左右端点都只前进。含 `0` 或负数就不能用。
- 同一个“正数”条件让前缀和严格递增 → **前缀和加二分**，对应进阶的 `O(n log n)`。
- `n = 10^5` → 需要 `O(n)` 或 `O(n log n)`。

**推导链。**
1. 暴力：枚举全部子数组并求和，`O(n^3)`；用前缀和求和，`O(n^2)`。
2. 浪费：固定右端，满足条件的最大起点只会随右端右移而不降；每个右端都从头重找起点是重复劳动。
3. 右端前进时累加；只要和 `>= target`，记录长度并缩左端，缩到不满足为止；左端不回退。
4. 每个下标进窗口一次、出窗口一次，`O(n)`，空间 `O(1)`。
5. 二分版：前缀和 `pre` 严格递增，对每个起点 `i` 二分找最小的 `j` 使 `pre[j] - pre[i] >= target`，`O(n log n)`。

**同模式的题**：LC 3 无重复字符的最长子串、LC 76 最小覆盖子串、LC 713 乘积小于 K 的子数组、LC 862 和至少为 K 的最短子数组（含负数）。
