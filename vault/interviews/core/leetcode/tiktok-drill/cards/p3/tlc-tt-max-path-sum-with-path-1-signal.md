## Q
**二叉树最大路径和（并输出路径）**｜Hard · 近一年被问：美国 5 次、国内 0 次 · 最近 2026-07-18（面试记录）

二叉树的每个节点有整数值（可为负）。路径是树中一条相连的节点序列，每个节点至多出现一次，不要求经过根或叶子；路径和是路径上节点值之和。求最大路径和，并返回取得最大和的路径（节点序列）。节点数 `1 <= n <= 3 * 10^4`，`-1000 <= val <= 1000`，树可能退化成链。例：`-10 -> (9, 20 -> (15, 7))` → `42`，路径 `[15, 20, 7]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「任意两点之间、不要求过根」→ 树形 DP：路径有一个最高点（拐点），左右各一条向下的臂。
- 「值可以为负」→ 负贡献的分支要放弃（当作 `0`）；全负时答案是最大的单个节点，初值不能是 `0`。
- 「输出路径」→ 在 DP 的同时记录选择：每个节点的最优单链走向哪个孩子，以及全局最优的拐点。
- 自底向上要先拿到孩子的结果 → 后序递归最直观；`n = 3 * 10^4`、可能是链时递归深度超过 CPython 默认上限约 `1000`，要调高上限或改成显式栈。

**推导链。**
1. 暴力：枚举所有节点对，求路径和，`O(n^2)` 以上。
2. 浪费：以某节点为拐点的最优路径 = 自己 + 左边最好的单链 + 右边最好的单链，每棵子树的最好单链只需算一次。
3. 洞察：`gain[v] = val + max(0, gain[左], gain[右])`，向父亲只能提供一条链；答案在每个节点用两条臂更新：`val + max(0, gain[左]) + max(0, gain[右])`，同时记下拐点和每个节点选的方向。
4. 最优：自底向上一遍 `O(n)`；最后从拐点向两侧沿记录的方向展开，反转左臂，拼成路径。

**同模式的题**：LC 124 二叉树中的最大路径和、LC 543 二叉树的直径、LC 687 最长同值路径、LC 1372 二叉树中的最长交错路径。
