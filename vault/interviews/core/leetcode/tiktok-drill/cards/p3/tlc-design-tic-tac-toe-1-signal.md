## Q
**LC 348 设计井字棋**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-10-13（面试记录）

在 `n x n` 棋盘上实现井字棋的胜负判定器：两名玩家（`1` 和 `2`）轮流落子，`move(row, col, player)` 返回落子后获胜的玩家编号，没有人获胜返回 `0`；同一行、同一列或同一条对角线上全是自己的棋子就获胜。每次落子都在棋盘内的空格，有人获胜后不再落子。`2 <= n <= 100`，最多 `n^2` 次 `move`。进阶：每次 `move` 能比 `O(n^2)` 更快吗？

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「进阶：比 `O(n^2)` 更快」→ 不要每次重扫整盘；一次落子只影响它所在的至多 4 条线。
- 「一行/一列/一条对角线全是同一个人」→ 对每条线做计数，而不是存每个格子的归属。
- 「两个玩家」→ 用相反的符号计数（`+1`、`-1`），则绝对值等于 `n` 当且仅当全是同一个人。
- 「设计」类题（有 `__init__` 与方法）：状态放在对象里，每个方法 `O(1)`。

**推导链。**
1. 暴力：每次落子后检查整盘的 `n` 行、`n` 列、两条对角线，`O(n^2)`。
2. 浪费：只有落子所在的行、列、（可能）两条对角线会变化，其余线上的结果与上一步相同。
3. 洞察：每条线维护一个计数，落子时顺手加一；玩家 1 加 `1`，玩家 2 减 `1`，计数的绝对值为 `n` 就是整条线同色。
4. 最优：行计数、列计数各一个长度为 `n` 的数组，加主、副对角线各一个整数，`move` 为 `O(1)`，空间 `O(n)`。
