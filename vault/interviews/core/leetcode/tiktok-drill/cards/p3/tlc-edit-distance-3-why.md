## Q
**LC 72 编辑距离**｜正确性

编辑距离的转移里，三个操作分别对应哪一个邻格？为什么末尾字符相同时直接取左上角 `dp[i-1][j-1]` 就够了？漏掉「替换」这一项会在哪个输入上出错？

## A
**状态含义。** `dp[i][j]` = 把 `word1[:i]` 变成 `word2[:j]` 的最少操作数。考虑最后一步对末尾做了什么：
- **替换**：把 `word1[i]` 换成 `word2[j]`，剩下的是 `word1[:i-1]` → `word2[:j-1]`，即 `dp[i-1][j-1] + 1`。
- **删除**：删掉 `word1[i]`，剩下 `word1[:i-1]` → `word2[:j]`，即 `dp[i-1][j] + 1`。
- **插入**：在 `word1` 末尾补上 `word2[j]`，剩下 `word1[:i]` → `word2[:j-1]`，即 `dp[i][j-1] + 1`。

**为什么相同时取左上角。** 末尾字符相同时，让它们互相对应不花任何操作，代价是 `dp[i-1][j-1]`。再去试删除或插入，得到的值至少是 `dp[i-1][j-1]`（因为每多走一步，距离最多缩短 `1`），所以不会更优。

**反例：漏掉替换。** 只保留删除和插入，`("a", "b")`：要先删掉 `a` 再插入 `b`，需要 `2` 次；正确答案是 `1`（直接替换）。`("horse", "ros")`：只用插入和删除得到 `4`，正确是 `3`。替换相当于「一删一插」合并成一步，是唯一能同时消耗两个字符的操作，缺了它，答案会系统性偏大。

**边界。** 第 0 行 `dp[0][j] = j`（`word1` 为空只能插入），第 0 列 `dp[i][0] = i`（`word2` 为空只能删除）。若把整张表初始化为 `0`，`("", "abc")` 会得到 `0`，`("a", "bcd")` 得到 `1`，正确答案都是 `3`。
