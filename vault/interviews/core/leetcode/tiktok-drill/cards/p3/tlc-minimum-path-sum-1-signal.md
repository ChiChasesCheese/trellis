## Q
**LC 64 最小路径和**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 42 次 · 最近 2026-10-27（面试记录）

给一个 `m x n` 的非负整数网格 `grid`，找一条从左上角到右下角、路径数字和最小的路径；每次只能向下或向右移动一步。

约束：`1 <= m, n <= 200`，`0 <= grid[i][j] <= 200`。例：`[[1,3,1],[1,5,1],[4,2,1]]` → `7`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格 + 只能向右 / 向下」→ 每个格子只能从上或左到达，无环，计算顺序固定：网格 DP。
- 「路径和最小」→ 最优子结构：到达某格的最优路径，其前一格的部分也必须是到那格的最优。
- 「路径数指数级」→ 不能枚举，必须合并：同一格的不同到达方式只保留最小和。
- `m, n <= 200` → `O(mn)` 即可（4 万格）；每格只依赖上和左，一张和网格一样大的表就够。

**推导链。**
1. 暴力：DFS 枚举所有路径，`C(m+n-2, m-1)` 条，指数级。
2. 浪费：到达同一格的多条路径，之后的走法相同，只需要最小的那个和。
3. 洞察：`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`，首行首列只有一个来源。
4. 最优：二维表，先填第一行（前缀和）、第一列（前缀和），再按行填其余格子，`O(mn)` 时间、`O(mn)` 空间。

**同模式的题**：LC 62 不同路径、LC 63 不同路径 II、LC 120 三角形最小路径和、LC 931 下降路径最小和。
