## Q
**LC 139 单词拆分**｜Medium · LC TikTok 热度 56/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 44 次 · 最近 2026-08-27（国内 CodeTop）

给字符串 `s` 和字符串列表 `wordDict`。判断能否用字典中的一个或多个单词拼接出 `s`；单词可以重复使用，不要求用完。

约束：`1 <= s.length <= 300`，`1 <= wordDict.length <= 1000`，`1 <= wordDict[i].length <= 20`，`s` 与单词只含小写字母，字典里的单词互不相同。例：`s = "leetcode", wordDict = ["leet","code"]` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「能否把序列切成若干合法片段」→ 线性序列 DP：前缀 `s[:i]` 能否拆分，只取决于更短前缀的结果。
- 「单词可重复使用」→ 状态里不需要记用过哪些单词，只记位置。
- 递归枚举会从同一个位置反复出发 → 子问题重叠，要记忆（自顶向下）或自底向上填表。
- `s <= 300`、单词长 `<= 20` → `O(n · L)` 次切点查找足够；字典放进 `set` 让每次判断是 `O(L)`。

**推导链。**
1. 暴力：递归尝试每个能匹配的前缀单词，失败回溯，最坏指数级。
2. 浪费：「从位置 `i` 开始能不能拆成功」只和 `i` 有关，被不同前缀组合反复计算。
3. 洞察：`dp[i] = any(dp[j] and s[j:i] in words)`，`dp[0] = True`；单词最长 `L`，`j` 只需在 `[i - L, i)` 里取。
4. 最优：`O(n · L)` 个切点，每次 `O(L)` 切片与哈希，总 `O(n · L²)`。
