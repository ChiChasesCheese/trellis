## Q
**LC 141 环形链表**｜Easy · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 84 次 · 最近 2026-10（面试记录）

给链表的头节点 `head`，判断链表中是否有环：如果有某个节点可以通过连续跟踪 `next` 指针再次到达，则存在环。链表中节点的数目范围是 `[0, 10^4]`，`-10^5 <= Node.val <= 10^5`（值可重复）。例：`head = [3,2,0,-4]`，尾节点连回下标 `1` 的节点 → `true`；`head = [1]`，无环 → `false`。进阶：用 `O(1)` 内存解决。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「链表是否有环」→ **判圈**：沿 `next` 走，要么走到 `None`（无环），要么永远转圈（有环）。
- 进阶「`O(1)` 内存」→ 不能存访问过的节点，用**快慢指针**（Floyd 判圈）。
- 「值可重复」→ 判重只能看**节点对象**，不能看值。
- `n <= 10^4`：`O(n)` 很轻松；考点是空间。

**推导链。**
1. 暴力：集合记录已访问的节点，走到已记录的节点就是有环，走到 `None` 就无环。`O(n)` 时间，`O(n)` 空间。
2. 浪费：为了发现「回到了走过的地方」，不需要记住走过的所有节点。
3. 洞察：让两个指针以不同速度走，有环时快的会在环里追上慢的。`fast` 每步比 `slow` 多一格，两者距离每步减 `1`，不会跳过 `0`，所以一定相遇。
4. 最优：`slow` 一步、`fast` 两步，每走一轮比较；`fast` 走到 `None` 就无环。`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 142 环形链表 II、LC 202 快乐数、LC 287 寻找重复数、LC 876 链表的中间结点。
