## Q
**LC 64 最小路径和**｜写出 Python 实现

`m x n` 的非负整数网格 `grid`（`1 <= m, n <= 200`，元素 `0..200`）。每次只能向下或向右走一步，返回从左上角到右下角的最小路径数字和。

## A
**思路。** `dp[i][j]` 是从左上角走到 `(i, j)` 的最小路径和。`dp[0][0] = grid[0][0]`；第一行每格只能从左来，是 `grid[0]` 的前缀和；第一列每格只能从上来，是 `grid` 第一列的前缀和。其余格子取上方和左方的较小值，再加上本格的数。答案是右下角。

```python
def min_path_sum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    # dp[i][j]：从左上角走到 (i, j) 的最小路径和
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]        # 第一行只能从左来
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]        # 第一列只能从上来
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
    return dp[m - 1][n - 1]
```

**运行。** `[[1,3,1],[1,5,1],[4,2,1]]` → `7`；`[[1,2,3],[4,5,6]]` → `12`；`[[7]]` → `7`；`[[1,2,3]]` → `6`；`[[1],[2],[3]]` → `6`。

**复杂度。** 时间 `O(mn)`：每格一次 `min` 与一次加法；空间 `O(mn)`，不修改输入。

**写法要点。** `[[0] * n for _ in range(m)]` 每行是新列表（写成 `[[0] * n] * m` 所有行是同一个对象）；第一行、第一列各用一个单层循环写好，主循环从 `(1, 1)` 开始，不用在循环里判断边界；`min(dp[i - 1][j], dp[i][j - 1])` 一眼看出「上」和「左」两个来源；单行（`m = 1`）或单列（`n = 1`）时主循环为空，答案直接是前缀和。
