## Q
**LC 1293 网格中的最短路径**｜正确性

为什么每个格子只记录最大剩余次数是对的？为什么普通的“格子访问过就不再访问”会出错？给出那种写法答错的输入。

## A
**不变量。** 在第 `d` 层结束时，对每个格子 `c`，`best_left[c]` 是“用不超过 `d` 步到达 `c` 时能保留的最大剩余次数”。

**为什么只记最大值是对的（支配）。** 两个状态在同一个格子 `c`，一个剩余 `a`，一个剩余 `b > a`，且第二个到达的步数不少于第一个（BFS 层序，后入队的步数不小于先入队的）。设第一个状态之后能走完一条路径到终点，需要的消除次数不超过 `a`；那么第二个状态可以走完全相同的路径，也不超过 `b`。反过来第二个若剩余更多，则它的可能性是第一个的超集。所以：先到的状态剩余更少时，后到的“剩余更多”的状态仍有意义，不能丢；而后到的“剩余不多于已有”的状态，已被先到的状态支配，丢掉不会损失最优解。

**反例：按格子标记已访问。** 网格
```
0 0 1
1 0 1
0 1 0
```
`k = 1`，正确答案 `4`：`(0,0) -> (0,1) -> (1,1) -> (2,1)`（消除障碍）`-> (2,2)`。
- 第 `1` 层：邻居顺序是先下后右，`(1,0)` 是障碍，带剩余 `0` 先入队；`(0,1)` 是空格，带剩余 `1`，后入队。
- 第 `2` 层：先处理 `(1,0)`（剩余 `0`），它走到 `(1,1)`，标记 `(1,1)` 已访问；再处理 `(0,1)`（剩余 `1`），到 `(1,1)` 时发现已访问，被丢弃。
- 此后，`(1,1)` 只带着 `0` 次，不能再穿过障碍 `(2,1)`；终点 `(2,2)` 的两个邻居 `(1,2)` 和 `(2,1)` 都是障碍，带着 `0` 次到不了，最终返回 `-1`。
改成“剩余次数更多才入队”后，`(0,1)` 带着 `1` 次到 `(1,1)`，状态保留，第 `4` 步到达终点。
