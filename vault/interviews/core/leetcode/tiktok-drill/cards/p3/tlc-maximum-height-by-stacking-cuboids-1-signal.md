## Q
**LC 1691 堆叠长方体的最大高度**｜Hard · 近一年被问：美国 0 次、国内 3 次 · 最近 2026-10-23（面试记录）

给 `n` 个长方体，`cuboids[i] = [width, length, height]`。选一个子集堆叠：`i` 能放在 `j` 上当且仅当三个维度都满足 `i <= j`；每个长方体可旋转（重排长宽高）。求最大总高度。`1 <= n <= 100`，每条边 `1..100`。例：`[[50,45,20],[95,37,53],[45,23,12]]` → `190`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「选子集」+「能否叠放由逐维 `<=` 决定」+「求总和最大」→ 偏序上的**最大权链**，即**带权 LIS**。
- 「可以旋转」→ 先想能不能把朝向**规范化**，别把它塞进状态里。
- `n = 100` → `O(n^2)` 甚至 `O(n^3)` 都够，不需要树状数组或二分。

**推导链。**
1. 暴力：枚举子集、顺序、每个箱子 6 种朝向，指数级。
2. 朝向的浪费：每个箱子的三条边升序排好，如果某个朝向下 `i` 能放在 `j` 上，升序后一定也能；最长边当高度又让每个箱子贡献最大。所以朝向固定为「升序，最长边当高」。
3. 顺序的浪费：升序后，能放在 `i` 上面的 `j` 字典序不大于 `i`；整体按三元组排序，`dp[i]` 只需扫 `j < i`。
4. `dp[i] = 高度_i + max(dp[j])`，答案取 `max(dp)`，`O(n^2)`。

**同模式的题**：LC 354 俄罗斯套娃信封、LC 300 最长递增子序列、LC 646 最长数对链、LC 368 最大整除子集。
