## Q
**LC 470 用 Rand7() 实现 Rand10()**｜Medium · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 47 次 · 最近 2026-10-18（面试记录）

已给方法 `rand7()`，等概率返回 `[1, 7]` 内的整数。只准调用 `rand7()`，不能用其他随机方法，实现 `rand10()`，等概率返回 `[1, 10]` 内的整数。测试时 `rand10()` 会被调用 `n` 次，`1 <= n <= 10^5`。例：`n = 3` 时可能得到 `[3, 8, 10]`，结果随机，要求每个值的概率都是 `1/10`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「只能调用小范围随机源，造一个大范围的」→ **拒绝采样**（rejection sampling）：先造一个更大的均匀范围，再截成目标范围的整数倍。
- 「**等概率**」是硬要求 → 任何「把两次结果加起来 / 乘起来」的方案都会偏斜；必须让每个输出对应**相同个数**的等概率基本事件。
- `n <= 10^5` 只是调用次数，没有数据结构和规模压力；解法是 `while True`，期望有限（几何分布），不是最坏情况有限。
- 进阶问「调用次数的期望」→ 期望 = 每轮调用次数 ÷ 每轮成功概率，要会算。

**推导链。**
1. 直觉：`rand7() + rand7()`，取值 `2..14`，和为 `8` 的概率是 `7/49`、和为 `2` 只有 `1/49`，不均匀；乘法同理。
2. 浪费与洞察：均匀要靠「等概率格子数相同」。两次调用的有序对 `(a, b)` 是 `49` 个等概率格子，`(a - 1) * 7 + b` 把它们映射到 `1..49`。
3. `49` 不是 `10` 的倍数，取最大倍数 `40`，丢掉 `41..49` 重抽；丢弃不改变保留格子之间的相对概率，所以仍等概率。
4. 最优：`idx <= 40` 时返回 `(idx - 1) % 10 + 1`，每个结果恰好 `4` 个格子；期望调用 `2 / (40/49) = 2.45` 次。进阶：把被丢的 `9` 个格子留作下一轮的前缀，期望降到约 `2.19`。
