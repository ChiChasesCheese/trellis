## Q
**LC 232 用栈实现队列**｜Easy · 近一年被问：美国 1 次、国内 2 次 · CodeTop 国内累计 52 次 · 最近 2026-09-16（面试记录）

只用两个栈实现先入先出队列，支持 `push(x)`（放到队尾）、`pop()`（移除并返回队首）、`peek()`（返回队首）、`empty()`。只能用标准栈操作（压栈、弹栈、看栈顶、取大小、判空）。`1 <= x <= 9`，最多调用 `100` 次，调用都合法。进阶：每个操作均摊 `O(1)`。例：`push(1)`、`push(2)`、`peek()` 得 `1`、`pop()` 得 `1`、`empty()` 得 `False`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「用栈模拟队列」→ **两个栈串联，倒一次序**：栈后进先出，把一个栈的内容逐个弹出压进另一个栈，顺序整体反转，后进先出就变成先进先出。
- 「**两个**栈」→ 一个专管入（`inbox`）、一个专管出（`outbox`），分工明确。
- 「均摊 `O(1)`」→ 允许个别操作很慢，关键是**每个元素最多被搬运常数次**；这是摊还分析（amortized analysis）的典型形态。
- 操作次数只有 100，暴力也能过，但面试考的是进阶。

**推导链。**
1. 暴力：每次 `push` 把所有元素倒到辅助栈、放入新元素再倒回，`push` 是 `O(n)`；或者每次 `pop` 倒两遍。
2. 浪费：倒过去之后，`outbox` 里已经是出队顺序，没有理由再倒回去。
3. 改法：`push` 只进 `inbox`；`pop` / `peek` 先看 `outbox`，**只有它为空**才把 `inbox` 整个倒进去。
4. 每个元素一生最多被搬一次（`inbox` → `outbox`），`n` 个操作总共 `O(n)`，均摊 `O(1)`。

**同模式的题**：LC 225 用队列实现栈、LC 155 最小栈、LC 622 设计循环队列、LC 239 滑动窗口最大值（单调队列）。
