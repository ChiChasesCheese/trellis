## Q
**LC 560 和为 K 的子数组**｜Medium · LC TikTok 热度 75/100（近 6 个月） · 近一年被问：美国 2 次、国内 1 次 · CodeTop 国内累计 29 次 · 最近 2026-10-19（国内面试记录）

给整数数组 `nums` 和整数 `k`，统计并返回该数组中**和为 `k` 的子数组的个数**。子数组是数组中元素的连续非空序列。`1 <= nums.length <= 2 * 10^4`，`-1000 <= nums[i] <= 1000`，`-10^7 <= k <= 10^7`。例：`nums = [1,1,1], k = 2` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子数组的和」→ **前缀和**（prefix sum）：`sum(i..j) = pre[j] - pre[i-1]`，区间和变成两个前缀和相减。
- 元素有**负数** → 窗口和不再单调，**滑动窗口失效**，不能靠「和大了就缩左端」。
- 「统计个数」→ 哈希表里要存**出现次数**，不是存在性。
- `n` 到 `2×10^4` → `O(n^2)` 约 2×10^8 次，在 Python 里太慢，目标 `O(n)`。

**推导链。**
1. 暴力：枚举每对 `(i, j)` 并求和，`O(n^3)`。
2. 前缀和 `O(1)` 求区间和，枚举 `(i, j)` 变成 `O(n^2)`。
3. 浪费：固定右端 `j` 后，要在所有左端里找满足 `pre[i-1] = pre[j] - k` 的个数——这是「一个确定的值之前出现过几次」。
4. 哈希表记录每个前缀和出现的次数，边扫边查边存：以 `j` 结尾的答案就是 `seen[pre[j] - k]`，累加得总数，`O(n)`。

**同模式的题**：LC 1 两数之和（同样查补数）、LC 523 连续的子数组和、LC 525 连续数组、LC 974 和可被 K 整除的子数组。
