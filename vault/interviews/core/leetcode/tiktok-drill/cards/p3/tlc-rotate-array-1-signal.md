## Q
**LC 189 轮转数组**｜Medium · LC TikTok 热度 56/100（近 3 个月） · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 13 次 · 最近 2026-07-20（国内面试记录）

给整数数组 `nums`，把数组中的元素向右轮转 `k` 个位置（`k` 非负），原地修改，不返回。`1 <= nums.length <= 10^5`，`-2^31 <= nums[i] <= 2^31 - 1`，`0 <= k <= 10^5`。例：`nums = [1,2,3,4,5,6,7], k = 3` → `[5,6,7,1,2,3,4]`。进阶：至少想出三种解法；能否用 `O(1)` 额外空间原地完成？

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「向右轮转 `k` 位」= 循环移位：结果是「最后 `k` 个整体搬到最前，其余整体后移，内部顺序不变」→ **整块搬动**，可以用翻转（reverse）实现。
- `k` 的上界 `10^5` 和 `n` 无关，`k` 可以大于 `n` → 先 `k %= n`。
- 「原地」「`O(1)` 额外空间」→ 排除开新数组的做法；`n` 到 `10^5` 排除 `O(nk)`。
- 「至少三种解法」→ 额外数组、环状替换、三次翻转。

**推导链。**
1. 暴力：每次右移一位，做 `k` 次，每次 `O(n)`，总 `O(nk)`，最坏约 10^10，不行。
2. 额外数组：元素 `i` 直接放到 `(i + k) % n`，`O(n)` 时间，但要 `O(n)` 空间。
3. 环状替换：每个元素一步到位，沿 `i -> (i + k) % n` 走环，共 `gcd(n, k)` 个环，`O(1)` 空间，但下标绕环容易写错。
4. 关键观察：整体翻转后，原来的后 `k` 个正好排在最前，只是顺序倒了；再把前 `k` 个、后 `n-k` 个各翻转一次就恢复。三次翻转 `O(n)` 时间、`O(1)` 空间，代码最短最稳。

**同模式的题**：LC 61 旋转链表、LC 796 旋转字符串、LC 151 反转字符串中的单词、LC 186 反转字符串中的单词 II。
