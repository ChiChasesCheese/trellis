## Q
**LC 134 加油站**｜正确性

为什么从 `start` 出发在第 `i` 站失败后，可以直接跳到 `i + 1` 而不用逐个检查 `start + 1`、`start + 2` 等站？为什么总油量 `>= 0` 就保证最后的 `start` 能绕完一圈？

## A
**失败区间可以整段跳过。** 设从 `start` 出发，油量在第 `i` 站首次变负，那么对每个 `start < k <= i`，到达 `k` 之前从 `start` 带来的油量 `>= 0`（否则更早就失败了）。以 `k` 为起点则空手出发，到达 `i` 时的油量等于“从 `start` 出发时的油量”减去“到达 `k` 时那部分带来的油量”，不会更多，仍然为负。所以 `start..i` 里没有任何站可以当起点，下一个候选是 `i + 1`。

**总油量够就保证有解。** 记 `S(k)` 为前 `k + 1` 站净油量的前缀和（约定 `S(-1) = 0`）。贪心的重置发生在 `S(i)` 严格低于重置点之前的前缀和时，所以最后的 `start - 1` 恰好是 `S` 取全局最小值的位置（第一次出现）。从 `start` 出发：
- 走到站 `k >= start` 时油量是 `S(k) - S(start - 1) >= 0`（因为 `S(start - 1)` 是最小值）；
- 绕回到站 `k < start` 时油量是 `total + S(k) - S(start - 1) >= 0`（`total >= 0` 且同样 `S(k) >= S(start - 1)`）。
所以整圈油量都不为负。

**反例：漏掉总油量判断。** `gas = [2,3,4]`，`cost = [3,4,3]`：净油量 `[-1,-1,1]`，`total = -1`。扫描：`i = 0`、`i = 1` 各重置一次，`start` 变成 `2`；`i = 2` 时 `tank = 1`，没有再重置。只返回 `start` 会得到 `2`；加上 `total >= 0` 的判断才得到正确的 `-1`。

**反例：重置成 `start = i`。** `gas = [1,2,3,4,5]`，`cost = [3,4,5,1,2]`：净油量 `[-2,-2,-2,3,3]`。失败发生在 `i = 0,1,2`，`start = i` 会停在 `2`，正确是 `3`；第 `i` 站本身是失败区间的一员。
