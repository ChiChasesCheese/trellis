## Q
**LC 151 反转字符串中的单词**｜Medium · LC TikTok 全时段热度 41/100 · 近一年被问：美国 3 次、国内 1 次 · CodeTop 国内累计 29 次 · 最近 2026-09-06（国内 CodeTop）

给字符串 `s`，反转其中单词的顺序。单词是非空格字符组成的串，`s` 里可能有前导空格、尾随空格、单词间的多个空格；返回的结果里单词之间只能有**一个**空格，不能有前导或尾随空格。`1 <= s.length <= 10^4`，`s` 只含英文字母、数字和空格，至少有一个单词。例：`"a good   example"` → `"example good a"`。进阶：可变字符数组时 `O(1)` 额外空间。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按单词颠倒」+「空格要规范化」→ 分词问题：难点是多余空格，不是反转。
- 「从后往前读单词」→ 从右向左扫描天然得到反转顺序，不用再翻一次。
- 进阶「`O(1)` 额外空间」「可变数组」→ 经典三步：压缩空格、整体反转、逐词反转（整体反转后每个单词的字母是倒的，再各自反转一次）。
- `n <= 10^4`：线性扫描即可，不存在性能问题。

**推导链。**
1. 暴力：`s.split(" ")` 得到单词列表，反转，再连接——但连续空格会切出空串，结果的空格数不对。
2. 浪费：不是复杂度浪费，而是边界处理：`split()` 不带参数时按任意长度的空白切，并自动丢弃空串。
3. 手动版：指针从末尾向左，跳过空格，记下单词的右边界，走到单词左边的空格，切片加入列表。
4. 原地版：先用读写双指针压缩空格；整体反转；再按空格切出每个单词各自反转。
