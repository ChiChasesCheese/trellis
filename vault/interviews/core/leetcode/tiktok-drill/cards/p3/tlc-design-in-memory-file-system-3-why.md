## Q
**LC 588 设计内存文件系统**｜正确性

前缀树版的文件系统里，路径拆分、`ls` 和追加各有一个最容易写错的细节。它们分别是什么？对每一个给出会出错的具体调用，并说明正确结果。

## A
**不变量。** 树的根代表 `/`，从根到某节点的每一层对应路径里的一个非空名字；节点的 `content` 为 `None` 当且仅当它是目录。

**1. 拆路径要去掉空段。** `"/".split("/")` 是 `['', '']`，`"/a".split("/")` 是 `['', 'a']`。不过滤，`mkdir("/a")` 就在根下建出一个名为 `""` 的节点，`a` 挂在它下面；随后 `ls("/")` 去找 `""` 的 `""` 子节点，抛 `KeyError: ''`。正确结果是 `['a']`。`filter(None, ...)` 同时让根路径 `"/"` 变成空序列，直接停在根。

**2. 文件上的 `ls` 返回文件名。** 写入 `/a/b/c/d` 后调用 `ls("/a/b/c/d")`：只看 `children` 会返回 `[]`，正确结果是 `['d']`。必须先判断 `content is not None`。

**3. 追加不是覆盖。** 先写 `"hello"`，再写 `" world"`：把 `content` 直接赋值，读出 `' world'`；追加后读出 `'hello world'`。新建文件时旧内容用 `node.content or ""` 兜底，一个表达式覆盖两种情况。
