## Q
**LC 212 单词搜索 II**｜Hard · LC TikTok 热度 62/100 · 近一年被问：美国 3 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-05-20（美国面试记录）

给 `m x n` 的字符网格 `board` 和单词列表 `words`，返回所有能在网格上按相邻（上下左右）格子拼出的单词，同一个格子在一个单词里只能用一次。`1 <= m, n <= 12`，`board[i][j]` 是小写字母，`1 <= words.length <= 3 * 10^4`，`1 <= words[i].length <= 10`，单词互不相同。例：示例网格里 `words = ["oath","pea","eat","rain"]` → `["eat","oath"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格上拼单词、不能重复用格子」→ **DFS 回溯**（LC 79 的写法）：占位、递归、还原。
- 「很多单词」（`3 * 10^4`）+「单词有公共前缀」→ **字典树**（trie）：把所有单词合并成一棵树，一次搜索对应全部单词。
- 「前缀走不通就整批放弃」→ 在字典树上同步下行，孩子不存在立刻回头，等于一次剪掉所有以该前缀开头的单词。
- `m, n <= 12`，单词长度 `<= 10` → 递归深度 `<= 10`，不会爆栈；规模小，但逐词搜索的 `W` 倍开销不可接受。
- 「返回所有」且单词互不相同 → 找到后要避免重复收集。

**推导链。**
1. 暴力：对每个单词做一次 LC 79，`O(W · mn · 3^L)`，`W = 3 * 10^4` 超时。
2. 浪费：公共前缀被重复搜；某个前缀走不通时，以它开头的所有单词各自再试一遍。
3. 洞察：单词建字典树，DFS 同时推进「网格位置」与「树结点」，孩子不存在就剪。
4. 最优：找到的词从结点上摘掉，搜空的分支从父亲上删除；每个格子起一次搜索，`O(mn · 3^L)` 的上界，实际由字典树大幅剪枝。

**同模式的题**：LC 79 单词搜索、LC 208 实现 Trie、LC 472 连接词、LC 140 单词拆分 II。
