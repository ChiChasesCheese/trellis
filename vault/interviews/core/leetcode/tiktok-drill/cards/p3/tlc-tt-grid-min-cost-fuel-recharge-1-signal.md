## Q
**带油量限制和补给点的网格最小代价路径**｜Hard · 近一年被问：美国 4 次、国内 0 次 · 最近 2026-06-30（美国面试记录）

`m x n` 的网格：`grid[r][c] >= 0` 是进入该格的代价，`-1` 是障碍；到达补给点后油量立刻恢复到满（`K`）。起点 `(0, 0)`（不计代价），终点 `(m-1, n-1)`，初始油量 `K`，每走一步（上下左右）耗 `1` 单位油，油量为 `0` 时不能再走。求最小总代价，不可达返回 `-1`。`1 <= m, n <= 50`，`0 <= grid[r][c] <= 100`，`0 <= K <= 10^9`。例：`[[0,1,1,1],[9,-1,9,1],[1,1,1,1]]`，`K = 5` → `5`，`K = 4` → `-1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最小总代价、格子有权」→ 带权最短路：Dijkstra，优先队列按总代价。
- 「油量限制、补给点重置油量」→ 位置不足以描述状态，要把剩余油量加进状态：扩展状态 `(行, 列, 剩余油量)`。
- `K` 可以到 `10^9`：不能按 `K` 展开状态；需要对 `K` 封顶（最优路径步数小于 `m·n`）和支配剪枝。
- 「油量为 `0` 不能再走」→ 展开邻居前要检查剩余油量；到达终点时油量为 `0` 是合法的。

**推导链。**
1. 暴力：DFS 枚举所有路径，指数级。
2. 朴素扩展：Dijkstra 加油量维度，`m·n·(K+1)` 个状态，`K` 大时不可行。
3. 洞察：同一个格子里，代价更小且油更多的状态使其他状态失去意义；Dijkstra 按代价递增弹出，只需记录每格已弹出的最大剩余油量，之后不超过它的状态直接丢弃；`K` 超过 `m·n` 等价于 `m·n`。
4. 最优：剪枝后每格最多 `min(K, m·n) + 1` 个状态，每个状态 `O(log)`，实际远小于上界。

**同模式的题**：LC 787 K 站中转内最便宜的航班、LC 1293 网格中的最短路径（消除障碍）、LC 871 最低加油次数、LC 743 网络延迟时间。
