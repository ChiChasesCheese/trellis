## Q
**LC 69 x 的平方根**｜Easy · LC TikTok 热度 75/100 · 近一年被问：美国 1 次、国内 1 次 · CodeTop 国内累计 69 次 · 最近 2026-08-25（CodeTop）

给非负整数 `x`，返回 `x` 的算术平方根，只保留整数部分；不允许使用内置的指数函数和运算符（如 `pow(x, 0.5)`、`x ** 0.5`）。`0 <= x <= 2^31 - 1`。例：`8` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「求整数部分」+「禁用内置开方」→ 在**答案的取值范围**上二分（binary search on the answer），找最大的 `m` 使 `m * m <= x`。
- 判定「`m * m <= x`」对 `m` 单调：小的 `m` 为真，大的为假 → 可以二分。
- `x <= 2^31 - 1`：答案最大 `46340`，线性也能过，但 `O(log x)` 是预期。

**推导链。**
1. 暴力：从 `1` 开始往上试，直到 `m * m > x`，`O(sqrt(x))`。
2. 浪费：每次只排除一个候选，没有利用单调性。
3. 洞察：搜索区间 `[0, x]`，每次取中点，可行就保留右半，不可行就保留左半。
4. 因为要找「最大的可行值」，`mid` 向上取整；可行时 `lo = mid`，不可行时 `hi = mid - 1`，区间严格缩小。`O(log x)`。
