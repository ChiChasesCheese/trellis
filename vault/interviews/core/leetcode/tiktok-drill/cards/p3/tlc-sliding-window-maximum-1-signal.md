## Q
**LC 239 滑动窗口最大值**｜Hard · LC TikTok 热度 50/100 · 近一年被问：美国 3 次、国内 0 次 · CodeTop 国内累计 47 次 · 最近 2026-10-26（面试记录）

给整数数组 `nums`，一个大小为 `k` 的窗口从数组最左侧每次右移一位直到最右侧；你只能看到窗口内的 `k` 个数。返回每个窗口位置上的最大值组成的数组。

约束：`1 <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`，`1 <= k <= nums.length`。

例：`nums = [1,3,-1,-3,5,3,6,7], k = 3` → `[3,3,5,5,6,7]`（六个窗口 `[1,3,-1]`、`[3,-1,-3]`、`[-1,-3,5]`、`[-3,5,3]`、`[5,3,6]`、`[3,6,7]` 的最大值）；`nums = [1], k = 1` → `[1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「滑动窗口 + 每个窗口的最大值」→ 窗口聚合是**最值**，不是和：最值不能像求和那样「加一个减一个」，需要能删除过期元素的结构。
- `n = 10^5`、`k` 范围 `1..n` → `O(nk)` 的暴力不行；堆 `O(n log n)` 可行；要 `O(n)` → **单调队列**。
- 核心观察：右边来了一个更大（或相等）的数，左边更小的数就**永远不可能**再当最大值（它更小、更早离开）→ 可以直接丢弃。

**推导链。**
1. 暴力：每个窗口取最大值，`O(nk)`。
2. 堆：最大堆 + 惰性删除（堆顶过期才弹），`O(n log n)`。
3. 洞察：候选值只需要保留「从左到右严格递减」的那些下标；新数把队尾不大于它的全部弹掉；队首过期就弹出。
4. 最优：双端队列存下标，每个下标入队出队各一次，窗口最大值总在队首，`O(n)`。
