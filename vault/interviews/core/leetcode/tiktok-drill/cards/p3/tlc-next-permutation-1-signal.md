## Q
**LC 31 下一个排列**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 103 次 · 最近 2026-08（面试记录）

整数数组的「下一个排列」是指按字典序排列所有排列时，排在当前排列后面的那一个；如果当前已是最大排列，就重排成最小排列（升序）。给数组 `nums`，**原地**把它改成下一个排列，只允许使用常数额外空间。`1 <= nums.length <= 100`，`0 <= nums[i] <= 100`，元素可能重复。例：`[1,2,3]` → `[1,3,2]`；`[3,2,1]` → `[1,2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**下一个**字典序更大的排列」→ 不是搜索，而是一条**字典序规律**：要变大一点点，就保持尽量长的前缀不变，只改最靠右、能变大的那一位。
- 「原地」+「常数额外空间」→ 只能用下标和交换，不能生成全部排列再排序。
- 元素可以重复 → 比较要区分 `<`、`<=`，相邻相等的数不算「升」。
- `n <= 100`：线性扫描绰绰有余，但全排列枚举（`n!`）不可能。

**推导链。**
1. 暴力：生成全部排列并排序，找到当前排列的后一个，`O(n · n!)`。
2. 观察：如果一个后缀已经是降序，它就是这些数能排出的最大排列，动它不可能变大，所以必须改它左边的位置——从右往左第一个满足 `nums[i] < nums[i+1]` 的 `i`。
3. 要「大一点点」：把 `nums[i]` 换成它右边比它大的**最小**值。右边是降序，从右往左遇到的第一个大于 `nums[i]` 的就是它。
4. 换完后右边仍是降序，翻转成升序得到最小的后缀。三次线性扫描，`O(n)` 时间，`O(1)` 空间。找不到 `i` 就整体翻转。

**同模式的题**：LC 46 全排列、LC 60 排列序列、LC 556 下一个更大元素 III、LC 496 下一个更大元素 I。
