## Q
**LC 394 字符串解码**｜Medium · LC TikTok 热度 75/100（近 3 个月） · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 58 次 · 最近 2026-08-20（CodeTop）

给一个编码后的字符串 `s`，返回解码后的字符串。编码规则 `k[encoded_string]` 表示方括号内部的 `encoded_string` 正好重复 `k` 次，`k` 为正整数。输入总是有效的，没有额外空格，方括号总是合法的；原始数据不含数字，数字只表示重复次数；测试用例保证输出长度不超过 `10^5`。`1 <= s.length <= 30`，`s` 由小写英文字母、数字和方括号组成，`s` 中所有整数的取值范围为 `[1, 300]`。例：`"3[a2[c]]"` → `"accaccacc"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号嵌套」+「先展开内层，再交给外层」→ **后进先出**（LIFO），用**栈**，或者等价地用递归。
- 数字紧挨着 `[`，且可以是多位数（上限 300）→ 要逐位累加成次数，而不是一个字符一个字符地理解。
- `s.length <= 30` 很小，真正的开销在**输出**（至多 `10^5`）→ 复杂度由输出长度决定，不需要在解析上做花样。
- 输入保证合法 → 不用写错误处理，专心写主干。

**推导链。**
1. 暴力：用正则反复把最内层的 `k[xxx]` 替换成重复后的字符串，直到没有括号，每一轮扫描整个字符串。
2. 浪费：嵌套越深，扫描轮数越多，同一部分被反复扫描。
3. 关键：括号的配对顺序正好是后进先出。进入 `[` 时把「外层目前拼到的前缀 + 这一层的重复次数」暂存起来，内层从空串重新开始拼。
4. 遇到 `]` 就弹出暂存的现场：新的外层 = 前缀 + 内层 × 次数。扫描一遍即可，时间与输出长度同阶。

**同模式的题**：LC 224 基本计算器（括号 + 符号）、LC 227 基本计算器 II、LC 726 原子的数量、LC 20 有效的括号。
