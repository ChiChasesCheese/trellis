## Q
**LC 78 子集**｜Medium · LC TikTok 热度 50/100（近 6 个月） · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 49 次 · 最近 2026-03-18（国内 CodeTop）

给一个元素**互不相同**的整数数组 `nums`，返回它所有可能的子集（幂集），解集不能包含重复子集，顺序任意。`1 <= nums.length <= 10`，`-10 <= nums[i] <= 10`。例：`nums = [1,2,3]` → `[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**子集」→ **回溯枚举**：答案本身就有 `2^n` 个，不存在多项式解法，目标是不重不漏。
- `n <= 10` → 输出至多 `2^10 = 1024` 个子集，指数枚举就是预期解；`n` 这么小也是在暗示指数级。
- 「元素互不相同」→ 不需要排序去重；含重复时（LC 90）才要处理。
- 「子集」（无序）而不是排列 → 要规定选择顺序（只往后选），避免同一个集合被生成多次。

**推导链。**
1. 暴力：每个元素选或不选，`n` 位二进制掩码从 `0` 到 `2^n - 1`，每个掩码构造一个子集。
2. 换成递归树：每个节点是一个子集；从某个下标 `start` 起依次挑下一个元素。进入节点时记录当前路径。
3. 去重靠“只往后选”：下一个元素的下标必须大于上一个选的，同一个集合只有按下标递增排列这一种出现方式。
4. 回溯：`append` 之后递归，递归后 `pop` 撤销，路径列表复用，记录时拷贝一份。
5. 共 `2^n` 个子集，每个拷贝 `O(n)`，总计 `O(n * 2^n)`。
