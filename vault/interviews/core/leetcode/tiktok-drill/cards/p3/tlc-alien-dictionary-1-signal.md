## Q
**LC 269 火星词典（Alien Dictionary）**｜Hard · LC TikTok 全时段热度 53/100 · 近一年被问：美国 4 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-09-02（美国面试记录）

外星语言使用小写英文字母，字母顺序未知。给字符串列表 `words`，已知其中的单词按这门语言的字典序排好。若这个说法自相矛盾（不对应任何字母顺序）返回 `""`；否则返回一个满足该顺序的、包含所有出现过字母的字符串，多个解时返回任意一个。

约束：`1 <= words.length <= 100`，`1 <= words[i].length <= 100`，`words[i]` 仅由小写字母组成。例：`["wrt","wrf","er","ett","rftt"]` → `"wertf"`；`["z","x","z"]` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按未知顺序排好序的序列，恢复顺序」→ 序列里的先后关系是**偏序约束**，不是完整顺序 → 有向图加拓扑排序（topological sort）。
- 「任意一个解」→ Kahn（入度）或 DFS 后序都行，不需要额外的最小化。
- 「说法是错的就返回 `""`」→ 两类无解：约束成环，或长词是短词的真前缀却排在前面。
- 单词不多、字母 `<= 26` → 图很小，关键是约束抽取正确，而不是性能。

**推导链。**
1. 暴力：枚举 `26!` 种字母排列并检查，不可行。
2. 浪费：排好序的列表有传递性，不相邻的两个词比较不会提供新信息。
3. 洞察：每对相邻单词只看第一个不同的字母 `x, y`，建边 `x → y`；全部出现过的字母都是结点（包括没有约束的）。
4. 最优：Kahn 拓扑排序，取不完说明有环；前缀违例单独判断。时间 `O(总字符数)`。
