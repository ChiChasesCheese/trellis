## Q
**LC 622 设计循环队列**｜Medium · 近一年被问：美国 4 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-07-06（面试记录）

设计循环队列（环形缓冲器）：先进先出，队尾连接队首，空间可循环利用。类 `MyCircularQueue(k)` 容量为 `k`，支持 `enQueue(value)`（成功 `True`，满了 `False`）、`deQueue()`（成功 `True`，空了 `False`）、`Front()`、`Rear()`（空返回 `-1`）、`isEmpty()`、`isFull()`。值在 `0` 到 `1000`，操作数在 `1` 到 `1000`，不要使用内置的队列库。例：容量 `3`，入队 `1,2,3` 成功，再入队 `4` 为 `False`，`Rear()` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「固定容量、队尾连接队首、空间循环利用」→ 环形缓冲区（ring buffer）：下标对容量取模。
- 「不要使用内置队列库」→ 自己管理一个定长数组和下标。
- 「`isEmpty` 与 `isFull` 都要正确」→ 核心难点是空和满的区分：只有 `head`、`tail` 两个下标时二者都是 `head == tail`。
- 操作数最多 `1000`：规模很小，题目考的是边界，不是性能。

**推导链。**
1. 朴素：用 `list`，出队 `pop(0)` 要 `O(k)`，也不是定长。
2. 浪费：定长数组出队后只移动队首，前面空出的格子再也用不上。
3. 洞察：让下标对 `k` 取模，首尾相接，空出的格子自然被后面的入队用上；再存元素个数 `size`，空是 `size == 0`，满是 `size == k`，队尾位置是 `(head + size) % k`。
4. 最优：每个操作 `O(1)`，空间 `O(k)`，不浪费格子。
