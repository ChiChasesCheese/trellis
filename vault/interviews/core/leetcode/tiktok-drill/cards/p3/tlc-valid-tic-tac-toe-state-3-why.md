## Q
**LC 794 有效的井字游戏**｜正确性

为什么「`O <= X <= O + 1`」加上「谁连线谁刚好落了最后一子」这几条就够判定可达？只看子数、或者对连线的数量要求写错，各会错成什么样？

## A
**不变量。** 一局游戏中子数序列是 `X, O, X, O, ...`，所以任何盘面都有 `O <= X <= O + 1`。游戏在某方连线的那一刻结束：`X` 连线意味着最后一子是 `X` 落的，此时 `X == O + 1`；`O` 连线意味着最后一子是 `O` 落的，此时 `X == O`。反过来，满足这些条件的盘面，总能把连线一方的最后一子留到最后落下，其余子按 `X`、`O` 交替落完，所以条件既必要又充分。两方同时连线要求 `X == O + 1` 且 `X == O`，不可能，自然返回 `False`。

**反例一：只看子数。** `["XXX","OOO","   "]` 子数是 `3 : 3`，满足 `O <= X <= O + 1`，只看子数会返回 `True`；两方都连线，不可能同时出现，正确是 `False`。

**反例二：`X` 连线时只要求 `X >= O`。** `["XXX","OO ","O  "]` 子数 `3 : 3`，只看 `x >= o` 返回 `True`；`X` 连线后游戏已经结束，`O` 却又落了子，正确是 `False`。

**反例三：`O` 连线时不检查子数。** `["OOO","XX ","XX "]` 子数 `4 : 3`，满足 `O <= X <= O + 1`，返回 `True`；`O` 连线时最后一子是 `O`，必须 `X == O`，这里 `X` 比 `O` 多一子，说明 `O` 连线之后 `X` 又落了子，正确是 `False`。
