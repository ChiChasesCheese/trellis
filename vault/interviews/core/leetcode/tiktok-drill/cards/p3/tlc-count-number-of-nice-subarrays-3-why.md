## Q
**LC 1248 统计「优美子数组」**｜正确性

为什么「恰好 `k` 个奇数的子数组数」等于「前缀奇数个数相差 `k` 的前缀对数」？为什么用滑动窗口直接数“恰好 `k` 个奇数的窗口”会少算？

## A
**不变量。** 处理完前 `i` 个元素后，`odd` 是 `nums[:i]` 里的奇数个数，`seen[j]` 是长度 `0..i-1` 的前缀里奇数个数恰为 `j` 的前缀个数（含空前缀）。

**为什么是前缀对。** 子数组 `nums[a:b]` 里的奇数个数 = `odd(b) - odd(a)`，其中 `odd(t)` 是 `nums[:t]` 的奇数个数。恰好 `k` 个奇数 ⟺ `odd(b) - odd(a) = k`。每个子数组由一对 `(a, b)`、`a < b` 唯一确定，所以数合法的子数组就是数满足 `odd(a) = odd(b) - k` 的 `a`，对每个 `b` 累加即可。

**反例：滑动窗口只数一个。** 窗口每次让奇数个数 `> k` 时缩左端，窗口奇数个数恰为 `k` 时 `ans += 1`：`nums = [2,2,2,1,2,2,1,2,2,2]`，`k = 2`。
- 对每个右端点，合法的左端点不止一个：窗口左边紧挨着的偶数可以任意取舍，所以每个右端点要加的是**一批**起点，而不是 `1`。
- 这种写法得到 `4`，正确是 `16`。

**正确的滑动窗口思路。** 先数“奇数个数 `<= k`”的子数组（对每个右端点，合法左端点是一段连续区间，数量为 `right - left + 1`），再减去“奇数个数 `<= k - 1`”的，差就是恰好 `k` 个。`[2,2,2,1,2,2,1,2,2,2]`，`k = 2`：`at_most(2)` 与 `at_most(1)` 之差即为 `16`。

**空前缀。** `seen[0] = 1` 对应 `a = 0`（子数组从下标 `0` 开始）。`[1,1,2,1,1]`，`k = 3`：不放它，从头开始的 `[1,1,2,1]` 不被计数，答案是 `1`，正确是 `2`。
