## Q
**LC 53 最大子数组和**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 119 次 · 最近 2026-10-14（CodeTop）

给整数数组 `nums`，找出一个具有最大和的**连续子数组**（至少包含一个元素），返回其最大和。`1 <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`。例：`nums = [-2,1,-3,4,-1,2,1,-5,4]` → `6`（子数组 `[4,-1,2,1]`）。进阶：`O(n)` 解法，再试分治法。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连续**子数组」+「最大和」→ **动态规划**，状态写成「以第 `i` 个元素**结尾**」，这样天然保证连续；等价视角是**前缀和**：子数组和 = 两个前缀和之差。
- 数组里有**负数** → 不能用滑动窗口：窗口扩大后和不一定变大，没有单调性可以据此收缩。
- `n` 到 `10^5` → `O(n^2)` 要 `10^10` 次操作，必须 `O(n)` 或 `O(n log n)`。

**推导链。**
1. 暴力：枚举所有起点终点再求和，`O(n^3)`；用前缀和 `O(1)` 求和，降到 `O(n^2)`。
2. 浪费：以 `j` 结尾的最优子数组，只和「以 `j - 1` 结尾的最优子数组」有关，起点不必重新枚举。
3. 洞察：设 `cur` 是以 `j - 1` 结尾的最大和。若 `cur < 0`，接上它只会让 `x` 变小，直接丢掉从 `x` 重新开始；否则接上。即 `cur = max(x, cur + x)`。
4. 最优：一遍扫描，`best = max(best, cur)`，`O(n)` 时间，`O(1)` 空间。前缀和写法等价：对每个 `j` 取 `P[j] - 此前最小的前缀和`。
