## Q
**LC 93 复原 IP 地址**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 2 次、国内 2 次 · CodeTop 国内累计 63 次 · 最近 2026-09-06（国内 CodeTop）

有效 IP 地址正好由四个整数组成，每个整数在 `0` 到 `255` 之间，且不能含有前导 `0`，整数之间用 `'.'` 分隔。给一个只包含数字的字符串 `s`，返回所有能通过在 `s` 中插入 `'.'` 得到的有效 IP 地址；不能重新排序或删除数字，答案可以按任意顺序给出。`1 <= s.length <= 20`。例：`"25525511135"` → `["255.255.11.135","255.255.111.35"]`；`"0000"` → `["0.0.0.0"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「在字符串里**插入分隔符**，切成若干段，每段要满足条件」→ **回溯切割**：从左到右一段一段地切，每段尝试不同的长度。
- 「正好四个整数、每个 `0..255`」→ 段数固定为 `4`，每段至多 `3` 位，搜索树深度 `4`、每层至多 `3` 个分支。
- 「不能有前导 `0`」→ 剪枝条件：一段以 `0` 开头且长度大于 `1`，更长的段同样非法。
- `s.length <= 20`：有效地址最多 `12` 位，长度超出直接无解；整体规模是常数。

**推导链。**
1. 暴力：在 `n - 1` 个空位里选 `3` 个放点，共 `C(n-1, 3)` 种（最多 `969`），逐个检查四段。
2. 观察：一段不合法，把它再加长也一定不合法（有前导零，或数值已经超过 `255`），可以提前 `break`。
3. 剪枝：还要切 `left` 段时，剩余字符数必须落在 `[left, 3 * left]`；超出范围无论怎么切都凑不出来。
4. 最优：深度为 `4` 的回溯，每层尝试 `1..3` 位，到第 `4` 段后检查字符是否恰好用完。总计最多 `81` 种切法，`O(1)`。
