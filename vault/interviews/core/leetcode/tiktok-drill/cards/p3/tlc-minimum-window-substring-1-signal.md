## Q
**LC 76 最小覆盖子串**｜Hard · LC TikTok 热度 75/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 53 次 · 最近 2026-08-30（CodeTop）

给字符串 `s` 和 `t`，返回 `s` 中最短的子串，使其包含 `t` 中的每个字符（含重复，出现几次就要覆盖几次）；不存在返回 `""`。测试用例保证答案唯一。`m == s.length`，`n == t.length`，`1 <= m, n <= 10^5`，`s` 和 `t` 由英文字母组成。进阶要求 `O(m + n)`。例：`"ADOBECODEBANC"`，`"ABC"` → `"BANC"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子串」+「最短」+「必须覆盖 `t` 的所有字符」→ 可变长滑动窗口（sliding window）。
- 「包含重复字符」→ 要用**计数**（`Counter`），不能只用集合。
- 条件有单调性：窗口越大越容易覆盖；右端右移，最优左端不会左移 → 左端只进不退。
- `m, n <= 10^5` 且进阶要求 `O(m + n)`：线性。

**推导链。**
1. 暴力：枚举所有子串逐个检查，`O(m^2 (m + n))`；固定左端扩到刚好覆盖，`O(m^2)`。
2. 浪费：每个新左端都从头扩，之前窗口里已经满足的信息被丢弃。
3. 洞察：右端先扩到覆盖，再从左端尽量收缩到不能再缩，记录长度；此后丢掉一个必需字符，窗口变得不完整，继续扩右端。两个指针都只前进，总计 `O(m)`。
4. 覆盖判断做到 `O(1)`：`need[ch]` 记录还差多少个 `ch`，`missing` 记录总共还缺多少，加入字符时仅 `need[ch] > 0` 才让 `missing` 减一，`missing == 0` 即覆盖。

**同模式的题**：LC 3 无重复字符的最长子串、LC 438 找到字符串中所有字母异位词、LC 567 字符串的排列、LC 727 最小窗口子序列。
