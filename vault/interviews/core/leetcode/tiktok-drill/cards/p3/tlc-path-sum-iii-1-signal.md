## Q
**LC 437 路径总和 III**｜Medium · LC TikTok 热度 41/100（近 30 天） · 近一年被问：美国 3 次、国内 3 次 · CodeTop 国内累计 7 次 · 最近 2026-10-07（CodeTop）

给二叉树的根结点 `root` 和整数 `targetSum`，求结点值之和等于 `targetSum` 的**路径**条数。路径不必从根开始、不必在叶子结束，但方向必须向下（只能从父结点走到子结点）。

约束：结点数在 `[0, 1000]`，`-10^9 <= Node.val <= 10^9`，`-1000 <= targetSum <= 1000`。

例：`root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8` → `3`（`5→3`、`5→2→1`、`-3→11`）；`root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「和等于目标」+「路径不必从根开始」+ 路径是**向下**的 → 路径 = 根到某结点链上的一段连续片段，等价于数组上的「和为 K 的子数组」。
- 结点值可以是**负数** → 排除双指针 / 滑动窗口，只能用**前缀和 + 哈希**。
- `n ≤ 1000`：`O(n^2)`（每个结点向下枚举）能过，但目标是 `O(n)`；树可以退化成链，递归深度会到 `n`，要留意递归上限。

**推导链。**
1. 暴力：每个结点当起点，向下 DFS 累加，命中计数，`O(n·h)`，链上 `O(n^2)`。
2. 浪费：不同起点的路径大量重叠，同一段和被重复相加。
3. 洞察：路径和 = 两个前缀和之差；到达结点 `b` 时问「链上有多少个前缀和等于 `前缀(b) - targetSum`」。
4. 最优：DFS 时用 `Counter` 记当前链的前缀和（初始 `{0: 1}`），进入 `+1`、离开 `-1`，每个结点 `O(1)`，总 `O(n)`。

**同模式的题**：LC 560 和为 K 的子数组、LC 112 / 113 路径总和 I / II、LC 974 和可被 K 整除的子数组、LC 1248 统计优美子数组。
