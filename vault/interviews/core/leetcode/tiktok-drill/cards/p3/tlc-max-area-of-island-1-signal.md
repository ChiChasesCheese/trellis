## Q
**LC 695 岛屿的最大面积**｜Medium · LC TikTok 热度 62/100 · CodeTop 国内累计 47 次 · 最近 2026-10-26（CodeTop）

给一个 `m x n` 的二进制矩阵 `grid`，岛屿是一组上下左右相邻的 `1`，面积是岛上 `1` 的个数。返回最大的岛屿面积，没有岛屿返回 `0`。`1 <= m, n <= 50`，`grid[i][j]` 为 `0` 或 `1`。例：`[[0,0,0,0,0,0,0,0]]` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「相邻的 `1` 构成一块」「求一块的大小」→ **连通分量**（connected component）：DFS / BFS / 并查集。
- 「四个方向」→ 邻居数组是 `(±1, 0)`、`(0, ±1)`，对角线不算（题面特意强调）。
- `m, n <= 50` → 整张图至多 `2500` 格，`O(mn)` 毫无压力；「岛的面积 = 自己 + 四邻各自的面积」是天然的递归，写成返回面积的 DFS 最直观（深岛的递归深度风险见追问）。
- 每格只需要访问一次 → 访问过的格子立刻「沉岛」（`1` 改 `0`），省掉 `visited` 数组。

**推导链。**
1. 暴力：对每个 `1` 单独搜一次它所在的岛，同一座岛被重复搜，`O((mn)^2)`。
2. 浪费：一座岛内的每个格子都重新搜整座岛。
3. 洞察：一座岛搜完后它的所有格子都已经处理过，不会再作为起点；只要搜到就标记，外层循环遇到标记过的格子直接跳过。
4. 最优：双层循环找起点，递归 DFS 进入格子先沉岛、再返回 `1 + 四个方向的面积之和`，取最大。`O(mn)`。

**同模式的题**：LC 200 岛屿数量、LC 463 岛屿的周长、LC 827 最大人工岛、LC 130 被围绕的区域、LC 305 岛屿数量 II（并查集）。
