## Q
**LC 51 N 皇后**｜正确性

为什么用 `r - c` 和 `r + c` 就能表示两个方向的斜线？回溯时撤销标记为什么不能省？只检查一个方向的对角线会给出什么结果？

## A
**不变量。** 进入 `place(r)` 时，前 `r` 行各有一个皇后，且它们占用的列、`r - c`、`r + c` 恰好等于三个集合的内容。这时选一个列 `c`，仅当 `c`、`r - c`、`r + c` 都不在集合里才不与前面的任何皇后冲突。

**斜线编号。** 沿主对角线（左上到右下）移动一步，行加一、列加一，`r - c` 不变；沿副对角线（右上到左下）移动一步，行加一、列减一，`r + c` 不变。两个皇后在同一斜线上，当且仅当它们的 `r - c` 相同或 `r + c` 相同。

**为什么要撤销。** 回溯的含义是"尝试一个选择，探索完再恢复现场，让同一层的下一个选择看到干净的状态"。如果放完第 `r` 行的某列后不撤销，下一个列的尝试看到的是被上一个尝试污染的集合，会把本来合法的位置误判为冲突，解会丢失。

**反例：只检查一个方向的对角线。** 只检查列和主对角线（`r - c`）、漏掉副对角线（`r + c`）：`n = 2` 得到 `1` 个解（正确是 `0`），`n = 3` 得到 `3` 个（正确是 `0`），`n = 4` 得到 `7` 个（正确是 `2`）。`n = 1` 到 `7` 依次得到 `1, 1, 3, 7, 23, 83, 405`，而真实的解数是 `1, 0, 0, 2, 10, 4, 40`。多出来的摆法里有互相沿副对角线攻击的皇后。
