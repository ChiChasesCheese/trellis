## Q
**LC 39 组合总和**｜Medium · LC TikTok 全时段热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 56 次 · 最近 2026-09-05（美国面试记录）

给无重复元素的整数数组 `candidates` 和目标 `target`，找出所有和为 `target` 的不同组合；同一个数字可以无限次重复选取，只要有一个数字的选取次数不同就是不同的组合；保证不同组合数少于 `150` 个。`1 <= candidates.length <= 30`，`2 <= candidates[i] <= 40`，元素互不相同，`1 <= target <= 40`。例：`[2,3,5], 8` → `[[2,2,2,2],[2,3,3],[3,5]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「找出**所有**组合」→ 回溯（backtracking / DFS 搜索树），而不是只求数量的动态规划。
- 「同一个数可以重复选」「组合（不是排列）」→ 递归时带起点 `start`，只能选当前下标及之后的数，并且选完之后下标**不加一**。
- `target <= 40`、`candidates[i] >= 2` → 搜索深度至多 20，不会爆栈；组合数少于 150，规模很小。

**推导链。**
1. 暴力：每一步从全部候选里选一个，和不小于目标就停，得到的是排列，`[2,2,3]`、`[2,3,2]`、`[3,2,2]` 被当成三个答案。
2. 浪费：同一个组合以不同的顺序重复出现。
3. 洞察：规定组合里的数按候选下标非递减出现，递归带 `start`，本层只枚举 `candidates[start:]`，选了第 `i` 个之后传 `i`。
4. 剪枝：先排序，`candidates[i] > remain` 时后面更大的数一定放不下，直接 `break`。

**同模式的题**：LC 40 组合总和 II（每数一次、含重复）、LC 216 组合总和 III、LC 78 子集、LC 518 零钱兑换 II（只求个数）。
