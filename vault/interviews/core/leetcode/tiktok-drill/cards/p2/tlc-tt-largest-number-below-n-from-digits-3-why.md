## Q
**用给定数字拼出小于 N 的最大数**｜正确性

用数组 `digits` 的数字（可重复使用）拼出严格小于 `N` 的最大整数时，为什么「共享前缀越长越好、在第一个不同位取更小的最大数字、之后全取最大数字」一定最优？把上界取成「含 `N` 本身」、或者只试一次最长前缀不回退，各会错成什么样？

## A
**不变量。** 同位数且小于 `N` 的数，都有唯一的「与 `N` 第一个不同的位」`i`，该位更小，前面与 `N` 相同。固定 `i`：前缀已定，第 `i` 位越大越好（取比 `N[i]` 小的最大数字），其后位不受约束，全取最大数字最大。比较不同的 `i`：`i` 较小的候选在位置 `i` 就已经比 `N` 小，`i` 较大的候选在这个位置上和 `N` 相同，所以 `i` 越大的候选越大；从大到小试，第一个成功的就是最大值。同位数都失败时，位数更少的数一定更小，其中最大的是全最大数字。

**反例一：含 `N` 本身。** `N = 22222`，`digits = [2]`。让 `i` 取到 `length` 等于把 `N` 自己当候选，得到 `22222`，违反严格小于；正确答案是 `2222`。

**反例二：不回退。** `N = 2311`，`digits = [2, 3]`。前缀 `23` 可用，但第三位 `1` 没有比它小的数字，只试这一次就退到少一位的 `333`；正确是回到第二位，把 `3` 换成 `2`，其后全取最大数字，得 `2233`（`2233 > 333`，且 `2233 < 2311`）。

**反例三：降位之后后面不放最大数字。** `N = 23415`，`digits = [2, 4, 9]`。在第二位把 `3` 换成 `2` 之后，后面如果放最小数字 `2`，得到 `22222`；后面不再受 `N` 约束，全放最大数字 `9`，得到 `22999`，更大且仍小于 `N`。
