## Q
**LC 253 会议室 II**｜Medium · LC TikTok 热度 88/100（近 3 个月） · 近一年被问：美国 2 次、国内 1 次 · CodeTop 国内累计 16 次 · 最近 2026-10（美国面试记录）

给一个会议时间数组 `intervals`，`intervals[i] = [start_i, end_i]`，返回需要的最少会议室数量；一个会议结束的时刻可以立刻开始下一个会议。`1 <= intervals.length <= 10^4`，`0 <= start_i < end_i <= 10^6`。例：`[[0,30],[5,10],[15,20]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少需要多少个房间」=「同一时刻最多有多少个会议在进行」→ 区间的最大重叠数，扫描线（sweep line）或堆。
- 「最早结束的房间能不能复用」→ 小根堆（min-heap）维护各房间的结束时间。
- 时间范围 `10^6`、`n <= 10^4`：逐时刻计数 `O(范围 * n)` 太慢，`O(n^2)` 两两比较也不理想，目标是 `O(n log n)`。

**推导链。**
1. 暴力：枚举每个时刻，统计覆盖它的会议数，取最大；或对每个会议数它与多少会议重叠。
2. 浪费：时刻太多；真正有意义的只有会议开始的那些时刻。
3. 洞察：按开始时间处理会议，只关心"现有房间里最早空出来的那间有没有空"，最早结束的时间可以用小根堆在 `O(log n)` 内取到。
4. 堆顶 `<=` 新会议开始时间就复用（替换为新会议的结束时间），否则新开一间；最终堆的大小就是峰值房间数。

**同模式的题**：LC 252 会议室、LC 2402 会议室 III、LC 1094 拼车、LC 56 合并区间。
