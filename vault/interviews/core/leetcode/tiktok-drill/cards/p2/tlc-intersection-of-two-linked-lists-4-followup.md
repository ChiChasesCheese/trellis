## Q
**LC 160 相交链表**｜追问

面试官接着问：（1）如果想不到「换表头」的技巧，还有什么 `O(1)` 空间的做法？（2）只想知道两条链表**是否**相交，不要交点？（3）如果链表里**可能有环**怎么办？

## A
1. **先量长度**：分别遍历求出 `m`、`n`，让较长的链表先走 `|m - n|` 步，再两个指针同步前进，遇到的第一个相同节点就是交点；没有则同时到末尾。同样 `O(m + n)` 时间、`O(1)` 空间，多一遍扫描，但逻辑更直观。

```python
def get_len(head: ListNode | None) -> int:
    n = 0
    while head:
        n, head = n + 1, head.next
    return n
```

2. **只判断是否相交**：相交的两条链表共享尾部，所以**最后一个节点**一定是同一个对象。各走到末尾比较最后一个节点即可，`O(m + n)` 时间、`O(1)` 空间。
3. **可能有环**：先分别用快慢指针判环（LC 141）。一个有环、一个无环：不可能相交。都无环：用上面的双指针做法。都有环：看一条链表的入环点出发绕一圈能不能碰到另一条链表的入环点，能则相交（交点可取任意一个入环点）。

**Python 提醒**：用集合做哈希版本时，`set` 里放的是节点对象，按身份哈希；如果节点类重写了 `__eq__` 却没有 `__hash__`，对象就不可哈希，放进集合会报 `TypeError: unhashable type`。不要用 `node.val` 当键，值相同的不同节点会被误判为相交。
