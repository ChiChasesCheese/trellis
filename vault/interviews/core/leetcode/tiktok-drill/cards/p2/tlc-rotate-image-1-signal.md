## Q
**LC 48 旋转图像**｜Medium · LC TikTok 近 6 个月热度 88/100（全时段 38） · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 37 次 · 最近 2026-08-30（国内面试记录）

给一个 `n × n` 的二维矩阵 `matrix`，把图像**顺时针**旋转 `90` 度，必须**原地**修改，不允许另开矩阵。`1 <= n <= 20`，`-1000 <= matrix[i][j] <= 1000`。例：`matrix = [[1,2,3],[4,5,6],[7,8,9]]` → `[[7,4,1],[8,5,2],[9,6,3]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「矩阵旋转 / 翻转」→ **位置映射**：先写出元素 `(i, j)` 旋转后的位置 `(j, n - 1 - i)`，再看能否拆成更简单的变换。
- 「**原地**」→ 不能新建 `n × n` 的矩阵，要用交换；拆出来的两个简单变换（转置、行翻转）都天然原地。
- `n <= 20` → 规模极小，复杂度不是瓶颈，考察点是 `O(1)` 空间和下标的正确性。

**推导链。**
1. 暴力：新建矩阵，`new[j][n - 1 - i] = matrix[i][j]`，`O(n^2)` 空间，违反“原地”。
2. 拆解映射：`(i, j) → (j, n - 1 - i)` = 先 `(i, j) → (j, i)`（沿主对角线转置），再 `(j, i) → (j, n - 1 - i)`（每行左右翻转）。
3. 转置：只交换主对角线以上的元素（`j > i`），每对交换一次；翻转：每行 `reverse()`。
4. 总共 `O(n^2)` 时间，`O(1)` 空间。
5. 备选：一圈一圈处理，每个位置的四个元素循环移位，同样原地，但下标公式更容易写错。
