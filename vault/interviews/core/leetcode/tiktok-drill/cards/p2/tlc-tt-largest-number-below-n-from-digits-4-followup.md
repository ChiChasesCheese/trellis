## Q
**用给定数字拼出小于 N 的最大数**｜追问

给正整数 `N` 和数字数组 `digits`（可重复使用），已经能拼出严格小于 `N` 的最大整数。面试官接着问：（1）改成「不大于 `N`」？（2）`N` 很大，以字符串给出？（3）拼不出时怎么约定返回值？（4）统计能拼出多少个小于 `N` 的数？

## A
1. **不大于 `N`**：严格小于 `N + 1` 就是不大于 `N`，调用 `largest_below(n + 1, digits)`。`largest_below(23416, [2, 4, 9])` 为 `22999`（`23415` 拼不出），`largest_below(22223, [2])` 为 `22222`（`N` 自己能拼出）。
2. **超大 `N`**：代码里只有 `str(n)` 和位操作，把参数直接改成字符串 `s` 即可，最后返回字符串，不必转成整数；位数上万时 `str(top) * k` 和切片仍是 `O(L)`。
3. **返回约定**：先问清。常见做法是返回 `-1`（纯数字场景）、`None`（Python 里更符合习惯）或抛异常；`digits` 全是 `0` 时 `0` 是合法答案（`N > 0` 时），不要误判成无解。
4. **计数**：按位数分段累加，记 `D = |digits|`。短于 `L` 位（`L > 1` 时）：一位数有 `D` 个，`l >= 2` 位有 `(D - [0 在 digits 里]) * D^(l-1)` 个（首位不能是 `0`）。恰好 `L` 位：对每个位置 `i`，前缀 `N[:i]` 全在 `digits` 里才计，累加「第 `i` 位比 `N[i]` 小的数字个数（`i = 0` 且 `L > 1` 时去掉 `0`）乘 `D^(L-i-1)`」，前缀一断就停。这是不带记忆化的数位 DP。

**Python 提醒**：`bisect_left` 要求列表有序，传入未排序的 `digits` 不会报错但结果错；`set(digits)` 去重再 `sorted`，否则重复数字会让 `allowed[j - 1]` 不是严格更小的数字。
