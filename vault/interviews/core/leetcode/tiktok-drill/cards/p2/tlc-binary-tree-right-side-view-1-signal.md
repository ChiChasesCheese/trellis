## Q
**LC 199 二叉树的右视图**｜Medium · LC TikTok 热度 62/100（近 6 个月） · 近一年被问：美国 2 次、国内 4 次 · CodeTop 国内累计 90 次 · 最近 2026-10（美国面试记录）

给二叉树的根节点 `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。节点个数范围 `[0, 100]`，`-100 <= Node.val <= 100`。例：`root = [1,2,3,null,5,null,4]` → `[1,3,4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「从上到下，每个位置看到一个」→ 结果的长度等于树的**深度**，每层贡献一个节点 → **按层处理**：层序遍历（BFS）。
- 「从右侧看到」→ 每一层从右往左看，第一个遇到的就是**该层最右的节点**；它不一定是右孩子，较浅的右子树不会遮挡较深层的左子树节点。
- 节点数至多 `100` → 任何 `O(n)` 解法都足够，重点是定义正确。
- 也可以用深度优先（DFS）：先右后左，每个深度第一次访问到的节点即答案。

**推导链。**
1. 暴力（错误）：从根开始一直走 `right`，得到「最右链」。
2. 错在哪：当右子树比左子树浅时，更深的层只有左子树的节点，它们也能被看到，最右链漏掉了它们。
3. 正确定义：每一层从左到右的最后一个节点。
4. 层序遍历：`level` 保存当前层所有节点，取 `level[-1]`；下一层由当前层每个节点的非空孩子按顺序拼成。`O(n)`。

**同模式的题**：LC 102 二叉树的层序遍历、LC 515 在每个树行中找最大值、LC 637 二叉树的层平均值、LC 116 填充每个节点的下一个右侧节点指针。
