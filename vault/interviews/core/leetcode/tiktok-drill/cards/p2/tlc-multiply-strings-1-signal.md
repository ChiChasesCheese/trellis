## Q
**LC 43 字符串相乘**｜Medium · LC TikTok 热度 50/100（近 6 个月） · 近一年被问：美国 2 次、国内 3 次 · CodeTop 国内累计 49 次 · 最近 2026-09（美国面试记录）

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回它们的乘积，乘积也表示为字符串。不能使用任何内置的 BigInteger 库，也不能直接把输入转换为整数。`1 <= num1.length, num2.length <= 200`，`num1` 和 `num2` 只由数字组成，且不含前导零（除了数字 `0` 本身）。例：`"123"` × `"456"` → `"56088"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「字符串形式的大整数」+「不许转成整数」→ **按位模拟**（simulation）竖式乘法。
- 长度各至多 `200` → 逐位相乘 `O(mn)` = 4×10^4 次，足够；不需要更复杂的算法。
- 乘积的位数至多 `m + n` → 结果可以用定长数组承接。
- 数字之间的位权关系固定：第 `i` 位乘第 `j` 位，位权是 `10^(i+j)` → 位置 `i + j` 可以直接累加。

**推导链。**
1. 暴力：`num1` 的每一位乘整个 `num2`，得到若干个中间字符串，再用字符串加法逐个相加。
2. 浪费：每一行都要自己进位，再做多轮加法，代码长、易错。
3. 关键：个位起第 `i` 位与第 `j` 位的乘积只贡献到结果的第 `i + j` 位。把所有乘积先累加到数组 `res[i + j]`，暂不进位。
4. 最后从低位到高位统一进位一次（`carry, digit = divmod(res[k] + carry, 10)`），再去掉高位多余的 `0`，拼成字符串。

**同模式的题**：LC 415 字符串相加、LC 67 二进制求和、LC 2 两数相加、LC 66 加一。
