## Q
**LC 227 基本计算器 II**｜正确性

为什么除法要写成 `int(a / b)` 而不是 `a // b`？另外，如果不在字符串末尾补哨兵 `"+"`，会漏掉什么？各给一个具体输入。

## A
**不变量。** 每次遇到运算符（或哨兵）时，`num` 是刚读完的完整数字，`op` 是它左边的运算符；结算后栈里的每一项都是最终要相加的、已经算完乘除的项，所以 `sum(stack)` 就是答案。

**反例一：用 `//`。** `s = "3-5/2"`。
- 读到 `-` 时压入 `3`；读到 `/` 时，按左边的 `-` 把 `5` 以 `-5` 压栈；读到哨兵 `+` 时，按 `/` 结算栈顶 `-5` 与 `2` 的除法。
- 题面要求向 0 取整：`-5 / 2` 应得 `-2`，结果 `3 + (-2) = 1`。
- `//` 向下取整，`-5 // 2 = -3`，结果 `3 + (-3) = 0`。正确答案是 `1`。
- 非负数相除两种写法一致，所以示例 `" 3/2 "` 暴露不出这个问题。

**反例二：没有哨兵。** 数字只有在遇到**下一个**运算符时才被结算，表达式最后一个数后面没有运算符。
- `s = "42"`：整个循环里没有任何结算，`stack` 为空，返回 `0`；正确是 `42`。
- `s = "3+2*2"`：最后的 `2` 没有结算，得到 `3 + 2 = 5`；正确是 `7`。
- 补上 `"+"`（`for ch in s + "+"`）后，最后一个数用 `op` 结算，再遇到哨兵结束。

**补充。** 若把乘除也推迟到最后统一做，会得到从左到右的错误优先级：`"3+2*2"` 先算 `3+2=5` 再乘 `2` 得 `10`。
