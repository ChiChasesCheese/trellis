## Q
**LC 20 有效的括号**｜Easy · LC TikTok 热度 62/100 · 近一年被问：美国 3 次、国内 2 次 · CodeTop 国内累计 91 次 · 最近 2026-10（美国面试记录）

给一个只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断它是否有效：左括号必须用相同类型的右括号闭合，左括号必须以正确的顺序闭合，每个右括号都有对应的同类型左括号。`1 <= s.length <= 10^4`。例：`"()[]{}"` → `true`；`"([)]"` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「正确的顺序闭合」「嵌套」→ 最后打开的最先闭合，即**后进先出**（LIFO）→ **栈**。
- 「相同类型」→ 括号有三种，只统计个数是否相等不够，要记住打开的顺序，栈里存字符（或下标）。
- `n <= 10^4`：`O(n^2)` 勉强可以（约 `5 × 10^7`），但一遍扫描 `O(n)` 才是标准解。

**推导链。**
1. 暴力：反复把 `"()"`、`"[]"`、`"{}"` 从字符串里删掉，直到不再变化，看是否剩空串。每轮 `O(n)`，最多 `n/2` 轮，`O(n^2)`。
2. 浪费：每删掉一对，都要重新从头扫描。
3. 洞察：一个右括号只可能匹配「最近一个还没闭合的左括号」，也就是栈顶；不匹配就立刻无效。
4. 最优：遇左括号入栈，遇右括号对照栈顶并弹出，最后栈必须为空。每个字符至多进出一次，`O(n)` 时间，`O(n)` 空间。

**同模式的题**：LC 22 括号生成、LC 32 最长有效括号、LC 921 使括号有效的最少添加、LC 394 字符串解码、LC 150 逆波兰表达式求值。
