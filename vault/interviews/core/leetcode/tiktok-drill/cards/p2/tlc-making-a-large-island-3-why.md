## Q
**LC 827 最大人工岛**｜正确性

翻转一个 `0` 后的面积为什么是「邻居岛屿面积之和 + 1」？为什么邻居编号必须去重？为什么答案初值不能是 `0`？各给一个具体输入。

## A
**不变量。** 翻转 `(i, j)` 之后，新岛 = 这一格 + 所有与它四邻相接的原有岛屿。原有岛屿两两不相连，面积互不重叠，所以新岛面积 = `1 + Σ 不同相邻岛的面积`。远处的岛不受影响，它们的最大面积已被初值覆盖。

**反例一：不去重。** `grid = [[1,1],[1,0]]`。
- 右下角的 `0`，上邻居和左邻居都属于同一座面积为 `3` 的岛。
- 不去重得到 `3 + 3 + 1 = 7`；这个格子只有 `4` 个位置，面积不可能是 `7`。
- 正确是 `3 + 1 = 4`。用集合 `{label[a][b] ...}` 去重。

**反例二：初值取 `0`。** `grid = [[1,1],[1,1]]`。
- 没有 `0` 可翻，第二遍枚举里不会更新 `best`。
- `best = 0` 时返回 `0`；正确是原有最大岛 `4`。初值必须是 `max(size.values(), default=0)`。

**实现上的防护。** 水格的编号是 `0`，一个 `0` 的邻居里常有水格。让 `size` 只包含编号 `1..K`，并用 `size.get(t, 0)` 对水格取 `0`，水格就不会给面积加任何东西，也不用写 `if t`。
