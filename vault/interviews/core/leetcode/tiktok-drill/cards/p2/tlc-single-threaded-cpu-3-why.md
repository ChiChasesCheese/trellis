## Q
**LC 1834 单线程 CPU**｜正确性

事件驱动模拟里，堆里应该装哪些任务？时间在什么时候推进、怎么推进？堆里的键写成 `(执行时间, 入队时间)` 而不是 `(执行时间, 下标)` 会错在哪里？

## A
**不变量。** 每次选任务之前，堆里恰好是“到达时间 `<= t` 且尚未执行”的全部任务，CPU 要选的正是其中 `(执行时间, 下标)` 最小的一个。

**时间推进。** 时间只有两种变化：执行完一个任务后 `t += 执行时间`；以及堆为空时，`t` 跳到下一个任务的到达时刻（CPU 一直空闲，中间没有任何事件，跳过去不改变结果）。每轮选择前先把 `到达时间 <= t` 的任务全部入堆，等于号必不可少：任务恰在 CPU 完成上一个任务的那一刻到达，也要参与本轮竞争。

**反例一：键写错。** 题目规定并列时选**下标最小**。`tasks = [[3,2],[1,4],[2,2]]`：
- 时刻 1 只有任务 `1`，执行到时刻 5；此时任务 `0`（入队时间 3）和任务 `2`（入队时间 2）都已到达，执行时间都是 `2`。
- 按下标决胜：先任务 `0` 再任务 `2`，结果 `[1, 0, 2]`。
- 按入队时间决胜：任务 `2` 的入队时间更早，先执行，结果 `[1, 2, 0]`，错了。

**反例二：没有空闲跳转。** `tasks = [[1,1],[100,1]]`：第一个任务在时刻 2 完成，之后没有任何任务到达，堆为空；不跳时间直接 `heappop` 抛 `IndexError`。如果改成每秒 `t += 1` 空转，到达时间 `10^9` 时要循环十亿次，超时。
