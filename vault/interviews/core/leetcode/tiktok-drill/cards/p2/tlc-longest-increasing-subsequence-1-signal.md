## Q
**LC 300 最长递增子序列**｜Medium · LC TikTok 热度 88/100（近 6 个月） · 近一年被问：美国 1 次、国内 3 次 · CodeTop 国内累计 109 次 · 最近 2026-09-16（CodeTop）

给整数数组 `nums`，求其中**最长严格递增子序列**的长度；子序列不要求连续，但要保持原有相对顺序。`1 <= nums.length <= 2500`，`-10^4 <= nums[i] <= 10^4`。进阶要求 `O(n log n)`。例：`[10,9,2,5,3,7,101,18]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子序列（不连续）+ 最长 + 严格递增」→ 最长递增子序列（LIS）的标准问题，动态规划（dynamic programming）。
- `n <= 2500`：`O(n^2)` 的 `dp[i]` 能过；进阶写明 `O(n log n)` → 把状态换成「每个长度的最小结尾」，用二分。
- 「严格」递增 → 二分用 `bisect_left`；允许相等才用 `bisect_right`。

**推导链。**
1. 暴力：枚举所有子序列，`O(2^n)`。
2. 动态规划：`dp[i]` = 以 `nums[i]` 结尾的最长长度，`dp[i] = 1 + max(dp[j] for j < i if nums[j] < nums[i])`，`O(n^2)`。
3. 浪费：每个 `i` 都扫全部 `j`；对同一个长度，只有结尾最小的子序列有用，因为结尾越小越容易往后接。
4. 洞察：长度为 `k+1` 的最小结尾 `tails[k]` 随 `k` 严格递增，所以能二分：新数 `x` 放到第一个 `>= x` 的位置，替换或追加，答案是 `len(tails)`，`O(n log n)`。
