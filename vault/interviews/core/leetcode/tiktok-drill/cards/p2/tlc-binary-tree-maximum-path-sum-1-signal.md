## Q
**LC 124 二叉树中的最大路径和**｜Hard · LC TikTok 近 6 个月热度 53/100（全时段 62） · 近一年被问：美国 5 次、国内 0 次 · CodeTop 国内累计 79 次 · 最近 2026-10-13（国内 CodeTop）

二叉树中的**路径**是一条节点序列，相邻节点之间有边，同一个节点在序列中至多出现一次；路径至少包含一个节点，不一定经过根节点。**路径和**是路径中各节点值的总和。给根节点 `root`，返回其最大路径和。树中节点数目范围 `[1, 3 * 10^4]`，`-1000 <= Node.val <= 1000`。例：`root = [-10,9,20,null,null,15,7]` → `42`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「不一定经过根节点的任意路径」→ 每条路径都有唯一的**最高点**（离根最近的节点）→ 枚举最高点，左右各取一条向下的链：**树形 DP**（DP on trees）。
- 「至少包含一个节点」+ 值可为**负** → 负的子树宁可不要；全是负数时答案是最大的单个节点，不是 `0`。
- 一个节点向父亲汇报时，路径只能继续向上走一条边 → 汇报值只能含**一侧**，而「拐弯」的候选答案要同时含两侧。
- `n = 3×10^4` → `O(n)` 的后序遍历；链状树的深度也达 `3×10^4`，递归要留意栈深。

**推导链。**
1. 暴力：枚举所有点对，求两点间的路径和，`O(n^2)` 对，每对还要找路径。
2. 浪费：路径可以按最高点分组。固定最高点 `v`，最好的路径是 `v.val` 加上左子树和右子树各自「向下最大单链和」（负的取 `0`）。
3. 关键：每个节点只需向父亲汇报一个数 `gain = val + max(左, 右, 0)`；同时用 `val + 左 + 右` 刷新全局答案。
4. 后序遍历（孩子先于父亲）一遍完成，`O(n)`。
