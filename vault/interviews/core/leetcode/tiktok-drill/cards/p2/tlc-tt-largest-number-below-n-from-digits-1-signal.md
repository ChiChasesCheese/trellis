## Q
**用给定数字拼出小于 N 的最大数**｜Medium · 近一年被问：美国 1 次、国内 9 次 · 最近 2026-10（面试记录）

给正整数 `N` 和数字数组 `digits`（元素 `0` 到 `9`，每个数字可使用任意多次），拼出**严格小于** `N` 的最大整数并返回；不能有前导零（`0` 本身除外），拼不出返回 `-1`。`1 <= N <= 10^18`，`1 <= len(digits) <= 10`。例：`N = 23415`，`digits = [2, 4, 9]` → `22999`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「严格小于 `N` 的最大值」→ 数位贪心：高位决定大小，答案应尽量贴着 `N`——共享一段前缀，在尽量靠后的位置变小。
- 「数字可重复使用」→ 一旦某位已经比 `N` 小，后面不再有约束，全放最大数字即可。
- `N <= 10^18`：不能从 `N - 1` 往下枚举，位数最多 19，按位处理 `O(L)`。
- 「严格」「不能有前导零」「无解返回 `-1`」→ 边界要单独处理：`N` 本身不算，首位不能是 `0`，只剩一位时 `0` 合法。

**推导链。**
1. 暴力：从 `N - 1` 往下逐个检查每一位是否都在 `digits` 里，最坏 `O(N)`。
2. 浪费：绝大多数数在高位就不合法。
3. 洞察：答案与 `N` 的第一个不同位在 `i`，该位取比 `N[i]` 小的最大数字，之后全取最大数字；前缀 `N[:i]` 必须全在 `digits` 里；`i` 越大答案越大，所以从最长可用前缀往回试，第一个成功的就是答案。
4. 最优：同位数都失败，则答案是少一位的全最大数字；总计 `O(L log |digits|)`。

**同模式的题**：LC 902 最大为 N 的数字组合、LC 738 单调递增的数字、LC 670 最大交换、LC 1215 步进数。
