## Q
**LC 224 基本计算器**｜追问

面试官接着问：（1）把乘除也加进来（LC 772）？（2）嵌套特别深（比如 10^5 层括号）时，递归写法会怎样？（3）表达式里有变量或函数调用怎么扩展？

## A
1. **加入乘除**：不再能只靠符号；改用两个栈。数字栈存操作数，运算符栈存 `+ - * / (`。遇到运算符，先把栈顶优先级不低于它的运算符归约，再入栈；遇到 `)` 一直归约到 `(`。`"2*(5+5*2)/3+(6/2+8)"` → `21`。
2. **深嵌套**：递归下降写法的深度等于括号嵌套深度，`"(" * 100000 + "1" + ")" * 100000` 会触发 `RecursionError`，而显式栈的版本直接得到 `1`。需要递归时，要么 `sys.setrecursionlimit`（Python 3.12+ 纯 Python 递归不再受 C 栈限制，但内存仍线性增长），要么改写成栈。
3. **变量与函数**：把「数」换成「项」：词法分析（tokenize）先把字符串切成数字、标识符、运算符，再对标识符做符号查找；多项式的情形（LC 770）把值换成「项到系数」的字典，加减合并同类项，乘法做卷积。

**Python 提醒**：`ch in "+-"` 是子串判断，`ch` 是单个字符时与「是否等于 `+` 或 `-`」一致；但如果 `ch` 是空串，`"" in "+-"` 为 `True`，从 `s.split()` 之类的来源取字符时要小心。逐字符循环里 `str.isdigit()` 对 ASCII 数字安全，输入不可信时改用 `"0" <= ch <= "9"`。
