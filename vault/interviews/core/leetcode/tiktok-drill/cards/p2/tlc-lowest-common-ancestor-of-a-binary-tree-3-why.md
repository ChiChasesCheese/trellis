## Q
**LC 236 二叉树的最近公共祖先**｜正确性

后序递归求最近公共祖先时，为什么「左右两边都非空就返回当前节点」是对的？为什么碰到 `p` 或 `q` 就能直接返回、不必再往下找？给一个「左边非空就提前返回」会出错的输入。

## A
**不变量。** `lca(node)` 的返回值有三种含义：`None` 表示 `node` 的子树里既没有 `p` 也没有 `q`；`p` 或 `q` 表示子树里只找到了这一个；非空且不是 `p`、`q` 的节点表示 `p`、`q` 都在子树里，它就是它们的最近公共祖先。

**为什么左右都非空就返回当前节点。** 左右子树各自的返回值非空，说明 `p`、`q` 分居在两个子树（各自的返回值就是 `p`、`q` 本身，因为一个子树里只找到一个时，返回的是被找到的那个）。它们在当前节点处第一次汇合，所以当前节点是最深的公共祖先。

**为什么碰到 `p` 就能直接返回。** 若 `q` 在 `p` 的子树里，`p` 自己就是答案（节点可以是自己的祖先）；若 `q` 不在，那 `p` 的下面没有别的目标，往下找也找不到，返回 `p` 即可，上层会把它和另一侧的汇报合并。

**反例。** `root = [3,5,1,6,2,0,8,null,null,7,4]`：
- 把合并写成「左边非空就返回左边」（`if left: return left`）。`p = 5, q = 1` 时，到根 `3`，左子树返回 `5`，直接返回 `5`，右子树里的 `1` 根本没看；正确答案是 `3`。
- 碰到 `p` 之后不返回、继续往下递归。`p = 5, q = 4` 时，`5` 的子树里能找到 `4`，`5` 会把 `4` 往上传，最后返回 `4`；正确答案是 `5`。
