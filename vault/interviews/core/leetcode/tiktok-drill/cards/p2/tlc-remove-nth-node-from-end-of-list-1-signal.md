## Q
**LC 19 删除链表的倒数第 N 个节点**｜Medium · 近一年被问：美国 2 次、国内 6 次 · CodeTop 国内累计 51 次 · 最近 2026-10（面试记录）

给一个链表的头结点 `head`，删除链表的倒数第 `n` 个结点，返回新链表的头结点。结点数 `sz` 满足 `1 <= sz <= 30`，`0 <= Node.val <= 100`，`1 <= n <= sz`。进阶：只扫描一趟。例：`head = [1,2,3,4,5]`，`n = 2` → `[1,2,3,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**倒数**第 `n` 个」+ 单链表（不知道长度，不能回头）→ **快慢指针保持固定间距**：两个指针相隔 `n`，前者到尾时后者就在倒数位置。
- 「只扫描一趟」→ 不能先遍历求长度，间距法正好省掉那一趟。
- 「删除」→ 需要拿到**前驱**结点；头结点没有前驱，所以要加**哑结点**（dummy）统一处理。
- `sz <= 30`：规模很小，暴力两趟也能过，这里考的是模式。

**推导链。**
1. 暴力：第一趟求长度 `L`，第二趟走到第 `L - n - 1` 个结点，删除它的下一个。两趟，`O(L)`。
2. 浪费：第一趟只为了知道长度。
3. 间距法：`fast` 先走 `n` 步，然后 `fast`、`slow` 同速前进。`fast` 到达最后一个结点时，`slow` 恰好是倒数第 `n + 1` 个结点，也就是待删结点的前驱。
4. 头结点可能被删：让两个指针都从哑结点出发，哑结点是头结点的前驱。
5. 一趟扫描，`O(sz)` 时间，`O(1)` 空间。

**同模式的题**：LC 876 链表的中间结点、LC 141 / 142 环形链表、LC 61 旋转链表、剑指 Offer 22 链表中倒数第 k 个节点。
