## Q
**LC 1143 最长公共子序列**｜Medium · LC TikTok 热度 38/100 · 近一年被问：美国 0 次、国内 5 次 · CodeTop 国内累计 61 次 · 最近 2026-10-25（CodeTop）

给两个字符串 `text1` 和 `text2`，返回它们最长**公共子序列**的长度，不存在则返回 `0`。子序列是不改变相对顺序、删掉若干字符（可以不删）得到的串，如 `"ace"` 是 `"abcde"` 的子序列。`1 <= text1.length, text2.length <= 1000`，只含小写英文字母。例：`text1 = "abcde"`，`text2 = "ace"` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个字符串」+「子序列」+「最长」→ **二维前缀 DP**：每个字符要么参与匹配，要么被跳过，状态就是「两个串各处理到哪」。
- 「子序列」而不是「子串」→ 字符不连续也行，失配时不能清零，要继承已有的最优。
- `m, n <= 1000` → `O(mn) = 10^6` 刚好；`2^m` 的枚举不行。

**推导链。**
1. 暴力：枚举 `text1` 的全部 `2^m` 个子序列，逐个判断是不是 `text2` 的子序列，指数级。
2. 递归：`f(i, j)` 看两个串的末尾，相等就一起后退（`1 + f(i-1, j-1)`），不等就丢掉任意一个末尾（取 `max`）。不记忆化仍是指数级。
3. 浪费：`f(i, j)` 只有 `m * n` 种参数，大量重复计算 → 记忆化，或自底向上填表，`O(mn)`。
4. 填表：第 0 行、第 0 列是 `0`（空串）；每格只依赖左上 `dp[i-1][j-1]`、上方 `dp[i-1][j]`、左边 `dp[i][j-1]`，按行填完 `(m+1) × (n+1)` 的表，答案是 `dp[m][n]`，`O(mn)` 时间和空间。

**同模式的题**：LC 72 编辑距离、LC 583 两个字符串的删除操作、LC 1035 不相交的线、LC 712 最小 ASCII 删除和、LC 718 最长重复子数组。
