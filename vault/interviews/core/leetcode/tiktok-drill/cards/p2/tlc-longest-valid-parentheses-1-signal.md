## Q
**LC 32 最长有效括号**｜Hard · LC TikTok 近 6 个月热度 50/100（全时段 50） · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 70 次 · 最近 2026-10（国内面试记录）

给一个只包含 `'('` 和 `')'` 的字符串 `s`，找出最长的有效（格式正确且连续）括号子串的长度。`0 <= s.length <= 3 * 10^4`。例：`s = "(()"` → `2`；`s = ")()())"` → `4`；`s = ""` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号匹配」→ **栈**：后出现的左括号先被闭合。
- 「最长**连续**有效子串」→ 需要知道有效段的**左端点**，所以栈里存**下标**，不是字符；等价的另一条思路是动态规划 `dp[i]`（以 `i` 结尾的最长有效长度）。
- 「只有两种括号」→ 还可以只用两个计数器，正反各扫一遍，做到 `O(1)` 空间。
- `n <= 3 * 10^4`：`O(n^2)` 约 `4.5 * 10^8`，太慢；要 `O(n)`。

**推导链。**
1. 暴力：枚举所有子串并判断有效，`O(n^3)`；每个起点向右扫并维护计数，`O(n^2)`。
2. 观察：有效段被「无法匹配的括号」切开。把这些分界的下标记在栈里，每个 `')'` 匹配成功后，栈顶就是当前有效段左边的最近分界。
3. 洞察：以 `i` 结尾的最长有效长度是 `i - 栈顶`。栈底放哨兵 `-1`，让从头开始的段也适用同一公式。
4. 最优：左括号压下标；右括号先弹栈，栈空则把自己的下标压进去当新分界，否则更新答案。每个下标进出各一次，`O(n)` 时间，`O(n)` 空间。

**同模式的题**：LC 20 有效的括号、LC 22 括号生成、LC 301 删除无效的括号、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号。
