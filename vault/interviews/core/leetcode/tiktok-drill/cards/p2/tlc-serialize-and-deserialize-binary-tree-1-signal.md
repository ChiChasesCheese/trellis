## Q
**LC 297 二叉树的序列化与反序列化**｜Hard · LC TikTok 近 6 个月热度 50/100（全时段 62） · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 25 次 · 最近 2026-02-04（美国面试记录）

序列化是把数据结构转换为字符串，反序列化是反过来重建原结构。设计算法实现二叉树的序列化与反序列化：不限定具体格式，只需保证一棵二叉树可以被序列化为一个字符串，并且这个字符串可以被反序列化为原始的树结构。树中结点数在 `[0, 10^4]` 内，`-1000 <= Node.val <= 1000`。例：`root = [1,2,3,null,null,4,5]` 往返后仍是 `[1,2,3,null,null,4,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「序列化 + 反序列化，必须还原原来的树」→ **编码要可逆**：字符串里必须同时携带**值**和**结构**。
- 值可以重复、可以为负 → 不能靠「前序 + 中序」两个序列重建（那需要值互不相同）；要在单个序列里直接编码结构。
- 「格式不限」→ 自由选择遍历方式：前序 DFS 或层序 BFS，加上**空位标记**（`null` / `#`）。
- 结点数到 `10^4`，一条链的深度也是 `10^4` → 递归 DFS 可行，但要留意 Python 的递归上限；不想递归就用层序（迭代）。

**推导链。**
1. 暴力：只记录前序（或层序）里的值。
2. 错在哪：丢了结构，`[1,2]`（2 是左孩子）和 `[1,null,2]`（2 是右孩子）都变成 `"1,2"`。
3. 关键：把每个空孩子也写成一个占位符。这样序列里每个真实节点后面都紧跟「它的两个孩子位」，树与序列一一对应。
4. 前序实现：序列化是「根、左、右」递归输出，空节点写 `#`；反序列化用同一个迭代器按同样顺序递归读：`#` 返回 `None`，否则建节点、先左后右。`O(n)`。
