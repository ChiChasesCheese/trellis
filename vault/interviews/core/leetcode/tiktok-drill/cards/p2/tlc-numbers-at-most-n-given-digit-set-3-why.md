## Q
**LC 902 最大为 N 的数字组合**｜正确性

数位计数为什么不会重复、也不会遗漏？“贴不住就提前返回”和“全贴住再加 `1`”各是什么意思？给出漏掉这两处会出错的输入，写出错误输出和正确输出。

## A
**不变量。** 每个 `<= n` 且能拼出的数，恰好属于下面一类：位数少于 `L`；位数等于 `L` 且与 `n` 第一次不同的位置是 `i`，该位更小（`i = 0..L-1` 各一类）；与 `n` 完全相同。这些类互不相交、合起来覆盖全部。第 `i` 类要成立，前 `i` 位必须与 `n` 的前 `i` 位完全一致，所以每处理一位之前都要确认 `n` 的前一位在 `digits` 里。

**提前返回。** 若 `n[i]` 不在 `digits` 里，没有任何数能与 `n` 的前 `i+1` 位一致，后面的类全是空的。继续往后累加，会把根本拼不出的前缀当成存在。反例：`digits = ["1","3","5","7"]`，`n = 100`，第二位 `'0'` 不在其中。正确答案是 `4 + 16 = 20`（一位数和两位数）；继续累加并 `+1` 得到 `21`。

**全贴住加 `1`。** 每一位都在 `digits` 里，说明 `n` 自己能拼出来，而前面各类都是“严格小于 `n`”，不含它。反例：`digits = ["7"]`，`n = 77`，前面累计得到 `1`（只有 `7`），不加 `1` 就漏掉了 `77`，应为 `2`。
