## Q
**LC 236 二叉树的最近公共祖先**｜Medium · LC TikTok 热度 53/100 · 近一年被问：美国 2 次、国内 5 次 · CodeTop 国内累计 134 次 · 最近 2026-10-19（面试记录）

给一棵二叉树和其中两个节点 `p`、`q`，找出它们的**最近公共祖先**（LCA）：既是 `p` 的祖先又是 `q` 的祖先、且深度尽可能大的节点；一个节点也可以是它自己的祖先。节点数在 `[2, 10^5]` 内，节点值互不相同，`p != q`，`p`、`q` 都在树中。例：`root = [3,5,1,6,2,0,8,null,null,7,4]`，`p = 5, q = 1` → `3`；`p = 5, q = 4` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最近公共祖先」→ 祖先关系是**向上**的：最直觉的是自底向上递归（后序）让每棵子树汇报「里面找到了谁」；备选是给每个节点记**父指针**。
- 只说「二叉树」、没说「二叉搜索树」→ 节点值没有顺序，不能靠比大小往左右走（那是 LC 235）。
- `n` 到 `10^5`：`O(n)` 的一遍遍历；递归深度等于树高，单链树深度 `10^5`，超过 CPython 默认递归上限（约 `1000`）会 `RecursionError`，面试里要说出来，并给出显式栈的备选。

**推导链。**
1. 暴力：分别求出根到 `p`、根到 `q` 的路径，取最长公共前缀的最后一个节点。`O(n)`，但路径回溯和保存都要自己写。
2. 洞察：不必保存路径，让每棵子树只回答「里面有没有 `p` 或 `q`，是谁」：碰到 `p` 或 `q` 就返回自己；左右两边都非空，说明 `p`、`q` 分居两侧，当前节点就是汇合点；只有一边非空就原样往上传。
3. 实现：后序递归，约 5 行；`O(n)` 时间，`O(h)` 栈空间。
4. 备选：祖先也可以靠父指针往上走，两条祖先链在根处汇合（和相交链表 LC 160 同构），递归深度不再成问题，但要 `O(n)` 额外空间。

**同模式的题**：LC 235 二叉搜索树的最近公共祖先、LC 160 相交链表、LC 1650 含父指针的最近公共祖先、LC 1123 最深叶节点的最近公共祖先。
