## Q
**LC 160 相交链表**｜Easy · LC TikTok 近 6 个月热度 53/100（全时段 50） · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 116 次 · 最近 2026-09-17（国内 CodeTop）

给两个单链表的头节点 `headA` 和 `headB`，找出并返回两个链表相交的起始节点；不相交则返回 `null`。数据保证无环，函数返回后链表必须保持原结构。节点数 `1 <= m, n <= 3 * 10^4`，`1 <= Node.val <= 10^5`。相交指同一个节点对象，不是值相同。例：`listA = [4,1,8,4,5]`，`listB = [5,6,1,8,4,5]`，共享从值 `8` 开始的后三个节点 → 返回值为 `8` 的节点。进阶：`O(m + n)` 时间、`O(1)` 内存。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两条链表」+「`O(1)` 空间」→ **双指针**，不能用哈希集合存节点。
- 「相交」→ 交点之后两条链表**共享同一段尾部**；差别只在交点之前各自独有的部分。
- 「同一个节点」→ 比较的是对象身份（`is`），不是 `val`；值相同的节点很多，不能当判据。
- `m, n <= 3 * 10^4`：`O(m · n)` 约 `9 × 10^8`，太慢；要线性。

**推导链。**
1. 暴力一：每个 A 节点对每个 B 节点比地址，`O(m · n)`。
2. 暴力二：A 的节点放进集合，扫 B 找第一个命中的，`O(m + n)` 时间，`O(m)` 空间，进阶不满足。
3. 洞察：设两条链表独有部分长 `x`、`y`，共享 `c`。让指针 `a` 走完 A 再走 B，指针 `b` 走完 B 再走 A，到交点的步数都是 `x + y + c + 1`（含越过末尾的那一步），于是它们同时到达交点。
4. 最优：不相交时 `c = 0`，两个指针同时走到 `None`，循环结束，返回 `None`。`O(m + n)` 时间，`O(1)` 空间。
