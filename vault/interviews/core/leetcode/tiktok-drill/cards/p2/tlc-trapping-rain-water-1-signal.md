## Q
**LC 42 接雨水**｜Hard · LC TikTok 热度 88/100 · 近一年被问：美国 1 次、国内 4 次 · CodeTop 国内累计 130 次 · 最近 2026-10-28（面试记录）

给 `n` 个非负整数表示宽度为 1 的柱子的高度图，求下雨后一共能接多少单位的雨水。`n == height.length`，`1 <= n <= 2 * 10^4`，`0 <= height[i] <= 10^5`。例：`height = [4,2,0,3,2,5]` → `9`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每个位置上方能存多少水」是**逐位置**的量，而且由左右两侧各自的最高柱子共同决定 → 前缀最大 / 后缀最大（prefix / suffix max）。
- 只关心「两端向中间收拢时较矮的一侧」→ 对撞双指针（two pointers），可以把空间从 `O(n)` 压到 `O(1)`。
- `n <= 2 * 10^4`：`O(n^2)` 理论上能过，但面试要的是 `O(n)`。

**推导链。**
1. 暴力：每个 `i` 向左扫求最大、向右扫求最大，水量 `min(左最大, 右最大) - height[i]`，共 `O(n^2)`。
2. 浪费：相邻位置的左最大、右最大差别极小，却从头各扫一遍。
3. 先优化一步：预处理 `left_max[]` 和 `right_max[]` 两个数组，`O(n)` 时间、`O(n)` 空间。
4. 关键洞察：若 `height[left] < height[right]`，`left` 右边必有不低于 `height[right]` 的柱子，所以 `left` 的水位只取决于左侧最大值，可以立刻结算并右移 `left`；否则对称地结算右侧。两指针走一遍，`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 11 盛最多水的容器、LC 84 柱状图中最大的矩形、LC 407 接雨水 II、LC 238 除自身以外数组的乘积。
