## Q
**LC 198 打家劫舍**｜正确性

打家劫舍的转移为什么是 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`？为什么“偷奇数位或偷偶数位取较大者”的贪心是错的？滚动变量写成 `skip = max(skip, take)` 再 `take = skip + x` 会错在哪里？

## A
**不变量。** `dp[i]` 是只考虑前 `i + 1` 间房时的最大金额。

**转移为什么对。** 最优方案里第 `i` 间房要么没偷，金额等于只考虑前 `i` 间房的最优 `dp[i-1]`；要么偷了，那么第 `i-1` 间一定没偷，剩下的部分是前 `i-1` 间房的最优 `dp[i-2]` 加上 `nums[i]`。两种情况覆盖了所有方案，取较大者。

**反例一：奇偶贪心。** `nums = [2,1,1,2]`。偷奇数位（第 1、3 间）得 `2 + 1 = 3`，偷偶数位（第 2、4 间）得 `1 + 2 = 3`，贪心答案 `3`；但偷第 1 间和第 4 间（不相邻）得 `2 + 2 = 4`。最优方案之间可以隔两间，不局限于隔一间。

**反例二：更新顺序。** `skip, take` 必须同时更新，用的都是上一间房的值。若先 `skip = max(skip, take)`，再 `take = skip + x`，新的 `take` 用的是已经包含“上一间偷了”的 `skip`，等于允许连续偷两间：
- `[1,2,3,1]`：正确 `4`，错误写法得到 `7`（把四间房全偷了）。
- `[2,7,9,3,1]`：正确 `12`，错误写法得到 `22`（全部加起来）。

Python 的元组赋值 `skip, take = max(skip, take), skip + x` 先对右边求值，天然避免这个问题。
