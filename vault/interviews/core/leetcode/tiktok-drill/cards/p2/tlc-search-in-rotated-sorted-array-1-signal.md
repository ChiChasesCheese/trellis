## Q
**LC 33 搜索旋转排序数组**｜Medium · LC TikTok 近 6 个月热度 53/100（全时段 75） · 近一年被问：美国 3 次、国内 4 次 · CodeTop 国内累计 162 次 · 最近 2026-10-15（国内 CodeTop）

升序且值互不相同的数组在某个未知下标处向左旋转（如 `[0,1,2,4,5,6,7]` 变成 `[4,5,6,7,0,1,2]`）。给旋转后的 `nums` 和 `target`，返回 `target` 的下标，不存在返回 `-1`，要求 `O(log n)`。`1 <= nums.length <= 5000`，`-10^4 <= nums[i] <= 10^4`，所有值互不相同，`-10^4 <= target <= 10^4`。例：`[4,5,6,7,0,1,2], 0` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「有序数组」+「`O(log n)`」→ 二分查找（binary search）。
- 「旋转」破坏了整体有序，但保留了**局部有序**：取中点后，左右两半至少有一半是普通升序 → 二分的每一步先判断哪一半有序。
- 「值互不相同」→ 比较 `nums[lo]` 和 `nums[mid]` 就能判断哪半有序；有重复时会失效（LC 81）。

**推导链。**
1. 暴力：线性扫描，`O(n)`，不满足要求。
2. 两步法：先二分找旋转点（最小值），再在对应一段上做普通二分，两次 `O(log n)`，可行但代码长。
3. 一步法洞察：旋转点只可能在 `[lo, mid]` 或 `[mid, hi]` 其中一个里，另一个一定是有序的。`nums[lo] <= nums[mid]` 说明左半有序。
4. 在有序的那半里判断 `target` 是否落在它的值域内：在就去那一半，不在就去另一半。每步排除一半，`O(log n)`。

**同模式的题**：LC 81 搜索旋转排序数组 II（有重复）、LC 153 寻找旋转数组最小值、LC 34 查找元素的第一个和最后一个位置、LC 162 寻找峰值。
