## Q
**LC 542 01 矩阵**｜正确性

多源 BFS 为什么能保证每个格子第一次被访问时的层数就是最短距离？只从一个 `0` 出发会错在哪？

## A
**不变量。** 队列里的格子距离按非递减顺序排列，且只相差 0 或 1：先出队的是第 `d` 层，它们的邻居被赋值 `d + 1` 并排在后面。因此一个格子第一次被赋值时，一定来自当前最小的层。

**为什么对。** 所有 `0` 同时在第 0 层，等价于加一个到每个 `0` 距离为 0 的虚拟起点；从这个起点出发的 BFS，到每个格子的最短路径恰好等于到最近 `0` 的距离。

**反例。** 只把第一个 `0` 入队：`mat = [[0,1,1,1,0]]` 得到 `[[0,1,2,3,4]]`；正确是 `[[0,1,2,1,0]]`，因为右端的 `0` 离后两个格子更近。

**对比单趟 DP。** `[[1,1,0]]` 只从左上扫一遍，左边两格拿不到右边 `0` 的信息；正确结果是 `[[2,1,0]]`，需要再做一趟反向扫描。
