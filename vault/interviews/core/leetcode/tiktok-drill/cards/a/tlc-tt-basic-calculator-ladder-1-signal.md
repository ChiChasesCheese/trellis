## Q
**计算器梯度题（先校验再求值）**｜Hard · 近一年被问：美国 6 次、国内 2 次 · 最近 2026-09-09（面试记录）

给一个字符串表达式 `s`，实现整数计算器。面试官逐级加条件：（1）只有 `+ - * /` 和空格，无括号，处理优先级，除法向零取整；（2）再加括号和一元负号；（3）先校验表达式是否合法（空串、非法字符、括号不配对、连续运算符、缺操作数），合法才计算。`1 <= len(s) <= 3 * 10^5`，操作数是非负整数，一元负号只出现在开头或 `(` 之后，除数不为 `0`。例：`"3+2*2"` → `7`，`"-(2+3)"` → `-5`，`"2*-3"` 不合法。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「运算符有优先级、有括号」→ 栈：运算符栈存「还没轮到算」的运算符，数字栈存已就绪的操作数。
- 「长度 `3 * 10^5`、括号可以任意嵌套」→ 递归下降会 `RecursionError`，用显式栈迭代。
- 「一元负号」→ 开头或 `(` 之后的 `-`，补一个 `0` 变成二元减法，不用专门的一元运算符。
- 「先校验」→ 一个「期待操作数 / 期待运算符」的状态机加括号深度，一遍扫描 `O(n)`。

**推导链。**
1. 暴力：反复找最内层括号，算出子串替换回去，每次重扫整个字符串，`O(n^2)`。
2. 浪费：同一段被反复扫描；其实只要知道「这个运算符现在能不能算」。
3. 洞察：栈顶运算符优先级不低于新来的，它的左右操作数都已就绪，立刻算（同级左结合）；否则新运算符入栈等右操作数。`(` 当隔板，`)` 把括号内算完。
4. 最优：每个数字、运算符各进出栈一次，`O(n)` 时间、`O(n)` 空间；校验在求值之前用状态机拦截非法输入。

**同模式的题**：LC 227 基本计算器 II、LC 224 基本计算器、LC 772 基本计算器 III、LC 150 逆波兰表达式求值、LC 394 字符串解码。
