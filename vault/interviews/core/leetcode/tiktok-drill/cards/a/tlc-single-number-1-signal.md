## Q
**LC 136 只出现一次的数字**｜Easy · 近一年被问：美国 0 次、国内 3 次 · CodeTop 国内累计 9 次 · 最近 2026-10-20（面试记录）

非空整数数组 `nums`，除一个元素只出现一次外，其余每个都恰好出现两次，找出那个落单的数，要求线性时间、常数额外空间。`1 <= nums.length <= 3 * 10^4`，`-3 * 10^4 <= nums[i] <= 3 * 10^4`。例：`[4,1,2,1,2]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「其余都出现两次」→ **成对抵消**，找一个自己和自己运算得到单位元的操作：异或（`a ^ a = 0`）。
- 「线性时间 + 常数空间」→ 哈希表（`O(n)` 空间）、排序（`O(n log n)` 时间）都被排除。
- 数据范围小（`3 * 10^4`）说明不是在卡常数，而是在考**有没有想到位运算**。

**推导链。**
1. 暴力：`Counter(nums)` 数次数，找计数为 1 的，`O(n)` 时间 `O(n)` 空间，违反空间。
2. 排序后相邻比较：省了哈希表，但 `O(n log n)`，违反时间。
3. 观察：需要一个交换律、结合律成立、且 `x ⊕ x = 单位元` 的运算 → 异或，单位元是 0。
4. 从 0 异或全部元素，成对的抵消，剩下落单的：`O(n)` 时间 `O(1)` 空间。

**同模式的题**：LC 137 只出现一次的数字 II、LC 260 只出现一次的数字 III、LC 268 丢失的数字、LC 389 找不同。
