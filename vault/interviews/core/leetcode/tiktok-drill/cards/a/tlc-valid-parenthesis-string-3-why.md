## Q
**LC 678 有效的括号字符串**｜正确性

区间贪心里，为什么 `lo` 每一步都要截到 `0`？为什么区间里的每个整数都真的可达（不会出现「区间里有洞」）？给出不截断就答错的输入。

## A
**不变量。** 处理完前 `i` 个字符后，「前缀中没有任何时刻未配对数为负」的所有取法所能达到的未配对数集合，恰好是 `[lo, hi]` 里的全部整数。

**为什么没有洞。** 每个字符对集合的作用只有两种：`'('` / `')'` 把集合整体平移；`'*'` 把集合 `S` 变成 `S ∪ (S - 1) ∪ (S + 1)`。区间做并集、平移后仍是区间，所以始终连续。

**为什么要截断。** 未配对数是一个计数，负数在语义上不存在：前缀里 `')'`（含当 `')'` 用的星号）比 `'('` 多，意味着有一个 `')'` 没有可配对的左括号，这条取法已经失败。截断相当于把这些失败的取法丢掉，只保留非负的那部分；不截断，失败的取法会混进区间，后面的 `'('` 把它们「救活」。

**反例 `"*("`。** 正确答案是 `False`：星号在 `'('` 之前，不管它当什么，结尾的 `'('` 都没有后面的 `')'` 配对。
- 不截断：读 `'*'` 后 `lo = -1`、`hi = 1`；读 `'('` 后 `lo = 0`、`hi = 2`，末尾 `lo == 0`，返回 `True`，错。
- 截断：读 `'*'` 后 `lo = max(-1, 0) = 0`；读 `'('` 后 `lo = 1`，末尾 `lo != 0`，返回 `False`，对。

**提前失败为什么只看 `hi`。** `hi` 是最乐观的取法（所有星号都当 `'('`）下的未配对数。连它都小于 `0`，说明前缀里的 `')'` 太多，任何取法都无解，可以立刻返回 `False`。
