## Q
**LC 123 买卖股票的最佳时机 III**｜写出 Python 实现

`prices` 长度 `1` 到 `10^5`，每个值在 `[0, 10^5]`。最多完成两笔交易（必须先卖出才能再买入），返回最大利润，没有盈利机会时为 `0`。

## A
**思路。** 四个变量：`buy1` 是第一次持有时手里的最大现金（`-价格`），`sell1` 是第一次卖出后的最大现金，`buy2`、`sell2` 同理。逐天更新：每个状态要么沿用，要么由前一个状态加上今天的买卖得到。`sell2` 就是答案。

```python
def max_profit(prices: list[int]) -> int:
    buy1 = buy2 = -prices[0]               # 持有股票时手里的最大现金（买入花钱，所以是负的）
    sell1 = sell2 = 0                      # 卖出之后手里的最大现金
    for p in prices:
        buy1 = max(buy1, -p)               # 第一次买入：从零现金开始买
        sell1 = max(sell1, buy1 + p)       # 第一次卖出
        buy2 = max(buy2, sell1 - p)        # 第二次买入：用第一次赚到的钱买
        sell2 = max(sell2, buy2 + p)       # 第二次卖出
    return sell2
```

运行：`[3,3,5,0,0,3,1,4]` → `6`，`[1,2,3,4,5]` → `4`，`[7,6,4,3,1]` → `0`，`[1]` → `0`，`[1,5,2,10]` → `12`；`10^5` 个随机价格约 `0.02` 秒。

**复杂度。** 时间 `O(n)`，一次扫描；空间 `O(1)`，四个变量。

**写法要点。** 初值 `buy = -prices[0]` 表示第一天就买入；`sell = 0` 表示什么都不做；链式赋值 `buy1 = buy2 = ...` 对不可变整数安全；四行更新的顺序按状态链排列，同一天内用刚更新的值是允许的（同一天买了又卖利润为 `0`），所以不必保存旧值；少于两笔交易的情形自然被包含：`sell2` 至少等于 `sell1`（第二次在同一天买入再卖出，利润为 `0`）。
