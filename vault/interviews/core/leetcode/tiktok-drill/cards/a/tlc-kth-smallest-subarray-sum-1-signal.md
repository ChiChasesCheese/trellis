## Q
**LC 1918 第 K 小的子数组和**｜Medium · TikTok 高频

给长度为 `n` 的整数数组 `nums` 和整数 `k`，返回第 `k` 小的子数组和（子数组非空且连续，不同位置的子数组各算一个）。`1 <= n <= 2 * 10^4`，`1 <= nums[i] <= 5 * 10^4`，`1 <= k <= n * (n + 1) / 2`。例：`nums = [2,1,3]`，`k = 4` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「第 `k` 小」+「答案是一个数值」→ **二分答案**：答案落在 `[min, sum]` 这个有界区间，并且"不超过 `x` 的个数"随 `x` 单调。
- 「元素全为正」→ 子数组和随右端点单调，**双指针**能在 `O(n)` 内数出和不超过 `x` 的子数组个数。
- `n = 2 * 10^4` → 子数组约 `2 * 10^8` 个，不能全部枚举排序；`k` 可达 `2 * 10^8`，堆法也不行。

**推导链。**
1. 暴力：枚举所有子数组和，排序后取第 `k` 个，`O(n^2 log n)` 时间、`O(n^2)` 空间。
2. 改写问题：第 `k` 小 = 最小的 `x` 满足「和 `<= x` 的子数组个数 `>= k`」。
3. 数个数：右端点前进，窗口和超过 `x` 就收缩左端，以 `right` 结尾、和不超过 `x` 的子数组有 `right - left + 1` 个，累加，`O(n)`。
4. 在 `[min(nums), sum(nums)]` 上二分，约 `30` 轮，总 `O(n log S)`。

**同模式的题**：LC 378 有序矩阵中第 K 小的元素、LC 668 乘法表中第 k 小的数、LC 719 找出第 K 小的数对距离、LC 875 爱吃香蕉的珂珂。
