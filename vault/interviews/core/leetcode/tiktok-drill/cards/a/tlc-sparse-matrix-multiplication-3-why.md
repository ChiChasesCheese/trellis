## Q
**LC 311 稀疏矩阵的乘法**｜正确性

为什么跳过 `mat1[i][k] == 0` 和 `mat2[k][j] == 0` 不会漏掉结果？循环里最容易写错的两个地方是什么？给出各自的错误输出。

## A
**不变量。** 处理完 `mat1` 的第 `i` 行后，`res[i][j]` 等于 `Σ_k mat1[i][k] * mat2[k][j]` 中所有非零项之和。零乘任何数是零，加零不改变和，所以跳过它们的结果与不跳过完全一致。

**错误 1：共享行。** `res = [[0] * n] * m` 里 `m` 个元素是同一个列表对象。示例 1 `[[1,0,0],[-1,0,3]] x [[7,0,0],[0,0,0],[0,0,1]]`：第 0 行写入 `res[0][0] += 7`，再写 `res[1][0] += -7`，两行是同一个对象，最后同步成 `[[0, 0, 3], [0, 0, 3]]`；正确 `[[7, 0, 0], [-7, 0, 3]]`。用 `[[0] * n for _ in range(m)]`。

**错误 2：赋值代替累加。** 同一个 `res[i][j]` 会被不同的 `k` 多次命中。`[[1, 1]] x [[1], [1]]`：`k = 0` 和 `k = 1` 都写到 `res[0][0]`，写成 `=` 得 `[[1]]`，写成 `+=` 得 `[[2]]`，后者才对。
