## Q
**LC 47 全排列 II**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 20 次 · 最近 2025-10-20（CodeTop）

给一个可能含重复数字的数组 `nums`，按任意顺序返回所有不重复的全排列。`1 <= nums.length <= 8`，`-10 <= nums[i] <= 10`。例：`[1,1,2]` → `[[1,1,2],[1,2,1],[2,1,1]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**排列」→ 输出本身是指数级，只能**回溯**（backtracking）：选一个、递归、撤销。
- `n <= 8`：`8! = 40320`，枚举全部可行；不要找多项式解。
- 「含重复 + 不重复结果」→ **同层去重**：同一个位置上相同的值只能试一次。这是组合 / 排列 / 子集这一族题的统一手法。

**推导链。**
1. 暴力：`itertools.permutations` 生成全部 `n!` 个，再 `set` 去重。最坏 `[1,1,1,1,1,1,1,1]` 生成 40320 个只留 1 个。
2. 浪费在哪：同一层选「第一个 `1`」或「第二个 `1`」，两棵子树完全一样，一半以上的搜索白做。
3. 关键洞察：去重要发生在**决策点**，而不是结果上——把「选哪个下标」改成「选哪个值」。
4. 最优：`Counter` 记每个值剩余数量；每层只遍历不同的值，`count[x] > 0` 才能选；选完回溯时把计数加回。每条叶子是一个不同的排列，没有重复搜索。
