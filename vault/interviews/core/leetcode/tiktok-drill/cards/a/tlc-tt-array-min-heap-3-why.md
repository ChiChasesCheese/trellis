## Q
**手写最小堆**｜正确性

`pop` 把末尾元素放到根之后下沉，为什么每一步必须和**较小**的孩子比较？只和左孩子比会错在哪里？再说明为什么建堆要从最后一个非叶子节点倒着做。

## A
**不变量。** 堆序：每个节点都不大于它的孩子；形状：数组前 `n` 个位置恰好是一棵完全二叉树，所以不会出现空洞。下沉开始时，只有被换上来的那个节点 `x` 可能违反堆序，它下面的两棵子树本身都是合法的堆。

**为什么取较小孩子。** `x` 要往下换时，换上来的孩子会成为另一个孩子的父节点，它必须不大于那个兄弟，所以只能换上**较小**的那个。换成较大的，兄弟会比新父亲更小，堆序当场被破坏。

**反例：只比左孩子。** 堆 `[1, 5, 2, 6, 7, 3, 4]`：
- 第一次 `pop` 返回 `1`，末尾的 `4` 放到根，数组是 `[4, 5, 2, 6, 7, 3]`。
- 只和左孩子 `5` 比：`5` 不比 `4` 小，下沉直接停了；堆里 `2` 却在 `4` 的下面。
- 第二次 `pop` 返回 `4`，正确答案是 `2`。取较小孩子 `2` 后根变成 `2`，`4` 下沉到它原来的位置。

**为什么倒着建堆。** 下沉要求“两棵子树已经是堆”。倒着处理时，处理到节点 `i` 的时候，下标比 `i` 大的节点都已处理完，它的两棵子树已经合法；正着处理，下沉时子树还是乱的。`[4, 3, 2, 1]` 正着建出 `[2, 1, 4, 3]`，连续 `pop` 得 `[2, 1, 3, 4]`；倒着建出 `[1, 3, 2, 4]`，连续 `pop` 得 `[1, 2, 3, 4]`。
