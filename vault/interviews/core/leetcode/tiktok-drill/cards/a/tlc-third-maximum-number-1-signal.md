## Q
**LC 414 第三大的数**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-01-20（CodeTop）

给整数数组 `nums`，返回所有**不同**数字中第三大的数；不存在则返回最大的数。`1 <= nums.length <= 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。进阶：`O(n)`。例：`[2,2,3,1]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「第 3 大」，`k = 3` 是常数 → 扫描时维护**前 k 名候选**，不必排序整个数组。
- 「不同数字中」→ 必须**去重**，重复值不占名次。
- 值域含 `-2^31` → 用 `-2^31` 当「空位」哨兵会和真实值混淆。
- 「进阶 `O(n)`」→ 一遍扫描、每步常数时间。

**推导链。**
1. 暴力：`sorted(set(nums), reverse=True)` 取第三个，`O(n log n)`。
2. 浪费：只要前三名，却给所有数排了序。
3. 关键：任何时刻只需记住「至今最大的 3 个不同值」；新数要么已在其中（跳过），要么插入后挤掉第四名。
4. 最优：候选列表至多 4 个元素，每步插入和截断是常数时间，`O(n)` 时间、`O(1)` 空间。
