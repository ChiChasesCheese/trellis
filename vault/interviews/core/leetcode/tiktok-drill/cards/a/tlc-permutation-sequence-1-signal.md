## Q
**LC 60 排列序列**｜Hard · TikTok 高频

集合 `[1,2,...,n]` 的所有排列按字典序编号（`n = 3` 时是 `"123"`、`"132"`、`"213"`、`"231"`、`"312"`、`"321"`）。给定 `n` 和 `k`，返回第 `k` 个排列。`1 <= n <= 9`，`1 <= k <= n!`。例：`n = 4, k = 9` → `"2314"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「第 `k` 个字典序排列」→ 不生成，按块跳：首位相同的排列连续成块，每块大小相同。
- 「`1 ... n` 全排列、字典序」→ 阶乘进制（factorial number system）：每一位的基数是递减的阶乘。
- `n <= 9`：`9! = 362880`，暴力生成也能过，说明考点是不生成前 `k - 1` 个。
- `k` 从 `1` 开始：先转成 `0` 开始的名次再做除法。

**推导链。**
1. 暴力：生成全部 `n!` 个排列，排序后取第 `k` 个，`O(n * n!)`。
2. 稍好：从最小排列出发调用 `k - 1` 次「下一个排列」（LC 31），`O(k * n)`。
3. 浪费：到达第 `k` 个之前，把前面所有排列都走了一遍。
4. 洞察：首位确定后，后面 `n - 1` 位的排列数是 `(n-1)!`；排列按首位分块，每块 `(n-1)!` 个。所以 `(k-1) // (n-1)!` 是首位在剩余数字里的排名，`(k-1) % (n-1)!` 是块内排名。
5. 最优：循环 `n` 次，每次一次 `divmod` 和一次 `pop`，`O(n^2)`。

**同模式的题**：LC 46 全排列、LC 31 下一个排列、LC 1415 长度为 n 的开心字符串中字典序第 k 小的字符串、LC 440 字典序的第K小数字。
