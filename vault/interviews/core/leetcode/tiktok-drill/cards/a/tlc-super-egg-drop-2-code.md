## Q
**LC 887 鸡蛋掉落**｜写出 Python 实现

`k` 枚相同的鸡蛋，`n` 层楼，高于某层 `f` 扔下会碎、`f` 及以下不会。求最坏情况下确定 `f` 的最少操作次数。`1 <= k <= 100`，`1 <= n <= 10^4`。要求在 `k = 100`、`n = 10^4` 下瞬间返回。

## A
**思路。** `dp[m][j]` 是用 `j` 枚蛋、最多操作 `m` 次，最坏情况下最多能确定的楼层数。第 `0` 行全是 `0`（没有操作什么也确定不了），第 `0` 列也是 `0`（没有蛋）。第 `m` 次操作扔下一枚蛋：碎了用 `j-1` 枚蛋、`m-1` 次覆盖下面，没碎用 `j` 枚蛋、`m-1` 次覆盖上面，再加被扔的这一层，所以 `dp[m][j] = dp[m-1][j-1] + dp[m-1][j] + 1`。一行一行往下加，直到 `dp[m][k] >= n`，答案就是行号 `m`。

```python
def super_egg_drop(k: int, n: int) -> int:
    # dp[m][j]：用 j 枚蛋、最多操作 m 次，最坏情况下最多能确定多少层；第 0 行：0 次操作什么也确定不了
    dp = [[0] * (k + 1)]
    while dp[-1][k] < n:
        m = len(dp)                                # 要填的新一行：操作 m 次
        dp.append([0] * (k + 1))                   # dp[m][0] = 0：没有蛋什么也确定不了
        for j in range(1, k + 1):
            dp[m][j] = dp[m - 1][j - 1] + dp[m - 1][j] + 1    # 碎了 + 没碎 + 被扔的这一层
    return len(dp) - 1                             # 第一次 dp[m][k] >= n 的行号 m
```

运行：`(1, 2)` → `2`，`(2, 6)` → `3`，`(3, 14)` → `4`，`(1, 1)` → `1`，`(2, 100)` → `14`，`(100, 10**4)` → `14`，`(2, 10**4)` → `141`。

**复杂度。** 时间 `O(k · m)`，`m` 是答案：`k = 1` 时 `m = n`，`k = 100`、`n = 10^4` 时 `m = 14`，几十次运算；空间 `O(k · m)`，整张表。

**写法要点。** 事先不知道答案 `m` 有多大，所以表从第 `0` 行起，用 `dp.append([0] * (k + 1))` 一行一行往下加，`dp[-1][k]` 就是最新一行的结果；`m = len(dp)` 在追加之前取，正好是新一行的行号；新行默认全是 `0`，`dp[m][0]` 不用再写；每一格只读上一行 `dp[m - 1]`；`while dp[-1][k] < n` 同时承担"循环到够为止"和"统计行数"，不需要二分外层。最后返回 `len(dp) - 1`，因为第 `0` 行是基础行、不算一次操作：写成 `len(dp)` 会多 `1`，`(3, 14)` 得到 `5`。
