## Q
**LC 1074 元素和为目标值的子矩阵数量**｜Hard · 字节 高频

给矩阵 `matrix` 和目标值 `target`，返回元素总和等于 `target` 的**非空子矩阵**数量（坐标不同就算不同）。`1 <= matrix.length, matrix[0].length <= 100`，`-1000 <= matrix[i][j] <= 1000`，`-10^8 <= target <= 10^8`。例：`matrix = [[1,-1],[-1,1]], target = 0` → `5`（两个 `1x2`、两个 `2x1`、一个 `2x2`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**数个数**」+「子矩阵和等于目标」→ **前缀和 + 哈希计数**（二维版的 LC 560）。
- 元素有**负数** → 滑动窗口 / 双指针失效，不能靠单调性。
- 固定上下边界后，每列变成一个数，剩下的左右边界就是**一维**的「和为 `target` 的子数组个数」→ 降维。
- `100 × 100` → `O(R^2 · C) = 10^6`，轻松；`O(R^2 C^2)` 约 `2.5 * 10^7` 个子矩阵，勉强可过但不是预期解。

**推导链。**
1. 暴力：枚举两个角并求和，`O(R^3 C^3)`；二维前缀和 `O(1)` 求和，降到 `O(R^2 C^2)`。
2. 浪费：上下边界固定后，枚举左右边界 `C^2` 对，其实只是一维计数问题。
3. 一维计数：前缀和 `s_j`，以第 `j` 列结尾、和为 `target` 的个数 = 此前出现过前缀和 `s_j - target` 的次数 → 哈希表计数，`O(C)`。
4. `bottom` 下移一行只需把新行加进列和数组 `O(C)`；总时间 `O(R^2 · C)`，空间 `O(C)`。

**同模式的题**：LC 560 和为 K 的子数组、面试题 17.24 最大子矩阵、LC 363 矩形区域不超过 K 的最大数值和、LC 974 和可被 K 整除的子数组。
