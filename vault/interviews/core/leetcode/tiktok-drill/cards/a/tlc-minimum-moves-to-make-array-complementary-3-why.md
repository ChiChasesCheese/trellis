## Q
**LC 1674 使数组互补的最少操作次数**｜正确性

为什么一对 `(a, b)` 让和变成 `s` 的代价是：`s == a+b` 为 `0`，`s` 在 `[min(a,b)+1, max(a,b)+limit]` 内为 `1`，其余为 `2`？区间左端写成 `min(a,b)` 会在哪个输入上出错？

## A
**不变量。** 对固定的 `s`，各对的最少操作数互相独立，总代价是它们之和；差分前缀和在每个 `s` 上恰好还原这个和。

**为什么是这三档。**
- 不用改：`a + b == s`。
- 改一个：只改 `a`，需要新值 `s - b` 落在 `[1, limit]`，即 `s` 在 `[1 + b, limit + b]`；只改 `b`，同理 `s` 在 `[1 + a, limit + a]`。两个区间的并集，因为 `lo <= hi`，是 `[lo + 1, hi + limit]`（两段有重叠或相邻时连成一段）。
- 其余的 `s`：两个数都要改，总能做到（把它们改成和为 `s` 的两个合法数，`2 <= s <= 2 * limit`），代价 `2`。

**反例（左端写成 `lo`）。** `nums = [1,2,2,1]`，`limit = 2`，两对是 `(1, 1)` 和 `(2, 2)`。
- 目标和 `s = 2`：`(1, 1)` 代价 `0`；`(2, 2)` 要把某个 `2` 改成 `0`，不合法，只能两个都改成 `1`，代价 `2`，总代价 `2`。
- 错误的左端 `lo`：`(2, 2)` 的区间变成 `[2, 4]`，把 `s = 2` 算成代价 `1`，总代价 `1`，答案输出 `1`。
- 正确区间 `[3, 4]`，`s = 2` 的总代价是 `2`，全局最小也是 `2`（`s = 3` 时每对各改一个，`1 + 1 = 2`；`s = 4` 时同理 `2`）。
