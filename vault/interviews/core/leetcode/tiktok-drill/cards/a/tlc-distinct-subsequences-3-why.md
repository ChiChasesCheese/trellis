## Q
**LC 115 不同的子序列**｜正确性

转移 `dp[i][j] = dp[i-1][j] + (s[i-1] == t[j-1]) * dp[i-1][j-1]` 为什么不会重复计数也不会漏？第 0 列为什么必须每一行都是 `1`，字符相等时丢掉「不用」那一项会错成什么样？给出具体输入和输出。

## A
**不变量。** `dp[i][j]` 是 `s[:i]` 中等于 `t[:j]` 的子序列的下标选法总数。

**转移为什么对。** 看 `s[i - 1]` 有没有被用上，两类选法互斥且完备：
- **没有用** `s[i - 1]`：这些选法就是 `s[:i - 1]` 中等于 `t[:j]` 的选法，共 `dp[i-1][j]`；
- **用了** `s[i - 1]`：它必须配 `t` 的最后一个字符 `t[j - 1]`，所以要求 `s[i - 1] == t[j - 1]`；前面 `j - 1` 个字符由 `s[:i - 1]` 配出，共 `dp[i-1][j-1]`。
按「是否用最后一个字符」分类，同一种下标选法只会落在一类，不会重复也不会漏。

**边界。** `dp[i][0] = 1` 对每个 `i` 都成立：`t` 为空，从任意前缀里什么都不选，恰有一种选法，它是所有计数的起点；`dp[0][j] = 0`（`j > 0`）：空的 `s` 凑不出非空的 `t`。

**反例一：第 0 列只在 `dp[0][0]` 置 `1`。** 非空前缀的 `dp[i][0]` 变成 `0`，起点丢了：`s = "aaa"`，`t = "a"` 得到 `1`，正确是 `3`；`s = "babgbag"`，`t = "bag"` 得到 `3`，正确是 `5`。

**反例二：相等时只取 `dp[i-1][j-1]`。** 把「不用 `s[i - 1]`」这一类丢了：`s = "rabbbit"`，`t = "rabbit"` 得到 `1`，正确是 `3`（三个 `b` 里去掉任意一个）。

**反例三：相等时加同一行的 `dp[i][j-1]`。** 这等于 `s[i - 1]` 先配了 `t[j - 2]` 又配 `t[j - 1]`，同一个字符用了两次：`s = "a"`，`t = "aa"` 得到 `1`，正确是 `0`；`s = "aaa"`，`t = "aa"` 得到 `6`，正确是 `C(3, 2) = 3`。
