## Q
**LC 204 计数质数**｜Medium · TikTok 高频

给非负整数 `n`，返回严格小于 `n` 的质数个数。`0 <= n <= 5 * 10^6`。例：`n = 10` → `4`（`2, 3, 5, 7`），`n = 1` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「某个范围内**所有**满足条件的数」+ 条件由**因子/倍数**关系定义 → **筛法**（sieve），一次预处理回答整段。
- 只问个数，不问判断某一个数 → 不需要对每个数独立证明。
- `n <= 5 * 10^6`：`O(n)` 的数组装得下（`bytearray` 约 5MB），`O(n sqrt n)`（约 `10^10`）不行，要 `O(n log log n)` 或 `O(n)`。

**推导链。**
1. 暴力：对每个 `k < n` 试除到 `sqrt(k)`，`O(n sqrt n)`。
2. 浪费：每个数各判各的，没有利用「合数一定是某个质数的倍数」。
3. 倒过来：找到质数 `p` 就把 `2p, 3p, ...` 全划掉，划过的数不再判。
4. 两个剪枝：从 `p*p` 开始划（`p*k`，`k<p`，已被更小的质因子划过）；`p` 只枚举到 `sqrt(n-1)`（合数必有不超过其平方根的质因子）。
5. 结果 `O(n log log n)`，Python 里用 `bytearray` 切片赋值一次划掉整串倍数。
