## Q
**LC 517 超级洗衣机**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-04-26（CodeTop）

`n` 台洗衣机排成一排，`machines[i]` 是第 `i` 台里的衣服件数。每一步可以任选 `m` 台（`1 <= m <= n`），被选中的每台**同时**把自己的一件衣服送到相邻的一台。求让所有洗衣机的衣服件数相等的最少步数；做不到返回 `-1`。`n == machines.length`，`1 <= n <= 10^4`，`0 <= machines[i] <= 10^5`。 例：`[1,0,5]` → `3`，`[0,2,0]` → `-1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每步任意多台**同时**送一件」→ 不要逐步模拟，找**瓶颈下界**：哪些量每步最多减少 1。
- 「排成一排、只能送给相邻」→ 任一条相邻边两侧的总余量必须穿过这条边 → **前缀和**。
- `n` 到 `10^4`、件数到 `10^5` → 模拟、BFS 都不行，要 `O(n)` 公式。
- 「所有台相等」→ 先判 `total % n`，不整除直接 `-1`。

**推导链。**
1. 暴力：BFS 搜索所有状态，状态数随件数指数增长。
2. 下界一（边）：第 `i` 条边左侧的总余量 `flow` 必须全部经这条边过去，每步最多过一件 → 步数 `>= |flow|`。
3. 下界二（机器）：多出 `surplus` 件的机器每步只能送出一件 → 步数 `>= surplus`；缺衣服的机器可以两边同时收，不算下界。
4. 两类下界的最大值可以达到，一趟扫描求出，`O(n)`。
