## Q
**LC 1131 绝对值表达式的最大值**｜Medium · 字节 高频

给两个长度相等的整数数组 `arr1`、`arr2`，返回 `|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|` 在所有下标 `0 <= i, j < n` 上的最大值。`2 <= n <= 40000`，`-10^6 <= arr1[i], arr2[i] <= 10^6`。例：`arr1 = [1,2,3,4], arr2 = [-1,4,5,6]` → `13`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个下标 `i, j` 之间一串**绝对值之和**的最大值」= 三维点 `(arr1[i], arr2[i], i)` 之间的**曼哈顿距离**最大值。
- `n = 40000` → `O(n^2) = 1.6 * 10^9` 不行，要 `O(n)` 或 `O(n log n)`。
- 绝对值是可分离的障碍：`|a_i - a_j|` 同时依赖 `i` 和 `j`。用 `|x| = max(x, -x)` 把它**展开成符号组合**，每个组合都能拆成「只与 `i` 有关的量 − 只与 `j` 有关的量」。
- 拆开后求「某个量的最大值 − 最小值」→ 一次扫描。

**推导链。**
1. 暴力：双重循环枚举 `(i, j)`，`O(n^2)`。
2. 洞察 1：三个绝对值相加 = `2^3 = 8` 种符号选择 `s1 x + s2 y + s3 z` 的最大值。
3. 洞察 2：固定一种符号，表达式 = `f(i) - f(j)`，其中 `f(i) = s1 a_i + s2 b_i + s3 i`；对所有 `(i, j)` 的最大值是 `max f - min f`。
4. 符号 `s` 与 `-s` 的 `f` 互为相反数，结果相同 → 只需 `4` 种（固定 `i` 项的符号为 `+`）。总时间 `O(4n)`，空间 `O(n)`。

**同模式的题**：LC 1330 翻转子数组得到最大的数组值、LC 296 最佳的碰头地点、LC 3102 最小化曼哈顿距离、LC 462 最少移动次数使数组元素相等 II。
