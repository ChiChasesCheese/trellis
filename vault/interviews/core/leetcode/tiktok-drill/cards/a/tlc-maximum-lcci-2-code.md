## Q
**面试题 16.07 最大数值**｜写出 Python 实现

写一个方法，返回两个整数 `a`、`b` 中较大的那个，不得使用 if-else 或其他比较运算符（也不能调用 `max`）。

## A
**思路。** 算 `diff = a - b`，从它的符号位得到 0/1 的 `neg`（`a < b` 时为 1）。返回 `a - neg * diff`：`neg = 1` 时是 `a - (a - b) = b`，`neg = 0` 时是 `a`。

```python
def maximum(a: int, b: int) -> int:
    diff = a - b
    neg = (diff >> diff.bit_length()) & 1    # a < b 时 diff 为负，右移后全是 1，& 1 得 1；否则得 0
    return a - neg * diff                    # neg = 1：a - (a - b) = b；neg = 0：a
```

运行：`1, 2` → `2`，`2, 1` → `2`，`5, 5` → `5`，`-3, -7` → `-3`，`2147483647, -1` → `2147483647`，`-2147483648, 2147483647` → `2147483647`，`10**30, -10**30` → `1000000000000000000000000000000`。

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**写法要点。** `int.bit_length()` 给出表示 `|diff|` 所需的位数，右移这么多位保证符号位被完整移出，因此对任意大小的整数都成立；Python 的 `>>` 对负数是算术右移（补 1），所以结果是 `-1` 或 `0`，`& 1` 把它变成 `1` 或 `0`；最后的选择用乘法代替分支。
