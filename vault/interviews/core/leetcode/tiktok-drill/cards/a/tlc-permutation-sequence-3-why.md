## Q
**LC 60 排列序列**｜正确性

为什么「`(k-1) // (n-1)!` 就是首位在剩余数字里的排名」？每一步的不变量是什么？给出 `k` 不减一、块大小写错时的具体输入。

## A
**不变量。** 每轮开始时，`digits` 是升序的剩余数字，共 `m` 个；`k` 是「在以已确定前缀开头的所有排列中，按字典序的 `0` 开始的名次」，满足 `0 <= k < m!`。

**为什么商就是首位排名。** 字典序下，所有以最小的剩余数字开头的排列排在最前，一共 `(m-1)!` 个；接着是以次小数字开头的 `(m-1)!` 个，以此类推。所以名次 `k` 落在第 `k // (m-1)!` 块，对应首位是第 `k // (m-1)!` 小的剩余数字；块内的名次是 `k % (m-1)!`，在剩余 `m - 1` 个数字的排列里按字典序编号，满足不变量，规模减一。

**终止。** 最后一轮 `m = 1`，块大小 `0! = 1`，`q = k = 0`，取走唯一的数字，`k` 变成 `0`。

**反例一：不减一。** `n = 3, k = 3`，直接用 `k = 3`：
- 第一轮 `divmod(3, 2) = (1, 1)`，首位取第 `1` 小的 `2`，剩余 `[1, 3]`，`k = 1`。
- 第二轮 `divmod(1, 1) = (1, 0)`，取 `3`；第三轮取 `1`，得到 `"231"`。
- 正确是 `"213"`；`n = 3, k = 6` 时第一轮 `divmod(6, 2) = (3, 0)`，`digits.pop(3)` 抛 `IndexError`。

**反例二：块大小写成 `factorial(remaining)`。** `n = 3, k = 3`（`k` 已减一为 `2`）：
- 第一轮 `divmod(2, 6) = (0, 2)`，首位取 `1`；第二轮 `divmod(2, 2) = (1, 0)`，取剩余 `[2, 3]` 里的第 `1` 小即 `3`；第三轮取 `2`。
- 得到 `"132"`，正确是 `"213"`。
