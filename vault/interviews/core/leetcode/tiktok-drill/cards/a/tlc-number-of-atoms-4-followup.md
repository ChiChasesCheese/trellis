## Q
**LC 726 原子的数量**｜追问

面试官接着问：（1）结果里的数字会非常大，怎么办？（2）支持 `[]`、`{}` 这几种括号？（3）不用正则，手写扫描怎么写？

## A
1. **数字很大**：Python 的 `int` 是任意精度，不会溢出，`cnt * mult` 直接乘；Java / C++ 里用 `BigInteger`，或者按题目要求对某个模数取余（乘法逐步取模）。
2. **多种括号**：把 token 正则里的括号类扩成 `[(\[{]` 和 `[)\]}]`，栈里同时记录括号类型（或另开一个栈），弹出时校验类型匹配；计数的逻辑不变。
3. **手写扫描**：用下标 `i` 扫描：遇到 `(` 压栈；遇到 `)` 用内层 `while` 读后面的数字；遇到大写字母先吞小写字母得到原子名，再读数字。比正则多十几行，但不依赖 `re`，面试官要求「不许用正则」时用。

**Python 提醒**：`re.finditer` 中 `m.groups()` 里没参与匹配的组是 `None`，参与但匹配空串的 `(\d*)` 是 `""`；两者都为假值，`int(x or 1)` 能一次处理，但如果写成 `int(x) if x is not None else 1`，空串会让 `int("")` 抛 `ValueError`。
