## Q
**LC 516 最长回文子序列**｜Medium · CodeTop 国内累计 9 次 · 最近 2026-04-06（CodeTop）

给字符串 `s`，求其中最长**回文子序列**的长度（子序列可以不连续，但不能改变顺序）。`1 <= s.length <= 1000`，只含小写英文字母。例：`"bbbab"` → `4`（`"bbbb"`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「回文」→ 结构是「两端配对、向内收缩」，天然的状态是区间 `[i, j]` → **区间 DP**。
- 「子序列」（不要求连续）→ 两端不等时可以跳过一端，转移是 `max`；若是「子串」则要用中心扩展或 Manacher。
- `n <= 1000` → `O(n^2) = 10^6` 个状态可行，`O(2^n)` 枚举不可行。
- 等价视角：回文子序列 = `s` 与 `s[::-1]` 的公共子序列 → 也可以当 **LCS** 做。

**推导链。**
1. 暴力：枚举 `2^n` 个子序列，每个 `O(n)` 判回文。
2. 浪费：大量子序列共享相同的「外层配对 + 内部区间」结构，内部区间被重复求解。
3. 关键：看区间两端。`s[i] == s[j]` 时让它们做最外层一对不会更差，答案 = 内部区间 + 2；不等时至少一端不在答案里，答案 = `max(去左端, 去右端)`。
4. 最优：`O(n^2)` 个区间，`i` 从后往前、`j` 从 `i+1` 往后填表，`O(n^2)` 时间。

**同模式的题**：LC 5 最长回文子串、LC 1143 最长公共子序列、LC 1312 让字符串成为回文串的最少插入次数、LC 312 戳气球。
