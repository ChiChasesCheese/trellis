## Q
**LC 74 搜索二维矩阵**｜Medium · 字节高频

给 `m x n` 整数矩阵 `matrix`，满足：每行从左到右非严格递增；每行第一个整数大于前一行最后一个整数。判断 `target` 是否在矩阵中，要求 `O(log(m * n))`。`1 <= m, n <= 100`，`-10^4 <= matrix[i][j], target <= 10^4`。例：`matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]`、`target = 3` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`O(log(m * n))`」→ 二分查找，而且是对**整个**矩阵一次二分（`log(m·n)`）。
- 「每行有序」+「行首大于上一行行尾」→ 按行拼起来是一个升序的一维数组 → 虚拟展开，不用真的复制。
- 下标换算：一维下标 `k` 对应行 `k // n`、列 `k % n`，`n` 是每行的长度（列数）。
- 对比 LC 240：只要求每行、每列各自有序时，行间不连续，不能展开成一维，只能阶梯搜索 `O(m + n)`。

**推导链。**
1. 暴力：逐个元素扫描，`O(m·n)`。
2. 次优：先二分找行、再二分找列，`O(log m + log n)`，但要处理两次边界。
3. 洞察：两个条件让整个矩阵展开后单调，直接在虚拟下标 `[0, m·n)` 上二分。
4. 用左闭右开模板找第一个 `>= target` 的位置，`divmod(mid, n)` 得到行列，结束后检查等于目标；不创建新数组，空间 `O(1)`。

**同模式的题**：LC 240 搜索二维矩阵 II、LC 704 二分查找、LC 35 搜索插入位置、LC 378 有序矩阵中第 K 小的元素。
