## Q
**LC 198 打家劫舍**｜Medium · LC TikTok 热度 68/100 · 近一年被问：美国 1 次、国内 5 次 · CodeTop 国内累计 38 次 · 最近 2026-10-17（CodeTop）

一排房屋，`nums[i]` 是第 `i` 间的现金；相邻两间不能同时偷，求最多能偷多少。`1 <= nums.length <= 100`，`0 <= nums[i] <= 400`。例：`nums = [2,7,9,3,1]` → `12`（偷第 1、3、5 间）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「相邻不能同时选」+「最大总和」→ **一维线性 DP**：决策从左到右推进，之前的决策只通过“上一间偷没偷”影响后面。
- 每间房只有“偷 / 不偷”两种选择，状态极少 → 可以用两个变量滚动，`O(1)` 空间。
- `n <= 100` → 指数枚举 `2^100` 不可行，说明要多项式解；数据小也容许 `O(n^2)`，但最优是 `O(n)`。

**推导链。**
1. 暴力：每间房偷或不偷，枚举 `2^n` 种方案，剔除相邻同偷的。
2. 递归：`f(i) = max(f(i+1), nums[i] + f(i+2))`，不记忆化会指数级重复。
3. 浪费：`f(i)` 只有 `n` 个不同参数 → 记忆化或自底向上，`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，`O(n)`。
4. `dp[i]` 只依赖前两项 → 两个变量滚动。用“不偷当前房 `skip` / 偷当前房 `take`”两个状态：新 `skip = max(旧 skip, 旧 take)`，新 `take = 旧 skip + x`。
5. 一趟扫描 `O(n)`，空间 `O(1)`。
