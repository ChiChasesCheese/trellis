## Q
**LC 478 在圆内随机生成点**｜正确性

为什么半径要取 `R * sqrt(U)`，直接取 `R * U` 为什么不均匀？

## A
**不变量。** 均匀分布意味着点落进任一区域的概率等于该区域面积除以圆面积。半径不超过 `ρ` 的小圆面积是 `πρ^2`，所以必须有 `P(r <= ρ) = (ρ / R)^2`。取 `r = R * sqrt(U)` 时，`P(r <= ρ) = P(U <= (ρ / R)^2) = (ρ / R)^2`，正好成立；角度独立均匀，所以同一半径的圆环上也是均匀的。

**反例。** 取 `r = R * U` 时 `P(r <= ρ) = ρ / R`，半径 `R / 2` 以内的概率是 `1/2`，而半径 `R / 2` 的小圆面积只占 `1/4`。`10^5` 个点里，正确写法落在半径 `0.5` 内的比例约 `0.25`，错误写法约 `0.50`：圆心附近的密度被放大了。

**另一种做法的不变量。** 拒绝采样：在外接正方形里均匀取点，保留落在圆内的点，被保留的点在圆内仍然均匀（条件在均匀分布上，等于限制到子区域），所以不需要任何变换。
