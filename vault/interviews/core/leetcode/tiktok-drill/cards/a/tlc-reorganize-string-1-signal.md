## Q
**LC 767 重构字符串**｜Medium · TikTok 高频

给字符串 `s`，判断能否重新排列其中的字母，使任意两个相邻字符都不同；可以则返回任意一种排列，不行返回 `""`。`1 <= s.length <= 500`，`s` 只含小写字母。例：`"aab"` → `"aba"`，`"aaab"` → `""`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「重排」+「相邻不同」+「每一步该先放谁」→ 贪心，优先放剩余次数最多的字符；要反复取最大值 → 最大堆（max-heap）。
- 约束只涉及邻居 → 需要记住上一步放了谁，而不是只看全局计数。
- `n <= 500`、字符集 26 → 复杂度不是难点，重点是贪心的正确性，以及能推广到“间隔 `k`”。
- 「任意一种排列」→ 不要求字典序，不需要回溯。

**推导链。**
1. 暴力：枚举全排列，检查相邻，`O(n! · n)`。
2. 浪费：只关心相邻是否相等，大量排列等价。
3. 洞察：次数最多的字符最难安置，优先放；每步在“不等于上一个”的字符里取剩余最多的。
4. 可行性判据：互不相邻的位置最多 `(n + 1) // 2` 个，最多的字符超过这个数就不可能。
5. 实现：堆里存 `(-次数, 字符)`；取出的字符先放在一边，下一轮取完才放回堆，保证相邻不同。
