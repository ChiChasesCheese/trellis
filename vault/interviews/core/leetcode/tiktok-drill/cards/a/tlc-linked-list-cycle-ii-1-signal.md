## Q
**LC 142 环形链表 II**｜Medium · 字节 高频

给一个链表的头结点 `head`，返回链表**开始入环的第一个结点**；链表无环则返回 `null`。链表有环，指的是通过连续跟踪 `next` 指针能再次到达某个结点（评测系统用 `pos` 表示尾结点连回的下标，`-1` 表示无环；`pos` 不作为参数传入）。**不允许修改**链表。

约束：结点数在 `[0, 10^4]`，`-10^5 <= Node.val <= 10^5`，`pos` 为 `-1` 或链表中的有效下标。进阶：能否用 `O(1)` 空间？

例：`head = [3,2,0,-4], pos = 1` → 返回下标 `1` 的结点（值 `2`）；`head = [1], pos = -1` → `null`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「环的入口」+「`O(1)` 空间」+「不许修改链表」→ 不能哈希、不能打标记 → **Floyd 快慢指针**。
- 「有环必会相遇」：快指针相对慢指针每步多走 1，进入环后距离每步缩小 1，一定相遇，不会跳过。
- 入环点需要额外推导：相遇点不一定是入环点，从**表头**和**相遇点**同速出发，会在入环点汇合。

**推导链。**
1. 暴力：哈希集合存已访问结点，第一个重复访问的结点就是入环点，`O(n)` 空间。
2. 目标：`O(1)` 空间。快慢指针（一步 / 两步）判断有环，在环内相遇。
3. 洞察：设表头到入环点 `a`，入环点到相遇点 `b`，相遇点回入环点 `c`；`2(a+b) = a+b+k(b+c)` ⇒ `a = (k-1)(b+c) + c`。
4. 最优：相遇后慢指针回表头，两个指针每次一步，再次相遇处就是入环点，`O(n)` 时间 `O(1)` 空间。

**同模式的题**：LC 141 环形链表、LC 287 寻找重复数、LC 202 快乐数、LC 160 相交链表、LC 876 链表的中间结点。
