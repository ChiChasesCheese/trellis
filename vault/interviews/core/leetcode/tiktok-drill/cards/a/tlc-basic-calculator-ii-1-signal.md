## Q
**LC 227 基本计算器 II**｜Medium · LC TikTok 热度 66/100（近 3 个月） · 近一年被问：美国 6 次、国内 2 次 · CodeTop 国内累计 20 次 · 最近 2026-09-09（面试记录）

给字符串表达式 `s`，实现一个基本计算器计算并返回它的值。整数除法仅保留整数部分。表达式总是有效的，所有中间结果在 `[-2^31, 2^31 - 1]` 内；不允许使用 `eval()`。`1 <= s.length <= 3 * 10^5`，`s` 由整数和算符 `+ - * /` 组成，中间由一些空格隔开；所有整数是非负整数，范围 `[0, 2^31 - 1]`。例：`" 3+5 / 2 "` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「四则运算」→ **运算符优先级**：`*` `/` 先于 `+` `-`。
- **没有括号**、数字都非负 → 不需要完整的调度场（shunting-yard）算法，一个栈就够。
- 「整数除法仅保留整数部分」→ **向 0 取整**，不是向下取整；Python 的 `//` 对负数向下取整，需要特别处理。
- `n` 到 `3×10^5`、含空格 → 逐字符一遍扫描，不能递归，也不要反复切片。

**推导链。**
1. 暴力：先扫一遍把所有 `*` `/` 就地算掉，再扫一遍算 `+` `-`；或转成后缀表达式再求值。
2. 浪费：没有括号，转换成后缀表达式是多余的；两轮扫描也写得很啰嗦。
3. 关键：加减项相互独立，乘除只和它**左边紧挨着的那一项**结合。所以把加减项压栈（减法压负数），乘除当场与栈顶合并。
4. 记住「数字左边的运算符 `op`」，读完整个数字（遇到下一个运算符或结尾）时再按 `op` 结算；末尾补一个哨兵 `"+"` 触发最后一次结算。最后 `sum(stack)`。

**同模式的题**：LC 224 基本计算器（括号 + 一元负号）、LC 772 基本计算器 III、LC 150 逆波兰表达式求值、LC 394 字符串解码。
