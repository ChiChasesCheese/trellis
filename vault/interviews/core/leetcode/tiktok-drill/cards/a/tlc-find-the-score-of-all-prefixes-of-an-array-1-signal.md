## Q
**LC 2640 一个数组所有前缀的分数**｜Medium · LC TikTok 热度 62/100

数组 `arr` 的转换数组 `conver[i] = arr[i] + max(arr[0..i])`，`arr` 的分数是 `conver` 的元素和。给整数数组 `nums`，返回 `ans`，`ans[i]` 是前缀 `nums[0..i]` 的分数。

约束：`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^9`。例：`nums = [2,3,7,5,10]` → `[4,10,24,36,56]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「所有前缀的分数」→ 前缀类问题：相邻前缀只差最后一个元素，答案应当能递推，`ans[i] = ans[i-1] + 新增的一项`。
- `max(arr[0..i])` 只看左边 → 前缀最大值（prefix max），随下标单调不减，一边扫一边维护一个变量即可。
- 「元素和」→ 前缀和（prefix sum）。
- `n = 10^5` → 需要 `O(n)` 或 `O(n log n)`；每个前缀重算是 `O(n^2)`，约 `10^10`，不行。

**推导链。**
1. 暴力：对每个前缀 `i`，扫一遍求最大值并累加，`O(n^2)`。
2. 浪费：前缀 `i` 的转换数组就是整体转换数组的前 `i + 1` 项，每项只依赖它左边，没必要重算。
3. 洞察：`conver[i] = nums[i] + 当前最大值`，`ans[i]` 是 `conver` 的前缀和。
4. 最优：单次扫描，两个变量（当前最大值、累计和），`O(n)` 时间。
