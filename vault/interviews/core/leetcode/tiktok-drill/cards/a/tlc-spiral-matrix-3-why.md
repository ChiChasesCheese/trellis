## Q
**LC 54 螺旋矩阵**｜正确性

为什么每圈的下边和左边前面要加 `top < bottom and left < right` 的判断？去掉它会在哪些输入上出错，输出是什么？每圈的四段切片边界怎么保证不重不漏？

## A
**不变量。** 每次进入循环时，`matrix[top..bottom][left..right]` 是尚未取走的子矩阵，且非空（`top <= bottom` 且 `left <= right`）。一圈取走这个子矩阵最外层的所有元素，然后边界内缩一格，剩下的仍是尚未取走的子矩阵。

**四段不重不漏。** 上边取整行 `[left, right]`；右边取 `top + 1` 到 `bottom` 的最后一列（不含右上角，已在上边取过）；下边取 `bottom` 行的 `right - 1` 到 `left`（不含右下角，已在右边取过）；左边取 `left` 列的 `bottom - 1` 到 `top + 1`（不含左下角和左上角）。四个角各被取一次。

**为什么需要保护。** 只剩一行（`top == bottom`）时，上边已经取完整行，下边和上边是同一行，再反向取一次就重复了；只剩一列时同理。当 `top == bottom` 或 `left == right` 时，下边和左边应该跳过。

**反例：去掉保护。** 输入 `[[1,2,3]]`（一行三列），正确 `[1,2,3]`。去掉保护后上边取 `[1,2,3]`，右边没有新行，下边又取 `matrix[0][0:2]` 的反向 `[2,1]`，结果 `[1,2,3,2,1]`。输入 `[[1],[2],[3]]`（三行一列），正确 `[1,2,3]`：上边取 `[1]`，右边取 `[2,3]`，下边 `matrix[2][0:0]` 为空，左边 `range(1, 0, -1)` 取到 `matrix[1][0] = 2`，结果 `[1,2,3,2]`。
