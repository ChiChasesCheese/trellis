## Q
**LC 1860 增长的内存泄露**｜追问

面试官接着问：（1）内存范围放大到 `10^18`，怎么办？（2）要输出每一秒内存是分给了哪一条？（3）有 `k` 个内存条？

## A
1. **范围放大**：模拟的步数是 `sqrt(2 · 总量)`，`10^18` 对应约 `1.4 × 10^9` 步，Python 里太慢。要用公式分段：第一段，较大的内存条连续被分配，直到它的剩余量不再大于较小的那个，连续分配的秒数 `t` 满足 `t(t+1)/2 <= 差值`，用 `math.isqrt` 解整数二次不等式；第二段，两条剩余接近，之后分配者轮流交替，奇偶位的和各是等差数列，同样用 `isqrt` 求崩溃时刻。每一段都要处理平局归谁，细节多，写完必须与逐秒模拟对照验证。
2. **记录分配方向**：循环里加一个列表 `order`，每次追加 `1` 或 `2`；输出长度是 `second - 1`，最大约 `9.3` 万项，可以接受。
3. **`k` 个内存条**：每秒取剩余最多的一条，用 `heapq`（存负数模拟最大堆）：`heappop` 取最大、判断是否 `>= second`、减去后 `heappush`。每秒 `O(log k)`，总 `O(sqrt(总量) · log k)`；平局取编号小的，把 `(-剩余, 编号)` 作为堆元素。

**Python 提醒**：`math.isqrt(n)` 返回整数平方根，没有浮点误差，适合解 `t(t+1)/2 <= x` 这类不等式（`t = (isqrt(8 * x + 1) - 1) // 2`）；用 `math.sqrt` 在大整数上会丢精度。`heapq` 只有最小堆，最大堆要存取负数。
