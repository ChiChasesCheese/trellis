## Q
**LC 104 二叉树的最大深度**｜Easy · 字节高频

给二叉树的根节点 `root`，返回它的最大深度：从根节点到最远叶子节点的最长路径上的**节点数**。节点数在 `[0, 10^4]`，`-100 <= Node.val <= 100`。例：`[3,9,20,null,null,15,7]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「深度 / 高度 / 最长路径」→ 树上的**自底向上汇总**：节点的答案由左右子树的答案合并得到。
- 同一个问题也能按**层**数：层序遍历（BFS）的轮数就是深度。
- `n` 可达 `10^4`：退化成链的树深度 `10^4`，超过 Python 默认递归上限 `1000`；信号是「树可能很深 → 考虑迭代」。

**推导链。**
1. 暴力：枚举每条根到叶路径，取最长，路径数最多 `O(n)`，每条长 `O(h)`。
2. 浪费：不同路径共享前缀，同一棵子树的深度被反复重算。
3. 洞察：`depth(node) = 1 + max(depth(left), depth(right))`，`depth(None) = 0`；每个节点只算一次。
4. 工程上：递归深度等于树高，单链会 `RecursionError` → 改成逐层展开：当前层 → 下一层，数轮数。
