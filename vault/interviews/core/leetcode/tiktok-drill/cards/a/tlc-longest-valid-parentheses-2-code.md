## Q
**LC 32 最长有效括号**｜写出 Python 实现

只含 `'('` 和 `')'` 的字符串 `s`（长度 `0..3 * 10^4`），返回最长的有效（格式正确且连续）括号子串的长度。用存下标的栈实现。

## A
**思路。** 栈初始放一个哨兵 `-1`。扫描每个字符：`'('` 压下标；`')'` 先弹出栈顶。弹完若栈空，说明这个 `')'` 没有可匹配的 `'('`，把它的下标压入当作新的哨兵；否则当前有效段是栈顶之后到 `i` 的部分，长度 `i - stack[-1]`，用它更新答案。

```python
def longest_valid_parentheses(s: str) -> int:
    stack = [-1]                        # 栈底永远是"最近一个没被匹配的位置"，初始是虚拟的 -1
    best = 0
    for i, ch in enumerate(s):
        if ch == "(":
            stack.append(i)
        else:
            stack.pop()                 # 先尝试匹配：弹掉栈顶
            if stack:
                best = max(best, i - stack[-1])     # 当前有效段是 (栈顶, i]
            else:
                stack.append(i)         # 栈空：这个 ")" 无法匹配，成为新的分界线
    return best
```

运行：`"(()"` → `2`，`")()())"` → `4`，`""` → `0`，`"()"` → `2`，`"()(()"` → `2`，`"())(()"` → `2`，`"(()())"` → `6`，`15000` 个 `"("` 接 `15000` 个 `")"` → `30000`。

**复杂度。** 时间 `O(n)`：每个下标最多入栈、出栈各一次；空间 `O(n)`：全是左括号时栈最深。

**写法要点。** 栈里存下标而不是字符，既能判断 `ch`（直接看 `s[i]`），又能算长度；`stack = [-1]` 用哨兵避免「栈为空」的特殊分支；先 `pop` 再判空，把「匹配」和「建立新分界」统一在一个分支里，右括号永远要弹一次栈；`max(best, i - stack[-1])` 只在栈非空时执行，不会在空栈上索引；扫描一遍用 `enumerate`，不写 `range(len(s))` 再 `s[i]`。
