## Q
**LC 691 贴纸拼词**｜Hard · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-08-17（面试记录）

有 `n` 种贴纸，每张贴纸上是一个小写英文单词，每种数量无限。你要用贴纸上剪下的字母（可任意重排）拼出 `target`，返回所需的最少贴纸数，做不到返回 `-1`。`1 <= n <= 50`，`1 <= stickers[i].length <= 10`，`1 <= target.length <= 15`，字符串只含小写字母。例：`stickers = ["with","example","science"]`，`target = "thehat"` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- `target.length <= 15` → 状态压缩（bitmask）：用 `2^15 = 32768` 个状态记录「`target` 的哪些位置已盖住」。
- 「最少张数、每种无限」→ 完全背包 / 状态图上的最短路（BFS 或 DP），不是计数题。
- 字母可重排但数量有限 → 贴纸当字母多重集合（`Counter`），盖位置时要按个数消耗。
- `n <= 50`、每张 `<= 10` 个字母：单次转移很便宜，总成本由状态数决定。

**推导链。**
1. 暴力：每步从 `n` 种贴纸里任选一张，直到盖满，`n^k` 级。
2. 浪费：贴纸顺序无关却被当成不同序列；同一个「未盖住集合」被反复到达。
3. 洞察一：状态 = 已盖住的位置集合，`2^m` 个，`dp[mask]` 为最少张数。
4. 洞察二：任何方案都必须盖住最低的未覆盖位置，而贴纸可以任意换序，所以规定下一张必须含该字母，分支数大幅缩小。
5. 洞察三：一张贴纸对未覆盖位置能盖多少盖多少，多盖不会更差（状态更大更接近终点）。
6. 最优：按 `mask` 从小到大转移（新状态一定比旧状态大），`O(2^m * k * m)`。
