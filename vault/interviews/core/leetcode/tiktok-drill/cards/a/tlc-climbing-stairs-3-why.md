## Q
**LC 70 爬楼梯**｜正确性

为什么 `f(n) = f(n-1) + f(n-2)` 不会重复计数或漏数？初值为什么是 `f(0) = 1` 而不是 `0`？给出初值写错的输出。

## A
**不变量。** 第 `k` 轮结束后，`cur` 等于到第 `k` 阶的方法总数，`prev` 等于到第 `k-1` 阶的方法总数。

**不重不漏。** 任意一种爬到第 `n` 阶的方法，有且仅有一个「最后一步」：要么是 `1` 阶（来自第 `n-1` 阶），要么是 `2` 阶（来自第 `n-2` 阶）。按最后一步分成两个互不相交的集合，它们的并集是全部方法，所以总数是两者之和。前面的 `n-1`（或 `n-2`）阶怎么爬，正好是子问题 `f(n-1)`（`f(n-2)`）。

**为什么 `f(0) = 1`。** `f(0)` 的含义是「已经站在目标位置，不需要任何步」，这是一种方法（空序列）。`f(2) = f(1) + f(0) = 1 + 1 = 2` 才对：`1+1` 和 `2`；`2` 这一种正是「从第 `0` 阶一步迈 `2`」，靠 `f(0) = 1` 计入。

**反例：初值 `(0, 1)`。** 把 `prev, cur` 初值写成 `0, 1`（标准斐波那契），同样循环 `n - 1` 次：
- `n = 3`：`(0,1)` → `(1,1)` → `(1,2)`，返回 `2`，正确是 `3`。
- `n = 45`：返回 `1134903170`，正确是 `1836311903`。

整体错一位：这样得到的是 `F(n)`，而爬楼梯的答案是 `F(n+1)`。
