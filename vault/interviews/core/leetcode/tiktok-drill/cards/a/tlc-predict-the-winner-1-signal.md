## Q
**LC 486 预测赢家**｜Medium · CodeTop 国内累计 6 次 · 最近 2026-01-26（CodeTop）

数组 `nums`（`1 <= n <= 20`，`0 <= nums[i] <= 10^7`），两个玩家轮流从数组两端之一取数并加到自己的得分，玩家 1 先手，双方都想让自己的分数最大。玩家 1 得分不小于玩家 2 就返回 `true`。例：`[1,5,2]` → `false`，`[1,5,233,7]` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两人轮流 + 都用最优策略」→ 零和博弈，用极小极大（minimax）：我选择让「我的收益 - 对手的收益」最大的走法。
- 「只能取两端」→ 剩下的数始终是一段连续区间 `[i, j]`，状态是区间，区间 DP。
- 「是否赢」只关心得分差的符号，不需要分别记录两个人的分数 → 状态可以压成一个数：当前取数者的得分差。
- `n <= 20` → `2^20` 约 `10^6`，暴力递归能过；`O(n^2)` DP 是面试里想要的。

**推导链。**
1. 暴力：递归模拟，每步取左或取右，同时累加两人得分，`O(2^n)`。
2. 浪费：同一个区间 `[i, j]` 可由不同的取数顺序到达，重复求解；而且谁在取由区间长度的奇偶决定，不必再带"轮到谁"。
3. 洞察：`dp[i][j]` 定义为「该区间上轮到取数的人，能领先对手多少」；取左端的净收益是 `nums[i] - dp[i+1][j]`（对手接着在剩下区间上领先）。
4. 最优：按区间长度从短到长填表，答案看 `dp[0][n-1] >= 0`，`O(n^2)`。
