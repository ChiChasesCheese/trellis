## Q
**LC 90 子集 II**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 4 次 · 最近 2026-02-21（面试记录）

给一个可能包含重复元素的整数数组 `nums`，返回它所有可能的子集；解集不能包含重复的子集，顺序任意。`1 <= nums.length <= 10`，`-10 <= nums[i] <= 10`。例：`[1,2,2]` → `[[],[1],[1,2],[1,2,2],[2],[2,2]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「所有子集」→ 回溯 / 子集树：每个节点是一个子集，每次决定后面选哪个元素。
- 「含重复元素、解集不能重复」→ 同层去重：相同的数在同一层只选第一个，必须先排序让相同的数相邻。
- `n <= 10`：`2^10 = 1024` 个子集，回溯加拷贝完全够；考点是去重条件，不是性能。
- 「顺序任意」→ 不需要对结果再排序。

**推导链。**
1. 暴力：当作元素互不相同，用位掩码或回溯生成全部 `2^n` 个下标子集。
2. 去重：把每个子集排序成元组放进集合，最后转成列表。
3. 浪费：先生成大量重复再删；数组里重复越多，浪费越大（全相同的数组只有 `n + 1` 个不同子集，却生成了 `2^n` 个）。
4. 洞察：重复来自「相同的数选哪一个」。排序后，在同一层循环里跳过与前一个相同的数，保证每个值只在每个位置被选一次。
5. 最优：回溯，条件 `i > start and nums[i] == nums[i-1]` 跳过；进入更深一层时 `start = i + 1`，允许再选后面相同的数，从而生成「选多个相同数」的子集。每个不同的子集恰好生成一次。

**同模式的题**：LC 78 子集、LC 40 组合总和 II、LC 47 全排列 II、LC 491 非递减子序列。
