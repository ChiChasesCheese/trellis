## Q
**删除一个长度为 k 的窗口，使奇偶下标之和相等**｜追问

删除长度为 `k` 的窗口使剩余数组奇偶下标之和相等，已经用带符号前缀和做到 `O(n)`。面试官接着问：（1）返回所有满足条件的起点，或者统计个数？（2）窗口长度不固定，任意长度的连续子数组都可以删？（3）类似 LC 1664：只删除单个元素？（4）怎么测试？

## A
1. **所有起点 / 个数**：循环里不要 `return`，满足时收集进列表（或计数）；复杂度不变。
2. **任意长度的窗口** `[l, r)`：条件变成 `pre[l] + (-1)^(r-l) · (pre[n] - pre[r]) = 0`。按长度奇偶分两类：偶长度窗口要 `pre[l] + pre[n] - pre[r] = 0`，即 `pre[r] - pre[l] = pre[n]`；奇长度窗口要 `pre[l] - pre[n] + pre[r] = 0`，即 `pre[l] + pre[r] = pre[n]`。用哈希表按 `l` 的下标奇偶分别记录历史 `pre[l]` 的出现次数，枚举 `r` 时查对应奇偶的表，`O(n)`。
3. **只删一个元素**：就是 `k = 1`，翻转规则一样；LC 1664 求的是满足条件的删除下标个数，把 `return i` 换成计数即可。
4. **测试**：以 `O(n · k)` 的暴力（真的切片拼接后分别求和）做参照，随机小数组（长度 `1` 到 `12`，值有正有负）逐个比较；边界：`k == n`（删空）、`k == 1`、全 `0` 数组（每个起点都满足，答案 `0`）、答案在末尾。

**Python 提醒**：`nums[0::2]` 和 `nums[1::2]` 是写暴力参照时取偶数、奇数下标最短的写法；`accumulate` 不带 `initial` 时 `pre[i]` 是前 `i + 1` 个元素之和，下标整体错一位；写前缀和一律带 `initial=0`，让 `pre[i]` 是前 `i` 个元素之和。
