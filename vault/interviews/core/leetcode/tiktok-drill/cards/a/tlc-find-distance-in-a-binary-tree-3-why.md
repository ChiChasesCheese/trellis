## Q
**LC 1740 找到二叉树中的距离**｜正确性

为什么「深度大的先爬一步」的双指针会恰好在 LCA 相遇、且步数就是距离？如果只比较深度、深度相同就停下，会错在哪？

## A
**不变量。** `a`、`b` 始终分别是 `p`、`q` 的祖先（含自身），且 LCA 仍是二者的祖先（含自身）。每步的上行是安全的：深度不同时，更深者比另一方深，而 LCA 不会比任何一方更深，所以更深者一定不是 LCA；深度相同且 `a is not b` 时，二者也都严格在 LCA 之下（否则其中之一是 LCA，另一方在同一深度只能是它自己）。因此上行不会越过 LCA，最终两者在 LCA 重合。路径上的每条边恰好被爬一次，步数 `= depth[p] + depth[q] - 2*depth[LCA]`。

**反例。** 示例树 `[3,5,1,6,2,0,8,null,null,7,4]` 中 `p=6, q=2`：二者都是 `5` 的孩子，都在第 2 层。
- 错误写法：`while depth[a] != depth[b]: …` 之后直接返回 `dist`：深度一开始就相等，返回 `0`。
- 正确写法：循环条件是 `a is not b`，两边各爬一步到 `5`，返回 `2`。

另一个常见错误：用递归求 LCA。单链 `10^4` 层时 `RecursionError`；上面的迭代写法没有这个问题。
