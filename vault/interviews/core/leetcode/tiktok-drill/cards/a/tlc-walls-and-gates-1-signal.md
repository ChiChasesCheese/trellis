## Q
**LC 286 墙与门**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 1 次 · 最近 2023-10-28（CodeTop）

`m × n` 网格 `rooms`：`-1` 墙，`0` 门，`INF = 2^31 - 1` 空房间。原地把每个空房间填成它到最近的门的步数（上下左右走，不穿墙），到不了就保持 `INF`。`1 <= m, n <= 250`。例：`[[INF,-1,0,INF],[INF,INF,INF,-1],[INF,-1,INF,-1],[0,-1,INF,INF]]` → `[[3,-1,0,1],[2,2,1,-1],[1,-1,2,-1],[0,-1,3,4]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格上到**最近**某物的最短步数」，每步代价相同 → **BFS**（无权最短路）。
- 源点有**多个**（所有的门）→ **多源 BFS**：把全部源点同时作为第 0 层入队。
- 「原地填写」→ 格子值本身就能当 visited 标记：只有仍是 `INF` 的格子没被访问过。
- `m, n <= 250`：`62500` 格，`O(mn)` 轻松；`O((mn)^2)` 约 `4 · 10^9`，不行。

**推导链。**
1. 暴力：对每个空房间做一次 BFS 找最近的门，`O((mn)^2)`。
2. 浪费在哪：每次 BFS 都重新探索大片相同区域。
3. 洞察：把方向反过来——从**门**出发。所有门同时出发，波前一层层向外扩，某格第一次被到达时，所经过的层数就是它到最近门的距离（BFS 的层序保证）。
4. 最优：所有门入队；出队一个格子，把仍是 `INF` 的邻居填成 `自己 + 1` 并入队。每格最多入队一次，`O(mn)`。

**同模式的题**：LC 542 01 矩阵、LC 994 腐烂的橘子、LC 1162 地图分析、LC 317 离建筑物最近的距离。
