## Q
**LC 667 优美的排列 II**｜正确性

为什么「前 `k + 1` 个数头尾交替」恰好给出 `k` 种不同的差？为什么必须把交替取数限制在 `1..k+1`，而不是铺到 `1..n`？

## A
**不变量。** 前 `k + 1` 个元素 `1, k+1, 2, k, ...` 的相邻差依次为 `k, k-1, ..., 1`，每一对相邻元素的差比上一对恰好小 `1`，所以共 `k` 种且互不相同。

**接缝与后半段。** 后面追加 `k+2, k+3, ..., n`：
- 后半段内部相邻差都是 `1`，已经出现过。
- 接缝处差为 `k + 2 - 末项`。前半段的末项在 `k` 为偶数时是 `k/2 + 1`，奇数时是 `(k+3)/2`，接缝差分别是 `k/2 + 1` 与 `(k+1)/2`，都落在 `[1, k]` 内，是已有的差。
- 所以总种类数仍是 `k`。

**为什么只用 `1..k+1`。** 想得到 `k` 种差只需要 `k + 1` 个数；剩下的数用递增排列补齐，几乎不增加新差。

**反例：交替取数铺到 `1..n`。** 令 `lo, hi = 1, n`，取 `k` 个数后把剩余的递增接上，`n = 5`，`k = 2`：
- 得到 `[1, 5, 2, 3, 4]`，相邻差是 `4, 3, 1, 1`，种类 `{1, 3, 4}` 共 `3` 种。
- 正确答案需要恰好 `2` 种，例如 `[1, 3, 2, 4, 5]`，差为 `2, 1, 2, 1`。
