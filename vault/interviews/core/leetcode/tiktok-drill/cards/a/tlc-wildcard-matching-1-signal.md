## Q
**LC 44 通配符匹配**｜Hard · 字节 高频

给输入字符串 `s` 和模式 `p`，实现支持 `?` 和 `*` 的通配符匹配：`?` 匹配任意**单个**字符，`*` 匹配任意字符序列（**包括空序列**）。匹配必须覆盖整个 `s`。`0 <= s.length, p.length <= 2000`；`s` 只含小写英文字母，`p` 只含小写英文字母、`?` 或 `*`。例：`s = "aa", p = "*"` → `true`；`s = "cb", p = "?a"` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 两个字符串各取前缀、问「能否**完全**匹配」→ **字符串双序列 DP**，状态是 `(i, j)` 一对前缀长度。
- `*` 代表任意长度 → 递归时**分叉**（匹配空 / 多吞一个）；分叉后的子问题只有 `m * n` 种 → 重叠子问题，适合记忆化 / 填表。
- `m, n <= 2000` → `O(mn) = 4 * 10^6` 可行；指数级递归不行。
- 近似信号要分清：LC 10 的 `*` 是「前一个字符重复」，需要多看一个字符，转移不同。

**推导链。**
1. 暴力递归 `match(i, j)`：`p[j]` 是 `*` 就试 `match(i, j + 1)` 或 `match(i + 1, j)`；否则当前字符兼容再走 `(i + 1, j + 1)`。多个 `*` 叠加，最坏指数级。
2. 浪费：同一个 `(i, j)` 被不同路径反复求解。
3. 洞察：答案只取决于 `(i, j)` → 记忆化，或自底向上填 `dp[i][j]`，`O(mn)`。
4. 填表：第 0 行是「`s` 为空，连续的 `*` 才为真」，第 0 列（非空 `s` 配空模式）是 `False`；其余格子按行填，答案是 `dp[m][n]`，`O(mn)` 时间和空间。

**同模式的题**：LC 10 正则表达式匹配、LC 72 编辑距离、LC 97 交错字符串、LC 115 不同的子序列。
