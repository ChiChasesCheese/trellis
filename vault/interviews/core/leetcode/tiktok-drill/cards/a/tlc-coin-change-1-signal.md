## Q
**LC 322 零钱兑换**｜Medium · TikTok 高频

给整数数组 `coins`（不同面额的硬币）和整数 `amount`（总金额），返回凑成总金额所需的**最少**硬币个数；凑不出来返回 `-1`。每种硬币的数量无限。`1 <= coins.length <= 12`，`1 <= coins[i] <= 2^31 - 1`，`0 <= amount <= 10^4`。例：`coins = [1,2,5], amount = 11` → `3`（`5+5+1`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少个数」+「凑出目标」→ **动态规划**（DP）求最优值；状态是金额，决策是「最后一枚用哪种面额」。
- 「每种硬币无限」→ **完全背包**（unbounded knapsack），同一种硬币可重复使用。
- `amount <= 10^4`、至多 12 种硬币 → 状态数 `10^4`，每个状态试 12 种面额，约 `1.2×10^5` 次转移，DP 轻松；金额不大是 DP 可行的前提。
- 「最少」听起来像贪心，但面额没有倍数关系 → 贪心不成立，要用 DP。

**推导链。**
1. 暴力：递归枚举每一步取哪种硬币，分支数 `len(coins)`，深度可达 `amount`，指数级。
2. 浪费：不同的取法会走到同一个剩余金额，重复展开（重叠子问题）。
3. 关键：凑成金额 `a` 的最少个数只依赖更小金额的答案：`dp[a] = min(dp[a - c] + 1)`，对所有 `c <= a`（最优子结构）。
4. 从小到大填 `dp`，不可达用 `amount + 1` 做哨兵，答案 `dp[amount]`，`O(amount × 硬币种数)`。

**同模式的题**：LC 518 零钱兑换 II（数组合）、LC 279 完全平方数、LC 139 单词拆分、LC 377 组合总和 IV。
