## Q
**LC 87 扰乱字符串**｜正确性

`s1` 的一段在第 `k` 个字符后切开时，为什么 `s2` 那一段只需在两个位置检查（第 `k` 个之后、第 `L - k` 个之后）？交换分支的下标为什么是 `dfs(i, j + length - k, k)`？

## A
**不变量。** `dfs(i, j, L)` 为真，当且仅当存在一棵扰乱树，把 `s1[i:i+L]` 变成 `s2[j:j+L]`。

**为什么只看两个位置。** 扰乱树的根把 `s1` 段切成 `x`（长度 `k`）和 `y`（长度 `L - k`），之后 `x` 和 `y` 各自独立地扰乱成 `x'`、`y'`，长度不变。根只有两种选择：
- 不交换：结果是 `x' + y'`，`x'` 占 `s2` 段的前 `k` 个 → `dfs(i, j, k) and dfs(i + k, j + k, L - k)`；
- 交换：结果是 `y' + x'`，`x'` 占 `s2` 段的**后** `k` 个，起点是 `j + L - k` → `dfs(i, j + L - k, k) and dfs(i + k, j, L - k)`。
枚举所有 `k`，就覆盖了根的所有选择，子树由递归负责，所以不漏；每个分支都对应一棵真实的扰乱树，所以不错。

**反例：交换分支写成 `dfs(i, j + k, k)`。** `s1 = "abc", s2 = "bca"`：正确做法在 `k = 1` 切成 `"a" | "bc"` 再交换，得到 `"bc" + "a" = "bca"`，答案 `True`。错误版本让 `s1` 的 `"a"` 去对 `s2[1:2] = "c"`，计数不同；其他切点也对不上，返回 `False`。

**另一个诱人的错误。** 只比较字符计数：`"abcde"` 与 `"caebd"` 计数相同，但答案是 `False`。计数相同只是必要条件。
