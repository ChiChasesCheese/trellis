## Q
**LC 1530 好叶子节点对的数量**｜正确性

为什么每对叶子恰好被统计一次？数组为什么只保留 `distance + 1` 个距离？比较条件写成 `< distance` 会错在哪里？给出具体输入。

## A
**不变量。** 处理到节点 `x` 时，`cnt[x][d]` 精确等于 `x` 子树里距 `x` 为 `d`（`d <= distance`）的叶子个数；距离更大的叶子已被丢弃。

**每对恰好一次。** 两个叶子的路径一定经过它们的 LCA，在这个 LCA 上，一个叶子在左子树、另一个在右子树，路径长是它们各自到 LCA 的距离 `i` 与 `j` 之和。统计只在 LCA 处做，且是「左 × 右」，同一侧内部的叶子对由更深的祖先负责，所以既不重复也不遗漏。

**为什么只留 `distance + 1` 个距离。** 一个叶子到某个祖先的距离一旦超过 `distance`，它和任何其他叶子的路径长至少也超过 `distance`（距离只会加不会减），再也不可能成为好叶子对的一员，丢弃不影响答案。所以数组长度固定，合并是常数。

**反例：`<` 与 `<=`。** 题目要求「小于或等于」。
- `root = [1,2,3,null,4]`，`distance = 3`：叶子 `3` 和 `4` 路径长恰好是 `3`。条件写成 `< distance`（相当于传入 `distance - 1`）得到 `0`，正确是 `1`。
- `root = [1,1,1]`，`distance = 2`：两片叶子路径长 `2`，写成 `<` 得到 `0`，正确是 `1`。
