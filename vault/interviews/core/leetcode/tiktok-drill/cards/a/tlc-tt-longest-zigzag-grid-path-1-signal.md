## Q
**网格中最长的之字形递增路径**｜Hard · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-06-17（面试记录）

给 `m x n` 整数网格。路径从任意格子出发，每步走到上下左右相邻的格子，值必须**严格增大**，并且**水平移动和竖直移动必须交替**（第一步方向任意）。返回最长路径的格子数。`1 <= m, n <= 200`，`0 <= grid[i][j] <= 2^31 - 1`。例：`[[1,2],[4,3]]` → `4`（`1→2` 水平，`2→3` 竖直，`3→4` 水平）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格 + 严格递增 + 最长路径」→ LC 329 的骨架：「走到更大的格子」构成**有向无环图**（DAG），最长路径可以 DP。
- 「水平竖直交替」→ 一个格子之后能走多远取决于**下一步允许的方向**，状态要多一维：`(i, j, d)`。
- `m, n <= 200` → `4·10^4` 个格子、`8·10^4` 个状态，`O(mn log(mn))` 轻松；递归深度却可能很大，要用迭代顺序。

**推导链。**
1. 暴力：从每个格子 DFS 枚举所有交替递增路径，路径数指数级。
2. 浪费：同一个 `(格子, 下一步方向)` 被不同前缀反复展开；而它后面能走多远与前缀无关，因为递增保证不会回到前缀里的格子。
3. 洞察：定义 `dp[d][i][j]` = 从 `(i, j)` 出发、下一步必须走方向 `d` 时的最长格子数，`dp[d][i][j] = 1 + max dp[1-d][邻居]`（邻居在方向 `d` 上、值更大）。
4. 最优：依赖总指向值更大的格子 → 按值从大到小排序后顺序填表，不用递归。时间 `O(mn log(mn))`，空间 `O(mn)`。

**同模式的题**：LC 329 矩阵中的最长递增路径、LC 2328 网格图中递增路径的数目、LC 1372 二叉树中的最长交错路径。
