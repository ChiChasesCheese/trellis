## Q
**LC 204 计数质数**｜正确性

筛法为什么只需要枚举到 `sqrt(n-1)`，而且可以从 `i*i` 开始划？给出一个把上界写小一点就会出错的输入。

## A
**不变量。** 外层处理完 `i` 之后，所有「最小质因子 `<= i`」的合数都已被划掉。轮到下一个仍为 1 的 `i` 时，它没有更小的质因子，所以是质数。

**为什么到 `sqrt(n-1)` 就够。** 设合数 `m <= n-1`，写成 `m = a * b` 且 `a <= b`，则 `a <= sqrt(m) <= sqrt(n-1)`，`a` 的某个质因子 `p` 也不超过 `sqrt(n-1)`，`m` 一定会在 `p` 那一轮被划掉。

**为什么从 `i*i` 开始。** `i*k`（`k < i`）含有因子 `k` 的质因子，且比 `i` 小，早在更前面的轮次被划过。

**反例。** 外层写成 `range(2, isqrt(n))`（漏掉上界本身）。`n = 10`：`isqrt(10) = 3`，`range(2, 3)` 只处理 `2`，划掉 `4, 6, 8`；`3` 没处理，`9` 留着，剩 `2, 3, 5, 7, 9` 五个，答案 `5`；正确是 `4`。`n = 5` 同理：`4` 留着，得 `3`，正确 `2`。上界用 `isqrt(n - 1) + 1`，`n = 10` 时是 `range(2, 4)`，`3` 被处理，`9` 被划掉。
