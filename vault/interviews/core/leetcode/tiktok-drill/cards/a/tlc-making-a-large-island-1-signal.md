## Q
**LC 827 最大人工岛**｜Hard · TikTok 高频

给 `n x n` 的二进制矩阵 `grid`，**最多**只能将一格 `0` 变成 `1`。返回执行此操作后，`grid` 中最大的岛屿面积。岛屿由一组上、下、左、右四个方向相连的 `1` 形成。`n == grid.length == grid[i].length`，`1 <= n <= 500`，`grid[i][j]` 为 `0` 或 `1`。例：`[[1,0],[0,1]]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「岛屿（四连通的 `1`）」→ **连通分量**（connected components），DFS / BFS / 并查集（Union-Find）。
- 「最多翻一格 `0`」→ 翻转只会把这一格**四周的岛屿**连起来，别的岛不受影响 → 可以**预处理每座岛的面积**，翻转时只做加法。
- `n <= 500` → `2.5×10^5` 个格子，暴力「每个 `0` 翻一次重算全图」是 `O(n^4)`，不行；要 `O(n^2)`。
- DFS 深度可达 `2.5×10^5`，**递归会栈溢出**，用显式栈或并查集。

**推导链。**
1. 暴力：枚举每个 `0`，翻成 `1`，重新求最大岛，共 `O(n^2)` 个 `0`，每次 `O(n^2)`，总 `O(n^4)`。
2. 浪费：每次翻转，几乎所有岛都没变，却重新搜了一遍。
3. 预处理：一次遍历给每座岛编号并统计面积 `size[编号]`。
4. 枚举每个 `0`：取上下左右四个邻居的编号，**去重**（同一座岛可能从两个方向碰到），面积相加再加 `1`。每个 `0` 常数时间，总 `O(n^2)`。别忘了「不翻也行」：初值是原有最大岛。

**同模式的题**：LC 695 岛屿的最大面积、LC 200 岛屿数量、LC 934 最短的桥、LC 1020 飞地的数量。
