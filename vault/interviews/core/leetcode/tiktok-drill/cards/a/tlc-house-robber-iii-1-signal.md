## Q
**LC 337 打家劫舍 III**｜Medium · 近一年被问：美国 1 次、国内 5 次 · CodeTop 国内累计 3 次 · 最近 2026-10-14（面试记录）

房屋排成一棵二叉树（入口是 `root`）。**直接相连（父子）的两栋房子不能在同一晚都被偷**，否则报警。返回不触发警报时能偷到的最高金额。节点数在 `[1, 10^4]`，`0 <= Node.val <= 10^4`。例：`[3,4,5,1,3,null,1]` → `9`（偷 `4` 和 `5`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树」+「父子不能同时选」+「最大和」→ **树形 DP**：每个节点两个状态（偷 / 不偷），约束只在父子之间。
- 约束局部、状态很少 → 自底向上，父节点只读两个孩子的两个值。
- 节点数 `10^4` 且树可能退化成链 → Python 递归会超过默认深度 `1000`，需要迭代后序。

**推导链。**
1. 暴力递归：偷根 = `val` + 四个孙子的最优；不偷根 = 两个孩子的最优；取较大者。
2. 浪费：孩子的最优在「不偷根」时算一次，孙子的最优在「偷根」时又算一次，子树被重复求解，深树上代价爆炸。
3. 关键：每个子树只需要两个数——**偷它的根**、**不偷它的根**时的最大收益；`take = val + 孩子的 skip 之和`，`skip = 孩子的 max(take, skip) 之和`。
4. 后序一遍求出，`O(n)`；用栈得到先序序列再倒序遍历，就能保证孩子先于父亲、又不用递归。

**同模式的题**：LC 198 / 213 打家劫舍、LC 124 二叉树中的最大路径和、LC 968 监控二叉树。
