## Q
**LC 88 合并两个有序数组**｜写出 Python 实现

非递减数组 `nums1`（长度 `m + n`，前 `m` 个有效，后 `n` 个是占位的 `0`）和 `nums2`（长度 `n`），`0 <= m, n <= 200`。把 `nums2` 合并进 `nums1`，使其整体非递减，原地修改，不返回。要求 `O(m + n)` 时间。

## A
**思路。** 三个指针都指向尾部：`i` 是 `nums1` 有效部分的最后一个，`j` 是 `nums2` 的最后一个，`k` 是 `nums1` 的最后一格。每次把 `nums1[i]` 与 `nums2[j]` 中较大的写进 `k`，对应指针和 `k` 前移。`nums2` 全部写完时，`nums1` 前面剩下的元素已经在正确位置，直接结束。

```python
def merge(nums1: list[int], m: int, nums2: list[int], n: int) -> None:
    i, j, k = m - 1, n - 1, m + n - 1           # 三个指针都从尾部往前
    while j >= 0:                               # nums2 放完就结束，nums1 剩下的本来就在位
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
```

运行：`[1,2,3,0,0,0]`，`m = 3`，`[2,5,6]` → `[1, 2, 2, 3, 5, 6]`；`[1]`，`m = 1`，`[]` → `[1]`；`[0]`，`m = 0`，`[1]` → `[1]`；`[4,5,6,0,0,0]`，`m = 3`，`[1,2,3]` → `[1, 2, 3, 4, 5, 6]`。

**复杂度。** 时间 `O(m + n)`：每次循环写一个位置，`k` 最多走 `m + n` 步；空间 `O(1)`。

**写法要点。** 循环条件只写 `j >= 0`，利用「`nums1` 的剩余部分已在原位」省掉收尾；`i >= 0 and nums1[i] > nums2[j]` 里先判 `i >= 0`，靠短路避免 `nums1[-1]` 这种下标 `-1` 悄悄取到最后一个元素的陷阱；`else` 分支同时覆盖「`nums1` 用完」和「`nums2[j]` 不小于 `nums1[i]`」两种情况；函数返回 `None`，只通过修改参数输出。
