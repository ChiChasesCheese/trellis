## Q
**LC 888 公平的糖果交换**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-04-04（CodeTop）

爱丽丝和鲍勃拥有不同总数量的糖果。`aliceSizes[i]` 是爱丽丝第 `i` 盒糖果的数量，`bobSizes[j]` 是鲍勃第 `j` 盒的数量。两人要各拿出一盒互相交换，使交换后两人的糖果总数相同。返回 `[爱丽丝给出的那盒的数量, 鲍勃给出的那盒的数量]`；有多个答案返回任意一个，保证至少有一个有效答案。`1 <= aliceSizes.length, bobSizes.length <= 10^4`，`1 <= aliceSizes[i], bobSizes[j] <= 10^5`，两人的糖果总数不同。例：`aliceSizes = [1,2,5], bobSizes = [2,4]` → `[5,4]`（爱丽丝给出 5、鲍勃给出 4，两人都变成 7）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「交换一个元素使两边总和相等」→ 先**写出等式**：`sumA - x + y = sumB - y + x`，化简成 `y = x - (sumA - sumB) / 2`，两个未知数变成一个。
- 每个 `x` 只对应唯一的目标 `y` → 「找一对」变成「查一个」→ **哈希集合**（和两数之和同类）。
- `n, m <= 10^4` → 双层循环 `10^8` 次，Python 里太慢；要 `O(n + m)`。「保证有解」→ 总和差必为偶数，可以整除。

**推导链。**
1. 暴力：枚举所有 `(x, y)` 对，检查交换后总和是否相等，`O(nm)`。
2. 浪费：等式把 `y` 完全由 `x` 决定，其余的配对根本不用试。
3. 洞见：`delta = (sumA - sumB) / 2`，合法交换满足 `y = x - delta`。
4. 最优：鲍勃的盒子放进集合，遍历爱丽丝的盒子，查 `x - delta` 是否存在，`O(n + m)`。

**同模式的题**：LC 1 两数之和、LC 532 数组中的 k-diff 数对、LC 1010 总持续时间可被 60 整除的歌曲、LC 560 和为 K 的子数组。
