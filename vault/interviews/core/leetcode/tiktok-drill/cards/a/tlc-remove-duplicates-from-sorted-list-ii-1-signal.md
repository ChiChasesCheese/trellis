## Q
**LC 82 删除排序链表中的重复元素 II**｜Medium · CodeTop 国内累计 49 次 · 最近 2026-08-05（CodeTop）

给一个**已排序**（升序）的链表头结点 `head`，删除所有出现重复数字的结点（重复的数字一个都不保留，只留下只出现一次的数字），返回仍然有序的链表。

约束：结点数在 `[0, 300]`，`-100 <= Node.val <= 100`，保证链表按升序排列。

例：`head = [1,2,3,3,4,4,5]` → `[1,2,5]`；`head = [1,1,1,2,3]` → `[2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**已排序**链表 + 重复值」→ 重复值**相邻**，一遍扫描即可，不需要哈希表（`O(1)` 空间）。
- 「重复的一个也不留」→ 要等到整段重复结束才知道该保留什么；删除可能涉及头结点 → **哑结点**。
- 结点数仅 `300` → 性能不是考点，考的是指针操作的正确性和边界（全是重复、头结点重复、重复段在末尾）。

**推导链。**
1. 暴力：哈希表统计次数，再删除次数大于 `1` 的结点，`O(n)` 时间、`O(n)` 空间，没有用到排序。
2. 观察：已排序 → 重复值连成一段，`cur` 与 `cur.next` 的值是否相等就能判断 `cur` 是否属于重复段。
3. 洞察：用 `prev` 记最后一个确认保留的结点；遇到重复段就整段跳过并让 `prev.next` 指向段后，`prev` 暂不前进（段后可能还有重复段）。
4. 最优：哑结点 + `prev` / `cur` 双指针，一遍扫描，`O(n)` 时间、`O(1)` 空间。
