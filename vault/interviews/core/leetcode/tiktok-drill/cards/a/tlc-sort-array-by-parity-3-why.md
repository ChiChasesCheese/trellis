## Q
**LC 905 按奇偶排序数组**｜正确性

对撞双指针的循环不变量是什么？有人写成「每轮都 `left += 1; right -= 1`，只在左奇右偶时交换」，错在哪？给出出错的输入。

## A
**不变量。** 每轮开始时，`nums[:left]` 全是偶数，`nums[right + 1:]` 全是奇数；中间 `nums[left : right + 1]` 未处理。三个分支都保持它：左偶则把它划进偶数区；右奇则把它划进奇数区；左奇右偶时交换，交换后左边是偶数、右边是奇数，两个区各扩一格。每轮至少一个指针向中间走，`left >= right` 时未处理区至多一个元素，它无论奇偶都不破坏「偶在前、奇在后」。

**错误版本。** 两个指针无条件同时前进，等于假设每一轮两端都会被处理好。可当左边是奇数、右边也是奇数时，左指针跳过的那个奇数**还没归位**，以后再也不会被看到。

`[2,3,1,4]`：
- 第 1 轮：`left=0`（`2`，偶）、`right=3`（`4`，偶），不交换，两指针移到 `1` 和 `2`。
- 第 2 轮：`left=1`（`3`，奇）、`right=2`（`1`，奇），不交换，两指针相遇，结束。
- 返回 `[2, 3, 1, 4]`，奇数 `3` 在偶数 `4` 前面，错误；正确结果如 `[2, 4, 1, 3]`。

**修法。** 每轮只移动「已经确定」的那一端：左偶右移、右奇左移，两端都放错才交换。
