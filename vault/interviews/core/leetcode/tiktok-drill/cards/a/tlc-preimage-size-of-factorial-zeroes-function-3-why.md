## Q
**LC 793 阶乘函数后 K 个零**｜正确性

为什么两次「第一个 `>=`」之差就是 `f(x) = k` 的 `x` 的个数？为什么二分上界 `5 * (target + 1)` 一定够？数 `x // 5` 为什么不行？

## A
**不变量。** `f(x)` 单调不减，所以对任意 `t`，集合 `{x : f(x) >= t}` 是一段后缀 `[first(t), +inf)`。`{x : f(x) = k}` 等于 `{f >= k}` 减去 `{f >= k + 1}`，即 `[first(k), first(k + 1))`，个数 `first(k + 1) - first(k)`；区间为空时就是 `0`。上界：`f(5m) >= m`（`5m` 里至少有 `m` 个因子 `5`），所以 `f(5 * (target + 1)) >= target + 1 >= target`，`first(target)` 一定不超过它，二分的搜索范围包含答案。

**反例（错误写法一）：`f` 只数 `x // 5`。** `k = 5`：`x // 5 = 5` 的有 `25..29`，会返回 `5`；真实 `f(25) = 5 + 1 = 6`（`25` 里有两个因子 `5`），不存在 `f(x) = 5` 的 `x`，正确是 `0`。

**反例（错误写法二）：二分下界取 `1`。** `k = 0`：`0!` 到 `4!` 共 `5` 个，下界 `1` 漏掉了 `0!`，返回 `4`；正确是 `5`。

**反例（错误写法三）：上界取 `4 * target`。** `k = 0`：`first(1)` 的真实值是 `5`，但搜索范围是 `[0, 4]`，二分得到 `4`，答案算成 `4 - 0 = 4`；用 `5 * (target + 1)` 才保证上界够大。
