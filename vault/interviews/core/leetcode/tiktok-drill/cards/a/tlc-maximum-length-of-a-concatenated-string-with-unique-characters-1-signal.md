## Q
**LC 1239 串联字符串的最大长度**｜Medium · TikTok 高频

给字符串数组 `arr`，从中选出若干个字符串（保持原顺序）连接成 `s`，要求 `s` 中所有字母互不相同，返回可行的 `s` 的最大长度。`1 <= arr.length <= 16`，`1 <= arr[i].length <= 26`，只含小写字母。例：`["un","iq","ue"]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「选一部分元素，满足全局约束，求最优」+ `n <= 16` → **子集枚举**（`2^16 = 65536`）；`n` 小到可以暴力，是在提示用回溯或位运算。
- 「字母是否重复」→ **位掩码**：用 26 位整数表示字母集合，`a & b` 判相交，`a | b` 合并，`bit_count()` 数个数。
- 一个字符串自己内部就有重复字母 → 永远不能选，先过滤。

**推导链。**
1. 暴力：递归「选 / 不选」，每次拼字符串后检查重复，`O(2^n * 26)` 并且反复构造字符串。
2. 浪费：重复构造字符串、重复检查字母。
3. 关键：每个串预先压成掩码；两串能一起选，当且仅当掩码不相交。
4. 用集合 `masks` 保存所有"已经能拼出的字母集合"，逐个串地与旧掩码两两尝试合并，更新答案为位数的最大值。集合最多 `2^n` 个，`O(2^n)`。

**同模式的题**：LC 78 子集、LC 1255 得分最高的单词集合、LC 2002 两个回文子序列长度的最大乘积、LC 1178 猜字谜。
