## Q
**LC 678 有效的括号字符串**｜写出 Python 实现

字符串 `s`（长度 `1..100`，只含 `'('`、`')'`、`'*'`），`'*'` 可以当 `')'`、`'('` 或空串，判断 `s` 能否成为一个有效的括号串。要求 `O(n)` 时间、`O(1)` 额外空间。

## A
**思路。** 维护「未配对 `'('` 个数」的可能区间 `[lo, hi]`：`'('` 两端加一，`')'` 两端减一，`'*'` 的 `lo` 减一、`hi` 加一。`hi < 0` 立刻失败，`lo` 截到 `0`，结束时 `lo == 0` 即有效。

```python
def check_valid_string(s: str) -> bool:
    lo = hi = 0                        # 还没配对的 '(' 数量的可能区间 [lo, hi]
    for ch in s:
        lo += 1 if ch == '(' else -1   # '*' 当 ')' 或 ')' 都让 lo 减一
        hi += 1 if ch != ')' else -1   # '*' 当 '(' 或 '(' 都让 hi 加一
        if hi < 0:                     # 即使全当 '(' 也配不上这个 ')'
            return False
        lo = max(lo, 0)                # 区间下界不能为负：多出来的 '*' 当空串
    return lo == 0                     # 0 在区间里，说明存在一种取法恰好配平
```

运行：`"()"` → `True`，`"(*)"` → `True`，`"(*))"` → `True`，`"*("` → `False`，`")*"` → `False`，`"*"` → `True`，`"(((*"` → `False`。

**复杂度。** 时间 `O(n)`：一趟扫描，每步常数次运算；空间 `O(1)`：只有 `lo`、`hi` 两个整数。

**写法要点。** `lo = hi = 0` 对不可变的 `int` 安全，可以链式赋值。`1 if ch == '(' else -1` 与 `1 if ch != ')' else -1` 的条件表达式把三种字符的增量压成两行，对照读：`'('` 两边都加，`')'` 两边都减，`'*'` 在 `lo` 上按「当 `')'`」减、在 `hi` 上按「当 `'('`」加。`max(lo, 0)` 是截断而非回滚，每一步都做，别只在最后做。
