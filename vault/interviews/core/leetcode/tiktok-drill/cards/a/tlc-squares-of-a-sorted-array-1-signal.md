## Q
**LC 977 有序数组的平方**｜Easy · CodeTop 国内累计 11 次 · 最近 2026-01-18（CodeTop）

给一个按非递减顺序排序的整数数组 `nums`（可能含负数），返回每个数字平方后组成的新数组，也要非递减。`1 <= nums.length <= 10^4`，`-10^4 <= nums[i] <= 10^4`。进阶：`O(n)`。例：`[-4,-1,0,3,10]` → `[0,1,9,16,100]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「数组已**有序**」+「对每个元素做变换后仍要有序」→ 变换（平方）破坏了保序，但有序性留下了**结构**：负数一侧平方后递减，非负一侧递增，整体是山谷。
- 最大值只可能出现在山谷的**两端** → **对撞双指针**（two pointers），每步从两端取较大的。
- 进阶要求 `O(n)` → 不能 `sorted`，要利用已有的有序性；`n` 只有 `10^4`，`O(n log n)` 也能过，但面试要 `O(n)`。

**推导链。**
1. 暴力：平方后 `sorted`，`O(n log n)`。
2. 浪费：输入已经有序，平方后只是「先降后升」的两段有序序列，排序把这个结构丢掉了。
3. 洞察：平方只看绝对值，绝对值最大的元素一定在数组两端 → 结果的最后一格是 `nums[0]²` 与 `nums[-1]²` 中较大的。
4. 最优：双指针从两端收缩，结果**从后往前**填，每个元素只处理一次 → `O(n)`。另一种等价想法：找到负数与非负数的分界，两段做归并。
