## Q
**LC 40 组合总和 II**｜Medium · LC TikTok 热度 38/100 · CodeTop 国内累计 26 次 · 最近 2025-12-09（CodeTop）

给数组 `candidates`（可能有重复元素）和 `target`，找出所有和为 `target` 的组合；每个元素在一个组合里只能用一次，结果里不能有重复的组合。`1 <= candidates.length <= 100`，`1 <= candidates[i] <= 50`，`1 <= target <= 30`。例：`[2,5,2,1,2], 5` → `[[1,2,2],[5]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「找出**所有**组合」→ **回溯**（backtracking）：路径 `path` + 剩余目标 `remain`，到 `0` 收集。
- 「每个元素只能用一次」→ 递归时下一层从 `i + 1` 开始，不回头。
- 「有重复元素，且结果不能重复」→ **排序 + 同层跳过相同值**：重复组合只来自「同一层选了值相同的两个不同下标」。
- 元素都是正数且 `target <= 30` → 排序后 `nums[i] > remain` 就可以 `break` 剪枝；递归深度不超过 `30`。
- 组合与顺序无关 → 只往后选（`start` 递增），不会生成同一组合的不同排列。

**推导链。**
1. 暴力：枚举 `2^n` 个子集、求和、用集合去重；`n = 100` 不可行。
2. 浪费：很多子集早就超过 `target` 了还在继续扩；同一个多重集被不同下标的相同值反复生成。
3. 洞察：排序后，超额就整层结束；同一层相同值只选第一个（`i > start` 才比较前一个）。
4. 最优：回溯 + 排序 + 两个剪枝，输出多少就搜多少，没有无谓分支。
