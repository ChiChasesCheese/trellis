## Q
**LC 1860 增长的内存泄露**｜Medium · LC TikTok 热度 62/100

两个内存条剩余 `memory1`、`memory2` 位。第 `i` 秒（从 `1` 开始）把 `i` 位分给剩余较多的内存条（相等分给第一个）；两个都不足 `i` 位时程序退出。返回 `[崩溃时刻, 内存条 1 剩余, 内存条 2 剩余]`。`0 <= memory1, memory2 <= 2^31 - 1`。例：`(8, 11)` → `[6, 0, 4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 规则逐秒给出、停止条件明确 → **模拟**（simulation）。
- 先估步数：每秒消耗 `i` 递增，`t` 秒总消耗约 `t^2 / 2`，不会超过 `memory1 + memory2 <= 2^32` → `t <= sqrt(2^33) ≈ 9.3` 万，**模拟足够快**，不用公式。
- “较多的那个”+“相等给第一个” → 比较写 `memory1 >= memory2`，平局规则藏在比较符号里。
- “两个都不足才退出” → 只看 `max(memory1, memory2) >= i`。
- 范围写成 `2^31 - 1` 容易让人误以为要 `O(1)` 公式，先算步数再决定是关键。

**推导链。**
1. 暴力：逐秒模拟，直接对应题意。
2. 担心：范围 `2^31`，会不会循环 `2^31` 次？
3. 洞察：消耗是等差数列求和，`t` 步总消耗 `t(t+1)/2`，被总量封顶，所以 `t` 最多约 `9.3` 万。
4. 最优：模拟，`O(sqrt(memory1 + memory2))`；范围再大才需要分段公式。

**同模式的题**：LC 1535 找出数组游戏的赢家、LC 1823 找出游戏的获胜者、LC 2073 买票需要的时间、LC 1344 时钟指针的夹角。
