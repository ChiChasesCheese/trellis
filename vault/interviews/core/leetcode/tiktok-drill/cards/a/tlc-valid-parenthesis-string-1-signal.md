## Q
**LC 678 有效的括号字符串**｜Medium · LC TikTok 热度 65/100 · 近一年被问：美国 3 次、国内 0 次 · CodeTop 国内累计 8 次 · 最近 2026-02-18（面试记录）

给一个只含 `'('`、`')'`、`'*'` 的字符串 `s`，判断它是否有效：每个 `'('` 都有后面的 `')'` 配对，每个 `')'` 都有前面的 `'('` 配对；`'*'` 可以当 `')'`、`'('` 或空串。`1 <= s.length <= 100`。例：`"(*))"` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号配对」→ 扫描一遍维护「未配对 `'('` 的个数」（计数代替栈），出现负数就失败。
- 「`'*'` 有三种取值」→ 暴力是每个星号三选一；但只关心未配对个数，所以不需要追踪具体选择，改追踪**可能取值的集合**。
- 集合恰好是连续区间（每个星号让集合向两侧各扩一格）→ 两个整数 `[lo, hi]` 就能表示，贪心 `O(n)`。
- `n <= 100`：`O(n^3)` 区间 DP 也能过，但那是退路，不是最优解。

**推导链。**
1. 暴力：`k` 个星号共 `3^k` 种替换，每种做一次计数检查，`O(3^k · n)`。
2. 浪费：不同替换常常走到同样的「未配对数」，之后的结果只取决于这个数字。
3. 洞察：处理完前 `i` 个字符后，所有可能的未配对数是区间 `[lo, hi]`；`'('` 让区间右移，`')'` 左移，`'*'` 两侧各扩一格；`lo` 不能为负，截到 `0`；`hi < 0` 立刻失败。
4. 最优：一趟扫描，结束时 `lo == 0` 即有效。`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 20 有效的括号、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号、LC 32 最长有效括号。
