## Q
**LC 1209 删除字符串中的所有相邻重复项 II**｜正确性

为什么用栈单遍扫描就能处理“删除之后又产生新的重复”？只对原字符串做一次分段统计（`groupby`，每段保留 `长度 % k` 个）错在哪里？给出具体输入。

## A
**不变量。** 每处理完一个字符，栈里的内容就是“当前已处理前缀在所有可能的删除都做完之后”的结果，并且相邻两项的字符一定不同、每项的次数都在 `1` 到 `k - 1` 之间。

**为什么能级联。** 一项因次数达到 `k` 被弹出后，露出的下一项成为新的栈顶。下一个字符如果与它相同，就会直接延长它，相当于被删除段两侧的字符“连在一起”之后继续合并。

**单遍分段的错误。** 分段统计看到的只是原字符串里的连续段，删除之后新合并出的段它看不见。
- `("deeedbbcccbdaa", 3)`：分段是 `d, eee, d, bb, ccc, b, d, aa`，保留 `长度 % 3`：`d`、空、`d`、`bb`、空、`b`、`d`、`aa`，拼成 `'ddbbbdaa'`；真实过程中 `bbb` 之后 `ddd` 又会被删除，正确是 `'aa'`。
- `("pbbcggttciiippooaais", 2)`：分段统计得到 `'pcciis'`；真实过程中 `bb`、`gg`、`tt` 被删除后两个 `c` 相邻再被删除；`iii` 留下一个 `i`，`pp`、`oo`、`aa` 删除后它与后面的 `i` 相邻，又被删除，正确是 `'ps'`。

分段统计相当于只做了一轮删除，而题目要求做到无法继续为止。
