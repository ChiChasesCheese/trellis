## Q
**LC 746 使用最小花费爬楼梯**｜正确性

为什么初始值是 `dp[0] = dp[1] = 0`，答案是 `dp[n]` 而不是 `dp[n-1]`？如果把状态定义成「已经付过 `cost[i]`」却仍返回最后一项，会错在哪里？

## A
**不变量。** 循环到下标 `i` 时，`two_back` 与 `one_back` 分别是到达第 `i-2` 级、第 `i-1` 级的最小**已付**花费。「到达」一级时，这一级自己的费用还没付；只有从它出发时才付。

**为什么初值是 `0`。** 题目允许直接站在下标 `0` 或 `1`，还没爬过任何一步，什么都没付。

**为什么是 `dp[n]`。** 顶部是越过最后一级的位置 `n`。从 `n-1` 出发要付 `cost[n-1]`，从 `n-2` 出发要付 `cost[n-2]`，这两种来源都包含在 `dp[n]` 的转移式里。

**反例：状态定义成「站在第 `i` 级并已付 `cost[i]`」。** 此时 `dp[i] = cost[i] + min(dp[i-1], dp[i-2])`，初值 `dp[0] = cost[0]`、`dp[1] = cost[1]`。`cost = [10,15,20]`：
- `dp = [10, 15, 30]`。返回最后一项 `dp[2] = 30`，错误。
- 正确答案是 `15`：最后一级不必站上去，从下标 `1` 直接爬两级到顶。
- 这种定义下必须返回 `min(dp[n-1], dp[n-2])`，也就是 `min(15, 30) = 15`。
