## Q
**LC 124 二叉树中的最大路径和**｜正确性

为什么向父亲返回 `val + max(左, 右)`（只选一侧），而更新全局答案时却用 `val + 左 + 右`？为什么要把负增益取成 `0`？给出具体的树。

## A
**不变量。** 处理完节点 `v` 后，`gain[v]` 是「从 `v` 出发、只向下走」的最大路径和；全局 `best` 是已处理子树内所有路径的最大和。每条路径恰好有一个最高点，在处理这个最高点时被 `val + 左 + 右` 考虑到。

**反例一：返回值也含两侧。** 树 `[1,2,3,null,null,4,5]`（`1` 的左孩子是 `2`，右孩子 `3` 带两个孩子 `4`、`5`）。
- 节点 `3` 若返回 `3 + 4 + 5 = 12`，父节点 `1` 会计算 `1 + 2 + 12 = 15`。
- 但这条「路径」`2 → 1 → 3` 之后又同时走到 `4` 和 `5`，在 `3` 处分叉，不是合法路径。
- 正确答案是 `12`（`4 → 3 → 5`）。向上返回只能延续一条链。

**反例二：不舍弃负增益。** 树 `[2,-1]`。
- 节点 `2` 的左增益是 `-1`。不取 `0` 时，以 `2` 为最高点的和是 `2 + (-1) = 1`。
- 正确答案是 `2`：只取节点 `2` 自己，不带上负的子树。

**反例三：全局答案初值取 `0`。** 树 `[-3]`。
- `best = 0` 时，`max(0, -3) = 0`，答案成了「空路径」的 `0`。
- 路径至少含一个节点，正确答案是 `-3`。
