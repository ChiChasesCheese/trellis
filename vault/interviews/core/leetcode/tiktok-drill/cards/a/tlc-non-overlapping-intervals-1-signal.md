## Q
**LC 435 无重叠区间**｜Medium · TikTok 高频

给一组区间 `intervals`，`intervals[i] = [start_i, end_i]`。返回最少需要移除的区间数，使剩下的区间两两不重叠；只在端点接触的区间不算重叠，如 `[1,2]` 和 `[2,3]`。`1 <= intervals.length <= 10^5`，`intervals[i].length == 2`，`-5 * 10^4 <= start_i < end_i <= 5 * 10^4`。例：`[[1,2],[2,3],[3,4],[1,3]]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「区间 + 两两不重叠 + 最少移除」→ 区间调度（Interval Scheduling）：最少移除 = 总数 - 最多保留，用贪心。
- `n = 10^5`：`O(n^2)` 的 DP 不行，只能排序加一遍扫描，`O(n log n)`。
- 「端点接触不算重叠」→ 边界比较写 `>=`；值域含负数 → 哨兵用 `-inf`，不是 `0`。

**推导链。**
1. 暴力：枚举保留哪些区间，检查两两不重叠，`2^n`。
2. 进一步：按右端点排序，做类似最长上升子序列的 DP，`dp[i]` 是以第 `i` 个结尾最多保留几个，`O(n^2)`，`10^5` 超时。
3. 浪费：DP 每次都在回头比较所有前驱，但接在谁后面只取决于最后一个保留区间的右端点。
4. 洞察：右端点最小的区间对后面的限制最小。交换论证：任何最优解里，把它的第一个区间换成右端点最小的区间，剩下的仍然不重叠，保留数不减。于是每一步选「右端点最小且不与已选重叠」的区间。
5. 最优：按右端点排序，一遍扫描，起点 `>=` 当前右端点就保留，否则丢弃，`O(n log n)`。
