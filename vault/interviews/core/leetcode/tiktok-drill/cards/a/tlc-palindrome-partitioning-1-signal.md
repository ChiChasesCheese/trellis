## Q
**LC 131 分割回文串**｜Medium · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 6 次 · 最近 2026-07（面试记录）

给字符串 `s`，把它分割成若干子串，使每个子串都是回文串，返回所有可能的分割方案。`1 <= s.length <= 16`，`s` 只含小写英文字母。例：`s = "aab"` → `[["a","a","b"],["aa","b"]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回所有分割方案」→ 枚举型回溯（backtracking）：输出规模本身就是指数级，不存在多项式解。
- `s.length <= 16`：`2^15 = 32768` 种切法，指数搜索可行；这个范围是在暗示「用回溯」。
- 「每个子串都是回文」→ 约束可以在选段时立刻检查，前缀不满足就剪枝，不必切完再验。
- 反复判断「`s[i..j]` 是不是回文」→ 区间 DP 预处理成表，之后 `O(1)` 查。

**推导链。**
1. 暴力：每个相邻字符间切或不切，`2^(n-1)` 种，切完逐段验证回文，`O(2^n · n^2)`。
2. 浪费：第一段已经不是回文，后面怎么切都是白搜；同一个子串的回文性被重复计算。
3. 洞察：从 `start` 出发枚举第一段的结束位置，只在 `pal[start][end]` 为真时下探；`pal` 用 `pal[i][j] = (s[i] == s[j]) and pal[i+1][j-1]` 递推。
4. 最优：搜索树只含有效前缀，每个叶子是一个答案，时间 `O(n · 2^n)`，预处理 `O(n^2)`。
