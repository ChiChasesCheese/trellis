## Q
**LC 61 旋转链表**｜Medium · CodeTop 国内累计 19 次 · 最近 2026-04-20（CodeTop）

给链表头 `head`，把每个结点向右移动 `k` 个位置（循环右移），返回新头。结点数在 `[0, 500]` 内，`-100 <= Node.val <= 100`，`0 <= k <= 2 * 10^9`。例：`[1,2,3,4,5], k = 2` → `[4,5,1,2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「循环右移 `k` 位」→ 结果就是把最后 `k` 个结点整段搬到前面：**找到切点、断开、重接**，是链表的指针操作题。
- `k` 到 `2 * 10^9`、`n` 最多 `500` → 转 `n` 次回到原样，必须 `k %= n`。
- 单链表不能按下标访问 → 先走一遍得到长度 `n` 和尾结点。

**推导链。**
1. 暴力：每次把尾结点搬到头部，重复 `k` 次，每次找尾 `O(n)` → `O(nk)`，`k` 太大。
2. 取模：`k %= n`，最多转 `n - 1` 次，仍是 `O(n^2)`。
3. 关键：右移 `k` 次 = 在第 `n - k` 个结点后切开、后段接到前面，一次完成。
4. 实现：尾接头成环，从头走 `n - k - 1` 步到新尾，新头是 `new_tail.next`，断环。`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 189（轮转数组）、LC 19（删除倒数第 N 个结点）、LC 876（链表中点）。
