## Q
**面试题 08.13 堆箱子**｜Hard · CodeTop 国内累计 2 次 · 最近 2026-03-11（CodeTop）

`n` 个箱子 `[wi, di, hi]`（宽、深、高），不能翻转；叠放时下面箱子的宽、深、高都必须严格大于上面的箱子。求箱堆的最大总高度。箱子数目不大于 `3000`。例：`[[1,1,1],[2,3,4],[2,6,7],[3,4,5]]` → `10`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「挑一串元素、相邻两个满足『全都更小』、求最优」→ **LIS 变形**：偏序换成三维严格支配，目标换成高度和（**带权 LIS**）。
- 「不能翻转」→ 每个箱子只有一种朝向，不用枚举旋转。
- 「严格大于」→ 任一维相等都不能叠，排序后宽度相同的箱子仍要显式比较。
- `n <= 3000` → `O(n^2) ≈ 4.5 * 10^6` 可行。

**推导链。**
1. 暴力：枚举子集并检查能否排成合法堆，指数级。
2. 浪费：一个合法堆从上到下宽度严格递增，顺序其实是确定的，枚举排列毫无必要。
3. 关键：按宽度排序后，任何合法堆都是排序数组的子序列；「以箱子 `i` 为底」的最优堆 = `h_i` + 能放在它上面的某个 `j` 为底的最优堆。
4. 最优：`dp[i] = h_i + max(dp[j])`（`j < i` 且三维都严格更小），答案 `max(dp)`，`O(n^2)` 时间、`O(n)` 空间。
