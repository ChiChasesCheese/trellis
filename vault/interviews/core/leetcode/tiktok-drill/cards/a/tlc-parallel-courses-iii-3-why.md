## Q
**LC 2050 并行课程 III**｜正确性

为什么一门课出队时它的 `start` 已经是最终值？为什么答案是所有完成时间的最大值，而不是最后一门课的完成时间或者所有时间之和？

## A
**不变量。** 一门课在入度归零时才入队，此时所有先修课都已经出队并且已经用它们的完成时间更新过 `start[v]`；之后再没有先修课会更新它，所以出队时 `start[u]` 就是 `max(先修课完成时间)`，`finish = start[u] + time[u]` 是它的最早完成时间。

**为什么取最大值。** 总时间是最晚完成的那门课的完成时间。拓扑顺序里最后出队的课，完成时间不一定最大：互不依赖的课程可以任意排列出队顺序。

**反例一：取最后出队的完成时间。** `n = 3`，没有先修关系，`time = [1,9,4]`：
- 三门课都入度为 `0`，按 `1, 2, 3` 出队，最后一门的完成时间是 `4`。
- 它们可以同时开始，总时间 `9`（耗时最长的那门课）。

**反例二：后继的 `start` 只在第一次赋值。** 写成 `if start[v] == 0: start[v] = finish`（取最先到达的先修课），`n = 5`，`relations = [[1,5],[2,5],[3,5],[3,4],[4,5]]`，`time = [1,2,3,4,5]`：
- 课程 `5` 的先修课 `1, 2, 3, 4` 的完成时间依次是 `1, 2, 3, 7`。
- 错误版本里 `start[5]` 停在第一个到达的 `1`，课程 `5` 的完成时间算成 `6`，最终答案是课程 `4` 的完成时间 `7`。
- 正确是 `start[5] = max(1, 2, 3, 7) = 7`，答案 `12`。

**反例三：把时间相加。** 第一个示例相加得到 `10`，忽略了课程 `1`、`2` 可以同时上，正确是 `8`。
