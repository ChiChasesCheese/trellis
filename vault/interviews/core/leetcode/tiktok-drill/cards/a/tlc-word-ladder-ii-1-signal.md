## Q
**LC 126 单词接龙 II**｜Hard · 近一年被问：美国 2 次、国内 1 次 · 最近 2026-10-25（面试记录）

给 `beginWord`、`endWord` 和字典 `wordList`。转换序列要求：相邻单词恰好差一个字母；除 `beginWord` 外每个单词都在 `wordList` 中；最后一个是 `endWord`。返回所有最短转换序列，没有则返回空列表。`1 <= beginWord.length <= 5`，`1 <= wordList.length <= 500`，单词等长、只含小写字母，`beginWord != endWord`，`wordList` 互不相同。例：`"hit"` 到 `"cog"`，字典 `["hot","dot","dog","lot","log","cog"]` → 两条最短序列。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最短转换序列」→ 无权图上的 BFS，单词是节点，差一个字母是边。
- 「返回所有最短」→ BFS 里保留同一层的多个父亲，形成层图，再从终点回溯展开。
- 「差一个字母」→ 通配符桶：把每个位置换成 `*` 作为键（`hot` 属于 `*ot`、`h*t`、`ho*`），同一个桶里的词两两相邻。
- `wordList <= 500`、长度 `<= 5`：图很小；难点在最短路条数可能很大，不能存整条路径。

**推导链。**
1. 暴力：DFS 枚举所有简单路径，取最短的，路径数指数级。
2. 改进：BFS 队列里存整条路径，每次扩展复制路径；同层要允许多次到达同一个词，访问标记变得复杂。
3. 浪费：大量不会成为最短路的路径前缀被保存和复制。
4. 洞察：只存「父亲关系」。一个词的父亲是上一层中与它相差一个字母的所有词；最短路 = 层图里从终点回到起点的所有路径。
5. 最优：按层 BFS，整层扫完再更新 `seen`，使同层的多个父亲都被记下；到达终点层就停；最后 DFS 沿父亲链回溯展开。

**同模式的题**：LC 127 单词接龙、LC 433 最小基因变化、LC 752 打开转盘锁、LC 773 滑动谜题。
