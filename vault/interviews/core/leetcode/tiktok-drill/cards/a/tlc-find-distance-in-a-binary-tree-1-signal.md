## Q
**LC 1740 找到二叉树中的距离**｜Medium · TikTok 高频

二叉树根结点 `root` 与两个整数 `p`、`q`，返回值为 `p` 的结点和值为 `q` 的结点之间路径上的边数。结点个数 `[1, 10^4]`，`0 <= Node.val <= 10^9`，所有值唯一，`p`、`q` 都在树中。例：`root = [3,5,1,6,2,0,8,null,null,7,4]`，`p=5, q=0` → `3`（5-3-1-0）；`p=5, q=5` → `0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树上两个结点的路径长度」→ **最近公共祖先**（LCA）：路径必然先上行到 LCA 再下行，`距离 = depth[p] + depth[q] - 2*depth[LCA]`。
- 结点只有 `left` / `right`，没有父指针 → 要么补父指针，要么把树当无向图。
- 「值唯一」→ 可以用 `值 → 结点` 的字典定位 `p`、`q`。
- `n = 10^4` 且树可能是单链，Python 递归默认深度约 1000 → 必须**迭代**遍历。

**推导链。**
1. 暴力：求根到 `p`、根到 `q` 的两条路径，去掉公共前缀，剩余长度相加。`O(n)` 时间，但要存两条路径。
2. 另一种暴力：建无向图，从 `p` 做 BFS 到 `q`，`O(n)` 时间、空间也多。
3. 浪费：路径本身用不上，只要「每个结点的父结点与深度」。
4. 最优：一次迭代遍历记 `parent`、`depth`；两个指针按「更深的先上爬」同步上行，相遇处就是 LCA，爬的步数即答案。

**同模式的题**：LC 236 二叉树的最近公共祖先、LC 863 二叉树中所有距离为 K 的结点、LC 2096 从二叉树一个结点到另一个结点的每步方向、LC 235 二叉搜索树的最近公共祖先。
