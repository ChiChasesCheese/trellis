## Q
**LC 886 可能的二分法**｜Medium · TikTok 高频

把编号 `1..n` 的 `n` 个人分进任意大小的两组。给定整数 `n` 和数组 `dislikes`，`dislikes[i] = [ai, bi]` 表示不允许把 `ai` 和 `bi` 分到同一组。当可以用这种方法把所有人分成两组时返回 `true`，否则返回 `false`。`1 <= n <= 2000`，`0 <= dislikes.length <= 10^4`，`dislikes[i].length == 2`，`1 <= dislikes[i][j] <= n`，`ai < bi`，每一组都不同。例：`n = 3, dislikes = [[1,2],[1,3],[2,3]]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「分成两组，某些对不能在同一组」→ 把人当点、「讨厌」当边 → **二分图判定**（bipartite check），也叫**二着色**（two-coloring）。
- 约束是**成对互斥**，选择会沿边传播：`a` 在甲组，则 `a` 的所有敌人必在乙组，敌人的敌人又回到甲组 → **BFS / DFS 染色**，或带奇偶的并查集。
- 图里有**奇数长度的环**就不可能二分，例 2 的三角形就是最小例子。
- `n <= 2000`、边至多 `10^4` → `O(n + m)`；DFS 的递归深度可达 `2000`，超过默认递归上限，BFS 更稳。
- 没说图连通 → 要对每个连通块各做一次。

**推导链。**
1. 暴力：枚举 `2^n` 种分组，逐条检查边。
2. 浪费：一个人的组一确定，邻居的组就被强制了，大部分分支根本不用试。
3. 关键：任选起点染成颜色 `1`，BFS 时邻居一律染成相反色；邻居已有颜色且与自己相同，就出现冲突（奇数环）。
4. 外层循环遍历所有点，对还没染色的点开一次新的 BFS（新的连通块）。全部通过则返回 `True`，`O(n + m)`。
