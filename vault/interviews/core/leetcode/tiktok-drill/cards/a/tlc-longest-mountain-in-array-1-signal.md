## Q
**LC 845 数组中的最长山脉**｜Medium · LC TikTok 热度 50/100（近 3 个月） · CodeTop 国内累计 3 次 · 最近 2026-05-10（CodeTop）

山脉数组：长度至少 `3`，存在下标 `i`（`0 < i < len - 1`），使 `arr[0] < ... < arr[i]` 且 `arr[i] > ... > arr[len - 1]`（严格上升再严格下降）。给整数数组 `arr`，返回其中最长山脉子数组（连续）的长度，不存在返回 `0`。`1 <= arr.length <= 10^4`，`0 <= arr[i] <= 10^4`。进阶：一趟扫描、`O(1)` 空间。例：`arr = [2,1,4,7,3,2,5]` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子数组」+「先严格升后严格降」→ **形状匹配**：每座山有且仅有一个山顶，用山顶定位，向两侧沿坡扩展。
- 「严格」+「长度至少 `3`」→ 平台（相等）不能算上坡或下坡，山顶两侧必须都至少有一步。
- 「进阶：一趟、`O(1)` 空间」→ 双指针扩展，或 `up` / `down` 两个计数器。
- `n <= 10^4`：`O(n^2)` 能过，但要的是 `O(n)`。

**推导链。**
1. 暴力：枚举所有子数组并检查是否山脉，`O(n^3)`；检查可以早退，但仍是 `O(n^2)` 以上。
2. 洞察：山脉由山顶唯一确定。扫描每个下标，判断是否为山顶（两侧都严格更低）。
3. 找到山顶后，向左沿严格上升走到山脚，向右沿严格下降走到山脚，长度 = 右脚 - 左脚 + 1。
4. 不同的山共用至多一个山脚点，处理完一座山就令 `i = right` 跳到右脚，扩展路径互不重叠，总代价 `O(n)`。
5. 空间 `O(1)`。另一种等价思路：用 `up`、`down` 计数器一趟扫描。
