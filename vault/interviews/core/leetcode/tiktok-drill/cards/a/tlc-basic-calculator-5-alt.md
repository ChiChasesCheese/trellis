## Q
**LC 224 基本计算器**｜另一种解法

不保存 `(res, sign)` 对，只用一个「符号栈」也能做：栈里存什么？怎么处理 `+`、`-`、`(`、`)`？它和主解法相比各有什么优劣？

## A
**思路。** 括号展开后，每个数的实际符号等于「它自己的运算符」乘以「它所在每一层括号前的符号之积」。用一个栈保存当前层的**总符号**：栈顶就是括号内部所有项共同乘上的那个符号。这样 `res` 全程是一个累加器，不需要在括号边界做合并。

```python
def calculate_signs(s: str) -> int:
    signs = [1]                           # 栈顶 = 当前括号层对内部每一项的总符号
    res, num, sign = 0, 0, 1              # sign：下一个数的实际符号
    for ch in s:
        if ch.isdigit():
            num = num * 10 + int(ch)
        elif ch in "+-":
            res += sign * num
            num = 0
            sign = signs[-1] * (1 if ch == "+" else -1)
        elif ch == "(":
            signs.append(sign)            # 括号内部的所有项都要再乘上这个符号
        elif ch == ")":
            res += sign * num
            num = 0
            signs.pop()
    return res + sign * num
```

运行：`"1 + 1"` → `2`，`"(1+(4+5+2)-3)+(6+8)"` → `23`，`"-(2+3)"` → `-5`，`"(-2)"` → `-2`，`"2-(5-6)"` → `3`。

**怎么工作。** 读到 `(` 时，当前 `sign` 就是括号前的符号，压栈作为新一层的总符号；括号内再遇到 `+`/`-`，实际符号 = 栈顶 × 自己的正负；`)` 弹出一层，栈顶恢复成外层的总符号。

**复杂度。** 时间 `O(n)`，空间 `O(d)`，与主解法相同。

**何时选哪个。**
- 符号栈版本：栈里只有整数，没有元组，括号边界处只有一个 `append` / `pop`，不做乘法合并，写起来最短，面试里手速快。
- 主解法（存 `(res, sign)`）：括号的语义更直观——「括号作为一整项」，之后扩展到乘除或变量时，保存每层状态的结构可以直接复用。
- 两者对 `"1-(2+3)"` 都给出 `-4`，都不递归，`"(" * 100000 + "1" + ")" * 100000` 都得 `1`。
