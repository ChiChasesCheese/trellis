## Q
**LC 3086 拾起 K 个 1 需要的最少行动次数**｜Hard · LC TikTok 热度 62/100

二进制数组 `nums`、正整数 `k`、非负整数 `maxChanges`。Alice 先选站立下标，若该位是 `1` 就免费拾起。之后每次行动二选一：（1）把某个 `j != aliceIndex` 的 `0` 置为 `1`（最多 `maxChanges` 次）；（2）交换相邻的 `1` 和 `0`，若 `1` 被换进了 Alice 的位置则拾起。求恰好拾起 `k` 个 `1` 的最少行动次数。

约束：`2 <= n <= 10^5`，`0 <= nums[i] <= 1`，`1 <= k <= 10^5`，`0 <= maxChanges <= 10^5`，`maxChanges + sum(nums) >= k`。例：`nums = [1,1,0,0,0,1,1,0,0,1], k = 3, maxChanges = 1` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「相邻交换、每步一格」→ 把一个 `1` 挪到 Alice 身边的代价就是它们的距离；`k` 个点聚到一处的最小总距离在**中位数**（median）处取到。
- 「`maxChanges` 次造 `1`」→ 造一个再换过来固定是 `2` 步，是一档固定代价，要和「挪已有的 `1`」比价，贪心用便宜的。
- 脚下 `0` 步、相邻 `1` 步 → 只有最多 3 个位置（脚下加左右）比造 `1` 便宜，这个数 `c` 等于连续 `1` 的长度封顶 `3`。
- `n = 10^5` → 窗口 + 前缀和，`O(n)`。

**推导链。**
1. 暴力：枚举站立位置 `i`；已有 `1` 代价 `|j - i|`，造 `1` 代价 `2`；取最便宜的 `k` 个，`O(n · (m + maxChanges) · log k)`。
2. 浪费：代价档位其实只有 `0, 1, 1, 2, 2, 3, …`，造 `1` 恰好卡在 `2`。
3. 洞察：先吃 `c` 个相邻的；若 `maxChanges >= k - c`，其余全造，答案 `max(c - 1, 0) + 2 * (k - c)`；否则造 `1` 用满，剩下 `need = k - maxChanges` 个必须从已有的 `1` 里挪。
4. 最优：在位置数组上滑动长度为 `need` 的窗口，站中位数，前缀和 `O(1)` 求距离和，取最小。

**同模式的题**：LC 462 最少移动次数使数组元素相等 II、LC 1703 得到连续 K 个 1 的最少相邻交换次数、LC 296 最佳的碰头地点、LC 2448 使数组相等的最小开销。
