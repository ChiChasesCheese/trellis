## Q
**LC 460 LFU 缓存**｜Hard · 近一年被问：美国 14 次、国内 27 次 · CodeTop 国内累计 21 次 · 最近 2026-10（面试记录）

设计最不经常使用（LFU）缓存：`LFUCache(capacity)`、`get(key)`（存在返回值，否则 `-1`）、`put(key, value)`（存在则更新，不存在则插入；容量已满时先淘汰**使用次数最少**的键，次数相同则淘汰**最久未使用**的键）。键首次插入次数为 `1`，之后每次 `get` 或 `put` 加一。`get`、`put` 必须平均 `O(1)`。`1 <= capacity <= 10^4`，`0 <= key <= 10^5`，`0 <= value <= 10^9`，最多 `2 * 10^5` 次调用。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「设计数据结构」+「`get` / `put` 平均 `O(1)`」→ 哈希表 + 某种能在 `O(1)` 内增删、定位"最老"的有序结构。
- 淘汰规则有**两级**：先比使用次数，再比最近使用时间 → 按次数分桶，桶内按使用先后排列（每个桶就是一个 LRU）。
- 「使用次数最少」→ 需要随时知道最小次数是几：`min_freq`，它只在"新键插入"和"最小桶搬空"时变化，可以 `O(1)` 维护。
- `2 * 10^5` 次调用：`O(n)` 的扫描淘汰会到 `2 * 10^9`，不可行；堆的 `O(log n)` 可以过但题目要求 `O(1)`。

**推导链。**
1. 暴力：淘汰时扫描所有键，找 `(次数, 最近使用时间)` 最小的，`O(n)`。
2. 堆：条目 `(次数, 时间, 键)`，使用一次就要更新，`O(log n)`，且需要处理过期条目。
3. 洞察：次数只会 `+1`，所以键只需要从 `f` 号桶搬到 `f+1` 号桶；桶内用有序字典，末尾追加 = 最近使用，最左边 = 最久未使用。
4. `min_freq`：新键到来时置 `1`；搬走最后一个键导致最小桶变空时加一。淘汰就是 `popitem(last=False)` 取最小桶最老的键。

**同模式的题**：LC 146 LRU 缓存、LC 432 全 O(1) 的数据结构、LC 380 O(1) 时间插入、删除和获取随机元素、LC 588 设计内存文件系统。
