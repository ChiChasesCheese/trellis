## Q
**LC 1530 好叶子节点对的数量**｜Medium · LC TikTok 热度 50/100

给二叉树的根节点 `root` 和整数 `distance`。如果两个叶节点之间的最短路径长度小于或等于 `distance`，它们就是一组好叶子节点对，返回好叶子节点对的数量。节点数在 `[1, 2^10]`，节点值在 `[1, 100]`，`1 <= distance <= 10`。例：`root = [1,2,3,4,5,6,7]`，`distance = 3` → `2`（叶子对 `[4,5]` 和 `[6,7]`，路径长都是 `2`；`[4,6]` 路径长 `4`，不算）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树上两个点之间的最短路径」→ 经过最近公共祖先（LCA），每对叶子在它们的 LCA 处恰好统计一次 → 树形 DP（后序，孩子先于父亲）。
- `distance <= 10` → 状态可以是“距离不超过 `distance` 的叶子在每个距离上的个数”，数组长度 `11`，合并是常数。
- 节点数 `<= 2^10` → 单链深度 `1023`，超过 Python 默认递归深度 `1000`，要用迭代。
- 「叶子」→ 叶子自己距自己 `0`，内部节点不上报自己。

**推导链。**
1. 暴力：收集所有叶子，两两求路径长（父指针找 LCA），`O(L^2 · h)`。
2. 浪费：每对叶子独立计算，没有利用“路径必经 LCA”。
3. 洞察：路径长 = 左叶子到 LCA 的距离 + 右叶子到 LCA 的距离，在 LCA 处用两侧的距离分布统计和 `<= distance` 的对数。
4. 右侧做前缀和，左侧每个距离 `i` 贡献 `left[i] * right_prefix[distance - i]`。
5. 上报时把两侧数组整体右移一位（距离加一）后相加，超过 `distance` 的丢弃。

**同模式的题**：LC 543 二叉树的直径、LC 124 二叉树中的最大路径和、LC 687 最长同值路径、LC 834 树中距离之和。
