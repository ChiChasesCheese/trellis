## Q
**LC 230 二叉搜索树中第 K 小的元素**｜正确性

为什么迭代中序弹出的顺序就是升序？计数如果放在「入栈时」而不是「出栈时」会错在哪里？给出具体输出。

## A
**不变量。** 每次从栈中弹出一个节点时，所有比它小的节点都已经被弹出过。理由：BST 满足「左子树所有值 < 根 < 右子树所有值」。弹出节点 `x` 之前，我们已经把 `x` 的整个左链压栈并先弹出了左子树里的节点（左子树节点比 `x` 小）；`x` 的祖先中，值比 `x` 小的是那些「`x` 在其右子树里」的祖先，它们在进入右子树之前就已经被弹出。弹出的顺序因此严格升序，第 `k` 次弹出就是第 `k` 小。

**为什么能提前停。** 前 `k` 次弹出已经确定了答案，后面的节点不会影响结果。

**反例 1：入栈时计数。** 树 `[5,3,6,2,4,null,null,1]`，`k = 3`。
- 入栈顺序是 `5, 3, 2, 1`，在第 `3` 个入栈的节点 `2` 处就返回。
- 输出 `2`，正确答案是 `3`（升序为 `1, 2, 3, 4, 5, 6`）。
- 入栈顺序是「先序」的一部分，不是升序；只有出栈顺序才是中序。

**反例 2：先序后取第 `k` 个。** 同一棵树的先序是 `5, 3, 2, 1, 4, 6`，第 `3` 个也是 `2`，错。
