## Q
**LC 283 移动零**｜追问

面试官接着问：（1）移到末尾的不是 `0` 而是某个给定值 `val`（或者直接删除，LC 27）；（2）要求写入次数尽可能少；（3）一行写法 `nums.sort(key=...)` 行不行？

## A
1. **任意值 `val`**：把条件换成 `nums[read] != val` 即可，写法完全一样；LC 27 只要求返回剩余长度，则 `write` 就是答案，不必把 `val` 放到末尾。
2. **最少写入**：已经做到——`write == read` 时一次都不写，之后每个需要搬动的非零元素写 `2` 次（放到 `write`、把原位置清零）。另一种写法是先把非零元素依次覆盖到前面，再把 `write` 之后全部补零：写入次数是「非零个数 + 零的个数」，没有零时也写满一遍；上面的写法在零很少或在末尾时更省。
3. **一行写法**：`nums.sort(key=lambda x: x == 0)` 是对的，因为 `sort` 稳定，键 `False < True` 把非零放前面；但它是 `O(n log n)`，且隐藏了考察的技巧，面试里只当作补充提一句。

**Python 提醒**：`nums = [x for x in nums if x] + [0] * k` 创建了新列表并重新绑定局部名字，调用方的列表不变；需要原地改成新内容时用切片赋值 `nums[:] = ...`，但那仍然会分配临时列表，不满足「不复制数组」的要求。
