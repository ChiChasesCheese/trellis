## Q
**LC 317 离建筑物最近的距离**｜正确性

为什么「每幢建筑一次 BFS 再累加」得到的就是每块空地到所有建筑的最短距离之和？为什么必须检查到达计数 `reach == 建筑数`？

## A
**不变量。** 处理完第 `k` 幢建筑后，`total[c]` 是空地 `c` 到这 `k` 幢建筑的最短路径长度之和（只对它能到达的建筑累加），`reach[c]` 是其中它能到达的建筑数。

**为什么正确。** 每次 BFS 是从一个源点出发的无权最短路，第一次访问空地 `c` 时的层数就是最短距离（建筑、障碍不可通行，BFS 只在空地上扩展）。不同建筑的距离互相独立，求和即可。

**为什么要 `reach == 建筑数`。** `total` 只累加了「能到达」的建筑。一块被障碍隔开的空地，可能只到达了一部分建筑，`total` 反而很小，但它不满足「到所有建筑」。

**反例。** `grid = [[1,0,2,1]]`：左边建筑、一块空地、障碍、右边建筑。
- 空地只能到左边的建筑，`total = 1`，`reach = 1`，而建筑总数是 `2`。
- 不检查 `reach`：返回 `1`，错误。
- 检查 `reach == 2`：没有合格空地，返回 `-1`，正确。

**另一个易错点。** BFS 若允许穿过建筑，会把「被建筑挡住」的空地当成可达，距离算短；建筑和障碍一样，只能作为终点或阻挡，不能作为路径的中间格。
