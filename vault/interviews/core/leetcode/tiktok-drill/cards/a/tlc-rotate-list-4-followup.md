## Q
**LC 61 旋转链表**｜追问

面试官接着问：（1）改成向左旋转 `k` 位？（2）同样的问题换成数组（LC 189），要求 `O(1)` 额外空间？（3）能不能用快慢指针一遍完成？

## A
1. **向左旋转 `k` 位**：等价于向右旋转 `n - k % n` 位；也可以直接改切点，新尾是第 `k % n` 个结点（走 `k % n - 1` 步），`k % n == 0` 时原样返回。
2. **数组轮转（LC 189）**：三次反转。先整体反转，再分别反转前 `k` 个和后 `n - k` 个：`[1,2,3,4,5]`、`k = 2` → `[5,4,3,2,1]` → `[4,5,3,2,1]` → `[4,5,1,2,3]`。每个元素交换常数次，`O(n)` 时间、`O(1)` 空间。Python 里用切片赋值 `nums[:] = nums[-k:] + nums[:-k]` 更短，但会建临时列表，是 `O(n)` 空间。
3. **快慢指针**：快指针先走 `k` 步，再一起走到快指针到尾，慢指针就是新尾。但 `k` 可能远大于 `n`，快指针先走 `k` 步本身就要 `O(k)`，所以仍要先数长度、取模，省不掉第一遍。

**Python 提醒**：切片越界不报错而是截断。`k > n` 时 `nums[-k:]` 是整个数组、`nums[:-k]` 是空列表，`[1,2,3]`、`k = 4` 不取模会原样得到 `[1,2,3]`（正确 `[3,1,2]`）；切片前先 `k %= n`。
