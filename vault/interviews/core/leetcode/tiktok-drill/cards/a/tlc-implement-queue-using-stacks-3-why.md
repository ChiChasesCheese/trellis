## Q
**LC 232 用栈实现队列**｜正确性

双栈队列里，为什么只有 `outbox` 为空时才能把 `inbox` 倒进去？每次 `pop` 都倒一遍会出什么错？

## A
**不变量。** 队列从队首到队尾的顺序，等于「`outbox` 从栈顶到栈底，再接 `inbox` 从栈底到栈顶」。也就是说 `outbox` 里的所有元素都比 `inbox` 里的所有元素**更老**。

**为什么只能在 `outbox` 为空时倒。**
- `outbox` 为空：把 `inbox` 整个弹出再压入，顺序反转，原来最老的元素到了栈顶，不变量继续成立。
- `outbox` 非空时倒：`inbox` 的新元素会压在 `outbox` 老元素的**上面**，成为栈顶，下一次 `pop` 先弹出新元素，破坏先进先出。

**反例。** 操作序列：`push(1)`、`push(2)`、`pop()`、`push(3)`、`pop()`。
- 正确实现：第一次 `pop` 触发倒栈，`outbox = [2, 1]`（栈顶 `1`），弹出 `1`，`outbox = [2]`；`push(3)` 进 `inbox`；第二次 `pop` 时 `outbox` 非空，直接弹 `2`。结果 `[1, 2]`。
- 每次 `pop` 都倒：第二次 `pop` 把 `inbox` 里的 `3` 倒进还剩 `2` 的 `outbox`，栈顶变成 `3`，弹出 `3`。结果 `[1, 3]`，错了，`2` 比 `3` 先进，应该先出。

**均摊为什么成立。** 每个元素进 `inbox` 一次、被倒入 `outbox` 一次、弹出一次，一共常数次搬运，所以 `n` 次操作总成本 `O(n)`；某一次 `pop` 虽然可能搬很多元素，但这些搬运的“成本”已经被之前每次 `push` 预付了。
