## Q
**LC 75 颜色分类**｜Medium · LC TikTok 热度 62/100 · CodeTop 国内累计 17 次 · 最近 2025-11-09（CodeTop）

数组 `nums` 只含 `0`（红）、`1`（白）、`2`（蓝），原地排成 `0, 1, 2` 的顺序，不许用库自带的排序函数。`1 <= n <= 300`，`nums[i]` 为 `0`、`1` 或 `2`。进阶：常数空间、一趟扫描。例：`[2,0,2,1,1,0]` → `[0,0,1,1,2,2]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「只有三种取值 + 原地排好」→ **三路划分**（荷兰国旗问题），三个指针维护三段区间。
- 「不许用库排序」→ 面试官要的是划分思想，不是 `sort()`。
- 「进阶：一趟、常数空间」→ 不能先计数再重写（两趟），要在一次扫描中把每个元素放到最终区域。
- 取值个数是固定的 `3` → 可以靠不变量维护，指针个数固定。

**推导链。**
1. 暴力：`sorted` 或自己写排序，`O(n log n)`。
2. 退一步：计数排序，数出每种个数再重写，`O(n)` 但两趟。
3. 洞察：维护「`0` 区、`1` 区、未检查区、`2` 区」四段。遇到 `0` 换到 `0` 区末尾，遇到 `2` 换到 `2` 区开头，遇到 `1` 不动。
4. 最优：`i` 扫描，`lo` / `hi` 收缩；遇到 `2` 换回来的数没检查过，所以 `i` 不前进；`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 283 移动零、LC 215 第 K 个最大元素（三路快速选择）、LC 905 按奇偶排序数组、LC 75 的 `k` 色推广。
