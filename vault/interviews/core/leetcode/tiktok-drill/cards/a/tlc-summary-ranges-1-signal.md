## Q
**LC 228 汇总区间**｜Easy · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-02（面试记录）

给一个**升序**、无重复元素的整数数组 `nums`，返回恰好覆盖其中所有数字的最小有序区间列表，每个区间输出为字符串：`a != b` 写 `"a->b"`，`a == b` 写 `"a"`。`0 <= nums.length <= 20`，`-2^31 <= nums[i] <= 2^31 - 1`。例：`[0,2,3,4,6,8,9]` → `["0","2->4","6","8->9"]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**有序、无重复**」+「连续整数成段」→ 相邻元素差恰为 `1` 就属于同一段，是**分组扫描**（双指针找极长段）。
- 「恰好覆盖、最小」→ 每段必须是**极长**的：不能把一个连续段拆成两个。
- `n <= 20` → 没有性能压力，真正在考的是边界：空数组、单元素段、整型极值。

**推导链。**
1. 暴力：每个数先单独成一段，再不断合并「首尾相接」的段 → 要多轮扫描。
2. 浪费：一段会不会继续，只取决于「下一个数是否等于当前数加一」，一次判断就够。
3. 关键：`i` 记段首，`j` 向右走到不再满足 `nums[j + 1] == nums[j] + 1`，`[i, j]` 就是一个极长段。
4. 输出后令 `i = j + 1`，不回头 → 每个下标只访问一次，`O(n)`。

**同模式的题**：LC 163 缺失的区间、LC 56 合并区间、LC 352 将数据流变为不相交区间、LC 128 最长连续序列。
