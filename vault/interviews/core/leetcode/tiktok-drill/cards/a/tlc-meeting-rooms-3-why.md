## Q
**LC 252 会议室**｜正确性

为什么排序之后只检查相邻两个会议就够了？比较条件为什么是 `prev_end <= cur_start` 而不是 `<`？不排序直接检查相邻会出什么错？

## A
**不变量。** 排序后起点非降。若所有相邻对都不重叠，则对任意 `i < j`，有 `end_i <= start_{i+1} <= start_j`（第一步来自相邻不重叠，第二步来自起点排序），所以第 `i` 个与第 `j` 个也不重叠。反过来，只要存在任何重叠对，就必然存在相邻重叠对（`start_{i+1} <= start_j < end_i`）。

**为什么是 `<=`。** 题目规定「在 `t` 结束」和「在 `t` 开始」不重叠，等价于区间是半开的 `[start, end)`。所以 `end == start` 允许。

**反例一：不排序。** `[[7,10],[2,4]]`，正确答案 `True`（两段时间不相交）。
- 不排序直接检查相邻：`10 <= 2` 不成立，返回 `False`，错误。
- 排序成 `[[2,4],[7,10]]` 后：`4 <= 7`，返回 `True`，正确。

**反例二：写成 `<`。** `[[1,2],[2,3]]`，正确答案 `True`。写成 `prev_end < cur_start` 时 `2 < 2` 不成立，返回 `False`，错误。

**反例三：只看起点。** 以为「起点不同就不重叠」：`[[0,30],[5,10]]` 起点不同但 `[5,10]` 完全在 `[0,30]` 里面，答案是 `False`。
