## Q
**LC 287 寻找重复数**｜Medium · 字节高频

数组 `nums` 包含 `n + 1` 个整数，每个数都在 `[1, n]` 内，只有一个整数出现两次或多次，其余只出现一次。找出这个重复的数，要求**不修改**数组、只用 `O(1)` 额外空间。`1 <= n <= 10^5`，`nums.length == n + 1`，`1 <= nums[i] <= n`。例：`[1,3,4,2,2]` → `2`；`[3,3,3,3,3]` → `3`。进阶：证明至少存在一个重复数，并且 `O(n)` 完成。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`n + 1` 个数，取值 `[1, n]`」→ 鸽巢原理保证有重复；同时每个值都是合法下标 → 可以把数组看成**函数图 / 链表**：`i → nums[i]`。
- 「不能修改、`O(1)` 空间」→ 排除排序、哈希集合、原地标记；剩下 **Floyd 快慢指针**（`O(n)`）和**按值二分计数**（`O(n log n)`）。
- 「重复数」= 链表里有两个下标指向同一个值 = **环的入口**，和 LC 142（环形链表 II）完全同构。
- `n <= 10^5`：`O(n^2)` 不行，`O(n log n)` 可以。

**推导链。**
1. 暴力：两层循环比较，`O(n^2)`；哈希集合 `O(n)` 空间；排序改了输入。
2. 二分答案值：数 `<= mid` 的元素个数，超过 `mid` 说明 `[1, mid]` 内有重复，`O(n log n)`、`O(1)`。
3. 洞察：从下标 `0` 出发反复 `x = nums[x]`，因为值在 `[1, n]`，永远不会越界，也永远不会回到 `0`；`n + 1` 个下标映射到 `n` 个值，必有环，环入口有两条入边，入口的值就是重复数。
4. Floyd：慢一步、快两步，在环内相遇；再从 `0` 与相遇点同速前进，相遇处是入口。`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 142 环形链表 II、LC 141 环形链表、LC 442 数组中重复的数据、LC 448 找到所有数组中消失的数字。
