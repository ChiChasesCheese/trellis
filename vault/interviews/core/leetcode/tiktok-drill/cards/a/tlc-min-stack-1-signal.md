## Q
**LC 155 最小栈**｜Easy · 字节 高频

设计 `MinStack`：`push(val)`、`pop()`、`top()` 和 `getMin()`，要求这四个操作都在常数时间内完成，其中 `getMin()` 返回栈中最小元素。

约束：`-2^31 <= val <= 2^31 - 1`；`pop`、`top`、`getMin` 总在非空栈上调用；最多 `3 * 10^4` 次调用。例：`push(-2)`、`push(0)`、`push(-3)`，`getMin()` → `-3`，`pop()`，`top()` → `0`，`getMin()` → `-2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「常数时间取最小」→ 不能临时扫描，只能提前维护；最小值要作为数据的一部分存下来。
- 「栈」→ 状态只在栈顶变化，`pop` 会回到更早的状态 → 存"每个时刻的快照"，弹出时自动恢复。
- 「设计类」题 → 先写出 `__init__` 的成员，再逐个方法说明复杂度，面试官会逐个追问。
- 调用次数 `3 * 10^4` 很小 → 暴力 `O(n)` 的 `getMin` 也能过，但题目要求常数时间，要给最优解。

**推导链。**
1. 暴力：`getMin` 遍历整个栈，`O(n)`。
2. 浪费：栈中某个位置之下的元素不再改变，"该位置及以下的最小值"也不再改变，却被每次重新算。
3. 洞察：入栈时算一次"压入后的最小值"，和元素绑成二元组（或放进并行的辅助栈）。
4. 最优：所有操作 `O(1)`，空间多一个整数；进一步可以只存差值，把额外空间降到 `O(1)`。

**同模式的题**：LC 716 最大栈、LC 232 用栈实现队列、LC 225 用队列实现栈、LC 239 滑动窗口最大值。
