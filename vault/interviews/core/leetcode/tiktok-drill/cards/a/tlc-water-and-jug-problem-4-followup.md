## Q
**LC 365 水壶问题**｜追问

面试官接着问：（1）如果想不起数学结论，怎么证明或搜索？（2）要输出具体的倒水步骤？（3）要求量出的水必须全部在**某一个**壶里，而不是两个壶合计？

## A
1. **搜索**：把 `(a, b)` 当节点，6 种操作当边，BFS 或 DFS 加集合去重，可达状态只有约 `2(x + y)` 个：`x = 1000, y = 999` 时是 `3998` 个，瞬间完成。用数学结论是把 `O(x + y)` 降到 `O(log)`，并且不用写 6 种操作。
2. **输出步骤**：BFS 时在字典 `parent[state] = (上一状态, 操作名)` 里记录来源，到达目标后沿 `parent` 回溯。BFS 保证步骤数最少。
3. **必须在单个壶里**：目标必须是 `a` 或 `b` 本身。此时条件变成 `target <= max(x, y) and target % gcd(x, y) == 0`——单壶装不下超过自己容量的水。例如 `(3, 5, 8)` 总量能凑出 `8` 但没有哪个壶装得下，答案是 `False`。

**Python 提醒**：`math.gcd(a, b)` 对负数返回非负值，`gcd(0, 0)` 返回 `0`，若输入可能为 `0` 要先特判，否则 `target % 0` 会抛 `ZeroDivisionError`。
