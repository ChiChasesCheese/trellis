## Q
**LC 143 重排链表**｜正确性

重排链表的三步里，为什么必须在中点处**断开**，才能放心翻转后半段？为什么前半段的节点数要不少于后半段？如果漏掉断开会怎样？

## A
**不变量。** 三个阶段之间靠两个事实衔接：
1. 断开之后，`head` 开头只含前半段，`second` 开头只含后半段，两条链表互不相交；翻转只改后半段节点的 `next`，不会影响前半段。
2. 拼接时，每一轮从前半段取 `first`、从后半段取 `second`，让 `first → second → first 的原后继`。后半段是倒序的，所以依次取到的是 `Ln, Ln-1, …`，恰好是目标顺序里夹在 `L0, L1, …` 之间的节点。

**为什么前半段不能比后半段短。** 目标序列以 `L0` 开头，奇数长度时以中间节点结尾。让前半段多一个，拼接循环以后半段走完为止，前半段最后多出来的那个节点本来就是 `first`，已接在末尾，不需要处理。如果后半段更长，会有后半段节点没人接。

**反例：漏掉断开。** `[1,2,3,4]`：中点是节点 `2`，如果不执行 `slow.next = None`，节点 `2` 的 `next` 仍指向 `3`。翻转后半段得到 `4 → 3`，且 `3.next = None`，但 `2.next` 还是 `3`。拼接：
- `1.next = 4`，`4.next = 2`；
- `2.next = 3`，`3.next = 3`（`first.next` 取到的 `nxt1` 就是 `3` 自己）。

节点 `3` 指向自己，遍历永远不会结束，前 8 个值是 `[1, 4, 2, 3, 3, 3, 3, 3]`。正确输出 `[1, 4, 2, 3]`。
