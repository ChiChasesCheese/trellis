## Q
**LC 4 寻找两个正序数组的中位数**｜Hard · 字节 高频

给两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`，找出并返回这两个数组合并后的**中位数**，时间复杂度应为 `O(log(m + n))`。`0 <= m, n <= 1000`，`1 <= m + n <= 2000`，`-10^6 <= nums1[i], nums2[i] <= 10^6`。例：`nums1 = [1,3]`，`nums2 = [2]` → `2.0`；`nums1 = [1,2]`，`nums2 = [3,4]` → `2.5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「正序数组」+「`O(log)`」→ **二分查找**。但二分的不是某个值，而是**切割点**：两个数组各切一刀，切出左右两半。
- 「中位数」→ 等价于「把全部元素分成左右相等（奇数时左多一个）的两半」，中位数由左半最大值和右半最小值决定。
- 左半元素个数固定 `half = (m + n + 1) // 2`，所以 `a` 取 `i` 个，`b` 就取 `j = half - i` 个，只有一个自由度 → 对 `i` 二分，并且在**较短**的数组上二分。
- `m + n <= 2000`：线性合并其实也能过，但题目明确要求对数级，这才是真正的考点。

**推导链。**
1. 暴力：合并两个数组取中间，`O(m + n)`；用双指针只走到中间，`O(1)` 空间，仍是线性。
2. 条件：切法合法等价于四个边界满足 `a_left <= b_right` 且 `b_left <= a_right`（每个数组内部本来有序）。
3. 单调性：`i` 变大 → `a_left` 变大且 `b_right` 变小（`j` 减小）。`a_left > b_right` 说明 `i` 太大，`b_left > a_right` 说明 `i` 太小。
4. 最优：在较短的数组上二分 `i`，用 `-inf` / `inf` 作哨兵处理切在两端的情形，`O(log min(m, n))`。

**同模式的题**：LC 295 数据流的中位数、LC 378 有序矩阵中第 K 小的元素、LC 410 分割数组的最大值、LC 33 搜索旋转排序数组。
