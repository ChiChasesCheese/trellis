## Q
**LCP 09 最小跳跃次数**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-01-29（CodeTop）

一排 `N` 个弹簧，编号 `0` 到 `N-1`，小球开始在 `0` 号。在 `i` 号按一次弹簧，小球可以**向右**弹到 `i + jump[i]`（`>= N` 表示弹出机器），或者**向左**弹到 `0..i-1` 中**任意**一个弹簧（在 `0` 号时不能向左）。求把小球弹出机器（向右越过 `N-1`）最少要按几次。`1 <= jump.length <= 10^6`，`1 <= jump[i] <= 10000`。例：`[2,5,1,1,1,1]` → `3`（`0 → 2 → 1 → 出界`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最少**按几次」+ 每次代价都是 1 → 无权图最短路 → **按层 BFS**。
- 「向左到**任意**位置」→ 一个点有 `O(i)` 条边，总边数 `O(n^2)`；而这些边恰好覆盖**前缀** `0..i-1` → 用单调指针只扫一次。
- 向左跳会回到小下标 → 有回边，从左到右的 DP 没有合法顺序，排除 DP。
- `n <= 10^6` → 必须 `O(n)` 或 `O(n log n)`，`O(n^2)` 不行。

**推导链。**
1. 直接 BFS：每个点枚举 `0..i-1` 和 `i + jump[i]`，`O(n^2)`。
2. 浪费：前缀 `0..i-1` 被不同的 `i` 反复扫描，而第一次扫到时给出的层数已经是最小的。
3. 关键：维护 `lo`，`0..lo-1` 都已入队；之后只扫 `lo..i-1`，`lo` 只增不减。
4. 最优：每个下标入队一次，`lo` 总共走 `n` 步，`O(n)`。

**同模式的题**：LC 1345 跳跃游戏 IV、LC 1871 跳跃游戏 VII、LC 2612 最少翻转操作数。
