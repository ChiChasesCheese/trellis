## Q
**LC 188 买卖股票的最佳时机 IV**｜正确性

最多 `k` 笔交易的股票问题，用 `buy[i][j]`、`sell[i][j]` 两张表填，`buy[i][j]` 由 `sell[i-1][j-1]` 转移。为什么这两张表足够，为什么 `k >= n // 2` 可以直接累加价差？第 0 行的 `buy` 写 `0`、`buy[i][j]` 由 `sell[i-1][j]` 转移，各会错成什么样？

## A
**不变量。** 填完第 `i` 行后：`sell[i][j]` 是前 `i` 天内最多完成 `j` 笔交易、手上没货的最大收益；`buy[i][j]` 是前 `i` 天内已经买入 `j` 笔、第 `j` 笔还没卖的最大收益。第 `i` 天的价格 `p` 只能：保持不动，或者在持有时卖出（`sell[i][j] = buy[i-1][j] + p`），或者在没货时买入（`buy[i][j] = sell[i-1][j-1] - p`，上一笔已完成才能开始第 `j` 笔）。所以两张表的更新完整覆盖了所有选择。

**为什么 `k >= n // 2` 可以直接累加。** 一笔交易至少占用两天，`n` 天最多完成 `n // 2` 笔；`k` 不小于它时限制不起作用。不限次数时最优策略是抓住每一段上涨，等价于累加所有正的相邻价差。

**反例一：第 0 行的 `buy` 是 `0`。** 相当于还没开盘就免费拿到一只股票，`k = 2`、`prices = [3,2,6,5,0,3]` 得到 `9`，真实最大利润是 `7`（两笔：`2 → 6` 赚 `4`，`0 → 3` 赚 `3`）。

**反例二：`buy[i][j]` 由 `sell[i-1][j]` 转移。** `sell[i-1][j]` 已经可能包含了第 `j` 笔，再从它出发买入，不增加笔数，次数限制失效，等价于不限次数：`k = 1`、`prices = [3,2,6,5,0,3]` 得到 `7`，正确是 `4`。

**反例三：答案取 `buy[n][k]`。** `buy` 是持有股票的状态，还没有卖出，不算已实现的利润，并且值可能是负数；答案必须取 `sell[n][k]`。
