## Q
**LC 41 缺失的第一个正数**｜Hard · 字节 高频

给一个未排序的整数数组 `nums`，找出其中没有出现的最小的正整数。要求时间复杂度 `O(n)`，并且只使用常数级别的额外空间。`1 <= nums.length <= 10^5`，`-2^31 <= nums[i] <= 2^31 - 1`。例：`nums = [3,4,-1,1]` → `2`；`nums = [7,8,9,11,12]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`O(n)` 时间 + `O(1)` 空间」→ 排序（`O(n log n)`）和哈希集合（`O(n)` 空间）都被排除 → **原地哈希**：把数组自身当哈希表，下标是键。
- 「最小的缺失**正**整数」→ 答案范围可以先缩小：长度为 `n` 的数组最多放下 `1..n`，所以答案在 `[1, n+1]`。
- 值域 `[-2^31, 2^31-1]` 很大，但绝大多数值（非正、`> n`、重复）对答案没用，可以直接忽略。
- 这类「数组里值与下标有对应关系」的题，常用**循环排序**：让每个数回到自己的位置。

**推导链。**
1. 暴力：对 `k = 1, 2, …` 在数组里线性查找，`O(n^2)`。
2. 用集合：`O(n)` 时间，`O(n)` 空间；排序：`O(n log n)`。都不满足要求。
3. 洞察：只需关心 `[1, n]` 内的数，数组恰好有 `n` 个格子。数 `x` 的「家」是下标 `x - 1`，把每个数送回家。
4. 最优：送完后扫一遍，第一个 `nums[i] != i + 1` 的 `i + 1` 就是答案，全对则 `n + 1`。每次交换让一个数永久归位，总交换不超过 `n`，`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 268 丢失的数字、LC 448 找到所有数组中消失的数字、LC 442 数组中重复的数据、LC 287 寻找重复数。
