## Q
**LC 2673 使二叉树所有路径值相等的最小代价**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-07-15（面试记录）

满二叉树有 `n` 个节点，编号 `1` 到 `n`，根是 `1`，非叶子节点 `i` 的孩子是 `2 * i` 和 `2 * i + 1`；`cost[i]` 是节点 `i + 1` 的值。每次操作可以把任意节点的值加 `1`，次数不限。让根到每个叶子的路径值（路径上节点值之和）都相等，求最少的操作次数。`3 <= n <= 10^5`，`n + 1` 是 `2` 的幂，`1 <= cost[i] <= 10^4`。例：`n = 7`，`cost = [1,5,2,2,3,3,1]` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「满二叉树，孩子是 `2i`、`2i+1`」→ 堆式下标，直接对数组操作，不用建树；最后一个非叶子节点是 `n // 2`。
- 「只能加、让所有根到叶路径相等」→ 自底向上的树形贪心：一个子树内的操作只影响这个子树的叶子。
- 「任意节点加 `1`」→ 补在兄弟子树的根上，一次操作能同时抬高其下所有叶子，比补在叶子上省。
- `n <= 10^5`：线性扫一遍数组即可。

**推导链。**
1. 暴力：选目标路径值，每个叶子补差额，没有利用共享祖先；`[1,5,2,2,3,3,1]` 补到 `9` 要 `9` 次，最优是 `6`。
2. 浪费：祖先上的一次加法可以同时抬高多个叶子，补在叶子上完全没用上。
3. 洞察：从最深的非叶子节点往上，两个孩子子树的“最大路径值”之差 `|L - R|` 是必须补的次数，补在较小一侧的根上；拉齐后整个子树的路径值都是 `自身 + max(L, R)`。
4. 最优：倒序遍历 `n // 2` 到 `1`，累加差值并把 `max` 传给自己，`O(n)`。
