## Q
**LC 704 二分查找**｜Easy · 字节高频

给升序整型数组 `nums`（元素互不相同）和目标值 `target`，若 `target` 在 `nums` 中返回下标，否则返回 `-1`，要求 `O(log n)` 时间。`1 <= n <= 10^4`，`-9999 <= nums[i] <= 9999`。例：`nums = [-1,0,3,5,9,12]`、`target = 9` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「升序 / 有序数组」+「查找」→ **二分查找**（binary search）。
- 「必须 `O(log n)`」→ 直接排除线性扫描；每步要排除一半候选。
- 能二分的根本原因是**单调性**：`nums[mid] < target` 蕴含 `mid` 及其左边全都小于 `target`，可以一次丢掉。
- `n <= 10^4`：线性也能过，但题目就是考二分的写法，关键是边界。

**推导链。**
1. 暴力：从头扫到尾，`O(n)`。
2. 浪费：数组已经有序，每次比较只用了一个元素的信息。
3. 洞察：和中点比较一次，就能排除一半：中点太小排除左半，否则保留左半（含中点）。
4. 为了不出边界错误，固定使用「左闭右开 `[lo, hi)`、`while lo < hi`、`lo = mid + 1` / `hi = mid`」这一套，退出时 `lo` 是第一个 `>= target` 的位置，最后检查是否等于 `target`。
