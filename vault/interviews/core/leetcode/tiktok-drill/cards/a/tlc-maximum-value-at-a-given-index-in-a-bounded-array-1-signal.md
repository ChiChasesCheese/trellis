## Q
**LC 1802 有界数组中指定下标处的最大值**｜Medium · LC TikTok 热度 62/100

给正整数 `n`、`index`、`maxSum`。构造长为 `n` 的正整数数组 `nums`，相邻元素之差的绝对值不超过 `1`，所有元素之和不超过 `maxSum`，并使 `nums[index]` 最大，返回这个最大值。`1 <= n <= maxSum <= 10^9`，`0 <= index < n`。例：`n = 6, index = 1, maxSum = 10` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最大化某个值，同时受总和上限约束」→ **二分答案**：峰值 `v` 可行 ⇒ 更小的也可行（单调）。
- `n, maxSum` 到 `10^9` → 不能建数组、不能线性枚举，需要 `O(1)` 的公式求和 + `O(log)` 的二分。
- 「相邻差不超过 `1`、元素为正」→ 给定峰值时，每个位置的最小值是 `max(v - 距离, 1)`：离峰越远越低，但至少为 `1`。
- 构造是**贪心**的：想让峰最高，别的位置越小越好；最小和是峰值的单调函数。
- 一侧求和有两种形态（降到 `1` 之前 / 之后补 `1`）→ 分段的等差数列。

**推导链。**
1. 暴力：从 `1` 开始逐个试峰值，每次建数组求和，`O(maxSum · n)`。
2. 浪费：可行性单调，不必全试；也不必建数组。
3. 洞察：峰值 `v` 的最小和 = `v` + 左侧最小和 + 右侧最小和，每侧是等差数列（可能带一段 `1`）。
4. 最优：二分 `v`，每次 `O(1)` 算最小和，约 `30` 次迭代。
