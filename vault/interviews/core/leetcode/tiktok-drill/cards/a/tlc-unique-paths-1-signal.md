## Q
**LC 62 不同路径**｜Medium · TikTok·字节 高频

机器人位于 `m x n` 网格的左上角，每次只能向下或向右移动一步，要到达右下角。问有多少条不同的路径。

约束：`1 <= m, n <= 100`，答案保证不超过 `2 * 10^9`。例：`m = 3, n = 7` → `28`；`m = 3, n = 2` → `3`；`m = 3, n = 3` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「只能向右 / 向下」→ 每个格子只能从上方或左方到达，没有环，计算顺序固定：网格 DP。
- 「数有多少条」→ 计数 DP，转移是相加：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
- 起点终点固定 → 每条路径恰好 `m - 1` 次下、`n - 1` 次右，只是顺序不同 → 组合数 `C(m + n - 2, m - 1)`。
- 答案可达 `2 * 10^9` → 不能一条条枚举；`m, n <= 100` → `O(mn)` 的 DP 很轻松。

**推导链。**
1. 暴力：DFS 每格分两个方向，路径数就是答案，指数级。
2. 浪费：到达同一格的不同路径，后面的走法完全相同，只需要记个数。
3. 洞察：第一行、第一列各只有 `1` 条路；其余格子 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`；或者直接数排列。
4. 最优：DP 填满 `m × n` 的表，`O(mn)` 时间和空间，答案是 `dp[m-1][n-1]`；或 `comb(m + n - 2, m - 1)`。

**同模式的题**：LC 63 不同路径 II、LC 64 最小路径和、LC 120 三角形最小路径和、LC 980 不同路径 III。
