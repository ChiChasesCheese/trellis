## Q
**LC 746 使用最小花费爬楼梯**｜Easy · TikTok 高频

整数数组 `cost`，`cost[i]` 是从第 `i` 级台阶向上爬需要支付的费用，支付后可以向上爬一级或两级。可以从下标 `0` 或 `1` 出发，求到达楼梯顶部（下标 `cost.length`）的最低花费。`2 <= cost.length <= 1000`，`0 <= cost[i] <= 999`。例：`[10,15,20]` → `15`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每次走一级或两级」+「最小总花费」→ **线性 DP**（爬楼梯型）：当前状态只由前两个状态转移。
- 「可以从 `0` 或 `1` 出发」→ 两个起点的初始花费都是 `0`。
- 「到达顶部」是下标 `n`，不是最后一级 `n - 1`。
- `n <= 1000` → `O(n)` 的 DP 绰绰有余；只依赖前两项，空间可以压到 `O(1)`。

**推导链。**
1. 暴力：`f(i) = cost[i] + min(f(i+1), f(i+2))` 递归，`f(i)` 被重复求解，指数级。
2. 浪费：同一个下标的最优值每次都一样，只需要算一次。
3. 关键：定义 `dp[i]` = 到达第 `i` 级的最小花费，则 `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`，`dp[0] = dp[1] = 0`。
4. 答案是 `dp[n]`；每个 `dp[i]` 只读前两项，用两个滚动变量即可。
