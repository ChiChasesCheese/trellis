## Q
**LC 781 森林中的兔子**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-06-05（CodeTop）

森林里有未知数量的兔子，问了其中一部分「还有多少只其它兔子和你颜色相同？」，回答放进 `answers`（`1 <= n <= 1000`，`0 <= answers[i] < 1000`）。返回森林中兔子的最少数量。例：`[1,1,2]` → `5`，`[10,10,10]` → `11`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最少数量」+「每个回答给出所在颜色组的大小」→ 贪心装箱（packing）：回答 `x` 的兔子，所在颜色组的总大小是 `x + 1`，同回答的兔子尽量塞进同一组。
- 「颜色」没有给出，只给「同色的其他兔子数」→ 颜色是隐变量，不需要真的分配，只需要统计每个回答值的人数。
- `n <= 1000`、回答 `< 1000` → 哈希计数 `Counter` 一遍即可，没有性能压力。
- 求 `ceil(count / (x + 1))` → 经典的"每箱容量固定、求最少箱数"。

**推导链。**
1. 暴力：把回答的兔子划分成颜色组（同组回答必须相同，组大小不超过 `x + 1`），取总代价最小的划分，指数级。
2. 浪费：回答值不同的兔子不可能同色，所以每个回答值互相独立。
3. 洞察：回答 `x` 的 `count` 只兔子，每个颜色组最多装 `x + 1` 只，最少 `ceil(count / (x + 1))` 组；每组不管被问到几只，森林里这种颜色的兔子就是 `x + 1` 只。
4. 最优：`Counter` 计数，按公式累加 `组数 * (x + 1)`，`O(n)`。

**同模式的题**：LC 455 分发饼干、LC 135 分发糖果、LC 621 任务调度器、LC 1029 两地调度。
