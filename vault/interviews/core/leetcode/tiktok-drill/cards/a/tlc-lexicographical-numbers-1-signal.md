## Q
**LC 386 字典序排数**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-05-10（CodeTop）

给整数 `n`，按字典序返回 `[1, n]` 内的所有整数；必须设计时间 `O(n)`、额外空间 `O(1)` 的算法。`1 <= n <= 5 * 10^4`。例：`n = 13` → `[1,10,11,12,13,2,3,4,5,6,7,8,9]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按**字典序**输出数字」→ 数字的十进制前缀构成一棵**十叉树**（trie），字典序就是这棵树的**先序遍历**。
- 「`O(1)` 额外空间」→ 不能 `sorted(key=str)`（`O(n log n)`、还要造字符串），也不能把递归栈算作免费 → 用一个变量做**迭代式先序**。
- `n <= 5 * 10^4` → 数字最多 5 位，树很浅但很宽；`O(n)` 是硬要求，每个数只能生成一次。

**推导链。**
1. 暴力：`sorted(range(1, n + 1), key=str)`，`O(n log n)` 时间、`O(n)` 额外空间，不满足要求。
2. 换个视角：以 `x` 为根的子树是 `x`、`10x…10x+9`、…，先序遍历就是字典序；递归 DFS 可行，但栈不是严格的 `O(1)`。
3. 洞见：先序里「下一个数」只有三种：`cur * 10`（下沉）、`cur + 1`（右移）、先回退到父亲再 `+1`（回溯）；判断条件只用 `cur * 10 <= n`、`cur % 10 == 9`、`cur + 1 > n`。
4. 最优：一个变量 `cur` 加三种动作，循环 `n` 次，`O(n)` 时间、`O(1)` 额外空间。

**同模式的题**：LC 440 字典序的第 K 小数字、LC 60 排列序列、LC 78 子集、LC 17 电话号码的字母组合。
