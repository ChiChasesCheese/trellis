## Q
**LC 1041 困于环中的机器人**｜Medium · TikTok 高频

无限平面上，机器人从 `(0, 0)` 出发，面朝北（北 = `y` 轴正方向，东 = `x` 轴正方向）。它按顺序执行指令串 `instructions` 并**无限循环**重复它。指令只有三种：`"G"` 直走 1 单位，`"L"` 左转 90 度，`"R"` 右转 90 度。当且仅当平面中存在一个机器人永远离不开的环时返回 `true`，否则 `false`。

约束：`1 <= instructions.length <= 100`，`instructions[i]` 仅为 `'G'`、`'L'`、`'R'`。

例：`"GGLLGG"` → `true`；`"GG"` → `false`（一直往北）；`"GL"` → `true`（绕一个小方块）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按指令**无限重复**」→ 不要真的无限模拟，找**周期**：状态（位置 + 朝向）里朝向只有 4 种，最多 4 轮朝向就回到起点。
- 「方向」+「转 90 度」→ 用方向向量 `(dx, dy)` 旋转，或者用长度 4 的方向表加下标取模。
- 「是否永远离不开」→ 转成有限判断：一轮后的净变化（旋转 + 平移）是什么？`n ≤ 100` 说明考点是结论，不是性能。

**推导链。**
1. 暴力：模拟指令重复很多轮，看是否远离原点；但「很多」是多少没有依据。
2. 观察：一轮 = 先旋转 `θ`（90 度的倍数）再平移 `v`。`θ` 只可能是 0、90、180、270 度。
3. 洞察：`θ = 0`：每轮平移同一个 `v`，`v ≠ 0` 才会逃走；`θ ≠ 0`：位移被旋转，至多 4 轮后合成为 `0`，必回原点 → 有界。
4. 最优：模拟一轮，返回「回到原点」或「不再朝北」，`O(n)` 时间 `O(1)` 空间。

**同模式的题**：LC 657 机器人能否返回原点、LC 874 模拟行走机器人、LC 2069 模拟行走机器人 II、LC 1496 判断路径是否相交。
