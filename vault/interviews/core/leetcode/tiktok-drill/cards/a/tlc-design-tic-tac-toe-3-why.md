## Q
**LC 348 设计井字棋**｜正确性

井字棋判定器给每行、每列、两条对角线各存一个计数，玩家 1 加 `1`、玩家 2 减 `1`，计数绝对值等于 `n` 就判获胜。为什么这能准确表示「整条线全是同一个玩家」？两个玩家都加 `1`、副对角线条件写错、中心格漏加，各会错成什么样？

## A
**不变量。** 每条线的计数等于「这条线上玩家 1 的棋子数」减去「玩家 2 的棋子数」。一条线共 `n` 个格子，计数的绝对值最大就是 `n`，当且仅当 `n` 个格子全由同一个玩家占据时取到（只要有一个对手的子，绝对值至多 `n - 2`）；格子只会被填入、不会被覆盖，所以计数的变化只来自刚落下的这一子，落子后只需检查它所在的线。

**反例一：两个玩家都加 `1`。** `n = 3`，依次 `move(0,0,1)`、`move(0,1,2)`、`move(0,2,1)`：第 0 行是 `X O X`，没有人获胜；两人都加 `1` 时第 0 行的计数是 `3`，第三步错误返回 `1`，正确是 `0`。符号相反时计数是 `+1 - 1 + 1 = 1`。

**反例二：副对角线条件写成 `row == n - col`。** `n = 3`，玩家 2 占 `(0,2)`、`(1,1)`、`(2,0)`：`0 == 3 - 2`、`1 == 3 - 1`、`2 == 3 - 0` 全部不成立，副对角线计数始终是 `0`，返回 `0`，正确是 `2`；条件应是 `row + col == n - 1`。

**反例三：中心格漏加一条对角线。** `n = 3`，把副对角线写成 `elif`，中心格 `(1,1)` 只加到主对角线。玩家 1 占 `(0,2)`、`(1,1)`、`(2,0)`，副对角线计数只有 `2`，返回 `0`，正确是 `1`。
