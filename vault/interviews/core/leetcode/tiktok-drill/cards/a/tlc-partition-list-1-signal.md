## Q
**LC 86 分隔链表**｜Medium · CodeTop 国内累计 8 次 · 最近 2025-12-21（CodeTop）

给链表 `head` 和整数 `x`，把所有值小于 `x` 的节点放到值大于等于 `x` 的节点之前，且每个分区内保持原来的相对顺序。节点数 `0 ~ 200`，`-100 <= Node.val <= 100`，`-200 <= x <= 200`。例：`[1,4,3,2,5,2]`，`x = 3` → `[1,2,2,4,3,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按条件把节点分成两组，**每组保持原相对位置**」→ 稳定划分（stable partition），链表上用**双链**，各自按顺序追加。
- 操作的对象是**链表**，要改指针而不是值 → 用**哑结点**（dummy node）统一头结点的处理，用尾指针 `O(1)` 追加。
- 节点数 `<= 200` → 复杂度不是难点，考点是指针操作与收尾（断环）。

**推导链。**
1. 暴力：值抄进数组，划分后重建链表，`O(n)` 额外空间。
2. 浪费：链表可以只改 `next` 指针重排，不需要拷贝值。
3. 洞察：稳定划分 = 两个队列；每个队列只需要一个尾指针；哑结点让头结点和普通结点一视同仁。
4. 最优：遍历一遍把节点挂到小链或大链尾部，**断开大链尾巴**，小链尾接大链头 → `O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 328 奇偶链表、LC 725 分隔链表、LC 21 合并两个有序链表、LC 75 颜色分类。
