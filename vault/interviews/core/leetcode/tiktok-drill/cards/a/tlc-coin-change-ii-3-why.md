## Q
**LC 518 零钱兑换 II**｜正确性

为什么用「前 `i` 种硬币」做行、金额做列，数出来的是组合，而先固定金额、再枚举最后一枚硬币数出来的是排列？转移读同一行和读上一行各代表什么？给出具体输入和输出。

## A
**不变量。** 第 `i` 行填完后，`dp[i][a]` 等于**只使用前 `i` 种硬币**凑出 `a` 的组合数。`dp[i][a - coin]` 在同一行里已经包含「用了若干个第 `i` 种」的方案，所以 `dp[i-1][a] + dp[i][a - coin]` 恰好是「一枚都不用」加上「至少用一枚」。

**为什么是组合。** 每个组合有唯一的"规范顺序"：按硬币在 `coins` 中的先后排列。行号按硬币顺序增加，一个组合只会在每种硬币上被"决定一次用几个"，所以每个组合只被数一次。

**反例 1：先固定金额、再枚举最后一枚硬币。** 这时没有「用到第几种硬币」这一维，每个金额 `a` 可以以任意一种硬币作为**最后一枚**，不同的出现顺序被分别数到：`amount = 3`、`coins = [1,2]`：
- 数出 `1+1+1`、`1+2`、`2+1`，共 `3`。
- 正确的组合数是 `2`（`1+2` 与 `2+1` 是同一组合）。

**反例 2：转移读上一行 `dp[i-1][a - coin]`。** 剩下的金额只能用前 `i - 1` 种硬币，第 `i` 种至多用一枚，变成 0/1 背包：
- `amount = 5`、`coins = [1,2,5]`：每种硬币至多一枚，和为 `5` 的子集只有 `{5}`（`1+2=3`，`1+2+5=8`），输出 `1`。
- 正确是 `4`。

**反例 3：漏掉 `if a >= coin`。** `a - coin` 为负时 Python 不报错，而是从行尾读数：`(1, [3])` 读到 `dp[1][-2]`，即 `dp[1][0] = 1`，得到 `1`，正确是 `0`。

**反例 4：第 0 列没有置 `1`。** 只写 `dp[0][0] = 1`，则 `dp[i][0] = 0`，所有方案最终都是从第 0 列累加来的，`(5, [1,2,5])` 和 `(0, [7])` 都输出 `0`，正确分别是 `4` 和 `1`。
