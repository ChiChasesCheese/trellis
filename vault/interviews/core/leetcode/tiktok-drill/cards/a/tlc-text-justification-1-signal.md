## Q
**LC 68 文本左右对齐**｜Hard · LC TikTok 热度 81/100（近 6 个月） · CodeTop 国内累计 8 次 · 最近 2025-07-22（CodeTop）

给单词数组 `words` 和宽度 `maxWidth`，排成每行恰好 `maxWidth` 个字符、左右对齐的文本。必须贪心：每行尽可能多放单词，用空格补齐；空格尽量均匀，不能均分时左边的空档多。最后一行以及只有一个单词的行左对齐。`1 <= words.length <= 300`，`1 <= words[i].length <= 20`，`1 <= maxWidth <= 100`，`words[i].length <= maxWidth`。例：`["What","must","be","acknowledgment","shall","be"]`，`16` → `["What   must   be","acknowledgment  ","shall be        "]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「必须用贪心」「每行尽可能多放」→ 贪心断行：从行首开始，下一个单词放得下就放。
- 「空格尽量均匀，余数给左边」→ `divmod(空格数, 空档数)`：每个空档 `q` 个，前 `r` 个多一个。
- 「最后一行、只有一个单词的行」→ 两种特殊行，没有可均分的空档，要单独处理，是这题的边界陷阱。
- `n <= 300`、`maxWidth <= 100`：规模极小，纯模拟，考的是拆解和边界，不是复杂度。

**推导链。**
1. 暴力：没有"暴力"，直接按规则逐行模拟；难点在一次写对，容易把断行和排版混在一起。
2. 浪费 / 风险：断行条件（含空格）和排版（均分）纠缠在一个循环里，边界容易乱。
3. 洞察：拆成两步——第一步只负责断行，`used` 记录单词总长加最少空格；第二步只负责把这一行排成 `maxWidth` 宽。
4. 排版：普通行用 `divmod` 均分；特殊行 `" ".join` 后 `ljust`。总复杂度与总字符数成正比。

**同模式的题**：LC 722 删除注释、LC 6 Z 字形变换、LC 43 字符串相乘、LC 1105 填充书架（断行 DP）。
