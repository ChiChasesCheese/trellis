## Q
**LC 1123 最深叶节点的最近公共祖先**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-03-31（CodeTop）

给一棵二叉树的根结点 `root`，返回它**最深的叶结点们**的最近公共祖先。叶结点是没有子结点的结点；根的深度是 `0`，深度为 `d` 的结点的子结点深度为 `d + 1`。一组结点 `S` 的最近公共祖先 `A` 满足：`S` 中每个结点都在以 `A` 为根的子树里，且 `A` 的深度在此条件下尽可能大。树中结点数在 `[1, 1000]` 范围内，`0 <= Node.val <= 1000`，每个结点的值都不相同。例：`root = [3,5,1,6,2,0,8,null,null,7,4]` → 值为 `2` 的结点（子树 `[2,7,4]`；最深的叶子是 `7` 和 `4`，深度 `3`）；`root = [1]` → `[1]`；`root = [0,1,3,null,2]` → `[2]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最深的叶结点」+「最近公共祖先」→ **树形 DP / 后序**：每个结点从两个孩子拿到「最深叶子的深度」和「它们的 LCA」，合并成自己的。
- 「一组结点的 LCA」可以通过「左右两侧是否都含目标」判断，这是 LCA 家族（LC 236）的共同套路。
- 结点数 `<= 1000` → 复杂度不是问题，但链状树深度可达 `1000`，Python 递归会触到默认上限，迭代更稳。
- 结点值互不相同 → 不影响解法，只是方便用值标识结点。

**推导链。**
1. 暴力：遍历一遍记深度，找出最深一层的所有叶子，再两两求 LCA，`O(n * h)`。
2. 浪费：深度和 LCA 分成两遍，重复走路径。
3. 洞察：`ld > rd` 沿用左边答案，`rd > ld` 沿用右边，`ld == rd` 答案就是当前结点。
4. 最优：后序一遍，`O(n)`；用 BFS 序倒过来处理，不需要递归。

**同模式的题**：LC 865 具有所有最深节点的最小子树、LC 236 二叉树的最近公共祖先、LC 1676 二叉树的最近公共祖先 IV、LC 543 二叉树的直径。
