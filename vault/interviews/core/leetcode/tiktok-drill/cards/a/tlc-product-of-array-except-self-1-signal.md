## Q
**LC 238 除了自身以外数组的乘积**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-06（面试记录）

给整数数组 `nums`，返回 `answer`，其中 `answer[i]` 是 `nums` 中除 `nums[i]` 以外所有元素的乘积。保证任意前缀、后缀的乘积都在 32 位整数范围内。**不能用除法**，要求 `O(n)` 时间。`2 <= nums.length <= 10^5`，`-30 <= nums[i] <= 30`。例：`[-1,1,0,-3,3]` → `[0,0,9,0,0]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「除自身以外的全体」+「不许除法」→ 把「全体之积 ÷ 自己」改写成**前缀积 × 后缀积**，这是前后缀分解（prefix / suffix）。
- 数组里可能有 `0` → 除法路线本来就要分类讨论（零的个数），前后缀乘法天然不受影响。
- `n = 10^5` → 暴力 `O(n^2)` 不行，要两趟线性扫描。
- 进阶要求 `O(1)` 额外空间 → 左积直接写进答案数组，右积用一个滚动变量。

**推导链。**
1. 暴力：对每个 `i` 乘遍其余元素，`O(n^2)`。
2. 浪费：`i` 与 `i + 1` 的「其余之积」只差一个因子，却各算一遍。
3. 关键：`answer[i] = L[i] * R[i]`，`L[i]` 是左边所有元素之积，`R[i]` 是右边所有元素之积；两个数组各一趟 `O(n)` 算好。
4. 优化空间：`L` 直接存进 `answer`；倒序扫描时把 `R` 用变量 `right` 滚动，乘进 `answer[i]` 后再把 `nums[i]` 乘进 `right`。
