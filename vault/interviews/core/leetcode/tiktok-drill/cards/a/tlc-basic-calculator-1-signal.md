## Q
**LC 224 基本计算器**｜Hard · TikTok·字节 高频

给字符串表达式 `s`，实现一个基本计算器计算并返回它的值。不允许使用 `eval()`。`1 <= s.length <= 3 * 10^5`，`s` 由数字、`+`、`-`、`(`、`)` 和空格组成；`s` 是有效表达式；`+` 不能用作一元运算，`-` 可以作一元运算（`"-1"`、`"-(2 + 3)"` 有效）；不存在两个连续的操作符；每个数字和运算结果都在有符号 32 位整数内。例：`"(1+(4+5+2)-3)+(6+8)"` → `23`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「括号嵌套」→ **栈**（后进先出）：内层先算完，结果交给外层。
- 只有 `+` 和 `-` → 没有优先级问题；括号唯一的作用是**翻转/保留符号**：`a - (b - c)` 等于 `a - b + c`。
- 「`-` 可以作一元运算」→ 表达式开头或 `(` 之后可能直接是 `-`，符号处理要自然地覆盖这种情况。
- `n` 到 `3×10^5` → 嵌套可深达 `1.5×10^5` 层，**递归会栈溢出**，必须用显式栈、一遍扫描。

**推导链。**
1. 暴力：递归下降——遇到 `(` 递归求值，括号内的结果乘上括号前的符号。
2. 浪费：递归深度等于括号嵌套深度，Python 默认递归上限约 1000，会 `RecursionError`。
3. 关键：递归真正保存的只有两样东西——「括号前累计的和」和「括号前的符号」。自己用栈存这一对，就不需要调用栈。
4. 进入 `(` 时压栈并把当前层重置为 `res = 0, sign = 1`；遇到 `)` 时结算括号内最后一个数，再 `res = prev_res + prev_sign * res`。`O(n)` 时间，空间只与嵌套深度有关。

**同模式的题**：LC 227 基本计算器 II（优先级）、LC 772 基本计算器 III（括号 + 优先级）、LC 394 字符串解码、LC 726 原子的数量。
