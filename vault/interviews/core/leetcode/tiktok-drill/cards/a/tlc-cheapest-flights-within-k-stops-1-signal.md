## Q
**LC 787 K 站中转内最便宜的航班**｜Medium · LC TikTok 热度 50/100（近 30 天）

`n` 个城市由航班连接，`flights[i] = [from_i, to_i, price_i]` 是一条有向、带价格的航班。给定 `src`、`dst` 和整数 `k`，求从 `src` 到 `dst` 最多经过 `k` 站中转的最便宜价格，不存在则返回 `-1`。`2 <= n <= 100`，`0 <= flights.length <= n * (n - 1) / 2`，`1 <= price_i <= 10^4`，航班无重复、无自环，`0 <= src, dst, k < n`，`src != dst`。例：`n = 4`，`flights = [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]]`，`src = 0`，`dst = 3`，`k = 1` → `700`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「最便宜」+ 图 → **最短路**；「最多 `k` 站中转」= 最多 `k + 1` 条边 → **带边数限制的最短路**，普通 Dijkstra 会忽略限制（示例 1 里不限站数得 `400`，违规）。
- 边数限制对应 **Bellman-Ford 的轮数**：把每一轮留成表的一行，`dp[t][v]` 是“至多 `t` 条边”到 `v` 的最小价格。
- `n <= 100`、边数至多 `4950` → `O(k * E)` 约 `5 * 10^5`，规模很小。
- 权重都为正，但这不是 Dijkstra 的充分理由：状态里多了“已用边数”，贪心的“先弹出的最优”不再成立。

**推导链。**
1. 暴力：深度优先枚举所有至多 `k + 1` 条边的路径，指数级。
2. 动态规划：`dp[t][v]` = 至多 `t` 条边到 `v` 的最小价格，`dp[t][v] = min(dp[t-1][v], dp[t-1][u] + w)`。
3. 填表：第 0 行只有 `dp[0][src] = 0`；第 `t` 行先复制第 `t - 1` 行，再对每条航班 `u → v` 用**上一行**的 `dp[t-1][u] + w` 更新 `dp[t][v]`，否则一行内可以连走多条边。
4. 填 `k + 1` 行（共 `k + 2` 行），答案是 `dp[k+1][dst]`，`inf` 就返回 `-1`。`O(k * E)` 时间，`O(k * n)` 空间。

**同模式的题**：LC 743 网络延迟时间、LC 1631 最小体力消耗路径、LC 1514 概率最大的路径、LC 1928 规定时间内到达终点的最小花费。
