## Q
**LC 83 删除排序链表中的重复元素**｜Easy · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 22 次 · 最近 2025-11-01（面试记录）

给升序排列的链表头节点 `head`，删除所有重复元素，使每个值只出现一次，返回仍然有序的链表。节点数在 `[0, 300]`，`-100 <= Node.val <= 100`，链表保证按升序排列。例：`[1,1,2,3,3]` → `[1,2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「已排序」→ 相同的值**必然相邻**，只需比较相邻节点，不需要哈希表。
- 「每个值只保留一次」→ 保留第一个，所以头节点永远保留，不需要哨兵节点（对比 LC 82 要整段删光）。
- 单链表只能向后走 → 原地修改 `next` 指针，一个指针 `cur` 就够。
- `n <= 300`：规模很小，考的是指针操作的细节，不是复杂度。

**推导链。**
1. 暴力：遍历时用集合记录见过的值，重复就删，`O(n)` 空间。
2. 浪费：排序已经让重复聚在一起，集合没有必要。
3. 洞察：`cur.val == cur.next.val` 就让 `cur.next = cur.next.next`；`cur` 先不动，因为新的下一个可能还是同值。
4. 只有不相同时 `cur` 才前进；每步要么删一个节点要么前进一步，`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 82 删除排序链表中的重复元素 II、LC 26 删除有序数组中的重复项、LC 80 删除有序数组中的重复项 II、LC 203 移除链表元素。
