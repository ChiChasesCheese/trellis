## Q
**螺旋矩阵（O(1) 额外空间、不改输入）**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-09-28（面试记录）

给一个 `m x n` 的整数矩阵，按顺时针螺旋顺序返回所有元素。额外空间必须是 `O(1)`（返回列表不算），不能修改输入矩阵：不能用 `visited` 数组，也不能把走过的格子改成哨兵值；要处理空矩阵、单行、单列。`0 <= m, n <= 1000`。例：`[[1,2,3],[4,5,6],[7,8,9]]` → `[1,2,3,6,9,8,7,4,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「螺旋、转圈」→ 层层剥洋葱：每圈走四条边，然后边界向里收缩。
- 「`O(1)` 额外空间 + 不能改输入」→ 排除 `visited` 数组和哨兵值；只能用几个整数变量记录状态。
- 「单行、单列、空矩阵」→ 边界相遇时上边与下边（或左边与右边）是同一条线，要加守卫避免重复；空矩阵要先判断。
- `m, n <= 1000`：`O(mn)` 时间就是下限（每个元素至少访问一次）。

**推导链。**
1. 暴力一：`visited` 矩阵加方向向量，撞墙或撞到已访问的格子就右转，`O(mn)` 额外空间。
2. 暴力二：取走第一行，把剩下的矩阵逆时针转 90 度再重复，每次重建矩阵，多余的拷贝很多。
3. 浪费：两者都在显式存「哪些格子走过了」，但已走过的格子永远在已经收掉的外圈里。
4. 洞察：四个整数 `top, bottom, left, right` 足以描述「还没走的矩形」。每圈沿这个矩形的边界走一周，再各收一格。
5. 最优：只有 `top < bottom` 才走下边，只有 `left < right` 才走左边，单行单列自然不重复。`O(mn)` 时间，`O(1)` 额外空间。

**同模式的题**：LC 54 螺旋矩阵、LC 59 螺旋矩阵 II、LC 885 螺旋矩阵 III、LC 2326 螺旋矩阵 IV。
