## Q
**LC 494 目标和**｜正确性

为什么 01 背包的容量循环必须倒序？转成子集和之前，为什么要先判断 `(sum + target)` 的奇偶和范围？给出正序遍历出错的具体输入。

## A
**不变量。** 处理第 `i` 个数之前，`dp[j]` 是只用前 `i - 1` 个数、和恰为 `j` 的子集数。倒序更新 `j` 时，`dp[j - x]` 还没被本轮改动，仍是「不含第 `i` 个数」的值，所以 `dp[j] += dp[j - x]` 恰好加上「选第 `i` 个数」的方案，每个数至多被选一次。

**为什么正序出错。** 正序时 `dp[j - x]` 已经被本轮更新过，里面包含「已经选过第 `i` 个数」的方案，等于允许同一个数选多次（完全背包）。

**反例：正序。** `nums = [1,1,1,1,1]`，`target = 3`，`need = (5 + 3) / 2 = 4`：
- 正确：从 5 个 1 里选 4 个，`C(5,4) = 5` 种。
- 正序遍历：每个 `1` 可以重复使用，计出的是「用若干次这些 1 凑出 4」的次数，结果 `70`。

**为什么要先判奇偶和范围。** `P = (S + target) / 2` 必须是非负整数，因为 `P` 是子集和。`[1,2]`，`target = 4`：`S + target = 7` 是奇数，没有整数解，正确答案 `0`；若直接写 `(3 + 4) // 2 = 3`，会数出子集 `{1,2}`，得到 `1`。`[1,1]`，`target = -3`：`(2 - 3) // 2 = -1`，建表 `[0] * 0` 后访问 `dp[0]` 越界。
