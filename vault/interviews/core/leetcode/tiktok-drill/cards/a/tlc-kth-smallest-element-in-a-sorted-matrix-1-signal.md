## Q
**LC 378 有序矩阵中第 K 小的元素**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 12 次 · 最近 2026-09-23（CodeTop）

`n × n` 矩阵，每行每列都非递减。求排序后的第 `k` 小的元素（重复值各算一个）。要求内存优于 `O(n^2)`。`1 <= n <= 300`，`-10^9 <= matrix[i][j] <= 10^9`，`1 <= k <= n^2`。例：`[[1,5,9],[10,11,13],[12,13,15]], k = 8` → `13`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「第 `k` 小」→ 两大套路：**堆**（Top-K）或**二分答案**（binary search on the answer）。
- 「行列都有序」→ 能在 `O(n)` 内数出「`<= mid` 的元素有多少」（阶梯扫描）——这是二分答案的计数函数。
- 值域是整数、范围 `[-10^9, 10^9]` → 对**值**二分只要约 `31` 轮。
- 「内存优于 `O(n^2)`」→ 不能展开排序；进阶「`O(1)` 内存」→ 二分答案。

**推导链。**
1. 暴力：展开全部元素排序，`O(n^2)` 内存，违反要求。
2. 堆：每行是一条有序链，用小根堆做 `n` 路归并，弹 `k` 次，`O(k log n)` 时间、`O(n)` 内存。
3. 洞察：设 `f(v)` = 矩阵中 `<= v` 的个数。第 `k` 小的值就是最小的 `v` 满足 `f(v) >= k`，而 `f` 对 `v` 单调不减，可以二分。
4. 最优：二分 `v`；计数用阶梯：每行的「小于等于 `v` 的列边界」随行号增大只会左移，一次扫描 `O(n)`。总计 `O(n log V)`，`O(1)` 空间。

**同模式的题**：LC 668 乘法表中第 k 小的数、LC 719 找出第 K 小的数对距离、LC 373 查找和最小的 K 对数字、LC 786 第 K 个最小的素数分数。
