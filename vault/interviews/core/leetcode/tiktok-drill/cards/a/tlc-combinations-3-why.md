## Q
**LC 77 组合**｜正确性

剪枝上界 `n - need + 1` 是怎么来的？为什么递归必须是 `dfs(x + 1)`？各给出写错时的错误输出。

## A
**不变量。** 每个递归节点的 `path` 是一个严格递增的前缀，`start` 是下一个允许选的最小数。每个组合（按升序写）恰好被某条根到叶的路径生成一次。

**上界从哪来。** 还差 `need` 个数时，选了 `x` 之后还需要 `need - 1` 个比 `x` 大的数，而 `x + 1..n` 共 `n - x` 个，所以 `n - x >= need - 1`，即 `x <= n - need + 1`。`range` 右开，所以写 `n - need + 2`。

**为什么是 `dfs(x + 1)`。** 只往后选，每个组合只会按升序出现一次，就不会有顺序不同的重复。

**反例一：上界少 1。** 写成 `range(start, n - need + 1)`，`n = 4, k = 2`：第一位只试到 `x = 2`（`range(1, 3)`），第二位试到 `x = 3`（`range(start, 4)`），输出 `[[1,2],[1,3],[2,3]]`，缺 `[1,4]`、`[2,4]`、`[3,4]`；正确有 `6` 个。

**反例二：不限制起点。** 把递归写成 `dfs(1)`、用 `x in path` 跳过已选的数，`n = 4, k = 2` 会产生 `[1,2]` 和 `[2,1]` 这样的排列，共 `12` 个，正确 `6` 个。
