## Q
**计算器梯度题（先校验再求值）**｜追问

整数计算器（`+ - * /`、括号、一元负号，除法向零取整）已经写好：先 `is_valid` 再用双栈求值。面试官接着问：（1）输入是字符数组 `list[str]`？（2）校验和求值能合成一遍吗，错误位置怎么给？（3）分析复杂度并说明怎么测？（4）再加 `^`（右结合）、小数、变量？

## A
1. **字符数组**：`"".join(chars)` 是 `O(n)`，一次就能复用现有代码；要求不额外建字符串时，直接 `for ch in chars` 遍历，数字逐位累加。
2. **合成一遍**：求值循环里同样维护「期待操作数 / 期待运算符」和括号深度，非法时当场抛 `ValueError(f"unexpected {tok!r} at {i}")`，带上 token 序号。代价是校验和计算耦合，每加一种语法两处都要改；分两遍更清晰，一般面试里先分开写，再提可以合并。
3. **复杂度与测试**：时间 `O(n)`，空间 `O(n)`。用例按类别准备：空串与纯空格、单个数、开头 `-`、嵌套 `10^5` 层、连续运算符、负数相除（`"(-7)/2"` 是 `-3`）、大数相乘（Python 不溢出，其他语言要问清位宽）；只含 `+ - *` 和括号时可以与 `eval` 的结果对照。
4. **扩展语法**：`PREC` 加 `"^": 3`，右结合的运算符弹出条件改成 `>`（`2^3^2` 才是 `2^(3^2)`）；小数就让 `tokenize` 的数字模式改成 `\d+(?:\.\d+)?`、结果用 `float`，或者用 `fractions.Fraction` 避免误差；变量加一个 `dict[str, int]` 环境，`tokenize` 增加标识符。结构不变，只动优先级表和 token 规则。

**Python 提醒**：不要用 `eval` 交作业，它会执行任意代码，也不是面试官要考的内容；`int(a / b)` 在 `10**17` 以上丢精度，要向零取整就用 `abs(a) // abs(b)` 再还原符号。
