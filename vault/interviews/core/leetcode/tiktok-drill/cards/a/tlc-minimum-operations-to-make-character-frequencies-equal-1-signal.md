## Q
**LC 3389 使字符频率相等的最少操作次数**｜Hard · LC TikTok 热度 62/100

字符串 `s`，若其中**出现过**的每个字符的出现次数都相等，它就是好的。允许任意次：删除一个字符、添加一个字符、把一个字符变成字母表中的下一个字母（`'z'` 不能变 `'a'`）。求把 `s` 变好的最少操作次数。

约束：`1 <= s.length <= 2 * 10^4`，`s` 只含小写英文字母。例：`"acab"` → `1`；`"wddw"` → `0`；`"aaabc"` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「出现过的字符次数全相等」→ 目标是一个共同的次数 `t`；枚举 `t`（`1..最大频次`），把「找最优目标」变成「给定目标算代价」。
- 每个字母只有两种去向：清零，或变成恰好 `t` 次 → 每个字母一个两状态选择，天然是 DP。
- 「只能变到下一个字母」→ 影响只发生在字母表上相邻的两个字母之间 → 沿字母表做线性 DP，状态记上一个字母的去向。
- `n = 2 * 10^4`、26 个字母 → `26 · n` 约 `5 * 10^5` 次转移，够用。

**推导链。**
1. 暴力：固定 `t`，每个字母清零（删 `c` 个）或变成 `t` 次（补 / 删 `|c - t|` 个），忽略第三种操作，`O(26n)`；但它不是最优。
2. 浪费：字母 `i` 多出的字符「删掉」、字母 `i+1` 缺的字符「补上」，共 2 步，而把前者变成后者只要 1 步。
3. 洞察：每对这样的字符省 1 步；推两格要 2 步，不比删 + 补好，所以只需看相邻字母；节省量是 `min(上一字母的富余, 本字母的缺口)`。
4. 最优：对每个 `t`，两状态 DP 扫过 26 个字母，总 `O(26 · 最大频次)`。

**同模式的题**：LC 1647 字符频次唯一的最小删除次数、LC 2423 删除字符使频率相同、LC 2370 最长理想子序列。
