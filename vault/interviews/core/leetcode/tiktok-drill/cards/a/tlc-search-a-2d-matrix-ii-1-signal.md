## Q
**LC 240 搜索二维矩阵 II**｜Medium · 字节 高频

在 `m x n` 矩阵 `matrix` 中搜索 `target`。每行从左到右升序，每列从上到下升序（行与行之间没有大小衔接）。返回 `target` 是否存在。

约束：`1 <= m, n <= 300`，`-10^9 <= matrix[i][j], target <= 10^9`。例：`[[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]`，`target = 5` → `true`，`target = 20` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「行升序 + 列升序」→ 矩阵有二维的有序结构；但行与行不衔接，不能拉直整体二分。
- 「找一个目标值」→ 每次比较应当排除一大片。右上角（或左下角）是"一个方向增、一个方向减"的位置，比较一次就能决定去向。
- `m, n <= 300` → `O(mn)` 能过，但目标是 `O(m + n)`；`O(m log n)`（逐行二分）是中间解。

**推导链。**
1. 暴力：遍历全部元素，`O(mn)`。
2. 改进：每行二分，`O(m log n)`，没有用上列的有序。
3. 洞察：右上角元素 `a`，同行左边都比 `a` 小，同列下边都比 `a` 大；`a > target` 排除整列，`a < target` 排除整行。
4. 最优：每步缩小一行或一列，至多 `m + n` 步，`O(1)` 空间。
