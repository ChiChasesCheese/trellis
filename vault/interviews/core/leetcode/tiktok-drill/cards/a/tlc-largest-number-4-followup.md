## Q
**LC 179 最大数**｜追问

面试官接着问：（1）能不能不写比较函数，用 `key` 一行排序？（2）要拼出最小的数怎么改？（3）数字不再限制 `10^9`，位数不限，哪里会出问题？

## A
1. **用 `key`**：每个数至多 `10` 位，把每个串重复 `10` 次再按字典序降序比较，等价于比较无限循环小数。
```python
def largest_number_key(nums: list[int]) -> str:
    strs = sorted(map(str, nums), key=lambda s: s * 10, reverse=True)
    return "0" if strs[0] == "0" else "".join(strs)
```
结果与比较器版完全一致（`[3,30,34,5,9]` → `"9534330"`）。`key` 只算一次，比比较器少很多拼接，更快。前提是位数有上限：位数至多 `L` 时重复 `L` 次就够；位数不限时就只能用比较器。
2. **最小拼接数**：比较方向反过来，`a + b` 更小的排前面。若题目还要求结果不能有前导零，要先把最小的非零数放到最前面，再排其余的。
3. **位数不限**：比较器每次 `O(L)`，总时间 `O(n log n · L)` 仍然成立，只是常数大；`key` 技巧要重复到至少两个串长度之和，实现不如比较器直接。

**Python 提醒**：`cmp_to_key` 的比较函数必须返回负 / 零 / 正的整数，返回布尔值（`True == 1`、`False == 0`）永远没有负数，排序结果会不对。
