## Q
**N 叉树路径和（前缀和加哈希）**｜Medium · TikTok 高频

给一棵 N 叉树（节点有整数值 `val` 和孩子列表 `children`）和整数 `target`，统计所有自上而下的路径条数，使路径上节点值之和等于 `target`：路径不必从根开始，也不必在叶子结束，只能往孩子方向走。要求 `O(n)`，节点数 `0 <= n <= 10^5`，`-10^9 <= val, target <= 10^9`，树可能很深。例：`10 -> [5 -> [3 -> [3, -2], 2 -> [1]], -3 -> [11]]`，`target = 8` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「路径不必从根开始、和等于 `target`」→ 子数组和问题搬到树上：前缀和加哈希计数（对应 LC 560）。
- 「值可以为负」→ 滑动窗口失效，必须用前缀和计数。
- 「`O(n)`，不接受向下暴力 `O(n · h)`」→ 沿根路径维护前缀和的哈希表，查询 `O(1)`。
- 「树可能很深」→ 显式栈；哈希表要随节点的进出同步增减（回溯）。

**推导链。**
1. 暴力：对每个节点向下 DFS，累加路径和，`O(n · h)`，链状树 `O(n^2)`。
2. 浪费：不同起点的向下搜索重复走过同一段路径。
3. 洞察：路径 `a -> ... -> b` 的和是 `prefix[b] - prefix[parent(a)]`；以 `b` 结尾的合法路径数，等于根链上前缀和为 `prefix[b] - target` 的祖先个数（包含空前缀 `0`）。
4. 最优：`Counter` 记录当前根链的前缀和，进入节点先查询再登记，离开节点撤销，`O(n)` 时间。

**同模式的题**：LC 437 路径总和 III、LC 560 和为 K 的子数组、LC 974 和可被 K 整除的子数组、LC 1248 统计优美子数组。
