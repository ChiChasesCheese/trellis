## Q
**LC 793 阶乘函数后 K 个零**｜另一种解法

不做二分，能不能直接判断 `k` 对应的答案是 `0` 还是 `5`？这个 `O(log k)` 的做法为什么对，和二分相比如何取舍？

## A
**思路。** 勒让德公式（Legendre's formula）的另一种写法：`f(x) = (x - s(x)) / 4`，`s(x)` 是 `x` 的五进制数位和。把 `x` 写成五进制 `x = sum(d_j * 5^j)`（每位 `0..4`），则 `f(x) = sum(d_j * (5^j - 1) / 4)`，各位的权重依次是 `1, 6, 31, 156, ...`（`w -> 5w + 1`），个位 `d_0` 的权重是 `0`。所以 `k` 能取到，当且仅当它能写成这些权重的组合、每个系数在 `0..4`；能取到时 `d_0` 任意（`0..4`），恰好 `5` 个 `x`。系数用贪心从大权重往小权重做带余除法，出现系数 `5` 就说明无法表示。

```python
def preimage_size_fzf_math(k: int) -> int:
    weights = [1]                               # 权重 1, 6, 31, 156, ...：w' = 5w + 1
    while weights[-1] * 5 + 1 <= k:
        weights.append(weights[-1] * 5 + 1)
    for w in reversed(weights):                 # 从大权重到小权重做"带余除法"
        digit, k = divmod(k, w)
        if digit == 5:                          # 某一位需要 5（合法数位只有 0..4）：k 无法表示，没有 x
            return 0
    return 5
```

运行：`k = 0` → `5`，`k = 3` → `5`，`k = 5` → `0`（`5 // 1 = 5`），`k = 6` → `5`，`k = 11` → `0`（`11 = 1 * 6 + 5`），`k = 30` → `0`（`30 // 6 = 5`），`k = 10^9` → `5`。

**为什么对。** 权重满足 `w_{j+1} = 5 * w_j + 1`，低位系数都取 `4` 时总和为 `w_j - j < w_j`，所以每一位的系数由 `k // w_j` 唯一确定（没有"借位"的余地）；系数最多出现 `5`（`k // w_j` 不会超过 `5`），一旦出现 `5` 就超出合法范围 `0..4`，说明这个 `k` 被跳过。

**取舍。** 数学解法 `O(log k)`，很短，但依赖五进制与勒让德公式，现场推导和解释都比较吃力；二分解法只依赖「`f` 单调」这一个事实，不易出错，可以顺手扩展成"列出所有 `x`"。面试里先写二分，被追问"能不能更快"时再给数学解法。
