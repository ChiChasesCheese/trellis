## Q
**LC 152 乘积最大子数组**｜追问

面试官接着问：（1）有没有不用维护最小值的写法？（2）要返回乘积最大的子数组本身？（3）元素是浮点数或乘积会溢出怎么办？

## A
1. **前后缀两遍扫描合一。** 若数组里没有 `0`，最优子数组要么从开头开始，要么到结尾结束（负数个数为偶数则整体相乘；为奇数则必须去掉第一个负数左边的部分，或最后一个负数右边的部分）。所以对前缀乘积和后缀乘积同时取最大；遇到 `0` 把乘积重置为 `1`，等价于把数组按 `0` 切段：
```python
def max_product_two_pass(nums: list[int]) -> int:
    best = nums[0]
    pre = suf = 1
    for i in range(len(nums)):
        pre = (pre or 1) * nums[i]            # 前缀乘积；上一步成了 0 就从 1 重新开始
        suf = (suf or 1) * nums[-1 - i]       # 后缀乘积，同理
        best = max(best, pre, suf)
    return best
```
`[2,3,-2,4]` → `6`，`[-2,0,-1]` → `0`。同样 `O(n)` 时间、`O(1)` 空间，但正确性论证比维护最大最小值更绕，面试里先写 `hi/lo` 版。
2. **返回子数组。** 记录 `hi`、`lo` 各自的起点，更新 `best` 时一并保存起点与终点；重新开始（候选取到 `x`）时起点设为当前位置。
3. **溢出与浮点。** 乘积可能溢出时，定长整数语言需要用更宽的类型或在中间步骤截断，Python 的整数不溢出，但位数很多时乘法变慢。浮点数连乘会损失精度，也不能用取对数转成加法：负数和 `0` 没有对数。

**Python 提醒**：`pre or 1` 利用了「`0` 为假」；若数组里有浮点数 `0.0` 也成立，但 `-0.0` 同样为假，别用这个技巧来区分有意义的零。
