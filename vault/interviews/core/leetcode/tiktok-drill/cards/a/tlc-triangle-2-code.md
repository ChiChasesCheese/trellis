## Q
**LC 120 三角形最小路径和**｜写出 Python 实现

三角形 `triangle` 有 `1` 到 `200` 行，第 `i` 行有 `i + 1` 个数，值在 `[-10^4, 10^4]`。每一步从第 `i` 列走到下一行的第 `i` 列或第 `i + 1` 列。返回自顶向下的最小路径和，额外空间 `O(n)`，不修改输入。

## A
**思路。** `dp[i][j]` 是从格子 `(i, j)` 走到最底行的最小路径和。最底行就是基础行，直接抄过来；往上一行时，每个格子加上它下方两个相邻格 `dp[i+1][j]`、`dp[i+1][j+1]` 中较小的一个。填到顶行后 `dp[0][0]` 就是答案。

```python
def minimum_total(triangle: list[list[int]]) -> int:
    n = len(triangle)
    # dp[i][j]：从格子 (i, j) 出发，走到最底行的最小路径和；第 i 行有 i + 1 个格子
    dp = [[0] * (i + 1) for i in range(n)]
    dp[n - 1] = triangle[n - 1][:]                 # 基础行：最底行，路径只含自己
    for i in range(n - 2, -1, -1):                 # 自底向上，一行一行往上填
        for j in range(i + 1):
            dp[i][j] = triangle[i][j] + min(dp[i + 1][j], dp[i + 1][j + 1])
    return dp[0][0]                                # 答案格：顶点
```

运行：`[[2],[3,4],[6,5,7],[4,1,8,3]]` → `11`，`[[-10]]` → `-10`；`200` 行的随机三角形约 `0.001` 秒；`200` 行全是 `-10^4` → `-2000000`；调用之后 `triangle` 没有变化。

**复杂度。** 时间 `O(n^2)`（格子总数）；空间 `O(n^2)`（整张表，与三角形同形）。

**写法要点。** `[[0] * (i + 1) for i in range(n)]` 用推导式建出"第 `i` 行 `i + 1` 格"的三角形，每行是独立的列表；写成 `[[0] * n] * n` 会让所有行共用同一个列表。`dp[n - 1] = triangle[n - 1][:]` 用切片拷贝最底行，`dp` 不与输入共用同一个列表，所以不会改动输入。外层 `range(n - 2, -1, -1)` 从倒数第二行倒着走到第 `0` 行，内层 `j` 只到 `i`，下一行 `j + 1` 恰好不越界，不需要边界判断。
