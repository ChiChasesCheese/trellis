## Q
**LC 416 分割等和子集**｜正确性

为什么转移必须读上一行 `dp[i-1][j-x]`，而不是本行 `dp[i][j-x]`？总和为奇数为什么要先判断？给出出错的输入。

## A
**不变量。** 填完第 `i` 行后，`dp[i][j]` 为真，当且仅当前 `i` 个数里存在一个子集的和是 `j`。

**为什么读上一行。** `dp[i-1][j-x]` 的含义是「前 `i-1` 个数能凑出 `j-x`」，再加上第 `i` 个数 `x` 恰好凑出 `j`，`x` 用了一次。若读本行 `dp[i][j-x]`，它已经可能包含第 `i` 个数，再加一次 `x` 相当于允许 `x` 被用多次，变成完全背包（每个数可用无限次）。

**反例 1：读本行。** `nums = [1, 5]`，总和 `6`，目标 `3`，正确答案 `False`（子集和只有 `0, 1, 5, 6`）。
- 写成 `dp[i][j] = dp[i-1][j] or dp[i][j-x]`：第 `1` 行（`x = 1`）里 `dp[1][1] = dp[0][0] = True`，接着 `dp[1][2] = dp[1][1] = True`（用了第二个 `1`），`dp[1][3] = dp[1][2] = True`。`dp[2][3]` 继承 `dp[1][3]`，为真，返回 `True`，错误。
- 读上一行：`dp[1][2]` 读的是 `dp[0][1] = False`，`dp[1][3]` 读的是 `dp[0][2] = False`，第 `2` 行 `x = 5 > 3` 只能继承，`dp[2][3] = False`，返回 `False`，正确。

**反例 2：总和为奇数不判断。** 两个子集和相等意味着每个都是 `S/2`，`S` 必须是偶数。`nums = [1, 2]`，总和 `3`，`half = 3 // 2 = 1`，表里 `dp[2][1]` 为真（选 `[1]`），直接返回 `True`；正确答案是 `False`，奇数总和不可能平分。
