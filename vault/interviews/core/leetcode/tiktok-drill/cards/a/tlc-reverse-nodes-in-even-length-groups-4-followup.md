## Q
**LC 2074 反转偶数长度组的节点**｜追问

链表按 `1, 2, 3, ...` 分组、反转实际长度为偶数的组，已经用「数 `count`、翻或跳过」的迭代实现。面试官接着问：（1）改成反转奇数长度的组？（2）组长度改成固定的 `k`（LC 25）？（3）用递归怎么写，深度多大？（4）必须先实现一个简单的链表反转，怎么拆？

## A
1. **奇数组**：把 `count % 2 == 0` 改成 `count % 2 == 1`，其余不变；第一组长度为 `1`，此时要反转（单个节点反转是空操作，结果不变），所以 `prev = head`、`size = 2` 的起点依然成立。
2. **固定 `k`**：把 `size += 1` 去掉，判断改成 `count == k`，不足 `k` 的最后一组保持原样，就是 LC 25，需要哑节点处理第一组。
3. **递归**：`solve(prev_tail, size)` 处理一组后递归下一组。递归深度等于组数，`1 + 2 + ... + g >= n` 时 `g` 约为 `sqrt(2n)`，`n = 10^5` 时约 `447` 层，没有越过 Python 默认递归上限，但不是 `O(1)` 空间。
4. **拆出子程序**：先写 `reverse_list(head)`（迭代反转整条链表，`prev` 初值 `None`），再把「反转本组」改成「反转从 `first` 开始的 `count` 个节点并接回下一组」，对应上面代码里 `tail` 初值取下一组的头这一步。

**Python 提醒**：链表题别把节点值收集到列表里再重建，那是 `O(n)` 额外空间，面试官一般会追问为什么不改指针；元组赋值 `cur.next, tail, cur = tail, cur, cur.next` 的顺序是从左到右，把 `cur` 放在最前会先改变 `cur`，后面的 `cur.next` 就指错了节点。
