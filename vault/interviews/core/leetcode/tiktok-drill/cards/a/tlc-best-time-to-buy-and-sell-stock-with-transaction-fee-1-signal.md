## Q
**LC 714 买卖股票的最佳时机含手续费**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-01-04（CodeTop）

`prices[i]` 是第 `i` 天的股价，`fee` 是每笔交易（买入并卖出）的手续费。交易次数不限，但同时最多持有一股。求最大利润。`1 <= prices.length <= 5 * 10^4`，`1 <= prices[i] < 5 * 10^4`，`0 <= fee < 5 * 10^4`。例：`prices = [1,3,2,8,4,9], fee = 2` → `8`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「交易次数不限」+「同时最多持一股」→ 每天的选择只取决于**手里有没有股票** → 股票状态机 DP，状态是 `(第几天, 是否持股)`。
- 「每笔交易有手续费」→ 拆成多笔会多付费，LC 122 的逐天贪心失效，必须把「是否持股」记进状态。
- `n` 到 `5 * 10^4` → 需要 `O(n)`，每天 `O(1)` 转移。

**推导链。**
1. 暴力：枚举所有买卖日组合，指数级。
2. 无手续费时可以贪心吃每段上涨；有手续费后，`1 → 3`、`2 → 8` 拆成两笔各付一次费，不如 `1 → 8` 一笔。
3. 关键：同一天「持股」和「不持股」之后的可能完全不同，把它当状态。不持股 = 昨天不持股，或昨天持股今天卖（`+ price - fee`）；持股 = 昨天持股，或昨天不持股今天买（`- price`）。
4. 每天两次 `max`，`O(n)`；答案是最后一天不持股的值。

**同模式的题**：LC 122（不限次、无费）、LC 309（冷冻期）、LC 123 / 188（最多 2 笔 / k 笔）。
