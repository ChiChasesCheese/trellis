## Q
**LC 2 两数相加**｜Medium · LC TikTok 热度 25/100 · CodeTop 国内累计 49 次 · 最近 2026-03-17（CodeTop）

给两个**非空**链表，各表示一个非负整数。数字按**逆序**存储（个位在链表头），每个结点存一位数字。把两个数相加，并以同样的形式返回表示和的链表。除了数字 `0` 本身，两个数都不含前导零。

约束：每个链表的结点数在 `[1, 100]`，`0 <= Node.val <= 9`，数字不含前导零。

例：`l1 = [2,4,3]`, `l2 = [5,6,4]` → `[7,0,8]`（`342 + 465 = 807`）；`l1 = [9,9,9,9,9,9,9]`, `l2 = [9,9,9,9]` → `[8,9,9,9,0,0,0,1]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「按**逆序**存储的数字，逐位相加」→ 链表头是个位，两条链**同步前进**，每步 `位和 + 进位`，这是竖式加法的直接模拟。
- 结点数最多 `100`，数字有上百位 → 不能当 `int`（Java / C++ 溢出）；要逐位处理，用 `carry` 传递进位。
- 新建结果链表 → 用**哑结点 + 尾指针**，避免对第一个结点特判；不同长度、最后一个进位，统一放进 `while l1 or l2 or carry`。

**推导链。**
1. 取巧：转整数相加再转回链表，Python 可行，但绕过了考点，其他语言会溢出。
2. 逐位：同步遍历两条链，每位和 `s = a + b + carry`，当前位 `s % 10`，新进位 `s // 10`。
3. 洞察：循环条件用「`l1` 或 `l2` 或 `carry`」，不同长度和最后的进位都不需要额外分支；缺失的位当作 `0`。
4. 最优：哑结点 + 尾指针 + `divmod`，`O(max(m, n))` 时间，`O(1)` 额外空间。
