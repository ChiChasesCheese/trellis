## Q
**LC 1073 负二进制数相加**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-01-12（CodeTop）

以 -2 为基数（negabinary）表示的数用 0/1 数组给出，从最高位到最低位排列：从右往左第 `i` 位（`i` 从 0 起）的位权是 `(-2)^i`。例如 `[1,1,0,1]` 表示 `(-2)^3 + (-2)^2 + (-2)^0 = -3`。数组没有前导零（`arr == [0]` 或 `arr[0] == 1`）。给 `arr1`、`arr2`，返回两数之和的同样表示（无前导零）。`1 <= arr1.length, arr2.length <= 1000`，元素是 0 或 1，都没有前导零。 例：`[1,1,1,1,1] + [1,0,1]` → `[1,0,0,0,0]`（11 + 5 = 16）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「数组表示的数、高位在前 + 求和」→ **模拟竖式加法**：从末尾往前逐位相加，维护进位。
- 「基数 -2」→ 进位规则要重新推：`2 · (-2)^i = -1 · (-2)^(i+1)`，满 2 向高位进 **-1**；进位因此可能是负数。
- 长度到 1000 → 数值远超 64 位，逐位做是通用解法。

**推导链。**
1. 暴力：转成整数相加再转回。Python 可以，其他语言溢出，面试官会要求逐位做。
2. 竖式加法：从最低位起，`x = a + b + carry`，`x` 在 `[-1, 3]`。
3. 关键：本位写 `x mod 2`，剩下的 `2c` 个本位单位等于 `-c` 个高一位单位，进位 `-(x // 2)`。
4. 输入走完后进位可能还剩 `1` 或 `-1`，继续展开（`-1` 写成 `11`）；最后去前导零。`O(max(m, n))`。

**同模式的题**：LC 67（二进制求和）、LC 415（字符串相加）、LC 2（两数相加）、LC 1017（负二进制转换）。
