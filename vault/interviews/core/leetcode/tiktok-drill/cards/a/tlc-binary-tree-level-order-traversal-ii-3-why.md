## Q
**LC 107 二叉树的层序遍历 II**｜正确性

为什么「自顶向下收集后整体反转」就是答案？为什么不能把整条 BFS 序列倒过来？说出递归 DFS 写法在这里会出什么错。

## A
**不变量。** 每轮循环开始时，`level` 恰好是同一深度的所有结点，且按从左到右的顺序。生成下一层时按「当前层顺序，先左后右」展开，所以下一层仍然是从左到右。

**为什么只反转外层。** 题目要求「层与层之间自底向上，层内仍从左到右」。自顶向下收集的 `ans` 层内已是从左到右，把外层列表反转后，最深的一层排在前面，层内顺序不变。

**反例：反转扁平的 BFS 序列。** 扁平的 BFS 访问序列是 `[3,9,20,15,7]`，整体反转得到 `[7,15,20,9,3]`：
- 不再分层，输出格式就是错的；
- 即使按层切分，最后一层变成 `[7,15]`，层内顺序反了。
正确答案是 `[[15,7],[9,20],[3]]`。

**反例：递归 DFS 在深树上崩溃。** 带深度的 DFS（`dfs(node.left, depth + 1)`）逻辑上正确，但结点数最多 `2000`，一条只有左孩子的链深度可达 `2000`。Python 默认递归上限约 `1000`，这棵树会抛 `RecursionError`；BFS 的循环不依赖调用栈，同一棵树能正常输出 `2000` 层。

**空树。** `level = [root] if root else []` 让 `while` 不执行，返回 `[]`；如果写成 `level = [root]`，`root` 为 `None` 时会访问 `None.val` 报错。
