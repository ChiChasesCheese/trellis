## Q
**LC 237 删除链表中的节点**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-03-23（CodeTop）

单链表里所有值都**互不相同**。只给你要删除的节点 `node`，**拿不到头节点 `head`**，且保证 `node` 不是尾节点。删除后：`node` 的值不再出现在链表中，节点数减 1，`node` 前后两部分的值各自保持原顺序（不要求真的释放内存）。节点数在 `[2, 1000]`，`-1000 <= Node.val <= 1000`。例：`[4,5,1,9]` 中删除值为 `5` 的节点 → `[4,1,9]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「拿不到 `head`」→ 找不到前驱，常规的 `prev.next = node.next` 无法执行。
- 「保证不是尾节点」→ 后继一定存在，提示用后继来「顶替」自己。
- 「删除只看值序列」→ 节点身份无所谓，可以**搬值**：复制后继的值，再删后继。
- 链表长度 `<= 1000` 无关紧要，解法是 `O(1)`。

**推导链。**
1. 常规：从 `head` 找前驱再改指针，`O(n)`，但没有 `head`。
2. 卡点：单链表只能往后走，无法回到前驱。
3. 关键：要消失的是 `node` 的**值**，不一定是 `node` 这个对象；后继的前驱正是 `node`，删后继很容易。
4. 最优：`node.val = next.val`，`node.next = next.next`，`O(1)`。
