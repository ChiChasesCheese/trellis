## Q
**LC 329 矩阵中的最长递增路径**｜Hard · LC TikTok 热度 62/100 · CodeTop 国内累计 29 次 · 最近 2026-04-23（CodeTop）

给 `m x n` 整数矩阵 `matrix`，求最长递增路径的格子数：每步向上下左右移动一格，路径上的值严格递增。`1 <= m, n <= 200`，`0 <= matrix[i][j] <= 2^31 - 1`。例：`[[9,9,4],[6,6,8],[2,1,1]]` → `4`（`1 -> 2 -> 6 -> 9`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格上的路径」+「严格递增」→ 沿递增方向永远不会回到原处 → 格子和「相邻且更大」的边构成**有向无环图**（DAG），不需要 `visited`。
- DAG 上求**最长路径** → 两条经典路线：**记忆化 DFS**，或**拓扑排序**（按层剥掉出度为 `0` 的点，层数即答案）。
- `m, n <= 200` → 至多 `40000` 格，`O(mn)` 毫无压力；但一条路径可能有两万格，Python 递归深度默认约 `1000`，**记忆化 DFS 会爆栈**，所以拓扑排序是更稳的主解。
- 「严格」→ 相等的邻居不连边。

**推导链。**
1. 暴力：从每个格子出发 DFS 枚举所有递增路径，指数级。
2. 浪费：不同起点会重复走同一段后缀；以某格为起点的最长路径只有一个值。
3. 洞察：缓存每个格子的答案（记忆化），或者反过来按拓扑层推进：出度为 `0` 的格子是第一层，剥掉后新的出度为 `0` 的格子是第二层……层数 = 最长路径点数。
4. 最优：算出度、层层剥离，每格进出一次，`O(mn)`，全程迭代。
