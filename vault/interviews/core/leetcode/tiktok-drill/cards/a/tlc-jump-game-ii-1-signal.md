## Q
**LC 45 跳跃游戏 II**｜Medium · TikTok·字节高频

数组 `nums` 长度为 `n`，初始在下标 `0`；`nums[i]` 表示从 `i` 出发最多向后跳 `nums[i]` 格（`0 <= j <= nums[i]` 且 `i + j < n`）。求到达 `n - 1` 的最少跳跃次数，保证可达。`1 <= nums.length <= 10^4`，`0 <= nums[i] <= 1000`。例：`[2,3,1,1,4]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最少**跳跃次数」+ 每步有多个去处 → 无权图最短路，本质是 **BFS 分层**。
- 每格能到的是一段**连续区间**（不是任意几个点）→ 每一层都是连续前缀，BFS 队列能压缩成「本层右边界」和「下一层最远点」两个数，这就是**贪心**。
- `n = 10^4`：`O(n^2)` 的 DP 约 `10^8` 步，Python 会超时，要 `O(n)`。

**推导链。**
1. 暴力 DFS：每步试所有跳法，指数级。
2. 记忆化 / DP：`dp[j] = min(dp[i] + 1)`，对每个 `i` 更新它能到的区间，`O(n^2)`。
3. 浪费在哪：`dp` 沿下标单调不降，所以「恰好 `k` 跳到达」的格子是连续一段，逐格记 `dp` 是多余的。
4. 只维护两个值：当前层右边界 `cur_end`、已扫格子能到的最远点 `farthest`。扫到 `cur_end` 就必须再跳一次，边界换成 `farthest`。一趟 `O(n)`，空间 `O(1)`。

**同模式的题**：LC 55 跳跃游戏、LC 1024 视频拼接、LC 1326 灌溉花园的最少水龙头数目、LC 871 最低加油次数。
