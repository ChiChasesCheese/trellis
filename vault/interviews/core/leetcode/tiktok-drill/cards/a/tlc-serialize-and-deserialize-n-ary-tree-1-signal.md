## Q
**LC 428 序列化和反序列化 N 叉树**｜Hard · TikTok 高频

设计一个把 N 叉树（每个结点有任意多个孩子）转成字符串、再从字符串还原成原树的算法：`serialize(root)` 返回字符串，`deserialize(data)` 返回树，格式自定。算法必须**无状态**——不能用类成员、全局变量或静态变量保存状态。

约束：结点数在 `[0, 10^4]`，`0 <= Node.val <= 10^4`，N 叉树的高度 `<= 1000`。

例：`root = [1,null,3,2,4,null,5,6]`（层序格式：`1` 的孩子是 `3,2,4`，`3` 的孩子是 `5,6`）经 `serialize` 再 `deserialize` 后必须得到同一棵树；`root = []` 得到 `[]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「序列化 / 反序列化，格式自定」→ 设计一个**无歧义、可逆**的编码；先序 + 结构信息（空标记 / 孩子个数 / 括号）是通用套路。
- N 叉树：每个结点孩子数不定，二叉树的「空标记」做法不再自然 → 把**孩子个数**写进结点，或给每组孩子加结束标记。
- 「高度 `<= 1000`」「结点 `10^4`」：线性解足够，但深度逼近 Python 递归上限（1000），暗示用显式栈。「无状态」→ 不能把迭代器 / 下标放在 `self` 上。

**推导链。**
1. 暴力想法：只记先序的值——`1→[2,3]` 与 `1→2→3` 都是 `1 2 3`，不可逆。
2. 补救一：加括号或 `null` 分隔（层序格式）；可逆，但解析要处理嵌套或队列，写起来冗长。
3. 洞察：解码真正需要知道的只有「这个结点后面跟几棵子树」→ 先序时把孩子个数写在值后面，整串自描述，无需任何分隔符。
4. 最优：序列化用显式栈做先序，输出 `值 个数`；反序列化用「结点栈 + 还缺几个孩子」的并行栈还原，`O(n)` 时间，无递归。
