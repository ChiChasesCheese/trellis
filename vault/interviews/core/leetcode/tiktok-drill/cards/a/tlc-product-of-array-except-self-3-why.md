## Q
**LC 238 除了自身以外数组的乘积**｜正确性

两趟扫描里，为什么每一趟都必须「先把 `left` / `right` 乘进答案，再把 `nums[i]` 乘进 `left` / `right`」？顺序反过来，`[1,2,3,4]` 会输出什么？

## A
**不变量。** 第一趟循环到下标 `i` 开始时，`left == nums[0] * ... * nums[i-1]`（不含 `nums[i]`）；第二趟到下标 `i` 开始时，`right == nums[i+1] * ... * nums[n-1]`（同样不含 `nums[i]`）。`ans[i]` 先后乘上两者，就是除自身外的全体之积。

**为什么顺序不能换。** `answer[i]` 要**排除** `nums[i]`。如果先 `right *= nums[i]` 再 `ans[i] *= right`，`right` 里就包含了 `nums[i]`；第一趟同理。

**反例（第二趟顺序反了）。** `nums = [1,2,3,4]`，第一趟之后 `ans = [1, 1, 2, 6]`：
- 反向扫描时先乘后用：`right` 依次变成 `4, 12, 24, 24`，`ans` 变成 `[24, 24, 24, 24]`。
- 先用后乘：`ans` 变成 `[24, 12, 8, 6]`，正确。

**为什么不用除法。** 总积除以 `nums[i]` 在有 `0` 时不成立：`[-1,1,0,-3,3]` 的总积为 `0`，`0 // 0` 抛 `ZeroDivisionError`；即便绕开，`0` 所在位置的答案应是 `9`（其余数之积），其余位置应是 `0`，需要额外的分类讨论。
