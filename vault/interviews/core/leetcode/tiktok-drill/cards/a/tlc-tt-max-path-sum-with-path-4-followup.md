## Q
**二叉树最大路径和（并输出路径）**｜追问

二叉树最大路径和（路径任意、节点值可负）并输出路径，已经用后序 DP 加记录选择做到 `O(n)`。面试官接着问：（1）只要数值，还能怎么简化？（2）要求路径必须经过根，或者必须从根走到叶子？（3）有多条路径并列最大？（4）如何证明路径还原是对的？

## A
1. **只要数值**：去掉 `down` 和 `arm`，递归函数返回 `gain`，用 `nonlocal best` 更新；额外空间只剩递归栈 `O(h)`，是 LC 124 的标准写法。
2. **必须过根**：只在根处统计 `root.val + max(0, 左 gain) + max(0, 右 gain)`。**必须从根到叶子**：`gain` 不再取 `max(0, ·)`，叶子处返回自身值，最后答案是根的 `gain`。
3. **并列最大**：当前代码用严格大于，保留处理顺序中先遇到的拐点，返回任意一条；要列出全部，就收集所有等于 `best` 的拐点分别展开两条臂，臂上遇到左右 `gain` 相等时有两种选择，需要展开成多条。
4. **还原的正确性**：`down[v]` 记录的是 `v` 的最优单链的下一步，所以沿 `down` 走出的链的和恰好是 `gain[v]`；拐点处的路径和等于 `val + gain[左臂首节点] + gain[右臂首节点]`，也就是记录的 `best`。验证时可以重新累加路径上的节点值，必须等于返回的 `best`，并且相邻节点必须互为父子。

**Python 提醒**：`dict` 以 `TreeNode` 对象为键是按身份比较的，不要给节点类定义 `__eq__` 而不定义 `__hash__`（否则对象不可哈希）；递归写法在链状的 `3 * 10^4` 层树上会 `RecursionError`，`sys.setrecursionlimit` 加大后还要给线程更大的栈（`threading.stack_size`），所以面试里更稳的是显式栈。
