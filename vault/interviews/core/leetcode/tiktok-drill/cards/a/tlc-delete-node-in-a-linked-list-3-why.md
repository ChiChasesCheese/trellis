## Q
**LC 237 删除链表中的节点**｜正确性

为什么「复制后继的值、再跳过后继」满足删除要求？如果写成 `node = node.next` 或只复制值会怎样？

## A
**要求的是值序列。** 设链表值序列为 `[..., v, w, rest...]`，`node` 的值是 `v`，后继的值是 `w`。执行后，`node` 的值变成 `w`，`node.next` 指向 `rest` 的开头，序列成为 `[..., w, rest...]`：`v` 消失、长度减 1、前后两部分顺序不变，正好是删除 `v` 的结果。值互不相同保证 `v` 不会在别处再出现。

**为什么需要「不是尾节点」。** 尾节点没有后继可以搬，而改动它的前驱必须先拿到前驱。

**反例 1：`node = node.next`。** 这只让函数里的局部名字 `node` 指向后继，链表上没有任何指针被改。`[4,5,1,9]` 删 `5` 后仍是 `[4,5,1,9]`（正确 `[4,1,9]`）。

**反例 2：只复制值。** `node.val = node.next.val` 而不跳过后继：`[4,5,1,9]` 删 `5` 变成 `[4,1,1,9]`，长度没减、`1` 出现两次。
