## Q
**LC 150 逆波兰表达式求值**｜Medium · CodeTop 国内累计 5 次 · 最近 2026-05-19（CodeTop）

给字符串数组 `tokens`，它是一个逆波兰表示法（后缀表达式：运算符写在两个操作数之后）的算术表达式，求它的整数值。运算符只有 `+ - * /`；整数除法**向零截断**；不会除以零；输入一定合法；答案和所有中间结果都在 32 位整数范围内。`1 <= tokens.length <= 10^4`，`tokens[i]` 是运算符或 `[-200, 200]` 内的整数。例：`["4","13","5","/","+"]` → `6`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「后缀表达式」→ 运算符作用于它之前**最近**的两个值，最近者先用，是后进先出（LIFO）→ **栈**。
- 没有括号、没有优先级 → 不需要调度场，一遍扫描即可。
- 「向零截断」→ 不能直接用 Python 的 `//`（向下取整），要单独处理负数。
- `n <= 10^4` → `O(n^2)` 也能过，但一遍 `O(n)` 是自然解。

**推导链。**
1. 暴力：反复找第一个运算符，把它和前两个数替换成结果，每次 `O(n)` 搬移，共 `O(n^2)`。
2. 浪费：每轮从头找运算符，还要整体移动数组。
3. 洞察：从左往右扫，还没用掉的数按出现顺序放好，运算符需要的两个数正好是最后放进去的两个。
4. 最优：数字入栈，运算符弹两个（先弹的是右操作数）、算完压回，`O(n)`。

**同模式的题**：LC 224 基本计算器、LC 227 基本计算器 II、LC 20 有效的括号、LC 394 字符串解码。
