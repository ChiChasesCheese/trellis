## Q
**LC 714 买卖股票的最佳时机含手续费**｜追问

面试官接着问：（1）卖出后必须休息一天才能再买（冷冻期），怎么改？（2）最多只能做 `k` 笔交易呢？（3）空间能不能更省？

## A
1. **冷冻期（LC 309）**：今天买入的前提是「前天结束时不持股」，因为昨天可能刚卖出。持股的转移改成 `dp[i][1] = max(dp[i-1][1], dp[i-2][0] - prices[i])`（`i < 2` 时用 `0`），不持股的转移不变。手续费和冷冻期可以同时存在，两处改动互不影响。
2. **最多 `k` 笔（LC 188）**：状态加一维「已经开始了几笔交易」，`dp[i][j][0/1]`；买入时 `j` 加一，`j <= k`。时间 `O(nk)`。`k >= n // 2` 时限制形同虚设，退化成不限次。
3. **空间**：每天只依赖前一天，空间可以压到 `O(1)`：见 Python 工具箱「DP 降维」。

**Python 提醒**：初始化二维表要写 `[[0, 0] for _ in range(n)]`；`[[0, 0]] * n` 复制的是同一个内层列表的引用，改一行等于改所有行，换一种转移顺序就会悄悄出错。
