## Q
**LC 273 整数转换英文表示**｜正确性

三位一组的写法里，哪些边界最容易出错？如果不判断「这一组是否全为 0」就直接加量级词，`1000000` 会输出什么？

## A
**分解的依据。** `num = Σ chunk_k × 1000^k`，每个 `chunk_k` 在 `0` 到 `999`。英文读法是把每个非 0 的 `chunk_k` 读出来再接第 `k` 个量级词，按 `k` 从大到小排列；值为 0 的组不发音。组内同理：`chunk = 100h + r`，`h` 非 0 读「`h` Hundred」，`r` 非 0 时 `r >= 20` 读「整十 + 个位」、否则查 1 到 19 的独立单词。

**三个边界。**
- 整个数为 `0`：唯一读出 `Zero` 的情况，必须在最前面单独返回，组内永远不读 Zero。
- 全 0 的组：既不读数字，也不读量级词。
- 11 到 19：不能拆成十位和个位。

**反例：全 0 组也加量级词。** `1000000` 分成三组 `[0, 0, 1]`（低位在前）。
- 第 0 组读出空列表、无量级词，得到空串 `""`；第 1 组读出 `[] + ["Thousand"]`；第 2 组 `"One Million"`。
- 反转拼接得 `"One Million Thousand "`：多了 `Thousand`，结尾还多一个空格。
- 正确是 `"One Million"`：加上 `if chunk:` 后前两组都被跳过。
