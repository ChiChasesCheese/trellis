## Q
**LC 150 逆波兰表达式求值**｜正确性

栈解法里栈保持什么不变量？为什么不能用 Python 的 `a // b` 做除法？给出 `//` 会算错的输入。

## A
**不变量。** 扫完前 `i` 个 token 后，栈里从底到顶是这段前缀中**尚未被运算符用掉**的子表达式的值，按出现顺序排列。后缀表达式里运算符作用于它前面最近的两个完整子表达式，它们正是栈顶两个值；后弹出的那个在原式中更靠左，是左操作数。输入合法时最后恰好剩一个值。

**为什么不能 `//`。** Python 的 `//` 向下取整（向负无穷），题目要向零截断。两者只在结果为负且除不尽时不同：`-7 // 2 == -4`，向零截断是 `-3`。

**反例：第三个示例。** `["10","6","9","3","+","-11","*","/","*","17","+","5","+"]`，正确值 `22`。
- 关键一步是 `6 / -132`：向零截断得 `0`，`//` 得 `-1`。
- 用 `//` 时：`10 * -1 + 17 + 5 = 12`，错成 `12`。

`int(a / b)` 在 32 位范围内也正确，但它走浮点；操作数超过 `2^53` 时会丢精度，所以用「绝对值整除再补符号」更稳。
