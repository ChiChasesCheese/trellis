## Q
**LC 1091 二进制矩阵中的最短路径**｜Medium · TikTok 高频

`n x n` 的 0/1 矩阵 `grid`，从 `(0, 0)` 走到 `(n-1, n-1)`，只能经过值为 `0` 的格子，8 个方向（含斜向）相邻，路径长度是经过的格子总数，求最短长度，不存在返回 `-1`。`1 <= n <= 100`。例：`[[0,0,0],[1,1,0],[1,1,0]]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「网格 + **最短**路径」且每一步代价相同 → **BFS**（无权图最短路），不是 DFS，也不需要 Dijkstra。
- 「8 个方向」→ 方向表有 8 项，不是 4 项。
- 「长度 = 格子总数」→ 起点算 1，不是 0。
- `n <= 100`，一万个格子 → 每格处理一次的 `O(n^2)` 绰绰有余。

**推导链。**
1. 暴力：DFS 枚举所有不重复的路径取最短，指数级。
2. 浪费：同一个格子被不同路径反复到达，重复探索。
3. BFS 按距离分层：一个格子第一次被到达就是它的最短距离，之后到达只会更长。
4. 所以每个格子只需入队一次：入队时就标记，不要等出队。总共 `O(n^2 * 8)`。
