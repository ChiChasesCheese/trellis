## Q
**LC 1997 访问完所有房间的第一天**｜正确性

递推 `first[i+1] = 2 * first[i] - first[nextVisit[i]] + 2` 为什么成立？"重走一遍的路程恰好是 `first[i] - first[nextVisit[i]]`"这个关键前提靠什么保证？漏掉一项会错成什么？

## A
**不变量。** 第一次到达房间 `i` 的那一刻，所有编号小于 `i` 的房间都已被访问**偶数**次，而房间 `i` 本身刚被访问 1 次。

**为什么。** 前进只发生在访问次数为偶数的时候，要走到编号 `i`，必须依次从 `i-1`、`i-2`……每个房间都以偶数次离开。第一次到 `i` 之前没有离开过 `i` 之后的任何房间，所以只有小于 `i` 的房间有过访问，且次数都是偶数。

**为什么重走的路程固定。** 第 `first[i] + 1` 天回到 `nextVisit[i]`（记为 `v`，`v <= i`）。`v` 之前被访问偶数次，现在变成奇数次，与第一次到 `v` 那一刻的状态一致（当时 `v` 是第 1 次，编号小于 `v` 的房间次数都是偶数）；`v` 与 `i` 之间的房间次数也都是偶数，等同于当初还没访问过的初始状态（0 次）。于是从 `v` 再走到 `i` 的过程与第一次从 `v` 走到 `i` 完全相同，花 `first[i] - first[v]` 天，到达 `i` 时它是第 2 次（偶数），下一天去 `i + 1`。合计 `first[i] + 1 + (first[i] - first[v]) + 1`。

**反例：漏掉减去的一项。** 写成 `first[i+1] = 2 * first[i] + 2`（把回跳当成回到 0 号房间）。`nextVisit = [0,1,2,0]`：`first[1] = 2`，`first[2] = 6`，`first[3] = 14`，答案 `14`；正确值 `first[2] = 2 * 2 - first[1] + 2 = 4`，`first[3] = 2 * 4 - first[2] + 2 = 6`，答案 `6`。只有 `nextVisit[i] = 0` 时 `first[0] = 0`，两种写法才碰巧相同。
