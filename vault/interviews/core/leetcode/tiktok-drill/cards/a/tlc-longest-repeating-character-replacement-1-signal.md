## Q
**LC 424 替换后的最长重复字符**｜Medium · LC 字节 热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-09-20（CodeTop）

给字符串 `s`（仅大写英文字母，`1 <= s.length <= 10^5`）和整数 `k`（`0 <= k <= s.length`）。可以把任意位置的字符改成任意其他大写字母，最多 `k` 次。返回替换后，只含同一字母的最长子串的长度。例：`s = "AABABBA", k = 1` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「连续子串」+「最长」+「最多修改 `k` 次」→ **可变长滑动窗口**。
- 把「替换」变成可计数的条件：窗口里想统一成字符 `c`，要改掉所有非 `c` 的位置；选出现次数最多的字符最省，代价 `= 窗口长度 − 最高频次数`，合法当且仅当 `<= k`。
- 单调性：窗口缩小，代价不会变大 → 违反条件就收缩左端是安全的。
- `n = 10^5`，字母只有 `26` 个：`O(n)` 或 `O(26n)`。

**推导链。**
1. 暴力：枚举所有子串，统计最高频，判断 `长度 − 最高频 <= k`，`O(n^2 · 26)`。
2. 滑窗：右端扩张、用 `Counter` 维护窗口内次数；代价超过 `k` 时左端右移，`O(n)` 次移动。
3. 洞察：答案只会在窗口**变长**时刷新，而变长必须最高频次数创新高。所以 `max_freq` 只记历史最大值、不随收缩更新即可，省去每次 `max(count.values())`。
4. 进一步：窗口永不缩小，只会增大或整体平移，所以最终答案就是窗口大小，用 `if` 而不是 `while`。
