## Q
**LC 939 最小面积矩形**｜Medium · LC 字节 热度 50/100

给 X-Y 平面上的点数组 `points`（`1 <= points.length <= 500`，`0 <= xi, yi <= 4 * 10^4`，所有点互不相同）。返回由这些点作为顶点、边与坐标轴平行的矩形的最小面积；不存在就返回 `0`。例：`[[1,1],[1,3],[3,1],[3,3],[2,2]]` → `4`；`[[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「边与坐标轴平行的矩形」→ 一条对角线就决定另外两个角：`(x1, y1)` 和 `(x2, y2)` 对应 `(x1, y2)` 与 `(x2, y1)`。
- 「在点集里找存在的组合」→ 枚举加哈希集合（hash set）查找存在性。
- `n <= 500` → 点对约 `12.5` 万个，`O(n^2)` 足够；`O(n^4)` 的四点枚举不行；坐标到 `4 × 10^4`，不能开二维数组标记全部格子。
- 「最小面积」→ 对所有合法矩形取 `min`，没有就是 `0`。

**推导链。**
1. 暴力：任选四个点，检查是否是轴平行矩形，`O(n^4)`。
2. 浪费：矩形四个点里只有两个是自由的，另外两个被完全决定。
3. 洞察：枚举点对作对角线，两点的 `x`、`y` 必须各不相同，另外两个角用集合 `O(1)` 查，`O(n^2)`。
4. 另一个角度：按列分组，同一列的每对 `(y1, y2)` 再次出现于另一列时形成矩形，适合点多但每列点少的情形。

**同模式的题**：LC 963 最小面积矩形 II、LC 750 角矩形的数量、LC 593 有效的正方形、LC 149 直线上最多的点数。
