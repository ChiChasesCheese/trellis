## Q
**LC 235 二叉搜索树的最近公共祖先**｜Easy · CodeTop 国内累计 7 次 · 最近 2026-03-19（CodeTop）

给一棵二叉搜索树（BST）的根结点 `root` 和其中两个不同的结点 `p`、`q`，返回它们的最近公共祖先（LCA）：既是 `p` 的祖先又是 `q` 的祖先、且深度尽可能大的结点。**一个结点也可以是它自己的祖先**。所有结点的值都唯一；`p`、`q` 是不同的结点，且都在这棵树里。例：`root = [6,2,8,0,4,7,9,null,null,3,5]`，`p = 2, q = 8` → `6`；`p = 2, q = 4` → `2`（`2` 是 `4` 的祖先，也是它自己的祖先）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「二叉**搜索**树」→ 利用有序性：比较一次值就能整棵子树地排除一边，复杂度从 `O(n)` 降到 `O(h)`。
- 「最近公共祖先」+「结点也可以是自己的祖先」→ 答案是 `p`、`q` 开始**分叉**的第一个结点，也可能是其中之一；分叉判据是「值落在 `[min, max]` 里」。
- 「值唯一」→ 可以直接用 `val` 比大小，不用担心相等值的左右归属。
- 题面没有给结点个数，链状 BST 的 `h` 可以等于 `n`；用循环而不是递归，不受 Python 递归深度限制。

**推导链。**
1. 暴力：求根到 `p`、根到 `q` 的两条路径，取最后一个公共结点。`O(h)` 时间、`O(h)` 空间。
2. 浪费：BST 已经指明方向，不需要先找到 `p`、`q` 才知道往哪走。
3. 洞察：当前结点 `x` 的值比 `p`、`q` 都小 → 都在右边；都大 → 都在左边；其余情况 `x` 就是答案。
4. 最优：从根出发的一条路径，`O(h)` 时间、`O(1)` 空间。
