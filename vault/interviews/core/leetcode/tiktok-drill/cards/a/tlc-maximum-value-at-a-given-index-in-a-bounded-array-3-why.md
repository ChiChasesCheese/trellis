## Q
**LC 1802 有界数组中指定下标处的最大值**｜正确性

为什么每个位置取 `max(v - 距离, 1)` 就是峰值为 `v` 时的最小和？为什么 `side` 要分两种情况？给出只用等差数列、不补 `1` 的错误输出。

## A
**不变量。** 二分区间 `[lo, hi]` 始终满足：`lo` 可行（`total(lo) <= max_sum`），答案不超过 `hi`。每轮把区间缩小一半，最后 `lo == hi` 就是最大可行的峰值。

**为什么 `max(v - d, 1)` 是最小和。** 位置距离峰 `d` 格，相邻差不超过 `1`，所以它的值至少是 `v - d`（每走一格最多降 `1`）；又必须是正整数，至少是 `1`。每个位置都取各自的下界，互相之间满足“差不超过 `1`”（下界序列本身每格降 `1` 或保持 `1`），所以这个数组合法且和最小。任何合法数组的和都不小于它。

**为什么单调。** `v` 增大，每个位置的下界不减，所以 `total(v)` 单调不减，二分成立。

**为什么 `side` 分两种。**
- `length >= peak - 1`：一侧的位置足够多，数列 `peak-1, peak-2, ..., 1` 走完后还有位置，剩下的都取 `1`。和 = `peak * (peak - 1) / 2 + (length - (peak - 1))`。
- `length < peak - 1`：位置不够降到 `1`，数列是 `peak-1` 到 `peak-length`，和 = `(peak - 1 + peak - length) * length / 2`。

**反例：不补 `1`。** 用 `(peak - 1 + peak - length) * length // 2` 统一计算一侧的和，在 `length >= peak - 1` 时会把本该是 `1` 的位置算成 `0` 或负数。
- `(n, index, maxSum) = (3, 0, 3)`：峰值取 `2` 时，右侧 `2` 个位置应当是 `1, 1`（和 `2`），总和 `4 > 3`，不可行；错误公式把右侧算成 `1 + 0 = 1`，总和 `3 <= 3` 可行，返回 `2`。正确答案是 `1`（数组 `[1,1,1]`）。
- `(4, 3, 4)` 同样错误地返回 `2`，正确是 `1`。
- 示例 `(4, 2, 6)` 和 `(6, 1, 10)` 恰好不触发，所以示例都对不代表公式对。
