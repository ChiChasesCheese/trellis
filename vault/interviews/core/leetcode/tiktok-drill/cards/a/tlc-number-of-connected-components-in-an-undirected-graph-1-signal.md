## Q
**LC 323 无向图中连通分量的数目**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-03-10（面试记录）

无向图有 `n` 个节点（下标 `0` 到 `n - 1`），`edges[i] = [a, b]` 表示 `a`、`b` 之间有一条边，返回连通分量的个数。`1 <= n <= 2000`，`1 <= edges.length <= 5000`，`0 <= a <= b < n`，`a != b`，没有重复的边。例：`n = 5`，`edges = [[0,1],[1,2],[3,4]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连通分量**的个数」+ 只给边列表 → **并查集**（Union-Find）或图遍历；只数个数、不要路径，并查集不需要建邻接表。
- 「边」按列表给出、顺序任意 → 适合逐条处理的在线算法；若题目变成「边一条条加入」，并查集仍然适用。
- `n <= 2000`、`m <= 5000` → 线性或近线性即可，`O(n * m)` 的反复遍历也许能过，但没有必要。

**推导链。**
1. 暴力：建邻接表，对每个未访问的点做一次 DFS / BFS，发起遍历的次数就是答案，`O(n + m)`。
2. 观察：一开始每个点各自是一个分量，共 `n` 个；一条连接**两个不同分量**的边让总数减一，连接同一分量内部的边（成环）不改变总数。
3. 用并查集维护「每个点属于哪个集合」，合并前用 `find` 判断两端是否同根。
4. 答案 = `n` − 成功合并的次数，边处理耗时近似 `O(1)`（路径压缩）。
