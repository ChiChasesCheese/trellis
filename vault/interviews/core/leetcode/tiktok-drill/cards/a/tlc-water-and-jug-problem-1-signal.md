## Q
**LC 365 水壶问题**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 4 次 · 最近 2026-05-08（面试记录）

容量分别为 `x`、`y` 升的两个水壶，水源无限。判断能否让两个壶里的水合计恰好 `target` 升。操作：装满任一壶；清空任一壶；把一个壶倒进另一个，直到接水壶满或倒水壶空。`1 <= x, y, target <= 10^3`。例：`x = 3, y = 5, target = 4` → `true`；`x = 2, y = 6, target = 5` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「用固定大小的容器量出某个数量」→ 每次操作让总量变化 `±x`、`±y` 或不变 → **裴蜀定理**（Bézout's identity）与**最大公约数**（gcd）。
- 「操作有限、状态有限」→ 也可以把 `(a, b)` 当节点做 **BFS / DFS**：可达状态只有约 `2(x + y)` 个，作为备用解。
- `x, y, target` 只到 `10^3`，搜索完全可行；但操作规则简单、问的是「能不能」，更像在考察数学结论。

**推导链。**
1. 暴力：状态 `(a, b)`，6 种操作（装满 `x`、装满 `y`、倒空 `x`、倒空 `y`、`x → y`、`y → x`），搜到总量或单壶等于 `target`。可达状态约 `2(x + y)` 个。
2. 观察总量：倒水不改变总量；装满 / 倒空使总量加减 `x` 或 `y` 的某个整数倍。所以总量始终形如 `a·x + b·y`。
3. 裴蜀定理：所有形如 `a·x + b·y` 的整数恰好是 `gcd(x, y)` 的倍数。所以 `target` 必须是 `gcd` 的倍数。
4. 容量限制：总量不可能超过 `x + y`。反过来，满足这两条的 `target` 一定能凑出来。结论：`target <= x + y and target % gcd(x, y) == 0`。
