## Q
**课程表输出学习顺序，及单词接龙输出最短路径**｜Medium · 近一年被问：美国 15 次、国内 4 次 · 最近 2026-10-15（面试记录）

第一问：`numCourses` 门课（编号 `0` 到 `numCourses - 1`）、先修关系 `prerequisites`（`[a, b]` 表示学 `a` 之前必须先学 `b`，`1 <= numCourses <= 2000`，`0 <= len(prerequisites) <= 5000`，关系互不相同），判断能否学完，能就输出一种学习顺序，不能返回空列表。第二问：`begin`、`end` 和单词列表 `words`（等长，全小写，`1 <= len(words) <= 5000`，`begin != end`），每次只改一个字母且结果必须在 `words` 里，输出一条最短转换路径，不可达返回空列表。例：`(4, [[1,0],[2,0],[3,1],[3,2]])` → `[0, 1, 2, 3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「先修关系、能否学完、输出顺序」→ 有向图的判环加拓扑排序（Kahn 算法，用入度）。
- 「每步改一个字母、最少步数」→ 无权图的最短路，BFS；单词是点，只差一个字母是边。
- 「输出路径」→ 在 BFS 里多记一个前驱，到达终点后回溯再反转。
- `N = 5000` 个单词：两两比较建图 `O(N^2 · L)` 太慢；用通配模式（`h*t`）分桶，同桶即邻居。

**推导链。**
1. 暴力（课程）：每轮扫全部课程找“先修都学完”的，`O(V · (V + E))`。
2. 浪费：每轮都在重复检查没有变化的课程。
3. 洞察：维护入度；学完一门课只更新它的后继，减到 `0` 就入队；出队数不足课程数说明有环。
4. 最优：课程 `O(V + E)`；接龙分桶建图加 BFS，`O(N · L^2)`，入队时记前驱即可还原路径。

**同模式的题**：LC 207 课程表、LC 210 课程表 II、LC 127 单词接龙、LC 126 单词接龙 II、LC 2050 并行课程 III。
