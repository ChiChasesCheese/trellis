## Q
**LC 384 打乱数组**｜Medium · CodeTop 国内累计 7 次 · 最近 2026-06-19（CodeTop）

设计类 `Solution(nums)`，`reset()` 返回初始数组，`shuffle()` 返回随机打乱的数组，要求所有排列等概率。`1 <= nums.length <= 50`，`-10^6 <= nums[i] <= 10^6`，元素互不相同，`reset` 与 `shuffle` 最多共调用 `10^4` 次。例：`Solution([1,2,3])`，`shuffle()` 可能返回 `[3,1,2]`，`reset()` 返回 `[1,2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「所有排列**等概率**」→ 均匀随机排列 → **Fisher–Yates 洗牌**。判断一个随机算法是否均匀，看「随机选择的总数」能否与 `n!` 个排列一一对应。
- 「reset 回到初始状态」→ 构造时另存一份副本，每次在副本的拷贝上洗。
- `n <= 50`、`10^4` 次调用 → 每次 `O(n)` 绰绰有余，但 `n!` 级的枚举不行。

**推导链。**
1. 暴力：列出全部 `n!` 个排列再随机选一个，`50!` 不可能。
2. 抽签：从剩余元素里随机抽一个放到结果末尾，均匀；但从列表中间删除是 `O(n)`，总 `O(n^2)`。
3. 关键：把「剩余元素」放在数组后段 `[i, n)`，抽中的与位置 `i` 交换，抽出变成 `O(1)`。
4. 第 `i` 步有 `n - i` 种选择，总共 `n · (n-1) · … · 1 = n!` 种，与排列一一对应 → 均匀，`O(n)`。
