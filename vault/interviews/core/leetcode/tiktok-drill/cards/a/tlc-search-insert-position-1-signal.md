## Q
**LC 35 搜索插入位置**｜Easy · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-02-18（面试记录）

给一个升序排列、没有重复元素的整数数组 `nums` 和目标值 `target`：找到就返回下标，找不到就返回它按顺序插入后应该在的下标。必须使用 `O(log n)` 的算法。`1 <= nums.length <= 10^4`，`-10^4 <= nums[i] <= 10^4`，`-10^4 <= target <= 10^4`。例：`nums = [1,3,5,6]`，`target = 2` → `1`；`target = 7` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「升序数组」+ 明确要求 `O(log n)` → 二分查找。
- 「不存在就返回插入位置」→ 要找的是**第一个大于等于 `target` 的下标**（下界，lower bound），找得到时它就是 `target` 的位置，找不到时它就是插入点，一个模板同时回答两种情形。
- 答案范围是 `[0, n]`：插到末尾时答案是 `n`，比合法下标多一个，所以右端点 `hi` 从 `len(nums)` 开始。
- `n <= 10^4`：线性扫描也能过，但题目明说要 `O(log n)`，目的是考二分的边界。

**推导链。**
1. 暴力：从左到右扫描找第一个 `>= target` 的元素，`O(n)`。
2. 浪费：数组有序，看一个元素本可以排除一大片，却没用上。
3. 洞察：判定「`nums[i] >= target`」在某个位置之后一直为真，具有单调性；看中点，小于 `target` 就整段左边丢掉，否则保留 `mid` 往左找。
4. 最优：半开区间 `[lo, hi)` 反复对半，`O(log n)` 时间、`O(1)` 空间。

**同模式的题**：LC 34 在排序数组中查找元素的第一个和最后一个位置、LC 704 二分查找、LC 278 第一个错误的版本、LC 69 x 的平方根。
