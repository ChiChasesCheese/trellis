## Q
**LC 179 最大数**｜正确性

为什么比较 `a + b` 与 `b + a` 排出来的顺序就是最优？这个比较会不会不满足传递性，导致排序结果不稳定？按字典序降序排会错在哪里？

## A
**不变量（交换论证）。** 取一个最优排列。若其中相邻的 `a`、`b` 满足 `b + a > a + b`，交换它们，整个拼接串在这两个位置的前后部分不变，中间那一段变大，整体严格变大，与「最优」矛盾。所以最优排列里每个相邻对都满足 `a + b >= b + a`。

**传递性。** 设 `a` 有 `p` 位、`b` 有 `q` 位。`a + b > b + a` ⇔ `a · 10^q + b > b · 10^p + a` ⇔ `a · (10^q − 1) > b · (10^p − 1)` ⇔ `a / (10^p − 1) > b / (10^q − 1)`。右边是一个实数（`a` 重复成无限循环小数 `0.aaa…`）。比较两个实数天然可传递，所以排序是良定义的，且相邻有序就等于全局有序。

**反例。** 按字符串字典序降序（`reverse=True`）：
- `[3,30]`：`"30"` 比 `"3"` 长，字典序更大（`"3"` 是 `"30"` 的前缀），排到前面，得 `"303"`；正确是 `"330"`。
- `[3,30,34,5,9]`：得 `"9534303"`，正确是 `"9534330"`。

**全零。** `[0,0]` 排完拼接是 `"00"`，不是合法的整数表示；应返回 `"0"`。排序后的第一个串是 `"0"`，当且仅当所有数都是 `0`。
