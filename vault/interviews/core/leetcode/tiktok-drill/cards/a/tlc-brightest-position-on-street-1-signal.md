## Q
**LC 2021 街上最亮的位置**｜Medium · LC TikTok 热度 53/100

数组 `lights`，`lights[i] = [position, range]` 表示该路灯照亮闭区间 `[position - range, position + range]`。位置 `p` 的亮度是能照到 `p` 的路灯数量。返回最亮的位置，有多个时取坐标最小的。

约束：`1 <= lights.length <= 10^5`，`-10^8 <= position <= 10^8`，`0 <= range <= 10^8`。例：`[[-3,2],[1,2],[3,3]]` → `-1`；`[[1,0],[0,1]]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「区间覆盖，找被覆盖次数最多的点」→ 差分数组 / 扫描线（sweep line）：区间 `[l, r]` 加一，等价于 `l` 处 `+1`、`r + 1` 处 `-1`。
- 坐标范围 `±2 * 10^8` → 不能开数组；亮度只在端点处变化 → 只处理事件坐标（离散化），排序后扫描。
- 「并列取最小坐标」→ 从小到大扫，严格更大才更新。
- `n = 10^5` → `O(n log n)` 排序即可，`O(n^2)` 不行。

**推导链。**
1. 暴力：对每个整点统计覆盖它的灯，范围太大；改成只试端点，`O(n^2)`。
2. 浪费：亮度在两个相邻事件坐标之间是常数，没必要逐点检查。
3. 洞察：差分把"区间加一"变成两个点事件，前缀和就是亮度；最大亮度首次出现的位置一定是某个事件坐标。
4. 最优：用字典累加同一坐标的事件，排序后一遍扫描，严格大于才更新，`O(n log n)`。
