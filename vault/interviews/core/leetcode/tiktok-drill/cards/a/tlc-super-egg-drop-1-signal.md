## Q
**LC 887 鸡蛋掉落**｜Hard · TikTok 高频

`k` 枚相同的鸡蛋，一栋 `n` 层的楼。存在楼层 `f`（`0 <= f <= n`），高于 `f` 的楼层扔下会碎，`f` 及以下不会。每次操作取一枚没碎的蛋从任一楼层扔下，碎了的蛋不能再用，没碎的可以重复用。求最坏情况下确定 `f` 的最少操作次数。`1 <= k <= 100`，`1 <= n <= 10^4`。例：`k = 2, n = 6` → `3`；`k = 3, n = 14` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**最坏情况**下的**最少**次数」→ 极小极大（minimax）的动态规划：每一步我选楼层，对手决定碎不碎，我取更坏的那种。
- 两个资源（蛋数、楼层数）+ 每次要选“扔哪层” → 状态 `(蛋, 楼层)`，转移要枚举 `x`。
- `k <= 100`、`n <= 10^4` → 状态数 `10^6`，再乘枚举 `n` 就是 `10^10`，必须去掉枚举。
- 蛋只有 `1` 枚时只能逐层扫，蛋不限时是二分，这两端提示答案随蛋数递减得很快。

**推导链。**
1. 暴力：`dp[e][f] = 1 + min_x max(dp[e-1][x-1], dp[e][f-x])`，`O(k n^2)`。
2. 改进：两个分支一个随 `x` 增、一个随 `x` 减，最优的 `x` 在交叉点，二分查找，`O(k n log n)`。
3. 换元：状态与目标互换，设 `f(m, k)` 为 `m` 次操作、`k` 枚蛋最多能确定的楼层数。
4. 转移：扔一次，碎了覆盖下面 `f(m-1, k-1)` 层，没碎覆盖上面 `f(m-1, k)` 层，加上这一层，`f(m, k) = f(m-1, k-1) + f(m-1, k) + 1`，`O(1)`，与具体扔哪层无关。
5. 逐步增加 `m`，第一个使 `f(m, k) >= n` 的 `m` 是答案。
