## Q
**LC 673 最长递增子序列的个数**｜Medium · CodeTop 国内累计 13 次 · 最近 2026-04-09（CodeTop）

给未排序的整数数组 `nums`，返回**最长严格递增子序列的个数**（子序列不要求连续）。`1 <= nums.length <= 2000`，`-10^6 <= nums[i] <= 10^6`。例：`[1,3,5,4,7]` → `2`（`[1,3,4,7]` 和 `[1,3,5,7]`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子序列」（不要求连续）+「严格递增」+「最长」→ **以每个位置结尾的一维 DP**，状态是 `length[i]`。
- 「求**个数**」→ 状态里再带一个方案数 `count[i]`，转移时按长度分「覆盖」和「累加」两种情况（counting DP）。
- `n <= 2000` → `O(n^2)` 的两层循环（约 `2 * 10^6` 次）可以过，不必上 `O(n log n)`。

**推导链。**
1. 暴力：枚举 `2^n` 个子序列，筛出递增的，统计最长者的个数，`O(2^n * n)`。
2. 浪费：不同子序列共享前缀。以 `i` 结尾的递增子序列，去掉末尾就是以某个 `j` 结尾的递增子序列。
3. 洞见：`length[i] = 1 + max(length[j])`（`nums[j] < nums[i]`）；`count[i]` 是所有让长度恰好等于 `length[i] - 1` 的 `j` 的 `count[j]` 之和。
4. 最优：双层循环填表，`O(n^2)`；答案是所有 `length[i]` 等于最大长度的位置的 `count[i]` 之和。
