## Q
**LC 114 二叉树展开为链表**｜Medium · 字节高频

给二叉树的根节点 `root`，原地把它展开成单链表：仍用 `TreeNode`，`right` 指向下一个节点，`left` 始终为 `null`，顺序与先序遍历相同。节点数在 `[0, 2000]`，`-100 <= Node.val <= 100`。进阶：`O(1)` 额外空间。例：`[1,2,5,3,4,null,6]` → `[1,null,2,null,3,null,4,null,5,null,6]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「展开成先序顺序的链表」→ 先序遍历（根、左、右）；链表的下一个节点就是先序的下一个节点。
- 「原地」「`O(1)` 空间」→ 不能存列表、不能用递归栈，需要沿树本身移动指针，是 Morris 遍历的思路：用「前驱节点」的空指针做连接。
- `n <= 2000`：深度可能到 `2000`，超过 Python 递归上限 `1000`；信号是「迭代」。

**推导链。**
1. 暴力：先序遍历收集所有节点到列表，再依次 `nodes[i].right = nodes[i + 1]`、`left = None`，`O(n)` 时间、`O(n)` 空间。
2. 浪费：额外列表只是为了记住顺序，而顺序其实藏在树的结构里：左子树整体排在右子树前面。
3. 洞察：对节点 `cur`，沿左孩子的右链走到头得到 `pred`，把 `cur` 的右子树接到 `pred.right`，再把左子树搬到 `cur.right`：先序序列不变，而 `cur` 的左指针清空了。
4. 然后沿 `right` 走到下一个节点重复，每个节点至多一次，`O(n)` 时间，`O(1)` 空间。

**同模式的题**：LC 430 扁平化多级双向链表、LC 426 二叉搜索树转双向链表、LC 94 / 144 的 Morris 遍历、LC 105 前序与中序构造二叉树。
