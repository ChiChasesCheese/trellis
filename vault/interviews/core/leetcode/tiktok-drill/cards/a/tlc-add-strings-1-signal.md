## Q
**LC 415 字符串相加**｜Easy · TikTok·字节 高频

给两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和，同样以字符串形式返回。不能使用任何内建的处理大整数的库，也不能直接把输入的字符串转换为整数。`1 <= num1.length, num2.length <= 10^4`，只包含数字 `0-9`，不含前导零。例：`num1 = "456"`，`num2 = "77"` → `"533"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「字符串形式的非负整数」+「不能转整数」→ **手工模拟竖式加法**：逐位相加，带进位。
- 加法进位是从低位向高位传的 → 从字符串**末尾**往前遍历。
- 两个数**长度不同** → 较短的数在高位补 `0`；Python 里用 `zip_longest(..., fillvalue="0")`。
- 长度到 `10^4`：`O(n)` 的一遍扫描足够；注意 Python 把整串转成整数默认最多 4300 位，`10^4` 位的输入会抛 `ValueError`。

**推导链。**
1. 暴力（违规）：`str(int(num1) + int(num2))`。题目禁止，而且 `10^4` 位会触到 Python 的转换位数上限。
2. 观察：竖式加法每一位只依赖该位的两个数字和上一位的进位，进位只能是 `0` 或 `1`。
3. 实现：反向遍历两个字符串，`carry, d = divmod(a + b + carry, 10)`，`d` 追加到结果，`carry` 带入下一位。
4. 收尾：循环结束后若还有进位，在最高位补 `1`；结果是低位在前，反转后拼成字符串。`O(max(m, n))` 时间。
