## Q
**LC 4 寻找两个正序数组的中位数**｜正确性

切割法里，为什么「`a_left <= b_right` 且 `b_left <= a_right`」就保证左半的每个数都不大于右半的每个数？为什么必须在较短的数组上二分，`half` 为什么是 `(m + n + 1) // 2`？

## A
**不变量。** 一次切法把 `a` 切成 `a[:i] | a[i:]`，把 `b` 切成 `b[:j] | b[j:]`，且 `i + j = half`。左半是 `a[:i]` 和 `b[:j]` 的并集，右半是剩下的。每个数组内部已有序，所以 `a[:i]` 的最大值是 `a_left`，`b[:j]` 的最大值是 `b_left`，右半的最小值是 `min(a_right, b_right)`。`a_left <= a_right` 与 `b_left <= b_right` 由有序性自动成立，再加上两个交叉条件，就得到「左半最大值 <= 右半最小值」。此时左半恰是全体中最小的 `half` 个数，中位数由边界值给出。

**为什么在较短数组上二分。** `j = half - i`。若 `m <= n`，当 `0 <= i <= m` 时，`j` 在 `[half - m, half]` 内，并且 `half - m >= 0`、`half <= n`，所以 `j` 一定落在 `[0, n]`。若在较长的数组上二分，`j` 可能是负数，或者超过另一个数组的长度。

**为什么 `half = (m + n + 1) // 2`。** 总数为奇数时，中位数是第 `(m + n + 1) / 2` 个，它必须属于左半，所以左半要多一个；总数为偶数时，`(m + n + 1) // 2` 等于 `(m + n) / 2`，左右等长。

**反例。**
- 在较长数组上二分：`nums1 = [1,2,3,4,5,6]`，`nums2 = [7,8]`，不交换直接对 `nums1` 二分，得到 `5.5`；正确答案是 `4.5`（合并为 `[1,…,8]`，中间两个是 `4` 和 `5`）。
- `half = (m + n) // 2`：`[1,3]` 与 `[2]` 总数为 `3`，左半只取到 `1` 个元素，中位数被算成 `1.0`；正确是 `2.0`。
