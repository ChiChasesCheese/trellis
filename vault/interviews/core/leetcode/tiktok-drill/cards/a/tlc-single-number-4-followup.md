## Q
**LC 136 只出现一次的数字**｜追问

面试官接着问：（1）其余每个数出现**三次**，只有一个出现一次，还是线性时间常数空间，怎么做？（2）恰好有**两个**数只出现一次呢？（3）如果不让用位运算，退一步怎么做？

## A
1. **出现三次（LC 137）**：异或不再抵消。改成统计每一位上 1 的个数，对 3 取模：其余数每位的 1 的个数都是 3 的倍数，模 3 后剩下的就是落单数这一位。
```python
def single_number_ii(nums: list[int]) -> int:
    ans = 0
    for bit in range(32):
        cnt = sum((x >> bit) & 1 for x in nums) % 3
        ans |= cnt << bit
    return ans - (1 << 32) if ans >= 1 << 31 else ans   # 第 31 位为 1 说明是负数，按补码还原
```
`[2,2,3,2]` 和 `[0,1,0,1,0,1,99]` 分别得 `3` 和 `99`，`[-5,2,2,2]` 得 `-5`。
2. **两个落单（LC 260）**：先全部异或得到 `a ^ b`，取其中一个为 1 的位把数组分成两组，每组各含一个落单数，再各自异或。见 LC 260。
3. **不用位运算**：`2 * sum(set(nums)) - sum(nums)`：去重后的和的两倍减去原和，正好剩下落单数；代价是 `set` 的 `O(n)` 空间，要向面试官说明违反常数空间。

**Python 提醒**：Python 的整数没有固定宽度，负数的 `x >> bit` 会无限符号扩展；做"按固定 32 位计数"时，只取 `range(32)`，最后用 `ans - (1 << 32)` 手动还原负数，而不是像 C++ 那样靠 `int` 自动溢出。
