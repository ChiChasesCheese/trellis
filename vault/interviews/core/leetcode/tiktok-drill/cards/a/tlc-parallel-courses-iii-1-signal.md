## Q
**LC 2050 并行课程 III**｜Hard · 近一年被问：美国 15 次、国内 4 次 · 最近 2026-10-15（面试记录）

`n` 门课（编号 `1` 到 `n`），`relations[j] = [prev, next]` 表示课程 `prev` 必须在 `next` 之前完成，`time[i]` 是第 `i + 1` 门课所需月数。先修课都完成后可以随时开始一门课，可以同时上任意多门课。返回完成所有课程所需的最少月数（保证是 DAG）。`1 <= n <= 5 * 10^4`，`relations.length <= 5 * 10^4`，`1 <= time[i] <= 10^4`。例：`n = 3`，`relations = [[1,3],[2,3]]`，`time = [3,2,5]` → `8`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「先修关系」+「保证无环」→ **拓扑排序**（DAG）。
- 「可以同时上任意多门课」→ 没有资源限制，总时间 = 依赖链上时间之和的最大值，即**关键路径**（带点权的最长路径）。
- `n`、`m` 到 `5 * 10^4` → `O(n + m)`；依赖链可达 `5 * 10^4`，递归记忆化会爆栈，用 Kahn 迭代算法。

**推导链。**
1. 暴力：枚举所有起点到终点的路径取最长，路径条数指数级。
2. DFS 记忆化：`finish[v] = time[v] + max(finish[p])`，每门课只算一次，`O(n + m)`，但深链上递归过深。
3. Kahn：入度为 `0` 的课先出队；一门课出队时，所有先修课都已出队，它的 `start` 是确定的最大值。
4. 出队时 `finish = start[u] + time[u]`，推高每个后继的 `start`，后继入度归零时入队。答案是所有 `finish` 的最大值，`O(n + m)`。

**同模式的题**：LC 207 / 210 课程表、LC 1136 并行课程、LC 1857 有向图中最大颜色值、LC 310 最小高度树。
