## Q
**LC 380 O(1) 时间插入、删除和获取随机元素**｜Medium · LC TikTok 热度 62/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 15 次 · 最近 2026-10-08（面试记录）

实现 `RandomizedSet`：`insert(val)` 不存在才插入并返回是否成功，`remove(val)` 存在才删除并返回是否成功，`getRandom()` 等概率返回现有的一个元素；每个操作平均 `O(1)`。`-2^31 <= val <= 2^31 - 1`，最多调用 `2 * 10^5` 次，调用 `getRandom` 时至少有一个元素。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「平均 `O(1)` 的增、删、查」→ **哈希表**（值 → 位置）。
- 「`O(1)` 等概率随机取」→ 必须能**按下标**访问元素 → **动态数组**；`set` / `dict` 无法在 `O(1)` 内随机取。
- 两个要求互相打架：数组删中间元素是 `O(n)`。化解办法是**与末尾元素交换后弹出末尾**：删除变成 `O(1)`。
- 「设计 + 全部 `O(1)`」→ 组合两个结构，并保证它们**同步更新**（交换时同步更新字典里的下标）。
- 元素无序、不要求保序 → 允许把末尾元素搬到别处。

**推导链。**
1. 暴力：只用 `set`，`getRandom` 要转列表 `O(n)`；只用列表，`insert` 判重和 `remove` 找位置都是 `O(n)`。
2. 浪费：两种结构各解决一半需求，各自的短板是另一半。
3. 洞察：列表 + 字典同时存；删除时用末尾元素补位，弹出末尾，补位元素的下标同步更新。
4. 最优：三个操作均摊 `O(1)`，空间 `O(n)`。

**同模式的题**：LC 381 允许重复、LC 146 LRU 缓存、LC 460 LFU 缓存、LC 432 全 O(1) 的数据结构、LC 528 按权重随机选择。
