## Q
**LC 958 二叉树的完全性检验**｜Medium · 字节高频

给二叉树的根节点 `root`，判断它是不是**完全二叉树**：除最后一层外所有层都填满，且最后一层的节点都尽可能靠左。树中节点数在 `[1, 100]`，`1 <= Node.val <= 1000`。例：`[1,2,3,4,5,6]` → `true`；`[1,2,3,4,5,null,7]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「完全」「靠左」「每一层」→ 这些都是按**层、按从左到右的顺序**定义的性质 → 层序遍历（BFS，广度优先）。
- 完全二叉树按层序排成一列后，真实节点连成一段、空位全在末尾 → 判定变成「空位之后不能再有节点」，一个布尔标志就够。
- `n <= 100`：任何线性解都行，关键是把定义翻译成层序序列的性质，不是卡复杂度。

**推导链。**
1. 暴力：算出树高 `h`，检查前 `h - 1` 层每层节点数是 `2^k`，再检查最后一层的节点是不是挤在最左边。要逐层计数还要处理最后一层的位置，分支多、容易漏。
2. 浪费：「最后一层靠左」「前面层全满」其实是同一件事——层序序列里没有空洞。
3. 洞察：把空孩子也放进 BFS 队列，出队序列形如「节点…节点, 空…空」才是完全二叉树；一旦见过空位，之后再见到真实节点就失败。
4. 每个节点和它的空孩子各处理一次，`O(n)` 时间。

**同模式的题**：LC 102 层序遍历、LC 222 完全二叉树的节点个数、LC 919 完全二叉树插入器、LC 662 二叉树最大宽度。
