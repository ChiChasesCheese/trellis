## Q
**LC 162 寻找峰值**｜Medium · TikTok·字节 高频

峰值元素是严格大于左右相邻值的元素。给整数数组 `nums`，找到一个峰值元素并返回其下标；数组可能有多个峰值，返回**任意一个**即可。假设 `nums[-1] = nums[n] = -∞`（两端之外视为负无穷）。必须设计 `O(log n)` 的算法。

约束：`1 <= nums.length <= 1000`，`-2^31 <= nums[i] <= 2^31 - 1`，对所有有效的 `i` 都有 `nums[i] != nums[i + 1]`。

例：`nums = [1,2,3,1]` → `2`；`nums = [1,2,1,3,5,6,4]` → `1` 或 `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 要求 `O(log n)` 但数组**无序** → 二分的依据不是全局有序，而是「判断一侧一定存在答案」的**局部性质**。
- 「找任意一个峰值」+「相邻不相等」+「两端视为 `-∞`」→ 沿着上坡走一定能爬到峰；沿着下坡往回看一定有峰。
- `n ≤ 1000` 小，暴力 `O(n)` 也能过；题目明确要 `O(log n)`，考察的是你能否识别出二分的不变量。

**推导链。**
1. 暴力：线性扫描，找第一个满足 `nums[i] > nums[i+1]` 的位置，`O(n)`（也可以直接取全局最大值）。
2. 要 `O(log n)`：只能每步排除一半，需要一个「哪一半必有峰」的判据。
3. 洞察：比较 `nums[mid]` 与 `nums[mid+1]`——上坡（`<`）则右半一定有峰，下坡则左半（含 `mid`）一定有峰，理由都是边界为 `-∞`。
4. 最优：`lo < hi` 的二分，上坡 `lo = mid + 1`，下坡 `hi = mid`，收缩到一个点，`O(log n)`。
