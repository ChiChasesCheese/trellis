## Q
**LC 88 合并两个有序数组**｜Easy · 近一年被问：美国 0 次、国内 6 次 · CodeTop 国内累计 97 次 · 最近 2026-10-18（面试记录）

给两个按非递减顺序排列的整数数组 `nums1` 和 `nums2`，以及整数 `m`、`n`，分别表示它们的有效元素个数。把 `nums2` 合并到 `nums1` 中，使合并后的数组同样非递减，结果存放在 `nums1` 里：`nums1` 长度是 `m + n`，前 `m` 个有效，后 `n` 个是占位的 `0`。`0 <= m, n <= 200`，`1 <= m + n <= 200`，`-10^9 <= nums1[i], nums2[j] <= 10^9`。例：`nums1 = [1,2,3,0,0,0]`，`m = 3`，`nums2 = [2,5,6]`，`n = 3` → `[1,2,2,3,5,6]`。进阶：`O(m + n)` 时间。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个**有序**数组合并」→ **归并**的双指针：每次比较两个队头，取较小（或较大）的。
- 「结果放进 `nums1`」且「空位在 `nums1` 的**尾部**」→ **从后往前填**：最大的元素放最后一格，不会覆盖未读的有效元素。
- `m + n <= 200`：任何做法都够快；考点是原地和 `O(m + n)`，而不是性能。

**推导链。**
1. 暴力：把 `nums2` 拷到 `nums1` 尾部再整体排序，`O((m + n) log(m + n))`，没利用有序。
2. 辅助数组归并：`O(m + n)` 时间，多 `O(m)` 空间。
3. 原地从前往后归并会出错：写入位置会追上读取位置，覆盖 `nums1` 里还没读的元素。
4. 洞察：从后往前写。写入位置 `k = i + j + 1 >= i`，写到的格子只会是空位或已经读走的元素。每次取两个末尾中较大的放进 `k`，`nums2` 放完即可停（`nums1` 的剩余本来就在原位）。`O(m + n)` 时间，`O(1)` 空间。
