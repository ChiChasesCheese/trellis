## Q
**LC 1131 绝对值表达式的最大值**｜正确性

为什么「绝对值之和的最大值」等于「各种符号组合下 `max f - min f` 的最大值」？为什么只需要 `4` 种符号组合而不是 `8` 种？只用一种组合会错在哪？

## A
**等式为什么成立。** 对任意实数 `x`，`|x| = max(x, -x)`；三个绝对值相加 `|x| + |y| + |z| = max(x, -x) + max(y, -y) + max(z, -z)`，等于对三项各自选一个符号后的和的最大值，即 `max over s1,s2,s3 of (s1 x + s2 y + s3 z)`。再对所有 `(i, j)` 取最大，最大和最大可以交换顺序：先固定符号，求 `max over (i,j)`，再对符号取最大。

**固定符号后为什么是 `max - min`。** 取 `x = a_i - a_j`、`y = b_i - b_j`、`z = i - j`，则 `s1 x + s2 y + s3 z = f(i) - f(j)`，其中 `f(t) = s1 a_t + s2 b_t + s3 t`。`i` 和 `j` 相互独立地取值（允许相等），最大差就是 `max f - min f`。

**为什么 `4` 种够。** 符号 `(s1, s2, s3)` 与 `(-s1, -s2, -s3)` 对应的函数互为相反数：`f' = -f`。`max f' - min f' = -min f - (-max f) = max f - min f`，结果相同，所以每对互为相反的组合只需算一个。固定 `s3 = +1`，剩下的 `(s1, s2)` 有 `4` 种。

**反例：只用一种组合 `(+, +)`。**
- `arr1 = [1,-2,-5,0,10]`、`arr2 = [0,-2,-1,-7,-4]`：`f = arr1 + arr2 + i` 为 `[1, -3, -4, -4, 10]`，`max - min = 14`，正确答案是 `20`；
- `arr1 = [-1,0]`、`arr2 = [0,-1]`：`f = [-1, 0]`，`max - min = 1`；真实值 `|−1−0| + |0−(−1)| + |0−1| = 3`，正确答案 `3`。
最大值取决于两个数组各自是「同向」还是「反向」贡献，必须四种符号都试。
