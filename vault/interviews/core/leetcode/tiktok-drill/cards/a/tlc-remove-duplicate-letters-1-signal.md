## Q
**LC 316 去除重复字母**｜Medium · TikTok·字节 高频

给字符串 `s`，去除重复字母，使每个字母只出现一次，并保证结果字典序最小；不能打乱其余字符的相对顺序。`1 <= s.length <= 10^4`，`s` 由小写英文字母组成。例：`"cbacdcbc"` → `"acdb"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「保持相对顺序」=结果是原串的**子序列**；「字典序最小」=前面的字符要尽量小 → 贪心加单调栈（monotonic stack）。
- 「每个字母恰好一次」→ 需要知道每个字母**后面是否还会出现**（最后出现位置）和**是否已经在结果里**。
- 字母只有 26 种，`n <= 10^4`：线性扫描即可，空间 `O(26)`。

**推导链。**
1. 暴力：枚举所有恰好包含每种字母一次的子序列，取字典序最小，指数级。
2. 浪费：字典序先比前面的字符，大部分子序列从第一位就输了。
3. 洞察：扫描到字母 `c` 时，若栈顶 `t > c` 且 `t` 在后面还会出现，弹掉 `t` 让 `c` 靠前，`t` 之后还能放回；若 `t` 不再出现就不能弹。
4. 已在栈中的字母跳过：它先前放的位置不会更差。每个字符至多进出栈一次，`O(n)`。
