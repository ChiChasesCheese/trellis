## Q
**LC 234 回文链表**｜Easy · CodeTop 国内累计 26 次 · 最近 2026-09-09（CodeTop）

给单链表的头节点 `head`，判断它是否是回文链表。节点数在 `[1, 10^5]`，`0 <= Node.val <= 9`。进阶：`O(n)` 时间、`O(1)` 空间。例：`[1,2,2,1]` → `true`；`[1,2]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「回文」→ 两端同时向中间比较（对撞双指针）；单链表不能倒着走，需要让后半段**反转**后才能从尾向前读。
- 「中点」→ 快慢指针（快指针每次两步，慢指针每次一步，快指针到头时慢指针在中点）。
- 进阶「`O(1)` 空间」→ 不能复制数组、不能递归（栈深 `n`，`10^5` 在 Python 里会超限），只能原地改链表。
- `n` 到 `10^5`：`O(n)` 是上限，`O(n^2)` 不行。

**推导链。**
1. 暴力：值复制进数组，判断 `vals == vals[::-1]`，`O(n)` 时间、`O(n)` 空间。
2. 浪费：额外数组只是为了能"倒着读"；链表本身可以改成倒着读。
3. 洞察：快慢指针找中点 → 反转后半段 → 两个指针分别从头和反转后的尾出发，一起走比较。
4. 比较完再反转一次还原，不污染输入；总共线性时间、常数空间。
