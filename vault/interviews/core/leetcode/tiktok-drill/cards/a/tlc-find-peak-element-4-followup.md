## Q
**LC 162 寻找峰值**｜追问

面试官接着问：（1）如果允许相邻元素相等？（2）二维矩阵里找峰值？（3）想把整个数组所有峰值都找出来？

## A
1. **允许相等**：遇到 `nums[mid] == nums[mid + 1]` 就无法判断该往哪边走（平台两侧都可能有峰），二分的前提被破坏。最坏要退化成线性扫描：`[1,1,1,...,1,2,1,...]` 里峰的位置可能在任何地方。面试里要说清「相邻不相等」这个前提为什么重要。
2. **二维峰值（LC 1901）**：取中间一列，找到该列的最大值（行号 `r`）；与左右邻居比较，比它大的一侧一定存在峰，往那一侧缩小列范围；每次把列区间减半，每步 `O(m)`，总 `O(m log n)`。不变量与一维完全一样。
3. **所有峰值**：峰值之间没有结构可利用，只能 `O(n)` 扫描：`[i for i in range(n) if (i == 0 or nums[i] > nums[i-1]) and (i == n-1 or nums[i] > nums[i+1])]`。

**对比** 二分只保证找到「一个」峰，且依赖「相邻不相等」；线性扫描没有前提，但 `O(n)`。

**Python 提醒**：`bisect` 的 `key` 参数是 Python 3.10 才有的，之前版本要手写二分。`bisect_left(range(n - 1), True, key=...)` 里的谓词「是否下坡」并不整体单调（下坡之后可能又上坡），`bisect` 仍会停在某个「前一个是上坡、这一个是下坡」的位置——它是一个峰，但不保证是第一个，对「任意一个峰」的要求足够。
