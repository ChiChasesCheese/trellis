## Q
**LC 567 字符串的排列**｜正确性

为什么「26 个字母的个数全部一致」就等价于「窗口是 `s1` 的排列」？为什么不能只比较字符集合，或者字符码之和？

## A
**不变量。** 每次检查 `diff` 时，`cnt[c]` 恰好等于 `s1` 中 `c` 的个数减去当前窗口中 `c` 的个数，`diff` 恰好是 `cnt` 中非零项的个数；窗口长度始终等于 `len(s1)`。

**为什么等价。** 排列只改变顺序、不改变每个字符的个数。窗口长度与 `s1` 相同，且每个字母的个数都相同，那么窗口就是 `s1` 的某个排列；反之亦然。

**反例一：只比较集合。** `s1 = "aab"`，`s2 = "abbcc"`：
- 窗口 `"abb"` 的字符集合 `{a, b}` 与 `s1` 相同，集合版本返回 `True`。
- 但 `s1` 有两个 `a`、一个 `b`，窗口有一个 `a`、两个 `b`，不是排列，正确是 `False`。

**反例二：字符码之和。** `s1 = "ad"`，`s2 = "bc"`：`97 + 100 = 197 = 98 + 99`，和相同，但字母完全不同，之和版本返回 `True`，正确是 `False`。

**为什么 `diff` 的更新是对的。** 对每个被改动的字母 `k`，先减去它改前是否非零（`cnt[k] != 0`），改完再加上改后是否非零；`diff` 因此始终等于非零项数量。同一个字母既进又出（相邻窗口里同一个字符）时，两次更新依次进行，结果仍然正确。
