## Q
**有序数组中出现次数超过 n/3 的数**｜Medium · TikTok 高频

给长度 `n >= 3` 的非递减有序整数数组，找出所有出现次数大于 `n / 3` 的数字，升序返回，要求时间复杂度低于 `O(n)`。`3 <= n <= 10^6`。例：`[1,1,2,4,4]` → `[1,4]`；`[1,2,3]` → `[]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「有序数组 + 某个值出现几次」→ `bisect_left` / `bisect_right` 两次二分，`O(log n)`。
- 「出现次数大于 `n/3`」→ 答案最多 `2` 个（三个值各超过 `n/3` 总数就超过 `n`），而且每个都是一整段连续的长块。
- 「复杂度低于 `O(n)`」→ 不能读完全部元素，只能抽样几个位置，再用二分验证。
- `n = 10^6`：`O(n)` 的 `Counter` 能过，但题目明确要求利用有序性做得更快。

**推导链。**
1. 暴力：`Counter` 数一遍，`O(n)` 时间、`O(n)` 空间。
2. 利用有序：相同值相邻，一遍扫描统计每段长度，`O(n)` 时间、`O(1)` 空间，仍要读完所有元素。
3. 浪费：为了找出几个很长的块，把每个元素都读了一遍。
4. 洞察：次数大于 `n/3` 即至少 `step + 1` 次（`step = n // 3`）；任意 `step + 1` 个连续下标必含 `step` 的倍数，所以长块一定覆盖下标 `0, step, 2*step, ...` 中的某一个。
5. 最优：候选值只有这些下标上的值，常数个；对每个候选用两次二分数出现次数，`3 * 次数 > n` 才保留。`O(log n)`。

**同模式的题**：LC 229 多数元素 II、LC 169 多数元素、LC 34 在排序数组中查找元素的第一个和最后一个位置、LC 1150 检查数字是否为排序数组中的多数元素。
