## Q
**LC 134 加油站**｜Medium · TikTok 高频

环形路线上有 `n` 个加油站，第 `i` 个站有汽油 `gas[i]` 升；从第 `i` 站开往第 `i + 1` 站耗油 `cost[i]` 升（最后一站开往第 `0` 站）。油箱容量无限，出发时为空。若能绕环路行驶一周，返回出发的站编号，否则返回 `-1`；若有解则唯一。`1 <= n <= 10^5`，`0 <= gas[i], cost[i] <= 10^4`。例：`gas = [1,2,3,4,5]`，`cost = [3,4,5,1,2]` → `3`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「环形」+「油量不能为负」+「找起点」→ **前缀和加贪心**：把每站化成净油量 `gas[i] - cost[i]`，问题变成找一个起点使所有前缀和不为负。
- 「答案唯一」→ 允许一个确定性的贪心给出那个位置。
- `n = 10^5` → 逐个起点绕一圈 `O(n^2)` 约 `10^10`，超时，目标 `O(n)`。
- 总油量的判断：总净油量 `< 0` 必无解。

**推导链。**
1. 暴力：每个起点模拟一圈，`O(n^2)`。
2. 观察一：总净油量 `>= 0` 才可能有解。
3. 观察二：从 `start` 出发在第 `i` 站首次油量为负，则 `start..i` 中任何站作为起点都会失败：到达中间站 `k` 时，从 `start` 带过来的油量 `>= 0`，从 `k` 空手出发只会更少。
4. 所以失败后一次性跳到 `i + 1` 作为新起点，`tank` 清零；每站只扫描一次。
5. 扫描结束，`total >= 0` 则返回最后一次重置的 `start`，否则 `-1`；`O(n)` 时间，`O(1)` 空间。
