## Q
**LC 409 最长回文串**｜正确性

为什么「每种字母取 `v // 2 * 2` 个，有剩余再加 1」一定最长？常见的两种错误写法错在哪？

## A
**结构。** 回文串去掉中心后左右镜像，每个字母在两侧出现次数相同，所以中心以外每种字母用的个数必须是偶数；中心至多一个字母。

**最优性。** 每种字母用 `v // 2 * 2` 个已是它能贡献的最大偶数；中心位置能放就放，只多不少。只要某种字母是奇数次，`pairs` 就小于 `len(s)`，就有一个落单字母可放中间。

**反例 1：偶数全加、奇数只取最大的一种。** `"aaabbbcc"`（`a:3, b:3, c:2`）：这种写法得 `2 + 3 = 5`；其实 `a`、`b` 各能用 2 个，`2 + 2 + 2 + 1 = 7`，如 `"abcacba"`。

**反例 2：每个奇数次字母都加 1。** `"abc"`：错成 `3`；正中间只有一个位置，正确答案 `1`。
