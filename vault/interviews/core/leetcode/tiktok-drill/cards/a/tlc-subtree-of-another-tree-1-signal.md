## Q
**LC 572 另一个树的子树**｜Easy · 字节高频

给两棵二叉树 `root` 和 `subRoot`，判断 `root` 中是否存在一棵子树，结构和节点值都与 `subRoot` 完全相同；子树指某个节点连同它的全部后代，`root` 自己也算。`root` 的节点数在 `[1, 2000]`，`subRoot` 的节点数在 `[1, 1000]`，节点值在 `[-10^4, 10^4]`。例：`root = [3,4,5,1,2]`、`subRoot = [4,1,2]` → `true`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`root` 里有没有和 `subRoot` 一样的子树」→ **子结构匹配**：每个候选节点做一次「两棵树是否完全相同」的比较（LC 100）。
- 「结构和值都要相同，且必须到叶子为止」→ 树可以压成带空位记号的先序序列，匹配变成字符串子串问题。
- `m <= 2000`、`n <= 1000`：`O(m·n)` 约 `2 * 10^6` 可以过；但 `root` 深度可达 `2000`，Python 递归会超限，信号是「用显式栈或序列化」。

**推导链。**
1. 暴力：对 `root` 的每个节点，判断以它为根的子树是否与 `subRoot` 完全相同，最坏 `O(m·n)`。
2. 浪费：每个候选都从头比较，没有利用「相同树的先序序列相同」。
3. 洞察：带空位记号（`#`）的先序序列唯一确定一棵树；于是 `subRoot` 的序列是 `root` 序列的**子串**，当且仅当存在匹配的子树。
4. 细节：值前加逗号避免 `"12"` 匹配 `"2"`；用迭代先序避免深度超限；子串判断用 `in`，`O(m + n)`。

**同模式的题**：LC 100 相同的树、LC 652 寻找重复的子树、LC 297 二叉树的序列化与反序列化、LC 1367 链表中的二叉树路径。
