## Q
**LC 525 连续数组**｜正确性

前缀和解法里，字典为什么只能记每个 `bal` 值**第一次**出现的下标？为什么要预置 `{0: -1}`？各给一个出错的输入。

## A
**不变量。** 处理到下标 `i` 时，`first[v]` 是前缀差值 `v` 最早出现的位置（空前缀算位置 `-1`）。以 `i` 结尾的合法子数组，左边界前一位必须是某个 `bal` 与 `bal[i]` 相等的位置；离 `i` 越远子数组越长，所以要的正是**最早**那个位置。

**只记第一次。** 若每次都覆盖成最新下标，字典里就只剩「最近一次」，得到的是以 `i` 结尾的**最短**合法子数组。反例 `[0,1,0,1]`：`bal` 依次为 `-1, 0, -1, 0`。覆盖写法在下标 3 查到 `first[0] = 1`，长度 `2`；正确写法查到 `first[0] = -1`，长度 `4`。

**预置 `{0: -1}`。** 空前缀的 `bal` 是 0，位置在第一个元素之前。不预置时，从下标 0 开始的子数组没有左边界可配：`[0,1]` 会得到 `0`，正确是 `2`。
