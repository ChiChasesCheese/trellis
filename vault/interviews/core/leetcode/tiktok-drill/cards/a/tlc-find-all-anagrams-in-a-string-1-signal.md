## Q
**LC 438 找到字符串中所有字母异位词**｜Medium · TikTok 高频

给两个字符串 `s` 和 `p`，找出 `s` 中所有是 `p` 的**异位词**（字母相同、次序可以不同）的子串，返回这些子串的起始下标，顺序任意。

约束：`1 <= s.length, p.length <= 3 * 10^4`，`s` 和 `p` 只含小写字母。

例：`s = "cbaebabacd", p = "abc"` → `[0, 6]`（`"cba"` 和 `"bac"`）；`s = "abab", p = "ab"` → `[0, 1, 2]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子串」+「异位词 / 排列」→ 只关心字母多重集，与顺序无关，窗口里维护**计数**即可。
- 要找的子串长度**固定**等于 `len(p)` → 定长滑动窗口：一进一出，不需要「扩右缩左」的 `while`。
- `n` 到 `3·10^4`、字符集只有 26 个小写字母 → 目标 `O(n)`，计数表大小是常数；对每个窗口排序（`O(n·m log m)`）会太慢。

**推导链。**
1. 暴力：每个起点取 `s[i:i+m]`，排序后与 `sorted(p)` 比较，`O(n·m log m)`。
2. 改进：用计数代替排序，`Counter(window) == Counter(p)`，`O(n·m)`；但相邻窗口只差一进一出，却整个重数。
3. 洞察：窗口右移时只有两个字母的计数变化，增量更新；比较两张表是 `O(Σ)`，再用「计数不为 0 的字母种数」把判断变成 `O(1)`。
4. 最优：`need` 记还缺的字母数，`unbalanced` 记不平衡的种数，右进左出，`unbalanced == 0` 时记录起点，`O(n)`。

**同模式的题**：LC 567 字符串的排列、LC 76 最小覆盖子串、LC 30 串联所有单词的子串、LC 242 有效的字母异位词。
