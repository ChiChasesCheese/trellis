## Q
**LC 50 Pow(x, n)**｜Medium · 字节高频｜写出 Python 实现

计算 `x^n`：`-100.0 < x < 100.0`，`-2^31 <= n <= 2^31 - 1`，要么 `x != 0` 要么 `n > 0`，结果在 `[-10^4, 10^4]`。要求 `O(log n)`，用迭代，不用内置 `**` 和 `pow`。

## A
**思路。** 负指数先换成 `(1 / x)^(-n)`。然后把 `n` 当二进制数从低位扫到高位：当前位是 1 就把当前底数乘进 `result`，每轮底数平方、`n` 右移一位。循环不变量：答案始终等于 `result * x^n`。

```python
def my_pow(x: float, n: int) -> float:
    if n < 0:                      # x^-n = (1/x)^n，先把指数变成非负
        x, n = 1 / x, -n
    result = 1.0
    while n:                       # 不变量：答案 = result * x^n
        if n & 1:                  # 当前二进制位为 1：把这一份 x 乘进结果
            result *= x
        x *= x                     # 底数平方，对应下一个二进制位
        n >>= 1
    return result
```

运行：`my_pow(2.0, 10)` → `1024.0`，`my_pow(2.1, 3)` → `9.261000000000001`，`my_pow(2.0, -2)` → `0.25`，`my_pow(2.0, 0)` → `1.0`，`my_pow(1.0, -2**31)` → `1.0`，`my_pow(-1.0, 2**31 - 1)` → `-1.0`。

**复杂度。** 时间 `O(log |n|)`：`n` 每轮右移一位，至多 32 轮；空间 `O(1)`。

**写法要点。** `x, n = 1 / x, -n` 元组赋值，一行完成「取倒数 + 取绝对值」；`while n:` 用整数真值判断结束；`n & 1` 和 `n >>= 1` 是位运算，比 `n % 2`、`n //= 2` 意图更直接；迭代版没有递归栈，也不会碰 Python 的递归深度上限。
