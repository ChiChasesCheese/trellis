## Q
**LC 409 最长回文串**｜Easy · CodeTop 国内累计 3 次 · 最近 2026-01-15（CodeTop）

字符串 `s` 只含大写和小写英文字母。用 `s` 里的字母（每个字母最多用一次，顺序可任意重排）构造回文串，返回最长回文串的长度。**区分大小写**：`"Aa"` 不是回文。`1 <= s.length <= 2000`。例：`"abccccdd"` → `7`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「用这些字母**构造**」→ 顺序可以重排，只关心每种字母的**个数** → `Counter` 计数。
- 「回文」→ 结构是「成对字母对称排列 + 中间至多一个」→ 贪心：成对能用就用。
- 「区分大小写」→ `'A'` 与 `'a'` 是不同的键，直接计数，不要转小写。
- `n <= 2000` 很小，但 `O(n)` 的计数解法是最直接的。

**推导链。**
1. 暴力：枚举字母子集并判断能否排成回文，`O(2^n)`。
2. 浪费：能否排成回文只取决于计数，不取决于选了哪几个位置。
3. 关键：回文里至多一种字母出现奇数次；每种字母最多用 `v // 2 * 2` 个放两侧。
4. 最优：对数之和，若还有剩余字母再加 1，`O(n)`。

**同模式的题**：LC 266 回文排列、LC 2131 连接两字母单词得到的最长回文串、LC 1400 构造 K 个回文字符串。
