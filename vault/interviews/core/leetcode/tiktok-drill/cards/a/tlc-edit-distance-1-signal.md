## Q
**LC 72 编辑距离**｜Medium · TikTok·字节 高频

给两个单词 `word1` 和 `word2`，返回把 `word1` 转换成 `word2` 所需的最少操作数。每次操作可以插入一个字符、删除一个字符、替换一个字符。`0 <= word1.length, word2.length <= 500`，两个单词都由小写英文字母组成。例：`word1 = "horse"`，`word2 = "ros"` → `3`；`word1 = "intention"`，`word2 = "execution"` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**两个字符串**」+「把一个变成另一个的**最少**操作数」→ **序列对齐型动态规划**，状态是两个前缀长度 `(i, j)`，与最长公共子序列同一家族。
- 三种操作都作用在**末尾** → 每个操作把问题缩小成更短前缀的子问题，天然满足最优子结构。
- `m, n <= 500`：`O(m · n) = 25 万` 个状态很轻松；指数级递归不行。

**推导链。**
1. 暴力：递归比较末尾字符，不同时三种操作都试，`O(3^(m+n))`。
2. 浪费：子问题 `(i, j)` 反复出现，真正不同的状态只有 `(m+1)(n+1)` 个。
3. 洞察：末尾相同则不用操作，退到 `(i-1, j-1)`；不同则 `1 +` 替换 `(i-1, j-1)`、删除 `(i-1, j)`、插入 `(i, j-1)` 三者的最小值。边界 `dp[i][0] = i`，`dp[0][j] = j`。
4. 最优：自底向上逐行填完 `(m+1) × (n+1)` 的表，`O(m · n)` 时间和空间，答案是 `dp[m][n]`。

**同模式的题**：LC 1143 最长公共子序列、LC 583 两个字符串的删除操作、LC 712 两个字符串的最小 ASCII 删除和、LC 115 不同的子序列、LC 97 交错字符串。
