## Q
**LC 543 二叉树的直径**｜Easy · 近一年被问：美国 1 次、国内 1 次 · CodeTop 国内累计 36 次 · 最近 2026-08-19（面试记录）

给一棵二叉树的根节点，返回树的直径：任意两个节点之间最长路径的长度，路径可以不经过根，长度用边数表示。

约束：节点数在 `[1, 10^4]`，`-100 <= Node.val <= 100`。例：`[1,2,3,4,5]` → `3`；`[1,2]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「树中任意两点之间的最长路径」→ 每条路径有唯一的最高点；枚举最高点，路径长 = 左子树深度 + 右子树深度（树形 DP / 后序）。
- 「可能不经过根」→ 必须对每个节点都更新一次全局答案，不能只看根。
- 「边数」→ 深度按节点数计时，`左高 + 右高` 恰好是边数；若按边数计深度，则要 `+ 2`。
- 节点数 `10^4`，链状树深度到 `10^4` → 递归会超 Python 默认 1000 层，需要迭代后序。

**推导链。**
1. 暴力：对每个节点单独递归求左右子树高度，高度被重复算，链上 `O(n^2)`。
2. 浪费：高度是后序遍历的副产品，不需要为每个节点重新算。
3. 洞察：孩子处理完，高度已知，`best = max(best, lh + rh)`，`height = 1 + max(lh, rh)`。
4. 最优：一次后序，`O(n)`；用显式栈两阶段访问实现，避免递归深度问题。

**同模式的题**：LC 124 二叉树中的最大路径和、LC 104 二叉树的最大深度、LC 687 最长同值路径、LC 110 平衡二叉树。
