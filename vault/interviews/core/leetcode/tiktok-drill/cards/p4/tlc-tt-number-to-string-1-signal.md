## Q
**手写数字转字符串**｜Medium · 近一年被问：美国 0 次、国内 1 次 · 最近 2026-10-22（国内面试记录）

不使用 `str`、`repr`、`format`、f-string，把数转成十进制字符串（`chr`、`ord`、`divmod`、`"".join` 可以用）。（1）64 位有符号整数 `n`（`-2^63 <= n < 2^63`），注意 `0` 和负数。（2）十进制数 `(sign, int_part, frac_value, frac_len)`：`sign` 是 `-1` 或 `1`，`int_part >= 0`，`frac_value` 是小数部分当整数读出的值（`0 <= frac_value < 10^frac_len`），`frac_len` 是小数位数（`0 <= frac_len <= 1000`）；输出规范写法：去掉小数末尾的 `0`，小数全为 `0` 时不输出小数点，数值为 `0` 时不带负号。例：`-12.050` 表示为 `(-1, 12, 50, 3)`，输出 `"-12.05"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「禁用 `str` / `format`」→ **基数分解**（radix conversion）：取余得最低位，整除去掉最低位。
- 「注意 `0` 和负数」「`-2^63`」→ 考边界：`0` 要特判，负数的整除方向，64 位语言里最小值取绝对值会溢出。
- 「整数部分与小数部分分开、去掉末尾 `0`、不输出多余的小数点」→ 考细节：小数部分当整数读会丢**前导 `0`**，要靠位数 `frac_len` 补回；末尾 `0` 要去掉；符号要看整个数值，不只看整数部分。
- 位数很少（整数至多 19 位）：不需要任何高级技巧，`O(d)` 就是最优。

**推导链。**
1. 先求位数 `d`、再从最高位 `n // 10^(d-1)` 往下取：要先算 `10^k`，绕远。
2. `n % 10` 是最低位，`n // 10` 去掉它，循环到 `0`；低位先出，最后反转。
3. 补上边界：`0` 单独返回 `"0"`；负数先记符号、取绝对值，因为 Python 的 `//` 向下取整，`divmod(-12, 10)` 是 `(-2, 8)`。
4. 小数部分：`frac_value % 10 == 0` 就除以 `10`、`frac_len` 减一，直到末位非 `0` 或位数用完；剩下的数字串在左边补 `0` 到 `frac_len` 位；位数为 `0` 就不输出小数点。

**同模式的题**：LC 8 字符串转换整数、LC 7 整数反转、LC 12 整数转罗马数字、LC 168 Excel 表列名称、LC 415 字符串相加。
