## Q
**LC 21 合并两个有序链表**｜Easy · CodeTop 国内累计 84 次 · 最近 2026-10-09（CodeTop）

把两个升序链表合并为一个新的升序链表并返回；新链表是通过拼接给定的两个链表的所有节点组成的。节点数目范围是 `[0, 50]`，`-100 <= Node.val <= 100`，两个链表均按非递减顺序排列。例：`list1 = [1,2,4]`，`list2 = [1,3,4]` → `[1,1,2,3,4,4]`；`list1 = []`，`list2 = [0]` → `[0]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「两个**有序**序列合成一个有序序列」→ **归并**（merge）的双指针：每次比较两个队头，取较小的。
- 「链表」+「**拼接**原来的节点」→ 只改 `next` 指针，不新建节点，空间 `O(1)`。
- 结果的头节点不固定（可能来自任一条链表，可能为空）→ **哑节点**（dummy）统一头部的处理。
- 节点数很少（`<= 50`），但这是几乎所有链表题的基本部件（排序链表、K 路合并都要用）。

**推导链。**
1. 暴力：取出所有值排序后重建链表，`O((m + n) log(m + n))`，且不是拼接原节点。
2. 递归：取较小队头，剩余部分递归合并。代码短，递归深度 `m + n`。
3. 洞察：两条链表各自有序，所以下一个结果节点必是两个队头里较小的；一条用完后，另一条的剩余部分已有序且不小于已合并部分，整段挂上。
4. 最优：哑节点加尾指针迭代，`O(m + n)` 时间，`O(1)` 空间。

**同模式的题**：LC 23 合并 K 个升序链表、LC 88 合并两个有序数组、LC 148 排序链表、LC 143 重排链表。
