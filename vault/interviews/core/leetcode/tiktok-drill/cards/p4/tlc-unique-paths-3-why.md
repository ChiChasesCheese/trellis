## Q
**LC 62 不同路径**｜正确性

为什么 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，第一行、第一列为什么都是 `1`？为什么组合数是 `C(m + n - 2, m - 1)` 而不是 `C(m + n, m)`？

## A
**不变量。** `dp[i][j]` 是到达 `(i, j)` 的路径数。到达 `(i, j)` 的最后一步要么从上方来（路径数 `dp[i-1][j]`），要么从左边来（`dp[i][j-1]`），两类互斥且完备，所以 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。第一行的格子没有上方，只能一路向右，恰好 `1` 条路；第一列同理。

**组合数。** 从 `(0, 0)` 到 `(m-1, n-1)` 恰好走 `(m - 1) + (n - 1) = m + n - 2` 步，其中向下 `m - 1` 步，选哪几步是向下的就决定了整条路径，所以是 `C(m + n - 2, m - 1)`。起点本身不是一步。

**反例（错误写法一）：步数写成 `m + n`。** `comb(m + n, m)` 在 `(3, 7)` 给出 `120`，正确是 `28`。

**反例（错误写法二）：边界全 `0`。** 整张表是 `0`，递推从 `(1, 1)` 开始，`(3, 7)` 得 `0`，正确是 `28`；只把第一行设成 `1`、第一列留着 `0`，`(3, 7)` 得到 `21`，`(3, 3)` 得到 `3`，正确是 `28` 和 `6`。第一行和第一列的每个格子都有恰好 `1` 条路。
