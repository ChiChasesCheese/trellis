## Q
**LC 417 太平洋大西洋水流问题**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2025-12-10（面试记录）

`m × n` 岛屿，太平洋在左、上边界，大西洋在右、下边界。水从一个格子流向上下左右高度**小于等于**它的邻居，边界格子的水可以直接入海。返回雨水既能流到太平洋又能流到大西洋的所有格子坐标。`1 <= m, n <= 200`，`0 <= heights[r][c] <= 10^5`。例：`[[2,1],[1,2]]` → 四个格子全部。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「水从高处流向低处，哪些格子能到某个区域」→ 网格上的**可达性**（BFS / DFS）。
- 目标区域（两个海洋）很少，起点（所有格子）很多 → **反向搜索**：从目标出发，条件反过来（逆流而上，走向高度 `>=` 的邻居）。
- 两个条件要同时满足（既到太平洋又到大西洋）→ 各算一个集合，取**交集**。
- `m, n <= 200`：暴力 `O((mn)^2)` 约 `1.6 · 10^9`，不行；`O(mn)` 即可。

**推导链。**
1. 暴力：对每个格子搜一遍，看能不能到达上 / 左边界、下 / 右边界。`O((mn)^2)`。
2. 浪费在哪：很多格子的搜索路径大量重叠，每次都重新走一遍。
3. 洞察：「`A` 能流到 `B`」等价于「从 `B` 逆流能走到 `A`」，条件是 `h[A] >= h[B]`。海洋的入口是整条边界，把它们一起作为起点做一次多源 BFS，就一次性得到所有能流到该海洋的格子。
4. 最优：太平洋、大西洋各做一次反向多源 BFS，结果集合取交集。`O(mn)`。

**同模式的题**：LC 130 被围绕的区域、LC 1020 飞地的数量、LC 542 01 矩阵、LC 286 墙与门。
