## Q
**手写最小堆**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-10-04（面试记录）

不用 `heapq`，用 Python 列表实现最小堆类 `MinHeap`：`push(x)`、`pop()`（返回并删除最小值）、`peek()`、`__len__`，以及从一个列表线性建堆的 `heapify`。`push` / `pop` 要 `O(log n)`，建堆要 `O(n)`；空堆 `pop` / `peek` 抛 `IndexError`；元素个数至多 `10^5`。例：用 `[5, 3, 8, 1, 9, 2]` 建堆后连续 `pop` 依次得到 `1, 2, 3, 5, 8, 9`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「反复取最小值，同时不断加入新元素」→ **优先队列**，实现是**二叉堆**（binary heap）。
- 「`push` / `pop` 要 `O(log n)`」→ 不能保持全序，只保持局部序；「建堆要 `O(n)`」→ 自底向上下沉建堆（Floyd），不是 `n` 次 `push`。
- 「用列表」→ 完全二叉树没有空洞，按层存进数组，下标算术代替指针：父 `(i - 1) // 2`，孩子 `2i + 1`、`2i + 2`。
- `n` 到 `10^5`：`O(n)` 的 `push` 会变成 `O(n^2)`，必须对数级。

**推导链。**
1. 有序数组：`pop` 取头 `O(1)`，`push` 要插入，`O(n)`。
2. 无序数组：`push` 追加 `O(1)`，`pop` 要扫一遍找最小值，`O(n)`。
3. 浪费在于维护了不需要的信息：只关心最小值，不关心其余元素的相对顺序。
4. 只保持“父不大于子”，最小值就在根；完全二叉树高度是 `log n`，`push` 上浮、`pop`（末尾元素放到根）下沉，都只沿一条路径走，`O(log n)`。建堆时叶子本来就合法，只对非叶子倒着下沉，总代价 `Σ 高度`，是 `O(n)`。
