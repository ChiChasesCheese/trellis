## Q
**枚举有向图中的所有简单路径（含环的情况）**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-08-23（面试记录）

给有向图（`n` 个点、边表 `edges`，没有重边）和起点 `s`、终点 `t`（`s != t`），按任意顺序返回从 `s` 到 `t` 的所有简单路径（不能重复经过同一个点）。`1 <= n <= 15`，边数 `<= 60`，图里可能有环。例：`n = 4`，`edges = [[0,1],[0,2],[1,2],[2,3],[1,3]]`，`s = 0`，`t = 3` → `[[0,1,2,3],[0,1,3],[0,2,3]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「返回**所有**路径」→ 输出可能是指数级，只能枚举：**回溯 DFS**。
- `n <= 15` → 明示指数级可以接受，不必找多项式算法。
- 「可能有环」+「简单路径」→ 需要防止重复进点，标记的是**当前路径上的点**（`on_path`），回溯时撤销；不是普通遍历的全局 `visited`。
- 只关心通往 `t` 的路径 → 可以预先求出「能到达 `t` 的点」来剪枝。

**推导链。**
1. 暴力：枚举点的所有排列，检查相邻点之间是否有边，`O(n!·n)`。
2. 浪费：绝大多数排列在第一对相邻点就不连通。改成沿边 DFS，只扩展存在的边。
3. 有环会无限绕圈 → 加 `on_path`，进点时标记、退出时撤销，让同一个点仍能出现在别的路径里。
4. 剪枝：从 `t` 沿反向边 BFS 一次（`O(n + m)`），DFS 只进能到达 `t` 的点，走不到 `t` 的整棵子树直接跳过。总代价由输出规模决定。

**同模式的题**：LC 797 所有可能的路径、LC 46 全排列、LC 79 单词搜索、LC 1059 从始点到终点的所有路径。
