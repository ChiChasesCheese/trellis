## Q
**LC 1043 分隔数组以得到最大和**｜正确性

为什么 `dp[i]` 只看「最后一段的长度」就够了？为什么贪心地「每段都取满 `k` 个」是错的？

## A
**不变量。** `dp[i]` 是前 `i` 个元素在「每段长度至多 `k`」下能得到的最大总和，与后面的元素无关。

**为什么够。** 任何合法分隔里，前 `i` 个元素被分成若干段，最后一段是 `arr[i-j:i]`（`1 ≤ j ≤ k`），其余部分是前 `i-j` 个元素的一个合法分隔，它的最大总和正是 `dp[i-j]`（最优子结构：前面段的取值不影响最后一段的价值）。枚举所有 `j` 取最大即覆盖所有分隔方案。

**反例（贪心取满 `k`）。** `arr = [1,15,7,9,2,5,10]`, `k = 3`。
- 取满 `k`：`[1,15,7]` → `45`，`[9,2,5]` → `27`，`[10]` → `10`，共 `82`。
- 最优：`[1,15,7]` → `45`，`[9]` → `9`，`[2,5,10]` → `30`，共 `84`。取满法让 `10` 独占一段，没能把 `2` 和 `5` 抬到 `10`；最优解把 `9` 单独切出，换来 `[2,5,10]` 这一段（`3 × 10`）。
