## Q
**LC 442 数组中重复的数据**｜写出 Python 实现

整数数组 `nums`，长度 `n`（`1 <= n <= 10^5`），每个元素在 `[1, n]` 内且出现一次或两次。返回所有出现两次的元素，要求 `O(n)` 时间、常量额外空间（输出不计），允许修改输入。

## A
**思路。** 对每个元素 `x`，下标 `abs(x) − 1` 是它的「记号位」。若记号位的值已为负，说明这个数之前来过，是重复；否则把记号位取负，表示来过了。遍历时读到的元素可能已被取负，所以先 `abs`。

```python
def find_duplicates(nums: list[int]) -> list[int]:
    res: list[int] = []
    for x in nums:
        i = abs(x) - 1                         # 值 x 对应的「标记位置」；x 可能已被前面的标记取负
        if nums[i] < 0:
            res.append(abs(x))                 # 这个位置已经被标记过：x 是第二次出现
        else:
            nums[i] = -nums[i]                 # 第一次出现：把 nums[i] 取负做记号
    return res
```

运行：`[4,3,2,7,8,2,3,1]` → `[2,3]`，`[1,1,2]` → `[1]`，`[1]` → `[]`，`[2,1,1]` → `[1]`，`[1,2,3,4,5]` → `[]`；`n = 10^5`、约四分之一重复的数组约 `0.005` 秒。

**复杂度。** 时间 `O(n)`：一次遍历；空间 `O(1)`：除输出外只用了几个变量。

**写法要点。** `for x in nums` 边遍历边改同一个列表是安全的（只改元素值，不改长度）；`abs(x) - 1` 把值映射到 `0..n-1` 的下标；负数下标在 Python 里不会报错而是绕到列表尾部，这是不写 `abs` 时错误悄悄发生的原因；结果列表 `res` 的类型标注 `list[int]`，读 `nums[i] < 0` 用符号当「已见」标记。
