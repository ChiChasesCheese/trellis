## Q
**LC 547 省份数量**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 3 次 · 最近 2026-03-05（美国面试记录）

有 `n` 个城市，一些直接相连，另一些没有；直接相连的传递链上的城市间接相连。「省份」是一组直接或间接相连的城市，组内不含其他没有相连的城市。给你 `n x n` 的矩阵 `isConnected`（`isConnected[i][j] = 1` 表示城市 `i`、`j` 直接相连，`isConnected[i][i] == 1`，矩阵对称），返回省份的数量。`1 <= n <= 200`。例：`[[1,1,0],[1,1,0],[0,0,1]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「直接或间接相连」「一组」→ 传递闭包（transitive closure）下的等价类，即**连通分量**（connected component）：DFS / BFS / 并查集（union-find）。
- 输入是 `n x n` 的 `0/1` 矩阵且 `isConnected[i][j] == isConnected[j][i]` → 无向图的邻接矩阵（adjacency matrix），顶点是城市，不是网格格子；邻居是整行里的 `1`。
- `n <= 200` → 读一遍矩阵 `O(n^2)` 只有 `4 * 10^4`，不需要更聪明的算法；递归深度最多 `n`，也不会爆栈。
- 朋友圈、相似照片分组、账号归并换了说法，仍是同一个模型：「按相似/认识关系分组，数组数」。

**推导链。**
1. 暴力：对每个城市单独搜一遍它能到的城市，再把相同的集合去重，同一个省份被搜很多次。
2. 浪费：一个省份里的每个城市都会重复搜整个省份。
3. 洞察：搜过的城市立刻标记，外层循环只在遇到未标记城市时才启动一次搜索；一次搜索恰好吃掉一个省份，启动次数就是答案。
4. 最优：递归 DFS（`seen` 数组），`O(n^2)` 时间；并查集做法等价，每合并两个不同的根省份数减一。

**同模式的题**：LC 200 岛屿数量、LC 323 无向图中连通分量的数目、LC 684 冗余连接、LC 721 账户合并。
