## Q
**LC 581 最短无序连续子数组**｜正确性

为什么右端是“最后一个小于前缀最大值的位置”，而不是“最后一个相邻逆序对的右侧”？给出只看相邻逆序对会出错的输入，并说明为什么这个区间既够用又最短。

## A
**不变量。** 扫到 `i` 时，`hi` 是 `nums[0..i-1]` 的最大值。`nums[i] < hi` 说明排完序后 `hi` 必须挪到 `i` 的右边，所以 `i` 一定在排序段里。反过来，右端之后的每个元素都不小于它左边的所有元素，左端之前的每个元素都不大于它右边的所有元素，这些元素已经在最终位置上，不用动。两个端点自身也必须被排序（`end` 处小于 `hi`，`start` 处大于 `lo`），所以这段既够用又最短。

**反例 `[1,2,4,5,3]`。** 正确答案 `3`（排序 `[4,5,3]` 得 `[1,2,3,4,5]`）。
- 只看相邻逆序对：只有 `(5, 3)`，区间取 `[3, 4]`，长度 `2`；排序后 `[1,2,4,3,5]`，仍然无序。
- 本解法：从左扫到 `i = 4` 时 `3 < hi = 5`，`end = 4`；从右扫，`j = 3` 处 `5 > lo = 3`，`start = 3`，`j = 2` 处 `4 > 3`，`start = 2`；`j = 1` 处 `2 <= 3`，`lo` 更新为 `2`，`start` 不变。长度 `4 - 2 + 1 = 3`。

问题出在 `4`：它和 `3` 之间不相邻，但仍然比 `3` 大。逆序是整个数组范围内的关系，要和前缀最大值、后缀最小值比，不能只和邻居比。
