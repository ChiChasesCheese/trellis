## Q
**LC 904 水果成篮**｜Medium · LC TikTok 热度 38/100（近 3 个月） · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-05-12（面试记录）

一排果树，`fruits[i]` 是第 `i` 棵树上水果的种类。你有两个篮子，每个篮子只能装**一种**水果、数量不限。可以从任意一棵树开始，**依次**向右采摘，每棵树恰好摘一个；一旦走到某棵树前水果不符合两个篮子的种类就必须停止。求最多能摘多少个水果。

约束：`1 <= fruits.length <= 10^5`，`0 <= fruits[i] < fruits.length`。

例：`fruits = [1,2,1]` → `3`；`fruits = [0,1,2,2]` → `3`（从第二棵树摘 `[1,2,2]`）；`fruits = [1,2,3,2,2]` → `4`（`[2,3,2,2]`）；`fruits = [3,3,3,1,2,1,1,2,3,3,4]` → `5`（`[1,2,1,1,2]`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「依次向右、不能跳过、遇到不符合就停」→ 选的是一段**连续**区间；「最多两个篮子，每篮一种」→ 区间内**不同种类数 ≤ 2**。
- 窗口内约束只会越扩越严、越缩越松（单调）→ **可变长滑动窗口**，左右指针都只前进。
- `n = 10^5` → 需要 `O(n)`；`fruits[i] < n` 的值域提示可以用数组计数，但字典 / `Counter` 更通用，种类数只有 3 个键不会变慢。

**推导链。**
1. 暴力：枚举起点，向右扩并用集合记种类，到第三种停下，`O(n^2)`。
2. 浪费：相邻起点会在同一个位置才被第三种水果挡住，大段重复扫描。
3. 洞察：右端固定时，合法的最左起点唯一，且随右端右移单调不减 → 左端不必回头。
4. 最优：右端扩张，`Counter` 记数量；种类 `> 2` 时 `while` 收缩左端并在计数为 0 时删键；每步更新 `best`，`O(n)` 时间、`O(1)` 空间。
