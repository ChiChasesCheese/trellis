## Q
**LC 450 删除二叉搜索树中的节点**｜Medium · LC 字节 全时段热度 50/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 5 次 · 最近 2026-03-11（国内 CodeTop）

给二叉搜索树的根节点 `root` 和值 `key`，删除值为 `key` 的节点，保证删除后仍是二叉搜索树，返回根节点。节点数 `[0, 10^4]`，值唯一，`-10^5 <= Node.val, key <= 10^5`。进阶：`O(h)`。例：`root = [5,3,6,2,4,null,7], key = 3` → `[5,4,6,2,null,null,7]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「二叉搜索树」+「`O(h)`」→ 沿树高一条路径走，每步靠大小比较决定向左还是向右（BST 查找）。
- 「删除后仍是 BST」→ 难点在删完留下的**空位怎么补**：补位节点必须大于左子树所有值、小于右子树所有值，只有**中序前驱**或**中序后继**。
- 按孩子数分三类：无孩子 / 一个孩子（直接顶替）/ 两个孩子（用后继顶替）。
- 「返回根节点」→ 递归里每层返回删除后的子树根，父节点用返回值接回去，删根也不用特判；节点 `10^4` 且 BST 可能退化成链时递归深度会超过 CPython 默认的约 `1000`，要调高上限或改成迭代。

**推导链。**
1. 暴力：中序遍历得到所有值，去掉 `key`，重新建树。`O(n)`。
2. 观察：BST 的有序性让查找只走一条路径，`O(h)`；删除只影响目标位置附近。
3. 洞察：目标至多一个孩子时，让孩子顶替；有两个孩子时，把右子树最小节点（后继）的值抄到目标上，然后删掉那个后继，它没有左孩子，回到「至多一个孩子」。
4. 最优：递归沿一条路径下去，命中后分三种情况，两个孩子时再向下走一条路径找后继，整体 `O(h)`；迭代版 `O(1)` 空间。
