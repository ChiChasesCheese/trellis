## Q
**LC 442 数组中重复的数据**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-08-12（国内面试记录）

长度为 `n` 的整数数组 `nums`，每个数都在 `[1, n]` 内，且每个数出现一次或两次。找出所有出现两次的数，要求 `O(n)` 时间、常量额外空间（不含输出）。`1 <= n <= 10^5`，`1 <= nums[i] <= n`。例：`[4,3,2,7,8,2,3,1]` → `[2,3]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「数的范围恰好是 `[1, n]`，数组长度也是 `n`」→ **值可以当下标用**（索引映射 / 数组当哈希表）。
- 「常量额外空间」→ 不能用集合、`Counter`；信息必须存进**原数组自己**。
- 「出现一次或两次」→ 只需要一位信息（见过 / 没见过）：元素都是正数，**符号位**是现成的一位。
- `n = 10^5`：`O(n^2)` 不行。

**推导链。**
1. 暴力：两层循环比较，`O(n^2)`。
2. 哈希集合：`O(n)` 时间，`O(n)` 空间，违反空间限制。
3. 值域映射：布尔数组 `seen[x − 1]`，仍是 `O(n)` 空间。
4. 洞察：用 `nums[x − 1]` 的符号当 `seen[x − 1]`：读到 `x` 时，若 `nums[x − 1]` 已是负数，`x` 是第二次出现；否则取负做记号。读元素本身时要先 `abs`，因为它可能已被标成负数。`O(n)` 时间，`O(1)` 空间。
5. 另一种原地手段：循环排序（把每个数交换到它「应该在」的位置），也是 `O(n)`。
