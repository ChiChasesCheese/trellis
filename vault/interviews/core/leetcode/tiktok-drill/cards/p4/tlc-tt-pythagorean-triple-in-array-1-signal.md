## Q
**整数数组中的勾股三元组**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-08-17（面试记录）

给整数数组 `nums`，判断是否存在三个不同下标 `i`、`j`、`k`，使 `nums[i]^2 + nums[j]^2 == nums[k]^2`。元素可以是负数、`0`、重复值；下标不同即可，值可以相同。返回布尔值，时间要求 `O(n^2)`。`0 <= n <= 3000`，`|nums[i]| <= 10^5`。例：`[-3,4,-5]` → `True`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「三个数满足 `a^2 + b^2 = c^2`」→ 和 3Sum 同构：固定一个数，其余两个做 Two Sum，只是变量换成了平方。
- 「要求 `O(n^2)`、`n = 3000`」→ 排序 + 双指针（`O(n log n) + O(n^2)`）或哈希集合（`O(n^2)`）；三重循环 `O(n^3)` 约 `10^10` 不可行。
- 「负数、`0`、重复」→ 先平方，符号和正负不再影响；`0` 和重复值不能用集合去重，否则丢掉「值相同、下标不同」的合法三元组。
- 「下标不同」→ 排序后的位置 `i < j < k` 天然互不相同。

**推导链。**
1. 暴力：三重循环枚举下标并判断，`O(n^3)`。
2. 浪费：固定斜边 `c` 之后，找 `a`、`b` 是 Two Sum，却被当作双重循环。
3. 洞察一：平方后排序，斜边平方一定不小于两条直角边的平方，所以直角边只来自斜边左边的元素。
4. 洞察二：固定 `k`，左指针 `i = 0`，右指针 `j = k - 1`；`sq[i] + sq[j]` 小了就右移 `i`，大了就左移 `j`，相等就找到。
5. 最优：外层 `O(n)` 个 `k`，内层 `O(k)`，总 `O(n^2)`，额外空间只有平方数组。

**同模式的题**：LC 15 三数之和、LC 611 有效三角形的个数、LC 16 最接近的三数之和、LC 259 较小的三数之和。
