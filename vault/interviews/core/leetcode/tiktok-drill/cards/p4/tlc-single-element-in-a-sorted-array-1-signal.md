## Q
**LC 540 有序数组中的单一元素**｜Medium · LC 字节 热度 50/100（近 6 个月） · CodeTop 国内累计 2 次 · 最近 2026-04-09（国内 CodeTop）

给一个有序整数数组，每个元素都出现两次，只有一个数出现一次，找出这个数。要求 `O(log n)` 时间和 `O(1)` 空间。`1 <= nums.length <= 10^5`，`0 <= nums[i] <= 10^5`。例：`nums = [3,3,7,7,10,11,11]` → `10`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「有序」+「`O(log n)`」→ **二分查找**。
- 「每个数出现两次，只有一个出现一次」→ 数组长度是奇数，成对元素**相邻**；单一元素让后面的成对关系整体错位一格，这是二分要利用的单调结构。
- 「`O(1)` 空间」→ 不能用哈希表，也不能递归占栈。
- 不要求有序的同类题（LC 136）用异或，这里的“有序”是在暗示更快的 `O(log n)`。

**推导链。**
1. 暴力：线性扫描，或把全体异或，`O(n)`，不满足 `O(log n)`。
2. 找单调条件：单一元素之前，成对元素的第一个在**偶数**下标（`nums[2k] == nums[2k + 1]`）；之后，成对元素的第一个在**奇数**下标，于是 `nums[2k] != nums[2k + 1]`。
3. 对偶数下标 `m`，「`nums[m] != nums[m + 1]`」先假后真，分界点就是单一元素。
4. 二分时让 `mid` 对齐到偶数；`nums[mid] == nums[mid + 1]` 就丢掉左半（含这一对）：`lo = mid + 2`，否则 `hi = mid`。
5. `lo`、`hi` 始终是偶数，`O(log n)` 时间，`O(1)` 空间。

**同模式的题**：LC 34 排序数组中查找元素的第一个和最后一个位置、LC 162 寻找峰值、LC 153 寻找旋转排序数组中的最小值、LC 136 只出现一次的数字。
