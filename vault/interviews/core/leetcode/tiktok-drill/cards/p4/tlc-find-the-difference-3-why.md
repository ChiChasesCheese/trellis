## Q
**LC 389 找不同**｜正确性

异或为什么能找出多出来的字母？为什么不能只比较两个字符串的字符集合？

## A
**不变量。** 异或满足交换律、结合律，且 `x ^ x = 0`、`x ^ 0 = x`。`t` 是 `s` 重排后加一个字符 `c`，把 `s` 和 `t` 的所有字符放在一起，每个原有字符恰好出现两次（一次在 `s`，一次在 `t`），`c` 出现奇数次。由交换律可以任意调整顺序，把相同的字符凑在一起两两抵消，剩下 `c`，所以结果是 `ord(c)`。顺序（重排）因此无关。

**反例。** 用集合差 `set(t) - set(s)`：`s = "a"`、`t = "aa"` 时两个集合都是 `{'a'}`，差集为空，无法给出答案；正确答案是 `"a"`。多出来的字母和已有字母相同时，只看「种类」会丢掉「次数」，而异或和计数看的是次数的奇偶 / 差。

**另一个常见错误。** 只比较排序后的字符串逐位找第一个不同：当多出来的字母排在末尾时，循环里找不到不同位置，必须额外返回 `t[-1]`。
