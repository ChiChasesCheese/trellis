## Q
**LC 99 恢复二叉搜索树**｜Medium · LC TikTok 全时段热度 34/100 · CodeTop 国内累计 6 次 · 最近 2026-06-02（国内 CodeTop）

给二叉搜索树的根结点 `root`，其中**恰好两个**结点的值被错误地交换了。请在**不改变树结构**的情况下恢复这棵树（原地交换两个结点的值即可）。结点数在 `[2, 1000]`，`-2^31 <= Node.val <= 2^31 - 1`。例：`root = [1,3,null,null,2]` → `[3,1,null,null,2]`；`root = [3,1,4,null,null,2]` → `[2,1,4,null,null,3]`。进阶：用 `O(n)` 空间很容易，能否只用 `O(1)` 空间？

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「二叉搜索树」+ 需要整体判断或修复 → 中序遍历（in-order）= 升序序列；BST 问题优先问自己：能否摊平成有序数组？LC 99 是 LC 98（验证 BST）的追问，与 LC 230 共用「中序有序」这一思路。
- 「恰好两个结点互换」→ 升序序列中交换两个元素，只会产生 1 处（相邻）或 2 处（不相邻）逆序对，位置可由一遍扫描确定。
- `n <= 1000` → 任何 `O(n)`、`O(n log n)` 都够；递归中序最直观，但单链树高可达 1000，会触到默认递归上限（约 1000 层），见追问的迭代版。
- 「进阶 `O(1)` 空间」→ 要摆脱栈 / 递归，信号指向 Morris 遍历。

**推导链。**
1. 暴力：中序收集成数组，排序后与原数组比较，找出两个不同的位置 → `O(n log n)` 时间、`O(n)` 空间。
2. 浪费：数组只有一对放错，不需要排序；逆序对的位置已经暴露了答案。
3. 洞察：不相邻互换产生两处逆序，取**第一处的前者**和**第二处的后者**；相邻互换只有一处，前者、后者就是它的两端。统一写成「第一处逆序取 `prev`，最后一处逆序取 `node`」。
4. 最优：中序遍历中只保留 `prev`，不存数组 → `O(n)` 时间、`O(h)` 空间；换成 Morris 遍历即 `O(1)` 空间。

**同模式的题**：LC 98 验证二叉搜索树、LC 230 BST 中第 K 小的元素、LC 530 BST 的最小绝对差、LC 501 BST 中的众数。
