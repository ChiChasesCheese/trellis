## Q
**LC 986 区间列表的交集**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-08-24（面试记录）

两个闭区间列表 `firstList`、`secondList`，各自内部两两不相交且已排序；返回两个列表的交集（一组闭区间）。`0 <= 长度 <= 1000`，两者长度之和 `>= 1`，`0 <= start < end <= 10^9`，同一列表中 `end_i < start_{i+1}`。例：`[[1,7]]` 与 `[[3,10]]` → `[[3,7]]`；`[[1,3],[5,9]]` 与 `[]` → `[]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**已排序** + 各自**不相交**」的两个序列 → **双指针归并**，不必再排序，也不需要堆。
- 「求交集」且是**闭**区间 → 两个区间 `[a,b]`、`[c,d]` 的交集是 `[max(a,c), min(b,d)]`，`max <= min` 才非空；相切于一点也算（单点区间）。
- `m, n <= 1000` → `O(m*n)` 暴力也能过，但前提是明示的，面试里应给 `O(m + n)`。

**推导链。**
1. 暴力：所有区间对两两求交，`O(m*n)`；输出还要再排序。
2. 浪费：设当前是 `A[i]`、`B[j]`，大多数配对根本不可能相交。
3. 关键观察：两个当前区间里**终点较小的那个**，已经和对方当前区间处理完；对方下一个区间的起点更大（大于对方当前终点），所以它与终点较小者之后无交集，可丢弃。
4. 最优：每步求当前对的交集，然后让终点小的指针前进；每步丢一个区间，总共 `O(m + n)`。
