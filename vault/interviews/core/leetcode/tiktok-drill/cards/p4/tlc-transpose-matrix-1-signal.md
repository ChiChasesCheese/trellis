## Q
**LC 867 转置矩阵**｜Easy · 近一年被问：美国 0 次、国内 2 次 · 最近 2026-10（面试记录）

给一个二维整数数组 `matrix`，返回它的转置矩阵：沿主对角线翻转，行下标和列下标互换。`m == matrix.length`，`n == matrix[i].length`，`1 <= m, n <= 1000`，`1 <= m * n <= 10^5`，`-10^9 <= matrix[i][j] <= 10^9`。例：`[[1,2,3],[4,5,6]]` → `[[1,4],[2,5],[3,6]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「行列互换」→ 纯下标映射 `res[j][i] = matrix[i][j]`，没有算法技巧，考的是对矩阵形状的处理。
- 矩阵不一定是方阵（`m` 与 `n` 独立）→ 结果形状是 `n x m`，不能原地，要开新矩阵。
- `m * n <= 10^5`：每个元素至少读写一次，`O(m·n)` 已经最优。
- 「第 `j` 列变成第 `j` 行」→ Python 的 `zip(*matrix)` 正好把各行按位置配对，一次得到所有列。

**推导链。**
1. 暴力：开 `n x m` 新矩阵，双重循环 `res[j][i] = matrix[i][j]`，`O(m·n)`。
2. 浪费：时间上没有浪费；可以优化的是代码的简洁度和（方阵时）额外空间。
3. 洞察：转置等价于「把行按位置配对」，`zip(*matrix)` 一句完成；方阵时 `(i, j)` 与 `(j, i)` 互换，只遍历上三角。
4. 最优：非方阵 `O(m·n)` 时间和空间；方阵可以原地，空间 `O(1)`。
