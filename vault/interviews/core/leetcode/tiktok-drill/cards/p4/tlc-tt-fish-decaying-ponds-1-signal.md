## Q
**鱼塘捕鱼（产量递减）**｜Hard · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-10-09（美国面试记录）

`n` 个鱼塘，第 `i` 个鱼塘第一次捕鱼得 `fish[i]` 条，之后每捕一次，下一次的收获减少 `decay[i]` 条（不低于 `0`）。共 `t` 个时间单位，每个时间单位选一个鱼塘捕一次，求最多能捞多少条鱼。`1 <= n <= 10^5`，`0 <= fish[i], decay[i] <= 10^9`，`1 <= t <= 10^9`。例：`fish = [10, 6]`、`decay = [4, 1]`、`t = 3` → `22`（`10 + 6 + 6`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每次选一个、收益递减」→ **贪心**：每步取当前最大的边际收益。收益沿每个塘不增，所以最优解等于“所有收获里最大的 `t` 个之和”。
- 「`t <= 10^9`、`fish` 到 `10^9`」→ 不能逐步模拟，答案里没有任何 `O(t)` 的步骤；转成“第 `t` 大的收获是多少”，对**阈值二分**（二分答案）。
- 「`decay` 可以是 `0`」→ 该塘收益永不下降，机会无限，是特判。
- 「每塘的收获是等差数列」→ 一个塘里取前 `k` 个的和有公式 `k·f - d·k·(k-1)/2`，不用逐个加。

**推导链。**
1. 暴力：模拟 `t` 步，每步扫 `n` 个塘找最大，`O(t · n)`。
2. 用最大堆：每步弹出最大、减 `decay` 后放回，`O(t log n)`；`t = 10^9` 仍然太慢。
3. 浪费：堆是在按从大到小逐个列出收获，而只要前 `t` 个的和。
4. 洞察：二分阈值 `x`，`count(收获 >= x)` 随 `x` 增大不增；找最大的 `x` 使它 `>= t`；严格大于 `x` 的全拿（等差数列公式），剩下的名额各拿 `x`。

**同模式的题**：LC 1648 销售价值减少的颜色球、LC 378 有序矩阵中第 K 小的元素、LC 875 爱吃香蕉的珂珂、LC 1011 在 D 天内送达包裹的能力。
