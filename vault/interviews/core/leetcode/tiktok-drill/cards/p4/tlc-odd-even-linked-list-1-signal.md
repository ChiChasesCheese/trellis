## Q
**LC 328 奇偶链表**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 11 次 · 最近 2026-08-06（国内面试记录）

给单链表头节点 `head`，把下标为奇数的节点排在前面、下标为偶数的节点排在后面（第一个节点下标为奇数），两组内部保持原有相对顺序，返回新链表。要求 `O(1)` 额外空间、`O(n)` 时间。节点数 `0 <= n <= 10^4`，`-10^6 <= Node.val <= 10^6`。例：`[1,2,3,4,5]` → `[1,3,5,2,4]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「`O(1)` 额外空间」+ 链表 → 原地改 `next`，不能拷贝值进数组，也不能新建节点。
- 「按位置奇偶分组、组内保序」→ **一趟遍历、拆成两条链再拼接**；保序意味着每组都只能尾部追加。
- `n` 只有 `10^4`，`O(n)` 一趟轻松通过；难点不在复杂度而在指针操作不出错。

**推导链。**
1. 暴力：读成数组，`v[0::2] + v[1::2]`，再写回或重建链表 → 时间 `O(n)`，空间 `O(n)`，不满足要求。
2. 浪费：节点没必要搬动，只需改它们的 `next`。
3. 关键观察：奇节点的下一个奇节点是 `even.next`；偶节点的下一个偶节点是新的 `odd.next`。两个指针交替「跳过对方」，一趟拆出奇链和偶链。
4. 最优：拆之前记住偶链头 `even_head`，结束后 `odd.next = even_head`；只用三个指针，`O(1)` 空间。

**同模式的题**：LC 86 分隔链表、LC 725 分隔链表（k 段）、LC 143 重排链表、LC 148 排序链表。
