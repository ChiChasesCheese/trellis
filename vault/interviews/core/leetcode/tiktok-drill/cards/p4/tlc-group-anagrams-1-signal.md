## Q
**LC 49 字母异位词分组**｜Medium · LC TikTok 全时段热度 50/100 · 近一年被问：美国 3 次、国内 0 次 · CodeTop 国内累计 9 次 · 最近 2026-06-05（国内 CodeTop）

给一个字符串数组 `strs`，把字母异位词（字母相同、顺序不同）分到同一组，按任意顺序返回。`1 <= strs.length <= 10^4`，`0 <= strs[i].length <= 100`，`strs[i]` 仅含小写字母。例：`["eat","tea","tan","ate","nat","bat"]` → `[["bat"],["nat","tan"],["ate","eat","tea"]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「把相同性质的元素**分组**」→ **哈希分组**：为每个元素算一个规范键（canonical key），键相同即同组。
- 「字母相同、顺序不同」→ 等价关系是「字母多重集相同」，所以键可以是**排序后的串**，也可以是**字母计数**。
- 只含**小写字母** + 长度 `<= 100` → 计数数组长度固定为 26，每个串 `O(L)`；`N = 10^4` 不允许两两比较。

**推导链。**
1. 暴力：两两判断是否异位词，`O(N^2 · L)`，`10^8 · 100` 量级，不行。
2. 浪费在哪：每次比较都重新处理两个串。应该「每个串只处理一次」。
3. 洞察：异位词排序后相同 → `sorted(s)` 做键，`O(N · L log L)`。
4. 再进一步：字符集只有 26，计数一遍就够，不用排序 → `tuple(count)` 做键，`O(N · L)`。

**同模式的题**：LC 242 有效的字母异位词、LC 438 找到字符串中所有字母异位词、LC 560 和为 K 的子数组（前缀和做键）、LC 128 最长连续序列（哈希集）。
