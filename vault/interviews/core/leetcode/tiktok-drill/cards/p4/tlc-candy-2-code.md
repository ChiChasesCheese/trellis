## Q
**LC 135 分发糖果**｜写出 Python 实现

`ratings` 长度 `1` 到 `5 * 10^4`，值在 `[0, 5 * 10^4]`。每个孩子至少 `1` 颗糖，相邻两人中评分更高者糖更多（评分相等不作要求）。返回最少总糖数。

## A
**思路。** 先全部发 `1` 颗。从左到右，评分比左邻居高就设成「左邻居 + 1」；再从右到左，评分比右邻居高就取「当前值」和「右邻居 + 1」中的较大者。最后求和。

```python
def candy(ratings: list[int]) -> int:
    n = len(ratings)
    give = [1] * n                                 # 每人至少 1 颗
    for i in range(1, n):                          # 左到右：只管「比左邻居评分高 -> 比左邻居多」
        if ratings[i] > ratings[i - 1]:
            give[i] = give[i - 1] + 1
    for i in range(n - 2, -1, -1):                 # 右到左：只管「比右邻居评分高 -> 比右邻居多」
        if ratings[i] > ratings[i + 1]:
            give[i] = max(give[i], give[i + 1] + 1)    # 取最大，不能破坏第一遍已满足的约束
    return sum(give)
```

运行：`[1,0,2]` → `5`，`[1,2,2]` → `4`，`[1]` → `1`，`[2,2,2]` → `3`，`[1,2,3,4,5]` → `15`，`[5,4,3,2,1]` → `15`；`n = 5 * 10^4` 的随机输入在几毫秒内完成。

**复杂度。** 时间 `O(n)`：两遍扫描加一次求和；空间 `O(n)`，`give` 数组。

**写法要点。** `[1] * n` 建立初值，元素是不可变整数，不会有共享引用问题；`range(n - 2, -1, -1)` 从倒数第二个走到第 `0` 个；第二遍必须 `max`，因为 `give[i]` 可能已经被第一遍抬高；比较用 `>` 而不是 `>=`，评分相等的相邻孩子没有约束；`sum(give)` 在最后一次性求和，不在循环里累加。
