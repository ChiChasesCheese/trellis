## Q
**LC 1044 最长重复子串**｜追问

面试官接着问：（1）要求两次出现**不重叠**怎么改？（2）要求至少出现 `k` 次？（3）担心被人构造数据卡你的哈希，怎么防？（4）不想用哈希还有什么办法？

## A
1. **不重叠**：`find` 里每个哈希只记**最早**的起点 `j`，判定改为 `i - j >= length`（后来的窗口与最早的那个不相交）。只记最早起点就够，因为最早起点离当前窗口最远，若它都不满足，更晚的起点更不满足。单调性仍成立（去掉一个字符，两处仍不相交）。
2. **至少 `k` 次**：哈希表的值改为计数 / 起点列表，窗口哈希出现并通过比对的次数达到 `k` 才算成功。
3. **防卡哈希**：用随机底数（如上），模数用 `2^61 - 1`，或做双哈希（两组底数和模数），两者同时相等才比对。固定底数 + 固定小模数的写法容易被针对性数据卡到碰撞。
4. **不用哈希**：后缀数组 + LCP（最长公共前缀）数组，相邻后缀的 LCP 最大值就是答案长度，倍增构造 `O(n log^2 n)`；或后缀自动机 `O(n)`。代码量比哈希大，但没有概率因素。

**Python 提醒**：不要用内置 `hash(s[i:i + L])` 代替滚动哈希：每次切片就是 `O(L)`，整体退化成 `O(nL)`；而且字符串的 `hash()` 在不同进程里值不同（哈希随机化），不能持久化或跨进程比较。比较子串用 `s[j:j + L] == s[i:i + L]`，是逐字符的 C 级循环，足够快。
