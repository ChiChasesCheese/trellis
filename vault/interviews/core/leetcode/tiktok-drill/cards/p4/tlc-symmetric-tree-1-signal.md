## Q
**LC 101 对称二叉树**｜Easy · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 63 次 · 最近 2026-08-15（面试记录）

给二叉树的根节点 `root`，检查它是否轴对称（左右两半互为镜像）。树中节点数在 `[1, 1000]` 内，`-100 <= Node.val <= 100`。例：`root = [1,2,2,3,4,4,3]` → `true`；`root = [1,2,2,null,3,null,3]` → `false`。进阶：递归和迭代两种方法。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「轴对称」「镜像」→ **同时遍历两棵子树**，指针**交叉**配对：左对右、右对左。这是「相同的树」的变体。
- 「递归和迭代两种方法」→ 递归关系是 `mirror(a, b)`；迭代就是把待比较的**一对子树**放进栈（或队列）。
- `n <= 1000`：`O(n)` 足够；对称树深度至多约 500，递归不会超过 Python 默认递归上限 1000，但迭代更稳。

**推导链。**
1. 暴力：造一棵镜像树，再逐点比较两棵树。`O(n)` 时间，多花 `O(n)` 空间造副本。
2. 浪费：镜像不需要真的造出来。
3. 洞察：`a` 与 `b` 互为镜像 ⇔ 值相等，且 `a.left` 与 `b.right`、`a.right` 与 `b.left` 分别互为镜像。
4. 最优：栈里放待比较的对，弹出后判三种情形（都空 / 一空 / 值不同），再把外侧对和内侧对压栈。每个节点只进一对，`O(n)` 时间，`O(h)` 空间。

只比较中序序列是不是回文是错的：`[1,1,null,1]` 的中序是 `1,1,1`，却不对称，因为结构不同。

**同模式的题**：LC 100 相同的树、LC 226 翻转二叉树、LC 572 另一棵树的子树、LC 951 翻转等价二叉树。
