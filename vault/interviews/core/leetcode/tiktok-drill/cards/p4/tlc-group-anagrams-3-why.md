## Q
**LC 49 字母异位词分组**｜正确性

为什么「26 个字母的计数元组」可以当分组的键？有人图省事用 `frozenset(s)` 当键，会错在哪里？

## A
**不变量。** 键函数 `f(s) = tuple(count)` 必须满足：`f(a) == f(b)` **当且仅当** `a` 和 `b` 是异位词。

**为什么成立。** 两个串是异位词，等价于每个字母出现的次数都相同，也就是计数向量逐项相等。所以 `f` 相等 ⇔ 异位词。反方向保证不会把不是异位词的串并在一起，正方向保证不会把异位词拆开。

**为什么 `frozenset(s)` 不行。** 集合只记「出现过哪些字母」，丢了次数，等于把键函数换成了更粗的等价关系。

**反例。** 输入 `["aab","abb"]`，正确答案是两组 `[["aab"],["abb"]]`（`a` 与 `b` 的个数不同）。
- `frozenset("aab") == frozenset("abb") == {"a","b"}`，两个串落进同一组，输出 `[["aab","abb"]]`。
- 计数元组：`aab` → `(2,1,0,...)`，`abb` → `(1,2,0,...)`，不同，分成两组，正确。

排序键 `"".join(sorted(s))` 也满足「当且仅当」（排序后的串就是字母多重集的规范展开），所以也对；只是慢一个 `log L`。
