## Q
**出现次数最多的元素（并列取较小的）**｜Easy · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-07-15（美国面试记录）

给整数数组 `nums`，返回出现次数最多的元素；多个元素并列最多时返回数值最小的那个。`1 <= nums.length <= 10^5`，`-10^9 <= nums[i] <= 10^9`。例：`[3,1,3,1,2]` → `1`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「出现次数」→ **哈希计数**（`Counter`）。
- 值域 `±10^9` → 不能开下标数组计数，只能用字典；`n = 10^5` → 要 `O(n)` 或 `O(n log n)`。
- 「并列取最小」→ 两级排序规则，用**元组复合键** `(-次数, 数值)` 一次比较完。

**推导链。**
1. 暴力：对每个不同值 `x` 调 `nums.count(x)`，每次扫整个数组，最坏 `O(n^2)`。
2. 浪费：同一个数组被扫了 `k` 遍，其实一遍就能数出所有值的次数。
3. 一遍 `Counter` 建计数表，`O(n)`。
4. 再对计数表取 `min(count, key=lambda x: (-count[x], x))`：次数取负让「多」变成「小」，并列时比数值，小的胜出。总 `O(n)`。另一条路是排序后数连续段，`O(n log n)`，并列时先遇到的就是较小值。
