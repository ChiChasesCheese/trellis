## Q
**圆环上走 n 步回到原点的方案数**｜写出 Python 实现

环上有 `size` 个点（默认 `10`），从点 `0` 出发每步顺时针或逆时针走一个点，返回恰好走 `n` 步回到点 `0` 的走法数，对 `mod`（默认 `10^9 + 7`）取模。`0 <= n <= 10^5`。

## A
**思路。** `ways[p]` 是当前步数下停在点 `p` 的方案数。每一步用列表推导式整体生成新数组，新 `ways[p]` 等于旧 `ways[p-1]` 加旧 `ways[(p+1) % size]`，再取模；走完 `n` 步返回 `ways[0]`。

```python
MOD = 10**9 + 7


def ring_walks(n: int, size: int = 10, mod: int = MOD) -> int:
    """环上 size 个点，从 0 出发每步顺时针或逆时针走一格，恰好 n 步回到 0 的走法数（对 mod 取模）。"""
    ways = [1] + [0] * (size - 1)                          # ways[p]：当前步数下停在 p 的走法数
    for _ in range(n):
        ways = [(ways[p - 1] + ways[(p + 1) % size]) % mod for p in range(size)]   # p - 1 为负时 Python 自动绕回
    return ways[0]
```

运行：`n = 0, 1, 2, 3, 4, 10, 20` → `1, 0, 2, 0, 6, 254, 215766`；`n = 100000` → `131065086`；`size = 4`、`n <= 12` 的结果与枚举全部方向序列的计数一致。

**复杂度。** 时间 `O(size · n)`，空间 `O(size)`。

**写法要点。**
- 列表推导式一次生成整个新数组：右边的 `ways` 在推导式运行期间始终是旧数组，赋值发生在推导式结束之后，所以不会读到本步的新值；这是“滚动数组”最省事的写法。
- `ways[p - 1]`：`p = 0` 时是 `ways[-1]`，Python 的负下标正好是环的前一个点；`(p + 1) % size` 则必须显式取模。
- 把 `size` 和 `mod` 做成带默认值的参数：同一份代码支持不同大小的环，测试时用 `size = 4` 的小环对照枚举。
- 一开始就 `[1] + [0] * (size - 1)` 表示“只有点 `0` 上有 `1` 种方式”，`n = 0` 时直接返回 `1`。
