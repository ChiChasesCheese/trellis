## Q
**LC 2673 使二叉树所有路径值相等的最小代价**｜写出 Python 实现

`n` 是满二叉树的节点数（`3 <= n <= 10^5`，`n + 1` 是 `2` 的幂），节点 `1` 是根，非叶子节点 `i` 的孩子是 `2i` 和 `2i + 1`，`cost[i]`（`1 <= cost[i] <= 10^4`）是节点 `i + 1` 的值。每次操作可以把任意节点加 `1`，求让根到所有叶子的路径值相等的最少操作次数。

## A
**思路。** 在前面补一个 `0`，让数组下标等于节点编号。从最后一个非叶子节点 `n // 2` 倒序到根：读两个孩子的当前路径值，累加差的绝对值，再把较大者加到自己身上。

```python
def min_increments(n: int, cost: list[int]) -> int:
    c = [0] + cost                               # 1 下标，节点 i 的孩子是 2i、2i+1
    ans = 0
    for i in range(n // 2, 0, -1):               # 从最后一个非叶子节点倒着往上
        left, right = c[2 * i], c[2 * i + 1]
        ans += abs(left - right)                 # 较小的一边加到和较大的一边相等
        c[i] += max(left, right)                 # c[i] 变成「i 到叶子的路径值」
    return ans
```

运行：`(7, [1,5,2,2,3,3,1])` → `6`，`(3, [5,3,3])` → `0`，`(7, [1,2,3,4,5,6,7])` → `5`，`(3, [1,1,1])` → `0`，`(15, [1,...,15])` → `17`；`n = 65535` 瞬间完成。

**复杂度。** 时间 `O(n)`，空间 `O(n)`（补了 `0` 的副本）；直接改输入可以降到 `O(1)`。

**写法要点。**
- `[0] + cost` 一次性消除 `0` 下标和 `1` 下标的错位，后面所有的 `2 * i`、`2 * i + 1` 都直接可用，不用到处 `-1`。
- `range(n // 2, 0, -1)`：满二叉树的最后一个非叶子节点是 `n // 2`，倒序保证处理 `i` 时它的孩子已经变成「路径值」。
- 用 `c[i]` 就地保存“到叶子的路径值”，不需要递归，也没有额外的树结构。
- 在 `ans` 上累加 `abs(left - right)`，同时用 `max(left, right)` 更新自己：同一对 `left`、`right` 只读一次。
