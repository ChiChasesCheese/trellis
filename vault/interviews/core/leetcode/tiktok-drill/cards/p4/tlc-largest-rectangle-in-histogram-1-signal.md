## Q
**LC 84 柱状图中最大的矩形**｜Hard · LC TikTok 热度 50/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 12 次 · 最近 2026-03-01（国内 CodeTop）

给 `n` 个非负整数表示柱状图中相邻柱子的高度，每根柱子宽 `1`。求能勾勒出的最大矩形面积。`1 <= heights.length <= 10^5`，`0 <= heights[i] <= 10^4`。例：`[2,1,5,6,2,3]` → `10`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「以每根柱子为基准，向左右扩到第一根更矮的」→ **单调栈**（monotonic stack），专门解「左右第一个更小 / 更大」。
- `n = 10^5`：`O(n^2)` 约 `10^10` 次，必须 `O(n)` 或 `O(n log n)`。
- 关键转化：最优矩形的高 = 它覆盖的柱子里**最矮那根**的高。所以只要对每根柱子算「以它为最矮」的最宽区间，取最大即可。

**推导链。**
1. 暴力：枚举左右端点，维护区间最小值，面积 = 最小值 × 宽，`O(n^2)`。
2. 换成枚举最矮柱，向两边扩：单调序列上每根都要扩很远，仍是 `O(n^2)`。
3. 浪费在哪：每根柱子的左右边界都在重新找。栈里保持高度递增，一根柱子被弹出的时刻，就是右边出现了不高于它的柱子；弹出后的新栈顶就是它左边第一根更矮的。
4. 最优：每个下标入栈出栈各一次，弹出时结算 `高 × (i - left - 1)`；末尾补一根高 `0` 的哨兵，把栈里剩下的全部结算。`O(n)`。
