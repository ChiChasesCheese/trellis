## Q
**删除一个长度为 k 的窗口，使奇偶下标之和相等**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-09-11（美国面试记录）

给整数数组 `nums` 和整数 `k`。删除一段长度恰为 `k` 的连续子数组，剩余元素保持相对顺序并重新编号，要求剩余数组中偶数下标元素之和等于奇数下标元素之和。返回满足条件的最小起始下标，没有则返回 `-1`；删空整个数组时两个和都是 `0`，算满足。`1 <= k <= len(nums) <= 10^5`，`-10^4 <= nums[i] <= 10^4`。例：`[1,1,2,3,4,4]`、`k = 2` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「删除连续一段后重新编号」→ 窗口右边的元素整体左移 `k` 位，奇偶性随 `k` 的奇偶翻转或不变：前缀和 + 后缀和。
- 「偶数下标和等于奇数下标和」→ 按奇偶加符号的总和为 `0`，一个带符号的前缀和数组可以 `O(1)` 回答任意区间。
- 「窗口长度固定为 `k`」→ 只枚举起点，`n - k + 1` 个，每个 `O(1)` 判断。
- `n = 10^5`：每个起点重建剩余数组是 `O(n^2)`，不可行。

**推导链。**
1. 暴力：对每个起点拼出剩余数组，分别求偶、奇下标之和，`O(n^2)`。
2. 浪费：相邻起点的剩余数组几乎一样，每次从头算。
3. 洞察：令 `pre[i]` 为前 `i` 个元素按原下标奇偶加符号的和；窗口左边贡献 `pre[i]`，窗口右边贡献 `(-1)^k · (pre[n] - pre[i+k])`。
4. 最优：从小到大枚举起点，和为 `0` 就返回，`O(n)` 时间、`O(n)` 空间。

**同模式的题**：LC 1664 生成平衡数组的方案数、LC 724 寻找数组的中心下标、LC 238 除自身以外数组的乘积、LC 560 和为 K 的子数组。
