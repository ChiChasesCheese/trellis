## Q
**LC 428 序列化和反序列化 N 叉树**｜正确性

为什么「值 + 孩子个数」的先序编码是可逆的，而只记先序的值不行？解码用的并行栈保持什么不变量？

## A
**不变量。** 解码过程中，`nodes` 是当前根到「最近创建的结点」的链，`left[i]` 是 `nodes[i]` 还没读到的孩子数。下一个 token 对 `(值, 个数)` 一定属于栈顶中 `left > 0` 的最深结点的下一个孩子。

**为什么可逆。** 先序里，结点 `u` 的所有子树连续地排在 `u` 之后；`u` 写明了孩子数 `c`，所以读完恰好 `c` 棵完整子树就知道 `u` 结束——每棵子树又递归地自描述。结构被唯一确定。

**反例。** 两棵不同的树：`A = 1→[2,3]`（`1` 有两个孩子），`B = 1→2→3`（一条链）。
- 只记先序的值：两者都得 `1 2 3`，无法区分。
- 带孩子数：`A` 得 `1 2 2 0 3 0`，`B` 得 `1 1 2 1 3 0`，解码时前者读到 `1 2` 后期待两棵子树，后者期待一棵，结果不同。
