## Q
**有效括号字符串：判断，并输出全部方案**｜追问

含 `'('`、`')'`、`'*'`（`'*'` 可当 `'('`、`')'` 或空串）的字符串，已经能判断是否有效并输出全部不同的有效串。面试官接着问：（1）判断能不能用栈？（2）只要方案数，是取法数还是不同字符串数？（3）输出太多怎么办？（4）怎么测试？

## A
1. **栈解法**：两个栈，分别存 `'('` 和 `'*'` 的下标。遇到 `')'` 先匹配 `'('`，没有再用 `'*'`，都没有就失败。最后剩下的 `'('` 要用下标更靠后的 `'*'` 逐个配对（`'*'` 当 `')'`），任何一个 `'('` 找不到更靠后的 `'*'` 就失败。`O(n)` 时间、`O(n)` 空间，比 `[lo, hi]` 贪心长，但思路更容易讲清楚。
2. **计数**：「取法数」是 `3^k` 里合法的个数，可以用 `dp[bal]` 滚动数组，`O(n^2)`；「不同字符串数」要去重，不同取法会得到同一个串，只能像 `all_valid` 那样带着集合，或者换成只依赖输出串的状态做计数，复杂度回到输出规模。先问清题目要哪个。
3. **输出规模**：`"*" * 20` 有 `23714` 个结果，`"*" * 26` 有 `1033412` 个。写成生成器逐个 `yield`，或者只输出前 `k` 个、只输出个数；面试里先说明输出本身就是下界。
4. **测试**：写一个 `3^k` 暴力（枚举每个 `'*'` 的三种取值，检查合法性，放进集合）作参照，对 `len <= 11` 的所有随机串比较 `check_valid` 与 `all_valid`；边界用例：空串、全是 `'*'`、只有 `'('`、只有 `')'`、`")*"`、`"()*("`。

**Python 提醒**：`itertools.product("()_", repeat=k)` 一行枚举全部取法，适合写参照实现；`functools.cache` 作用在带 `str`/`int` 参数的函数上很方便，但缓存的结果如果是可变集合，调用方修改它会污染缓存，所以返回 `frozenset`。
