## Q
**圆环上走 n 步回到原点的方案数**｜Medium · 近一年被问：美国 0 次、国内 2 次 · 最近 2026-09（面试记录）

环上有 `10` 个点，编号 `0` 到 `9`。从 `0` 出发，每一步顺时针或逆时针走一个点，问恰好走 `n` 步后回到点 `0` 有多少种走法（方向序列不同就算不同）。`0 <= n <= 10^5`，答案对 `10^9 + 7` 取模。例：`n = 2` → `2`；`n = 4` → `6`；`n = 10` → `254`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「恰好 `n` 步、每步两种选择、问方案数」→ 计数型动态规划，状态是（步数，位置）。
- 「环上、顺时针或逆时针」→ 位置对 `10` 取模，转移只涉及左右两个相邻点。
- `n <= 10^5`：状态 `n × 10` 个，`O(10n)` 轻松；每一步只用上一步，滚动数组把空间压到 `O(10)`。
- 「对 `10^9 + 7` 取模」「`n` 可能很大」→ 方案数指数增长，要取模；`n` 再大就要矩阵快速幂。

**推导链。**
1. 暴力：枚举 `2^n` 种方向序列，检查净位移是否是 `10` 的倍数，`O(2^n)`。
2. 浪费：许多方向序列在同一步停在同一个点，之后的走法完全相同，却被重复展开。
3. 洞察：按当前位置合并，`f[s][p]` 是走 `s` 步停在 `p` 的方案数，`f[s+1][p] = f[s][p-1] + f[s][p+1]`。
4. 最优：滚动数组，`O(10n)` 时间、`O(10)` 空间；`n` 极大时转移矩阵快速幂。

**同模式的题**：LC 70 爬楼梯、LC 935 骑士拨号器、LC 576 出界的路径数、LC 1269 停在原地的方案数。
