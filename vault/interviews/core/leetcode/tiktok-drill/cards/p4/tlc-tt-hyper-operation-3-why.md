## Q
**手写超运算**｜正确性

为什么 `hyper(n, a, b)` 可以改写成“从基值出发，把 `hyper(n - 1, a, ·)` 迭代 `b` 次”？`b = 0` 的基值为什么每层不同，写成统一的 `1` 会错在哪里？

## A
**不变量。** 记 `F_n(b) = hyper(n, a, b)`（`a` 固定）。定义给出 `F_n(0) = base(n)`，`F_n(b) = F_{n-1}(F_n(b - 1))`。把第二条反复展开：`F_n(b) = F_{n-1}(F_{n-1}(... F_{n-1}(base(n))))`，里面恰好套了 `b` 层。循环版每轮把 `result` 换成 `F_{n-1}(result)`，做 `b` 轮，与展开式一致。

**每层基值的含义。** 基值是“迭代 0 次”的结果，必须是这一层运算的**单位元**，下一层才能迭代出正确的结果：
- 加法层 `F_1`：`a + 0 = a`，所以基值 `a`，之后 `b` 次 `+1`；
- 乘法层 `F_2`：`a * 0 = 0`，所以基值 `0`，之后 `b` 次 `+a`；
- 幂层 `F_3` 及以上：`a ** 0 = 1`，所以基值 `1`，之后 `b` 次 `*a`（`F_4` 是 `b` 次 `a **`）。

**反例：基值全写 `1`。** 这样 `hyper(1, 3, 4)` 得 `5`（应 `7`），`hyper(2, 3, 4)` 得 `5`（应 `12`），`hyper(3, 2, 3)` 得 `4`（应 `8`）。**反例：`n >= 3` 的基值写 `0`。** `hyper(3, 2, 3)` 得 `0`，应是 `8`。

**为什么 `n = 3` 的基值 `1` 能带出 `n = 4`。** `hyper(4, 2, 3)` 展开成 `2 ** (2 ** (2 ** 1))`，最里面的 `1` 就是 `hyper(4, 2, 0)`，所以 `hyper(4, 2, 3) = 16`；如果 `hyper(4, 2, 0)` 取 `0`，整座塔都会错。
