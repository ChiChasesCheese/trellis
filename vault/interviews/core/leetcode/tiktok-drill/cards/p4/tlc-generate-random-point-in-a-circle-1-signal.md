## Q
**LC 478 在圆内随机生成点**｜Medium · 近一年被问：美国 0 次、国内 1 次 · 最近 2026-09-21（国内面试记录）

实现类 `Solution(radius, x_center, y_center)` 和方法 `randPoint()`，后者返回圆内**均匀分布**的随机点 `[x, y]`（圆周上也算）。`0 < radius <= 10^8`，`-10^7 <= x_center, y_center <= 10^7`，`randPoint` 最多调用 `3 * 10^4` 次。例：`Solution(1.0, 0.0, 0.0)` 后 `randPoint()` 可能返回 `[0.82314, 0.38945]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式**
- 「均匀随机」+ 二维区域：要求的是**面积均匀**，即任意两块面积相等的区域被命中的概率相同。这是概率采样，而不是搜索。
- 区域是圆而不是矩形：矩形可以直接取两个独立的均匀数，圆不行，要么变换要么拒绝。
- 调用次数 `3 * 10^4`、每次返回一个点：每次调用要 `O(1)`，不需要预处理。
- 答案是浮点数且题面不要求精确值：判分靠统计性质，所以必须从概率上推导正确，而不是靠单个样例碰运气。

**推导链**
1. 朴素想法：半径 `r = R * U`、角度 `θ` 均匀 → 错，点会聚在圆心附近（周长随 `r` 线性增长，小圆环面积小却分到同样多的点）。
2. 拒绝采样：在外接正方形里均匀取，落在圆外就重抽。正确，期望 `4 / π ≈ 1.27` 次。
3. 直接变换：要让 `P(r <= ρ) = ρ^2 / R^2`，取 `r = R * sqrt(U)`，角度均匀（反函数法）。
4. 两者都是 `O(1)`：反函数法没有循环，拒绝法不用三角函数，面试里两个都说，写其中一个。
