## Q
**LC 875 爱吃香蕉的珂珂**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 5 次 · 最近 2026-06-04（面试记录）

`n` 堆香蕉，第 `i` 堆有 `piles[i]` 根，`h` 小时后警卫回来。珂珂以速度 `k`（根/小时）吃：每小时选一堆吃 `k` 根，不足 `k` 根就吃完这堆，这一小时不再吃别的。求能在 `h` 小时内吃完的最小整数 `k`。`1 <= piles.length <= 10^4`，`piles.length <= h <= 10^9`，`1 <= piles[i] <= 10^9`。例：`[3,6,7,11]`、`h = 8` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「求满足条件的**最小**值」，且条件对答案单调（速度越快，用的小时越少）→ 二分答案（binary search on the answer）。
- 答案范围到 `10^9` → 不能线性枚举，需要 `O(log M)` 次判定。
- 判定函数 `需要的小时数 <= h` 能在 `O(n)` 内算出，`n <= 10^4` → 总共约 `30 × 10^4` 次运算。
- `h >= piles.length` → 速度取 `max(piles)` 时每堆 `1` 小时，一定可行，上界因此确定。

**推导链。**
1. 暴力：`k = 1, 2, 3, …` 逐个判定，每个 `O(n)`，最坏 `10^9` 个速度。
2. 浪费：`k` 可行则 `k + 1` 也可行，可行性是单调的，逐个试在重复回答同一个问题。
3. 洞察：速度从小到大排成 `FFF…TTT`，二分找第一个 `T`。
4. 判定：一小时只能吃一堆，第 `p` 堆需要 `ceil(p / k)` 小时，求和与 `h` 比较。

**同模式的题**：LC 1011 在 D 天内送达包裹的能力、LC 410 分割数组的最大值、LC 1482 制作 m 束花所需的最少天数、LC 2187 完成旅途的最少时间。
