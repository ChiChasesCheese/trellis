## Q
**LC 679 24 点游戏**｜Hard · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 8 次 · 最近 2026-09-08（国内 CodeTop）

给一个长度为 `4` 的整数数组 `cards`，每个数在 `[1, 9]`。用 `+ - * /` 和括号把它们排成表达式，判断能否得到 `24`。除法是实数除法；运算符只能放在两个数字之间（不能一元负号）；数字不能拼接成多位数。`cards.length == 4`，`1 <= cards[i] <= 9`。例：`cards = [4,1,8,7]` → `true`（`(8 - 4) * (7 - 1)`）；`cards = [1,2,1,2]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**固定** `4` 个数」→ 状态空间极小，可以**穷举 / 回溯**，不用找多项式算法。
- 「运算符 + **括号**」→ 难点是括号的所有结构；任何表达式树的最后一步都是「两个子结果做一次运算」，所以**每步选两个数合并**就覆盖了全部括号方式。
- 「实数除法」→ 中间结果是分数，浮点比较 `== 24` 不可靠 → 用 `Fraction` 或误差阈值。
- 减法、除法**不满足交换律** → 每对数要试 `a - b`、`b - a`、`a / b`、`b / a`。

**推导链。**
1. 暴力：`4!` 个排列 × `4^3` 个运算符 × `5` 种括号形状 = `7680` 个表达式，能做但易漏。
2. 浪费：括号形状要单独枚举，而且不同形状会重复计算相同的子表达式。
3. 洞察：不枚举括号；每次选两个数用一种运算合并成一个，数的个数减一，剩一个时与 `24` 比较。
4. 规模：第一步 `C(4,2) = 6` 对，第二步 `3` 对，第三步 `1` 对，每对最多 `6` 种结果，叶子至多 `6·6·3·6·1·6 = 3888` 个，常数时间。

**同模式的题**：LC 282 给表达式添加运算符、LC 241 为运算表达式设计优先级、LC 494 目标和、LC 22 括号生成。
