## Q
**LC 889 从前序与后序遍历序列构造二叉树**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 6 次 · 最近 2026-08-24（美国面试记录）

给两个整数数组 `preorder` 和 `postorder`，分别是同一棵无重复值二叉树的前序和后序遍历，重构并返回这棵树（多个答案时任意一个）。`1 <= preorder.length <= 30`，`1 <= preorder[i] <= preorder.length`，两个数组各自的值互不相同，长度相等，保证来自同一棵树。例：`preorder = [1,2,4,5,3,6,7]`，`postorder = [4,5,2,6,7,3,1]` → `[1,2,3,4,5,6,7]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「由遍历序列重构二叉树」→ **分治 + 找根 + 切左右**：前序首元素、后序末元素都是根。
- 只给前序和后序（没有中序）→ 不能用「中序里根的位置切左右」，要换依据：前序第二个元素是**左子树根**，它在后序中的位置决定左子树大小。
- 「值互不相同」→ 可以用 `值 → 下标` 字典 `O(1)` 定位。
- 「多个答案任选一个」→ 提示存在歧义（只有一个孩子的结点分不清左右）；`n <= 30` 说明暴力也能过，但要给出 `O(n)`。

**推导链。**
1. 暴力：每层用 `list.index` 找位置、切片复制子数组，`O(n^2)`。
2. 浪费：重复线性查找与重复拷贝。
3. 关键观察：后序里左子树根是左子树的最后一个元素，所以左子树大小 `= post_idx[左根] - post_lo + 1`；右子树大小 `= size - 1 - 左子树大小`。
4. 最优：预建 `post_idx`；递归只传 `(pre_lo, post_lo, size)` 三个整数，`O(n)`。
