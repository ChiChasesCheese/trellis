## Q
**LC 518 零钱兑换 II**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 26 次 · 最近 2026-02-17（面试记录）

给整数数组 `coins`（不同面额）和整数 `amount`，求凑成总金额的**硬币组合数**，凑不出返回 `0`；每种面额有无限个。`1 <= coins.length <= 300`，`1 <= coins[i] <= 5000`，`coins` 中的值互不相同，`0 <= amount <= 5000`，结果保证在 32 位整数内。例：`amount = 5`、`coins = [1,2,5]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每种硬币无限个」+「凑成总额」→ **完全背包**（unbounded knapsack）。
- 「组合数」而不是「最少个数」→ 计数 DP：状态是方案数，转移是加法。
- 「`1+2` 和 `2+1` 是同一种」→ 数**组合**：必须固定硬币的顺序，用「前 `i` 种硬币」做表的行。
- `len(coins) * amount` 约 `1.5 * 10^6`：完整的二维表也轻松，不需要更巧的方法。

**推导链。**
1. 暴力：递归枚举每种硬币用几个，剩余金额继续递归，指数级。
2. 浪费：同样的（剩余金额，硬币下标）会被重复求解。
3. 洞察：`dp[i][a] = dp[i-1][a] + dp[i][a - coin_i]`——不用第 `i` 种，或者至少用一个（剩下的还能继续用第 `i` 种）。
4. 填表：第 0 列全是 `1`，第 0 行其余是 `0`；逐行填，`dp[i][a] = dp[i-1][a] + dp[i][a - coin_i]`，答案是 `dp[n][amount]`。行是「用到第几种硬币」，所以每个组合只按硬币顺序被数一次。

**同模式的题**：LC 322 零钱兑换、LC 377 组合总和 IV、LC 279 完全平方数、LC 494 目标和。
