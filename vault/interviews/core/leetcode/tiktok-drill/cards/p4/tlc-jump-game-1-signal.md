## Q
**LC 55 跳跃游戏**｜Medium · LC TikTok 热度 50/100（近 6 个月） · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 28 次 · 最近 2026-04-18（CodeTop）

给非负整数数组 `nums`，你最初位于第一个下标，`nums[i]` 是你在位置 `i` 可以向前跳的**最大**长度。判断能否到达最后一个下标。`1 <= nums.length <= 10^4`，`0 <= nums[i] <= 10^5`。例：`nums = [3,2,1,0,4]` → `false`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「能否到达」+「每步**最多**跳多远」→ **可达性问题**，适合**贪心**：区间内的每一步都可选，所以可达位置不会出现空洞，可达集合是前缀 `[0, reach]`。
- 一旦走到某个位置发现它超过了 `reach` → 前面谁也跳不到这里 → 立刻判负。
- `n = 10^4`、跳跃长度到 `10^5` → 逐格标记的暴力最坏是 `10^9`，不可行；目标 `O(n)`。

**推导链。**
1. 暴力：`dp[j]` 表示下标 `j` 可达，每个可达的 `i` 把 `i + 1` 到 `i + nums[i]` 全标记，`O(n * 最大跳跃)`。
2. 浪费：逐格标记大量重复，而且标记出来的集合永远是连续前缀。
3. 洞察：只需要知道集合的右端点 `reach`。
4. 扫描下标 `i`：若 `i > reach`，之后全不可达，返回 `False`；否则 `reach = max(reach, i + nums[i])`。
5. 扫描完没被卡住 → `True`。`O(n)` 时间，`O(1)` 空间。
