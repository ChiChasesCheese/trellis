## Q
**LC 323 无向图中连通分量的数目**｜正确性

并查集解法里，为什么 `comps -= 1` 只能放在「两端根不同」的分支里？为什么不能直接用 `n - len(edges)`？

## A
**不变量。** 任意时刻，`comps` 等于 `parent` 表示的不相交集合个数；每个集合恰好对应已处理的边所构成的一个连通分量。

**为什么只在根不同时减一。** 连接两个不同集合的边把它们并成一个，集合数恰好少一。两端已在同一集合（根相同）时，这条边只是在分量内部多加了一条（成环），集合数不变，所以不能减。

**反例：`n - len(edges)`。** 它假设每条边都连接了两个不同的分量，即图是森林。有环就错：`n = 5`，`edges = [[0,1],[1,2],[0,2],[3,4]]`：
- `5 - 4 = 1`。
- 实际分量是 `{0,1,2}` 和 `{3,4}`，共 `2` 个。并查集处理 `[0,2]` 时两端同根，不减，得到 `2`。

**另一个陷阱。** 不比较根而直接比较端点（`a != b`）：题目保证 `a != b`，条件恒真，等价于上面的错误公式。
