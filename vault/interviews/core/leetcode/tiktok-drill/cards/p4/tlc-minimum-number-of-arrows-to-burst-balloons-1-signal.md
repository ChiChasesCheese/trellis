## Q
**LC 452 用最少数量的箭引爆气球**｜Medium · CodeTop 国内累计 7 次 · 最近 2026-09-02（国内 CodeTop）

气球在 `x` 轴上的水平直径记为 `points[i] = [xstart, xend]`。在坐标 `x` 沿竖直方向射一支箭，会引爆所有满足 `xstart <= x <= xend` 的气球，箭数不限。求引爆所有气球所需的最少箭数。`1 <= points.length <= 10^5`，`-2^31 <= xstart < xend <= 2^31 - 1`。例：`[[10,16],[2,8],[1,6],[7,12]]` → `2`；`[[1,2],[2,3],[3,4],[4,5]]` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「若干区间」+「用最少的点把**每个区间都穿到**」→ **区间贪心**（等价于 LC 435：最多能选多少个两两不相交的区间）。
- `n = 10^5` → 只能 `O(n log n)`：**排序** + 一次扫描。
- 区间是**闭**的，端点相接也算被同一支箭射到 → 比较时的等号方向是关键。
- 坐标范围到 `±2^31` → 在定宽整数语言里，排序比较用减法会溢出。

**推导链。**
1. 暴力：射点只需取端点，在候选里选最少的一组覆盖全部，是集合覆盖形状，组合爆炸。
2. 洞察（交换论证）：右端点最小的气球 `b` 必须被射中；把这支箭移到 `b.end`，不会少射爆任何气球（别的气球右端点都不小于 `b.end`，含有原射点就一定含有 `b.end`）。
3. 所以按**右端点**排序，第一支箭射在第一个气球的右端点，射爆所有左端点不超过它的气球，再对剩下的重复。
4. 扫描：`start > last` 就新射一支并更新 `last = end`；总时间 `O(n log n)`。

**同模式的题**：LC 435 无重叠区间、LC 56 合并区间、LC 646 最长数对链、LC 1288 删除被覆盖区间。
