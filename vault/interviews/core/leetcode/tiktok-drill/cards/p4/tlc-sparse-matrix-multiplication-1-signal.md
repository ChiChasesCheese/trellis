## Q
**LC 311 稀疏矩阵的乘法**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-10-27（面试记录）

`mat1` 是 `m x k`、`mat2` 是 `k x n` 的**稀疏**矩阵（大部分是 0），返回乘积。`1 <= m, n, k <= 100`，元素范围 `-100..100`。例：`[[1,0,0],[-1,0,3]] x [[7,0,0],[0,0,0],[0,0,1]]` → `[[7,0,0],[-7,0,3]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「稀疏」→ 把零当成不存在：**只处理非零元素**，用压缩存储（每行只留 `(列号, 值)`）。
- 矩阵乘法 `res[i][j] = Σ_k A[i][k] * B[k][j]` 是**求和**，乘积为 0 的项不影响结果 → 可以整项跳过。
- 数据范围只有 `100`：朴素 `O(m*k*n)` 约 `10^6` 也能过；面试考的是你能不能利用稀疏性、写对循环顺序。

**推导链。**
1. 暴力：`i, j, k` 三重循环，`O(m*k*n)`，零乘零也算。
2. 浪费：`A[i][k] == 0` 时，这一条 `k` 对第 `i` 行的 `n` 个结果都没贡献，却白做 `n` 次乘法。
3. 循环顺序改成 `i → k → j`：在 `k` 层判断 `A[i][k] == 0` 就整条跳过。
4. 内层也只需要 `B[k]` 的非零列：预处理成 `rows2[k] = [(j, 值), ...]`，一次性做好，别在每个 `(i, k)` 上重新扫。

**同模式的题**：LC 1570 两个稀疏向量的点积、LC 54 螺旋矩阵、LC 48 旋转图像。
