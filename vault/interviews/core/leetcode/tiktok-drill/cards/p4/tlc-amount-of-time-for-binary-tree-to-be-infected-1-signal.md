## Q
**LC 2385 感染二叉树需要的总时间**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-01-29（美国面试记录）

二叉树 `root` 的节点值互不相同，给定整数 `start`。第 `0` 分钟值为 `start` 的节点被感染，之后每分钟，与已感染节点相邻（父子）且尚未感染的节点被感染。返回感染整棵树所需的分钟数。节点数在 `[1, 10^5]`，`1 <= Node.val <= 10^5`。例：`root = [1,5,3,null,4,10,6,9,2]`，`start = 3` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每分钟向相邻节点蔓延一圈」→ **BFS 按层推进**，层数 = 分钟数。
- 感染会向上传给父亲 → 二叉树没有父指针，要**转成无向图**或记录父节点。
- 「节点值互不相同」→ 可直接用值当图中的节点编号，不需要给节点另编号。
- 节点数 `10^5` 且可能是链 → 递归建图最直观，但深度可达 `10^5`，超过默认递归上限约 `1000`：调大上限，或建图用显式栈（见追问）。

**推导链。**
1. 暴力：对每个节点求到 `start` 的距离（要找最近公共祖先），再取最大值。
2. 转化：感染 = 以 `start` 为源点的最短路，所有边权为 `1`，答案是最远节点的距离（图的偏心率）。
3. 遍历树时把每条父子边双向写入邻接表 `graph`。
4. 从 `start` 做 BFS，一次弹出一整层代表过一分钟，`seen` 防止回头；起点那层是第 `0` 分钟，所以层数减一，`O(n)`。

**同模式的题**：LC 863 二叉树中所有距离为 K 的结点、LC 1740 找到二叉树中的距离、LC 994 腐烂的橘子、LC 542 01 矩阵。
