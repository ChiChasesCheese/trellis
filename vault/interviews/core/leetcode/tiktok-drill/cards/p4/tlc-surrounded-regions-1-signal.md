## Q
**LC 130 被围绕的区域**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 7 次 · 最近 2026-09（面试记录）

给一个 `m x n` 的矩阵 `board`，由字符 `'X'` 和 `'O'` 组成。水平或垂直相邻算相连，连在一起的 `'O'` 构成一个区域；如果一个区域里所有 `'O'` 都不在棋盘边缘，它就被 `'X'` 围绕。把所有被围绕的区域原地填充成 `'X'`。`1 <= m, n <= 200`。例：`[["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]` → 只剩最下面一行的 `'O'`（它在边缘）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「区域」「相连」→ 连通块：BFS / DFS / 并查集。
- 「被围绕」= 「整个连通块都不碰边缘」→ 判断条件是**否定**的，反过来找「碰到边缘的」更容易：边缘的 `'O'` 是明确的起点。
- 「原地修改、不用返回」→ 用临时字符（`'#'`）同时当访问标记和保留标记，最后统一改回。
- `m·n` 最多 `4 * 10^4`：`O(m·n)` 的递归 DFS 足够；最坏递归深度会超过 Python 的默认上限，需要调高上限或改用队列迭代。

**推导链。**
1. 暴力：对每个未访问的内部 `'O'` 搜出整个连通块，记录是否碰到边缘，没碰到就整块改成 `'X'`；要存连通块的格子。
2. 浪费：需要两件事（找块、判断是否碰边缘）和额外的存储。
3. 洞察：与边缘相连的 `'O'` 起点明确；从它们出发搜一遍，标成 `'#'`；之后剩下的 `'O'` 一定被围绕。
4. 最优：从边缘做一次 DFS 加一遍扫描，`O(m·n)` 时间，不需要额外的 `visited` 数组。

**同模式的题**：LC 200 岛屿数量、LC 417 太平洋大西洋水流问题、LC 1020 飞地的数量、LC 1254 统计封闭岛屿的数目。
