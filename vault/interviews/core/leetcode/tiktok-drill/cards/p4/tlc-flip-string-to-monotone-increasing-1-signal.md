## Q
**LC 926 将字符串翻转到单调递增**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 1 次 · 最近 2026-10（国内面试记录）

二进制字符串由若干个 `0` 后面跟若干个 `1`（两段都可以为空）组成时，称为单调递增。给二进制字符串 `s`，每次可以把一个 `0` 翻成 `1` 或把一个 `1` 翻成 `0`，返回使 `s` 单调递增的最少翻转次数。`1 <= s.length <= 10^5`，`s[i]` 为 `'0'` 或 `'1'`。例：`"010110"` → `2`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「单调递增的 0/1 串」→ 目标形状固定为 `0...01...1`，只差一个分界点：枚举分界点 + 前缀和。
- 「两个方向的翻转都允许、求最少次数」→ 每个字符要么保持、要么翻转，位置之间独立，代价可以按字符累加。
- `n = 10^5`：`O(n^2)` 逐个分界点重数会超时，要 `O(n)`。
- 代价只依赖前缀 → 可以压成一遍扫描、`O(1)` 状态的 DP。

**推导链。**
1. 暴力：枚举所有 `2^n` 个目标串，或对每个分界点 `k` 数左边的 `1` 与右边的 `0`，`O(n^2)`。
2. 浪费：相邻两个分界点的计数只差一个字符，却每次重新数。
3. 前缀和：`ones[k]` 为 `s[:k]` 中 `1` 的个数，分界点 `k` 的代价是 `ones[k] + 右边的 0 的个数`，`O(n)` 时间、`O(n)` 空间。
4. 洞察：`flips` 表示前缀单调化的最少翻转。追加 `'1'` 不增加代价；追加 `'0'` 要么翻成 `1`（`flips + 1`），要么保持 `0`（前面所有 `1` 都翻掉，代价 `ones`），取较小者。
5. 最优：只保留 `ones` 与 `flips` 两个变量，`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 1653 使字符串平衡的最少删除次数、LC 2483 商店的最少代价、LC 1888 使二进制字符串字符交替的最少反转次数。
