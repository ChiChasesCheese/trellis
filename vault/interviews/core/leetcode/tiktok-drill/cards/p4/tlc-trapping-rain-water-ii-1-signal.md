## Q
**LC 407 接雨水 II**｜Hard · LC 字节 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 3 次 · 最近 2026-08-31（国内面试记录）

`m × n` 高度图 `heightMap`，每格是非负整数高度。下雨后，水只能向上下左右流动，流出边界即消失。求整张图最多能存下的水的体积。`1 <= m, n <= 200`，`0 <= heightMap[i][j] <= 2 * 10^4`。例：`[[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]` → `4`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「接雨水」的二维推广：一维（LC 42）用左右最高的较小值，但二维里水可以沿**任意弯曲路径**流出，不能按行列分开算。
- 一格的水位 = 从它到边界的所有路径中，**路径最高点**的最小值（木桶：最矮的出口决定水位）→ 这是 **minimax 路径**，用 **Dijkstra / 最小堆**求。
- 「水流出边界就没了」→ 最外圈是水位已知的起点（水位 = 自身高度）：从边界向内扩展。
- `m, n <= 200`：`4 · 10^4` 格，`O(N log N)` 轻松。

**推导链。**
1. 暴力：对每格枚举到边界的所有路径，指数级。
2. 误区：`min(行最大, 列最大) − h`（一维思路）错在忽略绕路流出，示例 1 会多算。
3. 洞察：围墙里最矮的一格 `w` 最先决定它邻居的水位——邻居的水位 `= max(w, 邻居高度)`，没有更低的出口能让水位更低。
4. 最优：最外圈入小根堆；每次弹出最矮的围墙，遍历未访问的邻居：累加 `max(0, w − 邻居高度)`，邻居以 `max(w, 邻居高度)` 入堆。每格进出堆一次，`O(mn log(mn))`。

**同模式的题**：LC 42 接雨水、LC 778 水位上升的泳池中游泳、LC 1631 最小体力消耗路径、LC 743 网络延迟时间。
