## Q
**LC 1247 交换字符使得字符串相同**｜正确性

为什么一个 `xy` 配一个 `yx` 要两次交换，而不是一次？为什么不匹配位置数是奇数就无解？如果写成「不匹配位置数的一半」会错在哪里？

## A
**不变量。** 每次交换最多同时修好两个不匹配位置，并且只有"同类"的两个位置才能一次修好。

**同类一次。** 位置 `i`、`j` 都是 `xy`（`s1` 是 `x`，`s2` 是 `y`）。交换 `s1[i]` 与 `s2[j]`：位置 `i` 变成 `(y, y)`，位置 `j` 变成 `(x, x)`，两个都修好。

**异类要两次。** 位置 `i` 是 `xy`（`s1[i] = x`，`s2[i] = y`），位置 `j` 是 `yx`（`s1[j] = y`，`s2[j] = x`）。跨串的交换里，能让位置 `i` 变化的，要么是 `s1[i]` 与 `s2[j]`（`x` 换 `x`，什么也没变），要么是 `s2[i]` 与 `s1[j]`（`y` 换 `y`，同样没变），要么动到位置 `i` 自己的两个字符，所以没有任何一次交换能同时修好 `i` 和 `j`。必须先交换 `s1[i]` 与 `s2[i]`，把位置 `i` 变成 `yx` 类，再用一次同类配对，共 `2` 次。

**为什么奇数无解。** 每个不匹配位置恰好含一个 `x`，匹配位置含 `0` 个或 `2` 个 `x`。两串的 `x` 总数的奇偶性由不匹配位置数决定；相同的两串 `x` 数相等，总数必为偶数，所以不匹配位置数必须是偶数。

**反例：用一半。** `s1 = "xy"`，`s2 = "yx"`：
- 不匹配位置有 `2` 个，一半是 `1`，错误。
- 实际要 `2` 次：交换 `s1[0]` 与 `s2[0]` 得到 `"yy"` 与 `"xx"`，再交换 `s1[0]` 与 `s2[1]` 得到 `"xy"` 与 `"xy"`。
