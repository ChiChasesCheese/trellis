## Q
**LC 2816 翻倍以链表形式表示的数字**｜正确性

为什么「右邻居 `>= 5`」恰好等于传给当前位的进位？把阈值写成 `> 5` 会错在哪里？为什么需要哑头？

## A
**不变量。** 处理到第 `i` 位时，它右边所有位还保持原值，而右邻居 `d` 翻倍后产生的进位 `= (2d + 右边的进位) // 10`。因为 `2d + 进位 <= 19`，进位只能是 `0` 或 `1`；再看阈值：右边的进位 `c` 只能是 `0` 或 `1`，`d = 4` 时 `2d + c <= 9` 不进位，`d = 5` 时 `2d = 10` 必进位。因此进位等价于 `d >= 5`，与再右边的进位无关。

**哑头。** 最高位若进位，结果比原数多一位；值为 0 的哑头翻倍后 `= 0*2 + 进位 = 1`，正好成为新的最高位；没有进位时哑头仍为 0，返回 `dummy.next`。

**反例。** 阈值写成 `> 5`：
- 输入 `[5]`（数字 5，翻倍 10）：正确 `[1,0]`；错误版哑头得不到进位，输出 `[0]`。
- 输入 `[2,5]`（25 翻倍 50）：正确 `[5,0]`；错误版输出 `[4,0]`。
`d = 5` 时 `2*5 = 10` 正好进位，是边界。
