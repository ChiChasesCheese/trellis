## Q
**LC 494 目标和**｜正确性

为什么 01 背包的转移必须读**上一行** `dp[i-1][j-x]`？转成子集和之前，为什么要先判断 `(sum + target)` 的奇偶和范围？给出读错行的具体输入和输出。

## A
**不变量。** `dp[i][j]` 是只用前 `i` 个数、和恰为 `j` 的子集数。第 `i` 个数要么不选，方案数是 `dp[i-1][j]`；要么选，剩下的和 `j - x` 只能由前 `i - 1` 个数凑出，方案数是 `dp[i-1][j-x]`。两类互斥且完备，所以 `dp[i][j] = dp[i-1][j] + dp[i-1][j-x]`，每个数至多被选一次。

**为什么读同一行出错。** 若写成 `dp[i][j-x]`，剩下的和 `j - x` 仍然可以用第 `i` 个数凑出，等于允许同一个数选多次（完全背包）。

**反例：读同一行。** `nums = [1,1,1,1,1]`，`target = 3`，`need = (5 + 3) / 2 = 4`：
- 正确：从 5 个 1 里选 4 个，`C(5,4) = 5` 种。
- 读同一行：每个 `1` 可以重复使用，计出的是「用若干次这些 1 凑出 4」的次数，结果 `70`。

**为什么要先判奇偶和范围。** `P = (S + target) / 2` 必须是非负整数，因为 `P` 是子集和。`[1,2]`，`target = 4`：`S + target = 7` 是奇数，没有整数解，正确答案 `0`；若直接写 `(3 + 4) // 2 = 3`，会数出子集 `{1,2}`，得到 `1`。`[1,1]`，`target = -3`：`(2 - 3) // 2 = -1`，每行长度 `0`，写 `dp[0][0] = 1` 直接抛 `IndexError`。

**边界。** 第 0 行是「一个数都没有」：`dp[0][0] = 1`（什么都不选，和为 `0`），其余为 `0`。忘了它，整张表恒为 `0`：`[1,1,1,1,1]`，`3` 得到 `0`，正确是 `5`。
