## Q
**LC 430 扁平化多级双向链表**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-07-18（面试记录）

双向链表的每个节点有 `val`、`prev`、`next` 和一个 `child` 指针；`child` 可能指向另一条独立的双向链表，子链表里的节点也可以再有 `child`，层层嵌套。把它扁平化成单层双向链表：带子链表的节点 `curr` 的子链表要出现在 `curr` 之后、`curr.next` 之前，所有 `child` 置为 `null`，返回扁平链表的头。节点数不超过 `1000`，`1 <= Node.val <= 10^5`，输入可能为空。例：`1-2-3-4-5-6`，`3` 的子链表是 `7-8-9-10`，`8` 的子链表是 `11-12` → `[1,2,3,7,8,11,12,9,10,4,5,6]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「子链表出现在 `curr` 之后、`curr.next` 之前」→ 先序顺序（当前 → `child` → `next`）；本质是把一条链表整段插入另一条链表的中间。
- 「返回头、`child` 置空、双向」→ 原地改指针，同时维护 `prev` 与 `next`，不是新建节点。
- 节点数 `<= 1000`：`O(n)` 时间足够；`child` 指向的是同样结构的子问题，最直觉的是递归，让子问题返回展平后的尾巴；最坏嵌套 1000 层会撞 Python 递归上限，面试里要说出来，并给出 `O(1)` 空间的迭代备选。

**推导链。**
1. 暴力：递归先序把所有节点收进数组，再按顺序重连 `prev`/`next`，`O(n)` 时间、`O(n)` 空间。
2. 浪费：数组只是为了记住「子链表走完后该接谁」，而答案就是 `curr.next`，遇到 `child` 的当场就知道。
3. 洞察：整条子链表插进 `curr` 与 `curr.next` 之间，只需要子链表的尾巴：`tail.next = curr.next`，再改 `curr` 与子链表头的两个指针，一共 4 个指针。让递归的子问题把「展平后的尾巴」返回给父层，父层就不用自己去找尾巴。
4. 最优：`dfs(node)` 沿 `next` 往后走，遇到 `child` 先递归展平它、再整段接进去，尾巴更新为子链表的尾巴；每个节点只访问一次，`O(n)` 时间，`O(嵌套深度)` 栈空间。备选：不递归，单指针边走边找尾巴再接上，`O(1)` 空间。
