## Q
**货币兑换查询**｜Medium · 近一年被问：美国 3 次、国内 0 次 · 最近 2026-01-05（面试记录）

给若干货币对和汇率：`pairs[i] = (a, b)`、`rates[i] = r` 表示 `1` 单位 `a` 可兑换 `r` 单位 `b`（`r > 0`），反方向是倒数。再给若干查询 `(from, to)`，返回换算比率，可以经过多个货币相乘；不连通或有货币从未出现，返回 `-1.0`。`1 <= len(pairs), len(queries) <= 10^5`，汇率互相不矛盾，允许 `1e-5` 的误差。例：`[("USD","JPY")]`、`[108.0]`，查询 `USD->JPY` → `108.0`，`JPY->USD` → `1/108.0`，`USD->GBP` → `-1.0`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「汇率可以多跳相乘、反向取倒数、不连通返回 `-1`」→ 带权图上的连通性与路径乘积，与 LC 399（除法求值）同型。
- 「汇率不矛盾」→ 任意路径的乘积相同，连通块里每个货币到根的比率是确定的 → 带权并查集（weighted union-find）。
- 查询数 `10^5`：每个查询跑一次 BFS/DFS 是 `O(Q · (V + E))`，太慢；并查集查询近似 `O(1)`。
- 货币是字符串、未知货币要返回 `-1.0` → 用字典存 `parent` 和 `ratio`，查询前先判断是否出现过。

**推导链。**
1. 暴力：建带权无向图（反向边取倒数），每个查询 BFS/DFS 一次，`O(Q · (V + E))`。
2. 浪费：同一连通块内任意两个货币的比率早已确定，却每次重新走路径。
3. 洞察：每个货币只记「到根的比率」；查 `from -> to` 就是 `ratio[from] / ratio[to]`；合并时 `1 ra = rate · ratio[b] / ratio[a]` 个 `rb`；`find` 递归走到根，回溯时做路径压缩，同步把比率乘到根。
4. 最优：近似 `O((P + Q) · α)`，`α` 是反阿克曼函数。

**同模式的题**：LC 399 除法求值、LC 990 等式方程的可满足性、LC 1202 交换字符串中的元素、LC 3387 两天内转换后的最大货币量。
