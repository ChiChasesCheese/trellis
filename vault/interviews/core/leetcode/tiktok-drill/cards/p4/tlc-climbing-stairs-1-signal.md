## Q
**LC 70 爬楼梯**｜Easy · LC TikTok 热度 62/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 40 次 · 最近 2026-09-19（CodeTop）

爬 `n` 阶楼梯到楼顶，每次可以爬 `1` 阶或 `2` 阶，问有多少种不同的方法。`1 <= n <= 45`。例：`n = 3` → `3`（`1+1+1`、`1+2`、`2+1`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「有多少种方法」→ **计数**，不是求最优，用加法合并子问题。
- 「每次 `1` 或 `2` 阶」→ 按**最后一步**分类：最后一步迈 `1` 阶，之前是 `f(n-1)`；迈 `2` 阶，之前是 `f(n-2)`。两类不重不漏，相加。
- 状态只有一个量「还差几阶」，且只依赖前两项 → **一维 DP**，可以滚动成两个变量。
- `n <= 45` → 答案 `f(45) = 1836311903` 刚好在 `int32` 范围内，提示结果是斐波那契级别；`n` 小也提示「直接递归会很慢但 DP 很轻」。

**推导链。**
1. 暴力：递归 `f(n) = f(n-1) + f(n-2)`，调用树指数级。
2. 浪费：`f(n-2)` 在 `f(n)` 的两个分支里各被重算；整棵树里同一个子问题重复出现。
3. 洞察：每个 `f(k)` 只依赖 `f(k-1)`、`f(k-2)`，自底向上从 `f(0) = 1`、`f(1) = 1` 推。
4. 最优：循环 `n - 1` 次，只保留两个变量，`O(n)` 时间、`O(1)` 空间；`n` 极大时用矩阵快速幂 `O(log n)`。

**同模式的题**：LC 746 使用最小花费爬楼梯、LC 198 打家劫舍、LC 509 斐波那契数、LC 1137 第 N 个泰波那契数、LC 62 不同路径。
