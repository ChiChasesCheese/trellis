## Q
**手写超运算**｜Hard · 近一年被问：美国 0 次、国内 1 次 · 最近 2026-10（面试记录）

实现超运算 `hyper(n, a, b)`（`n`、`a`、`b` 为非负整数，`n <= 5`，输入保证结果在可计算范围内）：`hyper(0, a, b) = b + 1`；`b = 0` 时 `hyper(1, a, 0) = a`、`hyper(2, a, 0) = 0`、`hyper(n, a, 0) = 1`（`n >= 3`）；其余 `hyper(n, a, b) = hyper(n - 1, a, hyper(n, a, b - 1))`。由此 `n = 1, 2, 3` 分别是加法、乘法、幂，`n = 4` 是迭代幂（`a` 的 `b` 层塔）。只允许在 `n = 0` 用 `+1`。例：`hyper(3, 2, 3) = 8`，`hyper(4, 2, 4) = 65536`。给出递归写法，并讨论递归深度、结果规模和怎样改成迭代。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「每层由下一层构造」「自变量里又调用自己」→ **嵌套递归**，阿克曼函数（Ackermann function）一类的定义；考点是读懂定义，不是套算法模板。
- 「`b = 0` 的值」每层不同（`a`、`0`、`1`）→ 基值要逐层写对，这是最容易错的地方。
- 「讨论递归深度、结果规模」→ 增长比指数还快：深度随结果大小增长，大整数很快装不下，要会估算并拒绝。
- 「怎样改成迭代」→ 每层就是“把下一层迭代 `b` 次”：沿 `b` 的递归改成 `for`，沿 `n` 的递归保留或换显式栈。

**推导链。**
1. 暴力：照定义递归。`hyper(1, a, b)` 要递归 `b` 层，答案 `a + b`，所以 `hyper(1, 2, 5000)` 就栈溢出。
2. 浪费：沿 `b` 的递归只是循环，每一层调用只是在重复 `b` 次同样的动作。
3. 洞察一：`hyper(n, a, b)` = 从基值出发，对 `hyper(n - 1, a, ·)` 迭代 `b` 次；用 `for` 取代沿 `b` 的递归，递归深度降到 `n`。
4. 洞察二：层 `1` 到 `3` 有闭式（`a + b`、`a * b`、`a ** b`），直接用内置运算；只有 `n >= 4` 才真正迭代，并在结果过大时拒绝计算。

**同模式的题**：LC 50 快速幂、LC 372 超级次方、LC 43 字符串相乘、LC 29 两数相除。
