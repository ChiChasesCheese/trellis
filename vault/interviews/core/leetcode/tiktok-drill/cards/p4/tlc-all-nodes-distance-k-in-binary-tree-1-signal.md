## Q
**LC 863 二叉树中所有距离为 K 的结点**｜Medium · LC TikTok 热度 46/100（近 30 天） · CodeTop 国内累计 10 次 · 最近 2025-09-17（国内 CodeTop）

给一棵二叉树的根结点 `root`、树中的一个目标结点 `target` 和一个整数 `k`，返回到 `target` 距离恰为 `k` 的所有结点的值（距离 = 两结点间路径的边数，可以向上走也可以向下走），答案顺序任意。

约束：结点数在 `[1, 500]`，`0 <= Node.val <= 500`，所有 `Node.val` 互不相同，`target` 是树上的结点，`0 <= k <= 1000`。

例：`root = [3,5,1,6,2,0,8,null,null,7,4], target = 5, k = 2` → `[7,4,1]`（`7`、`4` 在 `5` 的下面两层，`1` 要先上到 `3` 再下到 `1`）；`root = [1], target = 1, k = 3` → `[]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「到 `target` 距离为 `k`」且距离可以**往上走**——树结构里没有向上的边，说明要把树当作无向图，先补父指针。
- 「恰好 `k` 步 / 第 `k` 层」是**BFS 分层**的问法：每扩一层距离加 1，扩 `k` 层停下，不需要距离数组。
- `n ≤ 500`、`k ≤ 1000`：规模很小，任何线性的解都过；`k` 可能远大于树高，要保证 `frontier` 空了以后不出错。

**推导链。**
1. 暴力：对每个结点求它与 `target` 的距离（先求最近公共祖先，再用深度差），共 `O(n^2)`。
2. 浪费：这些距离都是同一个源点 `target` 出发的，一次单源搜索就够了，不必逐结点配对。
3. 洞察：树是无向无环图，所有边权为 1；缺的只是向上的边——一遍 DFS 记 `parent` 就补齐了。
4. 最优：从 `target` 出发 BFS 扩 `k` 层，`seen` 防回头，剩下的 `frontier` 就是答案，`O(n)` 时间 `O(n)` 空间。

**同模式的题**：LC 236 二叉树的最近公共祖先、LC 1740 找到二叉树中两个结点的距离、LC 2385 感染二叉树需要的总时间、LC 742 二叉树最近的叶节点。
