## Q
**LC 389 找不同**｜Easy · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 1 次 · 最近 2026-08-24（面试记录）

字符串 `s`、`t` 只含小写字母，`t` 由 `s` 重排后在随机位置多插入一个字母得到，找出多出来的字母。`0 <= s.length <= 1000`，`t.length == s.length + 1`。例：`s = "abcd"`、`t = "abcde"` → `"e"`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式**
- 「重排」：与顺序无关，只看每个字符出现的**次数**，排除任何依赖位置的做法。
- 「多出一个」：成对抵消的结构，对应异或（XOR）或求和之差，不需要完整的计数表。
- 「只含小写字母」：字符集 26，计数表 `O(26)` 也算 `O(1)`，可以退而用数组计数。
- `n <= 1000`：任何 `O(n)` 或 `O(n log n)` 都够，甚至排序后逐位比较（`O(n log n)`）也行。

**推导链**
1. 暴力：对 `t` 的每个字符统计它在 `s` 和 `t` 中的次数，次数不同的就是答案，`O(n^2)`。
2. 哈希计数：`Counter(t) - Counter(s)`，`O(n)` 时间、`O(Σ)` 空间。
3. 浪费：只要「落单的那一个」，不需要所有字母的计数。
4. 求和之差：`sum(t) - sum(s)` 是答案的编码；异或把相同字符成对抵消，只留下落单的字符。`O(n)` 时间、`O(1)` 空间。

**同模式的题**：LC 136 只出现一次的数字、LC 268 丢失的数字、LC 260 只出现一次的数字 III、LC 242 有效的字母异位词。
