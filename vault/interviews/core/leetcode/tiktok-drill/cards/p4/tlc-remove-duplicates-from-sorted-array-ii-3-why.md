## Q
**LC 80 删除有序数组中的重复项 II**｜正确性

为什么只和 `nums[w - 2]` 比较就能保证每个值最多出现两次？如果改成和原数组里的 `nums[i - 2]` 比较（`i` 是读指针的下标），会错在哪？

## A
**不变量。** 每次循环开始时，`nums[:w]` 是升序的，且每个值最多出现两次；读指针 `i >= w`，`nums[w:i]` 已经没用。

**为什么看 `nums[w - 2]` 就够。** 新元素 `x` 不小于结果里所有元素（升序）。若 `x` 在结果里已经出现过两次，这两个 `x` 一定排在结果最末尾，即 `nums[w - 2] == nums[w - 1] == x`；反过来，只要 `x != nums[w - 2]`，结果里的 `x` 至多一个（只能是 `nums[w - 1]`），再写一个仍合法。

**反例：和原数组的 `nums[i - 2]` 比较。** 写成 `if i < 2 or nums[i] != nums[i - 2]`，而写入又发生在同一个数组上，`nums[i - 2]` 可能已经被覆盖成别的值。`nums = [1,1,1,2,2]`：
- 读 `i = 2`（`x = 1`），`nums[0] = 1` 相等，丢弃；
- 读 `i = 3`（`x = 2`），`nums[1] = 1` 不等，写到 `nums[2]`，数组变成 `[1,1,2,2,2]`；
- 读 `i = 4`（`x = 2`），此时 `nums[2]` 已被改成 `2`，相等，被误丢弃。
结果长度 `3`、内容 `[1,1,2]`，而正确答案是长度 `4`、内容 `[1,1,2,2]`。

**反例：只和 `nums[w - 1]` 比较。** 这样每个值只保留一个：`[1,1,1,2,2,3]` 得到长度 `3`、内容 `[1,2,3]`，而正确是长度 `5`。
