## Q
**LC 115 不同的子序列**｜Hard · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 5 次 · 最近 2026-10（国内面试记录）

给两个字符串 `s` 和 `t`，统计并返回在 `s` 的**子序列**中 `t` 出现的个数（不同下标选出的相同字符串算不同的方案）。保证结果在 32 位有符号整数范围内。`1 <= s.length, t.length <= 1000`，由英文字母组成。例：`s = "rabbbit", t = "rabbit"` → `3`；`s = "babgbag", t = "bag"` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**统计**一个串作为另一个串的子序列出现了多少次」→ **双序列计数 DP**，状态是一对前缀 `(i, j)`（与求最大值的 LCS 同形，转移改成加法）。
- 「方案数」+「保证不超过 32 位」→ 不需要取模，但要用精确的加法。
- `1000 × 1000` → `O(mn) = 10^6` 可行；枚举下标组合 `C(m, n)` 不行。
- 近似信号：只问「是不是子序列」是 LC 392 的双指针；问最长公共子序列长度是 LC 1143。

**推导链。**
1. 暴力：枚举 `s` 里所有长度为 `|t|` 的下标组合，和 `t` 比较，指数级。
2. 递归 `f(i, j)`：`s[i] == t[j]` 时可以「用」它配 `t[j]` 或「不用」，两条路的方案数相加；不等只能「不用」。
3. 浪费：同一个 `(i, j)` 被反复求解 → 填表 `dp[i][j] = dp[i-1][j] + (s[i-1] == t[j-1]) * dp[i-1][j-1]`，`O(mn)`。
4. 边界：第 0 列全是 `1`（`t` 为空，什么都不选），第 0 行其余是 `0`；答案是 `dp[m][n]`，时间和空间都是 `O(mn)`。

**同模式的题**：LC 392 判断子序列、LC 1143 最长公共子序列、LC 72 编辑距离、LC 97 交错字符串。
