## Q
**LC 230 二叉搜索树中第 K 小的元素**｜Medium · CodeTop 国内累计 23 次 · 最近 2024-04-10（国内 CodeTop）

给二叉搜索树的根节点 `root` 和整数 `k`，返回树中第 `k` 小的元素（`k` 从 `1` 开始）。节点数 `n`，`1 <= k <= n <= 10^4`，`0 <= Node.val <= 10^4`。例：`root = [3,1,4,null,2]`、`k = 1` → `1`。进阶：树经常被修改且要频繁查第 `k` 小。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「二叉搜索树」+「第 k 小」→ **中序遍历**：BST 的中序（左、根、右）是升序序列，第 `k` 个出栈的节点就是答案。
- 只要前 `k` 个 → 数到第 `k` 个立刻停，不必遍历整棵树（提前终止）。
- 递归中序最直观；`n <= 10^4` 的链状 BST 深度 `10^4`，超过 CPython 默认递归上限约 `1000`，要调高上限或改成「迭代 + 显式栈」。
- 进阶「频繁修改、频繁查询」→ 在节点里存**子树大小**（顺序统计树，order-statistic tree），查询 `O(h)`。

**推导链。**
1. 暴力：收集全部值，排序，取第 `k - 1` 位，`O(n log n)`。
2. 浪费：BST 本身已经有序，排序是重复劳动。
3. 洞察：中序遍历天然升序，`O(n)` 收集即可；更好的是递归中序边遍历边数，到第 `k` 个就一路返回，`O(h + k)`。
4. 进阶：存子树大小，按「左子树有几个」决定向左、命中或向右，每层一次比较，`O(h)`。
