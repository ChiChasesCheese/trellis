## Q
**LC 91 解码方法**｜写出 Python 实现

字符串 `s` 只含数字，`1 <= len(s) <= 100`，可能有前导零。`"1"` 到 `"26"` 分别对应 `A` 到 `Z`。返回把 `s` 完整解码的方法数，没有合法解码返回 `0`。

## A
**思路。** 逐个字符 DP。`one_back` 是解码到上一个字符为止的方案数，`two_back` 是再往前一个字符为止的。当前字符不是 `'0'` 时可以单独成码，加 `one_back`；它与前一个字符组成的两位数在 `10`~`26` 时可以合起来成码，加 `two_back`。初值 `one_back = 1`（空串一种）、`two_back = 0`。

```python
def num_decodings(s: str) -> int:
    two_back, one_back = 0, 1              # 解码 s[:i-2] / s[:i-1] 的方案数；开始时 s[:0] 有 1 种（空串）
    for i, ch in enumerate(s):
        cur = 0
        if ch != "0":                      # 单独解码 s[i]：'1'..'9' 合法，'0' 不合法
            cur += one_back
        if i >= 1 and "10" <= s[i - 1:i + 1] <= "26":   # 两位一起：10..26 合法（两位字符串，字典序等于数值序）
            cur += two_back
        two_back, one_back = one_back, cur
    return one_back
```

运行：`"12"` → `2`，`"226"` → `3`，`"06"` → `0`，`"10"` → `1`，`"100"` → `0`，`"27"` → `1`，`"0"` → `0`，`"11106"` → `2`，`"2101"` → `1`，`"230"` → `0`；`"1" * 100` → `573147844013817084101`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**写法要点。** `"10" <= s[i - 1:i + 1] <= "26"` 用字符串比较判断两位数范围：两个字符串等长，字典序与数值序一致，且天然排除 `"06"`（`"06" < "10"`），不需要 `int()` 转换；`two_back, one_back = one_back, cur` 一次元组赋值滚动两个变量；`enumerate` 同时给下标和字符；`i >= 1` 保证有"前一位"。要注意字典序比较只在**长度相同**时才等于数值比较，所以切片长度必须固定为 `2`。
