## Q
**二叉树中序字符迭代器**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2025-10-31（美国面试记录）

二叉树每个节点存一个字符串（可以是空串）。实现迭代器：`next()` 每次按中序顺序返回下一个字符（逐字符，不是逐节点），`hasNext()` 判断是否还有字符。要求懒加载：不预先展开整棵树，额外空间与树高成正比；空串节点要被跳过。节点数不超过 `10^5`，每个字符串长度不超过 `100`。例：根 `"ab"`，左孩子 `"c"` → 依次 `c, a, b`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「中序 + 迭代器」→ 用显式栈模拟中序遍历（LC 173），`hasNext` / `next` 两个方法共享栈状态。
- 「逐字符而不是逐节点」→ 在栈之外再保存「当前字符串和已读位置」。
- 「不预先展开」→ 拒绝构造时全量遍历；状态只能是栈加游标，空间 `O(h)`。
- 「空串要跳过」→ 换节点必须是 `while` 循环，一次可能要跳过多个空节点。
- 节点数 `10^5`：斜树深度可达 `10^5`，递归会触发 `RecursionError`，必须显式栈。

**推导链。**
1. 暴力：构造时递归中序遍历，把所有字符收进一个列表，`next` 只是移动下标，`O(N)` 时间和空间。
2. 浪费：即使只读几个字符，也要先付全部代价，违反懒加载。
3. 洞察一：中序遍历的递归状态等价于「祖先栈」，栈里只放还没访问自己的祖先，最多一条左链。
4. 洞察二：节点内的位置是一个整数游标，当游标走到末尾才去栈里取下一个节点；取节点时先把它右子树的左链压栈。
5. 最优：换节点的逻辑放进 `hasNext()`，`next()` 只读字符；每个节点入栈出栈一次，`next` 摊还 `O(1)`，空间 `O(h)`。
