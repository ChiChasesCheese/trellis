## Q
**LC 108 将有序数组转换为二叉搜索树**｜Easy · CodeTop 国内累计 8 次 · 最近 2026-09-09（CodeTop）

给一个按**升序**排列的整数数组 `nums`，把它转换成一棵**高度平衡**的二叉搜索树（每个结点的左右子树高度差不超过 `1`）。`1 <= nums.length <= 10^4`，`-10^4 <= nums[i] <= 10^4`，严格递增；答案不唯一。例：`nums = [-10,-3,0,5,9]` → `[0,-3,9,-10,null,5]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**有序**数组」+「二叉搜索树」→ BST 的**中序遍历就是升序**，数组已经是某棵 BST 的中序序列。
- 「**高度平衡**」→ 左右子树结点数尽量相等 → 根取**中点** → 子问题和原问题同构，用**分治 / 递归**。
- `n <= 10^4` → `O(n)` 或 `O(n log n)` 都够；树高只有 `log n`，递归深度不是问题。
- 「答案不唯一」→ 偶数个元素取左中右中都合法，只验证性质，不比较形状。

**推导链。**
1. 暴力：按数组顺序逐个插入 BST。输入有序，每次都往最右边挂，树退化成链，高度 `n`，不平衡，总时间 `O(n^2)`。
2. 洞察：根是数组中的某个元素；它左边的全部进左子树，右边的全部进右子树（BST 性质）。平衡要求两边个数最多差 `1`。
3. 所以根取中点，左右各自递归，直到区间为空返回 `None`。
4. 实现用下标区间 `[lo, hi)`，不要切片（切片每层复制，总 `O(n log n)`）。每个元素建一次结点，`O(n)`。
