## Q
**K 个一组翻转链表的变体**｜追问

链表按 `k` 个一组翻转，已有「先量长度、再按大小序列逐组处理」的实现，支持从尾分组和翻转不足 `k` 个的组。面试官接着问：（1）只能遍历一遍、不能先量长度，怎么做？（2）组的长度依次是 `1, 2, 3, ...`，只翻转长度为偶数的组？（3）想同时返回翻转了多少组？（4）`k` 很大、接近 `n` 时有没有变化？

## A
1. **不预先量长度**：从头分组可以边走边数：往后数最多 `k` 个，够了就翻，不够按开关决定翻不翻。从尾分组必须知道长度，否则先整条翻转，再从头分组，最后整条翻转回来（三遍扫描，`O(1)` 空间）。
2. **偶数长度组（LC 2074）**：同一框架。大小序列换成 `1, 2, 3, ...`，最后一组取剩余节点数（`min(预期大小, 剩余)`），翻转条件换成「实际长度是偶数」；`[5,2,6,3,9,1,7,3,8,4]` 得到 `[5,6,2,3,9,1,4,8,3,7]`。
3. **统计翻转的组数**：循环里在翻转分支加一个计数器，返回 `(新表头, 组数)`；对 `reverse_partial=False` 来说就是 `n // k`，可以直接算，不需要计数。
4. **`k` 很大**：`k >= n` 时只有一个余数组，默认什么都不做，`reverse_partial=True` 才整条翻转；`k = 1` 永远是原链表。内层 `for _ in range(size)` 的总次数始终是 `n`，复杂度不随 `k` 变化。

**Python 提醒**：`cur.next, prev, cur = prev, cur, cur.next` 里赋值顺序是从左到右，`cur.next` 必须写在最前面；写成 `prev, cur, cur.next = cur, cur.next, prev`，第二步 `cur` 已经变了，第三步改的是下一个节点的 `next`，链表会断。
