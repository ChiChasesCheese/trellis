## Q
**LC 102 二叉树的层序遍历**｜Medium · 近一年被问：美国 0 次、国内 10 次 · CodeTop 国内累计 88 次 · 最近 2026-10（面试记录）

给二叉树的根节点 `root`，返回其节点值的**层序遍历**：逐层地，从左到右访问所有节点，每层一个列表。树中节点数在 `[0, 2000]` 内，`-1000 <= Node.val <= 1000`。例：`root = [3,9,20,null,null,15,7]` → `[[3],[9,20],[15,7]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**逐层**访问」「每层一个列表」→ **广度优先搜索**（BFS）：用队列，先进先出，节点按到根的距离从近到远出队。
- 「离根最近的先处理」的任何需求（最短路径、最小深度、右视图）都是同一个信号。
- `n <= 2000`：`O(n)` 的一次遍历足够；单链树深度可达 2000，所以递归 DFS 有爆栈风险，迭代 BFS 更稳。

**推导链。**
1. 暴力：DFS 带深度 `d`，把节点值放进 `res[d]`；先左后右，每层内部就是从左到右。`O(n)`，但递归深度等于树高。
2. 改用队列做 BFS 后，只剩一个难点：怎么知道一层到哪里结束。
3. 三种办法：队列里存 `(node, depth)`；用「当前层 / 下一层」两个列表；每轮开头拍下 `len(queue)` 的快照。
4. 选快照：此刻队列里恰好只有第 `d` 层的全部节点，快照 = 这层的宽度；循环里新入队的是第 `d + 1` 层，不会被这一轮处理。`O(n)` 时间，`O(w)` 空间。
