## Q
**LC 206 反转链表**｜Easy · LC TikTok 近 6 个月热度 53/100（全时段 62） · 近一年被问：美国 1 次、国内 9 次 · CodeTop 国内累计 243 次 · 最近 2026-10-28（国内面试记录）

给单链表的头节点 `head`，反转链表，并返回反转后的链表。链表中节点的数目范围是 `[0, 5000]`，`-5000 <= Node.val <= 5000`。例：`head = [1,2,3,4,5]` → `[5,4,3,2,1]`。进阶：链表可以选用迭代或递归方式完成反转，你能否用两种方法解决这个问题？

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「反转单链表」→ **指针操作**：只改每个节点 `next` 的方向，不动节点值。
- 单链表只能向后走 → 处理节点时必须**自己带着前一个节点**（`prev`），并在改指针前**先存下后继**（`nxt`）。
- 节点数可以是 `0` → 空链表要自然地返回 `None`，不要特判。
- 进阶「迭代或递归」→ 迭代 `O(1)` 空间；递归 `O(n)` 空间，`5000` 深度会超过 Python 默认递归上限。

**推导链。**
1. 暴力：把所有节点的值读进数组，再反向写回——`O(n)` 额外空间，也没考查指针。
2. 浪费：我们只想让每条边掉头。
3. 关键：处理节点 `cur` 时，把 `cur.next` 指向 `prev`，掉头一条边；但改之前必须先用 `nxt` 记住原来的 `cur.next`，否则后面的链表就断了、找不到了。
4. 三个指针 `prev / cur / nxt` 一起前进，一遍完成；`prev` 初始为 `None`，成为新的尾（旧头的 `next` 指向 `None`），循环结束时 `prev` 就是新头。`O(n)` 时间 `O(1)` 空间。
