## Q
**LC 3 无重复字符的最长子串**｜Medium · LC TikTok 全时段热度 88/100 · 近一年被问：美国 4 次、国内 21 次 · CodeTop 国内累计 698 次 · 最近 2026-10-26（国内 CodeTop）

给字符串 `s`，求其中不含重复字符的**最长子串**的长度（子串必须连续）。`0 <= s.length <= 10^5`，字符是英文字母、数字、符号和空格。例：`"abcabcbb"` → `3`（`"abc"`），`"pwwkew"` → `3`（`"wke"`）。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「**连续**子串」+「**最长**」+ 一个对窗口内容的约束（无重复）→ **可变长滑动窗口**。
- `n` 到 `10^5` → 需要 `O(n)` 或 `O(n log n)`，`O(n^2)` 的枚举不行。
- 约束有**单调性**：一个窗口有重复，再把它往外扩也一定有重复；所以右端前进时，左端只需要往右走，从不回退。这是滑动窗口能用的根本原因。

**推导链。**
1. 暴力：枚举所有起点终点，`O(n^2)` 个子串，每个再判重 → `O(n^3)`。
2. 固定起点往右扩，遇到重复就停 → `O(n^2)`，但每换一个起点都从头扩，浪费。
3. 观察：从起点 `i` 扩到 `j` 撞上重复字符 `c` 时，起点在 `i` 到 `c` 上次出现位置之间的子串都会在 `j` 处同样撞上 `c`，可以全部跳过 → 左端**直接跳到 `c` 上次出现的下一位**。
4. 每个下标被右端经过一次、左端只前进不后退 → `O(n)`。用字典记「字符最近出现的下标」，跳转是 `O(1)`。

**同模式的题**：LC 159 / 340（至多 k 种字符）、LC 424（替换后的最长重复字符）、LC 76（最小覆盖子串，求最短）。
