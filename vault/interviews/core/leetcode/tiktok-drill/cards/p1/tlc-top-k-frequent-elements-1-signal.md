## Q
**LC 347 前 K 个高频元素**｜Medium · LC TikTok 热度 75/100（近 6 个月） · 近一年被问：美国 4 次、国内 4 次 · CodeTop 国内累计 17 次 · 最近 2026-10-17（面试记录）

给整数数组 `nums` 和整数 `k`，返回出现频率前 `k` 高的元素，可按任意顺序返回。`1 <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`，`k` 的取值范围是 `[1, 数组中不相同元素的个数]`，数据保证答案唯一。例：`nums = [1,1,1,2,2,3], k = 2` → `[1,2]`。进阶：时间复杂度必须优于 `O(n log n)`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「出现频率」→ 先 **计数**（hash table / `Counter`），把问题变成「对（元素, 频次）对做选择」。
- 「前 `k` 个」「任意顺序」→ **Top-K**：只要一个集合，不要全序，所以不必完整排序。
- 进阶「优于 `O(n log n)`」→ 排除整体排序；堆是 `O(n log k)`，要 `O(n)` 就得利用频次的范围。
- 频次一定是 `1` 到 `n` 之间的整数 → 可以直接当下标做**桶排序**（bucket sort）。

**推导链。**
1. 暴力：计数后把所有元素按频次排序，取前 `k` 个，`O(n log n)`，不满足进阶。
2. 浪费：我们只要前 `k`，却把剩下的也排好了序。
3. 堆：维护大小为 `k` 的小根堆，堆顶是当前第 `k` 高频，来了更高频的就替换，`O(n log k)`。
4. 桶：频次的取值只有 `1..n`，不需要比较，下标 = 频次，把元素放进对应的桶，从最高频的桶往下取，凑够 `k` 个就停，`O(n)`。
