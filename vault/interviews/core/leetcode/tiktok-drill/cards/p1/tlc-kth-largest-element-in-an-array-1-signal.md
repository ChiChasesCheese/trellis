## Q
**LC 215 数组中的第 K 个最大元素**｜Medium · LC TikTok 热度 63/100（近 6 个月） · 近一年被问：美国 4 次、国内 4 次 · CodeTop 国内累计 206 次 · 最近 2026-10-26（国内 CodeTop）

给整数数组 `nums` 和整数 `k`，返回数组**排序后**的第 `k` 个最大元素（不是第 `k` 个不同的元素）。必须设计并实现时间复杂度为 `O(n)` 的算法。`1 <= k <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`。例：`nums = [3,2,1,5,6,4], k = 2` → `5`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「第 `k` 大」→ **选择问题**（selection）：只要一个排名位置上的值，不要完整排序。
- 「必须 `O(n)`」→ 排序 `O(n log n)` 和 `k` 大小的堆 `O(n log k)` 都不达标，要用**快速选择**（quickselect）。
- 「排序后的第 `k` 个，不是第 `k` 个不同的元素」→ 有重复值，划分时相等的元素要单独处理（三路划分）。
- `n` 到 `10^5`，值域只有 `2×10^4 + 1` 个整数 → 还有确定性的计数数组做法。

**推导链。**
1. 暴力：排序，取 `nums[-k]`，`O(n log n)`。
2. 浪费：只要一个位置的元素，却把所有元素都排好了序。
3. 堆：维护大小为 `k` 的小根堆，堆顶即答案，`O(n log k)`——更好，但不满足 `O(n)`。
4. 快速选择：像快速排序那样用 pivot 划分，但划分之后只钻进答案所在的那一堆，另一堆整个丢掉；每轮期望砍掉一半，`n + n/2 + n/4 + ... = O(n)`。随机 pivot 防止构造输入，三路划分处理重复值。
