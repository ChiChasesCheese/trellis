## Q
**LC 56 合并区间**｜Medium · LC TikTok 热度 88/100（近 3 个月） · 近一年被问：美国 7 次、国内 3 次 · CodeTop 国内累计 81 次 · 最近 2026-10（面试记录）

`intervals[i] = [start_i, end_i]` 表示一组区间，合并所有重叠的区间，返回互不重叠、恰好覆盖输入全部区间的数组；端点相接也算重叠。`1 <= intervals.length <= 10^4`，`intervals[i].length == 2`，`0 <= start_i <= end_i <= 10^4`。例：`[[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`。

题面里哪些信号指向哪个模式？从暴力解怎样一步步推到最优解？

## A
**信号 → 模式。**
- 「区间 + 重叠 + 合并 / 覆盖」→ 区间题，第一反应是**按起点排序**（扫描线的另一面）。
- 排序后能与当前区间重叠的只可能是紧邻的上一段 → 一次线性扫描，只和结果的最后一个区间比较。
- `n <= 10^4`：`O(n^2)` 的两两合并能过，但 `O(n log n)` 才是预期。

**推导链。**
1. 暴力：反复找任意一对重叠的区间合并，直到再也找不到，每轮 `O(n^2)`，轮数最坏 `O(n)`。
2. 浪费：区间乱序，每次都要重新找谁和谁重叠。
3. 洞察：按起点排序后，若当前区间的起点超过已合并最后一个区间的终点，后面所有区间的起点更大，也不会再和它重叠，这个区间封口。
4. 重叠时终点取两者较大值（当前区间可能被完全包含），否则开新区间；排序 `O(n log n)`，扫描 `O(n)`。

**同模式的题**：LC 57 插入区间、LC 435 无重叠区间、LC 253 会议室 II、LC 452 用最少数量的箭引爆气球。
