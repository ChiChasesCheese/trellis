## Q
**LC 287 寻找重复数**｜Medium · 全公司热度第 154 名 · NeetCode 150、Hot 100

给定包含 `n + 1` 个整数的数组 `nums`，数字都在 `[1, n]` 范围内，可知至少存在一个重复的整数。假设 `nums` 只有一个重复的整数（它可以出现两次或更多次，其余数各出现一次），返回这个重复的数。你的解法必须**不修改**数组 `nums`，且只用常量级 `O(1)` 的额外空间。`1 <= n <= 10^5`，`nums.length == n + 1`，`1 <= nums[i] <= n`。例：`[1,3,4,2,2]` → `2`；`[3,1,3,4,2]` → `3`；`[3,3,3,3,3]` → `3`。进阶：如何证明至少存在一个重复的数字？你能设计线性时间 `O(n)` 的解法吗？

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 快慢指针找环入口（Floyd 判圈）：把「数组下标 → 值」看成链表。

**一句话。** 把 `i → nums[i]` 当作 next 指针，重复数就是这个函数图里环的入口；快慢指针相遇后，一个回到起点，同速前进，再次相遇处就是入口。

**识别。** 「`n + 1` 个数、值域 `[1, n]`」是抽屉原理（pigeonhole principle）的信号；「不改数组、`O(1)` 空间、线性时间」把排序、哈希集合、原地交换（要改数组）全部排除，剩下的就是 Floyd。

**推导。** 排序 `O(n log n)` 要改数组；哈希集合 `O(n)` 空间。关键转化：因为值在 `[1, n]`，下标 `0` 没有任何入边，从 `0` 出发沿 `nums[i]` 走一定进入环；`n + 1` 个下标指向 `n` 个值，必有两个下标指向同一个值，这个值就是环的入口（它有两条入边）。证明至少有一个重复数同样是抽屉原理。

```python
def find_duplicate(nums: list[int]) -> int:
    # 把下标 i 指向 nums[i] 看成链表。值域是 [1, n]，所以 0 号下标没有入边（从 0 出发永远回不来），
    # 而 n+1 个下标指向 n 个值，必有两个下标指向同一点：这个点就是环的入口，也就是重复数
    slow = fast = 0
    while True:  # 第一阶段：快慢指针必然在环内相遇
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    slow = 0  # 第二阶段：设起点到入口 a 步，入口到相遇点 b 步，环长 c；
    while slow != fast:  # 相遇时 2(a+b) = a+b+kc，故 a = kc-b：同速从起点和相遇点出发，在入口会合
        slow = nums[slow]
        fast = nums[fast]
    return slow
```

运行：`[1,3,4,2,2]` → `2`；`[3,1,3,4,2]` → `3`；`[3,3,3,3,3]` → `3`；`[1,1]` → `1`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`，不修改数组。

**拓展优化。**
- 对值域二分（二分答案）：统计 `<= mid` 的元素个数，若超过 `mid` 则重复数在 `[lo, mid]`，否则在 `(mid, hi]`。时间 `O(n log n)`，同样 `O(1)` 空间、不改数组，思路更直接，是不记得 Floyd 时的稳妥备选。

```python
def find_duplicate(nums: list[int]) -> int:
    lo, hi = 1, len(nums) - 1  # 对"值"二分，答案在 [1, n]
    while lo < hi:
        mid = (lo + hi) // 2
        count = sum(x <= mid for x in nums)  # 值 <= mid 的个数：若 > mid，抽屉原理说明重复数在 [lo, mid]
        if count > mid:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

**易错点。**
- 第一阶段结束时的相遇点**不是**重复数：`[1,3,4,2,2]` 里两个指针相遇在 `4`，而重复数是 `2`，必须有第二阶段。
- 二分版本统计的是「值 `<= mid`」的个数，不是「值 `== mid`」的个数；后者不具有单调性，无法二分。
- 重复数出现多次（`[3,3,3,3,3]`）时仍然成立：环入口只关心「有几条入边」，不关心重复次数。

**同模式。** LC 142 环形链表 II、LC 141 环形链表、LC 202 快乐数、LC 41 缺失的第一个正数。
