## Q
**LC 48 旋转图像**｜Medium · 全公司热度第 47 名 · Blind 75、NeetCode 150、Hot 100、Top Interview 150

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像，将图像**顺时针**旋转 `90` 度。必须在**原地**旋转，即直接修改输入的二维矩阵，不要另开一个矩阵。`n == matrix.length == matrix[i].length`，`1 <= n <= 20`，`-1000 <= matrix[i][j] <= 1000`。例：`matrix = [[1,2,3],[4,5,6],[7,8,9]]` → `[[7,4,1],[8,5,2],[9,6,3]]`；`matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]` → `[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 矩阵几何变换：旋转 = 转置（transpose）+ 翻转（reverse）。

**一句话。** 顺时针旋转 `90` 度 = 沿主对角线转置，再把每一行左右翻转；两步都是原地交换，`O(1)` 额外空间。

**识别。** 「矩阵旋转 + 原地」是几何变换题：把旋转拆成两个天然原地的简单变换。位置公式 `(i, j) → (j, n - 1 - i)`。`n <= 20`，数据很小，考的是 `O(1)` 空间。

**推导。** 新建矩阵按公式 `new[j][n-1-i] = matrix[i][j]` 填写最直接，但题面禁止，且空间 `O(n^2)`。把位置映射 `(i, j) → (j, n-1-i)` 拆开：先 `(i, j) → (j, i)`（转置），再 `(j, i) → (j, n-1-i)`（每行内部左右翻转）。

```python
def rotate(matrix: list[list[int]]) -> None:
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):                  # 只交换上三角，沿主对角线转置
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()                              # 再把每一行左右翻转，合起来是顺时针 90 度
```

运行：`[[1,2,3],[4,5,6],[7,8,9]]` → `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]`；`4 × 4` 的示例 → `[[15, 13, 2, 5], [14, 3, 4, 1], [12, 6, 8, 9], [16, 7, 10, 11]]`；`[[1]]` → `[[1]]`；`[[1,2],[3,4]]` → `[[3, 1], [4, 2]]`。

**复杂度。** 时间 `O(n^2)`；空间 `O(1)`。

**拓展优化。**
- 一圈一圈四元素轮换：每个元素只搬一次，不需要两遍。
```python
def rotate_ring(matrix: list[list[int]]) -> None:
    n = len(matrix)
    for i in range(n // 2):                        # 第 i 层，共 n // 2 层；奇数 n 的中心格不动
        for j in range(i, n - 1 - i):              # 每条边去掉最后一个格，四条边正好不重叠
            tmp = matrix[i][j]                                   # 上
            matrix[i][j] = matrix[n - 1 - j][i]                  # 左 -> 上
            matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j]  # 下 -> 左
            matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i]  # 右 -> 下
            matrix[j][n - 1 - i] = tmp                           # 上 -> 右
```
- 逆时针 `90` 度：先转置，再把行的顺序整体倒过来（`matrix.reverse()`）。

**易错点。**
- 转置时内层循环从 `0` 开始：每一对被交换两次，等于没转置，翻转后得到的是水平镜像。`[[1,2,3],[4,5,6],[7,8,9]]` 得 `[[3, 2, 1], [6, 5, 4], [9, 8, 7]]`，正确是 `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]`。内层必须从 `i + 1` 开始。
- 在函数里写 `matrix = [list(r) for r in zip(*matrix[::-1])]`：只让局部变量指向新列表，调用方的矩阵不变。要么原地改，要么用切片赋值 `matrix[:] = ...`。
- 两步顺序反了：先翻转每一行再转置得到逆时针，`[[1,2,3],[4,5,6],[7,8,9]]` 得 `[[3, 6, 9], [2, 5, 8], [1, 4, 7]]`。

**同模式。** LC 54 螺旋矩阵、LC 59 螺旋矩阵 II、LC 867 转置矩阵、LC 73 矩阵置零。
