## Q
**LC 1823 找出游戏的获胜者（Find the Winner of the Circular Game）**｜Medium · 全公司热度第 270 名

共有 `n` 名小伙伴围成一圈做游戏，按顺时针顺序从 `1` 到 `n` 编号。游戏规则：从第 `1` 名小伙伴开始；沿顺时针方向数 `k` 名小伙伴，计数时包含起始时的那位，逐个绕圈进行；数到的最后一名小伙伴离开圈子并视作输掉游戏；如果圈子中仍有不止一名小伙伴，从刚刚输掉的小伙伴的顺时针下一位开始，重复数 `k` 个；否则最后一名小伙伴赢得游戏。返回获胜者的编号。`1 <= k <= n <= 500`。进阶：能否使用线性时间复杂度和常数空间复杂度解决。例：`n = 5`，`k = 2` → `3`（离开顺序 `2, 4, 1, 5`）；`n = 6`，`k = 5` → `1`（离开顺序 `5, 4, 6, 2, 3`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 模拟环形删除（circular simulation）：用下标取模定位被淘汰者；约瑟夫问题（Josephus problem）。

**一句话。** 用列表装所有人，维护本轮开始数数的位置 `idx`，被淘汰者在 `(idx + k - 1) % 当前人数`，弹出它，下一轮从弹出后落在同一下标的人开始。

**识别。** 「围成一圈、每隔 `k` 个淘汰一个、问最后留下谁」是约瑟夫问题。`n <= 500`，逐个模拟 `O(n²)` 完全够用；进阶要求线性时间、常数空间，是用递推公式（见拓展）。

**推导。** 数 `k` 个人，从 `idx` 出发，最后一个人在 `idx + k - 1`，环形所以对当前人数取模。把他从列表删除后，原来在他后面的人整体前移一位，所以下一轮的起点依旧是下标 `idx`（取模时再对新长度处理）。重复 `n - 1` 次，剩下的就是赢家。

```python
def find_the_winner(n: int, k: int) -> int:
    people = list(range(1, n + 1))
    idx = 0                                       # 本轮开始计数的位置
    while len(people) > 1:
        idx = (idx + k - 1) % len(people)         # 从 idx 起数 k 个人，最后一个落在 idx + k - 1（环形取模）
        people.pop(idx)                           # 出局；后一个人自动滑到下标 idx，正好是下一轮的起点
    return people[0]
```

运行：`(5, 2)` → `3`，`(6, 5)` → `1`，`(1, 1)` → `1`，`(3, 3)` → `2`，`(500, 500)` → `69`。

**复杂度。** 时间 `O(n²)`（`list.pop(idx)` 需要移动元素，总共 `n` 次），空间 `O(n)`；`n <= 500` 毫无压力。

**拓展优化。**
- 进阶：线性时间、常数空间。设 `f(size)` 是 `size` 个人时赢家的 0 起点下标，`f(1) = 0`。`size` 个人时第一个被淘汰的是下标 `(k - 1) % size`，之后下一轮从下标 `k % size` 开始、人数变成 `size - 1`：新环里的下标 `x` 对应旧环的 `(x + k) % size`。所以 `f(size) = (f(size - 1) + k) % size`，最后答案 `f(n) + 1`。

```python
def find_the_winner_josephus(n: int, k: int) -> int:
    win = 0                                       # 只剩 1 人时，赢家的下标（从 0 开始）
    for size in range(2, n + 1):                  # 人数从 size - 1 增加到 size，换算赢家下标
        # size 个人时第一轮淘汰 (k - 1) % size 号，下一轮从 k % size 号重新数起：
        # 小环里的下标 x 对应大环里的 (x + k) % size
        win = (win + k) % size
    return win + 1
```

- `k = 2` 时有闭式：`n = 2^m + l`（`0 <= l < 2^m`）则赢家是 `2l + 1`，`n = 5` 得 `2 * 1 + 1 = 3`。

**易错点。**
- 下标更新写成 `(idx + k) % len(people)`：少减 1，淘汰的是第 `k + 1` 个人，`(5, 2)` 得到 `4`，正确 `3`。
- 递推最后忘记 `+ 1`：下标从 0 起、编号从 1 起，`(5, 2)` 返回 `2`，正确 `3`。
