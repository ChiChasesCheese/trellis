## Q
**LC 647 回文子串**｜Medium · 全公司热度第 119 名 · Blind 75、NeetCode 150

给你字符串 `s`，统计并返回其中**回文子串**的数目。回文字符串是正着读和倒过来读一样的字符串；子串是字符串中由连续字符组成的序列。具有不同开始位置或结束位置的子串，即使内容相同也视作不同的子串。`1 <= s.length <= 1000`，`s` 由小写英文字母组成。例：`"abc"` → `3`（`"a"`、`"b"`、`"c"`）；`"aaa"` → `6`（`"a"`×3、`"aa"`×2、`"aaa"`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 中心扩展（expand around center）计数；回文子串 DP；Manacher 算法。

**一句话。** 枚举 `2n - 1` 个中心，从每个中心向两侧扩展，每成功扩一圈就多一个回文子串。

**识别。** 「统计回文子串个数」与 LC 5 同类，把「取最长」换成「每扩一圈计数」；`n = 1000`，`O(n^2)` 足够。

**推导。** 暴力：枚举所有子串并判断，`O(n^3)`。回文由中心决定：每个中心上，若半径 `r` 的子串是回文，则半径更小的同中心子串也是回文，所以向外扩一格，只要两端字符相同就多一个回文，一旦不同就停。中心共 `2n - 1` 个（奇数长度以字符为中心，偶数长度以缝为中心），每个最多扩 `O(n)`。

```python
def count_substrings(s: str) -> int:
    count = 0
    for center in range(2 * len(s) - 1):  # 2n-1 个中心：n 个字符 + n-1 条缝
        left = center // 2
        right = left + center % 2  # center 为偶数是字符中心 (left, left)，为奇数是缝中心 (left, left+1)
        while left >= 0 and right < len(s) and s[left] == s[right]:
            count += 1  # 每向外扩成功一圈，就多一个以该中心为中心的回文子串
            left -= 1
            right += 1
    return count
```

运行：`"abc"` → `3`；`"aaa"` → `6`；`"a"` → `1`；`"abba"` → `6`。

**复杂度。** 时间 `O(n^2)`，空间 `O(1)`。

**拓展优化。**
- Manacher 算法求出每个中心的回文半径后，各半径之和就是答案，`O(n)`；代码见 LC 5 的 Manacher 版本。

**易错点。**
- 只枚举奇数中心：`"aaa"` 会得到 `4`，正确是 `6`。
- 按「内容」去重：`"aaa"` 的不同回文内容只有 `3` 种，但题目按位置计数，答案是 `6`。
- 中心下标映射：`center` 为偶数时 `right = left`，为奇数时 `right = left + 1`，写错会把偶数长度回文当成奇数处理。

**同模式。** LC 5 最长回文子串、LC 516 最长回文子序列、LC 131 分割回文串、LC 1930 长度为 3 的不同回文子序列。
