## Q
**LC 124 二叉树中的最大路径和**｜Hard · 全公司热度第 93 名 · Blind 75、NeetCode 150、Hot 100、Top Interview 150

二叉树中的**路径**是一条节点序列，序列中每对相邻节点之间都存在一条边；同一个节点在一条路径中**至多出现一次**；路径至少包含一个节点，不一定经过根节点。路径和是路径中各节点值的总和。给你一个二叉树的根节点 `root`，返回其**最大路径和**。节点数在 `[1, 3 * 10^4]`，`-1000 <= Node.val <= 1000`。例：`root = [1,2,3]` → `6`（`2→1→3`）；`root = [-10,9,20,null,null,15,7]` → `42`（`15→20→7`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 树形 DP（后序 DFS）：递归返回「向下的单臂最大和」，在每个节点用两臂合成「拐弯路径」更新答案。

**一句话。** 对每个节点 `x`，以 `x` 为最高点的最大路径和 = `x.val` + 左臂最大贡献 + 右臂最大贡献（贡献为负就不要，取 `0`）；递归向上只能返回单臂 `x.val + max(左臂, 右臂)`。

**识别。** 「任意两点之间的最优路径」且路径在树里可以拐一次：每条路径有唯一的最高点，枚举最高点就覆盖所有路径；与 LC 543 同一骨架，只是长度换成带权和，且权可以为负。`n <= 3 * 10^4`，一次后序遍历 `O(n)`。

**推导。** 枚举每对端点求路径和，`O(n^2)` 甚至更差。固定最高点 `x` 后，路径由「向左下的一条链」和「向右下的一条链」加上 `x` 拼成，两条链互相独立，各取最好的；某条链的和为负就不选它（取 `0`），因为路径可以在 `x` 处就停。向父亲汇报时只能带一条链，否则对父亲而言路径就分叉了。

```python
def max_path_sum(root: TreeNode) -> int:
    best = root.val                                # 至少要包含一个节点：全为负数时答案是最大的单个节点

    def gain(node: TreeNode | None) -> int:        # node 向下延伸一条链能提供的最大和（不选则为 0）
        nonlocal best
        if node is None:
            return 0
        left = max(gain(node.left), 0)             # 负贡献直接丢掉，不如不走这一侧
        right = max(gain(node.right), 0)
        best = max(best, node.val + left + right)  # 以 node 为最高点的路径：左臂 + 自己 + 右臂
        return node.val + max(left, right)         # 向上只能带一条臂

    gain(root)
    return best
```

运行：`[1,2,3]` → `6`；`[-10,9,20,null,null,15,7]` → `42`；`[-3]` → `-3`；`[2,-1]` → `2`；`[-2,-1]` → `-1`。

**复杂度。** 时间 `O(n)`；空间 `O(h)`，递归栈。

**拓展优化。**
- 要输出路径本身（节点序列）：`gain` 同时返回「最佳单臂」的节点列表，或记录每个节点的最优选择后再回溯。
- 深链输入需要显式栈的后序遍历，见易错点中的递归深度。

**易错点。**
- 不对负贡献取 `0`：`[1,-2,3]` 得 `3`，正确是 `4`（`1→3`）；`-2` 这条臂拖累了结果。
- 向上返回 `node.val + left + right`：父节点会把两条臂同时接到自己上，路径变成分叉的「Y」形，不是一条路径。`[1,2,3,4,5]` 得 `15`，正确是 `11`。
- 链状树深度 `3 * 10^4`，远超 CPython 默认递归上限约 `1000`，会抛 `RecursionError`；需调高上限或改成迭代的后序遍历。

**同模式。** LC 543 二叉树的直径、LC 687 最长同值路径、LC 337 打家劫舍 III、LC 1372 二叉树中的最长交错路径。
