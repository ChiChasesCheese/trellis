## Q
**LC 222 完全二叉树的节点个数（Count Complete Tree Nodes）**｜Medium · 全公司热度第 582 名 · Top Interview 150

给你一棵**完全二叉树**的根节点 `root`，求出该树的节点个数。完全二叉树的定义：除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 `h` 层（从第 0 层开始），则该层包含 `1 ~ 2^h` 个节点。树中节点的数目范围是 `[0, 5 * 10^4]`，`0 <= Node.val <= 5 * 10^4`，题目数据保证输入的树是完全二叉树。进阶：遍历树来统计节点是 `O(n)` 的简单解决方案，设计一个更快的算法。例：`root = [1,2,3,4,5,6]` → `6`；`root = []` → `0`；`root = [1]` → `1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 利用完全二叉树的性质：满二叉树的节点数是 `2^h - 1`，递归时至少一棵子树是满的。

**一句话。** 沿最左链和最右链分别数层数，相等就是满二叉树，直接返回 `2^h - 1`；不相等就递归左右子树，其中一棵必然是满的，递归很快结束。

**识别。** 题目强调「完全二叉树」并要求比 `O(n)` 更快，说明要用结构信息。完全二叉树中任意子树要么是满的，要么左右至多一边不满。

**推导。** 前后序遍历计数是 `O(n)`，没用到「完全」这个条件。观察：完全二叉树的左子树和右子树里至少有一棵是满二叉树。判断一棵子树是不是满的，只需比较最左链长度和最右链长度（完全二叉树中二者相等当且仅当它是满的），每次 `O(log n)`；满的直接用公式，不满的递归。每层递归只有一棵子树不满，递归 `O(log n)` 层，每层 `O(log n)`，总共 `O(log^2 n)`。

```python
def count_nodes(root: TreeNode | None) -> int:
    lh, node = 0, root
    while node:                           # 沿最左链数层数
        lh += 1
        node = node.left
    rh, node = 0, root
    while node:                           # 沿最右链数层数
        rh += 1
        node = node.right
    if lh == rh:                          # 最左、最右一样深：完全二叉树里这就是满二叉树，节点数 2^h - 1
        return (1 << lh) - 1
    return 1 + count_nodes(root.left) + count_nodes(root.right)   # 否则两棵子树里至少有一棵是满的，递归会很快结束
```

运行：`[1,2,3,4,5,6]` → `6`，`[]` → `0`，`[1]` → `1`，节点数 `n = 50000` 的完全二叉树 → `50000`。

**复杂度。** 时间 `O(log^2 n)`，空间 `O(log n)`（递归深度）。

**易错点。**
- 公式漏掉 `- 1`：只有根的树 `lh = rh = 1`，写成 `1 << lh` 得到 `2`，正确 `1`。
- 把条件用在非完全二叉树上：根的左孩子只有右子节点、右孩子只有左子节点的树（`[1,2,3,null,4,5]`），最左链和最右链都是 2 层，公式给出 `3`，实际 `5` 个节点。该方法依赖「完全」。
- 每层递归都重新数两条链却不利用满子树提前返回，会退化成 `O(n)`：满子树必须直接 `return`。

**同模式。** LC 104 二叉树的最大深度、LC 110 平衡二叉树、LC 958 二叉树的完全性检验、LC 100 相同的树。
