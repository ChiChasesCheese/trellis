## Q
**LC 190 颠倒二进制位（Reverse Bits）**｜Easy · 全公司热度第 441 名 · Blind 75、NeetCode 150、Top Interview 150

颠倒给定的 32 位有符号整数的二进制位。`0 <= n <= 2^31 - 2`，`n` 为偶数。进阶：如果多次调用这个函数，你将如何优化你的算法？例：`n = 43261596`（二进制 `00000010100101000001111010011100`）→ `964176192`（`00111001011110000010100101000000`）；`n = 2147483644`（`01111111111111111111111111111100`）→ `1073741822`（`00111111111111111111111111111110`）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 位运算（bit manipulation）：逐位取出最低位，接到结果的末尾。

**一句话。** 循环 32 次，每次把结果左移一位、补上 `n` 的最低位，再把 `n` 右移一位。

**识别。** 「按位反转」固定 32 位：循环次数固定，`O(32)` = `O(1)`。必须循环 32 次而不是「直到 `n` 为 0」，高位的前导零在反转后变成低位的 0，不能丢。

**推导。** 转成字符串反转 `bin(n)[2:].zfill(32)[::-1]` 可行但绕开了位运算。位运算版：结果的第 `i` 位等于 `n` 的第 `31 - i` 位；每次取 `n` 的最低位放进结果的最低位，结果整体左移，循环 32 次后，先取出的位被推到最高位。

```python
def reverse_bits(n: int) -> int:
    res = 0
    for _ in range(32):
        res = (res << 1) | (n & 1)                # 取出 n 的最低位，接到 res 的末尾
        n >>= 1
    return res
```

运行：`43261596` → `964176192`，`2147483644` → `1073741822`，`0` → `0`，`2` → `1073741824`。

**复杂度。** 时间 `O(1)`（固定 32 次），空间 `O(1)`。

**拓展优化。**
- 进阶「多次调用」：缓存。把每个字节（8 位）的反转结果预先算成 256 项的表，一次调用只做 4 次查表；或者用掩码分治，逐级交换相邻的块（16、8、4、2、1 位），5 步完成，不需要表。

```python
REV8 = [int(f"{b:08b}"[::-1], 2) for b in range(256)]    # 每个字节反转后的值，只算一次


def reverse_bits_table(n: int) -> int:
    return (REV8[n & 0xFF] << 24 | REV8[n >> 8 & 0xFF] << 16
            | REV8[n >> 16 & 0xFF] << 8 | REV8[n >> 24 & 0xFF])    # 四个字节各自反转，再按相反的顺序拼回


def reverse_bits_swap(n: int) -> int:             # 不用表：把相邻的块逐级交换，5 步完成 32 位
    n = (n >> 16 | n << 16) & 0xFFFFFFFF
    n = (n & 0xFF00FF00) >> 8 | (n & 0x00FF00FF) << 8
    n = (n & 0xF0F0F0F0) >> 4 | (n & 0x0F0F0F0F) << 4
    n = (n & 0xCCCCCCCC) >> 2 | (n & 0x33333333) << 2
    n = (n & 0xAAAAAAAA) >> 1 | (n & 0x55555555) << 1
    return n
```

**易错点。**
- 用 `while n:` 循环：前导零不被处理，反转后的数偏小。`43261596` 只有 26 位有效位，会得到 `15065253`，正确 `964176192`。
- 先 `res |= n & 1` 再 `res <<= 1`：最后一轮多左移一位，结果是正确答案的 2 倍，`43261596` 得到 `1928352384`，正确 `964176192`。
- 字符串版漏了 `zfill(32)`：同样丢掉前导零，结果同上错成 `15065253`。

**同模式。** LC 191 位 1 的个数、LC 338 比特位计数、LC 7 整数反转、LC 461 汉明距离。
