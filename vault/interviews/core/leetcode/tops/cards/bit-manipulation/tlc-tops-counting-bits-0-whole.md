## Q
**LC 338 比特位计数**｜Easy · 全公司热度第 674 名 · Blind 75、NeetCode 150、LeetCode 75

给你一个整数 `n`，对于 `0 <= i <= n` 中的每个 `i`，计算其二进制表示中 `1` 的个数，返回长度为 `n + 1` 的数组 `ans`。不要使用内置的位计数函数（如 C++ 的 `__builtin_popcount`）。`0 <= n <= 10^5`。进阶：很容易写出 `O(n log n)` 的解法，你能在线性时间 `O(n)` 内用一趟扫描解决吗？例：`n = 2` → `[0,1,1]`；`n = 5` → `[0,1,1,2,1,2]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 动态规划 + 位运算：`i` 的 `1` 的个数由 `i >> 1` 的结果推出。

**一句话。** `i` 去掉最低位就是 `i >> 1`，已经算过；`i` 的 `1` 的个数 = `ans[i >> 1]` 加上最低位（`i & 1`）。

**识别。** 「对 `0..n` 每一个数求同一个量」「结果只和更小的数有关」= 一维 DP（1-D DP）；`n = 10^5`，要求 `O(n)`，不能对每个数循环 `32` 位。

**推导。** 暴力：对每个 `i` 逐位数 `1`，`O(n log n)`。二进制右移一位把 `i` 变成 `i >> 1`，只丢掉最低位，所以 `popcount(i) = popcount(i >> 1) + (i & 1)`；`i >> 1 < i`，从小到大填表时它一定已经算好。

```python
def count_bits(n: int) -> list[int]:
    ans = [0] * (n + 1)  # ans[0] = 0
    for i in range(1, n + 1):
        ans[i] = ans[i >> 1] + (i & 1)  # 去掉最低位后的 1 的个数，加上最低位本身
    return ans
```

运行：`n = 2` → `[0,1,1]`；`n = 5` → `[0,1,1,2,1,2]`；`n = 0` → `[0]`；`n = 8` → `[0,1,1,2,1,2,2,3,1]`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`（不计输出）。

**拓展优化。**
- 另一个递推：`ans[i] = ans[i & (i - 1)] + 1`。`i & (i - 1)` 清掉最低位的 `1`，所以比 `i` 恰少一个 `1`；写法同样 `O(n)`。

**易错点。**
- 数组长度写成 `[0] * n`：要覆盖 `0..n`，共 `n + 1` 项；`n = 2` 会在 `ans[2]` 处 `IndexError`。
- 用 `/` 取一半：`ans[i / 2]` 是浮点下标，抛 `TypeError`；要用 `>> 1` 或 `// 2`。
- 偷懒用 `bin(i).count("1")`：结果对，`O(n log n)`，而且违反"不用内置位计数"的要求，进阶也没有完成。

**同模式。** LC 191 位 1 的个数、LC 231 2 的幂、LC 461 汉明距离、LC 1356 根据数字二进制下 1 的数目排序。
