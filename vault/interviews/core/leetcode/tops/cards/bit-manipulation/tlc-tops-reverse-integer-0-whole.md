## Q
**LC 7 整数反转**｜Medium · 全公司热度第 113 名 · NeetCode 150

给你一个 `32` 位有符号整数 `x`，返回将 `x` 的数字部分反转后的结果。如果反转后的值超出 `32` 位有符号整数的范围 `[-2^31, 2^31 - 1]`，返回 `0`。假设环境不允许存储 `64` 位整数（有符号或无符号）。`-2^31 <= x <= 2^31 - 1`。例：`x = 123` → `321`；`x = -123` → `-321`；`x = 120` → `21`；`x = 0` → `0`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 逐位取出个位再拼接（`x % 10`、`x // 10`），并在乘 `10` 之前检查溢出。

**一句话。** 每次取出 `x` 的个位 `d`，把它接到结果末尾 `rev = rev * 10 + d`，接之前先判断这一步会不会超出 `32` 位范围。

**识别。** 「数字反转」= 数位循环；「不允许 `64` 位」= 溢出必须在运算**之前**用 `rev > (limit - d) // 10` 检出，不能事后比较；`x` 最多 `10` 位，`O(log x)`。

**推导。** 逐位反转本身很直白：个位变成最高位。难点在溢出：`rev * 10 + d` 在 `32` 位里一旦溢出就已经错了，所以把条件移项成 `rev > (limit - d) // 10`，只用不会溢出的量比较。负数的处理：Python 的 `%`、`//` 对负数向下取整（`-123 // 10 == -13`），数位会取错，所以先记下符号、取绝对值，最后再乘回去。

```python
def reverse(x: int) -> int:
    INT_MAX = 2**31 - 1
    sign = -1 if x < 0 else 1
    x = abs(x)  # Python 的 % 和 // 对负数向下取整，先取绝对值，符号最后补回
    limit = INT_MAX if sign == 1 else INT_MAX + 1  # 负数的下界是 -2^31，绝对值比正数上界多 1
    rev = 0
    while x:
        x, d = divmod(x, 10)  # d 是个位，x 去掉个位
        if rev > (limit - d) // 10:  # rev * 10 + d > limit：下一步会溢出，提前返回 0
            return 0
        rev = rev * 10 + d
    return sign * rev
```

运行：`123` → `321`；`-123` → `-321`；`120` → `21`；`0` → `0`；`1534236469` → `0`；`-2147483648` → `0`；`1463847412` → `2147483641`。

**复杂度。** 时间 `O(log x)`（位数，至多 `10` 次），空间 `O(1)`。

**拓展优化。**
- Python 没有 `64` 位限制，字符串写法最短：`rev = int(str(abs(x))[::-1]) * sign`，再判断是否在范围内，不在返回 `0`；它绕开了题目"不能用 `64` 位"的约束，面试里先写数位版本。

**易错点。**
- 对负数直接用 `x % 10` 和 `x //= 10`：`x = -123` 时 `-123 // 10 == -13`、`-13 // 10 == -2`、`-2 // 10 == -1`、`-1 // 10 == -1`，永远到不了 `0`，死循环。
- 忘记检查范围：`x = 1534236469` 应返回 `0`（反转后 `9646324351`），没有溢出检查的 Python 版本会返回 `9646324351`。
- 丢掉符号：`x = -123` 返回 `321`，正确是 `-321`；结尾的 `0` 不用特殊处理，`120` 自然得到 `21`。

**同模式。** LC 9 回文数、LC 8 字符串转换整数、LC 66 加一、LC 2 两数相加。
