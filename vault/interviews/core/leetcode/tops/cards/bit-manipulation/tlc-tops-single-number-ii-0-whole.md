## Q
**LC 137 只出现一次的数字 II**｜Medium · 全公司热度第 445 名 · Top Interview 150

给你一个整数数组 `nums`，除某个元素仅出现一次外，其余每个元素都恰出现三次。找出并返回那个只出现了一次的元素。你必须设计并实现线性时间复杂度的算法且使用常数级空间来解决此问题。`1 <= nums.length <= 3 * 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`，`nums` 中除某个元素仅出现一次外，其余每个元素都恰出现三次。例：`nums = [2,2,3,2]` → `3`；`nums = [0,1,0,1,0,1,99]` → `99`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 按位计数（bit counting）：每一位上 1 的个数对 3 取模。

**一句话。** 对每个二进制位，把所有数在这一位上的 1 的个数加起来对 3 取余，出现三次的数各贡献 3 的倍数，余下的就是只出现一次的那个数在这一位的值。

**识别。** 「其余都出现 k 次，找出现一次的」：k = 2 时异或抵消；k = 3 时异或不再抵消，但每个二进制位上的个数仍然是 3 的倍数。线性时间 + 常数空间排除哈希表和排序。

**推导。** 哈希表计数 `O(n)` 空间，排序 `O(n log n)`。把数拆成 32 个二进制位，每一位独立：出现三次的数在某一位上要么全 0、要么贡献 3 个 1；只出现一次的数贡献 0 或 1 个。该位 1 的总数对 3 取余，就是答案在这一位的取值。组合 32 位得到答案。补码：最高位（第 31 位）为 1 表示负数，需要减去 `2^32`。

```python
def single_number(nums: list[int]) -> int:
    ans = 0
    for i in range(32):
        # 第 i 位上 1 的个数模 3：出现三次的数抵消，剩下只出现一次的那个数的这一位
        # Python 里 x >> i & 1 对负数也按补码无限扩展，所以低 32 位是对的
        if sum(x >> i & 1 for x in nums) % 3:
            ans |= 1 << i
    return ans - (1 << 32) if ans >> 31 else ans   # 32 位补码：第 31 位为 1 是负数
```

运行：`[2,2,3,2]` → `3`，`[0,1,0,1,0,1,99]` → `99`，`[5]` → `5`，`[-2,-2,1,1,-3,1,-3,-3,-4,-2]` → `-4`，`[-5, 7, 7, 7]` → `-5`。

**复杂度。** 时间 `O(32 n)` 即 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 状态机一遍扫描，不用外层 32 次循环：每一位用两个比特 `ones`、`twos` 记录「1 的个数模 3」（`00 -> 01 -> 10 -> 00`），所有位并行更新：

```python
def single_number_state(nums: list[int]) -> int:
    ones = twos = 0                              # ones：模 3 余 1 的位；twos：模 3 余 2 的位
    for x in nums:
        ones = (ones ^ x) & ~twos                # 出现 1 次或 4 次...：加入 ones，除非已经在 twos 里
        twos = (twos ^ x) & ~ones                # 出现 2 次：从 ones 转入 twos；第 3 次两者都清零
    return ones                                  # 只出现一次的数留在 ones 里
```

这里 Python 的无限补码对负数同样成立，不用再修正符号。
- 一般化：其余出现 `k` 次，把「模 3」改成「模 k」，状态机需要 `ceil(log2 k)` 个比特。

**易错点。**
- 忘了处理符号：`[-4,1,1,1]` 这类答案是负数的输入，不修正会返回 `4294967292`（正确 `-4`），因为 Python 的 `int` 没有 32 位上限。
- 把模 3 写成模 2（异或思路）：`[2,2,3,2]` 得到 `2 ^ 2 ^ 3 ^ 2 = 1`（正确 `3`）。
- 状态机里 `ones` 和 `twos` 的更新顺序不能换：`twos` 要用更新后的 `ones`，先更新 `twos` 的话 `[2,2,3,2]` 返回 `0`（正确 `3`）。

**同模式。** LC 136 只出现一次的数字、LC 260 只出现一次的数字 III、LC 169 多数元素、LC 268 丢失的数字。
