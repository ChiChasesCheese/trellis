## Q
**LC 268 丢失的数字**｜Easy · 全公司热度第 188 名 · Blind 75、NeetCode 150

给定一个包含 `[0, n]` 中 `n` 个数的数组 `nums`，找出 `[0, n]` 这个范围内没有出现在数组中的那个数。`n == nums.length`，`1 <= n <= 10^4`，`0 <= nums[i] <= n`，`nums` 中的所有数字都独一无二。进阶：能否实现线性时间复杂度、仅使用额外常数空间的算法？例：`nums = [3,0,1]` → `2`；`nums = [0,1]` → `2`；`nums = [9,6,4,2,3,5,7,0,1]` → `8`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 异或（XOR）的自反性：`a ^ a = 0`，`a ^ 0 = a`，且满足交换律；配对相消。

**一句话。** 把 `0..n` 所有数和数组里的所有数全部异或在一起，成对出现的都抵消，剩下的就是缺失的那个数。

**识别。** 「`n` 个数覆盖 `n + 1` 个可能值、恰好缺一个」+ 要求线性时间、常数空间：用异或（或求和公式）让相同的数抵消。排序 `O(n log n)`、哈希集合 `O(n)` 空间都不满足进阶。

**推导。** 暴力：对每个 `0..n` 的候选值在数组里线性查找，`O(n^2)`。哈希集合 `O(n)` 时间但 `O(n)` 空间。观察：把完整的 `0..n` 和给定数组放在一起，除缺失的数出现 1 次以外，其余都出现 2 次；异或能让出现两次的数抵消为 `0`，所以总异或值就是缺失数。让下标 `i` 与 `nums[i]` 配对异或，再补上 `n`（下标范围只到 `n - 1`）即可，不需要额外生成 `0..n`。

```python
def missing_number(nums: list[int]) -> int:
    ans = len(nums)                  # 下标只有 0..n-1，少了 n，先把 n 放进去
    for i, x in enumerate(nums):
        ans ^= i ^ x                 # 下标 i 与值 x 配对：两者相等时抵消，缺失的数只会留下一份
    return ans
```

运行：`[3,0,1]` → `2`，`[0,1]` → `2`，`[9,6,4,2,3,5,7,0,1]` → `8`，`[0]` → `1`，`[1]` → `0`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 求和公式：`n * (n + 1) // 2 - sum(nums)`。Python 的整数不会溢出，所以一行就够；在 32 位整数的语言里求和可能溢出，异或没有这个问题。
- 数组已排序时可以二分：找第一个 `nums[i] != i` 的位置，`O(log n)`。

**易错点。**
- 忘了初始值 `n`：`[0,1]` 的下标是 `0, 1`，异或后得到 `0`（正确 `2`）。
- 只异或值、不异或下标：`ans ^= x` 把 `n` 与所有元素异或，`[3,0,1]` 得到 `1`（正确 `2`）。
- 把范围当成 `[1, n]`：题目是 `[0, n]`，`[1]` 的答案是 `0`，不是 `2`。

**同模式。** LC 136 只出现一次的数字、LC 287 寻找重复数、LC 448 找到所有数组中消失的数字、LC 41 缺失的第一个正数。
