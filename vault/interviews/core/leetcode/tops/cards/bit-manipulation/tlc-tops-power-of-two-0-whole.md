## Q
**LC 231 2 的幂**｜Easy · 全公司热度第 265 名

给你一个整数 `n`，判断它是否是 `2` 的幂次方：存在整数 `x` 使得 `n == 2^x`。是返回 `true`，否则返回 `false`。`-2^31 <= n <= 2^31 - 1`。进阶：不使用循环 / 递归能解决吗？例：`n = 1` → `true`（`2^0`）；`n = 16` → `true`；`n = 3` → `false`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 位运算（bit manipulation）：`n & (n - 1)` 清除最低位的 `1`。

**一句话。** 正数是 `2` 的幂，当且仅当二进制里只有一个 `1`；`n & (n - 1)` 恰好把最低位的 `1` 清掉，结果为 `0` 就说明只有一个 `1`。

**识别。** 「是不是 `2` 的幂」「二进制里有几个 `1`」= `n & (n - 1)` 技巧（Brian Kernighan）；`O(1)`，不需要循环。

**推导。** `2` 的幂在二进制里是 `1` 后面跟若干个 `0`，如 `16 = 10000`。`n - 1` 把这个 `1` 变成 `0`、后面的 `0` 全变成 `1`（`01111`），两者没有任何位同时为 `1`，按位与为 `0`。不是 `2` 的幂时至少有两个 `1`，`n - 1` 只改变最低位的 `1` 及其右边，最高位的 `1` 还在，结果不为 `0`。`0` 和负数不是 `2` 的幂，要单独排除（`0 & -1 = 0` 会被误判）。

```python
def is_power_of_two(n: int) -> bool:
    # n & (n-1) 清掉最低位的 1；只有一个 1 的正数清完恰好为 0
    return n > 0 and (n & (n - 1)) == 0
```

运行：`1` → `True`；`16` → `True`；`3` → `False`；`0` → `False`；`-2` → `False`；`2^30` → `True`；`-2^31` → `False`。

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**拓展优化。**
- 等价写法：`n > 0 and n & -n == n`（`n & -n` 取出最低位的 `1`，只有一个 `1` 时它就是 `n` 自己）；或者 `n > 0 and 2**30 % n == 0`（`2^30` 是 `32` 位有符号整数里最大的 `2` 的幂，它的约数恰好都是 `2` 的幂）。

**易错点。**
- 漏掉 `n > 0`：`n = 0` 时 `0 & -1 == 0`，会误返回 `True`，正确是 `False`。
- 括号：C++ / Java 里 `==` 的优先级高于 `&`，`n & (n - 1) == 0` 会被解析成 `n & ((n - 1) == 0)`，必须写成 `(n & (n - 1)) == 0`；Python 里 `&` 优先级更高，不写也对，但跨语言时这条最容易栽。
- 循环版本 `while n % 2 == 0: n //= 2` 没排除 `0`：`n = 0` 时 `0 // 2` 还是 `0`，死循环。

**同模式。** LC 191 位 1 的个数、LC 342 4 的幂、LC 326 3 的幂、LC 338 比特位计数。
