## Q
**LC 239 滑动窗口最大值**｜Hard · 全公司热度第 11 名 · NeetCode 150、Hot 100

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。返回滑动窗口中的最大值。`1 <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`，`1 <= k <= nums.length`。

例：`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3` → `[3,3,5,5,6,7]`；`nums = [1]`，`k = 1` → `[1]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点：** 单调队列（monotonic deque）：队列里存下标，对应的值从队首到队尾严格递减，队首永远是窗口最大值。

**一句话。** 新元素进来时，把队尾所有不比它大的下标弹掉（它们又早又小，再也当不成最大值）；队首过期就弹出；队首就是当前窗口的最大值。

**识别。** 「定长滑动窗口 + 最大/最小值」，且 `n` 到 `10^5`，每个窗口重新取 `max` 是 `O(nk)`。窗口左端出、右端进的最值问题，用单调队列。

**推导。** 暴力：每个窗口 `max(nums[i:i+k])`，`O(nk)`。窗口滑动时只变化两端：新元素 `x` 进来后，窗口里任何比 `x` 小且更靠左的元素，既比 `x` 小又会比 `x` 更早离开窗口，所以永远没有机会成为最大值，可以直接丢掉。保留下来的元素从左到右必然递减，最大值就在最左边（队首）；队首下标如果滑出了窗口，就从队首弹掉。每个元素入队出队一次，`O(n)`。

**简单解法。** 用最大堆加惰性删除：堆里存 `(-值, 下标)`，取最大值前把堆顶已滑出窗口的弹掉。多一个 `log` 因子，但不需要单调队列的不变式：
```python
import heapq


def max_sliding_window_heap(nums: list[int], k: int) -> list[int]:
    heap: list[tuple[int, int]] = []
    res: list[int] = []
    for i, x in enumerate(nums):
        heapq.heappush(heap, (-x, i))           # Python 只有最小堆，取负数变最大堆
        if i >= k - 1:
            while heap[0][1] <= i - k:          # 堆顶下标已不在窗口内：惰性删除
                heapq.heappop(heap)
            res.append(-heap[0][0])
    return res
```

**最优解：** 单调队列。

```python
from collections import deque


def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq: deque[int] = deque()            # 存下标；对应的值从队首到队尾严格递减，队首是窗口最大值
    res: list[int] = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x: # 队尾比 x 小：又早又小，永远不可能是最大值
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:              # 队首已经滑出窗口 [i-k+1, i]
            dq.popleft()
        if i >= k - 1:                  # 窗口已经形成，记录最大值
            res.append(nums[dq[0]])
    return res
```

**运行。** `[1,3,-1,-3,5,3,6,7]`、`k = 3` → `[3, 3, 5, 5, 6, 7]`；`[1]`、`k = 1` → `[1]`；`[9,8,7,6]`、`k = 2` → `[9, 8, 7]`；`[1,2,3]`、`k = 3` → `[3]`。

**复杂度。** 时间 `O(n)`；空间 `O(k)`（队列里至多 `k` 个下标）。

**拓展优化。**
- 滑动窗口最小值：把比较方向反过来即可；同时要最大和最小就维护两个队列。
- 数组分块 + 前后缀最大：把数组按 `k` 切块，块内算前缀最大和后缀最大，窗口最大值 = `max(后缀最大[l], 前缀最大[r])`，不依赖队列，`O(n)`。

**易错点。**
- 队列里存值而不存下标：无法判断队首是否过期，窗口滑过之后仍然读到旧的最大值。
- 过期判断写成 `dq[0] < i - k`：少弹一次，已经滑出窗口的队首被保留，`[9,8,7,6]`、`k = 2` 输出 `[9, 9, 8]`，正确是 `[9, 8, 7]`。
- 窗口没满就记录答案：忘了 `i >= k - 1`，示例 1 得到 `[1, 3, 3, 3, 5, 5, 6, 7]`，多出前 `k - 1` 个值，长度不是 `n - k + 1`。

**同模式。** LC 862 和至少为 K 的最短子数组、LC 1438 绝对差不超过限制的最长连续子数组、LC 1696 跳跃游戏 VI、LC 84 柱状图中最大的矩形。
