## Q
**LC 424 替换后的最长重复字符**｜Medium · 全公司热度第 62 名 · Blind 75、NeetCode 150

给你字符串 `s` 和整数 `k`。你可以选择字符串中的任一字符，把它改成任何其他大写英文字符，该操作最多执行 `k` 次。返回执行上述操作后，包含相同字母的最长子串的长度。`1 <= s.length <= 10^5`，`s` 仅由大写英文字母组成，`0 <= k <= s.length`。例：`s = "ABAB"`, `k = 2` → `4`；`s = "AABABBA"`, `k = 1` → `4`（把中间的一个 `A` 换成 `B`，得到 `"AABBBBA"`，其中 `"BBBB"` 长度为 4）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 滑动窗口 + 「窗口长度 − 最高频字符数 ≤ k」的合法性判据；窗口只增不缩的技巧。

**一句话。** 窗口合法当且仅当 `窗口长度 - 窗口内最多的字母个数 <= k`；右端扩张，不合法就整体右移一格，最后窗口长度就是答案。

**识别。** 「最多修改 `k` 次后得到最长的连续相同段」= 窗口内把其余字母都改成最多的那种；`s` 只含 26 个大写字母，`n = 10^5`，`O(26n)` 也能过。

**推导。** 暴力：对每个子串数最多的字母，检查 `长度 - 最大频数 <= k`，`O(n^2)` 到 `O(n^3)`。合法性具有单调性（子窗口一定合法），可以用滑窗。再进一步：窗口只需要在 `max_freq` 变大时才可能变长，所以 `max_freq` 无需随左端收缩而更新，窗口也不必缩短，只要不合法就把窗口整体平移一格。

**简单解法。** 标准滑窗：不合法时 `while` 缩左端，并在每次判断时现算 `max(count)`（对 26 个计数取最大，常数 26），不需要上面「只增不减」的技巧，逻辑更直白，复杂度 `O(26n)`，一般同样可以通过。

```python
def character_replacement(s: str, k: int) -> int:
    count = [0] * 26  # 窗口内每个字母的个数
    left = max_freq = 0  # max_freq：窗口出现过的最高单字母频数（只增不减，不必随左端收缩而更新）
    for right, ch in enumerate(s):
        count[ord(ch) - 65] += 1
        max_freq = max(max_freq, count[ord(ch) - 65])
        # 窗口长度 - 最多那种字母的个数 = 需要替换的字符数；超过 k 就把整个窗口右平移一格
        if right - left + 1 - max_freq > k:
            count[ord(s[left]) - 65] -= 1
            left += 1  # 用 if 不用 while：窗口只会保持或变长，永不缩短
    return len(s) - left  # 窗口最终长度就是答案：只有 max_freq 变大，窗口才会变长
```

运行：`("ABAB", 2)` → `4`；`("AABABBA", 1)` → `4`；`("A", 0)` → `1`；`("AAAA", 0)` → `4`。

**复杂度。** 时间 `O(n)`，空间 `O(26)`。

**易错点。**
- 不能把 `max_freq` 取整个字符串的全局最大值：`"AABABBA"`, `k = 1` 会算出 `5`，正确是 `4`。
- `max_freq` 不随左端收缩而减小是故意的：只有它变大，窗口才可能变长，过期的偏大值最多让窗口保持当前长度，不会虚增答案。
- 返回 `len(s) - left` 依赖窗口只平移或变长的性质，换成 `while` 缩窗口后就不能这样返回，需要另记 `best`。

**同模式。** LC 1004 最大连续1的个数 III、LC 3 无重复字符的最长子串、LC 1493 删掉一个元素以后全为 1 的最长子数组、LC 76 最小覆盖子串。
