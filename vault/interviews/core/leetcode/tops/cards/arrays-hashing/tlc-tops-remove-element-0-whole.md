## Q
**LC 27 移除元素**｜Easy · 全公司热度第 233 名 · Top Interview 150

给你一个数组 `nums` 和一个值 `val`，原地移除所有等于 `val` 的元素，元素的顺序可以改变。设不等于 `val` 的元素个数为 `k`，要求 `nums` 的前 `k` 个元素是不等于 `val` 的元素，返回 `k`；前 `k` 个之后留下什么不重要。`0 <= nums.length <= 100`，`0 <= nums[i] <= 50`，`0 <= val <= 100`。例：`nums = [3,2,2,3], val = 3` → `2`，`nums` 前两个元素为 `2, 2`；`nums = [0,1,2,2,3,0,4,2], val = 2` → `5`，前五个元素为 `0,1,3,0,4`（顺序可任意）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 快慢指针（read / write pointer）原地过滤。

**一句话。** 读指针扫整个数组，遇到不等于 `val` 的元素就写到写指针处，写指针的最终位置就是 `k`。

**识别。** 「原地 + 删除满足条件的元素 + 返回新长度」是双指针压缩（compaction）：`O(1)` 额外空间，一遍扫描。

**推导。** 每发现一个 `val` 就 `del nums[i]` 或 `pop`，列表删除要搬动后面所有元素，最坏 `O(n^2)`；还会在遍历时改变下标。浪费在于反复搬移；让保留下来的元素一次性写到前缀里，每个元素最多写一次。

```python
def remove_element(nums: list[int], val: int) -> int:
    k = 0                           # 写指针：nums[:k] 已经是保留下来的元素
    for x in nums:                  # 读指针：for 循环顺序读每个元素
        if x != val:
            nums[k] = x             # 写入不会超过读的位置，不会覆盖尚未读的元素
            k += 1
    return k
```

运行：`([3,2,2,3], 3)` → `2`，`nums[:2] = [2, 2]`；`([0,1,2,2,3,0,4,2], 2)` → `5`，`nums[:5] = [0, 1, 3, 0, 4]`；`([], 0)` → `0`；`([1], 1)` → `0`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- `val` 很少出现时，上面的写法仍然会把每个元素都复制一遍。改成「遇到 `val` 就用末尾元素覆盖它」，只写 `val` 的个数那么多次（顺序会变，题目允许）：

```python
def remove_element_swap(nums: list[int], val: int) -> int:
    i, n = 0, len(nums)             # nums[:n] 是尚未确定的区间
    while i < n:
        if nums[i] == val:
            nums[i] = nums[n - 1]   # 末尾元素补到这里，它还没检查过，所以 i 不前进
            n -= 1
        else:
            i += 1
    return n
```

**易错点。**
- 在遍历中 `nums.remove(val)` 或 `del`：`[3,2,2,3]` 这类相邻重复在 `for` 里会跳过元素，且每次删除 `O(n)`。
- 覆盖法里补过来的末尾元素没检查过，就把 `i += 1`：`[3,2,2], val = 2` 会漏删第二个 `2`，返回 `2` 而不是 `1`。
- 只返回计数、没有真正把保留元素放到前 `k` 位：评测会检查 `nums[:k]`。

**同模式。** LC 26 删除有序数组中的重复项、LC 283 移动零、LC 80 删除有序数组中的重复项 II、LC 75 颜色分类。
