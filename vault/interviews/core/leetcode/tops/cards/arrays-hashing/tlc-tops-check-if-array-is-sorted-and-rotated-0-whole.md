## Q
**LC 1752 检查数组是否经排序和轮转得到**｜Easy · 全公司热度第 266 名

给你一个数组 `nums`。`nums` 的源数组中，所有元素与 `nums` 相同，但按非递减顺序排列。如果 `nums` 能够由源数组轮转若干位置（包括 0 个位置）得到，返回 `true`，否则返回 `false`。源数组中可能存在重复项。`1 <= nums.length <= 100`，`1 <= nums[i] <= 100`。例：`nums = [3,4,5,1,2]` → `true`（源数组 `[1,2,3,4,5]` 轮转 2 位）；`nums = [2,1,3,4]` → `false`；`nums = [1,2,3]` → `true`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 循环数组（circular array）上的「下降点」计数。

**一句话。** 把数组首尾相连成环，一个有序数组轮转之后环上最多出现一次「前一个比后一个大」的下降，数出下降次数并判断 `<= 1`。

**识别。** 「排序后轮转」「循环」：用 `(i + 1) % n` 把线性数组当环处理；有序 + 轮转的指纹就是**至多一个断点**。`n <= 100` 时暴力也行，但计数更干净。

**推导。** 暴力：排序后枚举每个轮转位置比较，`O(n^2)`。有序数组（元素不全相等）连成环后恰有一次下降：最大值回到最小值；轮转只是换了这次下降出现的位置（`5 -> 1`），其余位置仍单调不降。全相等时一次下降也没有。环上下降次数 `>= 2` 说明至少有两处「断开」，不可能由一个有序数组轮转得到。

```python
def check(nums: list[int]) -> bool:
    n = len(nums)
    # 环上相邻对 (nums[i], nums[(i+1) % n]) 里，前一个更大的次数；最后一对是 nums[-1] -> nums[0]
    drops = sum(nums[i] > nums[(i + 1) % n] for i in range(n))
    return drops <= 1
```

运行：`[3,4,5,1,2]` → `True`，`[2,1,3,4]` → `False`，`[1,2,3]` → `True`，`[1,1,1]` → `True`，`[2,1]` → `True`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 一遍扫描提前退出：数到第 2 次下降就返回 `False`。
- 要找到轮转了多少位：唯一那次下降位置 `i` 满足 `nums[i] > nums[i + 1]`，轮转量由 `i + 1` 决定（全相等或无下降时为 `0`）。

**易错点。**
- 忘了首尾那一对：`[2,1,3,4]` 若只数线性相邻，下降只有 `2 -> 1` 一次，会误判成 `True`；环上的 `4 -> 2` 才是第二次下降，正确是 `False`。
- 下降要用严格 `>`：相等不算下降，`[1,1,1]` 用 `>=` 会数出 3 次而返回 `False`（正确 `True`）。
- 判断写成 `drops == 1`：全相等的 `[1,1,1]` 一次下降也没有，会错成 `False`（正确 `True`），所以是 `<= 1`。

**同模式。** LC 153 寻找旋转排序数组中的最小值、LC 33 搜索旋转排序数组、LC 896 单调数列、LC 189 轮转数组。
