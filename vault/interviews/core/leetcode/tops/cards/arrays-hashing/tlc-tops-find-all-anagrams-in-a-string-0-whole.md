## Q
**LC 438 找到字符串中所有字母异位词**｜Medium · 全公司热度第 170 名 · Hot 100

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**异位词**（字母相同、顺序可以不同）子串，返回这些子串的起始索引，不考虑输出顺序。`1 <= s.length, p.length <= 3 * 10^4`，`s` 和 `p` 仅包含小写字母。例：`s = "cbaebabacd"`, `p = "abc"` → `[0,6]`；`s = "abab"`, `p = "ab"` → `[0,1,2]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 滑动窗口 + 计数表（need counter）：窗口恰好「用完」`p` 的字符。

**一句话。** `need[c]` 记录窗口还欠多少个字符 `c`；加入右端字符后若某字符多了，就缩左端吐出来；窗口长度等于 `len(p)` 且没有多余字符时，每个字符恰好用完，就是一个异位词。

**识别。** 「子串是不是某个串的排列 / 字母异位词」= 窗口内字符的**多重集合**相等；固定长度 `len(p)`，`n = 3 * 10^4` 要求 `O(n)` 附近。

**推导。** 暴力：每个长度为 `m` 的子串排序后和 `p` 排序结果比较，`O(n·m log m)`。窗口右移只增减两个字符，不需要重新统计。用「欠账表」把比较变成不变式：窗口内没有任何字符透支（`need` 全部 `>= 0`），且窗口长度恰好为 `m`，那么 `need` 的总和为 `m - m = 0`，所以全部为 `0`，两个多重集合相等。

**简单解法。** 定长窗口，每步比较两个计数：`Counter(s[i:i+m]) == Counter(p)`（或维护 26 长度数组，比较两个数组），`O(26n)`，没有需要维护的不变式，也是可以接受的答案。

```python
from collections import Counter


def find_anagrams(s: str, p: str) -> list[int]:
    need = Counter(p)  # need[c]：窗口还欠 c 多少个（负数表示窗口里 c 多了）
    res: list[int] = []
    left = 0
    for right, ch in enumerate(s):
        need[ch] -= 1
        while need[ch] < 0:  # 窗口里 ch 多了：左端缩到把多出来的 ch 吐掉
            need[s[left]] += 1
            left += 1
        if right - left + 1 == len(p):  # 窗口没有多余字符，长度又刚好是 len(p)：每个字符恰好用完
            res.append(left)
    return res
```

运行：`("cbaebabacd", "abc")` → `[0, 6]`；`("abab", "ab")` → `[0, 1, 2]`；`("a", "ab")` → `[]`；`("aaa", "b")` → `[]`。

**复杂度。** 时间 `O(n)`（每个下标最多进出窗口各一次），空间 `O(Σ)`，`Σ = 26`。

**易错点。**
- 命中后跳过整个窗口（`left += len(p)`）是错的：`"abab"`, `"ab"` 会得到 `[0, 2]`，漏掉 `1`，正确是 `[0, 1, 2]`；命中后只正常右移一格，下一轮自然会吐出多余字符。
- `s` 里出现不在 `p` 中的字符时，`need` 变成负数，`while` 会一直缩到把它吐掉（窗口清空），不会死循环。
- `len(s) < len(p)` 时窗口永远凑不够长度，自然返回 `[]`。

**同模式。** LC 567 字符串的排列、LC 76 最小覆盖子串、LC 49 字母异位词分组、LC 242 有效的字母异位词。
