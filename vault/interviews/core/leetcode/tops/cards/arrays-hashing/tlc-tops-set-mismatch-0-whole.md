## Q
**LC 645 错误的集合**｜Easy · 全公司热度第 292 名

集合 `s` 原本包含 `1` 到 `n` 的所有整数，因为数据错误，其中一个数被复制成了另一个数的值，导致**丢失一个数**同时**有一个数重复**。给定出错后的数组 `nums`，找出重复的数和丢失的数，以 `[重复, 丢失]` 的形式返回。`2 <= nums.length <= 10^4`，`1 <= nums[i] <= 10^4`。例：`nums = [1,2,2,4]` → `[2,3]`；`nums = [1,1]` → `[1,2]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 哈希集合 + 求和做差；值域是 `1..n`，数组下标可以当哈希表。

**一句话。** 去重后的和比原和少一个重复值，比 `1..n` 的和少一个丢失值，两次相减得到两个数。

**识别。** 「`1..n` 里恰好错一个」「找重复 + 找缺失」首选求和 / 集合 / 计数；`n = 10^4` 任何 `O(n)` 都行，追求 `O(1)` 额外空间则用下标标记。

**推导。** 暴力：对每个 `1..n` 的数扫一遍数组数出现次数，`O(n^2)`。把差量拆开：`sum(nums) - sum(set(nums))` 恰好是多出来的那一份重复值；`n(n+1)/2 - sum(set(nums))` 恰好是缺失值（集合里少了它，其余都在）。

```python
def find_error_nums(nums: list[int]) -> list[int]:
    n = len(nums)
    uniq = set(nums)
    dup = sum(nums) - sum(uniq)                # 重复值被多算了一次
    missing = n * (n + 1) // 2 - sum(uniq)     # 1..n 的完整和，减去实际出现过的不同值之和
    return [dup, missing]
```

运行：`[1,2,2,4]` → `[2,3]`；`[1,1]` → `[1,2]`；`[2,2]` → `[2,1]`；`[3,2,3,4,6,5]` → `[3,1]`。

**复杂度。** 时间 `O(n)`，空间 `O(n)`（集合）。

**拓展优化。**
- 额外空间 `O(1)`：值域是 `1..n`，把「值 `x` 出现过」记在 `nums[x - 1]` 的符号上，第二次碰到已为负的位置就是重复值，扫描后仍为正的位置 `+ 1` 是丢失值（会改输入）：

```python
def find_error_nums_mark(nums: list[int]) -> list[int]:
    dup = -1
    for x in nums:
        i = abs(x) - 1  # 值 x 对应的位置；abs 因为这个位置可能已被标成负数
        if nums[i] < 0:
            dup = abs(x)  # 该位置已标过：x 是第二次出现
        else:
            nums[i] = -nums[i]
    missing = next(i + 1 for i, v in enumerate(nums) if v > 0)  # 从没被标过的位置
    return [dup, missing]
```

**易错点。**
- 只用 `n(n+1)/2 - sum(nums)`：它等于「丢失值 - 重复值」，`[1,2,2,4]` 得到 `1`，正确的丢失值是 `3`。
- 返回顺序写反：题目要 `[重复, 丢失]`，`[3,2]` 是错的。
- 丢失的恰好是 `n`（`[1,1]` → `[1,2]`）：循环 `range(1, n)` 会漏掉 `n`，要写 `range(1, n + 1)`。

**同模式。** LC 442 数组中重复的数据、LC 448 找到所有数组中消失的数字、LC 287 寻找重复数、LC 268 丢失的数字。
