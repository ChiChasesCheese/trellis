## Q
**LC 58 最后一个单词的长度（Length of Last Word）**｜Easy · 全公司热度第 342 名 · Top Interview 150

给你一个字符串 `s`，由若干单词组成，单词前后用一些空格字符隔开。返回字符串中最后一个单词的长度。单词是指仅由字母组成、不包含任何空格字符的最大子字符串。`1 <= s.length <= 10^4`，`s` 仅有英文字母和空格 `' '` 组成，`s` 中至少存在一个单词。例：`s = "Hello World"` → `5`；`s = "   fly me   to   the moon  "` → `4`；`s = "luffy is still joyboy"` → `6`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 字符串从后向前扫描：跳过末尾空格，再数字母。

**一句话。** 从末尾先跳过所有空格，再向前数到下一个空格或字符串开头为止，数到的就是最后一个单词的长度。

**识别。** 只关心最后一个单词，从后往前走一遍就够，不用把整串切开。陷阱是末尾可能带空格。

**推导。** `s.split()` 切成所有单词再取最后一个，写法最短，但会为用不到的前面单词分配列表，空间 `O(n)`。从尾部扫描只看最后一段，`O(1)` 额外空间，也是面试官期待的写法。

```python
def length_of_last_word(s: str) -> int:
    i = len(s) - 1
    while s[i] == " ":                 # 先跳过末尾的空格（保证至少有一个单词，所以不会越界）
        i -= 1
    end = i
    while i >= 0 and s[i] != " ":      # 再往前数这个单词的字母
        i -= 1
    return end - i
```

运行：`"Hello World"` → `5`，`"   fly me   to   the moon  "` → `4`，`"luffy is still joyboy"` → `6`，`"a "` → `1`，`"a"` → `1`。

**复杂度。** 时间 `O(n)`（最坏扫过全部末尾空格和最后一个单词），空间 `O(1)`。

**拓展优化。**
- 面试可先写 `len(s.split()[-1])`：`split()` 不带参数会按任意连续空白切分并丢掉空串，正好处理末尾空格；再说明手写版本把空间降到 `O(1)`。

**易错点。**
- 直接从 `s[-1]` 开始数字母：`"a "` 会数出 `0`，正确 `1`。
- 用 `s.split(" ")[-1]`（显式传空格）：末尾空格会切出空串，`"a "` 得到 `0`；`split()` 不带参数才会丢弃空串。
- 向前数字母时不检查 `i >= 0`：`"Hello"` 的下标会减到 `-1`，Python 的负下标悄悄绕回字符串末尾继续读，最终抛 `IndexError`。
