## Q
**LC 62 不同路径**｜Medium · 全公司热度第 168 名 · Blind 75、NeetCode 150、Hot 100、LeetCode 75

一个机器人位于 `m x n` 网格的左上角，每次只能向下或向右移动一步，试图到达网格的右下角。问总共有多少条不同的路径？`1 <= m, n <= 100`，题目数据保证答案小于等于 `2 * 10^9`。例：`m = 3, n = 7` → `28`；`m = 3, n = 2` → `3`；`m = 7, n = 3` → `28`；`m = 3, n = 3` → `6`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 二维网格 DP（grid DP）：到达一个格子的方案数 = 来自上方的 + 来自左方的。

**一句话。** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，第一行和第一列都只有一条路。

**识别。** 「只能向右 / 向下、数方案」= 路径计数 DP；`m, n <= 100`，状态 `10^4` 个，每个 `O(1)` 转移。

**推导。** 递归定义 `f(i, j) = f(i-1, j) + f(i, j-1)`，基线是第一行 / 第一列为 `1`；直接递归会指数级重复计算同一个格子，把结果存进表里就是自底向上的 DP。最后一步一定是「从上面下来」或「从左边过来」，两类路径互不重叠，所以相加。

```python
def unique_paths(m: int, n: int) -> int:
    # dp[i][j]：从左上角走到 (i, j) 的路径数；第一行、第一列只有一条路（一直向右 / 一直向下）
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]  # 最后一步要么从上面下来，要么从左边过来
    return dp[m - 1][n - 1]
```

运行：`(3, 7)` → `28`；`(3, 2)` → `3`；`(7, 3)` → `28`；`(3, 3)` → `6`；`(1, 1)` → `1`；`(10, 10)` → `48620`。

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。空间可以压到 `O(n)`：见 Python 工具箱「DP 降维」。

**拓展优化。**
- 组合数公式：一共要走 `m + n - 2` 步，其中 `m - 1` 步向下，答案是 `math.comb(m + n - 2, m - 1)`，`O(min(m, n))`，Python 大整数不会溢出。
- 加障碍物（LC 63）：障碍格的 `dp` 置 `0`，第一行 / 第一列遇到障碍后后面全是 `0`。

**易错点。**
- 整张表初始化成 `0` 又不处理边界：`dp[0][*]` 和 `dp[*][0]` 永远是 `0`，最终答案是 `0`；初始化成 `1` 才对。
- `dp` 的下标先行后列，`dp[i][j]` 里 `i` 对应 `m`、`j` 对应 `n`，写反会让 `m ≠ n` 的样例（如 `3×7`）下标越界。

**同模式。** LC 64 最小路径和、LC 63 不同路径 II、LC 120 三角形最小路径和、LC 70 爬楼梯。
