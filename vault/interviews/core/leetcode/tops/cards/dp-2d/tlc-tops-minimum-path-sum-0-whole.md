## Q
**LC 64 最小路径和**｜Medium · 全公司热度第 148 名 · Hot 100、Top Interview 150

给定包含非负整数的 `m x n` 网格 `grid`，找出一条从左上角到右下角的路径，使路径上的数字总和最小。每次只能向下或向右移动一步。`m == grid.length`，`n == grid[i].length`，`1 <= m, n <= 200`，`0 <= grid[i][j] <= 200`。例：`[[1,3,1],[1,5,1],[4,2,1]]` → `7`（`1→3→1→1→1`）；`[[1,2,3],[4,5,6]]` → `12`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 二维网格 DP（grid DP）：到达每个格子的最小路径和 = 本格 + min(上, 左)。

**一句话。** `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`，第一行 / 第一列只有一个来源。

**识别。** 「只能向右 / 向下、求路径代价最小」= 网格 DP；`m, n <= 200`，`O(mn)` 即可。

**推导。** 每个格子的最后一步只能来自上方或左方，所以到它的最小代价由这两个邻居的最小代价决定；两个邻居各自是同类子问题。递归会重复计算，用表格按行从左到右填一遍即可。贪心（每步选更小的方向）不成立，因为局部小的选择可能通向后面很大的格子。

```python
def min_path_sum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]  # dp[i][j]：从左上角走到 (i, j) 的最小路径和
    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                prev = 0  # 起点：前面没有路径
            elif i == 0:
                prev = dp[i][j - 1]  # 第一行只能从左边来
            elif j == 0:
                prev = dp[i - 1][j]  # 第一列只能从上面来
            else:
                prev = min(dp[i - 1][j], dp[i][j - 1])  # 其余格：取上、左中较小的
            dp[i][j] = prev + grid[i][j]
    return dp[m - 1][n - 1]
```

运行：`[[1,3,1],[1,5,1],[4,2,1]]` → `7`；`[[1,2,3],[4,5,6]]` → `12`；`[[7]]` → `7`。

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。空间可以压到 `O(n)`：见 Python 工具箱「DP 降维」。

**易错点。**
- 贪心走更小的邻居：`[[1,3,1],[1,5,1],[4,2,1]]` 会得到 `9`，正确是 `7`。
- 第一行只能从左边来、第一列只能从上面来；直接写 `min(dp[i-1][j], dp[i][j-1])` 会在边界访问 `dp[-1]`（Python 不报错，但取到最后一行 / 最后一列的值，得到错误结果）。
- 起点格 `dp[0][0]` 就是 `grid[0][0]`，不是 `0`。

**同模式。** LC 62 不同路径、LC 120 三角形最小路径和、LC 174 地下城游戏、LC 931 下降路径最小和。
