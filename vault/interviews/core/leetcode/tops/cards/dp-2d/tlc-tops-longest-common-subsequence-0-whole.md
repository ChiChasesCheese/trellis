## Q
**LC 1143 最长公共子序列**｜Medium · 全公司热度第 141 名 · Blind 75、NeetCode 150、Hot 100、LeetCode 75

给定两个字符串 `text1` 和 `text2`，返回它们的最长**公共子序列**的长度，不存在则返回 `0`。子序列是原字符串删除某些字符（也可以不删）、不改变剩余字符相对顺序得到的新字符串。`1 <= text1.length, text2.length <= 1000`，只含小写英文字母。例：`"abcde"`, `"ace"` → `3`（`"ace"`）；`"abc"`, `"abc"` → `3`；`"abc"`, `"def"` → `0`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 双串二维 DP：`dp[i][j]` 表示两个前缀的 LCS 长度。

**一句话。** 末尾字符相同就 `dp[i-1][j-1] + 1`，否则取「去掉 `text1` 末尾」和「去掉 `text2` 末尾」较大者。

**识别。** 「两个字符串、子序列（不要求连续）、求最长」= 经典双串 DP；`m, n <= 1000` 允许 `O(mn)` 的 `10^6` 状态。

**推导。** 递归：`lcs(i, j)` 看两个前缀的末尾。相同：这两个字符一定可以配对（不配对不会更好），问题缩小为 `lcs(i-1, j-1) + 1`。不同：至少有一个末尾字符不会出现在公共子序列里，分别尝试去掉，取较大者。子问题只由 `(i, j)` 决定，总共 `mn` 个，递归会重复，改成表格自底向上。第 0 行 / 第 0 列代表空串，值为 `0`。

```python
def longest_common_subsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    # dp[i][j]：text1[:i] 与 text2[:j] 的 LCS 长度；多出的第 0 行、第 0 列表示空串，答案为 0
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1  # 末尾字符相同：配对它们一定不亏
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # 不同：两个末尾字符至少有一个用不上
    return dp[m][n]
```

运行：`("abcde", "ace")` → `3`；`("abc", "abc")` → `3`；`("abc", "def")` → `0`；`("a", "a")` → `1`。

**复杂度。** 时间 `O(mn)`，空间 `O(mn)`。空间可以压到 `O(min(m, n))`：见 Python 工具箱「DP 降维」。

**拓展优化。**
- 输出一个具体的 LCS，不止长度：从 `dp[m][n]` 往回走，字符相同就记下并走斜上，否则往值大的方向走，最后反转。

**易错点。**
- 当成「最长公共子串」做：不同时把 `dp` 置 `0`，会让 `("abcde", "ace")` 得到 `1`，正确是 `3`。
- 下标错位：`dp` 比字符串多一行一列，比较的是 `text1[i-1]` 和 `text2[j-1]`，写成 `text1[i]` 会越界或错位。
- 相同时写 `dp[i-1][j] + 1` 而非 `dp[i-1][j-1] + 1`，会让同一个字符被重复配对。

**同模式。** LC 72 编辑距离、LC 583 两个字符串的删除操作、LC 516 最长回文子序列、LC 392 判断子序列。
