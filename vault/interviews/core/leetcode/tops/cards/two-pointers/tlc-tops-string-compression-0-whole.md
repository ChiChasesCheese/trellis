## Q
**LC 443 压缩字符串**｜Medium · 全公司热度第 31 名 · LeetCode 75

给你字符数组 `chars`，按下述算法压缩：从空字符串 `s` 开始，对 `chars` 中每组**连续重复字符**，如果这一组长度为 `1`，就把字符追加到 `s`；否则追加字符，后跟这一组的长度。压缩后的 `s` 不直接返回，而要原地存回 `chars`；组长度 `10` 及以上时，在数组中拆成多个字符（`12` 写成 `'1'`、`'2'`）。修改完输入数组后，返回数组的新长度。必须只使用常量额外空间，超出返回长度的内容无关紧要。`1 <= chars.length <= 2000`，`chars[i]` 是小写字母、大写字母、数字或符号。例：`["a","a","b","b","c","c","c"]` → `6`，前 6 个字符为 `["a","2","b","2","c","3"]`；`["a"]` → `1`；`["a","b","b","b","b","b","b","b","b","b","b","b","b"]` → `4`，前 4 个为 `["a","b","1","2"]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 读写双指针（read / write pointer）原地改写 + 分组计数。

**一句话。** `read` 数出每组连续相同字符的长度，`write` 在同一个数组里写下「字符 + 组长（若大于 1）」；写入永远不会追上还没读的位置。

**识别。** 「原地压缩 / 改写」「`O(1)` 额外空间」= 读写指针；「连续相同字符的分组」= 内层 `while` 数一段。

**推导。** 新建列表拼接最直观，但违反「常量额外空间」。能原地做的原因：一组压缩后的长度（字符 + 至多几位数字）不会超过这一组原来的长度（组长 `2` 压缩后是 `2` 个字符，组长 `>2` 时更短），所以 `write <= read` 恒成立，写入不会覆盖没读到的内容。

```python
def compress(chars: list[str]) -> int:
    write = read = 0  # read 扫描原数组，write 是压缩结果的写入位置（write <= read，不会覆盖没读的内容）
    while read < len(chars):
        ch, start = chars[read], read
        while read < len(chars) and chars[read] == ch:  # 数出这一组连续相同字符的长度
            read += 1
        chars[write] = ch
        write += 1
        if read - start > 1:  # 组长为 1 不写数字
            for digit in str(read - start):  # 12 要拆成 '1'、'2' 两个字符
                chars[write] = digit
                write += 1
    return write
```

运行：`["a","a","b","b","c","c","c"]` → `6`，数组前 6 项 `['a','2','b','2','c','3']`；`["a"]` → `1`；`["a","b"×12]` → `4`，前 4 项 `['a','b','1','2']`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`（`str(count)` 最多 4 位，是常数）。

**易错点。**
- 把组长 `12` 当一个元素写入：`chars` 里每个格子只能放一个字符，必须拆成 `'1'`、`'2'`，否则示例 3 会得到长度 `3` 而不是 `4`。
- 组长为 `1` 时不写数字：`["a"]` 压缩后是 `["a"]`，不是 `["a","1"]`。
- 内层 `while` 必须带 `read < len(chars)`，否则最后一组会越界。

**同模式。** LC 283 移动零、LC 27 移除元素、LC 26 删除有序数组中的重复项、LC 38 外观数列。
