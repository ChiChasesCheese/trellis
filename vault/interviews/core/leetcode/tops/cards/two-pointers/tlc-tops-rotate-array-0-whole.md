## Q
**LC 189 轮转数组**｜Medium · 全公司热度第 61 名 · Hot 100、Top Interview 150

给定整数数组 `nums`，把数组中的元素向右轮转 `k` 个位置，`k` 是非负数。`1 <= nums.length <= 10^5`，`-2^31 <= nums[i] <= 2^31 - 1`，`0 <= k <= 10^5`。例：`nums = [1,2,3,4,5,6,7]`, `k = 3` → `[5,6,7,1,2,3,4]`；`nums = [-1,-100,3,99]`, `k = 2` → `[3,99,-1,-100]`。进阶：尽可能想出至少三种不同的方法；你能用空间复杂度 `O(1)` 的原地算法解决吗？

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 三次反转（reverse）实现原地循环移位。

**一句话。** 整体反转，再分别反转前 `k` 个和后 `n - k` 个。

**识别。** 「循环移位 / 前后两段互换」+ 要求 `O(1)` 空间；`k` 可以大于 `n`，先取模。

**推导。** 新建数组把 `nums[i]` 放到 `(i + k) % n`，`O(n)` 时间 `O(n)` 空间，不满足进阶。原地一个个移动 `k` 次是 `O(nk)`。把数组看成 `AB`（`A` 是前 `n-k` 个，`B` 是后 `k` 个），目标是 `BA`；反转的性质是 `(AᵀBᵀ)ᵀ = BA`，所以先整体反转得到 `BᵀAᵀ`，再把两段各自翻回来。

**简单解法。** 切片拼接：`k %= n; nums[:] = nums[-k:] + nums[:-k]`，`O(n)` 额外空间，一行写完，是可以接受的开场答案；三次反转是把空间降到 `O(1)`。

```python
def rotate(nums: list[int], k: int) -> None:
    n = len(nums)
    k %= n  # k 可以大于 n，转满 n 步等于没转

    def reverse(left: int, right: int) -> None:  # 原地反转 nums[left..right]
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1

    # 记 A = nums[:n-k]，B = nums[n-k:]；向右转 k 步就是 AB -> BA，而 BA = (Aᵀ Bᵀ)ᵀ
    reverse(0, n - 1)  # 整体反转：BᵀAᵀ，B 已经到了最前面（但是倒的）
    reverse(0, k - 1)  # 前 k 个翻回：B
    reverse(k, n - 1)  # 后 n-k 个翻回：A
```

运行：`([1,2,3,4,5,6,7], 3)` → `[5,6,7,1,2,3,4]`；`([-1,-100,3,99], 2)` → `[3,99,-1,-100]`；`([1,2], 5)` → `[2,1]`；`k = 0` 时数组不变。

**复杂度。** 时间 `O(n)`（每个元素最多交换两次），空间 `O(1)`。

**拓展优化。**
- 环状替换：每个元素直接放到 `(i + k) % n`，沿着环走 `gcd(n, k)` 个环，同样 `O(n)` 时间 `O(1)` 空间，但环的数量和起点的处理比三次反转更容易写错。

**易错点。**
- 忘记 `k %= n`：`nums = [1,2]`, `k = 3` 时反转区间越界（`IndexError`）；切片写法则返回原数组 `[1,2]`，正确是 `[2,1]`。
- `k % n == 0` 时 `reverse(0, k - 1)` 的区间是 `(0, -1)`，循环不执行，是安全的。
- 在函数内用切片赋值 `nums[l:r] = nums[l:r][::-1]` 实现反转会产生临时副本，空间不再是 `O(1)`。

**同模式。** LC 61 旋转链表、LC 186 反转字符串中的单词 II、LC 796 旋转字符串、LC 283 移动零。
