## Q
**LC 11 盛最多水的容器**｜Medium · 全公司热度第 13 名 · Blind 75、NeetCode 150、Hot 100、Top Interview 150、LeetCode 75

给定长度为 `n` 的整数数组 `height`，有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。找出其中两条线，使得它们与 `x` 轴构成的容器能容纳最多的水，返回最大水量（不能倾斜容器）。`n == height.length`，`2 <= n <= 10^5`，`0 <= height[i] <= 10^4`。例：`[1,8,6,2,5,4,8,3,7]` → `49`；`[1,1]` → `1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 对撞双指针 + 贪心排除：每步丢掉一整个「不可能更优」的候选集合。

**一句话。** 从最宽的一对开始，每次移动**较短**那条线的指针，因为只有换掉短板，水位才有可能升高。

**识别。** 「在数组里选两个位置，价值由两者共同决定（宽度 × 较小值）」；`n = 10^5` 排除 `O(n^2)` 枚举。宽度随指针内移单调变小，这正是可以做排除论证的单调性。

**推导。** 暴力：枚举所有 `(i, j)`，`O(n^2)`。浪费在大量配对一定不会更优：对当前一对 `(l, r)`，设 `height[l] <= height[r]`，那么 `l` 与 `(l, r)` 之内任何 `r' < r` 配对，水位仍不超过 `height[l]`，宽度还变小，都不会比 `(l, r)` 更好。所以 `l` 的所有配对已经被「考虑完」，丢掉 `l` 即可。每步丢一个下标，`n - 1` 步结束。

```python
def max_area(height: list[int]) -> int:
    left, right = 0, len(height) - 1  # 从最宽的一对开始
    best = 0
    while left < right:
        best = max(best, min(height[left], height[right]) * (right - left))  # 水位由短板决定
        # 宽度每步减 1，只有换掉短板才可能让水位升高；
        # 短板和任何更靠内的板配对，水位 <= 短板、宽度更小，不会更优 -> 短板这一侧可以整个丢弃
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return best
```

运行：`[1,8,6,2,5,4,8,3,7]` → `49`；`[1,1]` → `1`；`[1,2,1]` → `2`；`[0,0]` → `0`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 移动**较长**的那一侧是错的：`[1,8,6,2,5,4,8,3,7]` 会得到 `8`，正确是 `49`；移动长板时水位不会升，宽度又变小。
- 水位取 `min` 不是 `max`，容器不能倾斜，短板决定容量。
- 两边相等时移动哪一侧都对（相等时丢掉任意一条都不会漏掉最优解）。

**同模式。** LC 42 接雨水、LC 15 三数之和、LC 167 两数之和 II、LC 1679 K 和数对的最大数目。
