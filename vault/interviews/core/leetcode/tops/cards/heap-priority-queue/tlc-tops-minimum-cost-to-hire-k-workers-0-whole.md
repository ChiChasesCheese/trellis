## Q
**LC 857 雇佣 K 名工人的最低成本**｜Hard · 全公司热度第 291 名

有 `n` 名工人，`quality[i]` 是第 `i` 名工人的工作质量，`wage[i]` 是他的最低期望工资。要雇佣恰好 `k` 名工人组成一个工资组，付薪规则：组内每个人的工资与其工作质量成正比（同一个"每单位质量的工资"），且每人至少拿到自己的最低期望工资。返回组成工资组所需的最小总金额，误差在 `10^-5` 内都算对。`n == quality.length == wage.length`，`1 <= k <= n <= 10^4`，`1 <= quality[i], wage[i] <= 10^4`。例：`quality = [10,20,5]`, `wage = [70,50,30]`, `k = 2` → `105.00000`（付 `0` 号 `70`、`2` 号 `35`）；`quality = [3,1,10,10,1]`, `wage = [4,8,2,2,7]`, `k = 3` → `30.66667`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 按比率排序 + 大根堆维护 k 个最小值（"枚举最大比率，选质量最小的 k 个"）。

**一句话。** 每个人有一个比率 `wage/quality`，一组人的付薪比率取组内最大比率，总价 = 最大比率 × 质量之和；按比率升序枚举"最大比率的人"，用大根堆保持质量最小的 `k` 个。

**识别。** 「按比例付薪」「每人有下限」：设单位质量工资为 `r`，则必须 `r >= wage_i / quality_i` 对所有组员成立，最小的合法 `r` 就是组内最大比率；这是"一个变量由最大值决定，另一个变量求和最小化"的结构，排序后用堆；`n = 10^4`，`O(n log n)`。

**推导。** 暴力：枚举所有 `C(n, k)` 种组，每组算 `最大比率 × 质量和`，指数级。固定最大比率的人是第 `i` 个（排序后）：组员必须从比率不超过他的人（排序后他前面的）中选，总价 = 他的比率 × 质量和，所以要选质量和最小的 `k - 1` 个再加上他自己，也就是前 `i + 1` 个人中质量最小的 `k` 个（如果他不在其中，这个组的真实最大比率更小，已被更早的枚举覆盖，当前计算只会多算，不会得到错误的更小值）。边扫边用大根堆保留质量最小的 `k` 个，并维护它们的质量和。

```python
from heapq import heappop, heappush
from math import inf


def mincost_to_hire_workers(quality: list[int], wage: list[int], k: int) -> float:
    # 按 wage / quality 升序：扫到第 i 个人时，他的比率就是前 i+1 个人里的最大比率
    workers = sorted(zip(quality, wage), key=lambda qw: qw[1] / qw[0])
    heap: list[int] = []  # 大根堆（存负数）：当前质量最小的 k 个人的质量
    total_q = 0           # 堆中质量之和
    best = inf
    for q, w in workers:
        heappush(heap, -q)
        total_q += q
        if len(heap) > k:
            total_q += heappop(heap)  # 弹出质量最大的（堆里是负数，加上去等于减掉）
        if len(heap) == k:  # 凑够 k 个才是合法的组
            best = min(best, total_q * w / q)  # 全组按当前这个人的比率 w/q 付薪
    return best
```

运行：示例 1 → `105.0`；示例 2 → `30.666666666666668`；`quality = [5]`, `wage = [7]`, `k = 1` → `7.0`。

**复杂度。** 时间 `O(n log n)`（排序和堆操作），空间 `O(n)`。

**拓展优化。**
- 比率 `wage/quality` 用浮点比较在并列时可能有误差；需要精确时按交叉相乘排序，或 `key=lambda qw: Fraction(qw[1], qw[0])`，最后一次除法再转浮点。

**易错点。**
- 只挑最便宜的人：按 `wage` 取最小的两个 `(5, 30)`、`(20, 50)`，按他们的最大比率 `6` 付薪要 `6 * 25 = 150`，示例 1 的正确答案是 `105`。工资低不等于比率低。
- 堆没凑够 `k` 个就更新答案：示例 1 里第一个人单独就得到 `50`，正确是 `105`。
- 弹出的是质量最**小**的（用了小根堆）：保留下来的是质量最大的 `k` 个，示例 1 返回 `150`，正确是 `105`；堆里要弹出的是质量最大的。
