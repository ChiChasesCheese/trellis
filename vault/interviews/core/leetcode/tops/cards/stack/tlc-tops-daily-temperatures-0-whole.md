## Q
**LC 739 每日温度**｜Medium · 全公司热度第 69 名 · NeetCode 150、Hot 100、LeetCode 75

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。`1 <= temperatures.length <= 10^5`，`30 <= temperatures[i] <= 100`。

例：`temperatures = [73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`；`[30,40,50,60]` → `[1,1,1,0]`；`[30,60,90]` → `[1,1,0]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点：** 单调栈（monotonic stack）求「下一个更大元素」；栈里放下标，等到更大的值出现时批量结算。

**一句话。** 栈里存还没等到更高温度的那些天（温度从栈底到栈顶递减）；新的一天来了，把栈顶所有比它低的天依次弹出并结算，天数差就是答案。

**识别。** 「下一个更大/更高/更晚的」「距离多远」是单调栈的标志。`n` 到 `10^5`，暴力 `O(n²)` 超时（温度全相同时每天都要扫到末尾）。

**推导。** 暴力：对每天往后扫到第一个更高温度，最坏 `O(n²)`。浪费在于很多天在等同一个更高温度：`[71, 69, 72]` 里 `71` 和 `69` 都在等 `72`。把还没等到答案的天存进栈，新来的一天 `t` 一次性解决栈顶所有比它低的天；栈里剩下的都不低于 `t`，保持从栈底到栈顶不增。每天最多入栈、出栈各一次，总共 `O(n)`。

```python
def daily_temperatures(temperatures: list[int]) -> list[int]:
    ans = [0] * len(temperatures)       # 等不到更高温度的天保持 0
    stack: list[int] = []               # 存下标；对应温度从栈底到栈顶不增：它们都还在等更高的一天
    for i, t in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < t:    # 今天比栈顶更高：栈顶等到了
            j = stack.pop()
            ans[j] = i - j                              # 等了 i - j 天
        stack.append(i)
    return ans
```

**运行。** `[73,74,75,71,69,72,76,73]` → `[1, 1, 4, 2, 1, 1, 0, 0]`；`[30,40,50,60]` → `[1, 1, 1, 0]`；`[30,60,90]` → `[1, 1, 0]`；`[50]` → `[0]`。

**复杂度。** 时间 `O(n)`（每个下标入栈一次、出栈一次），空间 `O(n)`。

**拓展优化。**
- 从右往左、不用栈的跳跃写法：算 `i` 时，沿着 `j = i + 1` 起用已算出的 `ans[j]` 直接跳到「下一个更高」，额外空间 `O(1)`，均摊线性。
```python
def daily_temperatures_jump(temperatures: list[int]) -> list[int]:
    n = len(temperatures)
    ans = [0] * n
    for i in range(n - 2, -1, -1):
        j = i + 1
        while j < n and temperatures[j] <= temperatures[i]:
            if ans[j] == 0:             # j 右边没有更高的，i 也不会有
                j = n
                break
            j += ans[j]                 # 直接跳到 j 的下一个更高温度
        if j < n:
            ans[i] = j - i
    return ans
```
- 「前一个更大」「左右第一个更小」（LC 84、901）：改变遍历方向或弹出条件。

**易错点。**
- 弹出条件写成 `<=`：相等温度也被弹出并结算，`[70,70,80]` 得到 `[1, 1, 0]`，正确是 `[2, 1, 0]`（第一天要等到更高的 `80`，不是相同的 `70`）。
- 栈里存温度而不存下标：弹出时算不出天数差。
- 先把 `i` 压栈再比较：栈顶就是今天自己，`while` 条件永远不成立，输出全是 `0`。

**同模式。** LC 496 下一个更大元素 I、LC 503 下一个更大元素 II、LC 901 股票价格跨度、LC 84 柱状图中最大的矩形。
