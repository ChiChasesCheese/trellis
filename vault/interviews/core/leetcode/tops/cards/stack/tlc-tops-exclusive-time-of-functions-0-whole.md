## Q
**LC 636 函数的独占时间（Exclusive Time of Functions）**｜Medium · 全公司热度第 242 名

单线程 CPU 正在运行含有 `n` 道函数的程序，函数标识符在 `0` 到 `n - 1` 之间。函数调用存储在调用栈上：开始时标识符入栈，结束时出栈，栈顶是当前正在执行的函数。每当函数开始或结束，记录一条日志 `"{function_id}:{"start" | "end"}:{timestamp}"`；`"0:start:3"` 表示函数 0 在时间戳 3 的**起始**开始执行，`"1:end:2"` 表示函数 1 在时间戳 2 的**末尾**结束执行。函数可以被调用多次，可能存在递归调用。函数的独占时间是它在所有调用中执行时间的总和，调用其他函数花费的时间不算。以数组形式返回每个函数的独占时间。`1 <= n <= 100`，`2 <= logs.length <= 500`，`0 <= function_id < n`，`0 <= timestamp <= 10^9`，两个开始事件不会在同一时间戳发生，两个结束事件不会在同一时间戳发生，每道函数都有一个对应 `"start"` 的 `"end"` 日志。例：`n = 2`，`logs = ["0:start:0","1:start:2","1:end:5","0:end:6"]` → `[3,4]`；`n = 1`，`logs = ["0:start:0","0:start:2","0:end:5","0:start:6","0:end:6","0:end:7"]` → `[8]`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 栈模拟调用栈 + 用「上一个事件时间」切分时间段。

**一句话。** 用栈保存正在执行的函数，时间轴被事件切成若干段，每一段只属于当时的栈顶；遇到事件就结算栈顶函数从 `prev` 到现在的时间。

**识别。** 「函数调用的开始/结束」「嵌套」「递归」就是调用栈；独占时间 = 总时间减去子调用时间，等价于「每个时间点只算给栈顶」。日志只有 500 条，`O(L)` 扫一遍即可。

**推导。** 记录每个函数的开始时间，结束时减去子调用累计时间：要为每层栈维护「子调用耗时」，容易出错。换成按时间段结算：维护 `prev`，表示「栈顶函数从时刻 `prev` 起一直在运行」。`start` 事件到来时，被打断的栈顶结算 `[prev, ts)`，新函数入栈；`end` 事件结算 `[prev, ts]`（含 `ts`，因为 `end` 记在该时刻的末尾），然后下一个恢复运行的函数从 `ts + 1` 起。

```python
def exclusive_time(n: int, logs: list[str]) -> list[int]:
    res = [0] * n
    stack: list[int] = []                     # 调用栈，栈顶是正在运行的函数
    prev = 0                                  # 栈顶函数「从时刻 prev 的起始开始（或恢复）运行」
    for log in logs:
        fid_s, kind, ts_s = log.split(":")
        fid, ts = int(fid_s), int(ts_s)
        if kind == "start":
            if stack:
                res[stack[-1]] += ts - prev   # 被打断的函数先结算 [prev, ts) 这一段
            stack.append(fid)
            prev = ts
        else:
            res[stack.pop()] += ts - prev + 1     # end 记在时刻 ts 的末尾：运行区间是闭区间 [prev, ts]
            prev = ts + 1                         # 下一个恢复运行的函数从 ts + 1 的起始开始
    return res
```

运行：示例一 → `[3, 4]`，示例二 → `[8]`，`n = 2`，`["0:start:0","0:start:2","0:end:5","1:start:6","1:end:6","0:end:7"]` → `[7, 1]`，`["0:start:0","0:end:0"]` → `[1]`，`["0:start:0","0:end:1000000000"]` → `[1000000001]`。

**复杂度。** 时间 `O(L)`（`L` 条日志），空间 `O(n + L)`（栈最深 `L / 2`）。

**易错点。**
- `end` 时少加 `1`：`start` 的时间戳是时刻起始，`end` 是时刻末尾，同一时刻 `"0:start:0"`、`"0:end:0"` 占 1 个单位。示例一会得到 `[3, 3]`，正确 `[3, 4]`。
- `end` 之后忘记更新 `prev = ts + 1`：恢复运行的函数时间被多算，示例二得到 `[10]`，正确 `[8]`。
- 递归调用时用「函数 id → 开始时间」的字典记状态：同一个函数的多层调用互相覆盖，必须按栈的层来存。

**同模式。** LC 20 有效的括号、LC 71 简化路径、LC 394 字符串解码、LC 150 逆波兰表达式求值。
