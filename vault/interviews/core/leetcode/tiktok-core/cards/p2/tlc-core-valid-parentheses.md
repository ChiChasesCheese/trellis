## Q
**LC 20 有效的括号**｜Easy · LC TikTok 热度 62/100 · 近一年被问：美国 3 次、国内 2 次 · CodeTop 国内累计 91 次 · 最近 2026-10（美国面试记录） · 也在：Amazon、LeetCode Hot 100、Blind 75、NeetCode 150、Top Interview 150

给一个只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断它是否有效。有效需同时满足：左括号必须用相同类型的右括号闭合；左括号必须以正确的顺序闭合；每个右括号都有对应的同类型左括号。`1 <= s.length <= 10^4`。例：`"()"` → `true`；`"()[]{}"` → `true`；`"(]"` → `false`；`"([])"` → `true`；`"([)]"` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈：遇到左括号入栈；遇到右括号，栈顶必须是与它配对的左括号，是就弹出，否则无效；扫描完栈必须为空。`O(n)`。

**识别。** 括号嵌套的规则是「最后打开的最先闭合」，即后进先出（LIFO），这正是栈。括号有三种类型，只数个数是不够的，必须记住打开的**顺序**。

**推导。** 暴力：反复把字符串里的 `"()"`、`"[]"`、`"{}"` 删掉，直到不再变化，看剩下的是不是空串 → 每一轮扫描 `O(n)`，最坏要 `n/2` 轮，总共 `O(n^2)`。浪费：每删一对都要重新从头扫。洞察：每个右括号只可能匹配「最近一个还没闭合的左括号」，而这正是栈顶 → 一遍扫描，每个字符进出栈各至多一次，`O(n)`。

```python
def is_valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}     # 右括号 -> 它该配的左括号
    stack: list[str] = []
    for ch in s:
        if ch in pairs:
            if not stack or stack.pop() != pairs[ch]:   # 栈空，或栈顶类型对不上
                return False
        else:
            stack.append(ch)
    return not stack                            # 还有没闭合的左括号就是无效
```

运行：`"()"` → `True`，`"()[]{}"` → `True`，`"(]"` → `False`，`"([])"` → `True`，`"([)]"` → `False`，`"("` → `False`，`")"` → `False`，`10^4` 个 `"("` → `False`，`"()" * 5000` → `True`。

**复杂度。** 时间 `O(n)`；空间 `O(n)`（全是左括号时栈最大）。

**易错点。**
- 只统计三种括号个数是否相等：`"([)]"` 和 `")("` 都会被判成 `True`，正确是 `False`。个数相等不代表顺序对。
- 弹栈前不判栈空：字符串以右括号开头（如 `"]"`），对空列表 `pop()` 会抛 `IndexError`。条件写成 `not stack or stack.pop() != ...`，短路保证只在栈非空时弹栈。
- 循环结束不检查栈是否为空：`"(("` 扫完什么都没出错，却有两个左括号没闭合，会被误判为有效。

**追问。**
- 返回第一个出错的位置：栈里存下标而不是字符，出错时返回当前下标，或结束后栈底剩下的最早的下标。
- 字符串里混有其他字符：对不是括号的字符直接跳过，只在 `ch in pairs.values()` 时入栈。
- 只有一种括号：栈退化为一个计数器，空间 `O(1)`，注意计数不能为负。

**同模式。** LC 22 括号生成、LC 32 最长有效括号、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号、LC 394 字符串解码。
