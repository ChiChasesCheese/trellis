## Q
**LC 32 最长有效括号**｜Hard · LC TikTok 近 6 个月热度 50/100（全时段 50） · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 70 次 · 最近 2026-10（国内面试记录） · 也在：Amazon、LeetCode Hot 100

给一个只包含 `'('` 和 `')'` 的字符串 `s`，找出最长的有效（格式正确且连续）括号子串的长度。「有效」指每个左括号都有对应的右括号将其闭合，比如 `"(()())"`。`0 <= s.length <= 3 * 10^4`，`s[i]` 为 `'('` 或 `')'`。例：`s = "(()"` → `2`（最长有效子串是 `"()"`）；`s = ")()())"` → `4`（`"()()"`）；`s = ""` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈存**下标**，栈底先放一个哨兵 `-1`，表示「最近一个无法匹配的位置」。遇到 `'('` 压入它的下标；遇到 `')'` 先弹栈：栈空说明这个 `')'` 无法匹配，把它的下标压入当新的分界线；栈非空则当前有效段长度是 `i - 栈顶`，更新答案。`O(n)` 时间，`O(n)` 空间。

**识别。** 「括号匹配」是栈的经典用途；「最长**连续**有效子串」还需要知道有效段从哪里开始，所以栈里存下标而不是字符。一个有效段的左端被「无法匹配的括号」挡住：它前面要么是字符串开头，要么是一个没法匹配的 `')'`，要么是一个到最后也没被闭合的 `'('`。

**推导。** 暴力：枚举所有子串逐个判断是否有效，`O(n^3)`；每个起点向右扫并维护计数，`O(n^2)`，`n = 3 * 10^4` 时约 `4.5 * 10^8` 次，太慢。洞察：栈里留下的下标正是所有「分界」：未被匹配的 `'('` 的下标，以及最近一个未被匹配的 `')'` 的下标（或哨兵）。当一个 `')'` 在位置 `i` 匹配成功，弹出的是它对应的 `'('`，此时栈顶就是这段有效括号左边的第一个分界，所以以 `i` 结尾的最长有效段长度是 `i - 栈顶`。哨兵 `-1` 让从开头起就有效的段（长度 `i - (-1) = i + 1`）也适用同一个公式。

**简单解法。** 暴力：枚举起点向右扫，维护左括号余量 `bal`；`bal` 回到 0 就是一段有效括号，记长度；`bal` 变负说明从这个起点再往右不可能有效，停。

```python
def longest_valid_parentheses(s: str) -> int:
    best = 0
    for start in range(len(s)):
        bal = 0                                     # 左括号比右括号多的个数
        for end in range(start, len(s)):
            bal += 1 if s[end] == "(" else -1
            if bal < 0:
                break                               # 右括号多了，这个起点到此为止
            if bal == 0:
                best = max(best, end - start + 1)   # [start, end] 恰好配平
    return best
```

时间 `O(n^2)`，空间 `O(1)`；`n = 3 * 10^4` 时约 `4.5 * 10^8` 步会超时，作开场答案，再引到「用栈记下分界下标」。

最优解：

```python
def longest_valid_parentheses(s: str) -> int:
    stack = [-1]                        # 栈底永远是"最近一个没被匹配的位置"，初始是虚拟的 -1
    best = 0
    for i, ch in enumerate(s):
        if ch == "(":
            stack.append(i)
        else:
            stack.pop()                 # 先尝试匹配：弹掉栈顶
            if stack:
                best = max(best, i - stack[-1])     # 当前有效段是 (栈顶, i]
            else:
                stack.append(i)         # 栈空：这个 ")" 无法匹配，成为新的分界线
    return best
```

运行：`"(()"` → `2`，`")()())"` → `4`，`""` → `0`，`"()"` → `2`，`"()(()"` → `2`，`"())(()"` → `2`，`"(()())"` → `6`，`15000` 个 `"("` 接 `15000` 个 `")"` → `30000`。

**复杂度。** 时间 `O(n)`：每个下标最多入栈、出栈一次；空间 `O(n)`。

**拓展优化。**
- 不用栈，正反各扫一遍，`O(1)` 空间：正向扫右括号多了就清零，反向扫左括号多了就清零，`left == right` 时更新答案：
```python
def longest_valid_parentheses_two_pass(s: str) -> int:
    best = 0
    for seq, open_ch in ((s, "("), (s[::-1], ")")):  # 正向看 "("；反向看 ")"，补上 "(()" 这类左括号一直偏多的情况
        left = right = 0
        for ch in seq:
            if ch == open_ch:
                left += 1
            else:
                right += 1
            if left == right:
                best = max(best, 2 * right)         # 配平：有效段长度是 2 * right
            elif right > left:
                left = right = 0                    # 闭括号多了：这一段不可能延伸，从头计数
    return best
```
- 一维 DP：`dp[i]` 是以 `i` 结尾的最长有效段长度，只有 `s[i] == ")"` 时非零：
```python
def longest_valid_parentheses_dp(s: str) -> int:
    n = len(s)
    dp = [0] * n
    for i in range(1, n):
        if s[i] != ")":
            continue
        if s[i - 1] == "(":                         # ...() 直接配对，再接上前面的有效段
            dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
        elif (j := i - dp[i - 1] - 1) >= 0 and s[j] == "(":   # ...)) 跨过 dp[i-1] 段，找与 i 配对的左括号 j
            dp[i] = dp[i - 1] + 2 + (dp[j - 1] if j >= 1 else 0)   # 内层段 + 这一对 + 左边相邻的有效段
    return max(dp, default=0)
```

**易错点。**
- 没有哨兵 `-1`：从头开始就有效的段算不出长度。`"()"` 得到 `0`，`"(())"` 得到 `2`，正确是 `2` 和 `4`。
- 只统计配对的数量再乘 `2`：`"()(()"` 得到 `4`，`"())(()"` 得到 `4`，正确都是 `2`。有效子串必须**连续**，不连续的配对不能相加。
- 栈里存字符而不是下标：知道配上了，却算不出长度。
- 弹栈后不判空就取 `stack[-1]`：`")"` 这类以右括号开头的输入会在空栈上抛 `IndexError`。

**追问。**
- 返回最长子串本身：刷新 `best` 时同时记下左端点 `stack[-1] + 1`，最后 `s[start:start + best]`。
- 括号有多种类型（`()[]{}`）：栈里存下标，匹配时比较 `s[栈顶]` 与当前字符是否配对；分界线的逻辑相同。

**同模式。** LC 20 有效的括号、LC 22 括号生成、LC 301 删除无效的括号、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号、LC 678 有效的括号字符串。
