## Q
**LC 88 合并两个有序数组**｜Easy · 近一年被问：美国 0 次、国内 6 次 · CodeTop 国内累计 97 次 · 最近 2026-10-18（面试记录） · 也在：Amazon、Top Interview 150

给两个按非递减顺序排列的整数数组 `nums1` 和 `nums2`，以及整数 `m`、`n`，分别表示它们的有效元素个数。把 `nums2` 合并到 `nums1` 中，使合并后的数组同样非递减。结果不用返回，直接存放在 `nums1` 里：`nums1` 的长度是 `m + n`，前 `m` 个是有效元素，后 `n` 个是占位的 `0`；`nums2` 的长度是 `n`。`0 <= m, n <= 200`，`1 <= m + n <= 200`，`-10^9 <= nums1[i], nums2[j] <= 10^9`。例：`nums1 = [1,2,3,0,0,0]`，`m = 3`，`nums2 = [2,5,6]`，`n = 3` → `[1,2,2,3,5,6]`；`nums1 = [0]`，`m = 0`，`nums2 = [1]`，`n = 1` → `[1]`。进阶：`O(m + n)` 时间。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 三个指针从**后往前**：`i` 指 `nums1` 有效部分的末尾，`j` 指 `nums2` 的末尾，`k` 指 `nums1` 的最后一个位置；每次把两者中较大的放到 `k`，`nums2` 放完就结束。`O(m + n)` 时间，`O(1)` 空间。

**识别。** 「合并两个有序数组，结果原地放进 `nums1`」，并且 `nums1` 的**空位在尾部**。空位在尾部意味着可以从大到小填，最大的元素直接放进最后一格，不会覆盖任何还没读的有效元素。

**推导。** 暴力：把 `nums2` 拷贝到 `nums1` 的尾部再整体排序，`O((m + n) log(m + n))`，没用上两段都已有序。辅助数组归并：`O(m + n)` 时间，但多用 `O(m)` 空间。原地从前往后归并：写入位置 `k` 会追上读取位置 `i`，把 `nums1` 里还没读到的元素覆盖掉。洞察：从后往前写，写入位置恒为 `k = i + j + 1 >= i`，写到的格子要么是空位，要么是已经被读走的 `nums1` 元素，永远不会覆盖尚未处理的元素。

```python
def merge(nums1: list[int], m: int, nums2: list[int], n: int) -> None:
    i, j, k = m - 1, n - 1, m + n - 1           # 三个指针都从尾部往前
    while j >= 0:                               # nums2 放完就结束，nums1 剩下的本来就在位
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
```

运行：`[1,2,3,0,0,0]`，`m = 3`，`[2,5,6]` → `[1, 2, 2, 3, 5, 6]`；`[1]`，`m = 1`，`[]` → `[1]`；`[0]`，`m = 0`，`[1]` → `[1]`；`[4,5,6,0,0,0]`，`m = 3`，`[1,2,3]` → `[1, 2, 3, 4, 5, 6]`。

**复杂度。** 时间 `O(m + n)`：`k` 从 `m + n - 1` 递减，每步写一个位置；空间 `O(1)`。

**易错点。**
- 从前往后原地写：`[1,2,3,0,0,0]` 与 `[2,5,6]` 得到 `[1, 2, 2, 2, 5, 6]`，`nums1` 里的 `3` 在被读到之前就被覆盖，丢失了。
- 循环条件写成 `while i >= 0 and j >= 0`，却忘了收尾：`m = 0` 时循环不执行，`[0]` 与 `[1]` 返回 `[0]`，正确是 `[1]`。本解法用 `while j >= 0`，`nums1` 的剩余部分已在原位，不需要收尾。
- 用 `nums1 = sorted(nums1[:m] + nums2)` 给名字重新赋值：只是让局部变量指向新列表，调用者看到的 `nums1` 没变。要原地改，写 `nums1[:] = ...`。

**追问。**
- 稳定性：相等时取 `nums2` 的元素（`else` 分支）。从后往前填，后取的排在前面，所以相等元素里 `nums2` 的排在 `nums1` 的后面，保持「`nums1` 的在前」的顺序。
- 偷懒写法：`nums1[m:] = nums2` 再 `nums1.sort()`。Timsort 能识别出两段已有序的连续片段并直接归并，实际接近 `O(m + n)`，面试里作为备选并说明理由。
- 输入是链表：改成合并两个有序链表（LC 21）；`k` 个有序数组用堆（LC 23）。
