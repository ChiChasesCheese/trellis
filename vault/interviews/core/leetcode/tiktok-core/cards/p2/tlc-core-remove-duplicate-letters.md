## Q
**LC 316 去除重复字母**｜Medium · LC TikTok 热度 58/100（近 3 个月） · 近一年被问：美国 2 次、国内 1 次 · CodeTop 国内累计 7 次 · 最近 2026-08-05（国内面试记录） · 也在：Amazon

给字符串 `s`，去除重复字母，使每个字母只出现一次，并保证结果的字典序最小；不能打乱其余字符的相对顺序（结果是 `s` 的子序列）。`1 <= s.length <= 10^4`，`s` 由小写英文字母组成。例：`"bcabc"` → `"abc"`；`"cbacdcbc"` → `"acdb"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 单调栈（monotonic stack）：从左到右扫描，若当前字母比栈顶小，并且栈顶字母在后面**还会再出现**，就把栈顶弹掉（以后还有机会放回来），再入栈；已经在栈里的字母直接跳过。`O(n)`。

**识别。** 「子序列 + 字典序最小 + 每个字符恰好一次」是单调栈的信号：要字典序最小，就希望前面的字母尽量小，遇到更小的字母就应该替换前面较大的。`s` 只有小写字母，字母种类至多 26。

**推导。** 暴力：枚举所有包含每种字母恰好一次的子序列，取最小，指数级。洞察一：字典序先比较靠前的字符，所以前面的位置要尽量放小的字母。洞察二：栈顶字母 `t` 比当前字母 `c` 大，且 `t` 在后面还出现（`last[t] > i`），那么弹掉 `t`，让 `c` 站到更前的位置只会更好，`t` 以后还能补回来；如果 `t` 后面不再出现，就绝不能弹，否则字母丢失。已经在栈里的字母不再入栈：它先出现的位置总不会更差。

```python
def remove_duplicate_letters(s: str) -> str:
    last = {ch: i for i, ch in enumerate(s)}       # 每个字母最后一次出现的下标
    stack: list[str] = []
    in_stack: set[str] = set()
    for i, ch in enumerate(s):
        if ch in in_stack:                         # 已经放好了，跳过（先放的位置一定不差）
            continue
        # 栈顶比 ch 大，且栈顶后面还会再出现：弹掉它，换更小的字母占前面的位置
        while stack and stack[-1] > ch and last[stack[-1]] > i:
            in_stack.discard(stack.pop())
        stack.append(ch)
        in_stack.add(ch)
    return "".join(stack)
```

运行：`"bcabc"` → `"abc"`；`"cbacdcbc"` → `"acdb"`；`"a"` → `"a"`；`"aaaa"` → `"a"`；`"abacb"` → `"abc"`；`"ecbacba"` → `"eacb"`。

**复杂度。** 时间 `O(n)`：每个字符至多入栈、出栈一次；空间 `O(Σ)`，`Σ = 26`。

**易错点。**
- 弹栈必须检查栈顶后面还会出现。漏掉这个条件，`"bca"` 会得到 `"a"`，丢了 `b` 和 `c`，正确是 `"bca"`。
- 必须跳过已经在栈里的字母。漏掉这一步，`"abab"` 得到 `"aab"`，字母重复，正确是 `"ab"`。
- 只按字母表顺序排列去重后的字母（`"".join(sorted(set(s)))`）会破坏相对顺序：`"bcab"` 得到 `"abc"`，但 `a` 之后找不到 `c`，它不是 `s` 的子序列，正确结果是 `"bca"`。

**追问。**
- LC 1081 不同字符的最小子序列：完全相同的题。
- 要字典序**最大**：弹栈条件改成 `stack[-1] < ch`；`"cbacdcbc"` → `"cbad"`。
- 去掉 `k` 个数字使结果最小（LC 402）：同样的单调栈，但不需要"后面还会出现"的条件，改成计数 `k`。

**同模式。** LC 1081 不同字符的最小子序列、LC 402 移掉 K 位数字、LC 496 下一个更大元素、LC 739 每日温度、LC 321 拼接最大数。
