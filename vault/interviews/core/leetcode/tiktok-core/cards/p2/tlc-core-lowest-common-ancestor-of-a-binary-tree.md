## Q
**LC 236 二叉树的最近公共祖先**｜Medium · LC TikTok 全时段热度 53/100 · 近一年被问：美国 2 次、国内 5 次 · CodeTop 国内累计 134 次 · 最近 2026-10-19（国内面试记录） · 也在：Amazon、LeetCode Hot 100、Top Interview 150

给一棵二叉树和其中两个节点 `p`、`q`，找出它们的**最近公共祖先**（LCA）：既是 `p` 的祖先又是 `q` 的祖先、且深度尽可能大的节点；一个节点也可以是它自己的祖先。树中节点数在 `[2, 10^5]` 内，`-10^9 <= Node.val <= 10^9`，所有节点值互不相同，`p != q`，`p` 和 `q` 都在树中。例：`root = [3,5,1,6,2,0,8,null,null,7,4]`，`p = 5, q = 1` → `3`；`p = 5, q = 4` → `5`；`root = [1,2], p = 1, q = 2` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 后序递归：`lca(root)` 汇报「这棵子树里找到了谁」，碰到 `p` 或 `q` 就返回它自己，左右两边都有汇报说明 `p`、`q` 分居两侧，当前节点就是最近公共祖先，否则把非空的一边往上传。`O(n)`。

**识别。** 「最近公共祖先」且题目没说二叉搜索树，就不能用值的大小来导航（那是 LC 235）。「在子树里找东西、答案由左右两边的结果合并出来」是树形递归（后序）的信号：每个节点只需要知道左右子树各自汇报了什么。另一条路是建父指针后把问题变成两条向上的链的汇合（和相交链表 LC 160 同构），放在追问。

**推导。** 暴力：分别求出根到 `p`、根到 `q` 的路径，取最长公共前缀的最后一个节点 → `O(n)` 时间，但要写路径回溯，且路径要完整保存。洞察：不必保存路径，让每个子树只回答一个问题「我这里面有没有 `p` 或 `q`，有的话是谁」。三种情形：当前节点就是 `p` 或 `q` → 返回自己（即使另一个在它下面，它也是答案，因为节点可以是自己的祖先）；左右两边都返回非空 → `p`、`q` 分居两侧，当前节点是汇合点；只有一边非空 → 两个都在那一边（或只找到一个），原样往上传。

```python
def lowest_common_ancestor(root: TreeNode | None, p: TreeNode, q: TreeNode) -> TreeNode | None:
    if root is None or root is p or root is q:       # 空树、或碰到 p / q：这棵子树的汇报就是它自己
        return root
    left = lowest_common_ancestor(root.left, p, q)   # 左子树里找到了谁
    right = lowest_common_ancestor(root.right, p, q) # 右子树里找到了谁
    if left and right:                               # p、q 分居两侧：当前节点就是最近公共祖先
        return root
    return left or right                             # 只有一边有：把它往上传
```

运行：`[3,5,1,6,2,0,8,null,null,7,4]` 中 `p = 5, q = 1` → `3`，`p = 5, q = 4` → `5`；`[1,2]` 中 `p = 1, q = 2` → `1`。

**复杂度。** 时间 `O(n)`：每个节点只访问一次；空间 `O(h)`，`h` 是树高（递归栈），平衡树 `O(log n)`，单链树 `O(n)`。

**易错点。**
- 碰到 `p` 或 `q` 必须立刻返回自己，不能再往下找：`p = 5, q = 4`（`4` 在 `5` 的子树里）时，如果到 `5` 还继续递归，`5` 会把下面找到的 `4` 往上传，最后返回 `4`；正确答案是 `5`。
- 两次递归都要做完再判断：`left` 非空就提前返回，`p = 5, q = 1` 会返回 `5`，因为右子树里的 `1` 没被看到；正确答案是 `3`。
- 深度：单链树深度可达 `10^5`，CPython 默认递归上限约 `1000`，深度超过它会抛 `RecursionError`（`1500` 个节点的单链就会），要么 `sys.setrecursionlimit` 调高，要么改成迭代（见追问）。

**追问。**
- 不递归的写法（深树安全）：用显式栈遍历给每个节点记下父节点，把 `p` 自己和全部祖先放进集合，让 `q` 沿父指针往上爬，第一个落进集合的节点就是答案；`O(n)` 时间，`O(n)` 空间，没有递归深度问题。祖先集合必须从 `p` 自己开始。
- 同一棵树要回答很多对查询：预处理深度和倍增表（binary lifting）`up[k][v]`，每次查询 `O(log n)`。
- `p`、`q` 不保证在树中（LC 1644）：要额外确认两个都被找到。

**同模式。** LC 235 二叉搜索树的最近公共祖先、LC 160 相交链表、LC 1650 含父指针的最近公共祖先、LC 1644 最近公共祖先 II、LC 1123 最深叶节点的最近公共祖先。
