## Q
**LC 239 滑动窗口最大值**｜Hard · LC TikTok 全时段热度 50/100 · 近一年被问：美国 3 次、国内 0 次 · CodeTop 国内累计 47 次 · 最近 2026-10-26（美国面试记录） · 也在：Amazon、LeetCode Hot 100、NeetCode 150

给整数数组 `nums`，一个大小为 `k` 的窗口从数组最左侧每次右移一位直到最右侧；你只能看到窗口内的 `k` 个数。返回每个窗口位置上的最大值组成的数组。

约束：`1 <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`，`1 <= k <= nums.length`。

例：`nums = [1,3,-1,-3,5,3,6,7], k = 3` → `[3,3,5,5,6,7]`（六个窗口 `[1,3,-1]`、`[3,-1,-3]`、`[-1,-3,5]`、`[-3,5,3]`、`[5,3,6]`、`[3,6,7]` 的最大值）；`nums = [1], k = 1` → `[1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用一个**单调递减的双端队列**存下标：新数 `x` 到来时，把队尾所有不大于 `x` 的下标弹掉（它们比 `x` 小又更早离开窗口，永远不会是最大值），再把 `x` 的下标放进队尾；队首下标滑出窗口就弹出；队首永远是当前窗口最大值的下标。`O(n)`。

**识别。** 「滑动窗口」+「每个窗口的最大 / 最小值」→ 窗口聚合要求 `O(1)` 地**增量**维护最值：用堆是 `O(n log n)`（带惰性删除），用**单调队列**是 `O(n)`。信号：`n = 10^5` 且 `k` 可大可小（`k = 1` 到 `k = n`），`O(nk)` 暴力不行；「窗口大小固定」且「最大值」是典型的单调队列题。

**推导。** 暴力：每个窗口取 `max(nums[i:i+k])`，`O(nk)`，`k` 大时 `10^10`。堆：窗口里的数放进最大堆，堆顶若已滑出窗口就惰性弹出，`O(n log n)`，能过但不是最优。观察：一旦有一个更靠右的 `x ≥ y`，`y` 就永远不可能成为任何窗口的最大值——它比 `x` 小，而且 `x` 比 `y` 更晚离开窗口。所以可以把 `y` 直接丢掉。保留下来的候选在下标上递增、值上严格递减，这就是一个单调递减队列；最大值总在队首。队首下标 `<= i - k` 说明滑出窗口，从队首弹出。每个下标入队一次出队一次，`O(n)`。

```python
def max_sliding_window(nums: list[int], k: int) -> list[int]:
    window: deque[int] = deque()       # 存下标；对应的值从队首到队尾严格递减
    ans: list[int] = []
    for i, x in enumerate(nums):
        while window and nums[window[-1]] <= x:
            window.pop()               # 比 x 小（或相等）且更靠左的数，永远没有机会当最大值
        window.append(i)
        if window[0] <= i - k:         # 队首已经滑出窗口
            window.popleft()
        if i >= k - 1:                 # 窗口满了才记录
            ans.append(nums[window[0]])
    return ans
```

运行：`nums=[1,3,-1,-3,5,3,6,7], k=3` → `[3, 3, 5, 5, 6, 7]`，`nums=[1], k=1` → `[1]`，`nums=[3,2,2,1,3], k=2（有重复值）` → `[3, 2, 2, 3]`，`nums=[5,1,1,1], k=2` → `[5, 1, 1]`，`nums=[4,3,2,1], k=4（窗口等于整个数组）` → `[4]`，`nums=[7,7,7], k=1` → `[7, 7, 7]`。

**复杂度。** 时间 `O(n)`：每个下标入队一次、出队至多一次（摊还），循环体内的 `while` 总共弹出不超过 `n` 次；空间 `O(k)`：队列至多存 `k` 个下标（输出数组另计）。

**易错点。**
- 队列里存值而不是下标：没法判断队首是否过期；用「值等于滑出的数」判断，遇到重复值会误弹。`nums=[3,2,2,1,3]`, `k=2` 应得 `[3,2,2,3]`，值版本（弹出相等值）得 `[3,2,1,3]`。
- 忘了让过期的队首出队：`nums=[5,1,1,1]`, `k=2` 应得 `[5,1,1]`，不过期则一直返回 `5`，得 `[5,5,5]`。
- 窗口还没满就记录答案：`i < k - 1` 时窗口不完整，会多输出 `k - 1` 个值。`nums=[1,3,-1,-3,5,3,6,7]`, `k=3` 会得到 `8` 个值而不是 `6` 个。
- 弹队尾用 `<` 而不是 `<=`：结果仍然正确（保留相等值），只是队列更长；用 `<=` 更紧凑。写成 `>` 方向就变成最小值队列了。

**追问。**
- 求滑动窗口最小值：把比较方向反过来，或对 `-nums` 求最大值；LC 1438 同时要最大和最小，用两个单调队列。
- 窗口大小不固定（变长）：两个指针，`while max - min > limit: left += 1`，同样用两个单调队列维护窗口最值（LC 1438 绝对差不超过限制的最长子数组）。
- 流式数据、窗口按时间：队列里存 `(时间戳, 值)`，用时间判断过期；或者按块分解（见「另一种解法」）。

**同模式。** LC 1438 绝对差不超过限制的最长连续子数组、LC 862 和至少为 K 的最短子数组、LC 1425 带限制的子序列和、LC 1696 跳跃游戏 VI、LC 155 最小栈、LC 739 每日温度。
