## Q
**LC 348 设计井字棋**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-10-13（美国面试记录） · 也在：Amazon

在 `n x n` 的棋盘上实现井字棋的胜负判定器：两名玩家（编号 `1` 和 `2`）轮流落子，`move(row, col, player)` 在 `(row, col)` 放下 `player` 的棋子，返回落子后获胜的玩家编号，还没有人获胜返回 `0`。同一行、同一列或同一条对角线上全是自己的棋子就获胜。保证每次落子都在棋盘内、落在空格里，有人获胜后游戏不再继续。`2 <= n <= 100`，最多调用 `move` `n^2` 次。进阶：每次 `move` 能否比 `O(n^2)` 更快？例：`n = 3`，依次 `move(0,0,1)`、`move(0,2,2)`、`move(2,2,1)`、`move(1,1,2)`、`move(2,0,1)`、`move(1,0,2)`、`move(2,1,1)` → `0,0,0,0,0,0,1`（玩家 1 占满最后一行）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 不存棋盘，只给每行、每列和两条对角线各存一个带符号的计数：玩家 1 落子加 `1`，玩家 2 落子减 `1`；落子后只检查它所在的行、列和（若在对角线上）对角线的计数，绝对值达到 `n`，说明这条线上全是同一个玩家，该玩家获胜。每次 `move` 是 `O(1)`，空间 `O(n)`。

**识别。** 进阶问的是「能不能比扫整盘更快」。一次落子只会改变它所在的至多 4 条线（行、列、主对角线、副对角线），其他线不变，不需要重新检查。「一条线全是同一个玩家」不需要知道具体是哪些格子，只需要同一个玩家在这条线上的子数等于 `n`。

**推导。** 暴力：每次落子后扫整个棋盘检查所有行、列、对角线，`O(n^2)`。第一步优化：只检查被影响的线，每条线扫 `n` 个格子，`O(n)`。浪费：每次都重新数这条线上的子。洞察：每条线维护一个计数，落子时顺手加一；两个玩家用相反的符号，则某条线上的计数绝对值为 `n` 当且仅当 `n` 个格子全是同一个玩家（混合时正负抵消，绝对值小于 `n`）。每步 `O(1)`。

```python
class TicTacToe:
    def __init__(self, n: int) -> None:
        self.n = n
        self.rows = [0] * n
        self.cols = [0] * n
        self.diag = self.anti = 0

    def move(self, row: int, col: int, player: int) -> int:
        d = 1 if player == 1 else -1            # 玩家 1 记 +1，玩家 2 记 -1
        self.rows[row] += d
        self.cols[col] += d
        if row == col:
            self.diag += d
        if row + col == self.n - 1:
            self.anti += d
        if self.n in (abs(self.rows[row]), abs(self.cols[col]), abs(self.diag), abs(self.anti)):
            return player
        return 0
```

运行：`n = 3` 的例子 → `[0, 0, 0, 0, 0, 0, 1]`；`n = 3`，玩家 2 依次占 `(0,2)`、`(1,1)`、`(2,0)`（副对角线）最后一步返回 `2`；`n = 2`，`(0,0,1)`、`(0,1,2)`、`(1,0,1)` → `0, 0, 1`（玩家 1 占满第 0 列）。

**复杂度。** `move` 为 `O(1)`，空间 `O(n)`。

**易错点。**
- 两个玩家都加 `1`：混合的一行也会数到 `n`。`n = 3`，`(0,0,1)`、`(0,1,2)`、`(0,2,1)`，第 0 行里有两个玩家 1 和一个玩家 2，这样写会在第三步返回 `1`，正确是 `0`；用相反符号时第 0 行的计数是 `+1 - 1 + 1 = 1`。
- 副对角线的条件写成 `row == n - col`：`n = 3` 时 `(0,2)`、`(1,1)`、`(2,0)` 都不满足，玩家 2 占满副对角线却返回 `0`，正确是 `2`；条件是 `row + col == n - 1`。
- 中心格（`n` 为奇数）同时在两条对角线上，两个计数都要加：把副对角线写成 `elif`，中心格只加主对角线，玩家 1 占满副对角线返回 `0`，正确是 `1`。

**追问。**
- 悔棋：对应的四个计数各减掉当时加的 `d`，`O(1)`。
- 平局：另记总步数，`n * n` 步后还没有赢家就是平局。
- 连成 `k` 个就赢（五子棋）：计数法失效，因为胜利线不是整行整列；在落子点沿四个方向各数连续同色格子，`O(k)`。
