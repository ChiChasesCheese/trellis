## Q
**LC 77 组合**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 1 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-09-25（国内面试记录） · 也在：Amazon、Top Interview 150

给两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合，顺序任意。`1 <= n <= 20`，`1 <= k <= n`。例：`n = 4, k = 2` → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`；`n = 1, k = 1` → `[[1]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回溯：从小到大逐个决定「下一个数选谁」，递归时起点永远是「刚选的数 + 1」，保证组合内部递增、不会重复；再用「剩余的数够不够凑满」剪掉走不通的分支。

**识别。** 「所有大小为 `k` 的组合」= 输出本身是 `C(n, k)` 级别，只能枚举；`n <= 20` 说明指数可以。「组合 vs 排列」的区别：组合不计顺序，所以要规定选取顺序（只往后选）来消除 `[1,2]` 与 `[2,1]` 的重复。

**推导。** 暴力：每个数选或不选，`2^n` 个子集，最后过滤大小为 `k` 的 → 剪枝：路径长度到 `k` 就收集，不再往下 → 再剪：还差 `need` 个数时，从 `x` 开始到 `n` 至少要有 `need` 个数，即 `n - x + 1 >= need`，所以 `x <= n - need + 1`，后面的起点不用试。最坏仍是 `O(k · C(n, k))`，但中间节点大幅减少。

```python
def combine(n: int, k: int) -> list[list[int]]:
    res: list[list[int]] = []
    path: list[int] = []

    def dfs(start: int) -> None:
        if len(path) == k:
            res.append(path[:])
            return
        need = k - len(path)                       # 还差几个数
        for x in range(start, n - need + 2):       # 剪枝：x 之后剩的数不够就别进
            path.append(x)
            dfs(x + 1)                             # 只往后选，保证组合不重复
            path.pop()

    dfs(1)
    return res
```

运行：`combine(4, 2)` → `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`，`combine(1, 1)` → `[[1]]`，`len(combine(20, 10))` → `184756`，`combine(20, 20)` → 只有 `[1, 2, ..., 20]` 一个。

**复杂度。** 时间 `O(k · C(n, k))`（每个结果拷贝 `k` 个数）；空间 `O(k)` 递归栈与 `path`，不含输出。

**易错点。**
- 剪枝上界写成 `n - need + 1`（少 1）：`range` 右开，会漏掉以最大数结尾的组合。`n = 4, k = 2` 只得到 `[[1,2],[1,3],[2,3]]`，缺三个。
- 递归时写 `dfs(start + 1)` 或 `dfs(1)` 而不是 `dfs(x + 1)`：前者产生重复或排列，`n = 4, k = 2` 出 `12` 个而不是 `6` 个。
- 忘记 `path[:]` 拷贝。

**追问。**
- 每个数可重复选（LC 39 组合总和）：递归改成 `dfs(x)`。
- 输入有重复（LC 40）：排序后同层跳过相同值。
- 调库：`[list(c) for c in itertools.combinations(range(1, n + 1), k)]`，面试里先写回溯，再说库。
