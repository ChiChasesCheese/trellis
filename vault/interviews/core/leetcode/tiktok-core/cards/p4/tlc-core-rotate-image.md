## Q
**LC 48 旋转图像**｜Medium · LC TikTok 热度 38/100（近 6 个月） · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 37 次 · 最近 2026-08-30（面试记录） · 也在：Amazon、LeetCode Hot 100、Blind 75、NeetCode 150、Top Interview 150

给一个 `n × n` 的二维矩阵 `matrix` 表示图像，将图像**顺时针**旋转 `90` 度。必须**原地**旋转，即直接修改输入矩阵，不允许另开一个矩阵来旋转。`n == matrix.length == matrix[i].length`，`1 <= n <= 20`，`-1000 <= matrix[i][j] <= 1000`。例：`matrix = [[1,2,3],[4,5,6],[7,8,9]]` → `[[7,4,1],[8,5,2],[9,6,3]]`；`matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]` → `[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 顺时针旋转 `90` 度 = **沿主对角线转置**，再把**每一行左右翻转**；两步都是原地交换，`O(n^2)` 时间、`O(1)` 空间。

**识别。** 「矩阵旋转」加「原地」是几何变换题：旋转可以拆成两个更简单的、天然原地的变换（转置、翻转）。`n <= 20`，数据很小，考的是 `O(1)` 空间的做法。位置公式：元素 `(i, j)` 旋转后到 `(j, n - 1 - i)`。

**推导。** 暴力：新建矩阵，`new[j][n - 1 - i] = matrix[i][j]`，时间 `O(n^2)`，空间 `O(n^2)`，被题目禁止。想原地做，先看位置映射 `(i, j) → (j, n - 1 - i)`：拆成两步，先 `(i, j) → (j, i)`（转置），再 `(j, i) → (j, n - 1 - i)`（每一行内部左右翻转）。转置只需交换主对角线两侧对称的元素（`j > i` 的那一半），每行翻转用 `list.reverse()`，都是原地。另一种思路是一圈一圈处理，每个位置的四个元素轮换，同样原地，但下标公式更容易写错。

```python
def rotate(matrix: list[list[int]]) -> None:
    n = len(matrix)
    for i in range(n):
        for j in range(i + 1, n):           # 只交换上三角，沿主对角线转置
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:
        row.reverse()                       # 再把每一行左右翻转 = 顺时针 90 度
```

运行：`[[1,2,3],[4,5,6],[7,8,9]]` → `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]`；`4 × 4` 的示例 → `[[15, 13, 2, 5], [14, 3, 4, 1], [12, 6, 8, 9], [16, 7, 10, 11]]`；`[[1]]` → `[[1]]`。

**复杂度。** 时间 `O(n^2)`：每个元素最多被碰到常数次；空间 `O(1)`。

**易错点。**
- 转置时内层循环从 `0` 开始（交换所有 `(i, j)` 对）：每一对被交换两次，等于没转置，矩阵保持原样 `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]`，翻转后得到的是水平镜像而不是旋转。内层必须从 `i + 1` 开始。
- 在函数里写 `matrix = [list(r) for r in zip(*matrix[::-1])]`：只是让局部变量指向新列表，调用方的矩阵不变（`[[1, 2], [3, 4]]` 仍是 `[[1, 2], [3, 4]]`）。要么原地改，要么用切片赋值 `matrix[:] = ...`。
- 翻转的顺序别搞混：先转置再翻转每一行是顺时针；先翻转每一行再转置得到的是逆时针（`[[1,2,3],[4,5,6],[7,8,9]]` → `[[3, 6, 9], [2, 5, 8], [1, 4, 7]]`），顺序反了方向就反了。

**追问。**
- 逆时针 `90` 度：先转置，再把行的顺序整体倒过来（`matrix.reverse()`）；`[[1,2,3],[4,5,6],[7,8,9]]` → `[[3, 6, 9], [2, 5, 8], [1, 4, 7]]`。
- 一圈一圈四元素轮换的写法，同样原地：对第 `i` 圈、位置 `j`，把上、右、下、左四个元素循环移位。
- 非方阵 `m × n` 旋转不可能原地（形状变了）：`[list(r) for r in zip(*matrix[::-1])]` 返回新矩阵，`[[1,2,3],[4,5,6]]` → `[[4, 1], [5, 2], [6, 3]]`。

**同模式。** LC 54 螺旋矩阵、LC 59 螺旋矩阵 II、LC 867 转置矩阵、LC 73 矩阵置零。
