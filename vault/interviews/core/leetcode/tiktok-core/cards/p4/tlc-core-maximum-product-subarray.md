## Q
**LC 152 乘积最大子数组**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 40 次 · 最近 2026-10（国内面试记录） · 也在：Amazon、LeetCode Hot 100、Blind 75、NeetCode 150

给整数数组 `nums`，找出乘积最大的**非空连续子数组**，返回它的乘积。单个元素的子数组乘积就是这个元素。答案和任何子数组的乘积都保证在 32 位整数范围内。`1 <= nums.length <= 2 * 10^4`，`-10 <= nums[i] <= 10`。例：`nums = [2,3,-2,4]` → `6`（子数组 `[2,3]`）；`nums = [-2,0,-1]` → `0`（`[-2,-1]` 不连续，不是子数组）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 类似最大子数组和（Kadane）的动态规划，但同时维护「以当前位置结尾的最大乘积 `hi`」和「最小乘积 `lo`」：遇到负数，最小乘积乘上去会变成最大，所以两个都要带着走；每一步的候选只有三个：自己重新开始 `x`、接最大 `hi * x`、接最小 `lo * x`。`O(n)`。

**识别。** 「连续子数组」加「最大」是 Kadane 的信号；但乘法与加法的区别是**符号会翻转**：乘一个负数，最大变最小、最小变最大。`0` 会把之前的乘积清零，这在候选里的 `x` 一项自然处理（重新开始）。`n = 2 * 10^4` 时 `O(n^2)` 枚举约 `2 * 10^8` 次，在 Python 里超时。

**推导。** 暴力：固定起点向右累乘，记录最大值，`O(n^2)`。Kadane 的做法是只记“以当前位置结尾的最优”：`cur = max(x, cur + x)`。乘法下直接套用会出错，原因是：以 `i - 1` 结尾的**最小**乘积（一个很大的负数）乘上负数 `x` 之后可能变成最大。所以状态增加一维：对每个结尾位置同时记最大和最小。新的最大和最小一定在 `{x, hi * x, lo * x}` 里产生：`x` 乘以一个范围 `[lo, hi]` 内的数，结果是关于它的线性函数，极值在端点取得，再加上“从 `x` 重新开始”。

```python
def max_product(nums: list[int]) -> int:
    best = hi = lo = nums[0]                # hi/lo：以当前位置结尾的最大/最小乘积
    for x in nums[1:]:
        cand = (x, hi * x, lo * x)          # 要么从 x 重新开始，要么接在前面的最大/最小乘积后面
        hi, lo = max(cand), min(cand)       # 负数会让最小变最大，所以两个都要带着走
        best = max(best, hi)
    return best
```

运行：`[2,3,-2,4]` → `6`，`[-2,0,-1]` → `0`，`[-2]` → `-2`，`[-2,3,-4]` → `24`，`[0,2]` → `2`，`[-1,-2,-3,0]` → `6`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只维护最大值：`[-2,3,-4]` 得到 `3`，正确是 `24`（全部相乘，两个负数抵消）。最小值 `-6` 乘上 `-4` 才得到答案。
- `best` 初始化成 `0`：`[-2]` 得到 `0`，正确是 `-2`；答案可能是负数，用 `nums[0]` 初始化。
- 把含 `0` 的数组当成特殊情况去拆段：不必，`0` 出现时三个候选里 `x = 0`、`hi * 0 = 0`、`lo * 0 = 0`，`hi` 和 `lo` 都变成 `0`，下一个元素自然从 `x` 重新开始。

**追问。**
- 前后缀两遍扫描：非零数组里，最优子数组要么包含第一个元素要么包含最后一个元素（负数个数为偶数时全乘，奇数时去掉一个负数左边或右边）；对前缀乘积和后缀乘积都取最大，遇到 `0` 就把乘积重置为 `1`，`O(1)` 空间。
- 返回子数组本身：额外记录 `hi`、`lo` 对应的起点，更新 `best` 时一并记录。
- 乘积溢出：题目保证 32 位以内；其他语言要注意中间值，Python 的大整数不会溢出但位数多了会变慢。

**同模式。** LC 53 最大子数组和、LC 238 除自身以外数组的乘积、LC 713 乘积小于 K 的子数组、LC 1567 乘积为正数的最长子数组。
