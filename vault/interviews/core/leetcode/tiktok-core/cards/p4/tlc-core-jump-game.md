## Q
**LC 55 跳跃游戏**｜Medium · LC TikTok 热度 50/100（近 6 个月） · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 28 次 · 最近 2026-04-18（CodeTop） · 也在：Amazon、LeetCode Hot 100、Blind 75、NeetCode 150、Top Interview 150

给非负整数数组 `nums`，你最初位于第一个下标，数组中每个元素是你在该位置**最多**可以向前跳的长度。判断能否到达最后一个下标。`1 <= nums.length <= 10^4`，`0 <= nums[i] <= 10^5`。例：`nums = [2,3,1,1,4]` → `true`（先跳 `1` 步到下标 `1`，再跳 `3` 步到末尾）；`nums = [3,2,1,0,4]` → `false`（无论怎么跳都会停在下标 `3`，那里的跳跃长度是 `0`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 贪心：从左到右扫描，维护「目前能到达的最远下标」`reach`；如果当前下标 `i` 已经超过 `reach`，说明被卡住，返回 `False`；否则用 `i + nums[i]` 更新 `reach`。扫描完没被卡住就是 `True`。`O(n)`。

**识别。** 「每个位置最多跳多远，能否到终点」是**可达性**问题。关键性质：由于可以跳**不超过**最大长度的任意步，从任何可达位置出发，它覆盖的整段区间都可达，所以可达集合永远是一个从 `0` 开始的连续前缀 `[0, reach]`，不会有“空洞”。有了这个性质，只需要记最远值，而不需要记整个集合。

**推导。** 暴力：深度优先或动态规划，`dp[j]` 表示下标 `j` 可达，对每个可达的 `i` 把 `i+1..i+nums[i]` 全部标记，`O(n * 最大跳跃长度)`，最坏 `10^4 * 10^5`，超时。浪费：同一个下标被不同的起点重复标记；而且可达集合是连续前缀，不需要逐格标记。只需维护 `reach = max(i + nums[i])`，扫描到 `i` 时，若 `i <= reach`，`i` 可达，用它扩展 `reach`；若 `i > reach` 则 `i` 以及之后全部不可达。

```python
def can_jump(nums: list[int]) -> bool:
    reach = 0                               # 目前能到达的最远下标
    for i, step in enumerate(nums):
        if i > reach:
            return False                    # 连 i 都够不着，后面更不可能
        reach = max(reach, i + step)
    return True
```

运行：`[2,3,1,1,4]` → `True`，`[3,2,1,0,4]` → `False`，`[0]` → `True`，`[0,1]` → `False`，`[1,0,1]` → `False`。

**复杂度。** 时间 `O(n)`：一趟扫描；空间 `O(1)`。

**易错点。**
- 漏掉 `i > reach` 的检查，只在最后比较 `reach >= len(nums) - 1`：`[3,2,1,0,4]` 里 `reach` 到了下标 `3` 后被 `0` 卡住，但下标 `4` 的 `4` 仍然被累计进 `reach`（`4 + 4 = 8`），返回 `True`，正确是 `False`。必须一旦发现不可达就停止。
- 把 `nums[i]` 当成“必须跳这么多”而不是“最多”：题目给的是最多，所以覆盖整段区间。
- 单元素数组 `[0]` 是 `True`：已经在终点，不需要跳。

**追问。**
- 最少跳几次（LC 45）：按层贪心，`end` 是当前这一跳能到的边界，`far` 是下一跳能到的最远；扫到 `end` 时跳数加一并更新 `end = far`。`[2,3,1,1,4]` → `2`。
- 可以向后跳（LC 1306）：变成图上的搜索，用 BFS 或 DFS。
- 想输出一条具体路线：记下每次更新 `reach` 时的出发下标，再回溯。
