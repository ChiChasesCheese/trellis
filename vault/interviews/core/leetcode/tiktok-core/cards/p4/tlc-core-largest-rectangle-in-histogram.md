## Q
**LC 84 柱状图中最大的矩形**｜Hard · LC TikTok 热度 50/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 12 次 · 最近 2026-03-01（国内 CodeTop） · 也在：Amazon、LeetCode Hot 100、NeetCode 150

给 `n` 个非负整数 `heights`，表示柱状图中相邻排列、宽度都为 `1` 的柱子的高度。求图中能勾勒出的**最大矩形面积**（矩形必须完全落在柱子内）。`1 <= heights.length <= 10^5`，`0 <= heights[i] <= 10^4`。例：`[2,1,5,6,2,3]` → `10`（高 `5`、宽 `2`，即 `5,6` 两根），`[2,4]` → `4`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 单调栈（monotonic stack）：栈里存下标，对应高度严格递增；遇到更矮的柱子时，栈顶柱子的右边界就确定了，弹出它，新的栈顶就是它的左边界，当场结算面积；末尾补一根高 `0` 的哨兵把栈清空。`O(n)`。

**识别。** 「每个元素向两侧扩展到第一个更小 / 更大的元素」是单调栈的标准信号；`n = 10^5` 排除 `O(n^2)`（约 `10^10`）。最大矩形的高一定等于其中某根柱子的高，所以问题变成「对每根柱子，求以它为最矮柱的最宽区间」。

**推导。** 暴力：枚举左右端点，边扩边维护区间最小值，面积 = 最小值 × 宽，`O(n^2)` → 换成「枚举高」：对每根柱子向两边扩到第一根更矮的，最坏仍 `O(n^2)`（单调序列）→ 浪费在于左右边界被反复重扫。栈让每根柱子只在**被弹出**时才结算：栈内递增，所以弹出时栈顶（弹出后）就是左边第一根更矮的，当前柱子 `i` 就是右边第一根不高于它的 → 每个下标进栈出栈各一次，`O(n)`。

```python
def largest_rectangle_area(heights: list[int]) -> int:
    stack: list[int] = []                      # 下标，对应高度严格递增
    best = 0
    for i, h in enumerate([*heights, 0]):      # 末尾补一根高 0 的柱子，把栈清空
        while stack and heights[stack[-1]] >= h:
            height = heights[stack.pop()]      # 这根柱子在 i 处找到了右边界
            left = stack[-1] if stack else -1  # 左边第一根更矮的柱子
            best = max(best, height * (i - left - 1))
        stack.append(i)
    return best
```

运行：`[2,1,5,6,2,3]` → `10`，`[2,4]` → `4`，`[0]` → `0`，`[5]` → `5`，`[2,2,2]` → `6`，`[6,5,4,3,2,1]` → `12`，`10^5` 根同高 `10^4` → `1000000000`，`range(10^5)` 递增 → `2500000000`。

**复杂度。** 时间 `O(n)`（每个下标最多入栈、出栈各一次）；空间 `O(n)`（栈）。

**易错点。**
- 没有哨兵：栈里剩下的柱子没人结算，`[2,4]` 返回 `0`（正确 `4`）。
- 宽度写成 `i - left`（漏掉 `- 1`）：`[2,4]` 得 `8`，`[2,1,5,6,2,3]` 得 `15`，正确是 `4` 和 `10`。
- 栈空时 `left` 要取 `-1`，表示一直延伸到最左边，不是 `0`。

**追问。**
- 在 01 矩阵里找最大全 1 矩形（LC 85）：逐行把每列连续 1 的个数当柱子高度，每行调一次这个算法，`O(mn)`。
- 同时返回矩形位置：更新 `best` 时记 `(left + 1, i - 1, height)`。
- 要求不用栈：左右各一遍预处理「最近更矮」数组（`left[i]`、`right[i]`，再算 `高 × 宽` 取最大），或分治（按最矮柱拆开，最坏 `O(n^2)`）。
