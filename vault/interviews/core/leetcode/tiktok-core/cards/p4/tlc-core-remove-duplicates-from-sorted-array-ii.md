## Q
**LC 80 删除有序数组中的重复项 II**｜Medium · CodeTop 国内累计 8 次 · 最近 2026-09-04（国内 CodeTop） · 也在：Top Interview 150

给一个升序数组 `nums`，**原地**删除重复出现的元素，使每个元素**最多出现两次**，返回删除后数组的新长度（调用者会读取 `nums` 的前 `新长度` 个元素）。不要使用额外的数组空间，必须在原数组上修改并满足 `O(1)` 额外空间。`1 <= nums.length <= 3 * 10^4`，`-10^4 <= nums[i] <= 10^4`，`nums` 已按升序排列。例：`nums = [1,1,1,2,2,3]` → 返回 `5`，`nums` 前五个元素为 `[1,1,2,2,3]`；`nums = [0,0,1,1,1,1,2,3,3]` → 返回 `7`，前七个元素为 `[0,0,1,1,2,3,3]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 快慢指针（写指针 `w`）：`nums[:w]` 是已经合法的结果；读到 `x` 时，只要它不等于结果里**倒数第二个**元素 `nums[w - 2]`，就写入 `nums[w]` 并 `w += 1`。`O(n)` 时间、`O(1)` 空间。

**识别。** 「有序数组 + 原地去重 + O(1) 空间」是快慢指针的标准信号（和 LC 26 同族，只是每个值最多保留两个）。有序保证相同的值相邻，所以判断「`x` 是否已出现两次」只需要看结果末尾的两个元素。

**推导。** 暴力：用 `Counter` 数每个值出现几次，另建数组只保留前两个，`O(n)` 额外空间，违反要求。逐个删除并移动后面所有元素：每次删除 `O(n)`，总 `O(n^2)`。浪费在于移动：不必真的删，只要把保留下来的元素顺序写到前面。写指针前面是合法结果；新来的 `x` 若等于 `nums[w - 2]`，由升序可知 `nums[w - 1]` 也等于 `x`，即结果里已有两个 `x`，丢弃；否则最多只有一个，写入。

```python
def remove_duplicates(nums: list[int]) -> int:
    w = 0                                  # 写指针：nums[:w] 是已经合法的结果
    for x in nums:
        if w < 2 or x != nums[w - 2]:      # 与结果里倒数第 2 个比：不等说明 x 至多出现过 1 次
            nums[w] = x
            w += 1
    return w
```

运行：`[1,1,1,2,2,3]` → `5`，前五个元素 `[1,1,2,2,3]`；`[0,0,1,1,1,1,2,3,3]` → `7`，前七个元素 `[0,0,1,1,2,3,3]`；`[1]` → `1`；`[1,1,1,1]` → `2`，前两个元素 `[1,1]`。

**复杂度。** 时间 `O(n)`：每个元素读一次；空间 `O(1)`。

**易错点。**
- 比较对象必须是**结果里**的倒数第二个 `nums[w - 2]`，而不是原数组的 `nums[i - 2]`：后者可能已被覆盖。`[1,1,1,2,2]` 会得到长度 `3`、结果 `[1,1,2]`（正确是长度 `4`、`[1,1,2,2]`）。
- 与 `nums[w - 1]` 比较只能保留一个：`[1,1,1,2,2,3]` 得到长度 `3`、`[1,2,3]`。
- `w < 2` 的保护不能省：前两个元素无条件保留，否则 `nums[w - 2]` 会取到负下标（Python 里是从末尾取，悄悄出错）。

**追问。**
- 至多保留 `k` 个：把 `2` 换成 `k`，条件改成 `w < k or x != nums[w - k]`；`k = 1` 就是 LC 26。
- 无序数组也要「每个值最多两个、保持原顺序」：不能靠相邻判断，需要 `Counter` 记录每个值已保留几次，`O(n)` 额外空间。
- 链表版（LC 82、LC 83）：同样的思路，用指针接链，注意头结点可能被删。

**同模式。** LC 26 删除有序数组中的重复项、LC 27 移除元素、LC 283 移动零、LC 82 删除排序链表中的重复元素 II。
