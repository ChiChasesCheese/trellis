## Q
**LC 328 奇偶链表**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 11 次 · 最近 2026-08-06（面试记录） · 也在：Amazon

给单链表的头节点 `head`，把所有**下标为奇数**的节点和**下标为偶数**的节点分别分组（第一个节点下标是奇数，第二个是偶数，依此类推），两组内部保持原有相对顺序，再把偶数组接到奇数组之后，返回重新排好的链表。必须 `O(1)` 额外空间、`O(n)` 时间。节点数 `0 <= n <= 10^4`，`-10^6 <= Node.val <= 10^6`。例：`[1,2,3,4,5]` → `[1,3,5,2,4]`；`[2,1,3,5,6,4,7]` → `[2,3,6,7,1,5,4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用两个指针 `odd` / `even` 隔一个节点串起各自的链（奇链、偶链），一趟走完后把偶链的头接到奇链的尾；只改 `next`，不新建节点。`O(n)` 时间、`O(1)` 空间。

**识别。** 「按位置奇偶分组 + 保持相对顺序 + `O(1)` 额外空间」→ 不能把值倒进数组，只能原地重连 `next`；「一条链拆成两条再拼接」是链表题的常见骨架（分隔链表、重排链表同源）。

**推导。** 暴力：把值读进数组，`v[0::2] + v[1::2]` 再写回，时间 `O(n)` 但空间 `O(n)`，违反要求。浪费在于：节点本身不用动，只需要重新指 `next`。奇节点的下一个奇节点就是 `even.next`，偶节点的下一个偶节点就是新的 `odd.next`，所以两个指针交替「跳过对方」就能一趟拆出两条链；拆之前先记下偶链的头 `even_head`，最后 `odd.next = even_head` 完成拼接。

```python
def odd_even_list(head: ListNode | None) -> ListNode | None:
    if head is None:
        return None
    odd, even = head, head.next
    even_head = even                   # 偶数链表的头：最后要接在奇数链表后面
    while even and even.next:
        odd.next = even.next           # 奇数节点跳过一个偶数节点
        odd = odd.next
        even.next = odd.next           # 偶数节点跳过刚摘下的奇数节点
        even = even.next
    odd.next = even_head
    return head
```

运行：`[1,2,3,4,5]` → `[1,3,5,2,4]`，`[2,1,3,5,6,4,7]` → `[2,3,6,7,1,5,4]`，`[]` → `[]`，`[1]` → `[1]`，`[1,2,3,4]` → `[1,3,2,4]`。

**复杂度。** 时间 `O(n)`，每个节点只被访问一次；空间 `O(1)`，只有 `odd`、`even`、`even_head` 三个指针。

**易错点。**
- 循环条件必须是 `while even and even.next`。写成 `while odd and even` 时，偶数长度会在 `even.next` 为空后让 `odd` 变成 `None`，再读 `odd.next` 抛 `AttributeError`：`[1,2,3,4]` 和 `[1,2]` 都会崩。
- 忘了先存 `even_head`：循环后 `even` 已经跑到链尾，找不到偶链的头。
- 空链表 `head = None` 要单独返回，否则 `head.next` 报错。

**追问。**
- 按**节点值**的奇偶分组：改用两个哑头节点（dummy）+ 尾插，遍历时按 `node.val % 2` 追加。
- 分成 `k` 组（下标模 `k`）：`k` 个哑头 + `tails[i % k]` 尾插，最后各尾置空。
- 「排序奇升偶降链表」：先按奇偶下标拆成两条，把偶链反转，再用合并两个有序链表（LC 21）合起来。

**同模式。** LC 86 分隔链表、LC 725 分隔链表（拆成 k 段）、LC 143 重排链表、LC 148 排序链表。
