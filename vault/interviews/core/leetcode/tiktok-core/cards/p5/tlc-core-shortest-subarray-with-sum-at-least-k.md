## Q
**LC 862 和至少为 K 的最短子数组**｜Hard · CodeTop 国内累计 15 次 · 最近 2026-09-03（CodeTop） · 也在：Amazon

给整数数组 `nums` 和整数 `k`，找出 `nums` 中**和至少为 `k` 的最短非空子数组**（子数组是连续的一段），返回它的长度；不存在则返回 `-1`。`1 <= nums.length <= 10^5`，`-10^5 <= nums[i] <= 10^5`，`1 <= k <= 10^9`。例：`nums = [1], k = 1` → `1`；`nums = [1,2], k = 4` → `-1`；`nums = [2,-1,2], k = 3` → `3`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 前缀和 + 单调递增双端队列（deque）：对每个右端点 `j`，队首起点只要满足 `pre[j] - pre[i] >= k` 就弹出并更新答案（更大的 `j` 只会更长）；入队前把队尾所有 `pre >= pre[j]` 的起点弹掉（起点更晚且前缀和更小，一定更优）。每个下标进出队一次，`O(n)`。

**识别。** 「和至少 `k` 的最短子数组」长得像滑动窗口（LC 209），但 `nums` 含**负数**：扩大窗口和可能变小，缩小窗口和可能变大，双指针的单调性不成立。遇到「带负数的子数组和」先转成**前缀和**：问题变成找 `j - i` 最小且 `pre[j] - pre[i] >= k`。对每个 `j` 只需要在更早的下标里找前缀和够小的最近起点，这类「窗口内维护候选并随时弹掉劣者」的结构就是单调队列。`n = 10^5` 要求 `O(n)` 或 `O(n log n)`。

**推导。** 暴力枚举所有 `(i, j)`，前缀和 `O(1)` 求区间和，仍是 `O(n^2)`。固定 `j` 时，对候选起点 `i` 有两条可以永久丢弃的规则：（1）`i` 已经和某个 `j` 配对成功（`pre[j] - pre[i] >= k`），之后更大的 `j` 只会让长度更长，`i` 不用再看 → 从队首弹；（2）若 `i1 < i2` 且 `pre[i1] >= pre[i2]`，则 `i2` 更晚、前缀和更小，对任何后续 `j` 都至少一样好，`i1` 永远不会是最优 → 从队尾弹。两条规则合起来让队列里前缀和严格递增，队首的前缀和最小，最容易满足条件，只检查队首即可。

```python
from collections import deque
from itertools import accumulate


def shortest_subarray(nums: list[int], k: int) -> int:
    n = len(nums)
    pre = [0, *accumulate(nums)]           # pre[j] - pre[i] 是 nums[i:j] 的和
    dq: deque[int] = deque()               # 存下标，对应的前缀和严格递增
    best = n + 1
    for j, cur in enumerate(pre):
        while dq and cur - pre[dq[0]] >= k:    # 队首起点已满足：记录并弹出（再往后只会更长）
            best = min(best, j - dq.popleft())
        while dq and pre[dq[-1]] >= cur:       # 队尾前缀和不小于 cur：起点更晚且更优，队尾作废
            dq.pop()
        dq.append(j)
    return best if best <= n else -1
```

运行：`[1]`、`k = 1` → `1`；`[1,2]`、`k = 4` → `-1`；`[2,-1,2]`、`k = 3` → `3`；`[84,-37,32,40,95]`、`k = 167` → `3`；`[-4,6]`、`k = 6` → `1`。

**复杂度。** 时间 `O(n)`：每个下标最多入队、出队各一次；空间 `O(n)`（前缀和与队列）。

**易错点。**
- 前缀数组必须从 `0` 开始（`pre[0] = 0`）：否则以第一个元素开头的子数组被漏掉，`[5]`、`k = 5` 会得到 `-1`（正确 `1`）。
- 队首弹出必须用 `while`：`[4,8]`、`k = 6` 在 `j = 2` 时队首 `0` 和 `1` 都满足，用 `if` 只弹一个，得到 `2`（正确 `1`）。
- 漏掉队尾弹出：`[-4,6]`、`k = 6` 得到 `-1`（正确 `1`，子数组 `[6]`），因为更好的起点被队首一个较小下标挡住。

**追问。**
- 返回子数组位置：更新 `best` 时同时记 `(i, j)`，弹出的队首就是 `i`。
- 全部为正数：窗口和单调，退化为双指针（LC 209）；有负数才需要单调队列。
- 不要求队列，要 `O(n log n)` 的简单写法：用最小堆存 `(前缀和, 下标)`，堆顶满足条件就弹出。

**同模式。** LC 209 长度最小的子数组、LC 239 滑动窗口最大值、LC 1425 带限制的子序列和、LC 1438 绝对差不超过限制的最长连续子数组、LC 560 和为 K 的子数组。
