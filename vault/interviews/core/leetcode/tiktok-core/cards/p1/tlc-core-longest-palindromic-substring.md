## Q
**LC 5 最长回文子串**｜Medium · LC TikTok 热度 75/100 · 近一年被问：美国 4 次、国内 8 次 · CodeTop 国内累计 140 次 · 最近 2026-10-29（国内 CodeTop） · 也在：Amazon、LeetCode Hot 100、Blind 75、NeetCode 150、Top Interview 150

给字符串 `s`，找出其中最长的回文子串（正着读和倒着读一样的**连续**子串）。`1 <= s.length <= 1000`，`s` 仅由数字和英文字母组成。例：`"babad"` → `"bab"`（`"aba"` 同样合法）；`"cbbd"` → `"bb"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回文是中心对称的：枚举所有 `2n - 1` 个中心（`n` 个字符、`n - 1` 个相邻字符之间的缝），从中心向两边扩展直到两端字符不相等，记录最长的一次。`O(n^2)` 时间，`O(1)` 空间。

**识别。** 「最长回文子串」是中心扩展或动态规划的标准题。`n <= 1000`，`O(n^2)` 约 `10^6` 步，足够；追问常常问 Manacher 的 `O(n)`。

**推导。** 暴力：枚举所有子串（`O(n^2)` 个），每个 `O(n)` 判回文，共 `O(n^3)`。浪费：判断 `s[i:j]` 是否回文时，其实只比 `s[i]` 与 `s[j-1]` 和内部子串的结果。动态规划：`dp[i][j] = s[i] == s[j] and dp[i+1][j-1]`，`O(n^2)` 时间但要 `O(n^2)` 空间。更省的洞察：回文由中心决定，从一个中心向外扩展，能扩多远就是以它为中心的最长回文，枚举全部中心即覆盖所有回文。奇数长度的中心是一个字符，偶数长度的中心是两个字符之间的缝，所以共有 `2n - 1` 个。

```python
def longest_palindrome(s: str) -> str:
    n = len(s)
    best_l = best_r = 0                            # 当前最长回文是 s[best_l : best_r + 1]
    for center in range(2 * n - 1):                # 2n-1 个中心：n 个字符 + n-1 个缝
        l = center // 2
        r = l + center % 2                         # center 偶数：以字符为中心（l == r）；奇数：以缝为中心（r = l + 1）
        while l >= 0 and r < n and s[l] == s[r]:
            l -= 1
            r += 1
        # 循环结束时 s[l+1 : r] 是以这个中心扩出的最长回文
        if r - l - 1 > best_r - best_l + 1:
            best_l, best_r = l + 1, r - 1
    return s[best_l : best_r + 1]
```

运行：`"babad"` → `"bab"`；`"cbbd"` → `"bb"`；`"a"` → `"a"`；`"ac"` → `"a"`；`"aaaa"` → `"aaaa"`；`"abacdfgdcaba"` → `"aba"`；`"a" * 1000` → 长度 `1000`。

**复杂度。** 时间 `O(n^2)`：`2n - 1` 个中心，每个最多扩展 `O(n)`；空间 `O(1)`。

**易错点。**
- 只枚举字符中心会漏掉偶数长度的回文：`"cbbd"` 得到 `"c"`，正确是 `"bb"`。
- 扩展结束时 `l`、`r` 已经各越界一步，回文是 `s[l+1 : r]`，长度 `r - l - 1`，不是 `r - l + 1`。
- 并列最长时返回哪一个都可以，上面的写法只在严格更长时更新，所以返回最靠左的。

**追问。**
- `O(n)` 的 Manacher 算法：在字符之间插入分隔符统一奇偶，利用已知的最右回文的镜像位置复用半径。
- 统计回文子串个数（LC 647）：同样的中心扩展，每成功扩一步就计数加一。
- 最长回文**子序列**（LC 516）：不连续，用区间 DP。

**同模式。** LC 647 回文子串、LC 516 最长回文子序列、LC 214 最短回文串、LC 131 分割回文串、LC 9 回文数。
