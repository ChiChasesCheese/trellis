## Q
**LC 3551 数位和排序需要的最小交换次数**｜Medium

给你一个由**互不相同**的正整数组成的数组 `nums`，按每个数字的数位和（各位数字相加）**升序**排序；数位和相等时，较小的数排在前面。返回把 `nums` 排成该顺序所需的**最小**交换次数。一次交换是交换数组中两个不同位置的值。`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^9`，`nums` 由互不相同的正整数组成。例：`nums = [37,100]`（数位和 `[10,1]`）→ `1`；`nums = [18,43,34,16]`（数位和 `[9,7,7,7]`，目标 `[16,34,43,18]`）→ `2`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 置换环分解（permutation cycles）：把数组交换成一个已知的目标排列，最少交换次数 = `n - 环数`。

**核心题。**

- LC 41 缺失的第一个正数（Hot 100）：同样沿「元素应在的位置」做交换归位

**一句话。** 元素互不相同，所以目标顺序唯一；把「第 `i` 个位置的元素应该去哪」连成一个置换，每个长度为 `L` 的环恰好要 `L - 1` 次交换，总数就是 `n - 环数`。

**识别。** 「交换任意两个位置、最少几次变成目标顺序」且元素互不相同（目标唯一）——这是置换环的标准信号。排序键是 `(数位和, 值)`，值互不相同，所以键也互不相同，不存在平局。`n <= 10^5` 排序加一遍扫描即可。

**推导。** 一次交换最多让两个元素归位，且一个长度为 `L` 的环至少要 `L - 1` 次交换才能拆开（每次交换最多把环数加 1，终点是 `n` 个自环）；沿环逐个把元素换到它的目标位，恰好用 `L - 1` 次，下界可以取到。所以只要算出目标位置并数环。

```python
def min_swaps(nums: list[int]) -> int:
    n = len(nums)
    # 目标顺序：按 (数位和, 值) 升序；target[j] = 排好后第 j 位上的元素在原数组中的下标
    target = sorted(range(n), key=lambda i: (sum(map(int, str(nums[i]))), nums[i]))
    visited = [False] * n
    cycles = 0
    for start in range(n):
        if visited[start]:
            continue
        cycles += 1                      # 发现一个新环（固定点也是长度 1 的环）
        i = start
        while not visited[i]:            # 沿 i -> target[i] 走完整个环
            visited[i] = True
            i = target[i]
    return n - cycles                    # 长度 L 的环要 L-1 次，求和 = n - 环数
```

运行：`[37,100]` → `1`；`[22,14,33,7]` → `0`；`[18,43,34,16]` → `2`；`[5]` → `0`；`[100,10,1]` → `1`。

**复杂度。** 时间 `O(n log n)`（排序，键计算 `O(n log V)`，`V` 是值域），空间 `O(n)`。

**易错点。**
- 排序键漏掉「数位和相等取较小值」：只按数位和做稳定排序，`[18,43,34,16]` 的目标变成 `[43,34,16,18]`，是一个 4 环，得到 `3`，正确是 `2`。
- 把「错位的元素个数」当答案：`[18,43,34,16]` 四个位置全错，得到 `4`，正确是 `2`；答案是 `n - 环数`。
- 环数只数长度大于 1 的环：公式 `n - 环数` 里固定点必须算作环，否则 `[22,14,33,7]` 得到 `4`，正确是 `0`。

**同模式。** LC 2471 逐层排序二叉树所需的最少操作数、LC 765 情侣牵手、LC 2459 通过移动项目到空白区域来排序数组、LC 1202 交换字符串中的元素。
