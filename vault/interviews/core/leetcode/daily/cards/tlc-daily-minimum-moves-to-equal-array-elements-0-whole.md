## Q
**LC 453 最小操作次数使数组元素相等**｜Medium

给你一个长度为 `n` 的整数数组，每次操作使 `n - 1` 个元素增加 `1`。返回让数组所有元素相等的最小操作次数。`n == nums.length`，`1 <= nums.length <= 10^5`，`-10^9 <= nums[i] <= 10^9`，答案保证符合 32 位整数。例：`nums = [1,2,3]` → `3`（`[1,2,3] → [2,3,3] → [3,4,3] → [4,4,4]`）；`nums = [1,1,1]` → `0`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 换一个等价操作（逆向 / 相对差思维）：让 `n - 1` 个数加 `1`，等价于让 `1` 个数减 `1`。

**核心题。**

- LC 1827 最少操作使数组递增（不在题单）：同样把操作次数化成逐元素差值求和

**一句话。** 把「其余 `n - 1` 个数加 `1`」看成「被排除的那个数相对减 `1`」，目标是所有数降到最小值，次数 = `sum(nums) - n * min(nums)`。

**识别。** 操作作用于「除一个以外的全部」，这种操作只改变相对差，所以换成相对差来想；`n <= 10^5` 与值域 `10^9` 排除了模拟。

**推导。** 模拟每一步要 `O(n)` 且次数可达 `10^9 · n`。给所有数同时加 `1` 不改变它们是否相等，所以「`n - 1` 个数加 `1`」与「`1` 个数减 `1`」等价。每次操作最多把一个数降一格，要让所有数都降到最小值，需要 `sum(x - min)` 次，且每次对一个大于最小值的数操作即可，下界可达。

```python
def min_moves(nums: list[int]) -> int:
    # 等价于每次让一个数减 1：所有数最终都降到最小值
    return sum(nums) - min(nums) * len(nums)   # 每个数要降 x - min 次，求和
```

运行：`[1,2,3]` → `3`；`[1,1,1]` → `0`；`[5]` → `0`；`[-3,0,4]` → `10`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 与 LC 462 混淆，把目标取成中位数：`[1,2,3]` 得到 `2`，正确是 `3`（那题是每次只改一个数 ±1，这里是 `n - 1` 个一起加）。
- 目标取成平均数或最大值：增加操作永远抬高除一个以外的所有数，目标值是 `min + 次数`，而不是固定的某个已有值。
- 把最小值当作 `nums[0]`（不排序、不取 `min`）：`[3,1,2]` 得到 `-3`，正确是 `3`。

**同模式。** LC 462 最小操作次数使数组元素相等 II、LC 1551 使数组中所有元素相等的最小操作数、LC 2448 使数组相等的最小开销、LC 1342 将数字变成 0 的操作次数。
