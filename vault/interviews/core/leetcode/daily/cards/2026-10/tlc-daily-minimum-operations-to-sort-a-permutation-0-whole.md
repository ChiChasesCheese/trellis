## Q
**LC 3942 排序排列的最少操作数**｜Medium · 2026-10-21 解出

给你长度为 `n` 的整数数组 `nums`，它是区间 `[0..n-1]` 内所有数字的一个排列。你**只能**执行两种操作：**反转**整个数组；**左旋一位**（把第一个元素移到末尾，其余整体左移一位）。返回把数组按递增顺序排好所需的**最少**操作次数；如果只用这两种操作无法排好，返回 `-1`。`1 <= n == nums.length <= 10^5`，`0 <= nums[i] <= n - 1`，`nums` 是 `0` 到 `n-1` 的排列。例：`nums = [0,2,1]` → `2`（左旋得 `[2,1,0]`，再反转）；`nums = [1,0,2]` → `2`（反转得 `[2,0,1]`，再左旋）；`nums = [2,0,1,3]` → `-1`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 旋转与翻转构成的二面体结构（dihedral group）：操作不会改变「环上的相邻关系」，所以先判断环形顺序，再用等价变换（`R L R = 右旋`）算最短操作数。

**一句话。** 能排好当且仅当数组是 `0,1,…,n-1` 的循环升序或循环降序；设 `0` 在下标 `p`，循环升序的代价是 `min(p, n - p + 2)`，循环降序的代价是 `1 + min(b, n - b)`，其中 `b = (p + 1) % n`。

**识别。** 操作集合只有「反转」和「循环移位」，不会打乱相邻关系，目标又是恰好 `0..n-1`：先把数组看成一个环，问它是不是排好序的环（可能被转过、翻过）。`n <= 10^5` 说明不能 BFS 状态空间，必须有闭式。

**推导。** 记 `L` = 左旋一次，`R` = 反转。循环升序时 `0` 在 `p`，左旋 `p` 次就排好；也可以「反转，左旋 `n - p` 次，再反转」，因为 `R L^k R` 等于右旋 `k` 次，共 `n - p + 2` 次。循环降序时 `0` 在 `p`（此时 `nums[i] = (p - i) % n`）：先左旋 `b` 次再反转，或先反转再左旋 `n - b` 次，`b = (p + 1) % n`，两者取小再各加那一次反转。

```python
from math import inf


def min_operations(nums: list[int]) -> int:
    n = len(nums)
    p = nums.index(0)                                    # 0 的位置决定一切
    best = inf
    # 循环升序：nums[i] == (i - p) % n；左旋 p 次，或 反转-左旋(n-p)次-反转
    if all(nums[i] == (i - p) % n for i in range(n)):
        best = min(best, p, n - p + 2)
    # 循环降序：nums[i] == (p - i) % n；先左旋 b 次再反转，或 先反转再左旋 n-b 次
    if all(nums[i] == (p - i) % n for i in range(n)):
        b = (p + 1) % n
        best = min(best, 1 + min(b, n - b))
    return -1 if best == inf else best                   # n <= 2 时两种形态可能同时成立，所以取 min
```

运行：`[0,2,1]` → `2`；`[1,0,2]` → `2`；`[2,0,1,3]` → `-1`；`[0]` → `0`；`[1,0]` → `1`；`[1,2,3,4,5,0]` → `3`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 只用左旋，不用「反转-左旋-反转」：`[1,2,3,4,5,0]` 只左旋要 `5` 次，正确是 `3`。
- 忘了循环降序也能排好：`[0,2,1]` 只检查升序得到 `-1`，正确是 `2`。
- 降序情形只算「先反转再左旋」：`[1,0,4,3,2]` 得到 `4`，正确是 `3`（左旋 2 次再反转）。
