## Q
**LC 4092 二进制位得分**｜Easy · 2026-10-26 解出

给你两个整数 `a` 和 `b`。设 `s1` 和 `s2` 分别为 `a` 和 `b` 的二进制表示中置位（值为 `1` 的位）的数量。两个整数的得分定义为：若 `s1 >= s2`，得分为 `s1 * s2`；否则得分为 `s2 / s1`，其中除法为整数除法。返回 `a` 和 `b` 的得分。`1 <= a, b <= 100`。例：`a = 14, b = 6`（`1110`、`110`，`s1 = 3, s2 = 2`）→ `6`；`a = 5, b = 15`（`s1 = 2, s2 = 4`）→ `2`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 位计数（popcount）与条件分支，没有算法技巧。

**一句话。** 用 `int.bit_count()` 得到两个置位数，按 `s1 >= s2` 分支返回乘积或整除商。

**识别。** 「二进制表示中 1 的个数」就是 popcount；`a, b <= 100` 没有任何性能压力，写对分支即可。

**推导。** 无需推导：`a, b >= 1`，所以 `s1, s2 >= 1`，`s2 // s1` 不会除以零。

```python
def binary_digit_score(a: int, b: int) -> int:
    s1, s2 = a.bit_count(), b.bit_count()      # 置位数（Python 3.10+）；旧版本用 bin(a).count("1")
    return s1 * s2 if s1 >= s2 else s2 // s1   # 相等也走乘法分支；除法必须是整除
```

运行：`(14, 6)` → `6`；`(5, 15)` → `2`；`(10, 12)` → `4`；`(1, 1)` → `1`；`(1, 100)` → `3`。

**复杂度。** 时间 `O(1)`（位数固定），空间 `O(1)`。

**易错点。**
- 条件写成 `s1 > s2`，相等时落进除法分支：`(10, 12)` 得到 `1`，正确是 `4`。
- 用 `/` 代替 `//`：`(5, 15)` 返回 `2.0`，类型是浮点；`s2 / s1` 不能整除时（如 `s1 = 2, s2 = 3`）还会返回 `1.5`，要的是 `1`。

**同模式。** LC 191 位 1 的个数、LC 338 比特位计数、LC 461 汉明距离、LC 762 二进制表示中质数个计算置位。
