## Q
**LC 4099 将锁定数组排序的最少操作次数**｜Medium · 2026-10-31 解出

给你一个长度为 `n` 的整数数组 `nums`，其中 `nums` 是范围 `[1, n]` 内整数的一个排列。同时给你一个长度为 `n` 的二进制数组 `locked` 和一个整数 `k`。`locked[i] = 1` 表示下标 `i` 已锁定，`locked[i] = 0` 表示下标 `i` 已解锁。可以按任意顺序执行两种操作：**交换**，选择下标 `i`，要求 `i` 和 `i + 1` 当前都处于解锁状态，交换 `nums[i]` 和 `nums[i + 1]`；**解锁**，选择一个 `locked[i] = 1` 的下标 `i`，把它永久解锁。交换次数不限，解锁最多 `k` 次。返回把 `nums` 整理为严格递增顺序所需的最小总操作次数；如果不可能，返回 `-1`。`1 <= n == nums.length == locked.length <= 2000`，`1 <= nums[i] <= n`，`0 <= locked[i] <= 1`，`nums` 是 `[1, n]` 的排列，`0 <= k <= n`。

例：`nums = [2,1,3,4]`，`locked = [0,1,0,1]`，`k = 1` → `2`（解锁下标 1，交换 `nums[0]` 与 `nums[1]`）；`nums = [3,1,2]`，`locked = [1,0,1]`，`k = 2` → `4`（解锁下标 0 和 2，再交换两次）；`nums = [2,3,1]`，`locked = [1,0,0]`，`k = 0` → `-1`（下标 0 锁定，值无法移动）。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 逆序对（相邻交换排序的最少次数）+ 「前缀最大值等于下标」的分块条件，决定哪些锁必须解开。

**一句话。** 相邻交换排序的最少次数是逆序对数，必须解锁的下标是那些「不是固定分隔点」的锁，答案是 `必须解锁数 + 逆序对数`，必须解锁数超过 `k` 则为 `-1`：下标 `i` 是固定分隔点，当且仅当 `nums[i] == i + 1` 且前缀 `nums[0..i]` 的最大值也是 `i + 1`。

**识别。** 「只能交换相邻」+ 「排成严格递增」是逆序对；锁住的下标不能被换走，也不允许别的元素从它身上穿过，所以每个仍然锁着的下标都必须恰好是一个**分块边界**（和「最多能完成排序的块」一样，前缀最大值等于下标）。`n <= 2000` 允许 `O(n^2)`，`O(n log n)` 更稳。

**推导。** 交换和解锁可以任意交错，所以先把需要的锁全部解开，然后在每一段连续解锁的下标内部随意排序，总交换次数不可能少于逆序对数，且在分块后恰好能达到。保持锁着的下标 `i`：它的值不会动，所以必须已经是 `i + 1`；它左右两边不能交换，所以左边的 `i` 个元素必须恰好是 `1..i`，等价于前缀最大值 `<= i + 1`。不满足的锁没有任何别的办法，必须解锁；满足的锁解了只会白花一次操作，不解。因此需要解锁的次数是固定的，答案不依赖别的选择。

```python
def min_ops_locked(nums: list[int], locked: list[int], k: int) -> int:
    unlock = 0                              # 必须解锁的下标个数
    inversions = 0                          # 逆序对个数 = 最少相邻交换次数
    mx = 0                                  # 前缀最大值
    seen: list[int] = []                    # 前缀元素的有序列表，用来数逆序对
    for i, v in enumerate(nums):
        mx = max(mx, v)
        # 锁着的下标要原地不动：值已是 i+1，且左边恰好是 1..i（前缀最大值 == i+1）
        if locked[i] and not (v == i + 1 and mx == i + 1):
            unlock += 1                     # 不满足就没有别的办法，只能解锁
        # 前面比 v 大的元素个数 = 以 v 为右端的逆序对
        inversions += len(seen) - bisect_right(seen, v)
        insort(seen, v)
    return -1 if unlock > k else unlock + inversions
```

运行：示例 1 → `2`；示例 2 → `4`；示例 3 → `-1`；`nums = [3,2,1]`，`locked = [0,1,0]`，`k = 0` → `-1`，`k = 1` → `4`；`nums = [1,3,2]`，`locked = [1,1,1]`，`k = 3` → `3`，`k = 1` → `-1`；`nums = [1,2,3]`，`locked = [1,1,1]`，`k = 0` → `0`。

**复杂度。** 时间 `O(n^2)`（`insort` 在有序列表里平移元素，`n = 2000` 下很快；换成树状数组是 `O(n log n)`），空间 `O(n)`。

**易错点。**
- 只检查 `nums[i] == i + 1` 就让锁保持：`nums = [3,2,1]`，`locked = [0,1,0]`，`k = 0` 得到 `3`（算作无需解锁），正确是 `-1`：下标 1 的值虽然对，但 `3` 和 `1` 必须穿过它。
- 把解锁次数漏算进总操作：示例 1 只算交换得到 `1`，正确是 `2`。
- 解锁所有被锁的下标：示例 1 要解锁 2 个，`k = 1` 时误判为 `-1`，正确是 `2`（下标 3 是固定分隔点，不用解）。

**同模式。** LC 769 最多能完成排序的块、LC 775 全局倒置与局部倒置、LC 315 计算右侧小于当前元素的个数、LC 1585 检查字符串是否可以通过排序子字符串得到另一个字符串。
