## Q
**LC 4098 最小化 GCD 连通数组的最大值**｜Medium · 2026-10-31 解出

给你三个整数 `n`、`index` 和 `value`。长度为 `n` 的整数数组 `nums` 若满足以下条件，称为 GCD 连通数组：`nums[i] > 0`；`nums[i] < nums[i + 1]`（严格递增）；`nums[index] = value`；对 `0 <= i <= n - 2` 有 `gcd(nums[i], nums[i + 1]) > 1`。在所有 GCD 连通数组中，返回最大元素 `nums[n - 1]` 可能的最小值；不存在这样的数组则返回 `-1`。`2 <= n <= 10^9`，`1 <= value <= 10^9`，`0 <= index <= n - 1`。例：`n = 4, index = 2, value = 8` → `10`（`[2,4,8,10]`）；`n = 2, index = 1, value = 3` → `-1`；`n = 2, index = 0, value = 3` → `6`。

给出完整的最优解答：考点、识别、推导、代码、复杂度、易错点。

## A
**考点。** 数论 + 贪心的上下界论证：相邻 `gcd > 1` 的严格递增链，每步至少增加「最小质因子」，之后全是偶数步长 `2`。

**一句话。** 左边只关心「放得下吗」，右边只关心「最后一个最小是多少」，两边互不干扰：偶数 `value` 两边都走步长 `2`；奇数 `value` 的第一步（向上 `+p`、向下 `-p`，`p` 是最小质因子）落到偶数，之后都走步长 `2`。

**识别。** `n` 到 `10^9`，数组根本造不出来，只能是闭式。「相邻 `gcd > 1`」意味着相邻差至少为 `gcd`，即至少为 `2`；偶数能把这个下界取到。

**推导。** 两个相邻数的差是它们公约数的倍数，所以差 `>= 2`；若其中有奇数 `v`，公约数是 `v` 的奇因子 `g`，差 `>= g >= p`（`p` 为 `v` 的最小质因子），且 `v ± g` 是偶数。
- 右边（还要放 `k = n - 1 - index` 个数，求最小末尾）：`value` 偶数时 `value + 2k`；奇数时第一步至少 `+p`、后面每步至少 `+2`，`value + p + 2(k - 1)`，都能取到（偶数的相邻偶数 `gcd >= 2`）。
- 左边（要放 `m = index` 个数）：每步至少 `-2`，最左一个数至少为 `2`；偶数 `value` 最多放 `value / 2 - 1` 个（`value - 2, …, 2`）；奇数 `value` 第一步至少 `-p`，最多放 `(value - p) / 2` 个。放不下返回 `-1`。
- `value = 1` 与任何数 `gcd` 都是 `1`，`n >= 2` 必无解。

```python
def minimize_max_gcd_connected(n: int, index: int, value: int) -> int:
    left, right = index, n - 1 - index         # 左边要放的个数，右边要放的个数
    if value == 1:
        return -1                              # gcd(1, 任何数) = 1，n >= 2 时无解
    p = 2                                      # value 的最小质因子；试除到 sqrt(value)
    while p * p <= value and value % p:
        p += 1
    if p * p > value:
        p = value                              # 没有更小的因子：value 本身是质数
    if value % 2 == 0:
        if left > value // 2 - 1:              # 偶数：value-2, ..., 2 最多放这么多
            return -1
        return value + 2 * right               # 右边每步 +2
    if left > (value - p) // 2:                # 奇数：先到 value-p（偶数），再 -2 直到 2
        return -1
    if right == 0:
        return value
    return value + p + 2 * (right - 1)         # 第一步 +p 变成偶数，其余每步 +2
```

运行：`(4, 2, 8)` → `10`；`(2, 1, 3)` → `-1`；`(2, 0, 3)` → `6`；`(3, 1, 9)` → `12`；`(7, 6, 15)` → `15`；`(9, 8, 15)` → `-1`（左边要放 `8` 个，最多 `(15 - 3) / 2 = 6` 个）。

**复杂度。** 时间 `O(sqrt(value))`（试除求最小质因子），空间 `O(1)`。

**易错点。**
- 把奇数 `value` 的第一步写成 `+2`（`gcd(15, 17) = 1`）：`(2, 0, 15)` 得到 `17`，正确是 `18`（`15 + 3`）。
- 左边按「`value` 的最小质因子倍数」估计容量：`value = 15` 时 `15, 12, 10, 8, …` 先到 `12` 再走偶数，容量是 `(15 - 3) / 2 = 6`，只数 `3` 的倍数得到 `4`，会把 `(7, 6, 15)`（左边放 `6` 个）误判为 `-1`。
- `value` 是奇质数且 `index > 0`：左边没有任何 `> 0` 的公倍数可放，必须返回 `-1`（`(2, 1, 3)`）。

**同模式。** LC 1627 带阈值的图连通性、LC 2709 最大公约数遍历、LC 952 按公因数计算最大组件大小、LC 1819 序列中不同最大公约数的数目。
