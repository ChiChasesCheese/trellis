## Q
**LC 237 删除链表中的节点**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-03-23（国内 CodeTop）

单链表里所有值都**互不相同**。只给你要删除的节点 `node`，**拿不到头节点 `head`**，且保证 `node` 不是尾节点。删除后：`node` 的值不再出现在链表中，节点数减 1，`node` 前后两部分的值各自保持原顺序（不要求真的释放内存）。节点数在 `[2, 1000]`，`-1000 <= Node.val <= 1000`。例：`head = [4,5,1,9]`，`node` 是值为 `5` 的节点 → 链表变为 `[4,1,9]`；`node` 是值为 `1` 的节点 → `[4,5,9]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 拿不到前驱就删不掉自己，那就**冒充后继**：把后继节点的值复制到 `node`，再让 `node` 跳过后继。`O(1)`。

**识别。** 普通删除要改前驱的 `next`，而没有 `head` 就找不到前驱；题目特意保证「不是尾节点」，说明要用后继节点。题目判定只看**值序列**，不看节点身份，所以「搬值」是合法的。

**推导。** 常规删除：从 `head` 走到前驱，`prev.next = node.next`，`O(n)`，但这里没有 `head`。换个角度：要的是值序列 `[..., node.val, next.val, ...]` 变成 `[..., next.val, ...]`。把 `next.val` 写进 `node`，序列变成 `[..., next.val, next.val, ...]`，再删掉后继（它的前驱就是 `node`，可以直接删），目标达成。

```python
def delete_node(node: ListNode) -> None:
    nxt = node.next                          # node 不是尾节点，nxt 一定存在
    node.val, node.next = nxt.val, nxt.next  # 把后继的值搬过来，再跳过后继
```

运行：`[4,5,1,9]` 删 `5` → `[4,1,9]`；删 `1` → `[4,5,9]`；`[4,5]` 删 `4` → `[5]`。

**复杂度。** 时间 `O(1)`；空间 `O(1)`。

**易错点。**
- 写 `node = node.next`：只是让局部变量指向别处，链表一点没变，`[4,5,1,9]` 删 `5` 后仍是 `[4,5,1,9]`。
- 只复制值不跳过后继：`[4,5,1,9]` 删 `5` 会变成 `[4,1,1,9]`。

**追问。**
- `node` 是尾节点：没有后继可搬，只能拿到 `head` 从头找前驱，`O(n)`。
- 外部还持有后继节点的引用（例如哈希表里存了节点，像 LRU 缓存那样）：被跳过的是后继这个对象，外部引用会指向一个已脱链的节点，这个技巧就不能用。
- 给 `head` 和值、删除对应节点（剑指 Offer 18）：用哑节点（dummy node）统一处理删除头节点的情况。

**同模式。** 剑指 Offer 18 删除链表的节点、LC 203 移除链表元素、LC 19 删除链表的倒数第 N 个结点、LC 83 删除排序链表中的重复元素。
