## Q
**LC 718 最长重复子数组**｜Medium · 字节高频

给两个整数数组 `nums1` 和 `nums2`，返回两个数组中**公共的、长度最长的子数组**（必须连续）的长度。`1 <= nums1.length, nums2.length <= 1000`，`0 <= nums1[i], nums2[i] <= 100`。例：`nums1 = [1,2,3,2,1]`、`nums2 = [3,2,1,4,7]` → `3`（公共子数组 `[3,2,1]`）；`nums1 = nums2 = [0,0,0,0,0]` → `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** `dp[i][j]` 表示以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的最长公共子数组长度：两个元素相等则 `dp[i][j] = dp[i-1][j-1] + 1`，不等则为 `0`；答案是所有 `dp` 的最大值。完整二维表，`O(m·n)` 时间和空间。

**识别。** 「两个序列 + 公共 + 连续（子数组 / 子串）」是二维 DP，且**以某位置结尾**是子数组问题的标准状态：连续性意味着只有"上一对也匹配"才能延长。对比子序列（LC 1143，可以跳过元素）：子序列用 `max(dp[i-1][j], dp[i][j-1])`，子数组一旦不匹配就清零。`m, n <= 1000`，`10^6` 个状态够用。

**推导。** 暴力：枚举两个起点再向后比较，`O(m·n·min(m, n))`（最坏全相同时 `10^9`）→ 浪费：从 `(i, j)` 开始比较时，会重复比较 `(i+1, j+1)` 开始的那一段 → 状态"以 `(i, j)` 结尾的公共后缀长度"，相等就是左上角加一，不等就是 `0` → `dp[i][j]` 只依赖左上角 `dp[i-1][j-1]`；第 `0` 行和第 `0` 列是空前缀，全为 `0`，从第 `1` 行第 `1` 列开始逐行填表，答案是全表最大值。

```python
def find_length(nums1: list[int], nums2: list[int]) -> int:
    m, n = len(nums1), len(nums2)
    # dp[i][j]：以 nums1[i-1] 和 nums2[j-1] 结尾的最长公共子数组长度；第 0 行 / 第 0 列是空前缀，全为 0
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    best = 0
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if nums1[i - 1] == nums2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1    # 左上角加一：把这一对接在上一对后面
                best = max(best, dp[i][j])
            # 不相等：dp[i][j] 保持 0，子数组必须连续，到此断开
    return best                                    # 答案是全表最大值，不是 dp[m][n]
```

运行：`([1,2,3,2,1], [3,2,1,4,7])` → `3`，`([0]*5, [0]*5)` → `5`，`([1], [2])` → `0`，`([1,2,3], [1,3])` → `1`；两个 `1000` 个元素的随机数组约 `0.02` 秒，全零数组约 `0.05` 秒。

**复杂度。** 时间 `O(m·n)`；空间 `O(m·n)`，整张表约 `10^6` 个整数。

**易错点。**
- 把子数组当成子序列：用 `max(dp[i-1][j], dp[i][j-1])` 转移。`([1,2,3], [1,3])` 得到 `2`（子序列 `1,3`），正确是 `1`。
- 不相等时沿用左上角 `dp[i-1][j-1]`，没有断开：`nums1 = [0,1,0]`、`nums2 = [0,0,0]` 得到 `2`，正确是 `1`。
- 答案取 `dp[m][n]`（像 LCS 那样）：子数组可以在任何位置结束，`([1,2,3,2,1], [3,2,1,4,7])` 得到 `0`，正确是 `3`；要取全表最大值。

**追问。**
- 输出这个子数组本身：记录取得最大值时的结束下标 `i`，`nums1[i - best:i]`。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 长度到 `10^5`：对长度二分（公共子数组长度有单调性：长度 `L` 存在则 `L-1` 存在），每次用滚动哈希（rolling hash）检查是否有公共的长度 `L` 窗口，`O(n log n)`。
- 改成最长公共子序列（LC 1143）：转移改成 `max`，答案取 `dp[m][n]`。

**同模式。** LC 1143 最长公共子序列、LC 72 编辑距离、LC 5 最长回文子串、LC 583 两个字符串的删除操作。
