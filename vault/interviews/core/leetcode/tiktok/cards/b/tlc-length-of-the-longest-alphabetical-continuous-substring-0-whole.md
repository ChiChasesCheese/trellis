## Q
**LC 2414 最长的字母序连续子字符串的长度**｜Medium · LC TikTok 热度 62/100

**字母序连续字符串**是由字母表中**连续**字母组成的字符串，即字符串 `"abcdefghijklmnopqrstuvwxyz"` 的任意子字符串。例如 `"abc"` 是字母序连续字符串，`"acb"` 和 `"za"` 不是（`z` 后面不会回到 `a`）。给一个仅由小写英文字母组成的字符串 `s`，返回其最长的字母序连续子字符串的长度。`1 <= s.length <= 10^5`，`s` 只含小写英文字母。例：`s = "abacaba"` → `2`（共有 `4` 个不同的字母序连续子串 `"a"`、`"b"`、`"c"`、`"ab"`，最长是 `"ab"`）；`s = "abcde"` → `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一趟扫描维护「以当前字符结尾的字母序连续子串长度」`run`：当前字符恰好比前一个字符大 `1`，`run` 加一，否则重置为 `1`；答案是所有 `run` 里的最大值。`O(n)` 时间，`O(1)` 空间。

**识别。** 「最长连续子串，满足局部条件（相邻两个字符差为 `1`）」是一维 DP / 线性扫描的信号：条件只涉及相邻两个字符，所以以第 `i` 个字符结尾的最长长度只依赖第 `i - 1` 个。`n = 10^5` 排除 `O(n^2)` 的枚举所有子串，一趟扫描足够。

**推导。** 暴力：枚举所有子串，逐个检查是否连续，`O(n^3)`；改成固定起点向右扩，遇到不满足就停，`O(n^2)`。浪费：从起点 `i` 扩到 `j` 遇到断点后，起点 `i+1..j` 开头的子串到同一个断点也停，重复走了同一段。洞察：连续段互不重叠、被断点切开，每个字符只属于一段；一趟扫描中遇到断点就开新的一段。所以 `run = run + 1 if 当前比前一个大 1 else 1`，`best = max(best, run)`。

```python
from itertools import pairwise


def longest_continuous_substring(s: str) -> int:
    best = run = 1                             # s 非空，单个字符本身就是长度 1
    for prev, cur in pairwise(s):
        run = run + 1 if ord(cur) - ord(prev) == 1 else 1   # 恰好差 1 才延续，否则从自己重新开始
        best = max(best, run)
    return best
```

运行：`"abacaba"` → `2`，`"abcde"` → `5`，`"a"` → `1`，`"zab"` → `2`，`"yz"` → `2`；`26` 个字母循环重复 `3846` 次（长度 `99996`）→ `26`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 把“差为 `1`”写成“递增”：`cur > prev` 会把 `"acd"` 整个当成连续，得到 `3`；正确是 `2`（`"cd"`），因为 `a` 和 `c` 之间隔了 `b`。
- `best` 和 `run` 初值写成 `0`：单字符 `"a"` 返回 `0`，而它本身是长度 `1` 的连续串。`s` 非空，初值为 `1`。
- 把 `z` 后接 `a` 当连续：题意里 `"za"` 不是字母序连续，`ord('a') - ord('z') = -25`，不等于 `1`，自然排除。

**追问。**
- 返回子串本身：记录最长段的结束下标，`s[end - best + 1 : end + 1]`。
- 另一种写法：连续段内 `ord(c) - 下标` 是常数，用 `itertools.groupby(enumerate(s), key=lambda p: ord(p[1]) - p[0])` 分组，最长的组长度就是答案；适合把“连续”的定义换成别的等差关系。
- 允许循环（`z` 后面接 `a`）：把差值判断改成 `(ord(cur) - ord(prev)) % 26 == 1`，字符串首尾相接的环形情形再另外处理。

**同模式。** LC 674 最长连续递增序列、LC 485 最大连续 1 的个数、LC 1446 连续字符、LC 128 最长连续序列、LC 978 最长湍流子数组。
