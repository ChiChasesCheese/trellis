## Q
**LC 1209 删除字符串中的所有相邻重复项 II**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 3 次 · 最近 2024-09-13（CodeTop）

给字符串 `s`，「`k` 倍重复项删除操作」是选择 `s` 中 `k` 个相邻且相等的字母并删除它们，被删去部分的左右两侧连在一起。对 `s` 重复进行这个操作，直到无法继续，返回最终的字符串，答案保证唯一。`1 <= s.length <= 10^5`，`2 <= k <= 10^4`，`s` 只含小写英文字母。例：`("abcd", 2)` → `"abcd"`；`("deeedbbcccbdaa", 3)` → `"aa"`；`("pbbcggttciiippooaais", 2)` → `"ps"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈（stack）保存 `(字符, 当前连续出现次数)`：新字符与栈顶相同就把栈顶计数加一，加到 `k` 就整项弹出；不同就压入新项，最后按计数还原字符串。每个字符进出栈各至多一次，`O(n)`。

**识别。** 「删除后左右两侧连起来，可能产生新的重复」是栈的信号：删除发生在“最近”的位置，后进先出。`k` 倍而不是两倍，所以栈里要多存一个连续计数。`n = 10^5` 排除每次重新扫描整个字符串的 `O(n^2)`。

**推导。** 暴力：反复在字符串里找连续 `k` 个相同字符，删掉，再从头找，最坏 `O(n^2 / k)` 次字符串复制。浪费：删除只会影响删除点附近，却每次从头找。洞察：从左到右扫描时，栈顶维护的正是“到目前为止、已经处理完的前缀”的最右边一段连续相同字符及其长度；新字符接上来，要么延长这一段，要么开启新的一段；一段长度达到 `k` 就整段消失，露出下面那一段，下一个字符可能与它接上，这正是级联删除。

```python
def remove_duplicates(s: str, k: int) -> str:
    stack: list[tuple[str, int]] = []      # (字符, 当前连续出现次数)
    for ch in s:
        if stack and stack[-1][0] == ch:
            _, cnt = stack.pop()
            if cnt + 1 < k:                # 还没凑够 k 个：把计数加一放回去；凑够就不放回，整段被删
                stack.append((ch, cnt + 1))
        else:
            stack.append((ch, 1))
    return "".join(ch * cnt for ch, cnt in stack)
```

运行：`("abcd", 2)` → `'abcd'`，`("deeedbbcccbdaa", 3)` → `'aa'`，`("pbbcggttciiippooaais", 2)` → `'ps'`，`("aaa", 3)` → `''`；`10^5` 个 `a`、`k = 10^4` → 空串，约 `4 ms`。

**复杂度。** 时间 `O(n)`；空间 `O(n)`（栈里至多 `n` 项）。

**易错点。**
- 用一遍 `groupby` 统计原始连续段，每段保留 `len % k` 个：删除之后相邻的段会合并成新的重复，单遍看不到。`("deeedbbcccbdaa", 3)` 得到 `'ddbbbdaa'`（正确 `'aa'`），`("pbbcggttciiippooaais", 2)` 得到 `'pcciis'`（正确 `'ps'`）。
- 最后只拼接字符、不乘以计数：`("aaab", 4)` 得到 `'ab'`，正确是 `'aaab'`。
- 栈里存的是“连续”次数，不是整个字符串里该字符的总数：`"abab"` 里 `a` 出现两次但不相邻，不能删。

**追问。**
- 额外空间压到只剩计数数组：写指针加计数数组，在 `list(s)` 上原地覆盖，达到 `k` 时写指针回退 `k - 1` 位。
- 统计一共做了多少次删除：每次整项弹出时加一。
- 输入是流：栈就是全部状态，每来一个字符均摊 `O(1)`。
