## Q
**LC 122 买卖股票的最佳时机 II**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 48 次 · 最近 2026-05-12（国内 CodeTop）

给整数数组 `prices`，`prices[i]` 是某股票第 `i` 天的价格。每天你可以决定买入和 / 或卖出，任何时候**最多持有一股**；可以在同一天先卖再买。返回能获得的最大利润。

约束：`1 <= prices.length <= 3 * 10^4`，`0 <= prices[i] <= 10^4`。

例：`prices = [7,1,5,3,6,4]` → `7`（第 2 天买、第 3 天卖赚 `4`；第 4 天买、第 5 天卖赚 `3`）；`prices = [1,2,3,4,5]` → `4`；`prices = [7,6,4,3,1]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 交易次数不限、可以当天买卖，所以每一段上涨都可以被「逐日拆开」吃掉：答案是所有相邻两天正差额之和。贪心，`O(n)`。

**识别。** 「不限交易次数」+「最多持有一股」+「求最大利润」→ 股票系列里最简单的一档（不限次数无冷却无手续费），**贪心 / 差分**：任何一段利润都能拆成逐日的价差。若换成「限定次数」「冷却」「手续费」才需要状态机 DP。

**推导。** DP 通解：每天两个状态，`cash`（不持股）和 `hold`（持股），`cash = max(cash, hold + p)`，`hold = max(hold, cash - p)`，`O(n)`。观察转移：不限次数时，价格上涨的一段 `a < b < c < d` 买在 `a` 卖在 `d` 的利润 `d - a`，等于逐日买卖的 `(b-a) + (c-b) + (d-c)`；而下跌的价差不会被选中。因此最优利润就是所有正的相邻差之和 `Σ max(p[i] - p[i-1], 0)`——不需要找谷峰，也不需要状态。

```python
def max_profit(prices: list[int]) -> int:
    # 每一段上涨都能吃到：把所有 “后一天比前一天高” 的差额加起来
    return sum(max(today - yesterday, 0) for yesterday, today in pairwise(prices))
```

运行：`prices=[7,1,5,3,6,4]` → `7`，`prices=[1,2,3,4,5]` → `4`，`prices=[7,6,4,3,1]` → `0`，`prices=[5]` → `0`，`prices=[2,2,2]` → `0`。

**复杂度。** 时间 `O(n)`，一遍扫描；空间 `O(1)`（`pairwise` 是惰性迭代器，不复制数组）。

**易错点。**
- 只允许一次交易（LC 121 的做法）：`[7,1,5,3,6,4]` 得 `5`，此处是 `7`；`[1,2,3,4,5]` 一次交易恰好也是 `4`，所以例 2 测不出区别。
- 找谷买峰卖时漏掉最后一段上涨：循环在到达末尾前退出，最后一个峰没卖出。逐日差额写法没有这个边界。
- 把「当天卖了再买」当作非法：题目明确允许，逐日拆分用的正是这条规则。
- 平价日 `prices[i] == prices[i-1]` 的差为 `0`，加或不加都一样；如果写成 `if diff > 0 ... elif ...` 要小心别把它当下跌重置状态。

**追问。**
- 每次交易有手续费 `fee`（LC 714）：贪心失效，改用 DP：`cash = max(cash, hold + p - fee)`，`hold = max(hold, cash - p)`。
- 卖出后冷却一天（LC 309）：DP 增加一个冷却状态，或 `hold = max(hold, cash_prev2 - p)` 用前两天的现金。
- 至多 `k` 次交易（LC 123 / 188）：DP 状态加上交易次数，`O(nk)`；`k ≥ n/2` 时退化为此处。

**同模式。** LC 121 买卖股票的最佳时机、LC 123 买卖股票的最佳时机 III、LC 188 买卖股票的最佳时机 IV、LC 309 含冷冻期、LC 714 含手续费。
