## Q
**LC 1262 可被三整除的最大和**｜Medium · CodeTop 国内累计 5 次 · 最近 2026-03-09（国内 CodeTop）

给整数数组 `nums`，从中选出一些元素（可以一个都不选，和为 `0`），使它们的和能被 `3` 整除，返回这个最大和。`1 <= nums.length <= 4 * 10^4`，`1 <= nums[i] <= 10^4`。例：`nums = [3,6,5,1,8]` → `18`（选 `3, 6, 1, 8`）；`nums = [4]` → `0`；`nums = [1,2,3,4,4]` → `12`（选 `1, 3, 4, 4`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 按「和除以 3 的余数」做状态的 DP：`dp[i][r]` 是只用前 `i` 个数、和模 3 等于 `r` 时的最大和；每个数选或不选，选 `x` 就从余数 `(r - x) % 3` 的状态转移而来。`O(n)` 时间（常数 3）。

**识别。** 「选一部分数、和满足整除条件、求最大」是带同余约束的子集和。模数只有 `3`，状态可以压成**余数**，不必记住具体的和。`n = 4 * 10^4` 排除了 `2^n` 的子集枚举，和最大 `4 * 10^8` 也不能直接当状态。

**推导。** 暴力：枚举所有子集，`O(2^n)`。浪费：我们只关心两件事，和的大小和它的余数；对同一个余数，保留最大的那个和就够了，更小的永远不会更好。洞察：状态 `(前 i 个数, 余数 r)`，值是最大和；`dp[i][r] = max(dp[i - 1][r], dp[i - 1][(r - x) % 3] + x)`，前者是不选，后者是选。初值 `dp[0] = [0, 不可达, 不可达]`。答案是 `dp[n][0]`。

```python
def max_sum_div_three(nums: list[int]) -> int:
    n = len(nums)
    NEG = -(10 ** 18)                          # 「这个余数凑不出来」
    # dp[i][r]：只用前 i 个数、和模 3 等于 r 时的最大和
    dp = [[NEG] * 3 for _ in range(n + 1)]
    dp[0][0] = 0                               # 空集：和为 0，余数 0
    for i, x in enumerate(nums, 1):
        for r in range(3):
            dp[i][r] = max(dp[i - 1][r],                         # 不选 x
                           dp[i - 1][(r - x) % 3] + x)           # 选 x：上一个余数是 (r - x) % 3
    return dp[n][0]
```

运行：`[3,6,5,1,8]` → `18`，`[4]` → `0`，`[1,2,3,4,4]` → `12`，`[2,2,2,2,2]` → `6`，`[1]` → `0`。

**复杂度。** 时间 `O(3n)`，即 `O(n)`；空间 `O(3n)`，用完整的二维表，每个 `i` 一行。

**易错点。**
- 初值写成全 `0`：等于承认「空集的和余 1、余 2 也可达」。`[4]` 会得到 `4`（正确 `0`）。不可达状态必须是一个很小的负数。
- 贪心「总和余几，就删最小的一个余几的数」是错的：`[2,6,8]` 总和 `16` 余 `1`，没有余 `1` 的数可删，会返回 `0`；正确做法是删两个余 `2` 的数 `2` 和 `8`，答案 `6`。
- 转移用 `(r - x) % 3`；C++ 里负数取模还是负的，要写 `((r - x) % 3 + 3) % 3`，Python 不需要。

**追问。**
- 空间可以压到 O(1)：见 Python 工具箱「DP 降维」。
- 贪心 `O(n)`：总和余 `r`，只需删去「最小的一个余 `r` 的数」或「最小的两个余 `3 - r` 的数」两者中损失小的一个。
- 改成被一般的 `k` 整除：状态数从 `3` 变成 `k`，复杂度 `O(nk)`，转移式不变。

**同模式。** LC 416 分割等和子集、LC 974 和可被 K 整除的子数组、LC 494 目标和（都是「按某个值做状态」的 DP）。
