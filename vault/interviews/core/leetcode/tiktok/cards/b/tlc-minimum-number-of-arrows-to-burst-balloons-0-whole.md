## Q
**LC 452 用最少数量的箭引爆气球**｜Medium · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 7 次 · 最近 2026-09-02（国内 CodeTop）

墙面（XY 平面）上贴着一些球形气球，`points[i] = [xstart, xend]` 表示第 `i` 个气球的水平直径在 `xstart` 到 `xend` 之间，不知道确切的 `y` 坐标。弓箭从 `x` 轴沿竖直方向射出：在坐标 `x` 射出的箭，会引爆所有满足 `xstart <= x <= xend` 的气球；箭的数量不限，射出后可以无限前进。求引爆所有气球所需的**最少**弓箭数。`1 <= points.length <= 10^5`，`points[i].length == 2`，`-2^31 <= xstart < xend <= 2^31 - 1`。例：`[[10,16],[2,8],[1,6],[7,12]]` → `2`（在 `6` 射爆 `[2,8]`、`[1,6]`，在 `11` 射爆 `[10,16]`、`[7,12]`）；`[[1,2],[3,4],[5,6],[7,8]]` → `4`；`[[1,2],[2,3],[3,4],[4,5]]` → `2`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 区间贪心：按**右端点**升序排序；第一支箭射在最靠前的右端点，所有左端点不超过它的气球都被引爆；扫描时遇到左端点大于上一支箭位置的气球，就必须新射一支，并射在它的右端点。`O(n log n)`。

**识别。** 「若干区间，用最少的点把每个区间都穿到」是区间贪心的经典模型（等价于 LC 435「最多不相交区间数」）。`n = 10^5` 说明排序加一次扫描。端点相接算同一支箭（闭区间），条件里的等号方向是关键。

**推导。** 暴力：射点只需取某个气球的端点，在所有候选里选最少的一组覆盖全部，是集合覆盖的形状，组合爆炸。洞察（交换论证）：看右端点最小的气球 `b`，必须有一支箭射中它，射点落在 `[b.start, b.end]`。把这支箭右移到 `b.end` 不会少射爆任何气球：任何另一个被原射点 `x` 射爆的气球，它的右端点不小于 `b.end`（`b` 的右端点最小），而它含有 `x <= b.end`，所以也含有 `b.end`。因此射在 `b.end` 最优；射爆一批气球后去掉它们，对剩下的重复同样的选择。按右端点排好序，这个过程就是一次从左到右的扫描。

```python
from math import inf
from operator import itemgetter


def find_min_arrow_shots(points: list[list[int]]) -> int:
    arrows = 0
    last = -inf                            # 上一支箭的位置
    for start, end in sorted(points, key=itemgetter(1)):   # 按右端点排序
        if start > last:                   # 上一支箭够不着：新射一支，射在 end（尽量靠右）
            arrows += 1
            last = end
    return arrows
```

运行：`[[10,16],[2,8],[1,6],[7,12]]` → `2`，`[[1,2],[3,4],[5,6],[7,8]]` → `4`，`[[1,2],[2,3],[3,4],[4,5]]` → `2`，`[[-2147483648,2147483647]]` → `1`，`[[1,10],[2,3],[4,5]]` → `2`。

**复杂度。** 时间 `O(n log n)`（排序主导，扫描 `O(n)`）；空间 `O(n)`（`sorted` 返回新列表，原地 `points.sort(...)` 可降到 `O(1)` 额外）。

**易错点。**
- 闭区间，相接算同一支箭：条件必须是 `start > last`。写成 `start >= last` 会让 `[[1,2],[2,3],[3,4],[4,5]]` 得到 `4`（正确 `2`）。
- 按左端点排序却不更新右边界：`[[1,10],[2,3],[4,5]]` 若一直用第一个区间的 `10` 当边界，会判成 `1` 支箭；正确是 `2`。按左端点排序时必须不断取 `min(end)` 收缩边界，按右端点排序则不需要。
- 排序比较写成 `a[1] - b[1]`：在定宽 `int` 的语言里会溢出（坐标范围是 `±2^31`），Python 没有这个问题，但要知道它在 Java / C++ 里是个坑。

**追问。**
- 返回具体射点：每次新射一支时记录 `end`，例一得到 `[6, 12]`。
- 「最少删除多少区间使其互不重叠」（LC 435）：`n` 减去同一扫描里统计的最大不相交数，把条件改成 `start >= last`（区间相接不算重叠）。
- 气球改成开区间：端点相接不能共用一支箭，条件改为 `start >= last`。

**同模式。** LC 435 无重叠区间、LC 56 合并区间、LC 253 会议室 II、LC 646 最长数对链、LC 1288 删除被覆盖区间。
