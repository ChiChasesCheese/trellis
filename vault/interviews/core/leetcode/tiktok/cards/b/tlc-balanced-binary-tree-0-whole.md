## Q
**LC 110 平衡二叉树**｜Easy · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 29 次 · 最近 2026-09-24（国内 CodeTop）

给定一个二叉树，判断它是否是**高度平衡**的二叉树：树中每个节点的左右两个子树的高度差的绝对值不超过 `1`。树中节点数在 `[0, 5000]`，`-10^4 <= Node.val <= 10^4`。例：`root = [3,9,20,null,null,15,7]` → `true`；`root = [1,2,2,3,3,null,null,4,4]` → `false`；`root = []` → `true`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 后序遍历（先左右、后根）自底向上算高度，同时检查平衡：每个节点返回自己的子树高度，一旦发现某个节点左右高度差大于 `1`，就返回哨兵 `-1`，并沿路一直传到根；根返回 `-1` 就是不平衡。每个节点只访问一次，`O(n)`。

**识别。** 「判断**每个**节点都满足某个与子树高度有关的条件」是树形递归：信息（子树高度）自底向上汇总，判断依赖左右孩子的结果，所以用后序。「高度」这个量既要被用来判断，又要被传给父节点，一个函数同时承担两件事（返回高度，同时用特殊值表示失败）就能避免重复计算。

**推导。** 暴力（自顶向下）：对每个节点分别递归求左右子树高度再比较，每个节点的高度被重复计算，最坏（链状）`O(n^2)`。浪费在于高度反复重算：节点 `v` 的高度被它的每一个祖先的检查重算一遍。改成自底向上：先算孩子，孩子的高度顺便返回，父节点直接拿来比较，一次遍历 `O(n)`。失败时用 `-1` 作为“不平衡”标记，一路上传，上面的节点见到 `-1` 就不用再比较，直接返回。

```python
def is_balanced(root: TreeNode | None) -> bool:
    def height(node: TreeNode | None) -> int:   # 返回子树高度；不平衡时返回 -1 并一路上传
        if node is None:
            return 0
        left = height(node.left)
        if left == -1:
            return -1
        right = height(node.right)
        if right == -1 or abs(left - right) > 1:
            return -1
        return max(left, right) + 1

    return height(root) != -1
```

运行：`[3,9,20,null,null,15,7]` → `True`，`[1,2,2,3,3,null,null,4,4]` → `False`，`[]` → `True`，`[1,2,2,3,null,null,3,4,null,null,4]` → `False`；5000 层的左链：默认递归上限下抛 `RecursionError`，`sys.setrecursionlimit(10000)` 后返回 `False`。

**复杂度。** 时间 `O(n)`；空间 `O(h)`，`h` 为树高，最坏（链状）`O(n)`。

**易错点。**
- 只比较根的左右子树高度：`[1,2,2,3,null,null,3,4,null,null,4]` 根的两边高度都是 `3`，差为 `0`，返回 `True`；但左子树里节点 `2` 的左右高度是 `2` 和 `0`，差为 `2`，整棵树其实不平衡，正确是 `False`。必须**每个**节点都检查。
- 得到 `-1` 后继续用它算 `abs(left - right)`：`-1` 会被当成高度参与比较，可能把不平衡“抹平”。见到 `-1` 必须立刻返回。
- 空树高度 `0`、空树平衡；叶子高度是 `1`，不是 `0`（约定要前后一致，差值才对）。

**追问。**
- 递归深度：5000 层的链会超过 Python 默认递归上限，要么调高 `sys.setrecursionlimit`，要么写成显式栈的后序遍历，用字典存每个节点的高度。
- 只想要树的高度（LC 104）或最小深度（LC 111）：同样的后序遍历，最小深度要小心只有一个孩子的节点。
- 把一棵普通二叉搜索树变平衡（LC 1382）：中序遍历得到有序数组，再取中点递归建树，高度差不超过 `1`。

**同模式。** LC 104 二叉树的最大深度、LC 543 二叉树的直径、LC 124 二叉树中的最大路径和、LC 1382 将二叉搜索树变平衡、LC 968 监控二叉树。
