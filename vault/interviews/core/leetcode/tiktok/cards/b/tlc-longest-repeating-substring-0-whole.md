## Q
**LC 1062 最长重复子串**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-08-05（CodeTop）

给一个字符串 `s`，找出并返回**最长重复子串**的长度：重复子串是在 `s` 中出现至少两次的连续子串（两次出现的位置可以重叠）；不存在重复子串时返回 `0`。`1 <= s.length <= 2000`，`s` 只含小写英文字母。例：`s = "abcd"` → `0`；`s = "abbaba"` → `2`（`"ab"` 和 `"ba"` 都出现两次）；`s = "aabcaabdaab"` → `3`（`"aab"` 出现三次）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对答案长度 `L` 二分（有长度 `L` 的重复子串 ⇒ 有长度 `L - 1` 的）；每个 `L` 用集合装下所有长度为 `L` 的窗口，遇到已经见过的就说明有重复。`O(n^2 log n)` 次字符比较。

**识别。** 「最长 + 重复子串」且 `n = 2000`：`O(n^2)` 可行，所以有两条路——二分答案加集合查重，或者动态规划（DP）求最长公共后缀。它是 LC 1044 的小规模版本：那里 `n = 3 * 10^4`，必须用滚动哈希；这里不需要。答案有**单调性**（去掉重复子串的最后一个字符，仍然重复）是二分的依据。

**推导。** 暴力：枚举长度从大到小，对每个长度把所有窗口放进集合，`O(n)` 个长度 × `O(n)` 个窗口 × `O(n)` 的切片和哈希，`O(n^3)`。第一个浪费是逐长度试，单调性让它变成二分，只需要 `log n` 个长度。判定一个长度 `L`：扫描所有窗口 `s[i:i+L]`，放进集合，已存在就返回真，花 `O(n · L)`。总计 `O(n^2 log n)`。

```python
def longest_repeating_substring(s: str) -> int:
    def has_repeat(length: int) -> bool:   # 是否存在长度为 length 的子串出现至少两次（可重叠）
        seen: set[str] = set()
        for i in range(len(s) - length + 1):
            sub = s[i:i + length]
            if sub in seen:
                return True
            seen.add(sub)
        return False

    lo, hi = 0, len(s) - 1                 # 答案在 [0, n-1]；长度 0 总是可行
    while lo < hi:
        mid = (lo + hi + 1) // 2           # 上取整，避免 lo = mid 时死循环
        if has_repeat(mid):
            lo = mid
        else:
            hi = mid - 1
    return lo
```

运行：`"abcd"` → `0`，`"abbaba"` → `2`，`"aabcaabdaab"` → `3`，`"a"` → `0`，`"aaaa"` → `3`。

**复杂度。** 时间 `O(n^2 log n)`：`log n` 轮，每轮 `O(n)` 个窗口，每个窗口切片和哈希 `O(L)`；空间 `O(n^2)` 最坏（集合里最多 `n` 个长度 `L` 的串）。

**易错点。**
- 中点必须**上取整**：`lo = mid` 时若写成 `(lo + hi) // 2`，当 `lo = 2, hi = 3` 且长度 `2` 可行，`mid` 永远是 `2`，死循环。
- 允许重叠：`"aaaa"` 的答案是 `3`（`"aaa"` 出现在下标 `0` 和 `1`）。若误按「两次出现不能相交」处理，只得到 `2`。
- 上界是 `n - 1`：长度 `n` 的子串只有一个，不可能重复；`hi = n` 虽然不会错，但多算一轮。

**追问。**
- 用 DP 代替二分：`dp[i][j]` 表示以 `s[i-1]` 和 `s[j-1]` 结尾（`i < j`）的最长公共后缀长度，答案是全表最大值，`O(n^2)` 时间和空间的完整二维表。空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- `n` 增大到 `3 * 10^4`（LC 1044）：切片和集合太慢，改用滚动哈希把判定降到 `O(n)`，总计 `O(n log n)`。
- 要返回子串本身：`has_repeat` 返回起点而不是布尔值。

**同模式。** LC 1044 最长重复子串、LC 718 最长重复子数组、LC 1143 最长公共子序列、LC 187 重复的DNA序列、LC 3 无重复字符的最长子串。
