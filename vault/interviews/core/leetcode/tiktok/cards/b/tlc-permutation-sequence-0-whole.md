## Q
**LC 60 排列序列**｜Hard · TikTok 高频

集合 `[1,2,3,...,n]` 的所有元素共有 `n!` 种排列。按大小（字典序）顺序列出并编号，`n = 3` 时依次是 `"123"`、`"132"`、`"213"`、`"231"`、`"312"`、`"321"`。给定 `n` 和 `k`，返回第 `k` 个排列（字符串）。`1 <= n <= 9`，`1 <= k <= n!`。例：`n = 3, k = 3` → `"213"`；`n = 4, k = 9` → `"2314"`；`n = 3, k = 1` → `"123"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 不生成前面的排列，直接按「阶乘进制」逐位确定：先把 `k` 改成从 `0` 开始，首位固定后后面的排列数是 `(n-1)!`，所以 `(k-1) // (n-1)!` 就是首位在剩余数字里的排名，余数是块内排名，继续处理剩下的位。`O(n^2)`（列表 `pop` 是 `O(n)`），`n <= 9`。

**识别。** 「第 `k` 个字典序排列」是典型的「按块跳」：首位相同的排列连续排成一块，每块大小都是 `(n-1)!`，可以直接算出落在第几块；`n <= 9` 时暴力生成 `9! = 362880` 个也能过，但考点是不生成前 `k - 1` 个。

**推导。** 暴力：生成全部排列排序取第 `k` 个，`O(n * n!)`；或从 `1...n` 开始调用 `k - 1` 次「下一个排列」，`O(k * n)` → 浪费：为了到达第 `k` 个，把前面 `k - 1` 个都走了一遍 → 洞察：字典序下，首位为最小数字的排列恰有 `(n-1)!` 个，接下来是首位为次小数字的 `(n-1)!` 个，以此类推；所以首位在剩余数字里的排名是 `(k-1) // (n-1)!`，块内排名是 `(k-1) % (n-1)!`，子问题与原问题同构，规模减一。这就是阶乘进制：每一位的基数依次是 `n-1, n-2, ..., 1, 0` 的阶乘。

```python
from math import factorial


def get_permutation(n: int, k: int) -> str:
    digits = list(range(1, n + 1))            # 还没用的数字，始终升序
    k -= 1                                    # 改成 0-based 的名次
    out: list[str] = []
    for remaining in range(n, 0, -1):
        block = factorial(remaining - 1)      # 固定首位后，后面 remaining-1 位的全排列数
        q, k = divmod(k, block)               # q：首位是剩余数字里的第 q 小；k：块内名次
        out.append(str(digits.pop(q)))
    return "".join(out)
```

运行：`(3, 3)` → `"213"`，`(4, 9)` → `"2314"`，`(3, 1)` → `"123"`，`(1, 1)` → `"1"`，`(9, 362880)` → `"987654321"`，`(9, 1)` → `"123456789"`。

**复杂度。** 时间 `O(n^2)`：`n` 轮，每轮 `pop` 是 `O(n)`；空间 `O(n)`。

**易错点。**
- 忘了 `k -= 1`：名次从 `1` 开始，不转成 `0` 开始就会整体偏一块。`(3, 3)` 会得到 `"231"`，正确是 `"213"`；`(3, 6)` 直接 `IndexError`。
- 块大小用 `factorial(remaining)` 而不是 `factorial(remaining - 1)`：`(3, 3)` 得到 `"132"`，正确是 `"213"`。
- 取数字不删除（用 `digits[q]` 而不是 `digits.pop(q)`）：数字会重复，`(4, 9)` 得到 `"2211"`，正确是 `"2314"`。

**追问。**
- 逆问题：给一个排列，求它是第几个。逐位统计「比当前位小、且没用过的数字个数」乘以对应的阶乘，累加后加一。
- 有重复元素的第 `k` 个排列：块大小不再是 `(n-1)!`，要用多重集合的排列数 `n! / ∏ 各值出现次数!`，每个候选首位的块大小不同。
- `n` 很大（如 `10^5`）：阶乘不能直接算，用连续除法取出阶乘进制的每一位，并用 Fenwick 树维护「第 `q` 小的未用数字」代替 `pop`。

**同模式。** LC 46 全排列、LC 47 全排列 II、LC 31 下一个排列、LC 1415 长度为 n 的开心字符串中字典序第 k 小的字符串、LC 440 字典序的第K小数字。
