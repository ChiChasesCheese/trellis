## Q
**LC 670 最大交换**｜Medium · LC TikTok 全时段热度 68/100 · CodeTop 国内累计 15 次 · 最近 2026-01-01（国内 CodeTop）

给一个非负整数 `num`，你**至多**可以交换其中任意两位数字一次，返回能得到的最大值。

约束：`0 <= num <= 10^8`。

例：`num = 2736` → `7236`（交换 `2` 和 `7`）；`num = 9973` → `9973`（不需要交换）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 贪心：从高位向低位扫，对每一位 `d`，看它右边有没有比 `d` 更大的数字；有就和其中**最大**数字的**最右**一次出现交换，立即返回——高位变大的收益永远比低位的任何收益大。用 `last` 记每个数字最后一次出现的位置，查询 `O(1)`。

**识别。** 「至多交换一次」+「得到最大」→ **贪心**：整数的大小由高位决定，所以想让最高的、能变大的那一位变大。位数只有 9 位，暴力也行（`O(d^3)`），但面试官想看到你证明贪心：为什么换最大数字、为什么换它最右边的那个。

**推导。** 暴力：枚举所有 `C(d,2)` 个交换对，每次转成整数比较，`O(d^3)`，`d ≤ 9` 完全可行。贪心洞察一：整数大小由高位决定，所以交换的**左边位置**应尽量靠左，且要换成更大的数字——第一个「右边存在更大数字」的位置 `i` 就是左边位置。洞察二：换过来的数字应该尽量大——选右边最大的数字。洞察三：最大数字可能出现多次，换最**右边**的一个，因为被换到右边的 `d` 是个较小的数，放在越靠右（低位）越不影响大小。用 `last` 字典，从大到小枚举候选数字，第一个满足 `last[big] > i` 的就是答案。

```python
def maximum_swap(num: int) -> int:
    digits = list(str(num))
    last = {d: i for i, d in enumerate(digits)}   # 每个数字最后一次出现的下标（后写覆盖前写）
    for i, d in enumerate(digits):
        for big in "9876543210":                  # 从最大的数字开始找
            if big <= d:
                break                             # 已经没有比 d 更大的了，这一位不用换
            if last.get(big, -1) > i:             # 右边有更大的数字：换最右边的那个
                digits[i], digits[last[big]] = digits[last[big]], digits[i]
                return int("".join(digits))
    return num
```

运行：`num=2736` → `7236`，`num=9973` → `9973`，`num=1993` → `9913`，`num=2998` → `9928`，`num=0` → `0`，`num=10**8` → `100000000`。

**复杂度。** 时间 `O(d · 10)`，`d` 为位数（`10^8` 时 `d ≤ 9`，实际是常数）：每一位最多看 10 个候选数字；空间 `O(d)`（数字列表与 `last` 字典，至多 10 个键）。

**易错点。**
- 与最大数字的**第一次**出现交换：`1993` 应得 `9913`，写成第一次出现得 `9193`（把 `1` 换到了较高的位置，丢了一个高位的 `9`）。
- 候选数字从小到大枚举：会换成「比 `d` 大的最小数字」而不是最大的。`2736` 应得 `7236`，从小到大找到 `3` 就换，得 `3726`。必须从 `9` 往下找。
- 没找到可交换的位就继续扫描所有位：贪心要在**第一个**能变大的位置交换并立即返回，继续往后扫会白白改动低位。
- 忘了 `num = 0` 或递减数字：`9973` 这类已经最大的数应原样返回，循环结束后返回 `num` 而不是别的值。

**追问。**
- 至多交换 `k` 次：不再有简单贪心，通常用 BFS 按层搜索交换后的状态，位数小时可行；每一层用 `set` 去重。
- 输入是一个很长的数字字符串（几十万位）：同样的方法，`last` 只有 10 个键，`O(10 · d)`；整数转换换成直接在字符数组上操作。
- 一次扫描 `O(d)` 的写法：从右向左维护「目前见到的最大数字的下标」，每当遇到比它小的数字就记下一对 `(i, max_idx)`，扫完后交换最后记录的那一对。

**同模式。** LC 402 移掉 K 位数字、LC 738 单调递增的数字、LC 1323 6 和 9 组成的最大数字、LC 321 拼接最大数、LC 556 下一个更大元素 III。
