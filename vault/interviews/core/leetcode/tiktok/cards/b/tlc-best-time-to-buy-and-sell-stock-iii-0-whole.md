## Q
**LC 123 买卖股票的最佳时机 III**｜Hard · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 21 次 · 最近 2026-06-03（国内 CodeTop）

数组 `prices` 的第 `i` 个元素是某股票第 `i` 天的价格。最多完成**两笔**交易，求最大利润；不能同时持有多笔（必须先卖出才能再次买入）。`1 <= prices.length <= 10^5`，`0 <= prices[i] <= 10^5`。例：`[3,3,5,0,0,3,1,4]` → `6`（第 4 天买入 `0`、第 6 天卖出 `3`，第 7 天买入 `1`、第 8 天卖出 `4`）；`[1,2,3,4,5]` → `4`（一笔交易即可）；`[7,6,4,3,1]` → `0`；`[1]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把过程看成四个状态依次前进的状态机：第一次持有、第一次卖出、第二次持有、第二次卖出；每天对每个状态保留「到目前为止该状态下手里最多的现金」，新的一天里每个状态要么保持不变，要么由前一个状态转移而来；答案是第二次卖出的值。`O(n)` 时间，`O(1)` 空间。

**识别。** 「最多 `k` 笔交易」的股票题是带次数限制的状态 DP：状态 = （已完成几笔，当前是否持有）。`k = 2` 只有四个状态，直接用四个变量，不必开数组。`n` 到 `10^5`，排除 `O(n^2)`。

**推导。** 暴力：枚举分界日，前面做一笔、后面做一笔，每段 `O(n)`，总 `O(n^2)` → 浪费：每个分界日都重新求一遍前后缀最大利润 → 前缀最优和后缀最优各扫一遍就能预先算好（另一种解法）→ 更一般的看法：每天的状态由前一天转移，`buy1 = max(buy1, -p)`、`sell1 = max(sell1, buy1 + p)`、`buy2 = max(buy2, sell1 - p)`、`sell2 = max(sell2, buy2 + p)`，四个值只依赖前面的状态，推广到 `k` 笔只要多几组变量。

```python
def max_profit(prices: list[int]) -> int:
    buy1 = buy2 = -prices[0]               # 持有股票时手里的最大现金（买入花钱，所以是负的）
    sell1 = sell2 = 0                      # 卖出之后手里的最大现金
    for p in prices:
        buy1 = max(buy1, -p)               # 第一次买入：从零现金开始买
        sell1 = max(sell1, buy1 + p)       # 第一次卖出
        buy2 = max(buy2, sell1 - p)        # 第二次买入：用第一次赚到的钱买
        sell2 = max(sell2, buy2 + p)       # 第二次卖出
    return sell2
```

运行：`[3,3,5,0,0,3,1,4]` → `6`，`[1,2,3,4,5]` → `4`，`[7,6,4,3,1]` → `0`，`[1]` → `0`，`[1,5,2,10]` → `12`；`10^5` 个随机价格约 `0.02` 秒。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 买入状态的初值写成 `0`：相当于免费持有股票。`[7,6,4,3,1]` 得到 `7`，正确是 `0`。初值应是 `-prices[0]`（第一天买入的现金）。
- 贪心「先取最佳的一笔，再在剩余区间取一笔」：`[1,5,2,10]` 先取 `1 → 10` 利润 `9`，两侧没有剩余，答案 `9`；正确是 `(1→5) + (2→10) = 4 + 8 = 12`。
- 同一天内连续更新四个变量是安全的：同一天买入再卖出利润为 `0`，不会虚增利润；因此不需要用「旧值」临时变量。

**追问。**
- 最多 `k` 笔（LC 188）：`buy` 和 `sell` 各开长度 `k + 1` 的数组，内层循环枚举笔数。
- 含冷冻期（LC 309）或手续费（LC 714）：状态换成「持有 / 未持有且不在冷冻期 / 冷冻期」，转移里加入相应的代价。
- 无限次交易（LC 122）：只要后一天更高就累加差值。

**同模式。** LC 121 买卖股票的最佳时机、LC 122 买卖股票的最佳时机 II、LC 188 买卖股票的最佳时机 IV、LC 309 含冷冻期、LC 714 含手续费。
