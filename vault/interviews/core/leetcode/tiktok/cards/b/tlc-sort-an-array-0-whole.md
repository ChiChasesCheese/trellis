## Q
**LC 912 排序数组**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 2 次 · 最近 2026-08-26（国内面试记录）

给整数数组 `nums`，升序排列并返回。**不能使用任何内置排序函数**，时间复杂度 `O(n log n)`，空间复杂度尽可能小。`1 <= nums.length <= 5 * 10^4`，`-5 * 10^4 <= nums[i] <= 5 * 10^4`。例：`[5,2,3,1]` → `[1,2,3,5]`；`[5,1,1,2,0,0]` → `[0,0,1,1,2,5]`（有重复值）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 手写堆排序（heap sort）：先把数组原地建成大根堆，再反复把堆顶（最大值）换到末尾、堆大小减一并下沉修复；最坏 `O(n log n)`、额外空间 `O(1)`，且全是循环，没有递归深度问题。

**识别。** 「不许用内置排序 + `O(n log n)` + 空间尽量小」：`O(n^2)` 的冒泡 / 插入 / 选择在 `n = 5 * 10^4` 时要 `2.5 * 10^9` 次操作，直接排除；`O(n log n)` 只剩归并（`O(n)` 额外空间）、快排（平均快，最坏 `O(n^2)`，递归栈）、堆排（最坏有保证、原地）。「空间尽量小」把天平压向原地且最坏有保证的堆排。

**推导。** 选择排序每轮线性扫描找最大值 `O(n^2)` → 浪费在重复扫描：每轮扫描没有保留任何下一轮能用的信息 → 用堆（heap）保留「谁最大」的信息，取最大 `O(log n)` → 把堆建在数组本身上，已取出的最大值就存放在堆后面空出的位置，不需要额外数组 → 建堆自底向上 `O(n)`，取出 `n` 次下沉 `O(log n)`，总 `O(n log n)`。

```python
def sort_array(nums: list[int]) -> list[int]:
    n = len(nums)

    def sift_down(root: int, size: int) -> None:
        # 把 nums[root] 下沉到 nums[:size] 这个大根堆里的正确位置
        val = nums[root]
        while (child := 2 * root + 1) < size:
            if child + 1 < size and nums[child + 1] > nums[child]:
                child += 1                      # 选较大的孩子
            if nums[child] <= val:
                break
            nums[root] = nums[child]            # 孩子上提，空位下移
            root = child
        nums[root] = val

    for i in range(n // 2 - 1, -1, -1):         # 自底向上建堆，O(n)
        sift_down(i, n)
    for end in range(n - 1, 0, -1):             # 反复把堆顶（最大值）换到末尾
        nums[0], nums[end] = nums[end], nums[0]
        sift_down(0, end)
    return nums
```

运行：`[5,2,3,1]` → `[1,2,3,5]`；`[5,1,1,2,0,0]` → `[0,0,1,1,2,5]`；`[7]` → `[7]`；`[3,3,3]` → `[3,3,3]`；`[-50000,50000,0]` → `[-50000,0,50000]`；`5 * 10^4` 个随机数、全相同、升序、降序的数组都正确，各在 `0.1` 秒内。

**复杂度。** 时间 `O(n log n)`（建堆 `O(n)` + `n` 次下沉各 `O(log n)`），最坏也是；空间 `O(1)`（原地，循环实现，没有递归）。不稳定排序。

**易错点。**
- 建堆必须自底向上：从最后一个非叶子 `n // 2 - 1` 倒着下沉到 `0`。从 `0` 往后下沉，`[1,2,3,4]` 会得到 `[1,2,4,3]`（正确 `[1,2,3,4]`）。
- `sift_down(0, end)` 的堆大小是 `end`，不是 `n`：用 `n` 会把已经排好的后缀又拉回堆里，破坏结果。
- 选孩子时先判断 `child + 1 < size` 再比较，否则最后一层会越界。

**追问。**
- 为什么常有人写快排：平均更快，常数更小；但固定首元素当基准在已排序数组上会退化成 `O(n^2)`，递归深度 `n`（升序的 `2000` 个数就会 `RecursionError`），要用随机基准 + 三路划分（`< / == / >`）处理大量重复值。
- 需要稳定排序：用归并排序，`O(n)` 额外空间；链表排序（LC 148）也用归并。
- 值域只有 `10^5 + 1` 种：计数排序 `O(n + V)`，比任何比较排序都快。

**同模式。** LC 215 数组中的第 K 个最大元素（堆 / 快速选择）、LC 75 颜色分类（三路划分）、LC 148 排序链表（归并）、LC 315 计算右侧小于当前元素的个数（归并计数）。
