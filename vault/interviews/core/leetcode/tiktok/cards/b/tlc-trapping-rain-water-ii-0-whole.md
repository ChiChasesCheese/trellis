## Q
**LC 407 接雨水 II**｜Hard · LC 字节 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 3 次 · 最近 2026-08-31（国内面试记录）

给 `m × n` 的矩阵 `heightMap`，每个元素是该格子的高度（非负整数）。下雨后，计算这张二维高度图最多能存多少体积的水（水只能向上下左右四个方向流动，流出边界就没了）。`1 <= m, n <= 200`，`0 <= heightMap[i][j] <= 2 * 10^4`。例：`[[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]` → `4`；`[[3,3,3,3,3],[3,2,2,2,3],[3,2,1,2,3],[3,2,2,2,3],[3,3,3,3,3]]` → `10`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 木桶原理 + 最小堆：一格能存的水位，等于「从它走到边界的所有路径中，路径上最高格子的高度」的最小值。把最外圈放进小根堆作为「围墙」，每次取出最矮的一格，用它的水位去灌它未访问的邻居（邻居的水位 = `max(围墙水位, 邻居自身高度)`），累加 `max(0, 围墙水位 − 邻居高度)`。`O(mn log(mn))`。

**识别。** 一维的接雨水（LC 42）用「左右最高中的较小值」；二维把「左右」换成「四周」，但水可以沿任意弯曲的路径流出去，不能分行分列算。信号：「从内部到边界的最低出口」= 最短路的变形（minimax path，路径代价是最高点而非总和）→ **Dijkstra**（小根堆）。`200 × 200 = 4 · 10^4` 格，`O(N log N)` 轻松。

**推导。** 暴力：一格一格求「到边界的所有路径里最高点的最小值」，路径指数多 → 用行列最大值的类比 `min(行最大, 列最大) − h` 是错的，因为水能绕路流出去 → 观察：最外圈的格子水位就是自己的高度；整张图的水位由「最矮的围墙」决定：当前围墙里最矮的格子 `w`，它相邻的内部格子的水位至少是 `w`（水位更高的话就是邻居自己更高）→ 像 Dijkstra：不断取出堆里最矮的围墙，向内扩展，邻居水位 `max(w, 邻居高度)` 入堆；每格只入堆一次。

```python
import heapq

def trap_rain_water(height_map: list[list[int]]) -> int:
    m, n = len(height_map), len(height_map[0])
    if m < 3 or n < 3:
        return 0                               # 没有内部格子，存不住水
    seen = [[False] * n for _ in range(m)]
    heap: list[tuple[int, int, int]] = []      # (当前水位, 行, 列)：最外圈先入堆作为「围墙」
    for r in range(m):
        for c in range(n):
            if r in (0, m - 1) or c in (0, n - 1):
                heap.append((height_map[r][c], r, c))
                seen[r][c] = True
    heapq.heapify(heap)
    water = 0
    while heap:
        level, r, c = heapq.heappop(heap)      # 目前围墙里最矮的一格：它的水位决定了邻居的水位
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < m and 0 <= nc < n and not seen[nr][nc]:
                seen[nr][nc] = True
                water += max(0, level - height_map[nr][nc])
                heapq.heappush(heap, (max(level, height_map[nr][nc]), nr, nc))
    return water
```

运行：示例 1 → `4`，示例 2 → `10`，`[[5]]` → `0`，`[[1,2],[3,4]]` → `0`，`[[1,1,1],[1,0,1],[1,1,1]]` → `1`；`200 × 200` 随机高度约 `0.02` 秒。

**复杂度。** 时间 `O(mn log(mn))`（每格入堆出堆一次）；空间 `O(mn)`。

**易错点。**
- 入堆时用邻居自己的高度而不是 `max(level, 邻居高度)`：水位被低估。示例 2 得 `2`（正确 `10`）。
- 用行最大、列最大的较小值做一维推广：示例 1 得 `5`（正确 `4`），因为水可以绕路从缺口流出。
- 没有判断 `m < 3 or n < 3`：不会报错（没有内部格子，循环不累加），但显式返回更清楚。

**追问。**
- 返回每格的水深 / 水位图：把 `level` 记进二维数组 `depth[nr][nc]`。
- 水可以斜着流（八个方向）：邻居改成 8 个方向，其余不变。
- 一维的 LC 42：双指针 `O(n)` 空间 `O(1)`，不需要堆。

**同模式。** LC 42 接雨水、LC 778 水位上升的泳池中游泳（minimax 路径）、LC 1631 最小体力消耗路径、LC 743 网络延迟时间（Dijkstra）。
