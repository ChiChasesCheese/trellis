## Q
**面试题 08.13 堆箱子**｜Hard · CodeTop 国内累计 2 次 · 最近 2026-03-11（国内 CodeTop）

有 `n` 个箱子，第 `i` 个用 `[wi, di, hi]` 表示宽、深、高。箱子不能翻转；把箱子堆起来时，下面箱子的宽度、深度和高度都必须**严格大于**上面的箱子。求能搭出的箱堆的最大高度（各箱高度之和）。箱子数目不大于 `3000`。例：`[[1,1,1],[2,2,2],[3,3,3]]` → `6`；`[[1,1,1],[2,3,4],[2,6,7],[3,4,5]]` → `10`（`[3,4,5]` 上放 `[2,3,4]` 再放 `[1,1,1]`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 按宽度排序后，问题变成「三维严格递增的、**高度和**最大的子序列」：`dp[i]` 是以 `boxes[i]` 为最底层的箱堆最大高度，等于 `h_i` 加上所有能放在它上面的 `dp[j]` 的最大值。`O(n^2)`。

**识别。** 「从一堆元素里挑一串、相邻两个满足偏序（三维都严格更小）、求最优」→ **最长递增子序列（LIS）的变形**：把「长度」换成「高度和」，把「数值更小」换成「三维都更小」。`n <= 3000` → `O(n^2) ≈ 4.5 * 10^6` 次比较可行；三维偏序没有 LIS 那种二分优化的简单写法。

**推导。** 暴力：枚举所有子集，检查能否排成合法的堆，`O(2^n · n log n)`。观察一：合法的堆从上到下宽度严格递增，所以按宽度升序排序后，任何一个堆都是排序后数组的一个**子序列**，不用再考虑排列。观察二：以某个箱子为最底层时，它上面的最优堆只取决于「哪个箱子紧挨在它上面」，与更上面怎么放无关 → 最优子结构，`dp[i] = h_i + max(dp[j])`，`j < i` 且 `boxes[j]` 三维都严格小于 `boxes[i]`。答案是所有 `dp[i]` 的最大值。

```python
def pile_box(box: list[list[int]]) -> int:
    boxes = sorted(box)                          # 按宽度升序：能放在 boxes[i] 上面的箱子都排在它前面
    dp = [0] * len(boxes)                        # dp[i]：以 boxes[i] 为最底层的箱堆的最大高度
    for i, (w, d, h) in enumerate(boxes):
        above = 0                                # 能放在 boxes[i] 上面的最高箱堆
        for j in range(i):
            wj, dj, hj = boxes[j]
            if wj < w and dj < d and hj < h:     # 三个维度都严格更小
                above = max(above, dp[j])
        dp[i] = above + h
    return max(dp)
```

运行：`[[1,1,1],[2,2,2],[3,3,3]]` → `6`，`[[1,1,1],[2,3,4],[2,6,7],[3,4,5]]` → `10`，`[[5,5,5]]` → `5`，`[[1,1,1],[1,1,1]]` → `1`，`[[3,1,1],[1,3,1]]` → `1`，3000 个 `[i,i,i]`（`i = 1..3000`）→ `4501500`。

**复杂度。** 时间 `O(n^2)`：排序 `O(n log n)`，双重循环约 `n^2/2` 次比较；空间 `O(n)`。

**易错点。**
- 以为「排序后宽度已经递增」就只比较深度和高度：宽度相同的箱子也会排在前面，却不能叠放。`[[1,1,1],[1,2,2]]` 会错成 `3`（正确 `2`）。
- 照搬 LIS 求「最多几个箱子」再乘高度，或按个数 DP：`[[1,1,1],[2,2,2],[3,3,3],[5,1,100]]` 按个数选出 3 个箱子（高 `6`），正确是单放 `[5,1,100]` 得 `100`。`dp` 存的必须是高度和。
- 不排序直接 DP：`[[3,3,3],[2,2,2],[1,1,1]]` 只得到 `3`（正确 `6`），因为能放在上面的箱子出现在后面，算 `dp[i]` 时还没算到。

**追问。**
- 返回箱堆本身：再开 `prev[i]` 记下取到最大值的 `j`，从 `argmax(dp)` 沿 `prev` 回溯；样例 2 → 从底到顶 `[[3,4,5],[2,3,4],[1,1,1]]`。
- 允许旋转、且只要求「不大于」（LC 1691 堆叠长方体的最大高度）：每个长方体三边升序排列，再整体排序，同样的 `O(n^2)` DP，条件改成 `<=`。
- 二维（LC 354 俄罗斯套娃信封）：按宽度升序、宽度相同按高度**降序**排序后，对高度做 `O(n log n)` 的 LIS；三维没有这种简单写法。
