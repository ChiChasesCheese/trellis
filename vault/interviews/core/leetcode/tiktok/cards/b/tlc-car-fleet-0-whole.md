## Q
**LC 853 车队**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-04-24（国内 CodeTop）

单行道上有 `n` 辆车开往同一个目的地，目的地在 `target` 英里处。数组 `position[i]`、`speed[i]` 是第 `i` 辆车的位置和速度（英里/小时）。车不能超过前面的车，但可以追上去，并以较慢那辆车的速度并排行驶。**车队**是并排行驶的一辆或几辆车，车队的速度是队内最慢那辆车的速度；即使在 `target` 才追上，也算同一个车队。返回到达目的地的车队数量。`n == position.length == speed.length`，`1 <= n <= 10^5`，`0 < target <= 10^6`，`0 <= position[i] < target`，`position` 中各值互不相同，`0 < speed[i] <= 10^6`。例：`target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]` → `3`（位置 `10` 和 `8` 的车在 `12` 处汇合，位置 `0` 的车单独，位置 `5` 和 `3` 的车在 `6` 汇合）；`target = 100, position = [0,2,4], speed = [4,2,1]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 按位置从离终点最近到最远排序，算每辆车不受阻挡时的到达时间；若某辆车的时间**严格大于**前面所有车队中最晚的到达时间，它追不上任何车队，自成一个新车队，否则被前面的车队吞并。`O(n log n)`。

**识别。** 一条路、不能超车：每辆车的命运只由它**前面**的车决定，后车追上前车就变成前车的速度。判断「追不追得上」不需要模拟过程，只比较到达终点的时间。这是单调栈 / 前缀最大值的思路，只不过栈里只需要保留一个数。`n = 10^5` 允许排序。

**推导。** 暴力：按时间推进模拟，每次找最早的追上事件并合并，`O(n^2)` 或更复杂。浪费：中间在哪里追上不重要。洞察：不能超车，所以每辆车的**实际**到达时间等于 `max(自己的无阻挡时间, 前方一辆车的实际到达时间)`；实际到达时间相同的车属于同一个车队。从前往后扫，维护「到目前为止最大的无阻挡时间」，每当当前车的时间超过它，就多出一个车队。

```python
def car_fleet(target: int, position: list[int], speed: list[int]) -> int:
    fleets = 0
    latest = 0.0                       # 目前所有车队里最晚到终点的时间
    for pos, spd in sorted(zip(position, speed), reverse=True):    # 从离终点最近的车开始
        arrive = (target - pos) / spd  # 这辆车不受阻挡时的到达时间
        if arrive > latest:            # 比前面所有车队都晚：追不上，自成新车队
            fleets += 1
            latest = arrive
    return fleets
```

运行：`car_fleet(12, [10,8,0,5,3], [2,4,1,1,3])` → `3`，`car_fleet(10, [3], [3])` → `1`，`car_fleet(100, [0,2,4], [4,2,1])` → `1`，`car_fleet(12, [10,8], [2,4])` → `1`。

**复杂度。** 时间 `O(n log n)`，排序占主导，扫描 `O(n)`；空间 `O(n)`，排序后的列表。

**易错点。**
- 直接数不同的到达时间：例 1 的无阻挡时间是 `1, 1, 12, 7, 3`，去重得 `4`；位置 `3` 的车时间是 `3`，被前面时间 `7` 的车拖慢，不是独立的车队。正确 `3`。
- 比较写成 `>=`：到达时间相等（在 `target` 才追上）也是同一车队。`car_fleet(12, [10,8], [2,4])` 两辆车都在时间 `1` 到达，`>=` 得 `2`，正确 `1`。
- 从远到近扫描：例 1 会得到 `1`（正确 `3`）。必须从离终点最近的车开始，前面的车才不受后面的影响。

**追问。**
- 浮点比较会不会出错：在题目范围内不会；相等的分数得到完全相同的浮点数，不等的分数相差远大于舍入误差。保险写法是交叉相乘：`(target - p1) * s2 > (target - p2) * s1`。
- 不想排序：`position < target <= 10^6`，用以位置为下标的数组桶放，从大到小扫，`O(n + target)`。
- 要输出每个车队包含哪些车：扫描时在新车队开始处开一个新分组，否则并入当前分组。
