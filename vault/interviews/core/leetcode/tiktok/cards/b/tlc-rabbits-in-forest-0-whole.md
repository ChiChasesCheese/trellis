## Q
**LC 781 森林中的兔子**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-06-05（国内 CodeTop）

森林中有未知数量的兔子。询问其中若干只兔子「还有多少只其它兔子与你颜色相同？」，答案收集到整数数组 `answers` 里，`answers[i]` 是第 `i` 只兔子的回答。返回森林中兔子的**最少**数量。`1 <= answers.length <= 1000`，`0 <= answers[i] < 1000`。例：`[1,1,2]` → `5`（两只回答 `1` 的可以同色，设为红色；回答 `2` 的不能是红色，设为蓝色，且森林里还应有另外 `2` 只蓝色兔子没被问到）；`[10,10,10]` → `11`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回答 `x` 的兔子所在的颜色组恰有 `x + 1` 只，且不同回答值的兔子一定不同色；对每个回答值 `x`，有 `count` 只兔子回答了它，就需要 `ceil(count / (x + 1))` 个颜色组，每组按满员 `x + 1` 只计，累加。`O(n)`。

**识别。** 「最少」+「每只兔子的话限定了它那一组的大小」：回答 `x` 的兔子说明同色共 `x + 1` 只，这是一个按回答值分组、每组容量固定的**装箱**（packing）问题，贪心就是最优——能同色就同色。`n <= 1000`，哈希计数一遍就够。

**推导。** 暴力：枚举把回答的兔子分成若干颜色组的所有方式，每组内回答相同、组大小不超过 `x + 1`，取代价（各组 `x + 1` 之和）最小的，指数级 → 观察 1：回答值不同的兔子一定不同色（同色的兔子组大小相同，回答也相同）→ 观察 2：回答 `x` 的 `count` 只兔子，每个颜色组最多容纳 `x + 1` 只，所以最少需要 `ceil(count / (x + 1))` 个组，且每个组即使只有一只兔子回答，森林里这种颜色的兔子也有 `x + 1` 只 → 用 `Counter` 数出每个回答值的人数，按公式累加。

```python
from collections import Counter


def num_rabbits(answers: list[int]) -> int:
    total = 0
    for x, count in Counter(answers).items():   # 回答 x 的兔子：同色一组，每组最多 x + 1 只
        groups = -(-count // (x + 1))           # 向上取整：需要几种颜色
        total += groups * (x + 1)               # 每组都按满员 x + 1 只计（没回答的也算进去）
    return total
```

运行：`[1,1,2]` → `5`，`[10,10,10]` → `11`，`[0]` → `1`，`[0,0,0]` → `3`，`[1,1,1]` → `4`，`[2,2,2,2]` → `6`，`[999] * 1000` → `1000`。

**复杂度。** 时间 `O(n)`（计数一遍，再遍历不同的回答值）；空间 `O(k)`，`k` 为不同回答值的个数。

**易错点。**
- 每只兔子都算一组新的 `x + 1`（没有合并）：`[10,10,10]` 得到 `33`，正确是 `11`。
- 向下取整（`count // (x + 1)`）：`[1,1,1]` 得到 `2`，正确是 `4`，第三只兔子必须另起一个颜色组（`2 + 2`）。
- 只返回 `len(answers)`：忘了没被问到的同色兔子，`[1,1,2]` 得到 `3`，正确是 `5`。

**追问。**
- 数据流式到来、不能先计数：为每个回答值记「当前这组还空着的名额」，来一只就占一个名额，没有名额就新开一组（总数加 `x + 1`，新组剩 `x` 个名额）；一遍扫描，不需要 `Counter`。
- 要给出一种具体的颜色分配：每个回答值开 `ceil(count / (x + 1))` 个组，依次往组里放兔子。
- 回答值的范围很小时可以用定长数组代替哈希表，常数更小。
