## Q
**剑指 Offer 60 n个骰子的点数**｜Medium · CodeTop 国内累计 4 次 · 最近 2026-01-14（CodeTop）

掷 `num` 个六面骰子，所有点数之和可能是 `num` 到 `6 * num` 中的某个值。用浮点数组返回答案：第 `i` 个元素是「所有可能的点数和中第 `i` 小的那个」出现的概率。`1 <= num <= 11`。例：`num = 3` → 长度 16 的数组 `[0.00463, 0.01389, 0.02778, 0.04630, 0.06944, 0.09722, 0.11574, 0.12500, 0.12500, 0.11574, 0.09722, 0.06944, 0.04630, 0.02778, 0.01389, 0.00463]`（分别对应和为 3 到 18）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维计数 DP：`dp[i][j]` 是 `i` 个骰子点数和为 `j` 的方案数，按最后一个骰子的点数拆分，`dp[i][j] = Σ dp[i-1][j-face]`（`face` 取 1 到 6）；最后每格除以 `6^num`。`O(num^2)`。

**识别。** 「多个独立骰子 + 点数和的分布」→ 前 `i` 个骰子的和 = 前 `i - 1` 个的和 + 第 `i` 个的点数，子问题「`i` 个骰子、和为 `j`」大量重叠 → 二维 DP（骰子数 × 点数和）。`num = 11` 时结果有 `6^11 ≈ 3.6 * 10^8` 种，不能逐一枚举。

**推导。** 暴力：`itertools.product(range(1, 7), repeat=num)` 枚举所有结果统计和，`6^num` 种，`num = 11` 不可行。浪费在于：前 `i` 个骰子的不同结果只要和相同，后面的扩展就完全相同，却被分别算了一遍。按「和」合并，只记方案数：最后一个骰子的点数是 1 到 6 之一，按它拆分不重不漏，得到 `dp[i][j] = Σ dp[i-1][j-face]`。表有 `(num+1) × (6num+1)` 格，每格 6 次加法。

```python
def dice_probability(num: int) -> list[float]:
    top = 6 * num
    # dp[i][j]：掷 i 个骰子、点数和恰好为 j 的方案数（整数，最后再除，避免浮点误差累积）
    dp = [[0] * (top + 1) for _ in range(num + 1)]
    dp[0][0] = 1                                     # 0 个骰子和为 0：一种方案
    for i in range(1, num + 1):
        for j in range(i, 6 * i + 1):                # i 个骰子的和只可能落在 [i, 6i]
            dp[i][j] = sum(dp[i - 1][j - face] for face in range(1, 7) if j - face >= 0)
    total = 6 ** num
    return [dp[num][j] / total for j in range(num, top + 1)]
```

运行（保留 5 位小数）：`num = 1` → 6 个 `0.16667`；`num = 3` → `[0.00463, 0.01389, 0.02778, 0.0463, 0.06944, 0.09722, 0.11574, 0.125, 0.125, 0.11574, 0.09722, 0.06944, 0.0463, 0.02778, 0.01389, 0.00463]`；`num = 11` → 长度 56，最小的概率 `1/6^11 ≈ 2.76e-09`。

**复杂度。** 时间 `O(num^2)`：表有 `(num+1)(6num+1)` 格，每格最多 6 项；空间 `O(num^2)`：整张表。

**易错点。**
- 结果下标没平移：点数和从 `num` 开始，写成 `[dp[num][j] / total for j in range(5 * num + 1)]` 时，`num = 1` 得到 `[0.0, 0.16667, 0.16667, 0.16667, 0.16667, 0.16667]`，混进了不可能的和 0，又漏掉了和 6。
- `j - face` 可能为负：Python 的负下标不会报错，而是读到行尾的元素；要显式写 `j - face >= 0`，不能指望越界异常帮你发现。
- 用整数计数、最后一次相除；不要在中间把概率四舍五入到 5 位，误差会逐层放大。

**追问。**
- `k` 面骰子：内层改成 `range(1, k + 1)`，和的范围变成 `[num, k·num]`，时间 `O(k^2 · num^2)`。
- 求「点数和至少为 `T`」的概率：对结果数组做后缀和，`itertools.accumulate(reversed(probs))`。
- 每格的 6 项是上一行一段连续区间的和，用前缀和可以 `O(1)` 求出；空间可以压到 `O(num)`：见 Python 工具箱「DP 降维」。
