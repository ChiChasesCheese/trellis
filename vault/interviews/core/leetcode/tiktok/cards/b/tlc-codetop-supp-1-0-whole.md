## Q
**补充题 1 排序奇升偶降链表**｜Medium · 字节高频

给一个单链表，位置从 `1` 开始数：**奇数位**上的值从头到尾**升序**，**偶数位**上的值从头到尾**降序**。把整条链表按值升序排好，返回新的头结点。要求 `O(n)` 时间、`O(1)` 额外空间（只改指针，不建新结点）。`0 <= 链表长度 <= 5 * 10^4`，`-10^5 <= Node.val <= 10^5`。例：`1 -> 8 -> 3 -> 6 -> 5 -> 4 -> 7 -> 2`（奇数位 `1,3,5,7` 升序，偶数位 `8,6,4,2` 降序）→ `1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 拆、反、并三步：按位置奇偶把链表拆成两条；偶数位那条本来是降序，边拆边头插就等于反转成升序；最后合并两条升序链表。`O(n)` 时间，`O(1)` 空间。

**识别。** 「奇升偶降」说明链表是两条**各自有序**的子序列交错而成。要排序，就把它拆开，然后用链表的两个基本操作拼回去：反转链表、合并两个有序链表。要求 `O(1)` 空间排除了抄进数组排序。

**推导。** 暴力：取出所有值放进数组排序，再写回，`O(n log n)` 时间和 `O(n)` 空间；或者直接对链表做归并排序，`O(n log n)`。浪费：没用上「每个子序列已经有序」这个条件，白白付了 `log n`。洞察：奇数位升序、偶数位降序，拆开后只差一次反转；拆开时对偶数位用头插法（每个结点插到偶链表的最前面），反转和拆分合并成同一趟扫描。三步各 `O(n)`，总 `O(n)`。

```python
def sort_odd_even_list(head: ListNode | None) -> ListNode | None:
    odd_dummy, even_dummy = ListNode(), ListNode()
    odd_tail = odd_dummy
    node, pos = head, 1
    while node:
        nxt = node.next
        if pos % 2:                    # 奇数位：本来就升序，尾插保持顺序
            odd_tail.next = node
            odd_tail = node
        else:                          # 偶数位：本来降序，头插即反转成升序
            node.next = even_dummy.next
            even_dummy.next = node
        node, pos = nxt, pos + 1
    odd_tail.next = None               # 切断最后一个奇数结点指向旧偶数结点的边
    tail = dummy = ListNode()          # 合并两条升序链表
    a, b = odd_dummy.next, even_dummy.next
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next
```

运行：`[1,8,3,6,5,4,7,2]` → `[1, 2, 3, 4, 5, 6, 7, 8]`，`[1,8,3,6,5,4,7]` → `[1, 3, 4, 5, 6, 7, 8]`，`[5]` → `[5]`，`[2,9]` → `[2, 9]`，空链表 → `None`。

**复杂度。** 时间 `O(n)`：一趟拆分加一趟合并；空间 `O(1)`：只用了几个指针和两个哑结点（dummy node）。

**易错点。**
- 偶数位不反转，直接和奇数位合并：`[1,8,3,6,5,4,7,2]` 得到 `[1, 3, 5, 7, 8, 6, 4, 2]`，不是有序。偶数位是降序，合并前必须翻成升序。
- 拆完不切断 `odd_tail.next`：最后一个奇数结点的 `next` 还指着原链表里它后面的偶数结点，合并时会形成环，遍历永不结束（`[1,8,3,6]` 会反复输出 `8`）。
- 把「位置的奇偶」当成「值的奇偶」：按下标 / 位置拆，不看 `val`。

**追问。**
- 链表不满足奇升偶降（一般链表排序）：链表归并排序，快慢指针找中点、断开、递归排序、合并，`O(n log n)` 时间，递归栈 `O(log n)`。
- 一次扫描能不能不建哑结点：可以，但要特判头结点，代码更容易出错，面试里用哑结点。
- 变成「奇降偶升」或「全部降序」：只需改变哪一条需要反转、合并时的比较方向。
