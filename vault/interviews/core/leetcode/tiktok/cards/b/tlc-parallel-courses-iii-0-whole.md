## Q
**LC 2050 并行课程 III**｜Hard · LC TikTok 全时段热度 26/100

有 `n` 门课，编号 `1` 到 `n`。`relations[j] = [prev, next]` 表示课程 `prev` 必须在课程 `next` **之前**完成；`time[i]` 是完成第 `i + 1` 门课所需的月数。规则：一门课的所有先修课都完成后，可以在**任意时间**开始；可以**同时**上任意多门课。返回完成所有课程所需的**最少月数**。保证先修关系构成有向无环图（DAG）。`1 <= n <= 5 * 10^4`，`0 <= relations.length <= min(n * (n - 1) / 2, 5 * 10^4)`，`1 <= prev, next <= n`，`prev != next`，先修对互不相同，`time.length == n`，`1 <= time[i] <= 10^4`。例：`n = 3`，`relations = [[1,3],[2,3]]`，`time = [3,2,5]` → `8`（课程 `1`、`2` 同时开始，第 `3` 个月后开始课程 `3`，再花 `5` 个月）；`n = 5`，`relations = [[1,5],[2,5],[3,5],[3,4],[4,5]]`，`time = [1,2,3,4,5]` → `12`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 拓扑排序加 DP：一门课的最早开始时间 `start[v]` 等于所有先修课完成时间的最大值；课程 `u` 出队时 `finish = start[u] + time[u]`，用它更新所有后继的 `start`；答案是所有 `finish` 的最大值，也就是 DAG 上带点权的最长路径（关键路径）。`O(n + m)`。

**识别。** 「先修关系（DAG）+ 可以同时上任意多门课 + 求最少总时间」是关键路径问题：没有并行数量的限制，总时间只取决于依赖链最长的那条，与课程总数无关。有依赖就想拓扑排序；要在拓扑顺序上累积某个量的最大值，就是 DP。

**推导。** 暴力：枚举所有从入度为 `0` 的课到出度为 `0` 的课的路径，求最长的，路径数指数级 → DFS 记忆化：`finish[v] = time[v] + max(finish[p] for p in 先修)`，`O(n + m)`，但依赖链最长可达 `5 * 10^4`，递归会爆栈 → 用 Kahn 算法（入度为 `0` 的先出队）：课程出队时它的所有先修课都已出队，`start` 已是最终值；每处理一门课，就用它的完成时间去「推高」后继的 `start`，后继入度减到 `0` 时入队。

```python
from collections import deque


def minimum_time(n: int, relations: list[list[int]], time: list[int]) -> int:
    graph: list[list[int]] = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    for a, b in relations:
        graph[a].append(b)
        indeg[b] += 1
    start = [0] * (n + 1)                          # start[v]：v 最早能开始的月份 = 所有先修课完成时间的最大值
    queue = deque(i for i in range(1, n + 1) if indeg[i] == 0)
    ans = 0
    while queue:
        u = queue.popleft()
        finish = start[u] + time[u - 1]
        ans = max(ans, finish)
        for v in graph[u]:
            start[v] = max(start[v], finish)
            indeg[v] -= 1
            if indeg[v] == 0:                      # 先修课全部完成，start[v] 已定
                queue.append(v)
    return ans
```

运行：`(3, [[1,3],[2,3]], [3,2,5])` → `8`；`(5, [[1,5],[2,5],[3,5],[3,4],[4,5]], [1,2,3,4,5])` → `12`；`(1, [], [7])` → `7`；`(3, [], [1,9,4])` → `9`；长度 `5 * 10^4` 的依赖链（每门 `10^4`）→ `500000000`，不抛 `RecursionError`。

**复杂度。** 时间 `O(n + m)`；空间 `O(n + m)`。

**易错点。**
- 答案取最后出队那门课的完成时间，而不是所有完成时间的最大值：`(3, [], [1,9,4])` 得到 `4`，正确是 `9`。
- 后继的开始时间只取第一个先修课的完成时间，没有取最大值：第二个示例得到 `7`，正确是 `12`。一门课要等**所有**先修课。
- 把所有课程的时间相加：忽略了可以并行，第一个示例得到 `10`，正确是 `8`。

**追问。**
- 输出关键路径上的课程：每次更新 `start[v]` 变大时同时记 `prev[v] = u`，最后从完成时间最大的课程沿 `prev` 回溯。
- 每门课的最晚开始时间和松弛量：再对反图做一遍拓扑 DP；松弛为 `0` 的课程就在关键路径上。
- 输入可能有环：处理的课程数小于 `n` 就说明有环，拓扑排序无法完成。
