## Q
**LC 3389 使字符频率相等的最少操作次数**｜Hard · LC TikTok 全时段热度 62/100

给字符串 `s`。如果字符串里**出现过**的每个字符的出现次数都相等，它就是好的。可以做任意次下面的操作：（1）删除一个字符；（2）添加一个字符；（3）把一个字符变成字母表中的下一个字母（`'z'` 不能变成 `'a'`）。返回把 `s` 变好的最少操作次数。`1 <= s.length <= 2 * 10^4`，`s` 只含小写英文字母。例：`"acab"` → `1`（删一个 `'a'`）；`"wddw"` → `0`；`"aaabc"` → `2`（一个 `'a'` 变 `'b'`，再补一个 `'c'`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 枚举每个存活字母最终的出现次数 `t`（`1..最大频次`）；对 26 个字母填一张 `dp[i][0/1]` 的表（第 `i` 个字母最终是 `0` 次还是 `t` 次），基础代价是删 / 补的个数，再减去相邻字母间的「推送」节省：前一个字母多余的字符变成后一个字母，1 步，比「删一个 + 补一个」的 2 步省 1。`O(26 · 最大频次)`。

**识别。** 「所有出现过的字符次数相等」是「枚举目标频次 `t`」的信号。操作 3 只能变到**下一个**字母，影响只出现在相邻字母之间，所以沿字母表做线性 DP，状态只需记上一个字母的去向。`n = 2 * 10^4`，`26 · n` 约 `5 * 10^5` 次转移，足够。

**推导。** 暴力：固定 `t`，每个字母要么清零（删 `c` 个），要么变成 `t` 次（补或删 `|c - t|` 个），忽略操作 3，`O(26n)`；这漏掉了省钱的机会。洞察：字母 `i` 有富余字符、字母 `i+1` 有缺口时，把富余的变成 `i+1` 只要 1 步，而删 + 补要 2 步，每对省 1；推两格要 2 步，不比删 + 补好，所以只看相邻。富余来自「清零」字母的全部 `c`，或「保留 `t`」字母的 `c - t`；缺口只来自「保留 `t`」且 `c < t` 的字母。节省的步数是 `min(前一个字母的富余, 本字母的缺口)`。

```python
from collections import Counter
from string import ascii_lowercase


def make_string_good(s: str) -> int:
    cnt = Counter(s)
    freq = [cnt[ch] for ch in ascii_lowercase]          # 26 个字母各出现几次
    best = len(s)                                       # 上界：全部删光
    for t in range(1, max(freq) + 1):                   # 枚举每个存活字母最终出现 t 次
        # dp[i][0] / dp[i][1]：处理完前 i 个字母，第 i 个字母最终是 0 次 / t 次时的最小总代价
        dp = [[0, 0] for _ in range(27)]                # 第 0 行：虚拟的第 0 个字母，代价 0
        for i in range(1, 27):
            c = freq[i - 1]                             # 第 i 个字母的原始次数
            prev = freq[i - 2] if i > 1 else 0          # 前一个字母的原始次数
            short = max(t - c, 0)                       # 本字母若变成 t 次，还缺几个
            zero_prev, full_prev = dp[i - 1]
            dp[i][0] = min(zero_prev, full_prev) + c    # 本字母清零：删 c 个
            dp[i][1] = abs(c - t) + min(                # 本字母变 t 次：补 / 删 |c-t| 个，
                zero_prev - min(prev, short),           # 前一个字母清零：它的全部 prev 个都是富余
                full_prev - min(max(prev - t, 0), short),   # 前一个字母保留 t 次：富余是 prev - t
            )                                           # 每个推送过来的字符省 1 步
        best = min(best, *dp[26])                       # 答案行：最后一个字母的两种去向取小
    return best
```

**运行。** `"acab"` → `1`；`"wddw"` → `0`；`"aaabc"` → `2`；`"a"` → `0`；`"aaaaabbb"` → `1`（一个 `'a'` 变 `'b'`）；`"zzzzzzzaaa"` → `3`；两万个 `'a'` → `0`。

**复杂度。** 时间 `O(26 · M)`，`M` 是最大频次，最坏 `M = n`，约 `5 * 10^5` 次内层转移；空间 `O(1)`（26 个计数，加上每个 `t` 重建一张 `27 × 2` 的小表）。

**易错点。**
- 漏掉「清零」状态，每个出现过的字母都强行变成 `t` 次：`"aaabbbc"` 会得到 `2`，正确是 `1`（删掉 `'c'`）。
- 把字母表当环，让 `'z'` 变 `'a'`：`"zzzzzzzaaa"` 会得到 `2`，正确是 `3`，因为 `'z'` 的富余没有去处。
- 推送量不取 `min(富余, 缺口)`，直接把全部富余算成节省：`"acab"` 会得到 `0`，正确是 `1`。

**追问。**
- 只有删除和添加两种操作：答案是 `min over t of Σ min(c, |c - t|)`，`"aaaaabbb"` 得 `2`，加上第三种操作才变成 `1`。
- 允许 `'z'` 变 `'a'`（字母表成环）：固定 `'a'` 的去向（`0` 或 `t`）各跑一遍线性 DP，最后补上 `'z'` 到 `'a'` 的那一对节省，两次 DP 取小。
- 要输出具体操作方案：记下每个字母取到最小值的状态，回溯得到每个字母的去向和推送量。

**同模式。** LC 1647 字符频次唯一的最小删除次数、LC 2423 删除字符使频率相同、LC 2370 最长理想子序列（沿字母表做 DP）。
