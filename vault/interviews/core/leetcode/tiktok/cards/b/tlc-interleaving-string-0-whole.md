## Q
**LC 97 交错字符串**｜Medium · 字节 高频

给三个字符串 `s1`、`s2`、`s3`，判断 `s3` 能否由 `s1` 和 `s2` **交错**组成：把 `s1`、`s2` 各自切成若干非空子串（段数相差不超过 `1`），然后交替拼接，各自内部字符的相对顺序不变。等价地说，`s3` 的每个字符依次取自 `s1` 或 `s2` 的下一个未用字符，且两者恰好用完。`0 <= s1.length, s2.length <= 100`，`0 <= s3.length <= 200`，三个字符串都由小写英文字母组成。进阶：只用 `O(s2.length)` 额外空间。例：`s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"` → `true`；`s3 = "aadbbbaccc"` → `false`；三个都是 `""` → `true`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维动态规划（DP）：`dp[i][j]` 表示 `s1` 的前 `i` 个字符与 `s2` 的前 `j` 个字符能否交错成 `s3` 的前 `i + j` 个字符；`s3` 的最后一个字符要么来自 `s1[i-1]`，要么来自 `s2[j-1]`；只依赖上一行，滚动成 `O(len(s2))` 空间。

**识别。** 「两个序列保持各自顺序合并出第三个序列，问是否可能」是双序列 DP 的信号（和 LCS、编辑距离同族）。关键观察是 `s3` 已经给定，所以走到 `s1` 的第 `i` 个、`s2` 的第 `j` 个字符时，`s3` 的位置必是 `i + j`，状态只需要 `(i, j)` 两维。先比长度：`len(s1) + len(s2) != len(s3)` 直接 `false`。数据规模 `100 * 100`，`O(mn)` 毫无压力。

**推导。** 暴力：每一步从 `s1` 或 `s2` 取下一个字符，两条分支，最坏 `2^(m+n)`。浪费：同样的 `(i, j)` 会被不同取法反复到达。贪心也不行：能从 `s1` 取就取，会在 `s1 = "aa"`、`s2 = "ab"`、`s3 = "aaba"` 上误判（见易错点）。所以用 DP 记录每个 `(i, j)`，`O(mn)`。再观察到第 `i` 行只依赖第 `i - 1` 行和同一行左边一格，可以压成一维。

```python
def is_interleave(s1: str, s2: str, s3: str) -> bool:
    m, n = len(s1), len(s2)
    if m + n != len(s3):                   # 长度不等一票否决
        return False
    # dp[j]：s1 的前 i 个字符与 s2 的前 j 个字符能否交错成 s3 的前 i + j 个字符
    dp = [False] * (n + 1)
    dp[0] = True
    for j in range(1, n + 1):              # i = 0：只能全取自 s2
        dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]
    for i in range(1, m + 1):
        dp[0] = dp[0] and s1[i - 1] == s3[i - 1]       # j = 0：只能全取自 s1
        for j in range(1, n + 1):
            k = i + j - 1                  # 要匹配的是 s3[k]
            dp[j] = (dp[j] and s1[i - 1] == s3[k]) or (dp[j - 1] and s2[j - 1] == s3[k])
    return dp[n]
```

运行：示例 1 → `True`，示例 2 → `False`，`("", "", "")` → `True`，`("", "", "a")` → `False`，`("a", "", "a")` → `True`，`("aa", "ab", "aaba")` → `True`。

**复杂度。** 时间 `O(mn)`；空间 `O(n)`（`n = len(s2)`），满足进阶。

**易错点。**
- 贪心错：`s1 = "aa"`、`s2 = "ab"`、`s3 = "aaba"`，「能取 `s1` 就取」会在第三个字符 `b` 处卡住，输出 `False`；正确答案 `True`（`a` 取自 `s1`，`a` 取自 `s2`，`b` 取自 `s2`，`a` 取自 `s1`）。
- 不先比长度：`("a", "b", "abc")` 会被误判为 `True`，因为 DP 只检查了前两个字符；长度不等时更可能直接越界。
- 滚动数组时每一行都要更新 `dp[0]`：漏掉的话，`("x", "a", "ya")` 会得到 `True`（正确 `False`）。

**追问。**
- 返回一种交错方案：保留二维表，从 `(m, n)` 往回看是 `s1` 还是 `s2` 贡献了 `s3[i+j-1]`。
- 自顶向下：`go(i, j)` 加 `@cache`，递归深度 `m + n <= 200`，不会超限。
- 三个及以上字符串：状态变成 `k` 维下标，复杂度指数增长；通常只做两个。

**同模式。** LC 72 编辑距离、LC 1143 最长公共子序列、LC 115 不同的子序列、LC 44 通配符匹配、LC 10 正则表达式匹配。
