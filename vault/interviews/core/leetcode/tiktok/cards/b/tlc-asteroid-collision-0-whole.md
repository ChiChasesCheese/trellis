## Q
**LC 735 小行星碰撞**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 1 次 · 最近 2022-03-03（CodeTop）

数组 `asteroids` 表示同一行上的小行星：元素绝对值是大小，正数向右移动，负数向左移动，速度相同。两颗小行星相撞时较小的爆炸，大小相同则都爆炸；同向移动的永远不会相撞。返回所有碰撞结束后剩下的小行星。`2 <= asteroids.length <= 10^4`，`-1000 <= asteroids[i] <= 1000`，`asteroids[i] != 0`。例：`[5,10,-5]` → `[5,10]`；`[8,-8]` → `[]`；`[10,2,-5]` → `[10]`；`[3,5,-6,2,-1,4]` → `[-6,2,4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈（stack）存目前还活着的小行星：新来的向左小行星 `a < 0` 只会和栈顶向右的小行星相撞，栈顶更小就弹出并继续撞，等大则同归于尽，栈顶更大则新来者爆炸；其他情况直接入栈。`O(n)`。

**识别。** 「相邻元素相互作用、会相互消除、后来者先和最近的先来者作用」是栈的典型信号。方向用符号编码，只有「左边向右（正）、右边向左（负）」才会相撞，所以判断条件是 `stack[-1] > 0 and a < 0`。一颗大行星可以连续撞毁多颗，所以是 `while` 而不是 `if`。

**推导。** 暴力：反复找相邻的 `(正, 负)` 对并处理，直到没有，每轮 `O(n)`，最多 `O(n)` 轮，`O(n^2)`。浪费：每次碰撞后都从头找。洞察：从左到右处理时，已处理的部分形如「若干向左的，后跟若干向右的」，向左的再也不会被撞（它们左边没有向右的）。新来的向左者只能碰栈顶最近的向右者，撞完看下一个，后进先出，正好是栈。每颗行星入栈一次、出栈至多一次，`O(n)`。

```python
def asteroid_collision(asteroids: list[int]) -> list[int]:
    stack: list[int] = []                   # 栈里是还活着的小行星，从左到右
    for a in asteroids:
        alive = True
        while alive and a < 0 and stack and stack[-1] > 0:   # 只有 向右的栈顶 撞 向左的新来者
            top = stack[-1]
            if top <= -a:
                stack.pop()                 # 栈顶爆炸（等大时两个都炸）
            alive = top < -a                # 新来者只有严格更大才活下来
        if alive:
            stack.append(a)
    return stack
```

运行：`[5,10,-5]` → `[5, 10]`，`[8,-8]` → `[]`，`[10,2,-5]` → `[10]`，`[3,5,-6,2,-1,4]` → `[-6, 2, 4]`，`[-2,-1,1,2]` → `[-2, -1, 1, 2]`，`[1,-1,-1]` → `[-1]`；`5000` 个 `1` 后接 `5000` 个 `-1000` 剩 `5000` 颗。

**复杂度。** 时间 `O(n)`（每个元素至多入栈、出栈各一次）；空间 `O(n)`。

**易错点。**
- 等大时没让新来者同时消失：`[8,-8]` 得到 `[-8]`，正确是 `[]`。
- 用 `if` 代替 `while`：新来者撞一颗就停，`[3,5,-6,2,-1,4]` 得到 `[3, -6, 2, 4]`，正确是 `[-6, 2, 4]`。
- 栈顶向左或新来者向右时不会相撞，不能弹栈；条件里的两个符号判断缺一不可，并且 `stack` 判空要写在 `stack[-1]` 之前。

**追问。**
- 返回幸存者的原下标：栈里存下标，比较时读 `asteroids[stack[-1]]`。
- 流式输入：栈就是全部状态，每来一颗均摊 `O(1)`。
- 规则改成速度与大小有关，或在环上碰撞：不再是单向栈，要用事件时间排序（堆）模拟。
