## Q
**LC 2021 街上最亮的位置**｜Medium · LC TikTok 全时段热度 53/100

一条街上有许多路灯，路灯的坐标由数组 `lights` 给出：`lights[i] = [position, range]` 表示坐标为 `position` 的路灯照亮闭区间 `[position - range, position + range]`。位置 `p` 的亮度等于能照到 `p` 的路灯数量。返回最亮的位置；有多个时返回坐标最小的。`1 <= lights.length <= 10^5`，`-10^8 <= position <= 10^8`，`0 <= range <= 10^8`。例：`[[-3,2],[1,2],[3,3]]` → `-1`（三盏灯照亮 `[-5,-1]`、`[-1,3]`、`[0,6]`，`-1` 被两盏灯照到，`0..3` 也是两盏，取最小的 `-1`）；`[[1,0],[0,1]]` → `1`；`[[1,2]]` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 差分加扫描线：每盏灯在区间左端 `+1`、在右端的**下一格** `-1`；把这些事件按坐标排序后累加，得到每一段的亮度；只在亮度严格增大时更新答案，保证并列时留下坐标最小的。`O(n log n)`。

**识别。** 「哪个点被最多的区间覆盖」是差分 / 扫描线（sweep line）的标准信号。坐标范围达 `±2 * 10^8`，不能开数组，但亮度只在区间端点处变化，所以只处理有事件的坐标（离散化）。「并列取最小」意味着从左往右扫，严格更大才更新。

**推导。** 暴力：对每个整点统计覆盖它的灯，范围太大；只检查端点作为候选，每个候选数一遍覆盖的灯，`O(n^2)`，`n = 10^5` 超时。洞察：区间 `[l, r]` 的加一操作等价于在 `l` 处 `+1`、在 `r + 1` 处 `-1`，累加后得到每点的亮度；亮度最大的值总出现在某个事件坐标上，且是该值最先出现的位置。排序事件坐标，一遍累加即可。

```python
from collections import defaultdict


def brightest_position(lights: list[list[int]]) -> int:
    diff: defaultdict[int, int] = defaultdict(int)   # 差分：在坐标 x 处亮度变化多少
    for pos, rng in lights:
        diff[pos - rng] += 1                     # 灯照亮 [pos-rng, pos+rng]：左端 +1
        diff[pos + rng + 1] -= 1                 # 右端的下一格 -1
    best = cur = 0
    ans = 0
    for x in sorted(diff):                       # 亮度只在有事件的坐标处变化，按坐标从小到大扫
        cur += diff[x]
        if cur > best:                           # 严格大于：并列时保留坐标更小的
            best, ans = cur, x
    return ans
```

**运行。** `[[-3,2],[1,2],[3,3]]` → `-1`；`[[1,0],[0,1]]` → `1`；`[[1,2]]` → `-1`；`[[0,0],[0,0]]` → `0`；`[[5,0],[1,0]]` → `1`；十万盏随机灯约 0.04 秒。

**复杂度。** 时间 `O(n log n)`，主要是对至多 `2n` 个事件坐标排序；空间 `O(n)`。

**易错点。**
- 右端事件放在 `pos + rng` 而不是 `pos + rng + 1`：区间是闭区间，右端点本身还被照亮。`[[1,0],[0,1]]` 会返回 `-1`，正确是 `1`。
- 并列时用 `>=` 更新：取到的是最后一个最亮位置。`[[5,0],[1,0]]` 会返回 `5`，正确是 `1`。
- 同一坐标上多个事件要先合并再判断，否则 `+1` 和 `-1` 的先后顺序会让亮度在中间出现虚假的峰值；用字典按坐标累加就保证了这一点。

**追问。**
- 返回所有最亮的位置（段）：记录最大值出现的区间，直到亮度下降。
- 灯会动态增删：坐标离散化后用线段树或树状数组维护区间加、全局最大。
- 二维（每盏灯照亮一个矩形）：扫描线加线段树，同 LC 850 矩形面积并。
