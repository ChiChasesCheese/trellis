## Q
**LC 416 分割等和子集**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 11 次 · 最近 2026-07-14（国内 CodeTop）

给一个只包含**正整数**的非空数组 `nums`，判断能否把它分成两个子集，使两个子集的元素和相等。`1 <= nums.length <= 200`，`1 <= nums[i] <= 100`。例：`[1,5,11,5]` → `true`（`[1,5,5]` 与 `[11]`）；`[1,2,3,5]` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 转成 0/1 背包（0/1 knapsack）的可行性问题：总和 `S` 是奇数直接 `False`，否则问「能否选出一些数，和恰为 `S/2`」。二维表 `dp[i][j]` 表示只用前 `i` 个数能否凑出和 `j`，基础行 `dp[0][0] = True`，每个数要么不选 `dp[i-1][j]`，要么选 `dp[i-1][j-x]`，答案是 `dp[n][S/2]`。`O(n · S)`。

**识别。** 「分成两部分使和相等」= 「选子集凑出总和的一半」；每个数用与不用 → 0/1 背包。数据范围 `n <= 200`、`nums[i] <= 100`，总和最大 `20000`，目标 `<= 10000`，`O(n · S)` 约 `2 · 10^6`，轻松。

**推导。** 暴力：枚举所有子集，`2^200` → 回溯带记忆化，状态 `(下标, 剩余目标)`，`O(n · S)` → 自底向上把这些状态摆成一张表：行是「考虑了前 `i` 个数」，列是「和 `j`」，`dp[i][j]` 表示能否凑出。基础行 `dp[0][0] = True`（空集的和是 `0`），其余是 `False`；第 `i` 行只依赖第 `i-1` 行：不选 `nums[i-1]`，继承 `dp[i-1][j]`；选它，要求 `j >= x` 且 `dp[i-1][j-x]` 为真。因为读的是上一行，每个数在一行里只用一次。

```python
def can_partition(nums: list[int]) -> bool:
    total = sum(nums)
    if total % 2:
        return False                           # 总和是奇数，不可能平分
    n, half = len(nums), total // 2
    # dp[i][j]：只用前 i 个数，能否凑出和恰好为 j
    dp = [[False] * (half + 1) for _ in range(n + 1)]
    dp[0][0] = True                            # 基础行：一个数都不选，只能凑出 0
    for i in range(1, n + 1):
        x = nums[i - 1]
        for j in range(half + 1):
            dp[i][j] = dp[i - 1][j] or (j >= x and dp[i - 1][j - x])   # 不选第 i 个 / 选第 i 个
    return dp[n][half]                         # 答案格：用全部 n 个数，凑出 half
```

运行：`[1,5,11,5]` → `True`，`[1,2,3,5]` → `False`，`[1]` → `False`，`[2,2]` → `True`，`[100] * 200` → `True`，`[99] * 199 + [100]` → `False`；随机 `200` 个 `1..100` 的数约 `0.02` 秒，`[100] * 200` 约 `0.06` 秒。

**复杂度。** 时间 `O(n · S)`（`n` 行 × `S/2` 列）；空间 `O(n · S)`，最坏约 `200 * 10000 = 2 * 10^6` 个布尔值。

**易错点。**
- 转移读错了行：写成 `dp[i][j - x]`（本行）而不是 `dp[i - 1][j - x]`（上一行），同一个数被重复使用，变成完全背包。`[1,5]` 目标 `3`，本行转移用三个 `1` 凑出 `3`，错答 `True`（正确 `False`）。
- 漏掉总和为奇数的判断：`half = total // 2` 向下取整，`[1,2]` 总和 `3`，`half = 1`，选 `[1]` 就能凑出 `1`，错答 `True`（正确 `False`）。
- 忘记基础行 `dp[0][0] = True`：整张表全是 `False`，`[2,2]` 得到 `False`（正确 `True`）。目标写成 `total / 2`（浮点数）会让 `range` 报错：用 `//`。

**追问。**
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 求两堆最小差（LC 1049 最后一块石头的重量 II）：看最后一行 `dp[n]`，找最接近 `total/2` 的可达和 `j`，差值 `total − 2j`。`[1,5,11,5]` → `0`，`[1,2,3,5]` → `1`。
- 要输出具体分法：整张表已经在手，从 `dp[n][half]` 往回走，若 `dp[i-1][j]` 为假，第 `i` 个数必须选，`j -= nums[i-1]`。
- 用整数当位集（bitset）加速：一整行布尔值存成一个整数的二进制位，每个数相当于整体左移再并入，一次大整数运算替代内层循环。

**同模式。** LC 494 目标和、LC 1049 最后一块石头的重量 II、LC 474 一和零、LC 698 划分为k个相等的子集。
