## Q
**LC 416 分割等和子集**｜Medium · TikTok 高频

给一个只包含**正整数**的非空数组 `nums`，判断能否把它分成两个子集，使两个子集的元素和相等。`1 <= nums.length <= 200`，`1 <= nums[i] <= 100`。例：`[1,5,11,5]` → `true`（`[1,5,5]` 与 `[11]`）；`[1,2,3,5]` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 转成 0/1 背包（0/1 knapsack）的可行性问题：总和 `S` 是奇数直接 `False`，否则问「能否选出一些数，和恰为 `S/2`」。用 Python 的大整数当位集（bitset）：第 `i` 位为 `1` 表示存在子集和为 `i`，每个数 `x` 对应 `bits |= bits << x`。`O(n · S / 64)`。

**识别。** 「分成两部分使和相等」= 「选子集凑出总和的一半」；每个数用与不用 → 0/1 背包。数据范围 `n <= 200`、`nums[i] <= 100`，总和最大 `20000`，目标 `<= 10000`，`O(n · S)` 约 `2 · 10^6`，轻松。

**推导。** 暴力：枚举所有子集，`2^200` → 回溯带记忆化，状态 `(下标, 剩余目标)`，`O(n · S)` → 自底向上 `dp[j]` 表示「能凑出和 `j`」，对每个数倒着更新 `j` 从大到小：`dp[j] |= dp[j − x]`，倒着是为了每个数只用一次 → 再进一步：`dp` 数组本质是 0/1 序列，用一个大整数的二进制位表示，「所有已有和都加上 `x`」就是整体左移 `x` 位，`bits << x`；与原 `bits` 取或表示「选或不选」。右边的 `bits` 是更新前的旧值，天然只用一次，没有倒序的坑。

```python
def can_partition(nums: list[int]) -> bool:
    total = sum(nums)
    if total % 2:
        return False                           # 总和是奇数，不可能平分
    bits = 1                                   # 第 i 位为 1 表示「存在子集和恰好为 i」
    for x in nums:
        bits |= bits << x                      # 每个数选或不选；右边的 bits 是旧值，所以每个数只用一次
    return bool(bits >> (total // 2) & 1)
```

运行：`[1,5,11,5]` → `True`，`[1,2,3,5]` → `False`，`[1]` → `False`，`[2,2]` → `True`，`[100] * 200` → `True`，`[99] * 199 + [100]` → `False`；随机 `200` 个数（和约 `10^4`）耗时不到 `0.001` 秒。

**复杂度。** 时间 `O(n · S / w)`，`w` 为机器字长（大整数移位或运算按字处理）；普通数组 DP 是 `O(n · S)`；空间 `O(S)` 位。

**易错点。**
- 一维数组 DP 正着更新（`j` 从小到大）：同一个数被重复使用，变成完全背包。`[1,5]` 目标 `3`，正着更新会用三个 `1`，错答 `True`（正确 `False`）。倒着更新，或用位集整体移位，才是 0/1。
- 忘记总和为奇数的剪枝：不影响答案但多算一遍。
- 目标写成 `total / 2`（浮点数）：用 `//`。

**追问。**
- 数组 DP 写法：`dp = [True] + [False] * half`，`for x in nums: for j in range(half, x - 1, -1): dp[j] = dp[j] or dp[j - x]`，倒着更新。
- 求两堆最小差（LC 1049 最后一块石头的重量 II）：位集里找最接近 `total/2` 的置位，差值 `total − 2i`。`[1,5,11,5]` → `0`，`[1,2,3,5]` → `1`。
- 要输出具体分法：保存每个数处理后的位集，从后往前回溯，看目标位在加入这个数之前是否就已经存在。

**同模式。** LC 494 目标和、LC 1049 最后一块石头的重量 II、LC 474 一和零、LC 698 划分为k个相等的子集。
