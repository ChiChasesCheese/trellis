## Q
**LC 12 整数转罗马数字**｜Medium · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 19 次 · 最近 2026-07-08（国内 CodeTop）

给整数 `num`，把它转成罗马数字。七个符号：`I`=1、`V`=5、`X`=10、`L`=50、`C`=100、`D`=500、`M`=1000。规则：按十进制位从高到低转换；4 和 9 用减法形式，且只允许 `IV`（4）、`IX`（9）、`XL`（40）、`XC`（90）、`CD`（400）、`CM`（900）；只有 `I`、`X`、`C`、`M` 可以连续出现至多 3 次，`V`、`L`、`D` 不能重复。`1 <= num <= 3999`。例：`3749` → `"MMMDCCXLIX"`（3000 + 700 + 40 + 9），`58` → `"LVIII"`，`1994` → `"MCMXCIV"`（1000 + 900 + 90 + 4）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把六个减法形式也当成「符号」，和七个基本符号一起排成 13 项、按面值从大到小的 `(值, 符号)` 表；对每一项用 `divmod` 取出能放几个，重复拼接符号。表驱动的贪心，`O(1)`。

**识别。** 「按固定符号表做进制转换」+「每一步取能减去的最大符号」是贪心（greedy）的标准信号。`num <= 3999` 时输出至多 15 个字符，复杂度不是考点；考点是把「4 和 9 的特殊规则」建模成数据，而不是写一堆 `if`。

**推导。** 朴素写法：逐个十进制位处理，每位按 0–3、4、5–8、9 四种情况分支，千、百、十、个位各自换一套符号，代码又长又容易错。观察：四个位上的规则完全相同，只是符号不同；而 `IV`、`IX`、`XL`、`XC`、`CD`、`CM` 本质上只是六个多出来的符号。把它们和基本符号放进同一张降序表，「选能减去的最大符号」就是纯贪心，没有特殊分支。每个面值取 `count, num = divmod(num, value)` 个，再拼 `symbol * count`。

```python
ROMAN: list[tuple[int, str]] = [
    (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
    (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
    (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
]                                          # 必须按面值从大到小排列


def int_to_roman(num: int) -> str:
    parts: list[str] = []
    for value, symbol in ROMAN:
        count, num = divmod(num, value)    # 这个面值能放几个，以及剩余多少
        parts.append(symbol * count)       # count 为 0 时是空串，不需要 if
    return "".join(parts)
```

运行：`3749` → `"MMMDCCXLIX"`，`58` → `"LVIII"`，`1994` → `"MCMXCIV"`，`1` → `"I"`，`4` → `"IV"`，`3888` → `"MMMDCCCLXXXVIII"`，`3999` → `"MMMCMXCIX"`。

**复杂度。** 时间 `O(1)`：固定 13 个面值，每个一次 `divmod`，输出至多 15 个字符；空间 `O(1)`。

**易错点。**
- 表里必须有 `900/400/90/40/9/4` 并按面值**降序**。只放七个基本符号，`4` 会写成 `IIII`（正确 `IV`）；把 `(4, "IV")` 排到 `(5, "V")` 前面，`8` 会变成 `IVIV`（正确 `VIII`）。
- `49` 不是 `IL`：减法形式只有六个，`49` = 40 + 9 = `XLIX`。表里没有 `IL`，贪心自然不会产生它。
- 用 `divmod` 一次得到商和余数；`symbol * count` 在 `count = 0` 时返回空串，不要再写 `if count:`。

**追问。**
- 反过来，罗马数字转整数（LC 13）：从左到右，当前符号比右邻小就减，否则加。
- 不用大表：按十进制位拆开，四张 0–9 的表（千、百、十、个位）各查一次，结果相同。
- 范围放大到 3999 以上：传统写法要上划线记号，题目范围外；只需把 `M` 重复，即 `"M" * (num // 1000)` 加上余下部分。

**同模式。** LC 13 罗马数字转整数、LC 273 整数转英文单词、LC 168 Excel 表列名称、LC 504 七进制数。
