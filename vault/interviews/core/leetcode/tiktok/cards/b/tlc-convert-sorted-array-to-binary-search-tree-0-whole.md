## Q
**LC 108 将有序数组转换为二叉搜索树**｜Easy · 字节 高频

给一个按**升序**排列的整数数组 `nums`，把它转换成一棵**高度平衡**的二叉搜索树（每个结点的左右子树高度差不超过 `1`）。`1 <= nums.length <= 10^4`，`-10^4 <= nums[i] <= 10^4`，`nums` 严格递增。答案不唯一，任何合法的平衡 BST 都可以。例：`nums = [-10,-3,0,5,9]` → `[0,-3,9,-10,null,5]`（`[0,-10,5,null,-3,null,9]` 也正确）；`nums = [1,3]` → `[3,1]`（`[1,null,3]` 也正确）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 取区间中点作根，左半部分递归建左子树，右半部分递归建右子树；用下标区间 `[lo, hi)` 传参而不是切片。每个元素恰好建一次结点，`O(n)`。

**识别。** 「有序数组 / 有序序列 → 二叉搜索树」要想到：BST 的中序遍历就是升序序列，所以数组本身已经是某棵 BST 的中序。「高度平衡」意味着左右子树结点数尽量相等，根就应该是中间那个元素，子问题和原问题同构 → 分治。与 LC 109（有序链表转 BST）同族。`n <= 10^4`，递归深度只有 `log n`。

**推导。** 暴力：按数组顺序逐个插入 BST。输入有序，每次都插在最右边，树退化成一条链，高度 `n`，不平衡（插入还要 `O(n^2)`）。洞察：根选哪个元素决定了左右子树各含多少结点；左边所有元素必须进左子树，右边所有进右子树（BST 性质）。为了平衡，让两边个数最多差 `1`，也就是取中点；两边再各自是同样的问题。实现上用下标 `[lo, hi)`：切片 `nums[:mid]` 每层都复制，总共 `O(n log n)`。

```python
def sorted_array_to_bst(nums: list[int]) -> TreeNode | None:
    def build(lo: int, hi: int) -> TreeNode | None:      # 用 nums[lo:hi]（左闭右开）建树
        if lo >= hi:
            return None
        mid = (lo + hi) // 2               # 中点当根，左右两半个数最多差 1
        return TreeNode(nums[mid], build(lo, mid), build(mid + 1, hi))
    return build(0, len(nums))
```

运行：`[-10,-3,0,5,9]` → 层序 `[0,-3,9,-10,None,5]`；`[1,3]` → `[3,1]`；`[1]` → `[1]`；`[1,2,3,4,5,6]` → `[4,2,6,1,3,5]`。

**复杂度。** 时间 `O(n)`：每个下标建一个结点；空间 `O(log n)`（递归栈，树高）。

**易错点。**
- 逐个插入：`[1,2,3,4,5,6,7]` 得到高度 `7` 的链，不平衡；平衡树高度应是 `3`。
- 用切片递归（`build(nums[:mid])`）：结果对，但每层复制，总时间 `O(n log n)`，空间也更大。
- 区间为空时必须返回 `None`；偶数个元素取左中还是右中都合法，答案不唯一，不要和示例的形状死磕。

**追问。**
- 有序链表转 BST（LC 109）：链表不能随机访问，先数长度，再按中序位置递归，用一个全局指针顺着链表推进，`O(n)`。
- 要求验证结果平衡：后序递归返回高度，发现高度差大于 `1` 就记失败。
- 数据很大、怕递归：树高只有 `log n`，递归没有问题；非递归写法用显式栈保存 `(lo, hi, 父结点, 方向)`。
