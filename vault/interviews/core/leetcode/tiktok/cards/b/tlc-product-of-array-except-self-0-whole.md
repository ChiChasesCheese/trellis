## Q
**LC 238 除了自身以外数组的乘积**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-06（面试记录）

给整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。题目保证任意前缀与后缀的乘积都在 32 位整数范围内。**不能使用除法**，要求 `O(n)` 时间。`2 <= nums.length <= 10^5`，`-30 <= nums[i] <= 30`。进阶：额外空间 `O(1)`（输出数组不算）。例：`[1,2,3,4]` → `[24,12,8,6]`；`[-1,1,0,-3,3]` → `[0,0,9,0,0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** `answer[i]` = 左边所有元素之积 × 右边所有元素之积：第一趟从左往右，把「左积」直接写进 `answer`；第二趟从右往左，用一个变量滚动「右积」乘进去。两趟、`O(n)` 时间、`O(1)` 额外空间。

**识别。** 「除自身以外的全体之积」+「禁止除法」→ 把「全体之积 ÷ 自己」换成「前缀积 × 后缀积」。数组里可能有 `0`，除法本来就不安全；`n = 10^5` 要求线性。这是「前缀 / 后缀分解」的标准信号。

**推导。** 暴力：每个位置把其余元素重新乘一遍，`O(n^2)` → 相邻两个位置的「其余之积」共享几乎所有因子，重复劳动 → 设 `L[i]` 为 `nums[0..i-1]` 之积，`R[i]` 为 `nums[i+1..]` 之积，`answer[i] = L[i] * R[i]`，两个辅助数组 `O(n)` 空间 → `L` 可以直接存进 `answer`，`R` 在倒序扫描时只需一个滚动变量，空间降到 `O(1)`。

```python
def product_except_self(nums: list[int]) -> list[int]:
    n = len(nums)
    ans = [1] * n
    left = 1
    for i in range(n):                 # 第一趟：ans[i] 存 nums[0..i-1] 的乘积
        ans[i] = left
        left *= nums[i]
    right = 1
    for i in range(n - 1, -1, -1):     # 第二趟：再乘上 nums[i+1..] 的乘积
        ans[i] *= right
        right *= nums[i]
    return ans
```

运行：`[1,2,3,4]` → `[24, 12, 8, 6]`；`[-1,1,0,-3,3]` → `[0, 0, 9, 0, 0]`；`[0,0]` → `[0, 0]`；`[2,3]` → `[3, 2]`。

**复杂度。** 时间 `O(n)`（两趟）；额外空间 `O(1)`，只有 `left`、`right` 两个变量，输出数组不计。

**易错点。**
- 先更新再使用：第二趟写成 `right *= nums[i]; ans[i] *= right`，会把 `nums[i]` 自己也乘进去，`[1,2,3,4]` 输出 `[24, 24, 24, 24]`；必须「先乘后更新」。
- 用总积除以自身：`[-1,1,0,-3,3]` 里有 `0`，`total // x` 直接 `ZeroDivisionError`；题目也明令禁止除法。
- 第一趟同样要先写 `ans[i] = left` 再 `left *= nums[i]`，顺序反了 `ans[i]` 就包含自己。

**追问。**
- 允许除法时怎么处理 `0`：数零的个数。`0` 个零，`total // x`；恰好 `1` 个零，只有零所在位置是其余非零数之积，其他位置为 `0`；`>= 2` 个零，全为 `0`。
- 乘积会溢出怎么办：Python 大整数不溢出；用 `int32` 的语言要按题目保证做，或者改对数 / 取模。
- 想要更直观的写法：用 `itertools.accumulate(..., operator.mul)` 分别算出前缀积与后缀积再 `zip` 相乘，代价是 `O(n)` 额外空间。
