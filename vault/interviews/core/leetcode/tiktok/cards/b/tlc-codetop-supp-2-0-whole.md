## Q
**补充题 2 圆环回原点问题**｜Medium · CodeTop 国内累计 35 次 · 最近 2025-08-18（国内 CodeTop）

圆环上有 `n` 个点，按顺时针依次编号 `0, 1, …, n - 1`（`n - 1` 号点与 `0` 号点相邻）。小明从 `0` 号点出发，每一步只能走到相邻的点（顺时针或逆时针各一种走法）。求**恰好走 `k` 步后回到 `0` 号点**的方案数，对 `10^9 + 7` 取模。`3 <= n <= 1000`，`0 <= k <= 1000`。例：`n = 3, k = 2` → `2`（`0→1→0`、`0→2→0`）；`n = 5, k = 5` → `2`（顺时针走一圈、逆时针走一圈）；`n = 5, k = 3` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 动态规划：`ways[i]` 表示当前走了若干步后停在 `i` 号点的方案数；每走一步，停在 `i` 的方案数等于上一步停在 `i - 1`（顺时针走来）与 `i + 1`（逆时针走来）的方案数之和，下标对 `n` 取模表示首尾相接；走 `k` 步后答案是 `ways[0]`。`O(nk)` 时间，`O(n)` 空间。

**识别。** 「环 + 固定步数 + 数方案」是 `(步数, 位置)` 状态 DP 的信号：每步只有两种选择，到达同一个 `(步数, 位置)` 的走法，后续完全一样，可以合并计数。环形用下标取模处理。`n, k <= 1000`，`O(nk) = 10^6`。

**推导。** 暴力：DFS 枚举 `2^k` 种走法，`k = 1000` 不可行。洞察：状态只有 `k * n` 个，每个状态的转移来源只有两个邻居。滚动数组：第 `s + 1` 步的结果只依赖第 `s` 步，用一个新列表整体替换旧列表即可。

```python
MOD = 10**9 + 7


def ring_ways(n: int, k: int) -> int:
    ways = [0] * n                               # ways[i]：当前走了若干步后停在 i 号点的方案数
    ways[0] = 1                                  # 起点：0 号点，0 步
    for _ in range(k):
        # 下一步停在 i，只能从 i-1（顺时针走来）或 i+1（逆时针走来）；下标取模就是"首尾相接"
        ways = [(ways[i - 1] + ways[(i + 1) % n]) % MOD for i in range(n)]
    return ways[0]
```

**运行。** `(3, 2)` → `2`；`(4, 2)` → `2`；`(5, 3)` → `0`；`(5, 5)` → `2`；`(3, 0)` → `1`；`(1000, 1000)` → `159835831`。

**复杂度。** 时间 `O(nk)`：共 `k` 步，每步更新 `n` 个位置；空间 `O(n)`：只保留当前一步。

**易错点。**
- 原地更新：`for i in range(n): ways[i] = ways[i-1] + ways[(i+1)%n]` 会让同一步里已经更新过的值被后面的下标读到，`(3, 2)` 得 `0`，正确是 `2`。必须用列表推导式一次产生新列表。
- 下标 `i - 1` 在 `i = 0` 时是 `-1`：Python 的负下标恰好指向最后一个点，写法正确；C++ / Java 里要写 `(i - 1 + n) % n`。
- `k = 0` 时答案是 `1`（已经在原点），不要在 `k` 为 `0` 时提前返回 `0`。

**追问。**
- `k` 到 `10^9`：用矩阵快速幂 `O(n^3 log k)`，或用循环卷积做多项式快速幂 `O(n^2 log k)`。
- 闭式：恰好走 `k` 步，其中 `j` 步顺时针，位移是 `2j - k`，回到原点当且仅当 `(2j - k) % n == 0`，答案是 `Σ C(k, j)`，对满足条件的 `j` 求和，`O(k)`。
- 允许原地不动：每步有三种选择，转移多一项 `ways[i]`。

**同模式。** LC 70 爬楼梯、LC 62 不同路径、LC 576 出界的路径数、LC 935 骑士拨号器、LC 688 骑士在棋盘上的概率。
