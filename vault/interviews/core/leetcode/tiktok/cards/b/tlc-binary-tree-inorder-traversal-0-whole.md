## Q
**LC 94 二叉树的中序遍历**｜Easy · 字节高频

给二叉树的根结点 `root`，返回它的**中序**（左、根、右）遍历结果。树中结点数在 `[0, 100]`，`-100 <= Node.val <= 100`。进阶：递归算法很简单，能用迭代完成吗？例：`root = [1,null,2,3]` → `[1,3,2]`；`root = []` → `[]`；`root = [1]` → `[1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用显式栈模拟递归：从当前结点一路向左把沿途结点压栈，到头后弹出一个结点并访问它，然后转向它的右子树，重复直到栈空且没有当前结点。`O(n)` 时间，`O(h)` 空间，`h` 是树高。

**识别。** 中序遍历是树的基础；递归三行即可，进阶要求迭代，本质是「自己维护调用栈」。「访问顺序是左 → 根 → 右」意味着一个结点要等它的整个左子树处理完才轮到自己，所以必须把它先存起来（压栈）。

**推导。** 暴力（递归）：`inorder(left)`、访问、`inorder(right)`，简洁，但递归深度等于树高，退化成链的树会让递归栈很深（结点数更大时在 Python 里 `RecursionError`）。迭代的洞察：递归做的事情就是「沿左链下潜，回来时访问，再转右」，把下潜时经过的结点放进显式栈，回溯时弹出就对应递归的返回。每个结点入栈一次、出栈一次，所以 `O(n)`。

```python
def inorder_traversal(root: TreeNode | None) -> list[int]:
    result: list[int] = []
    stack: list[TreeNode] = []
    node = root
    while node or stack:
        while node:                    # 一路向左，沿途结点都等着“左子树完成后”再访问
            stack.append(node)
            node = node.left
        node = stack.pop()             # 最左的结点：左子树已处理完
        result.append(node.val)        # 访问自己
        node = node.right              # 然后处理右子树
    return result
```

运行：`[1,null,2,3]` → `[1, 3, 2]`，`[]` → `[]`，`[1]` → `[1]`；`10^4` 个结点的左斜链（远超题目上限 `100`）→ 长度 `10000`，没有递归溢出。

**复杂度。** 时间 `O(n)`；空间 `O(h)`：栈里最多存一条从根往下的路径，链状树为 `O(n)`。

**易错点。**
- 弹出并访问之后忘了转向右子树（`node = node.right`），或者写成 `node = None`：`[1,null,2,3]` 只会得到 `[1]`，正确是 `[1, 3, 2]`。
- 循环条件只写 `while stack`：根结点入栈前栈是空的，循环根本进不去；要写 `while node or stack`，两者任一非空都继续。
- 把访问放在压栈时：那是前序（根、左、右），结果顺序不同。

**追问。**
- `O(1)` 额外空间：莫里斯遍历（Morris traversal）。临时把「左子树最右结点」的右指针指向当前结点，用线索代替栈；第二次回到该结点时说明左子树走完，拆线并访问。每条边最多走常数次，仍是 `O(n)`。
- 前序和后序：前序在压栈时访问；后序可以用「根、右、左」的前序再整体反转。
- 做成惰性迭代器（`yield`）：同样的循环，把 `result.append` 换成 `yield`，调用方按需取，适合只要前 `k` 个（LC 230）。

**同模式。** LC 144 前序遍历、LC 145 后序遍历、LC 98 验证二叉搜索树、LC 230 BST 中第 K 小的元素、LC 173 二叉搜索树迭代器。
