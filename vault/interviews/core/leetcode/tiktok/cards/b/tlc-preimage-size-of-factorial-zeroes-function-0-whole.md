## Q
**LC 793 阶乘函数后 K 个零**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-05-07（CodeTop）

设 `f(x)` 是 `x!` 末尾 `0` 的个数（`x! = 1 * 2 * 3 * ... * x`，`0! = 1`）。例如 `f(3) = 0`（`3! = 6`），`f(11) = 2`（`11! = 39916800`）。给定 `k`，返回满足 `f(x) = k` 的**非负整数 `x` 的个数**。`0 <= k <= 10^9`。例：`k = 0` → `5`（`0!, 1!, 2!, 3!, 4!` 末尾都没有 `0`）；`k = 5` → `0`（没有任何 `x!` 末尾恰好 `5` 个 `0`）；`k = 3` → `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 末尾零的个数等于 `x!` 里因子 `5` 的个数 `f(x) = x//5 + x//25 + x//125 + ...`，它随 `x` 单调不减；`f(x) = k` 的 `x` 构成一段连续区间，个数就是「第一个使 `f(x) >= k + 1` 的 `x`」减「第一个使 `f(x) >= k` 的 `x`」，各用一次二分。答案只可能是 `0` 或 `5`。`O(log^2 k)`。

**识别。** 「求满足 `f(x) = k` 的 `x` 的个数」，`f` 单调不减、`k` 高达 `10^9` → 不能线性枚举 `x`（`x` 约 `4 * 10^9`），要对 `x` 二分；「等于 `k` 的个数」转化成两个「第一个 `>=`」之差，是单调函数计数的标准手法。

**推导。** 暴力：从 `x = 0` 起逐个算 `f(x)` 并计数，`x` 到 `4 * 10^9` 级别，超时 → 先写出 `f(x)`：末尾零由因子 `2` 和 `5` 配对产生，`2` 总比 `5` 多，所以只数 `5`，每一轮除以 `5`，`O(log x)` → `f` 单调不减，满足 `f(x) = k` 的 `x` 是一段连续区间 `[lo, hi)`，其中 `lo` 是第一个 `f(x) >= k` 的位置，`hi` 是第一个 `f(x) >= k + 1` 的位置，个数 `hi - lo` → 两次二分，上界取 `5 * (target + 1)`（因为 `f(5m) >= m`）。

```python
def preimage_size_fzf(k: int) -> int:
    def zeros(x: int) -> int:                   # x! 末尾 0 的个数 = x! 里因子 5 的个数 = x//5 + x//25 + ...
        count = 0
        while x:
            x //= 5
            count += x
        return count

    def first_reaching(target: int) -> int:     # 最小的 x，使得 zeros(x) >= target
        lo, hi = 0, 5 * (target + 1)            # zeros(5 * (target + 1)) >= target + 1，上界一定够
        while lo < hi:
            mid = (lo + hi) // 2
            if zeros(mid) >= target:
                hi = mid
            else:
                lo = mid + 1
        return lo

    return first_reaching(k + 1) - first_reaching(k)    # zeros 单调不减：等于 k 的 x 是一段连续区间
```

运行：`k = 0` → `5`，`k = 5` → `0`，`k = 3` → `5`，`k = 6` → `5`（`25..29`），`k = 30` → `0`，`k = 31` → `5`，`k = 10^9` → `5`。

**复杂度。** 时间 `O(log k * log k)`：每次二分约 `33` 轮，每轮算 `f` 要约 `14` 次除法；空间 `O(1)`。

**易错点。**
- `f` 只数 `x // 5`，漏掉 `25`、`125` 的多重因子：`k = 5` 会返回 `5`（`x // 5` 在 `25..29` 恰好是 `5`），正确是 `0`，因为 `f(25) = 6`，没有 `x` 使 `f(x) = 5`。
- 二分下界取 `1`（以为 `0!` 无关）：`k = 0` 的答案包含 `0!`，会得到 `4`，正确是 `5`。
- 上界取得太小（如 `4 * target`）：`k = 0` 时第一个 `f(x) >= 1` 的是 `x = 5`，上界 `4` 到不了，返回 `4`，差值错成 `4`；`5 * (target + 1)` 一定够。

**追问。**
- 为什么答案只有 `0` 和 `5`：`f` 只在 `5` 的倍数处增长，所以相同的 `f` 值恰占连续 `5` 个 `x`；若某个值被跳过（`f` 一次增加 `>= 2`），个数就是 `0`。因此也可以只判断存在性，存在就返回 `5`。
- 找出这 `5` 个 `x`：就是 `range(first_reaching(k), first_reaching(k + 1))`。
- 不用二分的 `O(log k)` 数学解法：见另一种解法。
