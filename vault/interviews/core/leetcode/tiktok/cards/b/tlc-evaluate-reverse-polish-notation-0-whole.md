## Q
**LC 150 逆波兰表达式求值**｜Medium · CodeTop 国内累计 5 次 · 最近 2026-05-19（国内 CodeTop）

给字符串数组 `tokens`，它是一个逆波兰表示法（后缀表达式，reverse Polish notation：运算符写在两个操作数之后）的算术表达式，求它的整数值。运算符只有 `+ - * /`；整数除法**向零截断**；不会除以零；输入一定合法；答案和所有中间结果都在 32 位整数范围内。`1 <= tokens.length <= 10^4`，`tokens[i]` 是运算符或 `[-200, 200]` 内的整数。例：`["2","1","+","3","*"]` → `9`（`(2 + 1) * 3`），`["4","13","5","/","+"]` → `6`（`4 + 13 / 5`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一个栈：数字入栈；遇到运算符弹出两个数，**先弹出的是右操作数**，算完把结果压回去；最后栈里唯一的数就是答案。`O(n)`。

**识别。** 后缀表达式的定义就是「运算符作用于它前面最近的两个值」，「最近的」意味着后进先出（LIFO），所以是栈。没有括号和优先级要处理，那些在转成后缀时已经消掉了。

**推导。** 朴素做法：反复在数组里找第一个运算符，把它和前两个数替换成结果，每次替换 `O(n)`，共 `O(n^2)` → 浪费在于每次都从头找、整体搬移 → 从左往右扫一遍，把尚未用掉的数放在栈里，运算符一出现，它要的两个数正好在栈顶 → 每个 token 进出栈一次，`O(n)`。

```python
from operator import add, mul, sub


def _div(a: int, b: int) -> int:
    q = abs(a) // abs(b)                   # 先对绝对值做整除，再补符号：结果向零截断
    return q if (a < 0) == (b < 0) else -q


def eval_rpn(tokens: list[str]) -> int:
    ops = {"+": add, "-": sub, "*": mul, "/": _div}
    stack: list[int] = []
    for tok in tokens:
        if tok in ops:
            b = stack.pop()                # 先弹出的是右操作数
            a = stack.pop()
            stack.append(ops[tok](a, b))
        else:
            stack.append(int(tok))         # "-11" 不在 ops 里，会走到这里
    return stack[0]
```

运行：`["2","1","+","3","*"]` → `9`，`["4","13","5","/","+"]` → `6`，`["10","6","9","3","+","-11","*","/","*","17","+","5","+"]` → `22`，`["-7","2","/"]` → `-3`，`["5"]` → `5`，`["3","-4","-"]` → `7`。

**复杂度。** 时间 `O(n)`：每个 token 处理一次，运算 `O(1)`；空间 `O(n)`：最坏所有数字都在运算符之前。

**易错点。**
- 用 `a // b`：Python 的 `//` 向下取整，`-7 // 2 == -4`，而题目要 `-3`。第三个例子里 `6 / -132` 会变成 `-1`，整体错成 `12`（正确 `22`）。
- 弹出顺序写反成 `op(b, a)`：减法和除法出错，`["4","13","5","/","+"]` 会算成 `4 + 5 / 13 = 4`（正确 `6`）。
- 用 `tok.isdigit()` 判断数字：`"-11"` 不是纯数字，会被当成运算符；判断「是不是运算符」才不会漏负数。

**追问。**
- 给的是中缀表达式（LC 224 / 227 基本计算器）：用调度场算法（shunting-yard）按优先级转成后缀，或用两个栈（数和运算符）边扫边算。
- 支持一元负号或更多运算符：运算符表里登记元数（arity），弹出相应个数的操作数。
- 构造表达式树：栈里放节点而不是数，运算符弹出两个子节点组成新节点，最后栈顶是根。

**同模式。** LC 224 基本计算器、LC 227 基本计算器 II、LC 20 有效的括号、LC 394 字符串解码。
