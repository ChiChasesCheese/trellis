## Q
**面试题 16.07 最大数值**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-06-08（CodeTop）

写一个方法，找出两个整数 `a` 和 `b` 中较大的那个，**不得使用 if-else 或其他比较运算符**（`<`、`>`、`==` 等，也不能调用 `max`）。例：`a = 1, b = 2` → `2`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 比较大小的本质是看 `a - b` 的符号：用位运算取出符号位 `neg`（`a < b` 时为 1，否则为 0），答案是 `a - neg * (a - b)`——`neg = 1` 时等于 `b`，`neg = 0` 时等于 `a`。无分支，`O(1)`。

**识别。** 「禁止比较和分支」的信号是：把比较换成**算术或位运算**。大小关系藏在 `a - b` 的符号里；符号可以变成 0/1 开关，再用乘法做无分支选择（branchless select）。Python 整数没有溢出，不必像 C++/Java 那样担心 `a - b` 越界，但右移的位数要足够大。

**推导。** 直接 `max(a, b)` 或 `a if a > b else b` 都被禁。第一条路：`max = (a + b + |a - b|) / 2`。`abs` 严格说不是比较运算符，但在面试里是灰色地带，而且 `/` 会得到浮点数，大数精度丢失，必须用 `//`。第二条路：取符号位。`diff = a - b`，负数在补码里的高位全是 1；Python 对负数的右移是算术右移，`diff >> diff.bit_length()` 在 `diff < 0` 时为 `-1`、否则为 `0`（`bit_length()` 位足以容纳 `|diff|`），再 `& 1` 得到 0/1 的 `neg`。最后 `a - neg * diff` 完成选择。

```python
def maximum(a: int, b: int) -> int:
    diff = a - b
    neg = (diff >> diff.bit_length()) & 1    # a < b 时 diff 为负，右移后全是 1，& 1 得 1；否则得 0
    return a - neg * diff                    # neg = 1：a - (a - b) = b；neg = 0：a
```

运行：`1, 2` → `2`，`2, 1` → `2`，`5, 5` → `5`，`-3, -7` → `-3`，`2147483647, -1` → `2147483647`，`-2147483648, 2147483647` → `2147483647`，`10**30, -10**30` → `1000000000000000000000000000000`。

**复杂度。** 时间 `O(1)`（对大整数按位数线性）；空间 `O(1)`。

**易错点。**
- 把 32 位习惯写死成 `>> 31`：当 `|a - b| >= 2^31` 时符号判断错，`maximum(2147483647, -1)` 得到 `-1`（正确 `2147483647`）。用 `diff.bit_length()` 对任意大小的整数都对。
- 写成 `a * (a > b) + b * (a <= b)`：结果对，但用了比较运算符，违反题目要求。
- 绝对值公式 `(a + b + abs(a - b)) / 2` 用 `/` 得到浮点数：`maximum(2**62 + 1, 0)` 得到的是浮点数，约 `4.6 * 10^18`，末位的 `+ 1` 已经丢失；必须用 `//`。

**追问。**
- 三个数或一个数组的最大值：两两归约，`functools.reduce(maximum, nums)`。
- 最小值：`a + b - maximum(a, b)`。
- C++/Java 里 `a - b` 可能溢出：先转 `long`，或者分别取 `a`、`b` 的符号位，同号用差、异号直接看符号。

**同模式。** LC 371 两整数之和、LC 29 两数相除、LC 136 只出现一次的数字、LC 190 颠倒二进制位。
