## Q
**LCP 09 最小跳跃次数**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-01-29（CodeTop）

一排 `N` 个弹簧，编号 `0` 到 `N-1`，小球开始在 `0` 号。在 `i` 号按一次弹簧，小球可以**向右**弹到 `i + jump[i]`（`>= N` 表示弹出机器），或者**向左**弹到 `0..i-1` 中**任意**一个弹簧（在 `0` 号时不能向左）。求把小球弹出机器（向右越过 `N-1`）最少要按几次。`1 <= jump.length <= 10^6`，`1 <= jump[i] <= 10000`。例：`jump = [2,5,1,1,1,1]` → `3`，路线 `0 → 2 → 1 → 6`（出界）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 每按一次代价都是 1，求最少次数就是在无权图上做按层的广度优先搜索（BFS）；向左的边有 `O(n^2)` 条，但它们总是覆盖一段前缀 `0..i-1`，所以用一个只增不减的指针 `lo` 记录「前缀已经扫到哪」，每个下标只被向左扫到一次，整体 `O(n)`。

**识别。** 「最少次数 + 每步代价相同」是 BFS 的信号。不能从左到右做 DP：向左跳会回到更小的下标，状态之间有回边，没有固定的计算顺序。`n` 到 `10^6`，图的边数却可达 `n^2/2`，所以关键是**不显式枚举向左的边**。

**推导。** 直接 BFS：从 `i` 出发枚举 `0..i-1` 和 `i + jump[i]`，边数 `O(n^2)`，`n = 10^6` 时不可行。浪费在于同一段前缀被反复扫描：一旦 `i` 在第 `d` 层出队，`0..i-1` 都能在第 `d + 1` 层到达，此后任何 `i' > i` 再扫这段前缀都不会更早。于是维护 `lo`：`0..lo-1` 都已经入过队，每次只扫 `lo..i-1` 并推进 `lo`。每个下标入队一次，`lo` 总共走 `n` 步。

```python
def minimum_jump(jump: list[int]) -> int:
    n = len(jump)
    seen = [False] * n
    seen[0] = True
    frontier, lo, steps = [0], 1, 0      # lo：下标 < lo 的弹簧都已经入队过
    while frontier:
        steps += 1                       # 这一层的每个点再按一次
        nxt: list[int] = []
        for i in frontier:
            j = i + jump[i]
            if j >= n:                   # 向右弹出了机器
                return steps
            if not seen[j]:
                seen[j] = True
                nxt.append(j)
            while lo < i:                # 向左能到 0..i-1，只扫还没扫过的那一段
                if not seen[lo]:
                    seen[lo] = True
                    nxt.append(lo)
                lo += 1
        frontier = nxt
    return -1                            # 到不了这里：一直向右弹总能出界
```

运行：`[2,5,1,1,1,1]` → `3`（`0 → 2 → 1 → 出界`），`[1]` → `1`，`[4,1,1,1]` → `1`，`[3,1,1,1]` → `2`，`[1,1,1,1]` → `4`；`10^6` 个 `1` → `1000000`。

**复杂度。** 时间 `O(n)`：每个下标最多入队一次；`lo` 只增不减，向左的扫描总共 `n` 步。空间 `O(n)`：`seen` 和队列。

**易错点。**
- 只往右跳：`[2,5,1,1,1,1]` 会得 `5`（`0 → 2 → 3 → 4 → 5 → 出界`），正确是 `3`。
- 每个点都把 `range(i)` 整段扫一遍：结果对，但 `10^6` 个 `1` 时要扫约 `5 × 10^11` 次，超时。
- 在出队时才标记已访问：同一下标会被多次加入下一层，层数正确但重复工作成倍增加。

**追问。**
- 输出路线：入队时记 `parent[j] = i`，出界时沿 `parent` 回溯。
- 向左只能跳到 `[i - d, i - 1]`：区间不再是前缀，单个 `lo` 不够，用并查集（union-find）「跳过已访问」指针，见另一种解法。
- 向左免费、向右代价 1：代价只有 0 和 1，改用双端队列的 0-1 BFS。
