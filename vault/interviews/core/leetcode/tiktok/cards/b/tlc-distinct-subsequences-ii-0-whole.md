## Q
**LC 940 不同的子序列 II**｜Hard · CodeTop 国内累计 2 次 · 最近 2026-04-02（国内 CodeTop）

给字符串 `s`，求 `s` 的**不同非空子序列**的个数，结果对 `10^9 + 7` 取余。子序列是从原字符串删去一些（也可以不删）字符、不改变剩余字符相对顺序得到的新字符串，例如 `"ace"` 是 `"abcde"` 的子序列，`"aec"` 不是。`1 <= s.length <= 2000`，`s` 仅由小写英文字母组成。例：`"abc"` → `7`（`a, b, c, ab, ac, bc, abc`）；`"aba"` → `6`（`a, b, ab, ba, aa, aba`）；`"aaa"` → `3`（`a, aa, aaa`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** `dp[i]` 是 `s` 前 `i` 个字符的不同子序列个数（含空串）：新字符让每个旧子序列「接 / 不接」翻倍，`dp[i] = 2 * dp[i - 1]`；若这个字符以前在位置 `j` 出现过，接出来的串里有一批在位置 `j` 就造过了，数量正好是 `dp[j - 1]`，要减掉。答案是 `dp[n] - 1`。`O(n)`。

**识别。** 「**不同**的子序列」+「个数」+「取模」是子序列计数 DP。「不同」是难点：`2^n` 个选法里有大量选法产生相同的字符串，必须去重。`n = 2000` 允许 `O(n^2)`，但存在 `O(n)` 的递推。

**推导。** 暴力：枚举 `2^n` 个子序列放进集合，`n` 只能到 20 左右。第一步：若字符两两不同，每多一个字符，所有旧子序列（含空串）各有「接 / 不接」两种，`dp[i] = 2 * dp[i - 1]`。重复从哪来：设 `s[i]` 这个字符上一次出现在位置 `j`。在位置 `j`，已经把 `s[:j - 1]` 的每个子序列（含空串）后面接上这个字符造过一遍；现在在位置 `i` 又对它们接一遍，造出同样的串，重复数恰好是 `dp[j - 1]`。所以 `dp[i] = 2 * dp[i - 1] - dp[j - 1]`。最后去掉空串。

```python
def distinct_subseq_ii(s: str) -> int:
    MOD = 10 ** 9 + 7
    n = len(s)
    dp = [1] * (n + 1)              # dp[i]：s[:i] 的不同子序列个数，含空串
    last: dict[str, int] = {}       # 字符 -> 它上一次出现的位置（从 1 开始）
    for i, ch in enumerate(s, 1):
        dp[i] = 2 * dp[i - 1] % MOD                 # 每个旧子序列：不接 ch / 接 ch
        if ch in last:                              # 接 ch 得到的串里，有一批在上次已经造过
            dp[i] = (dp[i] - dp[last[ch] - 1]) % MOD
        last[ch] = i
    return (dp[n] - 1) % MOD        # 去掉空串
```

运行：`"abc"` → `7`，`"aba"` → `6`，`"aaa"` → `3`，`"a"` → `1`，`"a" * 2000` → `2000`，`"abcdefghijklmnopqrstuvwxyz" * 76` → `238585536`。

**复杂度。** 时间 `O(n)`：每个字符常数时间；空间 `O(n)`：`dp` 数组，`last` 至多 26 项。

**易错点。**
- 不去重，直接 `2^n - 1`：`"aba"` 得 `7`（正确 `6`），`"aaa"` 得 `7`（正确 `3`）。
- 下标差一：减的是 `dp[last[ch] - 1]`，写成 `dp[last[ch]]` 会少加：`"aba"` 得 `5`，`"aaa"` 得 `1`。
- 忘了去掉空串：`"abc"` 得 `8`（正确 `7`）。
- 取模后相减可能出现负数：Python 的 `%` 总是非负，C++ / Java 要写 `(x - y + MOD) % MOD`。

**追问。**
- 空间降到 `O(26)`：记录「以每个字母结尾的不同子序列个数」，见另一种解法。
- `n` 很大（`10^6`）或要在线处理字符流：用上面的 26 个计数，每步 `O(1)`（维护总和）。
- 统计 `s` 中恰好等于目标串 `t` 的子序列个数（LC 115）：这是二维 DP，`dp[i][j]` 表示 `s[:i]` 里 `t[:j]` 的出现次数。

**同模式。** LC 115 不同的子序列、LC 1987 不同的好子序列数目、LC 730 统计不同回文子序列、LC 300 最长递增子序列。
