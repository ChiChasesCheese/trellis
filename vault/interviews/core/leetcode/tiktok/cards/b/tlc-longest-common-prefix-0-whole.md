## Q
**LC 14 最长公共前缀**｜Easy · LC TikTok 热度 50/100 · CodeTop 国内累计 24 次 · 最近 2026-01-16（CodeTop）

编写函数查找字符串数组中的最长公共前缀；如果不存在公共前缀，返回空字符串 `""`。`1 <= strs.length <= 200`，`0 <= strs[i].length <= 200`，`strs[i]` 如果非空，则仅由小写英文字母组成。例：`["flower","flow","flight"]` → `"fl"`；`["dog","racecar","car"]` → `""`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 纵向扫描：用 `zip(*strs)` 按列取出所有字符串的第 `j` 个字符，只要这一列的字符不全相同就停止；通过的列数就是公共前缀的长度，返回 `strs[0][:size]`。`O(S)`，`S` 是所有字符的总数。

**识别。** 「所有字符串共有的前缀」意味着要让所有串在每个位置**同时**对齐比较，按列扫描最自然：第一列不齐就能立刻结束，不必看后面的字符。`zip` 在最短的串耗尽时自动停止，天然保证前缀不会超过最短串，也不会越界。

**推导。** 暴力一（横向）：用第一个串当前缀，依次与后面每个串求公共前缀并缩短，最坏要比较所有字符。暴力二（纵向，手写）：外层列、内层串，要自己处理越界。洞察：`zip(*strs)` 把"转置"和"在最短串处停止"一步做完；一列是否全相同，用 `len(set(column)) == 1` 判断。不需要比较的列根本不会被访问。

```python
def longest_common_prefix(strs: list[str]) -> str:
    size = 0
    for column in zip(*strs):                    # 按列扫：第 j 列是所有字符串的第 j 个字符；zip 在最短串处自动停
        if len(set(column)) != 1:                # 这一列有不同字符：前缀到此为止
            break
        size += 1
    return strs[0][:size]
```

**运行。** `["flower","flow","flight"]` → `"fl"`；`["dog","racecar","car"]` → `""`；`["a"]` → `"a"`；`[""]` → `""`；`["ab","","abc"]` → `""`；`["abc","abc"]` → `"abc"`；`200` 个长度 `200` 的相同字符串 → 长度 `200`。

**复杂度。** 时间 `O(S)`，最坏所有串完全相同（`S = n·m`），遇到第一列不齐就提前结束；空间 `O(n)`：每一列的 `set` 至多 `n` 项，不额外保存字符串。

**易错点。**
- 用第一个串的长度当循环上界，再访问其他串的同一位置：`["flower","flow"]` 会抛 `IndexError`；要么用 `zip`，要么每次检查长度。
- 数组里有空串：`zip(*strs)` 立刻结束，`size = 0`，返回 `""`，正确；只比较前两个串则会漏掉后面的空串。
- 只比较前两个字符串：`["flower","flow","flight"]` 会返回 `"flow"`，正确是 `"fl"`；公共前缀必须对所有串成立。

**追问。**
- 更短的写法：只比较字典序最小和最大的两个串，公共前缀就是全体的公共前缀。
- 字符串很多且查询频繁：建 Trie，公共前缀就是从根出发、直到出现分叉或某个单词结束为止的那条路径。
- 要求最长公共子串（不要求在开头）：用后缀数组或动态规划，是另一个问题。
