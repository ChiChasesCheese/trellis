## Q
**LC 115 不同的子序列**｜Hard · 字节 高频

给两个字符串 `s` 和 `t`，统计并返回在 `s` 的**子序列**中 `t` 出现的个数（子序列是删掉若干字符、不改变剩余字符相对顺序得到的串；用不同下标选出的相同字符串算不同的方案）。测试用例保证结果在 32 位有符号整数范围内。`1 <= s.length, t.length <= 1000`，`s` 和 `t` 由英文字母组成。例：`s = "rabbbit", t = "rabbit"` → `3`（三个 `b` 里去掉任意一个）；`s = "babgbag", t = "bag"` → `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 动态规划（DP）：`dp[j]` 表示 `s` 已读过的前缀里 `t[:j]` 作为子序列出现的方案数；读入 `s` 的每个字符 `ch`，对 `t` 中等于 `ch` 的位置 `j`，把 `dp[j - 1]`（用这个 `ch` 去配 `t[j - 1]`）加到 `dp[j]` 上；`j` 倒序遍历，保证每个字符只用一次。`O(mn)` 时间，`O(n)` 空间。

**识别。** 「在一个串里数另一个串作为子序列的出现次数」是双序列**计数** DP，状态是一对前缀 `(i, j)`，和求最大值的 LCS 同形、转移改成加法。规模 `1000 × 1000`，`O(mn) = 10^6`。近似但不同：LC 392 只问「是不是子序列」（双指针），LC 1143 求最长公共子序列的长度。

**推导。** 暴力：枚举 `s` 的所有长度为 `|t|` 的下标组合，`C(m, n)` 个，指数级。递归 `f(i, j)` 表示 `s[i:]` 里 `t[j:]` 的方案数：若 `s[i] == t[j]`，既可以「用」这个字符配 `t[j]`（`f(i+1, j+1)`），也可以「不用」（`f(i+1, j)`）；不相等只能「不用」。同一个 `(i, j)` 被反复求解 → 填表。改成「前缀」视角：`f[i][j] = f[i-1][j] + (s[i-1] == t[j-1]) * f[i-1][j-1]`，第 `i` 行只依赖第 `i - 1` 行，压成一维；一维更新时要用上一行的 `dp[j - 1]`，所以 `j` 必须倒序。

```python
def num_distinct(s: str, t: str) -> int:
    dp = [1] + [0] * len(t)                # dp[j]：s 目前读过的前缀里，t[:j] 作为子序列出现的次数
    for ch in s:
        for j in range(len(t), 0, -1):     # 倒序：dp[j - 1] 还是读 ch 之前的旧值
            if t[j - 1] == ch:
                dp[j] += dp[j - 1]
    return dp[-1]
```

运行：`("rabbbit", "rabbit")` → `3`，`("babgbag", "bag")` → `5`，`("a", "aa")` → `0`，`("aaa", "a")` → `3`，`("abc", "abc")` → `1`。

**复杂度。** 时间 `O(mn)`；空间 `O(n)`。

**易错点。**
- `j` 必须倒序：正序时 `dp[j - 1]` 已经被当前字符更新过，同一个字符被用了两次。`("a", "aa")` 会得到 `1`（正确 `0`），`("aaa", "aa")` 会得到 `6`（正确 `3`）。
- 初始值 `dp[0] = 1`：空串是任何前缀的子序列，恰有一种方案；写成 `0` 会让所有结果为 `0`。
- 答案是 `dp[-1]`（即 `dp[len(t)]`）；`t` 比 `s` 长时自然为 `0`。

**追问。**
- 需要输出方案或调试：保留二维表 `f[i][j]`，更直观，空间 `O(mn)`。
- 结果要对一个模数取余：每次 `dp[j] += dp[j - 1]` 后取模；原题保证结果不超过 32 位，所以 Python 里不会有精度问题，但中间值可能大于 32 位。
- 递归加 `@cache`：深度可达 `len(s) + len(t) = 2000`，超过默认递归上限，需要提高上限或改成迭代。

**同模式。** LC 392 判断子序列、LC 1143 最长公共子序列、LC 72 编辑距离、LC 97 交错字符串、LC 44 通配符匹配。
