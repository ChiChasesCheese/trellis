## Q
**LC 905 按奇偶排序数组**｜Easy · CodeTop 国内累计 4 次 · 最近 2026-03-02（国内 CodeTop）

给整数数组 `nums`，把所有偶数移到数组前面，后面跟所有奇数，返回满足条件的**任一**数组。`1 <= nums.length <= 5000`，`0 <= nums[i] <= 5000`。例：`[3,1,2,4]` → `[2,4,3,1]`（`[4,2,3,1]`、`[2,4,1,3]`、`[4,2,1,3]` 也对）；`[0]` → `[0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对撞双指针原地分区：左指针找奇数、右指针找偶数，左奇右偶就交换；`left` 左边全是偶数、`right` 右边全是奇数，两指针相遇即完成。`O(n)` 时间、`O(1)` 额外空间。

**识别。** 「按一个二元条件把元素分到两边」+「任一顺序都行」→ 这是快速排序里的**分区**（partition），不需要真正排序。原地、一遍扫描是面试期望；「任一」说明不要求稳定，可以交换。

**推导。** 最直接的是开两个列表分别收集偶数和奇数再拼接，`O(n)` 时间但 `O(n)` 额外空间；或按奇偶排序 `O(n log n)`。想原地完成：从两端向中间扫，左边遇到的偶数已经在正确的一侧，跳过；右边遇到的奇数也已在正确的一侧，跳过；只有「左奇右偶」这一对是放错的，交换一次两个都归位。每个元素至多被看一次，`O(n)`。

```python
def sort_array_by_parity(nums: list[int]) -> list[int]:
    left, right = 0, len(nums) - 1
    while left < right:
        if nums[left] % 2 == 0:            # 左边已经是偶数：放行
            left += 1
        elif nums[right] % 2 == 1:         # 右边已经是奇数：放行
            right -= 1
        else:                              # 左奇右偶：交换，两端各前进一步
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
    return nums
```

运行：`[3,1,2,4]` → `[4, 2, 1, 3]`，`[0]` → `[0]`，`[1]` → `[1]`，`[1,3,5]` → `[1, 3, 5]`，`[2,4]` → `[2, 4]`。

**复杂度。** 时间 `O(n)`：每步至少一个指针向中间移动；额外空间 `O(1)`。

**易错点。**
- 每轮无条件让两个指针都前进，只在「左奇右偶」时交换：放错的元素可能被跳过。`[2,3,1,4]` 原样返回 `[2, 3, 1, 4]`（`3` 在 `4` 前面），正确如 `[2, 4, 1, 3]`。
- 判断奇数写 `x % 2 == 1` 在 Python 里对负数也成立（`-3 % 2 == 1`）；换成 Java / C++ 时 `-3 % 2 == -1`，要写 `x % 2 != 0`。这里的值都非负，不受影响。
- 函数原地修改并返回同一个列表；调用方若还要原数组，先 `nums[:]` 复制。

**追问。**
- 要求**稳定**（偶数之间、奇数之间保持原顺序）：`sorted(nums, key=lambda x: x % 2)`，Python 排序稳定，`[3,1,2,4]` → `[2, 4, 3, 1]`；或两个列表推导拼接，`O(n)` 空间。
- 快慢指针写法：`write` 指向下一个偶数该放的位置，`read` 扫一遍，遇到偶数就和 `nums[write]` 交换；同样 `O(n)`、`O(1)`，偶数部分保持原相对顺序。
- 三类分区（如 0 / 1 / 2）：荷兰国旗三指针（LC 75）。
