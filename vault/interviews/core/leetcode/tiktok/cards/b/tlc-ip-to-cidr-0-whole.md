## Q
**LC 751 IP 到 CIDR**｜Medium · CodeTop 国内累计 1 次 · 最近 2023-12-16（国内 CodeTop）

IPv4 地址是 32 位无符号整数，按 8 位一组写成十进制，用点分隔（如 `15.136.255.107`）。**CIDR 块**写成 `基础IP/前缀长度k`，覆盖所有前 `k` 位与基础 IP 相同的地址，共 `2^(32-k)` 个。给起始地址 `ip` 和数量 `n`，用**尽可能少**的 CIDR 块恰好覆盖 `[ip, ip + n - 1]` 内的所有地址，不能覆盖范围外的地址，返回最短列表（多个答案返回任意一个）。`7 <= ip.length <= 15`，`ip` 是有效 IPv4，`1 <= n <= 1000`，范围内每个地址都是有效 IPv4。例：`ip = "255.0.0.7"`，`n = 10` → `["255.0.0.7/32","255.0.0.8/29","255.0.0.16/32"]`；`ip = "117.145.102.62"`，`n = 8` → `["117.145.102.62/31","117.145.102.64/30","117.145.102.68/31"]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把 IP 当 32 位整数 `x`，贪心地从起点开始切：每次取「既和 `x` 对齐、又不超过剩余数量 `n`」的最大 2 的幂 `size = min(x & -x, 不超过 n 的最大 2 的幂)`，输出 `x/(32 - log2(size))`，然后 `x += size`、`n -= size`。

**识别。** 「用最少的块覆盖一段连续区间，块大小必须是 2 的幂且起点对齐」就是二进制低位贪心（与树状数组的 `lowbit` 同一类）。一个大小为 `2^j` 的块合法，当且仅当它的起点 `x` 的低 `j` 位全是 `0`，即 `x` 是 `2^j` 的倍数。

**推导。** 暴力：每个地址各写一个 `/32` 块，合法但不是最少 → 要合并，就要找最大的合法块：块不能超过剩余数量 `n`（取不超过 `n` 的最大 2 的幂，`1 << (n.bit_length() - 1)`），起点还要对齐（`x & -x` 是 `x` 最低位的 `1`，也就是以 `x` 开头最多能对齐到多大） → 取这两者的较小值 → 贪心成立：第一块必须从 `x` 开始，取尽可能大的合法块，剩下的是一段更短、起点更靠后的同类问题，不会更差 → 起点 `x = 0` 时 `x & -x = 0`，要当作「不受对齐限制」处理。

```python
def ip_to_cidr(ip: str, n: int) -> list[str]:
    def to_int(s: str) -> int:
        a, b, c, d = map(int, s.split("."))
        return a << 24 | b << 16 | c << 8 | d

    def to_ip(x: int) -> str:
        return ".".join(str(x >> sh & 255) for sh in (24, 16, 8, 0))

    x = to_int(ip)
    ans: list[str] = []
    while n > 0:
        low = x & -x or 1 << 32                  # x 的最低位 1：当前地址最多对齐到多大的块（x=0 时不限）
        size = min(low, 1 << (n.bit_length() - 1)) # 又不能超过剩余数量 n 的最大 2 的幂
        ans.append(f"{to_ip(x)}/{33 - size.bit_length()}")
        x += size
        n -= size
    return ans
```

运行：`("255.0.0.7", 10)` → `['255.0.0.7/32', '255.0.0.8/29', '255.0.0.16/32']`；`("117.145.102.62", 8)` → `['117.145.102.62/31', '117.145.102.64/30', '117.145.102.68/31']`；`("0.0.0.0", 1000)` → `['0.0.0.0/23', '0.0.2.0/24', '0.0.3.0/25', '0.0.3.128/26', '0.0.3.192/27', '0.0.3.224/29']`；`("1.2.3.4", 1)` → `['1.2.3.4/32']`。

**复杂度。** 每个块的大小至少让 `n` 减掉其二进制最高位，块数不超过约 `2 log2(n)`，`n <= 1000` 时最多二十个左右：时间 `O(log n)`，空间 `O(log n)`。

**易错点。**
- 只取不超过 `n` 的最大 2 的幂、忽略对齐：`("255.0.0.7", 10)` 得到 `['255.0.0.7/29', '255.0.0.15/31']`，而 `/29` 块实际覆盖 `255.0.0.0` 到 `255.0.0.7`，起点没对齐，覆盖了范围外的地址。
- `x = 0` 时 `x & -x` 为 `0`，`size` 变成 `0`，循环永远不前进；必须特判成「不受对齐限制」。
- 前缀长度写成 `32 - size.bit_length()`：`size = 1` 时应是 `/32`，公式是 `33 - size.bit_length()`（等价于 `32 - log2(size)`）。

**追问。**
- 标准库一步到位：`ipaddress.summarize_address_range(IPv4Address(first), IPv4Address(last))` 返回同样的最短 CIDR 列表；面试里先手写，再提这个。
- 输入是任意多个 IP 区间：先排序合并重叠区间，再对每个合并后的区间调用上面的函数。
- IPv6：位宽从 `32` 换成 `128`，`1 << 32` 换成 `1 << 128`，格式化换成 8 组十六进制，算法完全不变。

**同模式。** LC 468 验证 IP 地址、LC 93 复原 IP 地址、LC 191 位 1 的个数、LC 231 2 的幂、LC 56 合并区间。
