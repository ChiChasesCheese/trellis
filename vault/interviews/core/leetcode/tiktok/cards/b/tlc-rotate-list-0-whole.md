## Q
**LC 61 旋转链表**｜Medium · CodeTop 国内累计 19 次 · 最近 2026-04-20（国内 CodeTop）

给链表的头结点 `head`，把链表的每个结点向右移动 `k` 个位置（循环右移，移出尾部的结点回到头部），返回新的头结点。结点数在 `[0, 500]` 内，`-100 <= Node.val <= 100`，`0 <= k <= 2 * 10^9`。例：`[1,2,3,4,5], k = 2` → `[4,5,1,2,3]`；`[0,1,2], k = 4` → `[2,0,1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先走一遍求长度 `n` 并找到尾结点，`k %= n`；把尾接到头上成环，从头走 `n - k - 1` 步到达新尾，新头是新尾的下一个，在这里断环。时间 `O(n)`，空间 `O(1)`。

**识别。** 「链表 + 循环右移 `k`」→ 右移 `k` 位等于把最后 `k` 个结点整段搬到前面，只需在第 `n - k` 个结点之后切一刀。`k` 到 `2 * 10^9` 而 `n <= 500` → 必须先取模；链表不能随机访问 → 先数长度。

**推导。** 暴力：每次把尾结点搬到头部，做 `k` 次，每次找尾 `O(n)`，共 `O(nk)`，`k = 2 * 10^9` 时不可能。第一个观察：转 `n` 次回到原样，所以 `k %= n`。第二个观察：右移 `k` 次的结果，就是在第 `n - k` 个结点后面切开、把后段接到前面；一次切割代替 `k` 次搬运。成环写法让「后段接到前面」这一步变成一行 `tail.next = head`。

```python
def rotate_right(head: ListNode | None, k: int) -> ListNode | None:
    if head is None or head.next is None or k == 0:
        return head
    # 第一遍：数长度，同时找到尾结点
    n, tail = 1, head
    while tail.next:
        tail = tail.next
        n += 1
    k %= n                                    # k 最大 2*10^9，转一整圈等于没转
    if k == 0:
        return head
    tail.next = head                          # 首尾相连成环
    new_tail = head
    for _ in range(n - k - 1):                # 新尾是原来的第 n-k 个结点
        new_tail = new_tail.next
    new_head = new_tail.next                  # 新头是它的下一个
    new_tail.next = None                      # 在这里断环
    return new_head
```

运行：`[1,2,3,4,5], 2` → `[4,5,1,2,3]`，`[0,1,2], 4` → `[2,0,1]`，`[], 3` → `[]`，`[7], 10^9` → `[7]`，`[1,2], 2 * 10^9` → `[1,2]`。

**复杂度。** 时间 `O(n)`：数长度一遍，找新尾不到一遍；空间 `O(1)`：只改指针。

**易错点。**
- 漏掉 `k %= n`：`[0,1,2], k = 4` 时 `range(n - k - 1)` 是空的，在头结点后断开，得到 `[1,2,0]`（正确 `[2,0,1]`），而且不报错。
- 走 `n - k` 步而不是 `n - k - 1` 步：停在新头而不是新尾，`[1,2,3,4,5], k = 2` 得到 `[5,1,2,3,4]`（正确 `[4,5,1,2,3]`）。
- 空链表要先返回：否则 `head.next` 抛 `AttributeError`。

**追问。**
- 向左旋转 `k` 位：等价于向右旋转 `n - k % n` 位，新尾是第 `k % n` 个结点。
- 数组轮转（LC 189）：三次反转（整体、前 `k` 个、后 `n - k` 个），`O(1)` 额外空间。
- 用快慢指针找倒数第 `k` 个：`k` 可能远大于 `n`，仍然要先数长度取模，所以省不掉第一遍。

**同模式。** LC 189 轮转数组、LC 19 删除链表的倒数第 N 个结点、LC 876 链表的中间结点、剑指 Offer 22 链表中倒数第 k 个结点。
