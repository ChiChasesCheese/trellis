## Q
**LC 50 Pow(x, n)**｜Medium · CodeTop 国内累计 15 次 · 最近 2026-03-24（国内 CodeTop）

实现 `pow(x, n)`，计算浮点数 `x` 的整数 `n` 次幂。`-100.0 < x < 100.0`，`-2^31 <= n <= 2^31 - 1`，`n` 是整数；要么 `x` 不为零，要么 `n > 0`；结果满足 `-10^4 <= x^n <= 10^4`。例：`x = 2.0, n = 10` → `1024.0`；`x = 2.1, n = 3` → `9.261`；`x = 2.0, n = -2` → `0.25`（`2^-2 = 1/4`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 快速幂（binary exponentiation）：把指数 `n` 按二进制拆开，底数每轮平方、指数每轮右移一位，当前二进制位是 1 就把底数乘进结果；负指数先取倒数。`O(log n)` 次乘法。

**识别。** 「同一个数连乘 `n` 次」且 `n` 大到 `2^31`，逐个乘要 `2 * 10^9` 次，必超时。乘法有结合律，`x^n` 可以拆成两半各算一次再相乘，这是「倍增 / 二分指数」的标志。负指数是边界，不是新算法。

**推导。** 暴力：循环乘 `n` 次，`O(n)`。浪费：`x^8` 要算 8 次乘法，但 `x^2 → x^4 → x^8` 只要 3 次平方，中间结果被重复利用。洞察：`x^n = (x^(n // 2))^2 * (x 若 n 为奇数)`，指数每步减半。展开成迭代：`n` 的二进制是 `1010` 就是 `x^8 * x^2`，从低位到高位，每位对应一次平方，位为 1 时把当前底数乘进结果。最多 32 轮。

```python
def my_pow(x: float, n: int) -> float:
    if n < 0:                      # x^-n = (1/x)^n，先把指数变成非负
        x, n = 1 / x, -n
    result = 1.0
    while n:                       # 不变量：答案 = result * x^n
        if n & 1:                  # 当前二进制位为 1：把这一份 x 乘进结果
            result *= x
        x *= x                     # 底数平方，对应下一个二进制位
        n >>= 1
    return result
```

运行：`my_pow(2.0, 10)` → `1024.0`，`my_pow(2.1, 3)` → `9.261000000000001`（和 `9.26100` 的误差在判题容差内），`my_pow(2.0, -2)` → `0.25`，`my_pow(2.0, 0)` → `1.0`，`my_pow(1.0, -2**31)` → `1.0`，`my_pow(0.0, 5)` → `0.0`。

**复杂度。** 时间 `O(log |n|)`：循环次数等于 `n` 的二进制位数，至多 32；空间 `O(1)`。

**易错点。**
- 负指数一定要先转成非负：Python 里 `-1 >> 1 == -1`，负数右移永远到不了 `0`，`while n` 变成死循环。
- 顺序是「先判最低位乘结果、再平方底数、再右移」。若先平方、右移，再检查最低位，`my_pow(2.0, 3)` 得到 `4.0`（正确 `8.0`）。
- `n = -2^31` 取负后是 `2^31`。C++ / Java 的 32 位 `int` 会溢出，要先转 `long`；Python 整数不会溢出，但这个边界是面试官常问的。

**追问。**
- 递归写法：`half = my_pow(x, n // 2)`，只算一次再平方；写成两次递归调用相乘会退化成 `O(n)`。
- 整数取模幂：`pow(a, b, m)` 是内置三参数形式，`O(log b)`。
- 精度：连乘误差随乘法次数线性累积，快速幂只做 `O(log n)` 次乘法，比逐个乘更准。

**同模式。** LC 372 超级次方、LC 29 两数相除（倍增）、LC 509 斐波那契数（矩阵快速幂）、LC 1922 统计好数字的数目。
