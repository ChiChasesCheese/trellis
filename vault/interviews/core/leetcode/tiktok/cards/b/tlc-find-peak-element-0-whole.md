## Q
**LC 162 寻找峰值**｜Medium · LC TikTok 全时段热度 53/100 · CodeTop 国内累计 49 次 · 最近 2026-04-19（国内 CodeTop）

峰值元素是严格大于左右相邻值的元素。给整数数组 `nums`，找到一个峰值元素并返回其下标；数组可能有多个峰值，返回**任意一个**即可。假设 `nums[-1] = nums[n] = -∞`（两端之外视为负无穷）。必须设计 `O(log n)` 的算法。

约束：`1 <= nums.length <= 1000`，`-2^31 <= nums[i] <= 2^31 - 1`，对所有有效的 `i` 都有 `nums[i] != nums[i + 1]`。

例：`nums = [1,2,3,1]` → `2`；`nums = [1,2,1,3,5,6,4]` → `1` 或 `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对「峰值」做二分：比较 `nums[mid]` 与 `nums[mid + 1]`——上坡就往右（右边一定有峰），下坡就往左（`mid` 或左边一定有峰），区间收缩到一个点就是峰。`O(log n)`。

**识别。** 题面要求 `O(log n)` 且数组**无序**——二分通常要求有序，这里的关键是**局部单调性 + 边界为负无穷**也能保证「某一侧一定有答案」。信号：「找任意一个」（不是最大的）、「相邻不相等」、「两端视为 `-∞`」，这三条合起来保证了二分的不变量。

**推导。** 线性扫描 `O(n)`：找第一个比后一个大的位置。要 `O(log n)`：看中点。若 `nums[mid] < nums[mid+1]`，说明 `mid` 处在上坡；沿着上坡一直往右，要么遇到一个下降点（那里就是峰），要么爬到最右端（`nums[n] = -∞`，最右元素就是峰），所以 `[mid+1, hi]` 里一定有峰。若 `nums[mid] > nums[mid+1]`（相邻不相等所以只剩这一种），`mid` 在下坡上；往左看，要么有一个上坡的转折点，要么一路下降到最左端（`nums[-1] = -∞`，最左元素就是峰），所以 `[lo, mid]`（含 `mid`）里一定有峰。每步把区间缩一半，`lo == hi` 时就是一个峰。

```python
def find_peak_element(nums: list[int]) -> int:
    lo, hi = 0, len(nums) - 1          # 在闭区间 [lo, hi] 里一定还有峰值
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < nums[mid + 1]:  # 上坡：右边一定有峰（最坏一路爬到最右端）
            lo = mid + 1
        else:                          # 下坡：mid 自己或左边有峰（相邻不相等）
            hi = mid
    return lo
```

运行：`nums=[1,2,3,1]` → `2`，`nums=[1,2,1,3,5,6,4]（1 或 5 都对）` → `5`，`nums=[1]` → `0`，`nums=[3,2,1]（峰在最左）` → `0`，`nums=[1,2,3]（峰在最右）` → `2`，`nums=[-2**31, -2**31 + 1]` → `1`。

**复杂度。** 时间 `O(log n)`：每轮把搜索区间缩小一半；空间 `O(1)`。

**易错点。**
- 下坡时写 `hi = mid - 1`：把可能是峰的 `mid` 排除了。`[1,2,1]` 中 `mid = 1` 恰是峰，写成 `hi = mid - 1` 会返回下标 `0`（值 `1`，不是峰）。
- 用 `lo <= hi` 的模板：`mid + 1` 可能越界；此处用 `lo < hi` 且 `hi = mid` 的「收缩到一点」写法，不需要最后再判断。
- 把 `nums[-1] = nums[n] = -∞` 当成真的补元素，并用 `-2^31` 当哨兵：`nums = [-2^31]` 时，`-2^31` 并不严格大于哨兵，会找不到峰；要么用 `-inf`，要么像上面那样不补哨兵，让区间端点自然处理。
- 以为必须返回最大值的下标：题目只要求任意一个峰值；全局最大值当然是峰，但需要 `O(n)`。

**追问。**
- 相邻元素可以相等：二分不再成立（`[1,1,1,1,2,1,1,1]` 中间平台让你无法判断往哪边走），最坏退化成 `O(n)`。
- 二维矩阵的峰值（LC 1901）：对中间列找该列最大值，再与左右邻居比较，往更大的一侧收缩，`O(m log n)`，思想相同。
- 要返回所有峰值：只能 `O(n)` 扫描；二分只保证找到一个。

**同模式。** LC 852 山脉数组的峰顶索引、LC 1095 山脉数组中查找目标值、LC 153 / 154 寻找旋转排序数组中的最小值、LC 33 搜索旋转排序数组、LC 1901 寻找峰值 II。
