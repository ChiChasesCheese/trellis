## Q
**LC 423 从英文中重建数字**｜Medium · CodeTop 国内累计 4 次 · 最近 2026-05-12（CodeTop）

字符串 `s` 由若干用英文单词表示的数字（`zero` 到 `nine`）把字母顺序打乱后拼成。按**升序**返回原始的数字（每个数字出现几次就写几次）。`1 <= s.length <= 10^5`，`s[i]` 只会是 `e g f i h o n s r u t w v x z` 这些字母，且 `s` 保证合法。例：`"owoztneoer"` → `"012"`；`"fviefuro"` → `"45"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 数字单词里有些字母**独一无二**（`z`→0、`w`→2、`u`→4、`x`→6、`g`→8），先靠它们数出这五个数字，再按「剩下的字母里是否唯一」依次识别 3、5、7、1、9，每识别一个就把它的所有字母从计数里扣掉。`O(n)`。

**识别。** 「字母打乱 + 求原始集合」是**计数 + 剥离**（peeling）问题：只关心每个字母出现几次，不关心顺序；十个单词的字母构成一个线性方程组，其中若干字母只属于一个单词，可以直接解出对应数字，再代入后会出现新的唯一字母；`n = 10^5` 只需要 `O(n)` 的一次计数，其余是常数。

**推导。** 暴力：回溯尝试每个单词能不能从字母池里取走，指数级。浪费：打乱后单词边界信息已经丢了，但字母总数没丢；一个字母出现几次，就等于含它的各单词数字出现次数的加权和。洞察：`z` 只出现在 `zero`，`w` 只在 `two`，`u` 只在 `four`，`x` 只在 `six`，`g` 只在 `eight`，所以这五个数字的个数直接等于对应字母的个数。扣掉它们之后，`h`（`three`）、`f`（`five`）、`s`（`seven`）变得唯一，再扣掉；最后 `o`（`one`）和 `i`（`nine`）也唯一。最优：一次 `Counter` 计数 + 按固定顺序做 10 次扣减，`O(n)`。

```python
def original_digits(s: str) -> str:
    # (数字, 英文单词, 识别它的字母)：顺序保证识别字母在轮到它时已经唯一
    steps = [
        (0, "zero", "z"), (2, "two", "w"), (4, "four", "u"), (6, "six", "x"), (8, "eight", "g"),
        (3, "three", "h"), (5, "five", "f"), (7, "seven", "s"), (1, "one", "o"), (9, "nine", "i"),
    ]
    cnt = Counter(s)
    digits = [0] * 10
    for digit, word, key in steps:
        k = cnt[key]                          # 此刻 key 字母只可能来自这个数字
        digits[digit] = k
        for ch, m in Counter(word).items():   # 把这 k 个单词用掉的字母全部扣掉
            cnt[ch] -= k * m
    return "".join(str(d) * c for d, c in enumerate(digits))
```

运行：`"owoztneoer"` → `'012'`，`"fviefuro"` → `'45'`，`"nineeightsix"` → `'689'`，`"eon"` → `'1'`，`"zeroonetwothreefourfivesixseveneightnine"` → `'0123456789'`。

**复杂度。** 时间 `O(n)`：一次 `Counter(s)`，之后 10 步每步只处理固定的几个字母；空间 `O(1)`（字母表 15 个，数字 10 个）。

**易错点。**
- 识别顺序错：先数 `one`（用 `o`）。`o` 同时出现在 `zero`、`two`、`four` 里，`"owoztneoer"` 里有 3 个 `o`，会得出 `01112`（正确 `012`）。必须先扣掉 0、2、4 再数 `o`。
- 只扣识别字母、不扣整个单词：数完 `zero` 后只减 `z`，`e`、`r`、`o` 还留在计数里，后面的 `h`、`s`、`i` 就不再唯一。
- 输出没有按数字升序拼：`digits` 数组按数字下标顺序展开，不要按识别顺序（0、2、4、6、8、3…）拼接。

**追问。**
- 单词表换了（别的语言、别的词集）怎么找识别顺序：反复找「只出现在剩余一个单词里」的字母，识别并剥离。
- 输入不保证合法：扣完后若有计数为负或非零，说明输入不合法，返回空串或报错。
- 某字母在识别单词里出现多次：`k = cnt[key] // 该字母的重数`。

**同模式。** LC 242 有效的字母异位词、LC 387 字符串中的第一个唯一字符、LC 49 字母异位词分组、LC 1189「气球」的最大数量、LC 389 找不同。
