## Q
**LC 1674 使数组互补的最少操作次数**｜Medium · CodeTop 国内累计 1 次 · 最近 2026-04-30（CodeTop）

给长度为**偶数** `n` 的整数数组 `nums` 和整数 `limit`。每次操作可以把 `nums` 中任意一个整数替换成 `1` 到 `limit` 之间的另一个整数。若对所有下标 `i`，`nums[i] + nums[n-1-i]` 都等于同一个数，则数组**互补**。求使数组互补的最少操作次数。`2 <= n <= 10^5`，`1 <= nums[i] <= limit <= 10^5`。例：`nums = [1,2,4,3]`，`limit = 4` → `1`（改成 `[1,2,2,3]`，每对和为 `4`）；`nums = [1,2,2,1]`，`limit = 2` → `2`；`nums = [1,2,1,2]`，`limit = 2` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 枚举目标和 `s`（`2..2*limit`）。对每一对 `(a, b)`，让它的和等于 `s` 的代价只有 `0 / 1 / 2` 三种，且随 `s` 呈**分段常数**：`s == a+b` 为 `0`，`s` 在 `[min+1, max+limit]` 为 `1`，否则为 `2`。用**差分数组**一次性累加所有对的代价，前缀和后取最小。`O(n + limit)`。

**识别。** 「对称位置两两配对」+「枚举统一的目标值」+ 每对的代价是 `s` 的分段常函数 → **差分数组 + 前缀和**（difference array）：把「对每个 `s` 逐对计算」的 `O(n * limit)` 变成「每对只更新 `O(1)` 个区间端点」。`n, limit` 都到 `10^5` 要求线性。

**推导。** 暴力：枚举目标和 `s`（`O(limit)` 种），每种扫描所有对算代价，`O(n * limit)`。浪费：每对的代价只在几个临界点变化，对大多数 `s` 值是同一个数。洞察：设一对为 `(a, b)`，`lo = min(a, b)`，`hi = max(a, b)`。改一个数可达的和是 `[lo + 1, hi + limit]`（把较大者改成 `[1, limit]`，或把较小者改成 `[1, limit]`，并集），所以 `s` 落在这个区间内代价至多 `1`，等于 `a + b` 时代价 `0`，区间外要改两个，代价 `2`。最优：默认每对代价 `2`，在区间 `[lo+1, hi+limit]` 上减 `1`，在 `s = a + b` 上再减 `1`，用差分数组 `O(1)` 更新；全部对处理完后做一次前缀和得到每个 `s` 的总代价，取最小。

```python
def min_moves(nums: list[int], limit: int) -> int:
    n = len(nums)
    diff = [0] * (2 * limit + 2)                 # diff[s]：目标和 s 的总操作数相对 s-1 的变化量
    for a, b in zip(nums[: n // 2], reversed(nums[n // 2 :])):   # 配对 (nums[i], nums[n-1-i])
        lo, hi = min(a, b), max(a, b)
        diff[2] += 2                             # 默认：每一对都要改 2 个数（s 从 2 开始）
        diff[lo + 1] -= 1                        # s 落在 [lo+1, hi+limit]：改 1 个数就够
        diff[hi + limit + 1] += 1
        diff[a + b] -= 1                         # s == a+b：不用改
        diff[a + b + 1] += 1
    cost = accumulate(diff)                      # cost[s] = 把所有对都变成和 s 的总操作数
    return min(c for s, c in enumerate(cost) if 2 <= s <= 2 * limit)
```

运行：`[1,2,4,3], limit=4` → `1`，`[1,2,2,1], limit=2` → `2`，`[1,2,1,2], limit=2` → `0`，`[1,1], limit=1` → `0`，`[1,1], limit=5` → `0`，`[1,5], limit=5` → `0`。

**复杂度。** 时间 `O(n + limit)`：处理 `n/2` 对各 `O(1)` 个端点，前缀和与取最小各扫 `2 * limit` 个位置；空间 `O(limit)`（差分数组）。

**易错点。**
- 区间左端写成 `lo` 而不是 `lo + 1`：改一个数时，新和最小是「另一个数 + 1」，也就是 `lo + 1`；写成 `lo` 会把「改成 `0`」这种不合法的操作算进来。`nums = [1,2,2,1]`，`limit = 2` 得 `1`（正确 `2`）。
- 只试数组里已有的 `a + b` 当目标和：`nums = [4,3,2,1,1,1,4,4]`，`limit = 4` 得 `5`（正确 `4`）。要对 `[2, 2*limit]` 全部取最小。
- 差分数组开小：`diff[hi + limit + 1]` 的下标最大到 `2 * limit + 1`，数组长度至少 `2 * limit + 2`，否则 `IndexError`。

**追问。**
- `limit` 极大（如 `10^9`）而 `n` 很小：差分数组放不下，改成稀疏事件点 + 排序扫描，复杂度 `O(n log n)`。
- 返回达到最小代价的目标和 `s`：遍历前缀和时记录取得最小值的 `s`。
- 要返回改完之后的数组：用最优目标和 `s`，逐对判断是不动、改一个（改成 `s - 另一个数`）还是改两个。

**同模式。** LC 1109 航班预订统计、LC 370 区间加法、LC 1094 拼车、LC 253 会议室 II（事件扫描）、LC 1589 所有排列中的最大和。
