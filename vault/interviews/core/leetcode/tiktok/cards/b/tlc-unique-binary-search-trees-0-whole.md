## Q
**LC 96 不同的二叉搜索树**｜Medium · CodeTop 国内累计 20 次 · 最近 2026-04-19（CodeTop）

给整数 `n`，求恰由 `n` 个节点组成、节点值为 `1` 到 `n` 互不相同的二叉搜索树有多少种。`1 <= n <= 19`。例：`n = 3` → `5`；`n = 1` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 枚举根节点 `i`：左子树用 `1..i-1`（`i-1` 个节点），右子树用 `i+1..n`（`n-i` 个节点），两边互相独立，方案数相乘；`G(n) = Σ G(i-1) · G(n-i)`，`G(0) = 1`。这就是卡特兰数（Catalan number）。`O(n^2)`。

**识别。** 「数有多少种树 / 结构」且每种结构由「选根 + 左右各自一棵结构」组成 → 区间 / 计数 DP。关键观察：BST 的形状只取决于节点个数，与具体值无关（值 `3..5` 构成的 BST 个数等于值 `1..3` 的），所以状态是「节点数」，不是「值区间」。`n <= 19` 是因为 `G(19) = 1767263190` 刚好在 32 位有符号整数以内，`G(20)` 就溢出了。

**推导。** 暴力：真的把每棵树建出来数（LC 95），数量是卡特兰数，指数级 → 浪费：只要个数，不要树本身；左右子树的个数互不影响 → 洞察：根取 `i` 时方案数是 `G(i-1) · G(n-i)`，求和覆盖所有根的取法；空树算 `1` 种（乘法单位元）→ 自底向上算 `G(0..n)`，每个 `G(size)` 做一次 `O(size)` 的求和，总 `O(n^2)`。

```python
def num_trees(n: int) -> int:
    g = [1, 1]                                  # g[i]：i 个节点的 BST 数量；空树算 1 种
    for size in range(2, n + 1):
        g.append(sum(g[left] * g[size - 1 - left] for left in range(size)))
    return g[n]
```

运行：`n = 1..5` → `1, 2, 5, 14, 42`，`n = 19` → `1767263190`，与公式 `comb(2n, n) // (n + 1)` 在 `n = 1..19` 全部一致。

**复杂度。** 时间 `O(n^2)`，`size` 从 `2` 到 `n`，每个求和 `size` 项；空间 `O(n)`。

**易错点。**
- 空树必须算 `1` 种而不是 `0`：把 `g[0]` 设成 `0`，`n = 2` 会得到 `0`，正确是 `2`（根为 `1` 或根为 `2`）。
- 右子树大小是 `size - 1 - left`，不是 `size - left`：根占一个节点。
- 不要把「值区间」当状态再去枚举区间端点，那是 LC 95 的做法，状态多、没必要。

**追问。**
- 要列出所有树（LC 95）：递归 `build(lo, hi)` 返回区间内所有树，枚举根再对左右列表做笛卡尔积；答案数量是卡特兰数。
- `n` 很大时（要对 `10^9 + 7` 取模）：用公式 `C(2n, n) / (n + 1)`，配合阶乘与逆元，`O(n)`；Python 的 `math.comb` 直接给精确大整数。
- 不同的二叉树（不要求是 BST）也是同一个数：形状个数只依赖节点数。

**同模式。** LC 95 不同的二叉搜索树 II、LC 241 为运算表达式设计优先级、LC 22 括号生成、LC 1130 叶值的最小代价生成树。
