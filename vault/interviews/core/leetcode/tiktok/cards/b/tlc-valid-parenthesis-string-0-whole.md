## Q
**LC 678 有效的括号字符串**｜Medium · TikTok 高频

给一个只含 `'('`、`')'` 和 `'*'` 三种字符的字符串 `s`，判断它是否有效。有效的条件：每个 `'('` 都有对应的 `')'`，每个 `')'` 都有对应的 `'('`，`'('` 必须在对应的 `')'` 之前；`'*'` 可以当作单个 `')'`、单个 `'('` 或空串。`1 <= s.length <= 100`，`s[i]` 只能是 `'('`、`')'`、`'*'`。例：`"()"` → `true`，`"(*)"` → `true`，`"(*))"` → `true`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 贪心维护「还没配对的 `'('` 个数」的可能区间 `[lo, hi]`：`'('` 让两端加一，`')'` 让两端减一，`'*'` 让 `lo` 减一、`hi` 加一；`hi < 0` 说明即使所有星号都当 `'('` 也配不上，直接失败；`lo` 小于 `0` 就截回 `0`；最后 `lo == 0` 即有效。`O(n)` 时间，`O(1)` 空间。

**识别。** 「括号匹配」想到栈或计数；「`'*'` 有三种取值」让暴力解变成 `3^k`。关键观察：不需要知道每个星号具体取了什么，只需要知道「此刻可能有多少个未配对的 `'('`」，而这个可能取值的集合恰好是一个连续区间，所以用两个整数就能表示。`n <= 100` 允许 `O(n^3)` 的区间 DP，但面试要的是 `O(n)` 的区间贪心。

**推导。** 暴力：每个星号三选一，`3^k` 种替换后各做一遍普通括号检查，`k` 个星号就是指数级。浪费：很多替换导致的「未配对左括号数」是一样的，只有这个数字对后续有影响。洞察：处理到第 `i` 个字符时，所有可能的未配对数构成区间 `[lo, hi]`——`'('` 整体右移，`')'` 整体左移，`'*'` 把区间向两侧各扩一格（当 `')'`、空串、`'('`）。未配对数不能为负，所以 `lo` 最低截到 `0`（多出来的星号当空串）；`hi < 0` 意味着连最乐观的取法都配不上，提前失败。扫完后只要 `0` 在区间里，就存在一种取法恰好配平。

```python
def check_valid_string(s: str) -> bool:
    lo = hi = 0                        # 还没配对的 '(' 数量的可能区间 [lo, hi]
    for ch in s:
        lo += 1 if ch == '(' else -1   # '*' 当 ')' 或 ')' 都让 lo 减一
        hi += 1 if ch != ')' else -1   # '*' 当 '(' 或 '(' 都让 hi 加一
        if hi < 0:                     # 即使全当 '(' 也配不上这个 ')'
            return False
        lo = max(lo, 0)                # 区间下界不能为负：多出来的 '*' 当空串
    return lo == 0                     # 0 在区间里，说明存在一种取法恰好配平
```

运行：`"()"` → `True`，`"(*)"` → `True`，`"(*))"` → `True`，`"*("` → `False`，`")*"` → `False`，`"*"` → `True`，`"(((*"` → `False`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**易错点。**
- 忘了把 `lo` 截到 `0`：`"*("` 里 `lo` 先变成 `-1`，再加一回到 `0`，误判为有效（`True`）；正确答案是 `False`，因为那个星号放在 `'('` 前面，没有任何字符可以让 `'('` 配对。
- `hi < 0` 要在每一步检查，不能留到最后：`")*"` 开头的 `')'` 就已经无解。
- 终点要判 `lo == 0`，不是 `lo <= 0` 也不是 `hi == 0`：`hi` 是最乐观的上界，`"(((*"` 的 `hi` 是 `4`，`lo` 是 `2`，`0` 不在区间里。

**追问。**
- 用两个栈存 `'('` 和 `'*'` 的下标：`')'` 先配 `'('` 再配 `'*'`；结束后每个剩余的 `'('` 必须配到它右边的 `'*'`。能还原出具体方案。
- 双向扫描：从左到右把星号都当 `'('`、从右到左把星号都当 `')'`，两次都不出现负数就有效，同样 `O(n)`。
- 括号种类变多（`[]{}`）：区间贪心不再成立（类型要对上），退回区间 DP 或带记忆的回溯。

**同模式。** LC 20 有效的括号、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号、LC 32 最长有效括号。
