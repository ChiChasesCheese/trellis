## Q
**LC 395 至少有 K 个重复字符的最长子串**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 16 次 · 最近 2026-09-08（国内 CodeTop）

给字符串 `s` 和整数 `k`，求 `s` 中最长的子串，要求该子串里**每个字符**出现的次数都不少于 `k`。返回这个子串的长度，不存在则返回 `0`。`1 <= s.length <= 10^4`，`s` 仅由小写英文字母组成，`1 <= k <= 10^5`。例：`s = "aaabb", k = 3` → `3`（`"aaa"`）；`s = "ababbc", k = 2` → `5`（`"ababb"`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 分治：统计整串字符次数，只要有字符出现次数 `< k`，任何包含它的子串都不合法，就按这个字符把串**切开**，对每一段递归求解；整串所有字符都满足时直接返回长度。`O(26 · n)`。

**识别。** 「子串里每个字符出现次数 `>= k`」是一个对**全体字符**的约束。先想滑动窗口，但窗口合法性**不单调**：`"aaab"` 非法，`"aaabbb"` 又合法，扩大窗口可能由非法变合法，也可能由合法变非法，经典的「违反就收缩左端」失效。突破口：字符集只有 `26`，且出现次数不足 `k` 的字符就像「地雷」，答案一定不跨过它。

**推导。** 暴力：枚举所有子串统计次数，`O(n^2 · 26)`，`n = 10^4` 太慢 → 滑窗不单调，换个维度：枚举窗口内**恰好有 `t` 种字符**（`t = 1..26`），此时「种类数超了就收缩」是单调的，每轮 `O(n)`，共 `O(26n)`（见追问）→ 另一条路：整串里次数 `< k` 的字符 `c` 绝不出现在答案里，按 `c` 切开，每段是独立的子问题；每次至少排除一种字符，递归深度 `<= 26`，每层总工作量 `O(n)`。

```python
from collections import Counter

def longest_substring(s: str, k: int) -> int:
    if len(s) < k:
        return 0
    count = Counter(s)
    bad = next((ch for ch, c in count.items() if c < k), None)   # 任意一个出现次数不足 k 的字符
    if bad is None:
        return len(s)                          # 整串已经合法
    return max(longest_substring(part, k) for part in s.split(bad))   # 含 bad 的子串一定不合法，按它切开
```

运行：`("aaabb", 3)` → `3`，`("ababbc", 2)` → `5`，`("a", 2)` → `0`，`("a", 1)` → `1`，`("abc", 100000)` → `0`；`10^4` 个随机小写字母 `k = 2` 瞬间返回。

**复杂度。** 时间 `O(26 · n)`：每深入一层至少排除一种字符，深度 `<= 26`，每层各段长度之和不超过 `n`；空间 `O(26 + 递归深度)`，切片本身会产生 `O(n)` 的临时字符串。

**易错点。**
- 把次数不足的字符**删除**再拼起来，而不是**切开**：`"aaacbbb", k = 3` 删掉 `c` 得 `"aaabbb"`，长度 `6`；正确是 `3`（`"aaa"` 与 `"bbb"` 被 `c` 隔开，不能连成一个子串）。
- 用普通双指针：窗口合法性不单调，会漏解。
- 忘了 `len(s) < k` 的剪枝：不影响正确性，但会多递归很多空段（`s.split(bad)` 可能产生空串）。

**追问。**
- 滑动窗口解法：枚举窗口内允许的不同字符种数 `t`，维护 `unique`（种数）和 `enough`（次数已达 `k` 的种数），`unique == enough == t` 时更新答案；`O(26n)`，无递归。
- 要返回子串本身：递归函数同时返回 `(长度, 起点)`，或用滑窗记录最佳左端点。
- 字符集很大（不再是 26）：分治深度可达 `n`，最坏 `O(n^2)`；此时滑窗枚举种数也不可取，改用其他结构（如按次数排序后用并查集 / 线段树）。
