## Q
**补充题23 检测循环依赖**｜Medium · 字节 高频

一个项目有 `n` 个模块，编号 `0` 到 `n - 1`。依赖关系用列表 `deps` 给出，`deps[k] = [a, b]` 表示模块 `a` 依赖模块 `b`（构建 `a` 之前必须先构建 `b`）。判断这些依赖里是否存在**循环依赖**：沿着「依赖」一路走下去，能否回到出发的模块（模块依赖它自己也算循环）。`1 <= n <= 10^5`，`0 <= len(deps) <= 2 * 10^5`，`0 <= a, b < n`，同一对依赖可能重复出现。例：`n = 3`，`deps = [[1,0],[2,1]]` → `False`（可按 `0, 1, 2` 的顺序构建）；`n = 3`，`deps = [[0,1],[1,2],[2,0]]` → `True`；`n = 1`，`deps = [[0,0]]` → `True`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把「`a` 依赖 `b`」看成有向边 `b -> a`，做拓扑排序（Kahn 算法）：反复取走入度为 `0` 的模块并删掉它发出的边；最后取走的模块数小于 `n`，说明剩下的模块永远凑不齐前置依赖，图里有环。`O(n + m)`。

**识别。** 「依赖 / 先后顺序」加「是否存在互相等待」是**有向图判环**。两个经典做法：拓扑排序（入度表加队列），或深度优先搜索三色标记（未访问 / 在当前路径上 / 已完成，撞上“在当前路径上”的点就是环）。`n` 到 `10^5`，依赖链可以有十万层，递归深度会超过 Python 的默认递归上限，所以用迭代的 Kahn 算法最稳。

**推导。** 暴力：对每个模块做一次搜索，看能否走回自己，`O(n * (n + m))`，`10^5` 个模块超时。浪费：同一段依赖链被重复搜索。观察：没有任何前置依赖（入度为 `0`）的模块一定不在环上，可以直接“构建完成”；它完成后，依赖它的模块少了一个等待项。这个“剥洋葱”的过程每条边只处理一次：能被剥完说明无环，剥不完剩下的模块要么在环上，要么（间接）依赖环上的模块。

```python
from collections import deque

def has_cycle(n: int, deps: list[list[int]]) -> bool:
    graph: list[list[int]] = [[] for _ in range(n)]
    indeg = [0] * n
    for a, b in deps:                       # a 依赖 b：先有 b 才能有 a，边 b -> a
        graph[b].append(a)
        indeg[a] += 1
    queue = deque(i for i in range(n) if indeg[i] == 0)   # 没有任何前置依赖的模块先上
    done = 0
    while queue:
        u = queue.popleft()
        done += 1
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                queue.append(v)
    return done < n                         # 有模块始终入度不为 0：它们在环上或依赖环上的模块
```

运行：`(3, [[1,0],[2,1]])` → `False`，`(3, [[0,1],[1,2],[2,0]])` → `True`，`(1, [[0,0]])` → `True`，`(4, [[1,0],[2,1],[3,2],[1,3]])` → `True`，`(2, [])` → `False`；`10^5` 个模块的一条依赖链 → `False`，在链尾再加一条回到链头的依赖 → `True`。

**复杂度。** 时间 `O(n + m)`：建图一遍，每个模块出队一次，每条边处理一次；空间 `O(n + m)`。

**易错点。**
- 把依赖当成无向边，用并查集（union-find）判环：有向无环图也会误报。`n = 3`，`deps = [[0,1],[0,2],[1,2]]` 没有环，并查集给出 `True`，拓扑排序给出 `False`。
- 只从模块 `0` 出发做 DFS：不连通的图会漏掉别处的环。`n = 4`，`deps = [[2,3],[3,2]]`，从 `0` 出发只访问到 `0` 自己，得到 `False`，正确是 `True`。
- 递归 DFS 在 `10^5` 层的依赖链上抛 `RecursionError`。
- 自依赖 `[a, a]` 是环：`a` 的入度里包含自己，永远无法降到 `0`，上面的写法自然返回 `True`。重复的依赖对在入度里被计数多次，出队时也被扣减多次，结果不受影响。

**追问。**
- 要求输出一个具体的环：改用迭代 DFS 三色标记，路径上记下节点，撞上“在当前路径上”的点时截取路径。
- 要求输出构建顺序：Kahn 算法出队的顺序就是一个合法顺序（LC 210）。
- 依赖在线逐条新增：新增 `[a, b]` 前，从 `b` 出发搜索能否到达 `a`，能到达就会成环、拒绝这条依赖。
