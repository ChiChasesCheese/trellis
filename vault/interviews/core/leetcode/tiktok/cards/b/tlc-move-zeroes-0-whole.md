## Q
**LC 283 移动零**｜Easy · LC TikTok 热度 50/100 · CodeTop 国内累计 22 次 · 最近 2026-01-16（CodeTop）

给数组 `nums`，把所有 `0` 移到末尾，同时保持非零元素的相对顺序。必须**原地**操作，不能复制数组。`1 <= nums.length <= 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。进阶：尽量减少操作次数。例：`[0,1,0,3,12]` → `[1,3,12,0,0]`，`[0]` → `[0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 快慢指针：`read` 扫描整个数组，`write` 指向「下一个非零元素该放的位置」；遇到非零就和 `write` 位置交换，`write` 前进。扫完后 `nums[:write]` 是按原序排好的非零元素，后面全是 `0`。`O(n)` 时间、`O(1)` 空间。

**识别。** 「原地」+「保持相对顺序」+「按条件把一类元素挪到一侧」= 同向双指针（稳定划分，stable partition）。不稳定的划分（头尾指针互换）顺序会乱，这是和 LC 75 荷兰国旗的区别。

**推导。** 暴力：新建数组放非零再补零，`O(n)` 空间，违反「原地」→ 逐个删除零后补零：`list.remove` / `pop(i)` 每次 `O(n)`，总 `O(n^2)` → 观察：每个非零元素的最终位置 = 它前面非零元素的个数，这正好是 `write` → 一趟扫描，每个非零元素直接放到 `write`。进阶（少操作）：`write == read` 说明前面还没出现过零，元素本来就在位置上，跳过不写。

```python
def move_zeroes(nums: list[int]) -> None:
    write = 0                                  # nums[:write] 是已经排好的非零元素
    for read in range(len(nums)):
        if nums[read] != 0:
            if write != read:                  # write == read 说明前面还没有零，不用动
                nums[write], nums[read] = nums[read], 0
            write += 1
```

运行：`[0,1,0,3,12]` → `[1,3,12,0,0]`，`[0]` → `[0]`，`[1,2,3]` → `[1,2,3]`（零次写入），`[0,0,1]` → `[1,0,0]`，`[3,0]` → `[3,0]`；对象 `id` 不变，确实是原地。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。写入次数：每个位于零之后的非零元素交换一次（2 次写入）；没有零时一次都不写。

**易错点。**
- 头尾双指针互换零和末尾非零：`[0,1,0,3,12]` 得 `[12,1,3,0,0]`，相对顺序被破坏。
- 在函数里重新绑定 `nums = [x for x in nums if x] + [0] * k`：调用方的列表没变，`[0,1,0,3,12]` 仍是 `[0,1,0,3,12]`。要改原对象必须用下标赋值或 `nums[:] = ...`。

**追问。**
- 把指定值 `val` 移到末尾（或删除它，LC 27）：条件换成 `nums[read] != val`。
- 要求写入次数最少：`write == read` 时跳过不写；极端情形零很少时接近 0 次写入。
- 只需按「零 / 非零」稳定划分，其他元素也要稳定：同样的双指针，换成谓词函数即可。

**同模式。** LC 27 移除元素、LC 26 删除有序数组中的重复项、LC 75 颜色分类、LC 905 按奇偶排序数组。
