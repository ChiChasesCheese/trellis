## Q
**LC 1539 第 k 个缺失的正整数**｜Easy · LC TikTok 热度 50/100 · CodeTop 国内累计 2 次 · 最近 2025-05-07（国内 CodeTop）

给一个**严格升序**排列的正整数数组 `arr` 和整数 `k`，找出这个数组里缺失的第 `k` 个正整数。`1 <= arr.length <= 1000`，`1 <= arr[i] <= 1000`，`1 <= k <= 1000`，对所有 `i < j` 有 `arr[i] < arr[j]`。进阶：设计时间复杂度小于 `O(n)` 的算法。例：`arr = [2,3,4,7,11]`，`k = 5` → `9`（缺失的数是 `1, 5, 6, 8, 9, 10, …`）；`arr = [1,2,3,4]`，`k = 2` → `6`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** `arr[i]` 之前缺失的正整数个数是 `arr[i] - (i + 1)`，它随 `i` 单调不减；二分找第一个满足「缺失数 `>= k`」的下标 `lo`，答案就是 `lo + k`。`O(log n)`。

**识别。** 「严格升序」「第 `k` 个」「进阶要求低于 `O(n)`」是二分的信号。关键是把“缺了多少个”写成关于下标的单调函数：每个元素把它之前该有的数 `1..arr[i]` 里实际在数组中的个数 `i + 1` 减掉，剩下的就是缺失数。

**推导。** 暴力：从 `1` 开始逐个数，不在数组里的计数，数到第 `k` 个，`O(arr[-1] + k)`。线性：遍历数组，遇到 `x <= k` 就让 `k += 1`（数组里的数占掉了一个位置，答案后移一位），`O(n)`。二分：令 `miss(i) = arr[i] - (i + 1)`，单调不减。设 `lo` 是第一个满足 `miss(lo) >= k` 的下标（都不满足则 `lo = n`）。第 `k` 个缺失数在 `arr[lo-1]` 和 `arr[lo]` 之间，它前面有 `lo` 个数属于 `arr`，其余都是缺失数，所以答案是 `k + lo`；`lo = 0` 时前面没有数组元素，答案就是 `k`。

```python
def find_kth_positive(arr: list[int], k: int) -> int:
    lo, hi = 0, len(arr)                   # 在 [0, n] 上找第一个下标 i，使 arr[i] 之前缺失的数 >= k
    while lo < hi:
        mid = (lo + hi) // 2
        if arr[mid] - (mid + 1) >= k:      # arr[mid] 之前缺了 arr[mid] - (mid + 1) 个正整数
            hi = mid
        else:
            lo = mid + 1
    return lo + k                          # 答案前面有 lo 个数在 arr 里：第 k 个缺失数 = k + lo
```

运行：`([2,3,4,7,11], 5)` → `9`，`([1,2,3,4], 2)` → `6`，`([2], 1)` → `1`，`([1], 1)` → `2`，`([1000], 1000)` → `1001`，`(list(range(1, 1001)), 1000)` → `2000`。

**复杂度。** 时间 `O(log n)`；空间 `O(1)`。

**易错点。**
- 缺失个数漏掉 `+ 1`，写成 `arr[mid] - mid`：`([1], 1)` 得到 `1`（正确 `2`），`([1000], 1000)` 得到 `1000`（正确 `1001`）。
- 比较写成 `> k`：缺失数恰好等于 `k` 时，第 `k` 个缺失数在这个元素的前面。`([2], 1)` 得到 `2`（正确 `1`）。
- 在二分里直接返回 `arr[lo] - …` 会在 `lo == n` 时越界；用 `lo + k`，对 `lo = 0` 和 `lo = n` 都成立。

**追问。**
- 线性写法：`for x in arr: if x <= k: k += 1 else: break`，最后返回 `k`，`O(n)`，不到 5 行，作为基线。
- `arr` 不保证有序或有重复：先 `sorted(set(arr))` 再做同样的事，`O(n log n)`。
- `k` 极大（如 `10^18`）：二分仍是 `O(log n)`，答案最大是 `k + n`。

**同模式。** LC 268 丢失的数字、LC 41 缺失的第一个正数、LC 34 在排序数组中查找元素的第一个和最后一个位置、LC 704 二分查找。
