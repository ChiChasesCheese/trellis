## Q
**LC 647 回文子串**｜Medium · CodeTop 国内累计 8 次 · 最近 2026-03-03（CodeTop）

给字符串 `s`，统计其中**回文子串**的个数（子串连续；位置不同的相同子串分别计数）。`1 <= s.length <= 1000`，`s` 只含小写英文字母。例：`"abc"` → `3`（`"a"`、`"b"`、`"c"`），`"aaa"` → `6`（三个 `"a"`、两个 `"aa"`、一个 `"aaa"`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 中心扩展（expand around center）：每个回文有唯一的中心，`n` 个字符和 `n - 1` 个字符间隙共 `2n - 1` 个中心；从每个中心向两边扩，每扩成功一次就多一个回文。`O(n^2)` 时间、`O(1)` 空间。

**识别。** 「回文 + 子串（连续）+ 计数」：回文由中心对称定义，`s[l..r]` 是回文当且仅当 `s[l] == s[r]` 且 `s[l+1..r-1]` 是回文，所以要么从内向外扩（中心扩展），要么按长度填区间 DP 表。`n <= 1000` 允许 `O(n^2)`，排除 `O(n^3)`。

**推导。** 暴力枚举 `O(n^2)` 个子串、每个反转比较 `O(n)`，共 `O(n^3)` → 浪费在于 `s[l..r]` 的判断重复做了 `s[l+1..r-1]` 的工作 → 把同一中心的子串放在一起：从中心往外扩，每步只比较新的两端字符，一旦不等，更长的也都不是回文，立刻停 → 总共 `O(n^2)`，不需要额外空间。

```python
def count_substrings(s: str) -> int:
    n = len(s)
    total = 0
    for center in range(2 * n - 1):         # 2n-1 个中心：n 个字符 + n-1 个相邻字符之间的空隙
        left = center // 2
        right = left + center % 2           # 偶数编号：奇数长度回文；奇数编号：偶数长度回文
        while left >= 0 and right < n and s[left] == s[right]:
            total += 1                      # 每次成功外扩都对应一个新的回文子串
            left -= 1
            right += 1
    return total
```

运行：`"abc"` → `3`，`"aaa"` → `6`，`"a"` → `1`，`"abba"` → `6`，`"a" * 1000` → `500500`。

**复杂度。** 时间 `O(n^2)`：`2n - 1` 个中心，每个最多扩 `O(n)` 步（全相同字符时达到上界）；空间 `O(1)`。

**易错点。**
- 只从字符中心扩（漏掉间隙中心）：偶数长度回文全丢。`"abba"` 会得到 `4`，正确是 `6`（漏了 `"bb"` 和 `"abba"`）。
- 扩展条件里先判越界再比较字符：顺序写反时 `left = -1` 不报错，`s[-1]` 绕到末尾字符，会多算，`right = n` 时再抛 `IndexError`。

**追问。**
- 区间 DP：`dp[i][j]` 表示 `s[i..j]` 是否回文，`i` 从大到小、`j` 从小到大填，`O(n^2)` 时间和空间；它能 `O(1)` 回答任意子串是否回文，适合后续还要查询的场景（如 LC 131 分割回文串）。
- 返回最长回文子串（LC 5）：同样的扩展，记录最长的 `(left, right)`。
- `O(n)`：Manacher 算法，利用已知回文的对称性给每个中心一个初始半径，再继续扩。

**同模式。** LC 5 最长回文子串、LC 131 分割回文串、LC 516 最长回文子序列、LC 214 最短回文串。
