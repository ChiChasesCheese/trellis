## Q
**LC 120 三角形最小路径和**｜Medium · 字节高频

给三角形 `triangle`，求自顶向下的最小路径和。每一步只能移动到下一行中**相邻**的结点：当前在第 `i` 列，下一步可到下一行的第 `i` 列或第 `i + 1` 列。`1 <= triangle.length <= 200`，`triangle[0].length == 1`，`triangle[i].length == triangle[i - 1].length + 1`，`-10^4 <= triangle[i][j] <= 10^4`。例：`[[2],[3,4],[6,5,7],[4,1,8,3]]` → `11`（`2 + 3 + 5 + 1`）；`[[-10]]` → `-10`。进阶：只用 `O(n)` 额外空间（`n` 为总行数）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 自底向上 DP：从最后一行开始，把上一行每个数与下一行（已合并的）两个相邻值中较小者相加，一行行往上合并，最后剩一个数就是答案；只需要一行长度的数组。`O(n^2)` 时间（`n^2` 是三角形的格子数），`O(n)` 空间。

**识别。** 「只能走到相邻位置」+「路径和最小」是网格 / 三角形上的最优路径 DP：到达某格的最优值只依赖相邻的前驱（或后继）。自顶向下要处理每行两端只有一个前驱的边界；**自底向上**每个格子恰好有两个后继，没有边界特判，最后答案直接在 `dp[0]`。`n <= 200`，格子数约 `2 * 10^4`。

**推导。** 暴力：DFS 枚举所有路径，路径条数 `2^(n-1)`，指数级 → 浪费：不同路径经过同一个格子时，从这个格子往下的最小和是相同的 → 状态 `dp[i][j]`：从 `(i, j)` 走到底的最小路径和，`dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])` → 第 `i` 行只依赖第 `i+1` 行，用一个一维数组滚动，每合并一行长度少一。

```python
from itertools import pairwise

def minimum_total(triangle: list[list[int]]) -> int:
    dp = triangle[-1]                      # 从最底行开始；下面每轮新建列表，不会改动输入
    for row in reversed(triangle[:-1]):    # 自底向上，一行一行往上合并
        dp = [v + min(pair) for v, pair in zip(row, pairwise(dp))]
    return dp[0]
```

运行：`[[2],[3,4],[6,5,7],[4,1,8,3]]` → `11`，`[[-10]]` → `-10`；`200` 行、值在 `[-10^4, 10^4]` 的三角形约 `0.001` 秒；全是 `-10^4` 的 `200` 行 → `-2000000`；调用之后输入没有变化。

**复杂度。** 时间 `O(n^2)`，每个格子处理一次；空间 `O(n)`，一行的 `dp`。

**易错点。**
- 贪心：每步选下一行相邻两格里较小的。`[[-1],[2,3],[1,-1,-3]]` 贪心走 `-1 → 2 → -1`，和 `0`；最优是 `-1 → 3 → -3`，和 `-1`。局部最小会错过后面更大的收益。
- 一维数组原地更新时方向写反：想省掉每轮新建列表，改成 `dp[j] = row[j] + min(dp[j], dp[j + 1])`，必须从左到右（`dp[j + 1]` 此时还是旧值）。从右往左会读到刚更新过的 `dp[j + 1]`，示例 `[[2],[3,4],[6,5,7],[4,1,8,3]]` 得到 `12`，正确是 `11`。
- 自顶向下时忽略边界：每行两端的格子只有一个前驱，写 `dp[j-1]` 在 `j = 0` 时会回绕到末尾（负下标）而不报错，结果悄悄出错。

**追问。**
- 输出路径本身：每个格子记下"向下走哪一列"，最后从顶端沿记录走一遍。
- 就地修改（不额外开数组）：从倒数第二行起，直接 `triangle[i][j] += min(triangle[i+1][j], triangle[i+1][j+1])`，空间 `O(1)`，但破坏输入。
- 推广：下降路径最小和（LC 931，每步可到下一行的左、中、右三个位置）、矩形网格的最小路径和（LC 64）。

**同模式。** LC 64 最小路径和、LC 931 下降路径最小和、LC 62 不同路径、LC 118 杨辉三角。
