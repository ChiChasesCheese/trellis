## Q
**补充题 9 36进制加法**｜Medium · 字节高频

给两个非负的 36 进制数，用字符串 `num1`、`num2` 表示：数字 `0`~`9` 表示 0 到 9，小写字母 `a`~`z` 表示 10 到 35，除 `"0"` 本身外没有前导零，`1 <= len(num1), len(num2) <= 10^4`。返回它们的和，同样用 36 进制字符串表示。不能用内置的进制转换（比如 `int(s, 36)`）把整个数一次转成整数。例：`"zz" + "1"` → `"100"`；`"1z" + "1"` → `"20"`；`"abc" + "xyz"` → `"18ab"`；`"z" + "z"` → `"1y"`；`"0" + "0"` → `"0"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 竖式加法：两个指针从个位（字符串末尾）向前走，每一位把「两个数字 + 进位」相加，用 `divmod(总和, 36)` 同时得到进位和本位的数字，最后反转结果；循环条件里要包含「还有进位」。`O(max(m, n))`。

**识别。** 「大数加法 + 任意进制」：数字长度可达 `10^4`，超出机器整数，必须逐位处理；进制只影响两件事：字符与数值的映射、进位的基数。与十进制加法（LC 415 字符串相加）完全同构，把 `10` 换成 `36`。

**推导。** 暴力：转成整数相加再转回 36 进制 → 在 Python 里 `int(s, 36)` 对超过 `4300` 位的串会抛 `ValueError`（整数转字符串的长度保护），且转换本身 `O(n^2)`；其他语言更不可行 → 逐位模拟竖式：每位总和最大 `35 + 35 + 1 = 71`，所以进位只会是 `0` 或 `1` → `divmod(total, 36)` 一次得出进位与本位 → 数字从低位到高位产生，收集在列表里最后反转。

```python
import string

DIGITS = string.digits + string.ascii_lowercase       # "0-9a-z"，下标就是数值
VALUE = {ch: v for v, ch in enumerate(DIGITS)}       # 字符 -> 数值

def add_36(num1: str, num2: str) -> str:
    i, j, carry = len(num1) - 1, len(num2) - 1, 0
    out: list[str] = []
    while i >= 0 or j >= 0 or carry:           # 最后还有进位时也要再走一轮
        total = carry
        if i >= 0:
            total += VALUE[num1[i]]
            i -= 1
        if j >= 0:
            total += VALUE[num2[j]]
            j -= 1
        carry, digit = divmod(total, 36)
        out.append(DIGITS[digit])
    return "".join(reversed(out))
```

运行：`("zz", "1")` → `"100"`，`("1z", "1")` → `"20"`，`("abc", "xyz")` → `"18ab"`，`("z", "z")` → `"1y"`，`("9", "1")` → `"a"`，`("0", "0")` → `"0"`；`"z" * 10000` 加 `"1"` → 长度 `10001` 的 `"1000…0"`。

**复杂度。** 时间 `O(max(m, n))`；空间 `O(max(m, n))`，结果列表。

**易错点。**
- 漏掉最高位的进位：循环只写 `i >= 0 or j >= 0`。`"zz" + "1"` 得到 `"00"`，正确是 `"100"`；`"z" + "z"` 得到 `"y"`，正确是 `"1y"`。
- 字符到数值的映射按十进制处理，或者只处理数字不处理字母：`"19" + "1"` 在 36 进制里是 `"1a"`（`9 + 1 = 10` 对应 `a`），不是 `"20"`。
- 用 `int(num, 36)` 一次转换：`"z" * 10000` 在 Python 3.11 及以上抛 `ValueError: Exceeds the limit (4300 digits)`。

**追问。**
- 其他进制（2 到 36）：把 `36` 和字母表换成参数；超过 36 需要自定义符号表。
- 兼容大写字母：先 `lower()`，或者让映射表同时包含大写。
- 相乘（LC 43 字符串相乘）、相减：同样逐位模拟，乘法用"位置 `i + j`"累加再统一进位。

**同模式。** LC 415 字符串相加、LC 67 二进制求和、LC 2 两数相加（链表）、LC 43 字符串相乘、LC 989 数组形式的整数加法。
