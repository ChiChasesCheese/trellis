## Q
**LC 263 丑数**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-02-05（CodeTop）

丑数是只包含质因数 `2`、`3`、`5` 的**正**整数（`1` 没有质因数，也算丑数）。给整数 `n`，判断它是否为丑数。`-2^31 <= n <= 2^31 - 1`。例：`6` → `true`（`6 = 2 × 3`）；`1` → `true`；`14` → `false`（含质因数 `7`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 非正数直接返回 `False`；否则把 `n` 里的因子 2、3、5 依次除干净，剩下的是 1 就是丑数。`O(log n)`。

**识别。** 「只包含某几个质因数」= 去掉这些质因数后什么都不剩，所以做法是**反复整除**。范围包含负数和 0，要先处理：丑数定义要求正整数，而 `0 % p == 0` 恒成立，不处理会死循环。

**推导。** 暴力：对 `n` 做完整的质因数分解（试除到 `sqrt(n)`，约 `4.6 × 10^4` 次），检查有没有 2、3、5 以外的质因数。浪费在于只关心「除了 2、3、5 还有没有别的」，不需要知道别的是什么。把 2、3、5 除干净后，剩余部分要么是 1，要么含有别的质因数，一次比较就能判断。每次整除至少让 `n` 减半，总共 `O(log n)` 次。

```python
def is_ugly(n: int) -> bool:
    if n <= 0:                       # 丑数必须是正整数；0 还会让下面的循环永不停止
        return False
    for p in (2, 3, 5):
        while n % p == 0:            # 把因子 p 除干净
            n //= p
    return n == 1                    # 只剩 1，说明没有 2、3、5 以外的质因数
```

运行：`6` → `True`，`1` → `True`，`14` → `False`，`0` → `False`，`-6` → `False`，`2^30` → `True`，`2^31 - 1` → `False`。

**复杂度。** 时间 `O(log n)`：每次整除至少减半，`2^31` 以内最多 31 次；空间 `O(1)`。

**易错点。**
- 漏掉 `n <= 0` 的判断：`n = 0` 时 `0 % 2 == 0` 永远成立，`while` 死循环。
- 用 `/` 而不是 `//`：`n` 变成浮点数，返回值的类型和比较都不再干净；整数运算一律用 `//`。

**追问。**
- 第 `n` 个丑数（LC 264）：三指针动态规划，`O(n)`。
- 质因数换成任意给定列表（LC 313 超级丑数）：多指针或最小堆。
- 能被 `a`、`b`、`c` 之一整除的第 `n` 个数（LC 1201）：二分答案 + 容斥原理。

**同模式。** LC 264 丑数 II、LC 313 超级丑数、LC 1201 丑数 III、LC 326 3 的幂。
