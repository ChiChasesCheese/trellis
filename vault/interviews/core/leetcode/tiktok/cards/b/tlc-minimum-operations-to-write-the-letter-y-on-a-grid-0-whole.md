## Q
**LC 3071 在矩阵上写出字母 Y 所需的最少操作次数**｜Medium · LC TikTok 全时段热度 50/100

给下标从 `0` 开始、大小为 `n x n` 的矩阵 `grid`，`n` 为奇数，`grid[r][c]` 的值为 `0`、`1` 或 `2`。属于以下三条线之一的单元格算作字母 `Y` 的一部分：从左上角开始到中心单元格的对角线；从右上角开始到中心单元格的对角线；从中心单元格开始到矩阵底部边界的竖直线。当且仅当 `Y` 上的所有单元格值相等、不属于 `Y` 的所有单元格值相等、并且两个值不同，才算写出了字母 `Y`。每次操作可以把任意单元格的值改成 `0`、`1` 或 `2`。返回写出 `Y` 所需的最少操作次数。`3 <= n <= 49`，`n` 为奇数。例：`[[1,2,2],[1,1,0],[0,1,0]]` → `3`；`[[0,1,0,1,0],[2,1,0,1,2],[2,2,2,0,1],[2,2,2,2,2],[2,1,2,2,2]]` → `12`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 分别统计 `Y` 内和 `Y` 外各个值（`0`、`1`、`2`）的出现次数；枚举 `Y` 的目标值 `a` 和 `Y` 外的目标值 `b`（`a != b`，共 `6` 种），操作数是 `总格数 - (Y 内等于 a 的格数) - (Y 外等于 b 的格数)`；取最小。`O(n^2)`。

**识别。** 值域只有 `3` 个，要把两个区域各自统一成某个值，并且两个值必须不同，是「计数加枚举有限组合」的模板，用 `Counter` 即可。真正的难点不在算法，而在把“哪些格子属于 `Y`”判断对。

**推导。** 暴力：对 `6` 个 `(a, b)` 组合各扫一遍矩阵，逐格比较，`6 · n^2`，已经是 `O(n^2)`。更干净的写法：扫一遍统计两个 `Counter`，然后 `6` 个组合各 `O(1)` 算出。洞察：把格子改成目标值的代价是“当前不等于目标的格数”，也就是 `总数 - 已经等于目标的格数`；`Y` 内与 `Y` 外互相独立，只被“`a != b`”这一个条件耦合。判定 `Y` 格：设 `mid = n // 2`；行 `r <= mid` 时，列 `c == r` 或 `c == n - 1 - r`（两条对角线，在 `r = mid` 处汇合于中心）；行 `r > mid` 时，列 `c == mid`（中心下方的竖线）。

```python
from collections import Counter
from itertools import permutations


def minimum_operations_to_write_y(grid: list[list[int]]) -> int:
    n = len(grid)
    mid = n // 2
    in_y: Counter[int] = Counter()         # Y 上各个值的出现次数
    out_y: Counter[int] = Counter()        # Y 外各个值的出现次数
    for r, row in enumerate(grid):
        for c, v in enumerate(row):
            on_y = (r <= mid and (c == r or c == n - 1 - r)) or (r > mid and c == mid)   # 两条对角线（到中心）+ 竖线（中心以下）
            (in_y if on_y else out_y)[v] += 1
    # Y 内统一成 a，Y 外统一成 b，且 a != b；改动数 = 总格数 - 已经正确的格数
    return min(n * n - in_y[a] - out_y[b] for a, b in permutations(range(3), 2))
```

运行：`[[1,2,2],[1,1,0],[0,1,0]]` → `3`，`[[0,1,0,1,0],[2,1,0,1,2],[2,2,2,0,1],[2,2,2,2,2],[2,1,2,2,2]]` → `12`，全 `1` 的 `3 × 3` → `4`，全 `0` 的 `3 × 3` → `4`；`n = 49` 时 `Y` 有 `73` 个格子。

**复杂度。** 时间 `O(n^2)`；空间 `O(1)`（两个只含 `3` 个键的计数器）。

**易错点。**
- 允许 `a == b`，枚举 `product(range(3), repeat=2)`：全 `1` 的 `3 × 3` 得到 `0`（正确 `4`），示例 2 得到 `11`（正确 `12`）。题目要求 `Y` 与非 `Y` 的值不同。
- 把竖线画成整条中线，漏掉“只到中心以下”的限制：中心上方的格子也被算进 `Y`，示例 2 得到 `10`（正确 `12`）。竖线只从中心开始向下。
- 对角线只画到中心：行 `r > mid` 不能再用 `c == r` 或 `c == n - 1 - r` 判断，否则会把下半部分的另外两条对角线也算进去。

**追问。**
- 值域扩大到 `k` 种：每个区域只需要考虑出现次数最多的两个值（含次数为 `0` 的值），因为 `a != b` 的冲突最多占用其中一个，枚举 `O(1)` 个组合而不是 `k^2` 个。
- 把 `Y` 换成任意形状（字母 `X`、`H`）：只要换一个“是否在形状上”的判断函数，其余完全不变。
- 要求输出具体应改成什么：同时记下取到最小值的 `(a, b)`，再扫一遍即可。
