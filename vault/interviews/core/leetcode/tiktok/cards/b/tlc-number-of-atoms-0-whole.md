## Q
**LC 726 原子的数量**｜Hard · CodeTop 国内累计 8 次 · 最近 2026-09-21（国内 CodeTop）

给一个字符串化学式 `formula`，返回每种原子的数量。原子名以一个大写字母开头，后面跟 `0` 个或多个小写字母；数量大于 `1` 时原子后面跟数字，等于 `1` 时不写数字（`"H2O"` 合法，`"H1O2"` 不合法）。两个化学式连在一起仍是化学式（`"H2O2He3Mg4"`）；括号括起的化学式后可以跟一个数字倍数（`"(H2O2)"`、`"(H2O2)3"`）。输出格式：按原子名的字典序，每个原子名后面跟数量（数量为 `1` 则省略）。`1 <= formula.length <= 1000`，由英文字母、数字、`(`、`)` 组成，保证是有效化学式。例：`"H2O"` → `"H2O"`；`"Mg(OH)2"` → `"H2MgO2"`；`"K4(ON(SO3)2)2"` → `"K4N2O14S4"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 栈里放一串计数器（`Counter`）：遇到 `(` 压入一个新计数器，原子累加到栈顶计数器，遇到 `)` 弹出栈顶、读后面的倍数、乘上之后并入新的栈顶；最后对栈底计数器按原子名排序输出。用正则一次把字符串切成 token。

**识别。** 「嵌套括号 + 倍数」是栈的信号（同族：LC 394 字符串解码、LC 224 基本计算器）。关键是倍数写在 `)` **后面**：读到 `(` 时不知道倍数，所以每层括号各自累计、弹出时再统一乘。输出要排序，所以最后一步按名字排。`n <= 1000`，线性或平方都可以。

**推导。** 暴力：把括号展开成一长串原子再数。`"((((H2)2)2)2)2"` 这样的嵌套倍数相乘是指数增长，展开会爆炸。浪费在于重复展开：每层只需要一个「原子 → 个数」的表，倍数直接乘进计数里，不用复制内容。扫描时遇到 `(` 开新层，遇到 `)` 把这一层乘倍数后并回上一层。原子名的切分用正则 `[A-Z][a-z]*`，数字用 `\d*`，括号单独成 token。

```python
import re
from collections import Counter

TOKEN = re.compile(r"([A-Z][a-z]*)(\d*)|(\()|\)(\d*)")


def count_of_atoms(formula: str) -> str:
    stack: list[Counter[str]] = [Counter()]    # 栈顶是当前括号层的计数
    for m in TOKEN.finditer(formula):
        name, num, left, close_num = m.groups()
        if name:                                # 原子：加到当前层
            stack[-1][name] += int(num or 1)
        elif left:                              # '(': 开一层新计数
            stack.append(Counter())
        else:                                   # ')': 弹出这一层，乘倍数后并回上一层
            inner = stack.pop()
            mult = int(close_num or 1)
            for atom, cnt in inner.items():
                stack[-1][atom] += cnt * mult
    return "".join(a + (str(c) if c > 1 else "") for a, c in sorted(stack[0].items()))
```

运行：`"H2O"` → `"H2O"`，`"Mg(OH)2"` → `"H2MgO2"`，`"K4(ON(SO3)2)2"` → `"K4N2O14S4"`，`"(H2O)10"` → `"H20O10"`，`"((H))"` → `"H"`，`"Uuo(U)2"` → `"U2Uuo"`。

**复杂度。** 时间 `O(n · k)`：`n` 是字符串长度，`k` 是不同原子的种类数（每次 `)` 合并一层要遍历该层的所有种类）；空间 `O(n)`（栈深度与计数器）。

**易错点。**
- 原子名只取一个大写字母：`"Mg(OH)2"` 会把 `Mg` 的 `g` 丢掉，得到 `"H2MO2"`（正确 `"H2MgO2"`）。要用 `[A-Z][a-z]*`。
- 忽略 `)` 后的倍数：`"Mg(OH)2"` 得到 `"HMgO"`，`"K4(ON(SO3)2)2"` 得到 `"K4NO4S"`。
- 数量为 `1` 不写数字；排序是按**原子名**的字典序（`"U"` 排在 `"Uuo"` 前面），不是按数量或出现顺序。

**追问。**
- 数量非常大：Python 整数不会溢出；在 Java / C++ 里用 `BigInteger` 或按题目要求取模。
- 括号嵌套很深：这里的显式栈没有递归深度问题；递归下降写法在长度 `1000`、嵌套 `499` 层时刚好不超默认递归上限。
- 支持 `[]`、`{}` 多种括号：token 正则加上这两类，栈的压入弹出对应各类括号即可。

**同模式。** LC 394 字符串解码、LC 224 基本计算器、LC 772 基本计算器 III、LC 439 三元表达式解析器、LC 20 有效的括号。
