## Q
**剑指 Offer 10- II 青蛙跳台阶问题**｜Easy · CodeTop 国内累计 9 次 · 最近 2026-04-12（国内 CodeTop）

一排平台共有 `n` 个格子，每次可以跳 **1 个格子或 2 个格子**，求从起点跳完全部 `n` 个格子的不同跳法数。结果对 `1000000007` 取模（例如算出 `1000000008` 时返回 `1`）。`0 <= n <= 100`。例：`n = 2` → `2`（1+1、2）；`n = 5` → `8`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 跳完 `n` 格的最后一跳要么是 1 格、要么是 2 格，所以 `f(n) = f(n - 1) + f(n - 2)`，`f(0) = f(1) = 1`；只依赖前两项，用两个变量从小到大推，每步取模。时间 `O(n)`，空间 `O(1)`。

**识别。** 「每次走 1 步或 2 步，求方案数」是一维动态规划（dynamic programming）的信号：按**最后一步**分类，各类互不重叠、合起来覆盖全部方案，方案数相加。「结果取模」说明数值会很大，每步都要取模。`n <= 100` 很小，但不带记忆的递归是指数级。

**推导。** 直接递归 `f(n) = f(n-1) + f(n-2)` 会把同一个 `f(k)` 重复算很多次，调用次数约 `1.6^n`，`n = 100` 根本算不完。加记忆化（memoization）后每个 `f(k)` 只算一次，`O(n)` 时间、`O(n)` 空间。再观察到 `f(k)` 只用到前两项，自底向上只保留两个变量，空间降到 `O(1)`。

```python
def num_ways(n: int) -> int:
    MOD = 1_000_000_007
    a, b = 1, 1                      # a = f(i)，b = f(i + 1)；从 f(0) = f(1) = 1 开始
    for _ in range(n):
        a, b = b, (a + b) % MOD      # 右边先全部求值，再一起赋给左边
    return a
```

运行：`n = 0` → `1`，`1` → `1`，`2` → `2`，`5` → `8`，`45` → `836311896`（未取模是 `1836311903`），`100` → `782204094`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 初值写成斐波那契数列的 `a, b = 0, 1`：`n = 2` 会错成 `1`（正确 `2`），`n = 0` 会错成 `0`（正确 `1`，不跳也是一种方案）。
- 只在最后取模：Python 整数不会溢出，结果仍对，但中间数会变得很大；Java / C++ 里会溢出。每步取模才对。

**追问。**
- 每次可跳 `1..n` 格：`f(n) = 2^(n-1)`（`n >= 1`），每个中间格「落或不落」两种选择。
- `n` 到 `10^18`：矩阵快速幂（matrix fast power），`[[1,1],[1,0]]` 的 `n` 次方，`O(log n)`。
- 某些格子不能落脚：落在禁止格的 `f` 记为 0，递推不变。

**同模式。** LC 70 爬楼梯、LC 509 斐波那契数、LC 746 使用最小花费爬楼梯、LC 91 解码方法。
