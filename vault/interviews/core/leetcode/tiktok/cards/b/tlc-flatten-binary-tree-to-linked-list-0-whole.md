## Q
**LC 114 二叉树展开为链表**｜Medium · 字节高频

给二叉树的根节点 `root`，原地把它展开成一个单链表：仍用 `TreeNode`，`right` 指向链表的下一个节点，`left` 始终为 `null`，顺序与先序遍历相同。节点数在 `[0, 2000]`，`-100 <= Node.val <= 100`。例：`[1,2,5,3,4,null,6]` → `[1,null,2,null,3,null,4,null,5,null,6]`；`[]` → `[]`；`[0]` → `[0]`。进阶：用 `O(1)` 额外空间。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对每个有左子树的节点，找到左子树里先序最后一个节点（左子树的最右下节点），把当前节点的右子树接在它后面，再把左子树整体搬到右边、左指针置空，然后沿 `right` 走到下一个节点。`O(n)` 时间，`O(1)` 空间。

**识别。** 「原地」+「先序顺序」+「O(1) 空间」：先序是「根、左子树、右子树」，展开后左子树必须排在右子树前面，而左子树结束的位置（右链末端）要连上原来的右子树——这就是 Morris 遍历（用前驱节点的空指针做临时连接）的核心操作。`n` 到 `2000`，深度可达 `2000`，Python 递归会超过默认的 `1000` 层，迭代更稳。

**推导。** 暴力：先序遍历把节点收进列表，再逐个改指针，`O(n)` 时间 `O(n)` 空间 → 浪费在额外列表 → 递归后序（右、左、根）用 `prev` 指针逆向拼接，空间是递归栈 `O(h)` → 洞察：把 `cur` 的右子树挂到左子树的「右链末端」`pred.right`，再把左子树搬到 `cur.right`，整棵树的先序序列**一点没变**——因为走完 `pred`（及它自己的左子树）之后，整棵左子树的先序恰好结束，原右子树本来就接在这之后 → 每次拼接保持先序不变，且让 `cur` 的左指针清空；沿 `right` 走完所有节点，最后全部左指针为空，先序序列就是这条右链。

```python
def flatten(root: TreeNode | None) -> None:
    cur = root
    while cur:
        if cur.left:
            pred = cur.left                # 从左孩子出发，沿右链走到头
            while pred.right:
                pred = pred.right
            pred.right = cur.right         # 先把原右子树接在右链末端
            cur.right = cur.left           # 再把左子树整体搬到右边
            cur.left = None
        cur = cur.right
```

运行：`[1,2,5,3,4,null,6]` → `[1,null,2,null,3,null,4,null,5,null,6]`，`[]` → `[]`，`[0]` → `[0]`，深度 2000 的左链展开后沿 `right` 数到 `2000` 个节点。

**复杂度。** 时间 `O(n)`：每个节点至多被「沿右链找末端」的内层循环经过一次（搬到主链之后它只能经 `right` 到达，不会再出现在别的节点的左子树里）；空间 `O(1)`。

**易错点。**
- 顺序：必须**先**把原右子树接到 `pred.right`，**再**覆盖 `cur.right`。直接写 `cur.right = cur.left`，原右子树就丢了。`[1,2,5,3,4,null,6]` 会只剩 `[1,null,2,null,3]`，正确有 `6` 个节点。
- 左指针要置 `None`，否则展开后还留着指向旧子树的 `left`，形成环或重复访问。
- 函数没有返回值：LeetCode 检查的是原树被改成什么样，不要新建树再返回。

**追问。**
- 用栈：先序遍历时记 `prev`，每弹出一个节点就让 `prev.right = node`、`prev.left = None`；右孩子先入栈、左孩子后入栈，`O(h)` 空间。
- 递归的「逆后序」：按「右、左、根」访问，维护全局 `prev`，`node.right = prev; node.left = None; prev = node`，代码最短，但递归深度等于树高。
- 展开成中序链表（LC 426 的变体）或展开多级双向链表（LC 430）：换遍历顺序或多一个 `prev` 指针。

**同模式。** LC 430 扁平化多级双向链表、LC 426 将二叉搜索树转化为排序的双向链表、LC 144 二叉树的先序遍历、LC 94 二叉树的中序遍历（Morris 遍历）。
