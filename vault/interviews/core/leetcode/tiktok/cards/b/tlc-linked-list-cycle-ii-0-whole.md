## Q
**LC 142 环形链表 II**｜Medium · 字节 高频

给一个链表的头结点 `head`，返回链表**开始入环的第一个结点**；链表无环则返回 `null`。链表有环，指的是通过连续跟踪 `next` 指针能再次到达某个结点（评测系统用 `pos` 表示尾结点连回的下标，`-1` 表示无环；`pos` 不作为参数传入）。**不允许修改**链表。

约束：结点数在 `[0, 10^4]`，`-10^5 <= Node.val <= 10^5`，`pos` 为 `-1` 或链表中的有效下标。进阶：能否用 `O(1)` 空间？

例：`head = [3,2,0,-4], pos = 1` → 返回下标 `1` 的结点（值 `2`）；`head = [1], pos = -1` → `null`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** Floyd 判圈：快指针每次两步、慢指针每次一步，有环必在环内相遇；相遇后把慢指针放回表头，两个指针都改成每次一步，它们再次相遇的结点就是入环点。`O(n)` 时间、`O(1)` 空间。

**识别。** 「链表是否有环 / 环的入口」+「`O(1)` 空间」是 Floyd 快慢指针（龟兔赛跑）的标志；`O(n)` 空间的哈希集合是明显的退而求其次。「不许修改链表」排除了做标记的方案。

**推导。** 哈希法：遍历时把结点存进集合，第一次遇到集合中已有的结点就是入环点，`O(n)` 空间。想要 `O(1)` 空间：快慢指针先判断有环。设表头到入环点距离 `a`，入环点到相遇点距离 `b`，相遇点回到入环点距离 `c`（环长 `b + c`）。相遇时慢走了 `a + b`，快走了 `a + b + k(b + c)`（多绕了 `k` 圈），而快是慢的两倍：`2(a + b) = a + b + k(b + c)`，化简得 `a = (k - 1)(b + c) + c`。意思是：从表头走 `a` 步，等于从相遇点走 `c` 步再加若干整圈——也就是正好走到入环点。所以第二个指针从相遇点出发、另一个从表头出发，同速前进，必在入环点相遇。

```python
def detect_cycle(head: ListNode | None) -> ListNode | None:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next               # 慢指针一步
        fast = fast.next.next          # 快指针两步
        if slow is fast:               # 在环内相遇：还不知道入环点
            slow = head                # 慢指针回表头，两个指针都改成每次一步
            while slow is not fast:
                slow, fast = slow.next, fast.next
            return slow                # 再次相遇的位置就是入环点
    return None                        # 快指针走到尽头：无环
```

运行：`head=[3,2,0,-4], pos=1 → 返回的结点值` → `2`，`head=[1,2], pos=0 → 返回的结点值` → `1`，`head=[1], pos=-1` → `None`，`head=[1], pos=0（自环）→ 返回的结点值` → `1`，`head=[]` → `None`，`10^4 个结点，pos=0 → 返回结点是否就是 head` → `True`。

**复杂度。** 时间 `O(n)`：第一阶段快慢指针至多走 `O(n)` 步相遇，第二阶段两个指针各走 `a` 步（`a` 为表头到入环点的距离）；空间 `O(1)`。

**易错点。**
- 把相遇点当入环点：快慢指针第一次相遇的结点一般在环内部。题面例 `[3,2,0,-4]`, `pos=1` 的入环点是值 `2` 的结点，快慢指针第一次相遇在值 `-4` 的结点，直接返回相遇点会得 `-4`。
- 用 `val` 比较判断相遇：结点值可重复。无环的 `[1,1,1,1]` 里 `slow.val == fast.val` 立即成立，会误判有环；要用 `is` 比较结点身份。
- 循环条件漏掉 `fast`：写成 `while fast.next` 时，无环且偶数个结点（如 `[1,2]`）快指针走到 `None`，再取 `.next` 抛 `AttributeError`；必须 `while fast and fast.next`。
- 第二阶段忘了把其中一个指针放回表头，或者两个指针速度还不一样：必须都是一步。

**追问。**
- 只判断是否有环（LC 141）：第一阶段相遇就返回 `True`。
- 求环的长度：相遇后让一个指针原地绕一圈，数步数；或相遇后记录，再走到再次相遇。
- 数组版（LC 287 寻找重复数）：把 `i -> nums[i]` 当作 `next`，重复数就是入环点，同一套 Floyd，不能修改数组、`O(1)` 空间。

**同模式。** LC 141 环形链表、LC 287 寻找重复数、LC 202 快乐数（判环）、LC 160 相交链表、LC 876 链表的中间结点。
