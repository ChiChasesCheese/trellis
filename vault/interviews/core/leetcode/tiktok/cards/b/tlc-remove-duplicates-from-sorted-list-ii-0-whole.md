## Q
**LC 82 删除排序链表中的重复元素 II**｜Medium · CodeTop 国内累计 49 次 · 最近 2026-08-05（国内 CodeTop）

给一个**已排序**（升序）的链表头结点 `head`，删除所有出现重复数字的结点（重复的数字一个都不保留，只留下只出现一次的数字），返回仍然有序的链表。

约束：结点数在 `[0, 300]`，`-100 <= Node.val <= 100`，保证链表按升序排列。

例：`head = [1,2,3,3,4,4,5]` → `[1,2,5]`；`head = [1,1,1,2,3]` → `[2,3]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用一个哑结点做头，`prev` 指向最后一个确认保留的结点，`cur` 往前扫：如果 `cur` 与后一个值相同，就把这一整段相同值的结点全部跳过，并让 `prev.next` 直接指向段后第一个结点；否则 `cur` 是唯一值，`prev` 前进。`O(n)` 时间、`O(1)` 空间。

**识别。** 「已排序链表」+「重复值」：排序意味着重复值**相邻**，不需要哈希表；「删除头结点也有可能」→ 哑结点（dummy node）；「重复的一个都不留」与 LC 83（留一个）的区别是：必须跳过整段，而且要等整段结束才知道 `prev` 该接到哪里。

**推导。** 哈希表法：先扫一遍统计每个值的出现次数，再扫一遍把计数不为 1 的结点删掉，`O(n)` 时间 `O(n)` 空间，没用上「有序」。排序给了更强的信息：重复值相邻，所以看 `cur` 与 `cur.next` 是否相同就知道 `cur` 是否属于重复段。重复段从 `cur` 开始，用内层循环跳到第一个值不同的结点；此时 `prev.next` 接到它，但 `prev` 不能前进，因为这个新结点可能又是另一段重复值的开头。只有确认 `cur` 唯一时才推进 `prev`。头结点可能被删，所以用哑结点作为 `prev` 的起点。

```python
def delete_duplicates(head: ListNode | None) -> ListNode | None:
    dummy = ListNode(0, head)          # 头结点也可能被删，所以需要哑结点
    prev, cur = dummy, head            # prev：最后一个确认保留的结点
    while cur:
        if cur.next and cur.next.val == cur.val:
            dup = cur.val
            while cur and cur.val == dup:   # 整段重复值一个不留
                cur = cur.next
            prev.next = cur            # 接到段后面；prev 不前进，cur 可能又是新一段的开头
        else:
            prev, cur = cur, cur.next  # cur 是唯一值：确认保留
    return dummy.next
```

运行：`head=[1,2,3,3,4,4,5]` → `[1, 2, 5]`，`head=[1,1,1,2,3]` → `[2, 3]`，`head=[]` → `[]`，`head=[1,1]（全是重复）` → `[]`，`head=[1,1,2,2,3]` → `[3]`。

**复杂度。** 时间 `O(n)`：每个结点至多被访问常数次；空间 `O(1)`（只有几个指针，原地修改）。

**易错点。**
- 只删掉多余的、留一个（LC 83 的做法）：`[1,2,3,3,4,4,5]` 得 `[1,2,3,4,5]`，此处要的是 `[1,2,5]`。
- 跳过重复段后让 `prev` 前进：`[1,1,2,2,3]` 得 `[2,3]`，正确是 `[3]`——`prev` 走到了后一段重复值的开头，然后这段被跳过时 `prev.next` 却把自己接到 `3`，等于保留了 `2`。
- 没有哑结点：头结点属于重复段时没有 `prev` 可接，`[1,1,2]` 仍返回原头，结果 `[1,1,2]` 而不是 `[2]`。
- 内层循环忘了判 `cur` 为空：`while cur.val == dup` 在重复段延伸到链表末尾时会对 `None` 取 `.val`，抛出 `AttributeError`，如 `[1,1]`。

**追问。**
- 链表**无序**：先用 `Counter` 统计，再一遍扫描删除计数不为 1 的结点；或者先排序（归并排序链表 `O(n log n)`）再用此处。
- 递归写法：`head` 与 `head.next` 不同则 `head.next = f(head.next)`；相同则跳过整段后返回 `f(段后)`。代码短，深度最多 `n`（此处 `≤ 300`）。
- 只保留重复的值（相反的题）：条件反过来，唯一值被删除；仍用同一套 `prev` / 跳段的框架。

**同模式。** LC 83 删除排序链表中的重复元素（留一个）、LC 26 / 80 删除有序数组中的重复项、LC 203 移除链表元素、LC 19 删除链表的倒数第 N 个结点、LC 148 排序链表。
