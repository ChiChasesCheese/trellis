## Q
**LC 516 最长回文子序列**｜Medium · CodeTop 国内累计 9 次 · 最近 2026-04-06（国内 CodeTop）

给字符串 `s`，求其中最长的**回文子序列**的长度。子序列是删去某些字符（或不删）、不改变剩余字符顺序得到的序列，不要求连续。`1 <= s.length <= 1000`，`s` 只含小写英文字母。例：`"bbbab"` → `4`（`"bbbb"`）；`"cbbd"` → `2`（`"bb"`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 区间 DP：`dp[i][j]` 是 `s[i..j]` 里最长回文子序列的长度；两端字符相同就「中间的最优 + 2」，不同就丢掉一端取较大；`i` 从后往前、`j` 从前往后填表，答案在 `dp[0][n-1]`。`O(n^2)`。

**识别。** 「子序列」+「回文」→ 状态是一个区间 `[i, j]`，因为回文的结构是「两端配对、向内收缩」。`n <= 1000` → `O(n^2) = 10^6` 个状态可以，`O(2^n)` 枚举子序列不行。另一个视角：回文子序列等于 `s` 和 `s[::-1]` 的公共子序列，所以也能写成 LCS。

**推导。** 暴力：枚举 `2^n` 个子序列逐个判回文。换个角度看最长回文子序列的两端：如果 `s[i] == s[j]`，把它们作为最外层一对一定不亏（任何不用它们的回文，都能把它的最外层换成这两个字符），于是答案 = `s[i+1..j-1]` 的答案 + 2；如果不等，二者至少有一个不在答案里，答案 = 去掉左端或去掉右端两种情况的较大者。子问题只有 `O(n^2)` 个区间，每个 `O(1)` 转移。`dp[i][j]` 依赖 `dp[i+1][*]`（下一行），所以 `i` 必须从大到小。

```python
def longest_palindrome_subseq(s: str) -> int:
    n = len(s)
    dp = [[0] * n for _ in range(n)]          # dp[i][j]：s[i..j] 内最长回文子序列的长度
    for i in range(n - 1, -1, -1):            # i 从后往前：dp[i][*] 依赖 dp[i+1][*]
        dp[i][i] = 1                          # 单个字符本身是回文
        for j in range(i + 1, n):
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1] + 2   # 两端相同：夹在中间的最优解外面各加一个
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])   # 两端不同：至少丢掉一端
    return dp[0][n - 1]
```

运行：`"bbbab"` → `4`，`"cbbd"` → `2`，`"a"` → `1`，`"ab"` → `1`，`"abcda"` → `3`。

**复杂度。** 时间 `O(n^2)`：`n(n-1)/2` 个区间各 `O(1)`；空间 `O(n^2)`。

**易错点。**
- 当成 LC 5 最长回文**子串**（要求连续）：`"bbbab"` 会得到 `3`（`"bbb"` 或 `"bab"`），正确是 `4`。
- 两端不同时写成 `dp[i+1][j-1]`（两端都丢）：漏掉「只丢一端」的情况，`"bbbab"` 得到 `3`。
- `i` 从小到大遍历：读到的 `dp[i+1][*]` 还没算，全是 `0`，`"bbbab"` 得到 `2`。
- 长度为 2 且两端相同时 `dp[i+1][j-1]` 是 `dp[i+1][i]`，位于对角线下方，值为 `0`，结果 `2` 正好对，不用特判。

**追问。**
- 返回回文子序列本身：从 `dp[0][n-1]` 倒推，两端相同就同时收下，否则走向较大的一侧；`"bbbab"` → `"bbbb"`。
- 让字符串变成回文的最少插入次数（LC 1312）= `n - LPS`。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。

**同模式。** LC 5 最长回文子串、LC 1143 最长公共子序列、LC 1312 让字符串成为回文串的最少插入次数、LC 730 统计不同回文子序列。
