## Q
**LC 939 最小面积矩形**｜Medium · 字节 高频

给 X-Y 平面上的点数组 `points`，`points[i] = [xi, yi]`。返回由这些点作为顶点、**边与坐标轴平行**的矩形的最小面积；不存在这样的矩形就返回 `0`。`1 <= points.length <= 500`，`points[i].length == 2`，`0 <= xi, yi <= 4 * 10^4`，所有点互不相同。例：`[[1,1],[1,3],[3,1],[3,3],[2,2]]` → `4`；`[[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]]` → `2`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把所有点放进哈希集合（hash set）。枚举每一对点当作矩形的一条对角线（两点的 `x` 和 `y` 都不相同），另外两个角的坐标由它们唯一确定，在集合里查一下是否存在，存在就用面积更新答案。`O(n^2)`。

**识别。** 「边与坐标轴平行的矩形」意味着一条对角线就唯一确定另外两个角。要在点集里“找存在的组合”，就是枚举加哈希查找。`n <= 500`，点对只有约 `12.5` 万个，`O(n^2)` 绰绰有余；枚举四个点的 `O(n^4)` 不行。

**推导。** 暴力：任选四个点检查是否构成轴平行矩形，`O(n^4)`，约 `6 × 10^{10}`。浪费：四个点里只有两个是“自由”的，另外两个被完全决定。洞察：对角两点 `(x1, y1)`、`(x2, y2)` 决定另外两角 `(x1, y2)`、`(x2, y1)`，用集合 `O(1)` 判断存在性，总共只需要枚举点对，`O(n^2)`。每个矩形有两条对角线，会被枚举两次，取最小值不受影响。

```python
from itertools import combinations


def min_area_rect(points: list[list[int]]) -> int:
    pts = [tuple(p) for p in points]       # 列表不可哈希，转成元组
    seen = set(pts)
    areas = (
        abs(x1 - x2) * abs(y1 - y2)
        for (x1, y1), (x2, y2) in combinations(pts, 2)
        if x1 != x2 and y1 != y2 and (x1, y2) in seen and (x2, y1) in seen   # 另外两个角也在
    )
    return min(areas, default=0)           # 没有矩形时返回 0
```

运行：`[[1,1],[1,3],[3,1],[3,3],[2,2]]` → `4`，`[[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]]` → `2`，`[[0,0]]` → `0`，`[[0,0],[1,1]]` → `0`；`500` 个随机点约 `4 ms`。

**复杂度。** 时间 `O(n^2)`；空间 `O(n)`。

**易错点。**
- 不排除共线的两点，漏写 `x1 != x2 and y1 != y2`：`(1,1)` 与 `(1,3)` 的“另外两角”恰好是它们自己，会被当成面积为 `0` 的矩形。示例 1 得到 `0`，正确是 `4`。
- 直接 `set(points)`：`points` 的元素是列表，抛 `TypeError: unhashable type: 'list'`，要先转成元组。
- 没有矩形时 `min` 作用于空序列会抛 `ValueError`，用 `default=0`。

**追问。**
- 点数很大（`10^5`）：`O(n^2)` 不行，改成按列扫描：同一列内的每对 `(y1, y2)` 记录上一次出现它的列 `x`，下次再遇到同一对就形成一个矩形，复杂度 `O(Σ 每列点数的平方)`。
- 返回矩形的四个顶点：保留最小面积对应的那一对对角点。
- 边不必与坐标轴平行（LC 963）：对角线中点相同、长度相同的两条线段构成矩形，按（中点、长度）分组，仍是 `O(n^2)`。

**同模式。** LC 963 最小面积矩形 II、LC 750 角矩形的数量、LC 593 有效的正方形、LC 149 直线上最多的点数。
