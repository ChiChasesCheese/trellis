## Q
**LC 16 最接近的三数之和**｜Medium · LC 字节 全时段热度 50/100 · CodeTop 国内累计 23 次 · 最近 2026-05-06（国内 CodeTop）

给长度为 `n` 的整数数组 `nums` 和整数 `target`，从 `nums` 中选出三个**不同下标**的整数，使它们的和与 `target` 最接近，返回这三个数的和。假定每组输入只存在恰好一个解。`3 <= nums.length <= 1000`，`-1000 <= nums[i] <= 1000`，`-10^4 <= target <= 10^4`。例：`nums = [-1,2,1,-4], target = 1` → `2`（`-1 + 2 + 1`）；`nums = [0,0,0], target = 1` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 排序后固定第一个数，剩下的两个数用左右双指针在有序数组里逼近：和小于 `target` 就右移左指针，和大于 `target` 就左移右指针，恰好等于就直接返回；每步用 `|和 - target|` 更新最接近的和。`O(n^2)`。

**识别。** 「选三个数，和与目标最接近」是 3Sum 家族的信号。`n = 1000`：`O(n^3)` 是 `10^9`，超时；`O(n^2)` 是 `10^6`，刚好。排序之后，固定一个数，剩下的是"有序数组里找两数之和最接近某个值"，双指针每步能排除一个端点。

**推导。** 暴力：三重循环，`O(n^3)`。观察：固定 `i` 后，在 `nums[i+1:]` 上选两个数，使和最接近 `target - nums[i]`。数组有序时，设 `lo < hi`：和偏小，则 `lo` 与任何比 `hi` 更小的右端搭配都更小，`lo` 不会再有机会，排除 `lo`；和偏大同理排除 `hi`。每步排除一个，`O(n)`；外层 `n` 次，总 `O(n^2)`。

```python
def three_sum_closest(nums: list[int], target: int) -> int:
    nums = sorted(nums)                          # 排序后才能用双指针；用 sorted 不改动调用者的数组
    best = nums[0] + nums[1] + nums[2]
    for i in range(len(nums) - 2):
        if i and nums[i] == nums[i - 1]:         # 相同的第一个数结果相同，跳过
            continue
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = nums[i] + nums[lo] + nums[hi]
            if abs(s - target) < abs(best - target):
                best = s
            if s == target:                      # 不可能更近了
                return s
            if s < target:
                lo += 1                          # 和偏小：左指针右移，让和变大
            else:
                hi -= 1                          # 和偏大：右指针左移，让和变小
    return best
```

**运行。** `([-1,2,1,-4], 1)` → `2`；`([0,0,0], 1)` → `0`；`([1,1,1,0], -100)` → `2`；`([1,1,-1,-1,3], -1)` → `-1`；`([-1000,-1000,-1000], 10000)` → `-3000`；`1000` 个随机数约 0.02 秒。

**复杂度。** 时间 `O(n^2)`（排序 `O(n log n)` 被覆盖）；空间 `O(n)`，`sorted` 产生拷贝，原地 `nums.sort()` 可以降到 `O(1)` 但会改动输入。

**易错点。**
- 比较时不取绝对值，直接比 `s - target < best - target`：`[-1,2,1,-4], target = 1` 会得到 `-4`，正确是 `2`。
- 用 `0` 当 `best` 的初值：`[1,1,1,0], target = -100` 会返回 `0`，而 `0` 不是任何三个数的和，正确是 `2`。初值必须是一个真实的三数之和。
- 指针移动方向反了：和偏小应当右移 `lo`，写反会让两个指针都走远，漏掉答案。

**追问。**
- 返回具体的三个数或下标：更新 `best` 时同时记录 `(i, lo, hi)`（用原下标需要先给元素配下标再排序）。
- 推广到 `k` 个数（LC 18）：外层再套 `k - 2` 层循环，最内层双指针，`O(n^{k-1})`。
- 剪枝：排序后若 `nums[i] + nums[i+1] + nums[i+2] > target`，之后的和只会更大，直接用它更新答案并结束。

**同模式。** LC 15 三数之和、LC 18 四数之和、LC 259 较小的三数之和、LC 167 两数之和 II、LC 611 有效三角形的个数。
