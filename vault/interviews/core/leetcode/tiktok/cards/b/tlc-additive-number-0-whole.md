## Q
**LC 306 累加数**｜Medium · CodeTop 国内累计 6 次 · 最近 2026-09-03（CodeTop）

累加数是一个字符串，组成它的数字可以形成**累加序列**：序列至少包含 `3` 个数，除开头两个数以外，每个数都等于它前面两个数之和。给一个只含数字 `'0'-'9'` 的字符串 `num`，判断它是否是累加数。序列中的数除了数字 `0` 本身，不会以 `0` 开头（不会出现 `1, 2, 03` 或 `1, 02, 3`）。`1 <= num.length <= 35`。例：`"112358"` → `true`（`1, 1, 2, 3, 5, 8`）；`"199100199"` → `true`（`1, 99, 100, 199`）。进阶：如何处理过大整数导致的溢出？

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 枚举前两个数的切分位置 `(i, j)`；一旦前两个数确定，后面每个数都被「等于前两数之和」唯一确定，只需把和转成字符串，逐个核对是否正好接在 `num` 的下一段；任何一组 `(i, j)` 通过就返回 `True`。

**识别。** 「把字符串切成满足递推关系的数列」看起来是回溯切分，但递推关系让状态大减：**前两个数决定整个序列**，所以不必枚举每一个数的切分，只枚举前两个，复杂度 `O(n^2)` 种选择乘上每种 `O(n)` 的校验，`n <= 35` 绰绰有余。前导零和「至少三个数」是边界规则。

**推导。** 暴力：回溯地枚举每个数的结束位置，再检查是否满足递推，指数级。浪费：第三个数起，每个数的值已经由前两个确定，其长度也随之确定，没有选择余地。所以只在前两个数上做选择（`i` 是第一个数的长度，`j` 是前两个数合起来的长度），其后用 `startswith` 逐段核对。剪枝：第三个数至少和前两个中较长者一样长，所以 `max(i, j - i) <= n - j`。

```python
def is_additive_number(num: str) -> bool:
    n = len(num)

    def valid(i: int, j: int) -> bool:     # 前两个数是 num[:i] 和 num[i:j]，其后每个数都被唯一确定
        if (i > 1 and num[0] == "0") or (j - i > 1 and num[i] == "0"):
            return False                   # 多位数不能有前导 0
        a, b = int(num[:i]), int(num[i:j])
        k = j
        while k < n:
            a, b = b, a + b
            s = str(b)
            if not num.startswith(s, k):   # 下一个数必须正好是 a + b
                return False
            k += len(s)
        return True                        # k == n：恰好用完

    return any(
        valid(i, j)
        for i in range(1, n)
        for j in range(i + 1, n)           # j < n：保证至少还有第三个数
        if max(i, j - i) <= n - j          # 第三个数的位数不会比两个加数的较长者短
    )
```

运行：`"112358"` → `True`，`"199100199"` → `True`，`"000"` → `True`，`"101"` → `True`，`"1023"` → `False`，`"12"` → `False`，`"1"` → `False`。

**复杂度。** 时间 `O(n^3)`：`O(n^2)` 个 `(i, j)`，每个校验最多 `O(n)` 个数、每次加法与比较 `O(n)`，实际远小于上界；空间 `O(n)`。

**易错点。**
- 前导零：`"1023"` 不能当成 `1, 02, 3`；漏掉检查会返回 `True`（正确 `False`）。单独的 `"0"` 合法，所以 `"000"`（`0, 0, 0`）是累加数。
- `j` 必须小于 `n`：序列至少三个数，`j` 取到 `n` 会让 `"12"` 通过（只有两个数），返回 `True`（正确 `False`）。
- 用 `int(num[:i])` 解析前，先判断前导零：`int("02")` 会悄悄变成 `2`，掩盖错误。

**追问。**
- 返回具体序列：校验过程中把 `a`、`b` 和之后每个 `b` 收集进列表。
- 溢出：Python 的 `int` 任意精度，不需要处理；Java / C++ 里用字符串竖式加法（逐位相加带进位）代替整数加法。
- 变体 LC 842「将数组拆分成斐波那契序列」：同样枚举前两个数，要求序列每个数不超过 `2^31 - 1`，返回序列本身。

**同模式。** LC 842 将数组拆分成斐波那契序列、LC 93 复原 IP 地址、LC 282 给表达式添加运算符、LC 131 分割回文串。
