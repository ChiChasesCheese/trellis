## Q
**LC 169 多数元素**｜Easy · CodeTop 国内累计 21 次 · 最近 2022-03-24（国内 CodeTop）

给大小为 `n` 的数组 `nums`，返回其中的多数元素：出现次数**大于** `⌊n/2⌋` 的元素。输入保证数组非空且一定存在多数元素。`1 <= n <= 5 * 10^4`，`-10^9 <= nums[i] <= 10^9`。例：`[3,2,3]` → `3`；`[2,2,1,1,1,2,2]` → `2`。进阶：`O(n)` 时间、`O(1)` 空间。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 摩尔投票（Boyer-Moore voting）：维护一个候选人和一个计数；遇到同一个值计数加一，不同的值计数减一，计数为零时换成当前值做新候选。多数元素的票数比其余元素加起来还多，抵消之后一定剩下它。`O(n)` 时间，`O(1)` 空间。

**识别。** 「出现次数超过一半」+ 进阶要求 `O(1)` 空间：哈希计数 `O(n)` 空间，排序 `O(n log n)` 时间，都不满足。「超过一半」意味着可以把元素成对抵消——每对「不同的两个数」一起扔掉，多数元素仍然是剩下部分的多数。

**推导。** 暴力：对每个元素数出现次数，`O(n^2)` → `Counter` 一遍计数，取最大值，`O(n)` 时间、`O(n)` 空间 → 排序后下标 `n // 2` 的元素必是多数元素，`O(n log n)` → 抵消思想：每次用多数元素的一票去抵掉一个其他元素的一票，多数元素的票数严格多于其余之和，抵消完仍剩至少一票；用 `(candidate, count)` 实时维护"当前未被抵消的票"。

```python
def majority_element(nums: list[int]) -> int:
    candidate, count = nums[0], 0
    for x in nums:
        if count == 0:                     # 票数抵消光了：换一个新候选人
            candidate = x
        count += 1 if x == candidate else -1
    return candidate
```

运行：`[3,2,3]` → `3`，`[2,2,1,1,1,2,2]` → `2`，`[5]` → `5`；`25001` 个 `1` 与 `24999` 个 `2` 打乱后 → `1`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 不保证有多数元素时直接返回候选人是错的：`[1,2,3]` 得到 `3`，但每个数只出现一次，没有多数元素；`[1,1,2,2]` 得到 `1`，每个数恰好一半，也没有多数元素。必须再扫一遍验证候选人的出现次数 `> n // 2`。
- 阈值是**大于** `⌊n/2⌋`，不是大于等于：`[1,1,2,2]` 里每个数恰好 `n/2` 次，不算多数。

**追问。**
- 超过 `⌊n/3⌋` 的元素（LC 229）：最多两个，维护两个候选人和两个计数，最后验证；推广到 `1/k` 用 `k - 1` 个候选人。
- 不保证存在多数元素：加一遍验证，`nums.count(candidate) > len(nums) // 2`，不满足返回 `-1`（或抛出）。
- 用别的办法：`Counter(nums).most_common(1)[0][0]`（`O(n)` 空间）；排序取 `sorted(nums)[n // 2]`；随机选一个元素验证，期望两次命中；按二进制位统计每一位上 `1` 是否过半。

**同模式。** LC 229 求众数 II、LC 1150 检查一个数是否在数组中占绝大多数、LC 136 只出现一次的数字（同样靠"抵消"做到 `O(1)` 空间）、LC 215 数组中的第 K 个最大元素。
