## Q
**LC 86 分隔链表**｜Medium · CodeTop 国内累计 8 次 · 最近 2025-12-21（CodeTop）

给链表头节点 `head` 和整数 `x`，对链表分隔，使所有**小于 `x`** 的节点都出现在**大于或等于 `x`** 的节点之前，并且保留两个分区中每个节点的初始相对位置。节点数在 `[0, 200]`，`-100 <= Node.val <= 100`，`-200 <= x <= 200`。例：`head = [1,4,3,2,5,2]`，`x = 3` → `[1,2,2,4,3,5]`；`head = [2,1]`，`x = 2` → `[1,2]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 拆成两条链：一条收所有 `< x` 的节点，一条收所有 `>= x` 的节点（各用一个哑结点 dummy 当头），遍历一遍原链按值分发，最后**把大链尾巴断开**，再把小链尾接到大链头。`O(n)` 时间、`O(1)` 空间。

**识别。** 「按条件把节点分成两组、每组内保持原序」是**稳定划分**（stable partition），链表上最自然的做法是**双链 + 哑结点**（dummy node）：只改 `next` 指针，不动值、不用数组；`n` 只有 200，复杂度不是瓶颈，考点是指针操作和收尾。

**推导。** 暴力：把值抄进数组，划分后再重建链表，`O(n)` 时间但 `O(n)` 额外空间，也不算「操作链表」。浪费：链表的优势是改指针就能重排，不必拷贝。洞察：稳定划分 = 两个队列，各自只需要一个尾指针按顺序追加；哑结点让「第一个节点」和「后续节点」的处理一致，不必判空。最优：一次遍历把节点挂到小链或大链的尾部，最后断开大链尾巴（它原来可能还指向小链节点），再拼接，`O(n)` 时间、`O(1)` 额外空间。

```python
def partition(head: ListNode | None, x: int) -> ListNode | None:
    small_dummy, big_dummy = ListNode(), ListNode()    # 两条链各一个哑结点
    small, big = small_dummy, big_dummy                # 各自的尾指针
    node = head
    while node:
        if node.val < x:
            small.next = node
            small = node
        else:
            big.next = node
            big = node
        node = node.next
    big.next = None                                    # 必须断开：大链尾巴原来可能还连着小结点
    small.next = big_dummy.next                        # 小链接上大链
    return small_dummy.next
```

运行：`[1,4,3,2,5,2], x=3` → `[1, 2, 2, 4, 3, 5]`，`[2,1], x=2` → `[1, 2]`，`[], x=0` → `[]`，`[3,1], x=3` → `[1, 3]`，`[1,2,3], x=10（全小于）` → `[1, 2, 3]`。

**复杂度。** 时间 `O(n)`：每个节点只访问一次；空间 `O(1)`：只用两个哑结点和几个指针，节点是原地重新挂接的。

**易错点。**
- 忘了 `big.next = None`：大链尾结点原来的 `next` 可能指向一个已经挂进小链的节点，拼接后成环。`head = [3,1]`，`x = 3`：小链 `1`，大链 `3`，`3.next` 还指着 `1`，结果 `1 → 3 → 1 → …` 无限循环，遍历永不结束。
- 只记头不记尾，每次追加都从头走到尾：退化成 `O(n^2)`。每条链用一个尾指针。
- 把值 `== x` 放进小链：题面是 `< x` 在前，`>= x` 在后；示例 1 里 `x = 3` 的节点 `3` 必须在大链，否则得到 `[1,3,2,2,4,5]`，与期望的 `[1,2,2,4,3,5]` 不符。

**追问。**
- 三路划分（`< x`、`== x`、`> x`）：多一条链，思路相同，三个哑结点。
- 数组上的原地划分：荷兰国旗（LC 75）或快排的 partition，稳定性不再保证，要稳定就得额外 `O(n)` 空间。
- 不用哑结点：需要单独处理「第一个小节点 / 第一个大节点」，边界判断多，容易漏。
