## Q
**LC 515 在每个树行中找最大值**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-06-21（国内 CodeTop）

给二叉树的根 `root`，返回每一层节点值的最大值组成的列表（从上到下）。节点数在 `[0, 10^4]` 内，`-2^31 <= Node.val <= 2^31 - 1`。例：`[1,3,2,5,3,null,9]` → `[1,3,9]`；`[1,2,3]` → `[1,3]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 层序遍历（BFS），每次把当前整层放在一个列表里，取 `max` 记入答案，再用一个列表推导生成下一层的所有非空孩子。`O(n)`。

**识别。** 「每一层 / 每一行」→ **层序遍历**的信号：需要知道节点属于哪一层，BFS 天然按层推进。值域覆盖整个 32 位整数（含负数）→ 不能拿 `0` 或某个「足够小」的数当初始最大值。节点数到 `10^4`，链状树递归深度会超过 Python 默认上限约 `1000`，迭代写法更稳。

**推导。** 朴素做法：先求树高 `h`，再对每一层单独从根往下找该层的节点，`O(nh)`，链状树退化成 `O(n^2)`。浪费在于每层都从根重走一遍。BFS 一次遍历就能按层分组：处理完第 `d` 层时，下一层恰好是这些节点的孩子，每个节点只进出一次，`O(n)`。也可以 DFS 并把深度作为下标更新 `ans[depth]`，同样 `O(n)`。

```python
def largest_values(root: TreeNode | None) -> list[int]:
    ans: list[int] = []
    level = [root] if root else []
    while level:
        ans.append(max(node.val for node in level))                              # 这一层的最大值
        level = [c for node in level for c in (node.left, node.right) if c]       # 下一层：所有非空孩子
    return ans
```

运行：`[1,3,2,5,3,null,9]` → `[1, 3, 9]`，`[1,2,3]` → `[1, 3]`，`[]` → `[]`，`[-3,-5]` → `[-3, -5]`，`[2147483647,-2147483648]` → `[2147483647, -2147483648]`。

**复杂度。** 时间 `O(n)`：每个节点进一次层列表；空间 `O(w)`，`w` 为最大层宽（同时只保存一层和下一层）。

**易错点。**
- 初始最大值设成 `0`：全是负数的层会得到 `0`。`[-3,-5]` 错成 `[0, 0]`，正确 `[-3, -5]`。用 `max()` 作用在整层上，或初始化为该层第一个节点的值。
- 递归 DFS 在 `10^4` 个节点的链上触发 `RecursionError`（默认上限约 `1000`）；用 BFS 或显式栈。
- 空树返回 `[]`，不要对空列表调用 `max`（会抛 `ValueError`）。

**追问。**
- 用 DFS：栈里放 `(节点, 深度)`，`depth == len(ans)` 时说明第一次到这一层，追加；否则 `ans[depth] = max(ans[depth], val)`。
- 同一套层序框架：右视图（LC 199，每层最后一个）、层平均值（LC 637）、锯齿形遍历（LC 103）。
- 树是 N 叉树：把 `(node.left, node.right)` 换成 `node.children`，其余不变。

**同模式。** LC 102 二叉树的层序遍历、LC 199 二叉树的右视图、LC 637 二叉树的层平均值、LC 111 二叉树的最小深度。
