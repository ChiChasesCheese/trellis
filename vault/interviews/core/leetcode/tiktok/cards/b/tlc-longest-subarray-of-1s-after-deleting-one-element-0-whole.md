## Q
**LC 1493 删掉一个元素以后全为 1 的最长子数组**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-03-30（CodeTop）

给一个二进制数组 `nums`，**必须**从中删除一个元素，返回删除后数组中仅包含 `1` 的最长非空子数组的长度；不存在则返回 `0`。`1 <= nums.length <= 10^5`，`nums[i]` 是 `0` 或 `1`。例：`[1,1,0,1]` → `3`（删下标 2 得 `[1,1,1]`）；`[0,1,1,1,0,1,1,0,1]` → `5`；`[1,1,1]` → `2`（必须删一个）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 可变长滑动窗口：窗口里**最多允许一个 `0`**（那就是被删掉的元素）；右端逐个扩，`0` 多于一个时左端前进直到吐出一个 `0`；因为必须删掉一个元素，答案取窗口长度 **减 1**。`O(n)`。

**识别。** 「连续子数组 + 最长 + 窗口内某种元素不超过 k 个」是滑动窗口的标准信号，这里 `k = 1`；「删除一个元素」等价于「窗口里允许有一个 0（它被删掉）」；`n = 10^5` 排除 `O(n^2)`；约束有单调性（窗口里零的个数随窗口扩大不减），所以左端只进不退。

**推导。** 暴力：枚举删哪个元素（`n` 种），每种 `O(n)` 求最长连续 `1`，`O(n^2)`。浪费：删哪个元素只和它两侧的连续 `1` 有关，没必要重算整个数组。洞察：删一个元素后最长的全 `1` 段，等价于原数组里「至多含一个 `0` 的最长窗口」去掉那个 `0`；窗口长度减 `1` 就是答案（没有 `0` 时也要删一个，同样减 `1`）。最优：右端扩张、零的个数超过 `1` 时左端收缩，`O(n)`。

```python
def longest_subarray(nums: list[int]) -> int:
    left = zeros = best = 0                   # 窗口 nums[left..right] 里最多容纳 1 个 0
    for right, x in enumerate(nums):
        zeros += x == 0                       # bool 当 0/1 加
        while zeros > 1:                      # 超过一个 0：左端前进直到吐出一个 0
            zeros -= nums[left] == 0
            left += 1
        best = max(best, right - left)        # 窗口长度 right-left+1，必须删掉一个元素，所以减 1
    return best
```

运行：`[1,1,0,1]` → `3`，`[0,1,1,1,0,1,1,0,1]` → `5`，`[1,1,1]` → `2`，`[0,0]` → `0`，`[1]` → `0`。

**复杂度。** 时间 `O(n)`：右端走 `n` 步，左端总共最多前进 `n` 步；空间 `O(1)`。

**易错点。**
- 忘了「必须删一个」：`best = max(best, right - left + 1)` 会把 `[1,1,1]` 答成 `3`（正确 `2`），示例 2 答成 `6`（正确 `5`）。窗口里有 `0` 时减掉的是那个 `0`，没有 `0` 时减掉的是任意一个 `1`，都是减 `1`。
- `zeros` 判断用 `>= 1` 或 `> 0`：这样窗口里一个 `0` 都容不下，窗口只是一段连续 `1`，再减 `1`，示例 1 答成 `1`（正确 `3`）。
- 左端收缩只改 `left` 不更新 `zeros`：计数和窗口脱节，之后窗口里实际有多少个 `0` 就不对了。

**追问。**
- 最多删 `k` 个元素（`k` 个 `0`）：把 `zeros > 1` 改成 `zeros > k`，答案取窗口里 `1` 的个数 `窗口长度 - zeros`。
- 只记「前一段 1」和「当前段 1」两个数，遇到 `0` 时交接，`O(1)` 空间，适合流式读入。
- 返回删除的下标：记录取得最大值时窗口里那个 `0` 的位置（或窗口为全 `1` 时任取一个）。

**同模式。** LC 1004 最大连续 1 的个数 III、LC 487 最大连续 1 的个数 II、LC 424 替换后的最长重复字符、LC 3 无重复字符的最长子串、LC 485 最大连续 1 的个数。
