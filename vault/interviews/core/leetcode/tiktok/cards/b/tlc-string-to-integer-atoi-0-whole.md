## Q
**LC 8 字符串转换整数 (atoi)**｜Medium · 字节高频

实现 `myAtoi(s)`，把字符串转成 32 位有符号整数，规则依次是：（1）丢弃前导空格 `" "`；（2）若下一个字符是 `'-'` 或 `'+'`，读入它决定正负，都没有就是正数；（3）读入数字直到遇到非数字字符或字符串结尾，跳过前置零，一个数字都没读到则结果为 `0`；（4）结果超出 `[-2^31, 2^31 - 1]` 时截断到边界。`0 <= s.length <= 200`，`s` 由英文字母、数字、`' '`、`'+'`、`'-'`、`'.'` 组成。例：`"42"` → `42`；`" -042"` → `-42`；`"4193 with words"` → `4193`；`"0-1"` → `0`；`"words and 987"` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一个只向前走的下标 `i` 依次经过「空格 → 符号 → 数字」三个阶段，每个阶段只能走一次；数字阶段边读边累加，一旦达到上限就提前返回截断后的值。`O(n)`。

**识别。** 「按规则一步步解析字符串」是有限状态机（finite state machine）：阶段只前进不回头。题目的坑全在边界：符号只能出现一次、符号后面立刻要是数字、读到非数字立即停止、范围截断且上下界不对称。`n <= 200`，复杂度无压力。

**推导。** 直接调用 `int(s)` 不行：它会对带字母的字符串抛异常，也不会截断 → 手写三段：跳空格；读符号；读数字 → 范围上下界不对称（`-2^31` 比 `2^31 - 1` 多一个），所以先根据符号确定"上限绝对值"`limit`：正数 `2^31 - 1`，负数 `2^31` → 累加时 `num >= limit` 就能确定结果已经到边界，直接返回 `sign * limit`，在 Java / C++ 里这等价于避免溢出的提前判断。

```python
def my_atoi(s: str) -> int:
    INT_MAX, INT_MIN = 2**31 - 1, -(2**31)
    i, n = 0, len(s)
    while i < n and s[i] == " ":                   # 1. 空格：只有 ' ' 才跳过
        i += 1
    sign = 1
    if i < n and s[i] in "+-":                     # 2. 符号：至多一个
        sign = -1 if s[i] == "-" else 1
        i += 1
    limit = INT_MAX if sign == 1 else -INT_MIN     # 正数最大 2^31-1，负数的绝对值最大 2^31
    num = 0
    while i < n and "0" <= s[i] <= "9":            # 3. 数字：遇到第一个非数字就停
        num = num * 10 + (ord(s[i]) - ord("0"))
        if num >= limit:                           # 4. 数字只会越来越大，达到上限就能提前返回
            return sign * limit
        i += 1
    return sign * num
```

运行：`"42"` → `42`，`" -042"` → `-42`，`"4193 with words"` → `4193`，`"0-1"` → `0`，`"words and 987"` → `0`，`""` → `0`，`"+-12"` → `0`，`"-91283472332"` → `-2147483648`，`"21474836470"` → `2147483647`，`"-2147483648"` → `-2147483648`，`"3.14159"` → `3`。

**复杂度。** 时间 `O(n)`，下标只前进；空间 `O(1)`。

**易错点。**
- 负数的下界是 `-2^31`，不是 `-(2^31 - 1)`：两边都用 `INT_MAX` 截断，`"-2147483648"` 会得到 `-2147483647`，正确是 `-2147483648`。
- 把符号读成循环：`while s[i] in "+-"` 会让 `"+-12"` 得到 `-12`，正确是 `0`（符号后面必须是数字）。
- 数字用 `str.isdigit()` 判断：它对全角数字、上标 `²` 等返回真，`int()` 还能把阿拉伯数字 `"١٢"` 转成 `12`，用 `"0" <= ch <= "9"` 才精确。

**追问。**
- 固定位宽语言里如何不溢出：累加前检查 `num > (INT_MAX - d) // 10`（正）或 `num > (INT_MAX + 1 - d) // 10`（负），不能先乘再判断。
- 用正则一行写：`re.match(r" *([+-]?\d+)", s)`，再用 `max(INT_MIN, min(INT_MAX, int(...)))` 截断。
- 小数、科学计数法、十六进制（LC 65 有效数字）：同样的状态机，状态更多，用"状态 → 字符类型 → 下一个状态"的转移表。

**同模式。** LC 65 有效数字、LC 7 整数反转、LC 394 字符串解码、LC 224 基本计算器。
