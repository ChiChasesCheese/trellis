## Q
**LC 2334 元素值大于变化阈值的子数组**｜Hard · LC TikTok 热度 88/100

给整数数组 `nums` 和整数 `threshold`。找一个长度为 `k` 的子数组（连续非空），使其中**每个**元素都大于 `threshold / k`。返回任意一个满足要求的子数组的**长度**，不存在则返回 `-1`。`1 <= nums.length <= 10^5`，`1 <= nums[i], threshold <= 10^9`。例：`nums = [1,3,4,3,1], threshold = 6` → `3`（`[3,4,3]`，每个都大于 `6/3 = 2`）；`nums = [6,5,6,5,8], threshold = 7` → 返回 `1` 到 `5` 之间任意满足的长度均可，如 `1`（`8 > 7`）、`2`、`3`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把"每个元素都大于 `threshold / k`"改写成「最小值 `h` 满足 `h * k > threshold`」；用单调栈求出以每个元素为最小值时能撑起的最大宽度 `k`，只要某个 `h * k > threshold` 就返回这个 `k`。`O(n)`。

**识别。** 「子数组 + 所有元素满足一个只依赖长度的条件」→ 看窗口的**最小值**；「以每个元素为最小值的最大区间」→ 单调栈（左右第一个更小的位置），与「柱状图中最大的矩形」（LC 84）同一结构：`h * k` 就是矩形面积，条件是面积 `> threshold`。`n` 到 `10^5`，`O(n^2)` 枚举不行。

**推导。** 暴力：枚举每个子数组，求最小值 `m` 与长度 `k`，检查 `m > threshold / k`，`O(n^2)`。浪费：固定最小值是谁时，窗口越宽 `k` 越大，`h * k` 越大，越容易满足，所以每个元素只需要看它做最小值时的**最宽**区间。这个区间由左右第一个更小的元素夹出，单调栈在弹栈时恰好得到这两个边界。条件 `h > threshold / k` 两边乘 `k`（`k > 0`）写成 `h * k > threshold`，避开浮点。

```python
from itertools import chain


def valid_subarray_size(nums: list[int], threshold: int) -> int:
    stack: list[int] = []                          # 下标栈，对应的值严格递增
    for i, x in enumerate(chain(nums, (0,))):      # 末尾补哨兵 0（nums[i] >= 1），把栈里剩下的全弹出
        while stack and nums[stack[-1]] >= x:
            h = nums[stack.pop()]                  # h 是一段区间的最小值
            left = stack[-1] if stack else -1      # 左边第一个比 h 小的位置
            k = i - left - 1                       # h 做最小值时能撑起的最大宽度
            if h * k > threshold:                  # h > threshold / k，乘过去避免浮点
                return k
        stack.append(i)
    return -1
```

运行：`[1,3,4,3,1], 6` → `3`；`[6,5,6,5,8], 7` → `3`（合法答案之一，`3` 对应 `[6,5,6]`，每个都大于 `7/3`）；`[1], 1` → `-1`；`[1], 5` → `-1`；`10^5` 个递增数、阈值 `10^9` → `11271`；`10^5` 个 `1` → `-1`。

**复杂度。** 时间 `O(n)`：每个下标入栈、出栈各一次；空间 `O(n)`。

**易错点。**
- 条件是严格大于。写成 `h * k >= threshold`：`nums = [2], threshold = 2` 会返回 `1`，正确是 `-1`（`2 > 2/1` 不成立）。
- 宽度是 `i - left - 1`，不是 `i - left`：`i` 是右边第一个更小（或哨兵）的位置，不属于窗口。
- 哨兵 `0` 保证栈在结尾被清空；`nums[i] >= 1`，所以 `0` 一定比所有元素小。
- 返回的是长度 `k`，不是下标或元素值。

**追问。**
- 想要**最大**的合法长度：不提前返回，对所有满足 `h * k > threshold` 的 `k` 取最大；`[6,5,6,5,8], 7` → `5`。
- 并查集的另一种做法：把元素按值从大到小逐个"点亮"并与已点亮的邻居合并，当前元素所在连通块的大小就是它做最小值时的最大宽度（见另一种解法）。
- 这和柱状图中最大的矩形（LC 84）的关系：同一个栈，只是判据不同。

**同模式。** LC 84 柱状图中最大的矩形、LC 85 最大矩形、LC 907 子数组的最小值之和、LC 739 每日温度、LC 496 下一个更大元素。
