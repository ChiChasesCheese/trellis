## Q
**LC 1247 交换字符使得字符串相同**｜Medium · TikTok 高频

有两个长度相同的字符串 `s1` 和 `s2`，它们都只含 `'x'` 和 `'y'`。每次「交换字符」可以在**两个不同的字符串中各选一个字符**互换，即交换 `s1[i]` 和 `s2[j]`，**不能**交换同一个字符串内部的两个字符。返回使 `s1` 和 `s2` 相同的最少交换次数，做不到返回 `-1`。`1 <= s1.length, s2.length <= 1000`，`s1.length == s2.length`。例：`s1 = "xx"`，`s2 = "yy"` → `1`；`s1 = "xy"`，`s2 = "yx"` → `2`；`s1 = "xx"`，`s2 = "xy"` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 只有两串在同一位置字符不同的地方需要处理，它们分两类：`xy`（`s1` 是 `x`、`s2` 是 `y`）和 `yx`。同类两个用一次交换解决；剩下一个 `xy` 和一个 `yx` 要两次；不同位置总数为奇数时无解。答案 `xy // 2 + yx // 2 + 2 * (xy % 2)`。`O(n)`。

**识别。** 「只含两种字符 + 交换」→ 不要模拟交换，直接对**不匹配位置分类计数**再按组合规则算次数。可行性看奇偶：每个不匹配位置恰有一个 `x`，所以两串里 `x` 的总数与不匹配位置数同奇偶；`x` 总数是奇数就永远无法让两串的 `x` 个数相同。

**推导。** 暴力：BFS 搜索所有交换后的状态对，指数级 → 相同的位置不动，只看不匹配的位置，分成 `xy` 与 `yx` 两类 → 两个 `xy` 位置 `i`、`j`：交换 `s1[i]` 与 `s2[j]`，位置 `i` 变成 `(y, y)`，位置 `j` 变成 `(x, x)`，一次解决两个；两个 `yx` 同理 → 剩下的情形只可能是一个 `xy` 加一个 `yx`（奇偶可行时）：先在其中一个位置交换 `s1[i]` 与 `s2[i]`，把它变成另一类，再按"同类两个"处理，共两次。

```python
def minimum_swap(s1: str, s2: str) -> int:
    xy = yx = 0                                  # xy：s1 是 x、s2 是 y 的位置数；yx 反之
    for a, b in zip(s1, s2):
        if a != b:
            if a == "x":
                xy += 1
            else:
                yx += 1
    if (xy + yx) % 2:                            # 不同位置总数为奇数：x 的总数是奇数，永远分不成两串相等
        return -1
    return xy // 2 + yx // 2 + 2 * (xy % 2)      # 同类两两一次；剩下一对 xy 和一对 yx 要两次
```

运行：`("xx", "yy")` → `1`；`("xy", "yx")` → `2`；`("xx", "xy")` → `-1`；`("x", "x")` → `0`；`("xyx", "yxx")` → `2`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 用「不同位置数的一半」：`("xy", "yx")` 有 `2` 个不同位置，得到 `1`，正确是 `2`（一个 `xy` 配一个 `yx` 不能一次解决）。
- 忘了可行性判断：`xy + yx` 为奇数时必须返回 `-1`，否则 `xy // 2 + yx // 2` 会悄悄丢掉一个不匹配位置。
- 异类配对漏乘 `2`：写成 `xy // 2 + yx // 2 + xy % 2`，`("xy", "yx")` 得到 `1`，正确是 `2`；一个 `xy` 加一个 `yx` 必须两次交换。

**追问。**
- 允许交换**同一个字符串内部**的字符：一个 `xy` 配一个 `yx` 只要交换 `s1` 内的两个字符一次，答案变成 `(xy + yx) // 2`，`("xy", "yx")` → `1`；这正是上面那个错误公式的含义，问清楚题目允许哪种交换。
- 输出具体的交换方案：分别记录 `xy` 位置和 `yx` 位置的下标，按配对规则依次输出 `(i, j)`。
- 想少写循环：`c = Counter(zip(s1, s2))`，`xy, yx = c[("x", "y")], c[("y", "x")]`，一行统计两类位置数；`Counter` 对不存在的键返回 `0`，不会 `KeyError`。

**同模式。** LC 1790 仅执行一次字符串交换能否使两个字符串相等、LC 854 相似度为 K 的字符串、LC 2193 得到回文串的最少操作次数、LC 1963 使字符串平衡的最小交换次数。
