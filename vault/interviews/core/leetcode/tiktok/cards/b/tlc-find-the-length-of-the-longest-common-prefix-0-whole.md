## Q
**LC 3043 最长公共前缀的长度**｜Medium · TikTok·字节 高频

给两个**正整数**数组 `arr1` 和 `arr2`。正整数的前缀是它最左边的一位或多位数字组成的整数，例如 `123` 是 `12345` 的前缀，`234` 不是。整数 `c` 是 `a` 和 `b` 的公共前缀，指 `c` 同时是 `a` 和 `b` 的前缀。在所有数对 `(x, y)`（`x` 来自 `arr1`，`y` 来自 `arr2`）中，求最长公共前缀的长度（位数）；没有公共前缀返回 `0`。同一个数组内部的元素之间的公共前缀不考虑。`1 <= arr1.length, arr2.length <= 5 * 10^4`，`1 <= arr1[i], arr2[i] <= 10^8`。例：`arr1 = [1,10,100]`，`arr2 = [1000]` → `3`；`arr1 = [1,2,3]`，`arr2 = [4,4,4]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把 `arr1` 里每个数的全部前缀放进哈希集合（反复整除 `10` 去掉末位就得到所有前缀）；对 `arr2` 的每个数同样从长到短逐位去掉末位，第一个出现在集合里的前缀就是它与 `arr1` 的最长公共前缀，取其位数的最大值。每个数最多 `9` 位，总共 `O((n + m) · 9)`。

**识别。** 「前缀」「两组数」「最长公共」是前缀集合或字典树（trie）的信号。值域 `10^8`，每个数至多 `9` 位、`9` 个前缀，`n = 5 × 10^4` 时前缀总数不到 `5 × 10^5`，集合放得下。数字的前缀可以直接用整数除法 `// 10` 得到，不必转字符串。

**推导。** 暴力：所有数对逐位比较，`O(n · m · 9)`，约 `2 × 10^{10}`。浪费：大量数对重复比较了同样的前缀。洞察：`x` 与 `y` 有公共前缀 `c`，当且仅当 `c` 同时属于 `x` 的前缀集合和 `y` 的前缀集合。先把一边的前缀存起来，另一边逐个查询；对 `y` 从最长的前缀往短处找，第一个命中的就是最长。提前停止：插入 `arr1` 的数时，如果当前前缀 `x` 已经在集合里，它的所有更短前缀此前也一定被插入过（每次插入的是一整条链），可以直接结束这个数。

```python
def longest_common_prefix(arr1: list[int], arr2: list[int]) -> int:
    prefixes: set[int] = set()
    for x in arr1:
        while x and x not in prefixes:     # 已经在集合里说明它的更短前缀也都在，可以提前停
            prefixes.add(x)
            x //= 10                       # 去掉最后一位 = 取前一个前缀
    best = 0
    for y in arr2:
        while y and y not in prefixes:     # 从最长的前缀往短处找第一个命中的
            y //= 10
        if y:
            best = max(best, len(str(y)))
    return best
```

运行：`([1,10,100], [1000])` → `3`，`([1,2,3], [4,4,4])` → `0`，`([123], [129])` → `2`，`([5655359], [56554])` → `4`，`([10**8], [10**8])` → `9`；两个数组各 `5 × 10^4` 个随机数约 `20 ms`。

**复杂度。** 时间 `O((n + m) · L)`，`L <= 9`；空间 `O(n · L)`。

**易错点。**
- 只存 `arr1` 里完整的数，不存它们的前缀：`([123], [129])` 得到 `0`（正确 `2`，公共前缀 `12`），`([5655359], [56554])` 得到 `0`（正确 `4`，公共前缀 `5655`）。
- 命中判断后位数用 `len(str(y))`，但 `y` 被除到 `0` 时 `len(str(0))` 是 `1`，会把“没有公共前缀”算成长度 `1`；必须先判断 `y` 非零。
- 把两个数组放进同一个字典树：这样会统计到同一个数组内部的公共前缀，而题目明确不算。

**追问。**
- 字典树写法：把 `arr1` 的每个数的数字串插入字典树，`arr2` 的每个数沿树走，走到的最大深度就是答案，思路相同，常数更大。
- 排序写法：把两组数转成字符串合并后排序，最长公共前缀一定出现在排序后相邻、且来自不同数组的一对之间，`O((n + m) log(n + m))`，不需要额外的集合。
- 输出具体是哪一对数和那个前缀：命中时记录 `y` 和前缀本身，再去 `arr1` 里找一个以它开头的数。
