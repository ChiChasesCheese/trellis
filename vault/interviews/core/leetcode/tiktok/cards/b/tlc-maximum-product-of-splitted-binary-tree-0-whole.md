## Q
**LC 1339 分裂二叉树的最大乘积**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-03-10（CodeTop）

给一棵二叉树的根 `root`，删除**一条边**使它分裂成两棵子树，求两棵子树**节点值之和的乘积**的最大值。答案可能很大，返回对 `10^9 + 7` 取模后的结果。每棵树最多 `50000` 个节点，至少 `2` 个；节点值在 `[1, 10000]`。例：`root = [1,2,3,4,5,6]` → `110`（和为 `11` 和 `10`）；`root = [1,null,2,3,4,null,null,5,6]` → `90`；`root = [1,1]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 删一条边 = 把某个非根节点的子树切下来，另一半的和是 `total - s`；先求出每个子树的和 `s`，再对所有非根节点取 `max(s * (total - s))`，**最后**才取模。一遍后序递归同时得到总和和所有子树和。`O(n)`。

**识别。** 「删一条边得到两部分、与两部分的和有关」→ 每条边对应唯一一个非根节点（切掉它与父亲的边），一部分的和就是**以它为根的子树和**，另一部分是 `total - s`；这是树上**后序累加**（子树和）的标准问题。`n = 50000` 意味着要 `O(n)`；子树和 = 自己 + 左子树和 + 右子树和，天然是递归。

**推导。** 暴力：对每条边实际断开，分别遍历两部分求和，`O(n^2)`。浪费：两部分的和互补，`total - s` 不需要再遍历；而所有子树和一次后序遍历就能全部得到。洞察：先得到整棵树的和 `total`，每个子树和 `s` 对应一种切法，乘积是 `s * (total - s)`；这是关于 `s` 的开口向下抛物线，越接近 `total/2` 越大，但直接枚举所有 `s` 取最大即可，不必找最接近的。最优：一遍后序递归求出所有子树和（`dfs` 返回子树和，顺便存进列表），根处得到 `total`，再枚举，`O(n)` 时间 `O(n)` 空间。取模放在最后：先模再比较大小会选错。

```python
def max_product(root: TreeNode | None) -> int:
    MOD = 10**9 + 7
    sums: list[int] = []                        # 每个结点为根的子树和（后序顺序）

    def dfs(node: TreeNode | None) -> int:
        if node is None:
            return 0
        s = node.val + dfs(node.left) + dfs(node.right)   # 先子后父：子树和 = 自己 + 左 + 右
        sums.append(s)
        return s

    total = dfs(root)                           # 一遍后序：整棵树的和，顺便收集所有子树和
    # 先在精确整数上取最大，最后才取模；根的子树和是 total，乘积为 0，不影响最大值
    return max(s * (total - s) for s in sums) % MOD
```

运行：`[1,2,3,4,5,6]` → `110`，`[1,null,2,3,4,null,null,5,6]` → `90`，`[2,3,9,10,7,8,6,5,4,11,1]` → `1025`，`[1,1]` → `1`，`10 个节点的链，值都是 10000` → `499999986`。

**复杂度。** 时间 `O(n)`：每个节点访问一次，再枚举一遍；空间 `O(n)`（`sums` 列表加递归栈）。

**易错点。**
- 先取模再比较：`s * (total - s) % MOD` 放进 `max`。10 个节点、值都是 `10000` 的链：真实最大乘积 `2500000000`，取模后 `499999986`；先模再比较会选中 `900000000`（`s = 10000` 那一种），输出 `900000000`，错。Python 整数不会溢出，所以可以放心用精确值比较，最后再 `% MOD`。
- 深度：链形树深度可达 `50000`，CPython 默认递归上限约 `1000`，深度超过它就抛 `RecursionError`（`1500` 个节点的链就会）；要么 `sys.setrecursionlimit` 调高（栈太深可能让解释器崩溃），要么改迭代（见追问）。
- 根节点也在 `sums` 里：根的子树和是 `total`，`total * 0 = 0`，不影响最大值；树至少有 2 个节点，其他候选的乘积都大于 0，所以最大值一定来自某个非根节点。

**追问。**
- 返回应该删的是哪条边（或哪个子树）：枚举时用 `max(range(1, n), key=...)` 取下标，再回到 `order[i]`。
- 不是二叉树而是 N 叉树，或直接给 `parent[]` 数组：同样的倒序累加，父下标小于子下标时根本不需要建树。
- 迭代写法（深链安全）：显式栈先序记下每个节点的父亲下标，倒序遍历把子树和累加给父亲，再枚举取最大；`O(n)`，没有递归深度问题。

**同模式。** LC 508 出现次数最多的子树元素和、LC 563 二叉树的坡度、LC 543 二叉树的直径、LC 337 打家劫舍 III、LC 124 二叉树中的最大路径和。
