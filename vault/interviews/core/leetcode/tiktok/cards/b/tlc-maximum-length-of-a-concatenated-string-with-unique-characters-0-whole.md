## Q
**LC 1239 串联字符串的最大长度**｜Medium · TikTok 高频

给字符串数组 `arr`。从中选出若干个字符串（保持原有顺序）连接成字符串 `s`，要求 `s` 中**所有字母各不相同**。返回所有可行的 `s` 中最长的长度（什么都不选时 `s` 为空串，长度 `0`）。`1 <= arr.length <= 16`，`1 <= arr[i].length <= 26`，`arr[i]` 只含小写字母。例：`["un","iq","ue"]` → `4`（`"uniq"` 或 `"ique"`）；`["cha","r","act","ers"]` → `6`（`"chaers"` 或 `"acters"`）；`["abcdefghijklmnopqrstuvwxyz"]` → `26`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把每个字符串压成 26 位的字母掩码；用一个集合 `masks` 保存「已经能拼出的所有字母集合」（初始 `{0}`），对每个自身不含重复字母的字符串，与每个和它**不相交**的旧掩码做并集，加入集合；答案是所有掩码里 `1` 的个数的最大值。最坏 `O(2^n)`。

**识别。** 「选子集 + 字母互不重复」且 `n <= 16`：这是子集枚举，`2^16 = 65536` 种，完全可以暴力。关键是用**位掩码**表示字母集合：判断两组字母是否有交集就是 `a & b`，合并就是 `a | b`，个数就是 `bit_count()`，都是常数时间，不需要拼接字符串、不需要 `set` 去重。

**推导。** 暴力：回溯「选 / 不选」，每次把新串拼到当前串上检查重复，每步 `O(26)`，`2^16 * 26` 可行，但要反复构造字符串 → 把每个字符串预处理成掩码，并先丢弃自己内部就有重复字母的串（永远不能选） → 不做递归，改成集合式的 DP：`masks` 里存所有已知可达的掩码，来一个新串 `cur`，对每个旧掩码 `m`，`m & cur == 0` 就把 `m | cur` 加入 → 遍历前对 `masks` 取快照，避免边遍历边修改。

```python
def max_length(arr: list[str]) -> int:
    masks = {0}                                  # 所有"字母互不重复"的拼接能得到的字母集合
    best = 0
    for s in arr:
        if len(set(s)) < len(s):                 # 自己内部就有重复字母：永远不能选
            continue
        cur = 0
        for ch in s:
            cur |= 1 << (ord(ch) - 97)
        for m in list(masks):                    # 对旧集合拍快照，别边遍历边加
            if m & cur == 0:                     # 和 s 没有公共字母：可以拼上
                masks.add(m | cur)
                best = max(best, (m | cur).bit_count())
    return best
```

运行：`["un","iq","ue"]` → `4`；`["cha","r","act","ers"]` → `6`；`["abcdefghijklmnopqrstuvwxyz"]` → `26`；`["aa","bb"]` → `0`；`["a","a"]` → `1`；`16` 个互不相同的单字母串 → `16`，毫秒级。

**复杂度。** 时间最坏 `O(2^n)`（`masks` 最多 `2^n` 个，每个新串遍历一遍旧集合）；空间 `O(2^n)`。

**易错点。**
- 边遍历 `masks` 边往里加：抛 `RuntimeError: Set changed size during iteration`，必须 `list(masks)` 取快照。
- 不过滤自带重复字母的串：`["aa","bb"]` 得到 `2`，因为掩码只记录"有没有"，`"aa"` 被当成一个字母；正确是 `0`。
- 用字符串长度求和而不是掩码的位数：被过滤之前的串长度与位数不一致，只有保证串内无重复时两者才相等。

**追问。**
- 返回具体的字符串：把 `masks` 换成字典 `mask -> 拼出的字符串`，合并时同时拼接。
- 回溯写法：`dfs(i, mask)` 选或不选第 `i` 个串，到末尾取 `mask.bit_count()`；代码短，常数略大。可加剪枝：当前位数加上剩余所有串的位数总和不超过已知最优时直接返回。
- `n` 很大（比如 `30`）：状态数不能再靠 `2^n`，但字母只有 26 个，掩码种类最多 `2^26`，需要在回溯里剪枝，或者按字母位数做更精细的背包式 DP。

**同模式。** LC 78 子集、LC 1255 得分最高的单词集合、LC 2002 两个回文子序列长度的最大乘积、LC 698 划分为 k 个相等的子集、LC 1178 猜字谜。
