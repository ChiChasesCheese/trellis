## Q
**LC 1185 一周中的第几天**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-09-19（CodeTop）

给一个日期，输入三个整数 `day`、`month`、`year`，返回它是星期几，结果必须是 `{"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"}` 中的一个。已知 `1971` 年 `1` 月 `1` 日是星期五。给出的日期保证是 `1971` 到 `2100` 年之间的有效日期。例：`day = 31, month = 8, year = 2019` → `"Saturday"`；`day = 18, month = 7, year = 1999` → `"Sunday"`；`day = 15, month = 8, year = 1993` → `"Sunday"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 以已知的基准日 `1971-01-01`（星期五）为起点，算出目标日期距离基准日的天数 `d`，答案是 `names[d % 7]`（`names` 从星期五开始排）；天数 = 之前每个整年的天数之和 + 本年之前每个整月的天数之和 + `day - 1`。

**识别。** 「已知某天是星期几，求另一天」是**基准日 + 天数模 `7`** 的模型：星期以 `7` 为周期。年份只到 `1971..2100`，一年一年累加最多 `130` 次，完全不需要公式。难点全在日历规则：闰年、闰月只对 `2` 月之后的日期生效。

**推导。** 暴力：从基准日开始一天一天往后数，最多约 `47000` 次，能过但不优雅。批量跳过：整年按 `365` 或 `366` 天一次跳过，整月按月份天数跳过，最后加上本月的 `day - 1`。闰年规则是「能被 `4` 整除，且（不能被 `100` 整除，或者能被 `400` 整除）」。这个范围里的特例是 `2100`：能被 `100` 整除、不能被 `400` 整除，**不是**闰年。

```python
def day_of_the_week(day: int, month: int, year: int) -> str:
    names = ("Friday", "Saturday", "Sunday", "Monday", "Tuesday", "Wednesday", "Thursday")   # 1971-01-01 是周五
    month_days = (31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31)

    def is_leap(y: int) -> bool:
        return y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)

    days = sum(365 + is_leap(y) for y in range(1971, year))      # 1971-01-01 到 year-01-01 的天数
    days += sum(month_days[:month - 1]) + (month > 2 and is_leap(year))   # 到本月 1 号
    days += day - 1                                              # 到当天
    return names[days % 7]
```

运行：`(31, 8, 2019)` → `"Saturday"`，`(18, 7, 1999)` → `"Sunday"`，`(15, 8, 1993)` → `"Sunday"`，`(1, 1, 1971)` → `"Friday"`，`(29, 2, 2096)` → `"Wednesday"`，`(1, 3, 2100)` → `"Monday"`，`(31, 12, 2100)` → `"Friday"`。

**复杂度。** 时间 `O(Y)`，`Y` 是年份跨度（至多 `130`），可视为常数；空间 `O(1)`。

**易错点。**
- 闰年只写 `y % 4 == 0`：`2100` 会被当成闰年，`(1, 3, 2100)` 得到 `"Tuesday"`（正确 `"Monday"`），`(31, 12, 2100)` 得到 `"Saturday"`（正确 `"Friday"`）。
- 闰日只对 `3` 月及以后的日期生效，所以是 `month > 2 and is_leap(year)`；当年 `1` 月、`2` 月的日期不加这一天。
- 天数要算到「当天」而不是「次日」：用 `day - 1`。写成 `day`，基准日本身 `(1, 1, 1971)` 会得到 `"Saturday"`（正确 `"Friday"`）。

**追问。**
- `O(1)` 的公式：蔡勒（Zeller）公式，把 `1`、`2` 月当作上一年的 `13`、`14` 月，直接算出星期几。
- 标准库：`datetime.date(year, month, day).strftime("%A")` 一行得到英文星期名，实际工作里首选；面试里要会手写上面的版本。
- 求两个日期相差的天数（LC 1360）：各自算出「距基准日的天数」，相减。

**同模式。** LC 1360 日期之间隔几天、LC 1154 一年中的第几天、LC 1507 转变日期格式、LC 1118 一月有多少天、LC 539 最小时间差。
