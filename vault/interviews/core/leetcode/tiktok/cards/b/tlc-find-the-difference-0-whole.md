## Q
**LC 389 找不同**｜Easy · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 1 次 · 最近 2026-08-24（面试记录）

给两个只含小写字母的字符串 `s` 和 `t`。`t` 由 `s` 随机重排后，在随机位置再插入一个字母得到。找出 `t` 中被添加的那个字母。`0 <= s.length <= 1000`，`t.length == s.length + 1`。例：`s = "abcd"`、`t = "abcde"` → `"e"`；`s = ""`、`t = "y"` → `"y"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把 `s` 和 `t` 的所有字符一起异或（XOR）：相同的字符成对抵消（`x ^ x = 0`），最后只剩多出来的那个字母，一遍扫描，`O(1)` 空间。

**识别。** 「两个集合几乎一样，只多一个元素，求多出来的」：信号是**成对出现 + 只有一个落单**，异或的「自反」性质（`x ^ x = 0`、`x ^ 0 = x`、交换律结合律）正好把成对的全部消掉，顺序（重排）无关。同类的信号还有「求和之差」和「计数之差」。

**推导。** 暴力：对 `t` 中每个字母去 `s` 里数出现次数并比较 `O(n^2)` → 用哈希表计数，`s` 加、`t` 减，剩下 `-1` 的就是答案，`O(n)` 时间 `O(Σ)` 空间 → 浪费在计数表：只关心「谁落单」而不关心每个字母出现几次 → 求和之差（`sum(t) - sum(s)`）或异或都只需一个整数 → 异或不会像求和那样依赖数值范围，是这类题的标准答案。

```python
from itertools import chain


def find_the_difference(s: str, t: str) -> str:
    x = 0
    for ch in chain(s, t):          # 不拼接 s + t，省一个临时字符串
        x ^= ord(ch)                # 成对的字符异或为 0，只剩多出来的那个
    return chr(x)
```

运行：`("abcd", "abcde")` → `"e"`；`("", "y")` → `"y"`；`("a", "aa")` → `"a"`；`("aabb", "babba")` → `"b"`；`s` 是 `1000` 个随机小写字母、`t` 是重排后加一个 `"z"` → `"z"`。

**复杂度。** 时间 `O(n)`（`n = len(s)`，一遍扫描 `2n + 1` 个字符）；空间 `O(1)`。

**易错点。**
- 用集合差 `set(t) - set(s)`：`s = "a"`、`t = "aa"` 时集合差是空集，找不到答案（正确 `"a"`）；多出来的字母可能和 `s` 里已有的字母相同，必须按**次数**而不是按种类。
- 忘记 `chr`：`ord` 异或的结果是整数，要转回字符；`ord('a') ^ ord('e')` 是 `4`，不是字母。

**追问。**
- 求和版：`chr(sum(map(ord, t)) - sum(map(ord, s)))`，同样 `O(n)`、`O(1)`；Python 的整数没有溢出，Java / C++ 里要注意，异或没有这个问题。
- 计数版：`next(iter(Counter(t) - Counter(s)))`，可读性最好；如果 `t` 比 `s` 多出的不止一个字符，就用计数把它们全找出来。
- 「落单的是一个数字」：LC 136 只出现一次的数字用同一个异或；两个落单的（LC 260）要先按异或结果的最低位分组。

**同模式。** LC 136 只出现一次的数字、LC 268 丢失的数字、LC 260 只出现一次的数字 III、LC 242 有效的字母异位词。
