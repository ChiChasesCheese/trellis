## Q
**LC 279 完全平方数**｜Medium · CodeTop 国内累计 18 次 · 最近 2026-03-20（CodeTop）

给整数 `n`，返回和为 `n` 的**完全平方数的最少数量**（完全平方数是某个整数的平方，如 1、4、9、16；同一个可以用多次）。`1 <= n <= 10^4`。例：`n = 12` → `3`（`4 + 4 + 4`），`n = 13` → `2`（`4 + 9`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一维 DP（动态规划）：`dp[i]` 是和为 `i` 的最少平方数个数，枚举凑成 `i` 的**最后一个**平方数 `j²`，`dp[i] = 1 + min(dp[i - j²])`，`O(n√n)`。

**识别。** 「凑成目标和 + 最少个数 + 每种可以重复用」是完全背包求最小值的信号，和 LC 322 零钱兑换同构，硬币就是 `1, 4, 9, …`；`n <= 10^4` 时平方数只有 `100` 个，`O(n√n) = 10^6` 级。「最少几步」也可以看成从 `n` 每步减一个平方数到 `0` 的最短路，用 BFS。

**推导。** 暴力递归 `f(n) = 1 + min f(n - j²)`，同一个余数被不同路径反复求，指数级 → 记忆化后每个 `i` 只算一次 → 改成自底向上填表：`dp[0] = 0`，`i` 从小到大，每个 `i` 试 `√i` 个平方数。贪心（每次取最大平方数）不对，必须枚举所有最后一项。

```python
from math import inf, isqrt


def num_squares(n: int) -> int:
    dp = [0] + [inf] * n                    # dp[i]：和为 i 的最少完全平方数个数
    for i in range(1, n + 1):
        dp[i] = 1 + min(dp[i - j * j] for j in range(1, isqrt(i) + 1))   # 枚举最后一个平方数 j²
    return dp[n]
```

运行：`12` → `3`，`13` → `2`，`1` → `1`，`7` → `4`（`4 + 1 + 1 + 1`），`10000` → `1`，`9999` → `4`。

**复杂度。** 时间 `O(n√n)`：每个 `i` 试 `isqrt(i)` 个平方数；空间 `O(n)`。

**易错点。**
- 贪心取最大平方数：`12` 会得到 `9 + 1 + 1 + 1` 共 `4` 个，正确是 `3`（`4 + 4 + 4`）。
- 开方用 `int(n ** 0.5)` 或 `int(math.sqrt(n))`：浮点误差在大数上会多 1，用 `math.isqrt` 得到精确的整数平方根。
- `dp[0] = 0` 是凑成一个平方数时 `1 + dp[0] = 1` 的来源，不能初始化成 `inf`。

**追问。**
- BFS：从 `n` 出发每层减一个平方数，第一次到 `0` 的层数就是答案；用 `set` 存每层的余数去重。
- 数学解 `O(√n)`：答案至多 `4`（四平方和定理）；`n` 去掉因子 4 后模 8 余 7 时答案是 `4`；是平方数是 `1`；能写成两个平方和是 `2`；其余是 `3`。
- 返回具体的拆分：多开一个 `choice[i]` 记下取得最优的 `j²`，最后从 `n` 沿 `choice` 往回走。

**同模式。** LC 322 零钱兑换、LC 518 零钱兑换 II、LC 377 组合总和 IV、LC 139 单词拆分。
