## Q
**LC 1669 合并两个链表**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-02-02（国内 CodeTop）

给两个链表 `list1`（`n` 个节点）和 `list2`（`m` 个节点），整数 `a`、`b`。删除 `list1` 中下标从 `a` 到 `b` 的全部节点（含两端），把 `list2` 接在被删节点的位置，返回结果链表的头。`3 <= list1.length <= 10^4`，`1 <= a <= b < list1.length - 1`，`1 <= list2.length <= 10^4`。例：`list1 = [10,1,13,6,9,5]`，`a = 3, b = 4`，`list2 = [1000000,1000001,1000002]` → `[10,1,13,1000000,1000001,1000002,5]`；`list1 = [0,1,2,3,4,5,6]`，`a = 2, b = 5`，`list2 = [1000000,1000001,1000002,1000003,1000004]` → `[0,1,1000000,1000001,1000002,1000003,1000004,6]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 链表手术：找到下标 `a - 1` 的节点（`before`）和下标 `b + 1` 的节点（`after`），把 `before.next` 指向 `list2` 的头，`list2` 的尾指向 `after`；中间那段节点不再被引用，自然被丢弃。一次遍历 `list1` 加一次遍历 `list2`，`O(n + m)`。

**识别。** 「删掉链表中间一段并换成另一条链表」是指针重连：不需要任何额外数据结构，关键是找准**两个锚点**（被删段的前一个、后一个节点）以及 `list2` 的尾。`a >= 1` 保证有前驱，`b < n - 1` 保证有后继，但用哑节点（dummy node）写法对 `a = 0` 也成立，更稳。

**推导。** 暴力：把两条链表都转成数组，切片拼接再建链表，`O(n + m)` 时间和空间 → 浪费在重建节点：链表本身就能原地改指针 → 走 `a` 步找到 `before`，再走 `b - a + 2` 步找到 `after`，`before.next = list2`，走到 `list2` 的尾接上 `after` → 只改两条指针，额外空间 `O(1)`。

```python
def merge_in_between(list1: ListNode, a: int, b: int, list2: ListNode) -> ListNode:
    dummy = ListNode(0, list1)                  # 哑节点：即使 a = 0 也有"a 的前一个节点"
    before = dummy
    for _ in range(a):                          # 走 a 步，停在下标 a - 1 的节点
        before = before.next
    after = before
    for _ in range(b - a + 2):                  # 再走 b - a + 2 步，停在下标 b + 1 的节点
        after = after.next
    before.next = list2                         # 接上 list2 的头
    tail = list2
    while tail.next:                            # 找 list2 的尾
        tail = tail.next
    tail.next = after                           # list2 的尾接回 list1 的后半段
    return dummy.next
```

运行：示例 1 → `[10,1,13,1000000,1000001,1000002,5]`，示例 2 → `[0,1,1000000,1000001,1000002,1000003,1000004,6]`；`[1,2,3,4]`、`a = 0, b = 1`、`list2 = [9]` → `[9,3,4]`；两条各 `10^4` 个节点、`a = 1, b = 9998` → 结果长度 `10002`。

**复杂度。** 时间 `O(n + m)`；空间 `O(1)`（原地改指针，不新建节点）。

**易错点。**
- 第二段步数少算一步（走 `b - a + 1`，停在下标 `b` 而不是 `b + 1`）：示例 1 得到 `[10,1,13,1000000,1000001,1000002,9,5]`，被删的 `9` 又接了回来；正确是 `[10,1,13,1000000,1000001,1000002,5]`。
- 把 `after` 直接接在 `list2` 的头后面（没找尾）：示例 1 得到 `[10,1,13,1000000,5]`，丢了 `list2` 后面两个节点。
- 先走完再改指针，别边走边改：`before.next = list2` 之后 `before` 后面已经是新链，再往下找 `after` 就找错了。

**追问。**
- 要返回被删下来的那一段：在 `b` 处断开（`last.next = None`），把头存下来。
- `a` 可以是 `0`（删掉头部）：哑节点已经覆盖，不用改。
- 不允许修改 `list1` / `list2`：改成复制节点，空间 `O(n + m)`。
