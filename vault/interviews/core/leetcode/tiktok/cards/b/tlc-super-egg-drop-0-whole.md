## Q
**LC 887 鸡蛋掉落**｜Hard · TikTok 高频

有 `k` 枚相同的鸡蛋和一栋 `n` 层的楼（第 `1` 层到第 `n` 层）。存在一个楼层 `f`（`0 <= f <= n`），从高于 `f` 的楼层扔下的鸡蛋都会碎，从 `f` 层或更低的楼层扔下都不会碎。每次操作取一枚没碎的鸡蛋，从任一楼层 `x`（`1 <= x <= n`）扔下；碎了的蛋不能再用，没碎的可以重复使用。求**最坏情况下**确定 `f` 所需的最少操作次数。`1 <= k <= 100`，`1 <= n <= 10^4`。例：`k = 1, n = 2` → `2`；`k = 2, n = 6` → `3`；`k = 3, n = 14` → `4`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把问题倒过来问：用 `m` 次操作、`k` 枚蛋，最多能确定多少层？设为 `f(m, k)`，则 `f(m, k) = f(m-1, k-1) + f(m-1, k) + 1`（这次扔下后，碎了就用 `k-1` 枚蛋覆盖下面的楼层，没碎就用 `k` 枚蛋覆盖上面的楼层，再加上被扔的这一层本身）。`m` 从 `1` 开始递增，第一个使 `f(m, k) >= n` 的 `m` 就是答案，用一维数组倒序更新。

**识别。** 「最坏情况下的最少次数」是极小极大（minimax）形式的动态规划。直接定义 `dp[蛋数][楼层数] = 最少次数` 要枚举扔哪一层，`O(k n^2)` 在 `k = 100`、`n = 10^4` 下是 `10^10`，太慢。常见突破口是**状态与目标互换**：不存“最少次数”，存“给定次数能覆盖的最大楼层数”，转移里就不用再枚举 `x`。

**推导。** 暴力：`dp[e][f] = 1 + min_x max(dp[e-1][x-1], dp[e][f-x])`，`O(k n^2)`。改进：`dp[e-1][x-1]` 随 `x` 增大而增大，`dp[e][f-x]` 随 `x` 增大而减小，最优的 `x` 在两者的交叉点，可以二分，`O(k n log n)`（见另一种解法）。洞察：不管第一次扔哪一层，只要要求“`m` 次内能确定”，能覆盖的楼层总数就是 `碎了能覆盖的 + 没碎能覆盖的 + 1`，与具体扔哪一层无关，转移 `O(1)`。答案是最小的 `m`，每增加一次操作就整体更新一轮，且 `m` 不会超过 `n`。

```python
def super_egg_drop(k: int, n: int) -> int:
    floors = [0] * (k + 1)                  # floors[j]: 用 j 颗蛋、当前操作次数最多能确定的楼层数
    moves = 0
    while floors[k] < n:
        moves += 1
        for j in range(k, 0, -1):           # 倒序：floors[j - 1] 还是上一轮的值
            floors[j] += floors[j - 1] + 1
    return moves
```

运行：`(1, 2)` → `2`，`(2, 6)` → `3`，`(3, 14)` → `4`，`(1, 1)` → `1`，`(2, 100)` → `14`，`(100, 10**4)` → `14`，`(2, 10**4)` → `141`。

**复杂度。** 时间 `O(k · m)`，`m` 是答案；`k = 1` 时 `m = n`，`k = 100`、`n = 10^4` 时 `m = 14`；空间 `O(k)`。

**易错点。**
- 把鸡蛋当二分查找，每次从当前区间中间扔：`k = 2, n = 100` 得到 `50`（碎了之后只剩一枚蛋，只能逐层扫），正确是 `14`。蛋少时要靠“步长递减”的策略。
- 一维数组正序更新 `j`：`floors[j - 1]` 已经是本轮的新值，等于同一次操作用了两次。`k = 3, n = 14` 得到 `3`，正确是 `4`。必须倒序。
- 转移里漏掉 `+ 1`（被扔的这一层本身）：`floors` 永远是 `0`，死循环。

**追问。**
- 输出每一步该扔哪层：下一次扔 `floors[k-1] + 1`（碎了能被 `k-1` 枚蛋覆盖的部分加一层），没碎则把起点上移。
- 蛋足够多（`k >= n.bit_length()`）时退化为二分，答案 `ceil(log2(n + 1))`，可以先 `k = min(k, n.bit_length())` 缩小工作量。
- `n` 到 `10^18`：`f(m, k) = Σ_{i=1..k} C(m, i)`，对 `m` 二分，每次 `O(k)`（`math.comb` 精确大整数）。
