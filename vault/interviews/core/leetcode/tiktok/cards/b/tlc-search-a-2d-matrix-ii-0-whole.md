## Q
**LC 240 搜索二维矩阵 II**｜Medium · CodeTop 国内累计 43 次 · 最近 2026-02-23（国内 CodeTop）

编写高效算法，在 `m x n` 矩阵 `matrix` 中搜索目标值 `target`。矩阵每行的元素从左到右升序，每列的元素从上到下升序（行与行之间没有大小衔接）。`1 <= m, n <= 300`，`-10^9 <= matrix[i][j], target <= 10^9`。例：`matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]`，`target = 5` → `true`；`target = 20` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从右上角出发：当前值大于 `target`，它所在的整列（往下都更大）可以排除，左移一列；当前值小于 `target`，它所在的整行（往左都更小）可以排除，下移一行；每步排除一行或一列，`O(m + n)`。

**识别。** 行升序且列升序，但行与行之间没有衔接，所以不能把矩阵拉直做一次二分（那是 LC 74 的条件）。信号是「找一个角，使两个方向一个增、一个减」：右上角往左递减、往下递增，每次比较都能确定去向；左下角同理。左上角和右下角做不到，因为两个方向同增或同减。`m, n <= 300` 时 `O(mn)` 也能过，面试里要给 `O(m + n)`。

**推导。** 暴力：遍历全部，`O(mn)`。改进：每行二分，`O(m log n)`，没用上列的有序性。洞察：右上角元素 `a`，同行左边的都比它小，同列下边的都比它大；若 `a > target`，同列下边更大，整列作废；若 `a < target`，同行左边更小，整行作废。每步搜索区域缩小一行或一列，至多 `m + n` 步。

```python
def search_matrix(matrix: list[list[int]], target: int) -> bool:
    row, col = 0, len(matrix[0]) - 1             # 从右上角出发
    while row < len(matrix) and col >= 0:
        cur = matrix[row][col]
        if cur == target:
            return True
        if cur > target:                         # 这一列自上而下递增：cur 往下更大，整列排除
            col -= 1
        else:                                    # 这一行自左而右递增：cur 往左更小，整行排除
            row += 1
    return False
```

**运行。** 例 1（`target = 5`）→ `True`；例 2（`target = 20`）→ `False`；`[[1]], 1` → `True`；`[[1]], 2` → `False`；`[[1,3,5]], 3` → `True`；`[[1],[3],[5]], 4` → `False`；`300 x 300` 矩阵里找不存在的值，瞬间返回。

**复杂度。** 时间 `O(m + n)`：每步让 `row` 加一或 `col` 减一，至多 `m + n` 步；空间 `O(1)`。

**易错点。**
- 从左上角出发：往右、往下都变大，比较之后无法决定走哪边。例 1 里找 `10`，左上角出发会漏掉，返回 `False`，正确是 `True`。
- 方向写反（`cur > target` 时下移）：例 1 找 `5` 会一路下移走出矩阵，返回 `False`，正确是 `True`。
- 当成 LC 74 整体二分：这里行尾不一定小于下一行行首（例 1 中第一行末尾 `15`，第二行开头 `2`），拉直后的数组不是有序的。

**追问。**
- 统计矩阵中小于等于 `target` 的个数（LC 378 的内部步骤）：同样的阶梯，每走到一行累加该行的个数。
- `m` 远小于 `n`：每行用 `bisect_left` 二分，`O(m log n)`，比 `O(m + n)` 更快。
- 分治：取中心元素把矩阵分成四块，排除其中一块，`O(n^1.58)`，不如阶梯法。

**同模式。** LC 74 搜索二维矩阵、LC 378 有序矩阵中第 K 小的元素、LC 1351 统计有序矩阵中的负数。
