## Q
**LC 1171 从链表中删去总和值为零的连续节点**｜Medium · LC 字节 热度 59/100 · CodeTop 国内累计 4 次 · 最近 2024-09-10（CodeTop）

给链表头节点 `head`，反复删去链表中**总和为 0 的连续节点序列**，直到不存在这样的序列，返回最终链表的头节点。答案不唯一，返回任何一个满足要求的结果即可。链表有 `1` 到 `1000` 个节点，`-1000 <= node.val <= 1000`。例：`[1,2,-3,3,1]` → `[3,1]`（`[1,2,1]` 也正确）；`[1,2,3,-3,4]` → `[1,2,4]`；`[1,2,3,-3,-2]` → `[1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 前缀和加哈希，两遍扫描：第一遍记录每个前缀和**最后一次**出现的节点；第二遍重新累加前缀和，让每个节点的 `next` 直接指向「与它前缀和相同的最后一个节点」的 `next`，这一段连续节点总和为 0，被整段跳过。`O(n)`。

**识别。** 「连续一段和为 0」等价于「两个位置的前缀和相等」，是前缀和 + 哈希的信号；链表可能从头开始就被删，所以用哨兵（dummy）节点，它的前缀和是 `0`。「反复删」听起来要循环，但同一前缀和取**最后**出现的位置，一次跳到最远，嵌套的、相邻的零和段会被一并跳过。

**推导。** 暴力：每轮枚举所有连续段找和为 0 的，删掉后重来，`O(n^3)` 或更差。洞察：节点 `i` 与节点 `j`（`i` 在前）的前缀和相等，等价于 `(i, j]` 之间的节点和为 0。被删段和为 0，所以保留下来的节点的前缀和不变，第一遍建好的表对第二遍依然有效。每个前缀和取最后出现的节点，就能从最早出现的位置一次跳到最远处，一遍扫完所有层的零和段。

```python
def remove_zero_sum_sublists(head: ListNode | None) -> ListNode | None:
    dummy = ListNode(0, head)                    # 哨兵：整条链表都被删光时也有地方挂
    last: dict[int, ListNode] = {}               # 前缀和 -> 最后一个取到这个前缀和的节点
    s, node = 0, dummy
    while node:                                  # 第一遍：同一前缀和后出现的覆盖先出现的
        s += node.val
        last[s] = node
        node = node.next
    s, node = 0, dummy
    while node:                                  # 第二遍：从 node 直接跳到同前缀和的最后一个节点之后
        s += node.val
        node.next = last[s].next                 # (node, last[s]] 这一段总和为 0，整段删掉
        node = node.next
    return dummy.next
```

**运行。** `[1,2,-3,3,1]` → `[3, 1]`；`[1,2,3,-3,4]` → `[1, 2, 4]`；`[1,2,3,-3,-2]` → `[1]`；`[0]` → `[]`；`[1,-1]` → `[]`；`[5]` → `[5]`；`1000` 个 `1` 组成的链表原样返回。

**复杂度。** 时间 `O(n)`，两遍线性扫描；空间 `O(n)`，哈希表至多 `n + 1` 项。

**易错点。**
- 第一遍用 `setdefault` 记录**第一次**出现的节点：第二遍会让指针指回前面，链表成环，循环不会结束。必须是后出现的覆盖先出现的。
- 把相邻两个节点和为 0 才删当作全部情况：`[1,2,-3]` 返回 `[1,2,-3]`，正确是 `[]`，因为三个连续节点和为 0。
- 不加哨兵：头部整段被删时没有前驱可改，要写一堆特判；`dummy` 的前缀和 `0` 也要放进哈希表。

**追问。**
- 数组版本：和为 `K` 的子数组个数（LC 560）用「前缀和计数」；最长和为 0 的子数组用「前缀和第一次出现的位置」。
- 只要删去的节点个数，或要输出被删的段：第二遍里记录被跳过的区间。
- 能否 `O(1)` 额外空间：不行，需要哈希表记住前缀和；若链表很短可以退回 `O(n^2)` 的枚举。

**同模式。** LC 560 和为 K 的子数组、LC 525 连续数组、LC 523 连续的子数组和、LC 82 删除排序链表中的重复元素 II（用哨兵处理头部）。
