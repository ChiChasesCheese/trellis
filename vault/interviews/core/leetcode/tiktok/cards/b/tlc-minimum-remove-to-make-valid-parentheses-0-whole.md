## Q
**LC 1249 移除无效的括号**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 2 次 · 最近 2026-02-04（国内 CodeTop）

给由 `'('`、`')'` 和小写字母组成的字符串 `s`。删除**最少**数目的 `'('` 或 `')'`（可以删任意位置的括号），使剩下的括号字符串有效，返回任意一个合法结果。有效字符串指：空串或只含小写字母的串；可以写成 `AB`（`A`、`B` 都有效）；可以写成 `(A)`（`A` 有效）。`1 <= s.length <= 10^5`，`s[i]` 是 `'('`、`')'` 或小写英文字母。例：`"lee(t(c)o)de)"` → `"lee(t(c)o)de"`（`"lee(t(co)de)"` 也对）；`"a)b(c)d"` → `"ab(c)d"`；`"))(("` → `""`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈（stack）存还没配对的 `(` 的下标：遇到 `)`，栈里有 `(` 就配对，没有就把这个 `)` 的下标记为多余；扫完后栈里剩下的 `(` 也都多余；删掉这些下标上的字符。`O(n)`。

**识别。** 「括号是否匹配」是栈的标准问题。「删除最少」听起来像搜索，其实不需要：每个多余的括号都是“被迫”删除的，数量就是最少值，构造方式也是确定的。`n = 10^5` 排除枚举子集。

**推导。** 暴力：枚举要删哪些括号，验证剩下的是否有效，`O(2^n · n)`。观察：括号串有效，当且仅当任何前缀里 `)` 不多于 `(`，且整体 `(` 和 `)` 个数相等。扫描时，一个 `)` 如果前面已没有可配的 `(`，它无论如何都不可能被配上，必须删；扫完后剩下没配上的 `(` 后面再没有 `)` 可配，也必须删。被迫删除的个数是下界，而删完这些之后恰好有效，所以达到下界，就是最少。栈里存下标而不是字符，才能在最后知道删哪个位置。

```python
def min_remove_to_make_valid(s: str) -> str:
    drop: set[int] = set()                 # 要删掉的括号下标
    opens: list[int] = []                  # 还没配对的 "(" 的下标
    for i, ch in enumerate(s):
        if ch == "(":
            opens.append(i)
        elif ch == ")":
            if opens:
                opens.pop()                # 配上最近的 "("
            else:
                drop.add(i)                # 前面没有可配的 "("：这个 ")" 多余
    drop.update(opens)                     # 扫完仍没配上的 "(" 也多余
    return "".join(ch for i, ch in enumerate(s) if i not in drop)
```

运行：`"lee(t(c)o)de)"` → `'lee(t(c)o)de'`，`"a)b(c)d"` → `'ab(c)d'`，`"))(("` → `''`，`"((a)"` → `'(a)'`，`"(a(b(c)d"` → `'ab(c)d'`；`50000` 个 `(` 接 `50000` 个 `)` 保持原样，约 `4 ms`。

**复杂度。** 时间 `O(n)`；空间 `O(n)`。

**易错点。**
- 只删多余的 `)`，扫完不处理栈里剩下的 `(`：`"((a)"` 原样返回（正确 `'(a)'`），`"(a(b(c)d"` 原样返回（正确 `'ab(c)d'`），`"))(("` 得到 `'(('`（正确 `''`）。
- 栈里存字符而不是下标：配对时没问题，但最后不知道该删哪一个位置。
- 在循环里用 `s = s[:i] + s[i+1:]` 删字符：每次复制整个字符串，`O(n^2)`，`n = 10^5` 会超时；先收集下标，最后一次 `join`。

**追问。**
- `O(1)` 额外空间（不算输出）：两遍扫描，从左到右用计数器删多余的 `)`，再从右到左删多余的 `(`。
- 只要最少删除的个数：`len(drop)`，或者一个计数器加一个“未配对 `(` 数”，空间 `O(1)`（LC 921）。
- 列出所有最少删除的方案（LC 301）：从原串出发按层 BFS，每层删一个括号并去重，第一次出现有效串的那一层就是最少删除数。

**同模式。** LC 921 使括号有效的最少添加、LC 301 删除无效的括号、LC 20 有效的括号、LC 32 最长有效括号、LC 1963 使字符串平衡的最小交换次数。
