## Q
**LC 11 盛最多水的容器**｜Medium · TikTok·字节 高频

给长度为 `n` 的整数数组 `height`，有 `n` 条垂线，第 `i` 条的两个端点是 `(i, 0)` 和 `(i, height[i])`。找出其中两条线，使它们与 `x` 轴构成的容器能容纳最多的水，返回这个最大水量（容器不能倾斜）。`n == height.length`，`2 <= n <= 10^5`，`0 <= height[i] <= 10^4`。例：`[1,8,6,2,5,4,8,3,7]` → `49`（第 1 条和第 8 条线，水位 7、宽 7）；`[1,1]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 双指针从两端向中间收缩：每步计算面积 `min(height[l], height[r]) * (r - l)` 并更新答案，然后移动**较矮**的一侧；移动较高的一侧不可能得到更大的面积。`O(n)`。

**识别。** 「选两个下标，使 `f(i, j) = min(h[i], h[j]) * (j - i)` 最大」：面积 = 短板 × 宽度。`n = 10^5` 排除 `O(n^2)`。宽度从最大开始往小缩，只有找到更高的短板才可能补回宽度的损失，这是双指针贪心的信号。

**推导。** 暴力：枚举所有二元组，`O(n^2)`。洞察：从最宽的一对 `(0, n-1)` 开始。设 `height[l] < height[r]`，那么线 `l` 和任何 `r' < r` 组成的容器：水位不超过 `height[l]`，宽度比现在更小，面积一定更小；所以线 `l` 的所有候选都不可能超过当前，可以淘汰 `l`，即移动短板。每步淘汰一条线，`n - 1` 步结束，且最优解不会被淘汰。

```python
def max_area(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        h = min(height[left], height[right])     # 水位由短板决定
        best = max(best, h * (right - left))
        if height[left] < height[right]:         # 移动长板只会让宽度变小、水位不会更高，所以动短板
            left += 1
        else:
            right -= 1
    return best
```

**运行。** `[1,8,6,2,5,4,8,3,7]` → `49`；`[1,1]` → `1`；`[0,0]` → `0`；`[4,3,2,1,4]` → `16`；`[1,2,1]` → `2`；十万条随机高度的线约 5 毫秒。

**复杂度。** 时间 `O(n)`：每次循环 `left` 加一或 `right` 减一，共至多 `n - 1` 次；空间 `O(1)`。

**易错点。**
- 移动较高的一侧：`[1,8,6,2,5,4,8,3,7]` 会返回 `8`，正确是 `49`；高板留下，短板永远限制水位，宽度却在变小。
- 水位取 `max` 而不是 `min`：同一个输入返回 `56`，容器的水位由短板决定，不能超过它。
- 宽度写成 `right - left + 1`：`[1,1]` 返回 `2`，正确是 `1`，宽度是两条线的距离，不是线的条数。

**追问。**
- 返回是哪两条线：更新 `best` 时同时记下 `(left, right)`。
- 接雨水（LC 42）与此不同：要累计所有柱子上方的水，用双指针加左右最大值，不是选两条线。
- 两条线高度相等时移哪一侧：任意一侧都行（上面的 `else` 移动右侧），两条线都不可能与对方组成更好的容器。

**同模式。** LC 42 接雨水、LC 167 两数之和 II、LC 15 三数之和、LC 16 最接近的三数之和。
