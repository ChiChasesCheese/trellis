## Q
**LC 252 会议室**｜Easy · LC TikTok 热度 50/100 · CodeTop 国内累计 3 次 · 最近 2022-03-09（CodeTop）

给会议时间数组 `intervals`，`intervals[i] = [start_i, end_i]`。一个人能参加所有会议，当且仅当任意两个会议的时间段不重叠；在时间 `t` 结束的会议和在时间 `t` 开始的会议**不重叠**。能参加全部会议返回 `true`，否则 `false`。`0 <= intervals.length <= 10^4`，`intervals[i].length == 2`，`0 <= start_i < end_i <= 10^6`。例：`[[0,30],[5,10],[15,20]]` → `false`，`[[7,10],[2,4]]` → `true`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 按开始时间排序，只检查**相邻**两个会议：前一个的结束时间必须不晚于后一个的开始时间。`O(n log n)`。

**识别。** 「区间是否有重叠」是区间题的入口：先**排序**，把二维的「任意两个比较」降成一维的「相邻比较」。结束时间等于开始时间算不重叠，所以比较用 `<=`。

**推导。** 暴力：任意两个会议两两判断重叠，`O(n^2)`，`n = 10^4` 约 `5 · 10^7` 次，Python 偏慢 → 排序后，若第 `i` 个与后面某个第 `j` 个重叠（`start_j < end_i`），因为 `start_{i+1} <= start_j`，所以第 `i+1` 个必然也与第 `i` 个重叠 → 只需检查相邻对，排序后 `O(n)` 扫描。

```python
from itertools import pairwise

def can_attend_meetings(intervals: list[list[int]]) -> bool:
    ordered = sorted(intervals)                          # 按开始时间排序，不改入参
    return all(prev[1] <= cur[0] for prev, cur in pairwise(ordered))
```

运行：`[[0,30],[5,10],[15,20]]` → `False`，`[[7,10],[2,4]]` → `True`，`[]` → `True`，`[[1,2],[2,3]]` → `True`，`[[1,5]]` → `True`；`10^4` 个首尾相接的短会议打乱顺序 → `True`。

**复杂度。** 时间 `O(n log n)`（排序主导）；空间 `O(n)`（排序后的新列表）。

**易错点。**
- 不排序直接检查相邻：`[[7,10],[2,4]]` 会因为 `10 <= 2` 不成立返回 `False`，正确是 `True`。
- 比较写成 `<`（把「结束时间等于开始时间」当重叠）：`[[1,2],[2,3]]` 返回 `False`，正确是 `True`。
- 空数组返回 `True`；`all()` 对空序列恰好是 `True`，不用特判。

**追问。**
- 最少需要几间会议室（LC 253）：排序后用小根堆存各房间的结束时间，开始时间不早于堆顶就复用，否则新开一间；`O(n log n)`。
- 在线插入新会议并判断是否冲突：用 `bisect` 在有序列表里找到位置，只需检查前后两个邻居，`O(log n)` 查找。
- 返回冲突的那一对会议：在 `all` 的位置改成循环，遇到重叠就返回 `(prev, cur)`。

**同模式。** LC 253 会议室 II、LC 56 合并区间、LC 57 插入区间、LC 435 无重叠区间。
