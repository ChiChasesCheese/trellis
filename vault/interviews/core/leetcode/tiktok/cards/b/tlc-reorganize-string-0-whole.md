## Q
**LC 767 重构字符串**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 5 次 · 最近 2026-05-20（国内 CodeTop）

给字符串 `s`，判断能否重新排列其中的字母，使任意两个相邻字符都不同。可以就返回任意一种排列，不行就返回空字符串 `""`。`1 <= s.length <= 500`，`s` 只含小写字母。例：`"aab"` → `"aba"`；`"aaab"` → `""`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 贪心加最大堆（max-heap）：每步取出剩余次数最多的字符放到结果末尾，但刚用过的那个字符先放在一边，隔一步才回到堆里；堆空时结果没排满就说明不可行。可行的充要条件是出现最多的字符不超过 `(n + 1) // 2` 次。`O(n log k)`，`k <= 26`。

**识别。** 「重排」「相邻不同」「每次要选剩余最多的」是贪心加堆的信号。约束只涉及邻居，不涉及全局计数，所以要记住上一步用了谁。`n <= 500` 很小，复杂度不是瓶颈，考的是贪心的正确性和能否推广到 LC 358 这类“间隔 `k`”的变体。

**推导。** 暴力：枚举全排列检查相邻，`O(n! · n)`。浪费：只关心相邻是否相等，大量排列等价。洞察一：出现最多的字符最难安置，应该优先放。洞察二：每步在「不等于上一个」的字符里取剩余最多的。判据：`n` 个位置里两两不相邻的位置最多 `(n + 1) // 2` 个，最多的字符超过它就一定有相邻重复。实现：`heapq` 是最小堆，存 `(-次数, 字符)`；取出后不立即放回，下一轮取完才放回，这样下一轮堆顶一定不同于上一个。

```python
from collections import Counter
from heapq import heapify, heappop, heappush


def reorganize_string(s: str) -> str:
    heap = [(-cnt, ch) for ch, cnt in Counter(s).items()]
    heapify(heap)                           # 出现次数最多的字符在堆顶
    out: list[str] = []
    held = (0, "")                          # 上一轮刚用过、暂时不能再选的 (负计数, 字符)
    while heap:
        cnt, ch = heappop(heap)
        out.append(ch)
        if held[0]:
            heappush(heap, held)            # 上一个字符隔了一位，可以重新参选
        held = (cnt + 1, ch)                # 用掉一个，剩余数量暂存
    return "".join(out) if len(out) == len(s) else ""
```

运行：`"aab"` → `'aba'`，`"aaab"` → `''`，`"a"` → `'a'`，`"vvvlo"` → `'vlvov'`，`"aabbb"` → `'babab'`；`"a"` 和 `"b"` 各 `250` 个 → `'abababab…'`，长度 `500` 且相邻都不同。

**复杂度。** 时间 `O(n log k)`，`k` 是不同字符数（至多 `26`），实际接近 `O(n)`；空间 `O(k)` 加结果。

**易错点。**
- 不暂存上一个字符，取出后立刻放回：`"aab"` 得到 `"aab"`（相邻重复），正确是 `"aba"`。
- 循环结束后不检查长度：`"aaab"` 循环退出时 `out = "aba"`，还有一个 `a` 留在 `held` 里，必须靠 `len(out) == len(s)` 返回 `""`。
- `heapq` 是最小堆，要存负次数；元组里次数相同时按字符比较，结果是确定的。

**追问。**
- 同字符至少间隔 `k` 位（LC 358）：暂存槽换成长度 `k` 的 `deque`，每步放入新用的字符，队列长度达到 `k` 时把最老的放回堆。
- 只问可不可以：`max(Counter(s).values()) <= (len(s) + 1) // 2`，`O(n)`。
- 线性构造：按次数从多到少把字符排成一排，先填偶数下标再填奇数下标，不需要堆。

**同模式。** LC 358 K 距离间隔重排字符串、LC 621 任务调度器、LC 1054 距离相等的条形码、LC 1405 最长快乐字符串。
