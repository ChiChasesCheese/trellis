## Q
**LC 3441 变成好标题的最少代价**｜Hard · LC TikTok 热度 62/100

给长度为 `n` 的字符串 `caption`。如果每个字符都位于**连续出现至少 3 次**的一组里，它就是好标题：`"aaabbb"`、`"aaaaccc"` 是，`"aabbb"`、`"ccccd"` 不是。每次操作可以选下标 `i`，把该处字符改成字母表中的前一个字母（要求不是 `'a'`）或后一个字母（要求不是 `'z'`）。用最少的操作次数把 `caption` 变成好标题；有多个最优结果时返回字典序最小的；无法做到返回 `""`。`1 <= caption.length <= 5 * 10^4`，只含小写字母。例：`"cdcd"` → `"cccc"`（`"dddd"` 同样 2 步，但字典序更大）；`"aca"` → `"aaa"`；`"bc"` → `""`（长度不足 3）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把字符改成别的字母的代价就是字母差，所以变成目标串 `T` 的总代价是逐位 `|caption[i] - T[i]|` 之和。先从右往左做 DP：`h[i][c][r]` 表示第 `i` 位已定为字母 `c`、末尾连续长度为 `r`（`1`、`2`、`>= 3` 三档）时，补完右边的最小代价；再从左往右逐位贪心：每一位取最小的字母，只要「已花代价 + 这一位的代价 + `h`」仍等于全局最小。`O(26n)`。

**识别。** 「最少操作次数」，且每次只改一格、代价是字母差，意味着总代价按位独立相加，适合 DP。「每个字符都在长度 `>= 3` 的连续组里」的约束只依赖「当前连续长度」，状态里只要记 `min(长度, 3)`。「代价最小里取字典序最小」要用两步法：先用 DP 算出每个状态的最小补完代价，再按位贪心重建；已选定的前缀唯一决定当前状态，所以每一位只需判断「选这个字母后，是否还能达到全局最优」。

**推导。** 暴力：枚举所有好标题，`26^n`。观察：约束只涉及「上一位的字母」和「当前连续长度」，状态 `(位置, 字母, 连续长度)` 共 `78n` 个。转移：与上一位相同字母则长度加一（封顶 3）；换字母要求上一段长度已达 3。换字母时要在 25 个字母里取最小，用「最小和次小」排除同字母，转移降到 `O(1)`，总 `O(26n)`。重建时：前缀决定 `(字母, 长度)` 和已花代价，从 `a` 到 `z` 试每个字母，第一个使「已花 + 本位 + `h` 等于全局最小」的就是字典序最小的最优选择。

```python
from array import array

INF = 10**9


def min_cost_good_caption(caption: str) -> str:
    n = len(caption)
    if n < 3:
        return ""
    cap = [ord(ch) - 97 for ch in caption]
    W = 26 * 3                                   # 每个位置 78 个状态：(字母 c, 连续长度 r)，r = 1, 2, 3(表示 >= 3)
    # h[i*W + c*3 + (r-1)]：位置 i 已定为字母 c、末尾连续 r 个时，补完 i+1.. 的最小代价（补不成为 INF）
    h = array("i", [INF]) * (n * W)
    for c in range(26):
        h[(n - 1) * W + c * 3 + 2] = 0           # 最后一位只有连续长度 >= 3 才合法
    for i in range(n - 2, -1, -1):
        nxt = (i + 1) * W
        cost = [abs(cap[i + 1] - c) for c in range(26)]
        # 换字母的最优：min over c' of cost[c'] + h[i+1][c'][r=1]，保留最小和次小，用来排除 c' == c
        g = sorted((cost[c] + h[nxt + c * 3], c) for c in range(26))
        (g1, c1), (g2, _) = g[0], g[1]
        for c in range(26):
            base = i * W + c * 3
            for r in range(3):                   # r+1 为当前连续长度
                stay = cost[c] + h[nxt + c * 3 + min(r + 1, 2)]      # 接着写同一个字母
                switch = (g2 if c == c1 else g1) if r == 2 else INF  # 只有连续 >= 3 才能换字母
                h[base + r] = min(stay, switch, INF)

    # 从左到右贪心：每一位取最小的字母，只要"已花代价 + 这一位 + 补完"仍等于全局最小
    best = min(abs(cap[0] - c) + h[c * 3] for c in range(26))
    if best >= INF:
        return ""
    out: list[str] = []
    acc, cur, run = 0, -1, 0                     # 已花代价、上一个字母、连续长度(1,2,3)
    for i in range(n):
        for c in range(26):
            if i == 0:
                r = 0
            elif c == cur:
                r = min(run, 2)                  # 连续长度 run -> min(run+1, 3) 对应下标 min(run, 2)
            elif run == 3:
                r = 0
            else:
                continue
            step = abs(cap[i] - c)
            if acc + step + h[i * W + c * 3 + r] == best:
                out.append(chr(97 + c))
                acc, cur, run = acc + step, c, r + 1
                break
    return "".join(out)
```

**运行。** `"cdcd"` → `"cccc"`；`"aca"` → `"aaa"`；`"bc"` → `""`；`"aaa"` → `"aaa"`；`"abcabc"` → `"bbbbbb"`；`"zzzaaa"` → `"zzzaaa"`；`"zzzzy"` → `"zzzzz"`；五万个随机字母约 0.5 秒。

**复杂度。** 时间 `O(26n)`：每个位置 78 个状态，每个 `O(1)`，重建每位至多试 26 个字母；空间 `O(78n)`，`array('i')` 约 `5 * 10^4 * 78 * 4` 字节，约 15 MB。

**易错点。**
- 允许连续长度不足 3 时换字母：`"abcabc"` 会原样返回（0 步），但它不是好标题；正确答案是 `"bbbbbb"`。
- 代价并列时没有取字典序最小：`"cdcd"` 返回 `"dddd"` 而不是 `"cccc"`。重建时必须从 `'a'` 到 `'z'` 试，并以「等于全局最小」为准，而不是只看当前位置代价最小。
- `array('i')` 是 32 位有符号整数：`INF` 与代价相加会溢出，每步 `min(…, INF)` 截断；`n < 3` 要先返回 `""`。

**追问。**
- 只要最少操作数、不要字符串：把块长度限制在 3、4、5，块内全改成中位数字母，`f[i]` 为后缀最小代价，`O(n)`；但块边界不由前缀唯一决定，不能直接逐位贪心出字典序最小的串。
- 把「至少 3 次」改成「至少 `k` 次」：状态里长度封顶到 `k`，状态数变成 `26k` 每位，总 `O(26nk)`。
- 只要任意一个最优串：重建时取第一个满足等式的字母就行，不必从小到大约束。
