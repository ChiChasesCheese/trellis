## Q
**LC 71 简化路径**｜Medium · TikTok 高频

给一个 Unix 风格的绝对路径 `path`（以 `'/'` 开头），把它化成规范路径。规则：`'.'` 表示当前目录；`'..'` 表示上一级目录（根目录没有上一级，留在根目录）；多个连续的 `'/'` 视为一个；其他形式的点（如 `'...'`、`'....'`）是合法的目录名。规范路径必须以 `'/'` 开头，两个目录名之间只有一个 `'/'`，末尾不能有 `'/'`（根目录除外），且不含 `'.'` 或 `'..'`。`1 <= path.length <= 3000`，`path` 由英文字母、数字、`'.'`、`'/'`、`'_'` 组成，且是有效的绝对路径。例：`"/home/"` → `"/home"`；`"/home//foo/"` → `"/home/foo"`；`"/home/user/Documents/../Pictures"` → `"/home/user/Pictures"`；`"/../"` → `"/"`；`"/.../a/../b/c/../d/./"` → `"/.../b/d"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈保存当前路径的目录名：按 `'/'` 切分后逐段处理，`'..'` 弹栈（栈空则忽略），空串和 `'.'` 忽略，其余入栈；最后用 `'/'` 拼起来，前面加一个 `'/'`。`O(n)`。

**识别。** 「`..` 回退到上一级」就是栈的弹出：路径是一串目录的进入与退出，后进先出。`path.split('/')` 一次解决「多个斜杠」和「结尾斜杠」：切出来的空串直接丢掉。`n <= 3000`，没有性能压力，考的是规则覆盖是否完整。

**推导。** 暴力：反复用字符串替换去掉 `//`、`/./`、`/xxx/../`，每次替换要重新扫描，边界（根目录、`...`）很容易漏。浪费：多次扫描、字符串反复拷贝。洞察：处理一段目录名只取决于栈顶：普通名字入栈，`..` 弹出栈顶，`.` 和空串没有任何效果。所以一趟扫描、一个栈就够了。

```python
def simplify_path(path: str) -> str:
    stack: list[str] = []
    for part in path.split('/'):       # '//' 切出空串，'.' 与空串都只是噪声
        if part == '..':
            if stack:                  # 根目录没有上一级：栈空时忽略
                stack.pop()
        elif part and part != '.':     # '...' 之类是合法名字，照常入栈
            stack.append(part)
    return '/' + '/'.join(stack)
```

运行：`"/home/"` → `"/home"`，`"/home//foo/"` → `"/home/foo"`，`"/home/user/Documents/../Pictures"` → `"/home/user/Pictures"`，`"/../"` → `"/"`，`"/.../a/../b/c/../d/./"` → `"/.../b/d"`，`"/"` → `"/"`，`"/a/./b/../../c/"` → `"/c"`。

**复杂度。** 时间 `O(n)`：切分和遍历各一趟；空间 `O(n)`：栈和切分结果。

**易错点。**
- `..` 不判栈空就弹栈：`"/../"` 抛 `IndexError: pop from empty list`，正确结果是 `"/"`。
- 用 `part.startswith('.')` 当作特殊目录：`"/.../a/../b/c/../d/./"` 会把 `...` 当成特殊段丢掉，得到 `"/b/d"`，正确是 `"/.../b/d"`。只有恰好等于 `'.'` 和 `'..'` 的段才特殊。
- 结果为空栈时要返回 `"/"`，不是空串：`'/' + '/'.join([])` 恰好是 `"/"`。

**追问。**
- 相对路径（不以 `/` 开头）：`..` 在栈空或栈顶也是 `..` 时要保留，结果为空时返回 `"."`。
- 标准库 `posixpath.normpath` 能不能直接用：规则几乎一致，但开头恰好两个 `/` 时会保留（`normpath("//a/b")` 得到 `"//a/b"`），要先处理；面试里要手写。
- 符号链接（symlink）：`a/b/..` 不一定等于 `a`，词法化简和真实文件系统解析（`os.path.realpath`）是两回事。

**同模式。** LC 20 有效的括号、LC 150 逆波兰表达式求值、LC 394 字符串解码、LC 1047 删除字符串中的所有相邻重复项、LC 1598 文件夹操作日志搜集器。
