## Q
**LC 2850 将石头分散到网格图的最少移动次数**｜Medium · LC TikTok 热度 50/100

给大小为 `3 * 3`、下标从 `0` 开始的整数矩阵 `grid`，`grid[i][j]` 是格子里的石头数，网格里总共恰好有 `9` 个石头，一个格子可能有多个。每次操作可以把一个石头从当前格子移动到有公共边的相邻格子。返回让每个格子恰好有一个石头的**最少**移动次数。`grid.length == grid[i].length == 3`，`0 <= grid[i][j] <= 9`，`grid` 中元素之和为 `9`。例：`[[1,1,0],[1,1,1],[1,2,1]]` → `3`；`[[1,3,0],[1,0,0],[1,0,3]]` → `4`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 多出来的石头（一个格子有 `k` 颗就多 `k - 1` 颗）要和空格子一一配对，一颗石头移到指定格子的最少步数是曼哈顿距离；枚举空格子的所有排列，把多余石头按顺序分配过去，取总曼哈顿距离的最小值。空格子最多 `8` 个，`8! = 40320` 种排列。

**识别。** `3 × 3`、石头总数恰好等于格子数、目标是每格一颗，这是供需一一对应的匹配问题（assignment problem）。数据极小，排列枚举就够；规模大了要用匈牙利算法、最小费用流或状压 DP。

**推导。** 暴力：把 `9` 个格子的石头分布当作状态（共 `C(17, 8) = 24310` 个），每步移动一颗石头到相邻格子，从当前状态 BFS 到全 `1` 的状态，可行但代码长。洞察：目标状态里多余石头的个数正好等于空格子的个数，每颗多余石头最终落在某个空格里。一颗石头从格子 A 走到格子 B 至少要曼哈顿距离步；沿途的格子里即使有石头，也可以让它们“顺延”接力，总步数不变。因此总代价就是所选匹配的距离之和，最少移动次数是最小代价匹配。

```python
from itertools import permutations


def minimum_moves(grid: list[list[int]]) -> int:
    extra = [(r, c) for r in range(3) for c in range(3) for _ in range(grid[r][c] - 1)]   # 多出来的石头（一个格子多 k 个就重复 k-1 次）
    empty = [(r, c) for r in range(3) for c in range(3) if grid[r][c] == 0]               # 空格子
    return min(
        sum(abs(r1 - r2) + abs(c1 - c2) for (r1, c1), (r2, c2) in zip(extra, order))
        for order in permutations(empty)            # 枚举“哪颗多余石头去哪个空格”
    )
```

运行：`[[1,1,0],[1,1,1],[1,2,1]]` → `3`，`[[1,3,0],[1,0,0],[1,0,3]]` → `4`，`[[1,1,1],[1,1,1],[1,1,1]]` → `0`，`[[9,0,0],[0,0,0],[0,0,0]]` → `18`，`[[0,0,0],[0,9,0],[0,0,0]]` → `12`；`8` 个空格的最坏情形约 `15 ms`。

**复杂度。** 时间 `O(E! · E)`，`E` 是空格数，`E <= 8`；空间 `O(E)`。

**易错点。**
- 一个格子里的多颗石头只当一颗：`for _ in range(grid[r][c] - 1)` 漏掉，写成 `if grid[r][c] > 1`，示例 2 的 `3` 颗石头格子只算一颗，`zip` 悄悄截断，得到 `2`（正确 `4`）。
- 贪心地每次挑距离最近的（多余石头、空格）对：`[[0,2,0],[2,1,1],[1,1,1]]` 贪心得到 `4`，正确是 `2`（`(0,1)→(0,2)` 和 `(1,0)→(0,0)` 各一步）。
- `extra` 与 `empty` 长度必须相等（总和为 `9` 保证），`zip` 不会报错，少一边就静默截断；写代码时心里要核对这条。

**追问。**
- 网格更大（`n × n`）：排列数爆炸，改成状压 DP（`dp[mask]` 表示前 `popcount(mask)` 颗多余石头已经落在 `mask` 里的空格，`O(2^E · E)`），或匈牙利算法，`O(E^3)`。
- 目标不是每格一颗，而是每格有各自的需求量：变成运输问题，用最小费用最大流。
- 要输出具体的移动序列：对每个匹配的（石头、空格）对，沿曼哈顿路径逐格移动。

**同模式。** LC 1066 校园自行车分配 II、LC 1947 最大兼容性评分和、LC 2172 数组的最大与和、LC 1879 两个数组最小的异或值之和。
