## Q
**LC 369 给单链表加一**｜Medium · CodeTop 国内累计 1 次 · 最近 2025-11-12（国内 CodeTop）

用链表表示一个非负整数，**最高位在链表头**，每个节点存一位数字。把这个整数加上 `1`，返回结果链表的头。链表节点数在 `[1, 100]`，`0 <= Node.val <= 9`，数字不含前导零（除了零本身）。例：`head = [1,2,3]` → `[1,2,4]`；`head = [0]` → `[1]`；`head = [9,9,9]` → `[1,0,0,0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 加一的进位只会沿着末尾连续的 `9` 向前传：找到**最后一个不是 `9` 的节点**，它加一，它后面的节点（全是 `9`）全部变 `0`；如果整条链都是 `9`，在最前面补一个哑节点（dummy node）充当新的最高位。一遍扫描，`O(n)` 时间、`O(1)` 空间。

**识别。** 「链表表示数字 + 低位在尾部」：加法要从尾部开始，但单链表只能从头走。常见出路有三种——反转链表、用栈、或者利用「加一」这个特殊性：进位只传递给末尾那串 `9`，找到停下的位置即可，不需要真的逐位处理进位。`n <= 100` 说明各种方法都能过，面试看的是 `O(1)` 空间的写法。

**推导。** 暴力：把链表转成整数、加一、再转回链表，`O(n)` 空间，且绕开了链表操作 → 反转链表，从头加一、处理进位，再反转回来，`O(1)` 空间但要三趟遍历 → 观察：加一时，末尾的 `9` 变 `0` 并向前进位，遇到第一个非 `9` 的数字就停（它加一，不再进位）→ 记录最后一个非 `9` 节点，加一并把它后面的节点置 `0`；全是 `9` 时，哑节点（值 `0`）本身就是「最后一个非 `9`」，加一后变成新的最高位 `1`。

```python
def plus_one(head: ListNode) -> ListNode:
    dummy = ListNode(0, head)                   # 哑节点：应对 999 -> 1000 需要新增最高位
    not_nine = dummy                            # 最后一个值不是 9 的节点
    node = head
    while node:
        if node.val != 9:
            not_nine = node
        node = node.next
    not_nine.val += 1                           # 它加一，它后面全是 9，全部变成 0
    node = not_nine.next
    while node:
        node.val = 0
        node = node.next
    return dummy if dummy.val else head         # 哑节点被进位成 1 才是新头
```

运行：`[1,2,3]` → `[1,2,4]`，`[0]` → `[1]`，`[9,9,9]` → `[1,0,0,0]`，`[1,9,9]` → `[2,0,0]`，`[9]` → `[1,0]`，`[1,9,2,9]` → `[1,9,3,0]`，`100` 个 `9` → 长度 `101`。

**复杂度。** 时间 `O(n)`（一趟找位置，一趟置零，合计 `2n` 以内）；空间 `O(1)`。

**易错点。**
- 只给最后一个节点加一，不处理进位：`[1,9,9]` 得到 `[1,9,10]`，一个节点里出现 `10`；正确是 `[2,0,0]`。
- 没有哑节点，全 `9` 时没有地方放进位：`[9,9,9]` 得到 `[0,0,0]`，正确是 `[1,0,0,0]`。
- `not_nine` 初值取 `head` 而不是哑节点：`[9,9]` 里没有非 `9` 的节点，`head` 被加一成 `10`，得到 `[10,0]`，正确是 `[1,0,0]`。

**追问。**
- 数字是**低位在前**（逆序存储）：从头开始，遇到 `9` 变 `0` 继续向后，遇到不是 `9` 的加一就结束；走到尾还有进位就在尾部补一个 `1`。
- 加的是任意链表（LC 445 两数相加 II）：用栈或反转对齐低位，逐位相加并处理进位。
- 不能修改输入：先复制一份链表，再按上面的方法处理。

**同模式。** LC 66 加一、LC 2 两数相加、LC 445 两数相加 II、LC 2816 翻倍以链表形式表示的数字、LC 206 反转链表。
