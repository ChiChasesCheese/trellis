## Q
**LC 45 跳跃游戏 II**｜Medium · LC TikTok 热度 50/100 · CodeTop 国内累计 20 次 · 最近 2026-03-06（CodeTop）

给长度为 `n` 的非负整数数组 `nums`，初始站在下标 `0`。`nums[i]` 表示从 `i` 出发最多向后跳 `nums[i]` 格（可以跳 `0` 到 `nums[i]` 之间的任意格数，且不越界）。求到达下标 `n - 1` 的**最少跳跃次数**；保证一定能到达。`1 <= nums.length <= 10^4`，`0 <= nums[i] <= 1000`。例：`[2,3,1,1,4]` → `2`（`0 → 1 → 4`），`[2,3,0,1,4]` → `2`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把「跳 `j` 次能到的所有格子」看成 BFS 的一层；一趟扫描中，边扫当前层边记下下一层能到的最远位置 `farthest`，扫到当前层末尾就计一跳、把层边界换成 `farthest`。`O(n)`，`O(1)` 空间。

**识别。** 「最少次数」+「每一步有多个去处」= 无权图最短路（BFS）。再看结构：每格能到的是一段**连续区间**，所以每一层也是一段连续前缀，BFS 的队列可以压缩成两个数（本层右边界、下一层最远点）。`n = 10^4` 时 `O(n^2)` 的 DP 在 Python 里约 `10^8` 次操作，会超时。

**推导。** 暴力 DFS 枚举每一步跳多远，指数级 → 用 `dp[j] = min(dp[i] + 1)` 记忆化，`O(n^2)` → 观察到 `dp` 沿下标**单调不降**（更靠后的格子不可能比靠前的更早到），所以「恰好 `k` 跳到达」的格子是一段连续区间 → 不必记每个格子的 `dp`，只要每层的右边界 → 扫描时顺手维护下一层的右边界，一趟 `O(n)`。

```python
def jump(nums: list[int]) -> int:
    jumps = cur_end = farthest = 0
    for i in range(len(nums) - 1):      # 最后一格不用再跳，所以不扫它
        farthest = max(farthest, i + nums[i])
        if i == cur_end:                # 当前这一跳的范围走完了，必须再跳一次
            jumps += 1
            cur_end = farthest          # 下一层的右边界
    return jumps
```

运行：`[2,3,1,1,4]` → `2`，`[2,3,0,1,4]` → `2`，`[0]` → `0`，`[1]` → `0`，`[1,1,1,1]` → `3`，`[1]*10000` → `9999`。

**复杂度。** 时间 `O(n)`（每个下标看一次）；空间 `O(1)`。

**易错点。**
- 循环范围写成 `range(len(nums))`：扫到最后一格时 `i == cur_end` 会多计一跳。`[2,3,1,1,4]` 错成 `3`（正确 `2`）。
- 以为「每次跳到 `nums[j]` 最大的格子」就最优：应比较 `j + nums[j]`（能到多远）。`[2,1,1,0]` 按值挑会走 `0→1→2→3` 得 `3`，正确是 `0→2→3` 得 `2`。
- 单元素数组答案是 `0`，不是 `1`。

**追问。**
- 不保证能到达（即 LC 55）：在 `i == cur_end` 时若 `farthest <= i` 就返回 `-1` / `False`。
- 要输出具体路径：每层记下使 `i + nums[i]` 最大的 `i`，层结束时把它压入路径。
- 每次跳跃有不同代价：贪心失效，改 DP 或 Dijkstra。

**同模式。** LC 55 跳跃游戏、LC 1024 视频拼接、LC 1326 灌溉花园的最少水龙头数目、LC 871 最低加油次数。
