## Q
**LC 286 墙与门**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 1 次 · 最近 2023-10-28（国内 CodeTop）

给 `m × n` 的网格 `rooms`，格子的值是：`-1` 墙或障碍，`0` 一扇门，`INF = 2^31 - 1 = 2147483647` 一个空房间。原地给每个空房间填上它到**最近的门**的步数（上下左右移动，不能穿墙）；到不了任何门就保持 `INF`。`1 <= m, n <= 250`，值只会是 `-1`、`0`、`2^31 - 1`。例：`[[INF,-1,0,INF],[INF,INF,INF,-1],[INF,-1,INF,-1],[0,-1,INF,INF]]` → `[[3,-1,0,1],[2,2,1,-1],[1,-1,2,-1],[0,-1,3,4]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** **多源 BFS**（multi-source BFS）：把所有门同时放进队列作为第 0 层，向外一层一层扩散；第一次到达某个空房间的那一层，步数就是它到最近门的距离。每格只入队一次，`O(mn)`。

**识别。** 「网格上每个点到**最近**某个源点的最短距离」，边权都是 `1` → BFS；「最近的多个源」→ 不要对每个格子找门，而是**反过来从所有门同时出发**。`m, n` 到 `250`，共 `62500` 格：对每个空房间各跑一次 BFS 是 `O((mn)^2) ≈ 4 · 10^9`，不行。

**推导。** 暴力：对每个空房间 BFS 找最近的门，`O((mn)^2)` → 浪费在于大量重复探索同一片区域 → 反向思考：门是源，距离是从门扩散出去的波前；把所有门作为第 0 层一起入队，BFS 的分层性质保证先到的就是最近 → 用格子本身的值当访问标记：只有仍是 `INF` 的格子才没被访问过，填入 `当前格子 + 1` 后入队。

```python
from collections import deque

INF = 2**31 - 1

def walls_and_gates(rooms: list[list[int]]) -> None:
    m, n = len(rooms), len(rooms[0])
    queue = deque((r, c) for r in range(m) for c in range(n) if rooms[r][c] == 0)  # 所有门同时入队
    while queue:
        r, c = queue.popleft()
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < m and 0 <= nc < n and rooms[nr][nc] == INF:   # 还没被填过的空房间
                rooms[nr][nc] = rooms[r][c] + 1
                queue.append((nr, nc))
```

运行：示例 1 → `[[3,-1,0,1],[2,2,1,-1],[1,-1,2,-1],[0,-1,3,4]]`；`[[-1]]` → `[[-1]]`；`[[INF]]` → `[[INF]]`；`[[0]]` → `[[0]]`；`250 × 250` 的空网格、对角两个门 → 中心格子 `248`，不到 `0.1` 秒。

**复杂度。** 时间 `O(mn)`：每格最多入队、出队一次，每次看 `4` 个邻居；空间 `O(mn)`：最坏队列装满一层波前。

**易错点。**
- 一个门跑一次 BFS，且只填 `== INF` 的格子：第二个门填不进已被第一个门填过的格子。`[[0,INF,INF,INF,0]]` 得 `[0,1,2,3,0]`，正确 `[0,1,2,1,0]`。
- 用 DFS：先到的路径不一定最短，需要每次比较更小才更新，最坏复杂度劣化；还会有 `62500` 层的递归深度。
- 忘记判断 `-1`（墙）：墙值 `-1 != INF`，被 `== INF` 条件天然排除；如果改成「`> 0`」之类的判断就会出错。

**追问。**
- 门和墙会动态变化 / 多次查询：仍用多源 BFS 建好距离表，更新时局部重算。
- 要求返回每个房间最近的是哪扇门：队列里同时携带「源门编号」，扩散时继承。
- 迷宫有不同代价的格子：BFS 失效，改 Dijkstra（`heapq`）。
