## Q
**LC 667 优美的排列 II**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 2 次 · 最近 2026-04（面试记录）

给两个整数 `n` 和 `k`，构造一个包含 `1` 到 `n` 共 `n` 个不同正整数的列表 `answer = [a1, a2, ..., an]`，使得相邻差的绝对值列表 `[|a1 - a2|, |a2 - a3|, ..., |a(n-1) - an|]` 中**恰好有 `k` 个不同的整数**。返回任意一个满足条件的列表。`1 <= k < n <= 10^4`。例：`n = 3`，`k = 1` → `[1,2,3]`（差为 `[1,1]`，只有 `1`）；`n = 3`，`k = 2` → `[1,3,2]`（差为 `[2,1]`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 前 `k + 1` 个数在 `1..k+1` 里「一头一尾」交替取（`1, k+1, 2, k, ...`），相邻差依次为 `k, k-1, ..., 1`，恰好是 `k` 个不同的值；其余的 `k+2..n` 按递增接在后面，只产生已有的差。`O(n)`。

**识别。** 构造题，目标是「差值的种类数恰好为 `k`」，答案不唯一。这类题的套路是：先找出只用 `k` 种差的最小模板，再用「不引入新差」的方式把剩下的数补齐。`k = 1` 时递增排列只有差 `1`；`k = n - 1` 时 `1, n, 2, n-1, ...` 的差正好是 `n-1, n-2, ..., 1`，这是模板的来源。

**推导。** 暴力：枚举 `n!` 个排列，不可行 → 递增排列只有 1 种差；每「跳」一下才可能多出新的差 → 在区间 `[lo, hi]` 里交替取两端：`lo, hi, lo+1, hi-1, ...`，每次相邻差比上一次小 1，从 `hi - lo` 一路降到 `1`；让 `hi - lo = k`，即 `[1, k+1]`，用 `k + 1` 个数恰好产生 `k` 个不同的差 → 剩下的 `k+2..n` 递增接上：接缝处的差是 `k + 2 - 末项`，介于 `1` 和 `k` 之间，后续相邻差都是 `1`，都是已有的差，种类数保持 `k`。

```python
def construct_array(n: int, k: int) -> list[int]:
    ans: list[int] = []
    lo, hi = 1, k + 1                          # 前 k+1 个数在 1..k+1 里"一头一尾"交替取
    while lo <= hi:
        ans.append(lo)
        lo += 1
        if lo <= hi:
            ans.append(hi)
            hi -= 1
    ans.extend(range(k + 2, n + 1))            # 剩下的递增接上，只产生已有的差
    return ans
```

运行：`(3, 1)` → `[1, 2, 3]`；`(3, 2)` → `[1, 3, 2]`；`(5, 3)` → `[1, 4, 2, 3, 5]`；`(10, 4)` → `[1, 5, 2, 4, 3, 6, 7, 8, 9, 10]`；`(2, 1)` → `[1, 2]`；`n = 10000`、`k = 9999` 与 `k = 1` 都满足条件。

**复杂度。** 时间 `O(n)`；除输出外额外空间 `O(1)`。

**易错点。**
- 把交替取数铺到整个 `1..n`（`hi` 从 `n` 开始）再补剩余：`n = 5`，`k = 2` 得到 `[1, 5, 2, 3, 4]`，差集合是 `{1, 3, 4}`，有 `3` 种，不是 `2`。
- 漏掉 `ans.extend(range(k + 2, n + 1))`：`n = 5`，`k = 2` 只返回 `[1, 3, 2]`，长度不足 `n`。
- 交替取数时 `lo <= hi` 的判断：最后一步 `lo` 与 `hi` 相遇，少这个判断会把同一个数加两次。

**追问。**
- 怎么验证一个列表合法：`sorted(a) == list(range(1, n + 1))` 且 `len({abs(x - y) for x, y in pairwise(a)}) == k`（`itertools.pairwise`，Python 3.10+）。
- 另一种构造：先递增放 `1..n-k-1`，再在 `[n-k, n]` 上交替取两端；`(5, 2)` → `[1, 2, 3, 5, 4]`，差为 `{1, 2}`。
- 要求「字典序最小」：这个题允许任意答案，字典序最小需要另外证明，不要在面试里随口承诺。
