## Q
**LC 518 零钱兑换 II**｜Medium · 字节高频

给整数数组 `coins`（不同面额的硬币）和整数 `amount`，求能凑成总金额的**硬币组合数**，凑不出返回 `0`；每种面额的硬币有无限个，结果保证在 32 位有符号整数内。`1 <= coins.length <= 300`，`1 <= coins[i] <= 5000`，`coins` 中的值互不相同，`0 <= amount <= 5000`。例：`amount = 5`、`coins = [1,2,5]` → `4`（`5`、`2+2+1`、`2+1+1+1`、`1*5`）；`amount = 3`、`coins = [2]` → `0`；`amount = 10`、`coins = [10]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 完全背包（unbounded knapsack）里数「组合」：`ways[a]` 是凑出金额 `a` 的组合数，**外层循环枚举硬币、内层正序枚举金额**，`ways[a] += ways[a - coin]`；外层硬币保证每个组合只按固定的硬币顺序被数一次。`O(n · amount)`。

**识别。** 「每种物品无限个」+「凑成总额」+「数方案数」是完全背包的计数形式。关键是**组合还是排列**：题目问的是组合（`1+2` 与 `2+1` 算同一种），所以外层是物品、内层是容量；若问排列（LC 377）则两层互换。`n * amount` 约 `1.5 * 10^6`，一维数组足够。

**推导。** 暴力：递归枚举每种硬币用几个，指数级 → 浪费：同一个（剩余金额，当前硬币下标）被重复求解 → 状态 `dp[i][a]`：只用前 `i` 种硬币凑 `a` 的组合数，`dp[i][a] = dp[i-1][a]`（不用第 `i` 种）`+ dp[i][a - coin]`（至少用一个，剩下的仍可再用第 `i` 种）→ 第 `i` 行只依赖上一行和本行更小的金额，压成一维，正序遍历金额让 `ways[a - coin]` 已经包含当前硬币。

```python
def change(amount: int, coins: list[int]) -> int:
    ways = [0] * (amount + 1)          # ways[a]：凑出金额 a 的组合数
    ways[0] = 1                        # 凑出 0 元只有一种：什么都不拿
    for coin in coins:                 # 外层枚举硬币：每种硬币只「决定一次」用多少，组合不会因顺序重复
        for a in range(coin, amount + 1):
            ways[a] += ways[a - coin]  # 正序：同一种硬币可以重复使用
    return ways[amount]
```

运行：`(5, [1,2,5])` → `4`，`(3, [2])` → `0`，`(10, [10])` → `1`，`(0, [7])` → `1`；`amount = 5000`、`coins = 1..300` 不到 `0.1` 秒。

**复杂度。** 时间 `O(len(coins) · amount)`；空间 `O(amount)`。

**易错点。**
- 循环顺序写反（外层金额、内层硬币）：数的是排列。`(3, [1,2])` 得到 `3`（`1+1+1`、`1+2`、`2+1`），正确是 `2`。
- 内层倒序：每种硬币最多用一次（0/1 背包）。`(5, [1,2,5])` 得到 `1`，正确是 `4`。
- `ways[0]` 必须是 `1`：设成 `0` 则所有答案都是 `0`；`amount = 0` 时答案是 `1`（空组合）。

**追问。**
- 数排列（LC 377）：两层循环互换，外层金额、内层硬币。
- 最少硬币数（LC 322）：同样的完全背包，状态变成 `min`，初值 `inf`。
- 每种硬币只能用一次（LC 494 / 0-1 背包）：内层倒序。

**同模式。** LC 322 零钱兑换、LC 377 组合总和 IV、LC 279 完全平方数、LC 494 目标和。
