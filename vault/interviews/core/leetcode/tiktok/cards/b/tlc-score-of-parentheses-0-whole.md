## Q
**LC 856 括号的分数**｜Medium · LC TikTok 全时段热度 50/100 · CodeTop 国内累计 2 次 · 最近 2025-09-18（国内 CodeTop）

给平衡括号字符串 `S`，按规则计分：`()` 得 `1` 分；`AB` 得 `A + B` 分（`A`、`B` 都是平衡括号字符串）；`(A)` 得 `2 * A` 分。返回 `S` 的分数。`S` 是平衡括号字符串，只含 `(` 和 `)`，`2 <= S.length <= 50`。例：`"()"` → `1`；`"(())"` → `2`；`"()()"` → `2`；`"(()(()))"` → `6`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用栈（stack）保存每一层已累计的分数：遇到 `(` 开新的一层（初值 `0`），遇到 `)` 弹出这一层的分数 `v`，把 `max(2 * v, 1)` 加到外层；栈底就是答案。`O(n)`。

**识别。** 括号嵌套、按层结算，是栈的标准场景。题目给的规则是递归定义（`(A) = 2A`，`AB = A + B`），栈把递归展开成一遍扫描。`n <= 50` 很小，不是复杂度题，考的是把文法翻译成状态更新。

**推导。** 暴力：按文法递归，找到第一个匹配的右括号把 `S` 拆成 `A`、`B`，或剥掉外层，`O(n^2)`。浪费：每次拆分都重新扫描找匹配位置。洞察：扫描一遍，用栈记住“外层目前累计的分数”。一个括号闭合时，内层累计值 `v` 已经确定：`v == 0` 说明里面是空的，也就是 `()`，得 `1`；否则是 `(A)`，得 `2v`；再加到外层，并列的部分自然相加。另一个看法：每个 `()` 的贡献是 `2^(它外面包着的括号层数)`，所以答案是这些贡献之和，可以只用一个深度计数。

```python
def score_of_parentheses(s: str) -> int:
    stack = [0]                             # stack[-1] 是当前这一层已累计的分数
    for ch in s:
        if ch == "(":
            stack.append(0)                 # 开新的一层
        else:
            inner = stack.pop()
            stack[-1] += max(2 * inner, 1)  # "()" 内部为 0，记 1；否则翻倍
    return stack[0]
```

运行：`"()"` → `1`，`"(())"` → `2`，`"()()"` → `2`，`"(()(()))"` → `6`，`25` 个 `(` 加 `25` 个 `)` → `16777216`（`2^24`）。

**复杂度。** 时间 `O(n)`；空间 `O(n)`（深度计数版本是 `O(1)`）。

**易错点。**
- 漏掉空括号的特判，写成 `stack[-1] += 2 * inner`：`"()"` 得到 `0`，正确是 `1`，`"(()(()))"` 得到 `0`，正确是 `6`。
- 把结果赋值给外层而不是累加，写成 `stack[-1] = ...`：`"()()"` 的第二个 `()` 会覆盖第一个，得到 `1`，正确是 `2`。
- 深度计数版本里，每个 `)` 都累加而不是只在紧挨着 `(` 的 `)` 处累加：`"(())"` 得到 `3`，正确是 `2`。

**追问。**
- `O(1)` 空间：只数深度，遇到 `()`（`)` 前一个字符是 `(`）时加 `1 << depth`，其中 `depth` 是弹出这个 `)` 之后剩下的层数。
- 输入可能不平衡：扫描中栈只剩一层时又遇到 `)`，或结束时栈多于一层，返回 `-1` 或抛错。
- 长度到 `10^5`：分数可达 `2^49999`，Python 的 `int` 不会溢出，Java、C++ 要取模或用大整数。
