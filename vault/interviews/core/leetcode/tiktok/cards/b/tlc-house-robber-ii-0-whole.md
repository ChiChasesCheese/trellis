## Q
**LC 213 打家劫舍 II**｜Medium · CodeTop 国内累计 14 次 · 最近 2026-07-21（国内 CodeTop）

你是小偷，沿街的房屋**围成一圈**（第一间和最后一间相邻），每间房 `nums[i]` 是可偷的现金。相邻两间不能在同一晚都偷（会报警）。求不触发警报时能偷到的最高金额。`1 <= nums.length <= 100`，`0 <= nums[i] <= 1000`。例：`[2,3,2]` → `3`（`2` 和最后的 `2` 相邻，只能偷中间的 `3`），`[1,2,3,1]` → `4`（`1 + 3`），`[1,2,3]` → `3`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 环上的「不相邻取数」：首尾相邻，所以任何合法方案都**不会同时包含第一间和最后一间**——把环拆成「去掉最后一间」和「去掉第一间」两条直线，各做一遍直线版打家劫舍（LC 198），取较大者。`O(n)`。

**识别。** 「相邻不能同时选 + 求最大和」是线性 DP 的经典状态（选 / 不选）；「围成一圈」只多出一条首尾约束。`n <= 100` 说明 `O(n)` 或 `O(n^2)` 都行，不是在考优化，而是在考能不能把环化成线。

**推导。** 暴力：枚举每间偷或不偷，`2^n` → 直线版有重叠子问题：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，`O(n)` → 环的麻烦只在首尾：合法方案要么没有第一间，要么没有最后一间（也可能两者都没有）→ 这两类方案分别恰好是 `nums[1:]` 和 `nums[:-1]` 上的直线问题，覆盖全部合法方案 → 答案取两者最大。只有一间房时两条直线都是空的，要单独返回 `nums[0]`。

```python
def rob(nums: list[int]) -> int:
    def rob_line(houses: list[int]) -> int:     # 直线版：dp[i] = max(dp[i-1], dp[i-2] + houses[i])
        skip, take = 0, 0                       # skip：前一间不偷的最优；take：偷到前一间为止的最优
        for money in houses:
            skip, take = take, max(take, skip + money)
        return take

    if len(nums) == 1:                          # 只有一间：首尾是同一间，不能切成两段
        return nums[0]
    return max(rob_line(nums[:-1]), rob_line(nums[1:]))   # 不偷最后一间 / 不偷第一间
```

运行：`[2,3,2]` → `3`，`[1,2,3,1]` → `4`，`[1,2,3]` → `3`，`[5]` → `5`，`[1,2]` → `2`，`[2,1,1,2]` → `3`，`[1000] * 100` → `50000`。

**复杂度。** 时间 `O(n)`（两遍线性扫描，外加两次切片拷贝）；空间 `O(n)`（切片），扫描本身只用两个变量。

**易错点。**
- 忘记首尾相邻，直接当直线做：`[2,3,2]` 得到 `4`（偷两端的 `2`），正确是 `3`。
- 漏掉 `n == 1` 的特判：`[5]` 的两条直线都是空列表，得到 `0`，正确是 `5`。
- `skip, take = take, max(take, skip + money)` 必须一条语句同时赋值；拆成两条会用到已被覆盖的 `take`。

**追问。**
- 返回具体偷了哪几间：直线版保留整张 `dp` 表，从后往前回溯（`dp[k] == dp[k-1]` 说明第 `k` 间没偷），两条直线各回溯一次，取总额大的那条。
- 房屋变成一棵树：LC 337，每个节点两个状态（偷 / 不偷），自底向上合并。
- 能否不拷贝切片：把直线版写成 `rob_range(nums, lo, hi)`，用下标区间代替切片，额外空间 `O(1)`。

**同模式。** LC 198 打家劫舍、LC 337 打家劫舍 III、LC 740 删除并获得点数、LC 2560 打家劫舍 IV。
