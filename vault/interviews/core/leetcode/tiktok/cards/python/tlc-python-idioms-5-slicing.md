## Q
**Python 工具箱｜切片、反转与它的真实代价**

`s[::-1]`、`a[i:j]`、`a[:]`、切片赋值各做什么？切片的复杂度是多少，会不会让 `O(n)` 的算法悄悄变成 `O(n^2)`？

## A
```python
s = "abcdef"
print(s[::-1], s[1:4], s[-2:], s[::2], s[:-1])   # fedcba bcd ef ace abcde
l = [1, 2, 3, 4]
l[1:3] = [9]; print(l)                  # [1, 9, 4]：切片赋值可以改变长度
l2 = l[:]; l2.append(0); print(l, l2)   # [1,9,4] [1,9,4,0]：l[:] 是浅拷贝
print(list(reversed(range(3))))         # [2, 1, 0]：reversed 返回迭代器，不拷贝
```

- 记号 `a[start:stop:step]`，左闭右开，负数下标从尾部数，越界会被截断而不是报错。
- **切片是拷贝**：`a[i:j]` 花 `O(j - i)` 时间和空间。递归里每层传 `a[1:]`，总成本 `O(n^2)`；传下标 `(lo, hi)` 才是 `O(1)`。
- 反转：`a[::-1]` 返回新列表；`a.reverse()` 原地；只遍历用 `reversed(a)`，最省。
- 判断回文：`s == s[::-1]` 简洁且是 `O(n)`；LC 5 的中心扩展不能用它，因为要判断很多子串。
- 原地修改的面试题（LC 189 轮转数组、LC 283 移动零）常被要求 `O(1)` 额外空间，`nums[:] = nums[k:] + nums[:k]` 用了 `O(n)` 额外空间，面试官可能不接受，要用三次反转或双指针。
- **坑**：`nums = nums[::-1]` 只是让局部变量指向新列表，**不会改传入的列表**；要原地改写 `nums[:] = ...`。
