## Q
**回溯（Backtracking）｜变形：括号生成、复原 IP、火柴拼正方形**

这三题分别用什么约束剪枝？回溯函数的参数里放什么状态？

## A
**LC 22 括号生成**：状态 `(已放左括号数, 已放右括号数)`；左括号还有额度就可以放，右括号只能在**已放左括号更多**时放。每条路径天然合法，不用事后检查。

```python
def generate_parenthesis(n: int) -> list[str]:
    res: list[str] = []
    def dfs(s: str, open_: int, close: int) -> None:
        if len(s) == 2 * n:
            res.append(s)
            return
        if open_ < n:
            dfs(s + "(", open_ + 1, close)
        if close < open_:
            dfs(s + ")", open_, close + 1)
    dfs("", 0, 0)
    return res
print(generate_parenthesis(3))   # ['((()))', '(()())', '(())()', '()(())', '()()()']
```

`n = 1..8` 的个数是卡特兰数 `1, 2, 5, 14, 42, 132, 429, 1430`。这里字符串用 `s + "("` 传参，每层新建，不需要撤销。

**LC 93 复原 IP 地址**：分 4 段，每段 1 到 3 位，不能有前导零（单独的 `0` 除外），值 `<= 255`。剪枝：剩余字符数必须在 `[剩余段数, 3 * 剩余段数]` 内。`"25525511135"` → `["255.255.11.135", "255.255.111.35"]`；`"0000"` → `["0.0.0.0"]`。

**LC 473 火柴拼正方形**：把每根火柴放到 4 条边之一。剪枝三招：① 总和不能被 4 整除或最长的火柴超过边长则直接 `False`；② **从大到小排序**，更早发现放不下；③ 当前边长度与前面某条边相同的，只试一次（等价）。
- `[1,1,2,2,2]` → `True`；`[3,3,3,3,4]` → `False`。
- 不加剪枝，`15` 根火柴 `4^15 ≈ 10^9`，超时；加了剪枝后瞬间完成。
