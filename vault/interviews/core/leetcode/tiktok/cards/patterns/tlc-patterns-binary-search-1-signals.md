## Q
**二分查找（Binary Search）｜信号**

什么样的题面该想到二分？「在下标上二分」和「对答案二分」分别由什么信号触发？哪些近似信号其实不能二分？

## A
**在下标上二分（数组本身有某种单调结构）：**
- 数组**有序**，要找值、找边界、找插入位置（LC 34）。
- 题面写明「时间复杂度 `O(log n)`」：LC 33、153、162、540 都有这句话。
- **旋转有序**数组、**峰值**、「只出现一次的数」：虽然整体不有序，但每次能判断答案在哪一半。

**对答案二分（答案在一个范围里，且可行性单调）：**
- 「**最小化最大值**」「**最大化最小值**」：LC 1011（最低运载能力）、LC 875（最小速度）。
- 「能否在 `x` 以内完成」判断函数容易写出来，且 `x` 越大（或越小）越容易 → 单调。
- 答案是整数，范围已知（`1..max`），第 `k` 小 / 大（LC 378 值域二分）、`sqrt`（LC 69）。

**共同点**：存在一个**判定函数** `ok(x)`，结果是 `False...False True...True`，要找第一个 `True`；每次判定后能丢掉一半。

**近似信号：**
- 数组无序，没有单调结构 → 排序后二分，或哈希。
- 判定函数**不单调**（`x` 变大时可行性忽好忽坏）→ 不能二分，可能是 DP。
- 要找**所有**满足条件的位置 → 找边界后线性输出。
- 值域极大但判定函数是 `O(n)`：二分次数是 `log(值域)`，总 `O(n log 值域)`，这是它依然可行的原因。
