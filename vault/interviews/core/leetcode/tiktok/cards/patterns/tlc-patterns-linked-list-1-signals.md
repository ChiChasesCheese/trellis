## Q
**链表技巧（Linked List）｜信号**

什么样的题面该想到哑节点、快慢指针、原地反转？链表题和数组题在思路上最大的区别是什么？

## A
链表题考的是**指针操作的严谨**：每一步都要想清楚「改谁的 `next`、先改哪个」。

**信号与对应技巧：**
- 可能要**删除头节点**或在头部插入、结果的头不确定（合并、删除、分段）→ **哑节点（dummy node）**：`dummy = ListNode(0, head)`，最后返回 `dummy.next`，统一处理头节点。
- 「**中间节点**」「**倒数第 k 个**」「**是否有环**」「**环的入口**」→ **快慢指针**（LC 142）。
- 「**反转**整个链表 / 一段 / 每 k 个一组」→ 原地反转（LC 206、92、25）。
- 「**两个链表相交**」→ 双指针各走完自己再走对方（LC 160）。
- 「**合并**有序链表」「**排序**链表」→ 归并（LC 23、148）。
- 「**重排** `L0, Ln, L1, Ln-1...`」→ 找中点 + 反转后半 + 交替合并（LC 143）。
- 「删除**连续**和为 0 的节点」→ 前缀和 + 哈希（LC 1171）。
- 「逆序存储的大数相加」→ 逐位加法带进位（LC 2）。

**要求 `O(1)` 空间** → 只允许改指针，不能把节点值倒进数组再重建（这是面试官最常追加的限制）。

**近似信号：**
- 需要随机访问第 `i` 个元素 → 先转数组（若允许）。
- 需要在链表里 `O(1)` 删除任意节点并快速定位 → 哈希 + 双向链表（LRU，见设计题）。
