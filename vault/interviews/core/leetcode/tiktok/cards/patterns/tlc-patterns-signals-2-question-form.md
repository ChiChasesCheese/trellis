## Q
**模式识别｜从「问什么」判断大类**

题目的问法（求最值、求方案数、判断存在、列出所有方案、求第 k 个）分别指向哪种算法？

## A
先看**问法**，再看输入的形状：

| 问法 | 首选想法 | 例 |
|---|---|---|
| 所有方案 / 所有组合 / 所有排列 | 回溯（Backtracking） | LC 39、46、78、51 |
| 方案**数** | DP（计数），或数学公式 | LC 62 不同路径、70 爬楼梯 |
| 最大 / 最小**值**，决策有重叠子问题 | DP | LC 322 零钱兑换、72 编辑距离 |
| 最大 / 最小**值**，局部最优能推出全局 | 贪心（排序 + 一次扫描） | LC 55、134、56 |
| **最少步数**，每步代价相同 | BFS | LC 127 单词接龙、994 腐烂的橘子 |
| **最短路**，边有权重 | Dijkstra | LC 787 |
| 是否存在 / 能否在 `x` 内完成，`x` 越大越容易 | 对答案二分 | LC 875、1011 |
| 第 `k` 大 / 前 `k` 个 | 堆、快速选择 | LC 215、347 |
| 能不能走完 / 有没有环 / 依赖顺序 | 拓扑排序、DFS 三色 | LC 207、210 |
| 是不是同一类 / 连通 | 并查集、DFS | LC 200、721 |
| 设计一个支持若干操作的结构 | 组合数据结构 | LC 146、380、295 |

- 「求**最值**」+「**连续**子数组」→ 滑动窗口或前缀和；「求最值」+「**子序列** / 双串」→ DP。
- 「不要求最优、只要找一个可行解」→ 常是 DFS 或构造。
- 同一道题问法一改，算法就换：LC 322 问「最少硬币数」→ DP；若问「能否凑出」→ 同样 DP 或 BFS；若问「有多少种凑法」→ 计数 DP，遍历顺序也要变（见背包一组）。
