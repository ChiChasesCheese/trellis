## Q
**滑动窗口（Sliding Window）｜常见陷阱**

滑动窗口题最容易在哪里出错？

## A
1. **答案更新位置错**：最长窗口要在缩完之后更新，最短窗口要在缩的过程中更新；反了会多算或漏算。
2. **计数为 0 的键没删**：`len(cnt)` 把已出窗的种类也算进去，`"abcdd"`、`k=2` 得 `2` 而不是 `3`。要么 `del`，要么另维护一个「种类数」整数。
3. **`while` 写成 `if`**：左端一次可能要走多步（例如窗口里连续多个重复字符）；LC 424 是特例，用的是不收缩窗口，不是随便换成 `if`。
4. **含负数仍用窗口**：和不单调，`[-2,3,-3]`、`target=2` 返回 `0` 而不是 `1`。
5. **窗口长度写错**：闭区间 `[left, right]` 的长度是 `right - left + 1`，不是 `right - left`。
6. **固定窗口的初始化**：先装 `m-1` 个再进入循环（进一个再判断），或先装满 `m` 个再单独判断一次；两种混用会漏掉第一个窗口。
7. **`k = 0` 或窗口为空**：LC 340 里 `k = 0` 应返回 `0`；先处理边界再进入循环。
8. **`Counter` 比较**：Python 3.10 之前，`Counter(a=1, b=0) == Counter(a=1)` 为 `False`；旧版本要自己删 0 值键。
9. **恰好 `k` 直接窗口**：窗口缩到「恰好」时下一步可能又合法，会漏掉多个起点，改成差。
10. **字符串切片当窗口**：每步 `s[left:right+1]` 是 `O(len)` 拷贝，把 `O(n)` 变成 `O(n^2)`，只存下标。

自检：对 `""`、单个字符、全部相同、全部不同四种输入手走一遍窗口。
