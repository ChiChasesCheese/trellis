## Q
**动态规划：网格、双串与区间｜信号**

什么样的题面该想到二维 DP？网格路径、双字符串、回文这三类的状态分别怎么设？

## A
**二维 DP 的触发信号：**
- **网格**，只能向右 / 向下走，问路径数或最小路径和：LC 62、64。`dp[r][c]` 只依赖上方和左方。
- **两个字符串 / 序列**，问最长公共子序列、编辑距离、能否匹配：LC 1143、72、10。`dp[i][j]` 表示 `a` 的前 `i` 个与 `b` 的前 `j` 个。
- **一个字符串**，问回文、括号：`dp[i][j]` 表示子串 `s[i..j]`（区间 DP），或 `dp[i]` 表示以第 `i` 个结尾（LC 5、32）。
- **正方形 / 矩形**：以 `(r, c)` 为右下角的最大正方形边长（LC 221）。
- 数据范围：`m, n` 到几百到一千（LC 72 的 `<= 500`，LC 1143 的 `<= 1000`），`O(mn)` 即可，约 `10^6` 个状态。

**四步法同样适用**：状态 → 转移 → 初值（第 0 行 / 第 0 列）→ 顺序（从小到大）。

**空间压缩**：`dp[i][j]` 只依赖上一行和本行左边时，用一维数组（或两个数组）滚动，空间 `O(n)`。

**近似信号：**
- 网格里有**障碍物 / 四个方向都能走** ⇒ 不是单向 DP，用 BFS / DFS（LC 200、1293）。
- 要输出**具体方案**（路径本身、编辑操作序列）⇒ 保留完整二维表，再回溯。
- 问子串且 `n` 很大 ⇒ 中心扩展、Manacher，而不是 `O(n^2)` 空间的 DP。
- 两个字符串的**子串**（连续）⇒ 状态定义为"以 `i`、`j` 结尾"，不匹配就清零。
