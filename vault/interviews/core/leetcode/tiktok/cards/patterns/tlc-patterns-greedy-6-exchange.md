## Q
**贪心（Greedy）｜交换论证：为什么选结束最早的区间，贪心在哪里会失效**

最多选多少个互不重叠的区间？按开始时间还是结束时间排序？零钱兑换为什么不能贪心？

## A
**区间调度**：按**结束时间**升序，依次选能接上的（开始时间 `>=` 上一个的结束时间）。

```python
def max_non_overlapping(intervals: list[list[int]]) -> int:
    count, end = 0, -float("inf")
    for s, e in sorted(intervals, key=lambda x: x[1]):   # 按结束时间排序
        if s >= end:
            count += 1
            end = e
    return count
print(max_non_overlapping([[1, 3], [2, 4], [3, 5]]), max_non_overlapping([[1, 10], [2, 3], [3, 4]]))   # 2 2
```

**交换论证**：设最优解的第一个区间不是结束最早的那个 `g`。把它换成 `g`：`g` 结束得最早，不会与最优解的第二个区间冲突，选出的个数不变。对剩下的区间重复这个论证，就证明了贪心最优。

**按开始时间排序的反例**：`[[1,10],[2,3],[3,4]]`。
- 按开始时间排序，先选 `[1,10]`，把后面两个都挡住，得到 `1`。
- 按结束时间排序，选 `[2,3]` 与 `[3,4]`，得到 `2`。

**贪心失效的典型**：零钱兑换 `coins = [1, 3, 4]`，金额 `6`。
- 贪心每次取最大面额：`4 + 1 + 1` 共 `3` 枚。
- 最优是 `3 + 3` 共 `2` 枚，要用 DP。
- 原因：面额组合不满足"大面额优先"的性质（只有特殊面额体系如 `1, 5, 10, 25` 才成立）。

- 经验：能证明交换论证 ⇒ 贪心；找不到反例但也证明不了 ⇒ 写 DP 兜底。
- 同类题：最少箭射爆气球（按右端点排序）、会议室（按开始时间 + 堆）。
