## Q
**拓扑排序（Topological Sort）｜信号**

什么样的题面该想到拓扑排序？Kahn 算法和 DFS 三色法分别适合什么场景？

## A
**触发信号：**
- 事物之间有**先后依赖**：先修课程、任务前置、编译顺序（LC 207、210、1462）。
- 问「能否全部完成」= **有向图是否有环**（LC 207）。
- 要「输出一个合法顺序」（LC 210）。
- 从**元素之间的偏序**还原全序：火星词典（LC 269），相邻单词的第一个不同字母给出一条边。
- 「最长递增路径」这类**在 DAG 上做 DP**，按拓扑顺序（或记忆化）计算（LC 329）。
- 「分层 / 最少几轮」：每一轮取出所有入度为 0 的点（并行学期数）。

**两种实现：**
- **Kahn 算法**（BFS，入度表）：反复取出入度为 0 的点；`O(V + E)`；环的判定很自然：取出的点数 `< V`。
- **DFS 三色法**（0 未访问 / 1 在当前路径 / 2 已完成）：遇到状态 1 的点即有环；完成时入列表，反转得到拓扑序。

**怎么选**：要分层、要字典序最小（改用堆）、要避免递归 → Kahn；写起来更短或要在 DFS 里顺便做计算 → DFS。

**近似信号：**
- 无向图的环 → 并查集或 DFS 记父节点，不是拓扑排序。
- 图本身有环但问最短路 → Dijkstra / BFS。
- 只需要判断两点是否连通 → BFS / 并查集。
- 数据范围：`numCourses <= 2000`、边 `<= 5000` 这类，`O(V + E)` 绰绰有余。
