## Q
**字符串处理与表达式解析｜常见陷阱**

表达式解析与字符串栈题最容易在哪里出错？

## A
1. **忽略优先级，从左到右算**：`"3+2*2"` 得 `10` 而不是 `7`。
2. **除法用了 `//`**：`"1-7/2"` 得 `-3`，向零截断应得 `-2`。
3. **最后一项没处理**：循环里只在遇到运算符时结算；要在末尾（`i == len(s) - 1`）再结算一次，注意末尾可能是空格。
4. **空格处理**：空格不更新 `op`、不清空 `num`；先 `replace(" ", "")` 最省事。
5. **多位数字**：`num = num * 10 + int(ch)`；解码字符串的次数 `k` 同理。
6. **数字清零**：结算后 `num = 0`；遇到 `[` 后 `k = 0`。
7. **括号前的符号**：`-(2+3)`、`2-(5-6)`：进入括号要保存括号前的符号，弹出时乘上。
8. **递归解析的下标共享**：用 `nonlocal i`（或类成员）让递归调用共享同一个读指针。
9. **版本号当字符串比较**：`"1.2" < "1.10"` 为 `False`；要拆开转整数。
10. **路径里的 `...`**：不是特殊目录，是合法名字；只有恰好 `.` 和 `..` 特殊。
11. **用 `eval`**：题目明确禁止；面试里也不会被接受。
12. **字符串反复切片 / 拼接**：`s = s[1:]` 是 `O(n)`，循环里用下标；结果用列表 `join`。
