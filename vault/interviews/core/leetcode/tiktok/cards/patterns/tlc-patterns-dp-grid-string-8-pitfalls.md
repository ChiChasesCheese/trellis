## Q
**动态规划：网格、双串与区间｜常见陷阱**

二维 DP 题最容易在哪里出错？

## A
1. **下标偏移**：`dp` 开 `(m + 1) x (n + 1)`，`dp[i][j]` 对应 `s[i-1]`、`t[j-1]`；比较字符时写成 `s[i]` 会错位。
2. **第 0 行 / 第 0 列没初始化**：编辑距离的 `dp[0][j] = j`、`dp[i][0] = i`，漏掉则 `("horse", "ros")` 得 `2`，`("", "a")` 得 `0`；正则的 `dp[0][j]` 要处理 `a*b*`。
3. **编辑距离漏了替换**：`"horse"→"ros"` 得 `4` 而不是 `3`。
4. **填表顺序反了**：`dp[i][j]` 依赖左、上、左上，`i`、`j` 都要从小到大；把编辑距离的内层 `j` 写成从大到小，读到的 `dp[i][j-1]` 还是没填的 `0`，`("horse", "ros")` 得 `1`，正确是 `3`。
5. **回文只枚举奇数中心**：`"cbbd"` 得 `"c"`，要同时枚举 `(i, i)` 与 `(i, i+1)`。
6. **正则 `*` 当通配符**：`*` 绑定前一个字符，`("ab", "a*")` 为 `False`。
7. **LCS 与最长公共子串混淆**：子串要求连续，不匹配时 `dp` 清零，答案取全表最大值；子序列不匹配取 `max`。
8. **答案取错位置**：LC 32、子串类取 `max(dp)`，不是 `dp[-1]`；LCS、编辑距离取 `dp[m][n]`。
9. **网格路径数的整数大小**：`unique_paths(100, 100)` 很大，Python 整数无溢出；其他语言要注意。
10. **用 `[[0] * n] * m`**：行共享同一个列表（见 Python 陷阱一组）；二维表要用推导式。
11. **要还原方案就保留完整二维表**：输出路径 / 操作序列要从 `dp[m][n]` 往回走；压缩空间见 Python 工具箱「DP 降维」。
12. **记忆化递归深度**：二维状态 `m + n` 层，`<= 2000` 可行；`1000 x 1000` 的完整递推最稳。
