## Q
**拓扑排序（Topological Sort）｜常见陷阱**

拓扑排序题最容易在哪里出错？

## A
1. **边方向写反**：LC 207 / 210 里 `[a, b]` 是"先学 `b`"，边是 `b -> a`；LC 1462 里 `[a, b]` 是"`a` 是 `b` 的先修课"，边是 `a -> b`。判环对方向不敏感，顺序对方向敏感。
2. **用两态 `visited` 判有向环**：必须有"在当前路径上"这一态，否则菱形依赖被误判为环。
3. **漏判输出长度**：Kahn 结束后必须比较 `len(order)` 与 `V`；不比较就把部分序当成完整答案。
4. **孤立点**：没有任何边的课程 / 字母也要在结果里（入度为 0 的点入队时要遍历 `range(V)`，不是只遍历出现在边里的点）。
5. **火星词典的前缀反序**：`["abc", "ab"]` 非法，返回 `""`。
6. **重复边**：入度累加与邻接表去重必须一致（用 `set` 存邻居，只在新增时 `indeg += 1`）。
7. **递归 DFS 爆栈**：链长 `> 1000` 时 `RecursionError`；用迭代 DFS 或 Kahn。
8. **多个合法答案**：评测通常接受任意合法序；自己验证时不要和样例逐字比较，要验证每条边 `pos[u] < pos[v]`。
9. **字典序最小**：换成最小堆；普通队列不保证。
10. **矩阵题递归深度**：LC 329 在 `200 x 200` 蛇形数据上递归会爆栈，用分层剥洋葱。
11. **把无向图当 DAG**：无向边没有"先后"，别套拓扑排序；无向环用并查集。
12. **复杂度**：Kahn 是 `O(V + E)`，不是 `O(V^2)`；邻接矩阵建图才会 `O(V^2)`。
