## Q
**图与网格的 BFS / DFS（Graph Traversal）｜信号**

什么样的题面该想到图遍历？DFS 与 BFS 怎么选？多源 BFS、隐式图各由什么信号触发？

## A
**触发信号：**
- 输入是**网格**（`0/1`、`'1'/'0'`、高度矩阵）并且问「连通块 / 岛屿 / 面积 / 能否到达」→ DFS 或 BFS 染色（LC 200、695、417）。
- 输入是**边列表 / 邻接关系**（先修课、对立关系、道路）→ 先建邻接表，再遍历（LC 886、1466）。
- 问**最少步数 / 最短转换次数**，每步代价相同 → **BFS**，第一次到达就是最短（LC 127、1293、815）。
- 题面没有"图"字，但**状态之间有转移**：单词改一个字母（LC 127）、乘公交换线（LC 815）→ **隐式图**，BFS 里动态生成邻居。
- 「**多个起点同时扩散**」：腐烂的橘子（LC 994）、墙与门（LC 286）→ **多源 BFS**，把所有起点一起入队。
- 「从边界反向找」：太平洋大西洋水流（LC 417）→ 从海洋出发反向 BFS。

**DFS 还是 BFS：**
- 连通块计数、面积、能不能到达 → 都可以，DFS 写起来短；但递归深度可达 `m * n`，Python 要用显式栈。
- **最短路 / 最少步数 / 按层扩散** → 只能 BFS。
- 需要记录路径或回溯 → DFS。

**近似信号：**
- 边有权重且不相等 → Dijkstra（最短路一组）。
- 有向图判环、依赖顺序 → 拓扑排序。
- 动态连边、问是否连通 → 并查集。
- 只要连通块个数且数据可以离线 → 并查集与 DFS 都行。
