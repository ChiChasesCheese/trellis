## Q
**图与网格的 BFS / DFS｜常见陷阱**

图遍历题最容易在哪里出错？

## A
1. **递归 DFS 爆栈**：`300 x 300` 的全陆地网格，递归深度可达近 `9 * 10^4`，超过默认 `1000` 的上限；用显式栈或 BFS。
2. **`seen` 标记太晚**：出队才标记会重复入队（`30 x 30` 空网格入队 `1741` 次而不是 `900` 次），大图超时。
3. **边界判断顺序**：先判断 `0 <= a < m and 0 <= b < n`，再访问 `grid[a][b]`，否则负下标会悄悄取到对面的格子（Python 的负数下标不报错）。
4. **字符还是整数**：LC 200 的格子是 `'1'`（字符串），LC 695 是 `1`（整数）；比较写错，整个遍历为空。
5. **多源 BFS 没有一起入队**：逐个起点各跑一次 BFS，会得到错误距离或超时。
6. **按层统计忘记固定 `len(q)`**：`for _ in range(len(q))` 必须在内层入队之前求值。
7. **不连通图只从一个点出发**：LC 886 的染色要对每个未染色节点各开始一次。
8. **无向边只建了一个方向**：建邻接表时 `g[a].append(b); g[b].append(a)`；LC 1466 的有向边要附带方向标记。
9. **同一座岛重复累加**：LC 827 需要对相邻岛屿编号去重，否则 `[[1,1,0],[1,0,0],[0,0,0]]` 得到 `7`。
10. **修改了输入**：把网格当作 `seen` 复用时，调用者再使用原网格会出错；需要时先拷贝。
11. **返回步数差一**：BFS 的第一层是否算一步由题意决定（LC 127 数的是**单词个数**，比转换次数多 1）。
12. **无解的返回值**：LC 994 无法腐烂完返回 `-1`，LC 934 保证有解，LC 127 无路径返回 `0`。
