## Q
**动态规划：线性与状态机｜正确性：为什么打家劫舍不能贪心，最大子数组和的初值为什么不能是 0**

打家劫舍里"每次偷当前最大的"错在哪里？Kadane 里 `best` 初值取 `0` 会错在哪里？

## A
**打家劫舍不能贪心**：局部最优（偷最大的房子）会占用相邻的两个房子，可能挡住两个合起来更大的房子。
- 输入 `[5, 7, 4]`：贪心偷 `7`，两边的 `5`、`4` 都不能偷，总计 `7`。
- 最优是偷两端 `5 + 4 = 9`。
- DP 的决策是"偷当前就必须放弃前一个"，比较的是两条完整路线 `skip + x` 与 `max(take, skip)`，不会被眼前最大值误导。

**不变量**：处理完第 `i` 个元素后，`take` 是"一定偷第 `i` 个"的最大收益，`skip` 是"一定不偷第 `i` 个"的最大收益；两者覆盖所有合法方案，所以最后取较大者。

**Kadane 初值**：题目要求子数组**至少含一个元素**。
- 全负数组 `[-3, -1, -2]`：正确答案 `-1`（只取 `-1`）。
- 把 `best = cur = 0` 当初值：空子数组的和 `0` 比任何负数都大，得到 `0`，错误。
- 正确初值：`best = cur = nums[0]`，从第二个元素开始循环。

**转移 `cur = max(x, cur + x)` 的含义**：如果前面累计的和 `cur` 是负的，带着它只会拖累后面，不如从 `x` 重新开始。这是 Kadane 的核心，也说明为什么以 `x` 结尾的最大和只依赖前一个位置。

- 判断一个题能不能贪心：问"当前的选择会不会改变后面可选的集合"，会改变就要 DP。
