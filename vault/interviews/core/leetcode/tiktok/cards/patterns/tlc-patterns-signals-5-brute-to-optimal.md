## Q
**模式识别｜从暴力解到最优解的五个提问**

写出暴力解之后，怎样系统地找到优化方向，而不是靠灵感？

## A
先写暴力并算出复杂度，再问：**暴力里什么在重复？**

1. **重复算同一个子问题** → 记忆化 / DP。信号：递归树里相同参数反复出现（LC 70、322、139）。
2. **重复在一个集合里找一个值** → 哈希（`O(1)` 查找）或有序 + 二分。信号：内层循环是「找 `target - x`」（LC 1）。
3. **重复求一段区间的聚合** → 前缀和 / 差分；窗口里最大值 → 单调队列。信号：反复求 `sum(a[i:j])`（LC 560）。
4. **重复检查已经不可能的分支** → 剪枝、单调性、双指针。信号：枚举的某些选择明显不可能更优（LC 11 盛水容器，先动短板）。
5. **顺序其实无关** → 先排序，换成一次扫描 / 贪心。信号：区间、会议室、任务调度（LC 56、253）。

示例：LC 3 无重复字符的最长子串：
- 暴力：所有子串 `O(n^2)` × 判重 `O(n)` = `O(n^3)`；
- 固定起点往右扩，遇到重复停下：`O(n^2)`（问 1：浪费在每次换起点都重头扩）；
- 观察到起点只会往右走：滑动窗口，`O(n)`（问 4：单调性）；
- 用字典记最近出现位置，起点直接跳转（问 2）。

- 每一步都**口头说出**复杂度和瓶颈，面试官评价的是思考路径，而不仅是最终代码。
- 提示：同一个瓶颈往往有两种解法（如 LC 215：堆 `O(n log k)` 与快速选择 `O(n)`），先说一种能过的，再主动提另一种。
