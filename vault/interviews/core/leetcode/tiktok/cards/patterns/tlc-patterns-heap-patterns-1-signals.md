## Q
**堆（Heap）｜信号**

什么样的题面该想到堆？Top-K、K 路归并、双堆、按时间调度分别由什么信号触发？哪些近似信号不需要堆？

## A
**堆的核心能力**：在动态变化的集合里，`O(log n)` 取出并删除最小（或最大）元素。

**信号：**
- 「**前 `k` 大 / 第 `k` 大 / 前 `k` 个高频**」：大小为 `k` 的堆，`O(n log k)`（LC 215、347）。
- 「**合并 `k` 个有序**链表 / 数组」：堆里每路放一个当前头（LC 23）。
- 「**数据流的中位数**」：一个最大堆装较小的一半，一个最小堆装较大的一半（LC 295）。
- 「**事件按时间顺序处理**」：会议室、任务调度、最早可用的资源：按开始时间排序，堆装结束时间（LC 253、2402）。
- 「**每次取当前最大 / 最小的可用项，再放回**」的贪心：重构字符串 LC 767、最长快乐字符串 LC 1405。
- Dijkstra 的边界选择（见最短路一组）。

**近似信号：**
- 只要一次最小 / 最大 → `min` / `max`。
- 数据一次给全、只要第 `k` 个、不要顺序 → 快速选择，平均 `O(n)`。
- 要的是频次且值域 `<= n` → 桶排序 `O(n)`。
- 要随时删除任意元素 / 取第 `k` 个 → 有序结构，堆做不了（可用懒删除）。
- `k` 接近 `n` → 直接排序。
- `heapq` 只有**最小堆**：最大堆存负数。
