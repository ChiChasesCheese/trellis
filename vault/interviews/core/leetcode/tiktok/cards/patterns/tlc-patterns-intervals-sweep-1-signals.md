## Q
**区间与扫描线（Intervals / Sweep Line）｜信号**

什么样的题面该想到「排序后扫描」「扫描线」或「差分」？哪些近似信号需要别的方法？

## A
**信号：**
- 输入是一组 `[start, end]` 区间，问**合并**、**是否重叠**、**最多同时有几个**、**需要几个资源**：LC 56、252、253。
- 「某个点被几个区间覆盖」「最亮的位置」：把每个区间拆成 `+1`（开始）和 `-1`（结束）两个事件，排序后累加（LC 2021）。
- 「按时间顺序处理事件，每个事件需要最早空闲的资源」：排序 + 堆（LC 253、2402）。
- 「用最少的区间覆盖 / 选最多互不重叠的区间」：按右端点（结束时间）排序的贪心。
- 「跳跃能到达的范围」：可达范围是一个区间，向右延伸（LC 55、45）。

**核心思路**：**先排序，让相关的区间相邻**；排序之后，重叠只可能发生在相邻（或与当前最右端）之间，一次扫描 `O(n)`，总共 `O(n log n)`。

**近似信号：**
- 区间非常多、坐标范围小（`<= 10^6`）→ 差分数组，不必排序。
- 要**动态**插入、删除区间并查询 → 平衡树 / 线段树，不是一次排序。
- 区间是二维的（矩形）→ 扫描线 + 线段树（复杂得多）。
- 只问两个区间是否相交 → 比较 `max(a.start, b.start) <= min(a.end, b.end)`，不需要排序。
- **端点相接**算不算重叠，是每道题的第一个澄清问题。
