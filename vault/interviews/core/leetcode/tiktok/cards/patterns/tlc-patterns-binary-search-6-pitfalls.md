## Q
**二分查找（Binary Search）｜常见陷阱**

二分题最容易在哪里出错？

## A
1. **`hi` 初值**：下界查找的 `hi` 应是 `len(a)`，而不是 `len(a) - 1`；否则「全部小于目标」时返回错误位置。
2. **`lo <= hi` 与 `lo < hi` 混用**：闭区间模板（`lo <= hi`，更新 `mid ± 1`）和半开模板（`lo < hi`，`hi = mid`）各自配套；混着写会死循环或漏解。
3. **死循环**：`lo = mid` 且 `mid = (lo + hi) // 2` 在 `hi = lo + 1` 时 `mid == lo`，区间不缩小。要么 `lo = mid + 1`，要么取上中位数 `(lo + hi + 1) // 2`。
4. **旋转数组里 `<` 与 `<=`**：`search([3, 1], 1)` 在写成 `<` 时返回 `-1`。
5. **判定函数不单调**：丢掉的一半里藏着答案，没有任何报错。
6. **求最大可行值忘了减 1**：LC 1802 要找「最大的可行 `v`」，做法是找第一个**不可行**的 `v` 再减 1；忘记减 1，`(4, 2, 6)` 得到 `3`，正确是 `2`。
7. **整数向上取整**：`-(-p // k)`，不要用 `math.ceil(p / k)`（浮点）。
8. **重复元素**：LC 81 / 154（有重复的旋转数组）里 `nums[mid] == nums[hi]` 时不能判断在哪一半，只能 `hi -= 1`，最坏退化成 `O(n)`。
9. **返回的是位置还是值**：LC 69 返回 `first_true - 1`，LC 1011 直接返回 `first_true`；写完后用最小输入手算。
10. **库函数能替代时先用**：`bisect_left(range(lo, hi), True, key=ok)` 一行实现对答案二分（Python 3.10+），省去手写边界；面试被要求手写时再写。
