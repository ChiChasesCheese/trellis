## Q
**前缀和与差分（Prefix Sum）｜信号**

什么样的题面该想到前缀和，什么样该想到差分？哪些近似信号其实要滑动窗口或别的方法？

## A
**前缀和（Prefix Sum）的信号：**
- 反复求**区间 `[l, r]` 的和**（或异或、乘积、计数），暴力每次 `O(n)` → 预处理 `pre`，每次 `O(1)`。
- 问**连续子数组**的和等于 / 被 `k` 整除的**个数**或存在性 → `pre[j] - pre[i] = k`，在哈希表里找 `pre[i] = pre[j] - k`。
- **数组含负数**，不能用滑动窗口（右端增大和不一定增大）。
- 「**恰好**有 `k` 个奇数 / 1」→ 把元素映射成 0/1，再按子数组和 = `k` 处理（LC 1248）。
- 二维矩阵的子矩阵和 → 二维前缀和。

**差分（Difference Array）的信号：**
- 对很多个区间**批量加减**同一个值，最后一次性读出每个位置 → 差分，更新 `O(1)`，还原 `O(n)`。
- 「某点被几个区间覆盖」「最亮的位置」「航班预订」→ 差分 / 扫描线。

**近似信号：**
- 全是**正数**，求和**至少** `target` 的最短子数组 → 滑动窗口 `O(n)`（LC 209），前缀和 + 二分是另一种 `O(n log n)`。
- 只问**最大**子数组和（不计数）→ Kadane / DP，不需要哈希。
- 需要区间**最大值**而非和 → 稀疏表、单调队列，前缀和做不了。
- 要**修改**元素再查询 → 树状数组 / 线段树，前缀和是静态的。
