## Q
**模式识别｜从数据范围倒推复杂度**

题面给出输入规模 `n`（数组长度、字符串长度、节点数）的上限，怎样据此判断该写 `O(n)`、`O(n log n)`、`O(n^2)` 还是指数级算法？Python 要比 C++ 保守多少？

## A
先估算操作次数：Python 一秒约做 `10^7` 条简单语句，C++ 约 `10^8` 以上，所以**把 C++ 的参考线降一个数量级**。

| `n` 上限 | 可接受复杂度 | 常见算法 |
|---|---|---|
| `<= 15` 到 `20` | `O(2^n)`、`O(n!)`（`n <= 10`） | 回溯、位掩码 DP、子集枚举 |
| `<= 100` | `O(n^3)` | Floyd、区间 DP |
| `<= 500` 到 `5000` | `O(n^2)` | 二维 DP、双串 DP、稠密图 |
| `<= 10^5` | `O(n log n)` 或 `O(n)` | 排序、堆、二分、哈希、单调栈、滑动窗口 |
| `<= 10^6` 以上 | `O(n)` | 一次扫描、哈希、前缀和 |
| 到 `10^9`、`2^31` | `O(log n)` 或 `O(1)` | 二分、数学、位运算 |

- 真实例子：LC 473 火柴拼正方形的 `matchsticks.length <= 15` → 指数级回溯；LC 51 N 皇后的 `n <= 9` → 回溯；LC 72 编辑距离 `<= 500` → `O(mn)` 的二维 DP；LC 300 最长递增子序列 `<= 2500` → `O(n^2)` 可过，`O(n log n)` 更稳；LC 347 前 K 个高频元素 `<= 10^5` → 不能 `O(n^2)`。
- 规模暗示**不是**范围上限：只看一维 `n`。`m x n` 网格要看 `m * n`，图要看点数 `V` 与边数 `E`（LC 207 里 `numCourses <= 2000`、`prerequisites <= 5000`，`O(V + E)` 的拓扑排序绰绰有余）。
- 值域小（`nums[i]` 绝对值不超过 `10^4`）常指向计数数组、桶排序、对值域做 DP；值域大指向哈希或排序。
- 如果暴力解已经落在允许的复杂度里，就先写暴力，不要过度优化。
