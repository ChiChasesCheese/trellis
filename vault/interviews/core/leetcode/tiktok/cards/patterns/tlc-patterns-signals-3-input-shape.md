## Q
**模式识别｜从「输入长什么样」选结构**

给的是有序数组、字符串、网格、树、依赖关系、区间、括号序列、数据流，分别该联想到什么？

## A
| 输入 / 关键词 | 联想 |
|---|---|
| **有序**数组 / 链表 | 双指针（相向）、二分 |
| 旋转有序、峰值、「`O(log n)`」 | 二分，判断哪一半有序 |
| 数组 + **连续子数组**（和、长度） | 前缀和 + 哈希；全正数时滑动窗口 |
| 字符串 + **最长 / 最短子串**，约束有单调性 | 滑动窗口 |
| 字符串 + 括号 / 嵌套 | 栈 |
| 「下一个更大 / 更小」、左右第一个满足条件 | 单调栈 |
| **区间** `[start, end]` | 按端点排序 + 扫描 / 贪心 / 堆（会议室） |
| **网格**（`0/1`、`'1'`/`'0'`） | DFS / BFS 连通块；最短步数用 BFS；路径计数 / 最小和用 DP |
| **树** | DFS（返回子树信息）；按层用 BFS；BST 用中序 |
| **依赖 / 先修 / 先后顺序** | 拓扑排序 |
| 「是否同一组」「合并」 | 并查集 |
| 「前缀」「单词表」 | 字典树 |
| 数据流 / 在线更新 | 堆、有序结构、`deque` |
| 多个元素需要 `O(1)` 查找 / 去重 / 计数 | 哈希 |
| 「设计一个类」 | 哈希 + 链表 / 堆 / 数组 的组合 |

- 一个信号通常不够，**两三个信号叠加**才能锁定：「子数组 + 和 + 含负数」→ 前缀和 + 哈希（LC 560），去掉「含负数」才是滑动窗口。
- 题目没有直接出现图，但「状态之间有转移」「每步走一格 / 改一个字母」就是隐式图 → BFS（LC 127 每次改一个字母，LC 1293 带状态的网格）。
