## Q
**动态规划：背包与计数｜常见陷阱**

背包题最容易在哪里出错？

## A
1. **容量循环方向写反**：0-1 背包倒序、完全背包正序。`[1, 5]` 的分割等和子集，正序得 `True`，正确 `False`。
2. **组合与排列的循环顺序**：物品在外是组合，容量在外是排列；`amount = 3`、`[1, 2]` 分别得 `2` 和 `3`。
3. **和为奇数没提前返回**：分割等和子集先判断 `total % 2`。
4. **初值**：`dp[0]` 是空集；求最少硬币的其他位置是哨兵（"不可达"），不是 `0`。
5. **哨兵溢出**：`inf + 1` 在整数类型里没问题；用 `float('inf')` 时返回前要转整数或判断。
6. **没有凑出时的返回值**：LC 322 返回 `-1`，不是 `dp[amount]` 本身。
7. **二维表的下标**：`dp[i][s]` 对应前 `i` 个物品；物品数组下标是 `i - 1`。
8. **目标和的转化**：先判 `abs(target) > total` 与奇偶，再除以 2；漏判会让 `want` 为负或小数。
9. **含 `0` 的数组**：每个 `0` 使方案数翻倍（`+0` 与 `-0`）；倒序循环写成 `range(want, x - 1, -1)`，`x = 0` 时区间包含 `s = 0`，正好完成翻倍，不要把下界写成 `x`。
10. **容量太大**：`10^9` 级别的容量不能开数组；考虑贪心 / 数学 / 二分。
11. **鸡蛋掉落的方向**：把"最少步数"反过来求"最多楼层"，再找最小的 `m`；直接 `O(k n^2)` 会超时。
12. **数位计数的前缀贴合**：某一位数字不在集合里就要立即返回，不能继续累计。
