## Q
**动态规划：线性与状态机｜常见陷阱**

线性 DP 题最容易在哪里出错？

## A
1. **状态定义含糊**：`dp[i]` 是"前 `i` 个"还是"以第 `i` 个结尾"，决定答案是 `dp[n]` 还是 `max(dp)`。写代码前先用一句话定义。
2. **初值错**：Kadane 全负数组 `[-3,-1,-2]`，`best = 0` 得 `0`，正确 `-1`。
3. **遍历顺序错**：`dp[i]` 依赖的状态必须先算；滚动变量要用元组同时更新（`take, skip = skip + x, max(take, skip)`）。
4. **贪心代替 DP**：打家劫舍 `[5,7,4]` 贪心得 `7`，正确 `9`。
5. **下标偏移**：用 `dp` 长度 `n + 1` 时，`dp[i]` 对应 `arr[i-1]`；`arr[i - j]` 是长度 `j` 的最后一段的第一个元素。
6. **取模遗漏**：LC 1997 每一步都要 `% mod`；Python 整数不溢出，但数字会越来越大拖慢。
7. **边界 `n = 1` 或 `n = 0`**：滚动变量的初值要覆盖这些情况（`rob([5])` → `5`）。
8. **滚动数组读到了新值**：二维压缩成一维时，遍历方向决定读到旧值还是新值；一维线性 DP 里用元组赋值最稳妥。
9. **答案取在哪里**：子序列类 DP 取 `max(dp)`，不是 `dp[-1]`。
10. **状态里漏了关键信息**：青蛙过河只用位置做状态会丢掉"上一步步长"，结果错。
11. **`O(n^2)` 超时**：`n <= 2500`（LIS）可过，`n = 10^5` 时必须换二分 / 单调结构。
12. **递归记忆化深度**：线性 DP 写成递归在 `n >= 1000` 时 `RecursionError`；改自底向上。
