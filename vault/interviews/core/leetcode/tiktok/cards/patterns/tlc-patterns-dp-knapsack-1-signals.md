## Q
**动态规划：背包与计数（Knapsack）｜信号**

什么样的题面是背包问题？0-1 背包、完全背包、计数型分别怎么识别？

## A
背包（Knapsack）模型：有一批"物品"，每个物品有"重量"（占用某种容量），要在**容量限制**下达成某个目标。

**触发信号：**
- 「**能否凑出**某个和」「分成两份和相等」：每个数选或不选，每个数**最多用一次** ⇒ **0-1 背包**（LC 416 分割等和子集）。
- 「用**最少**硬币凑出金额」「物品可以**无限次**使用」 ⇒ **完全背包**（LC 322 零钱兑换）。
- 「**有多少种**方式凑出」 ⇒ **计数**背包；要区分"组合"（顺序无关）和"排列"（顺序有关）。
- 「给每个数加 `+` 或 `-` 使结果为 `target`」 ⇒ 转成"选一部分使其和为某个值"（LC 494）。
- 数据范围：数的个数 `n <= 200`、和 `<= 2 * 10^4`（LC 416），状态数 `n × 容量` 约 `4 * 10^6`。

**状态**：`dp[i][s]` = 只用前 `i` 个物品、容量（和）恰好为（或至多为）`s` 时的最优值 / 方案数 / 能否。

**三个要素**：
1. 行是物品、列是容量：物品遍历在外层，容量遍历在内层（求组合与 0-1）。
2. 转移读**哪一行**决定每个物品能用一次还是多次：读上一行 `dp[i-1]` 只能用一次，读本行 `dp[i]` 可以重复用。
3. 初值：基础行 `dp[0][0]` 是空集的结果（`True` / `0` / `1`），其余列按"不可达"处理。

**近似信号：**
- 数据范围 `n <= 15` 且要列出方案 ⇒ 回溯。
- 容量是 `10^9` 级别 ⇒ 背包表开不下，换思路（贪心 / 数学 / 二分）。
- 物品之间有依赖或次序 ⇒ 不是纯背包。
