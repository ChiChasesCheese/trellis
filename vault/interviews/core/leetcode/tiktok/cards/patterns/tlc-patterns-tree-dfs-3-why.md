## Q
**二叉树 DFS（Tree DFS）｜正确性：为什么只返回单侧，为什么要对负收益取 0**

最大路径和（LC 124）里，如果向父节点返回 `val + left + right`，或者不对负收益取 `max(..., 0)`，各会出什么错？

## A
**不变量**：`gain(node)` 的含义是「以 `node` 为**最高点**、只向下走**一条链**的最大和」，这样父节点才能把它当作路径的一段接上。路径是一条链，不能在中间同时往两边分叉后又接到父节点。

**反例一：返回两侧之和。** 树 `[1,2,3,4,5]`（`1` 的左孩子 `2` 带 `4`、`5`，右孩子 `3`）：
- 错误写法（返回 `node.val + left + right`）：节点 `2` 返回 `2+4+5 = 11`，根节点计算 `1 + 11 + 3 = 15`，全局最大得到 `15`——这条「路径」是 `4-2-5` 加上 `1` 再加 `3`，已经分叉。
- 正确答案：`11`（路径 `4 → 2 → 5`，或 `5 → 2 → 1 → 3` 为 `11`）。

**反例二：不对负收益取 0。** 树 `[2,-1]`：
- 不取 `max(..., 0)`：根的 `left = -1`，`best = 2 + (-1) = 1`，答案 `1`。
- 取 0：丢弃负的子树，`best = 2`，正确答案 `2`。

- 取 0 的含义是「这一侧不接」：路径可以只在这一个节点结束。
- 全局变量 `best` 初值必须是 `-inf`，不是 `0`：全负树 `[-3]` 的答案是 `-3`。
- 这三个动作（返回单侧、负数不要、全局更新）缺一不可；记成「**拐点用两侧更新全局，返回时只带最好的一侧**」。
