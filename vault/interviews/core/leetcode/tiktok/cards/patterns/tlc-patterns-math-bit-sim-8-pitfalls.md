## Q
**数学、位运算与模拟｜常见陷阱**

这一类题最容易在哪里出错？

## A
1. **进位漏最后一位**：加法循环条件要包含 `carry`；`"999" + "1"` 得 `"1000"`。
2. **乘法前导零**：`lstrip("0")` 之前先特判 `"0"` 乘任何数。
3. **螺旋单行 / 单列重复**：下边和左边要判断 `top < bottom and left < right`，否则 `[[1,2,3]]` 会得到 `[1,2,3,2,1]`。
4. **旋转图像的方向**：顺时针 = 转置 + 每行反转；逆时针 = 每行反转 + 转置。
5. **机器人只判断回到原点**：朝向不再是北也构成环（`"GL"`）；要同时检查朝向。
6. **直接模拟 `10^9` 步**：内存泄漏 LC 1860 的内存最大 `2^31 - 1`，但每秒消耗 `t`，约 `√(2 · 2^31) ≈ 9.3 万` 秒就崩溃，直接模拟即可；先估算步数再决定。
7. **整数除法**：`//` 向下取整，`int(a / b)` 向零截断；负数不同。
8. **浮点**：`**0.5` 不精确，用 `math.isqrt`；`/` 得浮点。
9. **取模**：`(a - b) % mod` 在 Python 里非负；移植 C++ 题解时不必再补 `+ mod`。
10. **筛法范围**：数组长度开 `right + 1`；`0`、`1` 不是质数；下界 `left` 可能是 `1`。
11. **位运算优先级**：Python 里 `&` 的优先级高于 `==`（与 C 不同），`n & (n - 1) == 0` 恰好等价于 `(n & (n - 1)) == 0`；移植 C++ 代码时要留意，写上括号最清楚。
12. **位掩码子集的位数**：`1 << n` 个子集，`n <= 20` 才可行。
13. **原地标记丢信息**：LC 442 取负后再读值要 `abs(x)`。
