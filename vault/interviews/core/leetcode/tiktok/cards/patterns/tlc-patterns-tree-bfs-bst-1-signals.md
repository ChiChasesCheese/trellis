## Q
**二叉树 BFS 与 BST 性质｜信号**

什么样的题面该想到层序遍历（BFS）？什么样该想到 BST 的中序有序性？序列化题的信号是什么？

## A
**层序遍历（Level-order BFS）的信号：**
- 题面按**层**组织输出：「每一层的节点」「锯齿形层序」LC 103、「每层最大宽度」LC 662。
- 「从右侧看到的节点」「每层最后一个」LC 199。
- 「到最近叶子的深度」「最小深度」：BFS 遇到第一个叶子就停。
- 把树当**无向图**处理：「距离目标节点为 K 的所有节点」LC 863，需要父指针后做 BFS。

**BST 的信号（二叉搜索树：左 < 根 < 右）：**
- 题面出现「**二叉搜索树**」：**中序遍历是严格递增序列**，是几乎所有 BST 题的钥匙。
- 验证 BST：每个节点有一个合法的**取值区间**，从上往下收窄，不能只比较父子。
- 第 `k` 小：中序遍历数到第 `k` 个，可以提前停。
- 查找 / 插入 / 删除：沿着比较大小的方向走，`O(h)`（LC 450）。
- 转成有序双向链表 LC 426：中序遍历中接指针。

**序列化的信号：**
- 「把树变成字符串再还原」LC 297、428：需要**记录空节点**（或每个节点的孩子数），才能唯一还原结构。

**近似信号：**
- 只需要某种遍历序列、不关心层 → DFS 更简单。
- 路径、子树聚合 → 后序 DFS，不是 BFS。
- 树的节点数大且可能退化成链 → BFS 用队列没有递归深度问题，是 DFS 的备选。
