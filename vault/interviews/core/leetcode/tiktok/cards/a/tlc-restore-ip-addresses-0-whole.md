## Q
**LC 93 复原 IP 地址**｜Medium · TikTok·字节 高频

有效 IP 地址正好由四个整数组成，每个整数在 `0` 到 `255` 之间，且不能含有前导 `0`，整数之间用 `'.'` 分隔。例如 `"0.1.2.201"` 和 `"192.168.1.1"` 是有效地址，`"0.011.255.245"`、`"192.168.1.312"` 是无效地址。给一个只包含数字的字符串 `s`，返回所有能通过在 `s` 中插入 `'.'` 得到的有效 IP 地址；不能重新排序或删除 `s` 中的数字，答案可以按任意顺序给出。`1 <= s.length <= 20`。例：`"25525511135"` → `["255.255.11.135","255.255.111.35"]`；`"0000"` → `["0.0.0.0"]`；`"101023"` → `["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回溯：依次切出 `4` 段，每段取 `1` 到 `3` 位；一段合法当且仅当没有前导零（单独的 `"0"` 除外）并且不超过 `255`；剩余字符数必须在 `[剩余段数, 3 × 剩余段数]` 之间，否则剪枝；恰好切满 `4` 段并且用完所有字符时收集答案。

**识别。** 「在字符串里插入分隔符，切成若干段，每段要满足条件」是回溯切割的标准形态（同类的有分割回文串 LC 131）。段数固定为 `4`、每段至多 `3` 位，搜索树的深度是 `4`、每层至多 `3` 个分支，最多 `3^4 = 81` 种切法，规模是常数。

**推导。** 暴力：在 `n - 1` 个空位里选 `3` 个位置放点，共 `C(n-1, 3)` 种（`n = 20` 时 `969`），逐个检查四段是否合法。可行，但没有利用「一段不合法，后面更长的段也不合法」。回溯的两个剪枝：一段以 `0` 开头且长度大于 `1`，更长的段同样有前导零，直接 `break`；一段数值超过 `255`，更长的段只会更大，也 `break`。再加上长度剪枝：还要切 `left` 段时，剩余字符数必须在 `[left, 3 * left]` 内，否则不可能凑成。

```python
def restore_ip_addresses(s: str) -> list[str]:
    n = len(s)
    res: list[str] = []
    parts: list[str] = []

    def dfs(start: int) -> None:
        left = 4 - len(parts)           # 还要切出几段
        if left == 0:
            if start == n:              # 恰好用完所有字符
                res.append(".".join(parts))
            return
        if not left <= n - start <= 3 * left:   # 每段 1~3 位：剩余字符数不在范围内就剪枝
            return
        for end in range(start + 1, min(start + 3, n) + 1):
            seg = s[start:end]
            if len(seg) > 1 and seg[0] == "0":  # 前导零：更长的段同样非法，直接 break
                break
            if int(seg) > 255:                  # 更长的段只会更大
                break
            parts.append(seg)
            dfs(end)
            parts.pop()

    dfs(0)
    return res
```

运行：`"25525511135"` → `['255.255.11.135', '255.255.111.35']`，`"0000"` → `['0.0.0.0']`，`"101023"` → `['1.0.10.23', '1.0.102.3', '10.1.0.23', '10.10.2.3', '101.0.2.3']`，`"1"` → `[]`，`"1111"` → `['1.1.1.1']`，`20` 个 `"2"` → `[]`（太长，最多 `12` 位）。

**复杂度。** 时间 `O(3^4)`，即常数（段数固定为 `4`，每段最多 `3` 个选择）；空间 `O(1)`（递归深度 `4`）。

**易错点。**
- 不判前导零：`"101023"` 会多出 `"1.0.1.023"`、`"1.01.0.23"` 等，共 `10` 个，正确是 `5` 个。
- 把单独的 `"0"` 也当成前导零：`"0000"` 得到 `[]`，正确是 `["0.0.0.0"]`；`"101023"` 只剩 `["10.10.2.3"]`。条件必须是 `len(seg) > 1 and seg[0] == "0"`。
- 切满 `4` 段后不检查是否用完所有字符：`"11111"` 会多出 `"1.1.1.1"`（只用了前 `4` 位），正确只有 `4` 个。
- 用 `continue` 代替 `break`：不影响结果，但白白多试了更长的段。

**追问。**
- 不想写递归：`itertools.combinations(range(1, n), 3)` 枚举三个切点，直接验证四段，代码更短，面试里可以作为对照。
- 推广：段数 `k`、每段范围不同；IPv6 地址每段是十六进制，规则不同。
- 只验证一个地址是否有效（LC 468）：按 `.` 切成 `4` 段，逐段检查长度、前导零、数值范围。

**同模式。** LC 131 分割回文串、LC 468 验证 IP 地址、LC 165 比较版本号、LC 17 电话号码的字母组合、LC 39 组合总和。
