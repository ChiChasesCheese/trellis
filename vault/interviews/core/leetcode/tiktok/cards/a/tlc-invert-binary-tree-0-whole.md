## Q
**LC 226 翻转二叉树**｜Easy · 字节高频

给二叉树的根节点 `root`，把整棵树左右镜像翻转，返回根节点。节点数在 `[0, 100]`，`-100 <= Node.val <= 100`。例：`[4,2,7,1,3,6,9]` → `[4,7,2,9,6,3,1]`；`[2,1,3]` → `[2,3,1]`；`[]` → `[]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对每个节点交换它的左右孩子，再对两个孩子重复；先递归翻转两棵子树、再同时赋值给左右指针，一行元组赋值完成交换。`O(n)`。

**识别。** 「整棵树每个节点都做同一件局部操作」是树递归的标准信号：子问题与原问题同形（翻转一棵子树），空树是基准情形。深度只有 `100`，递归安全；换成任何遍历顺序（先序、后序、层序）都对，因为每个节点的交换彼此独立。

**推导。** 想象镜像：根的左子树变成原来右子树的镜像，右子树变成原来左子树的镜像 → 先把两个子树各自翻转（递归），再换位 → 每个节点访问一次。迭代版用栈或队列，弹出节点、交换孩子、把孩子压回去，同样 `O(n)`。

```python
def invert_tree(root: TreeNode | None) -> TreeNode | None:
    if root is None:
        return None
    # 右边的整个表达式先算完，再同时赋给左右，不需要临时变量
    root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root
```

运行：`[4,2,7,1,3,6,9]` → `[4,7,2,9,6,3,1]`，`[2,1,3]` → `[2,3,1]`，`[]` → `[]`。

**复杂度。** 时间 `O(n)`；空间 `O(h)`，递归栈深等于树高，平衡 `O(log n)`，退化成链 `O(n)`。

**易错点。**
- 拆成两条赋值会破坏数据：`root.left = invert_tree(root.right)` 之后再写 `root.right = invert_tree(root.left)`，此时 `root.left` 已经是新值。`[2,1,3]` 得到 `[2,3,3]`，正确是 `[2,3,1]`。
- 空树要返回 `None`，不能对 `None` 取 `.left`。
- 只交换节点的 `val` 不对：必须交换指针（整个子树），否则孩子下面的子树还留在原处。

**追问。**
- 不用递归：栈里放节点，弹出后交换孩子再压回，`O(n)`，不受递归深度限制。
- 判断一棵树是否轴对称（LC 101）：同时走左右两棵子树，比较 `左.左 == 右.右`、`左.右 == 右.左`。
- 只翻转某一层（比如奇数层）：层序遍历时按层号决定是否交换。

**同模式。** LC 101 对称二叉树、LC 100 相同的树、LC 617 合并二叉树、LC 572 另一个树的子树。
