## Q
**LC 287 寻找重复数**｜Medium · 字节高频

数组 `nums` 包含 `n + 1` 个整数，每个数都在 `[1, n]` 内，且只有一个整数出现两次或多次，其余整数只出现一次。找出这个重复的数。要求**不修改**数组、只用常数级额外空间。`1 <= n <= 10^5`，`nums.length == n + 1`，`1 <= nums[i] <= n`。例：`[1,3,4,2,2]` → `2`；`[3,1,3,4,2]` → `3`；`[3,3,3,3,3]` → `3`。进阶：如何证明至少存在一个重复数？能否 `O(n)` 时间完成？

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把数组看成链表：下标 `i` 指向 `nums[i]`。因为值落在 `[1, n]`，从下标 `0` 出发永远走不出数组；`n + 1` 个下标指向 `n` 个值，必有两个下标指向同一个值，链表里就有环，而环的入口正是重复的数。用快慢指针（Floyd 判圈算法）先找到环内的相遇点，再从起点和相遇点同速前进，相遇处即为入口。`O(n)` 时间，`O(1)` 空间。

**识别。** 「`n + 1` 个数、范围 `[1, n]`」是鸽巢原理（pigeonhole principle）的标志；「不能修改、`O(1)` 空间」排除哈希集合、排序、原地标记；「值既是数据又是下标」提示"函数图 / 链表环"。同样的结构也是 LC 142 环形链表 II 的入口问题。

**推导。** 暴力：两层循环比较，`O(n^2)`；哈希集合 `O(n)` 空间；排序要改数组 → 二分答案值（数 `<= mid` 的元素个数，超过 `mid` 就说明重复数在 `[1, mid]`），`O(n log n)`、`O(1)` 空间 → 要 `O(n)`：函数 `f(i) = nums[i]` 构成一个从 `0` 出发的"ρ"形路径（先一条尾巴，再一个环）；入口有两条入边（两个下标指向同一个值），就是重复数 → Floyd：慢指针每次一步、快指针每次两步，在环内相遇；之后令一个指针回到 `0`，两个都每次一步，设尾长 `a`、入口到相遇点的距离 `b`、环长 `c`，相遇时满足 `a = k·c - b`，所以同时到达入口。

```python
def find_duplicate(nums: list[int]) -> int:
    slow = fast = 0                        # 把 i -> nums[i] 看成链表；0 没有入边（值在 1..n），一定在链上而不在环里
    while True:                            # 阶段一：快慢指针在环内相遇
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    slow = 0                               # 阶段二：一个回到起点，两个都每次走一步，相遇点就是环的入口
    while slow != fast:
        slow = nums[slow]
        fast = nums[fast]
    return slow                            # 环的入口有两条入边，即重复的数
```

运行：`[1,3,4,2,2]` → `2`，`[3,1,3,4,2]` → `3`，`[3,3,3,3,3]` → `3`，`[1,1]` → `1`；`n = 10^5` 的数组约 `0.003` 秒；调用后数组保持不变。

**复杂度。** 时间 `O(n)`：两个阶段指针各自走的步数都与尾长加环长同阶；空间 `O(1)`。

**易错点。**
- 阶段二从相遇点继续，而不是回到起点 `0`（比如从 `nums[0]` 开始）：两个指针永远追不上，死循环。`[1,3,4,2,2]` 里把 `slow` 重置为 `nums[0]` 之后，`slow` 与 `fast` 始终不相遇。
- 用求和差：`sum(nums) - n(n+1)/2` 只在重复数恰好出现两次时成立。`[3,3,3,3,3]` 得到 `5`，正确是 `3`。
- 起点必须是下标 `0`：值域是 `[1, n]`，没有任何元素指向 `0`，所以它在环外，尾长 `a ≥ 1`，阶段二的追及关系才成立。

**追问。**
- 证明至少存在一个重复数：`n + 1` 个数放进 `n` 个值里，鸽巢原理。
- 允许修改数组：把每个数放到它自己的下标处（循环交换），冲突的就是重复数；或者遍历时把 `nums[abs(x)]` 取负，遇到已经为负的就是重复数。
- 二分答案值：数组中 `<= mid` 的个数大于 `mid`，则重复数在 `[1, mid]` 内，`O(n log n)`、`O(1)`、不修改数组，思路更容易讲清楚。
