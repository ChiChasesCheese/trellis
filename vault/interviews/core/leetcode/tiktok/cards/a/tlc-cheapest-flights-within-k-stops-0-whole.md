## Q
**LC 787 K 站中转内最便宜的航班**｜Medium · TikTok 高频

有 `n` 个城市通过一些航班连接。给数组 `flights`，`flights[i] = [from_i, to_i, price_i]` 表示从城市 `from_i` 到 `to_i` 的航班，价格 `price_i`。给定出发城市 `src`、目的地 `dst` 和整数 `k`，找出一条**最多经过 `k` 站中转**的路线，使从 `src` 到 `dst` 的价格最便宜，返回该价格；不存在则返回 `-1`。`2 <= n <= 100`，`0 <= flights.length <= n * (n - 1) / 2`，`0 <= from_i, to_i < n`，`from_i != to_i`，`1 <= price_i <= 10^4`，航班没有重复，没有自环，`0 <= src, dst, k < n`，`src != dst`。例：`n = 4`，`flights = [[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]]`，`src = 0`，`dst = 3`，`k = 1` → `700`（`0 → 1 → 3`；`0 → 1 → 2 → 3` 更便宜但中转了 2 站，无效）；`n = 3`，`flights = [[0,1,100],[1,2,100],[0,2,500]]`，`src = 0`，`dst = 2`，`k = 1` → `200`，`k = 0` → `500`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 带步数限制的最短路：最多 `k` 站中转 = 最多 `k + 1` 条边。用 Bellman-Ford 松弛 `k + 1` 轮，每一轮只基于**上一轮**的距离数组更新（先复制一份），第 `t` 轮结束时 `dist[v]` 就是「至多用 `t` 条边」到 `v` 的最小价格。`O(k * E)`。

**识别。** 「最便宜」是最短路；但「最多 `k` 站」给路径加了**边数限制**，这是最短路里最容易踩坑的变体：普通 Dijkstra 只关心价格，会选出价格最低但中转太多的路线（示例 1 里不限站数是 `400`）。边数限制天然对应 Bellman-Ford 的“轮数”：第 `t` 轮恰好扩展到 `t` 条边。`n <= 100`，边至多 `4950`，`k * E` 约 `5 * 10^5`，轻松通过。

**推导。** 暴力：深度优先枚举所有至多 `k + 1` 条边的路径，指数级。想要多项式解，用动态规划：`dp[t][v]` 表示至多 `t` 条边到达 `v` 的最小价格，转移 `dp[t][v] = min(dp[t-1][v], min over (u→v) dp[t-1][u] + w)`，边界 `dp[0][src] = 0`。`dp[t]` 只依赖 `dp[t-1]`，用两个数组滚动：每轮先复制当前的 `dist` 为 `nxt`，所有松弛都读旧的 `dist`、写新的 `nxt`，这样一轮里一条路径至多多走一条边。

```python
from math import inf

def find_cheapest_price(n: int, flights: list[list[int]], src: int, dst: int, k: int) -> int:
    dist: list[float] = [inf] * n
    dist[src] = 0
    for _ in range(k + 1):                  # 最多 k 个中转 = 最多 k + 1 条边：松弛 k + 1 轮
        nxt = dist[:]                       # 每轮只用上一轮的结果，否则一轮里会连走多条边
        for u, v, w in flights:
            if dist[u] + w < nxt[v]:
                nxt[v] = dist[u] + w
        dist = nxt
    return -1 if dist[dst] == inf else int(dist[dst])
```

运行：示例 1（`k = 1`）→ `700`；示例 2（`k = 1`）→ `200`；示例 3（`k = 0`）→ `500`；`n = 3`，`flights = [[0,1,5]]`，`src = 0`，`dst = 2`，`k = 2` → `-1`；`n = 100` 的完全图、`k = 98` 轻松跑完。

**复杂度。** 时间 `O(k * E)`，其中 `E = len(flights)`；空间 `O(n)`：两个距离数组。

**易错点。**
- 松弛时直接改 `dist`（不复制）：同一轮里会沿着刚更新的值继续走多条边，限制失效。`flights = [[0,1,100],[1,2,100],[0,2,500]]`，`k = 0` 得到 `200`（走了 2 条边），正确是 `500`。
- 轮数写成 `k`：`k` 站中转对应 `k + 1` 条边，`k = 0` 时必须还能走一条直达航班。
- 用不限步数的 Dijkstra：示例 1 得到 `400`，正确是 `700`。
- 终点不可达时 `dist[dst]` 仍是 `inf`，要转成 `-1`，不能直接 `int(inf)`（会抛 `OverflowError`）。

**追问。**
- 用 Dijkstra 能做吗：状态要带上边数，堆元素 `(价格, 边数, 城市)`；弹出时若边数已超限则丢弃，若该城市已有「边数不更多」的更早到达（价格也不高）则剪枝。示例 1 → `700`。
- 提前结束：若某一轮没有任何更新（`nxt == dist`），后面也不会再变，可以 `break`；`k` 很大时（接近 `n`）能省掉大量轮次。
- 要输出具体的路线：松弛时记录前驱数组，每轮同样要用上一轮的前驱。

**同模式。** LC 743 网络延迟时间、LC 1631 最小体力消耗路径、LC 1514 概率最大的路径、LC 1928 规定时间内到达终点的最小花费（同样带一个资源上限）。
