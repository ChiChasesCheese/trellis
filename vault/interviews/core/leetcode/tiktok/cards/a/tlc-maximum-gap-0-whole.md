## Q
**LC 164 最大间距**｜Hard · CodeTop 国内累计 8 次 · 最近 2026-01-29（CodeTop）

给一个无序整数数组 `nums`，返回它**排序之后**相邻元素之间最大的差值；元素个数小于 `2` 时返回 `0`。必须写出**线性时间**、**线性额外空间**的算法。`1 <= nums.length <= 10^5`，`0 <= nums[i] <= 10^9`。例：`[3,6,9,1]` → `3`（排序后 `[1,3,6,9]`，`(3,6)` 和 `(6,9)` 差都是 `3`），`[10]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 桶排序 + 鸽巢原理（pigeonhole）：`n` 个数把区间 `[lo, hi]` 切成 `n - 1` 段间隔，最大间隔至少是平均值 `(hi - lo) / (n - 1)`；把桶宽取成这个平均值的下界，则同一个桶内任意两数的差都小于答案，最大间距只会出现在**相邻非空桶之间**——每个桶只记最小值和最大值，一次扫描求 `桶最小 - 上一个非空桶最大` 的最大值。`O(n)`。

**识别。** 「排序后相邻差的最大值」本来 `sorted` 后一遍扫描就解决，题目偏偏要求线性：这就是在暗示**不能比较排序**，要用桶 / 基数排序（radix sort）这类非比较排序，或者像这里一样连排序都不做，利用鸽巢原理。`nums[i] <= 10^9` 让计数排序（开 `10^9` 的数组）不可行。

**推导。** 暴力：排序后扫描，`O(n log n)`，不满足线性要求 → 观察：`n` 个数形成 `n - 1` 个相邻间隔，间隔之和是 `hi - lo`，所以最大间隔 `>= ceil((hi - lo) / (n - 1))` → 取桶宽 `d = (hi - lo) // (n - 1)`（至少 `1`），桶内两数差至多 `d - 1`，一定小于最大间隔，因此最大间隔不在桶内 → 只需要比较「相邻非空桶」的边界：后一个桶的最小值减前一个非空桶的最大值 → 每个桶存最小 / 最大两个数，扫描一遍，桶数不超过 `2n`，`O(n)`。

```python
def maximum_gap(nums: list[int]) -> int:
    n = len(nums)
    if n < 2:
        return 0
    lo, hi = min(nums), max(nums)
    if lo == hi:                                # 全相等：排序后相邻差全是 0
        return 0
    size = max(1, (hi - lo) // (n - 1))         # 桶宽 <= 平均间距的下界，保证桶内差一定小于答案
    count = (hi - lo) // size + 1
    bucket_min = [hi + 1] * count               # 每个桶只记最小值和最大值
    bucket_max = [-1] * count
    for x in nums:
        i = (x - lo) // size
        bucket_min[i] = min(bucket_min[i], x)
        bucket_max[i] = max(bucket_max[i], x)
    best, prev_max = 0, lo
    for mn, mx in zip(bucket_min, bucket_max):
        if mx < 0:                              # 空桶：跳过，prev_max 保持不变
            continue
        best = max(best, mn - prev_max)         # 只比较"本桶最小 - 上一个非空桶最大"
        prev_max = mx
    return best
```

运行：`[3,6,9,1]` → `3`，`[10]` → `0`，`[1,1,1]` → `0`，`[1,10000000]` → `9999999`，`[0,1000000000]` → `1000000000`，`[1,2,100,101]` → `98`；`10^5` 个范围 `0..10^9` 的数也能瞬间算完。

**复杂度。** 时间 `O(n)`（求 `min`、`max`，分桶，扫桶各一遍）；空间 `O(n)`（桶数 `(hi - lo) // d + 1`，不超过 `2n`）。

**易错点。**
- 桶宽整除后可能是 `0`：`[1,1,1,2]` 中 `(2 - 1) // 3 = 0`，除以 `0` 报 `ZeroDivisionError`，要写 `max(1, ...)`；正确答案是 `1`。
- 只比较**相邻编号**的桶、遇到空桶就断开：`[1,2,100,101]` 得到 `0`，正确是 `98`，必须用「上一个非空桶的最大值」。
- 全部元素相等时 `hi - lo = 0`，桶宽、桶数都没意义，要先返回 `0`。

**追问。**
- 返回产生最大间距的那一对数：扫描时记下 `(prev_max, mn)`。
- 值域很小（比如 `<= 10^6`）：直接开计数数组 / 布尔数组，扫一遍记录相邻出现的值，`O(n + V)`。
- 现实里能不能就用 `sorted`：`sorted` + 相邻差是 `O(n log n)`，但在 Python 里常数极小；面试官要的是线性的思想，先说清楚再讲取舍。
