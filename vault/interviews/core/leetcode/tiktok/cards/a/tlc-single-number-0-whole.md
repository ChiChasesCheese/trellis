## Q
**LC 136 只出现一次的数字**｜Easy · 近一年被问：美国 0 次、国内 3 次 · CodeTop 国内累计 9 次 · 最近 2026-10-20（面试记录）

非空整数数组 `nums` 里，除了一个元素只出现一次，其余每个元素都恰好出现两次。找出那个只出现一次的元素。要求**线性时间、常数额外空间**。`1 <= nums.length <= 3 * 10^4`，`-3 * 10^4 <= nums[i] <= 3 * 10^4`。例：`[2,2,1]` → `1`，`[4,1,2,1,2]` → `4`，`[1]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把所有数异或（XOR）起来：`a ^ a = 0`、`0 ^ x = x`、异或满足交换律和结合律，成对的数两两抵消，剩下的就是只出现一次的那个。`O(n)` 时间，`O(1)` 空间。

**识别。** 「每个数出现两次，只有一个例外」+「线性时间、常数空间」：哈希表和排序都被空间或时间条件挡掉，信号是**成对抵消**，对应的运算是异或。再看到「出现 k 次，只有一个出现一次」就想按位计数模 k。

**推导。** 暴力：用 `Counter` 数次数，`O(n)` 时间 `O(n)` 空间，违反常数空间；排序后两两比较，`O(n log n)`，违反线性时间。数学法 `2 * sum(set(nums)) - sum(nums)` 时间线性但 `set` 用了 `O(n)` 空间。要找一个运算 `⊕`，满足 `x ⊕ x = 单位元`，且次序无关：异或正好，两个相同的数每一位都相同，异或后每一位都是 0。于是从 0 开始依次异或整个数组，成对的在过程中抵消，结果就是落单的数。

```python
def single_number(nums: list[int]) -> int:
    ans = 0
    for x in nums:
        ans ^= x                                     # a ^ a == 0，0 ^ x == x，与顺序无关
    return ans
```

运行：`[2,2,1]` → `1`，`[4,1,2,1,2]` → `4`，`[1]` → `1`，`[-3,5,-3]` → `5`（负数同样成立）。同一个意思可以写成 `reduce(xor, nums)`，需要 `from functools import reduce` 和 `from operator import xor`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 把 `reduce(xor, set(nums))` 当成等价写法：`set` 把成对的两份合成一份，抵消没发生。`[4,1,2,1,2]` 得 `4 ^ 1 ^ 2 = 7`，正确 `4`。
- 其余数出现**三次**时 XOR 不再成立（`x ^ x ^ x = x`）：`[2,2,2,3]` 得 `1`，正确是 `3`，那是 LC 137，要改成按位计数模 3。

**追问。**
- 其余数出现三次，找出现一次的（LC 137）：每一位上 1 的个数模 3，剩下的位拼回答案。
- 恰好有两个数只出现一次（LC 260）：先异或得 `a ^ b`，用其中一个为 1 的位把数组分成两组。
- 不准用位运算：`2 * sum(set(nums)) - sum(nums)`，但用了 `O(n)` 空间。

**同模式。** LC 137 只出现一次的数字 II、LC 260 只出现一次的数字 III、LC 268 丢失的数字（下标和值一起异或）、LC 389 找不同。
