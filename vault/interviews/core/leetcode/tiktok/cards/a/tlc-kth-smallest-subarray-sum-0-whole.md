## Q
**LC 1918 第 K 小的子数组和**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-01-08（面试记录）

给长度为 `n` 的整数数组 `nums` 和整数 `k`，返回**第 `k` 小的子数组和**。子数组是数组中非空且连续的一段，子数组和是其中所有元素之和（不同位置的子数组即使和相同也各算一个）。`1 <= n <= 2 * 10^4`，`1 <= nums[i] <= 5 * 10^4`，`1 <= k <= n * (n + 1) / 2`。例：`nums = [2,1,3]`，`k = 4` → `3`（所有子数组和升序是 `1, 2, 3, 3, 4, 6`）；`nums = [3,3,5,5]`，`k = 7` → `10`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对答案做二分：元素全为正数，「和不超过 `x` 的子数组个数」随 `x` 单调不减，用双指针 `O(n)` 就能数出这个个数；在 `[min(nums), sum(nums)]` 上找最小的 `x` 使个数 `>= k`。时间 `O(n log S)`，`S` 是总和。

**识别。** 「第 `k` 小」+「子数组和」+「元素全为正」：子数组有 `n(n+1)/2` 个，`n = 2 * 10^4` 时约 `2 * 10^8`，不可能全部枚举排序，堆法的 `k` 又可以大到 `2 * 10^8`。「第 `k` 小」常常对应**二分答案**：答案落在一个有界的数值区间上，且「不超过 `x` 的个数」单调。元素全为正，保证窗口和随右端点单调，双指针才能数个数。

**推导。** 暴力：枚举全部子数组和，排序取第 `k` 个，`O(n^2 log n)` 时间和 `O(n^2)` 空间，不行 → 把"求第 `k` 小"改成判定：`count(x)` = 和 `<= x` 的子数组个数，第 `k` 小就是最小的 `x` 满足 `count(x) >= k` → `count(x)` 用双指针 `O(n)`：右端 `right` 前进，窗口和超过 `x` 就收缩左端，以 `right` 结尾、和 `<= x` 的子数组有 `right - left + 1` 个 → 在 `[min(nums), sum(nums)]` 上二分，共 `log S ≈ 30` 轮。

```python
def kth_smallest_subarray_sum(nums: list[int], k: int) -> int:
    def count_le(x: int) -> int:                  # 和 <= x 的子数组个数（元素全为正，双指针）
        cnt = left = cur = 0
        for right, v in enumerate(nums):
            cur += v
            while cur > x:                        # 窗口和超标：收缩左端
                cur -= nums[left]
                left += 1
            cnt += right - left + 1               # 以 right 结尾、左端在 [left, right] 的子数组都 <= x
        return cnt

    lo, hi = min(nums), sum(nums)                 # 答案一定落在 [最小元素, 总和]
    while lo < hi:
        mid = (lo + hi) // 2
        if count_le(mid) >= k:                    # 至少 k 个子数组 <= mid：答案 <= mid
            hi = mid
        else:
            lo = mid + 1
    return lo
```

运行：`([2,1,3], 4)` → `3`；`([3,3,5,5], 7)` → `10`；`([5], 1)` → `5`；`([2,1,3], 1)` → `1`；`([2,1,3], 6)` → `6`；`n = 2 * 10^4` 的随机数组在不到 `0.1` 秒内返回。

**复杂度。** 时间 `O(n log S)`，约 `2 * 10^4 × 30`；空间 `O(1)`。

**易错点。**
- 判定写成 `count_le(mid) > k`（严格大于）：`([2,1,3], 4)` 得到 `4`，正确是 `3`。我们要的是最小的 `x` 使 `count >= k`，等于也算。
- 上界取 `max(nums)`：`([2,1,3], 6)` 得到 `3`，正确是 `6`（第 `6` 小是整个数组的和）。上界必须是 `sum(nums)`。
- 在含负数的数组上用这个双指针：窗口和不再单调，`count_le` 数不对；题目保证元素为正。

**追问。**
- 第 `k` **大**：转成第 `n(n+1)/2 - k + 1` 小。
- 数组含 `0`：双指针依然成立（窗口和非严格递增）；含负数则不行，要换成前缀和 + 排序 + 二分，`O(n log n log S)`。
- 写得更简短：`lo + bisect_left(range(lo, hi + 1), k, key=count_le)`，Python 3.10+ 的 `key=` 让 `bisect` 在整数区间上做二分，不用手写循环。
- `k` 很小、`n` 很大：用最小堆做多路归并，`O(k log n)`。

**同模式。** LC 378 有序矩阵中第 K 小的元素、LC 668 乘法表中第 k 小的数、LC 719 找出第 K 小的数对距离、LC 786 第 K 个最小的素数分数、LC 875 爱吃香蕉的珂珂。
