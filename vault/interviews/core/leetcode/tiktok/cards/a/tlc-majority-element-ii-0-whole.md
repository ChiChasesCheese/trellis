## Q
**LC 229 求众数 II**｜Medium · CodeTop 国内累计 1 次 · 最近 2025-12-22（CodeTop）

给大小为 `n` 的整数数组 `nums`，找出其中所有出现次数**超过** `⌊n / 3⌋` 的元素（顺序任意）。`1 <= n <= 5 * 10^4`，`-10^9 <= nums[i] <= 10^9`。进阶：时间 `O(n)`、空间 `O(1)`。例：`[3,2,3]` → `[3]`，`[1]` → `[1]`，`[1,2]` → `[1,2]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 主任务用哈希计数：`Counter` 一遍数出每个值的次数，留下次数 `> n // 3` 的；答案最多 2 个。`O(n)` 时间、`O(n)` 空间。进阶的 `O(1)` 空间用摩尔投票（Boyer-Moore voting）的两候选版本。

**识别。** 「出现次数超过某个比例」→ 计数；「超过 `n / 3`」→ 鸽巢原理（pigeonhole）：三个不同的数各超过 `n / 3` 次，总数就超过 `n`，所以答案至多 2 个。这个「至多 `k - 1` 个」的结论是进阶投票法的基础。

**推导。** 暴力：对每个元素再扫一遍数次数，`O(n^2)` → 浪费：同一个值被重复数了很多遍 → 一遍哈希计数，每个值只数一次，`O(n)` → 进阶要 `O(1)` 空间：既然答案至多 2 个，只保留 2 个候选和计数，每遇到三个互不相同的数就一起抵消，最后再数一遍确认候选。

```python
from collections import Counter


def majority_element(nums: list[int]) -> list[int]:
    limit = len(nums) // 3                  # 出现次数必须严格大于它
    return [x for x, c in Counter(nums).items() if c > limit]
```

运行：`[3,2,3]` → `[3]`，`[1]` → `[1]`，`[1,2]` → `[1, 2]`，`[1,2,3]` → `[]`，`[2,2,1,1,1,2,2]` → `[2, 1]`。

**复杂度。** 时间 `O(n)`：计数一遍，再扫一遍不同的值；空间 `O(m)`，`m` 是不同值的个数，最坏 `O(n)`。

**易错点。**
- 用 `>=` 代替 `>`：`[1,2,3]` 中 `n // 3 = 1`，每个值都出现 1 次，`>=` 会返回 `[1, 2, 3]`，正确是 `[]`。
- 套用 LC 169 的思路只返回一个元素：`[1,2]` 中 `n // 3 = 0`，两个值都超过，正确是 `[1, 2]`。

**追问。**
- `O(1)` 空间（进阶）：两候选摩尔投票，三个不同的数一起抵消，最后必须再数一遍确认。
- 推广到「超过 `n / k`」：保留 `k - 1` 个候选（Misra-Gries 算法），时间 `O(nk)`、空间 `O(k)`。
- 数据流、内存放不下：Misra-Gries 一遍扫描给出候选，若不能再扫一遍，就只能给出带误差的频次估计。

**同模式。** LC 169 多数元素、LC 347 前 K 个高频元素、LC 1150 检查一个数是否在数组中占绝大多数、LC 2404 出现最频繁的偶数元素。
