## Q
**LC 2845 统计趣味子数组的数目**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-06-18（面试记录）

给下标从 `0` 开始的整数数组 `nums`，以及整数 `modulo` 和 `k`。如果子数组 `nums[l..r]` 满足：设 `cnt` 为区间 `[l, r]` 内满足 `nums[i] % modulo == k` 的下标 `i` 的个数，并且 `cnt % modulo == k`，就称它为**趣味子数组**。返回趣味子数组的数目。`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^9`，`1 <= modulo <= 10^9`，`0 <= k < modulo`。例：`nums = [3,2,4]`，`modulo = 2`，`k = 1` → `3`（`[3]`、`[3,2]`、`[3,2,4]`，各自的 `cnt = 1`）；`nums = [3,1,9,6]`，`modulo = 3`，`k = 0` → `2`（`[3,1,9,6]` 的 `cnt = 3`，`3 % 3 == 0`；`[1]` 的 `cnt = 0`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先把每个元素变成 `0 / 1`（`nums[i] % modulo == k` 为 `1`），对这个 `0 / 1` 序列做前缀和并对 `modulo` 取模；子数组 `(l, r]` 趣味 ⇔ `(pre[r] - pre[l]) % modulo == k` ⇔ `pre[l] ≡ pre[r] - k (mod modulo)`。遍历右端点，用哈希表统计之前每个余数出现的次数，一趟累加。`O(n)`。

**识别。** 「统计满足条件的子数组个数」+「条件是某个计数的同余」是前缀和加哈希表（与 LC 560、LC 974 同一类）。先把「满足条件的元素」转成 `0 / 1`，计数就变成了前缀和之差。因为条件只和前缀和对 `modulo` 的余数有关，哈希表里只需要存余数的出现次数。条件不单调，滑动窗口用不了。

**推导。** 暴力：两层循环枚举子数组并累计 `cnt`，`O(n^2)`，`n = 10^5` 太慢 → 令 `pre[i]` 为前 `i` 个元素里 `1` 的个数，子数组 `(l, r]` 的 `cnt = pre[r] - pre[l]` → 条件 `(pre[r] - pre[l]) % modulo == k` 改写成 `pre[l] % modulo == (pre[r] - k) % modulo` → 对每个 `r`，只需要知道之前有多少个 `l`（包括空前缀 `l = 0`）的前缀余数等于 `(pre[r] - k) % modulo`，用哈希表计数，边扫边累加。

```python
from collections import Counter


def count_interesting_subarrays(nums: list[int], modulo: int, k: int) -> int:
    seen: Counter[int] = Counter({0: 1})           # 前缀计数（对 modulo 取模）出现的次数，空前缀算一次
    pre = ans = 0
    for x in nums:
        pre = (pre + (x % modulo == k)) % modulo   # 到当前位置，满足条件的元素个数 mod modulo
        ans += seen[(pre - k) % modulo]            # 需要某个旧前缀 p 使得 (pre - p) % modulo == k
        seen[pre] += 1
    return ans
```

运行：`([3,2,4], 2, 1)` → `3`；`([3,1,9,6], 3, 0)` → `2`；`([5], 1, 0)` → `1`；`([1,1,1], 2, 1)` → `4`；`10^5` 个元素、`modulo = 1`、`k = 0` → `5000050000`（所有子数组）。

**复杂度。** 时间 `O(n)`；空间 `O(min(n, modulo))`（哈希表最多存 `modulo` 个余数）。

**易错点。**
- 把条件当成 `cnt == k`（没有取模）：`([1,1,1], 2, 1)` 得到 `3`，正确是 `4`：长度为 `3` 的子数组 `cnt = 3`，`3 % 2 == 1` 也满足。
- `(pre - k)` 不取模：`pre - k` 可能是负数，找不到对应的余数，`([1,1,1], 2, 1)` 同样得到 `3`。
- 漏掉空前缀 `seen[0] = 1`：以第一个元素开头的子数组全部被漏，`([3,2,4], 2, 1)` 得到 `0`，正确是 `3`。

**追问。**
- 条件改成区间元素之和满足同余（LC 974 和可被 K 整除、LC 523 连续的子数组和）：把 `0 / 1` 换成元素本身，其余同构。
- `modulo` 很小：哈希表换成长度为 `modulo` 的数组，更快；`modulo` 很大：保持字典。
- 要求子数组至少长度为 `2`（或其他长度限制）：延迟把前缀加入哈希表，保证 `l` 与 `r` 之间至少隔着所需长度。

**同模式。** LC 560 和为 K 的子数组、LC 974 和可被 K 整除的子数组、LC 523 连续的子数组和、LC 1248 统计「优美子数组」、LC 930 和相同的二元子数组。
