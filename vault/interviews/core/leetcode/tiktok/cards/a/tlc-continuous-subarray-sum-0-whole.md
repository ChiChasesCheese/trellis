## Q
**LC 523 连续的子数组和**｜Medium · CodeTop 国内累计 7 次 · 最近 2026-04-08（CodeTop）

给整数数组 `nums` 和整数 `k`，判断是否存在一个**好的子数组**：它是连续的，长度**至少为 2**，元素总和是 `k` 的倍数（0 也算 `k` 的倍数）。存在返回 `true`，否则 `false`。`1 <= nums.length <= 10^5`，`0 <= nums[i] <= 10^9`，`0 <= sum(nums[i]) <= 2^31 - 1`，`1 <= k <= 2^31 - 1`。例：`nums = [23,2,4,6,7], k = 6` → `true`（`[2,4]` 的和为 6）；`nums = [23,2,6,4,7], k = 13` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 前缀和对 `k` 取余：两个前缀的余数相同，等价于它们之间的子数组和是 `k` 的倍数。用字典记每个余数**第一次**出现的下标，再次遇到同余数且下标差 `>= 2` 就返回 `true`。`O(n)`。

**识别。** 「连续子数组」+「和满足条件」是前缀和（prefix sum）的信号；「和是 `k` 的倍数」把前缀和变成「前缀和对 `k` 取余」。`n = 10^5` 排除 `O(n^2)` 枚举（约 `5 * 10^9` 个子数组）。「长度至少 2」是附加约束，它决定哈希里要存**最早**的下标。

**推导。** 暴力：枚举所有 `(i, j)`，用前缀和 `O(1)` 取区间和再判断是否整除，`O(n^2)`。观察：区间和 `P[j] - P[i]` 是 `k` 的倍数，当且仅当 `P[j] % k == P[i] % k`。所以对每个 `j`，只需问「前面有没有一个同余数的前缀，且下标至少隔 2」。字典存「余数 → 最早下标」，最早的下标最容易满足间隔要求；初始放 `{0: -1}`，代表空前缀（让从开头开始的子数组也能被匹配）。

```python
def check_subarray_sum(nums: list[int], k: int) -> bool:
    first_seen: dict[int, int] = {0: -1}     # 余数 -> 最早出现的前缀下标；空前缀的余数是 0
    prefix = 0
    for i, x in enumerate(nums):
        prefix = (prefix + x) % k            # 到 nums[i] 为止的前缀和对 k 的余数
        j = first_seen.setdefault(prefix, i)  # 第一次出现就登记 i，否则返回最早的下标
        if i - j >= 2:                       # 子数组 nums[j+1 .. i] 的长度 = i - j
            return True
    return False
```

运行：`[23,2,4,6,7], 6` → `true`，`[23,2,6,4,7], 6` → `true`，`[23,2,6,4,7], 13` → `false`，`[5,0,0], 7` → `true`，`[6,1], 6` → `false`，`[0], 1` → `false`。

**复杂度。** 时间 `O(n)`：一趟扫描，字典操作 `O(1)`；空间 `O(min(n, k))`：字典里至多有 `min(n + 1, k)` 个余数。

**易错点。**
- 漏掉 `{0: -1}`：从开头开始的子数组匹配不上。`[2,4]`、`k = 6` 得到 `false`（正确 `true`）。
- 忘了「长度至少 2」：下标差为 1 就返回会把单个元素当成好子数组。`[6,1]`、`k = 6` 得到 `true`（正确 `false`，`6` 单独是倍数但长度为 1，`[6,1]` 的和 7 不是）。
- 每次都覆盖下标：丢掉了最早的位置。`[5,0,0]`、`k = 7` 得到 `false`（正确 `true`，`[0,0]` 的和是 0）。

**追问。**
- `k` 可以为 0：倍数只有 0，条件变成前缀和**相等**，取余那一行改成 `prefix = (prefix + x) % k if k else prefix + x`。
- 统计这样的子数组个数（LC 974 可被 K 整除的子数组）：字典换成计数，`ans += cnt[prefix]; cnt[prefix] += 1`，此时没有长度限制。
- 允许负数：Python 的 `%` 结果始终非负，直接可用；C++/Java 要写 `((x % k) + k) % k`。

**同模式。** LC 560 和为 K 的子数组、LC 974 和可被 K 整除的子数组、LC 525 连续数组、LC 437 路径总和 III。
