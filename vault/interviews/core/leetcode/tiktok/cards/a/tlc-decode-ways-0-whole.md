## Q
**LC 91 解码方法**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 20 次 · 最近 2026-09-21（CodeTop）

消息由字母 `A`-`Z` 编码成数字：`"1"` → `A`，`"2"` → `B`，…，`"26"` → `Z`。给只含数字的非空字符串 `s`（可能有前导零），求解码方法的总数，没有合法解码返回 `0`。`1 <= s.length <= 100`，答案保证在 32 位整数内。例：`"12"` → `2`（`AB` 或 `L`）；`"226"` → `3`（`BZ`、`VF`、`BBF`）；`"06"` → `0`（`"06"` 不是合法编码，只有 `"6"` 合法）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 线性 DP：`f[i]` 是解码前 `i` 个字符的方案数；最后一个字符单独成码（它不是 `'0'`）贡献 `f[i-1]`，最后两个字符合起来成码（在 `10`~`26` 之间）贡献 `f[i-2]`，两者相加；只依赖前两项，用两个变量滚动。`O(n)`。

**识别。** 「数有多少种拆分方式」+ 每一段有长度限制（1 位或 2 位）+ 段是否合法有明确的规则 → 线性计数 DP，和爬楼梯 / 斐波那契同构，只是每种走法多了合法性判断。`n <= 100` 说明暴力枚举的指数级方案不行，但 DP 极轻。

**推导。** 暴力：回溯，每个位置选 1 位或 2 位，不合法就剪枝，方案数可达斐波那契级（`"1" * 100` 有 `573147844013817084101` 种）→ 浪费：解码 `s[i:]` 的方案数被不同的前缀路径重复计算 → 状态 `f[i]`：前 `i` 个字符的方案数，`f[0] = 1`（空串一种）→ 转移分两种互斥情形：`s[i-1] != '0'` 时加 `f[i-1]`；`s[i-2:i]` 在 `10..26` 时加 `f[i-2]` → 只用前两项，两个变量滚动。

```python
def num_decodings(s: str) -> int:
    two_back, one_back = 0, 1              # 解码 s[:i-2] / s[:i-1] 的方案数；开始时 s[:0] 有 1 种（空串）
    for i, ch in enumerate(s):
        cur = 0
        if ch != "0":                      # 单独解码 s[i]：'1'..'9' 合法，'0' 不合法
            cur += one_back
        if i >= 1 and "10" <= s[i - 1:i + 1] <= "26":   # 两位一起：10..26 合法（两位字符串，字典序等于数值序）
            cur += two_back
        two_back, one_back = one_back, cur
    return one_back
```

运行：`"12"` → `2`，`"226"` → `3`，`"06"` → `0`，`"10"` → `1`，`"100"` → `0`，`"27"` → `1`，`"0"` → `0`，`"11106"` → `2`，`"2101"` → `1`，`"230"` → `0`；`"1" * 100` 的结果是 `573147844013817084101`（斐波那契数，超过 32 位，但 Python 整数不会溢出）。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 把 `"06"` 当成 `6`：两位判断只写 `int(s[i-1:i+1]) <= 26`，漏了下界 `10`。`"06"` 得到 `1`，`"100"` 得到 `1`，正确都是 `0`。
- 对 `'0'` 也允许单独解码：`cur = one_back` 无条件加。`"10"` 得到 `2`，`"0"` 得到 `1`，正确分别是 `1` 和 `0`；`'0'` 只能跟在 `1` 或 `2` 后面构成 `10`、`20`。
- `i == 0` 时没有"前一位"：访问 `s[-1:1]` 会得到空串或错位切片，要先判断 `i >= 1`。

**追问。**
- 自顶向下：`ways(i)` 表示解码 `s[i:]` 的方案数，加 `functools.cache`，思路更接近回溯。
- 字符里带通配符 `*`（LC 639）：每个位置的"单独成码 / 两位成码"变成对应的合法个数，结果对 `10^9 + 7` 取模。
- 列出所有解码（而不是计数）：回溯，每次选 1 位或 2 位，数量可能指数级。

**同模式。** LC 70 爬楼梯、LC 639 解码方法 II、LC 17 电话号码的字母组合、LC 131 分割回文串。
