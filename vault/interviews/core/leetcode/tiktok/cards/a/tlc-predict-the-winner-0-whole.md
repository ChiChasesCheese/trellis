## Q
**LC 486 预测赢家**｜Medium · CodeTop 国内累计 6 次 · 最近 2026-01-26（CodeTop）

整数数组 `nums`，玩家 1 和玩家 2 轮流取数，玩家 1 先手，初始分值都是 `0`。每个回合从数组的**任意一端**（`nums[0]` 或 `nums[-1]`）取一个数加到自己的得分上，该数从数组中移除，取完为止。双方都用最优策略使自己的分数最大化。玩家 1 的分数大于等于玩家 2 时（平局算玩家 1 赢）返回 `true`。`1 <= nums.length <= 20`，`0 <= nums[i] <= 10^7`。例：`[1,5,2]` → `false`（玩家 1 无论取 `1` 还是 `2`，最后得 `3`，玩家 2 得 `5`），`[1,5,233,7]` → `true`（玩家 1 先取 `1`，之后总能拿到 `233`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 零和博弈（zero-sum game）的区间 DP：`dp[i][j]` 是「只剩 `nums[i..j]`、轮到你取时，你的得分减对手得分的最大值」；你取左端得 `nums[i] - dp[i+1][j]`（取完轮到对手，对手的优势要扣掉），取右端得 `nums[j] - dp[i][j-1]`，两者取大；答案是 `dp[0][n-1] >= 0`。`O(n^2)`。

**识别。** 「两端取数 + 双方都最优 + 比较总分」是极小极大（minimax）博弈；状态只由剩下的区间 `[i, j]` 决定（轮到谁由区间长度的奇偶决定），典型的区间 DP。`n <= 20` 又说明 `O(2^n)` 的暴力搜索（约 `10^6`）也能过，面试里先说暴力，再优化到 `O(n^2)`。

**推导。** 暴力：递归模拟两人各自的得分，每步两种取法，`O(2^n)` → 子问题只与剩下的区间 `[i, j]` 有关，大量重复 → 把「各自得分」合并成「当前取数者的分数差」：对手接下来在 `[i+1, j]` 上能领先 `dp[i+1][j]`，所以我取左端的净收益是 `nums[i] - dp[i+1][j]`，一个函数就够了 → 按区间长度从小到大填 `n x n` 的完整二维表，`O(n^2)` 时间与空间。

```python
def predict_the_winner(nums: list[int]) -> bool:
    n = len(nums)
    # dp[i][j]：只剩 nums[i..j]、轮到你取时，你的得分 - 对手的得分 的最大值
    dp = [[0] * n for _ in range(n)]
    for i, x in enumerate(nums):
        dp[i][i] = x                            # 只剩一个数：只能取它
    for length in range(2, n + 1):              # 按区间长度从小到大填表
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = max(nums[i] - dp[i + 1][j], nums[j] - dp[i][j - 1])
    return dp[0][n - 1] >= 0                    # 差值 >= 0：先手不输（平局算先手赢）
```

运行：`[1,5,2]` → `False`，`[1,5,233,7]` → `True`，`[0]` → `True`，`[7]` → `True`，`[3,3]` → `True`，`[1,2]` → `True`；`[1,5,2]` 的 `dp[0][2] = -2`，所以先手少 `2` 分。

**复杂度。** 时间 `O(n^2)`：`n^2 / 2` 个区间，每个 `O(1)`；空间 `O(n^2)`（完整二维表）。

**易错点。**
- 贪心（每次取两端中较大的）：`[1,5,233,7]` 先手取 `7`，后手取 `233`，先手 `12` 分、后手 `234` 分，得到 `false`；正确是 `true`。
- 平局判成输（写成 `> 0`）：`[3,3]` 双方各 `3`，差为 `0`，应返回 `true`，写 `> 0` 会返回 `false`。
- 递推写成「我取左端 + `dp[i+1][j]`」（加而不是减）：表里变成区间总和，永远非负，`[1,5,2]` 误判先手赢，返回 `true`。

**追问。**
- 返回先手最高得分：`(sum(nums) + dp[0][n-1]) // 2`。
- 偶数个数时先手必不输（LC 877 石子游戏）：先手可以固定拿下全部奇数下标或全部偶数下标，两者总和必有一个不小于另一个，所以偶数长度直接返回 `True`。
- 空间可以压到 `O(n)`：见 Python 工具箱「DP 降维」。

**同模式。** LC 877 石子游戏、LC 375 猜数字大小 II、LC 1140 石子游戏 II、LC 312 戳气球、LC 516 最长回文子序列（区间 DP）。
