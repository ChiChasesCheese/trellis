## Q
**LC 204 计数质数**｜Medium · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 6 次 · 最近 2026-09（面试记录）

给非负整数 `n`，返回**严格小于** `n` 的质数的个数。`0 <= n <= 5 * 10^6`。例：`n = 10` → `4`（`2, 3, 5, 7`），`n = 0` → `0`，`n = 1` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 埃拉托斯特尼筛（Sieve of Eratosthenes）：开一个长度 `n` 的布尔数组，从小到大遇到仍标记为质数的 `i`，就把 `i*i, i*i+i, ...` 全部划掉；`i` 只需枚举到 `sqrt(n-1)`，最后数剩下的 1。`O(n log log n)`。

**识别。** 「小于 `n` 的所有质数个数」是**批量**判质数，不是判断单个数；`n` 到 `5 * 10^6` 说明数组装得下、`O(n sqrt n)` 的逐个试除不行。「找出范围内所有 X，X 由因子关系定义」→ 筛法。

**推导。** 暴力：对每个 `k < n` 试除到 `sqrt(k)`，`O(n sqrt n)`，`n = 5 * 10^6` 约 `10^10`。浪费在于每个数都独立判断，没有利用「合数是某个质数的倍数」。倒过来做：找到一个质数 `p`，把它的倍数一次性划掉。再削两处：倍数 `p*k`（`k < p`）已经被更小的质因子划过，所以从 `p*p` 开始；任何合数 `m < n` 都有不超过 `sqrt(m)` 的质因子，所以外层只要枚举到 `sqrt(n-1)`。划倍数用切片赋值一次完成。

```python
from math import isqrt

def count_primes(n: int) -> int:
    if n < 3:
        return 0                                     # n <= 2 时没有小于 n 的质数
    is_prime = bytearray([1]) * n                    # is_prime[i] == 1 表示 i 目前仍是质数候选
    is_prime[0] = is_prime[1] = 0
    for i in range(2, isqrt(n - 1) + 1):             # 只需筛到 sqrt(n-1)
        if is_prime[i]:
            # 从 i*i 开始：更小的倍数 i*k (k<i) 已被更小的质因子划掉
            is_prime[i * i::i] = bytes(len(range(i * i, n, i)))
    return sum(is_prime)
```

运行：`10` → `4`，`0` → `0`，`1` → `0`，`2` → `0`，`3` → `1`，`5 * 10**6` → `348513`（约 0.01 秒）。

**复杂度。** 时间 `O(n log log n)`：质数 `p` 划 `n/p` 次，`Σ n/p` 对质数求和是 `n log log n`；空间 `O(n)` 字节（`bytearray` 每格 1 字节，5MB）。

**易错点。**
- 外层上界写成 `isqrt(n)`（不加 1，也没用 `n-1`）：`n = 10` 时 `range(2, 3)` 只处理 `2`，`9` 没被 `3` 划掉，得到 `5`，正确 `4`。
- 「小于 `n`」不含 `n` 本身：数组长度是 `n`，不是 `n + 1`；`n = 2` 要返回 `0`。
- `[True] * n` 用 8 字节一格的列表，`5 * 10^6` 个元素约 40MB，`bytearray` 只要 5MB，切片赋值也快得多。

**追问。**
- 只存奇数，内存和时间都减半。
- 内存装不下（`n` 到 `10^9`）：分段筛，先筛出 `sqrt(n)` 以内的质数，再分块划。
- 判断**单个**很大的数是不是质数：不筛，用试除到 `sqrt` 或 Miller-Rabin。

**同模式。** LC 263 / 264 丑数（按因子生成）、LC 1175 质数排列、LC 762 二进制表示中质数个数的数字（先筛后查表）。
