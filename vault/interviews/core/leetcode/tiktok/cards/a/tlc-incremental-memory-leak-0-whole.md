## Q
**LC 1860 增长的内存泄露**｜Medium · LC TikTok 热度 62/100

给两个整数 `memory1` 和 `memory2`，分别表示两个内存条剩余可用内存的位数。一个程序每秒消耗递增的内存：在第 `i` 秒（从 `1` 开始），有 `i` 位内存被分配给**剩余内存较多**的那个内存条（两者一样多时分给第一个）。如果两个内存条剩余内存都不足 `i` 位，程序意外退出。返回数组 `[crashTime, memory1crash, memory2crash]`，其中 `crashTime` 是程序退出的时刻（秒），后两项是两个内存条最后剩余的位数。`0 <= memory1, memory2 <= 2^31 - 1`。例：`memory1 = 2, memory2 = 2` → `[3, 1, 0]`（第 1 秒内存条 1 被占 1 位；第 2 秒内存条 2 被占 2 位；第 3 秒两者剩 1 和 0，都不足 3 位，退出）；`memory1 = 8, memory2 = 11` → `[6, 0, 4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 直接模拟：从 `i = 1` 开始，只要两个内存条里较大的剩余量不小于 `i`，就把 `i` 分给较大的那个（相等分给第一个），然后 `i` 加一；循环停下时的 `i` 就是崩溃时刻。循环次数约 `sqrt(2 · (memory1 + memory2))`，最多约 `9.3` 万次。

**识别。** 题面把规则完整写出来了，且“每秒一步、有明确的停止条件”→ 模拟（simulation）。要判断模拟会不会超时：每秒消耗的位数 `i` 一直增加，总消耗 `1 + 2 + ... + t ≈ t^2 / 2` 不会超过两个内存条的总量，所以步数 `t` 只有 `sqrt(2 · 总量)`，总量最大约 `2^32`，约 `9.3` 万步，远没有到 `2^31` 步。

**推导。** 暴力就是模拟本身，这里它已经是最优量级：浪费不存在。关键只在两个细节：判断是否崩溃的条件，以及平局时分给谁。崩溃的条件是“两个都不足 `i`”，等价于“较大的那个都不足 `i`”，所以只需要看 `max(memory1, memory2) >= i`；如果较大的那个够，就分给较大的（平局分给第一个）。更快的做法是分段用公式（先让较大者降到与较小者相同，再交替），但需要仔细处理平局和奇偶，不是必要的。

```python
def mem_leak(memory1: int, memory2: int) -> list[int]:
    second = 1                                 # 当前要分配的位数，也是秒数
    while max(memory1, memory2) >= second:     # 至少有一条放得下，程序才没崩
        if memory1 >= memory2:                 # 相等时给第一条，所以用 >=
            memory1 -= second
        else:
            memory2 -= second
        second += 1
    return [second, memory1, memory2]
```

运行：`(2, 2)` → `[3, 1, 0]`，`(8, 11)` → `[6, 0, 4]`，`(0, 0)` → `[1, 0, 0]`，`(1, 0)` → `[2, 0, 0]`，`(2^31 - 1, 2^31 - 1)` → `[92681, 88047, 41707]`，约 `3 ms`。

**复杂度。** 时间 `O(sqrt(memory1 + memory2))`；空间 `O(1)`。

**易错点。**
- 平局写成严格大于：`if memory1 > memory2` 先分给第一个的条件丢了，相等时会分给第二个。`(2, 2)` 得到 `[3, 0, 1]`，正确是 `[3, 1, 0]`。
- 崩溃条件写成“某一个不足”而不是“两个都不足”：较小的那个放不下不代表崩溃，较大的可能还放得下。
- 返回的时刻是 `second`（第一个失败的秒数），不是最后成功的秒数 `second - 1`：示例 1 的 `3` 是崩溃时刻。

**追问。**
- `memory` 范围再大（比如 `10^18`）：步数是 `sqrt(10^18) = 10^9` 量级，模拟不够用，需要公式：先让较大者连续被分配，直到它降到不大于较小者，用 `i(i+1)/2` 的等差和和 `math.isqrt` 找出这一段的长度；之后两者相差很小，交替被分配，再按奇偶规律用公式推进。
- 返回每一秒分配给谁：循环里把 `1` 或 `2` 追加进列表，输出长度是 `second - 1`。
- 三个或更多内存条：用 `heapq`（最大堆，存负数）取剩余最多的，`O(t log k)`。

**同模式。** LC 1535 找出数组游戏的赢家、LC 1823 找出游戏的获胜者、LC 1344 时钟指针的夹角、LC 1488 避免洪水泛滥、LC 2073 买票需要的时间。
