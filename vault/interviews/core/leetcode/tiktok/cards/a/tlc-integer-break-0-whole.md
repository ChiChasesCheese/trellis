## Q
**LC 343 整数拆分**｜Medium · CodeTop 国内累计 9 次 · 最近 2026-06-04（CodeTop）

给正整数 `n`，把它拆成 `k` 个**正整数**的和（`k >= 2`），使这些整数的乘积最大，返回最大乘积。`2 <= n <= 58`。例：`n = 2` → `1`（`1 + 1`）；`n = 10` → `36`（`3 + 3 + 4`，`3 × 3 × 4 = 36`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一维 DP：`dp[i]` 是把 `i` 拆成至少两份的最大乘积；先切下第一块 `j`，剩下的 `i - j` 要么不再拆（乘积 `j * (i - j)`），要么继续拆（乘积 `j * dp[i - j]`），取所有 `j` 的最大值。`O(n^2)`。

**识别。** 「把一个数拆成若干份，求某个目标最大」是**拆分型 DP**：整体的最优由「第一块 + 剩余部分的最优」组成，剩余部分是同类子问题。`n <= 58` 很小，`O(n^2)` 足够；最优解的结构（尽量拆成 3）也能推出来，放在追问。

**推导。** 暴力：枚举所有拆分方式（整数划分），数量随 `n` 指数增长。浪费：拆 `10` 时「`7` 怎么拆最好」被反复重算。洞察：`i` 的最优拆分，把第一块切掉后，剩余 `i - j` 的拆分也一定是 `i - j` 的最优拆分，否则换成更优的会让整体更大。所以 `dp[i] = max over j of max(j * (i - j), j * dp[i - j])`。两项缺一不可：`i - j` 可以整块留着当因子，也可以继续拆。

```python
def integer_break(n: int) -> int:
    dp = [0] * (n + 1)                 # dp[i]：把 i 拆成至少 2 个正整数的最大乘积
    for i in range(2, n + 1):
        for j in range(1, i):          # 先切下一块 j，剩下的 i - j 可以不再拆，也可以继续拆
            dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
    return dp[n]
```

运行：`integer_break(2)` → `1`，`integer_break(3)` → `2`，`integer_break(4)` → `4`，`integer_break(10)` → `36`，`integer_break(58)` → `1549681956`。

**复杂度。** 时间 `O(n^2)`：外层 `i`、内层 `j` 各至多 `n` 次；空间 `O(n)`。

**易错点。**
- 只写 `j * (i - j)`（只切两块）：`n = 10` 得 `25`，正确 `36`（`3 × 3 × 4`）。
- 只写 `j * dp[i - j]`：`dp` 全是 `0`，`n = 2` 得 `0`，正确 `1`。`dp[1]` 没有意义（`1` 不能拆成至少两份），所以「不再拆」那一项不可省。
- 把 `dp[i]` 定义成「`i` 的最大乘积且允许不拆」会让 `integer_break(2)` 和 `integer_break(3)` 返回 `2`、`3`；题面要求 `k >= 2`，正确是 `1`、`2`。

**追问。**
- 数学解 `O(log n)` 甚至 `O(1)`：尽量拆成 `3`。`n % 3 == 0` 取 `3^(n/3)`；余 `1` 取 `3^(n//3 - 1) * 4`；余 `2` 取 `3^(n//3) * 2`；`n <= 3` 直接 `n - 1`。
- `n` 到 `10^9` 并对 `10^9 + 7` 取模：用上面的数学解加 `pow(3, q, MOD)`。
- 要输出拆分方案：DP 里额外记下取到最大值的 `j`，从 `n` 往回还原。

**同模式。** LC 279 完全平方数、LC 322 零钱兑换、LC 139 单词拆分、LC 1808 好因子的最大数目（同样是拆成 3）。
