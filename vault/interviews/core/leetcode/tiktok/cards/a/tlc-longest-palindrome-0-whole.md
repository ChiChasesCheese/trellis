## Q
**LC 409 最长回文串**｜Easy · CodeTop 国内累计 3 次 · 最近 2026-01-15（CodeTop）

字符串 `s` 只含大写和小写英文字母。用 `s` 里的字母（每个字母最多用一次，顺序可任意重排）构造回文串，返回最长回文串的长度。**区分大小写**：`"Aa"` 不是回文。`1 <= s.length <= 2000`。例：`"abccccdd"` → `7`（如 `"dccaccd"`）；`"a"` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回文串是「成对的字母左右对称 + 正中间至多一个单独的字母」，所以每种字母贡献 `次数 // 2 * 2`，只要还有字母没用上，就再加 1 放中间。`O(n)`。

**识别。** 「用这些字母构造、顺序可重排」说明位置无关，只有**每种字母的个数**有用 → 计数（`Counter`）。回文的结构是对称的：除了中心，每个字母都必须成对出现。

**推导。** 暴力：枚举所有子集再判断能否排成回文，`O(2^n)`。观察到能否排成回文只取决于计数：至多一种字母出现奇数次。于是贪心：每种字母尽量成对使用（偶数全用，奇数用到 `v - 1`），所有对数之和就是两侧的长度；只要有任何一种字母出现奇数次，就多拿一个放中间。

```python
from collections import Counter


def longest_palindrome(s: str) -> int:
    pairs = sum(v // 2 * 2 for v in Counter(s).values())   # 每种字母能成对放在两侧的部分
    return pairs + (pairs < len(s))                          # 还有剩下的字母，就放一个在正中间
```

运行：`"abccccdd"` → `7`，`"a"` → `1`，`"Aa"` → `1`，`"aaabbbcc"` → `7`，`"abc"` → `1`。

**复杂度。** 时间 `O(n)`：计数一遍，再扫最多 52 种字母；空间 `O(Σ)`，`Σ = 52`。

**易错点。**
- 「偶数次全加，奇数次只取最多的那一种」：`"aaabbbcc"` 会错成 `2 + 3 = 5`（正确 `7`，`a`、`b` 各用 2 个，再放 1 个在中间）。
- 每个奇数次的字母都加 1：`"abc"` 会错成 `3`（正确 `1`，中间只能放一个）。

**追问。**
- 返回回文串本身：拼出一半 `half`，中间字母 `mid`，答案 `half + mid + half[::-1]`。
- 只判断能否重排成回文（LC 266）：奇数次的字母种数 `<= 1`。
- 不区分大小写：先 `s.lower()` 再计数。

**同模式。** LC 266 回文排列、LC 2131 连接两字母单词得到的最长回文串、LC 1400 构造 K 个回文字符串。
