## Q
**LC 430 扁平化多级双向链表**｜Medium · TikTok 高频

给一个双向链表，每个节点有 `val`、`prev`、`next`，还有一个 `child` 指针；`child` 可以指向另一条独立的双向链表，子链表的节点同样可以有自己的 `child`，层层嵌套。把整个结构扁平化成单层双向链表：带子链表的节点 `curr` 的子链表必须出现在 `curr` 之后、`curr.next` 之前；所有 `child` 置为 `null`；返回扁平链表的头。节点数不超过 `1000`，`1 <= Node.val <= 10^5`，输入可能是空链表。例：第一层 `1-2-3-4-5-6`，`3` 的子链表是 `7-8-9-10`，`8` 的子链表是 `11-12` → `[1,2,3,7,8,11,12,9,10,4,5,6]`；`1-2` 里 `1` 的子链表是 `3` → `[1,3,2]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 单指针从头往后走，遇到带 `child` 的节点，就把整条子链表一次性插到它和它的后继之间（找到子链表的尾巴，接上原来的后继，再改 4 个指针）；走到刚接进来的子链表头继续，嵌套自动展开。`O(n)` 时间，`O(1)` 空间。

**识别。** 「子链表夹在 `curr` 与 `curr.next` 之间」就是先序顺序（当前 → `child` → `next`）；「返回头、所有 `child` 置空」说明要原地改指针而不是新建节点；节点数 `<= 1000` 让递归也能过，但面试看的是 `O(n)` 和 `O(1)` 空间。

**推导。** 暴力：递归先序把所有节点收进数组，再按顺序重连 `prev`/`next`，`O(n)` 时间、`O(n)` 空间 → 浪费：数组只是为了记住「子链表走完后该接谁」，而这个答案就是 `curr.next`，当场就知道 → 洞察：子链表整条插入只需要它的尾巴；尾巴沿 `next` 一直走就能找到（它的下一级还没展开，`next` 链只含这一层）→ 每一层的尾巴只找一次，每个节点最多被「找尾巴」和主循环各走一次，`O(n)`。

```python
def flatten(head: 'Node | None') -> 'Node | None':
    cur = head
    while cur:
        if cur.child:
            tail = cur.child
            while tail.next:                   # 子链表这一层的尾巴（它的下一级还没展开，next 链只有这一层）
                tail = tail.next
            tail.next = cur.next               # 子链表的尾巴接上 cur 原来的后继
            if cur.next:
                cur.next.prev = tail
            cur.next = cur.child               # cur 直接指向子链表的头
            cur.child.prev = cur
            cur.child = None                   # 子指针必须清空
        cur = cur.next                         # 往后走：下一个就是刚接进来的子链表的头
    return head
```

运行：示例 1 → `[1, 2, 3, 7, 8, 11, 12, 9, 10, 4, 5, 6]`，示例 2 → `[1, 3, 2]`，空链表 → `None`；1000 个节点每个只有 `child`（嵌套 1000 层）→ 展平后 1000 个节点，`prev` 全部一致。

**复杂度。** 时间 `O(n)`；空间 `O(1)`，不用递归也不用栈。

**易错点。**
- 必须先把子链表尾巴接到 `cur.next`，再改 `cur.next`。若先写 `cur.next = cur.child`，原后继丢失，示例 1 会得到 `[1,2,3,7,8,11,12]`（少了 `9,10,4,5,6`）。
- 漏掉 `cur.child = None` 或 `cur.child.prev = cur`：前者违反题意，后者让从尾往头走的结果出错。
- 找尾巴用 `while tail.next`，不是 `while tail`；后者走过头得到 `None`。

**追问。**
- 递归 DFS（返回展平后的尾节点）：写法直观，但嵌套 1000 层会触发 `RecursionError`；迭代版没有这个风险。
- 用显式栈：遇到 `child` 先压入 `cur.next`，走到末尾再弹出接回，`O(n)` 时间、`O(嵌套深度)` 空间。
- 展平的逆操作：展平丢掉了层次，必须在展平时另存每个子链表的头和长度。
