## Q
**LC 874 模拟行走机器人**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-03-07（CodeTop）

机器人在无限大的 XY 网格上，从 `(0, 0)` 出发，面向北方（北是 `+Y`，东是 `+X`）。命令 `commands` 有三种：`-2` 左转 `90` 度，`-1` 右转 `90` 度，`1 <= x <= 9` 向前移动 `x` 个单位。网格上有一些障碍物 `obstacles[i] = (xi, yi)`；机器人无法走到障碍物上，会停在障碍物前一格，并继续执行下一条命令。返回机器人在行走过程中距离原点的**最大欧氏距离的平方**。原点处可能有障碍物。`1 <= commands.length <= 10^4`，`0 <= obstacles.length <= 10^4`，`-3 * 10^4 <= xi, yi <= 3 * 10^4`，答案保证小于 `2^31`。例：`commands = [4,-1,3]`，`obstacles = []` → `25`（走到 `(3, 4)`）；`commands = [4,-1,4,-2,4]`，`obstacles = [[2,4]]` → `65`（停在 `(1, 4)` 后走到 `(1, 8)`）；`commands = [6,-1,-1,6]`，`obstacles = []` → `36`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 直接模拟：用方向表 `dirs` 和下标 `d` 表示朝向（右转 `d + 1`，左转 `d - 1`，模 `4`），障碍物放进集合做 `O(1)` 查询，前进命令一格一格走、下一格是障碍就停，每条前进命令结束后更新最大距离平方。

**识别。** 「按命令逐步移动 + 障碍」是纯模拟，考的是状态设计：朝向用 `0..3` 的下标加方向向量表，比一堆 `if` 判断东南西北干净；障碍判断必须 `O(1)`。每条命令最多走 `9` 格，总步数不超过 `9 * 10^4`，一格一格走完全可行。

**推导。** 暴力：每走一步在障碍列表里线性查找，`9 * 10^4 * 10^4 = 9 * 10^8` 次比较，超时 → 把障碍放进集合，查询 `O(1)`；障碍坐标是列表不可哈希，先转成元组 → 朝向用方向向量表，`d = (d + 1) % 4` 右转 → 一格一格走，下一格是障碍就 `break`；距离在每条前进命令结束时更新（直线上离原点最远的点一定是线段端点，且被挡住时端点就是停下的位置）。

```python
def robot_sim(commands: list[int], obstacles: list[list[int]]) -> int:
    blocked = set(map(tuple, obstacles))        # 列表不可哈希，先转成元组放进集合：O(1) 判断障碍
    dirs = ((0, 1), (1, 0), (0, -1), (-1, 0))   # 北、东、南、西：右转 = 下标 +1，左转 = 下标 -1
    x = y = d = best = 0
    for cmd in commands:
        if cmd == -1:
            d = (d + 1) % 4
        elif cmd == -2:
            d = (d - 1) % 4
        else:
            dx, dy = dirs[d]
            for _ in range(cmd):                # 一格一格走，下一格是障碍就停
                if (x + dx, y + dy) in blocked:
                    break
                x, y = x + dx, y + dy
            best = max(best, x * x + y * y)     # 每条前进命令结束时更新最远距离
    return best
```

运行：示例 1 → `25`，示例 2 → `65`，示例 3 → `36`；`[-2,-1,5]`、障碍 `[[0,0]]`（原点有障碍，机器人仍能离开）→ `25`；`[1,1,1]`、障碍 `[[0,1]]`（第一步就被挡）→ `0`；`10^4` 条随机命令加 `10^4` 个随机障碍也能瞬间算完。

**复杂度。** 时间 `O(C * 9 + m)`：`C` 条命令每条至多走 `9` 格，`m` 个障碍建集合；空间 `O(m)`。

**易错点。**
- 只在最后一个位置算距离：`[6,-1,-1,6]` 走到 `(0, 6)` 再回到原点，得到 `0`，正确是 `36`；最大值要在过程中取。
- 一次跳 `x` 格、只检查终点是否是障碍：示例 2 里向东一次跳 `4` 格落在 `(4, 4)`（终点不是障碍），越过了 `(2, 4)`，最后到 `(4, 8)`，得到 `80`，正确是 `65`。
- 把 `obstacles` 的元素直接放进 `set`：元素是列表，抛 `TypeError: unhashable type: 'list'`，要先 `map(tuple, ...)`。

**追问。**
- 每条前进命令的步数很大（如 `10^9`）：不能一格一格走，把障碍按行、列分组并排序，用二分找到前进方向上最近的障碍，一次跳到它前面一格。
- 障碍坐标范围很大时集合里的元组内存开销大：可以把 `(x, y)` 编码成一个整数。
- 要输出整条路径：每走一格把坐标追加到列表。

**同模式。** LC 657 机器人能否返回原点、LC 489 扫地机器人、LC 54 螺旋矩阵、LC 59 螺旋矩阵 II、LC 2069 模拟行走机器人 II。
