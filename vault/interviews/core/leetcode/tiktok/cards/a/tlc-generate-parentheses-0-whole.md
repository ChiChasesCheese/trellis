## Q
**LC 22 括号生成**｜Medium · TikTok·字节 高频

数字 `n` 代表生成括号的对数，设计一个函数，生成所有可能的并且**有效的**括号组合。`1 <= n <= 8`。例：`n = 3` → `["((()))","(()())","(())()","()(())","()()()"]`；`n = 1` → `["()"]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回溯（backtracking）：一位一位地放括号，记录已放的左括号数 `opened` 和右括号数 `closed`。`opened < n` 时可以放 `"("`；`closed < opened` 时才可以放 `")"`；放满 `2n` 位就是一个答案。放置规则本身保证有效，不会生成无效串。

**识别。** 「生成所有……有效的……」→ 回溯加剪枝。有效括号串的充要条件是：任意前缀里左括号不少于右括号，且左右括号总数都是 `n`。这个条件可以直接变成放置规则，搜索树里没有废枝。`n <= 8`，结果数是卡特兰数（Catalan）`C(8) = 1430`，输出规模很小。

**推导。** 暴力：枚举所有 `2^(2n)` 个由 `(` 和 `)` 组成的串（`n = 8` 时 `65536` 个），逐个判断有效。浪费：大量串的前缀早就无效（右括号多于左括号），却还要把后面全部展开。洞察：有效当且仅当每个前缀都满足 `右 <= 左`，并且左括号总数是 `n`。所以放置时就保证：左括号用到 `n` 个为止，右括号只能闭合已经放出的、还没闭合的左括号（`closed < opened`）。这样每个叶子都是有效串，叶子数恰是卡特兰数 `C(2n, n) / (n + 1)`。

```python
def generate_parenthesis(n: int) -> list[str]:
    res: list[str] = []
    path: list[str] = []

    def dfs(opened: int, closed: int) -> None:
        if len(path) == 2 * n:
            res.append("".join(path))
            return
        if opened < n:                  # 左括号还有余量：随时可以放
            path.append("(")
            dfs(opened + 1, closed)
            path.pop()
        if closed < opened:             # 右括号只能闭合已有的左括号
            path.append(")")
            dfs(opened, closed + 1)
            path.pop()

    dfs(0, 0)
    return res
```

运行：`n = 3` → `['((()))', '(()())', '(())()', '()(())', '()()()']`，`n = 1` → `['()']`，`n = 1..8` 的结果个数依次为 `1, 2, 5, 14, 42, 132, 429, 1430`。

**复杂度。** 时间 `O(n · C(n))`，`C(n)` 是卡特兰数，每个结果拼接字符串 `O(n)`；空间 `O(n)`（递归深度 `2n`，不含输出）。

**易错点。**
- 右括号的条件写成 `closed < n`：只限制了右括号总数，没有保证前缀合法。`n = 2` 会生成 `6` 个串，包括 `"())("`、`")(()"`，正确只有 `["(())", "()()"]`。
- 漏掉回溯时的 `path.pop()`：`path` 越来越长，到达不了恰好 `2n` 位的条件，结果缺失。
- 先放右括号再放左括号：结果仍是正确的集合，但顺序不同，与题目示例不一致；先放 `"("` 得到字典序。

**追问。**
- 只要个数：卡特兰数 `math.comb(2 * n, n) // (n + 1)`，`O(n)`；或递推 `C(n) = Σ C(i) · C(n - 1 - i)`。
- 另一种生成法（闭包数）：任何有效串都可以写成 `"(" + A + ")" + B`，`A` 是 `k` 对、`B` 是 `n - 1 - k` 对的有效串，递归组合，同样得到全部结果。
- 括号有三种类型，或者要求输出第 `k` 个：回溯时记录栈里的未闭合类型；第 `k` 个可以用卡特兰数分块跳过，不必全部生成。

**同模式。** LC 20 有效的括号、LC 17 电话号码的字母组合、LC 46 全排列、LC 78 子集、LC 301 删除无效的括号、LC 241 为运算表达式设计优先级。
