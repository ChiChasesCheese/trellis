## Q
**LC 402 移掉 K 位数字**｜Medium · LC TikTok 热度 41/100 · CodeTop 国内累计 36 次 · 最近 2025-09-24（CodeTop）

给以字符串表示的非负整数 `num` 和整数 `k`，从中移除 `k` 位数字，使剩下的数字最小，以字符串形式返回（结果不能有前导零；全部移掉时返回 `"0"`）。`1 <= k <= num.length <= 10^5`，`num` 仅由数字组成，除 `0` 本身外不含前导零。例：`num = "1432219", k = 3` → `"1219"`（移掉 `4, 3, 2`）；`num = "10200", k = 1` → `"200"`（移掉首位 `1`，去掉前导零）；`num = "10", k = 2` → `"0"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 单调栈：从左到右扫描每个数字，只要栈顶比当前数字大、且还有删除额度，就弹出栈顶（删掉它）；当前数字入栈；扫完后若额度没用完，从末尾删；最后去掉前导零，空串返回 `"0"`。`O(n)`。

**识别。** 「删掉 `k` 位，剩下最小」且结果位数固定，比较数大小就是比较字符串字典序：高位更小优先。「前面的数字比后面的大，就删前面的」是贪心，用栈把"回头删"摊成一次扫描，是单调栈的标准场景。`n = 10^5` 要求 `O(n)`。

**推导。** 暴力：枚举保留哪些位，`C(n, k)` 种。改进：重复 `k` 次，每次删掉第一个"比后一位大"的数字（找不到就删最后一位），`O(nk)`。浪费：每次都从头找下降位置。洞察：栈里保持非递减，新来的数字比栈顶小，说明栈顶就是"第一个下降位置的前一位"，立刻删它；删完新栈顶可能仍大于新数字，继续弹。每个数字最多入栈、出栈各一次。

```python
def remove_kdigits(num: str, k: int) -> str:
    stack: list[str] = []
    for d in num:
        while k and stack and stack[-1] > d:     # 前面的数字比当前大：删掉它，高位变小
            stack.pop()
            k -= 1
        stack.append(d)
    stack = stack[: len(stack) - k]              # 还没删够说明整体非递减，从末尾删；不能写 [:-k]，k=0 会清空
    return "".join(stack).lstrip("0") or "0"     # 去前导零；全删光时返回 "0"
```

**运行。** `("1432219", 3)` → `"1219"`；`("10200", 1)` → `"200"`；`("10", 2)` → `"0"`；`("112", 1)` → `"11"`；`("9", 1)` → `"0"`；`("12345", 2)` → `"123"`；`("100", 1)` → `"0"`。

**复杂度。** 时间 `O(n)`：每个数字入栈一次、出栈至多一次；空间 `O(n)`。

**易错点。**
- 末尾截断写成 `stack[:-k]`：`k` 被用完（变成 `0`）时，`[:-0]` 是空列表，`("1432219", 3)` 会返回 `"0"`，正确是 `"1219"`。要写 `stack[: len(stack) - k]`。
- 栈顶与当前数字相等也弹出（`>=`）：`("112", 1)` 得 `"12"`，正确是 `"11"`；相等时删谁结果相同，却白白浪费了额度。
- 不去前导零：`("10200", 1)` 得 `"0200"`，正确是 `"200"`；删光时 `""` 要变成 `"0"`。

**追问。**
- 反过来保留 `m` 位使数字**最大**：条件改成 `stack[-1] < d`，额度是 `len(num) - m`，最后取前 `m` 位。
- 去除重复字母使字典序最小（LC 316 / 1081）：同样的单调栈，再加"这个字母后面还会出现"和"已在栈里"两个条件。
- 数字很长：全程用字符串和列表，不要转成整数。

**同模式。** LC 316 去除重复字母、LC 1673 找出最具竞争力的子序列、LC 321 拼接最大数、LC 496 下一个更大元素 I、LC 739 每日温度。
