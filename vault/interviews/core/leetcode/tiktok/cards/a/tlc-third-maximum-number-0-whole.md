## Q
**LC 414 第三大的数**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-01-20（CodeTop）

给整数数组 `nums`，返回其中**第三大的数**；如果不存在，返回最大的数。「第三大」指在所有**不同**数字中排第三。`1 <= nums.length <= 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。进阶：`O(n)` 时间。例：`[3,2,1]` → `1`；`[1,2]` → `2`（第三大不存在，返回最大）；`[2,2,3,1]` → `1`（两个 `2` 并列第二，第三大是 `1`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一遍扫描，维护「目前见过的最大的至多 3 个**不同**值」：重复值跳过，新值加入后只留前 3 名；最后有 3 个就返回第三个，否则返回最大。`O(n)` 时间、`O(1)` 空间。

**识别。** 「第 k 大」+ `k` 是很小的常数 3 → 不用排序，扫描时维护一个大小为 `k` 的候选集合（Top-K 的退化形态）。「不同数字中」→ 去重是题眼。值域包含 `-2^31` → 不能用 `-2^31` 当「还没有值」的哨兵。

**推导。** 直接做法：去重后排序取第三个，`O(n log n)`。浪费在于只需要前三名，却把所有数排好了序。扫描时只保留前三名：每来一个数，若已在前三名里就跳过（去重），否则插入并挤掉第四名。前三名最多 4 个元素，每步排序是常数时间，总共 `O(n)`。

```python
def third_max(nums: list[int]) -> int:
    top: list[int] = []                        # 目前见过的最大的至多 3 个不同的值，降序
    for x in nums:
        if x in top:                           # 重复的数不占名次
            continue
        top.append(x)
        top.sort(reverse=True)                 # 最多 4 个元素，排序是 O(1)
        del top[3:]                            # 只留前 3 名
    return top[2] if len(top) == 3 else top[0]
```

运行：`[3,2,1]` → `1`，`[1,2]` → `2`，`[2,2,3,1]` → `1`，`[1]` → `1`，`[1,1,2]` → `2`，`[1,2,-2147483648]` → `-2147483648`。

**复杂度。** 时间 `O(n)`：每个元素做 `O(1)` 次比较和大小至多 4 的排序；空间 `O(1)`。

**易错点。**
- 不去重直接排序取第三个：`[2,2,3,1]` 降序是 `[3,2,2,1]`，返回 `2`（正确 `1`）。
- 三个变量用 `-2^31` 作初值表示「空」：`[1,2,-2147483648]` 的第三大恰好是 `-2^31`，被误判为「不存在」，返回 `2`（正确 `-2147483648`）。用 `None` 或 `float('-inf')` 表示空。
- 「不存在」时返回的是**最大值**，不是第二大，也不是 `-1`。

**追问。**
- 三个变量的经典写法：`x > first` 时三者依次下移，`x > second` 时后两者下移，`x > third` 时只替换第三；遇到与任一相等的值跳过。
- 推广到第 `k` 大不同值：大小为 `k` 的最小堆加一个集合去重，`O(n log k)`。
- 不追求面试考点时，`heapq.nlargest(3, set(nums))` 一行搞定，`O(n)`。
