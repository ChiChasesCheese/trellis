## Q
**LC 188 买卖股票的最佳时机 IV**｜Hard · TikTok 高频

给整数数组 `prices`（`prices[i]` 是某股票第 `i` 天的价格）和整数 `k`，最多完成 `k` 笔交易（一笔交易是一次买入加一次卖出），不能同时参与多笔交易（再次买入前必须先卖出手上的股票），求最大利润。`1 <= k <= 100`，`1 <= len(prices) <= 1000`，`0 <= prices[i] <= 1000`。例：`k = 2`，`prices = [2,4,1]` → `2`（第 1 天买、第 2 天卖）；`k = 2`，`prices = [3,2,6,5,0,3]` → `7`（`2` 买 `6` 卖赚 `4`，`0` 买 `3` 卖赚 `3`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 状态机动态规划：`buy[j]` 表示“正在持有第 `j` 笔交易买入的股票”时的最大收益，`sell[j]` 表示“最多完成 `j` 笔交易、手上没货”时的最大收益；每天依次更新 `buy[j] = max(buy[j], sell[j-1] - p)`、`sell[j] = max(sell[j], buy[j] + p)`，答案是 `sell[k]`。当 `k >= n // 2` 时交易次数实际不受限，直接累加所有正的相邻价差。`O(n·k)` 时间、`O(k)` 空间。

**识别。** 「最多 `k` 笔交易、不能同时持有多笔」是带交易次数的买卖股票 DP（系列题 LC 121、122、123、188）。状态要同时包含「第几笔交易」和「手上有没有货」。`k` 只有 `100`、`n` 只有 `1000`，`O(n·k)` 只有 `10^5`。当 `k` 足够大时，限制失效，退化成 LC 122。

**推导。** 暴力：枚举所有最多 `k` 段互不相交的买卖区间，指数级。第一步：二维 DP `dp[i][j][hold]`，`i` 天、`j` 笔、是否持有，`O(n·k)` 状态、每个 `O(1)` 转移，空间 `O(n·k)`。浪费：第 `i` 天的状态只依赖第 `i-1` 天（和同一天里的前一笔），不需要保存所有天。洞察：把「持有」和「不持有」拆成 `buy[j]`、`sell[j]` 两个数组，只保留当前天，空间压成 `O(k)`。同一天先更新 `buy[j]` 再更新 `sell[j]`，最多相当于当天买当天卖（利润 `0`），不会出错。

```python
from itertools import pairwise
from math import inf


def max_profit(k: int, prices: list[int]) -> int:
    if k >= len(prices) // 2:                    # 交易次数不受限：只要上涨就赚，所有正的相邻差之和
        return sum(max(b - a, 0) for a, b in pairwise(prices))
    buy = [-inf] * (k + 1)                       # buy[j]：完成 j-1 笔后，第 j 笔已买入未卖时的最大收益
    sell = [0] * (k + 1)                         # sell[j]：最多完成 j 笔交易的最大收益
    for p in prices:
        for j in range(1, k + 1):
            buy[j] = max(buy[j], sell[j - 1] - p)
            sell[j] = max(sell[j], buy[j] + p)
    return sell[k]
```

运行：`(2, [2,4,1])` → `2`，`(2, [3,2,6,5,0,3])` → `7`，`(1, [3,2,6,5,0,3])` → `4`，`(3, [3,2,6,5,0,3])` → `7`，`(1, [1])` → `0`，`(100, [1,2,3,4,5])` → `4`（走快捷分支），`(2, [7,6,4,3,1])` → `0`；`k = 100`、`n = 1000` 的随机价格几毫秒算完。

**复杂度。** 时间 `O(n·min(k, n // 2))`，空间 `O(k)`。

**易错点。**
- `buy` 初值写成 `0`：相当于免费拿到一只股票，`(2, [3,2,6,5,0,3])` 得到 `9`，正确是 `7`；`buy` 要初始化成负无穷（`-inf`）。
- 状态转移用错下标：`buy[j]` 应当从 `sell[j-1]` 转移（上一笔交易已完成），写成 `sell[j]` 就等于卖出后可以不增加笔数地再次买入，交易次数的限制失效：`(1, [3,2,6,5,0,3])` 得到 `7`，正确是 `4`。
- `k` 很大时不走快捷分支：`k` 若是 `10^9`，`[-inf] * (k + 1)` 直接内存爆炸；`k >= n // 2` 时改用 LC 122 的累加。
- 答案取 `sell[k]` 而不是 `buy[k]`：持有未卖的股票不算利润。

**追问。**
- 恰好 `k` 笔而不是最多 `k` 笔：`sell` 初值除 `sell[0]` 外改成 `-inf`，答案仍取 `sell[k]`。
- 加冷冻期 / 手续费（LC 309、714）：状态机多一个冷冻状态，或在卖出时减手续费。
- 另一种与 `k` 的大小几乎无关的解法：把价格序列拆成「谷到峰」的段，用栈合并，取前 `k` 大的利润之和，`O(n log k)`。

**同模式。** LC 121 买卖股票的最佳时机、LC 122 买卖股票的最佳时机 II、LC 123 买卖股票的最佳时机 III、LC 309 含冷冻期、LC 714 含手续费。
