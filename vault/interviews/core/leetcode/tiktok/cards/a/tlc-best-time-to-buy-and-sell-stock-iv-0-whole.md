## Q
**LC 188 买卖股票的最佳时机 IV**｜Hard · TikTok 高频

给整数数组 `prices`（`prices[i]` 是某股票第 `i` 天的价格）和整数 `k`，最多完成 `k` 笔交易（一笔交易是一次买入加一次卖出），不能同时参与多笔交易（再次买入前必须先卖出手上的股票），求最大利润。`1 <= k <= 100`，`1 <= len(prices) <= 1000`，`0 <= prices[i] <= 1000`。例：`k = 2`，`prices = [2,4,1]` → `2`（第 1 天买、第 2 天卖）；`k = 2`，`prices = [3,2,6,5,0,3]` → `7`（`2` 买 `6` 卖赚 `4`，`0` 买 `3` 卖赚 `3`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维动态规划（状态机 DP）：`buy[i][j]` 表示第 `i` 天结束时手上有货、已经买入 `j` 笔（第 `j` 笔还没卖）的最大收益，`sell[i][j]` 表示第 `i` 天结束时手上没货、最多完成 `j` 笔的最大收益；`buy[i][j] = max(buy[i-1][j], sell[i-1][j-1] - p)`，`sell[i][j] = max(sell[i-1][j], buy[i-1][j] + p)`，答案是 `sell[n][k]`。`O(n·k)` 时间、`O(n·k)` 空间。

**识别。** 「最多 `k` 笔交易、不能同时持有多笔」是带交易次数的买卖股票 DP（系列题 LC 121、122、123、188）。状态要同时包含「第几天」「第几笔交易」「手上有没有货」，前两个是表的两个下标，第三个拆成 `buy`、`sell` 两张表。`k` 只有 `100`、`n` 只有 `1000`，表只有 `10^5` 格。

**推导。** 暴力：枚举所有最多 `k` 段互不相交的买卖区间，指数级。浪费：同一个「第 `i` 天、已用 `j` 笔、有没有货」会被不同的买卖序列反复到达，真正不同的状态只有 `n·k·2` 个。洞察：第 `i` 天每个状态只来自第 `i - 1` 天，当天只有三种动作：不动、有货时卖出、没货时买入。有货表 `buy[i][j]`：要么昨天就持有第 `j` 笔（`buy[i-1][j]`），要么今天才买入——今天买之前必须已经完成 `j - 1` 笔、手上没货（`sell[i-1][j-1] - p`）。空仓表 `sell[i][j]`：要么昨天就空仓（`sell[i-1][j]`），要么今天卖掉昨天持有的第 `j` 笔（`buy[i-1][j] + p`）。边界：第 0 行没有任何天数，不可能有货，`buy[0][j] = -inf`；没做过交易收益为 `0`，`sell[0][j] = 0`；第 0 列 `j = 0` 表示不许交易，`buy[i][0] = -inf`、`sell[i][0] = 0`。

```python
from math import inf


def max_profit(k: int, prices: list[int]) -> int:
    n = len(prices)
    # buy[i][j]：第 i 天结束时手上有货，且已经买入 j 笔（第 j 笔还没卖）的最大收益
    # sell[i][j]：第 i 天结束时手上没货，且最多完成 j 笔的最大收益
    buy = [[-inf] * (k + 1) for _ in range(n + 1)]    # 第 0 天不可能有货：-inf
    sell = [[0] * (k + 1) for _ in range(n + 1)]      # 第 0 天没做过交易：收益 0
    for i, p in enumerate(prices, 1):
        for j in range(1, k + 1):
            buy[i][j] = max(buy[i - 1][j], sell[i - 1][j - 1] - p)   # 继续拿着 / 今天开第 j 笔
            sell[i][j] = max(sell[i - 1][j], buy[i - 1][j] + p)      # 继续空仓 / 今天卖掉
    return sell[n][k]
```

运行：`(2, [2,4,1])` → `2`，`(2, [3,2,6,5,0,3])` → `7`，`(1, [3,2,6,5,0,3])` → `4`，`(3, [3,2,6,5,0,3])` → `7`，`(1, [1])` → `0`，`(100, [1,2,3,4,5])` → `4`，`(2, [7,6,4,3,1])` → `0`；`k = 100`、`n = 1000` 的随机价格不到 `0.5` 秒算完。

**复杂度。** 时间 `O(n·k)`：两张 `(n+1)×(k+1)` 的表，每格常数；空间 `O(n·k)`。

**易错点。**
- 第 0 行的 `buy` 写成 `0`：相当于还没开盘就免费拿到一只股票，`(2, [3,2,6,5,0,3])` 得到 `9`，正确是 `7`；`buy[0][j]` 必须是负无穷（`-inf`）。
- 买入转移写成 `buy[i][j] = max(buy[i-1][j], sell[i-1][j] - p)`：用的是已经完成 `j` 笔的空仓状态再买，不占用新的笔数，交易次数的限制失效：`(1, [3,2,6,5,0,3])` 得到 `7`，正确是 `4`。买入要从上一列 `sell[i-1][j-1]` 来。
- 答案取 `buy[n][k]` 而不是 `sell[n][k]`：持有未卖的股票不算已实现的利润，值还可能是负数。

**追问。**
- 恰好 `k` 笔而不是最多 `k` 笔：第 0 行 `sell[0][j]` 除 `j = 0` 外改成 `-inf`，答案仍取 `sell[n][k]`。
- 加冷冻期 / 手续费（LC 309、714）：状态机多一个冷冻状态，或在卖出时减手续费。
- `k` 特别大（比如 `10^9`）：`k >= n // 2` 时交易次数实际不受限，直接累加所有正的相邻价差；另有「谷到峰」分段、用栈合并、取前 `k` 大利润的 `O(n log n)` 解法。
- 空间可以压到 O(k)：见 Python 工具箱「DP 降维」。

**同模式。** LC 121 买卖股票的最佳时机、LC 122 买卖股票的最佳时机 II、LC 123 买卖股票的最佳时机 III、LC 309 含冷冻期、LC 714 含手续费。
