## Q
**LC 498 对角线遍历**｜Medium · CodeTop 国内累计 21 次 · 最近 2026-04-20（CodeTop）

给 `m x n` 的矩阵 `mat`，按对角线遍历的顺序返回所有元素：从左上角出发，先向右上走，到边界后拐到下一条对角线，改向左下走，如此交替。`m == mat.length`，`n == mat[i].length`，`1 <= m, n <= 10^4`，`1 <= m * n <= 10^4`，`-10^5 <= mat[i][j] <= 10^5`。例：`[[1,2,3],[4,5,6],[7,8,9]]` → `[1,2,4,7,5,3,6,8,9]`；`[[1,2],[3,4]]` → `[1,2,3,4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 同一条反对角线上的元素满足 `i + j` 相同：按行优先扫一遍，把元素放进以 `i + j` 为键的组里（组内行号递增）；再按 `d = 0, 1, …, m + n - 2` 依次输出每组，`d` 为偶数时（向右上走）把组反过来。`O(m·n)`。

**识别。** 「沿对角线走、拐弯、方向交替」这类矩阵遍历题，最稳的做法是找**不变量**：一条反对角线上 `i + j` 是常数，一共有 `m + n - 1` 条，奇偶决定方向。不要去模拟"撞墙后怎么拐"，那需要处理四种边界情形，极易写错。`m·n <= 10^4`，线性即可。

**推导。** 暴力：模拟行走，维护方向，撞到上 / 右边界或下 / 左边界时按规则拐弯，边界分四种、拐弯点要特判（如到右上角既撞上又撞右）→ 浪费：每步都在判断边界 → 按 `i + j` 分组，对角线内的顺序天然是行号递增（从右上到左下）→ 偶数条对角线需要反向（从左下到右上），奇数条保持原样。

```python
from collections import defaultdict

def find_diagonal_order(mat: list[list[int]]) -> list[int]:
    m, n = len(mat), len(mat[0])
    diagonals: defaultdict[int, list[int]] = defaultdict(list)
    for i, row in enumerate(mat):
        for j, v in enumerate(row):
            diagonals[i + j].append(v)             # 同一条反对角线上 i + j 相同；行优先扫描时 i 递增
    result: list[int] = []
    for d in range(m + n - 1):
        line = diagonals[d]                        # 此时 line 是从右上到左下
        result.extend(line if d % 2 else reversed(line))   # d 为偶数时向右上走，要从左下到右上
    return result
```

运行：`[[1,2,3],[4,5,6],[7,8,9]]` → `[1,2,4,7,5,3,6,8,9]`，`[[1,2],[3,4]]` → `[1,2,3,4]`，`[[7]]` → `[7]`，`[[1,2,3]]` → `[1,2,3]`，`[[1],[2],[3]]` → `[1,2,3]`；`1 x 10000` 与 `10000 x 1` 都返回长度 `10000`。

**复杂度。** 时间 `O(m·n)`；空间 `O(m·n)`，分组存放了所有元素。`O(1)` 额外空间的写法见追问。

**易错点。**
- 完全不反向：`[[1,2,3],[4,5,6],[7,8,9]]` 得到 `[1,2,4,3,5,7,6,8,9]`，正确是 `[1,2,4,7,5,3,6,8,9]`。
- 方向的奇偶写反：`d` 为奇数时反向，得到 `[1,4,2,3,5,7,8,6,9]`。起点方向是向右上，`d = 0` 那条只有一个元素，`d = 1` 才是第一条会"走"的，它应该保持从右上到左下（`2` 再 `4`）。
- 单行或单列矩阵：`m + n - 1` 条对角线都只含一个元素，不要假设至少 `2 x 2`。

**追问。**
- `O(1)` 额外空间：对每条对角线直接算出合法的行号区间 `[max(0, d - n + 1), min(d, m - 1)]`，按奇偶决定正序还是倒序读取 `mat[i][d - i]`。
- 反方向（先向左下）或蛇形遍历（LC 54 螺旋矩阵）：同样先找不变量，再决定顺序。
- 结果能否边读边产出：用生成器 `yield` 逐条对角线输出，内存 `O(1)`。

**同模式。** LC 54 螺旋矩阵、LC 59 螺旋矩阵 II、LC 1329 将矩阵按对角线排序、LC 566 重塑矩阵。
