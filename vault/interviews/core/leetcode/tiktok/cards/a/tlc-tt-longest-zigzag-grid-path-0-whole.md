## Q
**网格中最长的之字形递增路径**｜Hard · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-06-17（面试记录）

给 `m x n` 的整数网格 `grid`。一条路径从任意格子出发，每步走到上下左右相邻的格子，要求：
- 走到的格子的值**严格大于**当前格子；
- **水平移动和竖直移动必须交替**（第一步方向任意）。

返回最长路径包含的**格子数**。`1 <= m, n <= 200`，`0 <= grid[i][j] <= 2^31 - 1`。例：`[[1,2],[4,3]]` → `4`（`1→2` 水平，`2→3` 竖直，`3→4` 水平）；`[[1,2,3]]` → `2`（只能水平走，不能连走两步水平）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 状态是「格子 + 下一步必须走的方向类型」：`dp[d][i][j]` 表示从 `(i, j)` 出发、下一步必须是方向 `d`（水平或竖直）时最长路径的格子数，转移是 `dp[d][i][j] = 1 + max dp[1-d][邻居]`（邻居在方向 `d` 上且值更大）。值严格递增保证没有环，按值**从大到小**处理格子，算到一个格子时它所有更大的邻居都已算好。`O(mn log(mn))`。

**识别。** 「严格递增路径 + 网格 + 最长」是 LC 329 矩阵中的最长递增路径：严格递增让「走到更大的格子」这张图成为有向无环图（DAG），最长路径可以 DP。「水平竖直交替」是额外约束：同一个格子出发，后续能走多远取决于下一步允许的方向，所以状态必须带上方向，多一维。

**推导。** 暴力：从每个格子 DFS 枚举所有路径，路径数是指数级。浪费在于同一个「(格子, 下一步方向)」被许多不同前缀反复展开，而它后面能走多远和前缀无关（递增保证前缀里的格子都比当前小，不会再被走到）。所以对 `(i, j, d)` 记忆化，状态 `2mn` 个，每个看 2 个邻居。计算顺序：依赖总是指向值更大的格子，按值从大到小排序后顺序填表，免去递归；递归版的深度等于路径长度，最坏可达 `m·n` 量级，会超过 Python 的递归上限。

```python
H, V = 0, 1                                               # 下一步必须是水平 / 竖直
STEPS = (((0, 1), (0, -1)), ((1, 0), (-1, 0)))            # STEPS[H]、STEPS[V]


def longest_zigzag_path(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    # dp[d][i][j]：从 (i, j) 出发、下一步方向类型必须是 d 时，最长路径的格子数
    dp = [[[1] * n for _ in range(m)] for _ in range(2)]
    # 值从大到小处理：严格递增保证邻居（更大的值）已经算好
    cells = sorted(((grid[i][j], i, j) for i in range(m) for j in range(n)), reverse=True)
    for val, i, j in cells:
        for d in (H, V):
            for di, dj in STEPS[d]:
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] > val:
                    dp[d][i][j] = max(dp[d][i][j], 1 + dp[1 - d][ni][nj])   # 走完这步，下一步换方向
    return max(max(map(max, layer)) for layer in dp)
```

运行：`[[1,2],[4,3]]` → `4`；`[[1,2,3]]` → `2`；`[[5]]` → `1`；`[[1,2],[3,4]]` → `3`；`[[9,9,4],[6,6,8],[2,1,1]]` → `3`；`[[4,2,1],[1,6,1]]` → `3`。

**复杂度。** 时间 `O(mn log(mn))`，排序占主导，填表 `O(mn)`（每个格子 2 个方向 × 2 个邻居）；空间 `O(mn)`。`m = n = 200` 时 `4·10^4` 个格子。

**易错点。**
- 状态不带方向，每个格子只存「最长路径 + 它第一步的方向」：同一格子出发、第一步方向不同的两条路径只留一条，另一条被丢掉。`[[4,2,1],[1,6,1]]` 会错成 `2`（正确 `3`：`1 → 2` 水平，`2 → 6` 竖直）。
- 直接套 LC 329 不管交替：`[[1,2,3]]` 得到 `3`，正确是 `2`。
- 值相等的邻居不能走（严格大于）；按值排序时相等的值谁先谁后都行，因为相等的格子之间没有边。

**追问。**
- 输出路径：转移时记下取到最大值的邻居 `nxt[d][i][j]`，从答案所在的 `(i, j, d)` 沿 `nxt` 走到底。
- 不要求交替：去掉 `d` 这一维，就是 LC 329。
- 空间：`dp` 必须保留整张表（依赖的邻居顺序由值决定，不是按行），这里没有滚动数组可用。

**同模式。** LC 329 矩阵中的最长递增路径、LC 2328 网格图中递增路径的数目、LC 1372 二叉树中的最长交错路径、LC 1027 最长等差数列。
