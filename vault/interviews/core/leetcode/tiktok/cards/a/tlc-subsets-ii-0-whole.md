## Q
**LC 90 子集 II**｜Medium · TikTok 高频

给一个可能包含重复元素的整数数组 `nums`，返回它所有可能的子集（幂集）。解集不能包含重复的子集；子集可以按任意顺序返回。`1 <= nums.length <= 10`，`-10 <= nums[i] <= 10`。例：`[1,2,2]` → `[[],[1],[1,2],[1,2,2],[2],[2,2]]`（顺序任意）；`[0]` → `[[],[0]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先排序让相同的数相邻，再回溯：回溯树的每个节点就是一个子集；在同一层的循环里，相同的数只选第一个（`i > start and nums[i] == nums[i-1]` 就跳过），相同数值的「多选」只能通过往下一层走得到。每个不同的子集恰好生成一次，`O(n * 2^n)`。

**识别。** 「子集枚举」是回溯；「含重复元素、结果不能重复」是同一层去重；去重的前提是相同的数相邻，所以必须先排序；`n <= 10`，最多 `2^10 = 1024` 个子集，回溯足够。

**推导。** 暴力：当作数组元素互不相同，生成全部 `2^n` 个下标子集，把每个子集排序成元组放进集合去重 → 浪费：先生成大量重复，再付出排序和哈希的代价去删，重复多时（如全相同的数组）浪费巨大 → 洞察：重复的根源是「几个相同的数里选哪个」不应当有区别。排序后，在回溯树的同一层（同一次 `for` 循环）里，若第 `i` 个数和第 `i-1` 个数相同，选第 `i` 个得到的所有子集都已经在选第 `i-1` 个时生成过，直接跳过；而在更深一层（`start = i`，即上一个相同的数已被选入路径）时，再选相同的数是允许的，这就产生了「选两个、三个相同的数」的子集。

```python
def subsets_with_dup(nums: list[int]) -> list[list[int]]:
    nums = sorted(nums)                         # 排序让相同的数相邻，才能“同层跳过”
    path: list[int] = []
    res: list[list[int]] = []

    def backtrack(start: int) -> None:
        res.append(path[:])                     # 每个节点本身就是一个子集
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i - 1]:   # 同一层里相同的数只选第一个，避免生成重复子集
                continue
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return res
```

运行：`[1,2,2]` → `[[], [1], [1, 2], [1, 2, 2], [2], [2, 2]]`；`[0]` → `[[], [0]]`；`[1]*10` → `11` 个子集；`list(range(-5, 5))`（十个不同的数）→ `1024` 个子集。

**复杂度。** 时间 `O(n * 2^n)`（最多 `2^n` 个子集，每个拷贝 `O(n)`）；空间 `O(n)` 递归栈（不含结果）。

**易错点。**
- 去重条件写成 `i > 0`：`[1,2,2]` 会得到 `[[], [1], [1, 2], [2]]`，漏掉 `[1,2,2]` 和 `[2,2]`；`i > 0` 把「上一层已选了前一个相同数，这一层再选下一个」也跳过了。
- 忘了排序：`[2,1,2]` 生成 `8` 个子集，只有 `6` 个不同，相同的数不相邻，同层去重失效。
- 保存 `path` 本身而不是拷贝：`res.append(path)` 之后 `path` 还在被修改，最终所有结果都指向同一个已清空的列表，`[1,2,2]` 得到 `6` 个 `[]`。

**追问。**
- 不用递归：按不同的值分组（`Counter`），对每个值 `v` 出现 `c` 次，把当前所有子集各追加 `1..c` 个 `v`。
- 只数个数、不枚举：子集数是各值出现次数加一的乘积，`[1,2,2]` 是 `2 * 3 = 6`。
- 同样的剪枝用在「和为目标值的组合」：LC 40 组合总和 II。

**同模式。** LC 78 子集、LC 40 组合总和 II、LC 47 全排列 II、LC 491 非递减子序列（不能排序，用同层集合去重）。
