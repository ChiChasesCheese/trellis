## Q
**LC 926 将字符串翻转到单调递增**｜Medium · TikTok 高频

二进制字符串如果由若干个 `0`（可以没有）后面跟着若干个 `1`（可以没有）组成，就叫单调递增。给二进制字符串 `s`，每次可以把任意一个 `0` 翻成 `1` 或把任意一个 `1` 翻成 `0`，返回使 `s` 单调递增的最少翻转次数。`1 <= s.length <= 10^5`，`s[i]` 是 `'0'` 或 `'1'`。例：`"00110"` → `1`（翻最后一位得 `00111`）；`"010110"` → `2`（得 `011111` 或 `000111`）；`"00011000"` → `2`（得 `00000000`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 单调递增串一定存在一个分界点：左边全 `0`、右边全 `1`。从左到右扫描，维护 `ones`（已见到的 `1` 的个数）和 `flips`（当前前缀变成单调递增的最少翻转）：遇到 `'1'` 只增加 `ones`；遇到 `'0'` 取 `flips = min(flips + 1, ones)`——把它翻成 `1`，或让前面所有 `1` 都变成 `0`。`O(n)` 时间，`O(1)` 空间。

**识别。** 「`0...01...1` 的形状 + 最少修改」意味着只需枚举一个分界点，代价 = 左边的 `1` 数 + 右边的 `0` 数，可以用前缀和；再看它是不是只依赖前缀，就能压成一遍扫描的 DP。`n = 10^5` 排除 `O(n^2)`。

**推导。** 暴力：对每个分界点 `k` 数左边的 `1` 和右边的 `0`，`O(n^2)` → 浪费：相邻分界点的计数几乎一样，每次重数 → 前缀和：`ones[k]` 为 `s[:k]` 中 `1` 的个数，代价 `ones[k] + (右边长度 - 右边的 1 数)`，`O(n)` 时间 `O(n)` 空间 → 洞察：设 `flips` 为前缀 `s[:i]` 单调化的最少翻转。追加 `'1'` 总是合法（以 `1` 结尾可接在任意单调串后面），`flips` 不变；追加 `'0'` 只有两条路：翻成 `1`，代价 `flips + 1`；保留 `0`，则前面必须全是 `0`，代价是把前面的 `ones` 个 `1` 都翻掉。两者取小，只要两个变量。

```python
def min_flips_mono_incr(s: str) -> int:
    ones = flips = 0                  # ones：已见的 '1' 数；flips：s[:i] 变成单调递增的最少翻转
    for ch in s:
        if ch == "1":
            ones += 1                 # 追加 '1' 永远不破坏单调，代价不变
        else:
            flips = min(flips + 1, ones)   # 追加 '0'：把它翻成 '1'，或把前面所有 '1' 都翻成 '0'
    return flips
```

运行：`"00110"` → `1`，`"010110"` → `2`，`"00011000"` → `2`，`"1"` → `0`，`"0"` → `0`，`"111000"` → `3`，`"0101100011"` → `3`；`"10" * 50000` → `50000`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 贪心地「第一个 `1` 之后的 `0` 全翻成 `1`」：`"100000"` 会得到 `5`，正确是 `1`（把开头的 `1` 翻成 `0`）。
- `ones` 当成整个字符串的 `1` 的个数：遇到 `'0'` 时只能让「已经出现的」`1` 变成 `0`，要用扫描到当前的 `ones`。
- 只翻 `0 → 1` 或只翻 `1 → 0`：两个方向都允许，`min` 里的两项分别对应这两种选择。

**追问。**
- 要返回翻转后的字符串或位置：先用前缀和找到最优分界点 `k`，再把左边的 `1` 和右边的 `0` 翻掉。
- 前缀和写法：`ones = list(accumulate((c == "1" for c in s), initial=0))`，答案 `min(ones[k] + (n - k) - (ones[n] - ones[k]) for k in range(n + 1))`，容易讲清楚分界点的含义。
- 流式输入：`ones`、`flips` 只依赖已读前缀，每读一个字符都能给出当前前缀的答案。

**同模式。** LC 1653 使字符串平衡的最少删除次数、LC 2483 商店的最少代价、LC 1888 使二进制字符串字符交替的最少反转次数。
