## Q
**LC 958 二叉树的完全性检验**｜Medium · CodeTop 国内累计 30 次 · 最近 2025-11-06（CodeTop）

给二叉树的根节点 `root`，判断它是不是**完全二叉树**：除最后一层外所有层都填满，且最后一层的节点都尽可能靠左。树中节点数在 `[1, 100]`，`1 <= Node.val <= 1000`。例：`[1,2,3,4,5,6]` → `true`；`[1,2,3,4,5,null,7]` → `false`（`7` 前面有空位，没有靠左）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 层序遍历（BFS）时把空孩子也入队；一旦出队遇到第一个空位，之后再出现任何真实节点就说明有「空位在前、节点在后」，返回 `False`；跑完都没有就是完全二叉树。`O(n)`。

**识别。** 「完全二叉树」的定义本身就是一个层序顺序上的性质：把节点按从上到下、从左到右排成一列，真实节点必须连成一段，空位只能出现在末尾。所以看到「完全性 / 靠左 / 层」就用层序遍历；`n <= 100` 不限制复杂度，考的是想到这条性质。

**推导。** 直接按定义检查「每层是否满」要逐层数节点、再判断最后一层，分支很多 → 换成性质：完全二叉树的层序序列（含 `None`）是「若干真实节点 + 若干 `None`」，`None` 之后不会再有真实节点 → 层序遍历时记一个布尔值 `seen_gap`，遇到 `None` 置真，之后遇到真实节点立即失败 → 每个节点入队出队一次。

```python
from collections import deque

def is_complete_tree(root: TreeNode | None) -> bool:
    queue = deque([root])              # 层序遍历，连空位（None）也入队
    seen_gap = False                   # 是否已经遇到过空位
    while queue:
        node = queue.popleft()
        if node is None:
            seen_gap = True
            continue
        if seen_gap:                   # 空位之后又出现真实节点：最后一层不靠左
            return False
        queue.append(node.left)
        queue.append(node.right)
    return True
```

运行：`[1,2,3,4,5,6]` → `True`，`[1,2,3,4,5,None,7]` → `False`，`[1]` → `True`，`[1,2]` → `True`，`[1,None,2]` → `False`。

**复杂度。** 时间 `O(n)`，每个节点和它的两个空孩子各入队出队一次；空间 `O(w)`，`w` 是最大层宽，最坏 `O(n)`。

**易错点。**
- 只检查「有右孩子没有左孩子」不够：`[1,2,3,None,None,4]` 中 `2` 是叶子、`3` 却有孩子，这个局部检查返回 `True`，正确答案是 `False`。必须跨节点比较，也就是整条层序序列。
- 用 `list.pop(0)` 当队列会让出队变成 `O(n)`，整体 `O(n^2)`；用 `deque.popleft()`。
- 不要在入队前过滤 `None`，否则「空位」信息就丢了。

**追问。**
- 不用「空位」状态，用堆式编号：根为 `1`，左孩子 `2i`，右孩子 `2i+1`；完全二叉树当且仅当节点数等于最大编号。
- 求完全二叉树的节点数（LC 222）：比较左右最左路径的高度，一侧是满树就直接用公式，`O(log^2 n)`。
- 在完全二叉树上做插入（LC 919）：保留队列里「还缺孩子」的节点，新节点挂到队首节点下。

**同模式。** LC 102 二叉树层序遍历、LC 222 完全二叉树的节点个数、LC 919 完全二叉树插入器、LC 662 二叉树最大宽度。
