## Q
**LC 424 替换后的最长重复字符**｜Medium · LC 字节 热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-09-20（CodeTop）

给字符串 `s` 和整数 `k`。你可以把字符串中任意位置的字符改成任意其他大写英文字母，这样的操作最多做 `k` 次。返回操作之后，包含相同字母的最长子串的长度。`1 <= s.length <= 10^5`，`s` 仅由大写英文字母组成，`0 <= k <= s.length`。例：`s = "ABAB", k = 2` → `4`（两个 `A` 换成 `B`）；`s = "AABABBA", k = 1` → `4`（中间的 `A` 换成 `B`，得到 `"BBBB"`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 可变长滑动窗口：一个窗口能被改成同一个字母，当且仅当「窗口长度 − 窗口内最高频字符的次数 `<= k`」。右端逐个扩张；一旦需要替换的数量超过 `k`，左端右移一格（窗口整体平移，不缩小）。答案就是窗口最终的长度。`O(n)`。

**识别。** 「连续子串 + 最长 + 最多修改 `k` 次」是滑动窗口的信号（和「最多翻转 `k` 个 0」LC 1004 同族）。把「替换」翻译成可计数的条件：想把窗口变成字符 `c`，需要改掉所有不是 `c` 的位置，最省的是选出现次数最多的字符：代价 `= 长度 − 最高频次数`。条件有单调性：窗口缩小，代价不会增加。`n = 10^5` 要求 `O(n)`。

**推导。** 暴力：枚举所有子串，算最高频次数判断，`O(n^2 · 26)` → 滑窗：右端扩一格，若 `长度 − 最高频 > k` 就左端收一格；左端用 `Counter` 维护窗口内各字母次数 → 一个不寻常的优化：`max_freq` 只记录**历史最大值**、不随左端收缩而减小。原因：答案只在窗口增大时才变，而增大需要窗口内最高频次数创新高，旧的（偏大的）`max_freq` 最多让窗口「多保持原尺寸」，不会让它虚假变大。所以每步 `O(1)`，不必每次重算 `max(count.values())`。

```python
from collections import Counter

def character_replacement(s: str, k: int) -> int:
    count: Counter[str] = Counter()
    max_freq = left = 0                        # max_freq：窗口出现过的最大字符频次（只增不减）
    for right, ch in enumerate(s):
        count[ch] += 1
        max_freq = max(max_freq, count[ch])
        if right - left + 1 - max_freq > k:    # 需要替换的字符数超过 k：窗口整体右移一格
            count[s[left]] -= 1
            left += 1
    return len(s) - left                       # 窗口只会增大或平移，最终大小就是答案
```

运行：`("ABAB", 2)` → `4`，`("AABABBA", 1)` → `4`，`("A", 0)` → `1`，`("AB", 0)` → `1`，`("ABC", 5)` → `3`；`10^5` 个随机字母、`k = 500` 远小于 `1` 秒。

**复杂度。** 时间 `O(n)`；空间 `O(26)`。

**易错点。**
- 把判断写成 `>= k`：少一个替换名额。`"ABAB", k = 2` 得 `3`（正确 `4`），`"AABABBA", k = 1` 得 `2`（正确 `4`）。
- 用 `while` 收缩并重算 `max_freq`：也对，但变成 `O(26n)`；写成 `if` 并保持 `max_freq` 单调是更省的做法。

**追问。**
- 为什么 `max_freq` 可以过期：窗口只在 `max_freq` 真的创新高时才会变长，过期的偏大值最多让窗口平移，不会让答案虚高。
- 只有 0/1 的数组，最多翻转 `k` 个 0（LC 1004）：窗口内 0 的个数 `> k` 就收缩，是同一个框架。
- 允许替换成任意字符（不限大写字母）：框架不变，`Counter` 自然支持任意字符。

**同模式。** LC 1004 最大连续1的个数 III、LC 3 无重复字符的最长子串、LC 340 至多包含 K 个不同字符的最长子串、LC 2024 考试的最大困扰度。
