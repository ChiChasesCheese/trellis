## Q
**LC 1131 绝对值表达式的最大值**｜Medium · 字节 高频

给两个长度相等的整数数组 `arr1` 和 `arr2`，返回下面表达式的最大值：`|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|`，其中下标满足 `0 <= i, j < arr1.length`。`2 <= arr1.length == arr2.length <= 40000`，`-10^6 <= arr1[i], arr2[i] <= 10^6`。例：`arr1 = [1,2,3,4], arr2 = [-1,4,5,6]` → `13`；`arr1 = [1,-2,-5,0,10], arr2 = [0,-2,-1,-7,-4]` → `20`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把每个绝对值拆成「取正或取负的较大者」：`|x| + |y| + |z|` 等于所有符号组合 `±x ± y ± z` 的最大值。每个符号组合下，表达式都是 `f(i) - f(j)` 的形式，最大值就是 `max f - min f`，一次扫描求出。因为 `i` 与 `j` 对称，固定 `i - j` 项的符号为正，只需要 `4` 种组合。总时间 `O(n)`。

**识别。** 这是三维点 `(arr1[i], arr2[i], i)` 之间的**曼哈顿距离**最大值。「两两之间的绝对值之和的最大值」且 `n = 40000`：`O(n^2) = 1.6 * 10^9` 不行。看到绝对值之和的最大值，要想到把绝对值展开成符号组合，使表达式对 `i` 和 `j` **可分离**，然后用 `max - min`。

**推导。** 暴力枚举所有 `(i, j)`，`O(n^2)`。关键等式 `|x| = max(x, -x)`，三个绝对值相加就是 `2^3 = 8` 种符号选择的最大值。取一种符号 `(s1, s2, s3)`，表达式 `s1(a_i - a_j) + s2(b_i - b_j) + s3(i - j)` 可以拆成 `[s1 a_i + s2 b_i + s3 i] - [s1 a_j + s2 b_j + s3 j] = f(i) - f(j)`。对所有 `(i, j)` 取最大就是 `max f - min f`。符号组合 `s` 和 `-s` 对应的 `f` 恰好互为相反数，`max f - min f` 的结果相同，所以 `8` 种折半成 `4` 种：固定 `s3 = +1`，枚举 `(s1, s2)`。

```python
from itertools import product


def max_abs_val_expr(arr1: list[int], arr2: list[int]) -> int:
    ans = 0
    for p, q in product((1, -1), repeat=2):          # 拆绝对值：|x| = max(x, -x)，i 项的符号可固定为 +
        vals = [p * a + q * b + i for i, (a, b) in enumerate(zip(arr1, arr2))]
        ans = max(ans, max(vals) - min(vals))
    return ans
```

运行：示例 1 → `13`，示例 2 → `20`，`[5,5]` 与 `[5,5]` → `1`，`arr1 = [-1,0]`、`arr2 = [0,-1]` → `3`。

**复杂度。** 时间 `O(4n) = O(n)`；空间 `O(n)`（可以改成边扫描边维护 `max` 和 `min` 降到 `O(1)`）。

**易错点。**
- 只算一种符号组合：示例 2 只用 `(+, +)`，得到 `14`（正确 `20`）；`arr1 = [-1,0]`、`arr2 = [0,-1]` 只用 `(+, +)` 得到 `1`（正确 `3`）。
- 只枚举 `p`、固定 `q = +1`：示例 2 得到 `16`，仍不对；`(p, q)` 的四种组合都需要。
- 用 `max(vals)` 而不是 `max(vals) - min(vals)`：表达式是 `f(i) - f(j)`，要用最大的减最小的。

**追问。**
- 推广到 `k` 个数组（`k + 1` 维点）：符号组合 `2^k` 种（固定一维符号），每种 `O(nk)`，总计 `O(2^k · n · k)`。
- 要返回取到最大值的下标对 `(i, j)`：记录最大 / 最小值对应的下标。
- 在线插入新点、查询与已有点的最大距离：对每种符号维护 `max f` 和 `min f`，每次查询 `O(2^k)`。

**同模式。** LC 1330 翻转子数组得到最大的数组值、LC 296 最佳的碰头地点、LC 3102 最小化曼哈顿距离、LC 462 最少移动次数使数组元素相等 II。
