## Q
**LC 1143 最长公共子序列**｜Medium · TikTok·字节 高频

给两个字符串 `text1` 和 `text2`，返回它们的**最长公共子序列**（longest common subsequence）的长度，不存在则返回 `0`。子序列是在不改变相对顺序的前提下删掉若干字符（可以不删）得到的串，例如 `"ace"` 是 `"abcde"` 的子序列，`"aec"` 不是。`1 <= text1.length, text2.length <= 1000`，只含小写英文字母。例：`text1 = "abcde"`，`text2 = "ace"` → `3`；`"abc"` 与 `"abc"` → `3`；`"abc"` 与 `"def"` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维动态规划（DP）：`dp[i][j]` 表示 `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的 LCS 长度；末尾字符相等就 `dp[i-1][j-1] + 1`，不等就取 `max(dp[i-1][j], dp[i][j-1])`；每行只依赖上一行，滚动成一维数组，`O(mn)` 时间、`O(min(m, n))` 空间。

**识别。** 「两个字符串」加「子序列」加「最长」是前缀对上的 DP 的标准信号：每个字符要么匹配、要么被跳过，状态天然是「两个串各看到哪」。`m, n <= 1000` 允许 `O(mn)` = `10^6`；暴力枚举 `text1` 的所有子序列有 `2^m` 个，不可行。

**推导。** 暴力递归 `f(i, j)`：末尾相等就同时后退一格，不等就分别丢掉其中一个串的末尾字符，取较大者，不加记忆是指数级。浪费在于 `f(i, j)` 只有 `m * n` 种不同参数，大量重复。改成自底向上填表，每格 `O(1)`。再看依赖：`dp[i][j]` 只用到上一行的 `dp[i-1][j-1]`、`dp[i-1][j]` 和本行的 `dp[i][j-1]`，一行数组加一个变量 `diag` 保存左上角就够了。

```python
def longest_common_subsequence(text1: str, text2: str) -> int:
    if len(text1) < len(text2):
        text1, text2 = text2, text1          # 让 text2 是较短的一条，滚动数组只有 min(m, n) + 1 长
    dp = [0] * (len(text2) + 1)              # dp[j]：当前行 text1[:i] 与 text2[:j] 的 LCS 长度
    for a in text1:
        diag = 0                             # 左上角 dp[i-1][j-1]，行首是 0
        for j, b in enumerate(text2, 1):
            diag, dp[j] = dp[j], (diag + 1 if a == b else max(dp[j], dp[j - 1]))
    return dp[-1]
```

运行：`("abcde", "ace")` → `3`，`("abc", "abc")` → `3`，`("abc", "def")` → `0`，`("a", "a")` → `1`，`("bl", "yby")` → `1`，两个长 1000 的全 `"a"` 串 → `1000`。

**复杂度。** 时间 `O(mn)`：双层循环，每格常数；空间 `O(min(m, n))`：一行滚动数组。

**易错点。**
- 把「不等」写成归零（按最长公共**子串**处理）会错：`"abcde"` 与 `"ace"` 得到 `1`，正确是 `3`。子序列允许跳过，不等时要继承 `max(上, 左)`。
- 滚动数组里，相等时用的是**左上角**，不是本行左边：写成 `dp[j] = dp[j-1] + 1`，`("a", "aaa")` 得到 `3`（正确 `1`）。覆盖 `dp[j]` 之前先把旧值存进 `diag`。

**追问。**
- 返回 LCS 字符串本身：滚动数组丢了信息，需要完整的二维表，再从右下角回溯（相等就斜上取字符，不等就往 `dp` 较大的方向走）。
- 三个串、`k` 个串：状态多一维，`O(n^k)`。
- 两个序列都很长但其中一个元素互不相同：把问题转成最长递增子序列（LIS），`O(n log n)`。

**同模式。** LC 72 编辑距离、LC 583 两个字符串的删除操作、LC 712 最小 ASCII 删除和、LC 1035 不相交的线、LC 718 最长重复子数组（子串版，不等归零）。
