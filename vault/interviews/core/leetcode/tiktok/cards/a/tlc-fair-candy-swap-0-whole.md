## Q
**LC 888 公平的糖果交换**｜Easy · CodeTop 国内累计 1 次 · 最近 2026-04-04（CodeTop）

爱丽丝和鲍勃拥有不同总数量的糖果。`aliceSizes[i]` 是爱丽丝第 `i` 盒糖果的数量，`bobSizes[j]` 是鲍勃第 `j` 盒的数量。两人要各拿出一盒互相交换，使交换后两人的糖果总数相同。返回 `[爱丽丝给出的那盒的数量, 鲍勃给出的那盒的数量]`；有多个答案返回任意一个，保证至少有一个有效答案。`1 <= aliceSizes.length, bobSizes.length <= 10^4`，`1 <= aliceSizes[i], bobSizes[j] <= 10^5`，两人的糖果总数不同。例：`aliceSizes = [1,1], bobSizes = [2,2]` → `[1,2]`；`aliceSizes = [1,2,5], bobSizes = [2,4]` → `[5,4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 设爱丽丝给出 `x`、鲍勃给出 `y`，交换后总数相等：`sumA - x + y = sumB - y + x`，化简得 `y = x - (sumA - sumB) / 2`。把鲍勃的盒子放进集合，遍历爱丽丝的每个 `x`，查 `x - delta` 在不在集合里。`O(n + m)`。

**识别。** 「交换一个元素使两边总和相等」→ 先写等式，把两个未知数化成一个：每个 `x` 只对应唯一的 `y`，于是「找一对」变成「查一个」，用哈希集合。`n, m <= 10^4`：双层循环是 `10^8` 次，Python 里太慢；`O(n + m)` 哈希或排序加双指针都行。「保证有解」意味着 `sumA - sumB` 必为偶数，可以放心用整除。

**推导。** 暴力：枚举所有 `(x, y)`，检查交换后总和是否相等，`O(nm)`。关键是代数：设 `delta = (sumA - sumB) / 2`，交换后爱丽丝的总数是 `sumA - x + y`，鲍勃是 `sumB - y + x`，令二者相等得 `y = x - delta`。所以枚举 `x`，目标 `y` 是确定的，只需 `O(1)` 判断它是否在鲍勃的盒子里。把鲍勃的盒子放进 `set`，总代价 `O(n + m)`。

```python
def fair_candy_swap(alice_sizes: list[int], bob_sizes: list[int]) -> list[int]:
    delta = (sum(alice_sizes) - sum(bob_sizes)) // 2   # 爱丽丝要比鲍勃多拿出这么多
    bob = set(bob_sizes)
    for x in alice_sizes:
        if (y := x - delta) in bob:                    # 交换 x 和 y 后两人总数相等
            return [x, y]
    return []                                          # 题目保证有解，这里不会执行
```

运行：`[1,1], [2,2]` → `[1,2]`，`[1,2], [2,3]` → `[1,2]`，`[2], [1,3]` → `[2,3]`，`[1,2,5], [2,4]` → `[5,4]`。

**复杂度。** 时间 `O(n + m)`：两次求和、建集合、遍历爱丽丝的盒子；空间 `O(m)`：鲍勃的集合。

**易错点。**
- 符号写反：目标是 `x - delta`，写成 `x + delta`，`[1,1]` 和 `[2,2]` 得到 `[]`（正确 `[1,2]`）。
- 用 `/` 而不是 `//`：`delta` 变成浮点数，答案会是 `[1, 2.0]` 而不是 `[1, 2]`。
- 鲍勃的列表忘了转成集合，直接写 `x - delta in bob_sizes`：每次是线性查找，总代价退回 `O(nm)`，约 `10^8` 次比较，超时。

**追问。**
- 两个数组都排序后用双指针：按总和差移动指针，额外空间 `O(1)`，总时间 `O(n log n + m log m)`。
- 题目不保证有解：先检查 `(sumA - sumB) % 2`，奇数直接返回 `[]`，否则整除会算错。
- 要交换多盒、使总和相等：变成子集和问题，不再是简单的查表。
