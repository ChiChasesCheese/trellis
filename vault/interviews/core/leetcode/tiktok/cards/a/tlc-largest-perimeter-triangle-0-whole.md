## Q
**LC 976 三角形的最大周长**｜Easy · CodeTop 国内累计 5 次 · 最近 2025-12-19（CodeTop）

数组 `nums` 里是若干正数，表示线段长度。从中选三条组成**面积不为零**的三角形，返回最大周长；组不成任何三角形时返回 `0`。`3 <= nums.length <= 10^4`，`1 <= nums[i] <= 10^6`。例：`[2,1,2]` → `5`；`[1,2,1,10]` → `0`（`1,1,2` 退化成一条线，`10` 太长）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从大到小排序，依次检查**相邻**的三条 `a >= b >= c`：第一次出现 `b + c > a` 时，`a + b + c` 就是最大周长。`O(n log n)`。

**识别。** 三角形条件 `x + y > z`（对三边都成立）在排序后只需检查「两条短边之和大于最长边」一条；「最大周长」提示从大往小贪心；`n = 10^4` 时三重枚举约 `1.7 × 10^11` 组，必须降下来。

**推导。** 暴力枚举三元组 `O(n^3)`。排序后固定最长边 `a`，最有希望成三角形的两条短边就是紧挨着它、比它小的两条 `b, c`：`b + c` 是 `a` 之后所有两数和里最大的。若 `b + c <= a`，`a` 不可能做任何三角形的最长边，直接丢掉；若 `b + c > a`，这组周长在以 `a` 或更短边为最长边的三角形里最大。所以从大到小扫一遍相邻三元组即可。

```python
def largest_perimeter(nums: list[int]) -> int:
    nums = sorted(nums, reverse=True)                 # 从大到小；不改动调用方的列表
    for a, b, c in zip(nums, nums[1:], nums[2:]):     # 相邻三元组，a >= b >= c
        if b + c > a:                                 # 两条短边之和大于最长边即可
            return a + b + c
    return 0
```

运行：`[2,1,2]` → `5`，`[1,2,1,10]` → `0`，`[2,3,4,10]` → `9`，`[3,6,2,3]` → `8`，`[1,2,3]` → `0`。

**复杂度。** 时间 `O(n log n)`，瓶颈是排序；空间 `O(n)`，`sorted` 复制了一份（用 `nums.sort()` 原地排序则是 `O(1)` 额外空间，但会改动输入）。

**易错点。**
- 只看最大的三条：`[2,3,4,10]` 会错成 `0`（正确 `9`，`10` 丢掉后 `2,3,4` 可以）。
- 写成 `b + c >= a`：等号时三点共线、面积为零，`[1,2,1,10]` 会错成 `4`（正确 `0`）。

**追问。**
- 数三角形的**个数**：LC 611，排序后固定最长边，双指针 `O(n^2)`。
- 数据量巨大：值域 `<= 10^6` 时连续失败的相邻三元组让长度至少按斐波那契数增长，最多约 30 次，`heapq.nlargest(32, nums)` 取前 32 个再算即可，`O(n)`。
- 要返回三条边：返回 `(a, b, c)` 而不是和。

**同模式。** LC 611 有效三角形的个数、LC 812 最大三角形面积、LC 1984 学生分数的最小差值。
