## Q
**LC 128 最长连续序列**｜Medium · LC TikTok 热度 66/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 42 次 · 最近 2026-10-17（面试记录）

给一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。要求设计并实现时间复杂度 `O(n)` 的算法。

约束：`0 <= nums.length <= 10^5`，`-10^9 <= nums[i] <= 10^9`。

例：`nums = [100,4,200,1,3,2]` → `4`（`[1,2,3,4]`）；`nums = [0,3,7,2,5,8,4,6,0,1]` → `9`；`nums = [1,0,1,2]` → `3`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把数放进哈希集合，只从**序列的起点**（`x - 1` 不在集合里的数）出发，向右数 `x+1, x+2, …` 直到断开；每个数只会被它所在序列的起点数到一次，总共 `O(n)`。

**识别。** 「最长连续数值序列」+「不要求在原数组中连续」+「要求 `O(n)`」→ 排序（`O(n log n)`）被禁止 → **哈希集合 + 只从起点扩张**。信号：值域很大（`±10^9`）所以不能用数组计数；存在重复元素；`O(n)` 提示每个元素最多处理常数次。

**推导。** 暴力：对每个数 `x`，一个个检查 `x+1, x+2, …` 是否存在，`O(n²)`（数组线性查找 `O(n³)`）。排序后一遍扫描：`O(n log n)`，不满足 `O(n)`。浪费在于：序列 `[1,2,3,4]` 里，从 `1`、`2`、`3`、`4` 都各数一遍，后面三次完全重复。洞察：只在 `x - 1` 不存在（`x` 是序列的起点）时才开始数，其它的数一定会被前面的起点数到。把数放进集合，`in` 查询 `O(1)`，每个数至多被「起点数」访问一次，总计 `O(n)`。遍历集合而不是原数组，避免重复元素重复数。

```python
def longest_consecutive(nums: list[int]) -> int:
    seen = set(nums)                   # 去重 + O(1) 查询
    best = 0
    for x in seen:
        if x - 1 in seen:              # x 不是序列的起点：跳过，让起点去数
            continue
        end = x + 1
        while end in seen:             # 从起点向右数下去
            end += 1
        best = max(best, end - x)
    return best
```

运行：`nums=[100,4,200,1,3,2]` → `4`，`nums=[0,3,7,2,5,8,4,6,0,1]` → `9`，`nums=[1,0,1,2]` → `3`，`nums=[]` → `0`，`nums=[-10**9, 10**9]` → `1`，`nums=list(range(10**5))` → `100000`。

**复杂度。** 时间 `O(n)`：每个数最多被「数一次」覆盖——只有序列起点才会往右数，而每个非起点的数恰好被它所在序列的起点数到一次；空间 `O(n)`（集合）。

**易错点。**
- 去掉 `x - 1 in seen` 的起点检查：每个数都往右数，`nums = range(1000)` 内层循环共 `499500` 步（`n²/2`），`n = 10^5` 就是 `5·10^9`，超时。
- 遍历 `nums` 而不是 `set`：序列起点重复出现时重复数。`[0] * 1000 + list(range(1, 1000))` 的内层循环 `999000` 步，而遍历集合只有 `999` 步。
- 用排序：`O(n log n)` 不满足题目要求；若用排序，别忘了去重（`[1,0,1,2]` 不去重会把相等的邻居当作断开，得 `2`，应为 `3`）。
- 空数组：`max` 没有初值时报错；这里 `best = 0` 起步，空集合不进循环，返回 `0`。

**追问。**
- 要返回这个最长序列本身：记录最优的起点 `start` 和长度，最后 `list(range(start, start + best))`。
- 数据是流式的 / 要支持动态插入：用「端点长度表」`length[x]`——插入 `x` 时，左右邻居 `x-1`、`x+1` 存在则合并，更新两端点的长度，`O(1)` 每次；或并查集。
- 允许最多跳过 / 补 `k` 个缺失的数（如把 `k` 个缺口填上）：在排序去重后的数组上用滑动窗口，窗口内缺口数 `<= k`。

**同模式。** LC 674 最长连续递增序列、LC 298 / 549 二叉树最长连续序列、LC 1 两数之和、LC 217 存在重复元素、LC 947 移除最多的同行或同列石头（并查集）。
