## Q
**LC 470 用 Rand7() 实现 Rand10()**｜Medium · 字节高频

已给方法 `rand7()`，它等概率地返回 `[1, 7]` 内的整数。只准调用 `rand7()`，不能用其他随机方法（比如 `Math.random()`），实现 `rand10()`，等概率地返回 `[1, 10]` 内的整数。测试时 `rand10()` 会被调用 `n` 次（`n` 是调用次数，不是参数），`1 <= n <= 10^5`。例：`n = 3` 时可能得到 `[3, 8, 10]`，结果是随机的，只要求每个值出现的概率都是 `1/10`。进阶：`rand7()` 调用次数的期望是多少？能不能尽量少调用？

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 拒绝采样（rejection sampling）：两次 `rand7()` 拼成 `[1, 49]` 上的均匀整数，只保留 `[1, 40]`（`10` 的倍数），落在 `41..49` 就整个丢掉重来，再取模映射到 `1..10`。期望每次 `rand10()` 调用 `2 × 49/40 = 2.45` 次 `rand7()`。

**识别。** 「用小范围的均匀随机源造大范围的均匀随机数」是固定套路：先把源放大成足够大的等概率格子，再把格子数截成目标范围的整数倍，多出来的丢掉重抽。`rand7() + rand7()`、`rand7() * rand7()` 这类「运算后直接用」的方案都会让分布偏斜，是面试官设的第一个坑。`n <= 10^5` 只是测试次数，没有数据结构，考的是概率直觉。

**推导。** 直觉方案 `rand7() + rand7()` 取值 `2..14`，和为 `8` 的概率是 `7/49`，和为 `2` 只有 `1/49`，不均匀。均匀的本质是「每个输出对应的等概率基本事件一样多」。两次调用得到有序对 `(a, b)`，共 `49` 个等概率结果，用 `(a - 1) * 7 + b`（七进制两位数加一）一一映射到 `1..49`。`49` 不是 `10` 的倍数，就取最大的倍数 `40`，丢掉 `41..49` 重来：丢弃与结果无关，所以条件概率下保留的 `40` 个格子仍然等概率；`(idx - 1) % 10 + 1` 让每个结果恰好对应 `4` 个格子。每一轮用 `2` 次调用、以 `40/49` 的概率成功，次数服从几何分布，期望为 `2 / (40/49) = 2.45`。

```python
import random


def rand7() -> int:                    # 题目提供：[1, 7] 上的均匀随机整数
    return random.randint(1, 7)


def rand10() -> int:
    while True:
        idx = (rand7() - 1) * 7 + rand7()   # 两次调用拼成 1..49 上的均匀分布
        if idx <= 40:                       # 只保留 40 个，拒绝 41..49 后重来
            return (idx - 1) % 10 + 1       # 40 = 4 * 10，每个结果恰好 4 个 idx
```

运行：`49` 个有序对 `(a, b)` 里，`idx <= 40` 的有 `40` 个，`1..10` 各恰好 `4` 个，`9` 个被拒绝；`random.seed(0)` 后调用 `rand10()` `10^5` 次，`1..10` 出现的次数依次是 `10258, 9994, 9876, 10026, 9929, 10150, 9862, 9986, 9735, 10184`，最小值 `1`、最大值 `10`，平均每次消耗 `2.45028` 次 `rand7()`。

**复杂度。** 期望时间 `O(1)`（平均 `2.45` 次 `rand7()`），最坏情况没有上界（可能一直被拒绝，但概率指数衰减）；空间 `O(1)`。

**易错点。**
- `rand7() + rand7()` 或 `rand7() * rand7()`：不均匀。和的分布是 `1, 2, 3, 4, 5, 6, 7, 6, 5, 4, 3, 2, 1`（对应 `2..14`），中间高两头低。
- 拼接写成 `rand7() * 7 + rand7()`：范围变成 `8..56`，起点偏了。要写 `(rand7() - 1) * 7 + rand7()`。
- 取模前不过滤：对 `1..49` 直接 `(idx - 1) % 10 + 1`，结果 `1..9` 各有 `5` 个格子，结果 `10` 只有 `4` 个，`10` 的概率是 `4/49 ≈ 0.082`，不是 `0.1`。

**追问。**
- 期望调用次数：`2.45`；要更少，就别丢掉被拒的 `41..49`——它们是 `1..9` 上的均匀数，再拼一次 `rand7()` 得到 `63` 个格子，保留 `60`，以此类推，期望降到 `329/150 ≈ 2.193`。
- 反过来用 `rand10()` 造 `rand7()`：反复抽，`<= 7` 就返回，否则重抽。
- 任意 `randM`（由 `randN`）：攒够 `N^k >= M` 个格子，取 `M` 的最大整数倍，其余重抽。
