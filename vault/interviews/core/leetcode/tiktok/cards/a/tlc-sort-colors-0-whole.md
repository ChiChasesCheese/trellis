## Q
**LC 75 颜色分类**｜Medium · TikTok 高频

给一个含 `n` 个元素的数组 `nums`，元素是 `0`（红）、`1`（白）、`2`（蓝）。**原地**排序，使相同颜色相邻，并按红、白、蓝（`0, 1, 2`）的顺序排列；不许使用库自带的排序函数。`n == nums.length`，`1 <= n <= 300`，`nums[i]` 为 `0`、`1` 或 `2`。进阶：能否只用常数空间、一趟扫描完成？例：`[2,0,2,1,1,0]` → `[0,0,1,1,2,2]`；`[2,0,1]` → `[0,1,2]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 荷兰国旗问题（Dutch national flag）的三指针划分：`lo` 之前全是 `0`，`hi` 之后全是 `2`，`i` 向右扫描中间未检查的部分；遇到 `0` 就和 `lo` 交换，遇到 `2` 就和 `hi` 交换，遇到 `1` 跳过。一趟扫描，`O(n)` 时间，`O(1)` 空间。

**识别。** 「只有三种取值的数组要原地排好」是三路划分（three-way partition）的标志；进阶明确要求一趟、常数空间，排除了计数后重写（两趟）和通用排序（`O(n log n)`）。取值个数固定为 `3`，可以用区间不变量直接维护。

**推导。** 暴力：调用排序 `O(n log n)`，题目不让用。两趟：先数出 `0, 1, 2` 各有几个，再按个数重写，`O(n)` 但扫了两遍。洞察：把数组分成四段并始终保持——`nums[:lo]` 全是 `0`，`nums[lo:i]` 全是 `1`，`nums[hi+1:]` 全是 `2`，`nums[i:hi+1]` 是还没看过的。遇到 `0` 与 `lo` 位置交换，被换过来的一定是已确认的 `1`，所以 `i` 和 `lo` 都可以前进；遇到 `2` 与 `hi` 交换，被换过来的是没看过的，所以 `i` 不能动，只让 `hi` 收缩。

```python
def sort_colors(nums: list[int]) -> None:
    # 不变量：nums[:lo] 全是 0，nums[lo:i] 全是 1，nums[hi+1:] 全是 2，nums[i:hi+1] 未检查
    lo, i, hi = 0, 0, len(nums) - 1
    while i <= hi:
        if nums[i] == 0:
            nums[lo], nums[i] = nums[i], nums[lo]   # 换来的一定是 1（区间 [lo, i) 全是 1），i 可以前进
            lo += 1
            i += 1
        elif nums[i] == 2:
            nums[i], nums[hi] = nums[hi], nums[i]   # 换来的是未检查的数，i 不能动
            hi -= 1
        else:
            i += 1
```

运行：`[2,0,2,1,1,0]` → `[0, 0, 1, 1, 2, 2]`，`[2,0,1]` → `[0, 1, 2]`，`[0]` → `[0]`，`[1,2,0]` → `[0, 1, 2]`，`[2,2,2]` → `[2, 2, 2]`；长度 `1..8` 的全部 `0/1/2` 数组穷举，结果都与排序一致。

**复杂度。** 时间 `O(n)`：`i` 和 `hi` 总共向中间走 `n` 步，每步常数；空间 `O(1)`。

**易错点。**
- 遇到 `2` 交换后让 `i` 也前进：换来的数还没检查。`[1,2,0]` 这样写得到 `[1, 0, 2]`，正确是 `[0, 1, 2]`（换来的 `0` 被跳过了）。
- 循环条件写成 `i < hi`：`i == hi` 那个位置还没检查，`[2, 0, 1]` 换完第一步变成 `[1, 0, 2]`、`hi = 1`，`i = 0` 走到 `1` 后循环就停了，返回 `[1, 0, 2]`，正确是 `[0, 1, 2]`。
- 遇到 `0` 时以为换来的可能是 `2`：`lo <= i` 且 `nums[lo:i]` 全是 `1`，换来的只可能是 `1`（或 `lo == i` 时就是自己），所以 `i` 才能前进。

**追问。**
- 两趟计数排序：先 `Counter` 或数组计数，再切片赋值 `nums[i:i+k] = [color] * k`，简单但扫两遍。
- `k` 种颜色（LC 75 的推广）：用计数排序，或者对每种颜色做一轮划分，`O(nk)`；`k` 大时用计数 `O(n + k)`。
- 保持稳定（相同颜色的相对顺序不变）：三指针交换不稳定；若必须稳定，用三个列表分桶再拼接，代价是 `O(n)` 额外空间。

**同模式。** LC 283 移动零、LC 26 删除有序数组中的重复项、LC 215 数组中的第 K 个最大元素（快速选择的三路划分）、LC 905 按奇偶排序数组、LC 922 按奇偶排序数组 II。
