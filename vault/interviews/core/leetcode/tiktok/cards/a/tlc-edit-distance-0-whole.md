## Q
**LC 72 编辑距离**｜Medium · LC TikTok 热度 62/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 87 次 · 最近 2026-10-09（CodeTop）

给两个单词 `word1` 和 `word2`，返回把 `word1` 转换成 `word2` 所需的最少操作数。每次操作可以：插入一个字符、删除一个字符、替换一个字符。`0 <= word1.length, word2.length <= 500`，两个单词都由小写英文字母组成。例：`word1 = "horse"`，`word2 = "ros"` → `3`（`horse → rorse → rose → ros`：替换 `h`，删除 `r`，删除 `e`）；`word1 = "intention"`，`word2 = "execution"` → `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维动态规划：`dp[i][j]` 表示 `word1` 的前 `i` 个字符变成 `word2` 的前 `j` 个字符的最少操作数。末尾字符相同时 `dp[i][j] = dp[i-1][j-1]`；不同时 `dp[i][j] = 1 + min(替换 dp[i-1][j-1], 删除 dp[i-1][j], 插入 dp[i][j-1])`。第 0 行 `dp[0][j] = j`，第 0 列 `dp[i][0] = i`，答案是 `dp[m][n]`。`O(m · n)` 时间和空间。

**识别。** 「两个字符串」+「最少操作数」是序列对齐型 DP（和最长公共子序列同一家族）：状态是两个**前缀长度**的组合，操作都发生在末尾，每个操作都把问题缩小成更短前缀的子问题。`m, n <= 500`，`O(m · n) = 25 万` 个状态，绰绰有余。

**推导。** 暴力：递归比较两个串的末尾，不同时三种操作各试一次，复杂度指数级，最坏 `O(3^(m+n))`。浪费：同一个子问题 `(i, j)` 会被大量重复求解，而不同的状态只有 `(m+1)(n+1)` 个 → 记忆化或自底向上填表。洞察：只看末尾字符。相同就不需要操作，问题缩成 `(i-1, j-1)`；不同时，替换让两个末尾对齐并缩成 `(i-1, j-1)`，删除 `word1` 的末尾缩成 `(i-1, j)`，在 `word1` 末尾插入 `word2` 的末尾字符缩成 `(i, j-1)`。边界：`dp[i][0] = i`（全部删掉），`dp[0][j] = j`（全部插入）。

```python
def min_distance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    # dp[i][j]：word1[:i] 变成 word2[:j] 的最少操作数
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i                        # 第 0 列：word1[:i] -> 空串，删 i 个
    for j in range(n + 1):
        dp[0][j] = j                        # 第 0 行：空串 -> word2[:j]，插 j 个
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]         # 末尾相同，不花操作
            else:
                dp[i][j] = 1 + min(dp[i - 1][j - 1],   # 替换
                                   dp[i - 1][j],       # 删除 word1[i-1]
                                   dp[i][j - 1])       # 插入 word2[j-1]
    return dp[m][n]
```

运行：`("horse", "ros")` → `3`，`("intention", "execution")` → `5`，`("", "abc")` → `3`，`("abc", "")` → `3`，`("", "")` → `0`，`("a", "a")` → `0`，两个 500 个字符的随机串也瞬间算完。

**复杂度。** 时间 `O(m · n)`；空间 `O(m · n)`：`(m + 1) × (n + 1)` 的表。

**易错点。**
- 漏掉「替换」，只用删除和插入：`("horse", "ros")` 得到 `4`，`("a", "b")` 得到 `2`，正确是 `3` 和 `1`。
- 边界没有初始化：整张表是 `0`，`("", "abc")` 得到 `0`，`("a", "bcd")` 得到 `1`，正确都是 `3`。第 0 行必须是 `0, 1, 2, …, n`，第 0 列必须是 `0, 1, 2, …, m`。
- 字符相同时仍然加 `1`：`("a", "a")` 得到 `1`，正确是 `0`。

**追问。**
- 输出具体的操作序列：完整的二维表就是回溯的依据，从 `(m, n)` 往回走：字符相同就斜着走；否则看哪一个邻格加 `1` 等于当前值，对应替换 / 删除 / 插入。
- 加权操作（三种操作代价不同）：把 `1 +` 换成各自的代价；允许相邻交换（Damerau-Levenshtein）要多看 `dp[i-2][j-2]`。
- 字符串很长、编辑距离很小：只要距离不超过 `k`，沿对角线只算宽度 `2k + 1` 的带状区域，`O(k · n)`。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
