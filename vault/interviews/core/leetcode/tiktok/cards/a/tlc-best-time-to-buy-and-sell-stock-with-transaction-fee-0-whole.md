## Q
**LC 714 买卖股票的最佳时机含手续费**｜Medium · CodeTop 国内累计 3 次 · 最近 2026-01-04（CodeTop）

给整数数组 `prices`，`prices[i]` 是第 `i` 天的股价；整数 `fee` 是每笔交易的手续费。可以交易任意多次，但同一时间最多持有一股（卖出之后才能再买）；一笔交易指「买入并卖出」的整个过程，只付一次手续费。返回能得到的最大利润。`1 <= prices.length <= 5 * 10^4`，`1 <= prices[i] < 5 * 10^4`，`0 <= fee < 5 * 10^4`。例：`prices = [1,3,2,8,4,9], fee = 2` → `8`（第 0 天买、第 3 天卖，第 4 天买、第 5 天卖：`(8 - 1 - 2) + (9 - 4 - 2) = 8`）；`prices = [1,3,7,5,10,3], fee = 3` → `6`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 状态机 DP（state machine DP）：每天结束时只有「不持股」「持股」两种状态，`dp[i][0]`、`dp[i][1]` 是第 `i` 天结束时处于该状态的最大利润，卖出时扣手续费；答案是 `dp[n-1][0]`，`O(n)`。

**识别。** 「交易次数不限 + 同时最多持一股 + 每笔有额外成本（手续费、冷冻期）」是股票状态机 DP 的信号：每天能做什么只取决于「手里有没有股票」，这就是状态。`n` 到 `5 * 10^4`，要 `O(n)`。

**推导。** 暴力枚举所有买卖日的组合是指数级。无手续费时（LC 122）可以贪心吃掉每一段上涨；有了手续费，把一段连续上涨拆成多笔就要多付手续费，逐天贪心会算错。问题出在逐天决策时没有记住「现在手里有没有股」：同一天，持股与不持股之后能做的事不同。把它做成状态：第 `i` 天不持股 = 昨天就不持股，或者昨天持股、今天卖出（加股价、减手续费）；第 `i` 天持股 = 昨天就持股，或者昨天不持股、今天买入（减股价）。每天 `O(1)` 转移，总共 `O(n)`。

```python
def max_profit(prices: list[int], fee: int) -> int:
    n = len(prices)
    # dp[i][0]: 第 i 天结束时手里没股票的最大利润；dp[i][1]: 手里有股票的最大利润
    dp = [[0, 0] for _ in range(n)]
    dp[0][1] = -prices[0]                      # 第 0 天只能买入或什么都不做
    for i in range(1, n):
        # 不持有 = 昨天就没有，或昨天持有、今天卖出（卖出时付手续费）
        dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] + prices[i] - fee)
        # 持有 = 昨天就持有，或昨天没有、今天买入
        dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i])
    return dp[-1][0]                           # 最后一天不持股一定不比持股差
```

运行：`[1,3,2,8,4,9], 2` → `8`，`[1,3,7,5,10,3], 3` → `6`，`[5], 0` → `0`，`[5,4,3], 1` → `0`，`[1,2], 3` → `0`。

**复杂度。** 时间 `O(n)`：每天两次 `max`；空间 `O(n)`：`n` 行 2 列的表。

**易错点。**
- 照搬 LC 122 的逐天贪心 `sum(max(0, b - a - fee) for a, b in pairwise(prices))`：每段相邻上涨都算成一笔交易、各付一次费，`[1,3,2,8,4,9], 2` 得 `7`（正确 `8`，`1 → 8` 一笔只付一次费）。
- 手续费只扣一次：买入时扣或卖出时扣都行，两边都扣会得 `4`（正确 `8`）。
- 第 0 天持股的初值必须是 `-prices[0]`；写成 `0` 等于白送一股，`[5,4,3], 1` 得 `3`（正确 `0`）。

**追问。**
- 冷冻期（LC 309）：卖出后隔一天才能买，买入改从 `dp[i-2][0]` 转移。
- 最多 `k` 笔（LC 188）：状态加一维「已完成的交易笔数」。
- 每天只依赖前一天，空间可以压到 `O(1)`：见 Python 工具箱「DP 降维」。

**同模式。** LC 122 买卖股票的最佳时机 II、LC 309 含冷冻期、LC 123 买卖股票的最佳时机 III、LC 188 买卖股票的最佳时机 IV。
