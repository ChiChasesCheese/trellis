## Q
**LC 260 只出现一次的数字 III**｜Medium · TikTok 高频

整数数组 `nums` 里恰好有**两个**元素只出现一次，其余所有元素都恰好出现两次。找出这两个元素，顺序任意。要求线性时间、常数额外空间。`2 <= nums.length <= 3 * 10^4`，`-2^31 <= nums[i] <= 2^31 - 1`。例：`[1,2,1,3,2,5]` → `[3,5]`，`[-1,0]` → `[-1,0]`，`[0,1]` → `[1,0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 全部异或得到 `a ^ b`（`a`、`b` 是两个落单数，必不相等所以非零）；取其中最低位的 1，`a` 和 `b` 在这一位上不同，按这一位把数组分成两组，每组恰含一个落单数、其余成对，两组各自异或就得到 `a` 和 `b`。

**识别。** 「其余成对，落单的有两个」是 LC 136 的升级：直接异或只能得到 `a ^ b`，一个等式解不出两个数，要再拆成两个独立的子问题。线性时间常数空间同样排除哈希表。

**推导。** 暴力：`Counter` 数次数，`O(n)` 空间，违反空间。异或全部得到 `x = a ^ b`。`x` 的某位是 1，说明 `a`、`b` 在这位一个是 0 一个是 1。按这一位分组：落单数 `a`、`b` 进不同组；成对的两个相同数每位都相同，必然进同一组。所以每组都是「一个落单 + 若干对」，退化成 LC 136。最低位的 1 用 `x & -x` 直接取。

```python
def single_number_iii(nums: list[int]) -> list[int]:
    both = 0
    for x in nums:
        both ^= x                                    # both == a ^ b，且 a != b 所以 both != 0
    low = both & -both                               # 最低位的 1：a、b 在这一位不同
    a = 0
    for x in nums:
        if x & low:                                  # 只异或这一位为 1 的那一组
            a ^= x
    return [a, both ^ a]                             # 另一个由 a ^ b ^ a 得到，不用再扫一遍
```

运行：`[1,2,1,3,2,5]` → `[3, 5]`，`[-1,0]` → `[-1, 0]`，`[0,1]` → `[1, 0]`，`[-2**31, 2**31-1]` → `[2147483647, -2147483648]`。

**复杂度。** 时间 `O(n)`，扫两遍；空间 `O(1)`。

**易错点。**
- 分组的位必须取自 `a ^ b` 中值为 1 的位：随手取最低位 `x & 1` 会错。`[1,2,1,3,2,5]` 的 `a ^ b = 6`（二进制 `110`），第 0 位是 0，`a`、`b` 在这位相同，按第 0 位分组得 `[6, 0]`，正确 `[3, 5]`。
- 只扫一遍得到 `a` 就返回：要补 `both ^ a` 才是另一个。
- 在 C++ / Java 里 `x & -x` 对 `INT_MIN` 溢出，要用 `long`；Python 的整数无限精度，没有这个问题。

**追问。**
- 为什么落单数有三个就不行：异或只给出一个等式，一位也分不开三个数。
- 不限制空间：`Counter` 更直白，`[v for v, c in Counter(nums).items() if c == 1]`。
- 其余数出现三次、落单一个（LC 137）：按位计数模 3。

**同模式。** LC 136 只出现一次的数字、LC 137 只出现一次的数字 II、LC 268 丢失的数字、LC 389 找不同。
