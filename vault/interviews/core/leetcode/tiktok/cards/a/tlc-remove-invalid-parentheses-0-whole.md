## Q
**LC 301 删除无效的括号**｜Hard · LC TikTok 热度 50/100 · CodeTop 国内累计 12 次 · 最近 2025-05-16（CodeTop）

给由括号和小写字母组成的字符串 `s`，删除**最少数量**的无效括号，使结果字符串有效（括号匹配），返回所有可能的结果（去重，任意顺序）。`1 <= s.length <= 25`，`s` 由小写字母和 `(`、`)` 组成，`s` 中至多含 `20` 个括号。例：`"()())()"` → `["(())()","()()()"]`，`"(a)())()"` → `["(a())()","(a)()()"]`，`")("` → `[""]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先一趟扫描算出**必须删掉**的左括号数 `left_rem` 和右括号数 `right_rem`（最小删除量）；再回溯，对每个括号选「删」或「留」，用剩余删除额度和当前未配对左括号数 `balance` 剪枝，用集合去重。

**识别。** 「返回所有方案」+ 括号总数 `<= 20` → 回溯（`2^20 ≈ 10^6` 可接受）。「删除**最少**」→ 先把最少数量算出来当作剪枝的额度，而不是先生成全部再比较。括号有效性的判定只需要一个计数器 `balance`（栈退化成整数，因为只有一种括号）。

**推导。** 暴力：枚举所有子序列检查有效并保留最长的，`O(2^n · n)` 且没有利用「最少」→ BFS 按删除个数分层：第 `k` 层是删 `k` 个字符的所有串，遇到第一层出现有效串就停，天然最少，但每层都在生成大量重复串 → 直接算出最少要删的 `left_rem`、`right_rem`：扫描时 `(` 计数，遇 `)` 先抵消 `(`，抵消不了的 `)` 必删。然后 DFS：遇到 `(` 可删（`left` 额度减一）或留（`balance + 1`），遇到 `)` 可删或留；`balance < 0`（出现孤立的 `)`）、额度用完前剩余字符不够删、额度为负都剪枝；到末尾要求额度归零、`balance == 0`。不同位置删同样的括号会得到同一个串，所以结果放集合。

```python
def remove_invalid_parentheses(s: str) -> list[str]:
    left_rem = right_rem = 0                   # 至少还要删多少个 ( 和 )
    for ch in s:
        if ch == "(":
            left_rem += 1
        elif ch == ")":
            if left_rem:
                left_rem -= 1                  # 这个 ) 能和前面某个 ( 配对
            else:
                right_rem += 1                 # 前面没有可配的 (，这个 ) 必须删
    delta = {"(": 1, ")": -1}
    res: set[str] = set()                      # 不同位置删同样的括号会得到同一个串，用集合去重
    path: list[str] = []

    def dfs(i: int, left: int, right: int, balance: int) -> None:
        if left < 0 or right < 0 or balance < 0 or left + right > len(s) - i:
            return                             # 删多了、) 已无法挽回、或剩下的字符不够删
        if i == len(s):
            if left == right == balance == 0:
                res.add("".join(path))
            return
        ch = s[i]
        if ch == "(":
            dfs(i + 1, left - 1, right, balance)       # 删掉这个 (
        elif ch == ")":
            dfs(i + 1, left, right - 1, balance)       # 删掉这个 )
        path.append(ch)                                # 保留这个字符
        dfs(i + 1, left, right, balance + delta.get(ch, 0))
        path.pop()

    dfs(0, left_rem, right_rem, 0)
    return list(res)
```

运行（结果排序后）：`"()())()"` → `['(())()', '()()()']`，`"(a)())()"` → `['(a())()', '(a)()()']`，`")("` → `['']`，`"((("` → `['']`，`")))()"` → `['()']`，`"a"` → `['a']`；`"(" * 20` 瞬间返回 `['']`。

**复杂度。** 时间 `O(2^k · n)`，`k <= 20` 是括号数（剪枝后远小于此）；空间 `O(n)` 递归栈，不含结果集。

**易错点。**
- 结果用列表不去重：`"()())()"` 得 `['(())()', '()()()', '()()()']`（删第 4 个或第 5 个 `)` 得同一串）。
- 不限制删除额度、只要结果有效就收集：会混进更短的有效串，如 `"()"`，违反「最少」。
- 漏掉「剩下的字符不够删」的剪枝：`"(" * 20` 会展开约 `2 · 10^6` 次调用，加上它只需要 `41` 次。

**追问。**
- 只要一个答案 / 只要最少删除数：扫描得到的 `left_rem + right_rem` 就是最少删除数，`O(n)`。
- 括号有多种（`()[]{}`）：`balance` 不够用，要换栈；最少删除数的结论不再这么简单。
- 去重更彻底：在同一段连续相同括号里规定只能删前几个，可消去大部分重复路径。

**同模式。** LC 20 有效的括号、LC 22 括号生成、LC 921 使括号有效的最少添加、LC 1249 移除无效的括号。
