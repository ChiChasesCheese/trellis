## Q
**LC 593 有效的正方形**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 2 次 · 最近 2026-08-23（面试记录）

给平面上四个点 `p1`、`p2`、`p3`、`p4`，每个点是 `[x, y]`，**不保证任何顺序**。判断它们能否构成正方形（四条边等长、四个角都是 90 度）。`p1.length == p2.length == p3.length == p4.length == 2`，`-10^4 <= xi, yi <= 10^4`。例：`[0,0],[1,1],[1,0],[0,1]` → `true`；`[0,0],[1,1],[1,0],[0,12]` → `false`；`[1,0],[-1,0],[0,1],[0,-1]` → `true`（斜放的正方形）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 点没有顺序，就别去排顶点，改看顺序无关的量：四个点两两之间的 6 个**平方距离**，排序后必须是 `[s, s, s, s, 2s, 2s]` 且 `s > 0`（四条边、两条对角线）。

**识别。** 「固定个数的点 + 输入不给顺序 + 判定几何形状」：点数是常数，复杂度不是问题，难点是怎样得到一个**与顺序无关**的判据。坐标是整数，用平方距离全程整数运算，不开根号、不碰浮点误差。

**推导。** 暴力：枚举 4! 种顶点顺序，逐个验证相邻边等长且相邻边垂直（点积为 0），能过但代码长、易漏退化情形 → 浪费在「找顺序」上 → 正方形的 6 个两两距离只有两种值：4 条边 `s` 和 2 条对角线 `2s`（勾股定理，平方距离的 2 倍）→ 排序后一次比较即可，`O(1)`。

```python
from itertools import combinations


def valid_square(p1: list[int], p2: list[int], p3: list[int], p4: list[int]) -> bool:
    def dist2(a: list[int], b: list[int]) -> int:
        return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2   # 平方距离，全程整数

    d = sorted(dist2(a, b) for a, b in combinations((p1, p2, p3, p4), 2))   # 6 条两两距离
    # 四条边相等且 > 0（排除重合点），两条对角线相等且恰为边平方的 2 倍
    return d[0] > 0 and d[0] == d[3] and d[4] == d[5] == 2 * d[0]
```

运行：三个示例 → `True`、`False`、`True`；四个点全是 `[0,0]` → `False`；`[0,0],[1,0],[2,0],[3,0]` → `False`；四个角取 `±10^4` 的正方形 → `True`；菱形 `[0,0],[2,9],[9,2],[11,11]` → `False`。

**复杂度。** 时间 `O(1)`（6 个距离，排序 6 个数）；空间 `O(1)`。

**易错点。**
- 漏掉 `d[0] > 0`：四个点全重合时 6 个距离全是 `0`，满足「四条边相等、对角线是边的 2 倍」，会错判为 `True`（正确 `False`）。
- 只检查四条边相等：菱形 `[0,0],[2,9],[9,2],[11,11]` 的 6 个平方距离是 `[85,85,85,85,98,242]`，四条边相等但对角线不等，只查边会得到 `True`（正确 `False`）。对角线必须同时检查。

**追问。**
- 给 `n` 个点，问其中有没有四个点构成正方形：把点放进集合，枚举两点当一条边，旋转 90 度算出另外两个顶点，查集合，`O(n^2)`。
- 坐标是浮点数：平方距离比较要带容差，或乘以公倍数换成整数；整数坐标永远优先用精确比较。
- 判断矩形（不要求等边）：对角线等长且互相平分（两条对角线的中点重合）。

**同模式。** LC 469 凸多边形、LC 939 最小面积矩形、LC 963 最小面积矩形 II、LC 1232 缀点成线。
