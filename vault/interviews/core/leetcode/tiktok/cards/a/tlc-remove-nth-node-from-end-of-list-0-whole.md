## Q
**LC 19 删除链表的倒数第 N 个节点**｜Medium · 字节 高频

给一个链表的头结点 `head`，删除链表的倒数第 `n` 个结点，返回新链表的头结点。链表结点数为 `sz`，`1 <= sz <= 30`，`0 <= Node.val <= 100`，`1 <= n <= sz`。进阶：只扫描一趟。例：`head = [1,2,3,4,5]`，`n = 2` → `[1,2,3,5]`；`head = [1]`，`n = 1` → `[]`；`head = [1,2]`，`n = 1` → `[1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 加一个哑结点（dummy）指向头结点，让快指针先走 `n` 步，然后快慢指针同速前进；快指针停在最后一个结点时，慢指针正好停在待删结点的前一个，`slow.next = slow.next.next` 删掉它。一趟扫描，`O(sz)`。

**识别。** 「倒数第 `n` 个」在单链表里无法直接定位，因为不知道长度；「只扫描一趟」是在要求用**双指针保持固定间距**：两个指针相距 `n`，前一个到末尾时后一个就在倒数第 `n` 的位置。「删除」需要前驱结点，而头结点没有前驱，这是加哑结点的信号。

**推导。** 暴力：第一趟数出长度 `L`，第二趟走到第 `L - n - 1` 个结点删除下一个，两趟 `O(L)`，能过但不满足进阶。浪费在“先数长度”。改成间距法：快指针先走 `n` 步，之后两个指针同步走，快指针到尾时，慢指针离尾部恰好也是 `n` 个结点之差。因为要停在待删结点的**前一个**，快指针要停在最后一个结点（`fast.next` 为空）而不是越过它。待删的可能是头结点，所以从哑结点出发，哑结点充当头结点的前驱。

```python
def remove_nth_from_end(head: ListNode | None, n: int) -> ListNode | None:
    dummy = ListNode(0, head)               # 哑结点：删头结点时不用特判
    fast = slow = dummy
    for _ in range(n):                      # fast 先走 n 步，和 slow 拉开 n 的间距
        fast = fast.next
    while fast.next:                        # fast 停在最后一个结点时，slow 正好在待删结点的前一个
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next
    return dummy.next
```

运行：`[1,2,3,4,5]`、`n = 2` → `[1, 2, 3, 5]`；`[1]`、`n = 1` → `[]`；`[1,2]`、`n = 1` → `[1]`；`[1,2]`、`n = 2`（删头）→ `[2]`。

**复杂度。** 时间 `O(sz)`，一趟扫描；空间 `O(1)`。

**易错点。**
- 没有哑结点，删除头结点会出错：`[1]`、`n = 1` 时快指针走完 `n` 步变成 `None`，随后 `fast.next` 抛 `AttributeError: 'NoneType' object has no attribute 'next'`。哑结点让头结点也有前驱。
- 间距和停止条件要配套：从哑结点出发、先走 `n` 步、条件 `while fast.next`，三者一起保证慢指针停在待删结点之前；改任何一个都会偏一位。
- 返回 `dummy.next` 而不是 `head`：头结点被删时 `head` 已经过期。

**追问。**
- `n` 可能大于链表长度（非法输入）：先走的 `n` 步里一旦 `fast` 变成 `None` 就直接返回原链表。
- 用递归怎么写：回溯时计数，计到 `n` 的那层删除，需要 `O(sz)` 栈空间。
- 同样的间距技巧：LC 876 链表的中间结点（快指针每次两步）、剑指 Offer 22 链表中倒数第 k 个节点、LC 141 环形链表。

**同模式。** LC 876 链表的中间结点、LC 61 旋转链表、LC 141 / 142 环形链表、LC 160 相交链表。
