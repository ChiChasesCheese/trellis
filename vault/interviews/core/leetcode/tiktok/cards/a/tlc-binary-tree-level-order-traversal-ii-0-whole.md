## Q
**LC 107 二叉树的层序遍历 II**｜Medium · 字节 高频

给二叉树的根结点 `root`，返回其结点值**自底向上的层序遍历**：从叶子所在层到根所在层，逐层，每层从左到右。树中结点数在 `[0, 2000]`，`-1000 <= Node.val <= 1000`。例：`root = [3,9,20,null,null,15,7]` → `[[15,7],[9,20],[3]]`；`root = [1]` → `[[1]]`；`root = []` → `[]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 广度优先搜索（BFS）按层走：用一个列表 `level` 装当前层的全部结点，取出它们的值作为一层，再用它们的孩子拼出下一层；最后把按「自顶向下」收集好的各层整体反转。`O(n)`。

**识别。** 「层序」就是 BFS，「自底向上」只是把 LC 102 的结果倒过来。按层分组的难点是知道每层的边界：与其用一个队列再记录当前层大小，不如直接让一个列表代表一整层，处理完整层再生成下一层。

**推导。** 暴力：DFS 递归，带上深度，把值放进「深度 → 列表」，最后按深度倒序输出；思路对，但深度可达 `2000`，超过 Python 默认递归深度 `1000`，链形的树会 `RecursionError`。BFS 没有这个问题：按层处理，每个结点进出各一次。收集顺序是自顶向下，题目要自底向上，所以最后整体反转；反转的是外层的「层列表」，对 `O(层数)`，不是 `O(n)`。

```python
def level_order_bottom(root: TreeNode | None) -> list[list[int]]:
    ans: list[list[int]] = []
    level = [root] if root else []
    while level:
        ans.append([node.val for node in level])              # 这一层的值，从左到右
        level = [child for node in level for child in (node.left, node.right) if child]   # 下一层
    return ans[::-1]                                          # 自顶向下收集，最后整体反转
```

运行：`[3,9,20,null,null,15,7]` → `[[15, 7], [9, 20], [3]]`，`[1]` → `[[1]]`，`[]` → `[]`，`[1,2,3,4,null,null,5]` → `[[4, 5], [2, 3], [1]]`；2000 个结点的单链树 → 2000 层，不会递归溢出。

**复杂度。** 时间 `O(n)`：每个结点被访问一次；空间 `O(n)`：答案占 `n`，额外的 `level` 最多等于最宽的一层。

**易错点。**
- 空树要返回 `[]`，不是 `[[]]`：`level = [root] if root else []` 让空树直接跳过循环。
- 把整条 BFS 序列反转得不到答案：`[3,9,20,15,7]` 反转成 `[7,15,20,9,3]`，既丢了分层，层内顺序也反了；正确是 `[[15,7],[9,20],[3]]`。
- 展开孩子时漏掉 `if child`：`None` 会混进下一层，`node.val` 会报 `AttributeError`。

**追问。**
- 不想最后反转：用 `deque`，每收集一层就 `appendleft`，最后 `list(ans)`。
- 想用 DFS：必须带深度参数，并注意递归深度可达 `2000`，要改成显式栈或提高递归上限。
- 之字形层序（LC 103）：奇数层把该层的值反转；右视图（LC 199）：每层只取最后一个。

**同模式。** LC 102 二叉树的层序遍历、LC 103 之字形层序遍历、LC 199 二叉树的右视图、LC 429 N 叉树的层序遍历、LC 515 在每个树行中找最大值。
