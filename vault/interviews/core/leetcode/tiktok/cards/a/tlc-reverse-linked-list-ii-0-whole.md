## Q
**LC 92 反转链表 II**｜Medium · LC TikTok 热度 38/100 · CodeTop 国内累计 80 次 · 最近 2026-05-12（CodeTop）

给单链表的头指针 `head` 和两个整数 `left`、`right`（`left <= right`），反转从位置 `left` 到位置 `right` 的链表节点（位置从 `1` 开始），返回反转后的链表。链表节点数 `n` 满足 `1 <= n <= 500`，`-500 <= Node.val <= 500`，`1 <= left <= right <= n`。例：`head = [1,2,3,4,5]`，`left = 2`，`right = 4` → `[1,4,3,2,5]`；`head = [5]`，`left = 1`，`right = 1` → `[5]`。进阶：能否一趟扫描完成。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 哑节点加**头插法**：让 `pre` 停在第 `left - 1` 个节点，`cur` 是区间里原来的第一个节点；重复 `right - left` 次，把 `cur` 后面的那个节点摘下来，插到 `pre` 的后面。一趟扫描，`O(n)` 时间，`O(1)` 空间。

**识别。** 「反转链表的一段」是反转链表（LC 206）的区间版。`left` 可能等于 `1`，此时头节点会变，所以需要哑节点给第一个节点也提供一个「前一个节点」。进阶要求一趟扫描：不先去找右端点，而是边走边反转。

**推导。** 暴力：把区间的值取出来反转再写回，`O(n)`，但改的是值不是指针，面试不会认可。三段法：找到 `pre` 和区间的两端，反转区间，再把反转后的头接到 `pre`、尾接到区间后面的节点 → 要同时保存四个端点，接头接尾最容易漏。头插法的洞察：区间里原来的第一个节点 `cur` 在反转后恰好是区间的尾，它不需要移动；只要依次把 `cur` 后面的节点摘下来插到区间最前面（`pre` 后面），`cur` 就被一步步挤到了末尾，`cur.next` 始终指向还没处理的部分，尾部的接续自动完成。

```python
def reverse_between(head: ListNode | None, left: int, right: int) -> ListNode | None:
    dummy = ListNode(0, head)           # 哑节点：left = 1 时也有"前一个节点"
    pre = dummy
    for _ in range(left - 1):           # pre 停在第 left - 1 个节点
        pre = pre.next
    cur = pre.next                      # cur 始终是区间里原来的第一个节点，会被一步步挤到后面
    for _ in range(right - left):       # 头插法：把 cur 后面的节点依次插到 pre 后面
        nxt = cur.next
        cur.next = nxt.next
        nxt.next = pre.next
        pre.next = nxt
    return dummy.next
```

运行：`[1,2,3,4,5]`，`left = 2`，`right = 4` → `[1, 4, 3, 2, 5]`，`[5]`，`1`，`1` → `[5]`，`[1,2,3,4,5]`，`1`，`5` → `[5, 4, 3, 2, 1]`，`[1,2]`，`1`，`2` → `[2, 1]`，`[1,2,3]`，`2`，`2` → `[1, 2, 3]`。

**复杂度。** 时间 `O(n)`，至多走 `right` 步；空间 `O(1)`。

**易错点。**
- 不用哑节点：`left = 1` 时没有 `pre`，直接拿 `head` 当 `pre` 会把区间错位。`[1,2,3,4,5]` 反转 `1..3` 得到 `[1, 4, 3, 2, 5]`，正确是 `[3, 2, 1, 4, 5]`。
- 三段法反转后忘记把区间尾巴接回后面的节点：`[1,2,3,4,5]` 反转 `2..4` 得到 `[1, 4, 3, 2]`，丢了 `5`。
- 头插法里插入的是 `cur.next`（也就是 `nxt`），插入位置是 `pre.next`，不是 `cur.next`。四行赋值的顺序不能换：先让 `cur` 跳过 `nxt`，再把 `nxt` 接到当前区间头，最后更新 `pre.next`。
- 循环次数是 `right - left`，不是 `right - left + 1`：`cur` 本身不动，要挪的是它后面的 `right - left` 个节点。

**追问。**
- 整条反转（LC 206）：`left = 1`、`right = n` 的特例，也可以用 `prev, cur` 两指针写成更短的迭代。
- 每 `k` 个一组反转（LC 25）：对每一组做一次头插法，组与组之间保持链接；不足 `k` 个的最后一组保持不动。
- 递归写法：先实现「反转以 `head` 开头的前 `n` 个节点」，再对 `left > 1` 的情况递归到 `head.next`；深度至多 `500`，不会超过 Python 默认递归上限。

**同模式。** LC 206 反转链表、LC 25 K 个一组翻转链表、LC 24 两两交换链表中的节点、LC 234 回文链表、LC 143 重排链表。
