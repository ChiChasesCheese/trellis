## Q
**LC 1405 最长快乐字符串**｜Medium · LC TikTok 热度 68/100 · CodeTop 国内累计 1 次 · 最近 2021-04-14（CodeTop）

如果字符串中不含 `'aaa'`、`'bbb'`、`'ccc'` 这样的子串，就称它是「快乐字符串」。给三个整数 `a`、`b`、`c`，返回**任意一个**满足下列全部条件的字符串 `s`：`s` 是尽可能长的快乐字符串；`s` 中最多有 `a` 个 `'a'`、`b` 个 `'b'`、`c` 个 `'c'`；`s` 只含 `'a'`、`'b'`、`'c'`。如果不存在这样的字符串，返回 `""`。

约束：`0 <= a, b, c <= 100`，`a + b + c > 0`。

例：`a = 1, b = 1, c = 7` → `"ccaccbcc"`（`"ccbccacc"` 也对）；`a = 2, b = 2, c = 1` → `"aabbc"`；`a = 7, b = 1, c = 0` → `"aabaa"`（唯一答案）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 贪心 + 最大堆：每次取剩余最多的字母放进去，让它尽快被耗尽、不成为瓶颈；如果它已经连着放了两个，就改放次多的字母垫一个，再继续。放不了（没有别的字母可垫）就结束。`O(N)`。

**识别。** 「同一字母不能连续出现 3 次」+「尽可能长」+「只有三种字母、个数有限」→ **贪心 + 堆**（每步取当前最多的那种）：字母越多越容易被迫连续，所以先用掉它们，用其它字母去隔开。同类题 LC 767 重构字符串、LC 984 不含 AAA 或 BBB 的字符串。

**推导。** 暴力：DFS 枚举每一位放什么，指数级；用状态 `(a, b, c, 末尾字母, 连续次数)` 记忆化可以到 `O(a·b·c·6)`，`100^3` 的规模太大。贪心：若每步放剩余最多的字母，个数最多的字母被消耗得最快，最不容易在后面被迫连续或剩下。放第三个连续字母是违规的，所以当最多的字母已经连着两个，就用次多的字母垫一个。不垫（直接停）会少放字符；垫一个后最多的字母放回去继续。只剩下一种字母且已连着两个时，没法再放，结束。

```python
def longest_diverse_string(a: int, b: int, c: int) -> str:
    # 最大堆（用负数模拟）：(-剩余个数, 字母)；个数为 0 的字母不入堆
    heap = [(-n, ch) for n, ch in ((a, "a"), (b, "b"), (c, "c")) if n]
    heapq.heapify(heap)
    out: list[str] = []
    while heap:
        n, ch = heapq.heappop(heap)                    # 剩余最多的字母
        if out[-2:] == [ch, ch]:                       # 末尾已经连着两个 ch，不能再放
            if not heap:
                break                                  # 没有别的字母可垫：只能结束
            n2, ch2 = heapq.heappop(heap)              # 垫一个次多的字母
            out.append(ch2)
            if n2 + 1:
                heapq.heappush(heap, (n2 + 1, ch2))
            heapq.heappush(heap, (n, ch))              # 最多的字母原样放回
        else:
            out.append(ch)
            if n + 1:
                heapq.heappush(heap, (n + 1, ch))
    return "".join(out)
```

运行：`a=1, b=1, c=7` → `'ccaccbcc'`，`a=2, b=2, c=1` → `'ababc'`，`a=7, b=1, c=0` → `'aabaa'`，`a=0, b=0, c=1` → `'c'`，`a=0, b=0, c=5（只有一种字母）` → `'cc'`，`a=100, b=100, c=100 的长度` → `300`。

**复杂度。** 时间 `O(N log 3) = O(N)`，`N = a + b + c` 是总字符数：每放一个字符做常数次对大小为 `≤ 3` 的堆的操作；空间 `O(N)`（输出）+ `O(1)`（堆）。

**易错点。**
- 忘了连续个数限制，永远取最多的：`a=1, b=1, c=7` 得 `ccccccabc`，含 `ccc`，不合法。
- 遇到上限就直接结束：`1,1,7` 只得 `cc`（长度 2），正确最长 `8`；上限只意味着「这一步不能放它」，不是「整个字符串结束」。
- 垫了次多的字母后忘记把最多的字母放回堆：`1,1,7` 得 `ccab`（长度 4），正确是 `8`；最多的字母还没放完，必须推回堆。
- 把个数为 `0` 的字母留在堆里：`a=7, b=1, c=0` 里 `c` 的计数为 `0`，被取出来放进字符串，违反了「最多 `c` 个」的限制。入堆前先过滤掉 `0`，减 1 后也只在非 `0` 时放回。

**追问。**
- 字母种类推广到 `k` 种、每种连续上限 `r`：堆仍是同一思路，只是「末尾已连续 `r` 个」时改取次多的；堆操作 `O(log k)`。
- 只问最长长度、不要具体字符串：可以用公式式的贪心：两种较少字母的总和可用来隔开最多的字母；用堆模拟更不容易错。
- 必须恰好用完所有字母（LC 767 重构字符串，相邻不同）：条件改成相邻不同，若最多的字母超过 `⌈N/2⌉` 则无解；堆的做法类似。

**同模式。** LC 767 重构字符串、LC 984 不含 AAA 或 BBB 的字符串、LC 621 任务调度器、LC 358 K 距离间隔重排字符串、LC 1054 距离相等的条形码。
