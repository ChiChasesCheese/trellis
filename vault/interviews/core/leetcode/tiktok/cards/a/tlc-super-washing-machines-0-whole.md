## Q
**LC 517 超级洗衣机**｜Hard · CodeTop 国内累计 1 次 · 最近 2026-04-26（CodeTop）

`n` 台洗衣机排成一排，`machines[i]` 是第 `i` 台里的衣服件数。每一步可以任选 `m` 台（`1 <= m <= n`），被选中的每台**同时**把自己的一件衣服送到相邻的一台。求让所有洗衣机的衣服件数相等的最少步数；做不到返回 `-1`。`n == machines.length`，`1 <= n <= 10^4`，`0 <= machines[i] <= 10^5`。 例：`[1,0,5]` → `3`（第 1 步 `5` 向左送一件得 `[1,1,4]`；第 2 步中间和右边同时向左送得 `[2,1,3]`；第 3 步右边向左送得 `[2,2,2]`）；`[0,3,0]` → `2`；`[0,2,0]` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 总数不能被 `n` 整除就返回 `-1`；否则设 `avg = total / n`，答案是两类瓶颈的最大值：每条相邻边必须流过的件数 `|前缀余量|`（一条边每步只过一件），以及每台机器的多余件数 `machines[i] - avg`（一台机器每步只送出一件）。`O(n)`。

**识别。** 「每步很多位置**并行**移动、每个位置每步最多动一件」→ 不要模拟，找**瓶颈下界**：哪些量每一步最多只能减少 1？`n` 到 `10^4`、件数到 `10^5` → 模拟或搜索不可行，要 `O(n)` 的公式。

**推导。** 暴力 BFS 搜索状态，状态数随件数爆炸。换个角度：第 `i` 台与第 `i + 1` 台之间的那条边，左边 `i + 1` 台的总余量 `flow = Σ(machines[0..i] - avg)` 必须全部经这条边送到右边（负数则反向），每步一条边最多过一件，所以步数 `>= |flow|`。另一个瓶颈在机器自身：多出 `surplus` 件的机器每步只能送出一件（向左右两边送也只算一件），所以步数 `>= surplus`。缺衣服的机器却能同时从两边各收一件，不构成同样紧的下界，所以这里用 `surplus` 而不是 `|surplus|`。两类下界取最大值，并且可以同时达到。

```python
def find_min_moves(machines: list[int]) -> int:
    total, n = sum(machines), len(machines)
    if total % n:                          # 总数不能均分，永远做不到
        return -1
    avg = total // n
    ans = flow = 0
    for m in machines:
        surplus = m - avg                  # 这台多（正）或缺（负）几件
        flow += surplus                    # 前缀净余量：必须从它右侧这条边流过去的件数（负数表示向左流）
        # 一条边每步最多过 1 件 → |flow|；一台机器每步最多送出 1 件 → surplus
        ans = max(ans, abs(flow), surplus)
    return ans
```

运行：`[1,0,5]` → `3`，`[0,3,0]` → `2`，`[0,2,0]` → `-1`，`[2,2,0,0]` → `2`，`[3,0,3]` → `1`，`[4]` → `0`。

**复杂度。** 时间 `O(n)`：一趟扫描；空间 `O(1)`。

**易错点。**
- 只看边的流量 `|flow|`：`[0,3,0]` 得到 `1`（正确 `2`）。中间那台要送出 2 件，每步只能送 1 件。
- 用 `|surplus|` 代替 `surplus`：`[3,0,3]` 得到 `2`（正确 `1`）。中间那台缺 2 件，但左右两台能同时各送 1 件进来。
- 只看机器不看边：`[2,2,0,0]` 得到 `1`（正确 `2`）。两件衣服都要穿过正中间那条边。

**追问。**
- 每步全局只能移动一件衣服：答案变成总搬运量 `Σ|flow|`，每条边的流量逐件累加。
- 排成一个环、求最少的总搬运件数：设第一条边的流量为未知数 `x`，各边流量为 `x - c_i`，最小化 `Σ|x - c_i|` 取 `c_i` 的中位数。
- 换成一棵树（LC 979 在二叉树中分配硬币）：每条边的流量是子树的余量，总搬运量是所有边 `|余量|` 之和，后序遍历求。

**同模式。** LC 979 在二叉树中分配硬币、LC 462 最小操作次数使数组元素相等 II、LC 453 最小操作次数使数组元素相等。
