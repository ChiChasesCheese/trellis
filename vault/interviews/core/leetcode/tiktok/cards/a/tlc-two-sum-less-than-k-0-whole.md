## Q
**LC 1099 小于 K 的两数之和**｜Easy · CodeTop 国内累计 2 次 · 最近 2026-05-14（CodeTop）

给整数数组 `nums` 和整数 `k`，返回最大的和 `sum`，满足存在 `i < j` 使得 `nums[i] + nums[j] = sum` 且 `sum < k`；如果不存在这样的 `i, j`，返回 `-1`。`1 <= nums.length <= 100`，`1 <= nums[i] <= 1000`，`1 <= k <= 2000`。例：`nums = [34,23,1,24,75,33,54,8]`，`k = 60` → `58`（`34 + 24`）；`nums = [10,20,30]`，`k = 15` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 排序后对撞双指针：`lo` 在最小端、`hi` 在最大端，和 `< k` 就记录并右移 `lo`（让和变大去逼近 `k`），否则左移 `hi`（让和变小），每步排除一个端点，一遍扫描。`O(n log n)`（排序主导）。

**识别。** 「两个数的和与目标比较、求最接近 / 最大的」是两数之和家族：无序时想哈希表，但这里是**不等式**（`< k`）而不是相等，哈希查不了「小于」；排序后双指针可以。`n <= 100` 说明 `O(n^2)` 暴力也能过，面试里先说暴力再优化。

**推导。** 暴力：枚举所有数对，取小于 `k` 的最大和，`O(n^2)` → 排序后和有单调性：固定 `hi`，`lo` 越大和越大 → 若 `nums[lo] + nums[hi] < k`，那 `lo` 与任何 `<= hi` 的右端搭配都不会更好（和都不超过这一个），`lo` 可以排除，记录这个和后 `lo += 1`；若 `>= k`，`hi` 与任何 `>= lo` 的左端搭配都不合法（和更大），`hi` 可以排除 → 每步排除一个，`O(n)` 扫描，加排序 `O(n log n)`。

```python
def two_sum_less_than_k(nums: list[int], k: int) -> int:
    nums = sorted(nums)                         # 排序后用对撞双指针；sorted 不改动调用者的数组
    lo, hi = 0, len(nums) - 1
    best = -1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s < k:
            best = max(best, s)                 # 合法：记录；lo 与更小的 hi 搭配只会更小，lo 可以排除
            lo += 1
        else:
            hi -= 1                             # 太大：hi 与任何更大的 lo 搭配都太大，hi 可以排除
    return best
```

运行：示例 1 → `58`，示例 2 → `-1`，`[5]`、`k = 10` → `-1`，`[10,20,30]`、`k = 30` → `-1`，`[1,1]`、`k = 3` → `2`，`[1,1]`、`k = 2` → `-1`。

**复杂度。** 时间 `O(n log n)`（排序）+ `O(n)`（双指针）；空间 `O(n)`（`sorted` 的拷贝）。

**易错点。**
- 条件写成 `s <= k`：题目要求**严格小于**，`[10,20,30]`、`k = 30` 得到 `30`，正确是 `-1`。
- `best` 初值写成 `0`：没有合法数对时应返回 `-1`，`[10,20,30]`、`k = 15` 会返回 `0`。
- 找到合法和之后左右指针一起移动（`lo += 1; hi -= 1`）：会漏掉 `lo` 与更小 `hi` 的搭配，`[1,2,3]`、`k = 11` 得到 `4`，正确是 `5`（`2 + 3`）。

**追问。**
- 返回具体的两个数 / 下标：更新 `best` 时记录 `(nums[lo], nums[hi])`；要原下标就先对下标排序。
- 统计和小于 `k` 的数对个数：`nums[lo] + nums[hi] < k` 时，`lo` 与 `lo + 1` 到 `hi` 的每个数配对都合法（它们都不超过 `nums[hi]`），一次加 `hi - lo` 对，再 `lo += 1`；否则 `hi -= 1`。
- 用 `bisect`：对每个 `x`，在它前面的有序部分用 `bisect_left` 找 `< k - x` 的最大数，`O(n log n)`。

**同模式。** LC 1 两数之和、LC 167 两数之和 II、LC 15 三数之和、LC 16 最接近的三数之和、LC 259 较小的三数之和。
