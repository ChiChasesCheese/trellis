## Q
**LC 518 零钱兑换 II**｜Medium · 字节高频

给整数数组 `coins`（不同面额的硬币）和整数 `amount`，求能凑成总金额的**硬币组合数**，凑不出返回 `0`；每种面额的硬币有无限个，结果保证在 32 位有符号整数内。`1 <= coins.length <= 300`，`1 <= coins[i] <= 5000`，`coins` 中的值互不相同，`0 <= amount <= 5000`。例：`amount = 5`、`coins = [1,2,5]` → `4`（`5`、`2+2+1`、`2+1+1+1`、`1*5`）；`amount = 3`、`coins = [2]` → `0`；`amount = 10`、`coins = [10]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 完全背包（unbounded knapsack）里数「组合」：二维 DP，`dp[i][a]` 是只用前 `i` 种硬币凑出金额 `a` 的组合数，`dp[i][a] = dp[i-1][a] + dp[i][a - coin_i]`（不用第 `i` 种，或者至少用一枚、剩下的仍可再用第 `i` 种）；行代表「用到第几种硬币」，所以一个组合只按固定的硬币顺序被数一次。`O(n · amount)`。

**识别。** 「每种物品无限个」+「凑成总额」+「数方案数」是完全背包的计数形式。关键是**组合还是排列**：题目问的是组合（`1+2` 与 `2+1` 算同一种），所以表的行是硬币、列是金额；若问排列（LC 377）则状态不再有「用到第几种硬币」这一维，只有 `dp[a]`。`n * amount` 约 `1.5 * 10^6` 格，二维表足够。

**推导。** 暴力：递归枚举每种硬币用几个，指数级 → 浪费：同一个（剩余金额，当前硬币下标）被重复求解 → 状态 `dp[i][a]`：只用前 `i` 种硬币凑 `a` 的组合数。第 `i` 种硬币要么一枚都不用（`dp[i-1][a]`），要么至少用一枚：拿掉一枚后剩下 `a - coin`，而且剩下的仍可再用第 `i` 种，所以是同一行的 `dp[i][a - coin]`。边界：第 0 行（一种硬币都没有）除了 `dp[0][0] = 1` 全是 `0`；第 0 列每一行都是 `1`（凑 `0` 元只有「什么都不拿」一种）。答案在 `dp[n][amount]`。

```python
def change(amount: int, coins: list[int]) -> int:
    m = len(coins)
    # dp[i][a]：只用前 i 种硬币，凑出金额 a 的组合数
    dp = [[0] * (amount + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = 1                        # 凑出 0 元只有一种：什么都不拿
    for i, coin in enumerate(coins, 1):
        for a in range(1, amount + 1):
            dp[i][a] = dp[i - 1][a]         # 不用第 i 种
            if a >= coin:
                dp[i][a] += dp[i][a - coin]  # 至少用一枚：剩下的仍可再用第 i 种（同一行）
    return dp[m][amount]
```

运行：`(5, [1,2,5])` → `4`，`(3, [2])` → `0`，`(10, [10])` → `1`，`(0, [7])` → `1`。

**复杂度。** 时间 `O(n · amount)`；空间 `O(n · amount)`：`(n + 1) × (amount + 1)` 的表。

**易错点。**
- 转移写成 `dp[i-1][a - coin]`（上一行）：每种硬币至多用一枚，变成 0/1 背包。`(5, [1,2,5])` 得到 `1`，正确是 `4`。「剩下的还能再用第 `i` 种」必须读同一行 `dp[i][a - coin]`。
- 第 0 列没有置 `1`（只置了 `dp[0][0] = 1`）：`dp[i][0]` 是 `0`，后面所有的加法都从 `0` 开始，`(5, [1,2,5])` 得到 `0`，`(0, [7])` 也得到 `0`，正确分别是 `4` 和 `1`。`amount = 0` 的答案是 `1`（空组合）。
- 漏掉 `if a >= coin`：`a - coin` 为负时 Python 不报错，而是从行尾读数。`(1, [3])` 读到 `dp[1][-2]`，即 `dp[1][0] = 1`，得到 `1`，正确是 `0`。
- 先固定金额、再枚举最后一枚硬币（表里没有「用到第几种硬币」这一维）：数出的是排列，`(3, [1,2])` 得到 `3`（`1+1+1`、`1+2`、`2+1`），正确是 `2`。

**追问。**
- 数排列（LC 377）：两层循环互换，外层金额、内层硬币。
- 最少硬币数（LC 322）：同样的完全背包，状态变成 `min`，初值 `inf`。
- 每种硬币只能用一次（0-1 背包）：转移读上一行 `dp[i-1][a - coin]`，见易错点第一条。
- 空间可以压到 O(amount)：见 Python 工具箱「DP 降维」。

**同模式。** LC 322 零钱兑换、LC 377 组合总和 IV、LC 279 完全平方数、LC 494 目标和。
