## Q
**LC 120 三角形最小路径和**｜Medium · CodeTop 国内累计 18 次 · 最近 2026-08-03（CodeTop）

给三角形 `triangle`，求自顶向下的最小路径和。每一步只能移动到下一行中**相邻**的结点：当前在第 `i` 列，下一步可到下一行的第 `i` 列或第 `i + 1` 列。`1 <= triangle.length <= 200`，`triangle[0].length == 1`，`triangle[i].length == triangle[i - 1].length + 1`，`-10^4 <= triangle[i][j] <= 10^4`。例：`[[2],[3,4],[6,5,7],[4,1,8,3]]` → `11`（`2 + 3 + 5 + 1`）；`[[-10]]` → `-10`。进阶：只用 `O(n)` 额外空间（`n` 为总行数）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 自底向上的二维 DP：`dp[i][j]` 是从格子 `(i, j)` 走到最底行的最小路径和；最底行是基础行，往上每个格子等于自己加上下方两个相邻格中较小的一个；答案是顶点 `dp[0][0]`。`O(n^2)` 时间，`O(n^2)` 空间。

**识别。** 「只能走到相邻位置」+「路径和最小」是网格 / 三角形上的最优路径 DP：到达某格的最优值只依赖相邻的前驱（或后继）。自顶向下要处理每行两端只有一个前驱的边界；**自底向上**每个格子恰好有两个后继，没有边界特判，最后答案直接在 `dp[0][0]`。`n <= 200`，格子数约 `2 * 10^4`。

**推导。** 暴力：DFS 枚举所有路径，路径条数 `2^(n-1)`，指数级 → 浪费：不同路径经过同一个格子时，从这个格子往下的最小和是相同的 → 状态 `dp[i][j]`：从 `(i, j)` 走到底的最小路径和，`dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])` → 基础行是最底行，`dp[n-1][j] = triangle[n-1][j]`；从倒数第二行往上逐行填表，填第 `i` 行时第 `i+1` 行已经全部算好。例：`[[2],[3,4],[6,5,7],[4,1,8,3]]` 填完的表是 `[[11],[9,10],[7,6,10],[4,1,8,3]]`，顶点 `11`。

```python
def minimum_total(triangle: list[list[int]]) -> int:
    n = len(triangle)
    # dp[i][j]：从格子 (i, j) 出发，走到最底行的最小路径和；第 i 行有 i + 1 个格子
    dp = [[0] * (i + 1) for i in range(n)]
    dp[n - 1] = triangle[n - 1][:]                 # 基础行：最底行，路径只含自己
    for i in range(n - 2, -1, -1):                 # 自底向上，一行一行往上填
        for j in range(i + 1):
            dp[i][j] = triangle[i][j] + min(dp[i + 1][j], dp[i + 1][j + 1])
    return dp[0][0]                                # 答案格：顶点
```

运行：`[[2],[3,4],[6,5,7],[4,1,8,3]]` → `11`，`[[-10]]` → `-10`；`200` 行、值在 `[-10^4, 10^4]` 的三角形约 `0.001` 秒；全是 `-10^4` 的 `200` 行 → `-2000000`；调用之后输入没有变化。

**复杂度。** 时间 `O(n^2)`，每个格子处理一次；空间 `O(n^2)`，整张 `dp` 表和三角形同形，`n = 200` 时约 `2 * 10^4` 个整数。

**易错点。**
- 贪心：每步选下一行相邻两格里较小的。`[[-1],[2,3],[1,-1,-3]]` 贪心走 `-1 → 2 → -1`，和 `0`；最优是 `-1 → 3 → -3`，和 `-1`。局部最小会错过后面更大的收益。
- 忘了给基础行赋值：`dp` 建好后直接开始往上填，最底行还是全 `0`。示例 `[[2],[3,4],[6,5,7],[4,1,8,3]]` 得到 `10`，正确是 `11`。
- 自顶向下时忽略边界：每行两端的格子只有一个前驱，写 `dp[i-1][j-1]` 在 `j = 0` 时会回绕到末尾（负下标）而不报错，结果悄悄出错。

**追问。**
- 输出路径本身：整张表已经在手，从 `(0, 0)` 出发，每步走到 `dp` 更小的那个后继，不需要额外记录。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 推广：下降路径最小和（LC 931，每步可到下一行的左、中、右三个位置）、矩形网格的最小路径和（LC 64）。

**同模式。** LC 64 最小路径和、LC 931 下降路径最小和、LC 62 不同路径、LC 118 杨辉三角。
