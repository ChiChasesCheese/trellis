## Q
**LC 228 汇总区间**｜Easy · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-02（面试记录）

给一个**升序**、无重复元素的整数数组 `nums`。返回**恰好覆盖数组中所有数字**的最小有序区间列表：`nums` 的每个元素恰好被一个区间覆盖，且不存在属于某区间却不在 `nums` 里的数。区间 `[a,b]` 输出为字符串：`a != b` 写 `"a->b"`，`a == b` 写 `"a"`。`0 <= nums.length <= 20`，`-2^31 <= nums[i] <= 2^31 - 1`。例：`[0,1,2,4,5,7]` → `["0->2","4->5","7"]`；`[0,2,3,4,6,8,9]` → `["0","2->4","6","8->9"]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 双指针找每一段「极长连续整数」：`i` 指段首，`j` 向右延伸到 `nums[j + 1] != nums[j] + 1` 为止，输出这一段后令 `i = j + 1`；每个元素只被扫一次，`O(n)`。

**识别。** 「有序 + 连续整数分段」：相邻两数差恰为 `1` 就在同一段。数据量只有 20，没有性能压力，考的是边界：空数组、单元素段不能写成 `"7->7"`、整型两端的极值。

**推导。** 暴力：每个元素先各成一段，再反复合并相邻的段，要多次扫描 → 一段是否继续，只取决于「下一个数是否等于当前数加一」，一次扫描就能确定段尾 → `j` 走到段尾，`i` 直接跳到 `j + 1`，不回头，也不重复输出 → 每个元素进出一次，`O(n)`。

```python
def summary_ranges(nums: list[int]) -> list[str]:
    ans: list[str] = []
    i = 0
    while i < len(nums):
        j = i                                          # [i, j] 是当前连续段
        while j + 1 < len(nums) and nums[j + 1] == nums[j] + 1:
            j += 1
        ans.append(str(nums[i]) if i == j else f"{nums[i]}->{nums[j]}")
        i = j + 1                                      # 下一段从 j + 1 开始
    return ans
```

运行：`[0,1,2,4,5,7]` → `['0->2', '4->5', '7']`；`[0,2,3,4,6,8,9]` → `['0', '2->4', '6', '8->9']`；`[]` → `[]`；`[5]` → `['5']`；`[-2147483648, 2147483647]` → `['-2147483648', '2147483647']`。

**复杂度。** 时间 `O(n)`（内外层加起来每个下标只访问一次）；额外空间 `O(1)`，输出不计。

**易错点。**
- 下一段起点写成 `i += 1`：`[0,1,2,4,5,7]` 会输出 `['0->2', '1->2', '2', '4->5', '5', '7']`，段被重复输出。
- 单元素段写成 `"7->7"`：必须判断 `i == j`。
- `j + 1 < len(nums)` 必须放在 `and` 左边，反过来 `nums[j + 1]` 会越界抛 `IndexError`。

**追问。**
- 反过来输出缺失的段：LC 163，取相邻元素之间的间隙。
- 其他语言的整型溢出：`nums[j + 1] - nums[j]` 在 `-2^31` 与 `2^31 - 1` 之间会溢出 32 位，要用 `long` 或写成 `nums[j + 1] == nums[j] + 1` 的比较形式；Python 整数不溢出。
- 另一种写法：连续整数的「值减下标」相同，`groupby(enumerate(nums), key=lambda p: p[1] - p[0])` 一次分好组，每组取首尾；先写双指针，再提这个。

**同模式。** LC 163 缺失的区间、LC 56 合并区间、LC 352 将数据流变为不相交区间、LC 128 最长连续序列。
