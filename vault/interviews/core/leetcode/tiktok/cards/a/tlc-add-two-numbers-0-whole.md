## Q
**LC 2 两数相加**｜Medium · LC TikTok 热度 25/100 · CodeTop 国内累计 49 次 · 最近 2026-03-17（CodeTop）

给两个**非空**链表，各表示一个非负整数。数字按**逆序**存储（个位在链表头），每个结点存一位数字。把两个数相加，并以同样的形式返回表示和的链表。除了数字 `0` 本身，两个数都不含前导零。

约束：每个链表的结点数在 `[1, 100]`，`0 <= Node.val <= 9`，数字不含前导零。

例：`l1 = [2,4,3]`, `l2 = [5,6,4]` → `[7,0,8]`（`342 + 465 = 807`）；`l1 = [9,9,9,9,9,9,9]`, `l2 = [9,9,9,9]` → `[8,9,9,9,0,0,0,1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 模拟小学竖式加法：因为链表是逆序存储的，链表头就是个位，两条链同步向后走，每位 `两位数字之和 + 进位` 的个位写进新链表、十位作为新的进位；两条链走完后若还有进位，再补一个结点。`O(max(m, n))`。

**识别。** 「逆序存储的数字链表相加」→ 逆序正好让个位对齐，**同步遍历 + 进位**（carry）；不同长度的链用「缺位当 0」处理。这是链表题里的「哑结点（dummy node）+ 尾指针」模板题：构造新链表时用哑结点避免头结点特判。

**推导。** 取巧：把两条链转成整数相加再转回链表——Python 的大整数不会溢出，但这绕过了题目考的逐位模拟（Java / C++ 会溢出），面试官通常不接受。逐位法：每一位的和最多 `9 + 9 + 1 = 19`，所以进位只会是 `0` 或 `1`。循环条件用「`l1` 或 `l2` 或 `carry`」，既处理长度不同，又自然处理最后的进位。每次 `divmod(carry, 10)` 一步得到新进位和当前位。哑结点保证第一个结点和后面的结点处理方式一致。

```python
def add_two_numbers(l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
    dummy = tail = ListNode()          # 哑结点：头结点不用特判
    carry = 0
    while l1 or l2 or carry:           # 两条链都走完后，还要看有没有进位
        if l1:
            carry += l1.val
            l1 = l1.next
        if l2:
            carry += l2.val
            l2 = l2.next
        carry, digit = divmod(carry, 10)   # 商是新的进位，余数是当前位
        tail.next = ListNode(digit)
        tail = tail.next
    return dummy.next
```

运行：`l1=[2,4,3], l2=[5,6,4]` → `[7, 0, 8]`，`l1=[0], l2=[0]` → `[0]`，`l1=[9,9,9,9,9,9,9], l2=[9,9,9,9]` → `[8, 9, 9, 9, 0, 0, 0, 1]`，`l1=[5], l2=[5]（只剩进位）` → `[0, 1]`，`l1=[1], l2=[9,9]` → `[0, 0, 1]`。

**复杂度。** 时间 `O(max(m, n))`，两条链各走一遍；空间 `O(1)`（不计结果链表本身，结果长度至多 `max(m, n) + 1`）。

**易错点。**
- 丢掉最后的进位：循环只看 `l1 or l2`，`[5] + [5]` 得到 `[0]`，正确是 `[0, 1]`（`5 + 5 = 10`）。
- 循环条件写成 `and`：较长的链剩下的部分被丢掉，`[1] + [9, 9]` 得 `[0, 1]`，正确是 `[0, 0, 1]`（`1 + 99 = 100`）。
- 忘了哑结点、直接处理头结点：要为第一位单独写分支；一旦链表很短，边界很容易错。
- 转成整数相加：Python 能过，但无法展示链表技巧，也不适用于 Java / C++；若面试官允许，要说明这是投机。

**追问。**
- 正序存储（LC 445）：先用栈把两条链的数字倒过来，或者先反转链表再相加；不允许修改输入时用两个栈，从栈顶（个位）弹出相加，并用头插法构造结果。
- 原地复用较长链的结点：把和写回较长的那条链，省掉新结点的分配，空间 `O(1)`；缺点是破坏了输入。
- `k` 条链相加：两两合并，或者用同一个进位依次累加所有链的当前位（进位可能超过 1，用 `divmod`）。

**同模式。** LC 445 两数相加 II、LC 415 字符串相加、LC 67 二进制求和、LC 66 加一、LC 43 字符串相乘、LC 989 数组形式的整数加法。
