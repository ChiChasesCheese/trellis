## Q
**有效括号字符串：判断，并输出全部方案**｜Medium · 近一年被问：美国 3 次、国内 0 次 · 最近 2026-02-18（面试记录）

字符串 `s` 只含 `'('`、`')'` 和 `'*'`，`'*'` 可以当作 `'('`、`')'` 或空串。第一问：判断 `s` 能否变成有效的括号字符串（括号正确配对，空串也有效），`1 <= len(s) <= 100`。第二问：输出所有**不同的**有效字符串（每个 `'*'` 取三种之一，结果去重），按字典序返回，`1 <= len(s) <= 20`；要求自己写测试。例：`"(*)"` → 有效，方案 `["()"]`；`"(**)"` → 有效，方案 `["(())", "()", "()()"]`；`"*("` → 无效，方案 `[]`；`"**"` → 方案 `["", "()"]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 判断用贪心：维护「未匹配左括号个数」的取值范围 `[lo, hi]`，`'('` 两端加一，`')'` 两端减一，`'*'` 下界减一、上界加一；`hi < 0` 立刻失败，`lo` 与 `0` 取大，结束时 `lo == 0` 即有效。输出全部方案用带记忆化的搜索：`tails(i, bal)` 返回「从位置 `i` 起，已有 `bal` 个未匹配左括号时，所有能配平的后缀」的集合，三种取值各递归一次，结果用集合去重，最后排序。

**识别。** 「`'*'` 可以是三种东西」若逐个枚举是 `3^k`；判断问题只关心「未匹配左括号数」这一个量，它在 `'*'` 之后变成一个连续区间，所以用区间 `[lo, hi]` 代替枚举，`O(n)`。输出全部方案时，不同的取值可能产生同一个字符串（`"***"` 里 `"()*"` 与 `"*()"` 的两种选法都得到 `"()"`），所以必须去重，并且结果数本身是指数级，输出规模决定复杂度。

**推导。** 判断的暴力：`3^k` 种替换，每种 `O(n)` 检查。浪费：很多替换在同一个位置得到相同的未匹配数，之后的检查完全相同。洞察：状态只有「位置」和「未匹配左括号数」；`'*'` 让未匹配数从 `b` 变成 `b - 1`、`b`、`b + 1`，可达集合总是一段连续整数，所以只记 `lo`、`hi`。输出方案的暴力：枚举 `3^k`、检验、去重。优化：状态 `(i, bal)` 只有 `O(n^2)` 个，记忆化后每个状态只算一次后缀集合；`bal` 超过剩余字符数时不可能配平，直接剪枝。

```python
from functools import cache


def check_valid(s: str) -> bool:
    """LC 678：'*' 可当 '('、')' 或空串。lo..hi 是「未匹配左括号数」所有可能取值的范围（中间的值都能取到）。"""
    lo = hi = 0
    for ch in s:
        if ch == "(":
            lo, hi = lo + 1, hi + 1
        elif ch == ")":
            lo, hi = lo - 1, hi - 1
        else:                                      # '*'：可能 -1、0、+1
            lo, hi = lo - 1, hi + 1
        if hi < 0:                                 # 就算 '*' 全当 '('，右括号也多了
            return False
        lo = max(lo, 0)                            # 未匹配数不会小于 0：多出来的 '*' 当空串
    return lo == 0


def all_valid(s: str) -> list[str]:
    """所有不同的有效字符串（'*' 替换后的结果），按字典序返回。"""
    n = len(s)

    @cache
    def tails(i: int, bal: int) -> frozenset[str]:
        """s[i:] 在已有 bal 个未匹配左括号的前提下，所有能配平的替换结果。"""
        if bal > n - i:                            # 剩下的字符不够把 bal 个左括号都闭合
            return frozenset()
        if i == n:
            return frozenset({""}) if bal == 0 else frozenset()
        ch = s[i]
        result: set[str] = set()
        if ch in "(*":
            result |= {"(" + t for t in tails(i + 1, bal + 1)}
        if ch in ")*" and bal > 0:                 # 前缀里右括号不能比左括号多
            result |= {")" + t for t in tails(i + 1, bal - 1)}
        if ch == "*":
            result |= tails(i + 1, bal)            # '*' 当空串
        return frozenset(result)

    return sorted(tails(0, 0))
```

运行：`check_valid` 与 `all_valid`：`"()"` → `True`、`["()"]`；`"(*)"` → `True`、`["()"]`；`"(*))"` → `True`、`["(())"]`；`"*("` → `False`、`[]`；`")*"` → `False`、`[]`；`""` → `True`、`[""]`；`"(((*)"` → `False`、`[]`；`"(**)"` → `True`、`["(())", "()", "()()"]`；`all_valid("**")` → `['', '()']`；`all_valid("*" * 6)` → 9 个：`['', '((()))', '(()())', '(())', '(())()', '()', '()(())', '()()', '()()()']`；`"*" * 20` → `23714` 个。

**复杂度。** `check_valid` 时间 `O(n)`、空间 `O(1)`。`all_valid`：状态 `O(n^2)` 个，每个状态合并的集合大小等于输出规模，总体 `O(状态数 × 输出规模)`，是输出敏感的；递归深度 `n <= 20`。

**易错点。**
- 下界不与 `0` 取大：`"()*("` 的 `lo` 会降到 `-1` 再回到 `0`，误判有效，正确是无效。
- 不检查 `hi < 0`：`")*"` 的 `hi` 已经是 `-1`（多出的右括号），`'*'` 又把它加回 `0`，误判有效，正确是无效。
- 输出方案不去重：`"***"` 的 `27` 种取法里有 `4` 种得到有效串，但只有 `""` 和 `"()"` 两个不同的字符串；用列表收集会重复。
- 只比较左右括号的个数、不检查前缀：`")("` 个数相等但无效；搜索里必须要求 `bal > 0` 才能选 `')'`。

**追问。**
- 只统计方案数：`tails` 返回计数而不是集合，但不同取法产生相同字符串，计数要先去重才对；通常先问清是“取法数”还是“不同字符串数”。
- 栈解法判断：两个栈分别存 `'('` 和 `'*'` 的下标，遇到 `')'` 优先匹配 `'('`，最后每个剩余 `'('` 都要有位置更靠后的 `'*'` 与之配对。
- 输出规模太大：用生成器逐个产出，或者只输出前 `k` 个。

**同模式。** LC 678 有效的括号字符串、LC 20 有效的括号、LC 22 括号生成、LC 301 删除无效的括号、LC 32 最长有效括号。
