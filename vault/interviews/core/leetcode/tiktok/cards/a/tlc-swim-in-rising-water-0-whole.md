## Q
**LC 778 水位上升的泳池中游泳**｜Hard · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-01（面试记录）

`n x n` 的整数矩阵 `grid`，`grid[i][j]` 是位置 `(i, j)` 平台的高度。时间为 `t` 时水位是 `t`。你可以从一个平台游向上下左右相邻的平台，前提是此时水位**同时淹没**这两个平台（`t` 不小于两者的高度）；在平台内部移动、瞬间移动都不耗时。你从左上角 `(0, 0)` 出发，返回到达右下角 `(n-1, n-1)` 所需的**最少时间**。`1 <= n <= 50`，`0 <= grid[i][j] < n^2`，所有高度互不相同。例：`[[0,2],[1,3]]` → `3`；`[[0,1,2,3,4],[24,23,22,21,5],[12,13,14,15,16],[11,17,18,19,20],[10,9,8,7,6]]` → `16`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 求从起点到终点的路径上**最大高度的最小值**（瓶颈路径）：用小根堆做 Dijkstra 的变体，堆里的键是「到达该格所需的最低水位 = 路径上的最大高度」，邻格入堆的键是 `max(当前键, 邻格高度)`，第一次弹出终点时的键就是答案。`O(n^2 log n)`。

**识别。** 路径的代价不是边权之和，而是**路径上的最大值**，要它最小 → 最小化最大值（minimax / 瓶颈路径）。三种经典做法：Dijkstra 把 `+` 换成 `max`、二分答案加 BFS、并查集按高度从小到大「点亮」格子。高度互不相同且恰好是 `0..n^2-1` 的排列，让并查集写法特别简洁。

**推导。** 暴力：枚举水位 `t = 0, 1, ...`，每次 BFS 判断高度不超过 `t` 的格子里起点和终点是否连通，第一个连通的 `t` 就是答案，`O(n^4)` → 水位越高越容易连通（单调），可以二分答案，`O(n^2 log n)` → 更直接：总是先扩展「当前水位最低就能到达」的格子，堆顶就是下一个要淹没的位置，路径的瓶颈值只增不减 → 这就是 Dijkstra，只是路径长度的合并方式从 `+` 变成 `max`。

```python
from heapq import heappop, heappush


def swim_in_water(grid: list[list[int]]) -> int:
    n = len(grid)
    heap = [(grid[0][0], 0, 0)]                    # (到达此格所需的最低水位, 行, 列)
    seen = {(0, 0)}
    while heap:
        t, x, y = heappop(heap)                    # 弹出的是"当前最低水位下能到的最低一格"
        if x == y == n - 1:
            return t
        for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
            if 0 <= nx < n and 0 <= ny < n and (nx, ny) not in seen:
                seen.add((nx, ny))
                heappush(heap, (max(t, grid[nx][ny]), nx, ny))
    return -1
```

运行：`[[0,2],[1,3]]` → `3`；`5 x 5` 的示例 → `16`；`[[0]]` → `0`；`[[3,0],[1,2]]` → `3`（起点本身高度 `3`）；`50 x 50` 的随机排列在毫秒内完成。

**复杂度。** 时间 `O(n^2 log n)`：每格入堆一次，堆操作 `O(log n^2)`；空间 `O(n^2)`。

**易错点。**
- 把 `max` 写成 `+`（当成最短路径和）：示例 1 得 `4`、示例 2 得 `57`，正确是 `3` 和 `16`。
- 只允许向右、向下走：示例 2 得 `20`，正确是 `16`，因为最优路线中间要向左走一段。
- 起点的高度没计入（初始键写 `0`）：`[[3,0],[1,2]]` 得 `2`，正确是 `3`，水位至少要淹没起点。

**追问。**
- 同样的解法换成「最小体力消耗路径」（LC 1631）：边权改成相邻格高度差，键仍是路径上的最大边权。
- 二分答案加 BFS，或并查集按高度逐格点亮：前者不需要堆，后者天然支持多次查询。
- 输出具体路线：额外记录每格的前驱，终点出堆时往回走。

**同模式。** LC 1631 最小体力消耗路径、LC 1102 得分最高的路径、LC 743 网络延迟时间、LC 787 K 站中转内最便宜的航班、LC 1514 概率最大的路径。
