## Q
**LC 1288 删除被覆盖区间**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-04-13（CodeTop）

给一个区间列表 `intervals`，删除其中被其他区间**覆盖**的区间，返回剩下的区间数。区间 `[a,b)` 被 `[c,d)` 覆盖，当且仅当 `c <= a` 且 `b <= d`。`1 <= intervals.length <= 1000`，`0 <= intervals[i][0] < intervals[i][1] <= 10^5`，所有区间互不相同。例：`[[1,4],[3,6],[2,8]]` → `2`（`[3,6]` 被 `[2,8]` 覆盖）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 按起点升序、**起点相同时终点降序**排序，然后扫一遍维护「目前见过的最大终点」；当前区间的终点不超过它就是被覆盖的，超过才保留并更新最大终点。`O(n log n)`。

**识别。** 「区间 + 包含关系」几乎总是**先排序再线性扫描**：排序后包含关系只可能由前面的区间覆盖后面的，扫描时用一个量（最大终点）概括「前面所有区间」；`n <= 1000` 允许 `O(n^2)` 两两比较，但排序 + 扫描更简洁。关键细节是起点相同的区间如何排序。

**推导。** 暴力：对每个区间检查是否被另一个覆盖，`O(n^2)`（`n = 1000` 可过）。浪费：覆盖关系依赖起点和终点两个维度，两两比较没利用顺序。洞察：按起点升序后，只有排在前面的区间才可能覆盖当前区间（起点更小或相同）；而前面区间能否覆盖，只看它们终点的最大值是否 `>=` 当前终点。起点相同时，必须让终点大的排前面，这样终点小的才会被识别为被覆盖。最优：排序 `O(n log n)` + 一次扫描，只留一个变量 `max_end`。

```python
def remove_covered_intervals(intervals: list[list[int]]) -> int:
    intervals.sort(key=lambda iv: (iv[0], -iv[1]))     # 起点升序；起点相同时长的在前
    kept = 0
    max_end = 0                                        # 目前见过的最大右端点
    for _, end in intervals:
        if end > max_end:                              # 右端点超过前面所有区间：没被覆盖
            kept += 1
            max_end = end
    return kept
```

运行：`[[1,4],[3,6],[2,8]]` → `2`，`[[1,2],[1,4]]` → `1`，`[[1,4],[2,3]]` → `1`，`[[1,2]]` → `1`，`[[0,1],[1,2],[2,3]]` → `3`。

**复杂度。** 时间 `O(n log n)`：排序主导，扫描 `O(n)`；空间 `O(1)`（原地排序，不计排序栈）。

**易错点。**
- 起点相同时按终点升序（默认的 `sort()` 对列表按字典序，正好是升序）：`[[1,2],[1,4]]` 里 `[1,2]` 先被处理，`2 > 0` 被保留，`[1,4]` 再被保留，得 `2`；正确是 `1`（`[1,2]` 被 `[1,4]` 覆盖）。
- 判断写成 `end >= max_end` 才保留：终点相等的区间（起点更大）其实被覆盖；`[[1,4],[2,4]]` 会答成 `2`，正确是 `1`。
- 把区间当成开区间处理，用 `<` 做覆盖判断：题目的覆盖条件是 `c <= a` 且 `b <= d`，端点相等也算覆盖。

**追问。**
- 返回剩下的区间本身：扫描时把保留的区间追加到结果里。
- 区间可能重复（完全相同的两个区间）：定义需先明确，通常保留一个；排序键后面再按下标打破平局，保证只保留第一个。
- 区间已按起点有序、数据量很大：省掉排序，只需一次扫描，起点相同的组内要先处理长的。

**同模式。** LC 56 合并区间、LC 435 无重叠区间（按终点排序）、LC 452 用最少数量的箭引爆气球、LC 57 插入区间、LC 986 区间列表的交集。
