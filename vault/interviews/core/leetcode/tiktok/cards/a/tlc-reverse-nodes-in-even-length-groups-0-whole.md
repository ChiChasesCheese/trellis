## Q
**LC 2074 反转偶数长度组的节点**｜Medium · 近一年被问：美国 7 次、国内 12 次 · 最近 2026-10-27（面试记录）

给链表头节点 `head`。链表中的节点按顺序划分成若干非空组，组的长度依次是自然数序列 `1, 2, 3, 4, ...`（第 1 个节点是第一组，第 2、3 个节点是第二组，第 4、5、6 个节点是第三组，以此类推）；最后一组的长度可能小于预期的长度。把**每个长度为偶数的组**整体反转，返回修改后的头节点。节点数目范围是 `[1, 10^5]`，`0 <= Node.val <= 10^5`。例：`head = [5,2,6,3,9,1,7,3,8,4]` → `[5,6,2,3,9,1,4,8,3,7]`（第二组 `[2,6]` 和最后一组 `[7,3,8,4]` 长度为偶数，被反转）；`[1,1,0,6]` → `[1,0,1,6]`；`[2,1]` → `[2,1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用指针 `prev` 指向上一组的尾，预期组长 `size` 从 `2` 开始递增；每轮先往后**数出本组的实际节点数** `count`（最后一组可能不足 `size`），`count` 为偶数就原地反转这 `count` 个节点并接线，为奇数就把 `prev` 往后跳 `count` 个；一遍扫描，`O(n)` 时间、`O(1)` 空间。

**识别。** 「分段处理链表 + 段内反转」，与 LC 25 同一类：把「反转链表」当子程序，外层负责分组和接线。区别有两点：组长度是递增序列而不是固定的 `k`；是否反转取决于组的**实际**长度，而最后一组的实际长度可能小于预期。节点数 `10^5` 排除递归，`O(1)` 空间要求原地。

**推导。** 暴力：读进数组，按 `1, 2, 3, ...` 切块、偶数块反转、再写回，空间 `O(n)`，且违背「操作链表」的本意。浪费：数据结构本来就是链表，反转一段只需要改指针。洞察：每组的头尾接线只依赖三样东西——上一组的尾 `prev`、本组的头 `prev.next`、下一组的头（数完 `count` 个之后的 `node`）。反转时把累积指针 `tail` 初值设成下一组的头，翻完后本组的原头（变成新尾）已经指向下一组，不需要再单独接。

```python
def reverse_even_length_groups(head: ListNode | None) -> ListNode | None:
    prev = head                                  # 第 1 组只有 1 个节点，奇数，不翻；prev 是上一组的尾
    size = 2
    while prev.next:
        node, count = prev.next, 0
        while node and count < size:             # 数出本组实际有多少节点（最后一组可能不足 size）
            node, count = node.next, count + 1
        if count % 2 == 0:
            first = prev.next
            tail, cur = node, first              # tail 初值取下一组的头：翻完后本组尾自动接上
            for _ in range(count):
                cur.next, tail, cur = tail, cur, cur.next
            prev.next = tail                     # tail 现在是本组的新头
            prev = first                         # 原来的头变成本组的尾
        else:
            for _ in range(count):
                prev = prev.next
        size += 1
    return head
```

运行：`[5,2,6,3,9,1,7,3,8,4]` → `[5, 6, 2, 3, 9, 1, 4, 8, 3, 7]`，`[1,1,0,6]` → `[1, 0, 1, 6]`，`[2,1]` → `[2, 1]`，`[1]` → `[1]`，`[1,...,9]` → `[1, 3, 2, 4, 5, 6, 7, 8, 9]`（最后一组 `[7,8,9]` 实际长度 `3`，不反转），`[1,...,10]` → `[1, 3, 2, 4, 5, 6, 10, 9, 8, 7]`，`10^5` 个节点正常返回。

**复杂度。** 时间 `O(n)`：每个节点被数一次、至多被翻一次；空间 `O(1)`。

**易错点。**
- 用预期长度 `size` 而不是实际长度 `count` 判断奇偶：`[1,...,9]` 的最后一组预期 `4` 个、实际 `3` 个，错误地按 `size` 是偶数反转，得到 `[1, 3, 2, 4, 5, 6, 9, 8, 7]`，正确是 `[1, 3, 2, 4, 5, 6, 7, 8, 9]`。
- 反转时累积指针初值设成 `None`：本组的新尾指向 `None`，后面的节点全丢，`[5,2,6,3,9,1,7,3,8,4]` 只剩 `[5, 6, 2]`；初值要取下一组的头。
- 奇数组也要把 `prev` 推进 `count` 步，否则下一轮从错误的位置开始；每轮结束 `size += 1`。
- 第一组长度 `1` 是奇数，不用处理，所以 `prev = head`、`size` 从 `2` 开始；`while prev.next` 保证链表只有一个节点时直接返回。

**追问。**
- 奇数长度组反转：把条件改成 `count % 2 == 1`，其余不变。
- 递归写法：深度是组数（约 `sqrt(2n)`，`n = 10^5` 时约 `447`），没有越过默认上限，但不是 `O(1)` 空间。
- 组长度改成别的序列（如固定 `k`，LC 25）：同一框架，把 `size += 1` 换成对应的规则即可。

**同模式。** LC 25 K 个一组翻转链表、LC 206 反转链表、LC 92 反转链表 II、LC 24 两两交换链表中的节点。
