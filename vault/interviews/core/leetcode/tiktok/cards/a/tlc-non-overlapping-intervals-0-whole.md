## Q
**LC 435 无重叠区间**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 7 次 · 最近 2026-09-02（面试记录）

给一组区间 `intervals`，`intervals[i] = [start_i, end_i]`。返回最少需要移除多少个区间，才能让剩下的区间两两不重叠。只在端点接触的区间不算重叠，例如 `[1,2]` 和 `[2,3]`。`1 <= intervals.length <= 10^5`，`intervals[i].length == 2`，`-5 * 10^4 <= start_i < end_i <= 5 * 10^4`。例：`[[1,2],[2,3],[3,4],[1,3]]` → `1`（移除 `[1,3]`）；`[[1,2],[1,2],[1,2]]` → `2`；`[[1,2],[2,3]]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 「最少移除」等价于「最多保留」：按右端点升序扫描，当前区间的起点不小于已保留区间的右端点就保留，否则丢弃；答案是总数减去保留数。`O(n log n)`。

**识别。** 「区间 + 两两不重叠 + 最少/最多」是区间调度（Interval Scheduling）：可以用贪心；`n = 10^5` 排除 `O(n^2)` 的 DP；题面明说端点接触不算重叠，所以比较用 `>=`。

**推导。** 暴力枚举保留哪些区间 `2^n`；按右端点排序后做类似最长上升子序列的 DP 是 `O(n^2)`，`10^5` 太慢 → 浪费：DP 在每个位置都在比较「接在谁后面」，但其实只需要关心最后一个保留的右端点 → 洞察：右端点最小的区间最不占地方，任何最优解里把第一个区间换成右端点最小的那个都不会变差（交换论证），之后对剩余部分重复同样的选择 → 排序一次、扫描一遍。

```python
from math import inf
from operator import itemgetter


def erase_overlap_intervals(intervals: list[list[int]]) -> int:
    kept, end = 0, -inf                                   # 已保留的区间数、最后保留区间的右端点
    for start, finish in sorted(intervals, key=itemgetter(1)):   # 按右端点升序
        if start >= end:                                  # 只在端点接触不算重叠，所以是 >=
            kept += 1
            end = finish
    return len(intervals) - kept
```

运行：`[[1,2],[2,3],[3,4],[1,3]]` → `1`，`[[1,2],[1,2],[1,2]]` → `2`，`[[1,2],[2,3]]` → `0`，`[[1,2]]` → `0`，`[[1,100],[2,3],[4,5]]` → `1`；`10^5` 个区间可正常跑完。

**复杂度。** 时间 `O(n log n)`（排序主导，扫描 `O(n)`）；空间 `O(n)`（`sorted` 产生新列表）。

**易错点。**
- 按起点排序、遇到重叠就丢后来的：`[[1,100],[2,3],[4,5]]` 会得到 `2`，正确是 `1`（只丢 `[1,100]`）。必须按右端点排。
- 用 `>` 代替 `>=`：`[[1,2],[2,3]]` 会得到 `1`，正确是 `0`。
- `end` 的初值写成 `0`：起点可以是负数（最小 `-5 * 10^4`），会误丢区间；用 `-inf`。

**追问。**
- 要列出被移除的区间：扫描时把不满足条件的区间收集起来即可。
- 每个区间带权重、求保留的最大权重：按右端点排序 + 二分找前驱的 DP，`O(n log n)`（LC 1235）。
- 「最少几支箭射爆所有气球」（LC 452）是同一个贪心，但那里端点接触算重叠，条件改成 `>`。

**同模式。** LC 452 用最少数量的箭引爆气球、LC 56 合并区间、LC 253 会议室 II、LC 1353 最多可以参加的会议数目、LC 646 最长数对链。
