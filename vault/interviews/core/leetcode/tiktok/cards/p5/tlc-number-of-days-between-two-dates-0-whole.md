## Q
**LC 1360 日期之间隔几天**｜Easy · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-02-21（面试记录）

编写程序计算两个日期之间隔了多少天。日期以字符串 `YYYY-MM-DD` 给出，保证是 `1971` 年到 `2100` 年之间的有效日期。例：`date1 = "2019-06-29"`，`date2 = "2019-06-30"` → `1`；`date1 = "2020-01-15"`，`date2 = "2019-12-31"` → `15`（`date1` 可以晚于 `date2`，结果是非负的天数）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把每个日期换算成「距 `1970-12-31` 的天数」（整年的天数 + 整月的天数 + 日），两个数相减取绝对值；换算时必须按**闰年规则**（能被 `4` 整除且不能被 `100` 整除，或者能被 `400` 整除）。

**识别。** 「两个日期差几天」= 先统一换算成**绝对天数**（以某个固定起点计），再做整数减法。不要在两个日期之间直接按年月日逐项相减。范围 `1971` 到 `2100` 包含 `2100` 年，它能被 `100` 整除但不能被 `400` 整除，**不是**闰年，是考点。

**推导。** 暴力：从较早的日期开始一天天往后走，直到到达较晚的日期，最多约 `47000` 步，也能过，但要写日期进位逻辑，容易出错 → 换算成绝对天数：从 `1971` 到 `y - 1` 年每年 `365` 或 `366` 天；当年里，`m` 月之前每个月的天数之和，闰年的 `2` 月多一天；再加上日 → 两个日期各换算一次，相减取绝对值。

```python
MONTH_DAYS = (31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31)


def days_between_dates(date1: str, date2: str) -> int:
    def is_leap(y: int) -> bool:
        return y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)

    def to_days(s: str) -> int:                       # 距 1970-12-31 的天数
        y, m, d = map(int, s.split("-"))
        days = sum(365 + is_leap(k) for k in range(1971, y))     # 整年
        days += sum(MONTH_DAYS[:m - 1]) + (m > 2 and is_leap(y)) # 整月，闰年 2 月多一天
        return days + d

    return abs(to_days(date1) - to_days(date2))
```

运行：`("2019-06-29", "2019-06-30")` → `1`；`("2020-01-15", "2019-12-31")` → `15`；`("2100-03-01", "2100-02-28")` → `1`；`("1971-01-01", "2100-12-31")` → `47481`；两个日期相同 → `0`。

**复杂度。** 时间 `O(Y)`，`Y` 是年份跨度（最多 `130`）；若预先算好每年起始的累计天数，每次查询 `O(1)`；空间 `O(1)`。

**易错点。**
- 闰年只判断 `y % 4 == 0`：`2100` 年被当成闰年。`("2100-03-01", "2100-02-28")` 得到 `2`，正确是 `1`；`("2100-12-31", "2100-01-01")` 得到 `365`，正确是 `364`。
- 忘了取绝对值：`date1` 晚于 `date2` 时得到负数。
- 当年月份累计写成 `MONTH_DAYS[:m]`（把当月也算进去）：多出整月天数。要用 `[:m - 1]`，当月只加上日。

**追问。**
- 标准库：`(date.fromisoformat(a) - date.fromisoformat(b)).days` 一行得到带符号的天数，生产代码首选；面试里先手写，再提这个。
- 查询特别多：预处理 `1971` 到 `2100` 每一年的起始累计天数（`itertools.accumulate`），每次查询 `O(1)`。
- 求「某日期加 `n` 天是哪天」「星期几」：用 `date.toordinal()` / `date.fromordinal()`，不用自己进位。

**同模式。** LC 1154 一年中的第几天、LC 1185 一周中的第几天、LC 2409 统计共同度过的日子数、LC 1507 转变日期格式、LC 1118 一月有多少天。
