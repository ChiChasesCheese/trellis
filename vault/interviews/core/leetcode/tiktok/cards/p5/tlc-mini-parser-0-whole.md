## Q
**LC 385 迷你语法分析器**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-02-27（面试记录）

给一个字符串 `s`，表示整数的嵌套列表，实现解析器返回对应的 `NestedInteger`。列表里的每个元素只可能是整数，或整数的嵌套列表。`NestedInteger` 接口：`NestedInteger()` 创建空列表，`NestedInteger(v)` 创建单个整数，`add(x)` 把 `x` 追加进列表。`1 <= s.length <= 5 * 10^4`，`s` 只含数字、方括号、负号 `-`、逗号，保证可解析，所有数值在 `[-10^6, 10^6]`。例：`"324"` → 一个整数 `324`；`"[123,[456,[789]]]"` → 含两个元素的列表：整数 `123` 和列表 `[456,[789]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 用正则把字符串切成 `[`、`]`、整数三种记号，再用栈解析：遇到 `[` 压入新空列表，遇到整数加进栈顶列表，遇到 `]` 弹出栈顶并加进新的栈顶（栈空就是最终结果）；`O(n)`。

**识别。** 「括号嵌套的字符串 → 层次结构」是栈的典型信号，与 LC 394、LC 224 同类。`s` 最长 `5 * 10^4`，嵌套可以深到约 `25000` 层，递归下降会超过 Python 默认递归深度 `1000`，所以用显式栈。

**推导。** 递归下降：`parse()` 读到 `[` 就循环解析元素直到 `]`，简洁，但递归深度等于括号层数，最坏 `25000` 层，`RecursionError` → 用栈模拟递归：栈顶始终是「正在往里填元素的那个列表」 → 手写逐字符扫描时数字与负号的处理容易出错（多位数、`-`），改用 `re.findall(r"\[|\]|-?\d+", s)` 先分词，主循环只剩三个分支。整个字符串若只是一个整数（不以 `[` 开头），单独先处理。

```python
import re


def deserialize(s: str) -> NestedInteger:
    if s[0] != "[":                                    # 整个串就是一个整数
        return NestedInteger(int(s))
    stack: list[NestedInteger] = []
    for tok in re.findall(r"\[|\]|-?\d+", s):          # 切成 [  ]  整数 三种记号
        if tok == "[":
            stack.append(NestedInteger())              # 开一个新列表
        elif tok == "]":
            done = stack.pop()
            if not stack:                              # 最外层闭合：解析完成
                return done
            stack[-1].add(done)                        # 否则挂到父列表上
        else:
            stack[-1].add(NestedInteger(int(tok)))
    raise ValueError(s)
```

运行（结果用嵌套 Python 列表表示）：`"324"` → `324`；`"[123,[456,[789]]]"` → `[123, [456, [789]]]`；`"[]"` → `[]`；`"[-1,[]]"` → `[-1, []]`；`"-5"` → `-5`；`"[[]]"` → `[[]]`；`25000` 层嵌套的 `"[[[...]]]"` 正常返回，没有 `RecursionError`。

**复杂度。** 时间 `O(n)`：正则切分一遍，主循环每个记号一次；空间 `O(n)`：记号列表与栈。

**易错点。**
- 逐字符处理数字：`"[123,-4]"` 会解析成 `[1, 2, 3, 4]`，多位数被拆开、负号丢失。必须把整个整数（含 `-`）作为一个记号。
- 忘了以数字开头的整串：`"324"` 或 `"-5"` 没有 `[`，直接进循环会在 `stack[-1]` 上抛 `IndexError`。
- 遇到 `]` 时不判断栈是否已空：最外层列表应当返回，而不是再挂到「父列表」上。

**追问。**
- 反过来序列化（`NestedInteger` → 字符串）：递归拼接，遇到整数输出数字，遇到列表输出 `"[" + ",".join(...) + "]"`。
- 输入可能含空格或非法字符：正则里加 `\s*` 吃掉空白；`]` 比 `[` 多（栈空时再 `pop`）或结尾栈不空，说明不合法，抛异常。
- 递归下降写法：用共享下标 `i`，`parse()` 读元素直到遇到 `]`；写起来最短，但深度受递归限制，面试里要主动说出来。

**同模式。** LC 394 字符串解码、LC 224 基本计算器、LC 339 嵌套列表加权和、LC 341 扁平化嵌套列表迭代器、LC 726 原子的数量。
