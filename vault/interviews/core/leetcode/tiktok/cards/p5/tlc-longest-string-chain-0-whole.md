## Q
**LC 1048 最长字符串链**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2025-12-13（面试记录）

给单词数组 `words`，每个单词由小写字母组成。如果可以在 `wordA` 的**任意位置**添加**恰好一个**字母（不改变其他字符的相对顺序）得到 `wordB`，就说 `wordA` 是 `wordB` 的**前身**，例如 `"abc"` 是 `"abac"` 的前身，`"cba"` 不是 `"bcad"` 的前身。**词链**是单词序列 `[word_1, ..., word_k]`（`k >= 1`），其中每个单词是下一个的前身；单个单词本身就是长度为 `1` 的词链。返回从 `words` 里选词能组成的最长词链的长度。`1 <= words.length <= 1000`，`1 <= words[i].length <= 16`。例：`["a","b","ba","bca","bda","bdca"]` → `4`（`a → ba → bda → bdca`）；`["xbc","pcxbcf","xb","cxbc","pcxbc"]` → `5`；`["abcd","dbqca"]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 按单词长度从小到大处理，`dp[w]` = 以 `w` 结尾的最长词链长度 = `1 + max(dp[w 删去一个字母后的串])`（那个串若不在 `dp` 里就算 `0`）；答案是 `dp` 的最大值。`O(N * L^2)`。

**识别。** 「链」+「相邻元素满足某种关系」是 DAG 上的最长路径（类似最长递增子序列）。关键是转换视角：从 `w` 找前身，只需要**删去一个字母**，最多 `L = 16` 个候选；反过来找后继要尝试 `26 * (L + 1)` 种插入。单词按长度分层，长度相差 `1` 才可能有前身关系，所以按长度排序后，前身一定先于后继被处理。

**推导。** 暴力：对所有单词对判断前身关系，再做 LIS 式 DP，`O(N^2 * L)`，`10^6` 个单词对勉强但慢 → 对每个单词只枚举「删去第 `i` 个字母」得到的至多 `L` 个候选，用哈希表一次查到 `dp` → 排序保证候选（长度更短）已经算过 → 每个单词 `O(L)` 次、每次切片 `O(L)`，总 `O(N * L^2)`。

```python
def longest_str_chain(words: list[str]) -> int:
    dp: dict[str, int] = {}                                  # dp[w]：以 w 结尾的最长词链
    for w in sorted(words, key=len):                         # 短的先处理，前身一定已算好
        dp[w] = 1 + max((dp.get(w[:i] + w[i + 1:], 0) for i in range(len(w))), default=0)
    return max(dp.values())
```

运行：`["a","b","ba","bca","bda","bdca"]` → `4`；`["xbc","pcxbcf","xb","cxbc","pcxbc"]` → `5`；`["abcd","dbqca"]` → `1`；`["a"]` → `1`；`["a","a"]` → `1`（重复单词不叠加）。

**复杂度。** 时间 `O(N log N + N * L^2)`；空间 `O(N * L)`。

**易错点。**
- 不按长度排序：`["bdca","bda","bca","ba","a"]` 逆序输入时，每个词处理时它的前身还没算，结果是 `1`，正确是 `4`。
- 只比较字母出现的个数（忽略顺序）：`["ab","bca"]` 里 `"ab"` 的字母都在 `"bca"` 里，会算成 `2`；但在 `"bca"` 里 `a` 在 `b` 的后面，不是 `"ab"` 的超序列，正确是 `1`。
- 把候选串当作"在 `dp` 里就一定存在"：不在 `dp` 里的候选必须取 `0`，用 `dp.get(..., 0)`，直接 `dp[...]` 会 `KeyError`。

**追问。**
- 返回具体的词链：再记一个 `prev[w]`（取得最大值的那个候选），从最大值对应的词沿 `prev` 回溯。
- 前身关系改成「替换一个字母」或「增、删、替换均可」：候选集合变成替换 `26 * L` 种，思路不变，但换成替换后不再有"长度严格递增"的顺序，要另行处理（比如并查集或 BFS）。
- 单词很多、很长：用字典树或「通配符桶」（如 `"b*a"`）建倒排索引，避免大量切片。

**同模式。** LC 300 最长递增子序列、LC 354 俄罗斯套娃信封问题、LC 646 最长数对链、LC 368 最大整除子集、LC 127 单词接龙。
