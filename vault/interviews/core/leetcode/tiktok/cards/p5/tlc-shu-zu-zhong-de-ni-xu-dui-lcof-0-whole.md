## Q
**剑指 Offer 51 数组中的逆序对**｜Hard · CodeTop 国内累计 23 次 · 最近 2026-08-10（CodeTop）

数组 `record` 记录一段时间内的股票价格。如果前一天的价格**高于**后一天的价格，这一对就是一个「交易逆序对」，即满足 `i < j` 且 `record[i] > record[j]` 的 `(i, j)`。返回逆序对的总数。`0 <= record.length <= 50000`。例：`[9, 7, 5, 4, 6]` → `8`（`(9,7)`、`(9,5)`、`(9,4)`、`(9,6)`、`(7,5)`、`(7,4)`、`(7,6)`、`(5,4)`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 归并排序（merge sort）的合并步骤顺手数逆序对：左右两半各自排好序后，每当取出一个左边元素，此刻已经取走的右边元素个数 `j` 就是「在它后面、且比它小」的元素数，累加即可；总数 = 左半内部 + 右半内部 + 跨越两半的。`O(n log n)`。

**识别。** 「数满足 `i < j` 且 `a[i] > a[j]` 的对数」是逆序对，是经典的"排序过程中计数"题。`n = 5 * 10^4` 时 `O(n^2)` 约 `1.25 * 10^9` 次比较，太慢；信号是需要 `O(n log n)`：归并排序、树状数组（Fenwick tree）、平衡树都可以。

**推导。** 暴力：双重循环逐对比较，`O(n^2)` → 浪费：对左边的每个元素，重复扫描右边所有元素 → 如果右边已经有序，左边一个元素能用二分或双指针一次数出右边有多少个比它小 → 归并排序正好在合并时让左右两半都有序，双指针扫一遍就能数完所有跨越两半的逆序对，递归深度 `log n`，每层 `O(n)`。

```python
def reverse_pairs(record: list[int]) -> int:
    def sort(a: list[int]) -> tuple[list[int], int]:
        if len(a) <= 1:
            return a, 0
        mid = len(a) // 2
        left, x = sort(a[:mid])
        right, y = sort(a[mid:])
        merged: list[int] = []
        count = x + y                              # 左半内部、右半内部的逆序对
        i = j = 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:                # 相等不算逆序：先取左边
                merged.append(left[i])
                count += j                         # 此时已取走的 j 个右边元素都严格小于 left[i]
                i += 1
            else:
                merged.append(right[j])
                j += 1
        count += (len(left) - i) * len(right)      # 右半取完后，剩下的左元素比全部右元素都大
        merged.extend(left[i:])
        merged.extend(right[j:])
        return merged, count

    return sort(record)[1]
```

运行：`[9,7,5,4,6]` → `8`，`[]` → `0`，`[1]` → `0`，`[2,2,2]` → `0`，`[3,2,1]` → `3`；`50000` 个随机数约 `0.04` 秒，`50000` 到 `1` 的降序数组 → `1249975000`（即 `n(n-1)/2`）。

**复杂度。** 时间 `O(n log n)`：`log n` 层递归，每层合并共 `O(n)`；空间 `O(n)`，合并用的临时列表。

**易错点。**
- 相等元素处理：合并时用 `<` 而不是 `<=`（相等先取右边），会把相等的对也数进去。`[5,5]` 得到 `1`，正确是 `0`；`[2,2,1]` 得到 `3`，正确是 `2`。
- 漏掉「右半取完后左半的剩余」：`[2,1]` 得到 `0`，正确是 `1`；`[9,7,5,4,6]` 得到 `1`，正确是 `8`。
- 返回值只有计数、没有排好序的数组：上一层合并需要两个有序的半边，必须把排好序的列表一起返回。

**追问。**
- 每个元素各自右侧有多少个更小的（LC 315）：归并时带上原始下标，每次取左边元素时给它的计数加上 `j`。
- 翻转对（LC 493，`nums[i] > 2 * nums[j]`）：合并之前先用双指针单独数一遍，再正常合并。
- 在线、频繁插入：用树状数组做离散化后的前缀计数，每个元素 `O(log n)`，见另一种解法。

**同模式。** LC 315 计算右侧小于当前元素的个数、LC 493 翻转对、LC 327 区间和的个数、LC 912 排序数组。
