## Q
**LC 1186 删除一次得到子数组最大和**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-10-08（CodeTop）

给整数数组 `arr`，返回它的某个**非空**子数组（连续元素）在执行**至多一次**删除（可选）后能得到的最大元素和：可以从原数组选出一个子数组，并决定是否从中删掉一个元素；删除后子数组仍必须至少有一个元素。

约束：`1 <= arr.length <= 10^5`，`-10^4 <= arr[i] <= 10^4`。

例：`arr = [1,-2,0,3]` → `4`（选整个数组，删掉 `-2`，得 `[1,0,3]`）；`arr = [1,-2,-2,3]` → `3`（直接取 `[3]`）；`arr = [-1,-1,-1,-1]` → `-1`（删除后不能为空，所以不能靠删除得到 `0`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 在最大子数组和（Kadane）的基础上给每个位置加一个「是否已用掉删除机会」的维度：`keep` 是以 `i` 结尾、没删过的最大和，`skip` 是以 `i` 结尾、至多删过一个的最大和；`skip` 的转移要么延续、要么删掉当前元素（直接取上一格的 `keep`）、要么重新开始。`O(n)`、`O(1)` 空间。

**识别。** 「最大子数组和」+「至多一次…操作」→ Kadane 加**状态机**：把「操作用没用过」作为 DP 的一个维度（0 次 / 至多 1 次），每个位置各存一个最优值；这类「最多 `k` 次」的题套路一致（LC 121 / 123 / 188 买卖股票也是同一思路）。`n = 10^5` 要求线性。

**推导。** 暴力：枚举子数组再枚举删哪个，`O(n^3)`（或前缀和优化后 `O(n^2)`）。观察：以 `i` 结尾的最优子数组只依赖以 `i-1` 结尾的最优结果，Kadane 的 `max(keep, 0) + x`。加入删除后，「以 `i` 结尾且删过一个」有三种转移：① 前面就已经删过，继续接上 `x`（`skip + x`）；② 删的正是 `x`，于是子数组其实结束于 `i-1` 且没删过（`keep`，因为删了 `x` 就没有额外删除机会）；③ 当前元素单独成一段（`x`）。三项取最大。答案是所有 `i` 的 `keep` 和 `skip` 的最大值。

```python
def maximum_sum(arr: list[int]) -> int:
    keep = skip = best = arr[0]    # keep：以 i 结尾、没删过；skip：以 i 结尾、至多删过一个
    for x in arr[1:]:
        # skip 三选一：延续（含已删过的）/ 删掉 x（保留到 i-1 为止的 keep）/ 从 x 重新开始
        skip, keep = max(skip + x, keep, x), max(keep, 0) + x
        best = max(best, keep, skip)
    return best
```

运行：`arr=[1,-2,0,3]` → `4`，`arr=[1,-2,-2,3]` → `3`，`arr=[-1,-1,-1,-1]` → `-1`，`arr=[1,-4,1]` → `2`，`arr=[5]` → `5`。

**复杂度。** 时间 `O(n)`，一遍扫描；空间 `O(1)`，只保留两个状态变量和答案。

**易错点。**
- 允许把单元素子数组删空、或者答案取 `max(…, 0)`：`[-1,-1,-1,-1]` 应返回 `-1`，错成 `0`。题面强调删除后不能为空。
- 只做「Kadane 找到最大子数组，再删掉其中最小的负数」：`[1,-4,1]` 的 Kadane 子数组是 `[1]`（和 `1`），不含 `-4`，得 `1`；但选 `[1,-4,1]` 删掉 `-4` 能得 `2`。删除可能让一个原本不最优的区间翻身。
- 更新顺序：`skip` 要用**旧的** `keep`（`i-1` 处的值）。用元组同时赋值 `skip, keep = ..., ...`；若先改 `keep` 再算 `skip`，「删掉 `x`」那一项就错用成了含 `x` 的 `keep`：`[1,-5,1]` 得 `1`，正确是 `2`（删掉 `-5`）。
- 只有一个元素时不能删：`n = 1` 不进循环，直接返回 `arr[0]`；`keep`、`skip`、`best` 都以 `arr[0]` 起步，保证答案至少是某个真实子数组的和。

**追问。**
- 最多删 `k` 个：状态变成 `dp[j]`（删了 `j` 个），每个元素 `O(k)` 更新，总 `O(n·k)`；`k = 1` 就是此处。
- 前后缀写法：`left[i]` 是以 `i` 结尾的最大和，`right[i]` 是以 `i` 开头的最大和；删掉 `i` 的最优是 `left[i-1] + right[i+1]`，答案是它与 `max(left)` 的较大者。两遍扫描、`O(n)` 空间，思路最直观。
- 必须恰好删一个：只取 `skip` 里「真的删过」的值，需要把「没删」的状态排除；`n = 1` 时无解。

**同模式。** LC 53 最大子数组和、LC 152 乘积最大子数组、LC 121 / 122 / 123 / 188 买卖股票系列（同样的「状态机 DP」）、LC 1749 任意子数组和的绝对值的最大值、LC 918 环形子数组的最大和。
