## Q
**LC 44 通配符匹配**｜Hard · CodeTop 国内累计 15 次 · 最近 2026-08-11（CodeTop）

给输入字符串 `s` 和模式 `p`，实现支持 `?` 和 `*` 的通配符匹配：`?` 匹配任意**单个**字符，`*` 匹配任意字符序列（**包括空序列**）。匹配必须覆盖整个 `s`（不是部分匹配）。`0 <= s.length, p.length <= 2000`；`s` 只含小写英文字母，`p` 只含小写英文字母、`?` 或 `*`。例：`s = "aa", p = "a"` → `false`；`s = "aa", p = "*"` → `true`；`s = "cb", p = "?a"` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维动态规划（DP）：`dp[i][j]` 表示 `s` 的前 `i` 个字符能否被 `p` 的前 `j` 个字符完整匹配；遇到 `*` 就分叉成「匹配空」（`dp[i][j-1]`）或「多吞一个字符」（`dp[i-1][j]`），其余位置只看当前字符是否兼容，兼容则取左上角 `dp[i-1][j-1]`；`dp[0][0] = True`，第 0 行是「连续的 `*` 才为真」，答案是 `dp[m][n]`。`O(mn)` 时间和空间。

**识别。** 两个字符串各取前缀、问「能否完全匹配」，状态是 `(i, j)` 一对前缀长度，这是字符串双序列 DP 的标准信号。`*` 的「任意长度」造成分叉，直接递归会指数爆炸，但分叉后的子问题只有 `(i, j)` 这 `m * n` 种，满足重叠子问题。`m, n <= 2000`，`O(mn) = 4 * 10^6` 可行。近似但不同：LC 10 的 `*` 是「前一个字符重复任意次」，转移完全不同。

**推导。** 暴力递归 `match(i, j)`：`p[j]` 是 `*` 时，`match(i, j + 1)`（匹配空）或 `match(i + 1, j)`（吞掉 `s[i]`，`*` 留着继续用）；否则要求当前字符兼容再走 `(i + 1, j + 1)`。分叉多层叠加，最坏指数级。浪费在于同一个 `(i, j)` 被反复求解 → 自底向上填表。换成「前缀」视角：`p[j-1]` 是 `*` 时，它要么匹配空串（`s[:i]` 交给 `p[:j-1]`，即 `dp[i][j-1]`），要么至少吞掉最后一个字符 `s[i-1]`（`*` 还可以继续吞，所以是 `s[:i-1]` 交给 `p[:j]`，即 `dp[i-1][j]`）。边界：第 0 行是 `s` 为空，只有 `p` 的前缀全是 `*` 才匹配；第 0 列是 `p` 为空，非空 `s` 不可能匹配，保持 `False`。

```python
def is_match(s: str, p: str) -> bool:
    m, n = len(s), len(p)
    # dp[i][j]：s[:i] 能否被 p[:j] 完整匹配
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True                                  # 空串匹配空模式
    for j in range(1, n + 1):                        # 第 0 行：s 为空，只有连续的 '*' 能匹配
        dp[0][j] = dp[0][j - 1] and p[j - 1] == "*"
    for i in range(1, m + 1):                        # 第 0 列保持 False：非空 s 不能匹配空模式
        for j in range(1, n + 1):
            if p[j - 1] == "*":
                dp[i][j] = dp[i][j - 1] or dp[i - 1][j]       # '*' 匹配空 / 再多吞掉 s[i-1]
            elif p[j - 1] in ("?", s[i - 1]):
                dp[i][j] = dp[i - 1][j - 1]
    return dp[m][n]
```

运行：`("aa", "a")` → `False`，`("aa", "*")` → `True`，`("cb", "?a")` → `False`，`("", "*")` → `True`，`("", "?")` → `False`，`("adceb", "*a*b")` → `True`，`("acdcb", "a*c?b")` → `False`。

**复杂度。** 时间 `O(mn)`；空间 `O(mn)`：`(m + 1) × (n + 1)` 的布尔表，`2000 × 2000` 约四百万格。

**易错点。**
- 第 0 行必须初始化：`s` 为空时，`p` 的前缀全是 `*` 才匹配。漏掉它（只设 `dp[0][0]`），`("aa", "*")` 会得到 `False`（正确 `True`），`("", "*")` 也得到 `False`。
- `*` 的两个来源别写错：`dp[i][j-1]`（`*` 匹配空，退一格模式）和 `dp[i-1][j]`（`*` 多吞一个字符，退一行）。把 `*` 当 `?` 用、只取左上角 `dp[i-1][j-1]`，`("aa", "*")` 得到 `False`，`("adceb", "*a*b")` 得到 `False`，正确都是 `True`。
- 第 0 列误设成 `True`：`p` 为空时非空的 `s` 也"匹配"，`("a", "")` 得到 `True`，正确是 `False`。

**追问。**
- 想要 `O(1)` 额外空间：贪心 + 回溯到最近一个 `*`（只有最后一个 `*` 值得回溯），最坏仍是 `O(mn)`，常见输入接近线性。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 连续的 `*` 等价于一个 `*`：先压缩模式可以减少无意义的列。
- 与 LC 10 的区别：那里 `*` 绑定前一个字符，转移是 `dp[i][j-2]` 或 `dp[i-1][j]` 且前字符兼容。

**同模式。** LC 10 正则表达式匹配、LC 72 编辑距离、LC 97 交错字符串、LC 115 不同的子序列、LC 1143 最长公共子序列。
