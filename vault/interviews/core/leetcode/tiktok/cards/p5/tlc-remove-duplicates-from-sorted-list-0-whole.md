## Q
**LC 83 删除排序链表中的重复元素**｜Easy · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 22 次 · 最近 2025-11-01（面试记录）

给升序排列的链表头节点 `head`，删除所有重复元素，使每个值只出现一次，返回仍然有序的链表。节点数在 `[0, 300]`，`-100 <= Node.val <= 100`。例：`[1,1,2]` → `[1,2]`；`[1,1,2,3,3]` → `[1,2,3]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 有序意味着相同的值挨在一起：用一个指针 `cur` 走，若 `cur.next` 与 `cur` 值相同就把 `cur.next` 摘掉（`cur` 不动），否则 `cur` 前进一步。`O(n)` 时间，`O(1)` 空间。

**识别。** 「已排序」+「去重」→ 重复值必然相邻，不需要哈希表，只比较相邻节点。头节点永远保留（它是第一个出现的值），所以不需要哨兵节点；这与「重复值整段删光」（LC 82）不同，那里头节点可能被删，需要哨兵。

**推导。** 暴力：用集合记录见过的值，遇到见过的就删，`O(n)` 空间 → 浪费：排序已经保证重复相邻，空间不必要 → 只和下一个节点比较 → 相同就让 `cur.next = cur.next.next`，此时新的 `cur.next` 可能还是同值（比如三个连续的 `1`），所以 `cur` 不能前进；不同才前进。

```python
def delete_duplicates(head: ListNode | None) -> ListNode | None:
    cur = head
    while cur and cur.next:
        if cur.val == cur.next.val:
            cur.next = cur.next.next       # 跳过重复节点，cur 原地不动，继续和新的下一个比
        else:
            cur = cur.next
    return head
```

运行：`[1,1,2]` → `[1,2]`，`[1,1,2,3,3]` → `[1,2,3]`，`[]` → `[]`，`[1,1,1]` → `[1]`，`[1,1,1,2]` → `[1,2]`。

**复杂度。** 时间 `O(n)`，每一步要么删一个节点要么前进一步；空间 `O(1)`。

**易错点。**
- 删除之后又前进：写成「相同则摘掉，然后无条件 `cur = cur.next`」，连续三个相同值会漏删。`[1,1,1]` 得到 `[1,1]`，正确是 `[1]`。
- 循环条件缺少 `cur`（只写 `cur.next`）：空链表会对 `None` 取 `.next`。
- 题目保证有序，如果输入无序，相邻比较不能去重。

**追问。**
- 重复的值一个都不留（LC 82）：需要哨兵节点和 `prev` 指针，整段摘除。
- 无序链表去重：用 `set` 记录见过的值，`O(n)` 空间；或者先排序（归并排序 `O(n log n)`）。
- 保留最后一次出现而不是第一次：遇到相同值时删除当前节点本身（需要前驱指针和哨兵节点）。

**同模式。** LC 82 删除排序链表中的重复元素 II、LC 26 删除有序数组中的重复项、LC 203 移除链表元素、LC 1836 从未排序的链表中移除重复元素。
