## Q
**LC 1673 找出最具竞争力的子序列**｜Medium · CodeTop 国内累计 2 次 · 最近 2026-10-12（国内 CodeTop）

给整数数组 `nums` 和正整数 `k`，返回长度为 `k` 且最**具竞争力**的 `nums` 子序列（子序列 = 删去若干元素、保持相对次序）。在两个等长子序列 `a`、`b` 第一个不同的位置上，若 `a` 的数更小，则 `a` 比 `b` 更具竞争力（即字典序最小）。

约束：`1 <= nums.length <= 10^5`，`0 <= nums[i] <= 10^9`，`1 <= k <= nums.length`。

例：`nums = [3,5,2,6], k = 2` → `[2,6]`；`nums = [2,4,3,3,5,4,9,6], k = 4` → `[2,3,3,4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 字典序最小的长度为 `k` 的子序列 = 从 `n` 个数里**恰好丢掉 `n-k` 个**，使剩下的字典序最小；用**单调栈**：新来的数如果比栈顶小且还有丢弃额度，就弹出栈顶（把大数换成小数），最后取栈的前 `k` 个。`O(n)`。

**识别。** 「子序列」+「字典序最小」+「固定长度 `k`」→ **单调栈 / 贪心**：字典序先比较靠前的位置，所以前面的位置越小越好，只要还有额度，就应该把栈顶的大数换成后来的小数。同族：LC 402 移掉 K 位数字（去掉 `k` 个得到最小数）、LC 316 去除重复字母、LC 321 拼接最大数。`n = 10^5` 要求线性。

**推导。** 暴力：枚举所有长度为 `k` 的子序列，取最小的，`C(n,k)` 个，不可行。贪心思路：第一个位置选尽可能小的数——但选完要保证后面还够 `k-1` 个，所以第一个位置只能在 `nums[0 .. n-k]` 里选最小的（最左的最小值）；然后在它右边重复。每一步都找一个区间最小值，朴素 `O(nk)`。优化：用栈同时完成所有选择。扫描到 `x` 时，若栈顶比 `x` 大，丢掉栈顶、把 `x` 留在更靠前的位置字典序就变小——前提是丢弃额度（共 `n-k` 个）还有；一直弹到栈顶不大于 `x` 或额度用完，然后压入 `x`。扫描结束后，若额度没用完，栈长度大于 `k`，多出来的是末尾的元素，直接截断就是应丢掉的。

```python
def most_competitive(nums: list[int], k: int) -> list[int]:
    drop = len(nums) - k               # 一共可以丢掉多少个元素
    stack: list[int] = []
    for x in nums:
        while drop and stack and stack[-1] > x:   # 栈顶比新来的大：丢掉栈顶更优
            stack.pop()
            drop -= 1
        stack.append(x)
    return stack[:k]                   # 丢额度没用完时，末尾多出的部分直接截掉
```

运行：`nums=[3,5,2,6], k=2` → `[2, 6]`，`nums=[2,4,3,3,5,4,9,6], k=4` → `[2, 3, 3, 4]`，`nums=[3,1], k=2` → `[3, 1]`，`nums=[1,2,3,4], k=2（递增，末尾要截断）` → `[1, 2]`，`nums=[5], k=1` → `[5]`。

**复杂度。** 时间 `O(n)`：每个元素入栈一次、至多出栈一次（摊还）；空间 `O(n)`（栈，至多存下全部元素；最终截取前 `k` 个）。

**易错点。**
- 没有丢弃额度的限制：`nums=[3,1]`, `k=2`，应返回 `[3,1]`（必须留 2 个），不限额度会把 `3` 弹掉，只剩 `[1]`，长度不够；`[5,2,3]`, `k=3` 同理，会错返回 `[2,3]`。
- 忘了最后截取到 `k`：`nums=[1,2,3,4]`, `k=2`，递增序列一个也不会被弹出，栈里是 `[1,2,3,4]`，必须取前 `2` 个得 `[1,2]`。
- 比较用了 `>=`：弹掉相等元素没有收益，却白白消耗额度，后面更大的元素就丢不掉了。`nums=[0,0,1]`, `k=2` 得 `[0, 1]`，正确是 `[0, 0]`；必须用严格 `>`。
- 把「还能丢几个」写成「栈里还能放几个」：等价写法 `len(stack) + n - i > k` 也可以，但要同时加 `len(stack) < k` 才入栈，两处缺一不可。

**追问。**
- 最大的子序列（字典序最大）：比较符号反过来，`stack[-1] < x`。
- 必须从两个数组各取一些拼成最大的 `k` 位数（LC 321）：对每种切分，各自求最大子序列，再合并，枚举切分点取最大。
- 元素去重或限定每个字符只出现一次（LC 316）：加 `in_stack` 集合和「后面还有没有」计数，弹栈条件多一个「栈顶后面还会再出现」。

**同模式。** LC 402 移掉 K 位数字、LC 316 / 1081 去除重复字母、LC 321 拼接最大数、LC 496 / 739 单调栈入门、LC 84 柱状图中最大的矩形。
