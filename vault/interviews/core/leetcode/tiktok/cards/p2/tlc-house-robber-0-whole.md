## Q
**LC 198 打家劫舍**｜Medium · LC TikTok 全时段热度 68/100 · 近一年被问：美国 1 次、国内 5 次 · CodeTop 国内累计 38 次 · 最近 2026-10-17（国内 CodeTop）

沿街有一排房屋，`nums[i]` 是第 `i` 间房里的现金。相邻的两间房同一晚上都被偷会触发报警，求不触发警报的前提下一晚最多能偷到多少钱。`1 <= nums.length <= 100`，`0 <= nums[i] <= 400`。例：`nums = [1,2,3,1]` → `4`（偷第 1、3 间，`1 + 3`）；`nums = [2,7,9,3,1]` → `12`（偷第 1、3、5 间，`2 + 9 + 1`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 线性动态规划（DP）：处理到第 `i` 间房时只有两种结局——偷或不偷。不偷则收益是前面的最优，偷则收益是“再前一间不偷”的最优加上 `nums[i]`；整个状态只依赖前两项，两个变量滚动即可，`O(n)` 时间、`O(1)` 空间。

**识别。** 「相邻不能同时选，求最大和」是一维 DP 的经典信号：当前选择只和相邻位置有约束，决策可以从左到右一格一格推进，之前的决策对后面的影响只体现为“上一间偷了没有”这一个比特。`n <= 100` 说明期望的是多项式解，指数枚举（`2^100`）不可行。

**推导。** 暴力：枚举每间房偷或不偷，剔除相邻同偷的方案，`O(2^n)`。递归写法 `f(i) = max(f(i+1), nums[i] + f(i+2))`，没有记忆化时重复计算的规模是斐波那契级的。浪费：`f(i)` 只依赖 `i` 之后的两项，只有 `n` 个不同的状态。改成自底向上 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，`O(n)`；再看到 `dp[i]` 只用前两项，用两个变量滚动。这里用“不偷当前房 / 偷当前房”两个状态：新的“不偷”是旧的两者之大，新的“偷”是旧的“不偷”加当前值，两条赋值必须同时进行。

```python
def rob(nums: list[int]) -> int:
    skip = take = 0                         # skip：不偷当前房的最优；take：偷当前房的最优
    for x in nums:
        skip, take = max(skip, take), skip + x
    return max(skip, take)
```

运行：`[1,2,3,1]` → `4`，`[2,7,9,3,1]` → `12`，`[5]` → `5`，`[2,1,1,2]` → `4`，`[0]` → `0`。

**复杂度。** 时间 `O(n)`：一趟扫描；空间 `O(1)`：两个变量。

**易错点。**
- 贪心地“偷奇数位或偷偶数位，取总和大的”是错的：`[2,1,1,2]` 奇偶位总和都是 `3`，而最优是偷第 1 和第 4 间得到 `4`。
- 两个状态必须同时更新。写成 `skip = max(skip, take)` 再 `take = skip + x`，第二句用到了更新后的 `skip`，相当于允许连续偷：`[1,2,3,1]` 得到 `7`，`[2,7,9,3,1]` 得到 `22`，都是错的（正确 `4` 和 `12`）。
- 只有一间房时直接返回 `nums[0]` 的写法要小心下标；用 `skip` / `take` 从 `0` 起步，空数组、单元素都不需要特判。

**追问。**
- 房屋围成一圈（LC 213）：第一间和最后一间相邻，答案是 `max(线性(nums[1:]), 线性(nums[:-1]))`；单间房时返回 `nums[0]`。`[2,3,2]` → `3`，`[1,2,3,1]` → `4`。
- 要输出偷了哪几间：保留完整的 `dp` 数组，从前往后在“选”或“跳”之间按 `dp` 值回溯；`[2,7,9,3,1]` 偷下标 `[0, 2, 4]`。
- 房屋在二叉树上（LC 337）：对每个节点返回 `(偷它的最优, 不偷它的最优)` 的二元组，后序合并。

**同模式。** LC 213 打家劫舍 II、LC 337 打家劫舍 III、LC 740 删除并获得点数、LC 746 使用最小花费爬楼梯、LC 70 爬楼梯。
