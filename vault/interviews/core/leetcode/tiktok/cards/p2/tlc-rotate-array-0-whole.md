## Q
**LC 189 轮转数组**｜Medium · LC TikTok 近 3 个月热度 70/100（全时段 56） · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 13 次 · 最近 2026-07-20（国内面试记录）

给整数数组 `nums`，把数组中的元素向右轮转 `k` 个位置（`k` 非负），原地修改，不返回。`1 <= nums.length <= 10^5`，`-2^31 <= nums[i] <= 2^31 - 1`，`0 <= k <= 10^5`。例：`nums = [1,2,3,4,5,6,7], k = 3` → `[5,6,7,1,2,3,4]`；`nums = [-1,-100,3,99], k = 2` → `[3,99,-1,-100]`。进阶：至少想出三种解法；能否用 `O(1)` 额外空间原地完成？

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 三次翻转（reverse）：先整体翻转，再翻转前 `k` 个，最后翻转剩下的部分，原地 `O(n)` 时间、`O(1)` 空间；`k` 先对 `n` 取模。

**识别。** 「循环右移 + 原地 + `O(1)` 空间」。`k` 可以大于 `n`，所以先 `k %= n`。右移 `k` 位的结果是「后 `k` 个整体搬到最前面，内部顺序不变」，而翻转恰好能做「整块搬动」。

**推导。** 暴力：右移一位做 `k` 次，`O(nk)` → 用额外数组 `res[(i + k) % n] = nums[i]`，`O(n)` 时间但 `O(n)` 空间 → 环状替换（每个元素直接放到目的地，沿环走 `gcd(n, k)` 圈），`O(1)` 空间但下标绕环难写 → 观察：整体翻转后，原来的后 `k` 个到了最前，只是各自倒序了；把前 `k` 个、后 `n-k` 个各翻转一次就恢复顺序 → 三次翻转。

**简单解法。** 切片拼接：后 `k` 个接到前面，再写回原数组。

```python
def rotate(nums: list[int], k: int) -> None:
    k %= len(nums)                                  # k 可能大于 n
    nums[:] = nums[len(nums) - k:] + nums[:len(nums) - k]   # 原地写回；k = 0 时切成 [] 与全体，不会错
```

时间 `O(n)`，空间 `O(n)`（切片拷贝）；题目要求 `O(1)` 额外空间，所以只能作开场答案。

最优解：

```python
def rotate(nums: list[int], k: int) -> None:
    n = len(nums)
    k %= n                                    # k 可能大于 n
    def reverse(i: int, j: int) -> None:
        while i < j:
            nums[i], nums[j] = nums[j], nums[i]
            i, j = i + 1, j - 1
    reverse(0, n - 1)                         # 整体翻转：后 k 个跑到最前（但是倒序）
    reverse(0, k - 1)                         # 前 k 个翻回正序
    reverse(k, n - 1)                         # 其余翻回正序
```

运行：`([1,2,3,4,5,6,7], 3)` → `[5, 6, 7, 1, 2, 3, 4]`，`([-1,-100,3,99], 2)` → `[3, 99, -1, -100]`，`([1], 5)` → `[1]`，`([1,2], 3)` → `[2, 1]`，`([1,2,3], 0)` → `[1, 2, 3]`。

**复杂度。** 时间 `O(n)`：每个元素最多被交换两次；空间 `O(1)`。

**拓展优化。**
- 环状替换：元素直接放到目的下标 `(i + k) % n`，沿环走，共 `gcd(n, k)` 个环，`O(n)` 时间、`O(1)` 空间：
```python
def rotate_cyclic(nums: list[int], k: int) -> None:
    n = len(nums)
    k %= n
    if k == 0:
        return
    moved = start = 0                               # moved：已放到位的元素数，到 n 就结束
    while moved < n:
        cur, carry = start, nums[start]             # carry：手里拿着、要放到下一个位置的值
        while True:
            nxt = (cur + k) % n
            nums[nxt], carry = carry, nums[nxt]     # 放下手里的值，拿起被占位置的值
            cur = nxt
            moved += 1
            if cur == start:                        # 走完一圈回到起点，换下一个起点开新环
                break
        start += 1
```
- 标准库 `collections.deque.rotate(k)` 就是循环右移，需要时 `d = deque(nums); d.rotate(k)`，但要先拷进 `deque`，不满足原地 `O(1)`。

**易错点。**
- 忘了 `k %= n`：`[1,2]`、`k = 3` 时 `reverse(0, 2)` 越界；即使不越界，切片写法 `nums[-k:] + nums[:-k]` 在 `k > n` 时会给出没转的数组。例：`[1..7]`、`k = 10`，切片写法得到 `[1,2,3,4,5,6,7]`，正确是 `[5,6,7,1,2,3,4]`。
- 分界点错成 `n - k`：`[1..7]`、`k = 3` 会得到 `[4,5,6,7,1,2,3]`（那是左移 3 位），正确是 `[5,6,7,1,2,3,4]`。
- 必须原地修改：`nums = nums[-k:] + nums[:-k]` 只是让局部变量指向新列表，调用方看不到变化；要写 `nums[:] = ...`。

**追问。**
- 向左轮转：等价于向右轮转 `n - k`，或把三次翻转的分界点改成 `k`。
- 链表版本（LC 61）：先连成环再在第 `n - k % n` 处断开。

**同模式。** LC 61 旋转链表、LC 796 旋转字符串、LC 189 的翻转思想也用于 LC 151 反转字符串中的单词。
