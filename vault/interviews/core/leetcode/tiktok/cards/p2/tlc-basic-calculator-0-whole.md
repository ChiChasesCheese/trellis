## Q
**LC 224 基本计算器**｜Hard · LC TikTok 热度 62/100（近 6 个月） · 近一年被问：美国 6 次、国内 2 次 · CodeTop 国内累计 28 次 · 最近 2026-09-09（美国面试记录）

给字符串表达式 `s`，实现一个基本计算器计算并返回它的值。不允许使用 `eval()`。`1 <= s.length <= 3 * 10^5`，`s` 由数字、`+`、`-`、`(`、`)` 和空格组成；`s` 是有效表达式；`+` 不能用作一元运算（`"+1"` 无效），`-` 可以作一元运算（`"-1"`、`"-(2 + 3)"` 有效）；输入中不存在两个连续的操作符；每个数字和运算结果都在有符号 32 位整数内。例：`"1 + 1"` → `2`；`" 2-1 + 2 "` → `3`；`"(1+(4+5+2)-3)+(6+8)"` → `23`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 只有加减和括号：把括号展开成符号即可。扫描时维护当前层的 `res`（已结算的和）、`sign`（下一个数的符号）；遇到 `(` 把 `(res, sign)` 压栈并重置，遇到 `)` 把括号内的结果乘上括号前的符号，再并回外层。一遍扫描 `O(n)`，不递归。

**识别。** 「加减 + 括号 + 一元负号」：括号前面的 `-` 会把括号里所有项的符号翻转，这是栈的信号（嵌套、后进先出）。`n = 3×10^5`，嵌套深度可达 `1.5×10^5`，递归下降会栈溢出，必须用显式栈。没有乘除，所以不需要运算符优先级。

**推导。** 暴力：递归求值——遇到 `(` 递归，括号内的值再乘符号 → 浪费：Python 递归深度默认约 1000，深嵌套直接 `RecursionError` → 用显式栈代替调用栈：进入括号时保存「括号前的和 `res` 与括号前的符号 `sign`」，括号内从 `0` 重新累加，退出时 `res = prev_res + prev_sign * res`。

```python
def calculate(s: str) -> int:
    stack: list[tuple[int, int]] = []     # 进括号前保存 (已累计的结果, 括号前的符号)
    res, num, sign = 0, 0, 1
    for ch in s:
        if ch.isdigit():
            num = num * 10 + int(ch)
        elif ch in "+-":
            res += sign * num             # 结算上一个数
            num, sign = 0, 1 if ch == "+" else -1
        elif ch == "(":
            stack.append((res, sign))     # 括号内从 0 重新算
            res, sign = 0, 1
        elif ch == ")":
            res += sign * num             # 结算括号里最后一个数
            num = 0
            prev_res, prev_sign = stack.pop()
            res = prev_res + prev_sign * res   # 括号结果乘上括号前的符号，再并回去
    return res + sign * num
```

运行：`"1 + 1"` → `2`，`" 2-1 + 2 "` → `3`，`"(1+(4+5+2)-3)+(6+8)"` → `23`，`"-(2+3)"` → `-5`，`"(-2)"` → `-2`，`"1-(-2)"` → `3`，`"2-(5-6)"` → `3`，`"("*100000 + "1" + ")"*100000` → `1`。

**复杂度。** 时间 `O(n)`；空间 `O(括号嵌套深度)`。

**易错点。**
- 括号结果必须乘上括号前的符号：漏乘时 `"1-(2+3)"` 得 `6`，正确是 `-4`。
- 一元负号：表达式开头或 `(` 之后紧跟 `-` 时，`num` 还是 `0`，`res += sign * 0` 无副作用，符号照样被记下，所以 `"-(2+3)"` → `-5`、`"(-2)"` → `-2` 都对，不需要特判。
- 最后一个数在循环外结算：`return res + sign * num`；空格直接被忽略，因为它既不是数字也不是 `+-()`。

**追问。**
- 加入乘除（LC 772）：需要运算符优先级，用数字栈加运算符栈，遇到优先级不低于当前的运算符先归约。
- 只用符号栈、不存 `res`：栈里保存「当前括号层对内部每项的总符号」，每个数直接乘以有效符号累加。
- 递归下降能不能用：能，但深嵌套下要提高递归上限或改成显式栈。
