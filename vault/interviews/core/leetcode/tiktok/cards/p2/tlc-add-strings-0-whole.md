## Q
**LC 415 字符串相加**｜Easy · LC TikTok 热度 62/100 · 近一年被问：美国 1 次、国内 3 次 · CodeTop 国内累计 86 次 · 最近 2026-10-18（国内面试记录）

给两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和，同样以字符串形式返回。不能使用任何内建的处理大整数的库（比如 `BigInteger`），也不能直接把输入的字符串转换为整数。`1 <= num1.length, num2.length <= 10^4`，`num1` 和 `num2` 都只包含数字 `0-9`，且都不含前导零。例：`num1 = "11"`，`num2 = "123"` → `"134"`；`num1 = "456"`，`num2 = "77"` → `"533"`；`num1 = "0"`，`num2 = "0"` → `"0"`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 模拟竖式加法：从个位（字符串末尾）开始，逐位把两个数字和进位相加，用 `divmod(和, 10)` 一步得到新进位和当前位；较短的数用 `"0"` 补齐；最后别忘了残留的进位；结果是从低位到高位收集的，要反转后拼接。`O(max(m, n))`。

**识别。** 「字符串形式的大数」+「不能转成整数」→ 手工竖式加法。加法从低位开始，所以要**反向**遍历；两个数长度不同，较短的数在高位补 `0`，用 `itertools.zip_longest(..., fillvalue="0")` 一次性配好。

**推导。** 暴力（违规）：`str(int(num1) + int(num2))`，题目明确禁止。即使不禁止，Python 3.11 之后字符串转整数默认最多 4300 位，`10^4` 位的输入会直接抛 `ValueError`。洞察：竖式加法的每一位只取决于这一位的两个数字和上一位传来的进位，进位只可能是 `0` 或 `1`。所以一遍扫描、逐位计算，每位 `O(1)`，总共 `O(max(m, n))`。

```python
from itertools import zip_longest


def add_strings(num1: str, num2: str) -> str:
    digits: list[str] = []
    carry = 0
    # 从个位开始配对；短的那个用 "0" 补齐
    for a, b in zip_longest(reversed(num1), reversed(num2), fillvalue="0"):
        carry, d = divmod(int(a) + int(b) + carry, 10)    # 一步同时得到进位和当前位
        digits.append(str(d))
    if carry:
        digits.append("1")
    return "".join(reversed(digits))
```

运行：`("11", "123")` → `"134"`，`("456", "77")` → `"533"`，`("0", "0")` → `"0"`，`("999", "1")` → `"1000"`，`("1", "999")` → `"1000"`，`10^4` 个 `"9"` 加 `"1"` → `"1"` 后面跟 `10^4` 个 `"0"`。

**复杂度。** 时间 `O(max(m, n))`；空间 `O(max(m, n))`（结果）。

**易错点。**
- 漏掉最后的进位：`("999", "1")` 得到 `"000"`，`("5", "5")` 得到 `"0"`，正确是 `"1000"` 和 `"10"`。
- 用 `zip` 而不是 `zip_longest`：较长数的高位被丢掉，`("456", "77")` 得到 `"133"`（带上进位），正确是 `"533"`，`("11", "123")` 得到 `"34"`，正确是 `"134"`。
- 收集顺序：`digits` 是从低位到高位，最后必须 `reversed` 再拼接，否则 `"134"` 变成 `"431"`。
- 对单个字符 `int(a)` 是允许的（只是把 `"7"` 变成 `7`）；违规的是把整串转成整数。

**追问。**
- 字符串相乘（LC 43）：同样的竖式思路，二维逐位相乘，结果数组下标 `i + j` 和 `i + j + 1`。
- 其他进制：二进制求和（LC 67）把 `10` 换成 `2`；36 进制加法把 `int(a)` 换成字符到数值的查表，进位基数换成 `36`。
- 链表形式的大数（LC 2 / LC 445）：链表从低位到高位存储时直接逐节点相加；高位在前时先翻转链表或用栈。

**同模式。** LC 43 字符串相乘、LC 67 二进制求和、LC 2 两数相加、LC 445 两数相加 II、LC 989 数组形式的整数加法。
