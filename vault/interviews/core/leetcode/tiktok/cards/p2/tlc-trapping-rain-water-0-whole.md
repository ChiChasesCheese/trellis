## Q
**LC 42 接雨水**｜Hard · LC TikTok 热度 88/100 · 近一年被问：美国 1 次、国内 4 次 · CodeTop 国内累计 130 次 · 最近 2026-10-28（面试记录）

给 `n` 个非负整数表示宽度为 1 的柱子的高度图，求下雨后一共能接多少单位的雨水。`n == height.length`，`1 <= n <= 2 * 10^4`，`0 <= height[i] <= 10^5`。例：`height = [0,1,0,2,1,0,1,3,2,1,2,1]` → `6`；`height = [4,2,0,3,2,5]` → `9`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 第 `i` 格能存的水等于 `min(左边最高, 右边最高) - height[i]`；用左右两个指针向中间收拢，每次处理**较矮的那一侧**，因为较矮一侧的水位已经由它自己这边的最大值决定，不用等另一侧算完。`O(n)` 时间，`O(1)` 空间。

**识别。** 「每根柱子上方能存多少」是逐位置的量，且取决于**两侧**的最大值，这是「前缀最大 / 后缀最大」的信号；要求 `O(1)` 额外空间或追问优化时就用双指针。`n` 到 `2 * 10^4`，`O(n^2)` 勉强能过但面试不接受。

**推导。** 暴力：对每个 `i` 扫左边求最大、扫右边求最大，`O(n^2)`。浪费：相邻位置的左最大、右最大几乎相同，却各扫一遍。第一步优化：预处理 `left_max[i]` 和 `right_max[i]` 两个数组，`O(n)` 时间 `O(n)` 空间。第二步洞察：设 `height[left] < height[right]`，则 `left` 右边一定存在不低于 `height[right]` 的柱子，所以 `left` 的水位只由 `left_max` 决定（右侧最大值不会更小），可以直接结算 `left_max - height[left]` 并右移 `left`；反过来处理右侧。两个指针各走一遍，数组也省掉了。

```python
def trap(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    left_max = right_max = water = 0
    while left < right:
        if height[left] < height[right]:           # 左边更矮：左格的水位由 left_max 决定
            left_max = max(left_max, height[left])
            water += left_max - height[left]
            left += 1
        else:                                      # 右边更矮或相等：右格的水位由 right_max 决定
            right_max = max(right_max, height[right])
            water += right_max - height[right]
            right -= 1
    return water
```

运行：`[0,1,0,2,1,0,1,3,2,1,2,1]` → `6`，`[4,2,0,3,2,5]` → `9`；`[5]` → `0`，`[3,3,3]` → `0`，`[5,0,5]` → `5`，`[1,2,3,4]` → `0`；`n = 20000`、高度 `0` 与 `100000` 交替 → `999900000`（超过 32 位整数，用 C++ / Java 要 `long`）。

**复杂度。** 时间 `O(n)`，两个指针合计走 `n` 步；空间 `O(1)`。

**易错点。**
- 结算前要先更新 `left_max`（或 `right_max`），否则当前柱子比历史最大还高时会得到负数。
- 两侧的结算不能互换：处理较矮一侧才对。条件反过来写（`height[left] > height[right]` 时处理左侧）会出错，`[0,0,1]` 返回 `1`，正确是 `0`。
- 每格的水量是 `min(左最大, 右最大) - 高度`，不是整体最大值减高度：`[4,2,0,3,2,5]` 用整体最大值会得到 `14`，正确是 `9`。

**追问。**
- 二维版（LC 407）：从边界出发用小根堆，每次弹出最低的边界格向内扩展，水位取 `max(当前水位, 邻格高度)`。
- 改用单调栈：遇到比栈顶高的柱子，弹出栈顶当"坑底"，宽度是当前下标与新栈顶之间，高度差是两边较矮者减坑底，按"层"累加。
- 还要输出每格的水量：用前缀 / 后缀数组的版本更直接。

**同模式。** LC 11 盛最多水的容器、LC 84 柱状图中最大的矩形、LC 407 接雨水 II、LC 238 除自身以外数组的乘积（前缀 / 后缀）。
