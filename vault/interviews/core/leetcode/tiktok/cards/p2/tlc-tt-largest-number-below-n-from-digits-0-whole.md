## Q
**用给定数字拼出小于 N 的最大数**｜Medium · 近一年被问：美国 1 次、国内 9 次 · 最近 2026-10（面试记录）

给正整数 `N` 和一个数字数组 `digits`（元素是 `0` 到 `9`，每个数字可以使用任意多次），用这些数字拼出一个**严格小于** `N` 的最大整数并返回；整数不能有前导零（`0` 本身除外），拼不出就返回 `-1`。`1 <= N <= 10^18`，`1 <= len(digits) <= 10`。例：`N = 23415`，`digits = [2, 4, 9]` → `22999`；`N = 22222`，`digits = [2]` → `2222`；`N = 1`，`digits = [1]` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 答案要么和 `N` 同位数、要么少一位。同位数时，答案与 `N` 共享一段前缀，在某一位严格变小，之后全部放最大的数字；共享前缀越长答案越大，所以从最长的可用前缀往回试，第一个能把某位换小的位置就是答案；同位数都不行，就拼少一位的全最大数字。

**识别。** 「严格小于 `N` 的最大值，数字可重复使用」是数位贪心（digit greedy）：高位决定大小，所以尽量保持高位和 `N` 一致，在尽可能靠后的位置降一点，降完之后后面不再受限，全放最大数字。`N` 到 `10^18` 排除枚举。

**推导。** 暴力：从 `N - 1` 往下逐个检查每一位是否都在 `digits` 里，最坏 `O(N)`。浪费：绝大多数数在高位就已经不合法，却还要逐个检查。洞察：答案与 `N` 的第一个不同位在位置 `i`，该位取比 `N[i]` 小的最大数字，`i` 之后无约束全取最大；前缀 `N[:i]` 必须每位都在 `digits` 里，所以 `i <= p`（`p` 是 `N` 能被 `digits` 拼出的前缀长度）；`i` 越大答案越大，从 `min(p, 位数 - 1)` 往 `0` 试。位数相同全部失败，就少一位：全取最大数字。

```python
from bisect import bisect_left


def largest_below(n: int, digits: list[int]) -> int:
    """由 digits 中的数字（可重复使用）拼出严格小于 n 的最大非负整数，没有则返回 -1。"""
    allowed = sorted(set(digits))
    top = allowed[-1]
    s = str(n)
    length = len(s)
    usable = set(allowed)
    p = 0                                            # n 的前 p 位都能用 allowed 拼出来
    while p < length and int(s[p]) in usable:
        p += 1
    for i in range(min(p, length - 1), -1, -1):      # 共享前缀 s[:i] 从长到短试
        j = bisect_left(allowed, int(s[i]))          # allowed[:j] 是比 s[i] 小的数字
        if j and (allowed[j - 1] or i or length == 1):   # 多位数的首位不能是 0
            return int(s[:i] + str(allowed[j - 1]) + str(top) * (length - i - 1))
    if length > 1:                                   # 同长度没有解：少一位，全取最大数字（只有 0 时就是 0）
        return int(str(top) * (length - 1))
    return -1
```

运行：`(23415, [2, 4, 9])` → `22999`，`(2000, [3, 5])` → `555`，`(2311, [2, 3])` → `2233`，`(22222, [2])` → `2222`，`(23, [2, 3])` → `22`，`(100, [0, 1])` → `11`，`(10, [0])` → `0`，`(5, [0])` → `0`，`(1, [1])` → `-1`，`(5, [5])` → `-1`，`(10**18, [1, 9])` → `999999999999999999`。

**复杂度。** 时间 `O(L log |digits|)`，`L` 是 `N` 的位数（最多 19）；空间 `O(L)`。

**易错点。**
- 必须严格小于：把 `N` 本身也当候选，`(22222, [2])` 得到 `22222`，正确是 `2222`；所以 `i` 最大只取到 `length - 1`。
- 不回退：只在第一个失败的位置试一次，`(2311, [2, 3])` 的前缀 `23` 可用但第三位 `1` 没有更小的数字，不回退就退到少一位，得到 `333`，正确是 `2233`（回到第二位把 `3` 换成 `2`）。
- 同位数无解要退到少一位：`(2000, [3, 5])` 没有任何四位数小于 `2000`（`3`、`5` 都大于首位 `2`），只返回 `-1` 就错了，正确是 `555`。
- 无解只在最后判定：`(1, [1])`、`(5, [5])` 已经是一位数，没有更短的数，返回 `-1`；`(10, [0])` 有 `0` 可用，返回 `0`，不是 `-1`。

**追问。**
- 「不大于 `N`」：调用 `largest_below(n + 1, digits)`。
- 返回无解的约定、`digits` 为空、`N` 以字符串给出（超出 64 位）：位数操作都基于 `str`，直接可用；先问清再写。
- 统计有多少个小于 `N` 的数能拼出：按位数分段，短于 `L` 位的数每位有 `|digits|` 种选法（首位去掉 `0`），同位数的按「第一个不同位」累加。

**同模式。** LC 902 最大为 N 的数字组合、LC 1215 步进数、LC 738 单调递增的数字、LC 670 最大交换。
