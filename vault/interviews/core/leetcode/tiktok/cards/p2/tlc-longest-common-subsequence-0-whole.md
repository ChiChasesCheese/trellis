## Q
**LC 1143 最长公共子序列**｜Medium · LC TikTok 热度 38/100 · 近一年被问：美国 0 次、国内 5 次 · CodeTop 国内累计 61 次 · 最近 2026-10-25（CodeTop）

给两个字符串 `text1` 和 `text2`，返回它们的**最长公共子序列**（longest common subsequence）的长度，不存在则返回 `0`。子序列是在不改变相对顺序的前提下删掉若干字符（可以不删）得到的串，例如 `"ace"` 是 `"abcde"` 的子序列，`"aec"` 不是。`1 <= text1.length, text2.length <= 1000`，只含小写英文字母。例：`text1 = "abcde"`，`text2 = "ace"` → `3`；`"abc"` 与 `"abc"` → `3`；`"abc"` 与 `"def"` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二维动态规划（DP）：`dp[i][j]` 表示 `text1` 前 `i` 个字符与 `text2` 前 `j` 个字符的 LCS 长度；末尾字符相等就 `dp[i-1][j-1] + 1`，不等就取 `max(dp[i-1][j], dp[i][j-1])`；第 0 行、第 0 列是 `0`，答案是 `dp[m][n]`。`O(mn)` 时间、`O(mn)` 空间。

**识别。** 「两个字符串」加「子序列」加「最长」是前缀对上的 DP 的标准信号：每个字符要么匹配、要么被跳过，状态天然是「两个串各看到哪」。`m, n <= 1000` 允许 `O(mn)` = `10^6`；暴力枚举 `text1` 的所有子序列有 `2^m` 个，不可行。

**推导。** 暴力递归 `f(i, j)`：末尾相等就同时后退一格，不等就分别丢掉其中一个串的末尾字符，取较大者，不加记忆是指数级。浪费在于 `f(i, j)` 只有 `m * n` 种不同参数，大量重复。改成自底向上填表，每格 `O(1)`：`dp[i][j]` 只用到左上 `dp[i-1][j-1]`、上方 `dp[i-1][j]` 和左边 `dp[i][j-1]` 三个格子，所以按行从上到下、每行从左到右填就够了。边界：任一个串为空，LCS 是 `0`，所以第 0 行、第 0 列全是 `0`，建表时就是这样。

```python
def longest_common_subsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    # dp[i][j]：text1[:i] 与 text2[:j] 的 LCS 长度；第 0 行、第 0 列保持 0（空串）
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i, a in enumerate(text1, 1):
        for j, b in enumerate(text2, 1):
            if a == b:
                dp[i][j] = dp[i - 1][j - 1] + 1             # 末尾相同：一起算进去
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # 不同：丢掉其中一个串的末尾
    return dp[m][n]
```

运行：`("abcde", "ace")` → `3`，`("abc", "abc")` → `3`，`("abc", "def")` → `0`，`("a", "a")` → `1`，`("bl", "yby")` → `1`，两个长 1000 的全 `"a"` 串 → `1000`。

**复杂度。** 时间 `O(mn)`：双层循环，每格常数；空间 `O(mn)`：`(m + 1) × (n + 1)` 的表。

**易错点。**
- 把「不等」写成归零（按最长公共**子串**处理）会错：`"abcde"` 与 `"ace"` 得到 `1`，正确是 `3`。子序列允许跳过，不等时要继承 `max(上, 左)`。
- 相等时加的是同一行左边的格子：写成 `dp[i][j] = dp[i][j-1] + 1`，`("a", "aaa")` 得到 `3`（正确 `1`），`text1` 的一个 `a` 被重复匹配了三次。相等时必须取左上角 `dp[i-1][j-1] + 1`。

**追问。**
- 返回 LCS 字符串本身：完整的二维表就是回溯的依据，从右下角回溯（相等就斜上取字符，不等就往 `dp` 较大的方向走）。
- 三个串、`k` 个串：状态多一维，`O(n^k)`。
- 两个序列都很长但其中一个元素互不相同：把问题转成最长递增子序列（LIS），`O(n log n)`。
- 空间可以压到 O(min(m, n))：见 Python 工具箱「DP 降维」。
