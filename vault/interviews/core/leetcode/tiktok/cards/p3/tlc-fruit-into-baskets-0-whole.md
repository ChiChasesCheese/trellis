## Q
**LC 904 水果成篮**｜Medium · LC TikTok 热度 38/100（近 3 个月） · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-05-12（美国面试记录）

一排果树，`fruits[i]` 是第 `i` 棵树上水果的种类。你有两个篮子，每个篮子只能装**一种**水果、数量不限。可以从任意一棵树开始，**依次**向右采摘，每棵树恰好摘一个；一旦走到某棵树前水果不符合两个篮子的种类就必须停止。求最多能摘多少个水果。

约束：`1 <= fruits.length <= 10^5`，`0 <= fruits[i] < fruits.length`。

例：`fruits = [1,2,1]` → `3`；`fruits = [0,1,2,2]` → `3`（从第二棵树摘 `[1,2,2]`）；`fruits = [1,2,3,2,2]` → `4`（`[2,3,2,2]`）；`fruits = [3,3,3,1,2,1,1,2,3,3,4]` → `5`（`[1,2,1,1,2]`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 题目翻译过来就是「最多含两种不同数字的最长连续子数组」：可变长滑动窗口，用 `Counter` 记窗口里每种水果的数量，种类超过 2 就收缩左端到恰好 2 种，每步更新最大长度。`O(n)`。

**识别。** 「从某处开始连续向右、遇到不符合就停」= 连续子数组；「两个篮子 / 最多两种」= 窗口内**不同元素个数 ≤ k**（`k = 2`）。约束有单调性：窗口多于两种，再往外扩仍多于两种；窗口缩小只会变好 → 双指针只进不退。`n = 10^5` 要求 `O(n)`。

**推导。** 暴力：每个起点向右扩，用集合记种类，超过 2 种就停，`O(n^2)`。浪费在于：从起点 `i` 扩到第三种出现的位置 `j`，起点 `i+1, i+2, …` 中许多会在同一处停下，重复扫描了大段。洞察：右端固定在 `j` 时，合法的最左起点是唯一确定的，且随 `j` 增大只会右移（单调）。所以右端逐个前进，一旦种类数 `> 2` 就右移左端、把离开窗口的水果计数减 1，数到 0 就删键，直到恰好 2 种。每个下标被两个指针各经过一次，`O(n)`。

```python
def total_fruit(fruits: list[int]) -> int:
    count: Counter[int] = Counter()        # 窗口内 种类 -> 数量
    best = left = 0
    for right, kind in enumerate(fruits):
        count[kind] += 1
        while len(count) > 2:              # 超过两个篮子：收缩左端直到只剩两种
            gone = fruits[left]
            count[gone] -= 1
            if count[gone] == 0:
                del count[gone]            # 必须删键，len(count) 才是「种类数」
            left += 1
        best = max(best, right - left + 1)
    return best
```

运行：`fruits=[1,2,1]` → `3`，`fruits=[0,1,2,2]` → `3`，`fruits=[1,2,3,2,2]` → `4`，`fruits=[3,3,3,1,2,1,1,2,3,3,4]` → `5`，`fruits=[7]` → `1`。

**复杂度。** 时间 `O(n)`：`right` 走 `n` 步，`left` 总共前进不超过 `n` 步；空间 `O(1)`：`count` 最多同时有 3 个键（刚加入第三种、尚未收缩时）。

**易错点。**
- 计数减到 0 后不删键：`len(count)` 永远不会回落，种类数「卡」在 3 上，`left` 一路越过数组末尾，`[1,2,3,2,2]` 直接 `IndexError`。必须 `del count[x]`（或改用 `sum(v > 0 ...)`，那样每步是 `O(种类数)`）。
- 遇到第三种就整体清空重来：`[1,2,3,2,2]` 清空后从 `3` 起算，只能得 `3`，漏掉 `[2,3,2,2]` 的 `4`——正确的新窗口应保留与新水果相邻的那段 `2`。
- 把 `max` 放在收缩前：窗口此刻含三种，长度不合法，会高估答案。`max` 一定写在 `while` 之后。

**追问。**
- 最多 `k` 种（LC 340 / LC 159）：把 `2` 换成 `k`，代码不变；`count` 最多 `k + 1` 个键，空间 `O(k)`。
- 要返回具体区间：更新最优时同时记 `start = left`，返回 `fruits[start : start + best]`。
- 窗口只平移不缩小的技巧：把内层 `while` 改成 `if`，窗口大小永不减少，最后答案就是 `len(fruits) - left`。省掉 `max`，但需要说明为什么正确（窗口大小等于历史最大合法长度）。

**同模式。** LC 3 无重复字符的最长子串、LC 159 / 340 至多包含 K 个不同字符的最长子串、LC 424 替换后的最长重复字符、LC 992 K 个不同整数的子数组、LC 1004 最大连续 1 的个数 III。
