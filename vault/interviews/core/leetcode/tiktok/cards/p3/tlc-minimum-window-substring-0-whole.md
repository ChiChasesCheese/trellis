## Q
**LC 76 最小覆盖子串**｜Hard · LC TikTok 热度 75/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 53 次 · 最近 2026-08-30（CodeTop）

给字符串 `s` 和 `t`，返回 `s` 中**最短**的子串，使该子串包含 `t` 中的每个字符（包括重复字符，出现几次就要覆盖几次）；不存在则返回空字符串 `""`。测试用例保证答案唯一。`m == s.length`，`n == t.length`，`1 <= m, n <= 10^5`，`s` 和 `t` 由英文字母（大小写）组成。进阶：能否做到 `O(m + n)`？例：`s = "ADOBECODEBANC"`，`t = "ABC"` → `"BANC"`；`s = "a"`，`t = "a"` → `"a"`；`s = "a"`，`t = "aa"` → `""`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 可变长滑动窗口：右端逐个吞字符，用计数表 `need` 和「还缺几个字符」`missing` 判断窗口是否已经覆盖 `t`；一旦覆盖就从左端尽可能收缩，记录最短的窗口，再丢掉一个必需字符让窗口重新变得不完整，继续往右。`O(m + n)`。

**识别。** 「子串（连续）+ 最短 + 满足某种覆盖条件」是滑动窗口。条件有单调性：窗口越大越容易覆盖，所以右端扩张使条件趋于成立，左端收缩使其趋于破坏；`m` 到 `10^5`，需要线性。

**推导。** 暴力：枚举所有子串并检查是否覆盖，`O(m^2 * (m + n))`。固定左端、向右扩到刚好覆盖，`O(m^2)`。洞察：对每个右端，满足条件的最大左端是单调不减的（右端右移，最优左端不会左移），所以左端只前进不后退，双指针总计 `O(m)`。覆盖判断不用每次扫字符表：`need[ch]` 记录还差多少个 `ch`（负数表示窗口里多出来），`missing` 记录总共还缺多少个，加入字符时只在 `need[ch] > 0` 才让 `missing` 减一，`missing == 0` 就是覆盖。

```python
from collections import Counter


def min_window(s: str, t: str) -> str:
    need = Counter(t)                              # need[ch] > 0 表示还缺 ch；< 0 表示窗口里多出来
    missing = len(t)                               # 还缺的字符总数（含重复）
    best_l, best_len = 0, len(s) + 1
    left = 0
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        if missing == 0:                           # 窗口已经覆盖 t：尽量收缩左端
            while need[s[left]] < 0:               # 左端字符是多余的，丢掉
                need[s[left]] += 1
                left += 1
            if right - left + 1 < best_len:
                best_l, best_len = left, right - left + 1
            need[s[left]] += 1                     # 再丢一个必需字符，窗口重新变得不完整
            missing += 1
            left += 1
    return "" if best_len > len(s) else s[best_l : best_l + best_len]
```

运行：`"ADOBECODEBANC", "ABC"` → `"BANC"`；`"a", "a"` → `"a"`；`"a", "aa"` → `""`；`"aa", "aa"` → `"aa"`；`"ab", "b"` → `"b"`；`"bba", "ab"` → `"ba"`；`10^5` 个随机小写字母的 `s` 和 `100` 个字符的 `t` 瞬间完成。

**复杂度。** 时间 `O(m + n)`：右端走 `m` 步，左端最多走 `m` 步，建计数表 `O(n)`；空间 `O(Σ)`，`Σ` 为字母表大小（这里至多 52）。

**易错点。**
- 用集合代替计数：`t = "aa"` 需要两个 `a`，集合只记「出现过」，`s = "a"` 会被判成覆盖，返回 `"a"`，正确是 `""`。
- 收缩只能在 `missing == 0` 时进行，并且先丢掉多余字符、记录答案之后，再丢一个必需字符；顺序错了会漏掉当前窗口。
- 窗口收缩的循环用 `need[s[left]] < 0` 判断「多余」，不能用 `> 0` 或 `!= 0`。

**追问。**
- `t` 很短而 `s` 很长：先把 `s` 里属于 `t` 的字符及其下标过滤出来，只在这些位置上滑动，窗口端点不会落在无关字符上（见另一种解法）。
- 要求 `t` 的字符按顺序出现（LC 727 最小窗口子序列）：不能用计数，用正向匹配再反向收缩的双指针或动态规划。
- 返回所有最短窗口：长度并列时都保留，而不是只取第一个。

**同模式。** LC 3 无重复字符的最长子串、LC 438 找到字符串中所有字母异位词、LC 567 字符串的排列、LC 727 最小窗口子序列、LC 209 长度最小的子数组。
