## Q
**LC 69 x 的平方根**｜Easy · LC TikTok 全时段热度 75/100 · 近一年被问：美国 1 次、国内 1 次 · CodeTop 国内累计 69 次 · 最近 2026-08-25（国内 CodeTop）

给非负整数 `x`，返回 `x` 的算术平方根，结果只保留整数部分（向下取整）。不允许使用内置的指数函数和运算符，如 `pow(x, 0.5)` 或 `x ** 0.5`。`0 <= x <= 2^31 - 1`。例：`x = 4` → `2`；`x = 8` → `2`（`2.828...` 舍去小数）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 对答案做二分：在 `[0, x]` 里找最大的整数 `m` 使 `m * m <= x`；因为 `m * m` 随 `m` 单调递增，满足条件的 `m` 构成一个前缀，二分找这个前缀的右端点。`O(log x)`。

**识别。** 「求某个单调函数的反函数的整数部分」是**在答案上二分**（binary search on the answer）的信号：不是在数组里找元素，而是在取值范围 `[0, x]` 里找满足条件的最大值。`x` 最大 `2^31 - 1`，线性枚举约 `46340` 步也能过，但面试要的是 `O(log x)`。

**推导。** 暴力：从 `1` 开始枚举，直到 `m * m > x`，`O(sqrt(x))`。洞察：判定 `m * m <= x` 对 `m` 单调（小的 `m` 为真，大的为假），可以二分。写法的核心是「最大的满足条件的值」：区间 `[lo, hi]` 内，`mid` 向**上**取整（`(lo + hi + 1) // 2`），`mid` 可行就 `lo = mid`，不可行就 `hi = mid - 1`。向上取整是为了防止 `lo = mid` 时区间不缩小而死循环。

```python
def my_sqrt(x: int) -> int:
    lo, hi = 0, x                                  # 答案 m 满足 m*m <= x，找最大的这样的 m
    while lo < hi:
        mid = (lo + hi + 1) // 2                   # 向上取整，否则 lo = mid 时区间不缩小会死循环
        if mid * mid <= x:
            lo = mid                               # mid 可行：答案至少是 mid
        else:
            hi = mid - 1
    return lo
```

运行：`4` → `2`；`8` → `2`；`0` → `0`；`1` → `1`；`2^31 - 1` → `46340`。对 `0` 到 `19999` 的每个整数和 5000 个随机的 `31` 位整数，结果都等于 `math.isqrt(x)`。

**复杂度。** 时间 `O(log x)`，最多约 31 轮；空间 `O(1)`。

**易错点。**
- `mid` 向下取整会死循环：`x = 1` 时 `lo = 0, hi = 1, mid = 0`，`0 * 0 <= 1` 使 `lo = mid = 0`，区间永远不变。
- 可行条件写成严格小于 `mid * mid < x`，会少算平方数：`x = 4` 得到 `1`，正确是 `2`。
- 在 C++ / Java 里 `mid * mid` 会溢出 32 位整数，应写成 `mid <= x // mid` 或用 64 位；Python 整数不溢出。

**追问。**
- 牛顿迭代（Newton's method）：从 `r = x` 开始，`r = (r + x // r) // 2`，直到 `r * r <= x`，收敛极快（`2^31 - 1` 只要约 19 轮）。
- 保留 `k` 位小数：`math.isqrt(x * 10 ** (2 * k))` 再缩小 `10 ** k` 倍。
- 判断完全平方数（LC 367）：同样的二分，最后检查 `lo * lo == x`。

**同模式。** LC 367 有效的完全平方数、LC 50 Pow(x, n)、LC 278 第一个错误的版本、LC 875 爱吃香蕉的珂珂、LC 1011 在 D 天内送达包裹的能力。
