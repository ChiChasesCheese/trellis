## Q
**LC 51 N 皇后**｜Hard · LC TikTok 热度 75/100 · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 14 次 · 最近 2026-08-10（CodeTop）

按国际象棋规则，皇后可以攻击同一行、同一列或同一斜线上的棋子。把 `n` 个皇后放在 `n x n` 的棋盘上，使她们彼此不能攻击，返回所有不同的摆法；每种摆法是 `n` 个字符串，`'Q'` 表示皇后，`'.'` 表示空位。`1 <= n <= 9`。例：`n = 4` → `[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]`；`n = 1` → `[["Q"]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回溯（backtracking）：一行放一个皇后，逐行决定放在哪一列；用三个集合记录已占用的列、主对角线（`r - c` 相同）和副对角线（`r + c` 相同），冲突就跳过，放满 `n` 行就收集一个解。

**识别。** 「放置若干元素满足互不冲突，求所有方案」是回溯的典型题；`n <= 9` 说明指数级搜索可行。关键是用**每行恰好一个皇后**把状态空间从 `C(n^2, n)` 压到 `n^n`，再用冲突检测剪枝。

**推导。** 暴力：在 `n^2` 个格子里选 `n` 个，`C(81, 9)` 约 `2.6 * 10^11`，不可行。第一步：同一行至多一个皇后，所以恰好每行一个，只需决定每行的列，`n^n`。第二步：同一列至多一个，列必须是一个排列，`n!`。第三步：边放边检查对角线，不合法的分支立刻剪掉。对角线的编号是关键：同一条主对角线（左上到右下）上的格子 `r - c` 相同，同一条副对角线（右上到左下）上的格子 `r + c` 相同，所以三个 `set` 就能 `O(1)` 判断冲突。

```python
def solve_n_queens(n: int) -> list[list[str]]:
    result: list[list[str]] = []
    cols: list[int] = []                           # cols[r] = 第 r 行皇后所在的列
    used_col: set[int] = set()
    used_diag: set[int] = set()                    # 主对角线（左上-右下）：r - c 相同
    used_anti: set[int] = set()                    # 副对角线（右上-左下）：r + c 相同

    def place(r: int) -> None:
        if r == n:
            result.append(["." * c + "Q" + "." * (n - c - 1) for c in cols])
            return
        for c in range(n):
            if c in used_col or r - c in used_diag or r + c in used_anti:
                continue
            cols.append(c)
            used_col.add(c)
            used_diag.add(r - c)
            used_anti.add(r + c)
            place(r + 1)
            used_anti.remove(r + c)
            used_diag.remove(r - c)
            used_col.remove(c)
            cols.pop()

    place(0)
    return result
```

运行：`n = 4` → `[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]`；`n = 1` → `[["Q"]]`；`n = 1` 到 `9` 的解数依次是 `1, 0, 0, 2, 10, 4, 40, 92, 352`；`n = 9` 在几毫秒内完成。

**复杂度。** 时间上界 `O(n!)`，实际由冲突剪枝大幅缩小；空间 `O(n)`（三个集合、`cols` 和递归栈，不含输出）。

**易错点。**
- 少检查一条对角线，会放出互相攻击的皇后：只检查列和主对角线，`n = 4` 会得到 `7` 个解，正确是 `2` 个。
- 回溯时三个集合和 `cols` 都要撤销，漏掉任何一个，后面的分支会被错误地剪枝，解的数量变少。
- 棋盘字符串在 `cols` 里一次生成：`"." * c + "Q" + "." * (n - c - 1)`；不要用 `[["."] * n] * n` 创建二维数组，所有行会共享同一个列表。

**追问。**
- 只要解的个数（LC 52）：不用生成棋盘，改用位运算，`n = 12` 得到 `14200`，在 0.1 秒内完成。
- 想再快：利用左右对称，只搜第一行的前一半列，结果翻倍。
- 只要找到一个解：找到后立刻返回，不再继续搜索。
