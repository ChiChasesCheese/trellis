## Q
**LC 31 下一个排列**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 103 次 · 最近 2026-08（面试记录）

整数数组的「下一个排列」是指按字典序排列所有排列时，排在当前排列后面的那一个；如果当前已是最大排列，就重排成最小排列（升序）。给数组 `nums`，**原地**把它改成下一个排列，只允许使用常数额外空间。`1 <= nums.length <= 100`，`0 <= nums[i] <= 100`，元素可能重复。例：`[1,2,3]` → `[1,3,2]`；`[3,2,1]` → `[1,2,3]`；`[1,1,5]` → `[1,5,1]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从右往左找第一个「升」的位置 `i`（`nums[i] < nums[i+1]`）；在 `i` 右边的降序段里，从右往左找第一个比 `nums[i]` 大的 `nums[j]`，交换两者；最后把 `i` 右边整段翻转成升序。找不到 `i`（整体降序）时，整个数组翻转。`O(n)` 时间，`O(1)` 空间。

**识别。** 「下一个字典序更大的排列」+「原地、常数空间」。字典序的规律是：要让序列变大**一点点**，就要保持尽可能长的前缀不变，只改动最靠右、又能变大的那一位，再把它右边的部分变成最小。

**推导。** 暴力：生成全部排列排序后找下一个，`O(n · n!)`，`n = 100` 不可能。观察：如果某个后缀已经是降序，它就是这几个数能排出的最大排列，怎么动都不会变大 → 必须改更靠左的位置：最靠右的那个「升位」`i`。要变大一点点：把 `nums[i]` 换成后缀里**比它大的最小值**。后缀是降序的，所以从右往左遇到的第一个更大的数就是最小的更大值（有重复值时取最右者）。交换后后缀依然是降序，翻转成升序就是最小后缀。

```python
def next_permutation(nums: list[int]) -> None:
    n = len(nums)
    i = n - 2
    while i >= 0 and nums[i] >= nums[i + 1]:    # 从右找第一个"升"的位置：nums[i] < nums[i+1]
        i -= 1
    if i >= 0:
        j = n - 1
        while nums[j] <= nums[i]:               # 右边降序段里，从右数第一个比 nums[i] 大的
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]
    lo, hi = i + 1, n - 1                       # i = -1 时整个数组翻转，正好是最小排列
    while lo < hi:                              # 右边是降序段，翻转成升序 = 最小
        nums[lo], nums[hi] = nums[hi], nums[lo]
        lo, hi = lo + 1, hi - 1
```

运行：`[1,2,3]` → `[1, 3, 2]`，`[3,2,1]` → `[1, 2, 3]`，`[1,1,5]` → `[1, 5, 1]`，`[1,3,2,2]` → `[2, 1, 2, 3]`，`[2,3,1]` → `[3, 1, 2]`。

**复杂度。** 时间 `O(n)`：三次线性扫描；空间 `O(1)`。

**易错点。**
- 找升位时用严格比较 `nums[i] > nums[i+1]` 来继续左移：相等的相邻数被当成升位。`[1,2,2]` 会原样不动，正确是 `[2,1,2]`。继续左移的条件是 `nums[i] >= nums[i+1]`。
- 交换对象选错：与 `i+1` 位置的数交换，而不是后缀里比它大的最小值。`[1,3,2,2]` 会得到 `[3,1,2,2]`，正确是 `[2,1,2,3]`。
- 翻转写成 `nums[i+1:] = nums[:i:-1]`：`i = -1` 时 `nums[:-1:-1]` 是空列表，`[3,2,1]` 会变成 `[]`。

**追问。**
- 上一个排列：对称——找第一个 `nums[i] > nums[i+1]`，与右侧比它小的最大者交换，再把右段翻转成降序。
- 第 `k` 个排列（LC 60）：用阶乘进制逐位确定，不必迭代 `k` 次。
- 切片翻转 `nums[i+1:] = reversed(nums[i+1:])` 更短，但切片会产生 `O(n)` 的临时列表；要求严格常数空间时用双指针。

**同模式。** LC 46 全排列、LC 47 全排列 II、LC 60 排列序列、LC 556 下一个更大元素 III、LC 1850 邻位交换的最小次数。
