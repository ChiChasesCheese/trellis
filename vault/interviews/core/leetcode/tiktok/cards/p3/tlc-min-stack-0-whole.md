## Q
**LC 155 最小栈**｜Easy · 近一年被问：美国 3 次、国内 3 次 · CodeTop 国内累计 42 次 · 最近 2026-10-28（国内面试记录）

设计一个支持 `push`、`pop`、`top`，并能在**常数时间**内取到栈中最小元素的栈。实现 `MinStack` 类：`MinStack()` 初始化；`push(val)` 压入元素；`pop()` 删除栈顶；`top()` 返回栈顶；`getMin()` 返回栈中最小元素。`-2^31 <= val <= 2^31 - 1`；`pop`、`top`、`getMin` 总是在非空栈上调用；各操作合计最多调用 `3 * 10^4` 次。例：依次 `push(-2)`、`push(0)`、`push(-3)`，`getMin()` → `-3`；`pop()`；`top()` → `0`；`getMin()` → `-2`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 每个元素入栈时同时记下「压入它之后栈内的最小值」，二者作为一个二元组同进同出；`getMin` 就是读栈顶二元组的第二个分量。所有操作 `O(1)`，空间 `O(n)`。

**识别。** 「常数时间取最小」加「栈」：栈的状态只在栈顶变化，且 `pop` 之后要恢复到更早的状态。最小值是栈内容的函数，所以每个深度的最小值是确定的，可以在入栈时存下来，出栈时自然恢复，不需要重新扫描。

**推导。** 暴力：`getMin` 遍历整个栈，`O(n)`。浪费：栈里每个位置之下的内容永远不变，该位置"之下及自身"的最小值也永远不变。洞察：把最小值作为快照和元素绑在一起；也可以用一个并行的辅助栈，作用相同。

```python
class MinStack:
    def __init__(self) -> None:
        self.stack: list[tuple[int, int]] = []    # 每项 (值, 压入它时栈内的最小值)

    def push(self, val: int) -> None:
        low = min(val, self.stack[-1][1]) if self.stack else val
        self.stack.append((val, low))             # 最小值跟着元素一起入栈，随它一起出栈

    def pop(self) -> None:
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0]

    def getMin(self) -> int:
        return self.stack[-1][1]
```

**运行。** 依次 `push(-2)`、`push(0)`、`push(-3)`：`getMin()` → `-3`；`pop()` 之后 `top()` → `0`，`getMin()` → `-2`。边界：`push(-2147483648)`、`push(2147483647)` 之后 `getMin()` → `-2147483648`，`top()` → `2147483647`。

**复杂度。** 四个操作都是 `O(1)`；空间 `O(n)`，每个元素多存一个整数。

**易错点。**
- 只用一个变量记最小值：弹出最小值后无法恢复。`push(-2)`、`push(0)`、`push(-3)`、`pop()` 之后 `getMin()` 仍返回 `-3`，正确是 `-2`。
- 辅助栈只在 `val < 当前最小` 时才压：出现重复最小值时会少压。`push(0)`、`push(0)`、`pop()` 之后辅助栈为空，`getMin()` 抛 `IndexError`；条件要写成 `<=`。
- 第一次 `push` 时栈为空，直接访问 `self.stack[-1][1]` 会越界，要单独处理。

**追问。**
- 只用 `O(1)` 额外空间（栈里存 `val - 当前最小值` 的差值）：差值为负说明这个元素就是新的最小值，弹出时用差值还原旧的最小值；在 C++ / Java 里差值可能溢出，要用 `long`。
- 最大栈（LC 716）要支持 `popMax`：用堆加懒删除，或双向链表加有序结构。
- 最小队列：两个栈各存最小值，或单调双端队列。

**同模式。** LC 716 最大栈、LC 232 用栈实现队列、LC 225 用队列实现栈、LC 239 滑动窗口最大值、LC 895 最大频率栈。
