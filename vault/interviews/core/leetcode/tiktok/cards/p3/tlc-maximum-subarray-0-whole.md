## Q
**LC 53 最大子数组和**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 119 次 · 最近 2026-10-14（CodeTop）

给整数数组 `nums`，找出一个具有最大和的**连续子数组**（至少包含一个元素），返回其最大和。`1 <= nums.length <= 10^5`，`-10^4 <= nums[i] <= 10^4`。例：`nums = [-2,1,-3,4,-1,2,1,-5,4]` → `6`（子数组 `[4,-1,2,1]`）；`nums = [1]` → `1`；`nums = [5,4,-1,7,8]` → `23`。进阶：写出 `O(n)` 解法后，再试试分治法。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** Kadane 算法（动态规划）：`cur` 表示「以当前元素结尾的最大子数组和」；每个元素只有两种选择，接在前面最优的子数组后面，或者自己重新开始，即 `cur = max(x, cur + x)`；答案是所有 `cur` 里最大的。`O(n)` 时间，`O(1)` 空间。

**识别。** 「连续子数组 + 最大和」→ 动态规划，状态必须写成「以 `i` 结尾」，这样才保证连续；另一个等价视角是前缀和：子数组和 = 两个前缀和之差。数组里有负数，所以不能用滑动窗口——窗口扩大后和不一定变大，没有单调性可以收缩。`n` 到 `10^5`，`O(n^2)` 的枚举要 `10^10` 次，必须线性。

**推导。** 暴力：枚举所有 `(i, j)` 再求和，`O(n^3)`；用前缀和求和降到 `O(n^2)` → 浪费：以 `j` 结尾的最优子数组，只依赖「以 `j - 1` 结尾的最优子数组」，不必重新枚举起点 → 洞察：如果以 `j - 1` 结尾的最大和 `cur < 0`，带上它只会拖累 `x`，丢掉重新开始；否则接上去 → 一遍扫描，只留一个变量。前缀和写法等价：答案 = 对每个 `j` 取 `P[j] - min(P[0..j-1])` 的最大值。

```python
from itertools import islice


def max_sub_array(nums: list[int]) -> int:
    best = cur = nums[0]                # cur：以当前元素结尾的最大子数组和
    for x in islice(nums, 1, None):     # 跳过首元素，又不拷贝切片
        cur = max(x, cur + x)           # 接在前面后面，或者从 x 重新开始
        best = max(best, cur)
    return best
```

运行：`[-2,1,-3,4,-1,2,1,-5,4]` → `6`，`[1]` → `1`，`[5,4,-1,7,8]` → `23`，`[-3,-1,-2]` → `-1`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 用 `0` 初始化 `best` 和 `cur`：全是负数时返回 `0`，而题目要求至少选一个元素。`[-3,-1,-2]` 会得到 `0`，正确是 `-1`。用 `nums[0]` 初始化。
- 只在循环结束后返回 `cur`：`cur` 是以**最后一个**元素结尾的最大和，不是全局最大。`[3,-5]` 会返回 `-2`，正确是 `3`；答案要靠 `best` 在每一步刷新。
- 用 `nums[0]` 初始化后，循环必须从下标 `1` 开始；若从 `0` 重复处理首元素，`cur + x` 会把它算两次（`[5]` 得到 `10`）。

**追问。**
- 同时返回子数组的位置：当 `cur < 0` 时记下新的起点 `start`，每次刷新 `best` 时一并记下 `start` 和当前下标；`[-2,1,-3,4,-1,2,1,-5,4]` 得到下标 `3..6`。
- 分治（进阶）：每段维护四元组（总和、最大前缀、最大后缀、最大子段），合并时 `best = max(左.best, 右.best, 左.最大后缀 + 右.最大前缀)`；总 `O(n)`，适合并行和区间查询（线段树）。
- 环形数组（LC 918）：答案是 `max(Kadane 最大值, 总和 - 最小子数组和)`；全为负数时要特判，只取 Kadane 结果。
