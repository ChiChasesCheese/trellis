## Q
**LC 64 最小路径和**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 42 次 · 最近 2026-10-27（国内面试记录）

给一个 `m x n` 的非负整数网格 `grid`，找一条从左上角到右下角的路径，使路径上数字之和最小；每次只能向下或向右移动一步。`1 <= m, n <= 200`，`0 <= grid[i][j] <= 200`。例：`[[1,3,1],[1,5,1],[4,2,1]]` → `7`（路径 `1→3→1→1→1`）；`[[1,2,3],[4,5,6]]` → `12`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 网格 DP：`dp[i][j]` 是从左上角走到 `(i, j)` 的最小路径和，`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`；第一行只能从左来、第一列只能从上来，是前缀和；答案是右下角 `dp[m-1][n-1]`。`O(mn)` 时间，`O(mn)` 空间。

**识别。** 「网格 + 只能向右 / 向下 + 路径和最优」是网格 DP 的标准信号：每个格子只能从上或左到达，没有环，计算顺序天然是从左上到右下。数值非负、移动方向受限，所以不需要最短路算法；若允许四个方向走，才需要 Dijkstra。

**推导。** 暴力：DFS 枚举所有路径，路径数是 `C(m+n-2, m-1)`，指数级。浪费：到达同一格的多条路径，后面的走法完全一样，只有「到这格的最小和」有用。洞察：`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`。边界：`dp[0][0] = grid[0][0]`；第一行每格只有左边一个来源，`dp[0][j] = dp[0][j-1] + grid[0][j]`；第一列每格只有上边一个来源，`dp[i][0] = dp[i-1][0] + grid[i][0]`。填完边界，其余格子按行从上到下、从左到右填，用到的上方和左方都已算好。

```python
def min_path_sum(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    # dp[i][j]：从左上角走到 (i, j) 的最小路径和
    dp = [[0] * n for _ in range(m)]
    dp[0][0] = grid[0][0]
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]        # 第一行只能从左来
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]        # 第一列只能从上来
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
    return dp[m - 1][n - 1]
```

**运行。** `[[1,3,1],[1,5,1],[4,2,1]]` → `7`；`[[1,2,3],[4,5,6]]` → `12`；`[[7]]` → `7`；单行 `[[1,2,3]]` → `6`；单列 `[[1],[2],[3]]` → `6`；`200 x 200` 全是 `200` → `79800`。

**复杂度。** 时间 `O(mn)`，每格计算一次；空间 `O(mn)`，一张和网格一样大的表，不修改输入。

**易错点。**
- 第一行、第一列没有初始化，只设了 `dp[0][0]`：边界格子留着 `0`，会被当成"免费"的来源。`[[1,3,1],[1,5,1],[4,2,1]]` 得到 `2`，单列 `[[1],[2],[3]]` 得到 `0`，正确是 `7` 和 `6`。
- 在表外加一圈 `0` 的哨兵再统一用 `min(上, 左)`：第一行、第一列会从哨兵的 `0` 里取最小，路径可以"凭空"从边外进来。`[[1,3,1],[1,5,1],[4,2,1]]` 得到 `3`，正确是 `7`。哨兵要用 `inf`（只有起点上方的哨兵为 `0`）。
- 贪心地每步走较小的邻格：`[[1,3,1],[1,5,1],[4,2,1]]` 会先走下（`1 < 3`）、再走下（`4 < 5`），总和 `9`，正确是 `7`。

**追问。**
- 输出路径本身：完整的 `dp` 表就是回溯的依据，从右下角往回走：当前格的 `dp` 减去 `grid`，看它等于上方还是左方的 `dp`，就知道从哪来；收集下标后反转。
- 允许上下左右四个方向：不再有拓扑顺序，改用 Dijkstra（`heapq`），时间 `O(mn log mn)`。
- 有障碍物（LC 63）：障碍格的 `dp` 设为无穷大，或不可达的计数为 `0`。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。

**同模式。** LC 62 不同路径、LC 63 不同路径 II、LC 120 三角形最小路径和、LC 931 下降路径最小和、LC 174 地下城游戏。
