## Q
**LC 1691 堆叠长方体的最大高度**｜Hard · 近一年被问：美国 0 次、国内 3 次 · 最近 2026-10-23（国内面试记录）

给 `n` 个长方体，`cuboids[i] = [width, length, height]`。从中选一个**子集**堆叠起来：长方体 `i` 能放在 `j` 上，当且仅当 `width_i <= width_j`、`length_i <= length_j`、`height_i <= height_j`；每个长方体可以任意旋转（重新排列长宽高）后再放。返回堆叠后的**最大高度**。`1 <= n <= 100`，`1 <= width_i, length_i, height_i <= 100`。

例：`[[50,45,20],[95,37,53],[45,23,12]]` → `190`（95 + 50 + 45：53x37 朝下、45x20 朝下、23x12 朝下）；`[[38,25,45],[76,35,3]]` → `76`（谁也放不上谁，单个长方体立起来最高）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先把每个长方体的三条边升序排好（最长边当高度，对每个箱子都是最优朝向），再把所有长方体按三元组字典序排序，问题就变成**带权最长递增子序列**：`dp[i] = 高度_i + max(dp[j])`，`j < i` 且 `j` 三维都不大于 `i`（`j` 放在 `i` 上面）。`O(n^2)`。

**识别。**
- 「选子集堆叠」+「能不能放上去由一个逐维 `<=` 的关系决定」+「求总高度最大」= 在偏序（partial order）上求**最大权链**，即带权 LIS。
- 「可以旋转」看起来要枚举朝向，但 `n = 100`、边长 `<= 100` 说明有结论能把朝向消掉，剩下 `O(n^2)` 的 DP 就够。

**推导。** 暴力：枚举子集、堆叠顺序、每个箱子 6 种朝向，指数级。两处浪费。
1. 朝向：如果某个朝向下 `i` 能放在 `j` 上，那么把两个箱子的边各自升序排好之后，`i` 仍然逐维不大于 `j`（升序后第 `t` 小的边逐个比较，不会变坏）。而最长边当高度，是这个箱子能给总高度的最大贡献。所以每个箱子只保留「升序、最长边当高」这一个朝向。
2. 顺序：升序之后，`j` 能放在 `i` 上意味着 `j` 的三元组字典序不大于 `i`。把所有箱子按三元组排序，能放在 `i` 上面的只可能是排在它前面的 `j`，于是 `dp[i]` 只看 `j < i`，和最长递增子序列同构，只是「长度 1」换成「高度」。

```python
def max_height(cuboids: list[list[int]]) -> int:
    boxes = sorted(sorted(c) for c in cuboids)      # 先让每个长方体 w<=l<=h，再整体按字典序排
    dp = [0] * len(boxes)                            # dp[i]：以 boxes[i] 为底的最大高度
    for i, box in enumerate(boxes):
        dp[i] = box[2] + max(
            (dp[j] for j in range(i) if all(a <= b for a, b in zip(boxes[j], box))),
            default=0,                               # 上面放不了任何箱子：只有它自己
        )
    return max(dp)
```

运行：示例 1 → `190`，示例 2 → `76`，`[[7,11,17],[7,17,11],[11,7,17],[11,17,7],[17,7,11],[17,11,7]]` → `102`，`[[1,1,1]]` → `1`。

**复杂度。** 时间 `O(n log n + n^2)`，`n = 100` 时约一万次比较；空间 `O(n)`。

**易错点。**
- 忘了先给每个长方体内部排序：示例 1 会变成 `65`（正确 `190`）。
- 只给内部排序、不整体排序：`[[4,5,5],[4,4,2]]` 得 `5`，正确答案 `9`（`[2,4,4]` 应放在 `[4,5,5]` 上面，但它排在后面，`dp` 只看前面的项，看不到 `[4,5,5]`）。
- 把三个朝向都展开成独立项再 DP（经典 Box Stacking 的写法）会让同一个箱子被叠多次：`[[1,2,3]]` 得 `6`，正确答案 `3`。

**追问。**
- 要输出具体堆叠方案：多存一个 `prev[i]`，最后沿 `prev` 回溯。
- 要求严格小于：把 `a <= b` 改成 `a < b`，排序不变。
- `n` 到 `10^5`：三维偏序，用 CDQ 分治加树状数组（Fenwick tree），`O(n log^2 n)`。

**同模式。** LC 354 俄罗斯套娃信封（二维，可用二分把 LIS 做到 `O(n log n)`）、LC 300 最长递增子序列、LC 646 最长数对链、LC 368 最大整除子集。
