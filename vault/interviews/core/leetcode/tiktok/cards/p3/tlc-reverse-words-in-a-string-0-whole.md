## Q
**LC 151 反转字符串中的单词**｜Medium · 近一年被问：美国 3 次、国内 1 次 · CodeTop 国内累计 29 次 · 最近 2026-09-06（国内 CodeTop）

给字符串 `s`，反转其中单词的顺序。单词是由非空格字符组成的串，`s` 里用至少一个空格分隔单词，开头、结尾、单词之间都可能有多余的空格。返回单词顺序颠倒、单词之间只用**一个**空格连接、没有前导或尾随空格的字符串。`1 <= s.length <= 10^4`，`s` 只含英文字母、数字和空格，至少有一个单词。例：`"the sky is blue"` → `"blue is sky the"`；`"  hello world  "` → `"world hello"`；`"a good   example"` → `"example good a"`。进阶：字符串可变时用 `O(1)` 额外空间原地完成。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从右往左扫描：跳过空格，遇到单词就切下来放进列表，最后用单个空格连接。每个字符只看一次，`O(n)`。Python 里 `" ".join(reversed(s.split()))` 是同一件事的一行写法，要会写这版手动扫描，因为面试官常禁止 `split`。

**识别。** 「单词顺序反转 + 规范化空格」是字符串扫描 + 分词：关键是怎样处理多余空格。从右往左扫描天然得到反转的顺序，不需要再 `reverse` 一次。`n <= 10^4`，任何线性解都行；进阶要求原地 `O(1)`，信号是「整体反转 + 逐词反转」。

**推导。** 暴力：用 `split(" ")` 分割再反转再连接，单词之间有连续空格时会出现空串 → 浪费不在速度，而在边界：多个空格、首尾空格 → 要么用不带参数的 `split()`（按任意连续空白切，自动丢弃空串），要么自己扫描跳过空格 → 手动版：指针 `i` 从末尾向左，遇空格跳过，遇单词记下右边界，一路走到单词左边的空格，切片放进列表 → `" ".join(words)`。

```python
def reverse_words(s: str) -> str:
    words: list[str] = []
    i = len(s) - 1
    while i >= 0:                          # 从右往左扫描
        if s[i] == " ":
            i -= 1
            continue
        end = i + 1                        # 单词的右开边界
        while i >= 0 and s[i] != " ":
            i -= 1
        words.append(s[i + 1:end])         # i 停在单词左边的空格（或 -1）
    return " ".join(words)
```

运行：`"the sky is blue"` → `"blue is sky the"`，`"  hello world  "` → `"world hello"`，`"a good   example"` → `"example good a"`，`"a"` → `"a"`，`" a  "` → `"a"`。

**复杂度。** 时间 `O(n)`；空间 `O(n)`：单词列表和结果字符串。

**易错点。**
- 用 `s.split(" ")`（显式传一个空格）：连续空格会产生空串，连接后空格数不对。`"  hello world  "` 得到 `"  world hello  "`，正确是 `"world hello"`；`"a good   example"` 得到 `"example   good a"`，正确是 `"example good a"`。
- 切片边界：`end = i + 1` 要在 `i` 向左移动之前记下；晚了就会得到空串，单词全部丢失。
- 首尾空格：从右往左扫描时前导和尾随空格都被统一跳过，不需要先 `strip`，也不会漏掉其中一侧。

**追问。**
- 原地 `O(1)`（可变字符数组）：先压缩空格，再整体反转，再逐个单词反转回来。
- 只反转每个单词内部的字母、单词顺序不变（LC 557）：按空格切，逐个反转。
- 输入含制表符或换行：`split()` 会一并处理所有空白，手动扫描需要把 `s[i] == " "` 换成 `s[i].isspace()`。

**同模式。** LC 186 反转字符串中的单词 II（可变数组原地）、LC 557 反转字符串中的单词 III、LC 344 反转字符串、LC 58 最后一个单词的长度。
