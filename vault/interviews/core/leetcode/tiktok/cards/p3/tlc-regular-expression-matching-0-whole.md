## Q
**LC 10 正则表达式匹配**｜Hard · LC TikTok 热度 53/100 · 近一年被问：美国 3 次、国内 0 次 · CodeTop 国内累计 19 次 · 最近 2026-09-04（美国面试记录）

给字符串 `s` 和模式 `p`，实现支持 `'.'` 和 `'*'` 的正则匹配：`'.'` 匹配任意单个字符；`'*'` 匹配**零个或多个**它前面的那一个元素。匹配要覆盖整个 `s`，不是部分。`1 <= s.length <= 20`，`1 <= p.length <= 20`，`s` 只含小写字母 `a-z`，`p` 只含小写字母以及 `'.'`、`'*'`，保证每个 `'*'` 前面都有有效字符。例：`s = "aa", p = "a"` → `false`；`s = "aa", p = "a*"` → `true`；`s = "ab", p = ".*"` → `true`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 记忆化递归（动态规划）：`match(i, j)` 表示 `s[i:]` 能否被 `p[j:]` 完整匹配；如果 `p[j+1]` 是 `'*'`，有两条路：跳过 `x*`（匹配零次），或者当前字符匹配后留在 `p[j]` 不动、只让 `i` 前进（再多匹配一次）；否则当前字符匹配后两边一起前进。状态 `O(mn)` 个，每个 `O(1)`。

**识别。** 两个字符串比对、每一步取决于「各自走到哪」→ 状态是下标对 `(i, j)`，二维 DP / 记忆化的标准形态。`'*'` 的「零个或多个」是一个**选择**，不能贪心——吃多了后面就匹配不上，必须能回头。`m, n <= 20`，指数回溯可能超时，`O(mn) = 400` 个状态轻松。

**推导。** 暴力回溯：遇到 `x*` 枚举匹配 `0, 1, 2, ...` 次，再递归匹配剩余部分；`s = "aaaa...a"`、`p = "a*a*a*...b"` 这种输入下各个 `*` 的分配组合数是指数级。浪费：不同的分配方式会走到同一个 `(i, j)`，剩下的子问题完全一样。洞察：把「匹配几次」拆成两条边——`(i, j) → (i, j+2)`（零次），或 `(i, j) → (i+1, j)`（先吃一个字符，仍停在 `x*` 上，以后还能继续吃或跳过）；这样每个状态只有常数条出边，加上缓存就是 `O(mn)`。

```python
from functools import cache


def is_match(s: str, p: str) -> bool:
    @cache
    def match(i: int, j: int) -> bool:      # s[i:] 能否被 p[j:] 整个匹配
        if j == len(p):
            return i == len(s)
        first = i < len(s) and p[j] in (s[i], '.')   # 当前字符能否匹配 p[j]
        if j + 1 < len(p) and p[j + 1] == '*':
            # 星号两条路：匹配零次（跳过 "x*"），或匹配一次后留在原位继续
            return match(i, j + 2) or (first and match(i + 1, j))
        return first and match(i + 1, j + 1)

    return match(0, 0)
```

运行：`("aa", "a")` → `False`，`("aa", "a*")` → `True`，`("ab", ".*")` → `True`，`("aab", "c*a*b")` → `True`，`("mississippi", "mis*is*p*.")` → `False`，`("aaa", "a*a")` → `True`，`("a", "ab*")` → `True`，`("ab", ".*c")` → `False`；长度 `20` 的最坏输入 `("a" * 20, "a*a*a*a*a*a*a*a*a*a*b")` → `False`，瞬间返回。

**复杂度。** 时间 `O(mn)`：至多 `(m+1)(n+1)` 个状态，每个状态常数次转移；空间 `O(mn)`：缓存表，递归深度至多 `m + n`。

**易错点。**
- 把 `'*'` 当贪心：先吃光所有匹配的字符。`s = "aa", p = "a*a"`，`a*` 吃掉两个 `a`，剩下的 `a` 无字可配，得到 `False`；正确是 `True`（`a*` 只吃一个）。
- 漏掉「零次」分支：`s = "aab", p = "c*a*b"`，开头的 `c*` 必须匹配零次，不跳过就得到 `False`，正确是 `True`。
- 把 `first` 的判断写在 `j == len(p)` 之前，或者没有先判 `i < len(s)`：`i` 越界时下标报错；`s` 已经用完时仍然要走「跳过 `x*`」，比如 `("", "a*")` 应该是 `True`。

**追问。**
- 自底向上填表：`f[i][j]` 从 `i = m, j = n` 倒着算，只依赖 `f[i][j+2]`、`f[i+1][j]`、`f[i+1][j+1]`，可以用滚动数组压到 `O(n)` 空间，也避免递归。
- 增加 `'+'`（一个或多个）和 `'?'`（零个或一个）：`x+` 等价于 `xx*`，`x?` 只有「零次」和「一次」两条边。
- 通配符匹配（LC 44，`'*'` 匹配任意序列，`'?'` 匹配单个字符）：没有「前面那个元素」的约束，可以用双指针加回溯点的贪心。

**同模式。** LC 44 通配符匹配、LC 72 编辑距离、LC 1143 最长公共子序列、LC 97 交错字符串、LC 115 不同的子序列。
