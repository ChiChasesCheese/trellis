## Q
**LC 662 二叉树最大宽度**｜Medium · LC TikTok 热度 38/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 54 次 · 最近 2026-09-01（面试记录）

给二叉树的根节点 `root`，返回树的**最大宽度**。每一层的宽度是该层最左和最右的非空节点之间的长度，把树当作同结构的满二叉树，两端点之间的 `null` 节点也计入长度；最大宽度是所有层的宽度的最大值。答案保证在 32 位带符号整数范围内。节点数在 `[1, 3000]`，`-100 <= Node.val <= 100`。例：`root = [1,3,2,5,3,null,9]` → `4`（第 3 层的 `5,3,null,9`）；`root = [1,3,2,5,null,null,9,6,null,7]` → `7`；`root = [1,3,2,5]` → `2`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 给节点编号，像堆（heap）一样：根为 `0`，编号 `i` 的左孩子是 `2i`，右孩子是 `2i + 1`；按层遍历（BFS），每层的宽度 = 最右编号 - 最左编号 + 1，取最大。每层用最左编号归零，编号就不会随深度指数增长。`O(n)`。

**识别。** 「宽度包含中间的空节点」意味着不能只数节点个数，要知道每个节点在满二叉树里的**位置**；「每一层」指向层序遍历。满二叉树中位置有现成的编号公式。`n <= 3000` 但深度可以达到 3000，真把树展开成满二叉树数组会有 `2^3000` 个位置，不可行。

**推导。** 暴力：把树补成满二叉树，用数组存每一层，扫描每层的首尾非空位置。深度为 `d` 要 `O(2^d)` 的空间，链状树直接爆炸。浪费：空节点占了几乎所有空间，而宽度只取决于**每层最左和最右**两个非空节点的位置。位置有公式：父节点编号 `idx`，孩子是 `2 * idx` 和 `2 * idx + 1`。于是 BFS 时队列里带上编号，每层首尾相减即可。编号会逐层翻倍，其他语言会溢出；每层处理前减去本层最左编号，让编号相对本层归零，数值始终不超过当前层宽度的两倍。

```python
def width_of_binary_tree(root: TreeNode | None) -> int:
    if root is None:
        return 0
    best = 0
    level: list[tuple[TreeNode, int]] = [(root, 0)]      # (节点, 它在满二叉树该层里的编号)
    while level:
        base = level[0][1]                               # 本层最左编号，用来归零
        best = max(best, level[-1][1] - base + 1)
        nxt: list[tuple[TreeNode, int]] = []
        for node, idx in level:
            idx -= base                                  # 归零后编号不会随深度指数膨胀
            if node.left:
                nxt.append((node.left, 2 * idx))
            if node.right:
                nxt.append((node.right, 2 * idx + 1))
        level = nxt
    return best
```

运行：`[1,3,2,5,3,null,9]` → `4`，`[1,3,2,5,null,null,9,6,null,7]` → `7`，`[1,3,2,5]` → `2`，`[1]` → `1`；3000 个节点的右链 → `1`。

**复杂度。** 时间 `O(n)`：每个节点入列一次；空间 `O(w)`：`w` 是最宽一层的节点数，最坏 `O(n)`。

**易错点。**
- 只数每层的节点个数而不用编号：示例 1 得到 `3`（正确 `4`），示例 2 得到 `2`（正确 `7`），因为中间的空位没计入。
- 宽度是 `最右编号 - 最左编号 + 1`，漏掉 `+ 1` 会少算 1。
- 不归零在 Python 里不会溢出，但深度 3000 的树编号会长到 3000 位的大整数，每次运算变慢；用 `idx -= base` 保持小数值，也是在向面试官表明你知道其他语言会溢出。

**追问。**
- 用 DFS：先序遍历（先左后右）时，用字典 `first[depth]` 记每层**第一次**见到的编号，当前宽度 = `idx - first[depth] + 1`，取最大。
- 题目说答案在 32 位内但中间编号可能溢出：这就是要归零的原因（C++ / Java 常用无符号数或归零）。
- 只要最后一层的宽度，或每层的宽度数组：BFS 的 `best` 换成列表追加即可。

**同模式。** LC 102 层序遍历、LC 515 每个树行中找最大值、LC 919 完全二叉树插入器、LC 958 二叉树的完全性检验（也用编号）。
