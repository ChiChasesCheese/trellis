## Q
**LC 153 寻找旋转排序数组中的最小值**｜直觉：为什么和右端比

二分找旋转数组的最小值时，为什么拿 `nums[mid]` 和右端 `nums[hi]` 比，而不是和左端 `nums[lo]` 比？`nums[hi]` 在这里代表什么？

## A
**先分清。** `nums[lo]`、`nums[hi]` 是当前区间两端的值，不是最大值、最小值。`[4,5,6,7,0,1,2]` 里 `nums[hi] = 2`，既不是最大也不是最小。

**两段。** 旋转后的数组分成左段 `[4,5,6,7]` 和右段 `[0,1,2]`，两段各自递增，右段的每个值都比左段小。最小值就是右段的第一个，也就是「断崖」下面那个。

**右端永远在右段。** 所以和它比，答案只有两种：

- `nums[mid] > nums[hi]`：mid 比右段的值大，只能在左段，断崖在 mid 右边，`lo = mid + 1`
- `nums[mid] < nums[hi]`：mid 在右段，最小值在 mid 或它左边，`hi = mid`

**不变量。** `hi` 只会被设成 mid，而这时 mid 一定在右段，所以 `hi` 始终待在右段，这个比较的含义从头到尾不变。

**没旋转也成立。** `[1,2,3,4,5]` 整个数组就是「右段」，`nums[mid] < nums[hi]` 恒成立，`hi` 一路缩到下标 0，正好是最小值。

**记住。** 找最小值（断崖右边那个）和右端比；对称地，找最大值（断崖左边那个）和左端比。
