## Q
**圆环上走 n 步回到原点的方案数**｜Medium · 近一年被问：美国 0 次、国内 2 次 · 最近 2026-09（面试记录）

一个环上有 `10` 个点，编号 `0` 到 `9`（`9` 的顺时针下一个是 `0`）。从 `0` 出发，每一步可以顺时针或逆时针走一个点。问恰好走 `n` 步后回到点 `0` 有多少种不同的走法（两种走法只要某一步的方向不同就算不同）。`0 <= n <= 10^5`，答案对 `10^9 + 7` 取模。例：`n = 2` → `2`（先顺后逆、先逆后顺）；`n = 4` → `6`；`n = 10` → `254`；`n = 1` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 动态规划：`ways[p]` 表示当前步数下停在点 `p` 的走法数，初始只有 `ways[0] = 1`；每走一步，新的 `ways[p]` 等于上一步 `ways[p-1]` 与 `ways[p+1]`（下标对环取模）之和；走 `n` 步后答案是 `ways[0]`。只存 `10` 个数，`O(10n)` 时间、`O(10)` 空间。

**识别。** 「恰好 `n` 步、每步两种选择、问方案数」是计数型动态规划；状态是（步数、位置），转移只依赖上一步的两个相邻位置；环形用下标取模。`n` 到 `10^5`：`O(n · 10)` 毫无压力；每步只依赖上一步，所以只需要滚动的一行数组。

**推导。** 暴力：每步两个方向，枚举所有 `2^n` 种方向序列，检查净位移是不是 `10` 的倍数，`O(2^n)`，`n = 30` 就不可行。浪费：很多方向序列在同一步停在同一个位置，之后的走法完全相同，却被重复展开。洞察：把走法按“当前位置”合并，`f[s][p]` 记录走 `s` 步停在 `p` 的方案数；状态只有 `n × 10` 个，每个转移 `O(1)`。每一步只用上一步，滚动数组即可。

```python
MOD = 10**9 + 7


def ring_walks(n: int, size: int = 10, mod: int = MOD) -> int:
    """环上 size 个点，从 0 出发每步顺时针或逆时针走一格，恰好 n 步回到 0 的走法数（对 mod 取模）。"""
    ways = [1] + [0] * (size - 1)                          # ways[p]：当前步数下停在 p 的走法数
    for _ in range(n):
        ways = [(ways[p - 1] + ways[(p + 1) % size]) % mod for p in range(size)]   # p - 1 为负时 Python 自动绕回
    return ways[0]
```

运行：`n = 0, 1, 2, 3, 4, 10, 20` → `1, 0, 2, 0, 6, 254, 215766`；`n = 100000` → `131065086`；`size = 4` 的小环、`n <= 12` 的所有结果与逐条枚举方向序列的计数一致。

**复杂度。** 时间 `O(size · n)`，空间 `O(size)`。

**易错点。**
- 更新时覆盖了旧数组：在原数组上依次 `ways[p] = ways[p-1] + ways[(p+1) % size]`，后面的 `p` 读到的是本步新值。`n = 2` 得到 `0`，正确是 `2`；必须用列表推导式一次性生成新数组，保证全部读旧值。
- `(p + 1)` 忘记取模：`p = 9` 时下标 `10`，`IndexError`；`p - 1` 为负数靠的是 Python 的负下标刚好绕回末尾，换成 C++ 或 Java 要写 `(p - 1 + size) % size`。
- 每步不取模：Python 整数不溢出，但 `n = 10^5` 时数字有三万多位，每次加法变慢；取模保持数值小。
- 奇数步不可能回到起点（每步改变奇偶性，环有偶数个点），可以直接返回 `0`；环的点数是奇数时没有这个性质。

**追问。**
- `n` 到 `10^18`：转移是固定的 `10 x 10` 矩阵，用矩阵快速幂 `O(10^3 · log n)`。
- 闭式：顺时针 `j` 步、逆时针 `n - j` 步，净位移 `2j - n` 是 `10` 的倍数，答案是 `sum(C(n, j))` 对满足条件的 `j` 求和。
- 起点终点不同、有障碍点、步长可选：改成 `ways[target]`，或者在转移里跳过障碍点，框架不变。

**同模式。** LC 70 爬楼梯、LC 62 不同路径、LC 935 骑士拨号器、LC 576 出界的路径数、LC 1269 停在原地的方案数。
