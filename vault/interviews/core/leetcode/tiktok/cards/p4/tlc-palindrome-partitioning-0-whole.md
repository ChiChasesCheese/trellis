## Q
**LC 131 分割回文串**｜Medium · 近一年被问：美国 0 次、国内 2 次 · CodeTop 国内累计 6 次 · 最近 2026-07（国内面试记录）

给字符串 `s`，把它分割成若干子串，使每个子串都是回文串，返回所有可能的分割方案。`1 <= s.length <= 16`，`s` 只含小写英文字母。例：`s = "aab"` → `[["a","a","b"],["aa","b"]]`；`s = "a"` → `[["a"]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回溯（backtracking）加回文表：先用区间 DP 算出 `pal[i][j]`（`s[i..j]` 是否回文）；然后从位置 `start` 出发枚举第一段的结束位置 `end`，只有 `pal[start][end]` 为真才选这一段，递归处理 `end + 1`；`start` 走到末尾就收集当前路径的拷贝。

**识别。** 「返回**所有**分割方案」是枚举型回溯，输出规模本身就是指数级；`n <= 16` 说明 `O(2^n)` 级别的搜索可接受。「每一段都要是回文」意味着可以边切边判断，一旦前缀不是回文就剪枝，而不是切完再检验。反复判断同一段是不是回文，用区间 DP 预处理，之后 `O(1)` 查表。

**推导。** 暴力：每两个相邻字符之间切或不切，共 `2^(n-1)` 种切法，每种再逐段检验回文，`O(2^n · n^2)`。浪费：前缀已经不是回文，后面怎么切都是白搜；同一个子串的回文性被反复判断。洞察：切一段就立刻判断，不回文直接跳过，只会搜到有效方案的前缀；回文性用 `pal[i][j] = s[i] == s[j] and pal[i+1][j-1]` 递推，`i` 从大到小填表。搜索树的每个叶子都是一个答案。

```python
def partition(s: str) -> list[list[str]]:
    n = len(s)
    pal = [[False] * n for _ in range(n)]    # pal[i][j]：s[i..j] 是否回文
    for i in range(n - 1, -1, -1):
        for j in range(i, n):
            pal[i][j] = s[i] == s[j] and (j - i < 2 or pal[i + 1][j - 1])
    res: list[list[str]] = []
    path: list[str] = []

    def dfs(start: int) -> None:
        if start == n:
            res.append(path.copy())          # 必须拷贝：path 之后还会被修改
            return
        for end in range(start, n):
            if pal[start][end]:
                path.append(s[start:end + 1])
                dfs(end + 1)
                path.pop()                   # 回溯

    dfs(0)
    return res
```

运行：`"aab"` → `[['a', 'a', 'b'], ['aa', 'b']]`，`"a"` → `[['a']]`，`"aba"` → `[['a', 'b', 'a'], ['aba']]`，`"a" * 16` → `32768` 种方案（`2^15`，每个切点切或不切）。

**复杂度。** 预处理 `O(n^2)`；搜索最坏 `O(n · 2^n)`（全相同字符时有 `2^(n-1)` 个方案，每个方案拷贝 `O(n)`）；空间 `O(n^2)`（回文表）加 `O(n)` 递归栈，输出本身不计。

**易错点。**
- 收集结果时不拷贝：`res.append(path)` 存的是同一个列表，回溯结束后全被清空，`"aab"` 得到 `[[], []]`；要写 `path.copy()`。
- 回文表填表顺序：`pal[i][j]` 依赖 `pal[i + 1][j - 1]`，所以 `i` 必须从大到小；从小到大填，`"aba"` 的 `pal[0][2]` 读到未算的 `False`，漏掉 `['aba']`，只得到 `[['a', 'b', 'a']]`。
- 回溯要 `path.pop()` 撤销选择；漏掉的话前一个分支的段会留在路径里。
- 长度为 `1` 和 `2` 的回文要特判（`j - i < 2`）：否则 `pal[i + 1][j - 1]` 的下标会反过来。

**追问。**
- 最少分割次数（LC 132）：同一张回文表，再做一维 DP：`dp[j] = 0`（`s[:j+1]` 本身回文）或 `min(dp[i-1] + 1)` 对所有 `pal[i][j]` 的 `i`。
- 只要方案数：不必存路径，`count[start]` 记忆化，`O(n^2)`。
- `n` 更大（如 `10^3`）：方案数爆炸，题目只会问最少次数或方案数，这时回文表必须预处理，`O(n^2)`。
