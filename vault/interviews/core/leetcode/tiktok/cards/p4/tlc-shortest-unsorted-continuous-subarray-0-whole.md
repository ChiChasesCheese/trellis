## Q
**LC 581 最短无序连续子数组**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-09（面试记录）

给整数数组 `nums`，找一个连续子数组，把它升序排序后整个数组都变成升序，返回满足条件的**最短**子数组的长度。`1 <= nums.length <= 10^4`，`-10^5 <= nums[i] <= 10^5`。进阶：设计 `O(n)` 的解法。例：`[2,6,4,8,10,9,15]` → `5`（排序 `[6,4,8,10,9]` 即可）；`[1,2,3,4]` → `0`；`[1]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从左到右维护前缀最大值，凡是比它小的位置都必须被排序，最后一个这样的位置是右端；从右到左维护后缀最小值，凡是比它大的位置都必须被排序，最左的那个是左端。两遍可以合成一个循环，`O(n)` 时间、`O(1)` 空间。

**识别。** 「排序一段使整体有序」不要去找递减段，换成问：哪些元素不在最终位置上。`n = 10^4` 允许 `O(n log n)` 的排序对比，进阶要求 `O(n)`，指向前缀最大值与后缀最小值这类单调扫描。

**推导。** 暴力：枚举所有 `[l, r]`，排序后检查整体有序，`O(n^3 log n)`。改进：排序一份副本，第一个和最后一个与原数组不同的下标就是边界，`O(n log n)`。浪费：排序只是为了知道“谁不在原位”。洞察：位置 `i` 必须在排序段里，当且仅当它左边有比它大的数，或右边有比它小的数。所以右端是最后一个“小于前缀最大值”的位置，左端是最前一个“大于后缀最小值”的位置，一遍扫描两端各维护一个值。

```python
from math import inf


def find_unsorted_subarray(nums: list[int]) -> int:
    n = len(nums)
    start, end = 0, -1                     # 初始 end - start + 1 == 0，即已有序
    hi, lo = -inf, inf                     # 从左看的最大值；从右看的最小值
    for i in range(n):
        if nums[i] < hi:                   # 左边有更大的数，i 必须被排序
            end = i
        else:
            hi = nums[i]
        j = n - 1 - i
        if nums[j] > lo:                   # 右边有更小的数，j 必须被排序
            start = j
        else:
            lo = nums[j]
    return end - start + 1
```

运行：`[2,6,4,8,10,9,15]` → `5`，`[1,2,3,4]` → `0`，`[1]` → `0`，`[2,1]` → `2`，`[1,1,1]` → `0`，`[1,3,2,2,2]` → `4`，长度 `10^4` 的降序数组 → `10000`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`，不修改入参。

**易错点。**
- 只用相邻逆序对 `nums[i] > nums[i+1]` 定边界：`[1,2,4,5,3]` 得到长度 `2`（只含 `5, 3`），正确是 `3`，因为 `4` 也比 `3` 大，必须一起排序。
- 比较必须严格：`nums[i] <= hi` 会把重复值当成无序，`[1,1,1]` 返回 `3`，正确是 `0`。
- 初始值 `start = 0, end = -1`，有序数组才得到 `0`；写成 `start = end = 0` 会返回 `1`。

**追问。**
- 返回区间本身：循环结束的 `start, end` 就是区间。
- 单调栈写法：正反各扫一遍，弹出的最小下标是左端，最大下标是右端，要 `O(n)` 额外空间。
- 排序对比法：`sorted(nums)` 与原数组逐位比较，`O(n log n)`，写起来最短，进阶题不够。
