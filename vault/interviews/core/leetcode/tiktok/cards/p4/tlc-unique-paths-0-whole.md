## Q
**LC 62 不同路径**｜Medium · LC TikTok 全时段热度 26/100 · 近一年被问：美国 1 次、国内 1 次 · CodeTop 国内累计 35 次 · 最近 2026-05-06（国内 CodeTop）

一个机器人位于 `m x n` 网格的左上角，每次只能向下或向右移动一步，要走到网格的右下角。问总共有多少条不同的路径？`1 <= m, n <= 100`，题目数据保证答案小于等于 `2 * 10^9`。例：`m = 3, n = 7` → `28`；`m = 3, n = 2` → `3`（右右下 / 下下右 / 下右下）；`m = 7, n = 3` → `28`；`m = 3, n = 3` → `6`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 网格 DP 计数：`dp[i][j]` 是从左上角走到 `(i, j)` 的路径数，等于到达上方格与左方格的路径数之和 `dp[i-1][j] + dp[i][j-1]`，第一行和第一列都是 `1`；答案是 `dp[m-1][n-1]`，`O(mn)` 时间和空间。也可以直接用组合数：一共走 `m + n - 2` 步，从中选 `m - 1` 步向下，答案是 `C(m + n - 2, m - 1)`。

**识别。** 「网格 + 只能向右 / 向下 + 数路径」是网格 DP 计数的标准信号：每个格子只能从上或左到达，无环。步数固定，每条路径恰好 `m - 1` 次向下、`n - 1` 次向右，只是顺序不同，所以也是一个组合问题。答案可达 `2 * 10^9`，说明不能逐条枚举。

**推导。** 暴力：DFS 每个格子分两个方向走，路径数就是答案，指数级。改进：到同一格的路径后续相同，只记数量：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`，`O(mn)`。边界：第一行的格子只能一路向右，第一列的格子只能一路向下，各只有 `1` 条路，所以建表时整张表先填 `1`，再从 `(1, 1)` 开始按行覆盖。终极：每条路径是 `m - 1` 个"下"和 `n - 1` 个"右"的排列，`C(m + n - 2, m - 1)`。

```python
from math import comb


def unique_paths(m: int, n: int) -> int:
    # dp[i][j]：从左上角走到 (i, j) 的路径数
    dp = [[1] * n for _ in range(m)]                 # 第一行、第一列都只有 1 条路
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]   # 最后一步从上来，或从左来
    return dp[m - 1][n - 1]


def unique_paths_comb(m: int, n: int) -> int:
    return comb(m + n - 2, m - 1)                    # 一共走 m+n-2 步，选出 m-1 步向下
```

**运行。** `(3, 7)` → `28`；`(3, 2)` → `3`；`(7, 3)` → `28`；`(3, 3)` → `6`；`(1, 1)` → `1`；`(1, 100)` → `1`；`(51, 9)` → `1916797311`；两个函数在 `1..39` 的所有 `m, n` 上结果相同，`(100, 100)` 也一致。

**复杂度。** DP：时间 `O(mn)`，空间 `O(mn)`；组合数：`math.comb` 约 `O(min(m, n))` 次大整数乘除，空间 `O(1)`。

**易错点。**
- 初始化：整张表全设为 `0`，递推从 `(1, 1)` 开始就全是 `0`，`(3, 7)` 得到 `0`；第一行（和第一列）的每个格子都只有 `1` 条路。只把第一行设成 `1`、第一列留着 `0`：`(3, 7)` 得到 `21`，`(3, 3)` 得到 `3`，正确是 `28` 和 `6`。
- 组合数的步数：一共走 `m + n - 2` 步（起点本身不算），写成 `comb(m + n, m)` 会得到 `120`，而 `(3, 7)` 的正确答案是 `28`。
- 在 C++ / Java 里先算阶乘再相除会溢出（`100!` 远超 64 位）；要用 DP，或边乘边除保持整除。

**追问。**
- 有障碍物（LC 63）：障碍格的路径数置 `0`，不能再用组合公式。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 必须经过某个格子：拆成两段，路径数相乘。
- `m, n` 到 `10^5`、答案取模：预处理阶乘与逆元，用组合公式。

**同模式。** LC 63 不同路径 II、LC 64 最小路径和、LC 120 三角形最小路径和、LC 980 不同路径 III、LC 174 地下城游戏。
