## Q
**LC 115 不同的子序列**｜Hard · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 5 次 · 最近 2026-10（面试记录）

给两个字符串 `s` 和 `t`，统计并返回在 `s` 的**子序列**中 `t` 出现的个数（子序列是删掉若干字符、不改变剩余字符相对顺序得到的串；用不同下标选出的相同字符串算不同的方案）。测试用例保证结果在 32 位有符号整数范围内。`1 <= s.length, t.length <= 1000`，`s` 和 `t` 由英文字母组成。例：`s = "rabbbit", t = "rabbit"` → `3`（三个 `b` 里去掉任意一个）；`s = "babgbag", t = "bag"` → `5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 动态规划（DP）：`dp[i][j]` 表示 `s` 的前 `i` 个字符里 `t[:j]` 作为子序列出现的方案数；`dp[i][j] = dp[i-1][j]`（不用 `s[i-1]`），当 `s[i-1] == t[j-1]` 时再加上 `dp[i-1][j-1]`（用 `s[i-1]` 去配 `t[j-1]`）；第 0 列全是 `1`，答案是 `dp[m][n]`。`O(mn)` 时间，`O(mn)` 空间。

**识别。** 「在一个串里数另一个串作为子序列的出现次数」是双序列**计数** DP，状态是一对前缀 `(i, j)`，和求最大值的 LCS 同形、转移改成加法。规模 `1000 × 1000`，`O(mn) = 10^6`。近似但不同：LC 392 只问「是不是子序列」（双指针），LC 1143 求最长公共子序列的长度。

**推导。** 暴力：枚举 `s` 的所有长度为 `|t|` 的下标组合，`C(m, n)` 个，指数级。递归 `f(i, j)` 表示 `s[i:]` 里 `t[j:]` 的方案数：若 `s[i] == t[j]`，既可以「用」这个字符配 `t[j]`（`f(i+1, j+1)`），也可以「不用」（`f(i+1, j)`）；不相等只能「不用」。同一个 `(i, j)` 被反复求解 → 填表。改成「前缀」视角：看 `s` 的最后一个字符 `s[i-1]` 用不用，两类选法互斥且完备：不用，方案数是 `dp[i-1][j]`；用，它必须配 `t` 的最后一个字符 `t[j-1]`，要求 `s[i-1] == t[j-1]`，前面的由 `s[:i-1]` 配出 `t[:j-1]`，是 `dp[i-1][j-1]`。边界：`dp[i][0] = 1`（`t` 为空，什么都不选，恰有一种），`dp[0][j] = 0`（`j > 0`，空的 `s` 凑不出非空的 `t`）。

```python
def num_distinct(s: str, t: str) -> int:
    m, n = len(s), len(t)
    # dp[i][j]：s[:i] 里 t[:j] 作为子序列出现的次数
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = 1                        # 空串是任何前缀的子序列，恰有一种取法
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            dp[i][j] = dp[i - 1][j]         # 不用 s[i-1]
            if s[i - 1] == t[j - 1]:
                dp[i][j] += dp[i - 1][j - 1]  # 用 s[i-1] 去配 t[j-1]
    return dp[m][n]
```

运行：`("rabbbit", "rabbit")` → `3`，`("babgbag", "bag")` → `5`，`("a", "aa")` → `0`，`("aaa", "a")` → `3`，`("abc", "abc")` → `1`，`("a" * 1000, "a" * 500)` 也瞬间算完。

**复杂度。** 时间 `O(mn)`；空间 `O(mn)`：`(m + 1) × (n + 1)` 的表，`1000 × 1000` 约一百万个整数。

**易错点。**
- 第 0 列只在 `dp[0][0]` 置 `1`：非空前缀对应的 `dp[i][0]` 是 `0`，`("aaa", "a")` 得到 `1`，`("babgbag", "bag")` 得到 `3`，正确是 `3` 和 `5`。第 0 列每一行都必须是 `1`。
- 字符相等时只取 `dp[i-1][j-1]`（把「不用」那一项丢了）：`("rabbbit", "rabbit")` 得到 `1`，正确是 `3`。相等时「用」与「不用」两条路的方案数要相加。
- 相等时加的是同一行左边的 `dp[i][j-1]`，而不是上一行的 `dp[i-1][j-1]`：`s[i-1]` 被重复使用，`("a", "aa")` 得到 `1`（正确 `0`），`("aaa", "aa")` 得到 `6`（正确 `3`）。

**追问。**
- 需要输出方案或调试：保留的完整二维表就是答案的来源；从 `(m, n)` 回溯，`dp[i][j] > dp[i-1][j]` 说明用了 `s[i-1]`。
- 结果要对一个模数取余：每次 `dp[i][j]` 累加后取模；原题保证结果不超过 32 位，所以 Python 里不会有精度问题，但中间值可能大于 32 位。
- 递归加 `@cache`（自顶向下）：深度可达 `len(s) + len(t) = 2000`，超过默认递归上限，需要提高上限或改成迭代。
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。

**同模式。** LC 392 判断子序列、LC 1143 最长公共子序列、LC 72 编辑距离、LC 97 交错字符串、LC 44 通配符匹配。
