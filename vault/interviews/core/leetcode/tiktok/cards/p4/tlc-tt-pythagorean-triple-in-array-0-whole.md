## Q
**整数数组中的勾股三元组**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-08-17（美国面试记录）

给整数数组 `nums`，判断是否存在三个不同下标 `i`、`j`、`k`，使得 `nums[i]^2 + nums[j]^2 == nums[k]^2`。元素可以是负数、`0`，也可以有重复的值；只要求下标互不相同，值可以相同，所以 `[0,0,0]` 是 `True`，`[0,5,5]` 也是 `True`（`0^2 + 5^2 = 5^2`）。返回布尔值，要求时间 `O(n^2)`。`0 <= n <= 3000`，`|nums[i]| <= 10^5`。例：`[3,4,5]` → `True`；`[-3,4,-5]` → `True`；`[1,2,3]` → `False`；`[3,3,5]` → `False`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先把每个数平方（符号不再影响结果）并排序，再从大到小枚举斜边 `sq[k]`，在它左边用左右双指针找两个平方数之和等于 `sq[k]`，这就是 3Sum 的结构。`O(n^2)`。

**识别。** `a^2 + b^2 = c^2` 就是「三个数满足线性关系」，只不过变量换成了平方，和 3Sum 同构：固定一个数，在剩下的里面做两数之和；`n = 3000`、要求 `O(n^2)`，正好是「排序 + 双指针」的预算；负数通过平方抹掉符号；「下标不同」靠排序后的下标 `i < j < k` 自然保证，不需要按值去重。

**推导。** 暴力：三重循环枚举下标，`O(n^3)`，`3000` 时是 `10^10` → 浪费：固定 `c` 后，找 `a`、`b` 是 Two Sum，却被当成双重循环 → 洞察：平方后排序，`c` 取最大的候选，`a`、`b` 只能来自更小的平方；固定 `k`，左指针 `i = 0`，右指针 `j = k - 1`，和太小移 `i`，和太大移 `j`，一次 `O(k)`，总共 `O(n^2)`。

```python
def has_pythagorean_triple(nums: list[int]) -> bool:
    sq = sorted(x * x for x in nums)             # 平方抹掉符号；排序后位置不同的元素仍占不同下标
    for k in range(len(sq) - 1, 1, -1):          # sq[k] 当斜边，直角边从更小的下标里找
        i, j = 0, k - 1
        while i < j:
            s = sq[i] + sq[j]
            if s == sq[k]:
                return True
            if s < sq[k]:
                i += 1
            else:
                j -= 1
    return False
```

运行：`[3,4,5]` → `True`；`[-3,4,-5]` → `True`；`[0,0,0]` → `True`；`[0,5,-5]` → `True`；`[0,5]` → `False`；`[1,2,3]` → `False`；`[3,3,5]` → `False`；`[]` → `False`；`[6,8,10,7]` → `True`；`3000` 个奇数的最坏输入约 `0.1` 秒。

**复杂度。** 时间 `O(n^2)`（排序 `O(n log n)`，双指针 `O(n)` 乘 `n` 次）；空间 `O(n)`（平方数组）。

**易错点。**
- 没平方就排序：`[-5,3,4]` 按原值排序后最大的是 `4`，把它当斜边永远找不到，返回 `False`，正确是 `True`（`3^2 + 4^2 = (-5)^2`）。
- 用集合去重：`[0,0,0]` 去重后只剩一个 `0`，判成 `False`，正确是 `True`；`[5,0,5]` 去重后只剩一个 `5`，也会漏掉 `0^2 + 5^2 = 5^2`。
- 指针范围写成 `j = k`：斜边被同时当成直角边，`[0,5,7]` 里 `0^2 + 7^2 = 7^2` 用的是同一个位置，会误判 `True`，正确是 `False`。必须 `i < j < k`。

**追问。**
- 返回所有不重复的三元组或统计个数：命中后要跳过相同的平方值，避免重复计数。
- 数值有上界 `M`：可以用勾股数生成公式 `(m^2 - n^2, 2mn, m^2 + n^2)` 及其倍数枚举所有候选，再用哈希查数组里是否同时有这三个数。
- 数组更长（`10^5`）：`O(n^2)` 不够，只能利用值域有界加生成公式。

**同模式。** LC 15 三数之和、LC 611 有效三角形的个数、LC 16 最接近的三数之和、LC 259 较小的三数之和。
