## Q
**LC 2673 使二叉树所有路径值相等的最小代价**｜Medium · LC TikTok 全时段热度 41/100 · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-07-15（美国面试记录）

给整数 `n`，表示一棵满二叉树的节点数，节点编号 `1` 到 `n`，根是 `1`，每个非叶子节点 `i` 的左孩子是 `2 * i`、右孩子是 `2 * i + 1`。数组 `cost`（下标从 `0` 开始，长度 `n`）中 `cost[i]` 是节点 `i + 1` 的值。每次操作可以把任意一个节点的值加 `1`，次数不限。要让根到每个叶子的路径值（路径上所有节点值之和）都相等，求最少的操作次数。`3 <= n <= 10^5`，`n + 1` 是 `2` 的幂，`1 <= cost[i] <= 10^4`。例：`n = 7`，`cost = [1,5,2,2,3,3,1]` → `6`（把节点 4 加 1、节点 3 加 3、节点 7 加 2，所有路径值都是 9）；`n = 3`，`cost = [5,3,3]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 自底向上：在每个非叶子节点处，两个孩子子树的「最大路径值」之差就是这个节点必须补的次数，补在值较小的那个孩子上（它会同时抬高其下所有叶子）；然后把这个节点的值加上两个孩子里较大的路径值，传给父节点。累加所有差值。`O(n)`。

**识别。** 满二叉树用堆式下标（孩子是 `2i`、`2i+1`）表示，直接对数组操作，不需要建树。「只能加、让所有根到叶路径相等」是自底向上的树形贪心：对一个节点，其下的操作只会影响这个子树内的叶子；对两个兄弟子树，路径值较小的那个必须被补到与较大的相等，而补在兄弟子树的**根**上，一次操作抬高子树里所有的叶子路径，比补在更深的节点上省。

**推导。** 暴力：枚举目标路径值，对每个叶子补差额，总代价 `sum(目标 - 叶子路径值)`，没有利用共享的祖先，要把增量补在叶子上；示例中目标 `9` 时叶子各补 `1,0,3,5`，共 `9`，比最优的 `6` 多。浪费：同一个祖先的一次加法可以同时抬高它下面的多个叶子，补在叶子上就浪费了这种共享。洞察：从最深的非叶子节点往上看，每个节点的两个孩子子树必须“拉齐”，差值 `|L - R|` 是必要的最少操作，补在较小一侧的根上；拉齐之后，这个子树内所有路径值都一样，等于 `自身值 + max(L, R)`，作为一个整体交给上一层，上一层的决定与这个子树内部无关。所以全局最优是各层差值之和。

```python
def min_increments(n: int, cost: list[int]) -> int:
    c = [0] + cost                               # 1 下标，节点 i 的孩子是 2i、2i+1
    ans = 0
    for i in range(n // 2, 0, -1):               # 从最后一个非叶子节点倒着往上
        left, right = c[2 * i], c[2 * i + 1]
        ans += abs(left - right)                 # 较小的一边加到和较大的一边相等
        c[i] += max(left, right)                 # c[i] 变成「i 到叶子的路径值」
    return ans
```

运行：`(7, [1,5,2,2,3,3,1])` → `6`，`(3, [5,3,3])` → `0`，`(7, [1,2,3,4,5,6,7])` → `5`，`(3, [1,1,1])` → `0`，`(15, [1,2,...,15])` → `17`，`n = 65535`（取值上限内最大的满二叉树）瞬间完成。

**复杂度。** 时间 `O(n)`，空间 `O(n)`（复制出的 `c` 数组；可以直接改输入换成 `O(1)`）。

**易错点。**
- 把增量补在叶子上：`(7, [1,5,2,2,3,3,1])` 补到目标 `9`，叶子各补 `1,0,3,5`，共 `9`，正确是 `6`。
- 只比较孩子自己的值、不累加子树路径：`(7, [1,2,3,4,5,6,7])` 这样算得 `3`，正确是 `5`（要比较的是「到叶子的路径值」，所以 `c[i] += max(left, right)` 不能漏）。
- 下标偏移：题目节点编号从 `1`、`cost` 从 `0`；开头补 `[0]` 让两者对齐，循环从 `n // 2`（最后一个非叶子节点）到 `1`。
- 方向：必须从下往上；从上往下时，还不知道子树里的路径值，没法比较。

**追问。**
- 输出具体怎么加：每个非叶子节点处，较小的那个孩子的编号和差值 `abs(left - right)` 就是一次具体操作，记下来即可，`O(n)`。
- 空间：直接在 `cost` 上累加可以省掉拷贝，变成 `O(1)` 额外空间，代价是修改输入。
- 为什么补在兄弟子树的根最优：根上加 `d`，其下所有叶子路径同时增加 `d`；补在更深的节点只抬高更少的叶子，要达到同样效果需要更多次操作。
