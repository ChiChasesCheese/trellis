## Q
**LC 130 被围绕的区域**｜Medium · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 7 次 · 最近 2026-09（面试记录）

给一个 `m x n` 的矩阵 `board`，由字符 `'X'` 和 `'O'` 组成。相连指水平或垂直方向相邻；连在一起的 `'O'` 构成一个区域；如果一个区域里**所有** `'O'` 都不在棋盘边缘，这个区域就被 `'X'` 围绕。把所有被围绕的区域原地填充为 `'X'`，不需要返回值。`1 <= m, n <= 200`。例：`[["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]` → `[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]`（底部的 `O` 在边缘，不能被围绕）；`[["X"]]` → `[["X"]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 反过来想：不去找“被围绕的”，而是找“没被围绕的”——从边缘上的 `'O'` 出发做 BFS，把所有与边缘相连的 `'O'` 临时标成 `'#'`；然后扫一遍整个棋盘：`'#'` 还原成 `'O'`，其余的 `'O'`（一定是被围绕的）改成 `'X'`。`O(m·n)`。

**识别。** 「一个区域是否被围绕」等价于「这个连通块是否碰到边缘」，是连通块问题。直接判断每个内部的 `'O'` 要先找出整块再看有没有碰到边缘，既麻烦又容易重复；反向思考：与边缘相连的 `'O'` 数量少、起点明确（四条边上），从它们出发搜索一遍就够了。`m·n` 最大 `4 * 10^4`，递归 DFS 会超过 Python 的递归上限，所以用 BFS（或显式栈）。

**推导。** 暴力：对每个没访问的 `'O'` 搜出整个连通块，同时记录有没有碰到边缘，没碰到就整块改成 `'X'`，`O(m·n)`，要存连通块的格子列表。更简洁：碰到边缘的才是特殊的——保留它们，其余全部改掉。洞察：从边缘的 `'O'` 开始搜索，沿途标记成 `'#'`（既是访问标记，也是“保留”标记），一遍结束后，所有仍是 `'O'` 的格子都不与边缘相连，可以直接改成 `'X'`；最后把 `'#'` 还原。不需要额外的 `visited` 数组，也不需要存连通块。

```python
from collections import deque
from itertools import chain


def solve(board: list[list[str]]) -> None:
    m, n = len(board), len(board[0])
    border = chain(((r, c) for r in range(m) for c in (0, n - 1)),
                   ((r, c) for c in range(n) for r in (0, m - 1)))
    queue = deque()
    for r, c in border:
        if board[r][c] == "O":
            board[r][c] = "#"                    # 与边界相连的 O 先标成 #，入队时标记避免重复
            queue.append((r, c))
    while queue:
        r, c = queue.popleft()
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < m and 0 <= nc < n and board[nr][nc] == "O":
                board[nr][nc] = "#"
                queue.append((nr, nc))
    for r in range(m):
        for c in range(n):
            board[r][c] = "O" if board[r][c] == "#" else "X"   # # 还原成 O，剩下的 O 都是被围的，一起变 X
```

运行：开头的例子 → `['XXXX', 'XXXX', 'XXXX', 'XOXX']`；`[["X"]]` → `[["X"]]`；`[["O"]]` → `[["O"]]`（单个格子就在边缘）；`["XXX","OOX","XXX"]` → 不变（`(1,0)` 在边缘，`(1,1)` 与它相连）；`200 x 200` 全 `'O'` → 全部保留（`40000` 个 `'O'`）；`200 x 200` 外圈 `'X'`、内部全 `'O'` → `0` 个 `'O'`；`200 x 200` 的蛇形区域不会 `RecursionError`。

**复杂度。** 时间 `O(m·n)`（每个格子至多入队一次，最后扫一遍），空间 `O(m·n)`（队列最坏情形）。

**易错点。**
- 只把内部的 `'O'` 改掉、不沿着边缘的 `'O'` 搜索：`["XXX","OOX","XXX"]` 里 `(1,1)` 与边缘的 `(1,0)` 相连，应当保留；只改内部 `'O'` 的写法把它改成 `'X'`，得到 `['XXX', 'OXX', 'XXX']`。
- 忘记还原 `'#'`：棋盘里残留 `'#'`，输出不是 `'X'`/`'O'`。
- 递归 DFS：`200 x 200` 全 `'O'` 的棋盘递归深度可达 `4 * 10^4`，`RecursionError`；用队列迭代。
- 入队时不标记、出队时才标记：同一个格子可能被多个邻居重复入队，队列膨胀（最坏 `4` 倍），结果仍正确但变慢。

**追问。**
- 不允许改成 `'#'` 这样的临时字符（例如棋盘是只读的）：另开 `visited` 集合，`O(m·n)` 额外空间。
- 并查集解法：给边缘外加一个虚拟节点，所有边缘的 `'O'` 与它合并，相邻的 `'O'` 互相合并，最后不与虚拟节点连通的 `'O'` 改成 `'X'`。
- 8 方向相连：把四个方向换成八个，其余不变。

**同模式。** LC 200 岛屿数量、LC 417 太平洋大西洋水流问题、LC 1020 飞地的数量、LC 1254 统计封闭岛屿的数目。
