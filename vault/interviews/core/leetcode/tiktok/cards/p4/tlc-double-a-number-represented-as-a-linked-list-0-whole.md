## Q
**LC 2816 翻倍以链表形式表示的数字**｜Medium · 近一年被问：美国 0 次、国内 1 次 · 最近 2026-09-15（面试记录）

给一个非空链表的头节点 `head`，它从高位到低位表示一个不含前导零的非负整数，每个节点一位数字。把这个数翻倍，返回结果链表的头节点。节点数在 `[1, 10^4]`，`0 <= Node.val <= 9`，除数字 `0` 本身外没有前导零。例：`[1,8,9]`（189）→ `[3,7,8]`（378）；`[9,9,9]` → `[1,9,9,8]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 翻倍的进位只来自**右边**一位：右边那位 `>= 5` 就向左进 1。所以从左到右一趟扫，每位 `= (自己*2 + 右边是否>=5) % 10`，前面挂一个值为 0 的哑头吸收最高位的溢出。`O(n)` 时间、`O(1)` 空间，不用反转。

**识别。** 「链表表示的大数 + 算术」→ 先想进位方向。加法/乘法的进位是低位到高位，而链表头是高位，常规做法要反转或用栈；但「乘 2」的进位只有 0/1，且完全由右邻居的值决定，可以直接前瞻。`n = 10^4` 位，`int(...)` 转换在 Python 里会触发 4300 位的上限，不能偷懒转整数。

**推导。** 暴力：拼成字符串转 `int`，乘 2，再拆成链表；`10^4` 位会抛 `ValueError`（超过 4300 位），而且绕开了题目考点。常规：反转链表 → 从低位带进位翻倍 → 再反转，三趟、`O(1)` 空间。浪费在两次反转：每位 `d*2` 的进位只是 `d >= 5`（`2*9 = 18`，加上进位最多 `19`，进位恒为 0 或 1），不需要从低位传上来，看右邻居即可。于是单趟从左到右：`val = (val*2 + (next.val >= 5)) % 10`。最高位若进位，需要一个新节点，用值 0 的哑头统一处理：它翻倍后得到进位，非 0 就保留。

```python
def double_it(head: ListNode | None) -> ListNode | None:
    dummy = ListNode(0, head)          # 哨兵：最高位进位时，它自己变成新的最高位 1
    cur: ListNode | None = dummy
    while cur:
        nxt = cur.next
        carry = 1 if nxt and nxt.val >= 5 else 0   # 下一位 *2 是否 >= 10
        cur.val = (cur.val * 2 + carry) % 10
        cur = nxt
    return dummy if dummy.val else dummy.next
```

运行：`[1,8,9]` → `[3,7,8]`，`[9,9,9]` → `[1,9,9,8]`，`[0]` → `[0]`，`[5]` → `[1,0]`，`[2,5]` → `[5,0]`，`10^4` 个 9 → 长度 `10001`、以 `1,9,9` 开头、以 `9,9,8` 结尾。

**复杂度。** 时间 `O(n)`，一趟；空间 `O(1)`，只有哑头和游标（原地改值）。

**易错点。**
- 进位判断是 `>= 5` 不是 `> 5`：`[5]` 写成 `> 5` 得到 `[0]`，正确是 `[1,0]`；`[2,5]` 得到 `[4,0]`，正确是 `[5,0]`。
- 忘了哑头：`[9,9,9]` 没地方放最高位的 `1`。
- 结果为 `0` 时（输入 `[0]`）哑头值为 0，必须丢掉哑头，否则多出一个前导零。

**追问。**
- 乘以任意个位数 `k` 或加两个链表数（LC 2、LC 445）：进位不再是 0/1 的简单前瞻，用反转或栈，从低位带 `carry` 传上来，`divmod(val*k + carry, 10)`。
- 不能修改输入：新建链表，或用栈保存各位。
- 位数很大又不能反转：递归返回进位，回溯时处理，递归深度 `O(n)` 要注意 Python 限制。

**同模式。** LC 2 两数相加、LC 445 两数相加 II、LC 66 加一、LC 43 字符串相乘。
