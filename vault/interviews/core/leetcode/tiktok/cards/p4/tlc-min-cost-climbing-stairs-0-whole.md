## Q
**LC 746 使用最小花费爬楼梯**｜Easy · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-01-28（美国面试记录）

整数数组 `cost`，`cost[i]` 是从第 `i` 级台阶向上爬需要支付的费用。支付后可以向上爬**一级或两级**。你可以选择从下标 `0` 或下标 `1` 的台阶出发。返回到达楼梯顶部（下标 `cost.length`，最后一级之后的位置）的最低总花费。`2 <= cost.length <= 1000`，`0 <= cost[i] <= 999`。例：`[10,15,20]` → `15`（从下标 `1` 出发，付 `15` 爬两级到顶）；`[1,100,1,1,1,100,1,1,100,1]` → `6`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 线性 DP：到达第 `i` 级的最小花费 `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`，起点 `dp[0] = dp[1] = 0`，答案是 `dp[n]`；只依赖前两项，滚动成两个变量，`O(n)` 时间 `O(1)` 空间。

**识别。** 「每次走一步或两步 + 求最小总代价」是爬楼梯型的线性 DP：当前状态只由前两个状态转移而来。注意两个细节：起点可以是 `0` 或 `1`（所以两者初始花费都是 `0`），终点是 `n` 而不是 `n - 1`（越过最后一级才算到顶）。

**推导。** 暴力递归：`f(i) = cost[i] + min(f(i+1), f(i+2))`，答案 `min(f(0), f(1))`，同一个 `f(i)` 被反复求解，指数级 → 记忆化或自底向上，每个状态算一次，`O(n)` → 状态定义换成「到达第 `i` 级时已经付出的最小花费」，到达 `i` 要么从 `i-1` 付 `cost[i-1]`，要么从 `i-2` 付 `cost[i-2]` → 只用到前两个值，不需要整张表。

```python
def min_cost_climbing_stairs(cost: list[int]) -> int:
    two_back = one_back = 0                    # 到达第 i-2、i-1 级的最小花费；起点 0、1 都免费
    for i in range(2, len(cost) + 1):
        two_back, one_back = one_back, min(one_back + cost[i - 1], two_back + cost[i - 2])
    return one_back
```

运行：`[10,15,20]` → `15`；`[1,100,1,1,1,100,1,1,100,1]` → `6`；`[0,0]` → `0`；`[5,3]` → `3`；长度 `1000`、全是 `999` → `499500`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 把 `dp[i]` 定义成「站在第 `i` 级并且已经付了 `cost[i]`」，却返回 `dp[n-1]`：`[10,15,20]` 得到 `30`，正确是 `15`；这种定义下答案要取 `min(dp[n-1], dp[n-2])`。
- 终点写成 `n - 1`：到达顶部是越过最后一级，下标是 `n`。
- 以为必须从下标 `0` 出发：起点可以是 `0` 或 `1`，所以两者的初始花费都是 `0`。

**追问。**
- 返回具体路线：额外记录每个 `i` 的前驱（从 `i-1` 还是 `i-2` 来），从 `n` 往回走再反转。
- 每次最多爬 `k` 级：`dp[i] = min(dp[j] + cost[j] for j in i-k..i-1)`，朴素 `O(nk)`；用单调队列维护窗口最小值可到 `O(n)`。
- 费用变成「到达某级就要付」而不是「离开某级才付」：只是 `dp` 的定义平移了一格，转移式改成 `dp[i] = cost[i] + min(dp[i-1], dp[i-2])`，答案取最后两项的较小者。

**同模式。** LC 70 爬楼梯、LC 198 打家劫舍、LC 509 斐波那契数、LC 1137 第 N 个泰波那契数、LC 322 零钱兑换。
