## Q
**LC 417 太平洋大西洋水流问题**｜Medium · LC TikTok 全时段热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2025-12-10（美国面试记录）

`m × n` 的岛屿，太平洋在左边界和上边界，大西洋在右边界和下边界。`heights[r][c]` 是格子的高度，雨水可以从一个格子流向上下左右**高度小于等于**它的相邻格子，靠近海洋的格子的水可以直接流入海洋。返回所有雨水既能流向太平洋、又能流向大西洋的格子坐标 `[r, c]`（顺序任意）。`1 <= m, n <= 200`，`0 <= heights[r][c] <= 10^5`。例：`[[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]` → `[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]`；`[[2,1],[1,2]]` → 四个格子全部。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把问题**反过来**：从海洋出发，逆流而上（只走向高度不低于当前格的邻居），分别用 DFS 求出「能流到太平洋的格子集合」和「能流到大西洋的格子集合」，两个集合的交集就是答案。`O(mn)`。

**识别。** 「网格上，水往低处流，问哪些格子能到达某个目标区域」是可达性问题。对每个格子正向搜一遍是 `O((mn)^2)`；而**目标区域（海洋）只有两个**，从目标反向搜只需要两次遍历。信号：目标集合小、起点集合大 → 反向多源搜索。`200 × 200 = 4 · 10^4` 格，`O(mn)` 轻松。

**推导。** 暴力：对每个格子 DFS，看能否到达上、左边界，且能否到达下、右边界，`O((mn)^2)`，约 `1.6 · 10^9` → 浪费在于大量格子的搜索重复经过同一片区域 → 反向思考：水「从格子 A 流到格子 B」等价于「从 B 逆流可达 A」，条件 `h[A] >= h[B]`；所以从海洋相邻的所有边界格子出发（多源 DFS，共用一个 `seen`），向 `高度 >=` 当前格的邻居扩展，访问到的就是能流到这片海洋的格子 → 太平洋、大西洋各做一次，取交集。

```python
def pacific_atlantic(heights: list[list[int]]) -> list[list[int]]:
    m, n = len(heights), len(heights[0])

    def reach(starts: list[tuple[int, int]]) -> set[tuple[int, int]]:
        seen: set[tuple[int, int]] = set()

        def dfs(r: int, c: int) -> None:       # 从 (r, c) 逆流而上：只走向不矮于当前格的邻居
            seen.add((r, c))
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < m and 0 <= nc < n and (nr, nc) not in seen and heights[nr][nc] >= heights[r][c]:
                    dfs(nr, nc)

        for r, c in starts:                    # 海洋相邻的每个边界格子都是起点
            if (r, c) not in seen:
                dfs(r, c)
        return seen

    pacific = reach([(0, c) for c in range(n)] + [(r, 0) for r in range(1, m)])
    atlantic = reach([(m - 1, c) for c in range(n)] + [(r, n - 1) for r in range(m - 1)])
    return sorted([r, c] for r, c in pacific & atlantic)
```

运行：示例 1 → `[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]`，示例 2 → `[[0,0],[0,1],[1,0],[1,1]]`，`[[1]]` → `[[0,0]]`，`[[1,1],[1,1]]` → 四个格子全部；`200 × 200` 随机高度远小于 `0.1` 秒。

**复杂度。** 时间 `O(mn)`（每个格子在每个海洋的搜索里最多被访问一次）；空间 `O(mn)`（`seen` 集合加递归栈）。

**易错点。**
- 逆流时比较写成 `>`（严格）：题目允许流向「小于等于」，高度相等也通。`[[1,1],[1,1]]` 只得到 `[[0,1],[1,0]]`（正确是四个格子全部）。
- 比较方向写反（正向用 `<=`）：从海洋出发是逆流，要向更高或相等的邻居走。
- 对每个格子单独 DFS：`4 · 10^4` 个格子各搜一遍，会超时；要从海洋出发，两次搜索就够。
- 深度：递归深度最坏接近可达格子数。`200 × 200` 的网格全是同一高度时，一次 DFS 能深入上万格，超过 CPython 默认递归上限（约 `1000`）而抛 `RecursionError`；要么 `sys.setrecursionlimit` 调高，要么改成 BFS（见追问）。

**追问。**
- BFS 写法（深图安全）：把两个海洋的起点分别入队做多源 BFS，用 `deque` 逐层扩展，没有递归；其余逻辑不变。
- 只要个数：`len(pacific & atlantic)`，省掉排序。
- 水也能斜着流（八个方向）：邻居改成 8 个方向，其余不变。
- 多个海洋 / 任意边界集合：对每个海洋各做一次反向 BFS，再取交集；`k` 个海洋 `O(k · mn)`。

**同模式。** LC 130 被围绕的区域（从边界反向找）、LC 1020 飞地的数量、LC 542 01 矩阵、LC 286 墙与门。
