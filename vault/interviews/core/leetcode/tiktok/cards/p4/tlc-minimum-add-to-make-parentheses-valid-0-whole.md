## Q
**LC 921 使括号有效的最少添加**｜Medium · 近一年被问：美国 1 次、国内 0 次 · 最近 2026-04-19（美国面试记录）

括号字符串有效，当且仅当：它是空串；或可写成 `AB`（`A`、`B` 都有效）；或可写成 `(A)`（`A` 有效）。给定只含 `'('` 和 `')'` 的字符串 `s`，每次操作可以在**任意位置**插入一个括号。返回使 `s` 有效所需的**最少插入次数**。`1 <= s.length <= 1000`。例：`"())"` → `1`；`"((("` → `3`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从左到右扫描，用计数器 `open_cnt` 记录「还没配上对的 `(`」：遇到 `(` 加一；遇到 `)` 时，若 `open_cnt > 0` 就配对（减一），否则这个 `)` 前面必须补一个 `(`（`add += 1`）；扫完后答案是 `add + open_cnt`（剩下的 `(` 各需补一个 `)`）。`O(n)`、`O(1)`。

**识别。** 「括号有效性 + 最少插入 / 删除」是括号匹配的经典题。因为**只有一种括号**，栈里放的全是 `(`，栈的内容无关紧要，只有栈深有意义，所以栈可以换成一个计数器（余额，balance）。如果有多种括号，就必须用真栈记录种类。

**推导。** 暴力：BFS 枚举所有插入一个括号后的字符串，直到出现有效串，指数级 → 用栈模拟匹配：遇到 `(` 入栈，遇到 `)` 出栈，栈空时的 `)` 记为无法匹配，最后栈里剩的 `(` 也无法匹配，两者之和就是答案 → 栈里只有 `(`，把栈深换成整数 `open_cnt`，空栈对应 `open_cnt == 0`。

```python
def min_add_to_make_valid(s: str) -> int:
    open_cnt = add = 0                        # open_cnt：还没配对的 '('；add：必须补的 '('
    for ch in s:
        if ch == "(":
            open_cnt += 1
        elif open_cnt:                        # 有 '(' 可配
            open_cnt -= 1
        else:                                 # ')' 前面没有 '(' 可配：补一个 '('
            add += 1
    return add + open_cnt                     # 剩下没配上的 '(' 各需补一个 ')'
```

运行：`"())"` → `1`；`"((("` → `3`；`")("` → `2`；`"()"` → `0`；`")))((("` → `6`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 只比较两种括号的个数 `abs(s.count("(") - s.count(")"))`：`")("` 得到 `0`，正确是 `2`（顺序也要对）。
- 忘记加上结尾剩下的 `open_cnt`：`"((("` 得到 `0`，正确是 `3`。
- 遇到无法配对的 `)` 时让 `open_cnt` 变成负数继续计：`")("` 里 `open_cnt` 先变 `-1`，再变 `0`，最后得到 `0`，漏掉了两次插入。

**追问。**
- 有三种括号（LC 20）：必须用真正的栈，匹配时还要检查种类。
- 不是插入而是**删除**最少括号使其有效（LC 1249）：同样的扫描，记下无法配对的 `)` 的下标，以及结尾栈里剩下的 `(` 的下标，把它们删掉。
- 含通配符 `*`（LC 678）：维护余额的取值区间 `[lo, hi]`，`*` 让 `lo - 1`、`hi + 1`，`lo` 不低于 `0`，`hi` 变负就失败。
- 前缀和写法：设 `bal` 为前缀余额（`(` 记 `+1`，`)` 记 `-1`，用 `itertools.accumulate`），`m = min(0, min(bal))`，答案是 `bal[-1] - 2 * m`：`-m` 是补的 `(`，`bal[-1] - m` 是结尾剩下的 `(`。

**同模式。** LC 20 有效的括号、LC 32 最长有效括号、LC 678 有效的括号字符串、LC 1249 移除无效的括号、LC 1541 平衡括号字符串的最少插入次数。
