## Q
**LC 1041 困于环中的机器人**｜Medium · LC TikTok 热度 26/100（近 6 个月） · CodeTop 国内累计 1 次 · 最近 2024-01-08（国内 CodeTop）

无限平面上，机器人从 `(0, 0)` 出发，面朝北（北 = `y` 轴正方向，东 = `x` 轴正方向）。它按顺序执行指令串 `instructions` 并**无限循环**重复它。指令只有三种：`"G"` 直走 1 单位，`"L"` 左转 90 度，`"R"` 右转 90 度。当且仅当平面中存在一个机器人永远离不开的环时返回 `true`，否则 `false`。

约束：`1 <= instructions.length <= 100`，`instructions[i]` 仅为 `'G'`、`'L'`、`'R'`。

例：`"GGLLGG"` → `true`；`"GG"` → `false`（一直往北）；`"GL"` → `true`（绕一个小方块）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 只模拟一轮指令：若机器人回到原点，必然绕环；若没回原点但**不再朝北**，那么至多重复 4 轮，朝向转回北、位移合成为零，也绕环；只有「回不到原点且仍朝北」才每轮都朝同一方向漂移，逃出无穷远。`O(n)`。

**识别。** 「无限重复」的题往往有**周期**：不要真的无限模拟，找出循环不变量。位置 + 朝向构成状态，朝向只有 4 种，所以重复若干轮后一定回到同一朝向——这是「最多模拟 4 轮」的来源；「是否永远离不开」转化为「一轮之后的位移向量是否被旋转抵消」。`n ≤ 100` 很小，核心考点是结论而非性能。

**推导。** 暴力：模拟指令串重复很多轮，看机器人是否远离原点——但「多少轮才算足够」要论证。把一轮看成一个变换：先旋转角度 `θ`（由 `L`、`R` 的净转向决定，是 90 度的倍数）再平移。若 `θ = 0`，每一轮平移同一个向量 `v`：`v ≠ 0` 就无限漂移，`v = 0` 就停在原地。若 `θ ≠ 0`，每轮的位移向量被旋转，4 轮后（`θ` 的 1、2、3 个 90 度倍数，累计转回整圈时）位移向量 `v, Rv, R²v, R³v` 之和为 `0`，机器人回到原点，必然有界。所以：一轮后回到原点 或 朝向变了 → 有界。

```python
def is_robot_bounded(instructions: str) -> bool:
    x = y = 0
    dx, dy = 0, 1                      # 方向向量，初始朝北
    for ch in instructions:
        if ch == "G":
            x, y = x + dx, y + dy
        elif ch == "L":
            dx, dy = -dy, dx           # 逆时针转 90 度
        else:
            dx, dy = dy, -dx           # 顺时针转 90 度
    # 只模拟一轮：回到原点，或者不再朝北（转 4 轮后必回原点）
    return (x, y) == (0, 0) or (dx, dy) != (0, 1)
```

运行：`"GGLLGG"` → `True`，`"GG"` → `False`，`"GL"` → `True`，`"GLGLGLGL"` → `True`，`"LRG"` → `False`。

**复杂度。** 时间 `O(n)`：只模拟一轮指令；空间 `O(1)`：位置和方向共四个整数。

**易错点。**
- 只判断一轮后回到原点：`"GL"` 一轮后在 `(0, 1)` 朝西，不在原点，会错判 `false`；实际 4 轮后回到原点，应为 `true`。
- 只判断朝向变化：`"GLGLGLGL"` 一轮后朝向转了整整一圈，仍朝北，且在原点，应为 `true`，只看朝向会错判 `false`。必须同时检查「回到原点」。
- 把「朝向没变但位置不在原点」判有界：`"GG"` 每轮向北漂 2 格，永远逃走，必须返回 `false`。
- 方向旋转写错符号：左转 `(dx, dy) → (-dy, dx)`，右转 `(dx, dy) → (dy, -dx)`；写反会让 `L` / `R` 互换，`"GL"` 之类的对称例子测不出来，要用 `"GR..."` 的非对称输入验证。

**追问。**
- 有障碍物（遇到障碍就原地不动）：一轮不再是固定的旋转加平移，结论失效；只能模拟，并用「每轮结束时的 (位置, 朝向)」集合判重。
- 指令集更复杂（转 45 度、后退、速度）：方向向量不再只有 4 个；思路不变——一轮是旋转加平移，看净旋转是否回到恒等。
- 要求模拟循环中的最远距离：最多模拟 4 轮，记录途中的最大值。
