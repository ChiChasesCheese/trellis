## Q
**LC 478 在圆内随机生成点**｜Medium · 近一年被问：美国 0 次、国内 1 次 · 最近 2026-09-21（面试记录）

实现类 `Solution`：`Solution(radius, x_center, y_center)` 用圆的半径和圆心初始化；`randPoint()` 返回圆内**均匀分布**的一个随机点 `[x, y]`，圆周上的点也算圆内。`0 < radius <= 10^8`，`-10^7 <= x_center, y_center <= 10^7`，`randPoint` 最多调用 `3 * 10^4` 次。例：`Solution(1.0, 0.0, 0.0)` 之后三次 `randPoint()` 可能返回 `[-0.02493, -0.38077]`、`[0.82314, 0.38945]`、`[0.36572, 0.17248]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 极坐标采样：角度在 `[0, 2π)` 均匀取，半径取 `R * sqrt(U)`（`U` 是 `[0,1)` 均匀随机数），因为面积与半径的平方成正比，半径的累积分布必须是 `(r / R)^2`。

**识别。** 「在二维区域里均匀随机」：核心是**均匀指的是面积（密度）均匀**，而不是半径或角度各自均匀。信号是「均匀」二字加上区域不是矩形；矩形只需要两个独立的均匀数。

**推导。** 直觉解：半径取 `R * U`、角度均匀 → 点会向圆心堆积，因为半径 `r` 处的圆环周长是 `2πr`，小半径的圆环面积小却分到同样多的点 → 要让落在半径 `ρ` 以内的概率等于面积比 `(ρ / R)^2`，也就是让 `P(r <= ρ) = (ρ / R)^2` → 反函数法（inverse transform）：`r = R * sqrt(U)`。另一条路是拒绝采样（rejection sampling）：在外接正方形里均匀取点，落在圆外就重抽，期望 `4 / π ≈ 1.27` 次。

```python
import math
import random


class Solution:
    def __init__(self, radius: float, x_center: float, y_center: float) -> None:
        self.r = radius
        self.x = x_center
        self.y = y_center

    def randPoint(self) -> list[float]:
        # 面积正比于 r^2，所以半径取 R * sqrt(U)：落在半径 ρ 内的概率恰为 (ρ / R)^2
        r = self.r * math.sqrt(random.random())
        theta = random.uniform(0.0, math.tau)     # 角度均匀
        return [self.x + r * math.cos(theta), self.y + r * math.sin(theta)]
```

运行：`Solution(1.0, 0.0, 0.0)`，取 `10^5` 个点：落在半径 `0.5` 内的比例约 `0.252`（理论 `0.25`），第一象限的比例约 `0.25`，全部在圆内；换成 `r * U` 的错误写法，半径 `0.5` 内的比例约 `0.5`。把半径为 `2` 的圆分成 4 个等面积的同心环，各环的点数约 `24955 / 25185 / 24996 / 24864`（各约 `25%`）。`radius = 10^8`、圆心 `(-10^7, 10^7)` 同样正常。

**复杂度。** 时间每次 `O(1)`，空间 `O(1)`。

**易错点。**
- `r = R * random.random()`：半径均匀而面积不均匀，一半的点挤在半径 `R/2` 以内（正确应只有 `1/4`）。
- 拒绝采样里用 `dx * dx + dy * dy <= r * r` 判断，别写成 `sqrt(...) <= r`，既慢又多一次舍入；也别忘了在外接正方形 `[-R, R]^2` 里取，而不是 `[0, R]^2`。

**追问。**
- 拒绝采样版：每次期望 `4 / π ≈ 1.27` 次循环，不用 `sqrt`、`sin`、`cos`，常数很小；最坏没有上界，但概率指数级衰减。
- 圆环 `[r1, R]` 内均匀：`r = sqrt(U * (R^2 - r1^2) + r1^2)`；三维球内均匀：`r = R * U ** (1 / 3)`。
- 如何测试随机函数：把随机源做成可注入的参数，固定种子，再统计各等面积区域的频数。
