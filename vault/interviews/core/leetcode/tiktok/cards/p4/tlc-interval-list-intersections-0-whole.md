## Q
**LC 986 区间列表的交集**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-08-24（美国面试记录）

给两个由**闭区间**组成的列表 `firstList` 和 `secondList`，每个列表内部的区间两两不相交且已按起点排序。返回这两个列表的交集（同样是一组闭区间）。闭区间 `[a, b]` 表示实数 `a <= x <= b`，两个闭区间的交集要么为空，要么是闭区间，例如 `[1,3]` 和 `[2,4]` 的交集是 `[2,3]`。`0 <= firstList.length, secondList.length <= 1000`，两者长度之和 `>= 1`，`0 <= start < end <= 10^9`，同一列表中 `end_i < start_{i+1}`。例：`firstList = [[0,2],[5,10],[13,23],[24,25]]`，`secondList = [[1,5],[8,12],[15,24],[25,26]]` → `[[1,2],[5,5],[8,10],[15,23],[24,24],[25,25]]`；`[[1,3],[5,9]]` 与 `[]` → `[]`；`[[1,7]]` 与 `[[3,10]]` → `[[3,7]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 两个有序且各自不相交的列表，用双指针同时扫：当前一对区间的交集是 `[max(起点), min(终点)]`，非空就收下；然后**终点较小的那个区间**已经不可能再和对方后面的区间相交，指针前进。`O(m + n)`。

**识别。** 「两个已排序、内部不相交的区间列表」+「求交集」是双指针归并的信号；排序和不相交这两个前提，就是在暗示不要再排序、也不需要堆。`m, n <= 1000` 时 `O(m*n)` 也能过，但前提白送，应该写线性。

**推导。** 暴力：所有区间对两两求交，`O(m*n)`，结果还要再排序。浪费在大量不可能相交的对：设当前是 `A[i]`、`B[j]`，终点更小的比如 `A[i]`，它的右端在 `B[j]` 内或之前；`B[j+1]` 的起点比 `B[j]` 的终点还大，也就在 `A[i]` 终点之后，所以 `A[i]` 与 `B[j]` 之后的所有区间都不再相交，`A[i]` 可以丢弃。每步丢一个区间，最多 `m + n` 步。

```python
def interval_intersection(first: list[list[int]], second: list[list[int]]) -> list[list[int]]:
    i = j = 0
    ans: list[list[int]] = []
    while i < len(first) and j < len(second):
        lo = max(first[i][0], second[j][0])      # 交集左端取较大的起点
        hi = min(first[i][1], second[j][1])      # 右端取较小的终点
        if lo <= hi:                             # 闭区间：lo == hi 也是一个点
            ans.append([lo, hi])
        if first[i][1] < second[j][1]:           # 终点小的那个不可能再与对方后面的区间相交
            i += 1
        else:
            j += 1
    return ans
```

运行：示例 1 → `[[1,2],[5,5],[8,10],[15,23],[24,24],[25,25]]`；`[[1,3],[5,9]]` 与 `[]` → `[]`；`[]` 与 `[[4,8],[10,12]]` → `[]`；`[[1,7]]` 与 `[[3,10]]` → `[[3,7]]`。

**复杂度。** 时间 `O(m + n)`：每次循环有一个指针前进；空间 `O(1)` 额外（不计结果）。

**易错点。**
- 一次循环两个指针都 `+1`：`[[1,10]]` 与 `[[2,3],[5,6]]` 得到 `[[2,3]]`，正确是 `[[2,3],[5,6]]`，因为 `[1,10]` 还要和后面的区间比。
- 用 `lo < hi` 判空：闭区间里单点也是交集，`[[1,3],[5,9]]` 与 `[[3,5]]` 得到 `[]`，正确是 `[[3,3],[5,5]]`。
- 终点相同时动哪个指针都对，不要为此多写分支：动 `j` 后下一轮 `lo > hi`，会让 `i` 紧接着前进。

**追问。**
- `k` 个列表求公共交集：`reduce(interval_intersection, lists)`，逐个折叠；结果只会越来越短。
- 求并集或合并（LC 56）：先合并成一个按起点排序的序列（`heapq.merge`），再扫一遍合并重叠区间。
- 输入未排序/可能重叠：先排序并合并各自列表，退化成已排序不相交的情形，总 `O(m log m + n log n)`。

**同模式。** LC 56 合并区间、LC 57 插入区间、LC 253 会议室 II、LC 1229 安排会议日程。
