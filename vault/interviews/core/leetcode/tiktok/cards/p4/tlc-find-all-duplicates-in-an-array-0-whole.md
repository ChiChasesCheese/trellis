## Q
**LC 442 数组中重复的数据**｜Medium · LC TikTok 热度 50/100 · 近一年被问：美国 0 次、国内 1 次 · CodeTop 国内累计 6 次 · 最近 2026-08-12（面试记录）

给长度为 `n` 的整数数组 `nums`，其中每个整数都在 `[1, n]` 内，且每个整数出现**一次或两次**。找出所有出现两次的整数，以数组形式返回。必须设计 `O(n)` 时间、**仅用常量额外空间**（不含输出）的算法。`n == nums.length`，`1 <= n <= 10^5`，`1 <= nums[i] <= n`。例：`[4,3,2,7,8,2,3,1]` → `[2,3]`；`[1,1,2]` → `[1]`；`[1]` → `[]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把数组本身当哈希表：值 `x` 对应下标 `x − 1`。读到 `x` 时，看 `nums[x − 1]` 的符号——为负说明 `x` 之前出现过（重复），否则把它取负做「见过」的记号。`O(n)` 时间，`O(1)` 额外空间。

**识别。** 「值域恰好是 `[1, n]`」+「常量额外空间」是一个强信号：值可以直接当下标，数组自己就能记录「某个值是否出现过」。普通的哈希集合是 `O(n)` 空间，违反要求。原地标记的手段有两种：取负标记（本解法）和原地交换（循环排序）。

**推导。** 暴力：两层循环比较，`O(n^2)`，`n = 10^5` 不行 → 哈希集合记录见过的值，`O(n)` 时间 `O(n)` 空间，违反空间要求 → 利用值域：开一个长度 `n` 的布尔数组，`seen[x − 1]`，仍是 `O(n)` 空间 → 数组每个元素都是正数，符号位是「白送」的一位信息：把 `nums[x − 1]` 的符号当作 `seen[x − 1]`，不需要额外数组。读 `x` 时要先取 `abs`，因为它可能已经被前面的标记取负。

```python
def find_duplicates(nums: list[int]) -> list[int]:
    res: list[int] = []
    for x in nums:
        i = abs(x) - 1                         # 值 x 对应的「标记位置」；x 可能已被前面的标记取负
        if nums[i] < 0:
            res.append(abs(x))                 # 这个位置已经被标记过：x 是第二次出现
        else:
            nums[i] = -nums[i]                 # 第一次出现：把 nums[i] 取负做记号
    return res
```

运行：`[4,3,2,7,8,2,3,1]` → `[2,3]`，`[1,1,2]` → `[1]`，`[1]` → `[]`，`[2,1,1]` → `[1]`，`[1,2,3,4,5]` → `[]`；`n = 10^5`、约四分之一的值重复的数组耗时约 `0.005` 秒。

**复杂度。** 时间 `O(n)`；空间 `O(1)`（只改原数组，输出不计）。

**易错点。**
- 读 `x` 时不取绝对值：`x` 可能已被标成负数，`x − 1` 变成负下标。Python 的负下标不报错、悄悄绕到数组尾部。`[2,1,1]` 返回 `[-1]`（正确 `[1]`），`[4,3,2,7,8,2,3,1]` 返回 `[-2,3]`（正确 `[2,3]`）。
- 把重复值 `res.append(x)` 写成不加 `abs`：同样会得到负数。
- 忘记这个做法会改写输入：调用方的数组符号被破坏，需要还原时再扫一遍 `nums[i] = abs(nums[i])`。

**追问。**
- 不允许改输入（或输入只读）：只能用 `O(n)` 的集合 / 布尔数组，或排序后相邻比较（`O(n log n)`）。
- 值可能出现多于两次：取负标记只能判断「是否见过」，要统计次数用 `Counter`（`O(n)` 空间），或原地排序后统计相邻相同段的长度（`O(n log n)` 时间）。
- 找缺失的数字（LC 448）：同样的取负标记，最后仍为正的位置就是缺失值。

**同模式。** LC 448 找到所有数组中消失的数字、LC 287 寻找重复数、LC 41 缺失的第一个正数、LC 268 丢失的数字。
