## Q
**删除一个长度为 k 的窗口，使奇偶下标之和相等**｜Medium · 近一年被问：美国 2 次、国内 0 次 · 最近 2026-09-11（面试记录）

给整数数组 `nums` 和整数 `k`。删除一段长度恰为 `k` 的连续子数组，剩余元素保持相对顺序并重新编号（从 `0` 起），要求剩余数组中**偶数下标元素之和等于奇数下标元素之和**。返回满足条件的最小起始下标（删除窗口的左端点），没有则返回 `-1`；整个数组都被删掉（`k == len(nums)`）时剩余为空，两个和都是 `0`，算满足。`1 <= k <= len(nums) <= 10^5`，`-10^4 <= nums[i] <= 10^4`。例：`nums = [1,1,2,3,4,4]`，`k = 2` → `2`（删掉 `[2,3]`，剩 `[1,1,4,4]`，偶数下标 `1 + 4`，奇数下标 `1 + 4`）；`nums = [1,1,2,1,1]`，`k = 1` → `2`；`nums = [3,1,4,1,5]`，`k = 1` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 给原数组按原下标的奇偶加符号（偶数下标 `+`、奇数下标 `-`），做前缀和 `pre`。删除窗口 `[i, i+k)` 后：窗口左边的元素下标不变，对差值的贡献是 `pre[i]`；窗口右边的元素整体左移 `k` 位，`k` 为偶数时奇偶不变，`k` 为奇数时奇偶互换（符号翻转），贡献是 `±(pre[n] - pre[i+k])`。差值为 `0` 就满足条件。枚举 `i` 从小到大，第一个满足的就是答案，`O(n)`。

**识别。** 「删除一段连续子数组后下标重新编号」会让右半部分的奇偶性整体变化：这是“前缀和 + 后缀和”的信号。「偶数下标和等于奇数下标和」等价于「按奇偶加符号的总和为 `0`」，一个带符号的前缀和数组就能 `O(1)` 回答任意区间。`n = 10^5` 排除每个起点重新构造剩余数组的 `O(n^2)`。

**推导。** 暴力：对每个起点，拼出剩余数组，分别求偶、奇下标之和，`O(n · n)`。浪费：相邻两个起点的剩余数组几乎相同，每次从头计算。洞察：把“偶数下标和减奇数下标和”写成带符号的和，左半部分的下标不变，用前缀和 `pre[i]`；右半部分的元素在新数组里的下标是 `原下标 - k`，符号是原符号乘 `(-1)^k`，用后缀和 `pre[n] - pre[i+k]` 乘 `(-1)^k`。两段之和为 `0` 就合法。

```python
from itertools import accumulate


def min_balanced_deletion(nums: list[int], k: int) -> int:
    """删除一段长度 k 的连续子数组，使剩余数组偶数下标之和等于奇数下标之和；返回最小起点，没有则返回 -1。"""
    n = len(nums)
    # pre[i]：nums[:i] 按原下标奇偶加符号的和（偶 +，奇 -）。pre[n] 是整个数组的「偶数下标和 - 奇数下标和」
    pre = list(accumulate((x if i % 2 == 0 else -x for i, x in enumerate(nums)), initial=0))
    flip = -1 if k % 2 else 1                    # 窗口右边的元素整体左移 k 位：k 为奇数时奇偶互换，符号翻转
    for i in range(n - k + 1):
        left = pre[i]                            # 窗口左边：下标不变
        right = flip * (pre[n] - pre[i + k])     # 窗口右边：下标减 k
        if left + right == 0:
            return i
    return -1
```

运行：`([1,1,2,3,4,4], 2)` → `2`，`([1,1,2,1,1], 1)` → `2`，`([1,2], 2)` → `0`（删空，视为满足），`([3,1,4,1,5], 1)` → `-1`，`([1,1,2,2,3], 1)` → `4`，`([1,1,1,2,1], 1)` → `3`，`([1,1,1,2,1], 3)` → `1`；`10^5` 个元素瞬间完成。

**复杂度。** 时间 `O(n)`，空间 `O(n)`（前缀和数组）。

**易错点。**
- 忘记右半部分奇偶翻转：直接用 `pre[i] + (pre[n] - pre[i+k])`。`nums = [1,1,1,2,1]`、`k = 1`，删除下标 `3` 后剩 `[1,1,1,1]`，正确是 `3`，这个写法得到 `-1`；`k = 3` 时也得到 `2`，正确是 `1`。
- 窗口范围：起点只能到 `n - k`（含），`range(n - k + 1)`；写成 `range(n - k)` 会漏掉删除末尾的窗口，`([1,1,1,1,2],1)` 这类答案在末尾的输入会得到 `-1`。
- `pre` 要加 `initial=0`，使 `pre[i]` 是前 `i` 个元素之和，`pre[i+k]` 可以取到 `pre[n]`；省略的话所有下标错位一格。
- 整个数组被删掉时剩余为空，两个和都是 `0`，要判定为满足（`[1,2]`、`k = 2` → `0`）。

**追问。**
- 返回所有满足条件的起点：不要在找到第一个时 `return`，收集成列表。
- 窗口长度不固定（任意长度的连续子数组）：对每个右端点要在哈希表中找左端点，需要把 `pre` 按奇偶分类，思路是“前缀和差为 `0` 的下标对”。
- 删除后求奇偶下标之和之差的最小绝对值：同样的 `left + right`，取 `abs` 的最小值。

**同模式。** LC 1664 生成平衡数组的方案数、LC 238 除自身以外数组的乘积、LC 724 寻找数组的中心下标、LC 560 和为 K 的子数组。
