## Q
**LC 378 有序矩阵中第 K 小的元素**｜Medium · LC TikTok 全时段热度 50/100 · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 12 次 · 最近 2026-09-23（国内 CodeTop）

`n × n` 矩阵 `matrix`，每行每列都按非递减顺序排列。找到矩阵中**排序后**的第 `k` 小的元素（重复的值各算一个，不是第 `k` 个不同的值）。要求内存复杂度优于 `O(n^2)`。`1 <= n <= 300`，`-10^9 <= matrix[i][j] <= 10^9`，`1 <= k <= n^2`。例：`matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8` → `13`（排序后 `1,5,9,10,11,12,13,13,15`）；`[[-5]], k = 1` → `-5`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** **二分答案**（binary search on the answer）：在 `[最小值, 最大值]` 上二分一个值 `mid`，用「阶梯式扫描」`O(n)` 数出矩阵中 `<= mid` 的元素个数；个数 `>= k` 说明答案 `<= mid`。`O(n log(max − min))` 时间，`O(1)` 空间。

**识别。** 「第 `k` 小」+「矩阵行列有序」：先想三条路——全部展开排序（`O(n^2)` 内存，被题目禁止）、堆（`k` 路归并）、对**值域**二分。值域是整数且 `10^9` 级，二分只要约 `31` 步；每步需要的「`<= mid` 有多少个」恰好能利用行列有序在 `O(n)` 内数出来。内存要求 `O(1)` 也指向二分。

**推导。** 暴力：展开成 `n^2` 个数再排序，`O(n^2 log n)` 时间、`O(n^2)` 空间，违反内存要求 → 堆：把每行当有序链表，`k` 次弹出，`O(k log n)`，内存 `O(n)`；`k` 接近 `n^2` 时偏慢 → 换个角度：答案 `v` 满足「`<= v` 的个数 `>= k`」且 `v` 最小，这个条件对 `v` **单调**，所以可以二分 `v` → 数个数用阶梯：行从上到下，列指针从右往左只退不进（下一行同一列的值不会更小），`O(n)`。

```python
def kth_smallest(matrix: list[list[int]], k: int) -> int:
    n = len(matrix)

    def count_le(mid: int) -> int:             # 矩阵中 <= mid 的元素个数，阶梯式 O(n)
        count, col = 0, n - 1
        for row in matrix:                     # 行从上到下，每行的列边界只会左移
            while col >= 0 and row[col] > mid:
                col -= 1
            count += col + 1
        return count

    lo, hi = matrix[0][0], matrix[-1][-1]      # 答案一定落在 [最小值, 最大值]
    while lo < hi:
        mid = (lo + hi) // 2
        if count_le(mid) >= k:                 # 至少有 k 个数 <= mid：答案 <= mid
            hi = mid
        else:
            lo = mid + 1
    return lo
```

运行：`[[1,5,9],[10,11,13],[12,13,15]], k = 8` → `13`，`[[-5]], k = 1` → `-5`，`[[1,1],[1,3]]` 的 `k = 3` → `1`、`k = 4` → `3`；`n = 300` 时约 `0.01` 秒。

**复杂度。** 时间 `O(n · log(max − min))`（约 `31` 轮，每轮 `O(n)`）；空间 `O(1)`。

**易错点。**
- 把重复值去重后再数：示例 1 去重后第 `8` 小是 `15`，正确是 `13`。题目问的是排序后的第 `k` 个，不是第 `k` 个不同的。
- 二分写成 `count_le(mid) > k` 或 `hi = mid - 1`：会返回不在矩阵里的值或差一位。收缩条件用 `>= k` 配 `hi = mid`，最后的 `lo` 一定是矩阵里真实存在的元素（最小的满足条件的值必然出现在矩阵中）。
- 数个数时列指针每行都从头开始：退化成 `O(n^2)`。

**追问。**
- 用堆：`next(islice(heapq.merge(*matrix), k - 1, None))`，`n` 路惰性归并，`O(k log n)` 时间、`O(n)` 空间；`k` 小的时候更快。
- 进阶 `O(n)`：有论文中的算法，面试一般不要求，说出「二分答案 `O(n log V)` 和堆 `O(k log n)`」即可。
- 矩阵不是方阵或行列有序但不保证（只行有序）：改成每行二分计数，`O(n log n · log V)`。
