## Q
**LC 679 24 点游戏**｜Hard · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 8 次 · 最近 2026-09-08（CodeTop）

给一个长度为 `4` 的整数数组 `cards`，每张卡片上的数字在 `[1, 9]`。用运算符 `+ - * /` 和括号把这四个数字排成表达式，判断能否得到 `24`。规则：除法是**实数除法**（`4 / (1 - 2 / 3) = 12`）；每个运算在两个数字之间，不能用 `-` 作一元负号（`[1,1,1,1]` 不能写 `-1 -1 -1 -1`）；不能把数字拼接（`[1,2,1,2]` 不能写 `12 + 12`）。`cards.length == 4`，`1 <= cards[i] <= 9`。例：`cards = [4,1,8,7]` → `true`（`(8 - 4) * (7 - 1) = 24`）；`cards = [1,2,1,2]` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 回溯：每次从当前的数里**任选两个**，用 `+ - * /`（减法和除法两个方向都试）合并成一个新数，数的个数减一，递归到只剩一个数时检查它是否等于 `24`；用 `Fraction` 做精确运算，避免浮点误差。

**识别。** 固定只有 `4` 张牌，状态空间极小，可以穷举；难点是**括号**的所有结构怎么枚举。任何表达式树的最后一步都是「两个子结果做一次运算」，所以「每步选两个数合并」就覆盖了所有括号方式，不用单独枚举括号。看到「固定个数 + 运算符 + 括号」就想到这种递归合并。

**推导。** 暴力：枚举 `4!` 个排列、`4^3` 个运算符组合、`5` 种括号形状，共 `7680` 个表达式，能做但繁琐易漏。合并法：第一步 `C(4,2) = 6` 对，每对最多 `6` 种结果（`a+b`、`a*b`、`a-b`、`b-a`、`a/b`、`b/a`）；第二步 `3` 个数 `3` 对；第三步 `2` 个数 `1` 对。叶子最多 `6 * 6 * 3 * 6 * 1 * 6 = 3888` 个。除法产生分数，浮点比较 `== 24` 会出错，要么用误差阈值，要么直接用 `Fraction`。

```python
from fractions import Fraction
from itertools import combinations


def judge_point24(cards: list[int]) -> bool:
    def solve(nums: list[Fraction]) -> bool:
        if len(nums) == 1:
            return nums[0] == 24
        for i, j in combinations(range(len(nums)), 2):     # 任选两个数合并成一个
            a, b = nums[i], nums[j]
            rest = [x for k, x in enumerate(nums) if k != i and k != j]
            results = {a + b, a * b, a - b, b - a}         # + 和 * 可交换，- 和 / 要试两个方向
            if b:
                results.add(a / b)
            if a:
                results.add(b / a)
            if any(solve([*rest, r]) for r in results):
                return True
        return False
    return solve([Fraction(c) for c in cards])
```

运行：`[4,1,8,7]` → `True`，`[1,2,1,2]` → `False`，`[8,3,8,3]` → `True`，`[3,3,8,8]` → `True`（`8 / (3 - 8 / 3)`），`[1,1,1,1]` → `False`，`[9,9,9,9]` → `False`。

**复杂度。** 时间 `O(1)`：叶子数有固定上界 `3888`；空间 `O(1)`：递归深度 `3`。

**易错点。**
- 浮点直接比较 `== 24`：`[3,3,8,8]` 的 `8 / (3 - 8 / 3)` 在浮点里是 `23.99999999999999`，会被判成 `False`（正确 `True`）。用 `Fraction`，或者 `abs(x - 24) < 1e-6`。
- 除数为 `0` 必须跳过，否则 `ZeroDivisionError`（`Fraction` 同样会抛）。
- 只试 `a - b`、`a / b` 而漏掉 `b - a`、`b / a`：`[1,2,4,6]` 能写成 `4 * 6 * (2 - 1) = 24`，漏方向的版本得到 `False`。

**追问。**
- 要输出表达式：让每个数带上它的字符串，合并时同时拼接 `"(" + sa + "+" + sb + ")"`，找到 `24` 时返回字符串。
- 推广到 `n` 张牌、目标值 `target`：同一个递归，叶子数增长为阶乘级，加 `memo`（把排序后的元组做缓存键）去重。
- 浮点版：叶子比较 `abs(x - 24) < 1e-6`，除数判断 `abs(b) > 1e-6`；速度略快，但要小心阈值。
