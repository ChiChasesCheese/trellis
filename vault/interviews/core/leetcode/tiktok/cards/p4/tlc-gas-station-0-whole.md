## Q
**LC 134 加油站**｜Medium · LC TikTok 热度 50/100（近 3 个月） · CodeTop 国内累计 10 次 · 最近 2026-04-23（国内 CodeTop）

环形路线上有 `n` 个加油站，第 `i` 个加油站有汽油 `gas[i]` 升。你的油箱容量无限，从第 `i` 个加油站开往第 `i + 1` 个加油站要消耗 `cost[i]` 升汽油（最后一个站开往第 `0` 站）。你从其中一个加油站出发，开始时油箱为空。如果能按顺序绕环路行驶一周，返回出发的加油站编号，否则返回 `-1`；如果存在解，保证它**唯一**。`n == gas.length == cost.length`，`1 <= n <= 10^5`，`0 <= gas[i], cost[i] <= 10^4`。例：`gas = [1,2,3,4,5]`，`cost = [3,4,5,1,2]` → `3`；`gas = [2,3,4]`，`cost = [3,4,3]` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 一趟扫描维护两个量：总净油量 `total = Σ(gas[i] - cost[i])` 和从候选起点 `start` 出发的当前油量 `tank`；一旦 `tank < 0`，说明从 `start` 到当前站都不能当起点，把 `start` 改成下一站并清空 `tank`。最后 `total >= 0` 就返回 `start`，否则 `-1`。`O(n)`。

**识别。** 「环形路线」「油箱不能为负」「找出发点」是贪心加前缀和的信号。`n = 10^5`，逐个起点模拟绕一圈是 `O(n^2)` 约 `10^10`，超时。每站只有“净油量” `gas[i] - cost[i]` 起作用，问题简化成：在环形数组上找一个起点，使得从它出发的所有前缀和都不为负。

**推导。** 暴力：每个起点模拟一圈，`O(n^2)`。第一个观察：总净油量 `< 0` 一定无解，`>= 0` 一定有解（题目保证唯一）。第二个观察：从 `start` 出发在第 `i` 站首次油量为负，则 `start..i` 之间任何站 `k` 作起点也会失败——到达 `k` 时从 `start` 带来的油量 `>= 0`，从 `k` 白手起家只会更少，到 `i` 时一样会为负。所以可以一次跳过整段，下一个候选是 `i + 1`，每个站只扫描一次。

```python
def can_complete_circuit(gas: list[int], cost: list[int]) -> int:
    total = tank = start = 0
    for i, (g, c) in enumerate(zip(gas, cost)):
        diff = g - c                        # 在 i 站净得多少油
        total += diff
        tank += diff
        if tank < 0:                        # 从 start 出发走不到 i+1：start..i 都不能当起点
            start, tank = i + 1, 0
    return start if total >= 0 else -1      # 总油量够，从最后一次重置的位置出发一定可行
```

运行：`([1,2,3,4,5], [3,4,5,1,2])` → `3`，`([2,3,4], [3,4,3])` → `-1`，`([5], [4])` → `0`，`([2], [2])` → `0`，`([3,1,1], [1,2,2])` → `0`。

**复杂度。** 时间 `O(n)`；空间 `O(1)`。

**易错点。**
- 漏掉 `total >= 0` 的判断，直接返回 `start`：`gas = [2,3,4]`，`cost = [3,4,3]` 总油量不够，却返回 `2`，正确是 `-1`。
- 重置时写成 `start = i`（而不是 `i + 1`）：第一个示例返回 `2`，正确是 `3`；失败发生在 `i` 站，`i` 本身也包含在失败的区间里。
- `total` 和 `tank` 是两个不同的量：`total` 永远不清零，`tank` 每次重置。合并成一个变量，最后的 `total >= 0` 判断就失效了（重置后 `total` 只剩最后一段）。

**追问。**
- 为什么总油量够就一定有解：把净油量的前缀和 `S` 画出来，取 `S` 达到全局最小值的位置，从它的下一站出发，每个时刻的油量都是 `S(k) - S(最小位置)` 或绕回后加上 `total`，都不为负。
- 另一种写法：`diffs` 的前缀和里找最小值的位置，`(acc.index(min(acc)) + 1) % n`，先判断 `sum(diffs) < 0` 返回 `-1`。`[1,2,3,4,5]` 与 `[3,4,5,1,2]` 得到 `3`。
- 油箱有容量上限：不能无限囤油，贪心结论失效，需要重新分析（通常转为模拟或 DP）。
