## Q
**LC 974 和可被 K 整除的子数组**｜Medium · LC TikTok 热度 53/100（近 6 个月） · CodeTop 国内累计 9 次 · 最近 2026-08-27（CodeTop）

给整数数组 `nums` 和整数 `k`，返回元素之和可被 `k` 整除的**非空连续子数组**的个数。`1 <= nums.length <= 3 * 10^4`，`-10^4 <= nums[i] <= 10^4`，`2 <= k <= 10^4`。例：`nums = [4,5,0,-2,-3,1]`，`k = 5` → `7`（`[4,5,0,-2,-3,1]`、`[5]`、`[5,0]`、`[5,0,-2,-3]`、`[0]`、`[0,-2,-3]`、`[-2,-3]`）；`nums = [5]`，`k = 9` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 前缀和取模：子数组 `[i, j]` 的和能被 `k` 整除，当且仅当前缀和 `pre[j+1]` 与 `pre[i]` 对 `k` 的余数相同；所以一边扫描一边用哈希表记录「每个余数出现过几次」，当前余数在表里已有 `c` 个，就新增 `c` 个合法子数组。`O(n)`。

**识别。** 「**数子数组的个数**」加「和满足某个条件」是前缀和加哈希表的信号；数组里有**负数**，滑动窗口不可用（窗口和不单调）。条件是「整除」，转成「余数相等」后就变成“找相等的前缀值”，和 LC 560 和为 `k` 的子数组是同一个结构。`n = 3 * 10^4` 时 `O(n^2)` 约 `4.5 * 10^8`，Python 超时。

**推导。** 暴力：枚举所有起点终点，前缀和相减后取模，`O(n^2)`。浪费：固定终点后，对每个起点都重新判断。性质：`(pre[j+1] - pre[i]) % k == 0` 等价于 `pre[j+1] % k == pre[i] % k`，所以对每个终点只要知道“前面有多少个前缀的余数与我相同”。哈希表存余数的出现次数，初始放入 `{0: 1}`，代表空前缀（和为 `0`，余数 `0`），这样从下标 `0` 开始的合法子数组也被计数。

```python
from collections import Counter

def subarrays_div_by_k(nums: list[int], k: int) -> int:
    seen = Counter({0: 1})                  # 前缀和模 k 的出现次数；空前缀的余数是 0
    prefix = ans = 0
    for x in nums:
        prefix = (prefix + x) % k           # Python 的 % 对负数也返回 [0, k)，不用再补 + k
        ans += seen[prefix]                 # 以当前位置结尾、余数相同的前缀每个对应一个合法子数组
        seen[prefix] += 1
    return ans
```

运行：`([4,5,0,-2,-3,1], 5)` → `7`，`([5], 9)` → `0`，`([-1,2,9], 2)` → `2`，`([0], 2)` → `1`。

**复杂度。** 时间 `O(n)`；空间 `O(min(n, k))`，余数只有 `k` 种。

**易错点。**
- 没有给空前缀放 `{0: 1}`：`[4,5,0,-2,-3,1]`、`k = 5` 得到 `6`，正确是 `7`（漏掉从开头开始的整个数组）。
- 余数不能是负数。Python 的 `%` 对正的 `k` 总返回 `[0, k)`；换成按零截断的余数（C++ / Java 的 `%`，Python 里相当于 `int(math.fmod(...))`），同一输入得到 `4`，正确是 `7`，因为 `-1` 与 `4` 是同一个余数类却被当成两个。其他语言要写 `((s % k) + k) % k`。
- 子数组必须非空：空前缀只作为“左端点”出现，不能被计成一个子数组；上面的写法天然满足，因为每个子数组都对应一对不同的前缀。

**追问。**
- 和等于 `k`（LC 560）：键换成前缀和本身，`ans += seen[prefix - k]`。
- 长度至少为 `2` 且和是 `k` 的倍数（LC 523）：字典记每个余数**第一次**出现的下标，下一次遇到相同余数时检查下标差是否 `>= 2`。
- 最长的合法子数组：同样记第一次出现的下标，下标差的最大值；`[4,5,0,-2,-3,1]`、`k = 5` 的最长是 `6`。

**同模式。** LC 560 和为 K 的子数组、LC 523 连续的子数组和、LC 525 连续数组、LC 1590 使数组和能被 P 整除、LC 1248 统计优美子数组。
