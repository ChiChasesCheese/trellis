## Q
**LC 35 搜索插入位置**｜Easy · 近一年被问：美国 2 次、国内 0 次 · CodeTop 国内累计 2 次 · 最近 2026-02-18（美国面试记录）

给一个升序排列、没有重复元素的整数数组 `nums` 和一个目标值 `target`：找到 `target` 就返回它的下标；找不到就返回它按顺序插入后应该在的下标。必须使用 `O(log n)` 时间的算法。`1 <= nums.length <= 10^4`，`-10^4 <= nums[i] <= 10^4`，`-10^4 <= target <= 10^4`。例：`nums = [1,3,5,6]`，`target = 5` → `2`；`target = 2` → `1`；`target = 7` → `4`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 二分查找「第一个大于等于 `target` 的位置」（下界，lower bound）：区间取左闭右开 `[lo, hi)`，`hi` 初值是 `len(nums)`；`nums[mid] < target` 说明答案在 `mid` 右边，`lo = mid + 1`，否则 `mid` 本身可能就是答案，`hi = mid`；循环结束 `lo == hi` 就是答案。`O(log n)`。

**识别。** 「排序数组 + `O(log n)`」是二分的标准信号。这个问题问的不是「在不在」而是「插在哪」：答案是第一个不小于 `target` 的下标，它的取值范围是 `0` 到 `n`，比合法下标多一个（插到末尾），所以 `hi` 要从 `len(nums)` 开始。判定条件 `nums[i] >= target` 在某个位置之后一直为真，有单调性，才可以二分。

**推导。** 暴力：从左到右找第一个 `>= target` 的元素，`O(n)`，不满足要求。浪费：数组有序，扫过一个元素本可以排除一大片。洞察：看中点 `mid`，`nums[mid] < target` 则 `mid` 及左边全部排除，否则 `mid` 及右边都满足条件、只需在 `[lo, mid]` 里找第一个。每次区间减半，`O(log n)`。

```python
def search_insert(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums)                    # 答案区间 [lo, hi]，hi 可以等于 len(nums)（插到末尾）
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1                     # mid 和它左边都 < target，答案在右边
        else:
            hi = mid                         # mid 可能就是答案，保留
    return lo
```

运行：`([1,3,5,6], 5)` → `2`，`([1,3,5,6], 2)` → `1`，`([1,3,5,6], 7)` → `4`，`([1,3,5,6], 0)` → `0`，`([1], 1)` → `0`。

**复杂度。** 时间 `O(log n)`，空间 `O(1)`。

**易错点。**
- `hi` 写成 `len(nums) - 1`：答案可能是 `n`（插到末尾），这个值永远取不到。`([1,3,5,6], 7)` 得到 `3`，正确是 `4`。
- 条件写成 `nums[mid] <= target`：找到的是第一个**大于** `target` 的位置（上界）。`([1,3,5,6], 5)` 得到 `3`，正确是 `2`。
- 终止条件和更新必须配套：`while lo < hi` 搭配 `hi = mid`（半开区间）；换成 `while lo <= hi` 搭配 `hi = mid - 1`（闭区间）也正确，混用两套会死循环或漏解。

**追问。**
- 有重复元素：这个写法返回第一个 `>= target` 的位置，不用改；最后一个位置用「第一个 `> target`」减 1（LC 34）。
- Python 里直接用标准库：`bisect.bisect_left(nums, target)`，语义与上面完全相同。
- 旋转数组、答案空间不是数组下标（如开方、最小可行速度）：先写出单调的判定函数，再套同一个半开区间模板。

**同模式。** LC 34 在排序数组中查找元素的第一个和最后一个位置、LC 704 二分查找、LC 278 第一个错误的版本、LC 69 x 的平方根、LC 162 寻找峰值。
