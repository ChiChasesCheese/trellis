## Q
**LC 311 稀疏矩阵的乘法**｜Medium · 近一年被问：美国 1 次、国内 0 次 · CodeTop 国内累计 1 次 · 最近 2026-10-27（美国面试记录）

给两个**稀疏矩阵**（大部分元素是 0）：`mat1` 大小 `m x k`，`mat2` 大小 `k x n`，返回 `mat1 x mat2`。乘法一定可行。`1 <= m, n, k <= 100`，`-100 <= mat1[i][j], mat2[i][j] <= 100`。例：`mat1 = [[1,0,0],[-1,0,3]]`，`mat2 = [[7,0,0],[0,0,0],[0,0,1]]` → `[[7,0,0],[-7,0,3]]`；`[[0]] x [[0]]` → `[[0]]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 结果的 `res[i][j] = Σ_k mat1[i][k] * mat2[k][j]`，只有两个因子都非零的项有贡献：循环顺序改成 `i → k → j`，先跳过 `mat1[i][k] == 0`，再只遍历 `mat2` 第 `k` 行的非零项（预先压缩成 `(列号, 值)` 列表）。

**识别。** 题目点明「稀疏」，意思是别按 `O(m*k*n)` 做零乘零的无用功；矩阵乘法的每一项都是若干「乘积」的累加，乘积为 0 的项可以直接不算。数据只有 `100` 时朴素三重循环也过，但面试官要看你利用稀疏性。

**推导。** 暴力：`i, j, k` 三重循环，`O(m*k*n)`，不管是不是 0 都乘。观察：`mat1[i][k]` 为 0 时，整条 `k` 对第 `i` 行没有贡献，`n` 次乘法全省；`mat2[k][j]` 为 0 时同理。所以：外层 `i`，中层 `k` 跳过 `mat1[i][k] == 0`，内层只走 `mat2[k]` 的非零列。把 `mat2` 每行的非零项一次预处理好，不要在每个 `(i, k)` 上重新扫整行。

```python
def multiply(mat1: list[list[int]], mat2: list[list[int]]) -> list[list[int]]:
    m, n = len(mat1), len(mat2[0])
    # 把 mat2 每一行压成 [(列号, 值), ...]，只留非零项
    rows2 = [[(j, b) for j, b in enumerate(row) if b] for row in mat2]
    res = [[0] * n for _ in range(m)]                # 每行单独建，不能写 [[0] * n] * m
    for i, row in enumerate(mat1):
        for k, a in enumerate(row):
            if a == 0:
                continue                             # mat1[i][k] 为 0：整条 k 都不用算
            for j, b in rows2[k]:
                res[i][j] += a * b
    return res
```

运行：示例 1 → `[[7, 0, 0], [-7, 0, 3]]`，`[[0]] x [[0]]` → `[[0]]`，`[[2]] x [[-3]]` → `[[-6]]`。

**复杂度。** 预处理 `O(k*n)`；主循环扫 `mat1` 的 `O(m*k)`，加上每个非零 `mat1[i][k]` 乘 `mat2` 第 `k` 行的非零个数。稠密时退化成 `O(m*k*n)`（`m = k = n = 100` 时是 `10^6`）。空间 `O(m*n + nnz(mat2))`。

**易错点。**
- 用 `[[0] * n] * m` 建结果：`m` 行是同一个列表对象，写一行全行同步变。示例 1 会得到 `[[0, 0, 3], [0, 0, 3]]`，正确 `[[7, 0, 0], [-7, 0, 3]]`。
- `res[i][j] = a * b` 写成赋值：同一个 `(i, j)` 有多个 `k` 的项要累加。`[[1,1]] x [[1],[1]]` 得 `[[1]]`，正确 `[[2]]`。

**追问。**
- 输入本身就是稀疏格式（字典存非零项）：按行号给 `mat2` 分组，对 `mat1` 的每个非零项走一遍，输出也是字典，注意相消成 0 的项要去掉。
- 一个矩阵远比另一个稠密：把稀疏的那个放在外层循环。
- 用 NumPy：`np.array(mat1) @ np.array(mat2)`，但面试里通常要求手写。
