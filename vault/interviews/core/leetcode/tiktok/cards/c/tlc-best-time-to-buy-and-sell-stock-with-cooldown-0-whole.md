## Q
**LC 309 买卖股票的最佳时机含冷冻期**｜Medium · LC TikTok 全时段热度 38/100

给定整数数组 `prices`，`prices[i]` 是第 `i` 天的股票价格。设计算法计算最大利润，可以多次买卖同一支股票，但：卖出股票后，第二天不能买入（冷冻期 1 天）；不能同时参与多笔交易（再次买入前必须先卖出）。`1 <= prices.length <= 5000`，`0 <= prices[i] <= 1000`。例：`prices = [1,2,3,0,2]` → `3`（买、卖、冷冻、买、卖）；`prices = [1]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 状态机 DP：每天只有三种状态——持有股票、刚卖出（今天处于冷冻）、空仓可买，每个状态的最大利润只依赖前一天，一趟 `O(n)`。

**识别。** 「多次买卖 + 对买卖有约束」是股票系列题的状态机信号：把约束翻译成状态与转移，而不是枚举买卖点。`n = 5000` 允许 `O(n²)`，但状态机是 `O(n)` 且更不容易错。

**推导。** 暴力：枚举每笔交易的买卖日，指数级。把「第 `i` 天结束时的状态」当作 DP 状态：持有 `hold`、刚卖出 `sold`、空仓 `rest`。转移：持有 = 昨天持有，或昨天空仓今天买；刚卖出 = 昨天持有今天卖；空仓 = 昨天空仓，或昨天刚卖出（冷冻期过去）。冷冻期的约束就体现在「买入只能从 `rest` 来，不能从 `sold` 来」。答案取最后一天的 `sold` 与 `rest`。

```python
def max_profit(prices: list[int]) -> int:
    n = len(prices)
    # dp[i][0] 第 i 天结束持有股票；dp[i][1] 今天刚卖出（明天冷冻）；dp[i][2] 空仓且明天可买
    dp = [[0] * 3 for _ in range(n)]
    dp[0][0] = -prices[0]                        # 第 0 天只能买入或什么都不做
    for i in range(1, n):
        dp[i][0] = max(dp[i - 1][0], dp[i - 1][2] - prices[i])   # 买入只能来自可买状态，冷冻期不能买
        dp[i][1] = dp[i - 1][0] + prices[i]                      # 今天卖掉昨天的持仓
        dp[i][2] = max(dp[i - 1][2], dp[i - 1][1])               # 冷冻期结束后回到可买
    return max(dp[n - 1][1], dp[n - 1][2])       # 最后一天手里有股票不会更好
```

运行：`[1,2,3,0,2]` → `3`，`[1]` → `0`；`[5,4,3,2,1]` → `0`，`[1,2]` → `1`，`[1,2,4]` → `3`，`[2,1,4]` → `3`。

**复杂度。** 时间 `O(n)`，空间 `O(n)`（`n x 3` 的表）。空间可以压到 O(1)：见 Python 工具箱「DP 降维」。

**拓展优化。**
- 冷冻期改成 `c` 天：`rest` 要从 `sold` 在 `c` 天前的值转移，状态表里按 `dp[i - c][1]` 取。
- 去掉冷冻期、改成每笔手续费（LC 714）：买入从 `sold` 之外也能来，状态合并成两个，每次卖出扣手续费。

**易错点。**
- 买入也从刚卖出的状态转移（等于没有冷冻期）：`[1,2,3,0,2]` 得到 `4`，正确是 `3`。
- 答案只取 `rest`：最后一天刚卖出的利润可能更大，`[1,2]` 会得到 `0`，正确是 `1`。
- `dp[0][0]` 设成 `0`：等于白拿一股，`[3,2]` 得到 `2`，正确是 `0`。

**追问。**
- 最多 `k` 笔交易（LC 188）：状态加一维交易次数。
- 输出具体的买卖日：记录每个状态的转移来源，倒推路径。

**同模式。** LC 121 买卖股票的最佳时机、LC 122 买卖股票的最佳时机 II、LC 123 买卖股票的最佳时机 III、LC 188 买卖股票的最佳时机 IV、LC 714 买卖股票的最佳时机含手续费。
