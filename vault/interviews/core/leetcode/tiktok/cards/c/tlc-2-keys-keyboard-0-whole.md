## Q
**LC 650 只有两个键的键盘**｜Medium · LC TikTok 全时段热度 38/100

最初记事本上只有一个字符 `'A'`。每次可以做两种操作：`Copy All`（复制全部字符，不允许只复制部分）和 `Paste`（粘贴上一次复制的内容）。给你一个数字 `n`，求在记事本上输出**恰好** `n` 个 `'A'` 的最少操作次数。`1 <= n <= 1000`。例：`n = 3` → `3`（复制、粘贴、粘贴）；`n = 1` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 答案是 `n` 的所有质因数（含重复）之和：把 `n` 分解成 `p1 * p2 * ...`，每个因子 `p` 对应「一次复制加 `p - 1` 次粘贴」共 `p` 步，`O(√n)` 或 `O(n)`。

**识别。** 「只能整体复制、整体粘贴」→ 每一轮把长度乘以某个整数，最终长度 `n` 是各轮倍数的乘积；求最少步数就是把 `n` 拆成因子，使 `Σ 因子` 最小。

**推导。** DP：`dp[i]` 表示得到 `i` 个 `A` 的最少步数，最后一轮是把长度 `j`（`j` 整除 `i`）复制后粘贴 `i/j - 1` 次，共 `i/j` 步，`dp[i] = min(dp[j] + i/j)`。观察：一个合数因子 `a * b`（`a, b >= 2`）拆成两轮要 `a + b` 步，而 `a + b <= a * b`，所以拆得越细越好，最终全部拆到质因数，答案就是质因数之和。

```python
def min_steps(n: int) -> int:
    steps = 0
    d = 2
    while n > 1:
        while n % d == 0:                        # d 是质因数（小的因子已除尽，d 不可能是合数）
            steps += d                           # 每个质因子 d 贡献 d 步
            n //= d
        d += 1
    return steps
```

运行：`n = 3` → `3`，`n = 1` → `0`；`n = 6` → `5`，`n = 9` → `6`，`n = 1000` → `21`，`n = 997`（质数）→ `997`。

**复杂度。** 时间 `O(n)`（`d` 最多走到 `n`），空间 `O(1)`。

**拓展优化。**
- `d` 只需枚举到 `√n`，剩下的大于 1 的余数必是质数，直接加上，`O(√n)`。

```python
def min_steps_sqrt(n: int) -> int:
    steps = 0
    d = 2
    while d * d <= n:
        while n % d == 0:
            steps += d
            n //= d
        d += 1
    if n > 1:                                    # 剩下的是最后一个质因数
        steps += n
    return steps
```

**易错点。**
- 把答案算成「质因数个数」或「因子乘积」：`n = 9` 应该是 `6`（复制、粘贴、粘贴；复制、粘贴、粘贴），不是 `2`。
- 内层 `while` 写成 `if`：`n = 4` 只除一次 2 后 `d` 就越过 2，剩下的 `2` 永远除不尽，死循环。

**追问。**
- 允许复制部分字符：问题完全变了，状态要记录剪贴板长度，用 BFS。
- 只要判断步数是否 `<= k`：直接算上面的答案比较。
