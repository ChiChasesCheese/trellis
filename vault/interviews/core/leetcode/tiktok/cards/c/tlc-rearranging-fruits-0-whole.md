## Q
**LC 2561 重排水果**｜Hard · LC TikTok 全时段热度 26/100

有两个果篮，每个篮子里有 `n` 个水果，数组 `basket1`、`basket2` 表示每个水果的交换成本。每次操作选下标 `i`、`j`，交换 `basket1[i]` 与 `basket2[j]`，成本是 `min(basket1[i], basket2[j])`。排序后两个篮子完全相同时认为相等。返回使两个篮子相等的最小总成本，不可能则返回 `-1`。`basket1.length == basket2.length`，`1 <= basket1.length <= 10^5`，`1 <= basket1[i], basket2[i] <= 10^9`。例：`basket1 = [4,2,2,2], basket2 = [1,4,1,2]` → `1`；`basket1 = [2,3,4,1], basket2 = [3,2,5,1]` → `-1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 每种水果的总数必须为偶数；两篮子里「多出来」的水果凑成一个待交换列表，只需处理其中较小的一半，每次交换的代价是 `min(x, 2 * 全局最小值)`（直接换，或借最便宜的水果换两次）。

**识别。** 「用交换让两个多重集相等，代价是两者较小值」：先统计差异，再贪心地让昂贵的水果与便宜的水果配对，最便宜的水果还能当中转。

**推导。** 暴力：在状态空间里搜索所有交换序列，指数级。洞察：每种水果在两篮的数量差是 `d`，则多的一侧要换出 `d/2` 个（`d` 必须为偶数）。把所有要换出的水果合在一起排序，较小的一半与较大的一半一一配对交换，代价是较小者，总代价 `sum(extra[:k])`。再考虑中转：用全局最小的水果 `m` 先换出，再换回，花 `2m`，当 `x > 2m` 时更划算，所以每对取 `min(x, 2m)`。

```python
from collections import Counter


def min_cost(basket1: list[int], basket2: list[int]) -> int:
    diff = Counter(basket1)
    diff.subtract(basket2)                       # 每种水果在两个篮子里的数量差
    extra: list[int] = []                        # 需要换走的水果（两个篮子的多余部分合在一起）
    for fruit, d in diff.items():
        if d % 2:                                # 某种水果总数为奇数，永远无法平分
            return -1
        extra.extend([fruit] * (abs(d) // 2))
    extra.sort()
    cheapest = min(min(basket1), min(basket2))   # 全局最便宜的水果，可作为「中转」
    # extra 一半在篮 1、一半在篮 2，把最小的一半各配一个对手：
    # 直接交换花 x，或借 cheapest 交换两次花 2 * cheapest，取小
    return sum(min(x, 2 * cheapest) for x in extra[: len(extra) // 2])
```

运行：示例一 → `1`；示例二 → `-1`；`[1,1]`, `[1,1]` → `0`；`[84,80,43,8,80,88,43,14,100,88]`, `[32,32,42,68,68,100,42,84,14,8]` → `48`。

**复杂度。** 时间 `O(n log n)`（排序），空间 `O(n)`。

**拓展优化。**
- 不排序整个 `extra`，用 `heapq.nsmallest(len(extra) // 2, extra)` 取较小的一半，复杂度同阶；用快速选择可到 `O(n)`。
- 先判断偶数性可以用 `Counter` 的总和一次完成，提前返回 `-1`。

**易错点。**
- 忘记「借中转」：`basket1 = [100,100,1]`, `basket2 = [200,200,1]` 用最便宜的 `1` 换两次只花 `2`，只算直接交换得到 `100`。
- 全局最小只在 `basket1` 里找：`basket1 = [100,100,5,5]`, `basket2 = [200,200,1,1]` 的最小值 `1` 在另一个篮子里，漏掉会得到 `6`，正确答案是 `3`。
- 处理 `extra` 的全部元素而不是前一半：每次交换同时解决两个水果，应只累加较小的一半。

**追问。**
- 返回具体的交换方案：配对时记录 `(来自篮 1 的水果, 来自篮 2 的水果)`，借中转时多写两步。
- 交换成本改为 `max` 或两者之和：配对策略和中转条件都要重新推导。
