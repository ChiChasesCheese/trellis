## Q
**LC 740 删除并获得点数**｜Medium · LC TikTok 全时段热度 38/100 · CodeTop 国内累计 1 次 · 最近 2022-04-24（国内 CodeTop）

给定整数数组 `nums`。每次操作选一个 `nums[i]`，删除它并获得 `nums[i]` 点；之后必须删除所有等于 `nums[i] - 1` 和 `nums[i] + 1` 的元素。初始 0 点，返回能获得的最大点数。`1 <= nums.length <= 2 * 10^4`，`1 <= nums[i] <= 10^4`。例：`nums = [3,4,2]` → `6`（删 4 得 4，3 被删，再删 2 得 2）；`nums = [2,2,3,3,3,4]` → `9`（删 3 三次得 9）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 选了数值 `v` 就把所有 `v` 一次拿走，且不能选 `v±1`，按数值升序做「打家劫舍」：相邻数值二选一，不相邻随便选。

**识别。** 「选 x 就不能选 x±1」是打家劫舍的变形；先看清选 `v` 时同值元素全拿最划算（它们不冲突，多拿不亏）。

**推导。** 暴力：对每个元素决定删不删，状态是整个数组。洞察：只关心每个数值的总收益 `v * count[v]`；这样问题变成按数值排序后「相邻数值不能同时选」的最大权独立集，用两个变量滚动。

```python
from collections import Counter


def delete_and_earn(nums: list[int]) -> int:
    total = Counter(nums)
    take = skip = 0                              # take：选了当前数值的最优；skip：没选当前数值的最优
    prev = None
    for v in sorted(total):
        gain = v * total[v]                      # 选 v 就一次拿走所有 v
        if prev is not None and prev + 1 == v:   # 与前一个数值相邻：选 v 就不能选 prev
            take, skip = skip + gain, max(take, skip)
        else:                                    # 不相邻：互不影响
            take, skip = max(take, skip) + gain, max(take, skip)
        prev = v
    return max(take, skip)
```

运行：`[3,4,2]` → `6`；`[2,2,3,3,3,4]` → `9`；`[1]` → `1`；`[1,1,1,10000,10000]` → `20003`（数值不相邻，两个都拿）；`[1,2,3,4,5]` → `9`（选 1、3、5）；`[1,3,5]` → `9`。

**复杂度。** 时间 `O(n + k log k)`（`k` 为不同数值个数，排序），空间 `O(k)`。

**拓展优化。**
- 值域很小（这里 `<= 10^4`）时可以用定长数组 `points[v]` 直接做 `dp[v] = max(dp[v-1], dp[v-2] + points[v])`，免排序，时间 `O(n + max)`。
- 要还原选了哪些数值：改回 `dp` 数组并倒推。

**易错点。**
- 不相邻时仍然用 `skip + gain`：`[1,3,5]` 会少算，得到 `6` 而不是 `9`。
- 收益只算 `v` 而不是 `v * count[v]`：`[2,2,3,3,3,4]` 会得到 `6`（选 2 和 4），应为 `9`。
- 排序后只比较相邻下标而不比较数值是否差 1：相差 2 的数值没有冲突。

**追问。**
- 值域非常大：本解法按排序后的不同数值走，不依赖值域，所以不变。
- 把规则改成 `x±2` 也要删除：冲突范围变长，状态要多记一位。
