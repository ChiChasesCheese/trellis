## Q
**LC 36 有效的数独**｜Medium · LC TikTok 全时段热度 25/100 · CodeTop 国内累计 3 次 · 最近 2025-04-30（国内 CodeTop）

判断一个 `9 x 9` 的数独是否有效，只需要验证已填入的数字：数字 `1-9` 在每一行只能出现一次，在每一列只能出现一次，在每一个 `3 x 3` 宫内只能出现一次。空白格用 `'.'` 表示；有效的数独不一定可解。`board.length == 9`，`board[i].length == 9`，`board[i][j]` 是 `'1'`–`'9'` 或 `'.'`。例：经典示例盘面（左上角为 `5 3 . . 7 . . . .`）→ `true`；把左上角的 `5` 改成 `8`（与同宫的另一个 `8` 冲突）→ `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 扫描一遍棋盘，用 9 个行集合、9 个列集合、9 个宫集合记录已出现的数字，发现重复就返回 `false`；宫编号是 `r // 3 * 3 + c // 3`。

**识别。** 「检查三类约束内是否有重复」是哈希集合的直接应用；固定 `9 x 9`，所以时间是常数，但写法要干净。

**推导。** 暴力：对每一行、每一列、每一个宫各写一个检查函数，重复三次。洞察：每个格子同时属于一行、一列、一宫，一次遍历里查三个集合即可；宫的编号用整除把 `(r, c)` 映射到 `0..8`。

```python
def is_valid_sudoku(board: list[list[str]]) -> bool:
    rows = [set() for _ in range(9)]             # rows[r]：第 r 行已出现的数字
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]            # boxes[b]：第 b 个 3x3 宫内已出现的数字
    for r in range(9):
        for c in range(9):
            ch = board[r][c]
            if ch == ".":
                continue
            b = r // 3 * 3 + c // 3              # 宫的编号：按行优先 0..8
            if ch in rows[r] or ch in cols[c] or ch in boxes[b]:
                return False                     # 同一行 / 列 / 宫内重复
            rows[r].add(ch)
            cols[c].add(ch)
            boxes[b].add(ch)
    return True
```

运行：经典示例盘面 → `True`；左上角改成 `8` → `False`；全空棋盘 → `True`；`(0,0)` 与 `(2,2)` 都填 `5`（同宫、不同行列）→ `False`。

**复杂度。** 时间 `O(81)` 即 `O(1)`，空间 `O(81)` 即 `O(1)`。推广到 `n x n`（`n` 为完全平方数）是 `O(n^2)`。

**拓展优化。**
- 用位掩码代替集合：`rows[r] |= 1 << digit`，判重用 `&`，常数更小。
- 单个集合装下所有约束：把 `(r, ch)`、`(ch, c)`、`(r // 3, c // 3, ch)` 元组都放进同一个 `seen`，三者任一重复则无效。

**易错点。**
- 宫编号写成 `r // 3 + c // 3`：不同的宫会得到相同的编号，`(0, 3)` 和 `(3, 0)` 都是 `1`。
- 只检查行和列：`(0,0)` 与 `(2,2)` 都是 `5` 时行列都不冲突，但同宫，应返回 `false`。
- 遇到 `'.'` 也加入集合：第二个 `'.'` 会被判成重复。

**追问。**
- 求解数独（LC 37）：回溯 + 上面三类集合做可行性判断，选「候选最少」的格子优先填。
- 数独规模变成 `n x n`：宫边长 `√n`，宫编号 `r // k * k + c // k`。

**同模式。** LC 37 解数独、LC 51 N 皇后、LC 217 存在重复元素、LC 73 矩阵置零、LC 289 生命游戏。
