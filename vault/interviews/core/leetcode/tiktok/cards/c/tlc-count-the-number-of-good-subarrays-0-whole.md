## Q
**LC 2537 统计好子数组的数目**｜Medium · LC TikTok 全时段热度 26/100

给定整数数组 `nums` 和整数 `k`，返回 `nums` 中好子数组的数目。一个子数组如果有**至少** `k` 对下标 `(i, j)` 满足 `i < j` 且 `arr[i] == arr[j]`，它就是好子数组。`1 <= nums.length <= 10^5`，`1 <= nums[i], k <= 10^9`。例：`nums = [1,1,1,1,1]`，`k = 10` → `1`（只有整个数组，共 `C(5,2) = 10` 对）；`nums = [3,1,4,3,2,2,4]`，`k = 2` → `4`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 滑动窗口：对每个右端点，把左端点右移到「再移一步窗口就不好了」的位置，此时左边所有起点都构成好子数组，累加 `left`。

**识别。** 「统计满足至少 k 对的子数组个数」，条件随窗口变大单调（子数组越长，相等对只增不减），所以可以用「固定右端点，求最少需要保留多少」的滑动窗口计数。

**推导。** 暴力：枚举所有 `(l, r)`，增量维护相等对数，`O(n²)`。窗口 `[left, right]` 的相等对数 `pairs`，加入 `x` 时增加 `cnt[x]`（与窗口里每个 `x` 各成一对），移除 `x` 时先 `cnt[x] -= 1` 再减 `cnt[x]`。右端点 `right` 固定时，只要 `pairs >= k` 就把左端点右移（移出后窗口可能不再好）；循环结束后 `[left, right]` 不好，而 `[left - 1, right]` 是好的，所以起点 `0..left - 1` 共 `left` 个起点都是好子数组。

```python
from collections import defaultdict


def count_good(nums: list[int], k: int) -> int:
    cnt: defaultdict[int, int] = defaultdict(int)    # 窗口内每个值出现的次数
    pairs = 0                                    # 窗口内相等对数
    left = 0
    ans = 0
    for x in nums:
        pairs += cnt[x]                          # 新元素与窗口里每个相同值各成一对
        cnt[x] += 1
        while pairs >= k:                        # 窗口仍然好：继续缩小，找最短的好窗口
            cnt[nums[left]] -= 1
            pairs -= cnt[nums[left]]             # 移出的元素减少的对数 = 剩下的同值个数
            left += 1
        ans += left                              # 起点 0..left-1 的子数组都以 x 结尾且是好的
    return ans
```

运行：`([1,1,1,1,1], 10)` → `1`，`([3,1,4,3,2,2,4], 2)` → `4`；`([1,2,3], 1)` → `0`；`([1,1], 1)` → `1`。

**复杂度。** 时间 `O(n)`（每个元素最多入窗一次、出窗一次），空间 `O(n)`。

**拓展优化。**
- 「恰好 k 对」：`atLeast(k) - atLeast(k + 1)`，同一个模板调用两次。
- 把「至少 k 对」换成「至少 k 种不同值」或「某个值至少出现 k 次」，只需改窗口状态的维护方式，计数框架（`ans += left`）不变。

**易错点。**
- 把 `ans += right - left + 1`（计数窗口内的子数组）用于「至少」型条件：这是「最多」型的模板；「至少」型要统计的是左边能向左延伸的起点数。
- 移出元素时先减对数再减计数：`pairs -= cnt[x]` 要在 `cnt[x] -= 1` 之后，否则多减一对。
- `pairs` 用 32 位整型：最大约 `n²/2 = 5 * 10^9`，会溢出；Python 整数没有这个问题，但在 Java / C++ 里要用 `long`。

**追问。**
- 返回所有好子数组的最短长度：窗口里记录 `right - left + 1` 的最小值。
- `k` 很大（超过 `n²/2`）：答案直接为 `0`，不用扫描。

**同模式。** LC 713 乘积小于 K 的子数组、LC 930 和相同的二元子数组、LC 992 K 个不同整数的子数组、LC 1248 统计优美子数组、LC 2062 统计字符串中的元音子字符串。
