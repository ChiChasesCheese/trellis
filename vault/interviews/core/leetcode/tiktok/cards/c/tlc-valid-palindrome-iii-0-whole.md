## Q
**LC 1216 验证回文串 III**｜Hard · LC TikTok 全时段热度 25/100

给定字符串 `s` 和整数 `k`，若可以通过从 `s` 中删去最多 `k` 个字符将其变成回文串，则称它是「k 回文」，判断 `s` 是否是 k 回文。`1 <= s.length <= 1000`，`s` 只含小写英文字母，`1 <= k <= s.length`。例：`s = "abcdeca", k = 2` → `true`（删去 `b` 和 `e`）；`s = "abbababa", k = 1` → `true`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 区间 DP：`dp[i][j]` 是把 `s[i..j]` 变成回文最少要删的字符数，两端相同就看内部，不同就删一端取小，最后比较 `dp[0][n-1]` 与 `k`。

**识别。** 「删字符变回文」「最少操作」是回文子序列 / 区间 DP；等价于 `n - 最长回文子序列长度 <= k`。`n = 1000` 允许 `O(n^2)`。

**推导。** 暴力：枚举删除的字符子集，`2^n`。浪费：`s[i..j]` 的子问题被反复求解。洞察：看两端 `s[i]` 和 `s[j]`：相同时它们可以作为回文的外层，代价取决于内部 `dp[i+1][j-1]`；不同时必须删掉其中一个，`1 + min(dp[i+1][j], dp[i][j-1])`。区间由短到长填表，所以 `i` 倒序、`j` 正序。

```python
def is_valid_palindrome(s: str, k: int) -> bool:
    n = len(s)
    # dp[i][j]：把 s[i..j] 变成回文最少要删多少个字符（i >= j 时为 0）
    dp = [[0] * n for _ in range(n)]
    for i in range(n - 1, -1, -1):               # i 从后往前，保证 dp[i+1][*] 已算好
        for j in range(i + 1, n):
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1]      # 两端相同：不用删，看里面
            else:
                dp[i][j] = 1 + min(dp[i + 1][j], dp[i][j - 1])   # 两端不同：删左端或删右端，取小
    return dp[0][n - 1] <= k
```

运行：`"abcdeca"`, `2` → `True`；`"abbababa"`, `1` → `True`；`"abcdeca"`, `1` → `False`；`"a"`, `1` → `True`；`"ab"`, `1` → `True`；`"abc"`, `1` → `False`；长度 `1000` 的随机串不到 1 秒。

**复杂度。** 时间 `O(n^2)`，空间 `O(n^2)`。

**拓展优化。**
- 等价写法：求 `s` 与其反转串的最长公共子序列 `L`，答案是 `n - L <= k`，同样 `O(n^2)` 的二维表。
- 输出具体的最长回文子序列时，在同一张表上按决策倒推即可。

**易错点。**
- 把 `dp[i][j]` 当成最长回文子序列却不转换：`dp` 在这里存「最少删除数」，两端相同时取 `dp[i+1][j-1]` 而不是加 `2`。
- 遍历顺序错误（`i` 正序）：计算 `dp[i][j]` 时 `dp[i+1][*]` 尚未填写，值为初值 `0`，结果偏小。
- 两端不同时写成 `1 + dp[i+1][j-1]`（只删一个就当作两端都处理了）：`"abc"`, `k = 1` 会得到 `True`，正确答案是 `False`。

**追问。**
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 输出具体删除了哪些字符：保存每个状态的决策，从 `(0, n-1)` 倒推。

**同模式。** LC 516 最长回文子序列、LC 1312 让字符串成为回文串的最少插入次数、LC 5 最长回文子串、LC 647 回文子串、LC 680 验证回文串 II。
