## Q
**LC 829 连续整数求和**｜Hard · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 3 次 · 最近 2025-03-31（国内 CodeTop）

给定正整数 `n`，返回有多少组连续正整数的和等于 `n`（一个数本身也算一组）。`1 <= n <= 10^9`。例：`n = 5` → `2`（`5`，`2 + 3`）；`n = 9` → `3`（`9`，`4 + 5`，`2 + 3 + 4`）；`n = 15` → `4`（`15`，`7 + 8`，`4 + 5 + 6`，`1 + 2 + 3 + 4 + 5`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 设连续 `k` 项、首项为 `a`，则 `n = k*a + k(k-1)/2`；枚举 `k`，检查 `(n - k(k-1)/2)` 能否被 `k` 整除且商为正，`k` 只需枚举到约 `√(2n)`。

**识别。** 「连续整数之和」的暴力是滑动窗口 / 起点枚举，但 `n` 达 `10^9` 时线性也太慢；改成枚举项数，把求和写成公式，问题变成整除判断。

**推导。** 暴力：枚举起点向后累加，`O(n)` 起点 × 累加，`n = 10^9` 不可行。洞察：`k` 项之和至少是 `1 + 2 + ... + k = k(k+1)/2`，所以 `k(k+1)/2 <= n` 才有可能，`k` 最多约 `4.5 * 10^4`；对每个 `k`，首项 `a = (n - k(k-1)/2) / k` 是否为整数就是这个 `k` 是否合法。

```python
def consecutive_numbers_sum(n: int) -> int:
    count = 0
    k = 1                                        # k：连续整数的个数
    while k * (k + 1) // 2 <= n:                 # 首项至少为 1 时，k 项之和至少是 1+2+...+k
        # n = k*a + k(k-1)/2，其中 a 是首项；a 必须是正整数
        if (n - k * (k - 1) // 2) % k == 0:
            count += 1
        k += 1
    return count
```

运行：`5` → `2`，`9` → `3`，`15` → `4`，`1` → `1`，`2` → `1`，`3` → `2`，`10**9` → `10`。

**复杂度。** 时间 `O(√n)`，空间 `O(1)`。

**拓展优化。**
- 答案等于 `n` 的奇因数个数：质因数分解后，去掉 2 的幂，其余质数的 `(指数 + 1)` 连乘，仍是 `O(√n)`，但常数更小：

```python
def consecutive_numbers_sum_odd_divisors(n: int) -> int:
    while n % 2 == 0:                            # 答案 = n 的奇因数个数，先去掉所有因子 2
        n //= 2
    count, p = 1, 3
    while p * p <= n:                            # 质因数分解，因数个数 = Π(指数 + 1)
        exp = 0
        while n % p == 0:
            n //= p
            exp += 1
        count *= exp + 1
        p += 2
    return count * 2 if n > 1 else count         # 剩下一个大于 1 的质数，指数为 1
```

**易错点。**
- 循环条件写成 `k <= n`：`k` 项和的下限是 `k(k+1)/2`，超过 `n` 之后一定无解，线性枚举 `10^9` 次会超时。
- 条件放宽成 `k*(k-1)//2 <= n`：首项可能为 `0`，`n = 3` 会得到 `3` 而不是 `2`；`k(k+1)/2 <= n` 才保证 `a >= 1`。
- 整数除法写成浮点：`(n - k*(k-1)/2) / k` 在大数上有精度问题，要全程用 `//` 和 `%`。

**追问。**
- 返回具体的序列：对合法的 `k` 输出 `range(a, a + k)`。
- 为什么等于奇因数个数：每个奇因数 `d` 对应一组 `k = d` 或 `k = 2n/d` 的构造，奇偶性保证首项为整数。
