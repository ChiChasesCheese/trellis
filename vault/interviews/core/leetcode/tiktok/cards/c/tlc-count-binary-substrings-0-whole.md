## Q
**LC 696 计数二进制子串**｜Easy · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 1 次 · 最近 2021-09-02（国内 CodeTop）

给定只含 `0` 和 `1` 的字符串 `s`，统计并返回具有相同数量 `0` 和 `1` 的非空连续子串的数量，要求这些子串中所有的 `0` 和所有的 `1` 都是各自成组连续的。重复出现（不同位置）的子串要重复计数。`1 <= s.length <= 10^5`。例：`s = "00110011"` → `6`（`0011`、`01`、`1100`、`10`、`0011`、`01`）；`s = "10101"` → `4`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把字符串按连续相同字符切成若干段，相邻两段之间能产生的合法子串数等于两段长度的较小值，累加即可。

**识别。** 「0 和 1 数量相等且各自连续」的子串必然跨越恰好两个相邻的段（如 `0011`、`01`），所以问题等价于「相邻游程长度」的配对。

**推导。** 暴力：枚举所有偶数长度的子串并检查，`O(n^2)` 以上，`n = 10^5` 不可行。洞察：相邻两段长度 `a`、`b` 时，以边界为中心向两侧各扩 `1..min(a, b)` 位都是合法子串，共 `min(a, b)` 个；每个边界互不相交，求和就是答案。只需要记住上一段长度，不用存所有段。

```python
from itertools import pairwise


def count_binary_substrings(s: str) -> int:
    result = 0
    prev, cur = 0, 1                             # prev：上一段连续字符的长度；cur：当前这一段的长度
    for a, b in pairwise(s):
        if a == b:
            cur += 1
        else:
            result += min(prev, cur)             # 相邻两段之间能贡献 min(prev, cur) 个合法子串
            prev, cur = cur, 1
    return result + min(prev, cur)               # 最后一对相邻段
```

运行：`"00110011"` → `6`；`"10101"` → `4`；`"0"` → `0`；`"0011"` → `2`；`"00000111"` → `3`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 用 `itertools.groupby` 先得到所有段长再 `sum(map(min, lens, lens[1:]))`，写法更短，空间 `O(段数)`。

**易错点。**
- 循环结束后忘记加最后一对：`"0011"` 只有一个边界，所有贡献都在循环结束后的 `min(prev, cur)`，漏掉会得到 `0`，应为 `2`。
- `prev` 初值取 `1`：第一段前面没有段，`prev = 1` 会让第一个边界多算，`"0011"` 会得到 `3`；初值应为 `0`。
- 把相同的子串去重：题目要求不同位置的相同子串重复计数，示例一的 `0011` 和 `01` 各出现两次。

**追问。**
- 返回所有合法子串：对每个边界按 `1..min(prev, cur)` 切出，输出规模 `O(n^2)` 字符。
- 流式输入：本解法只保存 `prev`、`cur`，天然支持。

**同模式。** LC 695 岛屿的最大面积、LC 485 最大连续 1 的个数、LC 1513 仅含 1 的子串数、LC 647 回文子串、LC 5 最长回文子串。
