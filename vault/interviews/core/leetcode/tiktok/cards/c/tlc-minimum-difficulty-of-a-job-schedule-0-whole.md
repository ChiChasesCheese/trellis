## Q
**LC 1335 工作计划的最低难度**｜Hard · LC TikTok 全时段热度 38/100

要在 `d` 天内完成一串有依赖的工作：想做第 `i` 项必须先做完 `0..i-1` 的全部工作，每天至少完成一项。一天的难度是当天所做工作的最大难度，计划的总难度是 `d` 天难度之和。给定 `jobDifficulty` 和 `d`，返回最小总难度，无法制定计划返回 `-1`。`1 <= jobDifficulty.length <= 300`，`0 <= jobDifficulty[i] <= 1000`，`1 <= d <= 10`。例：`jobDifficulty = [6,5,4,3,2,1], d = 2` → `7`（第一天前 5 项难度 6，第二天最后 1 项难度 1）；`jobDifficulty = [9,9,9], d = 4` → `-1`；`jobDifficulty = [7,1,7,1,7,1], d = 3` → `15`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把一串工作切成 `d` 段连续区间，总代价是各段最大值之和；用二维 DP `dp[k][i]` 表示前 `i` 项用 `k` 天的最小难度，枚举最后一天从哪一项开始。

**识别。** 「顺序固定、切成 `k` 段连续区间、每段代价取最大值再求和」是划分型 DP（分割数组类）；`d <= 10`、`n <= 300` 允许 `O(d n^2)`。

**推导。** 暴力：枚举 `C(n-1, d-1)` 种切分，指数级。浪费：前 `j` 项的最优切分与最后一天怎么切无关。洞察：`dp[k][i] = min over j (dp[k-1][j] + max(job[j..i-1]))`；让 `j` 从 `i-1` 向左走，当天最大值边走边更新，不用重算区间最大值。

```python
from math import inf


def min_difficulty(job_difficulty: list[int], d: int) -> int:
    n = len(job_difficulty)
    if n < d:                                    # 每天至少一项工作
        return -1
    # dp[k][i]：前 i 项工作用 k 天完成的最小总难度
    dp = [[inf] * (n + 1) for _ in range(d + 1)]
    dp[0][0] = 0
    for k in range(1, d + 1):
        for i in range(k, n + 1):                # 前 i 项至少要 k 项才能每天一项
            day_max = 0
            for j in range(i - 1, k - 2, -1):    # 第 k 天做第 j..i-1 项，j 向左扩，当天最大难度只增不减
                day_max = max(day_max, job_difficulty[j])
                dp[k][i] = min(dp[k][i], dp[k - 1][j] + day_max)
    return dp[d][n]
```

运行：`[6,5,4,3,2,1]`, `d = 2` → `7`；`[9,9,9]`, `d = 4` → `-1`；`[1,1,1]`, `d = 3` → `3`；`[7,1,7,1,7,1]`, `d = 3` → `15`；`[11,111,22,222,33,333,44,444]`, `d = 6` → `843`；`[5]`, `d = 1` → `5`。

**复杂度。** 时间 `O(d * n^2)`，空间 `O(d * n)`。

**拓展优化。**
- 用单调栈维护「当前这一天内的最大值及对应的最优前驱」，把转移降到均摊 `O(1)`，总时间 `O(d * n)`；面试里 `O(d n^2)` 已足够。

**易错点。**
- 忘记 `n < d` 直接返回 `-1`：否则 DP 全是 `inf`，会返回 `inf` 而不是 `-1`。
- `j` 的下界写成 `0`：第 `k` 天之前需要先用 `k-1` 天各做一项，`j >= k - 1`；下界放得过低只会读到不可达状态 `inf`，放得过高则漏掉合法切分。
- 当天难度只取区间右端 `job[i-1]` 而不是区间最大值：`[6,5,4,3,2,1]`, `d = 2` 会得到 `3`，正确答案是 `7`。

**追问。**
- 空间可以压到 O(n)：见 Python 工具箱「DP 降维」。
- 输出具体切分方案：记录每个 `dp[k][i]` 取最小时的 `j`，从 `dp[d][n]` 倒推。
- `d` 很大 `n` 也很大：划分型 DP 的转移可用单调栈或分治优化。

**同模式。** LC 410 分割数组的最大值、LC 813 最大平均值和的分组、LC 1043 分隔数组以得到最大和、LC 1478 安排邮筒、LC 1531 压缩字符串 II。
