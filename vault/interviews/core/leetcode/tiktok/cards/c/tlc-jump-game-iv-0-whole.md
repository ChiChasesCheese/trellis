## Q
**LC 1345 跳跃游戏 IV**｜Hard · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 1 次 · 最近 2022-12-26（国内 CodeTop）

给定整数数组 `arr`，你一开始在下标 `0`。每一步可以跳到下标 `i + 1`（需 `i + 1 < arr.length`）、`i - 1`（需 `i - 1 >= 0`），或者任何满足 `arr[i] == arr[j]` 且 `i != j` 的下标 `j`。不能跳到数组外。返回到达最后一个下标所需的最少步数。`1 <= arr.length <= 5 * 10^4`，`-10^8 <= arr[i] <= 10^8`。例：`arr = [100,-23,-23,404,100,23,23,23,3,404]` → `3`（`0 -> 4 -> 3 -> 9`）；`arr = [7]` → `0`；`arr = [7,6,9,6,9,6,9,7]` → `1`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 下标是图的节点，相邻下标和同值下标是边，用 BFS 求最短路；同值下标的列表在第一次展开后立刻清空，保证每条「同值边」只走一次。

**识别。** 「每步代价为 1、求最少步数」：BFS。难点是同值的跳跃边可能有 `O(n²)` 条（全数组相等时），不处理会超时。

**推导。** 普通 BFS 每个节点出队时都遍历 `arr[i]` 的所有同值下标，全是同一个值时每个节点遍历 `n` 个，`O(n²)`。洞察：BFS 第一次从某个值的下标走到同值下标时，这个值的所有下标已经全部入队了（它们都在同一层），之后任何同值节点再展开都不可能得到更短的路，所以第一次展开后把该值的列表删掉。这样每个值的列表只被遍历一次。

```python
from collections import defaultdict, deque


def min_jumps(arr: list[int]) -> int:
    n = len(arr)
    if n == 1:
        return 0
    same: defaultdict[int, list[int]] = defaultdict(list)    # 值 -> 所有下标
    for i, v in enumerate(arr):
        same[v].append(i)

    seen = [False] * n
    seen[0] = True
    queue = deque([0])
    steps = 0
    while queue:
        steps += 1                               # 本层的节点再走一步
        for _ in range(len(queue)):
            i = queue.popleft()
            # same.pop：该值的下标列表只展开一次，之后同值节点不会再扫它
            for j in (*same.pop(arr[i], ()), i - 1, i + 1):
                if 0 <= j < n and not seen[j]:
                    if j == n - 1:
                        return steps
                    seen[j] = True
                    queue.append(j)
    return -1                                    # 不会到达：相邻跳跃保证最后一格可达
```

运行：`[100,-23,-23,404,100,23,23,23,3,404]` → `3`，`[7]` → `0`，`[7,6,9,6,9,6,9,7]` → `1`；`n = 5 * 10^4` 全相同的数组 → `1`（`0` 直接跳到末尾）。

**复杂度。** 时间 `O(n)`（每个下标入队一次，每个值的列表被遍历一次），空间 `O(n)`。

**拓展优化。**
- 双向 BFS 从两端同时搜索，每次扩展较小的一侧，实际更快，复杂度上界不变。
- 压缩连续相同值：连续三个以上相同值的中间那些节点没有意义，只保留两端，减小图的规模。

**易错点。**
- 不清空同值列表：全部相等的数组上每个节点都扫 `n` 个同值下标，`O(n²)`，会超时。
- 漏掉 `n == 1` 的特判：起点就是终点，循环里什么也走不到，会返回 `-1`，应为 `0`。
- `steps` 在层首递增、`return` 放在入队时：到达终点的那一步已经是 `steps`，不能等到出队再算。

**追问。**
- 输出最短路径：用 `prev[j] = i` 记录前驱，到达终点后回溯。
- 终点不固定、起点是所有值为 `x` 的下标：多源 BFS，初始队列放入全部起点。
