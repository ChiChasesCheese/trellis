## Q
**LC 962 最大宽度坡**｜Medium · LC TikTok 全时段热度 38/100

给定整数数组 `A`，坡是元组 `(i, j)`，满足 `i < j` 且 `A[i] <= A[j]`，坡的宽度是 `j - i`。求 `A` 中坡的最大宽度，不存在返回 `0`。`2 <= A.length <= 50000`，`0 <= A[i] <= 50000`。例：`[6,0,8,2,1,5]` → `4`（`(1, 5)`：`A[1] = 0 <= A[5] = 5`）；`[9,8,1,0,1,9,4,0,4,1]` → `7`（`(2, 9)`）。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 候选左端点只有「前缀最小值的下标」，把它们压进一个严格递减的单调栈；再从右往左扫右端点，只要栈顶的值不超过当前值就弹出并更新宽度，`O(n)`。

**识别。** 「求满足 `A[i] <= A[j]` 的最远 `i < j`」是单调栈的变种，不是常规的「下一个更大」，因为要的是**最远**而不是最近。`n = 5 * 10^4`，`O(n²)` 的纯 Python 会超时。

**推导。** 暴力：对每个 `i`，从右往左找第一个 `A[j] >= A[i]`，`O(n²)`。浪费在两处：一个 `i` 左边如果已经有更小或相等的 `i'`，`i` 永远不会是最优左端点（`i'` 更靠左且条件更容易满足）；所以候选左端点只留前缀最小值（值严格递减）。再从右往左扫 `j`：栈顶 `i` 若满足 `A[i] <= A[j]`，宽度 `j - i` 已经是 `i` 能得到的最大值（再往左的 `j` 只会更小），`i` 可以弹出。

```python
def max_width_ramp(nums: list[int]) -> int:
    stack: list[int] = []                        # 候选左端点：前缀最小值的下标，对应值严格递减
    for i, x in enumerate(nums):
        if not stack or x < nums[stack[-1]]:     # 比所有更靠左的数都小才可能成为更好的左端点
            stack.append(i)
    best = 0
    for j in range(len(nums) - 1, -1, -1):       # 右端点从右往左，宽度对每个 i 只会越来越小
        while stack and nums[stack[-1]] <= nums[j]:
            best = max(best, j - stack.pop())    # 栈顶 i 与最远的 j 配对，之后不再需要
        if not stack:
            break
    return best
```

运行：`[6,0,8,2,1,5]` → `4`，`[9,8,1,0,1,9,4,0,4,1]` → `7`；`[5,4,3]` → `0`，`[1,1]` → `1`，`list(range(50000))` → `49999`。

**复杂度。** 时间 `O(n)`，每个下标至多入栈、出栈一次；空间 `O(n)`。

**拓展优化。**
- 按值排序下标：值小的下标先处理，同时维护已处理下标的最小值，`O(n log n)` 但代码极短。

```python
def max_width_ramp_sorted(nums: list[int]) -> int:
    lo = len(nums)                               # 已处理（值不大于当前）下标里的最小下标
    best = 0
    for i in sorted(range(len(nums)), key=nums.__getitem__):   # 值升序，同值下标升序
        best = max(best, i - lo)                 # 之前处理的值都不大于 nums[i]，其中最靠左的下标配对
        lo = min(lo, i)
    return best
```

- 预处理后缀最大值再用双指针，同样 `O(n)`：右指针找到最右一个后缀最大值 `>= nums[i]` 的位置。

**易错点。**
- 弹栈条件写成 `<`：相等也是坡，`[1,1]` 得到 `0`，正确是 `1`。
- 右端点从左往右扫：每个 `i` 要配**最远**的 `j`，从右往左第一次满足才是最远。
- 弹出后忘了 `best` 取最大：同一个 `j` 可以连续弹出多个 `i`，每个都要比较，最左的那个最宽。

**追问。**
- 要返回坡的两端下标：弹出时同时记录 `i` 与 `j`。
- 条件改成 `A[i] < A[j]`：栈的弹出条件和入栈条件各改成严格比较。
