## Q
**LC 202 快乐数**｜Easy · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 6 次 · 最近 2025-05-21（国内 CodeTop）

判断正整数 `n` 是不是快乐数。「快乐数」的定义：每次把该数替换为它每个位置上的数字的平方和，重复这个过程，直到变为 `1`，也可能无限循环但始终变不到 `1`；结果为 `1` 就是快乐数。是返回 `true`，否则 `false`。`1 <= n <= 2^31 - 1`。例：`n = 19` → `true`（`19 → 82 → 68 → 100 → 1`）；`n = 2` → `false`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 把「数字平方和」当作函数 `f`，序列 `n, f(n), f(f(n)), ...` 要么到 `1`，要么进入环；用快慢指针（Floyd 判圈）检测环，`O(log n)` 时间、`O(1)` 空间。

**识别。** 「反复应用同一个函数，要么终止要么循环」就是链表找环的模型：状态空间有限（第一步之后最大不过 `810`），不终止就必然重复。判断是否进入环，首选哈希集合，进阶就是快慢指针。

**推导。** 序列会不会无限变大？10 位以内的数，平方和最大 `10 * 81 = 810`，之后的值都不超过这个范围，由鸽巢原理，序列要么到 `1`，要么重复出现某个值。暴力：用集合记录见过的值，再次遇到就返回 `false`，空间 `O(log n)`（序列很短）。快慢指针：慢的每次走一步，快的每次走两步，有环必相遇；相遇点若是 `1` 就是快乐数。

**简单解法。** 用集合记录见过的数。

```python
def is_happy_set(n: int) -> bool:
    seen: set[int] = set()
    while n != 1 and n not in seen:              # 重复出现说明进入了循环
        seen.add(n)
        n = sum(int(d) ** 2 for d in str(n))     # 各位数字的平方和
    return n == 1
```

时间 `O(log n)`，空间为序列长度（很短）；本身已经很好，面试官通常追问「能不能 `O(1)` 空间」。

最优解：

```python
def is_happy(n: int) -> bool:
    def step(x: int) -> int:
        total = 0
        while x:
            x, d = divmod(x, 10)                 # 一次拿到商和个位
            total += d * d
        return total

    slow, fast = n, step(n)                      # 起点错开一步，循环条件才能一开始成立
    while fast != 1 and slow != fast:
        slow = step(slow)                        # 慢指针一步
        fast = step(step(fast))                  # 快指针两步：有环必在环内追上慢指针
    return fast == 1                             # 到了 1（1 的后继还是 1）才是快乐数
```

运行：`19` → `true`，`2` → `false`；`1` → `true`，`7` → `true`，`4` → `false`，`2147483647` → `false`。

**复杂度。** 时间 `O(log n)`（第一步算一次位数，后面的值都在 `810` 以内，序列长度常数级）；空间 `O(1)`。

**拓展优化。**
- 不快慢指针也不用集合：所有不快乐的数最终都会掉进同一个环 `4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4`，所以走到 `1` 或 `4` 就停。

```python
def is_happy_cycle4(n: int) -> bool:
    while n not in (1, 4):                       # 不快乐数必然经过 4
        n = sum(int(d) ** 2 for d in str(n))
    return n == 1
```

**易错点。**
- `slow = fast = n` 同起点又用 `while slow != fast`：循环一次也不进，`19` 返回 `false`，正确是 `true`。
- 没有检测环：`n = 2` 会无限循环。
- 快指针只走一步：永远追不上慢指针，也检测不出环。

**追问。**
- 统计 `1..N` 中快乐数的个数：对每个数用「走到 1 或 4」判断，或对已判断过的值做记忆化。
- 把平方换成立方或别的函数：环的结构会变，不能再套用「必经 4」的结论，但快慢指针依然适用。

**同模式。** LC 141 环形链表、LC 142 环形链表 II、LC 287 寻找重复数、LC 258 各位相加、LC 263 丑数。
