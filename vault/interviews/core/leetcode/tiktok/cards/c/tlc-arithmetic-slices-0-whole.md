## Q
**LC 413 等差数列划分**｜Medium · LC TikTok 全时段热度 25/100

如果一个数列至少有三个元素，并且任意两个相邻元素之差相同，则称它为等差数列。给定整数数组 `nums`，返回 `nums` 中所有为等差数组的**子数组**（连续）个数。`1 <= nums.length <= 5000`，`-1000 <= nums[i] <= 1000`。例：`nums = [1,2,3,4]` → `3`（`[1,2,3]`、`[2,3,4]`、`[1,2,3,4]`）；`nums = [1]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 扫描时记录「以当前元素结尾的等差子数组个数」，三个相邻数公差相同就加一，公差断了清零，每步把它累加进答案。

**识别。** 「统计满足条件的连续子数组个数」常用「以 `i` 结尾的个数」作为 DP 状态；等差条件只取决于最近三个元素，状态可以只留一个变量。

**推导。** 暴力：枚举所有子数组并检查，`O(n^2)` 到 `O(n^3)`。洞察：若 `nums[i-2], nums[i-1], nums[i]` 成等差，则以 `i` 结尾的等差子数组比以 `i-1` 结尾的多一个（每个以 `i-1` 结尾的都能延伸，再加上刚好三个元素的新子数组），即 `dp[i] = dp[i-1] + 1`；否则 `dp[i] = 0`。答案是所有 `dp[i]` 之和。

```python
def number_of_arithmetic_slices(nums: list[int]) -> int:
    total = 0
    ending_here = 0                              # 以当前元素结尾的等差子数组个数（长度 >= 3）
    for i in range(2, len(nums)):
        if nums[i] - nums[i - 1] == nums[i - 1] - nums[i - 2]:
            ending_here += 1                     # 比前一个位置多出一个：从更远的起点延伸而来的 + 刚好 3 个元素的那个
            total += ending_here
        else:
            ending_here = 0                      # 公差断了，重新开始
    return total
```

运行：`[1,2,3,4]` → `3`；`[1]` → `0`；`[1,2]` → `0`；`[7,7,7,7]` → `3`；`[1,2,3,8,9,10]` → `2`；`[1,3,5,7,9]` → `6`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`（`dp[i]` 只依赖 `dp[i-1]`，压成一个变量）。

**拓展优化。**
- 不要求连续（子序列，LC 446 等差数列划分 II）：状态改成 `dp[i][diff]`，用字典按公差计数。
- 长度为 `L` 的一整段等差序列贡献 `(L-1)(L-2)/2` 个子数组，先分段再套公式也可以。

**易错点。**
- 公差断开时不清零：`[1,2,3,8,9,10]` 在 `8` 处断开后继续累加，会得到 `3`（偏大），应为 `2`。
- 累加放在 `if` 外：公差不同的位置也加上旧的 `ending_here`，结果偏大。
- 从下标 `1` 开始比较：需要三个元素才能判断，循环从 `2` 开始。

**追问。**
- 要求返回最长的等差子数组：记录当前段长度的最大值。
- 数组很长且流式输入：本解法只保留最近两个元素和一个计数器。

**同模式。** LC 446 等差数列划分 II - 子序列、LC 1027 最长等差数列、LC 978 最长湍流子数组、LC 53 最大子数组和、LC 152 乘积最大子数组。
