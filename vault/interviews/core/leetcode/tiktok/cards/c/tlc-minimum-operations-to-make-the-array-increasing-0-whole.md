## Q
**LC 1827 最少操作使数组递增**｜Easy · LC TikTok 全时段热度 26/100

给你一个整数数组 `nums`（下标从 0 开始）。每次操作可以选择数组中一个元素，把它增加 1。返回使 `nums` **严格递增**的最少操作次数。长度为 1 的数组是严格递增的特殊情况。`1 <= nums.length <= 5000`，`1 <= nums[i] <= 10^4`。例：`nums = [1,1,1]` → `3`（变成 `[1,2,3]`）；`nums = [1,5,2,4,1]` → `14`；`nums = [8]` → `0`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从左到右一趟，每个数至少要比前一个（已调整后的）数大 1，不够就抬到「前一个数 + 1」，抬多少就加多少次操作，`O(n)`。

**识别。** 「只能加、要求严格递增、操作最少」：只能增大，所以前面的数越小越有利于后面，每个数只抬到刚好满足即可，贪心。

**推导。** 设处理完前 `i` 个数后，最后一个数是 `prev`。当前数 `x` 若 `> prev` 不用动；否则必须抬到 `prev + 1`，代价 `prev + 1 - x`。把它抬得再高只会让后面更难，所以抬到刚好是最优，每个数的最终值由前一个数唯一确定，总代价最小。

```python
def min_operations(nums: list[int]) -> int:
    ops = 0
    prev = nums[0]                               # 调整后的前一个数
    for x in nums[1:]:
        target = max(x, prev + 1)                # 至少要比前一个大 1，已经够大就不动
        ops += target - x
        prev = target                            # 后面的数要和「调整后」的值比较
    return ops
```

运行：`[1,1,1]` → `3`，`[1,5,2,4,1]` → `14`，`[8]` → `0`；`[1,2,3]` → `0`，`[5,5]` → `1`，`[10000] * 5000` → `12497500`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`。

**拓展优化。**
- 既能加又能减、代价是 `|变化量|`，要变成严格递增：先把 `nums[i]` 换成 `nums[i] - i` 转成非递减，再用大根堆维护「斜率技巧」（slope trick），每个数入堆，堆顶比当前数大就加上差值并替换堆顶，`O(n log n)`。

**易错点。**
- `prev` 记成原始的 `x` 而不是调整后的值：`[1,5,2,4,1]` 会得到 `8`，正确是 `14`。
- 目标写成 `prev` 而不是 `prev + 1`：只保证非递减，`[1,1,1]` 得到 `0`，正确是 `3`。
- 当前数已经比 `prev` 大时还去减它：操作只能加，`max(x, prev + 1)` 保证了不会变小。

**追问。**
- 改成非严格递增（允许相等）：目标写成 `max(x, prev)`。
- 要求把数组变成「递减」：从右往左对称处理，或取相反数。

**同模式。** LC 945 使数组唯一的最小增量操作、LC 665 非递减数列、LC 1005 K 次取反后最大化的数组和、LC 2289 使数组按非递减顺序排列、LC 1887 使数组元素相等的减少操作次数。
