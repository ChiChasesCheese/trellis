## Q
**LC 2235 两整数相加**｜Easy · LC TikTok 全时段热度 26/100

给定两个整数 `num1` 和 `num2`，返回它们的和。`-100 <= num1, num2 <= 100`。例：`num1 = 12, num2 = 5` → `17`；`num1 = -10, num2 = 4` → `-6`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 直接返回 `num1 + num2`；面试追问的重点是「不用 `+` 怎么加」，用异或求不进位和、与加左移求进位，循环到没有进位。

**识别。** 这是热身题，答案本身一行；值得准备的是它的追问（位运算加法，LC 371 两整数之和）。

**推导。** Python 整数是任意精度，`+` 就是语言保证的正确做法，`O(1)`（在值域内）。位运算版的思路：每一位 `a ^ b` 是不考虑进位的和，`(a & b) << 1` 是产生的进位，把进位再加回去，重复直到进位为 0。

```python
def sum_of_two(num1: int, num2: int) -> int:
    return num1 + num2
```

运行：`12 + 5` → `17`；`-10 + 4` → `-6`；`-100 + -100` → `-200`；`0 + 0` → `0`。

**复杂度。** 时间 `O(1)`，空间 `O(1)`。

**拓展优化。**
- 位运算加法（不用 `+`）。Python 的负数是无限位补码，必须用掩码截到 32 位，最后再把符号位还原：

```python
def sum_bitwise(num1: int, num2: int) -> int:
    mask = 0xFFFFFFFF                            # Python 的整数是无限位，要手动限制到 32 位
    a, b = num1 & mask, num2 & mask
    while b:
        a, b = (a ^ b) & mask, ((a & b) << 1) & mask    # 异或是不进位的和，与再左移是进位
    return a if a <= 0x7FFFFFFF else ~(a ^ mask)        # 32 位补码还原成 Python 的负数
```

**易错点。**
- 位运算版不加掩码：Python 负数的二进制是无限个前导 1，`-1 + 1` 的进位会不断翻倍，`while b:` 永远不会结束。
- 还原负数写成 `-a`：32 位补码 `a > 0x7FFFFFFF` 表示负数，要用 `~(a ^ mask)`，`-(a)` 会得到一个很大的数。
- 符号判断的边界写错：`0x7FFFFFFF` 本身是最大的正数，`a > 0x7FFFFFFF` 才表示负数。

**追问。**
- 不使用 `+`、`-`：上面的位运算版。
- 两个任意长的数字字符串相加（LC 415）：逐位加并带进位。

**同模式。** LC 371 两整数之和、LC 415 字符串相加、LC 2 两数相加、LC 67 二进制求和、LC 989 数组形式的整数加法。
