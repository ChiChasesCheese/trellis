## Q
**LC 503 下一个更大元素 II**｜Medium · LC TikTok 全时段热度 26/100 · CodeTop 国内累计 10 次 · 最近 2024-06-23（国内 CodeTop）

给定循环数组 `nums`（`nums[nums.length - 1]` 的下一个元素是 `nums[0]`），返回每个元素的下一个更大元素：按遍历顺序，该数字之后（循环地搜索）第一个比它大的数，不存在则为 `-1`。`1 <= nums.length <= 10^4`，`-10^9 <= nums[i] <= 10^9`。例：`nums = [1,2,1]` → `[2,-1,2]`（第二个 1 要循环到开头才找到 2）；`nums = [1,2,3,4,3]` → `[2,3,4,-1,4]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 单调栈保存「还在等更大元素」的下标，把数组遍历两圈来模拟循环，遇到更大的数就弹栈回答。

**识别。** 「右边第一个更大 / 更小」是单调栈的标志；「循环」把数组视为首尾相接，等价于把数组拼接成两倍长再做普通版本。

**推导。** 暴力：对每个元素向后最多扫 `n-1` 个位置，`O(n^2)`，`n = 10^4` 约 10^8。浪费：被弹出的元素已经找到答案，没被弹出的元素对后来者来说，只有更大的才有意义。洞察：栈里的值从栈底到栈顶不增，新来的 `x` 比栈顶大就是栈顶的答案；走两圈让第二圈能回答第一圈剩下的元素。

```python
def next_greater_elements(nums: list[int]) -> list[int]:
    n = len(nums)
    answer = [-1] * n
    stack: list[int] = []                        # 还没找到更大元素的下标，对应的值从栈底到栈顶不增
    for i in range(2 * n):                       # 走两圈模拟循环数组
        x = nums[i % n]
        while stack and nums[stack[-1]] < x:     # x 是栈顶元素右边第一个更大的数
            answer[stack.pop()] = x
        if i < n:                                # 第二圈只负责回答，不再入栈
            stack.append(i)
    return answer
```

运行：`[1,2,1]` → `[2, -1, 2]`；`[1,2,3,4,3]` → `[2, 3, 4, -1, 4]`；`[5]` → `[-1]`；`[2,2,2]` → `[-1, -1, -1]`；`[5,4,3,2,1]` → `[-1, 5, 5, 5, 5]`。

**复杂度。** 时间 `O(n)`（每个下标最多入栈一次、出栈一次），空间 `O(n)`。

**拓展优化。**
- 从后往前遍历 `2n - 1 .. 0` 也可以：栈里维护「右边仍可能成为答案」的值，写法等价。
- 不复制数组：用 `i % n` 取值，空间不增加；全局最大值永远不会被弹出，答案保持 `-1`。

**易错点。**
- 第二圈也入栈：栈里出现重复下标，白做无用功；第二圈只需回答，用 `if i < n` 限制入栈。
- 栈判断用 `<=`：相等的数不算「更大」，`[2,2,2]` 会得到 `[2, 2, 2]`，应为 `[-1, -1, -1]`。
- 栈里存值而不是下标：无法写回 `answer` 的位置，也分不清重复的值。

**追问。**
- 下一个更小元素：把 `<` 改成 `>`。
- 最近的更大元素距离（LC 739 每日温度）：栈里存下标，答案写成 `i - 弹出的下标`。
