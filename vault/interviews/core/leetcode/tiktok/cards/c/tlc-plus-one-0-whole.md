## Q
**LC 66 加一**｜Easy · LC TikTok 全时段热度 25/100 · CodeTop 国内累计 1 次 · 最近 2021-11-02（国内 CodeTop）

给定表示大整数的整数数组 `digits`，`digits[i]` 是第 `i` 位数字，从左到右从最高位到最低位排列，不含前导 `0`。将这个大整数加 `1`，返回结果的数字数组。`1 <= digits.length <= 100`，`0 <= digits[i] <= 9`，`digits` 不含前导 `0`。例：`[1,2,3]` → `[1,2,4]`；`[4,3,2,1]` → `[4,3,2,2]`；`[9]` → `[1,0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从最低位往前找第一个不是 `9` 的数字，加一并结束；经过的 `9` 全部变成 `0`；全是 `9` 就在最前面补一个 `1`。

**识别。** 「数组表示的大整数做加法」：逐位进位，但加一的进位只会沿着连续的 `9` 传播，遇到第一个非 `9` 就终止。

**推导。** 转成整数加一再转回来依赖语言的大整数，面试里通常不被接受。逐位模拟进位：末位加一，若变成 `10` 就置 `0` 并向前进位。进位只在末位是 `9` 时发生并且继续向前，所以不用单独维护进位变量：遇到 `< 9` 的数字就 `+1` 并返回，`9` 就变 `0` 继续往前。

```python
def plus_one(digits: list[int]) -> list[int]:
    for i in range(len(digits) - 1, -1, -1):     # 从最低位往最高位
        if digits[i] < 9:
            digits[i] += 1                       # 没有进位了，直接结束
            return digits
        digits[i] = 0                            # 9 + 1 = 10：本位写 0，进位给前一位
    return [1] + digits                          # 全是 9：最高位还有进位，整体多出一位
```

运行：`[1,2,3]` → `[1,2,4]`，`[4,3,2,1]` → `[4,3,2,2]`，`[9]` → `[1,0]`；`[1,9,9]` → `[2,0,0]`，`[9,9,9]` → `[1,0,0,0]`。

**复杂度。** 时间 `O(n)`，空间 `O(1)`（不计全 `9` 时新建的数组）。

**拓展优化。**
- 加任意整数 `k`（LC 989 数组形式的整数加法）：从低位起 `k` 带着进位一起处理。

```python
def add_to_array_form(num: list[int], k: int) -> list[int]:
    res: list[int] = []
    i = len(num) - 1
    while i >= 0 or k:                           # 数组或 k 任何一边没处理完都继续
        if i >= 0:
            k += num[i]                          # 把当前位加进 k，k 同时承担进位
            i -= 1
        k, digit = divmod(k, 10)
        res.append(digit)
    return res[::-1]
```

- Python 里的「作弊」写法 `list(map(int, str(int("".join(map(str, digits))) + 1)))` 在位数超过 4300 时会因整数转字符串的长度限制抛 `ValueError`，面试里不建议。

**易错点。**
- 全 `9` 的情况漏了：`[9,9,9]` 循环结束后每位都是 `0`，必须在最前面补 `1`。
- 找到非 `9` 的位置后不 `return` 而是继续循环：前面的数字也被加一。
- 原地修改了入参：调用方的 `digits` 也被改成了结果，需要保留原数组时先拷贝。

**追问。**
- 链表表示的大整数（LC 369 给单链表加一）：先反转、加一、再反转；或者找最后一个非 `9` 的节点。
- 要求常数额外空间且不能改入参：不可能同时满足，因为全 `9` 时结果比输入长一位。

**同模式。** LC 989 数组形式的整数加法、LC 67 二进制求和、LC 2 两数相加、LC 415 字符串相加、LC 43 字符串相乘。
