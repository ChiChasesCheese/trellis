## Q
**LC 2672 有相同颜色的相邻元素数目**｜Medium · LC TikTok 全时段热度 26/100

给定整数 `n`，表示长度为 `n` 的数组 `colors`，初始全为 `0`（未染色）。给定 `queries`，`queries[i] = [index_i, color_i]`：第 `i` 次查询把 `colors[index_i]` 染成 `color_i`，然后统计 `colors` 中颜色相同的相邻对数（未染色的 `0` 不算）。返回数组 `answer`，`answer[i]` 是前 `i + 1` 次操作后的统计值。`1 <= n <= 10^5`，`1 <= queries.length <= 10^5`，`0 <= index_i <= n - 1`，`1 <= color_i <= 10^5`。例：`n = 4`，`queries = [[0,2],[1,2],[3,1],[1,1],[2,1]]` → `[0,1,1,0,2]`；`n = 1`，`queries = [[0,100000]]` → `[0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 增量维护相同相邻对数：每次染色只会影响被染位置和它左右两个邻居的两个相邻对，先减去旧颜色的贡献，再加上新颜色的贡献。

**识别。** 「单点修改 + 全局统计」，统计量由相邻对的局部性质累加而成：修改一个点只会改变与它相关的常数个项，所以不需要重新统计整个数组。

**推导。** 每次重新扫一遍数组是 `O(n · q)`，总量 `10^10`。洞察：位置 `i` 只参与 `(i - 1, i)` 与 `(i, i + 1)` 两个相邻对。修改前，如果 `colors[i]` 已经染过色，它与左右邻居相同的对数先从总数里减去；修改后，新颜色与左右邻居相同的对数再加回去。

```python
def color_the_array(n: int, queries: list[list[int]]) -> list[int]:
    colors = [0] * n                             # 0 表示未染色
    same = 0                                     # 当前相同颜色的相邻对数
    ans: list[int] = []
    for i, color in queries:
        if colors[i]:                            # 已染色才有旧贡献；0 与 0 不算一对
            same -= (i > 0 and colors[i - 1] == colors[i]) + (i < n - 1 and colors[i + 1] == colors[i])
        colors[i] = color
        same += (i > 0 and colors[i - 1] == color) + (i < n - 1 and colors[i + 1] == color)
        ans.append(same)
    return ans
```

运行：`(4, [[0,2],[1,2],[3,1],[1,1],[2,1]])` → `[0,1,1,0,2]`，`(1, [[0,100000]])` → `[0]`；重复染同一颜色 `(2, [[0,1],[1,1],[0,1]])` → `[0,1,1]`（第三步先减后加，结果不变）。

**复杂度。** 时间 `O(n + q)`，空间 `O(n)`。

**拓展优化。**
- 允许把颜色改回 `0`（取消染色）：逻辑不变，先减旧贡献，再加新贡献，新颜色为 `0` 时不加（注意 `0` 邻居不构成一对）。
- 区间染色（一次染一段）：需要线段树或分块维护相邻对，这里的 `O(1)` 局部更新不再够用。

**易错点。**
- 把 `0` 当作一种颜色：初始 `colors = [0, 0, 0, 0]` 会数出 3 对。染色前不要给未染色位置加贡献，旧贡献只在 `colors[i] != 0` 时减。
- 先改 `colors[i]` 再减旧贡献：减的就是新颜色的对数，数目错。必须先减、再赋值、再加。
- 重复染同色时不能直接跳过也不能只加不减：先减后加才能在颜色不变时保持原值。

**追问。**
- 只想知道最终的统计值：不需要每步输出，仍然是同样的更新。
- 颜色范围很大：算法不依赖颜色的取值，只比较相等，不需要映射。

**同模式。** LC 2569 更新数组后处理求和查询、LC 2653 滑动子数组的美丽值、LC 307 区域和检索 - 数组可修改、LC 1352 最后 K 个数的乘积、LC 1089 复写零。
