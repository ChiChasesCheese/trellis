## Q
**LC 280 摆动排序**｜Medium · LC TikTok 全时段热度 26/100

给你一个整数数组 `nums`，将该数组原地重新排序，使得 `nums[0] <= nums[1] >= nums[2] <= nums[3]...`。输入数组总是有一个有效的答案，满足条件的任一排列都算对。`1 <= nums.length <= 5 * 10^4`，`0 <= nums[i] <= 10^4`。例：`nums = [3,5,2,1,6,4]` → `[3,5,1,6,2,4]`（`[1,6,2,5,3,4]` 也对）；`nums = [6,6,5,6,3,8]` → `[6,6,5,6,3,8]`。进阶：能否在 `O(n)` 时间内解决？

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先排序，再把下标 `(1,2)`、`(3,4)`、`(5,6)`... 这几对相邻元素互换，就得到「小大小大」的摆动排列，`O(n log n)`；进阶的一趟扫描在拓展优化里。

**识别。** 「相邻元素大小交替」且不要求唯一解：不需要精确排名，只需要每个位置满足局部关系，局部调整或排序后交换都能构造。

**推导。** 排序后 `a0 <= a1 <= a2 <= ...`。交换 `(a1, a2)`、`(a3, a4)`...，得到 `a0, a2, a1, a4, a3, ...`：`a0 <= a2`（排序），`a2 >= a1`（交换后大的在前），`a1 <= a4`（`a1 <= a3 <= a4`），如此往后每个相邻关系都成立。

```python
def wiggle_sort(nums: list[int]) -> None:
    nums.sort()                                  # 升序：a0 <= a1 <= a2 <= ...
    for i in range(1, len(nums) - 1, 2):         # 交换 (1,2) (3,4) ...：让奇数下标成为「峰」
        nums[i], nums[i + 1] = nums[i + 1], nums[i]
```

运行：`[3,5,2,1,6,4]` → `[1,3,2,5,4,6]`，`[6,6,5,6,3,8]` → `[3,6,5,6,6,8]`，都满足 `nums[0] <= nums[1] >= nums[2] <= ...`；`[1]` → `[1]`，`[2,1]` → `[1,2]`。

**复杂度。** 时间 `O(n log n)`（排序），空间 `O(1)`（原地，不计排序栈）。

**拓展优化。**
- 进阶的 `O(n)`：从左到右一趟，若 `i` 位置的大小关系不满足就和前一个交换。交换不会破坏已经满足的前一对：奇数位 `i` 若 `nums[i] < nums[i-1]` 就交换，新的 `nums[i-1]` 变小，与 `nums[i-2]` 的「`>=`」关系仍成立；偶数位对称。

```python
def wiggle_sort_one_pass(nums: list[int]) -> None:
    for i in range(1, len(nums)):
        if i % 2 == 1:                           # 奇数位应该 >= 前一个
            if nums[i] < nums[i - 1]:
                nums[i], nums[i - 1] = nums[i - 1], nums[i]
        elif nums[i] > nums[i - 1]:              # 偶数位应该 <= 前一个
            nums[i], nums[i - 1] = nums[i - 1], nums[i]
```

**易错点。**
- 交换 `(0,1)`、`(2,3)`...：`[1,2,3,4]` 得到 `[2,1,4,3]`，开头 `2 <= 1` 不成立。
- 循环写成 `range(1, len(nums), 2)`：`n` 为偶数时最后一次 `i + 1` 越界抛 `IndexError`。

**追问。**
- 严格摆动 `nums[0] < nums[1] > nums[2] < ...`（LC 324）：相等元素会破坏严格关系，要把排序后的前后两半交错放，且各自倒序，不能用这里的相邻交换。
- 不原地、返回新数组：排序后切片交错即可。

**同模式。** LC 324 摆动排序 II、LC 376 摆动序列、LC 75 颜色分类、LC 905 按奇偶排序数组、LC 922 按奇偶排序数组 II。
