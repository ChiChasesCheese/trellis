## Q
**LC 1944 队列中可以看到的人数**｜Hard · LC TikTok 全时段热度 38/100

有 `n` 个人排成一个队列，从左到右编号 `0` 到 `n - 1`。给你整数数组 `heights`（互不相同），`heights[i]` 是第 `i` 个人的高度。第 `i` 个人能看到他右边第 `j` 个人，当且仅当 `i < j` 且 `min(heights[i], heights[j]) > max(heights[i+1], ..., heights[j-1])`，即两人之间的所有人都比这两人矮。返回长度为 `n` 的数组 `answer`，`answer[i]` 是第 `i` 个人在他右侧能看到的人数。`n == heights.length`，`1 <= n <= 10^5`，`1 <= heights[i] <= 10^5`，`heights` 中所有数互不相同。例：`heights = [10,6,8,5,11,9]` → `[3,1,2,1,1,0]`；`heights = [5,1,2,3,10]` → `[4,1,1,1,0]`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 从右往左扫，用单调栈（栈内高度自底向上递减）存「右边还没被挡住的人」：当前的人把栈里比自己矮的全部弹出（都看得到），再加上栈里第一个比自己高的（也看得到，如果有），`O(n)`。

**识别。** 「每个位置向右看，被更高的挡住」是单调栈的经典场景（同类：下一个更大元素）。`n = 10^5` 排除每人扫一遍右侧的 `O(n²)`。

**推导。** 暴力：对每个 `i` 向右走，维护中间的最大值，遇到比它高且不低于中间最大值的人就计一次，遇到比 `i` 高的人停下，`O(n²)`。浪费：相邻两人的「右边可见者」高度重叠很多。从右往左处理，栈里留下的是「从当前位置看过去的天际线」：比 `i` 矮的人被 `i` 挡住了，对左边所有人都不再可见，可以弹出；弹出的每个人 `i` 都看得到（中间的人都更矮），栈里剩下的第一个比 `i` 高的人也看得到，再往后都被他挡住。每个人入栈、出栈各一次。

```python
def can_see_persons_count(heights: list[int]) -> list[int]:
    n = len(heights)
    ans = [0] * n
    stack: list[int] = []                        # 高度自底向上递减：从当前位置往右看到的「天际线」
    for i in range(n - 1, -1, -1):
        h = heights[i]
        while stack and stack[-1] < h:
            stack.pop()                          # 比 i 矮：i 看得见，且今后被 i 挡住，不再需要
            ans[i] += 1
        if stack:
            ans[i] += 1                          # 栈里第一个比 i 高的人也看得见
        stack.append(h)
    return ans
```

运行：`[10,6,8,5,11,9]` → `[3,1,2,1,1,0]`，`[5,1,2,3,10]` → `[4,1,1,1,0]`；`[5]` → `[0]`，`[5,4,3,2,1]` → `[1,1,1,1,0]`，`[1,2,3,4,5]` → `[1,1,1,1,0]`。

**复杂度。** 时间 `O(n)`，空间 `O(n)`。

**拓展优化。**
- 高度可以相同（不再互不相同）：弹出条件改成 `<=`，同高的人被挡住后不重复计数；栈里再遇到相同高度需要先弹出再计数，规则按题目对「相同高度算不算挡」来定。
- 从左往右、统计「每个人能被多少人看到」：对称的做法，栈方向反过来。

**易错点。**
- 忘了「栈里第一个更高的人」：`[10,6,8,5,11,9]` 得到 `[2,0,1,0,1,0]`，正确是 `[3,1,2,1,1,0]`。
- 弹出时不计数：只算最后一个更高的人，`[5,1,2,3,10]` 得到 `[1,1,1,1,0]`。
- 从左往右扫：此时栈里装的是左边的人，答案变成「能看到左边多少人」，方向错了。

**追问。**
- 每个人能被右边几个人看到的反问：每个人被弹出一次说明他被「当前人」看到，也就是答案的转置；用同一个栈累计。
- 高度有重复的版本：把「严格更高才挡」改成「不低于就挡」，规则落在栈的弹出条件里。
