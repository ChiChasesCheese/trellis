## Q
**LC 1029 两地调度**｜Medium · LC TikTok 全时段热度 26/100

公司计划面试 `2n` 人。给你数组 `costs`，`costs[i] = [aCosti, bCosti]`，第 `i` 人飞往 `a` 市的费用为 `aCosti`，飞往 `b` 市的费用为 `bCosti`。返回将每个人都飞到 `a`、`b` 中某座城市的最低费用，要求每个城市都有 `n` 人抵达。`2 * n == costs.length`，`2 <= costs.length <= 100`，`costs.length` 为偶数，`1 <= aCosti, bCosti <= 1000`。例：`costs = [[10,20],[30,200],[400,50],[30,20]]` → `110`；`costs = [[259,770],[448,54],[926,667],[184,139],[840,118],[577,469]]` → `1859`；`costs = [[515,563],[451,713],[537,709],[343,819],[855,779],[457,60],[650,359],[631,42]]` → `3086`。

给出完整的最优解答：识别、推导、代码、复杂度、易错点、追问。

## A
**一句话。** 先假设所有人都去 `b` 市，再挑 `n` 个人改去 `a` 市，每个人改去的额外成本是 `a - b`，选 `a - b` 最小的 `n` 个，等价于按 `a - b` 排序后前 `n` 个去 `a`、后 `n` 个去 `b`，`O(n log n)`。

**识别。** 「分成两组、每组人数固定、每人两种代价」：把约束转成「选 `n` 个人」，每个人有一个差值代价，选最小的 `n` 个，是排序贪心的信号。`2n <= 100` 也允许 DP，但贪心更短。

**推导。** 总费用 = `Σ b + Σ_{去 a 的人}(a - b)`。`Σ b` 是常数，要最小化的是被选去 `a` 的 `n` 个人的 `a - b` 之和，直接取最小的 `n` 个。反证：若某个 `a - b` 较大的人去了 `a`，而某个 `a - b` 较小的人去了 `b`，互换后总费用不增，所以按差值排序是最优。

```python
def two_city_sched_cost(costs: list[list[int]]) -> int:
    n = len(costs) // 2
    ordered = sorted(costs, key=lambda c: c[0] - c[1])   # 去 a 比去 b 越省钱（差值越小）越靠前
    return sum(a for a, _ in ordered[:n]) + sum(b for _, b in ordered[n:])   # 前 n 个去 a，其余去 b
```

运行：`[[10,20],[30,200],[400,50],[30,20]]` → `110`，`[[259,770],[448,54],[926,667],[184,139],[840,118],[577,469]]` → `1859`，`[[515,563],[451,713],[537,709],[343,819],[855,779],[457,60],[650,359],[631,42]]` → `3086`；`[[1,2],[3,1]]` → `2`，`[[5,5],[5,5]]` → `10`。

**复杂度。** 时间 `O(n log n)`，空间 `O(n)`。

**拓展优化。**
- 不用排序整个数组：总费用 = 全去 `b` 的和 + 最小的 `n` 个差值之和，用 `heapq.nsmallest` 只取需要的，或用快速选择，平均 `O(n)`。

```python
from heapq import nsmallest


def two_city_sched_cost_heap(costs: list[list[int]]) -> int:
    n = len(costs) // 2
    base = sum(b for _, b in costs)                       # 先假设所有人去 b
    return base + sum(nsmallest(n, (a - b for a, b in costs)))   # 改去 a 的额外成本里最小的 n 个
```

**易错点。**
- 按 `a` 单独排序、前 `n` 个去 `a`：忽略了 `b` 的代价，`[[5,10],[1,6],[2,2],[5,6]]` 得到 `19`，正确是 `14`。
- 按 `a - b` 降序取前 `n` 个去 `a`：方向反了，得到的是最大值。
- 人数是奇数的一半（`len // 2` 写成 `len / 2`）：产生浮点数，切片报 `TypeError`。

**追问。**
- 三座城市（每市 `n` 人）：不再有单一差值，改用最小费用流或 DP（状态为已派往各城市的人数）。
- 每个城市人数上下限不固定：同样转成差值排序加区间约束，或用 DP。

**同模式。** LC 455 分发饼干、LC 135 分发糖果、LC 406 根据身高重建队列、LC 1005 K 次取反后最大化的数组和、LC 2279 装满石头的背包的最大数量。
