## Q
**数学算法 › 数论 › 其他**｜学习卡

套路是什么？

## A
**一句话。** 幂运算不要乘 n 次：把指数写成二进制，`x` 自己不断平方，指数的二进制位是 1 时把当前的 `x` 乘进答案，乘法次数从 n 降到 log n（快速幂，binary exponentiation）。

**例子。** 算 `3^13`：13 的二进制是 `1101`。

- 第 1 位是 1：答案乘 `3`，`x` 平方成 `9`。
- 第 2 位是 0：答案不变，`x` 平方成 `81`。
- 第 3 位是 1：答案乘 `81`，`x` 平方成 `6561`。
- 第 4 位是 1：答案乘 `6561`。
- 结果：`3 × 81 × 6561 = 3^(1+4+8) = 3^13`，4 次平方代替 12 次乘法。

```python
def my_pow(x, n):                  # LC 50
    if n < 0:                      # 负指数：先取倒数，再按正指数算
        x, n = 1 / x, -n
    ans = 1.0
    while n:
        if n & 1:                  # 当前最低位是 1：乘进答案
            ans *= x
        x *= x                     # x 依次是 x, x^2, x^4, x^8 …
        n >>= 1
    return ans

def super_pow(a, b):               # LC 372：a 的（数组 b 表示的大数）次方 mod 1337
    MOD = 1337
    ans = 1
    for d in b:                    # a^(10k+d) = (a^k)^10 · a^d
        ans = pow(ans, 10, MOD) * pow(a, d, MOD) % MOD
    return ans

def is_power_of_three(n):          # LC 326
    return n > 0 and 1162261467 % n == 0   # 3^19 是 32 位内最大的 3 的幂，它的约数只有 3 的幂
```

**要点。**
- **为什么对：** `x^n` 等于 `n` 的二进制里每个为 1 的位对应的 `x^(2^k)` 相乘，而 `x^(2^k)` 由上一个平方得到。
- **带模的版本：** 每次乘完立刻取模，中间结果不会溢出；Python 内置 `pow(a, e, m)` 就是这个算法。
- **指数是大数：** 指数按十进制一位一位处理，用 `a^(10k+d) = (a^k)^10 · a^d`，不必把整个指数转成整数。

**易错点。**
- **负指数溢出：** 在 Java 或 C++ 里 `n = -2^31` 时直接取负会溢出，要先转成 64 位再取负；Python 没有这个问题。
- **0 的负次方：** `x = 0` 且 `n < 0` 时除以零，题目若允许要单独处理。
- **3 的幂判断用对数：** `log(n) / log(3)` 有浮点误差，`243` 会被判错；用整数整除或 `3^19` 取余。
