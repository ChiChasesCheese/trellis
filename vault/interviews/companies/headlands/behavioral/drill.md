# 背景问题 6 天练习（今天 10/20 周二 → 10/26 周一 12:00 PT）

- 每天 90–120 分钟给背景题；其余时间给编码和 C++。
- 练习规则：**脱稿**；可以让 Claude 当面试官，但只给它故事的第一句；录音回听。
- 面试禁止使用 AI，所以平时关掉补全。

## 自评量表（每次录音后）

| 检查 | 通过标准 |
|---|---|
| 第一句是钩子 | ≤ 15 秒，无铺垫 |
| 动作主语是 I，团队的部分显式划线 | I ≥ 80% |
| 有一个数字，说得出怎么来的 | 被问不卡 |
| 有一句"为什么会这样"的机制 | NULL 传播 / 不可变分区 / 幂等键 / 窗口剪枝 |
| 该先说边界的先说 | 性能题 "capacity reasoning, not profiling"；个人项目先说 personal |
| 长度 | 60 秒版 ≤ 75 秒；2 分钟版 ≤ 2:15 |
| 讲完 L1 就停 | 等追问 |

## Day 1 · 10/20 · 补空 + 录开场
1. 通读 `00_how_it_works.md`，做自测（30 min）。
2. 补五个面试必问、材料里没有答案的空（45 min）：**Q9** C++ 真实写过多少；**Q6** 为什么离开；**Q3** 为什么做交易；**Q35** 办公室与工作许可；**Q34** 流程里还有谁。
3. 录 **Q1** 开场 ×2，计时 ≤ 60 秒（20 min）。
4. S3 的 60 秒版 ×2（15 min）。
5. 睡前默写 8 个故事的钩子句。

## Day 2 · 10/21 · 流利度 + 追问：S3 / S10 / S5
1. 每个故事 60 秒 ×2 → 2 分钟 ×1（30 min）。
2. 追问阶梯（45 min）：对方连续追 L1 → L2 → L3，你不看稿。重点：S3 的 NULL 语义和 `DROP`；S5 的窗口化 `ON` 及其代价；S10 的"读状态的时间点"。
3. C++ 诚实线（Q9）和 Linux/网络线（Q10）各说 3 遍，平静、不道歉（15 min）。
4. 从题库抽 10 题，只说"故事 + 第一句"（15 min）。

## Day 3 · 10/22 · 性能与"下一层"：S6 / S5 / S8
1. **Q13 ×3**（30 min）：先说边界，再讲 S6，再讲方法；检查有没有滑向"快了 N 倍"。
2. 补 `stories/templates.md` 的 T2（30 min）：只填真的；公司内部数据留在脑子里，不贴进仓库。
3. S8（20 min）：重点是"修完去扫仓库"和"收窄说宽的话"。
4. "I know it to here"（20 min）：随机抽 3 个下一层问题（NULL 语义之下？不可变分区之下？JIT 之下？），按"最深已知层 → 边界 → 怎么查"答。

## Day 4 · 10/23 · 动机 + 简历主线 + 好奇心：S7 / S1 / R1
1. **Q3、Q4、Q6** ×3，每个 ≤ 45 秒（30 min）。
2. **Q2** 简历主线，3 分钟，每块之后停（30 min）。
3. S7（20 min）：重点"为什么克隆 2 秒"和 V1 → V2 的确定性教训。
4. R1 + 补 T1（30 min）：先说 personal project；只补你记得的。
5. **Q22**（10 min）：写好 AI 题的真实版本。

## Day 5 · 10/24 · 整场模拟
1. 25 分钟背景块：随机抽 10 题，先判断用哪个故事、第一句是什么，再答；每题 ≤ 2 分钟含追问。
2. 40 分钟交织：做一道编码题，编码中途被插入背景题（"how would you test this?" → Q15；"have you optimized something like this at work?" → Q13）。练切换。
3. 每答完过量表，写 3 句反馈。
4. S3 / S5 / S7 / S10 各追到 L3，检查自己是不是在编。
5. 缺口演练：Q23（没有"输了再执行"的故事）和 Q27（code review）各用降级答法说一遍，≤ 40 秒。

## Day 6 · 10/25 · 轻量

3. 仍然空着的 【待补：…】：在对应故事里划掉，面试里不讲。
4. 不新增故事；早睡。
