# C08 · C++11 / 14 / 17 / 20 特性巡礼（"每个版本加了什么、为什么"）

> 面试原题：*Differences between C++ 11, 14, 17, and 20*。回答结构：**每个版本一句主题 + 3–5 个你真的用过的特性 + 一句"为什么加"**。下面每个版本的代码只用该版本及更早的特性。

## 0. 先给一句话地图

| 版本 | 主题 | 解决了什么痛点 |
|---|---|---|
| C++11 | "现代 C++"的诞生 | 手工管理内存、拷贝成本、没有并发标准、模板写法繁琐 |
| C++14 | 对 11 的补全 | lambda/constexpr/返回类型推导的限制 |
| C++17 | 日常好用的库与语法 | 样板代码、"可能没有值"的表达、编译期分支 |
| C++20 | 第二次大变革 | 模板报错、头文件模型、协程、比较运算符样板、范围操作 |
| (C++23) | 补 20 的缺口 | `expected`、`ranges::to`、`zip` 等 |

## 1. C++11

```cpp
enum class Side : char { Buy, Sell };                  // scoped enum: no implicit int conversion, no name leakage
using Price = long;                                    // alias declaration (readable typedef, and can be templated)
template <class T> using Vec = std::vector<T>;         // alias TEMPLATE: impossible with typedef

struct Base { virtual ~Base() = default; virtual int f() const { return 1; } };
struct Derived final : Base {                          // final: no further subclassing
    int f() const override { return 2; }               // override: compile error if it does not really override

struct NoCopy { NoCopy() = default; NoCopy(const NoCopy&) = delete; };   // = delete / = default
```


| 特性 | 为什么加 |
|---|---|
| `auto`、范围 `for`、`nullptr`、`enum class`、`using` 别名 | 少写样板；`nullptr` 修复 `0`/`NULL` 重载歧义；强类型枚举 |
| **移动语义 / 右值引用** | 避免深拷贝，值语义变快（`vector` 返回、扩容） |
| **智能指针** `unique_ptr`/`shared_ptr`/`weak_ptr` | 用 RAII 取代手工 `new`/`delete`；`auto_ptr` 废弃 |
| lambda | 就地写回调/谓词，配合算法 |
| 统一初始化 `{}`、`initializer_list` | 统一构造语法，禁止窄化 |
| `override`/`final`、`= default`/`= delete` | 让编译器检查重写；显式控制特殊成员函数 |
| 可变参数模板、`static_assert`、`constexpr`（单语句） | 通用库（`tuple`、`make_shared`）、编译期检查 |
| **并发库**：`thread`、`mutex`、`atomic`、`condition_variable`、`future`；**内存模型** | 语言第一次定义多线程语义（之前只能用平台 API） |
| `unordered_map/set`、`array`、`tuple`、`chrono`、`regex` | 标准库补全 |
| 用户定义字面量、原始字符串字面量 | 单位/正则等 |

## 2. C++14

```cpp
auto add(int a, int b) { return a + b; }                      // return type deduction for ordinary functions

constexpr int factorial(int n) {                              // relaxed constexpr: loops and locals allowed (C++11: single return)
    int r = 1;
    for (int i = 2; i <= n; ++i) r *= i;
    return r;
}
static_assert(factorial(5) == 120, "");

template <typename T> constexpr T kPi = T(3.1415926535897932385L);   // variable templates
```

```cpp
auto gen = [](auto a, auto b) { return a * b; };          // generic lambda: auto parameters
auto owned = std::make_unique<int>(9);                     // std::make_unique (C++11 had make_shared only)
auto use = [p = std::move(owned)] { return *p + 1; };      // init-capture: move into a lambda
std::cout << "  gen " << gen(3, 4) << " " << gen(1.5, 2) << ", init-capture " << use() << "\n";
```

```cpp
int mask = 0b1010'1010;                                    // binary literals and digit separators
long big = 1'000'000'000L;
using namespace std::string_literals;                      // "text"s : std::string literals
auto s = "abc"s + "def";
std::cout << "  mask=" << mask << " big=" << big << " s=" << s << " kPi<float>=" << kPi<float> << "\n";
```

```cpp
std::vector<int> v{1, 2, 3};
auto old = std::exchange(v, std::vector<int>{9});          // std::exchange: set a new value, get the old one
std::cout << "  exchange: old size " << old.size() << ", new size " << v.size() << ", add " << add(2, 3) << "\n";
```

| 特性 | 为什么加 |
|---|---|
| 泛型 lambda（`auto` 参数）、初始化捕获 | 11 的 lambda 不能泛型、不能捕获 move-only 对象 |
| 函数返回类型推导 `auto f()` | 少写重复类型 |
| 放宽 `constexpr`（循环、局部变量） | 11 的 `constexpr` 只能一个 `return` |
| 变量模板 `kPi<T>`、`make_unique` | 补齐对称性与异常安全 |
| 二进制字面量、数字分隔符 `1'000'000`、`[[deprecated]]`、`std::exchange` | 可读性 |

```cpp
    if constexpr (std::is_arithmetic_v<T>) return std::to_string(v);  // compile-time branch, replaces SFINAE tricks
    else return std::string(v);
```

| 特性 | 为什么加 |
|---|---|
| **结构化绑定** `auto [k, v] = ...`；`if`/`switch` 带初始化 | 解包 pair/tuple/结构体；缩小变量作用域 |
| **`std::optional` / `variant` / `any` / `string_view`** | "可能没有"、类型安全联合体、零拷贝字符串视图——以前靠指针/哨兵值/裸 union |

```cpp
// A minimal generator (C++20 gives you the machinery, not the library type; C++23 adds std::generator).
template <typename T>
struct Generator {
    struct promise_type {
        T current{};
        Generator get_return_object() { return Generator{std::coroutine_handle<promise_type>::from_promise(*this)}; }
        std::suspend_always initial_suspend() noexcept { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        std::suspend_always yield_value(T v) noexcept { current = v; return {}; }
        void return_void() {}
        void unhandled_exception() { std::terminate(); }
    };
    std::coroutine_handle<promise_type> h;
    explicit Generator(std::coroutine_handle<promise_type> hh) : h(hh) {}
    Generator(Generator&& o) noexcept : h(std::exchange(o.h, {})) {}
    ~Generator() { if (h) h.destroy(); }
    bool next() { h.resume(); return !h.done(); }
    T value() const { return h.promise().current; }
};

Generator<int> fibs() {
    int a = 0, b = 1;
    for (;;) { co_yield a; int t = a + b; a = b; b = t; }     // suspends here; resumes on the next next()
}
```

```cpp
constexpr int sum_squares(int n) {
    std::vector<int> v;                                       // std::vector / std::string usable at compile time (C++20)
    for (int i = 1; i <= n; ++i) v.push_back(i * i);
    return std::accumulate(v.begin(), v.end(), 0);
}
static_assert(sum_squares(10) == 385);
```

| 特性 | 为什么加 |
|---|---|
| **Concepts** | 给模板参数写约束，错误信息可读（`template <std::integral T>` 即要求 T 是整数类型） |
| **Ranges** + views | 惰性管线、投影，取代迭代器对的样板 |
| **协程**（`co_await`/`co_yield`/`co_return`） | 生成器、异步 I/O 的状态机由编译器生成（标准只给机制，库类型 C++23 才补 `std::generator`） |
| **Modules** | 取代 `#include` 头文件模型，编译更快（单文件面试中用不到） |
| 三路比较 `<=>` 与默认比较 | 一行生成全部六个比较运算符 |
| `consteval`、`constinit`、`constexpr` 里用 `vector`/`string` | 更多事情挪到编译期 |
| 指定初始化 `{.a = 1}`、模板 lambda、`using enum` | 可读性 |
| `std::span`、`std::format`、`<bit>`（`popcount`、`bit_cast`）、`jthread`/`stop_token`、`latch`/`barrier`/`semaphore`、`atomic::wait`、`erase_if` | 库补全：非拥有视图、类型安全格式化、位操作、可取消线程、同步原语 |

## 6. 坑

1. 说"C++11 加了智能指针"不够——要说出**为什么**（RAII 取代 `new/delete`，`auto_ptr` 的拷贝即转移语义有 bug）。
2. 把 `std::make_unique` 说成 C++11：它是 C++14 才补的（`make_shared` 在 11）。
3. 把 `std::optional/variant/string_view/structured bindings` 说成 20：它们是 17。
4. 把 ranges 说成 17、`std::format` 说成 17：都是 20。
5. 标准版本 ≠ 编译器支持度：不同编译器/标准库实现某个特性的时间不同；CoderPad 默认的 `-std` 可能是 17，先确认再用 C++20 特性。

## 7. 面试官接着会问

**Q：你日常最离不开哪几个特性？为什么？**
要点（选你真会用的）：移动语义 + 智能指针（所有权）、lambda + 算法、`auto` + 结构化绑定、`optional`/`string_view`、`constexpr`/`if constexpr`、concepts。

**Q：C++11 之前和之后写法有什么本质变化？**
要点：资源由类型管理（RAII/智能指针），值语义有了移动，不再手写 `new`/`delete`，并发有了标准内存模型。

**Q：C++20 你觉得最重要的是什么？**
要点：concepts（可读的泛型）、ranges（组合）、协程（异步/生成器）、modules（构建）；用一句话说明各自解决的痛点。

**Q：这些特性对性能有影响吗？**
要点：多数是零开销（编译期）；移动语义直接减少拷贝；`string_view`/`span` 避免分配；`constexpr` 把运行期算力挪到编译期；协程帧可能堆分配。

## 8. 自测

1. 哪个版本引入了：`make_unique`、`optional`、`<=>`、`unique_ptr`、`if constexpr`、`jthread`？
2. 保证的复制省略为什么让"不可移动类型"能按值返回？
3. 协程是怎么回事？标准库提供了什么，缺了什么？

<details><summary>答案</summary>

1. 14、17、20、11、17、20。
2. C++17 起用纯右值初始化对象不会创建临时对象，目标位置直接构造，不需要拷贝/移动构造函数。
3. 编译器把含 `co_yield/co_await` 的函数变成可挂起/恢复的状态机；标准提供机制（`coroutine_handle`、`suspend_always`）而不是现成的 generator/task 类型（`std::generator` 在 23）。

</details>
