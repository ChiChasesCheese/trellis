# hc16 · Tree DP on a Desk Hierarchy（交易台层级树上的 DP）

交易公司的台（desk）按上下级组成一棵树：一个根台，每个台最多一个直接上级，可以有任意多个下级。每个台有一个整数 PnL（当日盈亏，单位是 tick，可以为负）。
这个任务在这棵树上做动态规划：先求「不能同时选一个台和它的直接上级」时的最大总 PnL（树上的打家劫舍），再把选了哪些台还原出来，
然后求最大路径和与最大子树和，最后面对一条 10^5 层的链——递归写法会栈溢出，必须改成迭代。

## 读题前你需要知道

* **树（tree）**、**根（root）**、**父 / 子（parent / child）**、**叶子（leaf）**、**子树（subtree）** 各是什么意思；树怎么用「父数组（parent array）」或「边列表（edge list）」表示；
* **动态规划（DP）** 的基本想法：把大问题拆成子问题，子问题的答案存起来、只算一次；「每个台选或不选」是两个状态；
* **BFS（广度优先遍历）** 怎么按层走一棵树；为什么「父亲排在孩子前面」的顺序倒着扫，就等于「先处理孩子、再处理父亲」；
* **递归（recursion）** 每一层调用占一块栈空间；栈有大小上限，超过就崩（Java 抛 `StackOverflowError`，C++ 直接段错误）。

## 背景

* 台编号 `0..n-1`。树的形状由**父数组** `parent` 给出：`parent[i]` 是台 `i` 的直接上级，根台的 `parent` 是 `-1`。**不保证 `parent[i] < i`**，
  根也不一定是 0 号。另一种输入是**边列表**：`n-1` 条无向边加一个指定的根，要自己定向。
* `pnl[i]` 是台 `i` 的 PnL，整数（`long`），范围 `-10^12 .. 10^12`（含端点）。**钱不用浮点数。**
* **溢出规则：** `|pnl| ≤ 10^12`，台数 `n ≤ 10^6`，所以任何选择和、子树和、路径和的绝对值都不超过 `10^6 × 10^12 = 10^18 < Long.MAX_VALUE ≈ 9.22×10^18`——
  只要输入合法，所有查询都**不会溢出**，不需要 `addExact`。越界的输入在建树时就被拒绝（见下）。
* 「选一些台」允许**一个都不选**，所以答案不会是负数；空树和全负的树答案都是 0。

## Part 一览

| Part | 入口 | 内容 |
|---|---|---|
| 1 | `DeskTree.ofParents(parent, pnl)`、`size()` / `root()`、`maxPnl()` | 校验输入、建树；最大总 PnL，任何一个台和它的直接上级不同时被选 |
| 2 | `DeskTree.ofEdges(n, edges, pnl, root)`、`plan()` → `Plan` | 边列表输入；把选了哪些台还原出来，平局规则确定 |
| 3 | `maxDownPath()`、`maxPathSum()`、`bestSubtree()` → `Subtree` | 最大向下路径、最大任意路径（可拐弯）、子树和最大的台 |
| 4 | 全部方法在 10^5 层的链上不爆栈；`maxPnlRecursive()` | 迭代（BFS 顺序倒扫）；教科书递归版作对照；10^6 个台 < 2 s |

`Plan(long total, List<Integer> desks)`、`Subtree(int root, long total)` 在 starter 里已给出。签名以 starter 为准，这里只写语义。

## Part 1 · 建树 + 最大总 PnL

`ofParents(int[] parent, long[] pnl)`：`parent[i]` = 台 `i` 的直接上级，`-1` 表示根。入参数组要**拷贝**（建树之后再改入参，树不受影响）。`n = 0` 是合法的空树。

建树时校验，全部抛 `IllegalArgumentException`，信息固定，**按这个顺序**检查：

| 顺序 | 条件 | 信息 |
|---|---|---|
| 0 | `parent` 或 `pnl` 为 `null` | `NullPointerException` |
| 1 | `parent.length != pnl.length` | `length mismatch` |
| 2 | `n > 1_000_000` | `too many desks` |
| 3 | 某个 `pnl[i] > 10^12` 或 `< -10^12` | `invalid pnl` |
| 4 | 某个 `parent[i]` 不是 `-1`、也不在 `0..n-1`，或等于 `i` 自己 | `invalid parent` |
| 5 | `n > 0` 且值为 `-1` 的个数不是 1 | `invalid root` |
| 6 | 从根出发到不了所有台（说明有环） | `cycle` |

* `size()` → 台数；`root()` → 根台编号，空树是 `-1`。
* `maxPnl()` → 选一些台，**任何一个台和它的直接上级不能同时被选**（兄弟、祖孙隔代可以同时选），最大总 PnL；什么都不选 = 0。
* 检查 `pnl` 范围时不要写 `Math.abs(p) > MAX`：`Math.abs(Long.MIN_VALUE)` 还是负数，会放过它。直接比较 `p > MAX || p < -MAX`。

思路：每个台 `v` 算两个数——`take[v]` = 「选 `v`」时 `v` 的子树里能拿到的最大值，`skip[v]` = 「不选 `v`」时的最大值。

```
take[v] = pnl[v] + Σ skip[孩子]
skip[v] = Σ max(take[孩子], skip[孩子])
答案   = max(take[根], skip[根])
```

## Part 2 · 还原方案 + 边列表输入

面试官：「只给我一个数不够，我要知道选了哪些台。」

`plan()` → `Plan(total, desks)`：`total` 与 `maxPnl()` 相同，`desks` 是被选中的台编号，**升序**。最优方案可能不止一个，**平局规则**固定为：

> 台 `v` 被选，当且仅当它的直接上级**没被选**，并且 `take[v] > skip[v]`（严格大于）。相等就不选。

自顶向下判断：根没有上级，所以根被选当且仅当 `take[根] > skip[根]`；根没被选时，它的孩子各自按同样的规则判断；根被选时，它的孩子一律不选。
PnL 为 0 的台永远不会被选；全负的树方案是 `Plan(0, [])`。`Plan` 内部的 `desks` 不可变（`List.copyOf`）。

`ofEdges(int n, int[][] edges, long[] pnl, int root)`：`edges[i] = {a, b}` 是一条**无向**边；以 `root` 为根定向（离根近的一端是上级）。`n = 0` 时 `root` 被忽略。校验顺序：

| 顺序 | 条件 | 信息 |
|---|---|---|
| 0 | `edges` 或 `pnl` 为 `null` | `NullPointerException` |
| 1 | `n < 0` 或 `pnl.length != n` | `length mismatch` |
| 2–3 | 同 Part 1 的 `too many desks`、`invalid pnl` | |
| 4 | `n > 0` 且 `root` 不在 `0..n-1` | `invalid root` |
| 5 | 某条边为 `null`、长度不是 2、端点越界、或 `a == b` | `invalid edge` |
| 6 | 边数不是 `max(0, n-1)`，或从 `root` 到不了所有台（重复边、环、多个连通块） | `not a tree` |

边的顺序、两个端点的先后都不影响结果。最大独立集和最大路径和是**无向树**的性质，换一个根它们不变；`plan()` 的平局和 `bestSubtree()` 依赖根，会变。

## Part 3 · 路径与子树

面试官：「现在不选台了，看路径。」

* `maxDownPath()`：从某个台出发、每一步走到一个孩子的**非空**路径，最大 PnL 和（只含一个台的路径也算）。
* `maxPathSum()`：树中任意一条**非空简单路径**（每个台至多经过一次），最大 PnL 和。路径可以先往上走再往下走，在某个台**拐弯**（bend）：`左支 + 拐点 + 右支`。
* `bestSubtree()` → `Subtree(root, total)`：以 `root` 为根的子树的 PnL 总和最大的那个台；总和相同取**编号最小**的台。
* **空树**：三个方法都抛 `NoSuchElementException("empty tree")`。
* 全是负数时，路径不能为空，答案是最不坏的单个台（可能是负数）。

思路：`down[v] = pnl[v] + max(0, 最好的孩子 down)`（负的支路不要）；拐弯路径 `pnl[v] + 最好的两个非负 down 之和`。子树和 `sum[v] = pnl[v] + Σ sum[孩子]`。

## Part 4 · 10^5 层的链：不能递归

面试官：「如果这棵树是一条 10 万层的链呢？」

* **所有**查询方法（`maxPnl`、`plan`、`maxDownPath`、`maxPathSum`、`bestSubtree`，以及 `ofParents` / `ofEdges` 本身）必须在 10^5 层的链上正常工作，**调用线程的栈只有 512 KiB**。
  做法：建树时 BFS 出一个「父亲在孩子前面」的顺序，所有 DP 都按这个顺序**倒着扫**一遍——栈深度 O(1)。
* 链有两种方向：`parent[i] = i-1`（根是 0）和 `parent[i] = i+1`（根是 n-1，编号顺序和层次顺序相反）。后者会让「从 n-1 倒着扫父数组」之类的偷懒做法出错。
* `maxPnlRecursive()`：教科书递归版，**答案必须和 `maxPnl()` 一样**，但在 512 KiB 的栈上遇到 10^5 层的链会抛 `StackOverflowError`（C++ 版是进程崩溃）。留着它是为了让你亲眼看到、并能解释为什么。
* 规模：10^6 个台的随机深树，建树 + `maxPnl` + `plan` + 路径 + 子树 < 2 s。

**为什么递归会失败**（面试要能讲清）：每一层调用在栈上放一个**栈帧**（返回地址、参数、局部变量、保存的寄存器），几十到一百多字节。
线程栈是固定大小——Java 线程默认约 1 MiB（`-Xss` 可调），C++ 主线程在 macOS / Linux 上默认 8 MiB（`ulimit -s`），自己创建的线程更小（macOS 上 512 KiB）。
10^5 层 × 每帧 ~100 字节 = ~10 MB，超过上限。Java 抛 `StackOverflowError`（可以捕获，但捕获之后程序状态通常不可信）；
C++ 没有异常可抓，操作系统在栈尽头的保护页上发信号，进程以 SIGSEGV 结束。把栈调大只是推迟问题；链再长一个数量级还会爆。
**根治**：把调用栈换成自己的数组（显式栈，或者像这里 BFS 顺序倒扫）。

## 样例

```
          0 (1)
         /     \
     1 (4)     2 (-9)
     /   \      /   \
 3 (6)  4 (3) 5 (7)  6 (1)
```

```
parent = [-1, 0, 0, 1, 1, 2, 2]
pnl    = [ 1, 4, -9, 6, 3, 7, 1]
```

| 台 | take（选它） | skip（不选它） | 说明 |
|---|---|---|---|
| 3 | 6 | 0 | 叶子 |
| 4 | 3 | 0 | |
| 5 | 7 | 0 | |
| 6 | 1 | 0 | |
| 1 | 4 + 0 + 0 = 4 | 6 + 3 = 9 | 孩子 3、4 都可以选 |
| 2 | -9 + 0 + 0 = -9 | 7 + 1 = 8 | |
| 0 | 1 + 9 + 8 = 18 | 9 + 8 = 17 | 选根时孩子 1、2 的 take 不能用，只能用它们的 skip |

* Part 1：`maxPnl() = max(18, 17) = 18`。
* Part 2：根 `18 > 17` 被选 → 台 1、2 不选 → 台 3、4、5、6 各自 `take > skip` 被选，`plan() = Plan(18, [0, 3, 4, 5, 6])`（1 + 6 + 3 + 7 + 1 = 18）。
  平局例子：`parent = [-1, 0]`、`pnl = [5, 5]`：`take[0] = 5`，`skip[0] = 5`，相等不选根，`Plan(5, [1])`。
* Part 3：`down` = 3 号 6、4 号 3、1 号 4+6 = 10、5 号 7、6 号 1、2 号 -9+7 = -2（比单走 0 差，所以对上级的贡献按 0）、0 号 1+10 = 11。
  `maxDownPath() = 11`（0 → 1 → 3）；`maxPathSum() = 13`（3 → 1 → 4，在 1 号拐弯：6 + 4 + 3；经过根的最好路径 1 + 10 = 11 更差）；
  子树和：3 号 6、4 号 3、1 号 13、5 号 7、6 号 1、2 号 -1、0 号 13，最大 13，1 号和 0 号平局，取小的：`bestSubtree() = Subtree(0, 13)`。
* 非法：`ofParents(new int[]{-1, 2, 1}, …)` → `IllegalArgumentException("cycle")`；`parent = {1, 0}` → `invalid root`（没有 -1）。

## 边界清单（隐藏测试多半打这些）

空树（所有方法）；单个台（正 / 负 / 0）；全负；父子相等的平局；兄弟同时被选；PnL 为 0 的台；`parent[i] > i`、根不是 0；
`pnl = ±10^12` 的边界、`Long.MIN_VALUE`（`abs` 陷阱）；`n = 10^6` 的星形不溢出；所有检查的**先后顺序**；入参被拷贝；
边列表的重复边 / 环 / 非连通 / 自环 / 端点越界 / 换根；全负时最大路径是单个台；拐点本身为负；拐点要用最好的**两条**支路；子树和平局取小编号；
10^5 层的两种链（还有交替正负的链）；10^5 个孩子的宽树；`maxPnlRecursive` 在浅链上正确、深链上栈溢出。

## 相关变体

* 树以**逐行流**的形式到达（先到孩子后到父亲，或边乱序）：先收齐再建 BFS 顺序；不能假设父亲先出现。
* 每个台有「成本」、要求选出恰好 k 个台：状态里多一维 `dp[v][j]`，复杂度 O(n·k)。
* 不是「父子不能同选」而是「选了 v 就必须选它的上级」（闭包 / 依赖）：最大权闭合子图，另一类 DP（`take[v] = pnl[v] + Σ max(0, take[孩子])`）。
* 树上直径、最近公共祖先、换根 DP（每个台作根时的答案）：同一套「BFS 顺序倒扫 + 正扫」。
* 面试官常见追问：为什么不能递归？栈有多大？不想自己写显式栈还有什么办法（BFS 顺序、`Thread` 指定栈大小、尾递归在 JVM / C++ 里不被保证）？

## 考什么

不是什么偏题的算法：是**状态定义**（选 / 不选两个状态）、**把规则说清**（平局怎么定、空树和全负怎么办）、**工程鲁棒性**（输入校验与错误顺序、不溢出的论证、
10^5 层不爆栈），以及能把「递归 → 迭代」的改写讲成一个有因果的故事：栈是固定大小的资源，BFS 顺序倒扫用数组代替了调用栈。
