## Q
依次向空小根堆 add 5, 3, 8, 1, 2，每一步数组是什么？

## A
- add 5：`[5]`
- add 3：放下标 1，父亲 5，3 < 5 交换 → `[3, 5]`
- add 8：放下标 2，父亲 3，8 ≥ 3 不换 → `[3, 5, 8]`
- add 1：放下标 3，父亲下标 1（5）交换；再与下标 0（3）交换 → `[1, 3, 8, 5]`
- add 2：放下标 4，父亲下标 1（3），2 < 3 交换；与下标 0（1）比，2 ≥ 1 停 → `[1, 2, 8, 5, 3]`

最终树：根 1，孩子 2 和 8，2 下面挂 5 和 3。
