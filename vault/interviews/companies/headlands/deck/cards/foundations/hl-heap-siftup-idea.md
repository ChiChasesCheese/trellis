## Q
小根堆插入新元素时怎么做上浮（sift-up）？为什么这样能修好堆序？

## A
新元素先放**数组末尾**（保持完全二叉树），然后和父亲比：比父亲小就交换，一直换到不比父亲小或到根。

为什么对：插入前整棵树合法，新元素 x 放到末尾后唯一可能违规的是（x，x 的父亲）。若 x < 父亲 p，交换后 x 在 p 原位置，x < p ≤ p 原来的所有后代，向下没有违规；p 到了 x 原位置，其孩子是 p 原来的另一个孩子（p ≤ 它）；唯一可能的新违规是（x，x 的新父亲），继续处理。

每步 x 上一层，最多 log n 层，O(log n)。
