## Q
依次向空小根堆 add 4, 7, 2, 9, 1，每步数组是什么？再对结果 poll 一次得到什么？

## A
- add 4：`[4]`
- add 7：7 ≥ 父亲 4，不换 → `[4, 7]`
- add 2：2 < 4 换 → `[2, 7, 4]`
- add 9：父亲下标 1（7），9 ≥ 7 不换 → `[2, 7, 4, 9]`
- add 1：与下标 1（7）换，再与下标 0（2）换 → `[1, 2, 4, 9, 7]`

对 `[1, 2, 4, 9, 7]` poll：取走 1，末尾 7 搬到根 `[7, 2, 4, 9]`；根 7 的孩子 2 和 4，较小是 2，交换 → `[2, 7, 4, 9]`；7 在下标 1，孩子 9，7 ≤ 9 停。结果 `[2, 7, 4, 9]`。
