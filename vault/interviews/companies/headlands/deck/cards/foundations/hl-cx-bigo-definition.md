## Q
Big-O 记号怎么化简精确步数 T(n)？为什么「去低阶项、去常数」是合理的？它的形式定义是什么？

## A
Big-O 只保留 T(n) 里**增长最快的一项**，并去掉它前面的常数系数：n + 2 → O(n)；3n² + 5n + 7 → O(n²)；n(n−1)/2 → O(n²)；100 → O(1)；5n log n + 40n → O(n log n)。

- 去低阶项：n = 10⁶ 时 3n² = 3 × 10¹²，而 5n = 5 × 10⁶，只占百万分之二。
- 去常数：换机器、换语言「一步」的时间差几倍，但 n 变 10 倍时「慢多少倍」不变，Big-O 描述的是与机器无关的**增长形状**。

形式定义：存在常数 c > 0 和 n₀，使所有 n ≥ n₀ 都有 T(n) ≤ c · g(n)。例：3n² + 5n + 7 ≤ 15n²（取 c = 15，n₀ = 1）。c 和 n₀ 不唯一，找到一对即可。

代价：n 不大时，常数差 100 倍足以让 O(n) 输给 O(n²)。
