## Q
对小根堆 `[1, 2, 8, 5, 3]` 连续 poll，每次取出什么、堆变成什么？这和堆排序是什么关系？

## A
- poll 1：取走 1，末尾 3 搬到根 `[3, 2, 8, 5]`，孩子 2 和 8 较小是 2，交换；3 在下标 1，孩子 5，3 ≤ 5 停 → `[2, 3, 8, 5]`
- poll 2：取走 2，末尾 5 搬到根 `[5, 3, 8]`，与较小孩子 3 交换 → `[3, 5, 8]`
- poll 3：取走 3，8 搬到根 `[8, 5]`，与 5 交换 → `[5, 8]`
- poll 4：取走 5 → `[8]`；poll 5：取走 8 → `[]`

取出顺序 1, 2, 3, 5, 8 从小到大。这就是**堆排序**原理：建堆再 poll n 次得到有序序列，共 O(n log n)。
