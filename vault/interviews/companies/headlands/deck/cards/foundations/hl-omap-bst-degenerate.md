## Q
普通 BST 为什么会退化成链表？实验里 5000 个有序 key 与随机 key 的树高各是多少？这对订单簿为什么是真实风险？

## A
BST 所有操作是 O(**树高**)，而树高取决于**插入顺序**。依次插入 1, 2, 3, 4, 5，每个都成为上一个的右孩子，树高 = n，查找一次走 n 步，退化成链表。

实验 n = 5000：升序插入树高 **5000**（链表）；随机插入树高 **28**，约 log₂ n（12.3）的 2.3 倍（随机构造的 BST 期望高度是 O(log n)，精确常数约 3 log₂ n）。

真实风险：订单簿价位、时间戳、自增 id 常常递增，恰好是 BST 的最坏输入，生产环境不能用普通 BST。
