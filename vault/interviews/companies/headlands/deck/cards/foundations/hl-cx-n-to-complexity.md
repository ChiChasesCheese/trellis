## Q
面试里怎么从 n 的上限反推允许的复杂度？简单 Java 循环每秒大约多少次基本操作，总操作数应控制在多少？

## A
经验法则：简单 Java 循环每秒约 **10⁸** 次基本操作（保守值），面试限时 1 到几秒，总操作数别超过 10⁸ 到 10⁹。

- n ≤ 10：O(n!) 可以（10! = 3.6 × 10⁶）；
- n ≤ 20：O(2ⁿ)（2²⁰ = 10⁶）；
- n ≤ 500：O(n³)（1.25 × 10⁸）；
- n ≤ 5,000：O(n²)（2.5 × 10⁷）；
- n ≤ 10⁵：要 O(n log n) 或更好（n² = 10¹⁰ 太慢）；
- n ≤ 10⁶：O(n log n)；
- n ≤ 10⁸：只能 O(n)；
- n ≥ 10¹⁸：只能 O(log n) 或 O(1)。
