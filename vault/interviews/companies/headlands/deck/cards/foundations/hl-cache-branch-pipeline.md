## Q
CPU 流水线（pipeline）遇到条件分支时怎么办？分支预测失败的代价是多少？预测器能学会什么模式？

## A
CPU 像流水线：取指 → 解码 → 执行 → 写回，每级同时处理不同指令。遇到 `if (x > 0)`，下一步取哪条指令要等条件算出来；若等，流水线会空十几个周期。所以 CPU **猜**分支方向，先沿着猜的方向推测执行：
- 猜对：没有损失；
- 猜错：推测结果全部作废，清空流水线重来，惩罚约 **10–20 个周期**。

现代预测器记录每个分支最近的历史（及相关分支的历史），能学会「总是跳」「总是不跳」「交替」「每 8 次一轮」。**随机 50/50 学不会**，一半猜错。
