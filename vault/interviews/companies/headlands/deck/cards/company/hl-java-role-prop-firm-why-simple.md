## Q
用一句话向面试官说明你对 Headlands Java 岗里"研究平台 + 存储 + 集群"为什么存在的理解（因果链）。

## A
因果链：
1. 策略要靠**回测**检验，回测要重放海量历史数据；
2. 数据（tick）每天数百 GB，一块盘装不下 → **分布式存储**；
3. 参数要试上千组，串行要几十天 → **计算集群**并行；
4. 回测要和实盘同一套逻辑 → **自研研究平台**；
5. 研究员的迭代速度决定公司产出 → **监控与性能**要先于研究员发现问题。

说完补一句"这是我的理解，请你纠正"。
