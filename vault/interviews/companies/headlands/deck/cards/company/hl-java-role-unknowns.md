## Q
关于 Headlands 的 Java 岗，有哪四件事没有可靠的公开信息，面试中不要假装知道？

## A
1. Java 工程师人数，以及 Java 岗在组织里属于哪个组；
2. 研究平台的存储 / 调度是**自研还是开源**（岗位描述暗示两者都有）；
3. 公司人数与营收；
4. Java 岗的真实面试题。

对策：谈内部结构时说"这是我的理解，请你纠正"，并用提问换取信息（例如问研究平台最难保持快的是哪一块）。不知道就直说，比装懂更得分。
