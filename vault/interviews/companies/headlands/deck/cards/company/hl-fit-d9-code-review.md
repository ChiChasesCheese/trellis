## Q
JD 日常工作 "Conduct code reviews of other developers, researchers and operations team members"，你的证据偏薄时怎么说？绝对不能做什么？

## A
评级：**部分（证据薄）**。

- 简历：用 Claude Code 做 code review（评审 AI 的产出，不是评审同事）；带教只讲 domain-ownership / architectural collaboration；两年约 90 个 PR（自己的，不是评审数）。
- 说法："I read every diff — including the AI's — in money code, and I review as if it were someone else's code."
- **不要编造**"我评审过 N 个 PR"。
- 无需补课，需要**回忆一次真实的评审经历**。
