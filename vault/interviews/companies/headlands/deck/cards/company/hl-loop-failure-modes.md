## Q
Headlands 电话面常见的四种挂法是什么？各自的对策？

## A
1. **花很多时间修编译错误** → C++ 和 Java 都练到手熟；在 CoderPad 里先写一个能跑起来的最小 `main`。
2. **语言细节答得浅** → 过一遍 C++ 语言深度题库和速查表。
3. **基础题写完了，追问接不住** → 每道题的 Part 2–4 就是追问，练的时候连着做。
4. **背景问题讲成流水账** → 按提纲讲：一句开场 → 3 个关键决定 → 一个数字结果 → 留下了什么机制。
