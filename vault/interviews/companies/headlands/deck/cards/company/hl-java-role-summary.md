## Q
Headlands 的 Java 软件工程师岗每天主要做哪五类事？它在交易链路里处于什么位置？

## A
Java 岗**不在交易热路径上**，做的是基础设施：

1. **研究平台**（research platform）：提升性能、支持新交易所和新产品。
2. **分布式存储**（distributed storage）：满足各种性能与可靠性要求。
3. **分布式计算集群**（computing farm）：提升稳定性、可扩展性、性能。
4. **监控与主动检测**（monitoring / proactive detection）。
5. 改善系统内部组件间的**网络通信**，求最优延迟与吞吐。

毫秒以下的交易引擎是 C++ 岗的事。
