## Q
JD 要求 "Superior ability to write, refactor, and debug programs in Java"，你的证据和说法是什么？为什么不能说 "superior"？

## A
评级：**部分**。

- 证据：简历 skills 有 Java；PayPal 把 Ruby/Kotlin 迁到 **Java**（含 Claude Code 辅助重构 + 测试）；实习用 Kotlin / Spring Boot（跑在 JVM 上，但不等于 Java 语言功底）；HackerRank Java OA 已通过。
- 说法："Day to day at PayPal I'm in Java and Snowflake; I've also written Kotlin/Spring. The Java OA passed. I've been drilling Java 21 for this loop."
- 说 "superior" 会被追问，要靠编码题与语言深度题撑。
- 要补：Java 21 特性（record、sealed、模式 switch、虚拟线程）；视频面编码题。
