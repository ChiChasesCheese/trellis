## Q
用五句话概括 Headlands 和它的 Java 岗（公司性质、岗位位置、薪资、看重的人、哪些数字别报）。

## A
1. 自营量化交易公司，约 2010 年成立，总部芝加哥，只用自己的钱，没有客户。
2. Java 岗不在热路径，做研究平台、分布式存储、计算集群、监控、系统内部网络延迟；毫秒以下的引擎是 C++ 岗。
3. Chicago Java 岗 base **$175k–$300k**，只是 base。
4. 看重好奇、独立、低自我的人，金融知识反而要得很少。
5. 公司规模、营收、技术栈细节没有可靠公开数字，面试中不要报数字。
