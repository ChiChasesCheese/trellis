## Q
怎么把无用代码分析的答案连接到交易公司背景？回测与实盘共用代码时要注意什么？

## A
- Java 岗职责是研究平台、分布式存储、计算集群与监控，典型死代码来源是「旧交易所适配器」「废弃的数据格式解析器」「做过的实验性回测策略」。证据卡里写上 owner（如 research-platform 团队），PR 才有人接；
- 回测平台与实盘常共用同一份解析 / 模拟代码，删「回测专用」代码时必须把**实盘二进制和回测二进制都当根**；
- 删除的价值主张要讲对：不是「代码更漂亮」，而是**减小变更面（change surface）**，每次上线都是风险，死代码让每次改动的影响范围分析更难。
