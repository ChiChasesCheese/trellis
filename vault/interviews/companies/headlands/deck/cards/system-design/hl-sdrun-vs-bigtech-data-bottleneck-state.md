## Q
数据规模、瓶颈所在、状态存放、正确性证明、面试官看什么这五个维度，交易公司与大厂有什么不同？

## A
- **数据规模**：大厂 PB 级、吞吐是主要矛盾；交易公司单日 GB–TB，但速率有**尖峰**（开盘、新闻、做市商大量撤单），每条消息预算纳秒到微秒。
- **瓶颈**：大厂在网络 / 数据库 / 缓存命中率；交易公司在**内核（系统调用、中断、调度）、缓存未命中、GC 停顿、锁竞争、网络栈**，要点名「机械同情（mechanical sympathy）」：按硬件的工作方式写软件。
- **状态**：大厂放数据库、服务无状态；交易公司**状态在内存里**（订单簿、仓位），日志是持久化手段，不是数据库：崩溃 → 读快照 + 重放日志 → 追到最新。
- **正确性证明**：大厂靠压测 + 灰度；交易公司靠**回放**生产数据、模拟交易所、故障注入、线缆上打点测量。
- **面试官看什么**：看你**算数**，看你懂一层层往下（JVM、OS、CPU、网卡）。
