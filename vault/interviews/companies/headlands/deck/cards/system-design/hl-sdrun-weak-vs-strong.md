## Q
系统设计面试里好答案与坏答案各是什么样？列出几组对照。

## A
坏 → 好：
- 开口画 Kafka + Redis + 微服务 → 开口问 SLO 与速率，说「热路径单机单线程」；
- 「加机器就行」 → 「先算一台够不够，不够按品种分片，shared nothing」；
- 「用锁保护订单簿」 → 「单写者，跨线程只传不可变消息」；
- 「GC 调好就行」 → 「稳态分配率为 0，停顿根因是分配不是收集器」；
- 「宕机就切备机」 → 「谁有权发单？怎么避免双发？备机状态怎么保持一致？」；
- 只讲 happy path → 每个组件讲失败模式和停到安全状态的办法；
- 说「性能很好」 → 「我会在这里测 p99.99，线缆上打点，固定速率发包避免协调遗漏」；
- 把 Java 说成无所不能或一味回避 → 说清能做到什么、做不到什么，以及用什么纪律。
