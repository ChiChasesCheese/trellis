## Q
崩溃重启后的恢复流程有哪六步？对账发现不一致时怎么处理？

## A
1. 加载最近快照（各分片的订单簿 / 策略 / 订单 / 仓位 + 日志位置）；
2. 重放日志尾部，状态追到崩溃前一刻（决定性保证与崩溃前逐位相同，直到日志末尾）；
3. 连接交易所：重新登录，协商会话序号（请求补发错过的回报）；
4. 对账：查询未完成订单 / 当日成交 / 持仓，与重放得到的状态比对。一致 → 继续；日志落后（交易所有我们没有的成交 / 订单）→ 以交易所为准补入，记录一条「对账修复」事件；订单状态未知（发出去却没有回报）→ 查询，仍未知则撤销 + 视为可能已成交（保守）；
5. 行情：加入组播，快照 + 增量重新对齐，对齐前所有品种 STALE，不交易；
6. 人工 / 自动确认后解除熔断，恢复交易。
