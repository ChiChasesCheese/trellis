## Q
Headlands 这类交易公司的 Java 岗，系统设计题有哪两种「味道」？开场第一件事做什么？

## A
这家公司的 Java 岗在**研究平台 + 分布式存储 + 计算集群 + 监控**，不在交易热路径上（热路径是 C++）。所以：
- **基础设施味**：批处理、持久化、调度（如无用代码分析、未来时刻任务调度器）；
- **热路径味**：低延迟电子交易系统。

两种都要准备，**开场第一件事是判断面前的题是哪一种**。一律按 senior 门槛；术语第一次出现写「中文（English）」，数字都带推导，假设值标「假设」；先问清约束本身就是加分项。
