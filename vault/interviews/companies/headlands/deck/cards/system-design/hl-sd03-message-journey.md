## Q
一条行情消息从网卡到发出订单的旅程，各段预算（示例值）是多少？合计多少？

## A
- 包到达网卡，硬件打时间戳：0；
- Feed Handler 轮询取包（不进内核），解析 UDP 头、序号检查：约 0.5 µs；
- A/B 仲裁（位图 / 环形去重，这个序号是否已处理）：约 0.1–0.2 µs；
- 写入分片的 SPSC 环（一次 release 写，跨核缓存行传递约 50–100 ns）：约 0.1 µs；
- 分片线程读环，解码 + 更新订单簿（几个缓存行）：约 0.5 µs；
- 策略计算：约 3 µs；
- 风控闸门：约 0.3 µs；
- 编码 + 交给 Gateway 环：约 0.5 µs；
- Gateway 轮询环、写网卡（旁路发送）：约 0.7 µs。

合计约 **6 µs**，留约 4 µs 给抖动。
