## Q
无用代码分析开场必问哪些澄清问题？各自没有答案时采用什么假设？

## A
- 「没用」指什么（静态不可达？生产里从未执行？）→ 两者都做，**分层**报告：静态不可达为主，动态证据加权；
- 什么语言、构建系统？→ Java 为主（Maven / Gradle 或 Bazel），少量 C++ / Python / 脚本；
- 规模？→ 2×10⁷ 行（假设），并说明方案对 10⁸ 行同样成立；
- 删除自动还是人审？→ 只产候选，人审后删除；
- 误报（删了还在用的）和漏报（留着死代码）哪个更贵？→ 误报贵得多，宁可漏报（尤其是熔断 / 灾备路径）；
- 有无生产运行数据？→ 能拿到类加载日志，方法级需要 agent；
- 有无对外发布的库 / 公共 API？→ 有少量，标为「开放世界」需额外检查；
- 产出给谁？→ 代码 owner（CODEOWNERS），PR + 报告页面。
