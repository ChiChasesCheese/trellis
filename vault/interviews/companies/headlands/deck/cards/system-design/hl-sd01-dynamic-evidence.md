## Q
动态证据有哪几种信号，各自成本、能证明和不能证明什么？

## A
静态分析**证明不了**「没用」，只能证明「保守地看不出用法」，生产运行数据补上另一半：
- **类是否被加载过**：JVM `-Xlog:class+load` 或 JFR ClassLoad 事件，按（服务，版本）去重上报，成本极低；「N 个月从未加载」是很强的负证据，但加载了不等于方法被调用；
- **方法是否被调用过**：Java agent / JaCoCo 探针（全量开销可观，热路径不可用）或 JFR 执行采样；采样命中 = 肯定用过，但没命中 ≠ 没用过（假阴性），**稀有路径正是风险所在**；
- **日志 / 指标里出现过**：成本低，间接；
- **演练（game day）**：定期演练熔断 / 灾备并开启探针，给 L3 路径产生「被执行过」的证据。
