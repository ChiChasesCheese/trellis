## Q
设计题：公司有一个大型多语言（以 Java 为主）代码仓库，要对某一时刻的固定代码快照分析，产出「可能没用的代码」候选清单。这道设计题的关键限定词是什么，各意味着什么？

## A
题面：对**固定快照**做分析，产出每个候选**可解释**（为什么认为没用、证据是什么），并说明怎么把候选变成**安全的删除**，要在公司规模仓库上跑得完并能随代码变化持续运行。

- 「固定快照」：限定为**批处理分析**（离线、确定性、可复现），不是在线服务；
- 「可解释的候选」：输出不是布尔值，而是**带证据的判断 + 可信度**；
- 「候选」：系统不负责自动删除，**人审 + 安全流程**在回路里。

交易公司很少删代码，所以要把它讲成「代码库规模下的图可达性问题」。
