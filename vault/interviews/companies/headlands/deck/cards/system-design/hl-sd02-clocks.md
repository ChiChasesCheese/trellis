## Q
调度器的时钟与时区怎么处理：`fireAt` 用什么表示、怎么保证不早、墙上时钟回拨怎么办？

## A
- `fireAt` 是 **UTC 瞬时点**（epoch 毫秒）。「明天上午 9:00（纽约）」在提交时由 API 层按时区库解析；夏令时规则之后可能更新，所以远期任务要保存原始意图（本地时间 + 时区 id），在装载进时间轮前**再解析一次**；
- 服务端时钟误差 ε：NTP 局域网理想下可优于 1 ms，公网通常几十毫秒以内。保证不早：触发条件用 `now_calibrated − ε_max ≥ fireAt`。ε ≪ Δ，代价可忽略；
- **偏移监控**：节点周期性与时间源比较，偏移 > 阈值 → leader 主动让位（自我 fencing）并告警；
- **单调 vs 墙上**：推进时间轮只用 `nanoTime`，墙上时钟只用来比较 `fireAt`；墙上时钟被向后调整时，**不让时间轮倒退**，而是暂停推进直到墙上时间追上；
- 提交时若 `fireAt ≤ now`：立即触发，并在响应里标明「已过期，立即触发」。
