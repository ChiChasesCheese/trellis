## Q
回报缺失、对账差异、整机故障、控制面配置错误、时钟失步这五类故障的检测与响应是什么？

## A
- 回报缺失（订单长时间 PENDING）：超时计时；主动查询订单状态，仍未知 ⟹ 保守按「可能已成交」处理 + 对账；爆炸半径该订单；
- 对账差异（drop copy 与 OMS 不一致）：比对器检测；该范围 fail closed；受影响策略 / 品种；
- 整机（掉电 / 内核崩溃）：备机心跳；备机接管；本机全部；
- 控制面配置错误（限额设错）：变更审计 + 双人复核 + 灰度；配置版本回滚，限额变更本身被风控审计；取决于配置；
- 时钟（PTP 失步）：偏移监控；告警，时间戳不可信 ⟹ 对账降级；度量 / 对账。
