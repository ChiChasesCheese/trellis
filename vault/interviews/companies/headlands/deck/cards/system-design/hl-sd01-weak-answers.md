## Q
无用代码题常见的七种弱答案各有什么问题，正确修正是什么？

## A
- 「`grep` 每个函数名，没有结果就删」：找不到死环，被注释 / 字符串 / 同名类干扰，漏掉反射 → 符号级引用图 + 可达性；
- 「用 IDE 的 unused 提示」：只覆盖私有成员（L0），不跨模块 → 全程序可达性 + 根模型；
- 「上 Spark / GraphX 做分布式图计算」：估算后图只有约 80 MB → 分布式用在索引，图在单机；
- 「静态分析结果直接自动删」：反射 / 公共 API / 冷路径 → 事故 → 候选 + 证据 + 人审 + 软删除；
- 「看覆盖率，没覆盖的就是死代码」：测试覆盖率 ≠ 生产使用 → 生产类加载 / 采样作证据之一而非判决；
- 「只做运行时分析」：抽样漏稀有路径，永远不能证明没用 → 静态证明不可达 + 动态佐证；
- 没有评估方案 → 回测历史删除、种子注入、抽样人审。
