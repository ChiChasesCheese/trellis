## Q
面试追问：那交易公司为什么用 C++？Java 与 C++ 的差距主要在哪？

## A
- 稳态热点循环 Java 可接近 C++；差距主要在：**预热**、**GC 暂停**、**对象头与指针追逐**、**缺少内联值类型**、**对硬件的控制**。
- 交易公司用 C++ 的理由：**尾延迟、确定性**、内核旁路网络与硬件接近、对内存布局的完全控制。
- 一句话：不是 Java 慢，而是 Java 的**最差情况**和**不可控**成分更多。
