## Q
面试追问：为什么 C++ 比其他编译型语言（Rust、Go）也快或相当？编译本身决定速度吗？

## A
编译本身不决定速度，决定速度的是**运行期还剩多少工作**和**你能控制多少**。

| | C++ | Rust | Go | Java (HotSpot) |
|---|---|---|---|---|
| 编译 / GC | AOT / 无 | AOT / 无 | AOT / 有（并发） | JIT / 有 |
| 默认边界检查 | 无（`[]`） | 有（可优化消除） | 有 | 有（可被 JIT 消除） |
| 值类型/内联嵌套结构 | 有 | 有 | 有 | 无（目前只有基本类型） |
| 泛型 | 模板单态化 | 单态化 | 单态化+字典 | 擦除 + 装箱 |

- C++ ≈ Rust：同样无运行期开销，同后端 LLVM，Rust 的安全检查多在编译期。
- 对 Go 的优势：无 GC 和更强的优化器（Go 编译快优先）。
- 对 Java 的优势：布局和确定性。
