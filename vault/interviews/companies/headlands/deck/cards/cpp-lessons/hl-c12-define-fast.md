## Q
回答「C++ 为什么快」之前，「快」要先拆成哪三层含义？C++ 的优势主要体现在哪？

## A
- **吞吐**（throughput）：单位时间做多少事。
- **延迟**（latency）：一件事多久，尤其是**尾延迟**（p99、p99.9、最坏）。交易系统关心后者。
- **可预测性**：同样的输入每次耗时是否一样。

C++ 的优势主要体现在**尾延迟、可预测性和对内存布局的控制**；稳态吞吐上，热点代码经 JIT 的 Java 可以接近。要给出**机制**而不是口号。
