## Q
Java 只有一种"引用"，C++ 用哪三种东西承担这个角色？Java 方法参数传递的到底是什么？

## A
C++ 有三种：**值 `T`**（对象本身）、**引用 `T&`**（已有对象的别名）、**指针 `T*`**（存放地址的变量）。

Java 对照：
- 对象变量都是引用，可以为 `null`，可以重新指向别的对象。
- 方法参数按值传递**引用的拷贝**：方法里能改对象内容，但不能让调用者的变量指向别处。
- `final` 只表示**变量**不能重新赋值，不保证对象内容不变；而 C++ 的 `const` 能用类型表达"只读"。
