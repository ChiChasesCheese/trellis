## Q
比较四种 IPC：匿名管道 `pipe`、Unix 域套接字 / `socketpair`、TCP/UDP 套接字、共享内存 `shm_open`+`mmap`。数据怎么走、优缺点是什么？

## A
| 方式 | 数据怎么走 | 优点 / 缺点 |
|---|---|---|
| 匿名管道 | 内核缓冲区，字节流，单向 | 简单，父子进程，shell 里的管道符就是它；只能有亲缘关系，单向 |
| Unix 域套接字 / `socketpair` | 内核缓冲区，双向 | 双向、可传文件描述符、有流 / 报文模式；同机，有系统调用和拷贝 |
| TCP/UDP 套接字 | 经网络栈 | 跨机器，标准；最慢，回环也要走协议栈 |
| 共享内存 | 两个进程映射同一物理页 | **最快**，无系统调用、无拷贝；同步全靠自己，布局有限制（不能放指针） |
