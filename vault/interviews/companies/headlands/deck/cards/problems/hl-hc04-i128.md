## Q
用两个 `long`（`hi`、`lo`）实现 128 位累加器：`plus` 和 `minus` 怎么写？为什么 128 位一定够？

## A
`hi` 是高 64 位（有符号），`lo` 是低 64 位（**当无符号数看**）。
```java
I128 plus(long x) {
    long l = lo + x;
    long carry = Long.compareUnsigned(l, lo) < 0 ? 1 : 0;
    return new I128(hi + (x >> 63) + carry, l);
}
I128 minus(long x) {
    long l = lo - x;
    long borrow = Long.compareUnsigned(lo, x) < 0 ? 1 : 0;
    return new I128(hi - (x >> 63) - borrow, l);
}
```
- `lo + x` 绕回说明向高位进了 1：按无符号比较 `l < lo` 就是进位；
- `x >> 63`（算术右移）：`x` 非负得 0，负得 −1，即 `x` 扩展成 128 位时的高 64 位；
- 不要用 `plus(-x)` 实现 `minus`：`x == Long.MIN_VALUE` 时 `-x` 还是它自己（溢出），错；
- 演示 `MAX + MAX + MAX`：第三次 `lo` 绕回成 2⁶³−3，`carry = 1`，`hi = 1`，结果 `1·2⁶⁴ + (2⁶³−3) = 3·(2⁶³−1)`。

**够用**：n 个 `long` 之和绝对值 ≤ n·2⁶³；队列最多 2³¹ 个元素，和 < 2⁹⁴ < 2¹²⁷，128 位有符号数永远放得下。C++ 用 `__int128`（元素个数 < 2⁶⁴ 就够）。想要任意多就 `BigInteger`，代价是每次分配。

快路径判断：`hi == (lo >> 63)` 表示 128 位值能装进一个 `long`。
