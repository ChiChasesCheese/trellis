## Q
把秒数格式化成 `hh:mm:ss`（小时至少两位、不回绕）怎么写？分钟最容易漏掉什么？

## A
```java
static String hhmmss(long s) {
    return "%02d:%02d:%02d".formatted(s / 3600, s / 60 % 60, s % 60);
}
```
`/` 在整数间是整除，`%` 是取余；`%02d` 表示整数至少两位、不够补 0。小时**不** `% 24`（`360000` 秒 → `100:00:00`）。

最易漏的是**分钟要 `% 60`**：`s / 60` 是总分钟数，其中已算进小时的部分要去掉。漏掉的话 7200 秒会输出 `02:120:00`，这是最容易被边界用例抓到的错。

验算：7265 秒 → 小时 2、分钟 `121 % 60 = 1`、秒 5 → `02:01:05`；3599 → `00:59:59`；3600 → `01:00:00`。

平均值 = 总秒数 / job 数，整数除法**截断**：35 s / 2 = 17.5 → `00:00:17`。
