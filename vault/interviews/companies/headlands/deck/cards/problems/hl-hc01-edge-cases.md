## Q
买卖股票题的隐藏测试最常打哪些边界和 bug？

## A
- 空数组、1 天、全递减、全相等、单价 0；
- 最低点在最高点**之后**（`[10,9,8,1]`），误用全局最大减最小；
- `k = 0`、`k = Integer.MAX_VALUE`、`1_000_000_000`、`k = n/2` 临界（`new long[k+1]` 直接 OOM）；
- 手续费 ≥ 任何价差（一笔都不做）、手续费 == 价差（净利润 0 也不做）；
- 冷却下 `[1,2,1,2]`（不能第 1 天卖、第 2 天买）；`[1,2,3,0,2]` 读了今天已更新的 free 得 4 而非 3；
- 用 `Long.MIN_VALUE` 当哨兵再减价格 → 下溢变成巨大正数；
- 利润用 `int` 累加溢出；价格 0 与 `MAX_PRICE`；
- `plan` 回溯：先 `j--` 再读决策位；终点没比较 `cool` 和 `free`；冷却时多记或漏记卖出日；买入日必须 < 卖出日、交易不重叠、冷却间隔；
- `replay` 对非法方案不报错（重叠 / 冷却期买入 / 超过 k 笔 / 同一天两个动作 / 日期越界）。
- 手续费买入卖出各扣一次（题面每笔只扣一次）；平局也做交易产生零利润废交易。
