## Q
最多 k 笔交易（LC 188）的 DP 状态、转移、初值和答案分别是什么？为什么用「最多」而不是「恰好」？

## A
状态加下标 j（0..k）：
- `free[j]`：手里没股票、**最多**做过 j 笔时的最大现金；
- `hold[j]`：手里有一股、这一股的买入算在第 j 笔内（买前至多做过 j−1 笔）时的最大现金。

转移（j ≥ 1，价格 p）：
```
hold'[j] = max(hold[j], free[j-1] - p)   // 休息 或 今天买
free'[j] = max(free[j], hold[j] + p)     // 休息 或 今天卖
```
初值：`free[j] = 0`（0 笔也算「最多 j 笔」），`hold[j] = -∞`。答案 `free[k]`。

用「最多」而非「恰好」：`free[k]` 直接是答案，不必对 j 取最大，初值全 0。

验算 k=2，`[3,3,5,0,0,3,1,4]`：第 2 天 `free[1]=max(0,-3+5)=2`；第 3 天 `hold[2]=max(-3,free[1]-0)=2`；第 7 天 `free[2]=max(5,2+4)=6`。

暴力枚举所有互不重叠区间是 C(n,2k)，n=1000、k=10 就天文数字，所以必须 DP；暴力只留 n≤10 给 DP 对拍。
