## Q
AND、OR、XOR、NOT 各自的作用是什么？用掩码（mask）怎样做第 b 位的置 1、清 0、翻转、测试？

## A
逐位独立运算：`&` 都是 1 才是 1（用来**关掉**不想要的位）；`|` 有一个 1 就是 1（**打开**）；`^` 不同才是 1（**翻转**）；`~` 0 变 1、1 变 0（`~0 == 0xFFFFFFFF == -1`）。

掩码 `1 << b` 选中第 b 位（0 = 最低位）：
| 操作 | 公式 | 原因 |
|---|---|---|
| SET 置 1 | `reg \| (1 << b)` | OR 1 一定是 1，其他位 OR 0 不变 |
| CLEAR 清 0 | `reg & ~(1 << b)` | `~(1<<b)` 只有第 b 位是 0 |
| TOGGLE 翻转 | `reg ^ (1 << b)` | XOR 1 翻转，XOR 0 不变 |
| 测试 | `(reg >>> b) & 1` | 把第 b 位挪到最低位再 AND 1 |

例：`reg = 1011 0110`，b=3：SET → `1011 1110`；CLEAR → `1011 0110`（本来就是 0）；TOGGLE → `1011 1110`。

坑：`1 << 31` 在 `int` 里是负数，但位模式正是「只有最高位」，当掩码正确；`(1 << b)` 当 `long` 用时先溢出成 `int`，要 `1L << b`；位号必须 0..31，`1 << 32` 在 Java 里等于 `1`，位号 32 与 −1 要在入口（record 紧凑构造器）拒绝。

判断 2 的幂：`x != 0 && (x & (x - 1)) == 0`（`x & (x-1)` 清掉最低位的 1），或 `Integer.bitCount(x) == 1`；`0x80000000` 也为 true。
