## Q
Java 的 `<<`、`>>`、`>>>` 有什么区别？移位位数 ≥ 32 时 Java 和 C++ 各是什么行为，硬件语义怎么实现？

## A
8 位例，`x = 1011 0110 (0xB6)`：
- `x << 2` = `1101 1000`：低位补 0，高位挪出的丢掉；
- `x >>> 2` = `0010 1101`：**逻辑右移**，高位补 0，寄存器该用这个；
- `x >> 2` = `1110 1101`：**算术右移**，高位补原来的最高位（符号位）。`0xF0000000 >> 4 = 0xFF000000`，不是要的 `0x0F000000`。

**Java 特殊规则**：对 `int`，移位位数**只取低 5 位**（`n & 31`），所以 `x << 32 == x`，`x << 33 == x << 1`，`x >>> 32 == x`。**C/C++**：位数 ≥ 位宽是**未定义行为**（UB），位数为负也是 UB。题目的硬件语义是 `n ≥ 32` 时 32 个 bit 全挤出去，结果 0。两边都不等于 0，要自己处理：

```java
case Shl(var n) -> n >= 32 ? 0 : reg << n;
case Shr(var n) -> n >= 32 ? 0 : reg >>> n;
```
或 clamp 到 `[0,32]` 后用 `long` 移位免分支：`(int)(Integer.toUnsignedLong(reg) << a)`，`long` 移位位数最多 63，`<< 32` 真移 32 位，`(int)` 强转只留低 32 位得 0。

C++ 里 `uint8_t/uint16_t` 上的 `~x`、`x << n` 会整型提升成 `int`：`uint16_t x = 0x00FF; ~x == 0xFF00` 为 false（`~x` 是 `0xFFFFFF00`）。

C++ 补充：无符号加减乘溢出定义良好（按 2³² 回绕），有符号溢出才是 UB。
