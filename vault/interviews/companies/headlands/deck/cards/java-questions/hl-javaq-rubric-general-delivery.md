## Q
Java 语言深度类技术问题里，"Java 对 C++""追问""时间"三方面，强、一般、弱的回答分别什么样？

## A
- **Java ↔ C++**：强 = 能说清"C++ 里对应的是什么、Java 为什么不同、代价在哪"；一般 = 只讲 Java，不接对方的话题；弱 = 贬低一方，或"Java 一样快"式的一刀切。
- **追问**：强 = 往下一层走（从 GC 到 safepoint 到 OS），不会被一个"为什么"问倒；一般 = 能答第一层追问；弱 = 第二个"为什么"就重复第一层或沉默。
- **时间**：强 = 60 秒内说完要点，然后问"要我展开 X 还是 Y？"；一般 = 90–120 秒；弱 = 超过 2 分钟仍在铺垫。
