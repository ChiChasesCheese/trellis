## Q
Java 语言深度类技术问题，面试官在"结构、量化、诚实"三方面怎样区分强、一般、弱的回答？

## A
- **结构**：强 = 先一句话结论，再机制（为什么），再一个具体数字或例子，最后说边界 / 代价（"什么时候不成立"）；一般 = 有结论和机制，但没有例子或边界；弱 = 先讲背景、绕半天才说结论，或只有术语列表。
- **量化**：强 = 给数量级（"16 字节头""亚毫秒""慢约 10 倍"），并说明是自己测的还是常识；一般 = 只说"更快""更省"；弱 = 只说"很快""很慢"，或说错数量级。
- **诚实**：强 = 分开"我测过""我记得但没验证""我不确定"，不确定时说怎么验证；一般 = 偶尔含糊；弱 = 编造细节、把不确定的当事实，被追问时硬撑。
- 面试官看的是性能直觉、对系统细节的好奇心，以及是否诚实。
