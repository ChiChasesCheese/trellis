## Q
一段程序"慢"通常来自哪四类原因？C++ 对这四类分别怎么处理？

## A
四类原因：
1. **执行指令太多**：解释执行对比编译成机器码；有没有内联、有没有多余检查。
2. **等内存**：缓存未命中（cache miss），对象散落在堆里要追指针。
3. **做了不必要的工作**：分配对象、装箱、虚调用、加锁。
4. **被打断**：GC 暂停、线程切换、系统调用。

C++ 的答案：第 1、3 类交给编译器在**编译期**（AOT，ahead-of-time，提前编译）解决——模板按类型展开并内联（"零开销抽象"）；第 2、4 类由程序员手工控制：对象放栈上、成员内联在父对象里让数据连续，没有 GC，析构确定，数组下标默认不检查，还有未定义行为（UB）让编译器敢激进优化。
