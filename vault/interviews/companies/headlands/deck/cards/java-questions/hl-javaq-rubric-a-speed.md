## Q
回答"Java 为什么快 / 和 C++ 比 / 预热"这类速度与延迟问题，强、一般、弱的答案各有什么特征？

## A
- **强**：稳态靠 JIT + 运行时 profile（内联、去虚化、逃逸分析），差距在**尾部**——预热、去优化、GC / safepoint、对象头与指针；能给一个自己测的数（逃逸分析开 / 关的分配量；GC 最大停顿对比）；被问"为什么还用 C++"时承认内存布局与内核旁路的差距，并说出缓解手段（零分配、原始数组、堆外、ZGC、绑核）；预热题里说出"用真实多样的流量预热，否则触发去优化"。
- **一般**：知道 JIT 把热点编译成机器码、GC 有暂停、C++ 没有；说不出具体机制或数字；预热只会说"先跑一会"。
- **弱**：说"Java 是解释型所以慢"；"JVM 慢是因为 GC"没有后文；或相反"Java 和 C++ 一样快"；不知道 C1 / C2。
