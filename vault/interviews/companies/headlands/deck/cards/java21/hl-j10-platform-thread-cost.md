## Q
Java 的平台线程（platform thread）为什么贵？栈、创建、切换、数量上限各是什么量级？

## A
**平台线程 = 一个 OS 线程**，所以贵（64 位 Linux/macOS，量级不是保证）：

| 代价 | 量级 |
|---|---|
| 栈 | 默认约 **1 MB** 虚拟地址空间预留（`-Xss`），用到才占物理内存，但每个线程都要在内核登记 |
| 创建/销毁 | 几十到上百微秒，是系统调用 |
| 上下文切换 | 微秒级，线程越多越频繁 |
| 数量上限 | 几千到几万个，再多调度器和内存都撑不住 |

因此「一个请求一个线程」（thread-per-request）写起来最自然（从上往下写，遇阻塞就阻塞，栈清楚），跑起来却最贵。
