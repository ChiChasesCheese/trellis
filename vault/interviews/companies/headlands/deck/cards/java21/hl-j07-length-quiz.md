## Q
下面这个文本块的精确字符串是什么？如果把结束符 `"""` 紧跟在 `b` 后面（`  b"""`）又是什么？

```java
String s = """
        a
          b
        """;
```

## A
- 原写法：**`"a\n  b\n"`**。内容缩进 8，`b` 行 10，结束符 8；最小缩进 8，去掉后 `a` 零缩进、`b` 留 2 个空格；结束符单独一行 → 末尾换行。
- 结束符紧跟 `b`：**`"a\n  b"`**，没有结尾换行。
