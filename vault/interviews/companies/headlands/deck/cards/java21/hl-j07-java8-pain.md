## Q
Java 8 的字符串字面量为什么不适合写多行内容（JSON、SQL、测试样例）？有哪三个问题？

## A
字符串字面量**不能跨行**，多行内容只能一段段拼，每段末尾补 `\n`，双引号逐个转义。三个问题：

1. **可读性差**：想写 JSON，看到的却是引号、反斜杠、加号，漏一个 `\` 就是编译错误；
2. **复制粘贴困难**：JSON / SQL / 测试样例从别处复制进来要逐行改写，反过来也一样；
3. **悄悄出错**：拼接时漏空格，编译器看不出来。

测试里的样例输入 / 期望输出几乎全是多行文本，旧写法没法维护。文本块（`"""`）Java 15 正式（13、14 为预览）。
