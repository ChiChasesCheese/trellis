## Q
价值矩阵里带 `*` 的六处保留分别是什么（S6、S11、M1、R1、S7 两处）？

## A
- **S6 → 性能（价值 5）**：上线前的容量推理，不是剖析运行中的系统。
- **S11 → 分布式存储（价值 6）**：只做过消费 / sink 侧，从没运营过集群。
- **M1 → code review（价值 14）**：没有评审记录，只有契约和架构层面的评审。
- **R1 → Linux / 网络（价值 7）**：只是简历上的一行（自托管 CI、8-GPU 服务器），没有写下细节。
- **S7 → 各层都懂（价值 8）**：个人仓库，不是团队工具链。
- **S7 → 自主性（价值 3）**：同上，个人仓库。

用这些故事时，**先把保留说出来**，再讲内容。
