## Q
自我介绍之后的追问：哪一部分是你做的？为什么强调正确性与测试？被打断问 Java 迁移怎么办？
Which part was yours? Why correctness and testing?

## A
- **Which part was yours?** 从 Amex 管线的**拓扑**往后的所有部分；在 S3 事故里，**止血补丁**是同事的。
- **Why correctness and testing?** 我的测试曾经断言的是**路由而不是手续费**；现在我断言**输出**，并加了在**数据缺失**时会响的检查。
- **被追问 Java 迁移**：【待补：迁移里最难的一个行为差异】——补完前不要口播。
