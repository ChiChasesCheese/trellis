## Q
"一次真实的性能排查"是背景面里最大的单项缺口。要补的故事该包含哪六块？候选素材有哪些？

## A
六块：**现象**（什么慢了、一个数字、谁发现的）→ **怎么测**（你真用过的工具告诉了你什么）→ **假设**（怀疑过哪几个原因、为什么排除其他）→ **根因**（哪一层：算法 / 数据布局 / IO / 锁 / 网络 / GC / 配置）→ **修复与对比**（改了什么、前后各多少、有无回归测试）→ **下一步**（还要更快先看哪里）。开头的钩子要带一个数字。

候选素材（只填真的）：读 Snowflake / PostgreSQL 的 query profile 或 `EXPLAIN` 并改写查询；窗口化 `ON` 前后的 partitions scanned 对比；个人平台里某次面板/因子计算从太慢变可用；实习期 Spark 作业或 Kafka 消费者吞吐调优。
