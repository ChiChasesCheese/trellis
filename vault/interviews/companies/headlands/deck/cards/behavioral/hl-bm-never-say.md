## Q
Headlands 背景面试中，有哪些话"绝对不说"？

## A
- 夸大个人角色：**top committer / 615 commits**、**唯一 owner**、**spearheaded**。
- 绝对化的结果：**no bugs**、**零回归**、**两周**、**merchant by merchant**。
- 不实的动作：**I backfilled**；**the only resource missing it**；**parsing UDTFs**（解析其实在 procedure 的 `SUBSTRING` 里）。
- **点名**同事、商户、实习生。
- 任何"**快了 N 倍**"、延迟/吞吐数字；**美元量级**。
- **编造** code review 记录，或编造任何【待补：…】里的数字。

这些要么没有证据，要么会被一句追问击穿。
