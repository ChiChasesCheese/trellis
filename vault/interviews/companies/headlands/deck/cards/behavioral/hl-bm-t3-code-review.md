## Q
被问 code review 经历、而你没有真实评审记录时，模板要补哪四格？没有时该说什么？

## A
四格：
1. **对象**：你评审过谁的代码（说角色，不点名）？
2. **拦下了什么**：一个具体问题。
3. **对方反应**：怎么回应、最后怎么定？
4. **你被评审**：别人评审你、你因此改了设计的例子。

**没有就不讲**，不编。可以说的一句真话：**"I read every diff, including the AI's, in money code."**（涉及钱的代码，每个 diff 包括 AI 写的我都读。）
