## Q
"Java 强不强"之后的追问：你怎么知道 Java 重写是对的？JIT 和 GC 呢？
How do you know the Java rewrite is right? JIT and GC?

## A
- **How do you know the Java rewrite is right?** **一致性测试（parity tests）**：同样的输入，比对旧实现和新实现的输出。
- **JIT and GC?** 懂到 "**when they matter**" 的程度，我在练 Java 21；再往下 "I'd measure or read the docs."
