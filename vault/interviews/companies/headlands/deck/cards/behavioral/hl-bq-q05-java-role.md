## Q
你为什么选 Java 岗，而不是 C++ 或研究岗？（≤ 30 秒）
Why the Java role rather than C++ or research?

## A
- 我的**生产强项是 Java 和 SQL**，而这个岗位是**平台、存储、监控**。
- **热路径（hot path）是 C++**；我想**挣得**那一层的深度，而不是声称已有。
- 我对语言**保持开放**：面试官可能选 C++，我两个都在准备。
