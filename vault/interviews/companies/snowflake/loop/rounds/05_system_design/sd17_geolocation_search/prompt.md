# Geolocation Search Service（地理位置搜索服务）

我们要给内部的几个产品提供一个"找附近"的能力：数据平台团队要在地图上显示离某个坐标最近的数据中心和合作伙伴仓库，销售工具要搜"这个客户 50 公里内有哪些已签约客户"，还有一个面向外部开发者的 API 要支持"给我某个多边形区域里的所有点"。点的总量大约五亿个，每个点有经纬度和一些属性（类型、租户、状态），其中移动类的点（比如现场工程师）每几秒更新一次位置，而仓库和客户地址几乎不变。读请求峰值每秒几万次，要求 p99 在一百毫秒以内，结果要能按距离排序、按属性过滤、分页；写请求里移动点的更新频率很高，但允许几秒钟的延迟才能被搜到。不同租户只能搜到自己的点。请设计这个系统。
