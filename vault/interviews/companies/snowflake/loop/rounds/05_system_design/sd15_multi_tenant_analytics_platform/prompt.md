# Multi-Tenant Interactive Analytics Platform（多租户交互式分析平台）

我们要给很多租户（客户）提供一个交互式分析平台：每个租户持续往自己的数据集里摄取数据，同时
用 BI 工具跑即席 SQL 查询、刷新 dashboard，期望亚秒到几秒级的响应。租户规模差异极大——有的
租户数据量很小、查询很轻，有的租户数据量巨大、经常跑重查询；**一个租户的重负载不能拖慢另一个
租户的 dashboard**（noisy neighbor 问题）。计算资源要能随每个租户的负载形状弹性伸缩——同一时刻
"很多并发的小查询"和"少量的大批量查询"这两种形状都要能扛住，闲的时候不能一直占着资源烧钱。
摄取是持续的，不能阻塞、也不能被同一份数据上正在跑的交互查询阻塞。重复的相同查询（dashboard
自动刷新）不该每次都重新算一遍。即使摄取和查询并发进行，单次查询看到的必须是**一份自洽的数据
快照**，不能看到"摄取写了一半"的中间状态。每个租户按实际消耗的计算资源计费，要求精确。请设计
这个系统。
