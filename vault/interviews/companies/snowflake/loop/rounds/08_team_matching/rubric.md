# Team Matching 轮 —— 自评表

> 依据：`loop/LOOP_GUIDE.md` §9；一手风险：技术全过仍可能因 headcount 被搁置（Blind z4cg3oq0）。这轮没有分数，只有 HM 的一句话结论。自评标准就是：**HM 会后能否用一句话向 recruiter 推荐你。**

## 用法

`python3 loop/mock.py bq team -n 3 -m 3`；每题 3 分钟；按 4 维打分。

### 1. 偏好具体度
| 分数 | 长什么样 |
|---|---|
| 1 | "都可以" |
| 2 | 一个方向，无理由 |
| 3 | 三个方向各一句理由，且与团队 scope 对上 |
| 4 | 3 + 说出该团队公开的一个真实问题（Execution Anchor 1% 路径 / Adaptive Refresh 信号 / AI 计量归因） |

### 2. 六个月贡献画面
| 分数 | 长什么样 |
|---|---|
| 1 | 泛泛"快速上手" |
| 2 | 提到学习路径 |
| 3 | 第一个月读入口 + 跑测试 + 一个小上线；三个月内 own 一个组件 |
| 4 | 3 + 与自己做过的事一一映射 |

### 3. 边界诚实（on-call / RTO / 不想做的）
| 分数 | 长什么样 |
|---|---|
| 1 | 全部"没问题" |
| 2 | 含糊 |
| 3 | 直接回答 + 问执行口径 |
| 4 | 3 + 用真实 on-call 经历证明 |

### 4. 反问与 headcount
| 分数 | 长什么样 |
|---|---|
| 1 | 没问 |
| 2 | 问了泛泛的 |
| 3 | 问了 pager / RTO / 第一个项目 |
| 4 | 3 + 问了 headcount 与时间线 |
