# HM / Behavioral 轮 —— 自评表

> 依据：`loop/LOOP_GUIDE.md` §8；官方价值观原文（`../../../01-company-brief.md` §3）；面试官逐题记笔记（聚合站描述）。通过线：onsite 每轮都要 Hire（Blind 2025-10）。

## 用法

`python3 loop/mock.py bq hm -n 5 -m 3`，每题 3 分钟；讲完立刻按 6 维打分；任一 ≤ 2 分重讲；5 题打完回 `stories.md` 看价值观覆盖。

## 评分维度

### 1. 结构与时长
| 分数 | 长什么样 |
|---|---|
| 1 | 2 分钟还没到"我做了什么" |
| 2 | 有结构但啰嗦 |
| 3 | 一句话 → 动作 → 数字 → 改变，90 s |
| 4 | 3 + 被打断后能从任意一段续接 |

### 2. 我的动作（ownership 证据）
| 分数 | 长什么样 |
|---|---|
| 1 | "我们" |
| 2 | 有"我"但动作模糊 |
| 3 | "I forwarded the page to myself / I wrote the ADR / I froze the CI work" |
| 4 | 3 + 动作与价值观原文关键词对上（own issues / speak up / commit fully） |

### 3. 数字与验证
| 分数 | 长什么样 |
|---|---|
| 1 | 无数字 |
| 2 | 数字模糊 |
| 3 | 已确认数字 + 来源 |
| 4 | 3 + 反事实（"不这么做会怎样"） |

### 4. 反思（改了什么流程 / 学到什么）
| 分数 | 长什么样 |
|---|---|
| 1 | 没有 |
| 2 | "学到了沟通很重要" |
| 3 | 具体流程改动（non-null assertion 进 quality check） |
| 4 | 3 + 后来验证了改动有效 |

### 5. 对他人的描述（egoless）
| 分数 | 长什么样 |
|---|---|
| 1 | 对方不讲理 / 笨 |
| 2 | 中性但没有对方视角 |
| 3 | 说出对方合理的顾虑 |
| 4 | 3 + 最后怎么一起决定、自己怎么 commit |

### 6. 价值观覆盖（5 题一组检查）
| 分数 | 长什么样 |
|---|---|
| 1 | 5 题用同一个故事 |
| 2 | 两个故事 |
| 3 | ≥ 3 个故事，覆盖 Own It / Get It Done / Integrity Always |
| 4 | 3 + 至少一题落在其余五条价值观 |
