## 挂点 → 对策

| 挂点 | 对策 |
|---|---|
| DP 状态想半天 | 先问"最后一步做了什么选择"，状态 = 做选择需要知道的最少信息 |
| 生成题（n ≤ 6·10⁶）排序超时 | 能不排就不排；必须排就用内置 sort，别手写 |
| 取模忘了 | 每次加法后 `% MOD`，结果前再取一次 |
| 递归深度（树、DFS）| 迭代 + 显式栈；Python 默认递归限制 1000 |
| 历史上限 Java/C++ | 开考前看语言列表；Python 不可用就用 Java |
