# 卡片 · 题型识别（一眼信号 → 方向 → 本 kit 哪题）

> 碎片时间读。格式 `| Q | A | 哪些题 |`。每条先说"看到什么字眼"，再说"第一步做什么"。细节在 `../00-essentials/`，题解在 `../30-articles/`。

## 图与树

| Q | A | 哪些题 |
|---|---|---|
| 题面有"继承""祖先""角色授予角色""权限往下传"？ | DAG + **拓扑序一次传播**：父先结算、子读父的完整集合。别对每个节点往上爬到根 | pc01 |
| "deny 覆盖 allow" / "本地 deny 不继承"？ | allow、deny 各跑一遍传播，最后做差；"仅本地"那一侧不传播，只读自己 | pc01 P2/P3 |
| "谁拥有某权限 / 某角色下有哪些用户"？ | **反向查询 = 建倒排**：`permission → holders`，别每次查询重算 | pc01 P4 |
| 网格里"每个 X 到最近的 Y"？ | **多源 BFS**：所有 Y 同时入队，一次扩展 | pc02 |
| "最少点击 / 最短跳转"并要"输出路径"？ | BFS + parent 表；要**字典序最小**就先从终点反向 BFS 求距离，再正向每步选"距离减 1 的最小邻居" | pc04 q10 |
| "先修课 / 依赖顺序 / 启动顺序"？ | Kahn 拓扑；"最少学期 / 并行"= 按层 BFS 或关键路径 DP | q08 pc09 |
| "删最少叶子 / 剪子树使深度 ≤ k / 至多 k 次挂到根下"？ | 先算深度；删除类贪心自底向上；"k 次操作能否让高度 ≤ H"→ **二分高度** | q03 |
| "O(1) 空间中序遍历"？ | Morris：用右空指针线索化，回来时拆掉 | q07 |
| "反复做某个函数会不会回到起点 / 进环"？ | 隐式链表 → **Floyd 快慢指针** | pc06 |
| "只能发消息、等孩子都回复再上报"？ | 全局 FIFO 模拟；每节点一个 `pending` 计数 | pc10 |

## DP 与计数

| Q | A | 哪些题 |
|---|---|---|
| "长度 n、连续 X 不超过 k 的串有多少"？ | `dp[位置][当前游程长度]`，取模 | q02 |
| "不重叠选活动 / 订单 / 通话，价值最大"？ | 排序 + 二分找前驱 + DP（加权区间调度）；"至多 k 个"再加一维 | q04 pc05 |
| "付费机忙时可选免费机"这类二选一调度？ | 0/1 背包变形：付费机的"占用时间"换免费机能处理的个数 | q01 |

## 类设计与流

| Q | A | 哪些题 |
|---|---|---|
| "add(id, priority, ts) / execute() 取最高优先级"？ | 堆 + 完整 tie-break 键 `(-priority, ts, id)`；重复 ID 用**懒删除**（执行时跳过已失效） | od01 |
| "begin / commit / rollback 可以嵌套"？ | 撤销日志栈：每层只记本层**首次触碰**的旧值；嵌套 commit 合并到父层 | od03 |
| "最近 m 条 / 最近 W 秒内"？ | deque 做窗口 + 计数哈希；出窗时减计数 | pc03 od04 |
| "多条限流规则都要满足"？ | 找所有规则同时有余量的**最早时刻**，再一次性占位 | od04 |
| "O(1) get/put，按最久未用淘汰"？ | 哈希 + 双向链表；TTL 过期优先于 LRU 淘汰 | od08 |
| "cron 表达式 / pause / resume / 多实例不重复触发"？ | tick 循环 + 存储层条件更新（CAS）/ lease | od05 sd02 |
| "消费后要 ack / 超时重投"？ | visibility timeout；崩溃后未 ack 的重投、已 ack 的永不 | od09 sd05 |
| "mkdir / ls / 追加写文件"？ | trie（路径分段）；`ls` 文件返回自己，目录返回排序后的孩子 | od02 |
| "哪些表/列在 t 之后没被访问过"？ | 每个名字只存最后访问时间；别建"插入时排序"的索引（O(n²)） | od06 |

## 看到这些字眼先问一句

- "at most k"：k 能不能截到 `min(k, n)`？
- "inclusive end"：相邻区间算不算冲突？
- "tie"：tie-break 键写全了吗？
- "concurrent / thread-safe"：check-then-act 哪两步必须原子？
- "large"：n 的上限，决定能不能二重循环。
