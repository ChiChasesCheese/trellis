# q05 · Paint the Ceiling — generated sequence, counting pairs

**Type:** bespoke OA · **Stage:** OA (HackerRank) · **Skill:** S02（生成序列 + 双指针/二分计数）

## 背景
给一个递推公式生成 `n` 个"边长"（side length），再统计有多少对边长的乘积（面积）不超过给
定阈值 `a`——题面把它包装成"给天花板贴瓷砖，每块瓷砖是两条边长的矩形，面积不能超过预算"。
函数签名：`paintTheCeiling(s0, n, k, b, m, a) -> long`。

> FastPrep 原题描述：recurrence `s_i = ((k*s_{i-1}+b) mod m) + 1 + s_{i-1}` generates n side
> lengths; count pairs whose product (area) <= a.

## 输入格式（stdin，用于 `main`）
```
PART <1|2>
s0 n k b m a
```
六个整数在同一行，空格分隔。`n >= 1`（题目定义至少生成一条边），假设 `s0 >= 1`（边长是
物理量）。输出：单个整数（末尾换行）。

## 规则

### 生成规则（严格按官方样例核对，不能出错）
`sides[1] = s0`（种子本身就是第一条边，不做变换）；对 `i = 2..n`：
```
sides[i] = ((k * sides[i-1] + b) mod m) + 1 + sides[i-1]
```
一共生成恰好 `n` 条边（概念上 1-indexed；代码里用 0-indexed 数组）。

### 计数规则（同样要精确对照官方样例，这里最容易出错）
统计**所有有序对** `(i, j)`，其中 `i, j` **各自独立**取遍 `1..n`（**允许重复**，也就是
`i == j` 是合法的一对，"同一条边既当长又当宽"要算进去），满足：
```
sides[i] * sides[j] <= a
```

### Part 1
`part1(s0, n, k, b, m, a) -> int` — 正确即可，可以是简单的 `O(n^2)`（生成后暴力枚举所有
有序对计数）。

### Part 2
`part2(s0, n, k, b, m, a) -> int` — 必须在 `n` 达到 `1e6` 时仍满足性能预算：`O(n)` 生成
边长；排序；对每条边用双指针或 `bisect` 在整体 `O(n log n)` 内计数满足
`sides[i]*sides[j] <= a` 的数量。**注意计数对象是有序对且允许重复**：排序后，对每个
`sides[i]`（遍历整个多重集合，下标不受限制），统计有多少个 `sides[j] <= a // sides[i]`
（`sides[i]` 不可能为 0——见下方假设——所以整除安全）。可以对每个不同取值做一次
`bisect_right`，也可以用双指针一次扫描（排序后，随着下标 `i` 增大，阈值单调不增，因此计数
也单调不增，允许真正的 O(n) 双指针）。

**关于 `s0` 的最小值假设**：从递推公式看，`sides[i] = (mod 项，范围 [0, m-1]) + 1 +
sides[i-1] >= 1 + sides[i-1]`，也就是说只要 `sides[1] = s0 >= 1`，后续所有边长都严格递增
且恒为正整数，绝不会出现 `0`。本题假设 `s0 >= 1`（边长是物理量，符合题目场景），因此整除
`a // sides[i]` 永远安全。

## Worked Examples

**验证过的官方样例**（必须精确匹配）：
```
s0=2, n=3, k=3, b=3, m=2, a=15
```
生成过程：`sides[1]=2`；`sides[2] = ((3*2+3) mod 2)+1+2 = ((9 mod 2)+1+2) = (1+1+2) = 4`；
`sides[3] = ((3*4+3) mod 2)+1+4 = ((15 mod 2)+1+4) = (1+1+4) = 6` → `sides=[2,4,6]`。

统计 `{2,4,6}` 上所有 9 个有序对（允许重复）：`(2,2)=4✓ (2,4)=8✓ (2,6)=12✓ (4,2)=8✓
(4,4)=16✗ (4,6)=24✗ (6,2)=12✓ (6,4)=24✗ (6,6)=36✗` → 5 对合法 → **答案：5**。

**样例 (a)：`a` 大到覆盖所有对** → 答案 = `n^2`：
```
s0=2, n=3, k=3, b=3, m=2, a=10**9 -> 9   (sides=[2,4,6], 3*3=9 对全部满足)
```

**样例 (b)：`a=0`** → 由于所有边长 `>= 1`，乘积至少为 1，永远 `> 0` → 答案恒为 `0`：
```
s0=2, n=3, k=3, b=3, m=2, a=0 -> 0
```

## 隐藏测试边界清单
- `n=1`：唯一的一对是 `(1,1)`，检查 `sides[0]**2 <= a`
- `a=0` 或很小：由于 `sides>=1`，乘积`>=1`，`a=0` → 0 对
- `a` 很大：覆盖所有 `n^2` 对
- `m=1`：mod 恒为 0，递推简化为每步 `+1`
- `k=0`、`b=0`：递推退化，仍需正确生成
- 大规模 `n`（`1e5`~`1e6`）用于 perf 测试，参数用 `random.Random(0)` 生成
- part1 与 part2 在小规模（`n<=200`）随机参数下必须给出完全一致的结果（这是除官方样例外
  最主要的正确性防线）

## 变体
- 有的版本把条件从 `<=` 改成 `<`（严格小于），逻辑框架不变，只需把 `bisect_right` 换成
  `bisect_left`（对阈值 `a // x` 或改用浮点比较，视具体版本而定）。
- 有的版本只统计 `i < j`（无序、不重复），需要减去对角线再除以 2；本题按官方样例采用
  "有序、允许重复"的版本。

- S02：状态转移生成序列 + 排序后双指针/二分计数

- part1/part2 复杂度台阶 + 随机化交叉验证作为正确性防线
