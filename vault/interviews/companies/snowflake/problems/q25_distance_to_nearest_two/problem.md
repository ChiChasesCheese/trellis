# q25 · Distance to Nearest Two — 每个 1 到最近的 2 有多远

> OA 题（TrueInterview 同步清单 #77；本 kit 缺口补建）。Part 1 为原题（一维两遍扫描）；
> Part 2 **(reconstructed)**：二维网格版，多源 BFS 求曼哈顿距离，与 LC 542 / pc02 同族。

## 输入

### Part 1（一维）
- `arr`：只包含 `0`/`1`/`2` 的数组，`0 ≤ n`；
- 出现其他值抛 `ValueError`。

### Part 2（二维，reconstructed）
- `grid`：只包含 `0`/`1`/`2` 的矩形网格（每行长度必须一致）；
- 出现其他值或行长不一致抛 `ValueError`。

## API 契约（英文签名）

```python
def nearest_two_distances(arr: list[int]) -> list[int]
def nearest_two_distances_grid(grid: list[list[int]]) -> list[int]
```

## 规则

对每个值为 `1` 的位置，求它到最近的 `2` 的距离；数组里如果一个 `2` 都没有，所有 `1` 的
答案都是 `-1`；数组里如果没有 `1`，输出为空。

### Part 1 — 一维两遍扫描

从左到右扫一遍，记录"最近一次见到的 `2`"的位置，算出每个 `1` 到它左边最近的 `2` 的
距离；再从右到左扫一遍算到右边最近的 `2` 的距离；两遍取较小值。`O(n)`，只需要一个
"最近 2 的位置"变量，不需要额外的队列或图结构——这是 LC 542 的通用多源 BFS 技巧在一维
上的特化（一维网格里从两个方向各扫一遍，等价于多源 BFS 在一条直线上的传播）。

### Part 2 — 二维网格，多源 BFS 求曼哈顿距离 **(reconstructed)**

网格**无障碍**（`0`/`1` 格子都可以自由通过，值本身不影响可达性，只是"是不是终点/起
点"的标记）。把所有 `2` 当作 BFS 的多个起点，同时入队做一次多源 BFS；由于网格无障碍，
BFS 层数就是曼哈顿距离。这跟 LC 542 "01 Matrix"完全同构，也是 pc02"多源 BFS 到最近设
施"的直接应用。输出按行优先顺序，只对值为 `1` 的格子给出距离；网格里没有 `2` 就全部
`-1`。`O(rows × cols)`。

## Worked examples（全部由 `solution.py` 实际运行得出）

| 输入 | Part 1 / Part 2 |
|---|---|
| `[2, 0, 1, 0, 1, 0, 0, 2, 1]` | `[2, 3, 1]`（下标 2 处的 `1` 到左边 `2`(下标0)距离 2；下标4 处的 `1` 到右边 `2`(下标7)距离 3；下标8 处的 `1` 紧邻右边... 实际到下标7 的 `2` 距离 1） |
| `[1, 1, 0, 1]` | `[-1, -1, -1]`（没有 `2`） |
| `[2, 0, 0, 2]` | `[]`（没有 `1`） |
| `[2, 1, 2]` | `[1]`（两边都是 `2`，距离都是 1，取较小值仍是 1） |
| grid `[[0,1,0],[1,0,2],[0,1,0]]` | `[2, 2, 2]`（三个 `1` 到唯一的 `2` 曼哈顿距离都是 2） |
| grid `[[1,0],[0,1]]` | `[-1, -1]`（没有 `2`） |

## `main()` 命令流

```
PART 1                      PART 2

2 0 1 0 1 0 0 2 1            0 1 0
→ 2                          1 0 2
  3                          0 1 0
  1                          → 2
                               2
                               2
```

## 边界清单

- 没有 `2`：所有 `1` 输出 `-1`
- 没有 `1`：输出为空（不是输出 `0` 行数字，而是干脆没有任何一行）
- `1` 紧邻 `2`：距离 1
- `1` 两侧都有 `2`：取较小距离
- 空数组 / 空网格
- 二维网格行长不一致 → `ValueError`
- 非法值（不是 `0`/`1`/`2`）→ `ValueError`
- 性能：一维 `n = 10⁶` `< 2s`；二维 `500 × 500` 网格 `< 2s`

## 追问

1. **一维两遍扫描和二维多源 BFS 是同一个技巧吗？** 是。多源 BFS 的本质是"从所有源点
   同时开始按距离一层层扩散"；一维情况下"层"退化成"往左扩散"和"往右扩散"两个方向，
   直接用两次线性扫描代替显式的队列结构，本质等价但常数更小。
2. **如果网格有障碍（某些格子不能经过）呢？** 就不能再用"直接算曼哈顿距离"抄近路，
   必须老老实实做 BFS（本题的解法已经是标准 BFS 实现，只是因为无障碍所以 BFS 距离
   恰好等于曼哈顿距离——如果加障碍，两者会分道扬镳，纯计算曼哈顿距离的"抄近路"解法就
   不再正确，只有 BFS 版本还成立）。
3. **能不能不用 BFS，直接对每个 `1` 枚举所有 `2` 算曼哈顿距离取最小？** 可以（本题的
   暴力测试就是这么做的），复杂度 `O(rows·cols·k)`（`k` 是 `2` 的个数），网格稀疏时可
   能比 BFS 快，但最坏情况（`2` 很多）比 `O(rows·cols)` 的 BFS 差。
4. **三维网格呢？** 完全一样，只是 BFS 的邻接方向从 4 个变成 6 个，复杂度变成
   `O(x·y·z)`。
