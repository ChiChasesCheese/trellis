# Quarantine

Quarantine is the "Report phishing" backend of a multi-tenant email-security product. A customer's
employee clicks the button in their mail client; Quarantine analyses the reported message, decides whether
to pull it out of everyone's mailbox, and tells the reporter what happened. Admins can release a message
that was caught by mistake.

You have just joined the team that owns it. The repo is in `starter/` (Python 3.11+, standard library
plus pytest). `README.md` and `CONTRIBUTING.md` are the team's own docs. You have a browser VS Code with
Claude Code. Pick up the ticket you are given; you have about 35 minutes of implementation time.
