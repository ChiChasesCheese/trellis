## Q
当题目给出一堆"A / B = k"形式的等式，然后问"C / D = ?"（即经典的除法求值 / 汇率换算问题）时，为什么要建图，怎么识别这是**图上的路径乘积**问题？

## A
把每个变量看成图上的一个节点，"A / B = k"建一条从 A 到 B、权重为 k 的有向边，同时建一条从 B 到 A、权重为 `1/k` 的反向边。查询 "C / D" 就等价于从 C 出发做 DFS/BFS 找到 D，把路径上所有边权**相乘**即为答案。

这样建图之后，任意两个连通的变量之间的比值都能通过一条路径的权重乘积算出来，本质上是把传递关系（A/B、B/C 能推出 A/C）转成了图的可达性问题。

**最易错处**：
1. 查询中出现的变量如果**从未在等式里出现过**，要返回 -1（不存在），不能当成 0 或抛异常；
2. 反向边如果权重取值不当会导致**除零**；
3. 自己除以自己（如 A/A）如果 A 存在于图中，应该直接返回 `1.0`，即使没有显式给出这条等式。
