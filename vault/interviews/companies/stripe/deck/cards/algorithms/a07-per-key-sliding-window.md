## Q
当题目要求"同一个 key（用户/IP/设备）在时间窗口内触发了多少次事件，达到阈值就报警"时，为什么该用**每 key 一个按时间排序的滑动窗口**，怎么识别？

## A
给每个 key 维护一个 `deque`，事件按时间顺序依次到达时追加到队尾；每来一个新事件，就从队首开始弹出所有"超出窗口时间"的过期事件，
弹完之后 deque 的长度就是当前窗口内该 key 的事件数。用 deque 是因为过期事件总是从队首弹出、新事件总是从队尾加入，
保证均摊 O(1) 而不需要每次重新扫描整个历史。

**最易错处**：
1. 判断条件到底是"窗口内**≥3 次**就算触发"（每次满足都要算一次报警，还是只报警一次），还是"恰好第 3 次触发时报警一次"，两者代码逻辑差别很大；
2. 同一分钟/同一时刻可能出现多条事件，时间戳相同时窗口边界判断（`<=` 还是 `<`）容易被忽略。
