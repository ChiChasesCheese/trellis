# q39 · 服务器运行日志（最佳摘除时刻 · 聚合日志 · k 次摘除）

> `problems/q39_server_uptime_log/` · 4 个 part
> **主题：q08 的孪生题（`0/1` 代替 `Y/N`），但 Part 4 升级成了 DP。**

## 一句话题意

`1` = 该小时在线（UP），`0` = 宕机（DOWN）。
`remove_at = x` 表示"在第 `x+1` 小时之前把它摘出网络"。
罚分 = 在网期间的 DOWN 小时数 + 摘除之后的 UP 小时数。求罚分最小的摘除时刻。

## 核心考点

`S02` 解析 · **`S05` off-by-one 纪律** · `S08` 平手取小 · **`S10` token 状态机** ·
`S18` 畸形输入 · `S19` 增量 · `S20` 自测（题面要求写测试）

## 解题思路

### Part 1–2（与 q08 完全同构）

```
penalty(log, x) = (1..x 里 '1' 的个数) + (x+1..n 里 '0' 的个数)
```

**答案空间是 `[0, n]`，共 n+1 个候选。**

```python
def best_removal_time(log) -> int:
    cur = log.count("0")                 # x = 0：整段都在网外，罚分 = '0' 的个数
    best_x, best_v = 0, cur
    for i, ch in enumerate(log):
        cur += 1 if ch == "1" else -1
        if cur < best_v:                 # 严格 < → 平手取最小的 x
            best_x, best_v = i + 1, cur
    return best_x
```

> **注意极性和 q08 相反**：q08 里 `N`（无客）在营业时段扣分，
> 这里是 `1`（UP）在**摘除之后**扣分。写之前先在纸上确认一遍哪一侧扣哪个字符。

### Part 3 — 聚合日志

同 q08 的 tokenizer：`BEGIN` … `0/1` … `END`。
`BEGIN` 在 `END` 之前再次出现 → **重启**（丢弃之前的 token）；
孤立的 `END` 忽略；结尾未闭合的 `BEGIN` 忽略；`BEGIN…END` 之外的 token 忽略。
`BEGIN END`（空日志）→ 0。**不带空格的 `0010` 等价于 `0 0 1 0`。**

### Part 4 — 最多 k 次摘除（重构，这里升级成 DP）

摘除后可以在任意后续小时开头**重新接入**，再摘除，**最多 `k` 段离网区间**。
罚分定义不变。

```
dp[i][j][s]  = 前 i 小时、已用 j 段离网、当前状态 s（0=在网, 1=离网）的最小罚分
转移：
  在网 → 在网： + (log[i] == '0')
  在网 → 离网： j+1，+ (log[i] == '1')
  离网 → 离网： + (log[i] == '1')
  离网 → 在网： + (log[i] == '0')
```

- `k = 0` → 永不摘除，罚分 = `1` 的个数。
- **`k = 1` 不等于 Part 2** —— 唯一的离网区间**可以在日志结束前就结束**。

## 坑

1. **`remove_at = 0` 和 `= n` 都合法**；空日志 → 罚分 0、最佳 0。
2. 全 `0` → 最佳 `n`；全 `1` → 最佳 `0`；平手取小（`1 0` 的罚分 1,2,1 → **0**；`0 1 0 1` → 1）。
3. Part 3：嵌套 `BEGIN` 重启、孤立 `END`、未闭合的尾部 `BEGIN`、跨行、`BEGIN END` → 0、多份日志按序输出。
4. **不带空格的 `0010`** 也要接受。
5. Part 4：`k` 大于需要时**不会更差**（多的段可以不用）；`k = 0`。
6. **极性别写反**（见上面的提醒）。
