# qA11 · LC 2768 黑格块计数（稀疏网格）

> `problems/qA11_lc2768_number_of_black_blocks/` · 3 个 part · LC Stripe tag 频率 61–67
> **主题：`m·n` 是 10^10 而事件只有 10^4 —— 遍历事件，哈希它们碰到的窗口。**

## 一句话题意

`m × n` 的网格，给一批黑格坐标。统计每个 2×2 块里有 0/1/2/3/4 个黑格的块各有多少个。

## 解题思路

### Part 1

每个黑格 `(x, y)` 所属的块的左上角是 `(x−dx, y−dy)`，`dx, dy ∈ {0,1}`，
且必须满足 `0 <= x−dx <= m−2` 且 `0 <= y−dy <= n−2`
（角上的格子碰 1 个块，边上 2 个，内部 4 个）。

```python
touched = Counter()
for x, y in set(coordinates):                  # ★ 先去重
    for dx in (0, 1):
        for dy in (0, 1):
            bx, by = x - dx, y - dy
            if 0 <= bx <= m - 2 and 0 <= by <= n - 2:
                touched[(bx, by)] += 1
res = [0] * 5
for c in touched.values(): res[c] += 1
res[0] = (m - 1) * (n - 1) - len(touched)      # ★ 用算术算，绝不建网格
```

O(|coordinates|)，**绝不 O(m·n)**。

### Part 2 — k×k 块

`dx, dy ∈ [0, k)`，左上角限制在 `0 <= x' <= m−k`、`0 <= y' <= n−k`。
返回 `k²+1` 个计数；`res[0] = max(0, m−k+1) * max(0, n−k+1) − |touched|`。
`k = 2` 是 Part 1；`k = 1` 给 `[白格数, 黑格数]`；`k > min(m, n)` → 全零。
O(|coordinates| · k²)。

### Part 3 — 流式更新

`BlockCounter(m, n)` + `paint(x, y, black)` + `counts()`。
**同时维护**每个块的黑格计数（哈希表）**和**五个桶的直方图，**增量更新**：
把白格涂黑 → 它的 ≤4 个块从桶 `c` 移到 `c+1`；涂白 → 从 `c` 移到 `c−1`。
**`paint` 是幂等的**（把已黑的涂黑、已白的涂白，什么都不变）。
`counts()` 是 O(1)，`counts()[0]` 由 `(m−1)(n−1) − (c >= 1 的块数)` 推出。

## 坑

1. **`res[0]` 必须用 `(m−1)(n−1)` 的算术得到** —— 它可以到 ~10^10，**绝不建网格**。
2. 角（1 块）/ 边（2 块）/ 内部（4 块）；**最后一行/列的格子只碰上方/左方的块**。
3. `m = 2` 或 `n = 2`（只有一行块）；全黑的 2×2 网格 → `[0,0,0,0,1]`。
4. 没有黑格 → `[(m−1)(n−1), 0, 0, 0, 0]`。
5. **重复坐标要去重。**
6. Part 2：`k > min(m, n)` → 零个块；`k = 1`；输出长度 `k²+1`。
7. Part 3：幂等的 paint；涂白要减**正确的**桶；
   **计数回到 0 的块要重新算进桶 0**（从表里删掉，或正确处理 0）。
