# 07 · 陷阱总清单

> 从 53 道题的 "Edge cases hidden tests are known to target"、"Clarifications"、
> "Variants" 三个小节里抽出来，按类别归并、去重、一般化。
>
> 用法：写完一个 part，扫一遍对应类别；交卷前扫一遍全部粗体项。

---

## 1. 比较符（最高频）

- [ ] **"exceeds N" = `> N`，"at least N" = `>= N`。** 读错一个，"恰好等于"的隐藏测试就挂。
- [ ] **最小量门槛用 `>=`**：`total >= min_count`。
- [ ] 阈值恰好命中要单独测：`N-1` / `N` / `N+1` 三个用例。
- [ ] 规格含糊时，把比较符做成常量：`STRICT = False`，一行切换。
- [ ] "between A and B" 默认闭区间 `A <= x <= B`，写注释。
- [ ] 容量类的 "up to K" 是 `<= K`，"under capacity" 是 `< K`。

---

## 2. 计数 vs 比例阈值

- [ ] **靠字面量的形状区分**：`3` 是计数，`0.25` **和 `1.0`** 都是比例。判据是有没有小数点。
- [ ] `total == 0` 时**不判定**（不是判定为 0，不是除零）。
- [ ] 比例比较**不用浮点**：`fraud * den >= num * total`。
- [ ] `1/3` vs `0.33` 是**大于**；`1/3` vs `0.34` 是小于。浮点会在这里出错。
- [ ] 比例阈值几乎总配一个 min-volume 门槛，别漏。

---

## 3. 分组与聚合

- [ ] **"每组一次"的规则不能写在遍历行的循环里**。先分组，再对组应用。
- [ ] 判据：规则的主语是"这笔交易"还是"这个商户"。
- [ ] `itertools.groupby` **只对已排序的数据有效**，忘了排序会得到碎片化的组。
- [ ] `groupby` 产出的 `grp` 是一次性迭代器，要用两次就先 `list(grp)`。
- [ ] `Counter.most_common()` 在平手时按插入序，**不是确定性排序** → 自己再排一遍。

---

## 4. 金额

- [ ] **`float` 不得出现在任何金额路径上**（包括排序键、包括中间比较）。
- [ ] `int(float(s) * 100)` 会少一分（`"1.15"` → 114）。用 `int(Decimal(s).scaleb(2))`。
- [ ] **`round()` 是 banker's rounding**，题面说 "round half up" 时用它是错的。
- [ ] `x.xx5` 一定有测试。
- [ ] 负数金额格式化：`-1 // 100 == -1`，直接套公式会得到 `-1.99`。先取绝对值。
- [ ] **舍入粒度 = 题面描述规则的粒度**（逐行 vs 汇总）。
- [ ] 零小数货币（JPY、KRW…）不除 100。
- [ ] 分摊后各部分之和必须精确等于总额（最大余数法 + 确定的 tie-break）。
- [ ] `floor` 和 `truncate` 在负数上不同：`-7 // 2 == -4` vs `-3`。

---

## 5. 阶梯与计费

- [ ] **graduated（累进）≠ volume（整量）**。题面不清时按累进，写注释。
- [ ] 档位边界**含**上界：`first 1000 units` 包含第 1000 个。
- [ ] 最后一档通常无上界，别写死。
- [ ] 免费额度是"先减再进阶梯"还是"计档时仍算总量"—— 用样例反推。
- [ ] proration 的"天数"是 `(end-start).days` 还是 `+1` —— 用样例反推。

---

## 6. 时间

- [ ] **`timedelta` 没有 `months=`。** 加月要手写。
- [ ] **月末夹取**：Jan 31 + 1 month = Feb 28/29。
- [ ] 订阅锚点：每次从**原始日期**重算，不是从上次扣款日递推。
- [ ] 时区偏移是**分钟**（+5:30、+5:45），不是整小时。
- [ ] 跨日用 `divmod(minutes, 1440)`（对负数也对），星期跟着 `% 7`。
- [ ] naive `datetime.timestamp()` 按**本地时区**解释 → 本地对、评测机挂。
- [ ] **固定桶 ≠ 滚动窗口**：13:59 和 14:01 在桶里不同组，在窗口里同组。
- [ ] "within one hour" 的 `<` 还是 `<=` 要定死并写注释。
- [ ] `24:00` 作为合法输出要特判（`divmod` 会给你 `0:00` + 进位）。
- [ ] 非法日期（`2026-02-30`）用 `strptime` 的 `ValueError` 捕获。

---

## 7. 区间

- [ ] **在文件顶部声明闭区间还是半开区间**，全程只用一种。
- [ ] 整数域的**相邻区间要合并**：`[1,3]` 和 `[4,6]` → `[1,6]`。合并条件是 `lo <= prev_hi + 1`。
- [ ] 长度：闭区间 `hi - lo + 1`，半开 `hi - lo`。
- [ ] 找空隙时的空隙是 `(prev_hi + 1, lo - 1)`，只有 `<=` 时才存在。
- [ ] 被覆盖区间要按 `(lo 升序, hi 降序)` 排。
- [ ] 全域的两端（`LO` 之前、`HI` 之后）也可能是空隙。

---

## 8. 事件流与撤销

- [ ] **保留原始记录**，聚合值从它派生 —— 否则撤销时不知道该减哪个计数器。
- [ ] `apply` / `unapply` **逐字对称**。
- [ ] 撤销**不存在**的 id → 忽略。
- [ ] **重复撤销** → 第二次 no-op。
- [ ] 撤销**非欺诈**记录只减分母，可能让比例**上升**、把实体推**过**阈值（反直觉，必测）。
- [ ] 全部撤销后 `total == 0` → 不判定，不是 0/0。
- [ ] "sticky"（一旦触发永久保持）vs 非 sticky，是两套完全不同的输出。
- [ ] 被撤销的 id 再次出现，算新记录还是重复？规格没说就写注释。
- [ ] **setup 行先于所有事件生效，不管它出现在文件哪里** → 两遍扫描。

---

## 9. 幂等与去重

- [ ] 三种语义不同：**忽略**（第一次生效）、**覆盖**（最后一次生效）、**报错**。
- [ ] "last one wins if repeated" = 覆盖，不是忽略。
- [ ] 去重检查要在**处理之前**，不是之后。
- [ ] 双重释放（double free）、重复注册、重复 INIT 都是同一类。
- [ ] 百分比灰度要用**稳定哈希**（同一个 user 每次落同一个桶），不能用 `hash()`
      —— Python 的 `hash()` 对 str 每次进程启动都不同（PYTHONHASHSEED）。用 `hashlib.md5`。

---

## 10. 排序与输出

- [ ] **没说 tie-break 就自己定一个并写注释**，不确定的顺序 = 随机挂。
- [ ] `"acct_10" < "acct_2"` 是**对的**（字典序）。别偷偷改成数值序。
- [ ] 字符串降序不能取负号 → 多趟稳定排序或 `cmp_to_key`。
- [ ] `"Z" < "a"`（大写码点更小）。
- [ ] 空结果：`NONE` / 空行 / 不输出，**三选一，题面里找**。
- [ ] 末尾换行：`print("")` 会多一个空行，`sys.stdout.write("")` 不会。
- [ ] 对齐格式化会产生**尾随空格**。
- [ ] 格式化函数只写一个。

---

## 11. 解析

- [ ] 先 `strip()` 再判空行；**空行不是错误**。
- [ ] 每个字段都 `strip()`（题面说"容忍逗号周围的空格"时是必须的）。
- [ ] 含分隔符的字段用 `split(sep, maxsplit)` 或 `csv` 模块。
- [ ] 变长行：字段数少于最大值时后面的字段是可选的，`len(parts)` 要判断。
- [ ] 表头驱动的 CSV 用 `csv.DictReader`，不要假设列顺序。
- [ ] `strip()` 掉的可能有 `\r`（Windows 换行），`splitlines()` 已处理。
- [ ] 未知的记录类型：忽略还是报错？题面说了算。

---

## 12. 校验与错误路径

- [ ] 三类错误行为不同：格式坏（跳过行）、引用坏（忽略事件）、业务坏（输出拒绝信息）。
- [ ] **不要用 `try/except` 兜底一切** —— 会吞掉真 bug。
- [ ] 拒绝路径上**不得修改状态**（先全部校验，再全部修改）。
- [ ] 转账要么两端都成功，要么两端都不动。
- [ ] 缺字段和字段为空串是两回事。

---

## 13. 数据结构与性能

- [ ] **`defaultdict` 的读取会建键** → 查询用 `.get()`。
- [ ] 循环里 `x in some_list` 是 O(n) → 换 `set`。
- [ ] 循环里 `list.pop(0)` 是 O(n) → 换 `deque`。
- [ ] 循环里重新 `sort` / 重新 `split` → 提到循环外。
- [ ] 堆里的过期条目用**惰性删除**，弹出时校验是否最新。
- [ ] 10^6 条记录时 `@dataclass` 的实例开销可观 → `__slots__` 或直接用元组。
- [ ] 长时间不活跃的 key 要清理，否则内存爆。
- [ ] 递归深度默认 1000 → 10^5 节点的 DFS 写成迭代。

---

## 14. Python 语言本身

- [ ] 可变默认参数 `def f(a=[])`。
- [ ] `-7 // 2 == -4`（向下，不是向零）。
- [ ] `0.1 + 0.2 != 0.3`。
- [ ] 浅拷贝 `a[:]` 只复制一层。
- [ ] 闭包晚绑定：`[lambda: i for i in range(3)]` 全返回 2。
- [ ] `for k in d: del d[k]` → `RuntimeError`，用 `list(d)`。
- [ ] 混合类型比较 `1 < "a"` → `TypeError`。
- [ ] `is` 只用于 `None` / `True` / `False`。
