## Q
Cerebras 的 SDET 技术深挖轮可能问哪四块？每块举两个问题。

## A
| 块 | 例题 |
|---|---|
| **测试与发布** | 怎么给新功能写测试计划？flaky 测试怎么发现、隔离、修？ |
| **机器学习基础**（测试岗也问） | 过拟合是什么？L1 和 L2 正则化有什么区别？怎么评价分类模型（精确率、召回率）？ |
| **LLM 推理** | 预填充和解码的区别？批处理为什么提高吞吐、拉高单个请求延迟？ |
| **操作系统与调试** | 一个进程卡住怎么查？进程和线程、共享内存、死锁？ |

- **过拟合（overfitting）**：模型记住了训练数据的细节，对新数据反而不准。
- **正则化（regularization）**：在训练目标里惩罚过大的参数，防止过拟合；L1 倾向把参数压到 0，L2 让参数整体变小。
- **还可能有**：用日常物品打比方的测试题（"你会怎么测一部电梯"），按功能、边界、异常、性能、安全、可用性分层答。
- **准备**：`LLM 推理与 AI 加速器`、`软件测试与发布工程` 两个牌组。
