## Q
RIT 是新建的团队，这对你意味着什么？面试里怎么把它变成你的优势？

## A
- **证据**：公司同时在招一位技术负责人来"建立并领导 RIT"，他的职位把"把一项质量或发布能力从零做到一"列为加分项。
- **意味着**：
  - 你很可能是第一批工程师，要从零定流程、写工具、建度量。
  - 标准还没定，优先级会变，文档少。
  - 公司内部评价里常见的抱怨是技术债、知识只在人脑里、文档差、工程严谨度不够；RIT 正是来补这些的。
- **你的优势**（都是没人分配、你自己从零做的）：
  - 质量门框架：把"能不能读这份数据"从 Slack 约定变成 SQL 里的硬条件。
  - schema pool：从部署的提交派生出确定的测试状态。
  - 每日健康检查：抓到没有报错的费用缺失。
- **英文**："I like zero-to-one quality work: I've built a gate and a test-environment tool nobody assigned, and I'd rather define the gates than just run them."
- **别说**：批评公司现在的工程质量。说"what I'd build"，不说"what's broken"。
