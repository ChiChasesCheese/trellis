# 标头：在不解析消息体的情况下携带元数据

本节介绍消息标头(header)的用途——在不改变键值对的情况下附加路由、追踪等元数据，标头由字符串键和可序列化的值组成。适合需要在消息体加密或不便解析时仍要传递辅助信息的场景。
