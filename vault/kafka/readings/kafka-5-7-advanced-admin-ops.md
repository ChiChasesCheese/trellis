# 高级管理操作：分区、消息删除与首领选举

本节介绍一批风险较高但必要时非常有用的AdminClient操作：为主题添加分区、从主题中删除消息、触发首领选举，以及重新分配副本。这些是SRE日常运维中最重要但也最容易出错的操作，需要谨慎对待。
