# 流式处理的应用场景

本节讲解在什么情况下流式处理是最合适的选择——需要比批处理更快、又不要求毫秒级响应的场景，并列举了数据摄取、低延迟处理等典型应用场景，是判断一个具体问题是否适合用流式处理来解决的实用标准。
