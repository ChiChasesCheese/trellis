## Q
当题目要求"给定一堆人之间互相欠款的记录，求最少转账几次能把所有债务结清"时，怎么识别该用**净额化 + DFS 剪枝 / 状压 DP**这个套路？

## A
第一步必须先**净额化**：把每个人在所有交易中的收支相加，算出每个人的净值（正数表示该收到多少钱，负数表示该付出多少钱），
净值为 0 的人直接排除，不参与后续计算——原始的每一笔借贷记录本身没有意义，真正要结清的是净值。
净额化之后，问题变成"用最少的转账次数让所有净值归零"，可以用 DFS + 剪枝（每次让当前第一个非零的人和其他某个人凑平，递归），
当人数较多（n ≤ 12 左右）时也可以用状压 DP（子集和为 0 的最少分组数）来做。

**最易错处**：
1. **净额化之前就想直接对原始交易记录做最优匹配/DFS 是错的**——原始交易之间可能互相抵消，必须先算净值再规划转账路径；
2. 状压 DP 只有在 **n ≤ 12 左右**（状态数 2^n 可接受）时才可行，n 更大只能用 DFS 剪枝或贪心近似。
