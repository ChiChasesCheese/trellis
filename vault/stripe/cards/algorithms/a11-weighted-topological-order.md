## Q
当题目要求"任务有依赖关系，且每个任务有耗时，求完成所有任务的最短/最长总时间"时，为什么该用**带权拓扑序**，怎么识别？

## A
用 Kahn 算法（BFS 版拓扑排序）：维护每个节点的入度，入度为 0 的节点入队，出队时把它指向的所有后继节点入度减一，
减到 0 就继续入队；同时维护 `finish[v] = max(finish[u] + w[v])`（对所有前驱 u 取最大完成时间再加上 v 自身耗时），
遍历结束后 `finish` 数组里的最大值就是完成所有任务的总时间。这本质是在拓扑序上做一次动态规划。

**最易错处**：
1. 图中如果存在**环**，会导致 Kahn 算法执行完毕后**入队总数 < n**（有节点永远无法入度归零），这是判断"是否可完成/是否有循环依赖"的标准方法，必须显式检查这个计数；
2. 起点不是"某一个固定节点"，而是**所有入度为 0 的节点**都要作为初始状态同时入队，遗漏其中任何一个都会导致部分子图算错。
