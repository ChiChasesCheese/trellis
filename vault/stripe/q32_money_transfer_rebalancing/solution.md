# q32 · 资金调拨（让每个账户都 ≥ 最低额）

> `problems/q32_money_transfer_rebalancing/` · 4 个 part · phone + VO（2021–2026）
> **主题：可行性判据 + "最少转账次数"（LC 465 的变体）+ 反向审计。**

## 一句话题意

一堆账户余额和一个最低额。设计转账让每个账户都 ≥ 最低额。
P1 任意可行解；P2 **转账次数最少**；P3 反过来 —— 给一份转账清单，审计它；P4 加手续费。

## 核心考点

`S02` 解析 · `S03` 按 id 建记录 · **`S05` 阈值（≥ min、可行性 ==）** · `S08` 确定性顺序 ·
`S09` 格式 · **`S17` 台账余额** · `S18` 校验 · **`A10` LC 465 DFS 剪枝**

## 解题思路

### 可行性

```
可行 ⟺ sum(balances) >= minimum * n
```
否则 `IMPOSSIBLE`。**`==` 是可行的**（大家正好都在 min），少一个单位就不可行。

### Part 1 — 任意可行解（确定性贪心）

**按输入顺序**走 source（余额 > min）和 sink（余额 < min）：
`amount = min(source − min, min − sink)`；source 到达 min 就换下一个，sink 满足了就换下一个。

### Part 2 — 最少转账次数

**先净额化**：`net = balance − min`。只有 `net < 0` 的必须被填平；
`net > 0` 的是资金来源，**不必被抽干**（这是与纯 LC 465 的区别）。

**精确解（非零净额账户 ≤ 12 时）**：DFS + 分支限界。
deficit 按 `(缺口降序, 名字)` 排，source 按 `(盈余降序, 名字)` 排；
每次转 `min(source_剩余, deficit_剩余)`（最优解里总存在这样的形式：
每笔转账要么填满一个 sink，要么抽干一个 source）。同一个 deficit 的 source 按下标递增取。

**超过 12 个时**回退到排序双指针贪心（最大盈余 → 最大缺口）——
这是**启发式**，在逐字样例上会给 3 笔而最优是 2 笔。**要在注释里写明这是启发式。**

### Part 3 — 审计（"反过来问"）

按顺序应用转账清单（`from` 减、`to` 加，**允许透支**），
然后按输入序打印每个账户 `NAME: balance`，最后一行结论：

| 结论 | 条件 |
|---|---|
| `OK` | 每个账户都 ≥ min |
| `INCOMPLETE` | 有账户 < min，但 `sum >= min × n`（本来有完整解） |
| `BEST_EFFORT` | `sum < min × n`（不可行）**且没有账户在 min 之上而另一个在 min 之下**（能挪的都挪了） |
| `NOT_BEST_EFFORT` | 不可行，且仍有账户高于 min 而另一个不足 |
| `INVALID` | 某笔转账指向未知账户、`amount <= 0` 或 `from == to`；**该笔之前的照常应用，之后的全部跳过** |

### Part 4 — 手续费（重构）

`FEE f`：每笔转账**发送方**额外扣 `f`（接收方仍收到 `amount`）。
用 P2 的回退贪心；一个 source 每笔最多发 `盈余 − f`，`盈余 <= f` 时跳过它。
打印转账，然后 `FEES: total`。贪心留下未覆盖的缺口 → `IMPOSSIBLE`
（`f = 0` 时是精确的，`f > 0` 时是启发式结论，**要说明**）。

## 坑

1. **可行性 `sum >= min × n`，`==` 可行**，少一个单位就 `IMPOSSIBLE`。
2. 所有账户已经 ≥ min → **没有输出**（不是 `IMPOSSIBLE`，也不是一个空行）。
3. 负余额；只有一个账户；两个账户；一个缺口由**多个** source 填。
4. 转账**绝不能让 source 掉到 min 以下**（P1/P2/P4），且金额必须 > 0。
5. P2 的次数必须**最小**：样例只要 2 笔而排序贪心给 3 笔；等额的盈余/缺口对。
6. P3 结论的边界：**恰好在 min 是 `OK`**；`BEST_EFFORT` 要求**没有账户高于 min**。
7. `MIN` 不一定是 100；输入里的 `- ` 项目符号和 `:`/`,` 周围的空格。
8. 500 个账户（P1/P2 回退）要快；精确搜索只在**非零净额账户 ≤ 12** 时用。
