## Q
**Golden set · 怎么建、怎么维护**｜摘要 · 必会

要给一个客服机器人建一份 golden set（带标注的评测样本集）。样本从哪里来？只有一份够吗？上线后怎么维护？

## A
**一句话：** golden set 是一批带标注（标准答案或好坏判断）的真实样本，用来衡量每个版本。

**样本从哪来：**
- **线上真实数据**（首选）；
- 有"天然标签"的就直接用（比如用户是否采纳）；
- 没有的话请人或 AI 标注，标注的清晰程度取决于**评分标准**写得明不明确；
- 专家编写、合成（让模型生成）作补充。

**要有多份，每份代表一种切片：**

| 集合 | 用来 |
|---|---|
| 反映线上分布的总体集 | 估计总体表现 |
| 已知常出错的例子 | 防止这些问题复发 |
| 用户常犯错的例子（如拼写错误） | 测鲁棒性 |
| 超出范围的输入 | 看应用是否恰当地拒绝 |

**维护：**
- **版本化**：数据、评分标准、judge 的 prompt 和采样参数都要记录，评测才能互相比较；
- 评测标准会随需求和用户行为变，要迭代；但流程不能不停变，否则结果不能用来指导开发；
- **定期补入新发现的失败样本**；
- 评测数据别混进训练数据，否则分数虚高（污染）。
