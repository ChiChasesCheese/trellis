# K-State Basketball | Tex Winter - Triangle Offense

The man who built the triangle teaching it himself, which is worth more than
any second-hand explanation of it. The value is not the diagram; it is hearing
the geometry described as spacing rules that produce options, so you can spot
the same shapes in offences that are never called a triangle.

**Extract on watch:**
- The sideline triangle's dimensions and why those distances specifically.
- The two-man game away from the ball that makes the triangle more than a post-up.
- Reading the defence from the strong-side post outward.
- How the shape refills itself after each pass instead of resetting.
