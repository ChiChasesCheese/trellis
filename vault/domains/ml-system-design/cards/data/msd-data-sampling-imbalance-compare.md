## Q
处理类别不平衡，下采样、上采样、损失加权和 focal loss 各怎么做？各自的代价是什么？

## A
**背景**：正例只占 0.1%–2% 时（欺诈、违规、点击），模型几乎只看到负例，容易"全猜负例"也拿到很低的损失（loss，衡量预测离正确答案多远的数）。

- **下采样多数类**（undersampling）：丢掉大部分负例。
  - 优点：训练快、省存储。
  - 代价：丢了信息；概率偏高，需要校正。负例很多样时（各种正常行为），丢太多会让模型没见过某些正常模式，误报上升。
- **上采样少数类**（oversampling）：把正例复制多份，或用 SMOTE 在两个正例之间插值造出新正例。
  - 优点：不丢数据。
  - 代价：训练变慢；复制的正例容易被模型背下来（过拟合，在训练数据上很好、新数据上变差）；SMOTE 在文本、类别特征上造出的样本往往不合理。
- **损失加权**（class weight）：正例的损失乘以更大的权重，比如 50。
  - 优点：数据不变，一个参数就能调，例如 scikit-learn 的 `class_weight="balanced"`。
  - 代价：权重太大训练不稳定；概率同样需要校准。
- **focal loss**：给模型已经判断得很有把握的样本（大多是简单负例）降低损失权重，让训练集中在难样本上。公式是在交叉熵前乘 (1 − p)^γ，γ 常取 2。
  - 优点：适合"大量简单负例 + 少量难样本"，最早用于目标检测。
  - 代价：多一个超参数；输出概率不再校准。

**实践顺序**：先什么都不做，用 PR-AUC（精确率—召回率曲线下面积）等合适的指标看看效果；不够再试损失加权；数据量太大才下采样。无论哪种，**评估都在未经采样的真实分布上做**，需要概率时再校准。
