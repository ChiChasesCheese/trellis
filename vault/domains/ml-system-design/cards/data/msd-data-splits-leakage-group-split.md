## Q
什么时候要"按用户（或按实体）分组切分"？它和按时间切分有什么区别，什么时候两个都要用？

## A
**问题**：同一个用户、同一个病人、同一个设备、同一篇文档会产生很多条样本。随机切分时，同一个用户的样本一部分进训练、一部分进测试，模型可以靠"认出这个用户"得分，而不是学到可推广的规律。

**例子**：用某人过去的 100 次语音预测说话内容。随机切分时，测试集里的声音训练时都听过，准确率 95%；换成全新的人，只有 80%。如果产品要服务新用户，95% 就是虚高的。

**分组切分**：保证同一组的样本全部在训练集，或全部在测试集。
```python
from sklearn.model_selection import GroupShuffleSplit
splitter = GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=0)
train_idx, test_idx = next(splitter.split(X, y, groups=user_ids))
```
交叉验证时对应 `GroupKFold`。

**两种切法回答的是不同的问题：**
- **按时间切**：模型对"未来"有效吗？防的是看到未来信息。
- **按用户切**：模型对"没见过的人"有效吗？防的是认出个体。

**怎么选：**
- 推荐系统里同一批老用户明天还会来：主要按时间切，老用户出现在两边是合理的，这就是线上情况。另外单独报告"新用户切片"的指标。
- 欺诈、医疗、语音这类要推广到新个体的任务：按实体切。
- 两个都关心时：先按时间切出测试期，再在测试期里只保留训练期没出现过的用户做"新用户测试集"，和全体测试集分别报告。

**检查办法**：切完后算一下训练集和测试集的实体交集，`len(set(train_users) & set(test_users))`，应该和你的设计意图一致。
