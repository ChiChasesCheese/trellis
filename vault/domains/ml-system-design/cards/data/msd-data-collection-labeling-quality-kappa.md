## Q
人工标注的质量怎么保证？标注一致性用 Cohen's kappa 怎么算？手算一个例子。

## A
**保证质量的四个手段：**
- **标注指南**：写清每个类别的定义、边界案例和反例。"轻微辱骂算不算违规"没写清，两个人就会标得不一样。
- **黄金题**（gold questions）：混入一批已知答案的题，标注员答错率高就重新培训或剔除。
- **多人标注 + 投票**：同一条给 3 个人，取多数；分歧大的送专家仲裁。
- **一致性监控**：定期抽样计算两个标注员之间的一致性。

**为什么不能只看"一致率"**：两个人都随手乱标，也会有一部分碰巧一致。Cohen's kappa 扣掉了碰巧一致的部分：

kappa = (实际一致率 − 碰巧一致率) ÷ (1 − 碰巧一致率)

**手算**：100 条评论，标注员 A 和 B 判断"是否违规"。
- 两人一致的有 80 条，实际一致率 = 0.80。
- A 标了 50% 为违规，B 标了 60% 为违规。碰巧一致率 = 两人都标违规的概率 + 都标正常的概率 = 0.5 × 0.6 + 0.5 × 0.4 = 0.50。
- kappa = (0.80 − 0.50) ÷ (1 − 0.50) = **0.60**。

**怎么解读**：常用的经验分档是 0.6–0.8 为"较好"，0.8 以上为"很好"，0.4 以下说明指南有问题。

```python
from sklearn.metrics import cohen_kappa_score
print(cohen_kappa_score(labels_a, labels_b))
```

**和模型的关系**：人与人之间的一致性是模型的天花板。两个专家只有 85% 一致，模型在这份数据上报告 95% 准确率，多半是数据有泄漏或测试集太简单。
