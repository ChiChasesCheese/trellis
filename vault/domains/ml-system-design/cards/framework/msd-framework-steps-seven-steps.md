## Q
机器学习系统设计（ML system design）面试常用的"七步框架"是哪七步？每一步要产出什么？

## A
ML 系统设计题要你设计一个靠**模型**（model，从历史数据里学出来的函数：输入一组字段，输出一个预测）做决策的产品，例如视频推荐、垃圾邮件过滤、内容审核。七步按顺序走：

1. **澄清需求**：业务目标、规模（日活、每秒请求数 QPS）、延迟上限、手里有哪些数据。产出：一句话目标 + 三四个数字约束。
2. **定义成 ML 任务**：模型的输入是什么、输出是什么、**标签**（label，训练时告诉模型的"正确答案"）从哪来、优化什么目标。产出：例如"输入用户和视频，输出用户看完它的概率"。
3. **数据**：一条训练样本长什么样、标签怎么得到、训练集和测试集怎么切；**特征**（feature，喂给模型的输入字段，如用户年龄、视频时长）有哪些。产出：样本表结构 + 特征清单。
4. **模型**：先给一个简单**基线**（baseline，规则或最简单的模型，用来对比），再给主力模型并说明为什么选它。产出：模型结构与训练方式。
5. **评估**：**离线**指标（用历史数据算，不碰真实用户）和**在线**指标（把新模型放给一部分真实用户，做 A/B 实验）。产出：主指标 + 护栏指标（不许变差的指标）。
6. **部署与服务**：线上怎样产出预测、延迟预算怎么分、提前批量算还是请求来了再算。产出：架构图。
7. **监控与迭代**：输入数据的分布变了、效果下滑了怎么发现，多久重新训练一次。产出：报警项 + 再训练节奏。

**和普通系统设计的关系**：第 6 步就是熟悉的服务架构题；第 2、3、5、7 步是 ML 题特有的，面试官主要在这几步看你有没有真做过——标签从哪来、怎么证明模型变好了、上线后怎么知道它变差了。
