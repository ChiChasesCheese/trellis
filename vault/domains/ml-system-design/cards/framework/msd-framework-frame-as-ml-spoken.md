## Q
面试里被问"把'减少平台上的垃圾评论'定义成一个 ML 问题"，怎么答？

## A
按这个顺序说：

- **先说决策是什么**：系统对每条新评论做三选一：直接发布、送人工复审、直接拦截。模型只提供依据，决策由阈值决定。
- **输入**：评论文本、作者账号年龄和历史违规次数、评论里的链接数、发评频率（过去 1 分钟发了几条）。都是发评那一刻能拿到的。
- **输出**：一个 0 到 1 的分数，表示"是垃圾评论"的概率；定义成二分类。若还要区分广告、辱骂、诈骗，就做多标签（每类独立一个概率）。
- **标签从哪来**：三种来源，各有偏差——人工复审结果（准但少，每天几千条）、用户举报（多但有噪声，被举报的不一定违规）、被删除的账号的历史评论（量大，作弱标签）。我会以复审结果为准，其他作为补充。
- **目标与阈值**：训练最小化交叉熵（分类常用的损失）。线上用两个阈值：分数 > 0.95 直接拦截，要求精确率（拦截的里面真是垃圾的比例）≥ 99%，因为误删正常评论伤害大；0.6–0.95 送人工复审，按复审团队每天能处理的量调下限。
- **业务指标**：用户看到的垃圾评论比例（抽样人工估计）、误拦截申诉率、复审队列长度。

一分半钟讲完，然后自然进入数据部分："标签分布极不平衡，垃圾大约只占 1%，所以采样和评估要特别处理。"
