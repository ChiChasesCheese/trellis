## Q
面试里被问"你怎么评测一个新的大模型版本能不能替换线上版本？"，怎么答？

## A
按这个顺序说：

- **先分清在评什么**：换的是模型权重，还是同一个模型换了推理引擎、量化方式或硬件？前者评"能力有没有变好"，后者评"输出有没有变"，方法不同。
- **分层的评测组合：**
  - **数值一致性**（引擎或硬件变更时）：固定几百条输入，比较新旧版本每个输出位置的 logprob（模型给每个输出词的对数概率），差异在容差内；
  - **公开基准**：几个固定设置的基准（知识、数学、代码），命令、版本和少样本数全部锁定；
  - **业务评测集**：从线上抽样、分层、有标准答案或评分标准的私有题集，这是决策的主依据；
  - **安全评测**：有害请求的拒答率、越狱提示的通过率；
  - **性能**：首个 token 延迟、每秒生成 token 数、相同质量下的成本。
- **怎么判分**：能程序判断的（数字、JSON、代码测试）程序判断；开放式回答用成对比较，评委模型交换顺序评两次，并事先用几百条人工标注验证评委和人的一致率。
- **怎么判断差异是真的**：同一套题逐题配对比较新旧版本，只看结论不同的题；用统计检验，差异小于噪声不算回归；同时看切片，防止平均分掩盖某类问题的大幅下降。
- **决策规则事先定好**：主指标不降、安全不降、关键切片不降超过阈值、延迟和成本在预算内，才进入线上小流量和 A/B。
- **留证据**：评测集版本、评委版本、完整配置和每题输出都存档，换版本时可复现、可追溯。

收尾："离线评测决定能不能上小流量，线上实验决定能不能全量。"
