## Q
NDCG 是怎么算的？用一个 4 条结果的列表手算一次，并说明它和 Precision@k、MRR 的区别。

## A
**思路**：相关度越高的结果排得越靠前越好；位置越靠后，用户越可能看不到，所以按位置打折。

**三步：**
1. **DCG**（折损累计收益）：DCG@k = Σ 相关度ᵢ ÷ log₂(i + 1)，i 是位置（从 1 开始）。第 1 位除以 1，第 2 位除以 1.585，第 3 位除以 2，第 4 位除以 2.322。
2. **IDCG**：把同一批结果按相关度从高到低理想排列后算出的 DCG。
3. **NDCG = DCG ÷ IDCG**，在 0 到 1 之间，1 表示排序完美。

**手算**：模型返回 4 个视频，人工标注的相关度（0–3）依次为 [3, 2, 0, 1]。
- DCG = 3/1 + 2/1.585 + 0/2 + 1/2.322 = 3 + 1.262 + 0 + 0.431 = **4.693**
- 理想顺序 [3, 2, 1, 0]：IDCG = 3 + 1.262 + 1/2 + 0 = **4.762**
- NDCG@4 = 4.693 ÷ 4.762 ≈ **0.985**

把相关度 1 和 0 的位置换回来就完美了，所以只扣了一点分。

```python
from sklearn.metrics import ndcg_score
print(ndcg_score([[3, 2, 0, 1]], [[4, 3, 2, 1]]))  # 第二个参数是模型分数，决定顺序
```
（另一种常见写法用 2^相关度 − 1 作收益，更强调高相关结果，数值会不同，比较时要统一。）

**和其他指标的区别：**
- **Precision@k**：只看前 k 个里有几个相关，不管顺序、不分相关程度。
- **MRR**：只看第一个相关结果的位置，适合"找到一个答案就够"的问答和导航搜索。
- **NDCG**：既看程度又看位置，适合推荐和网页搜索这类"整页都会被看"的场景。

**注意**：没有任何相关结果的查询 IDCG 为 0，要约定跳过或记 0，否则平均值不可比。
