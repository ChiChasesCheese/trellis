## Q
面试里被问"你怎么用线上反馈持续改进模型？多久重新训练一次？"，怎么答？

## A
按这个顺序说：

1. **闭环结构：** 每次预测记下 `request_id`、当时的特征、分数和模型版本；真实结果到了按 ID 对齐成样本；等标签成熟（比如拒付要等 60 天）再进训练集；训练集按时间切并带版本。
2. **频率用实验定：** 用截止到 1 天前、7 天前、30 天前的数据分别训练，在今天的数据上比较；差距小就降低频率。再和训练成本对比，比如每天训练每月 1,440 GPU 小时、每周约 200。
3. **触发方式：** 定时是默认；漂移报警或效果跌破阈值时额外触发；在线学习只用在变化极快、标签马上可得的场景，并配严格护栏。
4. **讲反馈回路偏差：** 模型只看到自己选中的结果，再训练会越来越偏。用探索流量、留出组、记录展示概率并加权来打破，离线评估只用随机流量的数据。
5. **自动再训练的护栏：** 数据校验 → 固定评测集对比冠军（每个切片都设阈值）→ "好得可疑"也阻断 → 行为测试 → 影子和金丝雀。失败就保持现有冠军。
6. **大语言模型的分层更新：** 检索库（分钟级）→ 系统提示 → LoRA 微调（几天）→ 底座（几个月）。能在上层修的不下沉到下层；用户反馈主要用来扩充评测集和挑选微调数据。
