## Q
新版本在 GSM8K 上从 80.0% 降到 79.0%，这是真的退化还是噪声？怎样用统计方法判断，以及评测集要多大才能检出 1 个百分点的差异？

## A
**评测分数是抽样估计：** GSM8K 测试集有 1,319 道题，分数是"答对的比例"，本身有抽样误差。

**标准误（standard error）：** `SE = √(p × (1 − p) / n)`
- p = 0.80，n = 1,319：SE = √(0.16 / 1319) ≈ **1.1 个百分点**。
- 95% 置信区间约 ±2.2 个百分点，即 77.8% 到 82.2%。
- 1 个百分点的下降落在误差范围内，单凭两个总分**不能断定退化**。

**更好的方法：配对比较。** 两个版本做的是同一组题，可以逐题配对：
- 统计"旧对新错"的题数 b 和"旧错新对"的题数 c。两边都对或都错的题不提供差异信息。
- **McNemar 检验：** 统计量 `(b − c)² / (b + c)`，近似服从自由度 1 的卡方分布，大于 3.84 即在 5% 水平显著。
- 例子：b = 40，c = 27。统计量 = 169 / 67 ≈ 2.5 < 3.84，不显著。如果 b = 45，c = 20：625 / 65 ≈ 9.6，显著。
- 配对比较消除了"题目难度"带来的方差，比比较两个总分灵敏得多。

**要多大的评测集：** 用两个独立总分比较、想以 95% 置信检出 1 个百分点的差异，粗略需要每边 SE 约 0.35 个百分点，即 n ≈ 0.16 / 0.0035² ≈ **13,000 题**。所以：
- 合并多个任务、或使用大型题库（MMLU 有 14,042 道测试题）；
- 优先用配对检验；
- 生成类任务如果用随机采样，每题多跑几次取平均，降低采样带来的方差。

**还有一种噪声：** 采样温度大于 0 时，同一模型重跑分数也会波动。先把同一版本重跑 3–5 次，测出这部分波动。

**发布规则示例：** 每个任务做配对检验；显著下降且幅度超过 1 个百分点即阻断；不显著但多个任务同方向下降时，扩大评测集重测。
