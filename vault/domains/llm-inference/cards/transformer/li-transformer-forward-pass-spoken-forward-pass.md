## Q
面试里被问"一个 token 进入大模型后，一次前向计算发生了什么？"，怎么答？

## A
按数据流的顺序说，每一步带一个数字：

- **分词和嵌入：** 文字先被分词器切成 token 并转成编号；每个编号查嵌入表得到一个向量，7B 模型是 4,096 维。这一步只是查表，几乎没有计算。
- **几十个相同的块：** 7B 有 32 块。每块先归一化，再做注意力：向量分别乘三个矩阵得到 Q、K、V，按位置旋转 Q 和 K（RoPE），用 Q 和所有前文的 K 打分、softmax 得到权重、加权求和 V，只能看前面的位置。结果乘输出矩阵后加回原向量（残差）。然后再归一化，过前馈网络：变宽到 11,008、激活、变回 4,096，再加回残差。
- **输出：** 最后归一化，乘一个 `[4096, 词表大小]` 的矩阵得到 logits，即词表上每个 token 的分数；取最后一个位置的分数，经温度、top-p 等处理后选出下一个 token。
- **成本在哪：** 每个 token 约 2 × 参数量次运算，7B 约 140 亿次；参数的三分之二在前馈网络。处理整段输入时受算力限制；逐个生成时每步都要读一遍全部权重和 KV 缓存（已缓存的历史 K、V），受内存带宽限制。
- **推理特有的部分：** 生成时历史 token 的 K、V 不会变，存成 KV 缓存，每步只算新 token；所以服务的显存被权重和 KV 缓存瓜分。
- **测试角度收尾：** 我验证一个实现时会导出每层的隐藏状态和参考实现比较余弦相似度，加上最终 logits 的 top-1 一致率，第一个偏离的层就是嫌疑点。
