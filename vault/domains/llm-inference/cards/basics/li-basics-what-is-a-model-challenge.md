## Q
**挑战。** 线上回归：同一套推理代码、同一个 Docker 镜像，上周回答正常，这周同样的提示答得明显变差。运维说"代码一行没改，不可能是模型的问题"。你怎么反驳，先查哪几样？

## A
**评分点（答出 3 条算过）：**

1. 模型 = 代码 + 参数文件，行为主要由参数决定：代码没变不等于模型没变。
2. 查权重文件：校验和（hash）和上周是否一致，是否被换成另一个版本、另一种精度或量化版。
3. 查配套文件：分词器、对话模板、生成配置（温度等）有没有跟着换，或该换没换。
4. 用固定提示、温度 0 的一组黄金样例和上周的输出对比，把"模型变了"和"采样的随机波动"分开。
5. 以后把权重当作有版本的制品：记录 hash，和代码一样走发布和回滚。

<details class="pt"><summary>参考答案</summary>模型的行为写在几十亿个参数里，推理代码只是照着参数做矩阵乘法，所以代码不变不能说明模型没变。先核对权重文件的校验和，看是不是被换了版本、精度或量化方式；再看分词器、对话模板和生成配置有没有不匹配。然后用一组固定提示在温度 0 下重跑，和上周的输出逐条对比，排除随机波动。长期做法是把权重和配套文件当作版本化的制品来发布和回滚。</details>
