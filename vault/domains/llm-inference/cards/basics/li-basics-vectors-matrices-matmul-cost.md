## Q
矩阵乘法具体怎么算？乘一次要做多少次运算？用这个估算一个 7B 模型处理一个 token 要多少次浮点运算。

## A
**怎么算。** `C = A × B`，A 形状 `[m, k]`，B 形状 `[k, n]`，C 形状 `[m, n]`。C 的每个格子 = A 的一行和 B 的一列对应相乘再求和，也就是 k 次乘法和 k 次加法。

手算一个：A = `[[1, 2, 3]]`（1×3），B 的一列是 `[4, 5, 6]`，结果 = 1×4 + 2×5 + 3×6 = 32。

**运算量。** C 有 m×n 个格子，每个 k 次乘加，共 m×n×k 次乘加。一次乘加算 2 次浮点运算，所以总共 **2mnk 次浮点运算（FLOPs，floating-point operations）**。注意大小写：FLOPs 是"运算次数"，FLOPS 是"每秒运算次数"，衡量芯片算力。

**放到模型里。** 一个 token 的向量是 `[1, 4096]`，乘一个 `[4096, 4096]` 的参数矩阵：2 × 1 × 4096 × 4096 ≈ 3355 万次运算。规律是：**每个参数被这个 token 用到一次，贡献 2 次运算**（一乘一加）。

**推广到整个模型。** 模型的参数绝大部分都在这类矩阵里，所以经验法则：

- 处理 1 个 token ≈ **2 × 参数个数** 次浮点运算；
- 7B 模型：2 × 70 亿 = **约 140 亿次（14 GFLOP）每 token**；
- 处理 1000 个 token 的输入约 14 TFLOP（14 万亿次）。

这个估算忽略了"每个字和前面的字互相比较"那部分计算，它随文字长度增长，文字很长时才显著。
