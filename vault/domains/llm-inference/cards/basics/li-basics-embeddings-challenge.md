## Q
**挑战。** 同事做语义搜索：把一句话里每个 token 查嵌入表得到的向量取平均，当作这句话的向量。测试发现两件怪事："狗咬人"和"人咬狗"的相似度是 1.0；"苹果发布新手机"和"苹果很甜"里的"苹果"是同一个向量。假设每个字是一个 token，解释原因并给出改法。

## A
**评分点（答出 3 条算过）：**

1. 查表得到的嵌入只由 token 编号决定，和上下文、位置都无关：同一个 token 在任何句子里都是同一行。
2. 取平均与顺序无关：两句话的 token 相同、顺序不同，平均值完全相同，相似度就是 1.0。
3. 多义词要靠上下文区分：向量经过各层注意力之后，才混入了周围 token 和位置的信息。
4. 改法：用模型处理完整句后的隐藏状态来得到句向量，或直接用专门训练的嵌入模型。
5. 回归用例：准备"字相同、顺序不同"和"同词不同义"的句对。

<details class="pt"><summary>参考答案</summary>嵌入表只是按 token 编号查出一行向量，同一个 token 无论出现在哪句话、哪个位置，查到的都是同一行，所以两个"苹果"完全相同。取平均又是一个和顺序无关的运算，"狗咬人"和"人咬狗"由同样三个 token 组成，平均值相同，相似度就是 1.0。词在句子里的意思和词序，是向量经过各层注意力、混入上下文和位置信息之后才有的。所以应该用模型处理完整句后的隐藏状态，或者用专门训练的嵌入模型来生成句向量。</details>
