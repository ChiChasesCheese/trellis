## Q
嵌入（embedding）是什么？模型怎样把一个 token 编号变成一个向量？用 7B 模型的数字说明。

## A
**嵌入就是"查表"：每个 token 编号对应表里的一行，这一行是一个很长的数字列表（向量）。** token 是文字被切成的小片段，每个片段有一个整数编号。

**以 7B 模型（Llama 2 7B 的结构）为例：**
- 词表 32,000 个 token，每个 token 对应 4,096 个数。
- 嵌入表是一个 `[32000, 4096]` 的矩阵，共约 **1.31 亿个参数**，FP16 约 262 MB。
- 输入编号 `[1, 15043, 3186]`（3 个 token），就取出第 1、15043、3186 行，得到形状 `[3, 4096]` 的张量。

```python
emb = torch.nn.Embedding(32000, 4096)   # 可训练的查找表
ids = torch.tensor([1, 15043, 3186])
x = emb(ids)                            # 形状 [3, 4096]，就是取 3 行
assert torch.equal(x[0], emb.weight[1])
```

**为什么要变成向量：** 编号本身没有意义，15043 和 15044 不代表两个词相近。变成向量后，模型可以用乘法和加法去比较、组合它们。

**表里的数从哪来：** 和其他参数一样是训练出来的。一开始随机，训练中被调整到"用法相近的词，向量也相近"。

**计算代价：** 查表只是按行复制，几乎没有乘法运算，所以嵌入层虽然有 1.31 亿参数，计算量可以忽略。这和后面的矩阵乘法层很不一样：后者每个 token 都要用到每一个参数。

**之后发生什么：** 这个 4,096 维的向量叫隐藏状态（hidden state），它会依次流过模型的每一层，每层都在它上面加上新的信息，宽度始终保持 4,096。
