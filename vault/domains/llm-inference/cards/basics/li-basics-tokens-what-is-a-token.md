## Q
大模型说的 token 是什么？为什么模型不直接处理字或单词？

## A
**token 是文字被切成的小片段，每个片段对应一个整数编号。** 模型只会处理数字，所以文字进模型前必须先变成一串编号，模型输出的编号再变回文字。

**例子（不同模型的切法不同，以下示意）：**
- `"Hello world"` → `["Hello", " world"]` → `[15496, 995]`（GPT-2 的分词器）
- `"unbelievable"` → `["un", "believ", "able"]`，一个长词被切成 3 段
- 中文：常见汉字通常 1 个 token；词表里没有的字会被拆成 UTF-8 字节，一个汉字最多 3 个 token

**为什么不按字或按单词：**
- **按单个字符：** 词表很小，但一句话变得极长，模型要一步步处理更多位置，又慢又难学。
- **按完整单词：** 世界上的词无穷多，新词、拼写错误、代码变量名都会遇到"没见过的词"。
- **折中——子词（subword）：** 常见词整个保留，罕见词拆成常见片段。任何文字最终都能拆到字节，不存在"无法表示"的输入。最常用的切分算法叫 BPE（byte pair encoding，字节对编码），从单字节开始，反复把最常一起出现的两段合并成新 token。

**词表（vocabulary）：** 所有 token 的列表，大小是模型的固定属性。Llama 2 的词表 32,000 个，Llama 3 扩到 128,256 个。词表越大，同样文字切出的 token 越少，但模型最后一层要给每个词表项打分，计算也越多。

**经验数字：** 英文约 1 个 token ≈ 4 个字符 ≈ 0.75 个单词。API 计费、上下文长度上限、速度指标（token/s）全都以 token 为单位，而不是字或词。
