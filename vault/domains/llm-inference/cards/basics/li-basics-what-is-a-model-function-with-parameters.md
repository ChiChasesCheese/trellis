## Q
AI 里说的"模型"（model）到底是什么？从一个后端工程师熟悉的角度解释，并说明"参数"（parameter）指什么。

## A
模型就是一个**函数**：给它输入，它算出输出。和普通函数不同的是，函数里有大量**可调的数字**，这些数字决定了它算得准不准。

- **最小的例子：** 预测房价 `price = w * area + b`。`area` 是输入，`price` 是输出，`w` 和 `b` 就是参数。`w = 3.2`、`b = 50` 时，100 平米预测 370 万。换一组 `w`、`b`，同样的输入会得出不同的输出。
- **参数也叫权重（weight）：** 两个词在日常使用里基本可以互换，严格说 `w` 这类乘上去的数叫权重，`b` 这类加上去的数叫偏置（bias），合起来都算参数。
- **参数从哪来：** 不是人写的，而是用大量"输入—正确答案"的例子自动调出来的，这个过程叫训练（training）。调好之后参数就固定了，拿它去回答新问题叫推理（inference）。
- **大模型只是参数多：** 一个"7B 模型"有约 70 亿个参数（B = billion，十亿）。结构比 `w * x + b` 复杂得多，但本质一样：输入一串数，经过固定的乘法和加法，输出一串数。
- **和普通程序的区别：** 普通程序的逻辑写在代码里，能逐行审查；模型的"逻辑"藏在几十亿个数里，没人能逐个读懂。所以检查模型对不对，只能看它的输出：和参考答案、和上一个版本比。

一句话：模型 = 固定的计算结构 + 训练好的参数。代码描述"怎么算"，参数文件决定"算出什么"。
