## Q
为什么 AI 计算要用 GPU 而不是 CPU？两者在设计上的根本区别是什么？

## A
**CPU 的设计目标：快速完成一串复杂、有分支的指令。** 少数几个到上百个强大的核，每个核有复杂的分支预测、乱序执行、大缓存。擅长跑操作系统、数据库、Web 服务这类"逻辑多、分支多"的代码。

**GPU 的设计目标：同时对海量数据做同一种简单运算。** 成千上万个简单的计算单元，同一时刻对不同数据执行同一条指令。最初为图形渲染设计（每个像素做同样的计算），后来发现矩阵乘法完全符合这个模式。

**数字对比（数据中心级，约 2023–2024 年）：**
- 一颗服务器 CPU：几十到一百多个核，FP32 算力几 TFLOPS（每秒几万亿次）。
- 一块 NVIDIA H100 GPU：132 个流式多处理器（SM，streaming multiprocessor，可理解为 GPU 里的"大核"），每个 SM 内有大量计算单元和专门做矩阵乘法的 Tensor Core。BF16 稠密矩阵乘法峰值约 **989 TFLOPS**，比 CPU 高两个数量级。

**为什么矩阵乘法适合 GPU：** `[64, 4096] × [4096, 4096]` 的结果有 26 万个格子，每个格子的计算互相独立，可以同时分给成千上万个单元。神经网络 90% 以上的计算都是这种运算。

**GPU 不擅长什么：** 分支多、串行依赖强的逻辑，比如分词、调度、处理 HTTP 请求。所以推理服务里，CPU 负责收请求、分词、调度、拼结果，GPU 只负责矩阵运算，两者之间通过 PCIe 总线传数据。这条分工线上的数据搬运和同步，是推理服务常见的性能瓶颈和故障点。
