## Q
面试里被问"解释一下梯度下降，学习率和 batch size 怎么选"，怎么答？

## A
按这个顺序说，每点一两句：

- **先说目标：** 训练就是找一组参数让损失函数最小。损失函数衡量预测和正确答案的差距，回归常用均方误差，分类常用交叉熵。
- **再说梯度和更新：** 梯度是损失对每个参数的偏导数，指向损失上升最快的方向。每一步把参数往梯度的反方向挪一点：`w ← w − 学习率 × 梯度`。这一步的梯度用反向传播一次算出所有参数的。
- **学习率的取舍，用一个例子：** 在 `L = w²` 上，学习率 0.1 稳定收敛，1.1 就来回震荡越跳越远。太大发散或出 NaN，太小收敛极慢。实践中用预热加衰减，比如前几千步线性升高，之后余弦下降。
- **batch size 的取舍：** 全量数据算一步太贵，单条样本噪声太大，所以用小批量。批大，梯度准、GPU 利用率高，但占显存、要相应调大学习率；批小，噪声大但可能泛化更好。显存不够用梯度累积。
- **怎么判断选得对不对：** 看训练和验证集的损失曲线。训练损失震荡或 NaN，先降学习率；训练损失降但验证损失升，是过拟合，不是学习率的问题。
- **收尾连到自己的工作（测试工程师的角度）：** 训练脚本的可复现性要固定随机种子、数据顺序和批大小；比较两个版本时，确认它们的学习率和批大小配置一致，否则损失曲线的差异没有意义。

控制在一分半钟以内，被追问再展开公式或优化器（如 Adam）。
