## Q
常见的激活函数（activation function）有哪些？sigmoid、tanh、ReLU、GELU、SiLU 各有什么特点，为什么大模型不用 sigmoid 做中间层？

## A
**激活函数：** 神经网络每一层在矩阵乘法之后逐元素套用的一个非线性函数。没有它，多层线性运算叠起来仍然等于一层，网络学不到复杂规律。

| 函数 | 公式 | 输出范围 | 特点 |
|---|---|---|---|
| sigmoid | 1 / (1 + e⁻ˣ) | (0, 1) | 导数最大 0.25，深层网络梯度逐层变小 |
| tanh | (eˣ − e⁻ˣ)/(eˣ + e⁻ˣ) | (−1, 1) | 以 0 为中心，但两端同样饱和 |
| ReLU | max(0, x) | [0, ∞) | 计算最便宜，正区间导数为 1 |
| GELU | x × Φ(x) | 约 [−0.17, ∞) | ReLU 的平滑版，BERT、GPT-2 使用 |
| SiLU（Swish） | x × sigmoid(x) | 约 [−0.28, ∞) | 平滑，Llama 系列在 SwiGLU 里使用 |

Φ(x) 是标准正态分布的累积分布函数。

**为什么中间层不用 sigmoid：**
- **梯度消失：** 反向传播（从输出往回逐层算梯度）要连乘每层的导数，sigmoid 的导数最大只有 0.25，输入绝对值大时接近 0（"饱和"）。10 层之后梯度缩小到百万分之一，前面的层学不动。
- **输出不以 0 为中心：** 全是正数，会让下一层权重的更新方向偏向同号，收敛慢。
- **计算 eˣ 比 ReLU 贵。**
- sigmoid 仍然用在输出层做二分类概率，或用在门控结构里。

**ReLU 的问题：** 输入为负时导数为 0。如果某个神经元的输入一直为负，它永远不再更新，称为"死亡 ReLU"（dead ReLU）。Leaky ReLU（负区间给 0.01 的斜率）、GELU、SiLU 都缓解了这一点。

**对推理实现的意义：** GELU 有精确版（用误差函数 erf）和 tanh 近似版，两者结果有微小差异。推理引擎用的版本必须和模型训练时一致（配置里如 `hidden_act: "gelu_pytorch_tanh"`），否则会产生系统性的小偏差。
