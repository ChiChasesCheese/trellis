## Q
L1 正则和 L2 正则分别是什么？为什么 L1 会让很多权重恰好变成 0，而 L2 只让权重变小？

## A
**正则化（regularization）：在损失函数上加一个"惩罚参数太大"的项，迫使模型用更简单的方式拟合数据，从而减少过拟合（死记训练数据、对新数据表现差）。** 权重就是模型里训练出来的数字。

- **L1 正则：** 损失 + `λ × Σ|w|`（所有权重绝对值之和）。
- **L2 正则：** 损失 + `λ × Σw²`（所有权重平方和），也常写成 λ/2 倍。λ 控制惩罚强度。

**为什么效果不同——看惩罚项对每个权重的"推力"（梯度）：**
- **L2 的推力是 `2λw`，与 w 成正比。** w = 10 时推得很猛，w = 0.01 时推力几乎为 0。所以权重会被压小，但越接近 0 推得越轻，很难恰好到 0。效果：所有权重都变小、分布均匀。
- **L1 的推力是 `λ × sign(w)`，大小恒定。** 不管 w 是 10 还是 0.01，都以同样的力推向 0。小权重会被一路推到恰好为 0 并停在那里。效果：很多权重变成 0，模型**稀疏**（sparse）。

**手算（λ = 0.1，学习率 1，只看惩罚项，从 w = 0.3 开始）：**
- L2：每步 w ← w − 0.2w = 0.8w：0.3 → 0.24 → 0.192 → 0.154……一直变小但不为 0。
- L1：每步 w ← w − 0.1：0.3 → 0.2 → 0.1 → **0**，三步归零（实现上越过 0 就截断为 0）。

**几何直觉：** L1 的约束区域是菱形，角在坐标轴上，最优点容易落在角上（某些坐标为 0）；L2 的约束区域是圆，最优点一般不在轴上。

**怎么选：**
- 想做**特征选择**、希望模型只用少数特征：L1（Lasso 回归）。
- 只想防止过拟合、特征之间相关性强：L2（Ridge 回归），深度学习里的权重衰减就是它。
- 两者结合：Elastic Net。
