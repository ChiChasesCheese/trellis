## Q
**sort 为什么对有序数据几乎免费**｜Python · CPython 3.14

对已经有序、完全倒序、完全随机的 10 万个元素分别调用 `sorted`，比较次数各是多少？

## A
**结构。** Timsort：先扫出数据里已有的升序或严格降序段（run，降序段原地翻转），太短的段用二分插入排序补到 `minrun`，再把相邻的 run 归并。

**细节。**

- 实测比较次数：有序 99999，倒序 99999，随机约 153 万（`n·log2 n` 约 166 万）。
- `minrun` 在 32 到 64 之间，取值让 run 数接近 2 的幂，归并尽量平衡。
- 值全相等也只要 99999 次。

**为什么。** 真实数据常常是部分有序的，利用已有的顺序就能把最好情况降到 O(n)；最坏仍是 O(n log n)。
