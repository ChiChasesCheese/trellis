## Q
**Session 要同时管好什么**｜SQLAlchemy · 2.0.55

ORM 会话让你把数据库的行当 Python 对象来用。它要支持哪些操作？为什么「每次都新建对象、每次赋值立刻写库」行不通？

## A
**背景。** ORM（对象关系映射）让你这样用数据库：`u = session.get(User, 5)` 取出一行，`u.name = "x"` 修改，`session.commit()` 保存。会话（Session）要满足：

| 操作 | 要求 |
|---|---|
| 按主键取对象 | 同一行永远是同一个对象，取过就不再查库 |
| 改属性 | 立刻记账，但不立刻发 SQL |
| 新增、删除对象 | 先记在待办里，提交时才生效 |
| 写回（flush） | 只写真正变了的，按外键依赖排好顺序 |

两种朴素做法都会出问题：

- 每次查询都新建对象：同一行有了两个对象，各改各的，后写的盖掉先写的
- 每次赋值立刻 UPDATE：改三个属性发三条 SQL；子表的行先 INSERT，父表的行还没写，外键报错

所以需要三样东西：认对象的表、记改动的集合、写回时的排序。
