# RFC 8656 — Traversal Using Relays around NAT (TURN)
值得读：明确指出某些 NAT 组合（地址依赖/地址端口依赖映射）下打洞技术必然失败,
必须用中继,并且中继对服务提供方而言"成本很高"。本题解「深入探讨」第 2 节把这
句定性描述转化成了中继服务器容量的具体数字（约 6,374 台,承载能力约为普通媒体
节点的一半）。
