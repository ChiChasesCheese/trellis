# Automatic bidding — eBay Help

值得读：eBay 官方帮助文档，披露了完整的价位递增表（按当前价格区间给出对应的最小加价
幅度，从 0.01–0.99 美元区间的 0.05 美元到 5,000 美元以上区间的 100 美元）以及代理出价
"只加到刚好压过对手一个增量"的机制说明——这是真实生产系统里代理出价规则的第一手文档，
比大多数题解停留在"系统会自动帮你出价"这句笼统描述要精确得多。本题「深入探讨」第 3 节
用这张真实的表复现了一个具体的端到端解析例子，原文只给出规则和表格本身。
