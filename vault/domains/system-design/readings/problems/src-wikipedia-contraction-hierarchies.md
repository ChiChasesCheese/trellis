# Contraction hierarchies

值得读：Contraction Hierarchies（CH）算法本身的概念性说明——节点收缩（contraction）
如何添加捷径边（shortcut）、查询时如何靠"只沿更重要节点方向搜索"压缩搜索空间、节点
重要性排序为什么是启发式而非精确最优（精确最优是 NP 完全问题）。本题解「深入探讨」
第 2 节的算法描述以此为基础；原始论文（Geisberger, Sanders, Schultes, Delling,
WEA 2008）的具体实验数字（西欧路网规模、预处理时间、查询时间）本题解未能直接核对
