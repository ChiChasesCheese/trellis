# A Brief Primer on Anycast

值得读：Cloudflare 自己解释 anycast 路由机制、故障切换为什么是网络层的即时动作而不
是 DNS 层的分钟级动作。题解用它作为「深入探讨」第 1 节和第 5 节（PoP 故障切换）里
anycast 论证的来源，比多数二手教程更贴近机制本身；网络规模的具体数字（348 个城市）
另见 Cloudflare 官网 Network 页面，这篇博客本身没有给出该数字。
