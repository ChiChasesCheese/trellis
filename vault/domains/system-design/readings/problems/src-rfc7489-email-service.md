# RFC 7489 — Domain-based Message Authentication, Reporting and Conformance (DMARC)
值得读：定义了"对齐"（alignment）——要求 SPF 或 DKIM 验证通过的域名与用户看到的
`From:` 头域名一致，并提供 none/quarantine/reject 三级策略与聚合报告。本题解
「深入探讨」第 2 节用它作为 SPF、DKIM 各自的结构性空当被它填上的论据，是三者
关系里唯一"强制身份对齐"的一环。
