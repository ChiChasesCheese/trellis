# System Design — Netflix

值得读：一份免费、原创的开源系统设计笔记集合（不是付费课程或书籍的镜像），给出了
Netflix 架构的组件划分和术语速览，本题解用它做整体组件划分的交叉印证。本题解与它不
同的地方在于：它没有给出可验证来源的容量数字，本题解的所有数字要么现场用真实上传量
（500 小时/分钟）计算得出，要么直接引用 Netflix 官方工程博客（见另两篇来源），不采用
本仓库未注明出处的估算。
