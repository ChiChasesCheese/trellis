# Using Market Data — Robinhood Support

值得读：Robinhood 自己的支持文档，说明它的报价来源于 Nasdaq Last Sale（盘中）或另类
交易系统 ATS（盘后），常规时段展示 Nasdaq Bid/Ask（QBBO），并明确成交必须满足监管要求的
全美最优买卖价（NBBO）。它只讲经纪商如何获取报价，不涉及如何把报价分发给百万级订阅者——
本题「需求」一节采纳了 NBBO 这条外部监管约束，「深入探讨」第 3 节的合并（conflation）
分发模型是本文自己建立的，原文没有给出。
