# Design Pastebin.com (or Bit.ly)

值得读：作为被广泛引用的开源模板，它把这道题的范围划得很克制——明确排除账户体系、内容编辑等功能，先谈用例与约束再谈架构。本题解沿用了它"先划清范围再谈架构"的顺序，但把它一笔带过的点击分析需求单独展开成了一个独立的深入探讨小节，并给出了具体的异步管道设计。
