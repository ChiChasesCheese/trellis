储），并提到"Google Docs 根据维基百科使用 OT，CRDT 是活跃的研究方向"，但未展开具体的转换
算法、富文本格式处理或任何容量数字。本题解的容量估算、服务器权威控制回路和富文本深入探讨
都是这份指南完全没有覆盖的部分。
