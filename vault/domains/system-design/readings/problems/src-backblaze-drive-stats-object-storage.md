# Backblaze Drive Stats for 2025

值得读：Backblaze 每年公开自己运营的数十万块硬盘的真实故障统计，2025 年度报告
给出年故障率（AFR）1.36%，是实测数据而不是厂商标称的 MTBF。题解「深入探讨」第 3
节的耐久性算术（三副本 vs 纠删码的年丢失概率）直接用这个数字做失效模型的输入，
并在正文中说明这是一个独立分片故障率、忽略相关性和修复窗口的简化假设。
