## Q
你 review 一个 PR 时专盯并发问题，放行了。上线后才发现同一屏里有个明显的数组越界。专心找一样东西时，眼前别的大问题能漏到什么程度？专家也会吗？

## A
**非注意盲视（inattentional blindness）：注意力盯着一件事时，眼前发生的另一件大事可以完全看不见。**

**故事。** 2013 年，Drew、Võ 和 Wolfe 请 24 位放射科医生在一组肺部 CT 里找结节，这是他们每天做的事。在最后一例里，研究者在图像中放了一只大猩猩的图案，面积超过平均结节的 48 倍。83% 的医生没有看到它。眼动仪显示，其中多数人的视线直接扫过了那只猩猩。

- **证据 · 强：** 这个范式来自 Simons 和 Chabris 1999 年的实验：228 人数篮球传球次数，约一半的人没发现走进画面、扮成大猩猩的人。放射科的结果说明专家也会这样，但医生只有 24 位，场景是人为插入的。
- **谁在用：** 魔术师靠引开注意力，让观众看不见真正的动作。
- **动手：** 下次你做 code review 或排查线上问题时，先定下你要找的东西，找完一遍后，把「找的目标」换掉再扫一遍：这次只问「还有什么不对劲」，别带着刚才的问题看。
