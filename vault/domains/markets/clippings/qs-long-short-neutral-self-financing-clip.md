# 多空、中性、自融资:用 FX value 当例子讲清楚

用项目里最好的策略([G10 FX value](../ideas/fx-value.md))当活例子讲透:多空、美元中性、自融资、为什么看 Sharpe 不看收益率、怎么和 SPY 比——以及为什么一个"年化才 6.6%"的策略在 quant 眼里是块宝。

## 1. 多头 vs 空头(long / short)

- **做多(long)**:买入,赌它**涨**。涨了赚,跌了亏。普通人买股票都是做多。
- **做空(short)**:**借来**一个东西**卖掉**,赌它**跌**;跌了再低价买回还回去,赚差价。跌了赚,涨了亏。

做空的关键细节:你卖空时**先收到一笔现金**(卖掉借来的东西得来的)。记住这点,后面"自融资"要用。

## 2. 多空策略(long-short)

不只买,而是**同时**买一批、卖空另一批:
- 买入你认为**被低估/会涨**的(多头腿)。
- 卖空你认为**被高估/会跌**的(空头腿)。

赚的是**两边的相对差**(多头相对空头多涨/少跌),而不是赌整个市场涨跌。

**FX value 就是这样**:把 9 个发达货币按"离 3 年均值多远"排序,**做多最便宜的、做空最贵的**,赌便宜的相对贵的回归。

## 3. 美元中性 / 市场中性(dollar / market neutral)

如果多头和空头的**金额一样大**(各 100 块),那么整体**对大盘的净暴露≈0**:
- 大盘整体涨,你多头赚的 ≈ 空头亏的 → **相抵**。
- 你赚的纯粹是"多头相对空头"那一点,**不赌方向**。

FX value 是**美元中性**:它不赌美元整体涨还是跌,只赌"哪些货币相对哪些回归"。所以它和股市的相关性≈0(**beta≈0**),股市崩了它不一定跟着崩 —— 我们实测它在 [COVID-2020 反而 Sharpe +2.34](../ideas/fx-value.md)。

## 4. 自融资 / 不占净现金(self-financing)

拿 100 块走一遍,对比两种策略:

| | 只做多 SPY | 多空中性(FX value) |
|---|---|---|
| 你做什么 | 拿 100 块买 SPY | 做多 100 块便宜货币 + 做空 100 块贵货币 |
| 现金流 | **100 块被锁进 SPY** | 卖空**收到 100 块** → 拿去买多头 → **自己几乎没掏钱** |
| 你那 100 块 | 占用了,**放弃了国债的 ~4%** | **还在国债里吃 4%**,没被锁 |

**多空中性是"自融资"的:空头卖出收到的现金,正好养多头。** 你没把一笔净资本押进去,所以这 100 块还能照样吃无风险利率。

> (现实里卖空有借券费、保证金要求,所以是**近似**自融资,不是分文不掏 —— 但原理成立。)

**这有个直接后果(关于 Sharpe 怎么算)**:
- **只做多**占用现金 → 它的收益要**减掉**你放弃的无风险利率(那 4% 是基准)。
- **多空中性**不占净现金 → 它的收益**本身就是超额**,叠在你照样能拿的无风险利率之上 → **没有无风险利率要减,Sharpe 直接用 `收益/波动` 就是对的**。

(本框架 `compute_metrics` 默认无风险利率=0 —— 对自融资中性策略是准的;对净多头可传 `risk_free=0.04` 减掉无风险利率得到公平 Sharpe,见 [指标](../reference/metrics.md)。实测:一个长多头美股篮子 rf=0 时 Sharpe 0.73,减 4% 后公平值 0.51,**反而低于 FX value 的 0.61**。)

## 5. 为什么 quant 看 Sharpe,不看收益率

**[Sharpe 比率](../reference/metrics.md)** = 年化收益 ÷ 年化波动 = "每承担一份风险,赚多少"。

收益率为什么不靠谱:**它可以用杠杆随便放大**。杠杆把收益和**回撤一起**等比例放大:

| 杠杆 | 年化收益 | 最大回撤 |
|---|---|---|
| 1x | 6.6% | -17% |
| 2x | ~13% | -34% |
| 4x | ~26%(还更低)| **~-68%,坏年份奔 -90%** |

而且杠杆越高,**波动拖累(volatility drag)** 越狠 —— 复合收益里要扣 `(杠杆×波动)²/2`,这个减项随杠杆**平方级**增长,到某个点**再加杠杆复合收益不升反降**。所以 4x 是"回撤爆炸 + 收益还缩水",没人会干。

**结论:杠杆改变收益,但改不了 Sharpe(风险调整后的效率是钉死的)。** 所以衡量一个策略"本事"的是 Sharpe,不是收益率。想安全拿高收益,要找**更高 Sharpe** 的策略,不是给低 Sharpe 加杠杆。

**Sharpe 的体感**(年化 Sharpe ≈ 正收益年份的概率):

| Sharpe | 水平 | ≈ 多少年是赚的 |
|---|---|---|
| ~0.45 | 标普 500 自己 | ~67% |
| **0.61** | **FX value(体面)** | **~73%** |
| ~1.0 | 优秀,对冲基金级、罕见 | ~84% |
| 2+ | 慢策略里几乎一定过拟合 | — |

**基准线是 Sharpe 0(无技能),不是 1。** 1 已经很强了。所以 0.61 是"高于股市、落在真实因子合理区间"的体面成绩。

## 6. 和 SPY 对比:它们是两种东西

| | SPY(标普 500) | G10 FX value |
|---|---|---|
| 类型 | 净做多,纯 **beta**(大盘暴露) | 多空,**市场中性**(beta≈0) |
| 占用现金 | 是(要减无风险利率) | 否(自融资) |
| 年化 | ~10% | ~6.6%(默认仓位) |
| 最大回撤 | **-50%+** | **-17%** |
| 危机表现 | 崩(2008 -55%、2020 暴跌) | **抗跌甚至赚**(COVID +2.34) |
| 和股市相关 | =1(它就是股市) | ≈0(独立) |

**不是"谁更好",是"互补"。** SPY 给你市场的长期增长但回撤巨大;FX value 给你一份**和股市无关、危机里还正**的温和收益。

## 7. 为什么中性策略是"分散器"(diversifier)

**不相关的 Sharpe 能叠加。** 两个 Sharpe 0.6、互不相关的策略拼起来,组合 Sharpe ≈ `0.6 × √2 ≈ 0.85`;三个 ≈ 1.0。

所以 FX value 单看 6.6%/年不性感,但把它**拼进一个以股票为主的组合**里,它的价值是:
- 在股市崩的时候它不跟着崩(甚至赚)→ **拉低整体回撤**。
- 和股票收益不相关 → **抬高整体 Sharpe**。

**这就是机构做这类因子的真正用法:当卫星仓 / 分散器,不是单打独斗去搏高收益。** 几块不相关的 0.6 拼到组合 1.0+,那时再温和加点杠杆,才是安全地把收益做上去的路子。

## 术语小词典

| 词 | 大白话 |
|---|---|
| 多头 / long | 买入,赌涨 |
| 空头 / short | 借来卖掉,赌跌 |
| 多空 / long-short | 同时买一批、空一批,赚相对差 |
| 美元/市场中性 | 多空金额相等 → 不赌大盘方向,beta≈0 |
| 自融资 / self-financing | 空头收到的现金养多头,不占你的净现金 |
| beta | 跟大盘一起动的程度(1=就是大盘,0=不相关) |
| Sharpe | 收益÷波动,每份风险赚多少;衡量"本事",与杠杆无关 |
| 波动拖累 | 高杠杆下复合收益被波动平方吃掉 |
| 分散器 | 和现有持仓不相关的收益,拼进组合降波动/抬 Sharpe |
