# 家族 5:规模与流动性(Size & Liquidity)

> **核心概念(从零讲)**:**小公司、不好买卖的资产,长期回报更高 —— 因为它们"难搞"。** 规模(size):小盘股历史上跑赢大盘(但很不稳定)。流动性溢价:一个你想卖时卖不掉、买卖要付大价差的资产,必须用**更高的预期回报**来补偿你忍受这种不便。**为什么存在(风险溢价 + 结构性)**:大机构进不了小盘/不流动标的(容量太小、冲击成本太大),它们被"晾在"散户和小基金手里,定价更低、回报更高。**谁在另一边亏 / 谁付溢价**:急着变现的人付出流动性折价;你提供流动性、忍受不便,收这个租。

> ⚠️ size 因子是**最不稳定**的经典因子之一(很多年不灵、且大量是垃圾股/微盘噪音),需和质量结合("小而优"才行)。流动性溢价更真,但**容量极小** —— 赚得了小钱,放不进大资金。

## 方向清单

35. **规模因子(Size / SMB)** — 买小盘、卖大盘。**教**:Fama-French 三因子、size 的不稳定性。**谁亏**:无法配置小盘的大机构。**坑**:大量是垃圾股,需质量过滤。
36. **微盘 / 小小盘** — 越小溢价越强但越脏(流动性、数据、操纵)。**教**:容量 vs 溢价的权衡。**坑**:回测里的微盘收益常常是无法成交的幻觉。
37. **Amihud 非流动性** — 用"单位成交额带动多大价格变化"衡量不流动,买不流动的收溢价。**教**:Amihud 指标、流动性定价。**状态**:本项目实测发现它常是 **size/ETF-short 的伪信号**(和 -成交额高度相关),要小心证伪。
38. **买卖价差溢价** — 直接用报价价差排序,买高价差(不流动)标的。**教**:价差作为流动性代理。**数据**:盘口/报价数据。
39. **成交量冲击 / 换手率** — 低换手率股票(被"遗忘")长期回报更高。**教**:关注度、被遗忘溢价。
40. **流动性提供 / 做市返佣** — 在不流动标的上挂限价单提供流动性,赚价差 + 交易所返佣。**教**:做市、限价单、逆向选择风险。**坑**:本质是 [微观结构](08-microstructure-intraday.md)策略,需低延迟。
41. **小盘 × 质量("小而优")** — 只在小盘里选质量高的,过滤掉垃圾股,救活 size 因子。**教**:因子交互、为什么纯 size 不灵但"小而优"行。

## 共同的坑

- **容量墙**:流动性溢价的钱**装不下大资金** —— 你一买就把价差吃掉了。回测的高收益常常无法在真实规模下复现。
- **成本幻觉重灾区**:不流动 = 成本高,回测若用中间价/低成本假设,会严重高估。必须用 realistic per-asset 成本(Corwin-Schultz 价差等,见 [成本与价格](../deep/costs-and-prices.md))。
- **幸存者偏差**:小盘退市/破产多,必须用[去偏差 universe](../concepts/why-backtests-lie.md),否则"小盘溢价"全是没死的幸存者。
