# 家族 7:事件驱动与基本面(Event & Fundamental)

> **核心概念(从零讲)**:**信息不是一瞬间被消化的,是慢慢扩散的。** 财报、并购、指数调整、回购这些"事件"发生后,价格往往不一步到位,而是几天到几周慢慢漂移 —— 因为人**反应不足**、机构**逐步调仓**、散户**后知后觉**。**为什么存在(行为偏差 + 结构性)**:注意力有限、信息处理慢;有些是制度强制(指数基金必须在调整日买入)。**谁在另一边亏**:反应慢的人、被规则逼着在可预测时点交易的指数基金。**这一类最接近"真 alpha"**,因为它有明确的催化剂和"谁在另一边"。

## 方向清单

51. **盈余漂移(PEAD)** — 财报超预期(SUE 高)的股票,财报后还会继续漂涨几周。**教**:盈余惊喜 SUE、反应不足、最经典的"半强式有效市场反例"。**谁亏**:反应慢的散户。**数据**:盈余 + 分析师预期(免费 SUE 太噪,真 PEAD 需付费预期)。**状态**:本项目 A股测过,**可部署形态被拒**(裸 L/S 看着强,但 alpha 几乎全在"做空底部分位单股"那条腿,A股单票不能做空 → 塌掉;`research/rejected/cn_pead.md`)。
52. **分析师预期修正** — 分析师上调盈利预期的股票继续涨(预期修正也是慢扩散)。**教**:预期 vs 实际、修正动量。**数据**:分析师预期(付费)。
53. **并购套利(Merger Arb)** — 收购公告后,被收购方股价低于收购价(因交易可能黄),买入赚这个价差(deal spread),赌交易完成。**教**:事件概率、deal risk、为什么这是"卖保险给套利失败"。**谁亏**:怕交易黄而抛售的人。**坑**:交易失败时暴亏(负偏)。
54. **指数再平衡套利** — 股票被纳入/剔除指数前,抢先于被迫买入的指数基金建仓。**教**:需求冲击、结构性约束(指数基金必须在调整日成交)。**谁亏**:被规则逼着在可预测时点交易的指数基金。
55. **股票回购 / 增发** — 公司回购(看多信号 + 减少流通股)后股价偏强;增发(摊薄)偏弱。**教**:公司行为信号、供给变化。
56. **内部人交易** — 跟随公司高管的买入(他们最懂自家)。**教**:信息不对称、内部人信号。**数据**:监管披露(美股 Form 4 免费)。
57. **应计异象(Accruals)** — 盈利里"现金"成分高的公司未来更好,"应计"成分高的(可能盈余操纵)更差。**教**:盈利质量、现金 vs 应计。**数据**:财务报表。
58. **分拆 / 特殊事件(Spinoffs)** — 分拆出的子公司常被忽视、低估,后续跑赢。**教**:被忽视溢价、强制抛售(指数/基金不能持有分拆股)。
59. **财报日漂移 / 盈余公告溢价** — 财报日附近股票有系统性超额回报(承担不确定性的补偿)。**教**:事件溢价、不确定性定价。

## 共同的坑

- **数据是门槛**:真正的 edge(PEAD、预期修正)需要**分析师预期、PIT 基本面**等付费/难拿的数据;免费代理(用历史盈利算 SUE)信号太噪,常常证伪。
- **前视陷阱重灾区**:财务数据有**公告滞后**(pubDate),必须用"当时真正可得"的数据(本仓库 cn_panel 用 pubDate 对齐),否则严重前视。
- **容量 + 拥挤**:并购套利、指数套利早被专业基金占满,散户进去是接盘。
- **做空依赖**:很多事件因子的 alpha 在做空腿(超预期做多 + 不及预期做空),在禁空市场(A股单票)残废。
