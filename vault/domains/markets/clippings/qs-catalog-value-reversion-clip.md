# 家族 2:价值与均值回归(Value & Mean Reversion)

> **核心概念(从零讲)**:"太贵的会跌回来、太便宜的会涨回来"。**价值(value)**是慢速版(以年计):买便宜的资产(相对其基本面/历史均值),赌估值回归。**均值回归(mean reversion)**是快速版(以天计):价格短期偏离后弹回。**为什么存在**:价值是**风险溢价**(便宜的资产往往"看着危险",你扛住难受期收租)+ 过度反应的修正;短期反转是**流动性补偿**(有人急着卖压低了价,你接盘赚反弹)。**谁在另一边亏**:恐慌抛售的人、追逐光鲜成长股而抛弃"无聊便宜货"的人。

> ⚠️ **价值是典型的"风险溢价型 alpha"**:它平时赚、但在危机里(便宜的更便宜)会真亏 —— 这是它的定义,不是 bug。

## 方向清单

10. **股票价值因子(B/P、E/P、CF/P)** — 买低估值、卖高估值。**教**:估值比率、价值的风险溢价本质、价值长期跑输的"价值之冬"。**谁亏**:追成长弃价值的人。**数据**:PIT 基本面(EDGAR 免费)+ 复权价。
11. **G10 FX value** — 发达货币回归 3 年均值,便宜买贵卖,美元中性。**教**:购买力平价、为什么不拥挤的市场更可能活。**状态**:本项目曾视为 lead,**但在长样本上[被证伪](../ideas/fx-value.md)**(短窗口 artifact)—— 一个重要的诚实复盘。
12. **短期反转(1–5 日)** — 买过去几天跌最多的、卖涨最多的,赌反弹。**教**:流动性补偿、反转 vs 动量的时间尺度之分。**坑**:alpha 周期 < 交易成本周期 → 本项目实测 gross 强但净被成本吃光(见 [alpha 从哪来](../deep/where-alpha-comes-from.md))。
13. **配对交易 / 统计套利(Pairs / Stat-Arb)** — 找两个长期同涨同跌的标的,价差拉开时做多落后、做空领先,赌价差回归。**教**:协整、价差的均值回归、市场中性。**谁亏**:把价差推开的临时冲击。**坑**:协整关系会断裂(基本面变了)。
14. **协整篮子 / 多腿 stat-arb** — 不止两个,用一篮子构造一个均值回归的合成价差(更稳健)。**教**:协整向量、主成分。
15. **行业内相对价值** — 只在同行业内比估值(同质可比),剔除行业间差异。**教**:可比性、控制变量。
16. **盈利收益率 vs 债券收益率(Fed Model 变体)** — 股票 E/P 相对国债收益率极端时做多/空股市。**教**:跨资产相对价值、估值锚。
17. **商品现货-期货价值(展期均值回归)** — 期限结构极端时押回归。**教**:期货曲线、contango/backwardation。
18. **加密均值回归** — 高波动 + 散户主导 = 短期反转特别强;价格偏离后弹回。**教**:为什么散户市场反转更强。**数据**:crypto 分钟/小时线。**坑**:趋势市里反转会被趋势碾压,需 regime 过滤。

## 共同的坑

- **价值陷阱**:便宜有时是因为"该便宜"(基本面在恶化、要破产)。需配合质量/动量过滤(便宜 + 不在变差)。
- **盯住/结构性贬值标的**:像被钉住的汇率、长期贬值货币,"便宜"会永远便宜(见 [FX value 的坑](../ideas/fx-value.md))。
- 均值回归极易撞**成本墙**(高换手)和**前视**(用未来均值)—— 严格因果 + realistic 成本是生死线。
