# 家族 10:另类数据与机器学习(Alt-Data & ML)

> **核心概念(从零讲)**:**新数据 = 新 edge。** 传统价格/财务数据被挖烂了,但**别人还没用的数据**(新闻情绪、卫星图、信用卡流水、网页爬虫、供应链)里可能藏着没被定价的信息。机器学习(ML)则是**把很多弱信号非线性地组合**成强信号的工具。**为什么存在(信息优势)**:你比市场更早/更全地看到了某个真实变量。**谁在另一边亏**:还在只看财报的人。

> ⚠️ **这是坑最多的家族。** 另类数据贵、短(历史不够长 → DSR 难过)、且一旦有效就迅速被买断而失效。ML 极易过拟合 —— **复杂模型 + 少样本 = 完美的自欺机器**。本仓库纪律:ML 只用于**已验证因子的组合**,不用于"从价格里变魔术"(纯价格 ML 预测被反复证明无效,见下)。

## 方向清单

77. **新闻 / 社交情绪(NLP)** — 用语言模型给新闻、财报电话会、社媒打情绪分,预测股价。**教**:NLP 信号、情绪溢价、注意力。**数据**:新闻/社媒(部分免费如 Reddit/RSS)。**坑**:情绪已被大量基金消化,半衰期短。
78. **财报电话会语气 / 文本变化** — 管理层措辞的不确定性、与上季的文本差异预测风险。**教**:文本计量、软信息。
79. **卫星 / 地理空间** — 停车场车流(零售)、油罐阴影(原油库存)、夜间灯光(经济活动)。**教**:实物代理变量、信息领先。**数据**:卫星(贵)。
80. **供应链 / 关系网络** — 公司间的客户-供应商关系传导冲击(动量沿供应链扩散)。**教**:网络效应、动量溢出。
81. **搜索 / 网页流量** — Google Trends、App 下载、网站访问量预测需求。**教**:需求高频代理。**数据**:部分免费。
82. **ML 因子组合(树/集成)** — 用 GBDT/随机森林把几十个弱因子非线性组合。**教**:非线性组合、特征重要性、**为什么这容易过拟合**。**纪律**:严格 OOS + DSR,样本外验证组合而非单点。
83. **深度学习时序预测** — LSTM/Transformer 直接从价格序列预测。**教**:序列模型 —— **以及它的局限**。**现实**:[最新研究质疑](https://arxiv.org/abs/2606.27670)纯价格深度学习在 crypto 等的有效性;本仓库立场:**纯价格 ML 预测基本是过拟合,不碰**。
84. **强化学习执行 / 做市** — 用 RL 学最优下单/做市策略(而非预测价格)。**教**:RL 用在**执行**(有明确奖励)比用在**预测**更靠谱。
85. **因子动物园去伪(ML for factor selection)** — 用 ML + 严格统计(如 DSR、SHAP)从几百个已发表因子里筛掉假的。**教**:多重检验、因子复制危机(大部分发表因子无法复现)。

## 共同的坑

- **过拟合是头号敌人**:模型越复杂、数据越短,越容易拟合噪音。**复杂度必须配得上样本量**(见 [参数与过拟合的边界](../deep/parameters-and-hyperopt.md))。
- **数据短 + 贵**:另类数据往往只有几年历史 → 独立样本太少,**DSR 几乎必然过不了**;且贵。
- **失效快**:一旦某另类数据被证明有效,资金涌入迅速套利掉(alpha 半衰期短)。
- **ML 的正确用法**:用在**因子组合**和**执行优化**(有大量样本、明确奖励),**别用在"从价格变魔术"**。
