# Family 9: Macro & Cross-Asset

Covers top-down, cross-asset strategies keyed to yield-curve slope, credit-spread regime, and a growth/inflation quadrant framework for allocating across asset classes, alongside risk-on/risk-off timing and dollar-cycle effects. The headline, repeatedly-tested finding is a caution: macro state is a much better predictor of forward volatility than of forward return direction, so using it to time bull/bear exposure tends to misfire, it's late and often wrong-signed at V-shaped reversals, while using the same state purely to scale position size down ahead of expected volatility spikes is the version that has actually held up under honest testing.
