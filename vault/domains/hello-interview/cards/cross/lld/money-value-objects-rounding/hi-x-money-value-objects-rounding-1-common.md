## Q
**金额、取整与不可变值对象 (Money / Rounding / Immutable Value Objects)**｜跨题模式 · 共性

分期计划、计费计税、复式账本、钱包、直播分成，甚至日期时间库，这些题都在追问"金额怎么表示、哪里取整、对象要不要可变"。它们共用的设计规则是什么？必须成立的不变量是什么？不遵守会怎样？

## A
**规则：**
1. **金额用整数最小货币单位（加币种），或定点小数（Python 的 `Decimal`），不用浮点。** 币种决定小数位：日元 0 位，美元 2 位，科威特第纳尔 3 位。
2. **取整只在边界做一次，规则全系统唯一。** 中间计算保持全精度，每个输出金额取整一次；用哪种舍入（银行家舍入或四舍五入）由合同和监管决定，关键是只有一处实现。
3. **吸收误差的位置明确且固定。** 总额拆成多份时，余数由最后一期吸收，或分给前几期，写进规范；否则同一笔钱在不同实现里不一致。
4. **对象不可变。** 值对象（价格行、分录、日期）用不可变类型：线程安全，可作字典的键，任何一行金额都能被复现；改动产生新对象或新分录，不改旧的。

**不变量（守恒）：** 各期本金之和等于本金；每条分录各币种的腿之和为 0；展示值与由事件重算的结果对得上。

**不遵守会怎样：** 浮点的 `0.1 + 0.2 ≠ 0.3`，千万笔后账对不上；10000 分分 3 期各自四舍五入得 3333 × 3 = 9999，少 1 分；多处取整让误差系统性累积。
