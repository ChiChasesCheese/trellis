## Q
**HTTP 方法与幂等性**｜系统设计 · 核心概念

GET、POST、PUT、PATCH、DELETE 各自的语义是什么，哪些是幂等的？网络超时后客户端重试，为什么会出问题，幂等键（idempotency key）怎么解决？

## A
**要点。**
- GET：只读，幂等
- POST：创建，不幂等，调用两次就创建两个
- PUT：整体替换（不存在则创建），幂等
- PATCH：局部更新，不保证幂等：“把邮箱设为 X”是幂等的，“往列表追加”不是
- DELETE：删除，幂等（第一次返回 204，之后可能 404，但服务器状态相同）

**易错。** 幂等指重复请求后服务端状态不变。请求超时时客户端不知道服务器有没有处理，唯一办法是重试，POST 就可能重复订票、重复扣款。

**怎么解决。** 客户端为每个逻辑操作生成唯一 ID，放在请求头 `Idempotency-Key` 里。服务器把这个键和第一次的结果一起存下来，重试到达时直接返回已存的结果，不再执行。Stripe 的支付接口就是这样。

**取舍。** 凡是设计里有支付、订单、订座，主动说“用幂等键让重试不会重复订座”，比抽象地讲幂等更加分。
