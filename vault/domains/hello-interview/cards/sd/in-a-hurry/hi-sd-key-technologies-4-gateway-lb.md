## Q
**API 网关与负载均衡器**｜系统设计 · 速览

产品设计类面试里，API 网关和负载均衡器分别负责什么，应不应该画？怎么选 L4 还是 L7？

## A
**API 网关。** 位于系统前端，把请求路由到对应后端服务，并统一处理认证、限流、日志等横切关注点。产品设计题里几乎都值得作为客户端的第一接触点画出来；面试官很少深究它，更关心题目本身的细节。常见的有 AWS API Gateway、Kong、Apigee，也可以是 nginx。

**负载均衡器。** 凡是有多台能处理同一请求的机器，就需要它。面试里可当作黑盒，不必在每个服务前都画，只在最前面画一个，或者干脆说「服务已水平扩展」。

**L4 还是 L7。**
- 有持久连接（如 WebSocket）倾向 L4
- 其他情况用 L7，路由到不同服务更灵活，并减少下游连接数

**要知道的特性。** 有时需要粘性会话（sticky sessions）或持久连接。常见产品有 AWS ELB、NGINX、HAProxy。流量极高时，专用硬件比自建软件负载均衡更强，但那就进入网络工程领域了。
