## Q
**中间件怎么提才合适**｜系统设计 · 深入技术

网关能做的中间件很多，面试里该提哪些？应该花多少篇幅？

## A
**常见中间件。** JWT 鉴权、限流、SSL 终止、日志监控、响应压缩、CORS、IP 黑白名单、请求大小校验、超时、API 版本管理、流量整形、服务发现集成。

**重点。** 与面试最相关的是鉴权、限流、IP 黑白名单。

**说法。** 提中间件要有目的，不要展开。建议直接说「我会加一个 API 网关来做路由和基础中间件」，然后继续主线。

**易错。** 在网关上花太多时间比讲得不够更危险，它不是系统里最有意思的部分，容易挤掉真正的深入话题。
