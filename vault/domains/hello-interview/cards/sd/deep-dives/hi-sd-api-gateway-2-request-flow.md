## Q
**请求经过网关的六个步骤**｜系统设计 · 深入技术

一个请求从客户端到网关再到后端、再返回，网关依次做哪些事？

## A
**流程。**
1. 请求校验（validation）：URL、必要请求头、请求体格式是否合法，不合法就地拒绝并给出明确错误，省得后端白白处理注定失败的请求
2. 中间件：鉴权、限流等
3. 路由：按路由表转给对应服务
4. 后端处理并返回
5. 响应转换：整理成客户端要的格式
6. 可选缓存：存下响应供之后复用

**为什么先校验。** 越早拦住畸形请求（坏 JSON、缺 API key），越能保护内部服务。

**说法。** 面试里不必逐步展开，一句话带过即可。
