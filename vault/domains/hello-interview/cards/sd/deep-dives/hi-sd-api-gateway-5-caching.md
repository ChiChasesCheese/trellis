## Q
**网关层缓存什么、不缓存什么**｜系统设计 · 深入技术

网关可以缓存响应，什么样的响应适合缓存？有哪些缓存策略，缓存放在哪？

## A
**适合缓存。** 访问频繁、变化不大、而且与具体用户无关的数据；只要同一输入预期得到同一结果，就值得缓存。用户私有的响应不应在网关层共享缓存。

**策略。**
- 整个响应缓存：热点接口
- 部分缓存：只缓存变化少的片段
- 失效：TTL 过期或事件触发

**存放。** 网关进程内存，或 Redis 这类分布式缓存。进程内存读最快但各实例不共享，分布式缓存命中率更高但多一跳。
