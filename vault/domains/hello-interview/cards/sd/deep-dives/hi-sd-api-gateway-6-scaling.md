## Q
**网关怎么扩展：水平扩展与全球部署**｜系统设计 · 深入技术

API 网关如何应对更高负载和全球用户？客户端到网关、网关到服务的负载均衡有什么区别？

## A
**水平扩展。** 网关通常无状态，在前面加负载均衡器（如 AWS ELB、NGINX），多开实例即可。

**两层负载均衡。**
- 客户端到网关：由专用负载均衡器承担
- 网关到后端服务：网关自身可对多个服务实例做均衡

**全球分布。** 像 CDN 那样把网关部署到靠近用户的地区：多区域部署、用 GeoDNS 就近路由、同步各地路由规则与策略。

**说法。** 面试里画一个「API 网关 + 负载均衡」方框即可，入口细节越多越容易偏题。
