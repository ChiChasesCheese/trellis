## Q
**云盘与文件同步系统 · 变更日志与游标同步**｜必会 · 出自：云盘与文件同步系统 › 整体设计

多设备间远端变化怎样到达本地？变更日志和游标各起什么作用？设备收到通知后做什么？

## A
**流程。** 服务端每次提交追加到该命名空间的变更日志，并通知在线设备"命名空间 X 有新游标"。设备调 `GET /changes?cursor=本地游标`，拿到变更列表，只下载自己没有的块，然后推进本地游标。
**本地。** 用文件系统事件（FSEvents、inotify）监视，本地库记录路径到版本与块指纹，只上传指纹变了的块（增量同步）。
