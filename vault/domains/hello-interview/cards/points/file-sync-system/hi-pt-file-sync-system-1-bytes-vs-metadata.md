## Q
**云盘与文件同步系统 · 字节与元数据分开存**｜出自：云盘与文件同步系统 › 需求

设计 Dropbox 式云盘时，文件的字节和文件的名字、位置、版本为什么要分开存？各自放哪里？同步的本质是什么？

## A
**要点。** 字节巨大、不可变、按内容寻址，放对象存储并去重；元数据小、频繁变化、要强一致，放分片数据库。
**同步。** 客户端拿着游标追着元数据变更日志走，缺什么字节再去拿。
**非功能。** 可用性优先于强一致，但元数据提交本身要原子；文件最大 50 GB，上传可暂停续传。
