## Q
**云盘与文件同步系统 · 分享与命名空间**｜出自：云盘与文件同步系统 › 深入 5

文件分享的数据怎么建模，才能同时高效回答"谁能访问这个节点"和"我能看到什么"？被分享的文件夹怎么同步？

## A
**方案。** 单独的分享表，建两个索引：按节点、按被分享者。把分享列表塞进文件元数据则查"分享给我的"要全表扫描。
**命名空间。** 被分享的文件夹作为独立命名空间，有自己的变更日志，被分享者把它挂载到自己的目录树。权限变更只是增删挂载，同步逻辑统一。
**分片。** 元数据按 `namespaceId` 分片，事务不跨片。
