## Q
**云盘与文件同步系统 · 并发修改冲突**｜出自：云盘与文件同步系统 › 深入 3

两台设备都基于 v3 修改同一个文件，怎么处理？通用文件同步要不要自动合并？

## A
**机制。** 提交带 `baseVersion` 做乐观并发控制：第一个赢得 v4，第二个因 baseVersion 不匹配收到冲突错误。
**处理。** 客户端把自己的版本另存为"文件名（冲突副本，设备名）"并同步下来，由用户合并。
**边界。** 自动合并只适合有操作日志的协同文档，通用文件同步不尝试。
