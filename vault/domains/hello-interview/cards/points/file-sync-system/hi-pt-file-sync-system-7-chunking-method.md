## Q
**云盘与文件同步系统 · 固定切块还是内容定义切块**｜出自：云盘与文件同步系统 › 深入 1

文件在开头插入一个字节，固定大小切块会怎样？内容定义切块如何解决，代价是什么？压缩要不要做？

## A
**问题。** 固定切块在开头插入一字节会让之后所有块边界后移、指纹全变，增量同步失效。
**选择。** 内容定义切块（content-defined chunking）：用滚动哈希在内容特征点切分，插入只影响附近一两块。目标块约 4 到 8 MB，设上下限。
**代价。** 客户端 CPU 开销、块大小不均。
**压缩。** 只对文本等可压缩类型值得做，图片视频已压缩，白耗 CPU。
