## Q
**云盘与文件同步系统 · 大文件上传与提交流程**｜出自：云盘与文件同步系统 › 整体设计

一个 50 GB 文件的上传应该怎样走？为什么字节不经过应用服务器？服务端为何不信客户端说传完了？

## A
**流程。** 客户端切块并算 SHA-256 → 发指纹清单，服务端查块索引，只返回缺失块和预签名 URL → 客户端并行直传对象存储 → 对象存储完成事件通知服务端，核对大小和指纹后块才标 `READY` → 客户端 `commit {baseVersion}`。
**为什么直传。** 否则 50 GB 占满应用服务器带宽和连接。
**提交。** 一个事务：检查 baseVersion、写新版本和块清单、块引用计数加一、追加变更日志、扣配额。
