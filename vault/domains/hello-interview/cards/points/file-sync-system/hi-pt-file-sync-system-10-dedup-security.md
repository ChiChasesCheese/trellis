## Q
**云盘与文件同步系统 · 去重的安全问题**｜出自：云盘与文件同步系统 › 深入 4

块按指纹全局去重节省空间，但跨用户去重有什么安全风险？怎么缓解？端到端加密和配额又受什么影响？

## A
**风险。** 确认攻击：攻击者上传某文件的指纹，服务端说"已存在"就泄露别人有这个文件。
**对策。** 上传前让客户端对随机挑战算哈希证明持有内容；或敏感账号只做同用户内去重。
**冲突。** 端到端加密后指纹各不相同，无法去重，是安全与成本的取舍。配额按逻辑大小扣，去重不减少占用，否则可探测他人数据。
**GC。** 引用计数归零后延迟删除，防竞态误删。
