## Q
**熔断器 · 失败的判定方式**｜追问 · 出自：熔断器 › 深入 3

熔断器可以用连续失败数，也可以用滑动窗口失败率来判定是否熔断。两者各有什么缺陷？生产系统更接近哪一种？

## A
**连续失败数。** 简单直观，适合低流量的内部调用；缺点是低流量时偶发一次成功就清零计数，高流量时少量失败穿插成功永远触发不了熔断。
**滑动窗口失败率。** 统计最近 N 次调用或最近 T 秒的失败比例，超过阈值（如 50%）且样本数达到最小值才熔断，要用环形数组保存窗口内每次结果。更接近生产系统（Resilience4j、Hystrix）。
