## Q
**熔断器 · 与重试、超时的组合顺序**｜追问 · 出自：熔断器 › 取舍与追问

熔断器要和限流、超时、重试一起使用。它们的组合顺序大致怎样？重试放错位置会出什么问题？

## A
**顺序。** 由外到内一般是重试 → 熔断 → 限流 → 超时 → 实际调用，具体因框架而异；超时贴着调用，保证慢调用能被计为失败。
**关键。** 重试放在熔断器外面：每次重试都要重新过熔断器，熔断打开后立刻被拒绝；若重试在熔断器里面，同一次调用内的重试会绕过熔断，继续冲击下游。
**测试。** 注入假时钟，验证四条状态转换；并发测试验证半开期只放行一个探测。
