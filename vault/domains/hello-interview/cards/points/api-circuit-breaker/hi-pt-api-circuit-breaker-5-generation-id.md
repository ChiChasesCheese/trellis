## Q
**熔断器 · 状态代号防迟到结果**｜出自：熔断器 › 深入 1

线程 A 在关闭状态时发出了一个很慢的请求，期间熔断器已打开又进入半开，之后 A 的结果才返回。直接计入会有什么后果？如何设计才能避免？

## A
**问题。** 旧结果可能把半开的在途探测数减成负数，或者把很久以前的失败当成探测失败，使状态错乱。
**方案。** 每次状态转换让代号 `_gen` 加一；取许可时返回当前代号，回报结果时若代号不一致，就只计入指标，不改变状态。
```python
if gen != self._gen:
    return  # 迟到的旧请求：只计数，不影响新状态
```
