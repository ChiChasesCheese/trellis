## Q
**分布式限流器 · 限流放在哪一层**｜必会 · 出自：分布式限流器 › 整体设计

设计分布式限流器时，限流逻辑可以放在业务进程内、独立限流服务或 API 网关。各自的问题是什么，通常选哪个？

## A
**业务进程内。** 每台机器各自计数，机器数变化时总限额失控，实例间无法共享，最差。
**独立限流服务。** 集中，但多一跳网络，自己还要高可用。
**选择。** API 网关或负载均衡层：流量必经之处，作为过滤器无需业务改动。内部服务间用服务网格（sidecar）或客户端库，向同一个 Redis 集群发检查。
