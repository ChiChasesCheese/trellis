## Q
**矢量图形编辑器绘图 API · 预览与提交分离**｜必会 · 出自：矢量图形编辑器绘图 API › 深入 1

设计类 Figma 的矢量编辑器：用户拖动鼠标会产生每秒上百个指针事件。核心设计思路是什么？

## A
**要点。** 把手势过程中的瞬时预览和手势结束时的持久提交分开：高频指针事件只驱动本地预览与渲染（每帧最多处理一次），只有提交的操作才进撤销栈、持久化和协作同步。
**为什么。** 拖拽中的 100 个中间位置写进操作日志就是垃圾。
**瞬时状态。** 光标、拖拽中位置只走 presence 通道，不进历史。
