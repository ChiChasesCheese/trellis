## Q
**矢量图形编辑器绘图 API · 自由笔迹的简化**｜加分 · 出自：矢量图形编辑器绘图 API › 深入 7

矢量编辑器的自由画笔产生密集的点流，直接存储太大。怎么变成矢量路径？

## A
**要点。** 用 Ramer-Douglas-Peucker 简化折线，再拟合成贝塞尔曲线，路径数据量降一个数量级，缩放不失真。
**时机。** 笔迹绘制中本地实时显示，抬起时才简化并提交；简化形状与预览略有差别，抬起时做一次平滑过渡。
**对照。** 位图笔刷是栅格图层，同步的是瓦片变更，代价大得多，产品上要限制尺寸。
