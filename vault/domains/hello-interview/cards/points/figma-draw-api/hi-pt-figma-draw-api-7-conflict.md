## Q
**矢量图形编辑器绘图 API · 协作冲突处理**｜出自：矢量图形编辑器绘图 API › 深入 4

矢量编辑器中两人同时改同一对象怎么办？删除、层级移动又有哪些特殊情况？

## A
**要点。** 属性级后写者胜：同一属性由服务器接收顺序决定，不同属性两者都保留，比锁整个对象冲突少。
**删除。** 服务器忽略指向已删除节点的属性操作。
**成环。** 层级移动可能成环（A 放进 B 同时 B 放进 A），服务器检测并拒绝，客户端回滚。
**取舍。** 不需要 OT 或 CRDT，文本编辑才需要更复杂的算法。
