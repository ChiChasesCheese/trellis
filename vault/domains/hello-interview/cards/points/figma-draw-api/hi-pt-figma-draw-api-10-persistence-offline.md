## Q
**矢量图形编辑器绘图 API · 持久化与离线**｜出自：矢量图形编辑器绘图 API › 深入 7

矢量编辑器的服务器怎么保存文档，新客户端怎么加载，离线编辑怎么处理？

## A
**保存。** 操作日志加周期性快照；新客户端加载最近快照再追放增量，日志也用于恢复和审计。
**离线。** 本地继续累计操作，重连时批量发送；同属性被别人改过则以服务器顺序为准。
**取舍。** 本地优先（local-first），用户操作立即生效，网络不阻塞绘制。
