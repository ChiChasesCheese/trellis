## Q
**矢量图形编辑器绘图 API · 撤销分组**｜出自：矢量图形编辑器绘图 API › 深入 3

矢量编辑器里一次拖动产生很多个操作，撤销时应该怎样回退？多人协作时撤销有什么特殊语义？

## A
**要点。** 一次手势对应撤销栈里的一步：commit 保存一组（正向、逆向）操作，撤销时逆操作按相反顺序回放；新提交会清空重做栈。
**协作。** 撤销只撤销自己的操作，并且是产生新的逆向操作再同步，不是回退全局历史，否则会抹掉别人的修改。
**易错。** 每个鼠标事件一步，要撤销 100 次才回到拖拽前。
