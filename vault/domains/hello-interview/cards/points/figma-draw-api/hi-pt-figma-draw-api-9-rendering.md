## Q
**矢量图形编辑器绘图 API · 渲染与空间索引**｜出自：矢量图形编辑器绘图 API › 深入 6

矢量画布有数万个对象仍要流畅平移缩放。渲染和点击命中怎么做？

## A
**脏区域。** 修改后标记受影响对象包围盒的并集，只重绘脏区域；拖拽的对象单独一层，静态内容分块（tile）缓存。
**空间索引。** 四叉树或 R 树做视口剔除和命中测试，不遍历全部节点。
**大文档。** 缩得很小时把子树渲染成位图做低细节缓存。
