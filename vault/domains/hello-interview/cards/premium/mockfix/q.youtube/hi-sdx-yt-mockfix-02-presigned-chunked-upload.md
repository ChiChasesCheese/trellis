## Q
**大文件上传：预签名分块直传**｜模拟面试补强 · 视频平台（YouTube）

面试官：「100 MB 视频，上传到 90% 断线了怎么办？上传走哪条路？」

## A
**一句话。** 先发元数据换预签名 URL，客户端按块直传对象存储、断点续传；大文件不经过 API 服务器，CDN 只负责读。

**要点。**
- 为什么不放在 POST body？：100 MB 占住 API 服务器的连接和带宽，断线就从头再来。
- 怎么续传？：分块（5–100 MB，S3 multipart），服务端记已收块，断线后只补缺的块。
- 重复上传同一块？：块的 key 是 `(video_id, part_no)`，重传覆盖同一对象，天然幂等。
- 上传走哪条路？：只选一条：预签名直传对象存储，完成后由服务端回调触发转码。

**常见失分。**
- 上传路径摇摆：一会儿直传 CDN、一会儿先传到自己的服务，白板最后两条线都在；先说结论，选定就坚持。
