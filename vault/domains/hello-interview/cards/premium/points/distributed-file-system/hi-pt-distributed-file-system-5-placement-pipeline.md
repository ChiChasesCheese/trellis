## Q
**分布式文件系统 · 放置与写流水线**｜必会 · 出自：分布式文件系统 › 深入 2

分布式文件系统上传一个 128 MB 的块，放置服务怎样选 3 个副本？数据怎么写到三台机器？什么时候才算写成功？

## A
**放置。** 至少跨 2 个机架（扛机架或交换机故障），优先剩余空间多、负载低的机器；同一文件的不同块分散到不同机器，读时并行。

**写入。** 流水线：客户端写第一台，边收边转发给第二台、第三台，复制流量不占客户端出口。

**确认。** 三个副本都落盘才确认；某台太慢就换一台重写，块还没提交，没人看得见。
