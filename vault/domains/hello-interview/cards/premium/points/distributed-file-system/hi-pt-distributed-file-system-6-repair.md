## Q
**分布式文件系统 · 校验与修复**｜必会 · 出自：分布式文件系统 › 深入 3

分布式文件系统一台块服务器失联、或擦洗发现坏块，使一些块的副本少于 3。怎样修复？为什么修复窗口很重要？

## A
**校验。** 每 64 KB 一个 CRC，读时校验；后台擦洗读遍所有块，发现静默损坏。

**修复。** 进修复队列，按剩余好副本数少的优先；限速防修复风暴；从好副本拷贝到新机架的机器。

**窗口。** 全丢概率约与窗口的平方成正比，窗口缩短一半，丢块概率降到四分之一。
