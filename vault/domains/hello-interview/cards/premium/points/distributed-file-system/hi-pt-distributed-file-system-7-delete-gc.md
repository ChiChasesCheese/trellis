## Q
**分布式文件系统 · 删除与回收**｜必会 · 出自：分布式文件系统 › 深入 3

分布式文件系统的 delete 一个有大量子目录和文件的目录，怎样做到快，又不会误删数据？

## A
**删除。** 一个事务摘掉目录项，整棵子树立刻对外不可见（原子）；后台任务再逐层回收目录项。

**数据回收。** 周期性比对块服务器上的块和元数据引用的块，差集在宽限期（如 7 天）后删除（标记清除）。

**宽限期。** 留给误删恢复，也兜住未提交上传的孤儿块。
