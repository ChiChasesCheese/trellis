## Q
**分布式文件系统 · 元数据与数据分离**｜必会 · 出自：分布式文件系统 › 深入 1

分布式文件系统的文件不可变、目录可变。为什么把系统拆成元数据服务和数据服务两部分？拆开后各自的一致性要求是什么？

## A
**为什么。** 数据 200 PB 不可变，元数据 625 GB 可变，规模和一致性要求相反。

**元数据。** 强一致，分片加共识复制。

**数据。** 不可变，副本之间没有写冲突，不需要锁和租约，缓存永不失效，修复就是拷贝。

**收益。** 强一致的部分被做得很小。
