## Q
**CI/CD 平台 · 拉取式任务分发**｜必会 · 出自：CI/CD 平台 › 深入 2

CI/CD 平台里，调度器要把就绪的任务交给执行机（有的在内网，有的由客户自托管）。采用推送还是拉取？理由是什么？

## A
**选择。** 拉取：执行机主动长轮询，按标签领任务。

**为什么。** 执行机在内网或客户自托管，只能主动连出；控制平面不必知道谁空闲；背压天然（没有空闲执行机就不会领任务）。

**对比。** 推送要维护执行机清单、探活，还要穿透网络。
