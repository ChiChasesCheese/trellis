## Q
**指标聚合系统 · 查询缓存与标签索引**｜必会 · 出自：指标聚合系统 › 深入 3

很多人同时打开同一个仪表盘，每个面板都在查同一批指标。查询侧怎样保持快？按标签过滤怎么做？

## A
**缓存。** 热点查询按步长缓存，缓存时间等于步长，多人看同一面板只算一次。

**索引。** 时序库按“序列，时间”排布，标签过滤靠倒排索引：标签值指向序列 id 列表，求交集后再读数据。

**扩展。** 查询侧靠读副本和缓存水平扩展。
