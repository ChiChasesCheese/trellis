## Q
**餐厅候位 API · 等位估计**｜追问 · 出自：餐厅候位 API › 深入 5

怎样估计排队客人还要等多久？为什么不能用"平均等待时间乘队列位置"？

## A
**做法。** 在队伍副本上往前推演：每张忙桌的空出时刻 = 入座时间 + 用餐时长（超时的算现在），每到一个空出时刻调用同一个 `_drain`，目标入座的时刻减去现在就是等待时间。

**为什么。** 平均值区分不了大桌和小桌，一个 6 人团前面排着 2 人团时会差很远。推演复用同一条规则，防饿死自动遵守。

**数字。** 假设用餐时长 60 分钟，桌 `[2,4]` 18:00 同时坐满，`c(4)`、`d(2)`、`e(2)` 的估计是 60、60、120 分钟，18:30 变成 30、30、90。
