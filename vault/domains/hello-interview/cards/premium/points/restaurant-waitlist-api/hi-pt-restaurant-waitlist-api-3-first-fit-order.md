## Q
**餐厅候位 API · 跳过坐不下的人**｜必会 · 出自：餐厅候位 API › 深入 2

桌子空出来时，队首的 8 人团坐不下 6 人桌，后面的 4 人团坐得下。怎么处理？为什么不用优先队列？

## A
**处理。** 从队首往后找第一个坐得下的人入座，前面坐不下的人留在原位、保持相对顺序。

**为什么不用优先队列。** 规则是"第一个坐得下的"，不是最大或最小；中间离开、坐不下的人保持顺序，有序列表最直接。

**数字。** 桌 `[2,4]` 中 `a` 离开后，队伍 `['c'(4), 'd'(2)]` 里 `c` 被跳过，`finish("a")` 返回 `[('d', 0)]`。
