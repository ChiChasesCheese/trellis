## Q
**网络爬虫 · 高层设计**｜通览

网络爬虫的高层设计怎么搭？每个功能需求走哪条路径？

## A
**组件。** 前沿队列、爬虫、DNS、目标网页、对象存储（S3）；深挖后加元数据库和解析 worker。

**每条路径。**
- **从种子爬取：** 爬虫从前沿队列取 URL，经 DNS 得到 IP，抓取 HTML；新链接提取后回到前沿队列，循环到爬完。
- **提取并存文本：** 解析阶段从对象存储读 HTML，提取文本再写回对象存储。

**存储。** 对象存储放 HTML 与文本，便宜且可扩展；队列消息只放 URL 在元数据库里的 id，不放页面，因为队列不适合大载荷；元数据库记已抓取 URL、文本位置。
