## Q
**大数据结构 · 什么时候用**｜通览

面试里什么信号说明该用大数据结构？常见场景有哪些，什么时候不该用？

## A
**信号。**
- 数据大到哈希表装不下，内存成了瓶颈。
- 需求是查成员、数次数、数不同元素或看分位数。
- 业务能容忍一定误差。

**常见用法。**
- **爬虫去重：** 布隆过滤器说「大概率见过」。
- **缓存前置：** 布隆过滤器挡掉一定不在缓存的请求。
- **Top K 与缓存 LFU：** Count-Min Sketch 加候选堆。
- **日活与独立访客：** HyperLogLog。
- **反爬虫：** HyperLogLog 估算每个 IP 访问了多少不同网页。
- **p99 与 SLO：** 直方图。

**不该用。**
- **哈希表够用：** 上近似结构是过度设计。
- **要求不重复、不误拒：** 用精确存储。
- **不同元素很少：** 用哈希集合。

**常见追问。**
- **布隆过滤器多大：** 10 亿元素、1% 误判约 1.2 GB。
- **缓存前置的坑：** 缓存会过期而过滤器不能删，越用越饱和。
- **多机器的分位数：** 不能平均，要合并同边界的桶计数。
