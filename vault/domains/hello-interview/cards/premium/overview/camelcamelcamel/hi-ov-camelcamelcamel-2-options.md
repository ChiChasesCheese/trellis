## Q
**价格追踪（CamelCamelCamel） · 高层设计**｜通览

价格追踪的高层设计怎么搭？每个功能需求走哪条路径？

## A
**组件。** API 网关、价格历史服务、订阅服务、爬虫服务、通知定时任务、价格库、主库。

**每条路径。**
- **看价格历史：** 客户端经网关到价格历史服务，按商品 ID 与时间范围查价格库，返回 JSON 画折线图。
- **订阅降价通知：** 经网关到订阅服务，在主库的订阅表写一行（用户、商品、阈值）；每 2 小时的定时任务扫新价格，找阈值达标的订阅，发邮件并标记已发。

**存储。** 价格库放只追加、会涨到数十亿行、容忍最终一致的价格数据；主库放体量小、常规增删改查的用户、商品、订阅。爬虫是定时批量写，历史服务是高并发读，所以分开扩缩。
