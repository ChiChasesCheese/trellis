## Q
**长任务 · 什么时候用**｜通览

面试里什么信号说明该用长任务异步？常见场景有哪些，什么时候不该用？

## A
**信号。**
- 提到视频转码、PDF 生成、群发邮件这类要几秒到几分钟的操作。
- 规模算不过来：每秒要处理的时间超过 Web 服务器所能给。
- 重活需要 GPU 等不同硬件。
- 被问「服务器崩溃怎么办」或「十倍流量怎么办」。

**常见场景。**
- **视频平台：** 转码、缩略图、字幕、审核，多个工作者处理。
- **照片分享：** 缩放、滤镜、打标签，发帖扇出给粉丝。
- **打车：** 异步匹配司机，位置更新走工作者。
- **支付：** 欺诈检测、webhook、延迟确认的转账走异步。
- **网盘：** 上传后病毒扫描、索引、生成预览。

**不该用。**
- **快操作：** 不到 100ms 的查询，同步足够。

**常见追问。**
- **失败：** 心跳发现崩溃，重新分发。
- **重复失败：** 失败几次后进死信队列。
- **重复任务：** 幂等键。
- **积压：** 背压，按队列深度扩容。
- **混合负载：** 分快慢队列。
- **任务依赖：** 简单链或工作流编排器。
