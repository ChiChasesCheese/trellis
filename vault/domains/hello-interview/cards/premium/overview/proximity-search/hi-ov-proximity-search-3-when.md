## Q
**邻近搜索 · 什么时候用**｜通览

面试里什么信号说明该用邻近搜索？常见场景有哪些，什么时候不该用？

## A
**信号。**
- 按位置而不是按 ID 或数值查找。
- 要找某个点周围一定距离内的对象。
- 数据里有多边形、道路、配送区，要判断包含或相交。
- 数据是司机、用户这类持续移动的点，写入很频繁。

**常见场景。**
- **附近的司机：** 司机归入 H3 格子，乘客查本格加一圈，再按精确距离排序。
- **附近的餐厅：** 位置压成 Geohash 或 S2 格子，用普通索引取候选。
- **附近的人：** 同样用编码键取候选，再精确过滤。
- **配送区是否包含某个地址：** 用 PostGIS 的 R 树式索引。
- **道路是否穿过某个县：** 同样用 R 树式索引。
