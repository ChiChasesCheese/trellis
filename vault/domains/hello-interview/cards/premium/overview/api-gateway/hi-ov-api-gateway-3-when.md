## Q
**API 网关 · 什么时候用**｜通览

面试里什么信号说明该用 API 网关？常见场景有哪些，什么时候不该用？

## A
**信号。**
- 设计里有多个微服务，客户端要经同一入口访问。
- 鉴权、限流需要统一做。
- 要把内部服务结构和外部接口隔开。

**常见用法。**
- **微服务入口：** 路由表把路径分给各服务。
- **开放 API：** 重点是限流与 API 密钥。
- **内部 gRPC、外部 JSON：** 网关做协议与响应转换。
- **商品详情这类公共读：** 网关缓存。
- **全球用户：** 区域网关加 GeoDNS。

**不该用。**
- **简单单体：** 多一跳和一个组件，没有收益。
- **只有一种客户端：** 引入网关是不必要的复杂度。

**常见追问。**
- **为什么要网关：** 先答路由，再提中间件。
- **怎么扩展：** 无状态，加实例，限流计数放共享存储。
- **托管还是开源：** 看运维能力、合规与流量成本。
- **要讲多久：** 一两句话带过，把时间留给核心设计。
