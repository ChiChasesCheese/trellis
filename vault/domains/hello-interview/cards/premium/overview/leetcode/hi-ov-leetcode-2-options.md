## Q
**在线判题平台 · 高层设计**｜通览

在线判题平台的高层设计怎么搭？每个功能需求走哪条路径？

## A
**组件。** 浏览器（Monaco 编辑器）、单体 API 服务器、DynamoDB 一类 NoSQL、按语言分的容器、排行榜。

**每条路径。**
- **看题目列表：** API 服务器分页读库，只返回 id、标题、难度、标签；数据落在题目文档。
- **看单题写代码：** 按 id 读题面和该语言的代码模板；测试用例作为子文档内嵌在题目里。
- **提交得到反馈：** API 把代码交给对应语言的容器，容器在沙箱里跑完，结果写进提交记录再返回。
- **比赛排行榜：** 按竞赛查通过的提交，按用户数不同题目，解题数降序、完成时间升序；客户端约 5 秒重新请求。

**存储。** 不需要复杂查询，题目和测试用例嵌在一个文档里一次读全，所以用 NoSQL；提交结果也落在库里。
