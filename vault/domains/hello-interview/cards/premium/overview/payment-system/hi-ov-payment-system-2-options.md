## Q
**支付系统 · 高层设计**｜通览

支付系统的高层设计怎么搭？每个功能需求走哪条路径？

## A
**组件。** API 网关、意图服务、交易服务、运营数据库、外部支付网络。

**每条路径。**
- **发起收款：** 商户请求经网关认证到意图服务，写入状态为 created 的意图，返回意图 ID；此时不扣款。
- **顾客付款：** 商户带意图 ID 把卡信息交给交易服务，写 pending 的交易，向 Visa 等网络发授权，按结果与回调更新交易和意图。
- **查状态：** 商户 GET 经网关到意图服务，读库返回状态、错误信息和交易详情。

**存储。** 一个运营库，存意图、交易与商户信息；状态查询直接读它，不需要新服务。
