## Q
**大文件 · 什么时候用**｜通览

面试里什么信号说明该用大文件直传？常见场景有哪些，什么时候不该用？

## A
**信号。**
- 题目涉及用户生成内容：视频、照片、文件分享。
- 文件经 API 超过约 10MB。
- 面试官追问「传到一半断了怎么办」。

**常见场景。**
- **视频平台：** 分块直传，存储事件触发转码，CloudFront 签名 URL 出分片。
- **照片分享：** 直传原图，事件触发缩略图，签名 URL 防盗链。
- **网盘：** 分块直传，分享时发限时签名 URL。
- **聊天：** 直传存储，聊天只传文件引用，下载链接会过期。

**不该用。**
- **小文件：** 10MB 以下用普通 API。
- **需要同步校验：** 接受前就要检查内容，必须代理。
- **合规检查：** 金融或医疗要求存储前扫描，走代理。
- **即时反馈：** 上传后马上要基于内容响应，比如人脸检测。

**常见追问。**
- **传到 99% 失败：** 分块上传，查已传的块从断点续传。
- **防滥用：** 签入大小限制，上传进隔离桶扫描。
- **元数据：** 放数据库，签发 URL 时先建 pending 记录。
- **下载快：** 走 CDN，大文件用范围请求。
