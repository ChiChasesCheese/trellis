## Q
**内存文件系统 · 扩展二：按名字搜索**｜摘要 · 追问

要支持"config.json 在哪"，怎么加搜索？怎么优化？

## A
- **现状：** 没有办法回答，除非手动遍历整棵树。
- **最简单：** 从根（或任意文件夹）递归遍历，名字匹配就收进结果，是文件夹就继续往下。O(n)，n 是条目总数；几万个条目、搜索频繁时就慢。
- **索引：** 维护"名字→该名字的所有条目"的字典。创建时加入，删除时移除，改名时从旧名字的列表移到新名字的列表；搜索变成 O(1)（按名字）。
- **前缀搜索：** 把字典换成前缀树（trie）：插入 `config.json` 就沿着字符建节点；搜 `config*` 走到 `config` 节点，收集它下面所有条目。
- **通配符：** `*.txt` 这种简单模式可另建按扩展名的索引；复杂模式退回遍历加逐节点匹配。
- **内容搜索：** 建倒排索引（词→包含它的文件），基本是做一个小搜索引擎，除非被明确要求否则过度。
- **面试里：** 讲递归遍历加提一句索引就够，被追问再讲 trie。
