## Q
**内存文件系统 · 条目怎么知道自己的完整路径**｜摘要 · 必会

每个条目存完整路径字符串，还是存父指针？

## A
- **存路径字符串（反面）：** `get_path()` 直接返回，O(1)，很简单。但改名 `/home` 为 `/house` 时，下面每一个条目的路径前缀都错了，要全部更新，移动也一样；改名变成 O(后代数)，深层结构里很贵。
- **存父指针（选这个）：** 每个条目只存名字和父文件夹；`get_path()` 沿父指针向上走到根，把名字拼起来。改名、移动只改这个条目自己的名字或父指针，所有后代自动正确，因为路径是现算的。
- **代价：** `get_path()` 变成 O(深度)，文件系统的深度通常只有十几层，可忽略；还可以缓存。
- **新的负担：** 双向引用（孩子指向父，父通过字典指向孩子），移动时两边要一起改并保持同步。
- **根的细节：** 根的名字取 `/`，拼接时要防止出现 `//home`。
