## Q
**内存文件系统 · 路径什么时候值得缓存**｜考点 · 追问

父指针现算路径。深度 15 的条目，一次搜索返回 10 万个结果并都要显示完整路径，成本是多少？怎么优化？

## A
- **成本：** 每个结果要沿父指针走 15 步并拼接字符串，总共约 150 万步，相对遍历本身仍是同一量级，但字符串拼接分配的内存多。
- **缓存：** 在条目上缓存路径字符串，读时直接返回。
- **失效是难点：** 改名或移动一个文件夹，其所有后代的缓存都作废。做法一：遍历后代清缓存（又回到 O(后代数)）；做法二：全局版本号，每次改名、移动时加一，缓存里存"算出它时的版本"，读时版本不同就重算——写时 O(1)，读时按需。
- **取舍：** 读远多于写才值得；默认现算，因为深度只有十几层，简单且没有失效问题。
- **说法：** 先指出可缓存，再讲失效策略。
