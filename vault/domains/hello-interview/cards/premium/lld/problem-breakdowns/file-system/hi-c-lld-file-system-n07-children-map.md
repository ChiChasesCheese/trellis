## Q
**内存文件系统 · 文件夹的子节点用什么容器**｜摘要 · 必会

子节点放列表还是放"名字→条目"的字典？为什么还要把容器藏起来？

## A
- **列表（反面）：** 解析 `/home/user/docs/report.txt` 要逐层按名字找孩子；列表每层要扫所有孩子，一个文件夹有 1000 个文件就比较 1000 次，路径的每一层都乘一遍。要求几万条目仍然响应，不行。
- **字典（选这个）：** 按名字查是 O(1)，与同级有多少文件无关。
- **额外的好处：** 键唯一，同一文件夹里不可能有两个同名条目，数据结构本身排除了非法状态。
- **封装：** 字典不对外暴露，只提供 `add`、`remove`、`get`、`has`，由文件夹自己维护不变量——调用者不会忘了设置父指针，校验规则也只在一处。
- **`children()` 返回副本：** 外部拿到列表后随便改，也影响不到内部字典。
