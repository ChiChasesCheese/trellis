## Q
**内存文件系统 · 删除**｜摘要 · 必会

`delete` 怎么写？删除非空文件夹允许吗？

## A
- **步骤：** 不能删除根→解析父文件夹和名字→从父文件夹移除→移除返回空说明不存在，抛"找不到"。
- **文件和文件夹同样处理：** 都是"从父的孩子里摘掉"。
- **允许删除非空文件夹：** 整棵子树随之消失；类似 `rm -rf`。有的文件系统要求先清空（`rmdir`），面试官要这种行为就加一句检查：是文件夹且有孩子则抛错。先做简单的并说明可调整。
- **`remove` 要清父指针：** 摘下来的节点父指针设为空，否则它还挂着旧父的引用，路径也会算错。
- **细节：** 被删除子树里的后代仍相互引用，只是整棵与根断开；有人还拿着旧引用时，它们会得到一个看起来不含根的路径。
