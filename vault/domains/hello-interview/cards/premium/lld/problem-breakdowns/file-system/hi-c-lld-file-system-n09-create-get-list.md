## Q
**内存文件系统 · 创建、取条目、列出**｜摘要 · 必会

`create_file`、`create_folder`、`get`、`list` 怎么实现？边界在哪？

## A
- **创建文件：** 路径是根则报错（不能在根上建文件）→解析父文件夹、取最后一段名字→已有同名则抛"已存在"→建文件、挂到父文件夹下→返回。
- **创建文件夹：** 同样的流程；路径是根时报"根已存在"。
- **不要合并成一个带标志位的方法：** 两个名字明确的方法比 `create(path, is_file)` 更清楚。
- **`get`：** 直接返回路径解析的结果，文件或文件夹都行；所有工作都在解析里。
- **`list`：** 解析路径，确认是文件夹（不能列出文件的内容），返回孩子列表；条目对象的调用者可以看名字、类型，文件还能看内容。
- **边界：** 路径为空、不以 `/` 开头、父目录不存在、重名。
