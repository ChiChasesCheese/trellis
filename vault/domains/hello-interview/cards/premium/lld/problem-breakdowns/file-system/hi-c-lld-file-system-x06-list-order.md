## Q
**内存文件系统 · `list` 的返回顺序与大小写**｜考点 · 追问

调用者要按名字排序的目录列表，或者名字不区分大小写，要改什么？

## A
- **默认顺序：** Python 字典保持插入顺序，所以 `list` 返回创建顺序；不是排序后的。
- **要排序：** 返回前排序，O(k log k)，k 是孩子数，列目录不频繁时足够；列目录很频繁且孩子非常多时，才考虑有序容器（如平衡树或跳表）。
- **不区分大小写：** 键用规范化形式（如小写折叠），但对象上保留原名展示；这样 `Notes.txt` 和 `notes.txt` 算重名。
- **规范化要放在哪：** 只放在文件夹的 `get/add/remove` 三处，调用者不用知道。
- **注意：** 规范化规则在 Unicode 下比"转小写"复杂（同一个字符有多种写法），面试里说"规则集中在一处"即可。
