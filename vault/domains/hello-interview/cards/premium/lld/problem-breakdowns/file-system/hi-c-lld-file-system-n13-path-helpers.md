## Q
**内存文件系统 · 路径解析的三个辅助函数**｜摘要 · 必会

路径怎么解析？为什么要拆成辅助函数？

## A
- **解析路径：** 空路径、不以 `/` 开头的报无效；`/` 直接返回根；其余去掉开头的斜杠、按 `/` 拆开，从根逐层下降。某一段为空（连续斜杠）报无效；当前节点不是目录就报"不是目录"；找不到孩子报"找不到"。
- **解析父级：** 取最后一个斜杠之前的部分，若位置是 0 则父为根；解析它，并确认是文件夹。根没有父级。
- **取名字：** 取最后一个斜杠之后的片段。
- **为什么拆出来：** 创建、删除、改名、移动都要"定位父文件夹加最后一段"，公共方法专注自己的事。
- **刻意简单：** 不处理相对路径、符号链接，因为需求已排除；真实文件系统的路径解析本身就是一大块复杂性。
- **`get_path` 的根特判：** 根自己返回 `/`；父是根时直接拼 `/名字`，避免出现 `//`。
