## Q
**内存文件系统 · 各级别的期望**｜摘要 · 必会

文件系统这道设计，初级、中级、资深分别被期望做到什么？

## A
- **初级：** 能建模树：有 `FileSystem` 入口，`File` 和 `Folder` 做节点；创建、删除正确，路径解析合理；知道文件夹有孩子，需要按名字找（字典最好，列表也行）；基本错误处理。想不到共同基类没关系，被问"两者有没有共同点"时能说出名字和父指针。
- **中级：** 职责更清楚：`FileSystem` 管路径和调度，`File`、`Folder` 管自己；主动抽出基类；能解释为什么用父指针；如果选了存路径，被问"改名一个有上千后代的文件夹"时能意识到问题；`move` 处理父指针，成环检测可以提示后做好。
- **资深：** 不用提示就处理细微边界；主动讲父指针与存路径的取舍；成环检测自然出现；谈线程安全：创建的"先检查后操作"竞态、`move` 需要锁两个文件夹以及加锁顺序、粗粒度与细粒度的取舍；对搜索索引有想法（名字字典、前缀用 trie）；能说明怎么加符号链接、权限而不大改结构。
