## Q
**内存文件系统 · 核心实体**｜摘要 · 必会

文件、文件夹、路径、文件系统四个候选，哪些是类？

## A
- **文件（建类）：** 有名字、存内容、在树里有位置，是叶子节点，不能包含其他条目。
- **文件夹（建类）：** 有名字，包含文件或其他文件夹，不存内容；是容器。
- **路径（不建类）：** 它是标识位置的字符串，是操作的输入，本身没有状态和行为；我们会解析它，但不为它建模。
- **文件系统（要不要建类要比较）：** 要有人拥有根并提供公共接口；谁来解析路径、走到目标再创建。是单独建一个类，还是直接用根文件夹，是类设计里权衡的点。
- **关系是一棵树：** 文件系统拥有根文件夹；每个文件夹可以含任意混合的文件和文件夹；文件是叶子；深度不限。
