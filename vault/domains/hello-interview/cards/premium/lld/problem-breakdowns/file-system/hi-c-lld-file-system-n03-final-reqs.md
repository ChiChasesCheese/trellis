## Q
**内存文件系统 · 最终需求与范围外**｜摘要 · 必会

澄清后，文件系统的需求清单与明确不做的事是什么？

## A
**写在白板上的需求。**
1. 层级结构，单个根目录
2. 文件存字符串内容
3. 文件夹含文件和其他文件夹
4. 创建和删除文件、文件夹
5. 列出文件夹的内容
6. **绝对路径解析：** 解析绝对路径（如 `/home/user/docs`）
7. 改名和移动文件、文件夹
8. 从任何文件或文件夹的引用取到完整路径
9. 内存里支持几万个条目

**明确不做：** 搜索、相对路径（`../`、`./`）、权限与所有者与时间戳、按文件类型区分行为、持久化到磁盘、符号链接、界面。

**价值：** 第 8 条"从引用取完整路径"是个容易忽略的需求，它直接引出"存路径还是存父指针"的设计决策；第 9 条引出"子节点用字典"。
