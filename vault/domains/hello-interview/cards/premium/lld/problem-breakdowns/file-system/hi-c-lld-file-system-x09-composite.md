## Q
**内存文件系统 · 加 `size()`：多态还是类型判断**｜考点 · 必会

要给条目加"总字节数"：文件是内容长度，文件夹是所有后代之和。写在外面用 `isinstance` 判断，还是写进类里？

## A
- **类型判断（外部函数）：** 一个 `size(entry)` 里 `if isinstance(entry, Folder): ... else: ...`。每新增一种条目（比如符号链接）都要回来改这个函数，还有 `search`、`copy` 等同样的判断散落各处。
- **多态（选这个）：** 基类声明 `size()`；`File` 返回内容长度；`Folder` 对孩子求和。调用者统一写 `entry.size()`，加新类型只加新类。这正是组合模式的价值。
- **代价：** 行为分散到各个类里，要看全貌得逐个看；如果操作种类经常增加而节点种类很稳定，反过来用访问者模式更合适。
- **工程提醒：** 文件夹递归求和在很深的树里可能超出 Python 的递归深度，要么改成显式栈，要么按需缓存。
- **取舍说法：** 节点种类稳定、操作常增加时偏访问者；节点种类常增加时偏多态。
