## Q
**内存文件系统 · 预测：哪些 `move` 成功**｜考点 · 必会

树是 `/a`、`/a/b`、`/a/b/d`、`/c`，另有文件 `/a/f.txt`。判断：①`move(/a/b, /c/b)`；②`move(/a, /a/b/x)`；③`move(/a, /c)`；④`move(/a/b, /a/b2)`；⑤`move(/a/b, /a/b)`；⑥`move(/a/f.txt, /a/b/f.txt)`。

## A
| 调用 | 结果 | 原因 |
|---|---|---|
| ① | 成功 | 目标父 `/c` 存在，无同名 |
| ② | 拒绝（成环） | 目标父 `/a/b` 向上走会碰到 `/a` 本身 |
| ③ | 拒绝（已存在） | 目标 `/c` 已有同名条目；这里目标是新完整路径，不是"放进 `/c`" |
| ④ | 成功 | 相当于改名，同一个父 |
| ⑤ | 拒绝（已存在） | 目标就是自己，被同名检查挡住；也可以当作空操作 |
| ⑥ | 成功 | 文件不需要成环检查 |
- **结论：** 目标语义不同于 Unix 的 `mv`：后者目标是已有目录时会"放进去"。接口语义要和面试官确认。
- **成环检查的位置：** 在任何修改之前，从目标父向上走，只对文件夹需要。
