## Q
**内存文件系统 · `move` 的目标是新路径还是目标目录**｜考点 · 必会

`move("/a/f.txt", "/c")` 而 `/c` 是已存在的文件夹，应该得到 `/c`（覆盖或报错）还是 `/c/f.txt`？这个歧义怎么处理？

## A
- **两种语义：** ① 目标是"新的完整路径"：`/c` 被占用→报已存在；想放进去要写 `/c/f.txt`。② 目标是"目标目录"（像 `mv`）：目标是已有目录就放进去，沿用原名。
- **完整路径语义的好处：** 一个操作同时覆盖移动与改名；规则只有一条，没有"目标存在且是目录时的特殊情况"。
- **目录语义的好处：** 和命令行习惯一致。
- **怎么办：** 澄清阶段问清；按选定的语义在接口文档里写明，并让测试固定它。
- **别做的事：** 同一个方法在目标是目录时一种行为、不是时另一种，却不告诉调用者。
