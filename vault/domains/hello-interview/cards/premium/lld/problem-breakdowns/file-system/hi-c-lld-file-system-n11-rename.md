## Q
**内存文件系统 · 改名**｜摘要 · 必会

改名为什么不能只调 `set_name`？

## A
- **步骤：** 根不能改名→新名字不能为空或含 `/`→解析父文件夹→旧名字必须存在→新名字不能和同级冲突→改名。
- **陷阱：** 父文件夹的字典以名字为键。只改条目对象上的名字，字典里仍是旧键：用新名字找不到它，旧名字找到的对象却说自己叫新名字，状态不一致。
- **正确做法：** 先从父文件夹摘下（旧键），改名，再挂回去（新键）；`add` 会顺手把父指针也设好。
- **先检查后动手：** 所有校验放在修改之前，这样失败时树没有变化。
- **边界：** 根、空名字、含斜杠的名字、重名。
