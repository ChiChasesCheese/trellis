## Q
**内存文件系统 · 澄清问题**｜摘要 · 必会

文件系统人人熟悉，为什么更要先澄清？该问哪些问题？

## A
- **为什么要问：** 每个人都以为自己知道文件系统是什么，容易跳过澄清直接设计；面试官对范围有具体预期，你心里的模型未必一致。围绕：系统做什么、结构什么样、范围外是什么。
- **层级：** 单根（Unix 风格 `/home/user/file.txt`），还是 Windows 那样的多个盘符？单根让路径解析简单很多。
- **操作：** 创建、删除、列出，再加移动和改名；可以导航到任意路径取内容。
- **文件内容：** 要存，简单字符串即可。
- **错误：** 父目录不存在、删除根这类情形要抛异常，并且用不同的异常类型，调用者才能分别处理。
- **规模：** 几万个条目，深层目录也要快——这直接影响数据结构的选择（查找要 O(1)）。
- **排除：** 权限、时间戳、符号链接。
