## Q
**内存文件系统 · 必测的行为清单**｜考点 · 加分

只写 8 个测试，应该覆盖什么？

## A
- **创建：** 正常创建；父不存在；重名；在文件下建东西；根上建文件
- **路径：** 相对路径、连续斜杠、末尾斜杠、`/` 本身
- **列出：** 文件夹有序/无序按约定；对文件调用 `list` 报不是目录
- **改名：** 重名、非法名字（含斜杠、空）、改完后旧名找不到新名找得到
- **移动：** 成功后路径变化且后代路径同步；成环被拒；重名被拒；失败后树不变
- **删除：** 删子树；根不可删；删后重名可再建
- **不变量测试：** 每次操作后，遍历整棵树，断言每个孩子的父指针等于所在文件夹，每个键等于孩子的名字
- **并发（如果被追问）：** 多线程同时建同名文件，恰好一个成功
