## Q
**内存文件系统 · `list` 返回副本还是视图**｜考点 · 追问

`children()` 返回字典值的副本。如果直接返回内部字典的视图，会出什么问题？

## A
- **调用者可能改它：** 拿到内部集合后增删，绕过 `add / remove`，父指针不更新，两边不一致。
- **遍历时被修改：** 调用者一边遍历视图，一边（或另一线程）增删孩子，Python 会报"字典在遍历中改变了大小"。
- **副本的好处：** 调用者拿到的是调用时刻的快照，随便遍历、随便改自己的副本，不影响树；在多线程下也能避免读到一半被改的状态（拿副本那一刻仍要在锁内）。
- **代价：** 拷贝是 O(孩子数)；孩子很多又频繁列时可返回只读视图，或用生成器配合锁。
- **一般规律：** 内部可变状态不对外泄漏引用；要么给副本，要么给只读视图。
