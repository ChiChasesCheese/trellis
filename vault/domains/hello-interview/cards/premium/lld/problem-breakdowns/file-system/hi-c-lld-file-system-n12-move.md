## Q
**内存文件系统 · 移动与成环检查**｜摘要 · 必会

`move` 要处理哪些边界？成环怎么检测？

## A
- **步骤：** 不能移动根→找源条目及其父→解析目标父文件夹和目标名字→成环检查→目标重名检查→从源父摘下、改名、挂到目标父。
- **边界：** 根不能动；源不存在；目标父不存在；目标重名；把文件夹移进自己或自己的后代。
- **成环：** 把 `/home` 移到 `/home/user/stuff`，会让 `/home` 同时是 `/home/user` 的祖先和后代，造出一个不可能的环。
- **检测：** 如果源是文件夹，从目标父文件夹沿父指针一直向上走到根，途中碰到源条目就拒绝。
- **为什么先检查再动手：** 摘下之后才发现冲突，源条目就丢了；校验全部放在修改之前。
- **目标是什么：** 这里的目标是新的完整路径（含新名字），所以移动同时能改名。
