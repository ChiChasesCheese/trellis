## Q
**内存文件系统 · 预测：几个调用各抛什么**｜考点 · 必会

文件系统里已有 `/home`（文件夹）和 `/home/notes.txt`（文件）。下面调用各会怎样：①建 `/x/y.txt`；②建 `/home/notes.txt/z`；③取 `//home`；④取 `/home/`；⑤取 `home`；⑥删除 `/`；⑦再建 `/home/notes.txt`。

## A
| 调用 | 结果 | 原因 |
|---|---|---|
| ① 建 `/x/y.txt` | 找不到 | 父级 `/x` 不存在；不会自动补建中间目录 |
| ② 建 `/home/notes.txt/z` | 无效（父不是文件夹） | 把文件当目录往下走 |
| ③ 取 `//home` | 无效 | 出现空片段（连续斜杠） |
| ④ 取 `/home/` | 无效 | 末尾斜杠产生空片段；要不要容忍是需求，应先问 |
| ⑤ 取 `home` | 无效 | 不是绝对路径 |
| ⑥ 删除 `/` | 无效 | 根没有父级，不能删 |
| ⑦ 再建同名文件 | 已存在 | 字典的键唯一，重名在 `add` 里发现 |
- **要点：** 失败发生在任何修改之前，所以每个出错的调用都不会让树变样。
- **追问空间：** 是否需要 `mkdir -p` 式的自动补目录，属于需求，不要默认。
