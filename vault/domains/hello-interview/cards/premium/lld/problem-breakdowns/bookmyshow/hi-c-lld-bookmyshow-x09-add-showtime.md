## Q
**电影票预订 · 新增场次时漏掉一个索引**｜考点 · 追问

`add_showtime` 更新了影院的场次列表和按 id 的字典，却忘了按电影的字典。会出什么症状？怎么从结构上避免？

## A
- **症状：** 场次能订（按 id 找得到），影院的浏览页也显示，但按片名搜不到它——不同入口行为不一致，很难排查。
- **根因：** 冗余的索引要靠每个写入口记得同步。
- **结构上避免：** 把"建索引"写成一个函数 `_index(showtime)`，构造函数和 `add_showtime` 都调用它，新增索引只改一处。
- **更彻底：** 少建索引，让一个主数据（场次表）加几个由它派生的视图；视图可以在需要时重建，必要时提供 `rebuild()`。
- **测试：** 一个不变量测试——遍历所有索引，断言每个场次在每个应有的索引里恰好出现一次。
- **相关：** 删除场次更容易漏，所以同样集中成一个函数。
