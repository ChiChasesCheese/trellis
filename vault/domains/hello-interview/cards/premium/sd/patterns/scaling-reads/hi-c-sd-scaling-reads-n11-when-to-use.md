## Q
**读扩展 · 何时在面试中用**｜摘要 · 必会

读扩展在设计面试里该什么时候、怎么讲？

## A
- **位置：** 几乎每场设计面试的结尾都会谈扩展，而读多的应用从读扩展开始。
- **做法：** 逐个看对外 API，对高流量的接口想办法优化。顺序是先查询优化，再缓存和读副本。
- **强候选人的表现：** 主动找出读瓶颈。画 API 时在会被猛打的接口停一下：用户资料接口每次看人家主页都被调用，有数百万用户就是每天数十亿次读，我在深入环节处理。
