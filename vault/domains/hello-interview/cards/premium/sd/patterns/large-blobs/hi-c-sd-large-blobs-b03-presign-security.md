## Q
**大文件 · 预签名 URL 的安全边界**｜拓展 · 加分

预签名 URL 本质是什么？它的有效期真的就是你设置的那么长吗？

## A
- **本质是持有者令牌（bearer token）：** 谁拿到谁就能用，只受签名里编码的条件约束。所以必须 HTTPS，不要写进日志，不要放在可被转发的位置。
- **有效期取最小值：** 如果用的是临时凭证（如 IAM 角色的会话令牌）签名，URL 在凭证过期时就失效，即使设置的有效期更长；想要长期有效的下载链接，要用能长期有效的凭证签名，或者由服务器在访问时重新签发。
- **无法单独吊销：** 发出后无法撤销某一个 URL，只能等过期或使签名用的凭证失效（会影响所有用同一凭证签的 URL）。所以有效期要短，上传用的链接最好一次一个对象、不可猜的键。
- **按需缩小权限：** 上传 URL 只给 PUT，下载 URL 只给 GET。
