## Q
**大文件 · 何时用、典型场景**｜摘要 · 必会

什么信号说明该用这个模式？视频、照片、网盘、聊天各怎么用？

## A
- **规则：** 经过 API 的文件超过约 10MB 就马上想到它，阈值取决于基础设施，但 10MB 是痛点开始显现的地方。
- **视频平台：** 用户上传 2GB 的 4K 视频，Web 应用生成 S3 预签名 URL，客户端直传（常用分段上传以便续传），S3 事件触发转码工作流。下载由 CloudFront 用签名 URL 提供视频分片，支持自适应码率，服务器完全不碰视频字节。
- **照片分享：** 手机直传原图（现代相机可达 50MB 以上），S3 事件触发异步任务生成缩略图、滤镜、提取元数据；信息流通过 CloudFront 签名 URL 提供图片，防止盗链。
- **网盘：** 拖入 500MB 视频，拿到分块上传的预签名 URL 直传，再触发同步工作流；分享文件生成限时签名 URL，接收者无需有账号。
- **聊天：** 发视频时直传存储，聊天系统只传递文件引用；接收者拿到会过期的签名下载 URL，媒体不会被无限期访问。
