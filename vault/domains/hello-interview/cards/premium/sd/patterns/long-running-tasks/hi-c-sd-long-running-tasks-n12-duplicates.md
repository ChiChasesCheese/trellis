## Q
**长任务 · 追问：用户点了三次，怎么避免重复工作**｜摘要 · 追问

用户不耐烦连点三次"生成报告"，队列里有三个相同任务。怎么处理？

## A
- **危害：** 浪费资源；任务不是幂等的话还可能给同一用户发三封邮件或扣三次款。
- **幂等键（idempotency key）：** 接受任务时要求一个代表该操作的唯一标识。用户发起的动作用用户 ID + 动作 + 时间戳（取整到想防重复的时间窗口）；系统生成的任务用基于输入数据的确定性 ID。开工前检查这个键对应的任务是否已存在，存在就返回已有任务 ID，不创建新任务。
- **提交逻辑：** 先按键查任务，有就返回；没有则创建任务、存下键与任务 ID 的映射、入队、返回任务 ID。
- **工作本身也要幂等：** 任务做到一半失败又被重试应该安全，比如先检查邮件是否已发送、文件是否已处理。
