## Q
**长任务 · 何时在面试中主动提**｜摘要 · 必会

哪四种信号说明该主动引入异步工作者？

## A
- **提到具体的慢操作：** 视频转码、图片处理、PDF 生成、群发邮件、数据导出，这些要几秒到几分钟，马上说"转码要几分钟，所以我立刻返回任务 ID 并异步处理"。
- **算术行不通：** 每天处理 100 万张图、每张 10 秒，约每秒 12 张，等于每秒需要 120 秒的处理时间，Web 服务器会被完全占满，无法服务用户请求。要把它卸给独立的异步工作者池，Web 层保持快，工作者在计算优化硬件上独立扩缩。
- **不同操作需要不同硬件：** 简单 API 请求和 GPU 重活（模型推理、视频处理）不要放在同一批服务器上，GPU 实例上跑异步工作者。
- **被问到规模或故障：** "服务器处理中崩溃怎么办"或"十倍流量怎么办"是引入异步工作者的好机会：一个工作者崩了另一个从队列接手，不丢用户请求。
- **关键是主动：** 你来指出操作太慢，而不是等面试官问，体现对超时、资源利用和体验的前瞻。
