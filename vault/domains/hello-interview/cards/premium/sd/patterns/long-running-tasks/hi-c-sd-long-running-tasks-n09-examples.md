## Q
**长任务 · 典型场景**｜摘要 · 必会

视频、照片、打车、支付、网盘分别有哪些异步任务？

## A
- **视频平台：** 上传触发多种任务：转成不同分辨率（1080p、720p、480p）、生成缩略图、提取字幕、内容审核。每个视频可能需要跨多个工作者处理数小时。
- **照片分享：** 生成多种尺寸、滤镜、提取元数据、图像识别打标签、检查内容政策；扇出也用异步：粉丝数百万的人发帖，工作者把帖子传播到粉丝的信息流。
- **打车：** 匹配异步进行，用户看到"正在寻找附近司机"，工作者评估司机可用性、计算最优路线、定价；司机位置更新也通过异步工作者处理以免压垮主 API。
- **支付：** 基本的刷卡授权是同步的；欺诈检测、3D Secure 验证、webhook 通知用异步工作者；银行转账等延迟确认的支付方式，API 返回 pending，工作者处理实际结算。
- **网盘：** 上传后触发病毒扫描、搜索索引、生成预览、同步到其他设备，大文件处理要几分钟，上传 API 立即返回。
- **共同规律：** 重计算、外部 API 调用、对多用户扇出的操作，都适合异步。
