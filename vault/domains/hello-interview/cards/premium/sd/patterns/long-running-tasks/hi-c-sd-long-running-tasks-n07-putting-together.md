## Q
**长任务 · 完整流程与面试建议**｜摘要 · 必会

一个任务从提交到完成经过哪些步骤？各组件出故障时会怎样？

## A
- **步骤：** Web 服务器校验请求，在数据库创建状态为 pending 的任务记录；把任务 ID（而不是完整数据）推入队列；立刻把任务 ID 返回客户端。工作者从队列拉消息，从数据库取任务详情，把状态改为 processing，执行工作，把结果存起来（文件放 S3，元数据放数据库），最后把状态改为 completed 或 failed。
- **各组件可独立失败：** 队列挂了，Web 服务器仍能接收请求，任务在数据库里堆成 pending；工作者崩了，任务留在队列里等新工作者；数据库有问题，工作者可以重试直到恢复。
- **面试建议：** 别过度复杂。没有特殊理由就选 Kafka（或自己熟悉的队列），工作者用普通服务器进程，除非面试官要求无服务器。重点是展示你理解关注点分离，而不是争论各队列技术的优劣。
