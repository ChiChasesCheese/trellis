## Q
**长任务 · 问题所在**｜摘要 · 必会

为什么 45 秒才能生成完的 PDF 报告不能在一次请求里同步完成？

## A
- **同步处理的极限：** 查个人资料不到 100ms，用户几乎无感。但生成年度报告要查多张表、聚合数百万行、渲染图表，至少 45 秒。
- **第一个问题，超时：** 多数 Web 服务器和负载均衡器的超时在 30 到 60 秒，请求可能根本完成不了。
- **第二个问题，体验：** 用户只看到加载圈，不知道是在工作、失败了还是该刷新。等了 30 秒觉得坏了就重新点，制造重复工作，让问题更糟。
- **不只是报告：** 视频转码要几分钟，头像要裁剪并生成多种缩略图，群发邮件、导入大 CSV 更久。即使能无限扩容，同步处理的用户反馈也很糟。
