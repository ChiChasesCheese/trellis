## Q
**实时更新 · 给"连在某台服务器上的用户"发消息**｜考点 · 必会

聊天系统里 A 要给 C 发消息，但 C 的 WebSocket 连在不知道哪台服务器上。请给出发布订阅和一致性哈希两种方案的流程，并说明默认选哪个。

## A
- **发布订阅：** C 连上任意端点服务器，它订阅主题 `user:C`；A 的消息发布到 `user:C`；发布订阅服务广播给订阅者（也就是 C 所在的那台端点服务器），它沿 C 的连接转发。端点服务器无状态、可互换，入口用"最少连接"均衡。
- **一致性哈希：** 协调服务保存服务器列表；C 连接时被重定向到 `hash(C)` 对应的服务器；A 的消息由更新服务计算 `hash(C)` 直接发给那台服务器，它查出连接并写入。
- **默认选发布订阅：** 小消息、没有多少每连接状态，端点轻、扩展简单。
- **何时选哈希：** 每个连接有重状态，如协作文档中一篇文档的在线状态必须集中在一台服务器上。
- **要追问的点：** 发布订阅不知道 C 是否真的在线，离线消息要另存（队列或数据库）；订阅服务本身要分片，防止单点。
