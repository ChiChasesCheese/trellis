## Q
**实时更新 · L4 与 L7 负载均衡对持久连接的影响**｜摘要 · 必会

L4 和 L7 负载均衡器对长连接各意味着什么？WebSocket 为什么偏向 L4？

## A
- **L4（传输层）：** 只看 IP 和端口，不看内容。效果等同于随机选一台后端，并认为 TCP 连接直接建立在客户端和该后端之间：同一条连接上的所有数据都落在同一台服务器。快、省 CPU，但不能根据请求内容路由。
- **L7（应用层）：** 理解 HTTP，终止客户端连接，再向后端新建连接。可按 URL、头、Cookie 路由（类似 API 网关），能做会话粘性，功能灵活但更耗 CPU。
- **对实时的含义：** 持久连接需要始终连到同一台后端。L4 天然满足，所以 WebSocket 一般配 L4；有些 L7 也支持 WebSocket，但整体上支持参差不齐。
- **HTTP 类方案（轮询、长轮询、SSE）：** L7 更灵活。
- **别忽略连接这一层：** 即使有 L7 帮你屏蔽底层细节，只要你要"持久连接到固定的服务器"，就无法忽略 TCP 连接。
