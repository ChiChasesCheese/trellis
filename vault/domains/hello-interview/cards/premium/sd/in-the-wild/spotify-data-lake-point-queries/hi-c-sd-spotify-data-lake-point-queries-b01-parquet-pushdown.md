## Q
**Spotify 数据湖点查 · Parquet 谓词下推与排序的关系**｜拓展 · 加分

Parquet 自带的最大最小值统计在什么条件下才能真正剪掉数据？这和"按键排序"有什么关系？

## A
- **统计的位置：** 每个行组、每个页都记录各列的最小值和最大值，读者可以把"值不在 [min, max] 内"的整个行组或页跳过，这叫谓词下推（predicate pushdown）。它不会误剪（范围外的一定不含该值），但范围内不一定真有该值，所以只能排除、不能定位。
- **有效的前提：** 数据按这一列大致有序，每个行组的范围互不重叠、很窄。若用户 ID 乱序写入，几乎每个行组的 min 与 max 都覆盖全域，什么也剪不掉。
- **所以排序几乎是免费的杠杆：** 按键排序后，一个键只落在极少几个行组 / 页，统计就能剪掉其余部分；分桶、按页聚集是同一思想的延伸。
- **局限：** 只对排序键有效，对其他列依然无力，这也是需要外部索引或二级索引的原因。
