## Q
**API 设计 · REST · 返回什么**｜摘要 · 必会
API 响应由哪两部分组成？面试里状态码需要记到什么程度？

## A
- **两部分：** 状态码（成功与否）和响应体（通常是 JSON 数据）。
- **够用的状态码：** 200 成功、201 已创建、400 请求有误、401 需要认证、404 不存在、500 服务器错误。
- **真正要分清的是类别：** 4xx 是客户端错了（重试没用，要改请求），5xx 是服务端错了（也许可重试）。这个区分在谈重试、熔断时直接有用。
- **不必背全：** 就算写成 4xx、5xx 甚至用 X 代替具体数字，通常也被接受。
