## Q
**API 设计 · 收尾：判断力与时间**｜摘要 · 必会
API 环节最终考察什么？拿不准时靠什么原则兜底？

## A
- **考察的是工程判断，不是完整规范：** 选对协议（通常 REST）、把资源建清楚、对安全有基本意识。
- **兜底口诀：** 一致、可预测、无状态、重试安全。
- **时间纪律：** 不要超过约 5 分钟。候选人更常见的失败是在 API 上耗太久，而不是做得太少，后面更难的部分才拉开差距。
