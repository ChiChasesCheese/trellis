## Q
**API 设计 · 认证方式选型**｜考点 · 必会
判断下列场景用 API Key 还是 JWT：A) 订单服务调用库存服务；B) 开放给第三方做数据同步；C) 手机 App 的登录用户；D) 要立刻让某个被盗用的令牌失效。

## A
- **A、B 用 API Key：** 服务对服务和第三方开发者是程序在用，不需要用户上下文；服务器保存 key 与权限、限流配置。
- **C 用 JWT：** 令牌带用户 ID、角色、过期时间，网关验签后直接放行，无需每次查库。
- **D 是 JWT 的弱点：** 无状态令牌在过期前一直有效，服务器无法"收回"。办法：令牌有效期设得很短并配合刷新令牌；或维护吊销名单（但这又引入了一次查找，削弱了无状态的好处）。API Key 因为本来就要查表，吊销只要删记录。
- **总结：** 无状态与可吊销是一对取舍。
