## Q
**API 设计 · 数一数查询次数**｜考点 · 必会
GraphQL 查询"取 50 个活动及每个活动的场馆和 3 个最近评论"，朴素解析器会发多少次数据库查询？用批处理后是多少？

## A
- **朴素：** 1 次取活动 + 50 次取场馆 + 50 次取评论 = 101 次（评论按活动各取一次）。
- **批处理：** 活动 1 次，场馆合并成 1 次 `WHERE id IN (...)`，评论合并成 1 次 `WHERE event_id IN (...)`，共 3 次。
- **注意：** 批处理合并的是同一轮解析里的同类查找，所以延迟只多一点点；场馆去重后还能更少。
- **规律：** 查询次数与"嵌套层数"成正比，而不是与数据条数成正比，这就是批处理换来的。
- **注意"最近 3 条"：** 合并后要用窗口函数或按应用层截断，朴素的 `IN` 加 `LIMIT 3` 会限制总数而不是每个活动。
