## Q
**网络基础 · 专用负载均衡器与 L4**｜摘要 · 必会

什么时候需要专用负载均衡器？L4 负载均衡器怎么工作，适合什么？

## A
- **为什么用专用的：** 不想让客户端刷新服务器列表，甚至不想让它们知道后端有多台服务器；或客户端数量大且你不控制，又要快速更新。专用负载均衡器是位于客户端和后端之间的服务器或硬件，决定请求发给谁。
- **代价与收益：** 每个请求多一跳（先到均衡器，再到服务器），换来服务器列表快速更新和精细的路由控制。
- **L4（传输层）：** 基于 IP 地址和端口等网络信息做决定，不看包内容。效果就像随机选了一台后端，并假设 TCP 连接直接建立在客户端和那台服务器之间。
- **特征：** 在客户端和服务器间维持持久 TCP 连接；包检查最少，快而高效；无法基于应用数据做路由；通常在性能优先时使用。
- **连接粘性：** 客户端通过 L4 建立 TCP 连接后，该会话的所有后续请求都由同一台服务器处理，特别适合 WebSocket 等需要持久连接的协议。
- **选择：** 用 WebSocket 通常选 L4，其他情况多半 L7 更合适。
