## Q
**网络基础 · UDP**｜摘要 · 必会

UDP 提供什么、不提供什么？为什么还有人用，浏览器端有什么限制？

## A
- **形象：** 机关枪，"扫射再祈祷"。几乎不在 IP 之上增加任何功能，速度很快：无连接服务，不保证送达、不保证顺序、不防重复。应用收到的只有来源和目的 IP 与端口，其余是一团二进制。
- **特征：** 无连接（没有握手）；不保证送达（丢包没有通知）；无序；延迟低（开销小）。
- **适用：** 速度比可靠性重要，应用或客户端能处理偶尔丢包或乱序：直播视频、在线游戏、VoIP、DNS 查询。比如语音通话，丢一个包只是声音卡一下，整体仍可懂，远胜于重传丢包、被确认包塞满网络。
- **浏览器限制：** 浏览器不能直接开 UDP 套接字，只能经 WebRTC 或基于 HTTP/3 的 WebTransport 间接使用，后者近年才普及。若设计可以用 UDP（比如直播评论里刷屏的点赞和表情），要想清楚浏览器用户怎么办：App 端走实时 UDP 流，浏览器端走较慢、批量的 HTTP 流并在界面上摊开播放。
