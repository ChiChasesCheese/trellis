## Q
**网络基础 · 熔断器与级联故障**｜摘要 · 必会

什么是级联故障？熔断器（circuit breaker）怎么工作，用在哪里？

## A
- **背景：** 资深候选人常被问"这个服务挂了会怎样"。简单的答案是"失败并重试直到它恢复"，但有时这会带来新问题。数据库彻底宕机后要逐个实例重启，一波重试和愤怒用户组成的洪流可能让第一个实例永远起不来（惊群，thundering herd），整个数据库也就无法恢复。
- **为什么爱问：** 值班过的工程师有很多级联故障的故事，通常到凌晨三点才被发现。它既考你是否理解预防办法，也是筛选经验的手段。
- **熔断器五步：** 监控调用外部服务的失败；失败超过阈值就跳闸进入打开（open）状态；打开时请求立即失败，不去尝试真实调用；超时后转入半开（half-open）；用一个测试请求决定关闭熔断器还是继续保持打开。
- **好处：** 快速失败（不等超时）；减少对已吃力服务的负载；自我修复（不用全量流量就能测试恢复）；用户体验更好（快速降级而不是界面卡住）；系统稳定（一个服务的故障不波及整体）。
- **用在哪里：** 第三方外部 API 调用、数据库连接和查询、微服务间调用、可能超时的资源密集型操作、任何可能失败或变慢的网络调用。适合在面试官深入问可靠性、失败模式或灾难恢复时提。
