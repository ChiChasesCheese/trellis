## Q
**网络基础 · 什么时候选 TCP，什么时候选 UDP**｜摘要 · 必会

面试里默认用哪个？UDP 要同时满足哪些条件才值得选？

## A
- **默认 TCP：** 多数面试官默认你用 TCP，甚至不需要特别说出来。如果能为 UDP 做出有理有据的论证，且不搞砸细节，是加分项。
- **选 UDP 的情形：** 低延迟至关重要（实时应用、游戏）；可接受部分数据丢失（媒体流）；高流量遥测或日志，偶尔丢失没关系；不需要支持浏览器，或客户端有替代方案。
- **混合使用：** 网页视频会议常用 TCP / HTTP 做信令和认证，用 UDP / WebRTC 传实际音视频。
- **对比：** UDP 无连接、尽力而为、不保序、无流控与拥塞控制、头部 8 字节、更快，用于流媒体、游戏、VoIP；TCP 面向连接、保证送达、保序、有流控与拥塞控制、头部 20 到 60 字节、因开销较慢，用于其他一切。
