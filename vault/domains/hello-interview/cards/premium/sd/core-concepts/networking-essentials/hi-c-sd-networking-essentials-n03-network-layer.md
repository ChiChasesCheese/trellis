## Q
**网络基础 · 网络层：IP 与公网地址**｜摘要 · 必会

IP 地址从哪来？公网 IP 与私网有什么区别？

## A
- **IP 的职责：** 路由和寻址。节点启动时通常由 DHCP 服务器分配 IP。
- **地址本身是任意的：** 你可以在私有网络里给服务器随便分配地址，只有在你告诉别人时才有意义。
- **想让互联网流量找到你：** 必须使用可路由、由区域互联网注册机构（RIR）分配的公网 IP。互联网的路由基础设施针对公网 IP 优化，知道它们在哪。例如以 17 开头的地址属于苹果，骨干网知道发往这些地址的包要交给苹果的路由器。
- **深度：** 更多的路由细节对面试不重要，可以到此为止。
