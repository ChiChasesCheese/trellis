## Q
**数据库索引 · LSM 树的写路径**｜摘要 · 必会
一次写入在 LSM 树里依次经过哪些组件？每个组件的作用是什么？

## A
- **内存表（memtable）：** 新写入先进内存里的有序结构（红黑树或跳表），全在 RAM，极快。
- **预写日志（WAL）：** 同时把写入追加到磁盘上的日志，为了持久性；顺序追加比随机写快得多，崩溃后可重放日志恢复内存表。
- **刷盘成 SSTable：** 内存表达到一定大小（常为几 MB）后冻结，作为不可变的有序字符串表（Sorted String Table）一次性顺序写入磁盘。
- **压实（compaction）：** 磁盘上的 SSTable 越积越多，后台进程定期合并它们，去掉重复和已删除的条目，保持文件数量可控、读性能不退化。
- **结果：** 写入只是追加内存和日志，刷盘也是大块顺序写，写入极快。
