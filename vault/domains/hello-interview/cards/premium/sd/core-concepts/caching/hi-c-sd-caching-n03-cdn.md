## Q
**缓存 · 缓存放在哪里 · CDN**｜摘要 · 必会
CDN 怎么工作？为什么面试里最稳妥的引入时机是"大规模静态媒体"？

## A
- **是什么：** 分布在全球的边缘服务器网络，把内容副本放在离用户近的地方。
- **流程：** 用户请求图片 → 到最近的边缘节点 → 命中则立刻返回 → 未命中则节点向源站（origin）取回、存下再返回 → 同区域后续用户直接命中。
- **差距有多大：** 源站在弗吉尼亚、用户在印度，每个请求多约 250-300 毫秒；边缘节点提供则约 20-40 毫秒。
- **能力超出静态文件：** 现代 CDN（Cloudflare、Fastly、Akamai）也能缓存公开的 API 响应、HTML，并在边缘运行逻辑做个性化或安全检查。
- **面试里的稳妥顺序：** 先以"大规模静态媒体"为理由引入，只有题目要求时才扩展到动态内容。
