## Q
**Redis · 它是什么、为什么快又好推理**｜摘要 · 必会

Redis 的基本模型是什么？为什么说它既快又容易推理，为什么在系统设计里这么通用？

## A
- **数据结构存储：** C 语言写成，把所有数据放在内存，值是字符串、哈希、列表、集合、有序集合、流这类熟悉的数据结构，不像关系库有优化器、查询计划这些"魔法"。
- **单线程执行命令：** 命令一条接一条、按顺序执行。刻意这样设计：命令执行不需要加锁，而且操作足够简单，单核很少是瓶颈。新版本把网络 I/O 和后台工作交给其他线程，但心智模型仍是"一次一条命令"。
- **后果：** 每条命令天然原子，推理分布式场景时只需要知道几个基础事实。
- **总结的面试价值：** 能力建立在简单数据结构上，扩展影响很好推理，所以你能和面试官聊得深，却不必掌握内部实现。
