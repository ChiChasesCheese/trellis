## Q
**Redis · Lua 脚本在集群里的约束**｜拓展 · 加分

Lua 脚本为什么原子？在集群里使用要注意什么？

## A
- **原子的原因：** 脚本在单线程上作为一条命令执行，期间不会插入别的命令，所以"检查再删除""计数再设过期"这类复合操作是原子的。
- **集群约束：** 脚本访问的所有键必须通过 `KEYS` 参数传入，并且位于同一个槽，否则报错；不要在脚本里拼接键名，Redis 就无法判断路由。需要访问多个键时用哈希标签放在同一个槽。
- **不是事务回滚：** 脚本中途出错，已执行的命令不会撤销。
- **会阻塞：** 脚本越长越阻塞其他请求；用 `EVALSHA`（按脚本摘要调用）省去重复传输脚本文本。
- **新版 Functions：** Redis 7 起的 Functions 把脚本作为服务端库预先加载、随持久化与复制保存，适合管理一组可复用的脚本。
