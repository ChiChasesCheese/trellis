## Q
**邻近搜索 · H3：六边形为什么更适合环形分析**｜摘要 · 必会

Uber 的 H3 相比方格有什么不同？它和 geohash、S2 在可排序性上有什么区别？

## A
- **六边形：** Uber 开源，用于派单和动态加价。方格有两类邻居：四个隔着边，四个隔着角，角上的更远，导致"我周围 N 圈"的查询和热力图很乱。六边形有六个邻居，距离都差不多，更适合 Uber 常做的按圈分析。
- **ID：** 和 S2 一样，每个格子是 64 位的层级 ID，换算后可得父格子。
- **关键区别：** geohash 和 S2 把格子沿空间填充曲线排列，所以一段数值范围扫描就能扫出一个邻域；H3 不这样做，相近的 ID 在地图上不一定相近。
- **取而代之：** H3 提供廉价的网格运算，直接算出任意格子周围的一圈格子，你再按这些确切的 ID 去查。
