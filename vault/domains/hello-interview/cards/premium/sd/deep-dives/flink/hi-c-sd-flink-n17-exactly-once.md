## Q
**Flink · 精确一次的边界：只管内部状态**｜摘要 · 必会

Flink 说自己"精确一次"，调用外部 API 或写数据库时也成立吗？

## A
- **成立的范围：** 对 Flink 内部状态而言，每条消息只被处理一次。
- **不自动延伸到外部：** 调用外部 API 或写外部数据库时，故障后回退重放，同一条记录可能被再次处理，造成重复。
- **解决：** 要达到真正的端到端精确一次，必须让外部操作幂等（重复执行结果相同），或者让写入具备事务性。
- **面试说法：** 先问是否真的需要精确一次，它带来性能开销和复杂度；多数场景至少一次加幂等写入就够了。
