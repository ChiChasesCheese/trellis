## Q
**向量数据库 · 换嵌入模型的迁移**｜考点 · 必会

线上索引用旧嵌入模型（768 维），要换成新模型（1024 维）。直接逐个替换向量会出什么问题？怎么安全迁移？

## A
- **问题：** 新旧嵌入处在不同空间，互相不可比；维度都不同。索引里新旧混杂，查询无论用哪个模型都会得到错误结果。
- **做法：** 建一个新索引，用新模型对所有数据重新嵌入（昂贵、耗时，要限速）；同时新写入的数据双写到新旧两个索引。
- **验证：** 用评估集对比新旧召回与质量，必要时影子流量（同时查两个，只返回旧结果）。
- **切换：** 通过开关把查询切到新索引，保留旧索引一段时间以便回滚，然后下线。
- **预防：** API 和存储里记录每个向量的模型版本号，避免用错的嵌入搜索。
