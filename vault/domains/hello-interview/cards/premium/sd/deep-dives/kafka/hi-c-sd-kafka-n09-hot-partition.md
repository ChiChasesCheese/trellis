## Q
**Kafka · 热点分区的四种处理**｜摘要 · 必会

广告点击流按 `ad_id` 分区，某个广告突然爆红，怎么办？

## A
- **现象：** 点击事件按广告 ID 分区，耐克发布新广告，对应分区流量压垮，成了热点分区。
- **不用键：** 默认（粘性）分区器让消息大致均匀分布。代价是失去相关消息的顺序保证；顺序不重要就是好选择。
- **随机加盐（salting）：** 在广告 ID 后加随机数或时间戳作为分区键，让同一广告分散到多个分区。代价是消费者侧的聚合逻辑更复杂。
- **复合键：** 广告 ID 加上地区或用户段等另一个属性，在能找到与广告 ID 相互独立变化的属性时特别有用。
- **反压（back pressure）：** 直接减慢生产者。托管服务可能内置；自建则让生产者检查分区的滞后，滞后太高就放慢。
