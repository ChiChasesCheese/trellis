## Q
**API 网关 · 鉴权放网关，下游就不用验了吗**｜拓展 · 加分

网关已经验证了 JWT，后端服务还需要再验一次吗？网关里能做的鉴权到什么程度？

## A
- **网关适合做认证（authentication）：** 验证签名和过期时间，确认"这是谁"，拒绝匿名流量，业务服务拿到的是已验证的身份。
- **细粒度授权留给服务：** "这个用户能不能改这个订单"依赖业务数据，网关不知道，硬放进去会让网关变厚。
- **下游仍要做保护：** 网关被绕过（内网其他服务直连、配置错误）时，服务就完全裸奔。零信任做法是服务之间再用 mTLS 或签名令牌互相验证。
- **转发身份：** 网关通常验完后把用户身份放进内部请求头，下游只信任来自网关的请求，所以必须确保外部不能伪造这些头。
