## Q
**API 网关 · 网关缓存什么、放哪里**｜摘要 · 必会

网关层缓存响应适合什么样的数据？有哪些缓存方式，缓存放在哪里？

## A
- **适合缓存：** 访问频繁、变化慢、并且与具体用户无关的响应。判断标准是同一输入是否总得到同一结果；用户私有的数据放进共享缓存会串号。
- **三种做法：** 整个响应缓存（热点接口）；部分缓存（只缓存变化少的片段）；失效靠 TTL 过期或事件触发。
- **存放位置：** 网关进程内存最快但各实例各存一份、互不共享；Redis 等分布式缓存命中率高，代价是多一次网络往返。
- **提示：** 这一步是可选的，不是网关的必备能力。
