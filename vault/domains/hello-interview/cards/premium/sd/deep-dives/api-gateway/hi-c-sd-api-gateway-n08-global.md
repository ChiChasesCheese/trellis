## Q
**API 网关 · 全球部署**｜摘要 · 必会

用户遍布全球时，网关怎么部署才能降低延迟？

## A
- **思路像 CDN：** 把网关实例部署到离用户近的区域，用户少走跨洋链路。
- **三个要素：** 多区域部署网关实例；用 GeoDNS（按解析者位置返回不同 IP 的 DNS）把用户导向最近的网关；各区域的路由规则与策略要保持同步，否则不同地区行为不一致。
- **代价：** 配置同步和后端服务的位置要一起考虑，网关离用户近但后端远，延迟优势会被抵消。
