## Q
**API 网关 · 找出这段说法的问题**｜考点 · 必会

面试中有人这样答："我会加一个 API 网关，它负责鉴权、限流、日志、压缩、CORS、请求大小校验和 IP 黑名单……"并且讲了两分钟。这段回答的问题在哪？一个 senior 会怎么说？

## A
- **问题一：漏了根本理由。** 没提路由，也没说明为什么这个设计需要网关（多个后端服务要隐藏在一个入口后面）。
- **问题二：清单式列举。** 中间件没有和这个系统的需求挂钩，像在背词，而且占掉本该给核心设计的时间。
- **senior 的说法：** 一句"微服务前放一个网关做路由和基础中间件，鉴权与限流在这里统一做"，再说明这个系统里哪一个中间件特别重要，例如开放 API 重点是限流。
- **时间感：** 网关只值半分钟，剩下的时间留给数据模型、扩展性等深入话题。
