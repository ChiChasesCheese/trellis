## Q
**API 网关 · 核心职责：路由第一，中间件其次**｜摘要 · 必会

网关的核心职责是什么？为什么说很多人讲网关时漏掉了最关键的一条？

## A
- **第一职责是请求路由（routing）：** 判断每个请求该交给哪个后端服务。这是引入网关最根本的理由，没有路由就不需要这个组件。
- **附带职责是横切关注点**（cross-cutting concerns）： 鉴权、限流、缓存、SSL 终止等所有服务都要做的公共逻辑，放在入口做一次，比每个服务各写一遍更一致、更省事。
- **常见失误：** 只大谈中间件、不提路由，等于没说清它为什么存在；面试官会觉得你在背清单。
- **说法：** 先讲"为了路由"，再补一句"顺便承载基础中间件"。
