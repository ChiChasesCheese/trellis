## Q
**API 网关 · 它是什么、为什么需要**｜摘要 · 必会

单体拆成许多微服务之后，客户端为什么需要一个统一入口？API 网关（API Gateway）到底是什么？

## A
- **定义：** 所有客户端请求先到网关这一个入口，由它决定交给哪个后端服务，并顺手做鉴权等公共处理。
- **为什么出现：** 没有网关时客户端要记住每个服务的地址和协议；服务一拆分、合并或搬家，所有客户端都得改，耦合很重。
- **它做的隔离：** 内部拓扑和对外接口分开，内部怎么重构，对外 API 都可以不变。
- **刻意保持很薄（thin）：** 只做转发和公共逻辑，不放业务逻辑；一旦塞进业务，网关就变成新的单体和发布瓶颈。
- **类比：** 酒店前台，客人不用知道客房部、维修部在哪，前台统一受理再转给对应部门。
