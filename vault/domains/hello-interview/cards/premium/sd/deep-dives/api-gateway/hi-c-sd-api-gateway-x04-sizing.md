## Q
**API 网关 · 网关要开多少实例**｜考点 · 必会

峰值 20 万 QPS，单个网关实例稳定处理约 1 万 QPS。需要几个实例？限流用的计数器放在哪里才正确？

## A
- **容量：** 200000 / 10000 = 20 个实例刚好吃满；要留余量（一个可用区宕机、突发流量），按 30 个左右规划，分布在多个可用区。
- **为什么能直接加实例：** 网关无状态，加机器不需要迁移数据。
- **限流的陷阱：** 若每个实例各自计数，一个用户的请求被均匀打散到 30 个实例，实际放行量最多是限额的 30 倍（取决于分流方式）。
- **做法：** 要精确的全局限额就把计数放进共享存储（Redis），代价是每个请求多一次网络调用；允许误差时可让每个实例用"限额除以实例数"的本地配额。
