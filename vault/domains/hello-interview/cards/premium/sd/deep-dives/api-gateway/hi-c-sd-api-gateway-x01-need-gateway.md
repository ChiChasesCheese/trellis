## Q
**API 网关 · 该不该画网关**｜考点 · 必会

你在设计一个短链接服务：一个单体后端，网页和手机 App 调用同一组接口。你已经画好了负载均衡器，该不该再加一个 API 网关？说出你的判断和理由。

## A
- **结论：不加。** 网关解决的是"多个服务各有地址、客户端要认识所有服务"的问题；这里只有一个后端，路由无从谈起。
- **负载均衡器已经够用：** 它负责分流和健康检查；鉴权、限流在单体里用中间件或过滤器实现，成本更低。
- **加了的代价：** 多一跳延迟、多一个必须高可用的组件、多一份配置要维护。
- **什么信号会改变结论：** 后端拆成多个服务，或出现不同种类的客户端需要不同的接口形态；那时再引入网关。
