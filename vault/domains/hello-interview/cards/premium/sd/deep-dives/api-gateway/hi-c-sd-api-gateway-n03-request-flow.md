## Q
**API 网关 · 一个请求穿过网关的六步**｜摘要 · 必会

一个请求从客户端到网关、后端、再回到客户端，网关依次做哪些事？顺序有什么讲究？

## A
- **入口：** 客户端通常走 HTTP，也可以是 gRPC 等其他协议。
- **六步顺序：** ① 校验请求格式 ② 套用中间件（鉴权、限流等）③ 查路由表转发 ④ 后端处理并返回 ⑤ 网关转换响应 ⑥ 可选地缓存响应。
- **便宜的检查在前：** 先校验、再鉴权限流，最后才碰后端，越早拦住注定失败的请求，越能保护后端的算力。
- **面试里：** 不必逐步展开，一句话带过；只有被追问时再讲具体某一步。
