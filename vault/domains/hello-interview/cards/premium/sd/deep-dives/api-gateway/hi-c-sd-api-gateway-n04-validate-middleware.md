## Q
**API 网关 · 请求校验与中间件：该提哪几个**｜摘要 · 必会

网关第一步的请求校验查什么？可挂的中间件很多，面试里该提哪几个、花多少时间？

## A
- **校验：** 查 URL 是否合法、必需请求头是否齐全、请求体格式是否符合约定。坏 JSON、缺 API key 这类请求不可能成功，在入口就地返回清楚的错误，后端不用白白处理。
- **中间件清单很长：** JWT 鉴权、限流、SSL 终止、日志监控、压缩、CORS、IP 黑白名单、请求大小限制、超时、版本管理、流量整形、服务发现。
- **面试相关度最高的三个：** 鉴权、限流、IP 黑白名单。
- **篇幅要克制：** 提中间件要带目的，一句"我加一个网关负责路由和基础中间件"后继续主线；网关不是最有意思的部分，在它身上停留太久比讲少更危险。
