## Q
**API 网关 · 水平扩展与两层负载均衡**｜摘要 · 必会

负载上升时网关怎么扩展？客户端到网关、网关到服务这两段的负载均衡有什么区别？

## A
- **扩展方式：** 网关通常无状态（请求之间不依赖本机保存的数据），所以直接多开实例，前面放负载均衡器分流。
- **客户端到网关：** 由专用负载均衡器负责，例如 AWS ELB 或 NGINX。
- **网关到后端服务：** 网关自己对同一服务的多个实例做均衡。
- **面试里的画法：** 画一个"网关加负载均衡"的方框就够；入口细节画得越多，越容易偏离真正要讨论的核心功能。
- **前提：** 一旦网关里放了本机状态（如本机限流计数、本机缓存），"无状态"就不成立，扩展时要把状态外移。
