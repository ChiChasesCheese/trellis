## Q
**API 网关 · 网关的超时、重试与熔断**｜拓展 · 加分

网关是所有流量的必经之路。后端服务变慢时，网关层可能出什么问题，该怎么防？

## A
- **慢比挂更危险：** 后端变慢时，网关上堆积等待中的连接，线程或连接池耗尽，一个服务拖垮整个入口，其他健康服务也访问不了。
- **超时：** 每个后端设独立超时，并且总预算要小于客户端的超时，否则网关还在等、客户端早已放弃。
- **重试要节制：** 无脑重试会把压力放大（重试风暴）；只对幂等请求（如 GET）重试，限制次数并加随机退避，并设置全局重试预算。
- **熔断（circuit breaker）：** 某服务连续失败时在一段时间内直接快速失败，让它有机会恢复。
- **舱壁隔离（bulkhead）：** 给不同后端分配独立连接池，一个坏服务耗不光所有资源。
