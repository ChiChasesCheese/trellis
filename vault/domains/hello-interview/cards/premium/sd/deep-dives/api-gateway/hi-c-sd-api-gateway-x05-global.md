## Q
**API 网关 · 欧洲用户延迟高怎么办**｜考点 · 必会

网关和后端都部署在美国东部，欧洲用户的首字节延迟明显偏高。你会怎么改？新的方案带来什么新问题？

## A
- **改法：** 在欧洲区域部署网关，用 GeoDNS 把欧洲用户解析到它，TLS 握手和请求校验在近处完成。
- **只放网关不够：** 如果网关转发的后端仍在美国，每个请求还是要跨洋；要看哪些响应能在网关缓存，或把读服务也复制到欧洲区域。
- **新问题一：配置一致性。** 路由表和限流策略要同步到各区域，更新时短时间内各区域规则会不一致。
- **新问题二：** 跨区域的限流配额、故障切换（区域整体宕机时 DNS 切走需要时间）。
