## Q
**大数据结构 · HyperLogLog 怎么实现与精度**｜摘要 · 必会

为什么 HyperLogLog 要分桶？桶里存什么，最后怎样得到估计，内存和误差的关系是什么？

## A
- **为什么分桶：** 只靠一个最长连续零，一次偶然的罕见哈希就会严重拉偏估计，所以做冗余，用多个桶平均。
- **做法：** 哈希后，前 b 位当桶号（共 2^b 个桶），剩下的位用来数前导零；每个桶存一个寄存器，记下见过的最大前导零数加 1。新元素只有前导零更多时才更新。
- **估计：** 对所有寄存器取调和平均，再对很小或很大的范围做修正。
- **精度与内存：** 约 1.5 KB 内存，对几十亿个元素误差约 2.3%；3 KB 约 1.6%；6 KB 约 1.2%。误差与 1/√m 成正比，m 是寄存器数。
- **含义：** 内存翻倍，误差只降到约 0.7 倍，到后面性价比下降。
