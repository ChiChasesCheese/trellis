## Q
**大数据结构 · 布隆过滤器的直觉：盖章**｜摘要 · 必会

用「村民开会盖章」的比喻，怎样理解布隆过滤器能证明某人没来，却不能证明某人来了？饱和又是什么？

## A
- **比喻：** 每个村民有一枚独特的印章，开会的人都盖在同一张纸上。检查某人时，看他印章的每一处纹路是否都被墨水盖到。
- **有一处没盖到：** 他一定没来，不用寄礼物。
- **全都盖到：** 只能说他可能来了，因为别人的印章叠在一起也可能盖满这些纹路，所以永远无法证明某人来过。
- **饱和：** 参会的人太多，纸上几乎被盖满，每个人的纹路都被覆盖，就什么都证明不了，方案失效。
- **印章设计：** 印章要唯一、也要稀疏；整块实心的印章会让纸立刻饱和。
