## Q
**大数据结构 · 近似分位数的直觉**｜摘要 · 必会

要看 p95 响应时间，为什么不能存下所有数值再排序？怎样用桶近似？

## A
- **问题：** 精确分位数要存下并排序全部数据，海量数据下做不到。
- **直方图：** 把数值分成区间，每个区间只记一个计数，内存有界，与数据量无关。
- **例子：** 1 万个请求按区间计数：0–10ms 有 1000 个，10–50ms 有 8000，50–100ms 有 800，100–500ms 有 180，500ms 以上 20。累计依次是 1000、9000、9800、9980、10000。
- **读出分位数：** 100ms 以内共 9800 个，占 98%；中位数是第 5000 个，落在 10–50ms 桶；p95 是第 9500 个，落在 50–100ms 桶；p99 是第 9900 个，落在 100–500ms 桶。
- **一眼看清：** 不需要保存任何单次测量，就能得到分布形状。
