## Q
**大数据结构 · 为什么要学概率型数据结构**｜摘要 · 必会

系统要处理海量数据时，为什么有时光加机器不够，要换数据结构？学它有什么风险？

## A
- **为什么：** 数据量大到一台机器的哈希表装不下时，换一种近似的数据结构，会改变整个方案的形状，不只是省点内存。
- **四类结构：** 布隆过滤器（成员判断）、Count-Min Sketch（频次估计）、HyperLogLog（去重计数）、近似分位数（直方图分桶）。
- **风险：** 这些结构不常用是有原因的：哈希表够用时还上布隆过滤器，面试官会当成过度设计。先用最简单的，遇到内存或规模瓶颈再升级。
- **学习顺序：** 对中级面试偶尔有用，但回报率远低于先学好缓存、负载均衡、分区。只会写 Count-Min Sketch 而不懂分区的人，架构仍然做不好。
