## Q
**大数据结构 · Count-Min Sketch 怎么实现与调参**｜摘要 · 必会

Count-Min Sketch 的数据结构长什么样？宽度和深度各控制什么？

## A
- **结构：** 一个 d 行 w 列的二维计数器数组，加 d 个哈希函数，每行一个，哈希值决定这一行里该加哪一格。
- **更新：** 元素到来，每行算出自己的列，把那一格加 1。
- **查询：** 取这个元素在每行的那一格，再取最小值，就是出现次数的上界（只会偏大，不会偏小）。
- **宽度 w：** 控制冲突概率，越宽冲突越少，估计越准。
- **深度 d：** 控制可靠程度，行数越多，越不容易在所有行同时被撞偏。
- **取舍：** 用有界空间换近似计数；精确计数则要和不同元素的个数成正比的空间。
