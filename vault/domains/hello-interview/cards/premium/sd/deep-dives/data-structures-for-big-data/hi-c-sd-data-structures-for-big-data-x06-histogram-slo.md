## Q
**大数据结构 · 从直方图判断 SLO**｜考点 · 必会

1 万个请求，直方图桶计数：0–5ms 6000，5–20ms 3000，20–100ms 800，100–500ms 180，500ms 以上 20。SLO 是 p99 < 100ms。能判断是否达标吗？p95 在哪个桶？怎样改桶让判断更可靠？

## A
- **累计：** 6000、9000、9800、9980、10000。
- **p95：** 第 9500 个请求，落在 20–100ms 桶，达标没有疑问。
- **p99：** 第 9900 个请求，落在 100–500ms 桶，肯定 ≥ 100ms，SLO 不达标。事实上只有 98% 的请求在 100ms 内。
- **为什么 100ms 处必须是桶边界：** SLO 阈值落在某个桶中间时，桶内的请求可能在阈值两侧，就判不出。这里 100ms 恰好是边界，所以能下结论。
- **改桶：** 用指数间距覆盖全范围，并在阈值附近加密，如 50、80、100、120、200ms。
