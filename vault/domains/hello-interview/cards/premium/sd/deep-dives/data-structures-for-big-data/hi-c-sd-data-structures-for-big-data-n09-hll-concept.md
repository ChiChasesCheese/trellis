## Q
**大数据结构 · HyperLogLog 的直觉：最长连续零**｜摘要 · 必会

要统计一个数据集里有多少不同的元素（基数估计），为什么不能用哈希集合？HyperLogLog 的核心直觉是什么？

## A
- **问题：** 日活、独立访客、不同搜索词，这类计数需要去重。HashSet 的内存随不同元素的个数线性增长，数十亿时不可行。
- **抛硬币类比：** 连续出现多次反面的情况很少见，翻得越多，见到的最长反面连续就越长，所以最长连续长度能反推出翻了多少次。
- **落到哈希上：** 把元素哈希成均匀的二进制串。以 1 开头的占 50%，以 01 开头的占 25%，以 001 开头的占 12.5%……如果见过一个前导零很多的哈希，说明已经见过大量不同元素。
- **一句话：** 看哈希值里最长的连续零，就能估出有多少不同的值。
