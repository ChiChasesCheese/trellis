## Q
**大数据结构 · 选哪种结构**｜考点 · 必会

给五个需求选结构：(a) 判断 URL 是否已爬过；(b) 估计每个 IP 的请求次数，取前 100 名；(c) 统计昨日独立访客；(d) 报告 p99 延迟；(e) 每个用户 ID 是否已领过优惠券，要求绝对不能重复发。

## A
- **(a) 布隆过滤器：** 成员判断，漏爬可容忍。
- **(b) Count-Min Sketch 加堆：** 要次数且只关心前 K。
- **(c) HyperLogLog：** 数不同元素个数，容忍约 1–2% 误差。
- **(d) 直方图分桶：** 分位数，指数间距桶。
- **(e) 都不是，用精确存储：** 「绝对不能重复」意味着不能有误判，布隆过滤器的假阳性会让真正没领过的用户被误拒，而且还要支持核销，应该用数据库唯一约束或哈希集合。
- **模式：** 先看这个需求能否容忍误差和哪个方向的误差。
