## Q
**在线判题平台 · 高层设计：题目列表与单题**｜摘要 · 必会

题目列表和单题页怎么落地？为什么选单体加 NoSQL，题目文档里放什么？

## A
- **架构选择：** 多数设计题适合微服务，但这个系统小，单体更省管理成本：一个代码库、一个 API 服务器即可，服务拆分的开销不值得。
- **API 服务器：** 接请求、从库里取数据、做分页。
- **数据库选 DynamoDB 一类 NoSQL：** 不需要复杂查询，测试用例可以作为子文档嵌进题目文档，一次读取就拿全。关系库同样能做，只要能说清理由。列表分页要建好索引。
- **题目文档：** id、标题、题面、难度、标签；`codeStubs`（按语言区分的代码模板）；`testCases` 数组（类型、输入、输出）。模板可由管理员手写，也可以让大模型从一种语言生成其余语言。
- **单题页：** `GET /problems/:id` 取回题面和模板，浏览器里用 Monaco 编辑器让用户直接写。
- **注意：** 这两个功能很简单，几分钟讲完，把时间留给提交和排行榜。
