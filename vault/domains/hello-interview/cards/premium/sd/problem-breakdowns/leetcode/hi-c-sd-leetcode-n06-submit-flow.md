## Q
**在线判题平台 · 高层设计：提交流程与长耗时任务**｜摘要 · 必会

一次提交从点击到出结果经历哪些步骤？判题耗时数秒，属于哪种通用模式？

## A
- **流程（初版）：**
  1. API 服务器收到代码和题目 ID，把它交给对应语言的容器；
  2. 容器在沙箱里运行；容器自己不发起外部调用，而是由管理它的 worker 同步调用（比如 Docker 的 exec 接口），等待结束，从标准输出或挂载卷里读结果；
  3. API 服务器把提交结果写进数据库，再返回给客户端。
- **模式：长耗时任务（managing long running tasks）。** 判题要在容器里对数百个用例跑数秒，是典型的耗时操作：接口立即返回任务 ID，后台 worker 负责耗时工作，避免请求超时，也让 worker 可以独立扩缩。加上消息队列之后就是这个模式的完整形态。
- **要点：** 初版为了先满足功能，同步等待结果；5 秒要求和突发流量放在深入里解决。
