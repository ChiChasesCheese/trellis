## Q
**在线判题平台 · 在哪里运行用户代码**｜摘要 · 必会

提交的代码不可信，直接跑、虚拟机、容器、无服务器函数各有什么优缺点？最终怎么选？

## A
- **差：在 API 服务器里直接跑。** 恶意代码可以删数据、外传数据、挖矿、发起 DDoS；死循环和内存泄漏会吃光 CPU；崩溃会把 API 服务拖垮，所有人都受影响。
- **中：虚拟机（VM）。** 在 hypervisor 上给每次运行一个带完整操作系统的隔离环境，隔离最强，崩了可以重置。缺点是镜像大、启动慢、占资源，生命周期管理不好会浪费钱。
- **好：容器（Docker）。** 和宿主共享内核，只包含应用和依赖，轻量、秒级启动，每种语言一个运行时容器；复用容器时要保证每次运行环境干净（用预热池轮换，跑完即销毁）。代价是共享内核使隔离弱于 VM，必须自己加固并限制资源，防止逃逸。
- **好：无服务器函数。** 云厂商托管、按需自动伸缩，适合 CPU 密集且不可预测的负载。缺点是冷启动延迟和资源上限。
- **选择：容器。** 提交量波动不大，且不想承担冷启动。选哪个都行，关键是讲清取舍。
