## Q
**在线判题平台 · 深入一：沙箱加固**｜摘要 · 必会

用户代码跑进容器后，还要叠加哪些限制来防止滥用？面试里讲到什么程度就够？

## A
- **容器只是起点，再叠五层：**
  - 只读文件系统：代码目录只读，输出写到临时目录并很快清掉，防止篡改和遗留文件；
  - CPU 与内存上限：超限就杀容器，防止资源耗尽；
  - 显式超时：如 5 秒，到点杀进程，防死循环，也顺带兑现"5 秒内返回"；
  - 限制网络：禁用网络，防止外传数据和发起攻击；在 AWS 上可用 VPC 安全组和 NACL 只放行必要连接；
  - 限制系统调用：用 seccomp 限定容器能发出的 syscall，缩小对宿主内核的攻击面。
- **口述程度：** 说清每一层挡住什么威胁即可，不必讲实现。"用 Docker 容器，限制网络，设 CPU 和内存上限，给执行加超时"这一句通常已经够，面试官有兴趣的方向会再追问。
