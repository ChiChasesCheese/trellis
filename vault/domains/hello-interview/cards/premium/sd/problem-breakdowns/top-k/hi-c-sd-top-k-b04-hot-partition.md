## Q
**Top K · 拓展：一个爆款视频压垮一个分区**｜拓展 · 加分

按视频 ID 分区的 Kafka 与分片库里，某个视频突然每秒几十万次播放，会怎样？怎么处理？

## A
- **现象：** 同一个视频的所有事件都落在同一个分区和同一个消费者，那个消费者落后，别的分区空闲，称为数据倾斜（skew）或热点分区。
- **做法一，两级聚合：** 事件先随机或按轮询分散到多个预聚合实例，每个实例在内存里按视频累加，再按视频 ID 把小计送到最终聚合。热点只增加小计数量，不增加事件数量。
- **做法二，加盐：** 给热点视频的键加上 0 到 N−1 的随机后缀，分散到 N 个分区，读取时合并 N 个小计；只对检测出的热点键使用。
- **要点：** 因为播放是可加的（求和），先局部求和再合并不会改变结果；这也是批量聚合能降低写入的同一性质。
- **模式。** 两级聚合：先局部预聚合，再全局合并，用来化解热点键。
