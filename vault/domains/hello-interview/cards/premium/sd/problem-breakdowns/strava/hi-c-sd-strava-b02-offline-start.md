## Q
**Strava 运动记录 · 拓展：离线开始的活动没有服务端 ID**｜拓展 · 加分

接口里 `POST /activities` 先创建活动并由服务端返回 ID。可是用户在无信号处点"开始"，应用该怎么办？

## A
- **矛盾：** 本地优先的前提是"没有网络也能开始"，但按这个接口，创建要先联网拿 activityId，后续的路线点都挂在这个 ID 上。
- **做法：** 活动 ID 由客户端生成（UUID，或带时间前缀的 UUIDv7/ULID，碰撞概率可忽略），本地先用它记录；联网后用 `PUT /activities/{id}`（带完整内容）或"创建或覆盖"的语义上传。
- **好处：**
  - 上传天然幂等：重发同一个 ID 只会覆盖不会重复；
  - 不再需要"创建"这次往返；
  - 多个设备离线各自创建，不会 ID 冲突。
- **要点：** 离线优先系统里，实体 ID 的生成权要交给客户端，服务端只做校验和去重。
- **模式。** 客户端生成幂等键：用 ID 的可预先生成性换取离线能力和安全重试。
