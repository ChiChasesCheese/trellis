## Q
**Strava 运动记录 · 运动中的路线与距离**｜摘要 · 必会

运动中怎么记录路线和距离？最简方案是什么，它有什么明显的浪费？

## A
- **采样：** 手机用系统定位服务（iOS 的 Core Location、Android 的 Fused Location）按固定间隔取 GPS 坐标，比如骑行 2 秒一次、跑步 5 秒一次。具体 API 不必背，要知道手机自带 GPS。
- **距离：** 用 Haversine 公式（球面上两经纬度点的大圆距离）算新点与上一个点的距离，累加到活动的距离字段。
- **最简流程：** 客户端把每个点发给活动服务，服务把点和记录时间写进 Route 表，再更新距离。
- **明显的浪费：** 这些计算在手机上同样能做。把每个点都发给服务端，既耗流量电量，又在没网时彻底失效，还让服务端承担了不必要的写入。这正是第一个深入问题要解决的。
