## Q
**协同文档编辑 · 光标与在线状态**｜摘要 · 必会

他人光标和在线状态为什么不放进文档数据里？怎么实现？

## A
- **用途：** 感知（awareness）让你看到同伴在编辑哪里，避免同时改同一处或重复劳动。
- **特性：** 它是瞬时的，只关心现在的位置，不关心一小时前；用户离线后位置也毫无意义，数据随连接而存在。
- **所以：** 不放进文档数据，也不落盘。
- **做法：**
  - 用户把光标变化上报文档服务；服务存在内存里，经同一 WebSocket 广播给其他用户；
  - 新用户连入时，服务从内存读出别人的光标和在线状态发给他；
  - 服务跟踪套接字断开，把该用户从列表移除，并向剩余用户广播。
- **阶段结论：** 到这里已经是一个能工作的协同编辑器，能撑几千个用户（单台服务器）。
