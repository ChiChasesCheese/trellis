## Q
**协同文档编辑 · 各级别的期望**｜摘要 · 必会

协同文档编辑器这道设计，中级、高级、Staff 分别被期望做到什么？

## A
- **中级：** 面试官通常不会问中级。若被问到，期望能给出高层设计，并在协助下思考高并发问题；要显示出能随机应变、提出方案，并有一个小而在增长的技术工具箱。
- **高级：** 立即意识到一致性与持久性难点。可以从很基础、低效的方案起步，但要主动识别瓶颈并解决。不要求区分 OT 和 CRDT，但要能谈数据库的取舍和局限，以及它们怎样影响设计。可能还有时间多做一个深入问题。
- **Staff：** 期望对问题近乎精通。大致熟悉 CRDT；对套接字服务的伸缩、一致性取舍、序列化问题、事务等了如指掌；能走完所有深入问题，并可能加一个额外的。
