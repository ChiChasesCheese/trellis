## Q
**协同文档编辑 · 深入一：伸缩带来的状态迁移与运维问题**｜摘要 · 追问

一致性哈希方案在扩缩容和故障时有什么代价？面试官追问时要讲哪些点？

## A
- **核心代价：** 搬迁的是状态。不仅要让被替换的用户断线重连到正确服务器，还要把文档操作移到正确的服务器上。
- **扩缩容复杂度：**
  - 加服务器时要同时记新旧两个哈希环；
  - 过渡期请求可能要发往多台服务器；
  - 服务器故障要快速重新分配连接并更新环。
- **连接状态管理：**
  - 要有可靠监控，发现服务器故障与连接问题；
  - 客户端必须实现重连逻辑，应对服务器不可用。
- **容量规划：**
  - 确保服务器有足够资源承担其连接负载；
  - 监控连接分布，防止出现热点服务器。
- **为什么还是值得：** 一致性哈希让搬迁规模只与变动的服务器数成比例，而不是全部文档。
