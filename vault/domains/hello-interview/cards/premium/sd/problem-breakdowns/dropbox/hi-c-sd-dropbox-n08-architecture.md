## Q
**云文件存储 · 整体设计里各组件做什么**｜摘要 · 必会

把四个功能合在一起后，上传方、下载方、网关、文件服务、元数据库、S3、CDN 分别负责什么？

## A
- **上传方和下载方：** 客户端（浏览器、手机、桌面）。上传方还负责主动发现本地变化并推送；下载方负责发现远端变化并下载。
- **负载均衡和 API 网关：** 路由请求，处理 SSL 终止、限流、请求校验。
- **文件服务：** 控制平面（control plane）。读写元数据，用 S3 SDK 生成预签名 URL。生成预签名 URL 是纯本地的签名运算，用服务自己的 AWS 凭证做加密签名，不需要调用 S3。它不经手文件上传下载。
- **元数据库：** 文件名、大小、类型、上传者，以及用于权限检查的 SharedFiles 表。
- **S3：** 存文件字节，客户端凭预签名 URL 直传。
- **CDN（如 CloudFront）：** 下载时文件服务发的是 CDN 签名 URL；首次请求从 S3 回源（未命中），之后从边缘节点提供（命中），用户从最近的边缘下载。
