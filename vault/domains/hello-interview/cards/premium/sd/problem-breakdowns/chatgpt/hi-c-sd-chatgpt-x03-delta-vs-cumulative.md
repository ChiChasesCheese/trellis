## Q
**ChatGPT · 计算：每个 token 重发全文有多浪费**｜考点 · 必会

同事为了省事，每生成一个 token 就向频道发布"目前为止的全文"。一个 4000 token 的回答一共发出多少 token？是只发增量的多少倍？回答到 3 万 token 呢？

## A
- **累计发送：** 第 k 步发 k 个 token，总量 1+2+…+4000 = 4000×4001÷2 = 8,002,000，约 800 万 token。
- **增量发送：** 4000 个 token，每个只出现一次。
- **倍数：** 800 万÷4000 ≈ 2000 倍。
- **3 万 token：** 30000×30001÷2 ≈ 4.5 亿，是 3 万的 15000 倍。
- **结论：** 总量与长度的平方成正比，在 12 万路并发流下带宽不可行。发布增量时每个 token 在线上只出现一次，客户端自己拼接。
- **配套：** 增量要带序号或 Stream ID，缺一条才能被发现和补齐。
