## Q
**ChatGPT · 计算：按 token 预留的配额怎么扣、怎么退**｜考点 · 必会

用户的桶里还有 8000 token。他发一条提示，输入共 2000 token，请求的最大输出 4000。准入时怎么扣？实际输出 600 token 后桶是多少？如果桶里只剩 5000 呢？

## A
- **准入：** 扣精确输入 2000，再预留最大输出 4000，共 6000，桶剩 2000。
- **结束：** 实际成本 2000+600 = 2600，退还 6000−2600 = 3400，桶回到 8000−2600 = 5400。
- **只剩 5000：** 不够预留 6000。可选：①拒绝并提示稍后重试；②排队等桶补充；③把本次最大输出降到 3000（5000−2000）再放行，但可能截断回答。选哪个是产品决策，**不能**先放行再中途砍流，预留的意义就是一次运行永远不超出启动时的预算。
- **预留的代价：** 同时开 5 个这样的运行会占住 5×6000=3 万预算，而实际只用 1.3 万；吞吐受最坏情况限制，最大输出设得太大会冤枉用户。
- **为什么检查在聊天服务：** 网关只见原始请求，聊天服务拼出提示词，才知道输入有多少 token。
