## Q
**通知系统 · 拓展：为什么不用 FIFO 队列直接解决去重**｜拓展 · 加分

SQS 有 FIFO 队列和消息去重 ID，为什么通知系统仍要自己做去重？

## A
- **FIFO 的去重窗口只有 5 分钟：** 相同去重 ID 的消息在窗口内只投递一次；超过窗口，同一条消息再发就不会被识别。而调用方的重试、死信队列回放可能在几小时后。
- **它只防重复入队：** 重复的另一个来源是消费者在调用服务商后、删除消息前死亡，这属于投递侧的重复，队列去重管不到。
- **吞吐受限：** FIFO 为了保证顺序，吞吐上限低于标准队列，并且同一消息组内是串行的；洪峰每秒 5000 条的需求和严格顺序（范围外）都不需要它。
- **结论：** 队列自带去重是第一层的补充，不是替代；端到端的幂等键、发送前检查加成功后记录仍然需要。
- **一般原则：** 去重要放在每个能产生重复的边界，而且保留时间要覆盖该边界上最晚的重试或回放。
