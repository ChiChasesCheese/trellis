## Q
**票务系统 · 各级别的期望**｜摘要 · 必会

Ticketmaster 题在中级、高级、Staff 以上各被期望做到什么？

## A
- **中级（约 80% 广度）：** 定义清楚 API 和数据模型，做出至少能浏览和订票的高层设计；至少用「状态字段加超时加 cron」解决双订；更多深度是加分项，不要求。面试官会探查每个组件的基础，如你加了 API 网关，会问它做什么。
- **高级（60% 广度、40% 深度）：** 快速过完高层设计，把时间花在：用 Elasticsearch 优化搜索；用分布式锁预订座位并防双订；讨论热门活动；要知道分片和复制。
- **Staff 及以上（40% 广度、60% 深度）：** 基础带过，深入至少 2 到 3 个方向，体现实践经验和创新；要高度主动，面试官只负责聚焦，不负责引导；好的衡量是面试官聊完后是否获得了新的认识。
- **画图：** 视觉沟通重要，面试官会在第二天凭你的图回忆，图要清晰。
