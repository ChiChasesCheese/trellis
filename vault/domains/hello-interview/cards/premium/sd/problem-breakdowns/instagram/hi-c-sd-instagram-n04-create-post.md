## Q
**Instagram 图片分享 · 发帖的基础流程**｜摘要 · 必会

最简单的发帖链路有哪些组件、各管什么？这个版本的假设是什么？

## A
- **链路：** 客户端 → API 网关 → 发帖服务（Post Service）→ 帖子库（Posts DB）+ 对象存储（Blob Store，S3）。
  - 网关是统一入口，负责路由，也集中做认证、限流、日志这类横切关注点；
  - 发帖服务存元数据（作者、时间、说明、媒体链接）到库，字节存 S3，返回 postId；
  - 库里只存媒体的链接，因为数据库不擅长存大二进制，S3 便宜且为大对象设计。
- **假设：** 这个版本假设媒体小到一次请求就能传完。大文件的分片直传是深入问题，不要在第一遍就画复杂。
- **面试做法：** 先把每个功能需求逐一用最简方案走通，再回头按非功能需求找瓶颈，这样即使时间不够，也已经有一个可运行的完整系统。
