## Q
**支付系统 · 拓展：授权与扣款是两步**｜拓展 · 加分

信用卡支付为什么常分"授权"和"扣款"（capture）两步？这对 PaymentIntent 状态机意味着什么？

## A
- **授权（authorize）：** 向发卡行确认卡有效、额度足够，并冻结这笔额度，钱还没有真正转移。
- **扣款（capture）：** 商户在发货等条件满足后，才真正请求划转，金额不超过授权额，可以更小（如缺货只发部分）。
- **为什么分开：** 商户在确认能履约前不想收钱；酒店、租车等场景要预授权后按实际消费扣款；失败时只需释放冻结，不用退款。
- **状态机含义：** created → authorized → captured，另有 canceled（授权后撤销、释放冻结）和 refunded（扣款后退回）；每个状态转换只能向前，非法转换被拒。
- **授权会过期：** 授权不是永久的，过期时间因卡组织和卡类型而异（通常是几天到一周量级），超过后要重新授权，所以系统要记录授权时间，并在到期前提醒或自动处理。
- **结算是更晚的第三步：** 扣款后资金在清算、结算流程里到账，往往隔天或更久，所以 `captured` 不等于钱已到商户账户。
- **对设计的影响：** 状态转换表、过期任务和对账（授权数、扣款数、结算数三者核对）都由这个模型衍生。
