## Q
**网络爬虫 · 系统接口与数据流**｜摘要 · 必会

没有用户界面的数据处理系统，怎样开始设计？这个爬虫的输入、输出和数据流是什么？

## A
- **为什么先定接口：** 对数据处理类题目，先明确系统收什么、产出什么，划出系统边界，再据此搭整体结构。这里没有用户接口，所以用"输入输出"代替 API。
- **输入输出：** 输入是种子 URL，输出是从网页提取出的文本。
- **数据流（先简单、再改进）：**
  1. 从待爬队列（frontier）取一个 URL，向 DNS 查 IP；
  2. 用 IP 向外部服务器拉取 HTML；
  3. 从 HTML 中提取文本；
  4. 把文本存进数据库；
  5. 提取网页里的链接，加入待爬队列；
  6. 重复，直到所有 URL 爬完。
- **目的：** 在设计前就把流程和面试官对齐，后面的组件直接对应这些步骤。
