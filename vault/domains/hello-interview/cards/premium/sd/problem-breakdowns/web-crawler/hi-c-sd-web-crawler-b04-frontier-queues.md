## Q
**网络爬虫 · 拓展：按域名分队的待爬队列（front/back queue）**｜拓展 · 加分

大型爬虫的待爬队列怎样同时做到"优先级"和"每个站点的礼貌间隔"？为什么单个先进先出队列做不到？

## A
- **单队列的问题：** 先进先出的队列里，同一域名的 URL 可能挨在一起，爬虫取到后只能等或延后，既浪费并发，又容易把礼貌延后误记成重试次数。
- **前端队列管优先级：** 若干个队列，按优先级（网页热度、更新频率、深度等）把 URL 分进去，取的时候偏向高优先级队列。
- **后端队列管礼貌：** 每个主机（或一组主机）对应一个队列，每个爬虫线程固定绑定若干个后端队列，保证同一主机同一时刻只有一个线程在访问。
- **最小堆调度：** 用一个按"该主机下次允许访问时间"排序的最小堆，堆顶就是最早可以访问的主机；取出后爬一个网页，再把它的下次时间设为 now + 间隔放回堆。
- **这是 Mercator 一类爬虫的经典结构：** 把"选谁"和"何时轮到"拆成两层。
- **模式。** 双层队列：先按优先级挑，再按资源（主机）排队限速。
