## Q
**网络爬虫 · 最初的高层设计与种子 URL**｜摘要 · 必会

爬虫的简单版有哪些组件，各自负责什么？种子 URL 从哪来？

## A
- **待爬队列（Frontier Queue）：** 存放要爬的 URL，从种子开始，随爬随加；技术可用 Kafka、Redis 或 SQS，稍后再选。
- **爬虫（Crawler）：** 拉取网页、提取文本、提取新链接放回队列；后面再讲怎样扩展到 100 亿页。
- **DNS：** 把域名解析成 IP；缓存、失败处理、避免压垮 DNS 服务器是后续话题。
- **外部网页服务器：** 系统边界之外，我们从它拉 HTML。
- **S3 文本存储：** 用对象存储（blob）保存文本，可扩展、持久且便宜，GCS、Azure Blob 同理。
- **边界：** 虚线框内是我们的系统，框外（网页）是外部。
- **种子 URL：** 多数情况下题目会给；顺口问一句显得全局思考。若没有，可从搜索引擎、新闻站、社交平台、网站目录入手。
