## Q
**帖子搜索 · 实体与接口**｜摘要 · 必会

帖子搜索的实体有哪些？接口怎样分成读写两条路径？

## A
- **实体：** 用户（User，创建帖子）、帖子（Post，要被搜索的对象，有内容、作者，隐含点赞数）、点赞（Like，只关心点赞数）。实体很简单，不必多花时间。
- **两条路径：** 查询路径是搜索接口；写路径是发帖和点赞两个接口。
- **现实：** 真实系统里发帖和点赞事件会来自 Kafka 之类的事件总线；面试中先分成独立接口讲清楚，并告诉面试官实际会合并进已有系统。
- **得到的形状：** 写入经两个写接口进库，查询经搜索接口读库。先有这个骨架，再优化。
