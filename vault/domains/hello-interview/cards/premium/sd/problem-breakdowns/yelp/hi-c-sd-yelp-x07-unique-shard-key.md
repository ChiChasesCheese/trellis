## Q
**Yelp · 以后要分片，"一人一评"的唯一约束放哪里**｜考点 · 追问

评价表将来要分片。如果按评价 ID 随机哈希分片，(user_id, business_id) 的唯一约束还有效吗？按什么键分片才能保住它？

## A
- **随机哈希分片：** 同一用户对同一商户的两条评价可能落在不同分片，各分片的本地唯一索引互相看不见，约束失效。
- **能保住的分片键：** 任何让"相同 (user_id, business_id) 一定在同一分片"的键都行：按商户 ID 分片（同一商户的评价在一起，读取商户评价也只访问一个分片，最自然）；或按这一对的哈希分片。
- **按商户分片的好处：** 查看商户及其评价、计算平均分都是单分片操作；唯一约束与平均分更新能放在同一个本地事务里。
- **代价：** 极热门的商户成为热点分片；可用缓存和读副本缓解。
- **一般规则：** 想要本地唯一性或本地事务，相关列要包含在分片键里（或能决定分片键）。
