## Q
**关键技术 · 对象存储要知道的五个特性**｜摘要 · 必会

面试里讲对象存储，持久性、扩展性、成本、安全和分块上传各要说到什么程度？

## A
- **持久性：** 靠复制和纠删码（erasure coding，把数据切片加校验片，丢几片仍能还原），磁盘或服务器坏了数据也安全。
- **扩展性：** 托管的 S3 可视为无限容量、无限请求，面试里不用单独论证，当作给定条件。
- **成本：** 量级差距是关键——S3 约 0.023 美元 / GB / 月（前 50 TB），DynamoDB 标准表约 0.25 美元 / GB / 月，约相差 10 倍，这就是大文件不进数据库的经济理由。
- **安全：** 内置静态加密与传输加密，以及细粒度访问控制；预签名 URL 就是临时授权的手段，上传和下载都能用。
- **分块上传（chunking）：** 大文件切成小块，可并行传、失败后只重传坏的那块、断点续传；S3 的 multipart upload API 原生支持。
- **选哪个：** 不熟就选 S3，最普及，许多非 S3 产品也兼容它的接口。
