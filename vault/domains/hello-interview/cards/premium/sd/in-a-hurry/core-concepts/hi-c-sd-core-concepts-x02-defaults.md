## Q
**核心概念速览 · 判断"默认选择"是否合适**｜考点 · 必会
判断下面的提议是否合理：A) 聊天室提醒用 WebSocket，而需求只是"每分钟看到是否有新通知"；B) 面试官没提过 GraphQL，候选人主动选 GraphQL；C) 数据 300 GB、500 写/秒，直接按用户 ID 分 16 个分片。

## A
- **A 不合理：** 每分钟看一次，长轮询或 SSE 足够；WebSocket 带来有状态连接的复杂度，仅在需要频繁双向通信时才值得。
- **B 不合理：** 默认 REST，只有面试官暗示客户端多样、需要灵活取数时才换 GraphQL。主动选它要自己论证其复杂度。
- **C 不合理：** 300 GB 与 500 写/秒远低于单库上限，调优良好的单库加读副本就够；分片带来跨分片查询和重分片的麻烦。
- **方法：** 每个默认都要有"换掉它的信号"，没有信号就不换。
