## Q
静态类型和动态类型在机器层面差在哪？为什么 Python 的一个整数要占 28 字节，而 Java 的 `int` 只有 4 字节？

## A
静态类型语言的类型信息主要存在于编译期。编译器知道 `a + b` 里两个都是 `int`，直接生成一条整数加法指令；运行时的 `int` 变量就是 4 个字节的纯数据，没有任何类型标记。类型在编译期已经「用掉」了，运行时不再需要（Rust 的 `i32`、Go 的 `int` 同理，没有运行时标签）。

动态类型语言必须让值自己携带类型，因为运行时才有机会检查。Python 的每个对象都有一个头：引用计数（该对象被引用的次数，用于内存回收，8 字节）、指向类型对象的指针（8 字节）、长度和符号信息（8 字节），再加上数值本身（4 字节），所以 `sys.getsizeof(1)` 是 28，浮点数 `1.0` 是 24。

执行 `a + b` 的过程也不同：

1. 取出 `a` 的类型对象。
2. 在类型上查找 `__add__`，调用它。
3. 如果返回 `NotImplemented`，再试 `b` 的 `__radd__`，都不行就抛出 `TypeError`。

这一连串查找替代了 Java 里的一条指令。静态类型的收益因此不只是「早报错」，还有「少做事」：类型在编译期确定，运行时就不必再问「你是什么」。
