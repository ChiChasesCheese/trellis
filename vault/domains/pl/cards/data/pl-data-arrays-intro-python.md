## Q
Python 的 `list` 在内存里是什么？它的切片、赋值和乘法分别会产生共享还是复制？

## A
**是什么**：`list` 是动态数组，但存的不是值，而是**指向对象的指针**。每个元素 8 字节指针，真正的对象各自在堆上。所以一个 `list` 可以装不同类型，也意味着数字 1,2,3 的列表，是三个指向整数对象的指针，没有 C 数组那样的缓存局部性。

**容量策略**：过度分配约 12.5%（外加一个常数）。本机观察到的容量增长序列：4、8、16、24、32、40、52、64、76、92、108……每次约乘以 1.125。这比 Java 的 1.5 倍和 Go、Rust 的 2 倍更保守，更省内存，复制更频繁。

**三种共享行为**：
```python
a = [1, 2, 3]
b = a            # same object: b.append(4) changes a too
c = a[:]         # slice: a NEW list (shallow copy)
g = [[0]*3]*3    # three references to ONE inner list
g[0][0] = 1      # [[1,0,0],[1,0,0],[1,0,0]]
```

真实输出：`b.append(4)` 后 `a` 变成 `[1, 2, 3, 4]` 且 `a is b` 为 `True`；`c` 追加 5 不影响 `a`；`[[0]*3]*3` 的结果是三行同时改变，要写成 `[[0]*3 for _ in range(3)]`。

**要点**：Python 的赋值永远是「绑定名字到对象」，不是复制；切片是浅拷贝，复制外层列表，内层对象仍然共享。`list.insert(0, x)` 要搬动全部指针，是 O(n)，一次本机测量，在 10 万元素列表头部插入 2000 次约 23 ms，而 `append` 同样次数接近 0。
