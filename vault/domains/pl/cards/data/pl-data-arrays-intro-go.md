## Q
Go 的数组（array）和切片（slice）是什么？切片头里有什么，`append` 和子切片怎样共享或不共享底层内存？

## A
**数组 `[3]int`**：长度是类型的一部分，是值类型。赋值或传参会复制全部元素：`arr2 := arr` 之后改 `arr2[0]` 不影响 `arr`。日常很少直接用。

**切片 `[]int`**：一个三字的小结构（切片头）：指向底层数组某位置的指针、长度 `len`、容量 `cap`。切片本身是值，复制切片头很便宜，但**复制出来的切片和原切片指向同一块底层数组**。

```go
a := []int{1, 2, 3, 4}
b := a[:2]            // shares a's memory: len 2, cap 4
b = append(b, 99)     // len < cap: writes in place
// a is now [1 2 99 4]; b is [1 2 99]
```

真实输出：`a: [1 2 99 4] b: [1 2 99]`，`len/cap b: 3 4`。`b` 的追加没有越出容量，所以直接写进了和 `a` 共享的内存，改掉了 `a[2]`。

**append 的规则**：容量够就原地写，返回的切片头仍指向原数组；容量不够就分配新数组、复制、返回指向新数组的切片头。所以必须写 `s = append(s, x)`，因为切片头可能变了。

**传给函数**：切片头按值传递，函数里 `x[0] = 100` 会改到调用者的数据，但函数里 `x = append(x, 4)` 对调用者的切片头不可见。

**限制容量**：三下标切片 `a[:2:2]` 把容量限制为 2，之后 `append` 必然复制，不会写到 `a` 里。

**要记住的一点**：切片 = 视图 + 可增长，是 Go 的核心类型；是否共享内存取决于容量，而不是你的意图。
