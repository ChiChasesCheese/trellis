## Q
调用 `f(x)` 时，实参和形参之间到底传了什么？传值（call by value）、传引用（call by reference）、传共享（call by sharing）怎样区分？

## A
调用函数要把实参交给形参。问题是：形参拿到的是实参的**一份拷贝**，还是实参**变量本身的别名**？

区分三种模型，只需问两个问题：
1. 函数能不能让**调用者的变量**指向别的东西（重新绑定）？
2. 函数能不能修改调用者变量**指向的对象**（原地修改）？

- **传值**：形参是实参的拷贝，改形参不影响调用者。如果拷贝的内容本身是个指针，两个指针指向同一个对象，所以问题 2 的答案可以是「能」，问题 1 是「不能」。
- **传引用**：形参**就是**调用者那个变量的别名，函数里给形参赋值，调用者的变量跟着变。问题 1 的答案是「能」。C++ 的 `int&`、C# 的 `ref` 属于此类。
- **传共享**（call by sharing，CLU 语言提出）：传的是对象的引用，按值复制这个引用。函数和调用者共享同一个对象（能原地修改），但形参是独立的名字（重新绑定不影响调用者）。

经典测试是 `swap`：

```cpp
void swap_ref(int& a, int& b) { int t = a; a = b; b = t; }
void swap_val(int a, int b)   { int t = a; a = b; b = t; }
// x=1, y=2:  swap_val(x, y) -> still 1 2   swap_ref(x, y) -> 2 1
```

能写出会生效的 `swap` 的才是真传引用。

五门语言的答案：C++ 三种都有（值、`T&` 引用、移动），Java 和 Go 全部是传值（Go 没有引用类型的别名），Python 是传共享（行为上与 Java 引用类型相同），Rust 是「移动」或「借用」（把所有权交出去，或只借用一下）。其余四门语言**没有一门**提供 C++ 那种隐式的引用传参，需要别名时都要显式写出：Go 用指针 `*T`，Rust 用 `&mut T`。

设计空间的轴是：**隐式便利**（调用点看不出会不会被改）对**显式清晰**（调用点就能看出）。现代语言倾向后者。
