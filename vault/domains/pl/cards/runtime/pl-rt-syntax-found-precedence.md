## Q
运算符的优先级（precedence）和结合性（associativity）是什么？Python 的 `2**3**2`、`-2**2`、`a < b < c` 各是什么结果，这反映了设计者怎样的选择？

## A
**优先级**决定 `1 + 2 * 3` 里先算哪个；**结合性**决定同一级别的运算符连着出现时怎么分组：左结合 `8 - 3 - 2` 是 `(8 - 3) - 2`，右结合 `2 ** 3 ** 2` 是 `2 ** (3 ** 2)`。这两件事不是数学真理，是语言规定的约定，写进文法里。

Python 的实测：
```python
print(2**3**2, -2**2, 2**-1)   # 512 -4 0.5
print(1 < 2 < 3)               # True
```
- `**` 右结合，所以 `2**3**2` 是 512，不是 64，和数学写法 2^(3^2) 一致。
- `**` 比一元负号优先级高，`-2**2` 是 `-(2**2)` 即 -4，也和数学一致。
- 比较链：`a < b < c` 被当作 `a < b and b < c`，与数学写法一致，是 Python 特意给比较运算符加的语法糖。

**设计者的选择**：C 里 `a < b < c` 是 `(a < b) < c`，布尔值再和整数比，几乎总是 bug。同一串记号，三种处理：Python 赋予链式含义；Java 和 Go 解析成 C 的样子，但类型检查拒绝（Go 报 `mismatched types untyped bool and int`）；Rust 干脆在语法层拒绝（`comparison operators cannot be chained`，并建议改成 `a < b && b < c`）。

**为什么对资深工程师重要**：优先级表是语言“信任你记住多少”的刻度。Go 只有 5 级二元优先级，目的是让人不用查表；C 的 15 级让很多人靠括号自保。实践里，只要表达式里混用了位运算、比较、逻辑运算，就加括号，把读者的记忆负担降为零。
