## Q
什么是装箱（boxing）和对象头？Java 的 `Integer`、Python 的 `int` 比 C 的 `int` 多了什么，一个整数到底占多少内存？

## A
**原始值**（primitive）：Java 的 `int`、Go 的 `int`、Rust 的 `i32`，就是 4 或 8 个字节的数，直接放在变量、数组或结构体里。

**装箱**：把原始值包进一个堆上的**对象**。对象除了数据，还要有**对象头**（object header），记录类型、锁状态、GC 标记等元数据，访问它要通过一个**引用**（指针）。
- Java：`int` 是原始值；`Integer` 是装箱对象。泛型集合（`List<Integer>`）只能放对象，所以 `list.add(5)` 会自动装箱。一个 `Integer` 对象在常见 64 位 JVM 上约 16 字节（12 字节对象头 + 4 字节数据，对齐后 16），引用本身（压缩指针）4 字节。`int[]` 里每个整数只占 4 字节。
- Python：没有原始整数，每个整数都是对象。`sys.getsizeof(1)` 是 28 字节（引用计数、类型指针、长度、数值），一个只有 3 个整数的列表本身 88 字节，还要再加上整数对象。
- Go/Rust：切片、数组、结构体字段里的整数就是原始值，内联存放；只有显式放进接口（Go）或 `Box`（Rust）才会有堆对象和间接。

**两层代价**：
1. **内存**：`int[]` 每元素 4 字节；`ArrayList<Integer>` 每元素约 4 字节引用加约 16 字节对象，约 5 倍；Python 的 `list[int]` 每元素 8 字节指针加 28 字节对象，约 9 倍。
2. **速度**：多一层间接，多一次可能的缓存未命中。

Java 为小整数（-128 到 127）缓存了 `Integer` 对象，所以 `Integer a = 100, b = 100; a == b` 是 `true`，`1000` 就不是。这说明装箱对象有身份，不是值。

要点：**装箱是为了统一对象模型而付的代价**。Java 的 Valhalla 项目要引入“值类”，让对象像原始值一样内联。
