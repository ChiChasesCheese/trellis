## Q
进程（process）和线程（thread）到底是什么？它们在“共享什么、隔离什么”上有什么根本区别？

## A
**进程**是操作系统给一个正在运行的程序分配的“独立小宇宙”：一块私有的虚拟地址空间（代码、全局变量、堆、栈）、打开的文件表、权限。一个进程里的代码默认看不到别的进程的内存，崩溃也不会拖垮别人。

**线程**是进程内部的“执行流”：一个线程有自己的**栈**和一组寄存器（正在执行到哪一行），但同一进程里的所有线程**共享同一块堆和全局变量**。操作系统分别调度每个线程到不同的核上，所以一个进程里可以有很多线程同时前进。

心智模型：进程像一间独立的办公室，线程是办公室里的几个员工，共用同一批文件柜（共享内存），但各有自己的办公桌（栈）。进程间要交换信息，得通过邮局（管道、套接字、共享内存区）。

一个小场景（Python，同一个全局计数器，分别让线程和子进程各加 1）：
```python
counter = 0
def bump():
    global counter
    counter += 1
# thread: Thread(target=bump) then join -> print(counter)
# process: Process(target=bump) then join -> print(counter)
```
输出：`after thread : 1`，`after process: 1`。线程改的是共享的 `counter`（0 变 1）。子进程改的是**它自己那份拷贝**，父进程里的值没有变化；如果子进程和父进程真的共享内存，第二行应该是 2。

决定一切的事实：**线程共享内存，所以通信便宜，但需要同步（锁）防止互相踩；进程隔离，所以安全，但通信贵（要序列化和拷贝），创建也贵。**
