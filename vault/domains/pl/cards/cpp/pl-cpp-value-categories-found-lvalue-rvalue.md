## Q
左值、纯右值、将亡值怎么区分？右值引用 `T&&` 绑定什么？一个类型为 `T&&` 的具名变量算左值还是右值？

## A
**区分的快速办法**：能不能对它取地址、它有没有名字。
- 左值：`x`、`v[0]`、`*p`。有名字或固定位置，可以取地址 `&x`。
- 纯右值：`42`、`g()`、`x + 1`。不能取地址，是“一个值”，不是“一个位置”。
- 将亡值：`std::move(x)`，或返回 `T&&` 的函数调用。它指向一个真实对象，但承诺不会再用它。

**右值引用 `T&&`**（rvalue reference）是一种只能绑定右值（纯右值或将亡值）的引用。它让函数能区分“调用者给了我一个以后不会再用的对象”。

**用重载观察**：

```cpp
void f(int&)  { println("lvalue"); }
void f(int&&) { println("rvalue"); }
int g() { return 1; }
// f(x) -> lvalue    f(g()) -> rvalue
// f(std::move(x)) -> rvalue    f(x + 1) -> rvalue
```

这就是编译器选择拷贝构造函数还是移动构造函数的依据。

**最容易错的一点**：`void h(std::string&& s)` 里，参数 `s` 的**类型**是右值引用，但 `s` 这个**表达式**有名字，所以是**左值**。把它再传给别的函数，调用的仍是拷贝版本，要再写一次 `std::move(s)` 才行。原因：具名对象在函数体内可能被多次使用，编译器不能假设“用一次就没了”。

**要记住的一点**：类型是 `T&&` 与表达式是右值，是两回事。值类别看的是表达式的形式，不看变量声明的类型。
