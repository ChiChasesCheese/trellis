## Q
「一等函数」（first-class function）指什么？为什么它是函数式风格进入主流语言的基础，语言有哪几种表示函数值的方式？

## A
一等函数指函数和整数、字符串一样是**值**：可以存进变量、放进数据结构、作为参数传给别的函数、作为返回值产出。接受或返回函数的函数叫高阶函数（higher-order function）。

价值：把**行为**作为参数，就能把「遍历 / 重试 / 排序的骨架」和「具体做什么」分开。`sort(xs, compareBy)`、`retry(3, call)`、`map(f, xs)` 的骨架只写一次。没有一等函数的语言（早期 Java）要用匿名内部类或单方法接口来模拟，每个行为都是一整个类的样板。

语言表示函数值有四种方式：

1. **函数指针**（C）：只是代码的地址，不携带外部变量。
2. **闭包**（closure）：代码加上它引用的外部变量（环境），见下一节。
3. **对象 + 单方法接口**（Java 8 之前，Java 现在的底层语义）：函数就是实现了某个接口的对象。
4. **语言内置的函数类型**（Go `func(int) int`、Rust `Fn(i32) -> i32`、Python 的可调用对象）。

沿着的轴是**函数的类型怎样出现在类型系统里**。Go 的函数类型是结构化的（参数和返回值一样就是同一类型）；Java 的 lambda 必须落到一个具名的函数式接口上；Rust 的每个闭包都有自己独特的类型；Python 的函数是动态对象，不关心类型。这个轴决定了性能、写法与能否内联。
