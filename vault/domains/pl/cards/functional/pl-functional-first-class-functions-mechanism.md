## Q
各语言的函数值在内存和调用上是怎样表示的？一次通过函数值的调用有多大代价？

## A
- **Go**：函数值是一个指向「闭包对象」的指针（8 字节），闭包对象的头部是代码地址，后面是捕获的变量。调用就是读代码地址、间接跳转，与接口方法调用同类。被捕获并逃出函数的变量会被分配到堆上。
- **Java**：lambda 在运行期由 `invokedynamic` 链接，生成一个实现函数式接口的隐藏类。调用是普通的接口方法调用（`invokeinterface`），JIT 若发现调用点只有一种 lambda，就内联。捕获的变量被复制进该对象的字段。
- **Rust**：闭包是编译器生成的结构体，字段是捕获的变量。通过泛型调用时是直接调用，可内联；通过 `&dyn Fn` / `Box<dyn Fn>` 调用时是虚表调用，与 trait 对象一致。
- **Python**：函数对象的调用要经过解释器的调用协议；3.11 起对 Python 函数之间的调用做了专用快路径，但仍比被内联的调用慢得多。

对比的核心：**能不能被内联**。函数值一旦只是一个运行期指针（Go 的函数值、Rust 的 `dyn Fn`、Java 的 megamorphic 接口调用），编译器就不知道会调用什么，无法内联，也就失去后续优化；Rust 的泛型版本则把函数体看得一清二楚。

捕获的代价：每个捕获的变量要么被复制进闭包对象（值捕获），要么只存一个指针指向原变量（引用捕获）。后者要保证被指的变量活得足够久，这在不同语言里由不同机制保证（GC 保活、借用检查），见闭包与捕获语义一节。
