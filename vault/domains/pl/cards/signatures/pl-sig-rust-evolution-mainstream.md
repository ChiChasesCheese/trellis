## Q
Rust 从 2015 年 1.0 到今天是怎样走进主流的？它的发布方式、edition 机制和在大型项目中的采用说明什么？

## A
**关键节点**：
- **2015**：Rust 1.0，承诺稳定版不破坏。
- **2018、2021、2024**：edition 发布，用 crate 级选择引入语法层变化，同时保持互操作。
- **async/await 稳定（2019）**：补上异步 I/O 的关键拼图，产生以 tokio 为主的异步生态。
- **Rust 基金会（2021）**：语言脱离 Mozilla，成为多公司共同治理。
- **进入 Linux 内核（6.1，2022 年合并基础设施）与 Android**：安全相关的新代码可以用 Rust 写，标志着它被接受为系统语言。
- **广泛的工业采用**：Cloudflare、AWS（Firecracker）、Microsoft、Google 在基础设施里使用；Python 生态里 Polars、Pydantic、ruff、uv 都是 Rust 写成。

**发布方式**：每六周一个稳定版，新特性经过 RFC（公开征求意见）、nightly 试验、稳定化三个阶段。节奏快而不破坏，是它信任的来源。

**演进方向**：
1. **降低学习曲线**：更好的错误信息，更宽松的借用检查（NLL，下一代 Polonius），更好的 IDE 支持。
2. **异步易用性**：`async fn` in traits、异步闭包，缓解“染色”和生态分裂。
3. **编译时间**：增量编译、并行前端、更快的链接器。
4. **与其他语言互操作**：与 C++ 的安全互操作、WebAssembly、Python 扩展。
5. **形式化验证**：Kani、Verus 等工具对关键代码做证明。

**说明什么**：Rust 的路径是“**一个难的想法加一个极好的工具链加一个稳定的承诺**”，用十年让一个高门槛的语言进入主流。它的采用模式也很典型：不是整体重写，而是**在新模块和关键组件里渐进采用**，与现有 C/C++/Go/Python 共存。

**对学习者**：Rust 的学习投资回报来自两处：直接写 Rust，以及它让你更清楚地理解其他语言里的所有权、生命周期和并发规则，即使不写 Rust，这些概念也会改善你的设计。
