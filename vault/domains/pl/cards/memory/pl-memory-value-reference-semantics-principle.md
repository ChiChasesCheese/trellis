## Q
`b = a` 或把 `a` 传给函数时，到底复制了什么？值语义（value semantics）和引用语义（reference semantics）有什么区别，语言有哪几种选法？

## A
赋值和传参都要把一个变量的内容交给另一个变量，问题是交出去的是「整个值」还是「指向值的地址」。

**值语义**：复制整个值，之后两个变量互相独立，改一个不影响另一个。好处是好推理，没有别名（alias，两个名字指向同一块数据）；代价是大对象复制贵。

**引用语义**：只复制一个指针，两个变量指向同一个对象，改一个另一个也变。好处是传递便宜、可以共享状态；代价是别名带来的意外修改，以及对象必须放在堆上、需要有人回收。

设计空间有四种：
1. 全部值语义：C 的结构体、Go 的结构体和数组。想共享就显式取指针。
2. 全部引用语义：Python 一切皆对象，变量只是名字，赋值就是让名字指向对象。
3. 混合：Java 基本类型（`int` 等）是值，类的实例是引用，由类型决定。
4. 值语义加移动（move）：Rust 默认赋值把值「搬走」，原变量作废，因此既没有大对象复制，也没有两个可写别名。

关键认知：这不是语法细节，它决定了你修改一个变量时，程序里还有谁会看到变化。
