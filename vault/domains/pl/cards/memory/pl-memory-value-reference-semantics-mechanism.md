## Q
传参在底层是怎么发生的？为什么说 Java 和 Python 永远是「按值传递」，却能在函数里改掉调用者的对象？

## A
所有主流语言传参时都只做一件事：把实参的内容复制到形参的槽里（栈或寄存器）。区别在于槽里装的是什么。

- 装的是值本身：`int` 占 4 字节，就复制 4 字节；Go 里一个 `struct{X, Y int}` 就复制 16 字节。
- 装的是引用：Java 对象变量、Python 的名字，槽里是一个 8 字节左右的地址（Java 开启压缩指针时是 4 字节）。复制的是地址。

一个小轨迹：
1. 堆上有一个对象 `P{x:1}`，调用者的变量 `p` 保存它的地址 A。
2. 调用 `change(p)`：形参 `p'` 得到同一个地址 A，对象没有复制。
3. 函数内 `p'.x = 100`：顺着地址改了堆上的对象，调用者看得到。
4. 函数内 `p' = new P(7)`：只改了形参槽里的地址，调用者的 `p` 仍是 A，看不到。

第 3 步和第 4 步的差别，就是「按值传递引用」的全部含义：共享的是对象，不共享的是变量本身。所以 Java 里写不出能交换两个引用的 `swap(a, b)`，Python 里在函数内 `lst = [0]` 也不会影响调用者。

要真正让被调函数改调用者的变量，需要传「变量的地址」：Go 的 `*T`、Rust 的 `&mut T`、C++ 的引用。
