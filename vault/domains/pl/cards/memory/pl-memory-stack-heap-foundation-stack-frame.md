## Q
调用栈（call stack）和栈帧（stack frame）是什么？一次函数调用在内存里留下了什么？

## A
程序每调用一个函数，就在一块专用内存（调用栈）的末端划出一小块，叫栈帧，用来放：这次调用的参数、局部变量、返回地址（函数结束后回到哪一行继续）。函数返回，这一块就被整体丢弃。因为调用是嵌套的（`main` 调 `f`，`f` 调 `g`），最后进入的最先退出，所以这块内存像一摞盘子：只在顶端放、只在顶端取，称为栈（stack）。

一个小场景：

```text
main() { int a = 1;  f(a); }
f(x)   { int b = x+1; g(b); }
g(y)   { int c = y*2; }
```

1. 进入 `main`：栈上有 `main` 的帧（含 `a`）。
2. 调用 `f`：压入 `f` 的帧（含 `x`、`b`）；栈上共两帧。
3. 调用 `g`：压入第三帧（含 `y`、`c`）。
4. `g` 返回：第三帧消失，`c` 随之不存在。`f` 返回后同理。

要记住的一个事实：**局部变量的生命周期就是它所在栈帧的生命周期**。函数一返回，这些变量占的内存立刻可被下一次调用覆盖，所以不能把指向局部变量的地址交给函数之外的代码长期使用。这条限制正是“堆”存在的理由。
