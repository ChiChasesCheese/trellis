## Q
一条卡授权请求从商户出发要经过哪些环节？请求里带了什么，发卡行在那一两秒里做什么判断？

## A
**路径**：商户系统 → 支付网关或 PSP → 处理器 → 收单行 → 卡组织网络 → 发卡行；响应按原路返回。整个往返通常在一到两秒内。

**请求里的主要内容**
- 卡信息：卡号（PAN）或令牌、有效期、安全码（CVV）。
- 交易信息：金额、币种、商户号、商户类别码（MCC，标识行业）、交易时间。
- 环境与验证信息：是线上还是线下、AVS 地址核验结果、3DS 认证结果、设备与 IP 的风险信号。

**发卡行的判断**
1. 卡状态：是否有效、过期、挂失、冻结。
2. 资金：信用卡看可用额度，借记卡看账户可用余额。
3. 风控：这笔是否符合持卡人的消费习惯（地点、金额、频率、商户类型），模型打分。
4. 认证：是否需要 3DS 或额外验证。

**结果**：批准（附授权码 authorization code）、拒绝（附响应码）、或要求进一步验证。批准时发卡行同时在持卡人账户上创建一条冻结。

响应里还带回网络交易标识（network transaction ID），后续请款、退款、续费都应保存并引用它。
