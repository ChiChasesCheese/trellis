## Q
为什么订单状态要写成显式的转移表，并且对"重复的回报"和"非法的回报"区别处理？

## A
交易所回报可能**重复**（网络重连后补发、至少一次投递）、乱序，系统本身也可能有 bug。

如果不用状态机，状态散落在一堆 `if` 里：订单已经 FILLED，又收到一条旧的成交回报，代码把成交数量又加了一遍，持仓翻倍。

做法：用一张"(当前状态, 事件) → 新状态"的表，不在表里的格子就是**非法转移**：不改状态，并告警。**重复**则用交易所给的执行编号（`execId`）去重，重复的回报安静忽略，不算错误。

顺序要对：先去重，再检查状态；否则迟到的重复回报会被误当成"终态之后又来成交"的非法转移。
