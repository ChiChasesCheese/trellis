## Q
交易系统里的"单线程忙轮询事件循环（busy-spin event loop）"是怎么工作的？

## A
一个线程被固定在一个**独占的 CPU 核**上，跑一个永不退出的 `while (true)` 循环。每一圈：
1. 看网卡接收队列里有没有新包；
2. 看各条内部队列里有没有新事件；
3. 有就立刻处理完（解码、更新订单簿、策略、风控、发单）；没有就**马上进入下一圈**，不睡眠、不等待通知。

因为这些数据只有这一个线程碰，所以**不需要锁**。

代价是：这个核永远 100% 占用，哪怕市场很安静。这是低延迟的固定成本，要算进机器预算里。
