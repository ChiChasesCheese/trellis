## Q
订单发出去很久都没有收到任何回报（状态未知），或者系统重启了，订单状态该怎么确定？

## A
订单的**真相在交易所**，不在本地。

1. 不能假设"没有回报 = 没成交"。要主动查询，或者在重连时利用会话序号让交易所补发错过的回报。
2. 查清之前按保守假设处理：**可能已经成交**，计入最坏情况持仓，并暂停对该品种发新单（fail closed，无法判断时就停）。
3. 仍无法确定时，发整体撤单（mass cancel），再与成交记录对账。

另外，客户端订单号（ClOrdID）必须全局唯一，并且重启后继续递增；否则交易所可能把重启后的新单当作重复订单拒绝，甚至把新单和旧单混淆。
