## Q
为什么交易系统在开盘前要"预热（warm-up）"？具体做什么？

## A
刚启动的程序是"冷"的：
- Java 的 JIT 编译器（把热点字节码编译成机器码）还没编译热路径，代码在解释执行，慢得多。
- 代码和数据还不在 CPU 缓存里。
- 内存页第一次被访问时会触发缺页（page fault），要内核介入。

所以第一批真实订单会比稳态慢几倍到几十倍，而开盘往往是一天里最忙、最赚钱的时刻。

做法：开盘前用合成的或回放的历史行情把整条热路径跑几十万遍，包括生成并丢弃的假订单（不发给交易所），让 JIT 编译完成、缓存和页表热起来、预先触碰所有内存，确认预热完成后再开始交易。
