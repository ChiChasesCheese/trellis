## Q
热路径上也要记日志，怎么记才不拖慢交易？

## A
热路径只把**原始数据**写进一块预先分配好的内存环形缓冲区（ring buffer）：事件类型编号、几个整数字段（价格用整数）、硬件时间戳，按固定格式一次写完，约**几十纳秒**。

另一个后台线程把记录取出来，格式化成文本、压缩、写盘。

这样做是因为"把价格变成字符串、分配 String 对象、写文件"每一样都是微秒级起步，而且在 Java 里还可能触发垃圾回收。

原则：**热路径不格式化、不分配内存、不做系统调用**。同步记一行日志大约几微秒，异步写环约几十纳秒，每条行情都会差出两个数量级。
