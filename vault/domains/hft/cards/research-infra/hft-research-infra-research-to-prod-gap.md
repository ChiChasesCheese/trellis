## Q
研究用 Python 写原型、生产用 C++ 或 Java 重写，会带来什么“研究和实盘不一致”的问题？请举一个具体的例子。

## A
研究员用 Python（pandas、numpy）快速验证想法，迭代快、易于画图。但生产系统要求低延迟、确定性和不分配内存，必须用 C++ 或 Java 重新实现。重写会引入**细微差异**：策略在回测里赚钱，实盘却表现不同。

常见的差异有这几类：
- **边界处理**：窗口计算的起始阶段；
- **数值**：浮点求和顺序不同导致末位差异；
- **缺失数据**：缺一条行情时，Python 版填充前值，生产版直接跳过；
- **时间对齐**：时间戳取整方式、时区、交易所时间与本机时间。

例：pandas 的 `rolling(20).mean()` 在前 19 个点返回 NaN（不产生信号），C++ 版本从第 1 个点就用已有的数据算均值。开盘第一分钟里，两个版本的信号不一样，实盘交易了研究里没有交易的东西。

每一个差异单独看都很小，叠加起来就让“回测中的策略”和“实盘中的策略”变成了两个不同的策略。
