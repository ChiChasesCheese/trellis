## Q
交易系统里最快的那段代码叫热路径（hot path，从收到行情到发出订单的主链路）。为什么很多高频交易公司在这段代码上选 C++，而不是 Java 或 Python？

## A
关键不是“C++ 是编译型语言”（Go、Java 也编译），而是 C++ 在运行时**留给你的不确定性最少**：
- **没有垃圾回收**（GC）：不分配内存就不会有回收，也就没有 GC 线程抢核或让程序暂停。
- **没有虚拟机和预热**：编译一次，进程启动就是满速；Java 要先解释执行，再经 C1、C2 逐步优化，还可能因假设失效而退回。
- **值类型、连续布局**：`vector<Order>` 里每个订单就紧挨着存放，缓存（cache）友好；你还能控制字段顺序、对齐和内存来源。
- **零成本抽象**：模板、迭代器、`unique_ptr` 优化后与手写代码生成相同的机器码；虚函数只有声明了 `virtual` 才付费。

结果：热路径的**最坏情况**更可控，这正是交易最看重的。
