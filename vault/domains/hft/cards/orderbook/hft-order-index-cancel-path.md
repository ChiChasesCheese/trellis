## Q
订单簿怎么做到收到"撤销订单 #7"这样只有订单编号的消息时，也能在 O(1) 时间内把那笔订单删掉？

## A
需要两个结构配合：

1. **订单索引：** 一个哈希表，键是订单编号，值是那笔订单对象。订单对象里记着它的价格、方向、数量，以及它在所在价位队列里的前后指针。
2. **价位里的订单队列：** 同一价位的订单按时间顺序串成一条**双向链表**，价位对象保存链表的头、尾和总量。

**撤单步骤：**
1. 用订单编号在哈希表里找到订单对象，O(1)。
2. 通过订单对象里的前后指针，把它从链表里摘下来，O(1)，不需要遍历。
3. 从所在价位的总量里减去它的数量。
4. 如果这个价位空了，就把价位删除，必要时更新最优价。
5. 在哈希表中删除这条记录。

没有扫描、没有比较，只有几次内存读写，几十纳秒。

关键点：单向链表摘除中间元素要先找到前驱，所以用**双向**链表，才能 O(1) 摘除任意位置的元素。
