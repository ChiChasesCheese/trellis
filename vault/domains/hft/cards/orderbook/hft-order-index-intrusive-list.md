## Q
订单簿里的"侵入式链表"（intrusive list）和 Java 标准库的 `LinkedList` 有什么区别？为什么订单簿要选前者？

## A
**`LinkedList`（非侵入式）：** 链表自己有一个节点对象 `Node`，里面装着前后指针和一个指向你的订单对象的引用。你的订单对象和链表节点是两个分开的对象。

**侵入式链表：** 前后指针（`prev`、`next`）直接作为订单对象自己的字段。订单对象本身就是链表节点。

**区别带来的影响：**
- **内存：** 每个订单少一个节点对象。Java 里一个 `Node` 约 24 字节，每次进出还要分配和回收，垃圾回收（GC）压力更大。
- **缓存：** 订单数据和指针在同一个对象里，访问一次就都读到，少一次指针追逐。
- **O(1) 摘除：** `LinkedList.remove(Object)` 要先线性查找，O(n)。侵入式链表已经持有订单对象，直接改前后指针即可。

例子：撤单时哈希表返回订单对象 `o`，执行 `o.prev.next = o.next; o.next.prev = o.prev;` 两行就完成了。

**代价：** 一个订单对象同一时间只能放在一条链表里，数据结构和订单类耦合更紧。
