## Q
同一家高频交易公司里，写 C++ 的工程师和写 Java 的工程师通常分别做什么？

## A
区别在于**是否在交易热路径**（hot path）上。热路径指从收到行情到发出订单的那一段代码，每多一微秒都可能亏钱。
- **C++（以及 FPGA）工程师**：写热路径：行情解析、订单簿、策略、下单网关。要精确控制内存和 CPU，避免任何不可预测的停顿（比如垃圾回收，GC）。
- **Java 工程师**：多数在热路径之外：研究平台（回测和数据工具）、分布式存储（存海量历史行情）、计算集群（并行跑成千上万个回测）、监控和内部网络。这些系统要的是吞吐量和可靠性，不要求微秒级延迟。

例子：Headlands Technologies 的 Java 岗位描述围绕研究平台、分布式存储、计算集群和监控。

也有公司把 Java 用在低延迟系统上（例如 LMAX 的交易所撮合引擎），但要付出"稳态不分配对象"的纪律。
