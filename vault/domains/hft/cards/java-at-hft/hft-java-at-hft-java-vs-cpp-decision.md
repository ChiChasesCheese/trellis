## Q
给一个新的交易系统模块，用什么准则决定用 Java 还是 C++？

## A
用三个问题判断：
1. 这条路径需要在大约 10 微秒以内完成，并且尾部要非常稳吗？是，选 **C++**；
2. 逻辑复杂、变化快、要和很多别的系统打交道吗？是，选 **Java**；
3. 严重依赖内核旁路或 FPGA 厂商的 C 接口吗？是，选 **C++**。

例：“解析交易所的 ITCH 行情”选 C++；“把当天所有成交和交易所回传的成交副本对账”选 Java；“汇总全公司持仓和盈亏”选 Java。

中间地带（约 10 到 100 微秒）两种语言都可以，看团队熟悉什么、代码要不要和别的模块共享。核心原则：把最贵的资源，也就是极致优化的人力，只花在真正需要的地方。
