## Q
让 Java 系统做到微秒级，需要满足哪四个前提？每个前提消除的是哪种延迟来源？

## A
四个前提，缺一都会出现尖刺：
- **零垃圾**：消除 GC 停顿；缺它的症状是每隔几秒一次毫秒级的年轻代回收；
- **预热**：消除 JIT 冷启动和首次去优化；缺它的症状是开盘后第一批请求慢数倍；
- **线程绑核与核隔离**：消除操作系统调度和中断的抖动；缺它的症状是随机出现几十微秒到毫秒的卡顿；
- **堆外内存与紧凑布局**：减少缓存未命中，并让 GC 不必扫描大块数据。

四项是串在一起的：前三项都做了，只要有一次预热没覆盖到的路径，就会在最关键的时刻慢一下。所以要有端到端的延迟监测，用 p99.9 去验证，而不是只看平均值。
