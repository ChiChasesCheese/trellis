## Q
Aeron、Chronicle Queue 这类 Java 工具大约能把延迟做到什么量级？靠的是什么？

## A
量级（取决于机器和配置，以实测为准）：Aeron 在同一台机器内（IPC）的一次传递可以做到个位数微秒以内，在同一局域网内的 UDP 往返约几十微秒；Chronicle Queue 的一次写入通常在微秒量级。

靠的是同一组手段：
- **无 GC**：稳态不分配；
- **共享内存或内存映射文件**：数据不经过内核协议栈；
- **批处理**：多条消息一次处理，摊薄同步成本；
- **忙等待加专用核**：线程不睡眠，一有数据立即处理；
- 可选的内核旁路。

注意：这只是传输和持久化的延迟，不包含你自己的业务逻辑。你的业务代码本身也必须同样零垃圾，否则整体延迟还是由业务代码的 GC 和缓存未命中决定。
