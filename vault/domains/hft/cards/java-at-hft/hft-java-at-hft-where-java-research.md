## Q
为什么交易公司的研究平台和回测系统适合用 Java 这类托管语言，而不是全部用 C++？

## A
研究平台的特点是：需求变化快（每增加一个交易所或品种，数据格式和规则都不同）、代码量大、多人协作；回测是批处理，关心总吞吐而不是单次几微秒；一个静默的内存错误会让回测结果悄悄出错，托管语言在越界时直接抛异常，更安全。

吞吐靠并行取得：试 1000 组参数，每组回测 1 小时，串行要 1000 小时（约 42 天）；100 台机器并行约 10 小时。瓶颈在并行度和数据读取，而不是单核的指令级优化。

当然也有公司让回测直接复用 C++ 的实盘代码，以保证回测和实盘用同一套行情解析与订单模拟逻辑；用哪种语言要看这个目标（回测与实盘一致）怎么达成，而不是只看速度。
