## Q
选择 Java 的主要代价和风险有哪些？面试时怎样坦诚地说？

## A
主要代价有四项：
- **尾延迟多了几层来源**：GC、JIT 预热与去优化、safepoint，要靠工程手段压住；
- **内存占用与布局控制弱**：对象头、指针间接访问，数据布局不如 C++ 紧凑；
- **热路径写法被迫变成“像 C 一样”**：零垃圾、原始类型数组、手工布局，失去了 Java 的部分生产力优势；
- **工具链不在一边**：内核旁路、FPGA 厂商的库以 C/C++ 为中心，Java 要靠 JNI 或 FFM API 桥接。

坦诚的说法是：Java 的价值在“整个系统的开发速度乘以可靠性”，而不是每一纳秒；最极限的热路径应该交给 C++ 或硬件。能说出边界在哪里，比说“Java 什么都行”更可信。
