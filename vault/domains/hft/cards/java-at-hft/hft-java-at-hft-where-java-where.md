## Q
在高频交易（HFT）公司里，Java 一般用在哪些系统上？

## A
常见位置是**不在最极端热路径上**的系统：
- **研究平台**：研究员提假设、取数据、回测、看结果的内部软件；
- **分布式存储**：存放每天数百 GB 到 TB 级的逐笔行情（tick）数据；
- **计算集群**：调度回测和参数优化作业；
- **监控与告警**、**内部工具**；
- **风控聚合与订单管理**，以及部分对延迟要求不到个位数微秒的交易路径。

例如 Headlands Technologies（芝加哥的自营量化交易公司）的 Java 岗位描述写的是研究平台、分布式存储、计算集群、监控和系统内部网络延迟；超低延迟的交易引擎在这类公司通常是 C++ 岗位。

这些系统共同的特点：重吞吐、业务复杂、需求变化快，延迟预算以毫秒甚至更宽计，所以适合 Java 的生产力与生态。
