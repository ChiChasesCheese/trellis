## Q
面试快结束时，向交易公司的面试官提哪些问题，能显示你理解 Java 在这里的角色？

## A
好问题的特点：具体、说明你理解约束、让对方讲自己的经验。
1. “Java 系统和 C++ 热路径的边界在哪，数据是怎样跨过边界的？”
2. “你们怎样度量延迟，主要看哪个分位数？上次排查一个尾延迟问题是怎么回事？”
3. “研究员的迭代循环里，回测一次要多久，最大的瓶颈在哪？”
4. “怎样保证回测和实盘的行为一致？”
5. “新人头一年会做什么，怎样上手？”

不要这样问：一上来就问薪资和期权；不要假装知道公司内部的技术栈，只说“我推测大概是这样，请你纠正”。
