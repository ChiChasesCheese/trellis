## Q
交易公司里 C++ 和 Java 通常怎样分工？决定分工的是什么？

## A
常见的分法：
- **C++**：纳秒到个位数微秒的热路径：行情解析、策略核心、下单网关，以及 FPGA 周边的软件；
- **Java**：吞吐型、业务复杂、迭代快的系统：研究平台、存储、调度、监控、风控聚合、内部工具。

决定分工的是三件事：
1. **延迟预算**：尾部稳定性和绝对时间要求有多严；
2. **开发速度与正确性成本**：逻辑变化快、规则复杂的部分，托管语言写、测、改更快；
3. **团队和招聘**：现有人员的技能和招人的难易。

另外要看是否依赖内核旁路库或 FPGA 厂商的 C 接口，依赖越深越偏 C++。分工是一个综合判断，不是语言之争。
