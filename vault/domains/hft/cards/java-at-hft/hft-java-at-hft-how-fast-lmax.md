## Q
LMAX 交易所用 Java 做到了什么？它的架构要点是什么？

## A
LMAX 是伦敦的一家金融交易所，核心系统用 Java 编写。架构要点：
- 全部**业务逻辑（撮合、风控等）跑在一个线程上**，按顺序处理每个事件，不加锁、不做 I/O，所有数据都在内存里；
- 输入先写入日志（journal）并复制到备机，保证崩溃后可以重放恢复；
- 输入输出通过 Disruptor 环形缓冲区与业务线程相连。

公开的数据是：这个单线程每秒可以处理约数百万个订单（约 600 万量级），延迟在微秒级。

快的原因：数据小而热，留在 CPU 缓存里；没有锁和线程间争用；零垃圾，没有 GC 打扰；批处理摊薄了同步成本。这个案例说明：Java 并不天生慢，慢的是用普通方式写出来的 Java。
