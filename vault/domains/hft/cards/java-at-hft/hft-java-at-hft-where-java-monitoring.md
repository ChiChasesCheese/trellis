## Q
监控、告警和内部工具在交易公司里为什么算“关键系统”，而不是辅助工具？

## A
交易系统从周日下午到周五持续自动运行，没有人盯着每一笔。策略出了问题（长时间无成交、持仓异常、延迟变大、行情断流），如果没人发现，损失每分钟都在累积。假设某策略每分钟的期望收益是 500 美元，一次静默故障拖 30 分钟，就是 1.5 万美元的机会损失；更糟的是方向错了亏钱。

所以监控要**先于人发现问题**：采集指标、阈值和异常检测、对账（实盘记录与交易所回传的成交副本 drop copy 是否一致）、数据质量检查（昨天的行情有没有缺口）。Java 常用来写服务端的聚合、Web 界面后端和调度，这些系统必须长期稳定、能排查，对延迟并不苛刻。
