## Q
怎样判断一个系统“Java 够不够快”？

## A
先问**延迟预算**：这条路径需要在多少时间内完成，尾部要多稳。大致的量级：
- **毫秒级**（研究、风控聚合、监控）：普通 Java 加 G1 就够；
- **几十到几百微秒**：调优过的 Java（ZGC、零垃圾、绑核）可行；
- **个位数微秒**：很难，要极致的零垃圾、堆外内存、绑核和隔离，偶发尾部抖动仍是风险；
- **纳秒到亚微秒**（贴近交易所的最快套利，或 FPGA 周边）：用 C++ 或 FPGA。

判断依据是 p99、p99.9 这样的尾部分位数，而不是平均值，并且要在自己的负载上测，不要只看别人公布的数字。这些分界只是量级，具体看业务。
