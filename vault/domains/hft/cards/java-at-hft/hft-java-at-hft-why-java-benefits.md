## Q
为什么交易公司愿意在很多系统里选 Java，而不是全用 C++？

## A
主要有四点：
- **内存安全**：没有悬空指针；数组越界会抛异常、带调用栈，而不是悄悄改坏内存。对管理资金的系统，这很重要；
- **开发速度**：垃圾回收、丰富的标准库、成熟的 IDE 和重构工具，新交易所、新品种的需求能更快落地；
- **并发与可观测工具成熟**：`java.util.concurrent`、JFR、线程转储、调试器；
- **生态与招聘池大**：Java 工程师多，也容易找。

对比：C++ 的一个野指针可以悄悄改坏持仓数据，几天后才表现为对不上账；Java 在出错的当场抛异常。

代价是 GC、JIT 带来的抖动和较高的内存占用，这就是它不适合所有路径的原因。
