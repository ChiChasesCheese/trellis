## Q
被问“你怎么提升系统性能”时，怎样讲“测量驱动优化”？

## A
可以按六步讲，每一步都说出理由：
1. **定义指标**：看 p50、p99、p99.9 和最大值，而不是平均值；
2. **建基线并测量噪声**：测量工具自己也有误差；
3. **分环节打点**：把整条路径拆成几段，先找最大的一段；
4. **用剖析器找热点**：采样剖析和火焰图，Java 里用 JFR、async-profiler，隔离的微基准用 JMH；
5. **一次只改一处**，对比改前改后的分布；
6. **警惕协同遗漏**，否则测出来的尾部偏乐观。

例子：平均延迟 50 µs，每一万个请求里有一个 100 ms，只看平均值完全看不出来。“先测量，再优化”体现的是纪律，比报几个调优参数更有说服力。
