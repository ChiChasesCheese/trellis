## Q
交易公司的分布式存储和计算集群，各自在解决什么问题？Java 在其中的优势是什么？

## A
**分布式存储**：逐笔行情每天数百 GB，设每天 200 GB、250 个交易日，一年约 50 TB。一块盘装不下，也读不快：单盘顺序读约 500 MB/s，读 50 TB 要约 10 万秒（近 28 小时）。所以数据要切开放在很多台机器上并行读。关心的指标是吞吐、读的尾延迟和可靠性（副本、校验）。

**计算集群**：研究员提交作业，调度器把它们分给空闲机器。关心调度开销、资源利用率、故障重试和排队时间，研究员的迭代速度直接取决于它。

Java 的优势：成熟的并发和网络库、长期运行的服务稳定、JFR 等可观测工具齐全，适合写这类需要稳定运行几个月的基础设施。
