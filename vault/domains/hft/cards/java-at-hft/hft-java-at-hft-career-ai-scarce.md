## Q
AI 写代码越来越强的时候，低延迟交易系统里哪些工程能力仍然稀缺？

## A
AI 擅长样板代码、常见 API 用法和标准算法。仍然稀缺的是：
- **理解机器**：缓存、内存序、GC、JIT、内核的行为，决定“为什么慢”“为什么偶尔卡一下”；
- **测量与调试**：在没有现成答案的尾延迟尖刺里，用 JFR、`perf`、抓包把问题定位出来；
- **正确性与风险意识**：判断一段生成的代码在并发、边界、故障下是否安全；
- **对业务的判断**：知道该优化哪里、值不值得，以及什么时候不该动。

原因是：AI 生成的代码常常“看起来对”，但它不知道你的机器和负载，错误往往只在 p99.9 才显现。能把“看起来对”变成“经过测量证明对”的人，价值就在这里。
