## Q
与 C++ 和 FPGA 相比，调优后的 Java 通常处在哪个延迟档位？什么时候还是该换？

## A
大致的梯度（量级，不是保证）：
- **FPGA** 方案：从收到行情到发出订单可到亚微秒甚至百纳秒量级；
- **优化后的 C++ 软件**：个位数微秒；
- **调优过的 Java**：十几到几十微秒（一套较慢的软件系统，从行情到下单约 30 µs）；
- **普通 Java**：毫秒级。

什么时候该换：当竞争对手在你前面几十纳秒就能抢到同一个机会时，你的收益取决于最快的那几家，这时 Java 再怎么调优也追不上，应该用 C++ 或 FPGA；如果策略收益取决于更聪明的判断而不是更快的速度，几十微秒完全可以接受，Java 的开发速度就更有价值。
