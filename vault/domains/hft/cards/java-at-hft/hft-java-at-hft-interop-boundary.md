## Q
一个 Java 服务要用 C++ 写的行情解码库，应该每条消息调用一次，还是整批调用一次？边界应该放在哪里？

## A
每次跨语言调用有固定成本。设每次约 50 ns（假设）：每秒 100 万条消息逐条调用，是 50 ms/秒，约占一个核的 5%，看似可接受；但更大的成本是参数转换和数据拷贝，如果每次还要把 C++ 的结果创建成 Java 对象，就又制造垃圾。

更好的做法：把一批消息放在同一块堆外内存里，传地址和长度，让 C++ 一次处理 1000 条，固定成本摊薄到 1/1000；或者干脆不跨函数调用，让数据通过共享内存或消息队列流动，两边各自处理。

原则：**边界要粗**（以消息或批为单位，而不是以字段为单位），**边界上只传扁平字节**，不传对象。
