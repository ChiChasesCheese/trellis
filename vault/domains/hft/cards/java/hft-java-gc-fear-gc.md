## Q
为什么低延迟交易系统最怕 GC 停顿，而不是平均吞吐稍微下降一点？

## A
因为交易关心的是**尾部延迟**（p99、p99.9、最大值），而不是平均值。假设平均处理一单只要 50 µs，但每一万单里有一单被 GC 卡住 100 ms，平均值几乎不变，那一单却足以出大问题。

两个放大效应：一是行情包之间的间隔约 10～1000 µs，100 ms 的停顿期间可能漏掉上千个行情包，停顿结束时手里的报价已经过期，对手可以专挑这些旧报价成交（逆向选择，adverse selection）；二是行情最忙的时候分配也最快，GC 恰恰最频繁，也就是最赚钱、最不能停的时刻最容易停。
