## Q
HotSpot JVM 为什么要同时配备 C1 和 C2 两个 JIT 编译器（分层编译），而不是只用一个最强的编译器？

## A
JIT（即时编译，Just-In-Time）在程序运行时把“热”方法的字节码翻译成机器码。HotSpot 的做法叫**分层编译**（tiered compilation）：
- 方法先由**解释器**（interpreter）逐条执行，同时收集运行统计（哪个分支常走、调用点实际是哪个类）；
- 调用约 200 次后交给 **C1**：编译快、代码中等快、继续收集统计；
- 再调用约 5000 次后交给 **C2**：编译慢且占 CPU，但做激进优化，代码最快。

只用 C2，启动阶段每个方法都要等慢编译，程序长时间停在解释器里；只用 C1，稳态代码不够快。一个玩具方法的实测：只解释约 565 ns/次，只 C1 约 140 ns，C1 到 C2 约 123 ns。
