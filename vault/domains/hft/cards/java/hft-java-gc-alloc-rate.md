## Q
为什么降低“分配速率”（allocation rate）是减少 GC 停顿次数最直接的办法？

## A
年轻代的空间是固定的，新对象一直往里放，放满就触发一次年轻代回收。所以**回收频率约等于分配速率除以年轻代大小**。

例：热路径每秒分配 1 GB，年轻代约 1 GB，那么大约每秒一次 GC；每次几毫秒，一小时就是几千次停顿。如果把热路径的分配降到原来的 1/100，大约 100 秒才一次。如果稳态分配为 0，年轻代永远填不满，就没有 GC。

这就是低延迟 Java 的第一原则：与其去调 GC 参数，不如先少 `new`。回收频率直接由你写的代码决定。
