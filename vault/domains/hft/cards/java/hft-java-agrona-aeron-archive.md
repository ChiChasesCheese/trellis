## Q
Aeron Archive 解决什么问题？“录制”与“回放”对交易系统有什么价值？

## A
Aeron 的消息流默认是“流式”的：发出去、被订阅者收到，就没了。**Archive** 是一个独立的服务，订阅某条流并把消息持久录制到磁盘，每个录制都有编号和位置；之后可以从任意位置**回放**（replay）成一条新的流，让迟到的消费者追上进度，也让故障后的进程重建状态。

对交易系统的价值是**事件溯源**（event sourcing）：把进入撮合引擎或策略的全部输入按顺序录下来。只要业务逻辑是确定性的，从头回放就会得到完全相同的状态，可用于：崩溃恢复、事后复现线上 bug、审计留存，以及用真实流量回归测试新版本。
