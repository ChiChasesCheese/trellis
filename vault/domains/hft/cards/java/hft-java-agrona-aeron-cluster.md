## Q
Aeron Cluster 解决什么问题？Raft 在其中起什么作用？

## A
它要解决的是：把一个有状态服务（比如撮合引擎）做成高可用。多个节点（通常 3 个或 5 个）各自运行同一份**确定性状态机**（deterministic state machine，相同输入顺序必得相同状态）。

**Raft**（一种共识算法）保证输入顺序一致：客户端请求先到 leader，复制到多数节点并提交后，才交给每个节点按相同顺序执行。leader 宕机后重新选举，新 leader 已拥有所有已提交的日志，服务不丢已确认的请求。3 个节点可容忍 1 个故障（多数是 2）。

代价：每个请求要多一次到多数派的网络往返（微秒到几十微秒，取决于网络）；业务代码必须确定，不能直接用系统时间、随机数，要用集群提供的时间。
