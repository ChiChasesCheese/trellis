## Q
ZGC 是怎样在应用线程继续运行的同时搬动对象，从而让停顿几乎与堆大小无关的？

## A
ZGC 的标记和搬对象都在**应用线程运行时并发**完成，靠两个机制：
- **着色指针**（colored pointers）：在引用里拿出几位当状态位，记录“这个引用检查过吗”“对象已被搬走吗”；
- **加载屏障**（load barrier）：应用线程每从堆里读一个引用，JIT 都在后面插一小段检查，发现对象已搬家，就帮忙找到新地址并修好这个引用，然后继续往下走。

于是真正需要 STW 的只剩极短的同步点，目标是不超过 1 ms，而且与堆大小、存活对象数无关。一个实验里，分代 ZGC 最长暂停约 0.011 ms（11 µs），同样负载下 G1 的 p99 约 75 ms。
