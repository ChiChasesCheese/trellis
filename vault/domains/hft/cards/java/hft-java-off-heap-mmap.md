## Q
内存映射文件（mmap）为什么能让堆外数据“写入即持久化、可跨进程共享”？它有什么抖动风险？

## A
mmap 把文件的页映射进进程的虚拟地址空间，读写就是普通内存读写，数据实际存放在操作系统的**页缓存**（page cache）里，脏页由内核异步写回磁盘，不需要 `write` 系统调用和用户态拷贝。两个进程映射同一个文件，看到的就是同一份页缓存，相当于共享内存。进程崩溃后，已写入页缓存的数据仍由内核保留；但机器断电时尚未写盘的部分会丢，需要刷盘才能保证。

抖动风险是**缺页**（page fault）：第一次访问某页时，内核要分配页，如果数据不在页缓存还要读磁盘，耗时从微秒到毫秒不等。常见对策是预先分配文件并提前触碰各页。
