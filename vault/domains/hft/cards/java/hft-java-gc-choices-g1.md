## Q
G1 收集器的暂停目标 `-XX:MaxGCPauseMillis` 是什么？它是对延迟的保证吗？

## A
G1（Garbage-First）把堆切成许多等大的**区域**（region，1～32 MB），每次优先回收“垃圾最多、收益最大”的那些区域。你给它一个**暂停目标**，默认 200 ms，G1 据此调整每次回收多少个区域，尽量不超过目标。

但这只是**软目标**，不是保证。年轻代回收是停止世界（STW）的，暂停随存活对象量增长；老年代虽有后台并发标记，一旦分配得比回收快，G1 就退化成 Full GC，整堆暂停，可达数百毫秒到秒级。所以 G1 适合平均表现好、能容忍偶发长停顿的服务，不能保证交易热路径的尾延迟。
