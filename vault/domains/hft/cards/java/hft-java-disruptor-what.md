## Q
LMAX Disruptor 是什么？它为什么能让一个线程每秒处理数百万个事件？

## A
Disruptor 是伦敦的 LMAX 交易所开源的线程间消息传递结构，核心是一个**预分配的环形缓冲区**（ring buffer）：槽位里的事件对象在启动时一次性建好，之后只覆盖字段，所以不产生垃圾。生产者和消费者靠一个递增的**序列号**（sequence）协调：槽位下标 = 序列号 & (大小 - 1)，缓冲区大小取 2 的幂，用位运算代替取模；生产者写完槽后发布序列号，消费者按序列号读取，不用锁。

LMAX 把所有业务逻辑放在**一个线程**上顺序执行，不加锁、不做 I/O，数据又小又热、留在 CPU 缓存里，公开的数字是单线程约每秒数百万（约 600 万量级）个订单。快的原因是：无锁、无垃圾、少缓存未命中、批处理。
