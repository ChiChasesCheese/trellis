## Q
每秒处理 100 万条消息时，flyweight 解码和解析成普通 Java 对象（POJO）的差别有多大？

## A
假设每条消息 64 字节，解析成 POJO：对象头约 12 字节加字段，再加上可能的 `String` 和数组，每条约产生 50～100 字节垃圾。每秒 100 万条就是约 50～100 MB/s 的垃圾，1 GB 的年轻代每 10～20 秒要回收一次，每次几毫秒的停顿落在行情最忙的时候。

flyweight 解码：每条 0 字节垃圾，GC 不会因为消息而触发。

还有两项隐性收益：POJO 通常把所有字段都读出来，哪怕只用价格和数量，flyweight 只读用到的字段；数据留在原缓冲区里，少一次拷贝，缓存里也少一份副本。代价是视图不能保存、不能跨线程共享，字节序和越界也要自己小心。
