## Q
为什么一个 Java 交易程序刚启动时，前几千次请求会比稳态慢好几倍？交易系统上线前通常怎么处理？

## A
刚启动时代码在解释器和 C1 里运行，解释执行比机器码慢约 5～10 倍；JIT 编译线程本身还要占用 CPU。一个玩具方法的第 1 轮比稳态慢约 6.5 倍。如果开盘第一笔订单恰好撞上冷代码，延迟可能是稳态的几倍甚至几十倍，而这正是行情最密的时刻。

做法是**预热**（warm-up）：上线前用回放的行情或合成流量把关键路径跑上足够多次，让它们完成 C2 编译，再接真实订单。注意预热流量要覆盖真实会走到的分支：如果只预热了“新单”，开盘后第一次走“撤单”路径时，那段代码仍是冷的。
