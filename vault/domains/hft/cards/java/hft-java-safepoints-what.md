## Q
JVM 的安全点（safepoint）是什么？为什么有些操作必须等所有线程到达安全点才能做？

## A
**安全点**是线程执行中的特定位置（如方法返回处、循环回边），在这些位置 JVM 能准确知道线程栈上哪些是对象引用，堆和栈处于一致状态。

JVM 有些全局操作，必须保证没有线程正在改堆或栈：GC 的停止世界阶段、去优化、类的重定义与卸载、线程栈转储、（历史上的）偏向锁撤销等。于是 JVM 先发出请求，每个 Java 线程在下一个安全点检查处停下；全部停好以后，JVM 才开始做操作，做完再放行。

所以一次 safepoint 停顿的总时长 = **到达安全点的时间**（time to safepoint，TTSP）+ 操作本身的时间。后者你能在 GC 日志里看到，前者往往是隐藏的。
