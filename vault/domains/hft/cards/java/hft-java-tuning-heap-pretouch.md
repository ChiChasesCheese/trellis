## Q
低延迟 JVM 为什么要把 `-Xms` 和 `-Xmx` 设成一样的值，还要加 `-XX:+AlwaysPreTouch`？

## A
`-Xms` 是初始堆，`-Xmx` 是最大堆。两者不同时，堆会在运行中扩缩，要向操作系统申请或归还内存，还可能引发额外的 GC。设成一样，堆大小从头到尾固定。

`-XX:+AlwaysPreTouch` 让 JVM 在启动时把整个堆逐页写一遍，让操作系统提前把物理页分配好。否则第一次用到某页时才触发**缺页**（page fault）：内核当场分配并清零一页，每次约微秒量级，在运行期间零星散布成延迟抖动。

代价是启动变慢：堆越大，预触碰越久，几十 GB 的堆可能要数秒到数十秒。但交易进程在开盘前启动并预热，把这个成本付在开盘前，换取盘中的平稳，是划算的。
