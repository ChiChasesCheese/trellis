## Q
把数据放到堆外内存（off-heap memory）有什么好处和代价？

## A
堆外内存是 JVM 堆之外、由操作系统直接分配的内存，GC 完全看不见它。

好处：
- **不增加 GC 工作量**：GC 的扫描和整理量与堆内存活对象有关，堆外放 100 GB 对 GC 来说也是 0；
- **布局自己定**：可以连续存放、对齐到缓存行，像 C 的 struct 数组；
- **可共享**：能用内存映射文件在进程间共享，也能直接交给本地库。

代价：生命周期要自己管，忘了释放就泄漏；越界或释放后再用，轻则异常重则整个进程崩溃；没有对象和类型的保护，代码更复杂。所以只给大而长寿、布局固定的数据用，例如行情快照表，并且要先用 JFR 确认 GC 确实是瓶颈。
