## Q
垃圾回收器（GC）为什么要把堆分成年轻代和老年代？背后的“分代假设”是什么？

## A
**分代假设**（generational hypothesis）是一个经验观察：绝大多数对象很快就死（临时字符串、迭代器、一次请求的对象），只有少数活得很久（缓存、订单簿）。

据此 GC 把堆分成两块：新对象先放**年轻代**（young generation），频繁回收；活过几轮的对象晋升到**老年代**（old generation），很少回收。好处是：回收的工作量跟“活着的对象有多少”成正比，而不是跟垃圾量或堆总大小成正比。年轻代里往往 99% 都是垃圾，几乎不用搬什么，所以一次年轻代回收很便宜；昂贵的老年代回收则尽量少做。
