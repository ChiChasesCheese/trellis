## Q
交易系统长时间没有行情和订单之后，为什么"第一笔订单"往往比之后的订单慢得多？这跟存储层级有什么关系？

## A
因为缓存是"用过才会有"的：数据和代码只有被访问过，才会被复制进 L1/L2/L3。

- 长时间没走过下单路径，这条路径用到的数据（订单簿、风控参数）和代码，会被别的程序挤出缓存（这叫缓存变冷，cold cache）。
- 第一笔订单要把这些东西全部从主内存重新取回，每次约 100 ns；路径上有几十次这样的未命中，就是几微秒甚至更多的额外延迟。
- 同一路径跑第二次、第三次时，数据已在 L1/L2，每次访问只要 1–5 ns，延迟明显下降。

这正是交易系统要"预热"（warm-up）的原因：开盘前和空闲期间，用假数据让完整的下单路径反复跑，让缓存保持热（hot），真正的行情到来时就不用付"第一次"的代价。
