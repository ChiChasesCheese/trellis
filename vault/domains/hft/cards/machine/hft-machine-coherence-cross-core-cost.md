## Q
在多核服务器上，一个核写入数据后，另一个核读到这份数据要多久？这个数字对线程间通信的设计意味着什么？

## A
这是核间通信的基本成本：数据要从写入方的缓存搬到读取方的缓存，约需**几十纳秒**；同一插槽（socket，一颗 CPU 芯片）内的核之间一般几十 ns，跨插槽更慢，可达一百多 ns。

作为对比，读自己 L1 里的数据只要约 1 ns，所以核间传递一次数据，比本地读贵几十倍。

对设计的含义：
- 把一条消息从线程 A 交给线程 B，下限就是这一次缓存行搬运，约几十 ns。线程间每多一次交接，延迟就加几十 ns。
- 所以 HFT 系统尽量让一条消息在一个线程里走完整条路径，只在必要处交接，并且减少每次交接要搬运的缓存行数（例如消息体一次写入一行或两行）。
- 无锁队列再快，也快不过这个物理下限。
