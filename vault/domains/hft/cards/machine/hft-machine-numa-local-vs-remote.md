## Q
NUMA（非统一内存访问）是什么？为什么同一台服务器里，不同位置的内存访问速度不一样？

## A
很多服务器有两颗（或更多）CPU 芯片，每颗插在一个插槽（socket）上。每颗 CPU 自带内存控制器，直接连着一部分内存条，这一块叫它的**本地内存**，CPU 加上本地内存合称一个 NUMA 节点（NUMA node）。

- 访问本地内存：CPU 直接经自己的内存控制器读，约 80–100 ns。
- 访问另一个插槽的内存（远端内存）：请求要先走两颗 CPU 之间的互连总线（Intel 的叫 UPI），由对方的内存控制器读完再送回来，约 **140–200 ns**，通常是本地的 1.3–2 倍，带宽也更低。

整台机器仍然是一个统一的地址空间，程序看不出区别，所以叫"非统一"（访问时间不均匀）。结论：数据放在哪个节点的内存、线程跑在哪个节点的 CPU 上，会直接影响每一次未命中的代价。
