## Q
CPU 为什么要做分支预测（branch prediction）？猜错了会发生什么，代价有多大？

## A
遇到 `if` 这样的分支时，CPU 要等条件算出来才知道下一步走哪条路。但流水线很深，如果干等，前面已经取指译码的工作都浪费了。所以 CPU 会先**猜**一个方向，沿着猜的方向继续取指、执行（这叫推测执行，speculative execution）。

- **猜对**：几乎不花额外代价，流水线一直是满的。
- **猜错**：之前沿错误方向做的工作全部作废，流水线清空重来，代价约 **15–20 个周期**，在 3 GHz 下约 5 ns。

CPU 猜的依据是这条分支过去的历史：如果它一直走同一个方向，预测准确率可达 99% 以上。

结论：**可预测的分支几乎免费，随机的分支很贵**。判断一个循环里的分支贵不贵，不看它的位置，只看它的结果是不是有规律。
