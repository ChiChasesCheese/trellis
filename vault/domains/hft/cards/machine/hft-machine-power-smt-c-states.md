## Q
CPU 的节能睡眠状态（C-state）是什么？为什么它会让交易系统的"第一个包"特别慢？

## A
C-state 是 CPU 核空闲时进入的不同深度的睡眠状态：C0 表示正常运行，数字越大睡得越深（C1、C3、C6……），省电越多，但醒来越慢。

- 浅睡（C1）：醒来约 1 µs 量级。
- 深睡（C6）：核的时钟被关掉，缓存内容甚至被清空，醒来可能要**几十到上百微秒**。

交易场景的问题：一个核在等行情时空闲，操作系统让它睡了；行情到达（中断）时，核先要花几十微秒甚至更多醒来，而且缓存已变冷，随后还要重新把数据从内存取回。而整条 tick-to-trade 链路的预算只有几微秒到十几微秒，于是"安静了一阵之后的第一个包"特别慢，表现为延迟尖刺。

解决办法：在 BIOS 或内核参数里把最深睡眠状态限制到 C1 或关掉（如内核参数 `intel_idle.max_cstate=0 processor.max_cstate=1`），或者让热线程忙轮询（busy spin），根本不让核空闲。代价是整机耗电和发热上升。
