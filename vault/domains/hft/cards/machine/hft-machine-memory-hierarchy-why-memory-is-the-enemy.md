## Q
一个 CPU 核每个时钟周期只要约 0.3 纳秒，为什么低延迟工程师还说"访问内存"是头号敌人？

## A
因为 CPU 算得极快，而主内存（DRAM，动态随机存取内存）很慢，两者的速度差了两个数量级。

- 一个 3 GHz 的核，一个周期约 **0.3 ns**，每秒能执行几十亿条指令。
- 从主内存取一个数据要约 **80–100 ns**，相当于 **约 300 个周期**。
- 如果每条指令都要等内存，CPU 有 99% 的时间在空等，什么也没算。

所以"算"几乎是免费的，"等数据"才是真正的开销。一次缓存未命中（cache miss，要的数据不在 CPU 内部的小而快的存储里，只能去主内存取）就像让 CPU 白白停工 300 个周期。低延迟代码的核心工作，就是让 CPU 要用的数据尽量已经在身边，而不是去主内存取。
