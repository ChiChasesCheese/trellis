## Q
现代服务器 CPU 的存储层级（寄存器、L1、L2、L3、DRAM）各自的容量和访问延迟大约是多少？

## A
从近到远，越近越快、越小、越贵（下面是典型量级，不同型号会有差异）：

| 层级 | 容量 | 延迟 |
|---|---|---|
| 寄存器（register，CPU 内部直接参与运算的存储） | 几百字节 | 不到 1 个周期 |
| L1 缓存（每核私有） | 约 32–64 KB | 约 1 ns（约 4 周期） |
| L2 缓存（每核私有） | 约 256 KB–2 MB | 约 3–7 ns |
| L3 缓存（同一插槽多核共享） | 几十 MB | 约 10–40 ns |
| 主内存 DRAM | GB 到 TB | 约 80–100 ns |

记住"约 1 / 4 / 10–40 / 80–100 ns"这条阶梯：每往外一层，延迟大约乘 3–10 倍。缓存（cache）就是放在 CPU 里面的小而快的存储，里面存着最近用过的数据的副本。
