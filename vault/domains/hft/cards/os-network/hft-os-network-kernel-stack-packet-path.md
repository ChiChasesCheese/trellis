## Q
一个网络包从到达网卡，到应用程序拿到数据，在 Linux 内核里要经过哪些步骤？

## A
接收一个 UDP 包的主要步骤：
1. **网卡写内存**：网卡通过 DMA（直接内存访问，设备不经 CPU 自己往内存写）把包写入内存里的接收环形缓冲区；
2. **硬中断**：网卡向 CPU 发中断，CPU 暂停当前线程；
3. **软中断**：内核的网络驱动从环里取包，构造内核的包结构（`sk_buff`），交给协议栈做 IP 和 UDP/TCP 处理（校验、查找 socket 等）；
4. **放入 socket 缓冲区**：数据排进目标 socket 的接收队列，并唤醒在等它的线程；
5. **线程被调度运行**，调用 `recv` 系统调用；
6. **拷贝**：内核把数据从内核缓冲区复制到应用提供的缓冲区，返回用户态。

发包是反向的：应用调用 `send` 进内核，复制到内核缓冲区，经协议栈封装，再通知网卡发送。

这条路径上有中断、上下文切换、系统调用、至少一次内存拷贝，所以延迟累积起来达**几微秒到十几微秒**。它是为通用服务器设计的：很多进程共享同一块网卡，内核要做隔离、防火墙、公平调度。
