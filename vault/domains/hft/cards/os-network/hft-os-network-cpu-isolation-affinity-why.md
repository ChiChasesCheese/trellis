## Q
Linux 默认怎么调度线程？为什么要给交易线程设置 CPU 亲和性（affinity）？

## A
默认情况下，操作系统的调度器可以把一个线程放到**任何**核上，而且会为了均衡负载随时把它迁到别的核；每个核上还有很多线程轮流运行，各占一小段时间片。

对延迟敏感的线程，这有两个坏处：
- **被抢占**：交易线程的核上如果还有别的线程，调度器会在中途把它换下去，让别人跑几毫秒。
- **被迁移**：线程换到另一个核后，原来核里 L1/L2 的热数据全留在旧核上，新核的缓存是冷的，要重新从内存取，每次约 100 ns，总共可能几微秒到几十微秒。

亲和性（affinity）就是规定一个线程只能在指定的核上运行。命令行用 `taskset -c 3 ./app`，代码里调用 `pthread_setaffinity_np`。Java 标准库没有直接接口，通常用 JNA 或 OpenHFT 的 Affinity 库。

效果：线程总在同一个核上，缓存一直是热的，不再因迁移出现尖刺。但亲和性只管"你去哪"，管不了"别人来不来"，所以还需要隔离。
