## Q
网卡收到一个包时，为什么会打断正在运行的线程？这个打断大约要花多少时间？

## A
网卡收到包后，把数据放进内存，然后向 CPU 发一个**硬件中断**（interrupt，IRQ，一种让 CPU 暂停当前工作去处理设备事件的信号）。

CPU 收到中断后：
1. 立刻暂停当前正在跑的线程（不管它在做什么）；
2. 保存现场，转去运行内核的中断处理程序；
3. 处理程序再安排后续的网络协议栈处理（软中断，softirq），也在这个核上运行；
4. 做完后恢复现场，原线程继续。

代价：一次中断加软中断处理通常占用**几微秒**，而且处理期间用到的代码和数据把原线程的缓存挤掉了一部分，恢复后还要重新取数据，实际损失更大。

如果这个核恰好在跑交易线程，那么每个网络包到达，交易线程就会被打断一次；行情高峰时每秒几十万个包，就会被打断几十万次。所以要控制中断去哪个核。
