## Q
PTP（精确时间协议，IEEE 1588）是怎么让从时钟和主时钟对齐的？请用一组数字例子算一遍偏差和路径延迟。

## A
PTP 里有一台主时钟（grandmaster），其他机器是从时钟。它们靠交换带时间戳的报文，算出两个量：从钟比主钟快了多少（偏差，offset），以及报文单程走了多久（路径延迟，delay）。

四次时间戳：
- t1：主钟发出 Sync 报文时，按主钟的时间；
- t2：从钟收到时，按从钟的时间；
- t3：从钟发出 Delay_Req 报文时，按从钟的时间；
- t4：主钟收到时，按主钟的时间。

假设路径对称（来回时间相同）：
- t2 − t1 = 延迟 + 偏差
- t4 − t3 = 延迟 − 偏差
- 偏差 = ((t2 − t1) − (t4 − t3)) / 2；延迟 = ((t2 − t1) + (t4 − t3)) / 2

例子（单位 µs）：t1 = 100，t2 = 130，t3 = 200，t4 = 210。则 t2 − t1 = 30，t4 − t3 = 10。偏差 = (30 − 10) / 2 = **10 µs**（从钟快了 10 µs），延迟 = (30 + 10) / 2 = **20 µs**。从钟据此把自己调慢 10 µs。

精度关键：这些时间戳要由网卡硬件在包进出线路时打，并配合支持 PTP 的交换机，才能做到亚微秒（几十到几百纳秒）。
