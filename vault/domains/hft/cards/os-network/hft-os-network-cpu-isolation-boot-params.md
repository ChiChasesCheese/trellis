## Q
Linux 启动参数 `isolcpus`、`nohz_full`、`rcu_nocbs` 各自解决什么问题？合起来能给交易线程带来什么？

## A
这三个参数把一部分核变成"安静的核"，只留给交易线程用：

- **`isolcpus=2-5`**：把 2 到 5 号核从通用调度器里拿出来，普通线程不会被安排上去，只有你用亲和性明确指定的线程才会在这里跑。
- **`nohz_full=2-5`**：Linux 默认每个核每秒触发 250 到 1000 次定时器中断（tick，即周期性的"心跳"），每次几微秒，用来更新时间、做调度。`nohz_full` 让只有一个可运行线程的核不再接收这个心跳。
- **`rcu_nocbs=2-5`**：RCU 是内核的一种无锁同步机制，它需要在各核上执行延后的回调函数。这个参数把这些回调转移到别的核上去做。

合起来：这些核上没有别的线程、没有周期性中断、没有内核回调，交易线程近乎独占，几乎不被打断。

用法：先留出 0、1 号核给操作系统和后台任务（这叫 housekeeping 核），再把剩下的核按此参数隔离。
