## Q
PTP 假设报文来回的路径延迟相同，如果实际不对称，会产生多大误差？现实中哪些情况会导致不对称？

## A
PTP 算偏差时用的公式是“往返时间差的一半”，前提是去程和回程耗时一样。如果去程比回程多 d，算出的偏差就会错 **d / 2**。

数字例子：去程多出 1 µs（比如来回走的线缆不一样长，或交换机对两个方向的处理时间不同），时钟就会被调错 **0.5 µs**。对 1 µs 精度的目标来说，这已经占了一半的误差预算。

不对称的现实原因：
- 光纤的收发是两根独立的纤，长度可能不同；光信号在不同波长上速度略有差别（单纤双向设备尤为明显）；
- 普通交换机排队，主→从方向和从→主方向的排队时间不同；
- 网卡的发送和接收处理延迟不同；
- 用的是软件时间戳，各方向的软件延迟抖动不同。

对策：
- 使用支持 PTP 的交换机（透明时钟或边界时钟），让它测量并扣除自己的驻留时间；
- 用硬件时间戳；
- 对已知的线缆长度差做补偿设置；
- 用 GPS 对关键节点做独立校验，发现偏差持续异常就告警。

教训：时钟同步的误差上限，常常不是协议本身，而是物理链路不对称。
