## Q
PTP 加 GPS 授时和 NTP 在精度上差多少？各自适合什么用途？

## A
| | PTP + GPS | NTP |
|---|---|---|
| 时间来源 | 机房屋顶的 GPS 天线，接收卫星上原子钟的信号，授给本地的主时钟 | 通过互联网或局域网向时间服务器请求 |
| 时间戳 | 网卡硬件打戳 | 通常是软件时间戳，受内核和网络抖动影响 |
| 精度 | 相对 UTC 约几十到一百纳秒，机器之间亚微秒 | 局域网约 0.1–1 ms，互联网约几毫秒到几十毫秒 |
| 用途 | 交易系统、延迟测量、监管时间戳 | 普通服务器、日志、办公机器 |

差距约 **3 个数量级**（从毫秒到微秒以下）。

GPS 的作用：它提供全球统一的绝对时间（UTC），所以不依赖交易所或互联网。如果 GPS 信号丢失（天线故障、被干扰），主时钟靠内部高稳定度的晶振（如铷钟，rubidium）“保持”（holdover），在几小时到几天里只漂移很小。

使用方式：GPS 授时给主时钟，PTP 通过交换机把时间分发到各台服务器；NTP 只做备用或用于不需要高精度的机器。
