## Q
只做线程绑核（affinity）和再加上核隔离（isolation）有什么区别？为什么只绑核不够？

## A
两者管的是不同方向：

- **绑核**管"我的线程只能去哪些核"。它不阻止别的线程也到这个核上来。
- **隔离**管"别的线程不许来这些核"。

例子：你把交易线程绑到 3 号核，但系统里其他线程（日志、监控、内核的工作线程）仍然可能被调度到 3 号核。一旦它们来了，内核会在两者间切换，交易线程被抢占，一次可能停几百微秒到几毫秒（取决于时间片）。

做法：用 `isolcpus` 把 3 号核从通用调度中拿掉，再用 `taskset` 把交易线程指定上去；效果是整个核只有它。

另一种做法是用 cgroup 的 `cpuset`，把其他进程限制在 0、1 号核。它更灵活（可以在运行时调整），但对内核自身的任务和中断约束较弱，隔离不如启动参数彻底。

选择：追求最彻底的低抖动，用 `isolcpus` 加 `nohz_full`；需要灵活调整时用 cpuset；单独绑核只在没有其他竞争线程的时候够用。
