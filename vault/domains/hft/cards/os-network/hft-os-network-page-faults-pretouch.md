## Q
预触（pre-touch）内存是怎么做的？以 8 GB 的 Java 堆为例，大概要处理多少页、花多久？

## A
预触就是在系统启动（开盘前）时主动把要用的内存每一页都写一次，让缺页异常在不重要的时候发生，而不是发生在交易中。

JVM 的做法：参数 `-XX:+AlwaysPreTouch`，JVM 启动时会遍历整个堆，每页写入一次。C/C++ 里则自己 `memset` 一遍，或循环按页大小的步长写一个字节。

算账（用 4 KB 页）：8 GB / 4 KB ≈ **210 万页**。每页缺页约 0.5–1 µs，总计约 1–2 秒，一次性付清。如果换成 2 MB 的大页，只有约 4096 页，预触几乎瞬间完成。

代价：
- 启动变慢，要多等几秒到几十秒（堆越大越久）；
- 预触后物理内存被全部占住，机器必须真有那么多空闲内存。

好处：之后运行中堆内这些页不会再因"第一次访问"而缺页，延迟的尖刺来源少了一个。
