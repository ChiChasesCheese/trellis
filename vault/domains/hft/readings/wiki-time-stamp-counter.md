# 时间戳计数器（Time Stamp Counter）

x86 CPU 的周期计数器 TSC 与 rdtsc 指令：极低成本的高精度计时，以及多核与变频下的注意事项。

**读的时候提取：**
- invariant TSC 的含义。
- rdtsc 与 rdtscp 的区别。
