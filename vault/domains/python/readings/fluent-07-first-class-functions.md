# Fluent Python 2e · 第 7 章 一等函数

这一章讲函数作为一等对象意味着什么：可以赋值给变量、作为参数传递、作为返回值、存进容器，由此才有了高阶函数、装饰器、回调这一整套写法。

**读时提取：**
- “一等对象”的判定标准：能否赋值、作参数、作返回值、存容器
- `map`/`filter`/`sorted(key=...)` 为什么都在用这个性质
- 可调用对象不止函数：类实例只要实现 `__call__` 也算
