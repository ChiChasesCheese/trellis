# Fluent Python 2e · 第 10 章 一等函数实现的设计模式

这一章用策略模式举例，说明经典 GoF 模式里很多“为了传递行为而定义的类”，在把函数当一等对象的语言里可以直接用函数替代，减少样板类。

**读时提取：**
- 策略模式在 Python 里如何用一个函数字典替代一堆策略类
- 什么时候仍然需要类（有状态、需要多个协作方法）而不是裸函数
