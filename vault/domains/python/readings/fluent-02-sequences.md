# Fluent Python 2e · 第 2 章 序列构成的数组

这一章把内置序列类型按“容器 vs 扁平”“可变 vs 不可变”分类，讲清楚 list、tuple、array、deque 在存储和性能上的取舍，以及推导式和生成器表达式如何替代显式循环来构造序列。

**读时提取：**
- 容器序列（存引用）与扁平序列（存值本身）的内存布局差异
- list comprehension 与 generator expression 在何时该用哪个
- 元组的两种用法：不可变列表 vs 无字段名的记录
- 为什么 `array`/`deque` 在特定场景比 `list` 更合适
