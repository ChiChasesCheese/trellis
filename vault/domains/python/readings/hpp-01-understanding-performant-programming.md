# High Performance Python 2e · 第 1 章 理解高性能编程

这一章讲计算机体系结构（CPU 缓存层级、内存带宽）如何决定了『纯算法复杂度一样，实际跑起来速度可以差很多』，为后面每一章『先测量再优化』的方法论打底。

**读时提取：**
- 为什么同一个大 O 复杂度的实现，缓存命中率不同会让实际耗时差异很大
- 『计算密集』和『内存密集』的瓶颈分别该往哪个方向优化
