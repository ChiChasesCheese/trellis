# Fluent Python 2e · 第 8 章 函数中的类型提示

这一章是类型提示的入门：Python 的类型系统是渐进式的（gradual typing），注解在运行时基本不做强制检查，价值主要体现在静态类型检查器和编辑器补全上。

**读时提取：**
- 渐进类型：注解不改变运行时行为，靠 mypy/pyright 之类的工具校验
- 函数参数、返回值标注的基本写法和 `Optional`/`Union` 的含义
- 为什么给一个函数加类型提示不等于给它加了运行时约束
