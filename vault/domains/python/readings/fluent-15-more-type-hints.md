# Fluent Python 2e · 第 15 章 深入类型提示

这一章在第 8 章基础上深入到泛型（`TypeVar`、`Generic`）、协变/逆变，以及 `TypedDict`、`Literal` 这些用于精确描述字典结构和取值范围的类型。

**读时提取：**
- `TypeVar` 如何让函数签名表达『输入输出类型一致』这种约束
- `TypedDict` 用来标注字典的固定键结构，`Literal` 用来限定具体取值
- 协变、逆变、不变在泛型容器类型标注里分别对应什么场景
