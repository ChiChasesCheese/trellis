# High Performance Python 2e · 第 12 章 实战经验

这一章是几个真实团队的案例集合，讲的是『性能优化是一个持续的工程过程』：先用真实数据profile、按 80/20 抓大头、把优化结果沉淀成可重复的基准测试，而不是一次性调优就结束。

**读时提取：**
- 为什么性能优化案例都强调『用生产数据 profile』而不是用玩具输入
- 基准测试如何防止『之前的优化被后续改动悄悄退化』
- pandas 等数据处理库在大规模数据下常见的内存/速度瓶颈类型
