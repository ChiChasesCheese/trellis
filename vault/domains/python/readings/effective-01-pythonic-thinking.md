# Effective Python 3e · 第 1 章 Python 化思维

这一章是全书的开场条目集合，核心是『遇到显式循环先想有没有推导式能表达同样的意图』，用一组具体条目（如避免复杂表达式塞进单行推导式）划出推导式可读性的边界。

**读时提取：**
- 推导式该在什么复杂度上收手，改回显式 `for` 循环
- 赋值表达式 `:=`（海象运算符）用来避免推导式里重复计算的场景
