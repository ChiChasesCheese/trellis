# Effective Python 3e · 第 14 章 协作

这一章讲多人协作和长期维护的工程实践：虚拟环境和依赖锁定、模块和包的导入机制、用 `logging` 而不是 `print` 做可配置的输出，以及用类型检查器在 CI 里捕获接口不匹配。

**读时提取：**
- 虚拟环境和依赖锁定文件为什么是协作项目的前提，而不是可选项
- `logging` 相比 `print` 多出的分级、可配置输出目的地能力
- 把类型检查器接进 CI，作为文档之外『强制』接口一致性的手段
