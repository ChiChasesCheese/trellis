## Q
在大多数机器上，`float` 用二进制分数近似十进制数时，尾数（有效数字部分）用多少位来存储？Python 显示 `0.1` 而不是它真实存储的长串数字，靠的是什么规则？

## A
大多数机器上的 float 用 53 位有效数字（从最高有效位开始）的二进制分数近似十进制值，分母是 2 的幂；0.1 实际存储的近似值是 `3602879701896397 / 2**55`。由于很多不同的十进制小数会共享同一个最接近的二进制近似值，Python 3.1 起在 `repr()` 显示时会挑选这些十进制候选里最短的一个，只要满足 `eval(repr(x)) == x` 这个不变式（即显示的字符串能精确还原出同一个存储值）即可，所以看到的是 `0.1` 而不是完整的十七位小数。
