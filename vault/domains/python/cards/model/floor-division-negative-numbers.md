## Q
为什么 `-22 // 10` 的结果是 `-3` 而不是很多人直觉认为的 `-2`？这背后 `//` 和 `%` 要满足什么关系？

## A
Python 的设计目标是让 `i % j` 的符号始终和 `j` 保持一致，并且始终满足恒等式 `i == (i // j) * j + (i % j)`；要同时满足这两点，整数除法 `//` 必须向负无穷取整（floor division），而不是向零截断。所以 `-22 // 10` 向下取整到 `-3`，对应 `-22 % 10 == 8`（符号和除数 10 一致）。这个设计在时钟这类需要「结果落在一个非负区间内」的场景很有用，比如现在是 10 点，200 小时前是几点，用 `(10 - 200) % 12` 能直接得到一个合理的非负结果。
