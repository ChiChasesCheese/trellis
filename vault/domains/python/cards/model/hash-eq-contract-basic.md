## Q
自定义类实现 `__hash__` 时唯一必须满足的约束是什么？为什么违反这个约束会让对象在字典（dict）和集合（set）里查不到？

## A
唯一的硬性要求是：两个用 `__eq__` 比较相等的对象，`__hash__()` 必须返回相同的哈希值。dict 和 set 内部先用哈希值定位候选槽位，再用 `__eq__` 在同一槽位的候选项里确认，如果相等的对象哈希值不同，它们可能被分到不同的槽位，查找时用其中一个对象的哈希值去定位，永远碰不到另一个槽位里那个「相等」的对象，表现为明明相等却查不到、去不重。
