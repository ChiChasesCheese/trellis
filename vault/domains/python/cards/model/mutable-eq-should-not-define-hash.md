## Q
一个类的实例内容可变（比如可以修改用于比较的字段），并且实现了 `__eq__`，为什么不应该再实现 `__hash__`？

## A
可哈希集合（dict、set）要求一个键在其生命周期内哈希值保持不变，因为对象一旦被插入就固定放在某个哈希桶里；如果对象的比较字段后续被修改导致哈希值变化，它在桶里的位置和它「应该」被找到的位置就对不上了，查找会失败或找错对象。所以可变对象即使实现了 `__eq__`，也应该保持 `__hash__` 不可用（继承为 None 或显式设为 None），只有不可变对象才适合同时可哈希。
