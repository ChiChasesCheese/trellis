## Q
**每对象一把锁与分片锁 · 全局注册表加每局一把锁，两层怎么配合**｜写法

四子棋服务有很多对局，每局一把锁。新建对局要往字典里登记，落子要先按 ID 找到对局。字典本身也需要保护，于是还有一把全局锁。落子时应该怎么持锁？

## A
**要点。** 全局锁只保护「登记」和「按 ID 查找」，查到之后立刻放掉，再去拿这一局自己的锁。两层锁的方向是固定的（先全局、后对局，但从不持着全局锁等对局锁），所以不会死锁，而且一局里的慢操作不会挡住别的对局。

```python
def move(self, gid, slow):
    with self._mu:                    # 全局锁里只查，立刻放掉
        m = self._matches[gid]
    with m.lock:                      # 再持有这一局自己的锁
        time.sleep(slow); m.moves += 1
```

g1 的落子很慢（0.3 秒）时，g2 的落子要等多久：

```
全局锁持有到落子结束 -> g2 的落子等了 0.25s
查完就放全局锁   -> g2 的落子等了 0.00s
```

**为什么。** 注册表的锁保护的是「字典的结构」，对局的锁保护的是「对局的状态」。两个不变量，两把锁。

**易错。** 查找和使用之间有窗口：查到对局后，它可能已被别的线程删除。要么对局永不删除（只标记结束），要么拿到对局锁后再核对它还在注册表里。
