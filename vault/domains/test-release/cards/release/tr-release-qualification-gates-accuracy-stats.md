## Q
新版本推理服务在一套 1,319 道数学题上的准确率比旧版本低了 0.9 个百分点。这算回归、应该阻断发布吗？怎么用统计判断？

## A
**准确率**：让模型做一套有标准答案的题，答对的比例。这里用的是一套 1,319 道小学数学应用题的公开题集（GSM8K 的测试集）。新旧版本的模型参数相同，差异来自软件栈：编译器、计算顺序、数字精度的变化，会让个别题的答案变化。

**先看量级**：1,319 题，准确率在 50% 左右时，单次测量的标准误 = √(0.5 × 0.5 ÷ 1319) ≈ 1.4 个百分点。0.9 个点的差小于一个标准误，单看总分说明不了什么。

**更好的方法：成对比较**。两个版本做的是同一套题，逐题对比：
- 两个版本都对、都错的题不提供信息；
- 只看"不一致"的题：旧对新错 b 道，旧错新对 c 道。

设 b = 30，c = 18。净少答对 12 道，12 ÷ 1319 ≈ 0.9 个点。
McNemar 检验统计量 = (b − c)² ÷ (b + c) = 144 ÷ 48 = 3.0，小于 5% 显著性水平的临界值 3.84。**结论：这个差异不显著，不能据此判定回归**。

如果 b = 45、c = 15：(30)² ÷ 60 = 15，远超 3.84，就是显著的回归，应进入阻断项分诊。

**几个实际要点**：
- **固定生成方式**：做准确率测试时用贪心解码（greedy decoding，每一步都选模型认为最可能的那个 token；token 是模型处理文字的最小单位），去掉随机性，否则两次运行本身就不同；
- **看不一致题的内容**：如果新错的题集中在某类输入（例如很长的题目），往往指向一个具体缺陷，即使总体不显著也要追查；
- **用多个题集**：一个题集只覆盖一种能力；
- **门限两条一起用**：统计上显著，或者绝对下降超过某个值（例如 1 个点），任一满足就要人看。
