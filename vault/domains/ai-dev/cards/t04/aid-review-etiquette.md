## Q
**Review etiquette · 披露与责任**｜实践 · 追问

你提交的 PR 大部分是 agent 写的。要不要告诉审查者？出了问题谁负责？

## A
**责任归提交者。** agent 是你的工具；你批准的每个命令和每个提交，责任是你的。官方安全文档的写法：用户负责在批准前审查提议的代码和命令。

| 做 | 理由 |
|---|---|
| 提交前自己完整读过一遍 | 不能把"让审查者发现问题"当流程 |
| 在 PR 描述里说明 AI 参与了什么、你验证了什么 | 让审查者知道把注意力放在哪 |
| 遵守团队和项目的约定 | 有的要求披露，有的有限制 |
| 对开源项目，**先读它的贡献政策** | 各项目差别很大：有的禁止 AI 生成的贡献（常见理由是版权来源不明），有的允许但要求披露 |

**别做：** 把 agent 当成"不是我写的"的借口。

**出处：** Claude Code docs《Security》（User responsibility）
