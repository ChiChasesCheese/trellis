# LeetCode Project 题解

和编程智能体一起在真实代码库里实现、修复、排障的 45–75 分钟项目；先自己作答每个决定，再看评分点，错的地方回到知识树补。

- [[退货风险评分修复 题解]]：修复评分流水线：类型校验（bool 不是 int）、分段评分与阈值边界、决策映射、批量逐项隔离、单次遍历输入、返回值互不影响。
- [[关注演员与上新通知修复 题解]]：关注与取关、新片上线时每位关注者只收一条通知、重复导入幂等与冲突拒绝、收件箱按插入序返回独立快照、并发安全。
- [[可重试的工单服务 题解]]：授权与项目隔离、幂等键防重复创建、版本号乐观并发、状态流转、游标分页，经 HTTP 适配器暴露，失败操作不留痕。
- [[密码重置修复 题解]]：配置快照、重置码生成与唯一、带时区与旧式 naive 时间、精确 30 秒有效期、一次性消费防重放、经存储边界持久化。
- [[短链服务 题解]]：建表与短码生成、自定义短码校验与冲突、TTL 过期、跳转计数与统计、按所有者授权、SQLite 增删改查与并发读改写、严格 JSON 与状态码。
- [[退货策略引擎与严格 JSON 解析修复 题解]]：只接受扁平 JSON 子集：严格转义、64 位整数不溢出、拒绝重复键；六个必填字段校验、阈值评分、按固定顺序的拒绝规则、坏行不影响后续行。
- [[文件去重流水线 题解]]：递归扫描、按大小与抽样预筛、流式 SHA-256、逐字节确认防碰撞、并发与 worker 上限、文件系统错误隔离、软硬链接、确定性分组。
- [[汇率换算 题解]]：批量汇率报价解析与整批原子登记、直达汇率、最多一次中转的全部路线、所有简单路径中的最优路线、浮点容差与确定性平局、错误优先级。
- [[销售报表 题解]]：校验日期区间、Top-k 与可选过滤，用参数化 SQL 在数据库里完成过滤、分组、排序与限量：去重活跃客户、总量总额、三种排行与确定性平局、返回行数上限。
- [[预约服务线上事故 题解]]：和编程智能体一起排查线上预约服务：剩余名额不一致、取消留下脏状态；找根因、修事务与并发、补回归测试，并对生产库做可预演、可验证的原地数据修复。
- [[关键词与用户拦截 题解]]：配置校验与原子更新、关键词规范化与子串匹配、手动与违规累计封禁、计数状态、并发安全、单次遍历输入、返回值隔离。
- [[可靠的工具调用智能体 题解]]：实现模型与工具交替的循环：完整有序的对话记录、每批工具调用在 worker 上限内并发且结果保序、按调用 ID 重放缓存、工具失败作为错误结果、拒绝畸形输出、轮次与调用预算。
- [[LLM 网关限流器 题解]]：按客户端和接口各自限流：滑动窗口与令牌桶两种策略、剩余额度与恢复时间、统计数，并发下不超发。
- [[交易汇总与应收分账 题解]]：把卡交易汇总成应收款，再按固定额与百分比规则在合约与商户之间分账：整数运算、取整与余数归属、边界。
- [[带定时付款的银行账本 题解]]：带时间戳的存款、转账与定时付款（每次请求前先处理到期付款）、转账批次全有或全无、按支出排名、账户合并、任意历史时点余额。
- [[流式调用栈处理 题解]]：把采样调用栈的变化转成有序的 start/end 事件：按完整路径识别栈帧、连续 N 次才确认、惰性处理与有界内存、相邻相同栈合并、先校验再更新、快照可续跑且输出逐字相同。
- [[库存 API 修复 题解]]：修复 MongoDB 后端的库存接口：真正持久化并返回实际存储的数据、每次请求鉴权并按所有者限定读写删、版本号原子校验递增、同一所有者 SKU 唯一、存储错误映射到正确状态码。
- [[评论与回复 题解]]：两级评论数据模型、输入与资源关系校验、评论与回复各自自增 ID、保持创建顺序、返回值不可篡改内部状态、并发安全。
- [[活动推荐规则修复 题解]]：修复可组合的无状态规则：共享位置、周末窗口、售罄与价格、客户间串数据、分级、上限与兜底；和编程智能体一起定位并验证。
- [[付款对账服务 题解]]：发票批量原子登记；付款按备注号、精确金额、容差金额三级匹配并确定性打破平局；每张发票至多结算一次；幂等键重放与冲突；付款批次全有或全无；HTTP 状态码。
- [[服装购物车 题解]]：购物车行的添加与改量（改为 0 即删除）、新行追加在末尾、快照按目录原序与插入序、可超 32 位的精确整数总价、快照互相独立。
- [[功能开关与实验分组 题解]]：开关与变体建模、配置校验与规范化、按顺序首个命中的定向规则、确定性哈希分桶的百分比放量、放量调整时用户分组稳定、并发与配置一致性。
- [[图片变换流水线 题解]]：每张图按同一顺序做变换、不同图并发处理、结果顺序确定、失败隔离、FIFO 准入与按原图大小的在途内存预算、惰性读取任务、worker 上限。
- [[贷款生命周期修复 题解]]：修复贷款服务：创建与查询、放款与还款、pending → active → repaid 状态流转、转账余额守恒、并发放款的原子更新、失败时一致、返回快照隔离。
- [[电影推荐修复 题解]]：修复推荐流水线：输入校验、排除已评分已看与下架、按类型偏好加权打分、多级平局的确定性排序、冷启动、结果上限与输入输出隔离、HTTP 契约。
- [[私人片单修复 题解]]：修复 SQLite 片单服务：归属校验、增删改片单与成员、重复添加的状态、提交后其他实例可见、连接管理、安全删除与 REST 状态码。
- [[支付表单校验 题解]]：五个字段的严格格式规则、按注入的当前年份限定年份、失焦才标记已触碰、触碰后才显示错误、全部有效且已触碰才可提交、重置与独立快照。
- [[付款记录接口 题解]]：SQLite 上建账户、查余额（正负金额求和）、记一笔付款；账户不存在时不改任何数据也不消耗 ID；重开数据库后数据与 ID 序列仍在。
- [[评论审核修复 题解]]：修复依赖外部审核器的评论服务：新建和编辑都要过审、按所有权编辑、第三次被拒即封禁、审核器出错时评论、违规计数与 ID 分配都不变、并发安全。
- [[运费计算 题解]]：解析并校验分段费率：每个国家与商品的分段从 1 开始、无缝不重叠、最后一段无上界；整批原子替换涉及的费率；报价时合并重复商品、逐段累计；错误优先级与精确整数上限。
- [[交易列表视图模型 题解]]：把交易转成展示项并保持输入顺序、全部/收入/支出三种筛选只能有一个生效、换新列表时保留当前筛选、快照与输入和后续操作互相独立。
