## Q
有些改动，把它写成指令，比直接写代码还慢。什么情况下自己写更快、更稳？

## A
**说清楚的成本超过写出来的成本时，自己写**

- **改动很小**：三五行，且你已经想清楚了，写指令、等它、读 diff 的总时间更长；
- **约束多于代码**：要求“不动这个、不动那个、顺序是这样”，这些约束你本来就要自己核对；
- **你无法快速验证**：不知道怎么证明它对，这时交出去只是把不确定性包装了一下；
- **反过来交出去更划算**：大块样板、可以对表验收的函数、你想看的另一种实现；
- **这是判断**：没有固定阈值，凭一个问题：写指令的字数，是不是已经接近代码的字数？

```python
def clamp(n: int, lo: int, hi: int) -> int:
    return max(lo, min(n, hi))

# 指令：“写一个 clamp，lo<=hi，n 小于 lo 返回 lo，大于 hi 返回 hi，
#        不改其他函数，不动测试……”  比这一行还长
print(clamp(-1, 0, 10), clamp(5, 0, 10), clamp(99, 0, 10))     # 0 5 10
```

**知识点：**该交给 AI 还是自己写（When to Delegate）
