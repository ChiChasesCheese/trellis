## Q
快递柜（Amazon Locker）的取件码和密码有什么本质区别？由此，「连续输错就锁定」该锁定什么？

## A
取件码是**持有即凭证**（bearer token）：不绑定任何身份，谁拿到谁能开那一个柜门；由系统生成所以熵可以很高；只能用一次；只开一扇门；只在几天内有效。密码则绑定身份、由用户自选（熵低）、可反复使用。

推论是致命的：**错误尝试无法按包裹或账号计数**。一个错误的码不属于任何人——你根本不知道输它的人想开哪扇门。而且如果真按包裹锁定（比如先输手机号再输码），任何人都能对着别人的包裹连按三次，把机主锁在自己的包裹外面，认证机制变成拒绝服务武器。

所以限流按**终端**：这台柜机连续被输错 N 次就整机冷却几分钟。真正的防护来自码的熵（用 `secrets` 而不是 `random`，8 位 31 进制约 8.5e11 种）加上这个分钟级窗口。
