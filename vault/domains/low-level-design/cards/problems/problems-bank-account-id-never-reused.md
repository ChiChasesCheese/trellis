## Q
银行账户系统里，一个账户 id 被合并掉之后，能不能用同一个 id 重新开一个新账户？为什么这个设计选择很重要？

## A
不能——账户 id 一旦被使用过（哪怕对应的账户后来被合并掉、不再活跃），就永久保留在“已知 id”的集合里，`create_account` 会拒绝重复使用。如果 id 可以被合并之后重新分配给一个全新的账户，“这个 id 现在代表谁”会变成一个依赖时间的模糊问题：一次历史余额查询到底是在问原来那个已经合并掉的账户，还是新开的同名账户？账户 id 因此被当成一种永久的身份标识，而不是像车位编号那样可以被回收复用的资源，这是让“合并后的 id 依然能准确回答历史查询”这句承诺成立的前提。
