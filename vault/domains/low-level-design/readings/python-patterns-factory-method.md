# The Factory Method Pattern

值得读：一等函数和类怎么让工厂方法这层间接变得不必要——依赖注入、类属性工厂、实例属性工厂三种更轻的替代，对应
`patterns-misuse-factory`、`patterns-simple-factory-enough`、`patterns-factory-method-vs-abstract-factory` 几张卡，
读它能补上"什么时候一个 `classmethod` 或关键字参数就够了、什么时候才真的需要一整层工厂类"。
