# The Low Level Design Delivery Framework (Hello Interview)

The only free page that actually budgets the hour: a five-step framework with
explicit minute counts, written by FAANG interviewers, including what to say
while scoping and when to stop designing and start typing.

**Extract on read:**
- The clock: requirements ~5 min, core entities/interfaces ~10, class design
  ~15, code the core flows ~25, demo and discuss extensions at the end —
  and the failure mode of over-spending the first two boxes.
- Scope by *core flows*, not by feature list: pick the 2–3 user actions the
  design has to serve, write them down, and get explicit agreement before
  drawing anything.
- Drive the session out loud — state assumptions, name the trade-off you are
  taking, and leave hooks ("this is where a strategy would go") instead of
  building the extension you were never asked for.
