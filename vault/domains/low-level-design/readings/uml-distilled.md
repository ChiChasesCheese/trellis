# UML Distilled (Martin Fowler)

The definitive short reference for class-diagram vocabulary: association vs
aggregation vs composition vs dependency, the exact arrowheads and diamonds,
and Fowler's pragmatic advice on which distinctions matter (and which don't).

**Extract on read:**
- Ch. 3 class diagrams: the notation table — hollow diamond, filled diamond,
  dashed dependency arrow, generalization triangle.
- Composition's lifetime-ownership rule: a part belongs to one whole and dies
  with it; aggregation carries no such guarantee (Fowler: use it sparingly).
- "UML as sketch" — draw only what supports the conversation, which is exactly
  the interview mode.
