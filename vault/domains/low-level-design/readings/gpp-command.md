# Command (Game Programming Patterns, Bob Nystrom)

值得读：把一次方法调用"具象化"成对象的推导过程，从可配置输入绑定一路讲到撤销栈、宏命令、回放——直接对应
`patterns-command-when`、`patterns-command-macro`、`patterns-command-cost` 三张卡，读它能补上撤销为什么要求命令记住
"如何逆转"而不是简单存一份旧状态快照，以及命令队列和 Memento 该怎么分工。
