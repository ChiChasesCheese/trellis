# The Composite Pattern

值得读：用 UNIX 文件系统、Tkinter 组件树等例子讲清楚组合模式的核心——让容器和内容实现同一个接口，调用方不用区分
"这是一个叶子还是一整棵子树"，对应 `patterns-composite-when` 卡，读它能补上组合模式和单纯的树形数据结构的区别到底在哪——
是接口的一致性，不是数据结构本身。
