# PEP 484 – Type Hints

值得读：类型注解这套机制为什么长这样的原始提案——注解在运行时不做任何检查，只是给静态工具和人看的接口说明，是
`python-typing-not-enforced`、`python-typing-design-review-signal` 两张卡的依据，读它能补上类型注解在 Python 里从一开始
就被设计成可选、渐进的这条基本立场，而不是误当成运行时校验。
