# typing — Support for type hints

值得读：`TypeVar`、`Literal`、`NewType`、`Optional` 的官方定义都在这一页，对应
`python-typing-literal`、`python-typing-newtype`、`python-typing-optional-vs-sentinel` 三张卡——比如 `NewType`
只在静态检查时存在、运行时就是原类型这条"零成本"的边界，读它能补上这些工具各自解决什么问题、什么时候该用哪一个而不是全用 `Any`。
