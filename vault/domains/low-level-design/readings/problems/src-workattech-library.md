# workat.tech — Design Library Management System（机器编码题面）

值得读：一份**机器编码轮的真实题面**，比教科书式的题解更接近面试现场。商业站点，只链接不摘录。
它要求的是一个命令行程序：图书馆有若干书架，每个书架同一个书目最多放一册；书有 id、书名、
作者、出版者，每一册有自己的副本 id 并落在某个书架上；可以按 book id（取第一本可用的）
或按 copy id 借；每人最多借 5 本；归还时放回第一个空位；能列出某位读者借了哪些书；
支持按 book id、作者、出版者检索。评分项明确写着「可运行可演示」「模块化、职责分离」
「多文件而非单文件」「可扩展」「可测试的 main」，可选加分项是可配置的借阅上限、可扩展的书属性、
线程安全。

它对本题解最有用的两件事：一是确认了**书目与副本必须分开**不是设计洁癖，而是题面直接写死的
要求（"borrow by book id or by copy id"）；二是给出了真实机考的验收口径——评的是结构和可扩展性，
不是功能数量。

分歧也有两处。它的模型比本题解更物理：书架、空位、上架路径都要建模，而本题解把物理位置放进了
「范围之外」，把预算花在预约队列上。反过来，它**没有**要求预约队列、罚金与续借，而那三样正是
本题解着墨最多的地方——尤其是「预约的人不来取怎么办」，那是整道题唯一的泄漏点。
