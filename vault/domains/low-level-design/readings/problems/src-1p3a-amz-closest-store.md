# 一亩三分地：Amazon 电面 OOD（add / remove / search 最近值）

值得读：2026-09-17 的 Amazon 电面报告，中文帖，正文需要积分才能看，公开可见的只有回帖里的两句话：题目是 add / remove / search，search 是找离 target 最近的数，后来又给了值域约束。本题解把这三点当作唯一的一手信息，其余（平局、重复值、具体值域、k 个最近）全部标为重建，读者若能看到原文，应以原文 API 为准。
