# Cricket Match Dashboard（Udaan 机考真题）

值得读：一份真实的机考题面（原始出处是 LeetCode 讨论区的 Udaan 面经），逐字写出了"wide/no
ball 算额外分"、"记录每位击球手的个人得分、面对球数、四个数、六个数"、"打印投手的失分与
经济率"这几条规则，是核对本文规则覆盖面的一份很好的第一手清单。它把改判列为"加分项"而不是
基础要求，侧面印证了改判在这道题里公认偏难。仓库没有 LICENSE 文件，链接可以引用，不摘录
代码。
