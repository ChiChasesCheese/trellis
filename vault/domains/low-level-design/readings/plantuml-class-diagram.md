# Class Diagram syntax and features

值得读：PlantUML 官方文档把类图的箭头语义讲全了——继承 `<|--`、组合 `*--`、聚合 `o--`、依赖虚线——这正是
`method-class-diagram-grain` 卡要求"分清四种箭头分别表示什么承诺"的直接依据，读它能补上哪条线该用哪个箭头，而不是凭直觉乱画。
