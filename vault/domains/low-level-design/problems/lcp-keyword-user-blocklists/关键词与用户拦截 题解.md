# 关键词与用户拦截（Keyword & User Blocking）

**这个项目要做什么。** 配置校验与原子更新、关键词规范化与子串匹配、手动与违规累计封禁、计数状态、并发安全、单次遍历输入、返回值隔离。

## 设计要点

关键词与用户拦截（ContentGate）参考解：一个放在讨论区发帖入口前面的准入组件。

设计五句话：
1. 配置先在锁外读成列表并整体校验，通过后在锁内一次换上；中途失败，旧配置一个字节都不变。
2. 关键词在换配置时就规范化、去重、排好序（`Keywords`），判定时只剩一次 `casefold` 加子串查找。
3. 违规次数由 `StrikeLedger` 保管：只记出过违规的用户，到上限（3）就不再增加。
4. 一次 `check` 的“是否被封、匹配、记一次违规”整体放在同一把锁里，所以并发下严格等价于某个串行顺序。
5. 返回值每次新建（`Verdict.as_dict`、`state`），外部改它不影响服务；时间过期、HTTP、磁盘都不在范围内。

## 考点与卡片

- **配置是字符串可迭代对象：裸 str 和 bytes 要先拒绝，否则被拆成单个字符**：[[lcp-keyword-user-blocklists-contract-rules]]
- **空白条目非法：strip 之后为空；空关键词是任何内容的子串，会拒掉一切**：[[lcp-keyword-user-blocklists-contract-rules]]
- **非字符串条目非法：None、数字、bytes 都是 400**：[[lcp-keyword-user-blocklists-contract-rules]]
- **三个错误码各管一处：invalid_keywords、invalid_users、invalid_input**：[[lcp-keyword-user-blocklists-contract-rules]]
- **先整体校验，再整份替换；构造函数与替换走同一条校验路径**：[[lcp-keyword-user-blocklists-contract-rules]]、[[lcp-keyword-user-blocklists-state-and-invariant]]
- **校验失败旧配置不变：不能先 clear 再逐个填**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **一次性迭代器：先读成快照，只遍历一次，之后改原列表不影响服务**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **迭代中抛出的异常原样传出，不包成 400**
- **非可迭代的配置（None、整数）合同没写：开工前确认，这里归入 400**
- **关键词规范化：strip().casefold() 后去重**：[[lcp-keyword-user-blocklists-contract-rules]]
- **内容只 casefold：不 strip，也不做 NFC 或 NFD 规范化**：[[lcp-keyword-user-blocklists-contract-rules]]
- **casefold 与 lower 的区别：ß 折成 ss，词尾 Σ 折成 σ**
- **字面子串匹配：不是正则也不是整词，代价是 ass 命中 class**：[[lcp-keyword-user-blocklists-contract-rules]]
- **匹配结果排序、无重复，重叠的关键词都算命中**：[[lcp-keyword-user-blocklists-contract-rules]]
- **不可变的关键词表：建表时规范化、去重、排序，查询只过滤**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **空内容和空白内容合法，什么也不命中，不记账**：[[lcp-keyword-user-blocklists-contract-rules]]
- **用户 ID 区分大小写、原样保存：不 strip，不统一大小写**：[[lcp-keyword-user-blocklists-contract-rules]]
- **输入校验先于判封、匹配和记账，被封的用户也一样**：[[lcp-keyword-user-blocklists-contract-rules]]
- **被封是算出来的：手动名单里或次数 ≥ 3，不另存标志**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **被封用户：不匹配、不加次数、matches 为空，优先于关键词拒绝**：[[lcp-keyword-user-blocklists-contract-rules]]
- **一个被拒请求只加一次，与命中几个词无关**：[[lcp-keyword-user-blocklists-contract-rules]]
- **第三次被拒仍是 keyword，第四次起才是 user_blocked**：[[lcp-keyword-user-blocklists-contract-rules]]、[[lcp-keyword-user-blocklists-state-and-invariant]]
- **干净请求放行，且不清零次数**：[[lcp-keyword-user-blocklists-contract-rules]]
- **state 的形状：strikes 与 blocked，陌生用户为 0 次，只读不建条目**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **替换只换自己那一份，空表表示清空，不清零次数也不解除自动封禁**：[[lcp-keyword-user-blocklists-contract-rules]]
- **移出手动名单只在次数小于 3 时才解封**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **判封、匹配、记账放在同一把锁里：先检查后动作不能被切开**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **配置整份替换：锁外读完校验，锁内只换一个引用，请求看到整份旧表或新表**：[[lcp-keyword-user-blocklists-state-and-invariant]]、[[lcp-keyword-user-blocklists-reflection-million-keywords]]
- **次数封顶是安全不变量：到上限再加就抛异常，不用 assert**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **返回值每次新建：Verdict 转字典、matches 列表、state 字典都是副本**：[[lcp-keyword-user-blocklists-contract-rules]]
- **实例隔离：状态在实例里，默认参数不共享可变对象**
- **并发测试：屏障同时起跑，缩短切换间隔，断言恰好三个 keyword**：[[lcp-keyword-user-blocklists-state-and-invariant]]
- **申诉不丢审计：违规只追加成事件，撤销也是新事件**：[[lcp-keyword-user-blocklists-reflection-appeals-audit]]
- **次数改成对事件的查询，账本接口 count 与 add 不变**：[[lcp-keyword-user-blocklists-reflection-appeals-audit]]
- **百万级关键词：逐词扫描线性变慢且持着锁，换成 Aho–Corasick 自动机**：[[lcp-keyword-user-blocklists-reflection-million-keywords]]
- **后台建好新自动机，再在锁内换引用，请求不被建树堵住**：[[lcp-keyword-user-blocklists-reflection-million-keywords]]
- **自动机的新瓶颈是内存：字典树比词本身大几十倍**：[[lcp-keyword-user-blocklists-reflection-million-keywords]]
- **给编程智能体的第一条指令：十二条合同加数字例子，一次一个失败用例**：[[lcp-keyword-user-blocklists-contract-rules]]
- **智能体的老毛病：lower、词边界正则、strip 用户 ID、多存一个 blocked 标志**
- **自己写并发测试和合同数字逐项断言，不让智能体代写**

```python
from __future__ import annotations

import threading
from collections.abc import Iterable
from dataclasses import dataclass
from typing import TypedDict

STRIKE_LIMIT = 3  # 累计这么多次被拒，就自动封禁


class ServiceError(Exception):
    """对外的统一错误：status 是 HTTP 状态码，code 是稳定的字符串。"""

    def __init__(self, status: int, code: str) -> None:
        self.status, self.code = status, code
        super().__init__(code)


def _snapshot(values: Iterable[str], code: str) -> list[str]:
    """把配置读成一份列表并校验全部条目；任何一条不合格，整批作废。

    迭代过程中自己抛出的异常（比如生成器里的 IOError）原样冒出去，不换成 400。
    """
    if isinstance(values, (str, bytes, bytearray)):  # 裸字符串会被拆成单个字符，必须先拒绝
        raise ServiceError(400, code)
    try:
        iterator = iter(values)
    except TypeError:  # 根本不是可迭代对象
        raise ServiceError(400, code) from None
    items = list(iterator)  # 只遍历一次，一次性迭代器也能用
    if not all(isinstance(item, str) and item.strip() for item in items):
        raise ServiceError(400, code)
    return items


def _require_user(user: object) -> str:
    """用户 ID 必须是非空白字符串；原样返回，不 strip、不改大小写。"""
    if not isinstance(user, str) or not user.strip():
        raise ServiceError(400, "invalid_input")
    return user


@dataclass(frozen=True, slots=True)
class Keywords:
    """一份编译好的关键词表：规范化、去重、按字符串顺序排好，创建后不可变。"""

    words: tuple[str, ...] = ()

    @classmethod
    def compile(cls, raw: Iterable[str]) -> Keywords:
        """校验并规范化：strip 再 casefold，然后去重、排序。"""
        normalized = {word.strip().casefold() for word in _snapshot(raw, "invalid_keywords")}
        return cls(tuple(sorted(normalized)))

    def find(self, content: str) -> list[str]:
        """内容只做 casefold；逐个关键词做字面子串查找，结果已按字符串顺序排好。"""
        folded = content.casefold()
        return [word for word in self.words if word in folded]


@dataclass(frozen=True, slots=True)
class Verdict:
    """一次 `check` 的结果；`as_dict` 每次造新字典，调用方随便改。"""

    allowed: bool
    reason: str | None
    matches: tuple[str, ...]
    strikes: int

    @classmethod
    def clean(cls, strikes: int) -> Verdict:
        return cls(True, None, (), strikes)

    @classmethod
    def blocked(cls, strikes: int) -> Verdict:
        return cls(False, "user_blocked", (), strikes)

    @classmethod
    def keyword(cls, matches: Iterable[str], strikes: int) -> Verdict:
        return cls(False, "keyword", tuple(matches), strikes)

    def as_dict(self) -> dict[str, object]:
        return {
            "allowed": self.allowed,
            "reason": self.reason,
            "matches": list(self.matches),
            "strikes": self.strikes,
        }


class UserState(TypedDict):
    strikes: int
    blocked: bool


class StrikeLedger:
    """每个用户的违规次数。只记出过违规的用户，次数永远不超过上限。

    它自己不加锁：并发由持有它的 `BlocklistService` 用一把锁保证。
    """

    def __init__(self, limit: int = STRIKE_LIMIT) -> None:
        self._limit = limit
        self._counts: dict[str, int] = {}

    def count(self, user: str) -> int:
        return self._counts.get(user, 0)  # 查询不创建条目，没违规过的用户不占内存

    def exhausted(self, user: str) -> bool:
        return self.count(user) >= self._limit

    def add(self, user: str) -> int:
        """记一次违规并返回新的次数；已到上限的用户不该再走到这里。"""
        if self.exhausted(user):
            raise RuntimeError("user already at the strike limit")  # 安全不变量，不用 assert
        self._counts[user] = self.count(user) + 1
        return self._counts[user]


class BlocklistService:
    """关键词匹配、手动封禁与累计违规封禁。"""

    def __init__(self, keywords: Iterable[str] = (), blocked_users: Iterable[str] = ()) -> None:
        # 两份配置都校验通过以后才赋值；构造和替换走同一条校验路径
        compiled = Keywords.compile(keywords)
        manual = frozenset(_snapshot(blocked_users, "invalid_users"))
        self._lock = threading.Lock()
        self._keywords = compiled
        self._manual = manual
        self._ledger = StrikeLedger()

    @property
    def keywords(self) -> list[str]:
        """当前规范化后的关键词（按字符串顺序）的副本。"""
        with self._lock:
            return list(self._keywords.words)

    @property
    def blocked_users(self) -> list[str]:
        """当前手动封禁名单（按字符串顺序）的副本。"""
        with self._lock:
            return sorted(self._manual)

    def replace_keywords(self, keywords: Iterable[str]) -> None:
        compiled = Keywords.compile(keywords)  # 在锁外读用户给的迭代器，慢的或会抛错的迭代器不会占着锁
        with self._lock:
            self._keywords = compiled  # 一次引用替换：并发的 check 看到整份旧表或整份新表

    def replace_blocked_users(self, users: Iterable[str]) -> None:
        manual = frozenset(_snapshot(users, "invalid_users"))
        with self._lock:
            self._manual = manual

    def state(self, user: str) -> UserState:
        _require_user(user)
        with self._lock:
            return {"strikes": self._ledger.count(user), "blocked": self._is_blocked(user)}

    def check(self, user: str, content: str) -> dict[str, object]:
        _require_user(user)
        if not isinstance(content, str):
            raise ServiceError(400, "invalid_input")  # 校验在任何匹配和记账之前
        with self._lock:
            strikes = self._ledger.count(user)
            if self._is_blocked(user):  # 封禁优先于关键词：不匹配、不加次数
                return Verdict.blocked(strikes).as_dict()
            matches = self._keywords.find(content)
            if not matches:  # 干净请求不清零次数
                return Verdict.clean(strikes).as_dict()
            return Verdict.keyword(matches, self._ledger.add(user)).as_dict()  # 不管命中几处，只记一次

    def _is_blocked(self, user: str) -> bool:
        """调用方必须已持有锁。"""
        return user in self._manual or self._ledger.exhausted(user)


if __name__ == "__main__":
    service = BlocklistService([" SPAM "])
    print(service.check("alice", "SPAM offer"))
    print(service.check("alice", "hello"))
    for _ in range(3):
        print(service.check("bob", "spam spam spam"))
    print(service.state("bob"))
```
