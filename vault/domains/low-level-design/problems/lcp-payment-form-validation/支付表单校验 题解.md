# 支付表单校验（Payment Form Validation）

**这个项目要做什么。** 五个字段的严格格式规则、按注入的当前年份限定年份、失焦才标记已触碰、触碰后才显示错误、全部有效且已触碰才可提交、重置与独立快照。

## 设计要点

支付表单校验（PaymentForm）参考解。

设计五行：
1. 每个字段只存两样东西：用户敲进去的原始字符串、是否失焦过（`_Entry`）；有效性和错误文字都不存。
2. 有效性由 `Rule` 表按字段名查出来：一条规则 = 错误文字 + 一个只看字符串的判定函数；年份窗口由注入的当前年份在构造时算好。
3. `snapshot()` 每次从头算：valid = 规则通过；error = 已触碰且无效时才是规则文字；canSubmit = 五个字段都 valid 且 touched。
4. 返回给调用方的永远是新对象（新字典、新 `FieldState`），内部状态不外泄；字符串本身不可变，可以放心共享。
5. `apply_action` 是 HTTP 边界：只认三种动作的精确键集合与字符串类型，形状不对就抛 `ActionError`，表单状态一点不动。

## 考点与卡片

- **构造：PaymentForm(currentYear)，年份由外面注入，范围 2000–2096，保证窗口末端仍是四位数**：[[lcp-payment-form-validation-contract-rules]]
- **五个字段名固定：number、name、month、year、cvv，快照里按这个顺序**：[[lcp-payment-form-validation-contract-rules]]
- **初始状态：值为空串、未触碰、无效、无错误，canSubmit 为假**：[[lcp-payment-form-validation-contract-rules]]
- **change 原样存字符串：不裁剪、不改大小写、不补零**：[[lcp-payment-form-validation-contract-rules]]
- **change 不碰触碰标记：用户还在打字时不该看到红字**：[[lcp-payment-form-validation-contract-rules]]、[[lcp-payment-form-validation-reflection-error-visibility]]
- **blur 标触碰，之后一直保持；重复失焦没有副作用**：[[lcp-payment-form-validation-contract-rules]]、[[lcp-payment-form-validation-reflection-error-visibility]]
- **卡号：恰好 16 个 ASCII 数字，十五位与十七位都无效**：[[lcp-payment-form-validation-contract-rules]]
- **姓名：一个或多个 ASCII 字母，空串、空格、数字、带重音的字母都无效**：[[lcp-payment-form-validation-contract-rules]]
- **月份：恰好两位数字，01 到 12；00、13、1、001 都无效**：[[lcp-payment-form-validation-contract-rules]]
- **年份：恰好四位数字，currentYear 到 currentYear+3，含两端；+4 无效**：[[lcp-payment-form-validation-contract-rules]]、[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **月份与年份互相独立：没有“不能早于本月”的规则**：[[lcp-payment-form-validation-contract-rules]]
- **CVV：恰好 3 个 ASCII 数字，前导零保留（000 有效）**：[[lcp-payment-form-validation-contract-rules]]
- **isdigit 单独用会放过全角、阿拉伯数字和上标：要先 isascii**：[[lcp-payment-form-validation-contract-rules]]
- **int() 判断月份会接受 +5、空白，遇到 a1 还会抛 ValueError：用合法字符串的集合**：[[lcp-payment-form-validation-contract-rules]]
- **正则的两个陷阱：\d 匹配所有 Unicode 数字，$ 匹配末尾换行之前；用 [0-9] 加 fullmatch**
- **错误文字固定，五个字段各一句，大小写和空格都不能差**：[[lcp-payment-form-validation-contract-rules]]
- **error 只在“已触碰且无效”时是文字：未碰的无效字段为 None，碰过的有效字段为 None**：[[lcp-payment-form-validation-contract-rules]]、[[lcp-payment-form-validation-reflection-error-visibility]]
- **有效、已触碰、可见错误是三件事：值算出前者，事件改变后者，两者组合出第三个**：[[lcp-payment-form-validation-reflection-error-visibility]]、[[lcp-payment-form-validation-state-and-invariant]]
- **canSubmit = 五个字段全部有效且全部已触碰；只看有效或只看触碰都是错的**：[[lcp-payment-form-validation-contract-rules]]
- **改短 CVV 之后 canSubmit 立刻为假：不存它，每次快照现算**：[[lcp-payment-form-validation-contract-rules]]、[[lcp-payment-form-validation-state-and-invariant]]
- **状态里只存值和触碰；valid 和 error 是派生值，不单独存**：[[lcp-payment-form-validation-state-and-invariant]]、[[lcp-payment-form-validation-reflection-error-visibility]]
- **规则是“字段名到 Rule”的一张表：一个函数就是一个策略，不为五个字段各建一个类**：[[lcp-payment-form-validation-state-and-invariant]]
- **年份窗口在构造时随注入年份算好，reset 不碰规则**：[[lcp-payment-form-validation-state-and-invariant]]、[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **reset 清空值和触碰标记但保留年份；用新字典换旧字典，不原地清空**：[[lcp-payment-form-validation-contract-rules]]、[[lcp-payment-form-validation-state-and-invariant]]、[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **快照每次现建：新字典、新 FieldState；字符串不可变可以共享**：[[lcp-payment-form-validation-state-and-invariant]]、[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **改返回的快照不能影响表单，旧快照在之后的操作下不变**：[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **条目字典在 __init__ 里建，不是类属性：两个表单互不影响**：[[lcp-payment-form-validation-state-and-invariant]]、[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **未知字段名抛 ValueError、非字符串值抛 TypeError，失败的调用不留痕**：[[lcp-payment-form-validation-state-and-invariant]]
- **apply_action：键集合必须恰好等于 action 加该动作需要的键，值都是 str，校验通过前不碰表单**
- **重复的 blur 必须无副作用：页面的队列与过期响应处理依赖整份快照**
- **测试：用两个不同的注入年份，边界相对年份算，不写死 2026**：[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **测试：持有旧快照，操作、重置、破坏返回值，再比较**：[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **测试：固定种子的随机字符串与独立的 [0-9] 正则参照实现对拍**：[[lcp-payment-form-validation-reflection-reset-and-snapshot]]
- **给智能体的指令：规则加数字例子，一次一个失败用例，状态设计自己留着**：[[lcp-payment-form-validation-contract-rules]]
- **读智能体 diff 要查的四处：缓存 valid、strip()、int() 或 \d、change 里碰触碰**：[[lcp-payment-form-validation-contract-rules]]
- **可选扩展：touch_all 让提交时所有错误同时出现，first_invalid 把光标送到第一个坏字段**：[[lcp-payment-form-validation-state-and-invariant]]

## 参考解

```python
from __future__ import annotations

import dataclasses
from collections.abc import Callable
from dataclasses import dataclass

FIELD_NAMES: tuple[str, ...] = ("number", "name", "month", "year", "cvv")
YEAR_WINDOW = 4  # 当前年份起算共四年：currentYear … currentYear+3


@dataclass
class FieldState:
    """一个字段在某一刻的样子。"""

    value: str
    touched: bool
    valid: bool
    error: str | None


@dataclass
class PaymentSnapshot:
    """整张表单在某一刻的样子；`fields` 按 FIELD_NAMES 的顺序。"""

    fields: dict[str, FieldState]
    canSubmit: bool


class ActionError(ValueError):
    """HTTP 动作体形状不对（对应 400）。"""


@dataclass(frozen=True, slots=True)
class Rule:
    """一个字段的规则：判定函数只看字符串，错误文字固定。"""

    message: str
    accepts: Callable[[str], bool]


@dataclass(slots=True)
class _Entry:
    """内部可变状态：原始输入和是否失焦过。"""

    value: str = ""
    touched: bool = False


def _ascii_digits(length: int) -> Callable[[str], bool]:
    """恰好 `length` 个 ASCII 数字。先查 isascii：isdigit 单独用会放过全角数字、阿拉伯数字和上标。"""

    def accepts(text: str) -> bool:
        return len(text) == length and text.isascii() and text.isdigit()

    return accepts


def _ascii_letters(text: str) -> bool:
    """至少一个字符，全是 ASCII 字母；空格、重音字母、数字都不行。"""
    return text.isascii() and text.isalpha()


def build_rules(current_year: int) -> dict[str, Rule]:
    """五条规则。月份和年份直接写成合法字符串的集合：不调用 int()，也就没有正负号、空白、下划线的歧义。"""
    months = frozenset(f"{m:02d}" for m in range(1, 13))
    years = frozenset(str(y) for y in range(current_year, current_year + YEAR_WINDOW))
    return {
        "number": Rule("Invalid Card Number", _ascii_digits(16)),
        "name": Rule("Invalid Card Name", _ascii_letters),
        "month": Rule("Invalid Month", months.__contains__),
        "year": Rule("Invalid Year", years.__contains__),
        "cvv": Rule("Invalid CVV", _ascii_digits(3)),
    }


class PaymentForm:
    """五个字段的输入状态机：change 改值，blur 标触碰，reset 清空，snapshot 拍照。"""

    def __init__(self, currentYear: int) -> None:
        if type(currentYear) is not int or not 2000 <= currentYear <= 2096:
            raise ValueError("currentYear must be an int in 2000..2096")
        self._year = currentYear
        self._rules = build_rules(currentYear)
        self._entries = {name: _Entry() for name in FIELD_NAMES}

    def _entry(self, field: str) -> _Entry:
        try:
            return self._entries[field]
        except (KeyError, TypeError):
            raise ValueError(f"unknown field: {field!r}") from None

    def change(self, field: str, value: str) -> None:
        """原样保存字符串（不裁剪、不规范化）；不碰触碰标记。"""
        entry = self._entry(field)
        if not isinstance(value, str):
            raise TypeError("value must be a str")
        entry.value = value

    def blur(self, field: str) -> None:
        """标记触碰；重复失焦无副作用。"""
        self._entry(field).touched = True

    def touch_all(self) -> None:
        """点“提交”时的做法：把五个字段都标为已触碰，让每个无效字段同时亮出错误。"""
        for entry in self._entries.values():
            entry.touched = True

    def first_invalid(self) -> str | None:
        """第一个无效字段的名字（按页面顺序），用来在提交失败时把光标送过去；全有效时为 None。"""
        for name in FIELD_NAMES:
            if not self._rules[name].accepts(self._entries[name].value):
                return name
        return None

    def reset(self) -> None:
        """清空所有值和触碰标记，保留年份与规则。"""
        self._entries = {name: _Entry() for name in FIELD_NAMES}

    def snapshot(self) -> PaymentSnapshot:
        """每次现算、现建：返回值与表单、与上一次的快照都不共享可变对象。"""
        fields: dict[str, FieldState] = {}
        for name in FIELD_NAMES:
            entry, rule = self._entries[name], self._rules[name]
            valid = rule.accepts(entry.value)
            shown = entry.touched and not valid
            fields[name] = FieldState(
                value=entry.value,
                touched=entry.touched,
                valid=valid,
                error=rule.message if shown else None,
            )
        ready = all(state.valid and state.touched for state in fields.values())
        return PaymentSnapshot(fields=fields, canSubmit=ready)


# 每种动作需要的键（除 action 之外）；多一个或少一个都算畸形
_ACTION_KEYS: dict[str, tuple[str, ...]] = {
    "reset": (),
    "blur": ("field",),
    "change": ("field", "value"),
}


def apply_action(form: PaymentForm, body: object) -> dict[str, object]:
    """HTTP 边界：校验 JSON 体的形状，执行动作，返回快照的纯字典。校验全部通过之前不碰表单。"""
    if not isinstance(body, dict):
        raise ActionError("body must be an object")
    action = body.get("action")
    if type(action) is not str or action not in _ACTION_KEYS:
        raise ActionError("unknown action")
    wanted = {"action", *_ACTION_KEYS[action]}
    if set(body) != wanted:
        raise ActionError("unexpected or missing keys")
    if any(type(body[key]) is not str for key in wanted):
        raise ActionError("every value must be a string")
    if "field" in wanted and body["field"] not in FIELD_NAMES:
        raise ActionError("unknown field")
    if action == "reset":
        form.reset()
    elif action == "blur":
        form.blur(body["field"])
    else:
        form.change(body["field"], body["value"])
    return dataclasses.asdict(form.snapshot())


if __name__ == "__main__":
    form = PaymentForm(2031)
    steps = [("number", "4000000000000002"), ("name", "Ada"), ("month", "11"), ("year", "2033"), ("cvv", "42")]
    for name, text in steps:
        form.change(name, text)
        form.blur(name)
        snap = form.snapshot()
        print(f"{name:7} {text!r:20} error={snap.fields[name].error!r:24} canSubmit={snap.canSubmit}")
    form.change("cvv", "420")
    print("fixed cvv  ->", form.snapshot().canSubmit)
    form.reset()
    form.touch_all()
    print("after touch_all:", [s.error for s in form.snapshot().fields.values()])
```
