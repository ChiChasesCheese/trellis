# 运费计算（Shipping Cost）

**这个项目要做什么。** 解析并校验分段费率：每个国家与商品的分段从 1 开始、无缝不重叠、最后一段无上界；整批原子替换涉及的费率；报价时合并重复商品、逐段累计；错误优先级与精确整数上限。

## 设计要点

运费计算服务：分段费率整批登记，按订单逐段累计报价。

设计（五行）：
1. `parse_rule` 把一行文本变成 `(国家, 商品, Tier)`；所有行的语法都先检查完，再去看分段是否连续，所以语法错（400）总先于分段错（422）。
2. `Tier` 是冻结的值对象，自己知道"买到 q 件时这一段收多少钱"；`Schedule` 在构造时校验分段从 1 起、无缝、不重叠、末段无上界。
3. 登记在一份局部副本上改，全部校验通过之后整体换掉 `self._schedules`；失败时旧状态一个字节都没变。
4. 报价先按商品合并数量，再逐段累计；金额全用 Python 的精确整数，最后才和 32 位上界比较。
5. 返回值每次新建字典和列表，内部只存不可变的 `Schedule`，调用方碰不到内部状态。

## 考点与卡片

- **国家码是 2–5 个大写 ASCII 字母，商品名是 1–32 位字母数字下划线连字符；整串匹配，区分大小写，不去空白**：[[lcp-shipping-cost-contract-rules]]
- **数字只认 ASCII 数字，前导零可以，每个数字 ≤ 1,000,000（最小、最大、费用、数量都一样）**：[[lcp-shipping-cost-contract-rules]]
- **`\d` 会匹配 Unicode 数字（`int("١٢")` 是 12），要用 `[0-9]+`；`$` 放过末尾换行，要用 `fullmatch`**：[[lcp-shipping-cost-contract-rules]]
- **`0` 加五千个前导零加 `1` 是合法的 1，但 Python 3.11 的 `int()` 对超过 4300 位的字符串抛 ValueError：先去零、先看长度、再转换**：[[lcp-shipping-cost-contract-rules]]
- **一条规则恰好六段；类型只有 incremental 与 fixed；最大写 `*` 才是无上界；费用必须为正，0 是语法错**：[[lcp-shipping-cost-contract-rules]]
- **空批次、非列表、元素不是字符串都是 400 invalid_input**：[[lcp-shipping-cost-contract-rules]]
- **所有行的语法先检查完，再检查分段：语法错在批次末尾，也先于前面的分段错（400 先于 422）**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-state-and-invariant]]
- **最小数量可以是 0，语法合法，由分段规则以 422 拒绝（零锚点）；语法和分段必须是两个独立阶段**：[[lcp-shipping-cost-contract-rules]]
- **分段表连续：排序后第一段从 1 起、后一段从前一段有限最大加 1 起、末段无上界；缺口、重叠、起点重复、`*` 之后还有段、末段有限都是 422**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **“最大小于最小”要单独检查：只看起点会放过 `1–2`、`3–2`、`3–*` 这种序列**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **用一个游标表示“下一段该从哪里开始”，无界之后游标变成 None（不用 -1，因为最小数量可以是 0）；这比两两比较或逐件标记都简单**：[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **同一（国家，商品）的行分散在批次各处，先按对分组再排序；完全相同的两行是起点重复，422**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-state-and-invariant]]
- **整批原子：任何一步失败，同批里别的国家和商品也不生效，旧状态一个字节不变**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-state-and-invariant]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **按对整体替换：批里出现的（国家，商品）用新分段表替换旧的，没出现的原样保留；不是在旧表里插新段**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-state-and-invariant]]
- **成功返回 201 和输入行数，同一对的多行都计入，不是对数**：[[lcp-shipping-cost-contract-rules]]
- **原子的做法：解析只产出值、建表在局部副本上、成功后一次赋值；不需要回滚代码，也不需要事务或备忘录模式**：[[lcp-shipping-cost-state-and-invariant]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **`Schedule` 只能由 `build` 构造，拿到一张就等于拿到一份已验证的分段表（构造即校验）**：[[lcp-shipping-cost-state-and-invariant]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **`Tier` 与 `Schedule` 是冻结的数据类，分段表用元组；内部只存不可变值，隔离就不需要深拷贝**：[[lcp-shipping-cost-state-and-invariant]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **报价的错误五层：国家与容器 400 → 国家无费率 404（空订单也是）→ 订单行畸形或合并超限 400 → 商品无费率 404 → 金额超限 400**：[[lcp-shipping-cost-contract-rules]]
- **订单里任何一行畸形都先于“商品没有费率”，和这一行的位置无关；商品名格式不对是畸形行（400），不是缺商品（404）**：[[lcp-shipping-cost-contract-rules]]
- **订单数量是 1–1,000,000 的 ASCII 整数；0 不是一件商品，直接拒绝，不造“第 0 件”的分段；同一商品合并后也不得超过 1,000,000**：[[lcp-shipping-cost-contract-rules]]
- **同一商品的多行先合并再算价：固定段按“有没有进入”收一次，分开算会收两次（kettle 6 加 5 合并 2400，分开 4200）**：[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **逐段累计：从第 1 件起走到的每一段都加一笔，后面的段不取代前面的；incremental 按进入件数，fixed 进入就收一次，末段是 fixed 也合法**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **`Tier.charge` 对没走到的段返回 0，商品费用就是各段之和，不需要分支和提前退出；两种类型用枚举加一个 if，拒绝策略模式**：[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **金额用精确整数，不转浮点；单个商品的费用和整单总额各检查一次上界 2,147,483,647，恰好等于通过、多一分失败**：[[lcp-shipping-cost-contract-rules]]、[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **单商品一百万件乘一百万单价就是 10^12：每个商品合规、合起来超限的订单也要被挡住（总额检查不能省）**：[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **breakdown 按商品名的 ASCII 升序（大写在小写前，`_` 在两者之间）；空订单在已知国家返回总额 0 与空 breakdown**：[[lcp-shipping-cost-contract-rules]]
- **列表按（国家，商品，最小数量）排序；过滤是完全相等，没有匹配（含空串、畸形码）返回空列表，且不会创造出国家**：[[lcp-shipping-cost-contract-rules]]
- **返回的字典、列表每次新建；调用方清空输入列表或返回值，内部不受影响；之后的登记不改变已拿到的结果**：[[lcp-shipping-cost-state-and-invariant]]、[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **顺序调用才成立：两个线程各自复制各自赋值，后者覆盖前者；要线程安全就用一把锁包住“复制、校验、赋值”**：[[lcp-shipping-cost-reflection-atomic-and-detached]]
- **复杂度：合并 O(L)，算价 O(P·T)，排序 O(P log P)；优化是登记时预算累计费用、报价用二分**：[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **费率版本化：每次成功登记得到递增版本号和不可变快照，一次报价读一次版本、整单按它算，登记用比较版本再写**：[[lcp-shipping-cost-reflection-merge-before-pricing]]、[[lcp-shipping-cost-state-and-invariant]]
- **开工前把规则里的数字例子写成测试再让智能体实现；缺口、重叠、零锚点、坏批次后旧费率还在，一次只给它一个失败的测试**：[[lcp-shipping-cost-contract-rules]]
- **用“一件一件地买”的朴素实现做对照，在随机分段表上和解答比较；它不用区间公式，不会犯同一个错**：[[lcp-shipping-cost-reflection-merge-before-pricing]]
- **语法先于分段、商品名畸形算哪一层、替换还是合并这类语义自己定，写成测试再交给智能体，不让它顺手选一个**：[[lcp-shipping-cost-contract-rules]]

## 参考解

```python
from __future__ import annotations

import re
from collections.abc import Iterable
from dataclasses import dataclass
from enum import Enum

MAX_TOKEN = 1_000_000  # 每个十进制数字最多这么大
MAX_CENTS = 2_147_483_647  # 单个商品的费用、整单总额的上界（分）

_COUNTRY = re.compile(r"[A-Z]{2,5}")  # 一律 fullmatch：`$` 会放过末尾的换行
_PRODUCT = re.compile(r"[A-Za-z0-9_-]{1,32}")
_DIGITS = re.compile(r"[0-9]+")  # 不用 \d：它会匹配 Unicode 数字


class ServiceError(Exception):
    """对外的错误：status 是 HTTP 状态码，code 是稳定的字符串。"""

    def __init__(self, status: int, code: str) -> None:
        self.status, self.code = status, code
        super().__init__(code)


def _invalid() -> ServiceError:
    return ServiceError(400, "invalid_input")


def parse_number(token: str) -> int:
    """纯 ASCII 数字，允许前导零，值不超过 MAX_TOKEN。"""
    if _DIGITS.fullmatch(token) is None:
        raise _invalid()
    trimmed = token.lstrip("0")
    if len(trimmed) > len(str(MAX_TOKEN)):  # 先看长度：一长串零或大数交给 int() 会触发位数上限
        raise _invalid()
    value = int(trimmed or "0")
    if value > MAX_TOKEN:
        raise _invalid()
    return value


def is_country(value: object) -> bool:
    return isinstance(value, str) and _COUNTRY.fullmatch(value) is not None


class TierKind(Enum):
    INCREMENTAL = "incremental"  # 进入本段的每一件都收 cost
    FIXED = "fixed"  # 只要进入本段就一次性收 cost


@dataclass(frozen=True, slots=True)
class Tier:
    """一段闭区间 [low, high] 的费率；high 为 None 表示没有上界。"""

    kind: TierKind
    low: int
    high: int | None
    cost: int

    def charge(self, quantity: int) -> int:
        """买 quantity 件时这一段收多少分：没走到这一段是 0。"""
        if quantity < self.low:
            return 0
        if self.kind is TierKind.FIXED:
            return self.cost
        top = quantity if self.high is None else min(quantity, self.high)
        return (top - self.low + 1) * self.cost

    def as_row(self, country: str, product: str) -> dict:
        return {"country": country, "product": product, "type": self.kind.value,
                "min_quantity": self.low, "max_quantity": self.high, "cost_cents": self.cost}


@dataclass(frozen=True, slots=True)
class Schedule:
    """一个（国家，商品）的完整分段表。不变量：从 1 起、首尾相接、末段无上界；构造之后不再改变。"""

    tiers: tuple[Tier, ...]

    @classmethod
    def build(cls, tiers: Iterable[Tier]) -> Schedule:
        ordered = sorted(tiers, key=lambda tier: tier.low)
        expected: int | None = 1  # 下一段必须从这里开始；None 表示已经无界，后面不许再有段
        for tier in ordered:
            if tier.low != expected or (tier.high is not None and tier.high < tier.low):
                raise ServiceError(422, "invalid_rules")
            expected = None if tier.high is None else tier.high + 1
        if expected is not None:  # 最后一段是有限的
            raise ServiceError(422, "invalid_rules")
        return cls(tuple(ordered))

    def fee(self, quantity: int) -> int:
        return sum(tier.charge(quantity) for tier in self.tiers)


def parse_rule(line: object) -> tuple[str, str, Tier]:
    """一行恰好六段；只看语法，不看分段之间的关系。"""
    if not isinstance(line, str):
        raise _invalid()
    fields = line.split(",")
    if len(fields) != 6:
        raise _invalid()
    country, product, kind, low, high, cost = fields
    if not is_country(country) or _PRODUCT.fullmatch(product) is None:
        raise _invalid()
    try:
        tier_kind = TierKind(kind)
    except ValueError:
        raise _invalid() from None
    amount = parse_number(cost)
    if amount == 0:
        raise _invalid()
    upper = None if high == "*" else parse_number(high)
    return country, product, Tier(tier_kind, parse_number(low), upper, amount)


def parse_item(item: object) -> tuple[str, int]:
    """订单行 `商品,数量`：数量是 1 到 MAX_TOKEN 的整数。"""
    if not isinstance(item, str):
        raise _invalid()
    fields = item.split(",")
    if len(fields) != 2 or _PRODUCT.fullmatch(fields[0]) is None:
        raise _invalid()
    quantity = parse_number(fields[1])
    if quantity == 0:
        raise _invalid()
    return fields[0], quantity


class ShippingService:
    def __init__(self) -> None:
        self._schedules: dict[str, dict[str, Schedule]] = {}  # 国家 -> 商品 -> 分段表

    def register_rules(self, rules: list[str]) -> tuple[int, dict]:
        if not isinstance(rules, (list, tuple)) or not rules:
            raise _invalid()
        parsed = [parse_rule(line) for line in rules]  # 全部语法先过一遍
        grouped: dict[tuple[str, str], list[Tier]] = {}
        for country, product, tier in parsed:
            grouped.setdefault((country, product), []).append(tier)
        staged = {country: dict(products) for country, products in self._schedules.items()}
        for (country, product), tiers in grouped.items():  # 再逐对校验分段，改的是副本
            staged.setdefault(country, {})[product] = Schedule.build(tiers)
        self._schedules = staged  # 唯一的一次写入
        return 201, {"registered_count": len(parsed)}

    def calculate_shipping(self, country: str, items: list[str]) -> tuple[int, dict]:
        if not is_country(country) or not isinstance(items, (list, tuple)):
            raise _invalid()
        book = self._schedules.get(country)
        if book is None:
            raise ServiceError(404, "country_not_found")
        quantities: dict[str, int] = {}
        for item in items:  # 先合并重复商品：固定费率按总量算，分开算会多收
            product, quantity = parse_item(item)
            quantities[product] = quantities.get(product, 0) + quantity
            if quantities[product] > MAX_TOKEN:
                raise _invalid()
        if any(product not in book for product in quantities):
            raise ServiceError(404, "product_not_found")
        breakdown, total = [], 0
        for product in sorted(quantities):
            fee = book[product].fee(quantities[product])  # Python 整数是精确的，不会溢出
            if fee > MAX_CENTS:
                raise _invalid()
            breakdown.append({"product": product, "quantity": quantities[product], "cost": fee})
            total += fee
        if total > MAX_CENTS:
            raise _invalid()
        return 200, {"total_cost": total, "country": country, "breakdown": breakdown}

    def list_rules(self, country: str | None = None) -> tuple[int, list[dict]]:
        rows = [tier.as_row(name, product)
                for name in sorted(self._schedules) if country in (None, name)
                for product in sorted(self._schedules[name])
                for tier in self._schedules[name][product].tiers]
        return 200, rows


if __name__ == "__main__":
    service = ShippingService()
    service.register_rules(["NL,kettle,incremental,1,4,300", "NL,kettle,fixed,5,9,900", "NL,kettle,incremental,10,*,150"])
    print(service.calculate_shipping("NL", ["kettle,6", "kettle,5"]))  # 4*300 + 900 + 2*150 = 2400
```
