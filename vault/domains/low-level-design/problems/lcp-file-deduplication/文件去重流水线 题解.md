# 文件去重流水线（File Deduplication）

**这个项目要做什么。** 递归扫描、按大小与抽样预筛、流式 SHA-256、逐字节确认防碰撞、并发与 worker 上限、文件系统错误隔离、软硬链接、确定性分组。

## 设计要点

文件去重流水线（ArchiveSweep）的参考解。

设计五句话：
1. 发现：一个显式栈走遍所有根路径，用 lstat 判类型，不跟随软链接；路径身份是 str(Path(p))，每个身份只处理一次。
2. 逐级缩小候选：先按大小分组，再比首尾抽样，最后算流式全量摘要；每一级只处理上一级留下的同组文件。
3. 抽样与全量哈希共用一个 max_workers 大小的线程池，一组抽样全部回来就立刻提交这一组的全量哈希，两级流水线重叠。
4. 摘要相等不等于内容相等：每个摘要桶再用有界内存的逐字节比较拆成内容完全相同的等价类。
5. 每个文件的失败只记一条问题（以路径为键，后写覆盖先写），不影响别的文件；最后统一排序，结果与调度顺序无关。

## 考点与卡片

- **路径身份是 str(Path(p))：./a//b/ 与 a/b 同一个，a/../a 是另一个**：[[lcp-file-deduplication-contract-rules]]
- **同一路径身份只处理一次，根路径重叠、重复输入也一样**：[[lcp-file-deduplication-contract-rules]]
- **输入可能只能迭代一次：只迭代一次，先收成栈再处理**：[[lcp-file-deduplication-contract-rules]]
- **发现用 lstat 而不是 stat：不跟随软链接，大小也在这里取到**：[[lcp-file-deduplication-contract-rules]]
- **软链接（含断链、目录链接）记 FileIssue，不当文件也不走进去**：[[lcp-file-deduplication-contract-rules]]
- **特殊文件（管道、套接字）记问题，而且绝不打开它**：[[lcp-file-deduplication-contract-rules]]
- **缺失路径、遍历出错的目录只影响自己，别的文件照常处理**：[[lcp-file-deduplication-contract-rules]]
- **FileIssue.error 必须含底层异常的消息**：[[lcp-file-deduplication-contract-rules]]
- **files_considered 是发现的普通文件数，后面的阶段失败也照样计入**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **空输入是合法的空报告；max_workers 与 sample_size 都必须为正**：[[lcp-file-deduplication-contract-rules]]
- **按发现时的大小分组：大小唯一的文件不进抽样与全量，也不预检查可读性**：[[lcp-file-deduplication-contract-rules]]
- **抽样头部读 min(sample_size, size)，尾部从 max(head, size - sample_size) 起**：[[lcp-file-deduplication-contract-rules]]
- **抽样最多读 2 × sample_size；小于 sample_size 的文件只有头部一段**：[[lcp-file-deduplication-contract-rules]]
- **抽样钩子返回（摘要，实际读到的字节数），不是请求的字节数**：[[lcp-file-deduplication-contract-rules]]
- **只有大小相同且抽样摘要相同的文件才进入全量哈希**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **全量哈希按块流式读，内存与文件大小无关**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-reflection-storage-bounds]]
- **摘要相同不等于内容相同：用逐字节比较确认，哪怕 SHA-256 几乎不会碰撞**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **一个摘要桶里可以有多组不同内容：按代表比较拆成等价类，各自成组**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **逐字节比较一次读一块、遇到第一处不同就停，同一时刻内存里只有两块**：[[lcp-file-deduplication-contract-rules]]
- **canonical 是字符串最小的路径，重复项升序，组按 canonical 排序**：[[lcp-file-deduplication-contract-rules]]
- **排序按 str 不按 Path：Path 比较路径分量，a/b 会排在 a.txt 前面**：[[lcp-file-deduplication-contract-rules]]
- **问题按 (path, error) 排序；同一路径的重复问题只留最近一条**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **失败隔离：一个文件失败，别的重复组照常返回**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **逐字节比较失败记在出错的那一边；代表读不了就由下一个成员接任**：[[lcp-file-deduplication-contract-rules]]
- **bytes_hashed 只累加成功返回的抽样与全量钩子；抛异常记 0，逐字节比较读的不计**：[[lcp-file-deduplication-contract-rules]]、[[lcp-file-deduplication-state-and-invariant]]
- **抽样与全量共用一个线程池，同时活动的钩子不超过 max_workers**：[[lcp-file-deduplication-state-and-invariant]]、[[lcp-file-deduplication-reflection-storage-bounds]]
- **满 max_workers 个钩子互相阻塞时仍要能同时运行：一个池，不多不少**：[[lcp-file-deduplication-state-and-invariant]]、[[lcp-file-deduplication-reflection-storage-bounds]]
- **按批流水线：一批抽样全部回来就提交这批的全量，不做整体分段**：[[lcp-file-deduplication-state-and-invariant]]
- **单写者：工作线程只返回值，协调线程独占汇总状态，所以没有锁**：[[lcp-file-deduplication-state-and-invariant]]
- **在途任务无界：一次提交全部候选，要用信号量把已提交未完成的限制住**：[[lcp-file-deduplication-state-and-invariant]]、[[lcp-file-deduplication-reflection-storage-bounds]]
- **文件在扫描中变化：读前读后各 lstat，比较（大小，mtime_ns，inode）**：[[lcp-file-deduplication-reflection-changing-files]]
- **filecmp.cmp 按（大小，修改时间）缓存结论，同修改时间的改写会得到过期的相同**：[[lcp-file-deduplication-reflection-changing-files]]
- **硬链接是两个路径一个 inode：会成组，但节省量按（设备，inode）的个数算**：[[lcp-file-deduplication-state-and-invariant]]
- **worker 数跟着存储的并发能力走：固态盘看核数，网络文件系统与对象存储看服务端**：[[lcp-file-deduplication-reflection-storage-bounds]]
- **同时打开的文件数是 max(max_workers, 2)：每个钩子一个，比较阶段两个**：[[lcp-file-deduplication-reflection-storage-bounds]]
- **测试人造碰撞：让钩子对所有文件返回同一个摘要，断言仍然按字节分组**：[[lcp-file-deduplication-contract-rules]]
- **测试并发上限：屏障让前 max_workers 个钩子同时在场，断言峰值恰好等于它**：[[lcp-file-deduplication-reflection-storage-bounds]]
- **与暴力解对拍：随机目录树、固定种子、worker 数取 1 和 5，报告必须相同**：[[lcp-file-deduplication-state-and-invariant]]
- **交给智能体之前把十四条规则列成清单，逐条对照，先写会失败的测试**：[[lcp-file-deduplication-contract-rules]]
- **改坏实现检验测试：把尾部起点改成重叠、信任摘要，看测试是否变红**：[[lcp-file-deduplication-contract-rules]]

## 参考解

```python
from __future__ import annotations

import hashlib
import os
import queue
import stat
from collections import defaultdict
from concurrent.futures import Future, ThreadPoolExecutor
from contextlib import ExitStack
from dataclasses import dataclass, field
from functools import partial
from pathlib import Path
from typing import BinaryIO, Iterable

CHUNK = 1 << 20  # 每次最多读 1 MiB：内存上界与文件大小无关


@dataclass(frozen=True)
class DuplicateGroup:
    canonical: str
    duplicates: tuple[str, ...]
    size: int


@dataclass(frozen=True)
class FileIssue:
    path: str
    error: str


@dataclass(frozen=True)
class ScanReport:
    groups: tuple[DuplicateGroup, ...]
    issues: tuple[FileIssue, ...]
    files_considered: int
    bytes_hashed: int


def describe(exc: BaseException) -> str:
    """问题文本：异常类型加底层消息，消息必须保留。"""
    return f"{type(exc).__name__}: {exc}"


class _ReadFailure(Exception):
    """逐字节比较时某个文件打不开或读不动；path 指出是哪一个，问题记在它头上。"""

    def __init__(self, path: Path, cause: Exception) -> None:
        super().__init__(describe(cause))
        self.path = path


@dataclass
class _Batch:
    """同一大小（或同一抽样摘要）的一批文件：全部回来之后才知道哪些桶值得进下一级。"""

    stage: str  # "sample" 或 "full"
    size: int
    left: int
    buckets: dict[str, list[Path]] = field(default_factory=lambda: defaultdict(list))


def _feed(stream: BinaryIO, digest: "hashlib._Hash", limit: int | None = None) -> int:
    """把流按块喂给摘要，最多 limit 字节（None 表示读到尾）；返回实际读到的字节数。"""
    total = 0
    while limit is None or total < limit:
        want = CHUNK if limit is None else min(CHUNK, limit - total)
        chunk = stream.read(want)
        if not chunk:
            break
        digest.update(chunk)
        total += len(chunk)
    return total


def _open(path: Path) -> BinaryIO:
    try:
        return open(path, "rb")
    except Exception as exc:
        raise _ReadFailure(path, exc) from exc


def _read(stream: BinaryIO, path: Path) -> bytes:
    try:
        return stream.read(CHUNK)
    except Exception as exc:
        raise _ReadFailure(path, exc) from exc


def _same_content(a: Path, b: Path) -> bool:
    """逐块比较两个文件，遇到第一处不同就停；任何时刻内存里只有两块。"""
    with ExitStack() as stack:
        left = stack.enter_context(_open(a))
        right = stack.enter_context(_open(b))
        while True:
            chunk_a, chunk_b = _read(left, a), _read(right, b)
            if chunk_a != chunk_b:
                return False
            if not chunk_a:
                return True


def _place(path: Path, classes: list[list[Path]], issues: dict[str, str]) -> None:
    """把 path 放进第一个与它字节相同的等价类；每个类只和它的代表（第一个成员）比较。"""
    for members in classes:
        while members:
            try:
                same = _same_content(members[0], path)
            except _ReadFailure as failure:
                issues[str(failure.path)] = str(failure)
                if failure.path == path:
                    return  # 新来的文件读不了：丢掉它，别的类不必再比
                members.pop(0)  # 代表读不了：从类里去掉，下一个成员接任代表
                continue
            if same:
                members.append(path)
                return
            break  # 内容不同：试下一个类
    classes.append([path])


class FileDeduplicator:
    def __init__(self, max_workers: int = 4, sample_size: int = 4096):
        if max_workers < 1 or sample_size < 1:
            raise ValueError("limits must be positive")
        self.max_workers = max_workers
        self.sample_size = sample_size

    # ---- 两个测试钩子：各自只读文件、只返回（摘要，读到的字节数） ----

    def _full_digest(self, path: Path) -> tuple[str, int]:
        """流式全量 SHA-256：每次读一块，内存与文件大小无关。"""
        digest = hashlib.sha256()
        with open(path, "rb") as stream:
            nread = _feed(stream, digest)
        return digest.hexdigest(), nread

    def _sample_fingerprint(self, path: Path, size: int) -> tuple[str, int]:
        """开头最多 sample_size 字节，加结尾最多 sample_size 字节；两段不重叠。"""
        head = min(self.sample_size, size)
        tail_start = max(head, size - self.sample_size)
        digest = hashlib.sha256()
        with open(path, "rb") as stream:
            nread = _feed(stream, digest, head)
            if tail_start < size:
                stream.seek(tail_start)
                nread += _feed(stream, digest, size - tail_start)
        return digest.hexdigest(), nread

    # ---- 流水线 ----

    def scan(self, paths: Iterable[str | Path]) -> ScanReport:
        issues: dict[str, str] = {}
        files = self._discover(paths, issues)
        by_size: dict[int, list[Path]] = defaultdict(list)
        for name, size in files.items():
            by_size[size].append(Path(name))
        repeated = {size: group for size, group in by_size.items() if len(group) > 1}
        candidates, hashed = self._narrow(repeated, issues)
        groups = [g for size, bucket in candidates for g in self._verify(size, bucket, issues)]
        groups.sort(key=lambda g: g.canonical)
        ordered = sorted((FileIssue(p, e) for p, e in issues.items()), key=lambda i: (i.path, i.error))
        return ScanReport(tuple(groups), tuple(ordered), len(files), hashed)

    def _discover(self, roots: Iterable[str | Path], issues: dict[str, str]) -> dict[str, int]:
        """返回 {路径身份: 大小}，只含普通文件；根和子项用同一套处理，所以软链接、缺失、特殊文件的规则只写一遍。"""
        files: dict[str, int] = {}
        seen: set[str] = set()
        stack = [Path(root) for root in roots]  # 输入只迭代这一次
        while stack:
            path = stack.pop()
            key = str(path)
            if key in seen:
                continue
            seen.add(key)
            try:
                info = os.lstat(path)  # lstat：不跟随软链接，大小也在这里一并取到
            except Exception as exc:
                issues[key] = describe(exc)
                continue
            if stat.S_ISREG(info.st_mode):
                files[key] = info.st_size
            elif stat.S_ISDIR(info.st_mode):
                try:
                    stack.extend(path / name for name in os.listdir(path))
                except Exception as exc:
                    issues[key] = describe(exc)
            elif stat.S_ISLNK(info.st_mode):
                issues[key] = "symbolic link is not followed"
            else:
                issues[key] = "not a regular file (special file)"
        return files

    def _narrow(
        self, repeated: dict[int, list[Path]], issues: dict[str, str]
    ) -> tuple[list[tuple[int, list[Path]]], int]:
        """抽样、全量哈希两级共用一个线程池；返回（大小, 摘要都相同的路径）候选桶和 bytes_hashed。"""
        survivors: list[tuple[int, list[Path]]] = []
        hashed = 0
        in_flight = 0
        done: queue.SimpleQueue[tuple[Future[tuple[str, int]], _Batch, Path]] = queue.SimpleQueue()
        with ThreadPoolExecutor(max_workers=self.max_workers) as pool:

            def launch(stage: str, size: int, paths: list[Path]) -> None:
                nonlocal in_flight
                batch = _Batch(stage, size, left=len(paths))
                for path in paths:
                    if stage == "sample":
                        job = partial(self._sample_fingerprint, path, size)
                    else:
                        job = partial(self._full_digest, path)
                    future = pool.submit(job)
                    in_flight += 1
                    future.add_done_callback(lambda f, b=batch, p=path: done.put((f, b, p)))

            for size, paths in repeated.items():
                launch("sample", size, paths)
            while in_flight:  # 只有这个线程改 hashed、issues、桶，所以不需要锁
                future, batch, path = done.get()
                in_flight -= 1
                try:
                    digest, nread = future.result()
                except Exception as exc:
                    issues[str(path)] = describe(exc)  # 抛异常的钩子不计字节
                else:
                    hashed += nread
                    batch.buckets[digest].append(path)
                batch.left -= 1
                if batch.left:
                    continue
                for bucket in batch.buckets.values():
                    if len(bucket) < 2:
                        continue  # 唯一的摘要：不可能重复，不再读它
                    if batch.stage == "sample":
                        launch("full", batch.size, bucket)
                    else:
                        survivors.append((batch.size, bucket))
        return survivors, hashed

    def _verify(self, size: int, bucket: list[Path], issues: dict[str, str]) -> list[DuplicateGroup]:
        """把一个摘要桶按字节拆成等价类；代表是最小路径，所以结果与完成顺序无关。"""
        classes: list[list[Path]] = []
        for path in sorted(bucket, key=str):
            _place(path, classes, issues)
        groups = []
        for members in classes:
            if len(members) > 1:
                names = sorted(str(p) for p in members)
                groups.append(DuplicateGroup(names[0], tuple(names[1:]), size))
        return groups


if __name__ == "__main__":
    import sys
    import tempfile

    with tempfile.TemporaryDirectory() as tmp:
        root = Path(tmp)
        for name, data in {"a.txt": b"same", "c.txt": b"same", "b.txt": b"other!", "d.txt": b"other!"}.items():
            (root / name).write_bytes(data)
        report = FileDeduplicator().scan([root, root / "missing.txt", *map(Path, sys.argv[1:])])
        for group in report.groups:
            print(group.canonical, "->", group.duplicates)
        print(report.issues, report.files_considered, report.bytes_hashed)
```
