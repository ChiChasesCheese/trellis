# 评论与回复（Comments & Replies）

**这个项目要做什么。** 两级评论数据模型、输入与资源关系校验、评论与回复各自自增 ID、保持创建顺序、返回值不可篡改内部状态、并发安全。

## 设计要点

评论与回复（Comments & Replies）：帖子 → 评论 → 回复两级结构的进程内服务。
设计：每个帖子一个 `Thread`，评论按提交顺序存在以评论 ID 为键的 dict 里，状态按帖子天然隔离；
回复是不可变的 `Reply`，挂在所属评论的列表里；评论 ID 与回复 ID 是两条独立的全局递增序列；
文本校验与帖子检查在锁外，锁里只做"读时钟 → 分配 ID → 追加"这一小段，ID 在所有检查之后才分配；
对外只给每次新建的字典与列表（快照），内部对象永不出门；读取也在锁里，看到的是某一时刻的整串。

## 考点与卡片

- **结构只有两层：帖子 → 评论 → 回复，回复下面没有回复，回复不带 parent 字段**：[[lcp-comments-replies-state-and-invariant]]
- **三个返回形状固定：评论六个键含空的 replies，回复六个键含 comment_id 但没有 replies**：[[lcp-comments-replies-contract-rules]]
- **文本合法的标准：必须是 str，且 strip 之后非空；None、数字、列表、字节串、空白串都是 ValidationError**：[[lcp-comments-replies-contract-rules]]
- **strip 只用来判空：存下来、返回的都是调用方给的原值，首尾空白保留**：[[lcp-comments-replies-contract-rules]]
- **isinstance 检查要放在 strip 之前：对 None 和数字调用 strip 会抛 AttributeError，不是合同要的错误**
- **检查顺序固定：先文本，再帖子，加回复时最后才查评论**：[[lcp-comments-replies-contract-rules]]
- **帖子不存在、评论不存在、评论属于别的帖子，都是 NotFoundError；文本不合法才是 ValidationError**：[[lcp-comments-replies-contract-rules]]
- **布尔值不是 ID：True 等于 1，不排除就会悄悄命中评论 1，所以 ID 检查要单独排除 bool**
- **评论 ID 与回复 ID 是两条独立的序列，各自从 1 开始，各用一个 itertools.count**：[[lcp-comments-replies-contract-rules]]、[[lcp-comments-replies-state-and-invariant]]
- **ID 是全站递增，不按帖子分：帖子 10 的评论占了 1，帖子 20 的下一条是 2**：[[lcp-comments-replies-contract-rules]]
- **失败的调用不消耗 ID：取号放在所有可能失败的步骤之后，并且在锁里**：[[lcp-comments-replies-contract-rules]]、[[lcp-comments-replies-reflection-lock-scope]]
- **顺序就是提交顺序：评论和每条评论下的回复都按成功提交的先后返回，后提交的 ID 更大**：[[lcp-comments-replies-contract-rules]]
- **不按 created_at 排序：时钟可能回拨，两次调用可能同一时刻；它只是响应带出的元数据**：[[lcp-comments-replies-contract-rules]]
- **created_at 以秒为单位、是浮点数：默认用 time.time，测试里注入假时钟，不用 sleep**
- **没有评论的帖子返回 []，不存在的帖子抛 NotFoundError；空结果是每次新建的列表，空帖子不预建 Thread**：[[lcp-comments-replies-reflection-snapshot-reads]]、[[lcp-comments-replies-state-and-invariant]]
- **每个帖子一个 Thread：评论只存在自己帖子里，用别的帖子找它就是没找到，归属由结构保证**：[[lcp-comments-replies-state-and-invariant]]
- **评论放在 dict[评论 ID → Comment] 里：加回复是两次 O(1) 查找，不扫描全站**：[[lcp-comments-replies-state-and-invariant]]
- **字典的插入顺序等于提交顺序等于 ID 升序：一个结构既按 ID 查、又按顺序遍历**：[[lcp-comments-replies-state-and-invariant]]
- **读取的代价与返回的评论加回复总数成正比：只遍历这个帖子自己的 Thread**：[[lcp-comments-replies-state-and-invariant]]
- **Reply 设成 frozen 数据类：提交后不再变，快照可以共享它；Comment 只在末尾追加回复**：[[lcp-comments-replies-state-and-invariant]]、[[lcp-comments-replies-reflection-snapshot-reads]]
- **get(...) or Thread() 是陷阱：对象一旦为假就悄悄丢数据，要写 is None**
- **一把 threading.Lock 罩住读时钟、分配 ID、追加这一整段读—改—写**：[[lcp-comments-replies-reflection-lock-scope]]
- **itertools.count 的 next 原子，不等于顺序一致：A 取 5、B 取 6、B 先追加，列表顺序就和 ID 反了**：[[lcp-comments-replies-reflection-lock-scope]]
- **查评论再追加回复是一整段：这两步之间不能被别的线程插入**：[[lcp-comments-replies-reflection-lock-scope]]
- **文本校验与帖子检查放在锁外：持锁时不调外部对象，帖子不会被删除所以安全；能删帖就要改**：[[lcp-comments-replies-reflection-lock-scope]]
- **全局一把锁够用：临界区只有几次字典操作，GIL 下分片锁买不到并行**：[[lcp-comments-replies-reflection-lock-scope]]
- **每帖一把锁的代价：ID 序列仍是全站的，还要再加一把全局锁，锁字典自己的创建也要同步**：[[lcp-comments-replies-reflection-lock-scope]]
- **GIL 保护的是解释器，不是你的不变量：检查再追加是多条字节码，线程可以插在中间**：[[lcp-comments-replies-reflection-lock-scope]]
- **返回快照：每次新建字典与列表，调用方怎么改返回值都伤不到服务内部**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **直接返回内部列表的后果：调用方改内部、遍历中被改、两个调用方共享同一份**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **值只有字符串和数字，一层拷贝就够；n 条评论、m 条回复，一次读取新建 1 + 2n + m 个容器**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **快照要在锁里生成：否则评论是旧的、回复是新的，同一次读里出现两个时刻**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **add_comment 返回的 replies 是新的空列表：之后再加回复，手里的那份不会变长**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **并发测试用屏障让线程同时起跑，断言不变量：ID 恰好是 1 到 N、读到的评论 ID 是连续前缀**
- **GIL 下没有锁的读也常常侥幸通过：缩小线程切换间隔把交错放大，并靠读代码核对锁的范围**
- **多实例部署：进程内的锁和计数器管不到别的进程，ID 改由数据库序列生成，唯一递增但可能有空洞**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **多实例下的快照：一次查询或一个只读事务给出某一时刻；读从库要处理读自己的写**：[[lcp-comments-replies-reflection-snapshot-reads]]
- **给智能体先给规则和数字例子，让它先复述最容易漏的几条，一次只给一个失败的测试**
- **智能体的典型错误：返回内部对象、锁只包计数器、按时间排序；锁的范围和快照自己核对**
- **不接受把失败的测试改成通过：先判断是代码错还是测试错，合同里的例子不能改**

## 参考解

```python
from __future__ import annotations

import itertools
import threading
import time
from collections.abc import Callable
from dataclasses import dataclass, field
from typing import Protocol, TypedDict, TypeGuard

Clock = Callable[[], float]
"""时钟：返回以秒为单位的浮点时间；生产用 `time.time`，测试注入假时钟。"""


class NotFoundError(Exception):
    """帖子或评论不存在（评论存在但属于别的帖子，也算不存在）。"""


class ValidationError(Exception):
    """`user_id` 或 `content` 不是字符串，或去掉首尾空白后为空。"""


class PostStore(Protocol):
    """服务只需要帖子仓库回答一个问题：这个帖子在不在。"""

    def exists(self, post_id: int) -> bool: ...


class ReplyDict(TypedDict):
    id: int
    post_id: int
    comment_id: int
    user_id: str
    content: str
    created_at: float


class CommentDict(TypedDict):
    id: int
    post_id: int
    user_id: str
    content: str
    created_at: float
    replies: list[ReplyDict]


def _require_text(value: object, field_name: str) -> None:
    """必须是字符串且去空白后非空；`strip` 只用来判空，存进去的仍是原值。"""
    if not isinstance(value, str) or not value.strip():
        raise ValidationError(f"{field_name} must be a string with at least one non-whitespace character")


def _is_id(value: object) -> TypeGuard[int]:
    """ID 是真正的整数；`True` 虽然等于 1，却不是 ID。"""
    return isinstance(value, int) and not isinstance(value, bool)


@dataclass(frozen=True, slots=True)
class Reply:
    """一条回复。不可变：一旦提交就不会再变，所以快照可以直接共享它。"""

    id: int
    post_id: int
    comment_id: int
    user_id: str
    content: str
    created_at: float

    def to_dict(self) -> ReplyDict:
        return {
            "id": self.id,
            "post_id": self.post_id,
            "comment_id": self.comment_id,
            "user_id": self.user_id,
            "content": self.content,
            "created_at": self.created_at,
        }


@dataclass(slots=True)
class Comment:
    """一条评论和它的回复（按提交顺序）。唯一会变的是 `replies`，且只会在末尾追加。"""

    id: int
    post_id: int
    user_id: str
    content: str
    created_at: float
    replies: list[Reply] = field(default_factory=list)

    def to_dict(self) -> CommentDict:
        """每次都新建字典和列表；值只有字符串与数字，一层拷贝就够。"""
        return {
            "id": self.id,
            "post_id": self.post_id,
            "user_id": self.user_id,
            "content": self.content,
            "created_at": self.created_at,
            "replies": [reply.to_dict() for reply in self.replies],
        }


class Thread:
    """一个帖子下的全部评论。不变量：dict 的插入顺序就是提交顺序，也就是 ID 升序。"""

    def __init__(self) -> None:
        self._comments: dict[int, Comment] = {}

    def append(self, comment: Comment) -> None:
        self._comments[comment.id] = comment

    def find(self, comment_id: object) -> Comment | None:
        """按 ID 直接取，不扫描；别的帖子的评论不在这个 dict 里，所以天然取不到。"""
        return self._comments.get(comment_id) if _is_id(comment_id) else None

    def snapshot(self) -> list[CommentDict]:
        return [comment.to_dict() for comment in self._comments.values()]


class CommentService:
    """评论服务。一把锁保护所有可变状态；公开方法返回的都是新对象。"""

    def __init__(self, post_store: PostStore, clock: Clock = time.time) -> None:
        self.post_store = post_store
        self._clock = clock
        self._lock = threading.Lock()
        self._threads: dict[int, Thread] = {}
        self._comment_ids = itertools.count(1)
        self._reply_ids = itertools.count(1)

    def add_comment(self, post_id: int, user_id: str, content: str) -> CommentDict:
        """先校验文本，再查帖子；都通过之后才进锁、读时钟、分配 ID。"""
        _require_text(user_id, "user_id")
        _require_text(content, "content")
        self._require_post(post_id)
        with self._lock:
            now = self._clock()
            comment = Comment(next(self._comment_ids), post_id, user_id, content, now)
            thread = self._threads.get(post_id)
            if thread is None:
                thread = self._threads[post_id] = Thread()
            thread.append(comment)
            return comment.to_dict()

    def add_reply(self, post_id: int, comment_id: int, user_id: str, content: str) -> ReplyDict:
        """顺序固定：文本 → 帖子 → 评论（必须在这个帖子下）。评论查不到就不分配回复 ID。"""
        _require_text(user_id, "user_id")
        _require_text(content, "content")
        self._require_post(post_id)
        with self._lock:
            thread = self._threads.get(post_id)
            comment = thread.find(comment_id) if thread is not None else None
            if comment is None:
                raise NotFoundError(f"comment {comment_id!r} not found under post {post_id!r}")
            now = self._clock()
            reply = Reply(next(self._reply_ids), post_id, comment.id, user_id, content, now)
            comment.replies.append(reply)
            return reply.to_dict()

    def get_comments(self, post_id: int) -> list[CommentDict]:
        """整串快照在锁里生成：不会看到"回复已经在、评论却还没有"的半截状态。"""
        self._require_post(post_id)
        with self._lock:
            thread = self._threads.get(post_id)
            return thread.snapshot() if thread is not None else []

    def _require_post(self, post_id: object) -> None:
        if not _is_id(post_id) or not self.post_store.exists(post_id):
            raise NotFoundError(f"post {post_id!r} not found")


class _DemoPosts:
    def exists(self, post_id: int) -> bool:
        return post_id in (10, 20)


if __name__ == "__main__":
    service = CommentService(_DemoPosts())
    first = service.add_comment(10, "u1", "Hello Leet")
    service.add_reply(10, first["id"], "u2", "Hi Code")
    for item in service.get_comments(10):
        print(item["id"], item["content"], [r["content"] for r in item["replies"]])
```
