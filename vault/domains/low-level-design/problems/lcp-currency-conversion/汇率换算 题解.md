# 汇率换算（Currency Conversion）

**这个项目要做什么。** 批量汇率报价解析与整批原子登记、直达汇率、最多一次中转的全部路线、所有简单路径中的最优路线、浮点容差与确定性平局、错误优先级。

## 设计要点

汇率换算服务：批量报价整批登记，三种路线查询。

设计（五行）：
1. `parse_quotes` 把整段文本先解析成 `Quote` 列表；任何一条不合法就抛 400，此时服务的状态还没被碰过。
2. `RateBook` 是不可变的汇率簿：`extend` 返回一本新簿子，登记 = 解析成功、合并成功之后一次赋值。
3. 返回值每次都新建字典和列表（浮点数本身不可变），调用方改返回值碰不到内部状态。
4. 路线用递归深度优先枚举所有简单路径（货币至多 8 种，最多 1957 条），只在 `best_path` 里选一条。
5. 错误优先级固定：先格式（400），再货币是否出现过（404 currency_not_found），最后有没有路（404 route_not_found）。

## 考点与卡片

- **登记入参只接受非空字符串：None、数字、字节串、空串都是 400 invalid_input**：[[lcp-currency-conversion-contract-rules]]
- **每条记录恰好三段：空记录、空字段、多余冒号、首尾逗号都非法**：[[lcp-currency-conversion-contract-rules]]
- **字段不去空白、不改大小写：带空格或小写的货币码、汇率都是非法**：[[lcp-currency-conversion-contract-rules]]
- **货币码是 3 到 5 个 ASCII 大写字母，自报价（FROM 等于 TO）非法**：[[lcp-currency-conversion-contract-rules]]
- **用 fullmatch 匹配整串：`$` 会放过末尾的换行**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **汇率先过语法再交给 float()：float() 比语法宽，会放过下划线、空白、nan、inf 和 Unicode 数字**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **合法的汇率写法：1、1.、.5、+2.5e-1；非法：空白、十六进制、下划线、nan、inf**：[[lcp-currency-conversion-contract-rules]]
- **汇率区间 [1e-12, 1e12] 含两端，看的是解析后的 binary64 值；1e999 解析成 inf、1e-999 解析成 0，都在区间外**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **不做货币舍入，也不用对数近似：返回值就是边上的原始浮点数或乘积**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **累计图里的货币至多 8 种：边的起点和终点都算，跨调用累计**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **一批报价让货币数超过 8 种：整批非法，已有数据不变**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-atomic-and-snapshots]]
- **报价有方向：登记一个方向不会产生反方向，反向查询是 route_not_found**：[[lcp-currency-conversion-contract-rules]]
- **同一有向对重复登记，后写的覆盖先写的，跨调用也一样**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **成功返回 201 和 registered_count：数的是记录条数，重复的也算**：[[lcp-currency-conversion-contract-rules]]
- **整批原子：先把整段解析完，再合并成新簿子，最后一次赋值才生效**：[[lcp-currency-conversion-state-and-invariant]]、[[lcp-currency-conversion-reflection-atomic-and-snapshots]]
- **不可变汇率簿：extend 返回新对象，失败时没有改过旧对象，所以不需要回滚**：[[lcp-currency-conversion-state-and-invariant]]、[[lcp-currency-conversion-reflection-atomic-and-snapshots]]
- **失败的登记不留痕：同批里更早的覆盖和新出现的货币都不会漏进去**：[[lcp-currency-conversion-reflection-atomic-and-snapshots]]
- **查询的错误优先级：先两个码的格式（400），再是否出现过（404 currency_not_found），最后才找路线（404 route_not_found）**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **格式错误先于未知货币：另一个码是未知的，也先报 400**：[[lcp-currency-conversion-contract-rules]]
- **只作过报价终点的货币也算出现过：它能被查询，没有出边就是 route_not_found**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-state-and-invariant]]
- **两个码相同且出现过：直达 rate 为 1，单次中转 rates 为 [1]，最优 best_rate 为 1、path 为 [码]；没出现过仍是 currency_not_found**：[[lcp-currency-conversion-contract-rules]]
- **直达查询返回登记的那条边，不看别的路线；没有这条边是 route_not_found**：[[lcp-currency-conversion-contract-rules]]
- **单次中转：直达边加每个 S→M→T 的两段乘积，相同数值保留，升序；更长的路线不算**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **最优路线枚举所有简单有向路径：路径里已有的货币不再进入，所以环走不起来，走到 T 也就停了**：[[lcp-currency-conversion-state-and-invariant]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **路径乘积从 1 开始，从左到右依次连乘，和参考实现的浮点结果一致**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **合格路径：最大乘积 M 减去它的乘积不超过 1e-5，只用绝对容差**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **合格性以全局最大 M 为基准，不以已选中的路径为基准：否则容差会沿着路径链漂移**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **合格路径里先选边数最少的，再选整条货币序列字典序最小的：按代码逐个比较，不拼成字符串**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **返回被选中路径自己的乘积，它可能略小于 M，不要换成 M**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **为什么需要容差：0.1×3 得 0.30000000000000004，比直接登记的 0.3 大一点点，精确比较会选错路径**：[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **八种货币下完全图的 A 到 H 有 1957 条简单路径，毫秒级；十种就超过十万条，十二种近千万条**：[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **列表按起点、再按终点排序；None 列出全部；只作终点的货币返回空列表**：[[lcp-currency-conversion-contract-rules]]
- **列表的过滤码走同样的两层检查：格式错 400，没出现过 404**：[[lcp-currency-conversion-contract-rules]]
- **返回值每次新建字典和列表：改返回值不影响服务，之后的登记也不改变已拿到的结果；浮点数不可变，不需要 deepcopy**：[[lcp-currency-conversion-reflection-atomic-and-snapshots]]
- **状态存在实例上，不在类或模块上：不同服务实例互不影响**：[[lcp-currency-conversion-state-and-invariant]]
- **顺序调用不等于线程安全：两个并发登记各自基于旧簿子，后赋值的覆盖先赋值的，丢一批报价；要加锁包住读、合并、赋值**：[[lcp-currency-conversion-reflection-atomic-and-snapshots]]
- **规模变大或接实时行情：给簿子加版本号做快照读；查询缓存按版本失效；最优路线改成带剪枝的搜索或预计算，语义要重新约定（套利环、新鲜度）**：[[lcp-currency-conversion-reflection-atomic-and-snapshots]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **开工前把 README 的每条规则写成测试再让智能体实现；规则里的数字例子是第一批测试**：[[lcp-currency-conversion-contract-rules]]
- **用另一种写法（子集排列穷举）写对照实现，在随机图上和解答对拍，抓住容差、平局与方向的错误**：[[lcp-currency-conversion-reflection-routes-and-tolerance]]
- **容差、平局和错误优先级这些语义决定自己定，写成测试再交给智能体，不让它顺手选一个**：[[lcp-currency-conversion-contract-rules]]、[[lcp-currency-conversion-reflection-routes-and-tolerance]]

## 参考解

```python
from __future__ import annotations

import math
import re
from collections.abc import Iterator, Mapping
from dataclasses import dataclass

MAX_CURRENCIES = 8
RATE_MIN, RATE_MAX = 1e-12, 1e12
TOLERANCE = 1e-5  # 最优路线的绝对容差：以全局最大乘积为基准

_CODE = re.compile(r"[A-Z]{3,5}")  # fullmatch：`$` 会放过末尾的换行，fullmatch 不会
_RATE = re.compile(r"[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(?:[eE][+-]?[0-9]+)?")


class ServiceError(Exception):
    """对外的错误：status 是 HTTP 状态码，code 是稳定的字符串。"""

    def __init__(self, status: int, code: str) -> None:
        self.status, self.code = status, code
        super().__init__(code)


def _invalid() -> ServiceError:
    return ServiceError(400, "invalid_input")


@dataclass(frozen=True, slots=True)
class Quote:
    """一条有向报价：1 单位 source 换 rate 单位 target。"""

    source: str
    target: str
    rate: float


def is_code(value: object) -> bool:
    return isinstance(value, str) and _CODE.fullmatch(value) is not None


def parse_quote(record: str) -> Quote:
    """一条记录恰好三段；货币 3–5 位大写；汇率按语法匹配后再看解析出的 binary64 值。"""
    parts = record.split(":")
    if len(parts) != 3:
        raise _invalid()
    source, target, token = parts
    if not (is_code(source) and is_code(target)) or source == target:
        raise _invalid()
    if _RATE.fullmatch(token) is None:
        raise _invalid()
    rate = float(token)  # 最近的 binary64；语法已保证不会抛错
    if not (math.isfinite(rate) and RATE_MIN <= rate <= RATE_MAX):
        raise _invalid()
    return Quote(source, target, rate)


def parse_quotes(stream: object) -> list[Quote]:
    """整段先解析完：空串、空记录、非字符串都是 400。这一步不碰任何服务状态。"""
    if not isinstance(stream, str) or stream == "":
        raise _invalid()
    return [parse_quote(record) for record in stream.split(",")]


class RateBook:
    """不可变的汇率簿。不变量：边的端点至多 MAX_CURRENCIES 种；构造之后不再改变。"""

    def __init__(self, rates: Mapping[tuple[str, str], float] | None = None) -> None:
        self._rates = dict(rates or {})
        self._out: dict[str, dict[str, float]] = {}
        for (source, target), rate in self._rates.items():
            self._out.setdefault(source, {})[target] = rate
        if len(self.currencies) > MAX_CURRENCIES:
            raise _invalid()

    @property
    def currencies(self) -> frozenset[str]:
        """出现过的货币：边的起点和终点都算（只作终点的也算）。"""
        return frozenset(c for pair in self._rates for c in pair)

    def extend(self, quotes: list[Quote]) -> RateBook:
        """合并一批报价，返回新簿子；后面的同向报价覆盖前面的。原簿子不变，所以失败时无需回滚。"""
        merged = dict(self._rates)
        for quote in quotes:
            merged[(quote.source, quote.target)] = quote.rate
        return RateBook(merged)

    def rate(self, source: str, target: str) -> float | None:
        return self._rates.get((source, target))

    def pairs(self, source: str | None = None) -> list[tuple[str, str, float]]:
        """按起点、再按终点排序的所有报价。"""
        return sorted((s, t, r) for (s, t), r in self._rates.items() if source in (None, s))

    def single_hop(self, source: str, target: str) -> list[float]:
        """直达报价，加上每个中转货币 M（M 不是 source 也不是 target）的两段乘积；升序，重复值保留。"""
        rates = []
        direct = self.rate(source, target)
        if direct is not None:
            rates.append(direct)
        for middle, first in self._out.get(source, {}).items():
            second = self.rate(middle, target)
            if second is not None:  # 自报价在登记时就被拒绝，所以 middle 不可能等于 source 或 target
                rates.append(first * second)
        return sorted(rates)

    def routes(self, source: str, target: str) -> Iterator[tuple[list[str], float]]:
        """递归枚举 source 到 target 的所有简单有向路径及其乘积；走到 target 就停，不穿过它。"""

        def walk(path: list[str], product: float) -> Iterator[tuple[list[str], float]]:
            here = path[-1]
            if here == target:
                yield list(path), product
                return
            for nxt, rate in self._out.get(here, {}).items():
                if nxt not in path:  # 简单路径：每种货币至多出现一次，环就走不起来
                    path.append(nxt)
                    yield from walk(path, product * rate)  # 从 1 开始，从左到右连乘
                    path.pop()

        yield from walk([source], 1.0)


def best_path(routes: Iterator[tuple[list[str], float]]) -> tuple[list[str], float] | None:
    """先找全局最大乘积 M；乘积与 M 的差不超过容差的都算合格；合格里选边数最少，再选字典序最小。"""
    found = list(routes)
    if not found:
        return None
    top = max(product for _, product in found)
    eligible = [(path, product) for path, product in found if top - product <= TOLERANCE]
    return min(eligible, key=lambda item: (len(item[0]), item[0]))


class CurrencyExchangeService:
    def __init__(self) -> None:
        self._book = RateBook()

    def register_rates(self, rates_stream: str) -> tuple[int, dict]:
        quotes = parse_quotes(rates_stream)
        self._book = self._book.extend(quotes)  # 解析与合并都成功之后，唯一的一次写入
        return 201, {"registered_count": len(quotes)}

    def _known_pair(self, source: object, target: object) -> None:
        """错误优先级的前两层：两个码的格式都先查，再查有没有出现过。"""
        if not (is_code(source) and is_code(target)):
            raise _invalid()
        known = self._book.currencies
        if source not in known or target not in known:
            raise ServiceError(404, "currency_not_found")

    def get_direct_rate(self, from_currency: str, to_currency: str) -> tuple[int, dict]:
        self._known_pair(from_currency, to_currency)
        rate = 1.0 if from_currency == to_currency else self._book.rate(from_currency, to_currency)
        if rate is None:
            raise ServiceError(404, "route_not_found")
        return 200, {"from": from_currency, "to": to_currency, "rate": rate}

    def get_single_hop_rates(self, from_currency: str, to_currency: str) -> tuple[int, dict]:
        self._known_pair(from_currency, to_currency)
        if from_currency == to_currency:
            rates = [1.0]
        else:
            rates = self._book.single_hop(from_currency, to_currency)
        if not rates:
            raise ServiceError(404, "route_not_found")
        return 200, {"from": from_currency, "to": to_currency, "rates": rates}

    def get_best_rate(self, from_currency: str, to_currency: str) -> tuple[int, dict]:
        self._known_pair(from_currency, to_currency)
        if from_currency == to_currency:
            path, rate = [from_currency], 1.0
        else:
            best = best_path(self._book.routes(from_currency, to_currency))
            if best is None:
                raise ServiceError(404, "route_not_found")
            path, rate = best
        return 200, {"from": from_currency, "to": to_currency, "best_rate": rate, "path": path}

    def list_pairs(self, from_currency: str | None = None) -> tuple[int, list[dict]]:
        if from_currency is not None:
            if not is_code(from_currency):
                raise _invalid()
            if from_currency not in self._book.currencies:
                raise ServiceError(404, "currency_not_found")
        rows = self._book.pairs(from_currency)
        return 200, [{"from_currency": s, "to_currency": t, "rate": r} for s, t, r in rows]


if __name__ == "__main__":
    service = CurrencyExchangeService()
    service.register_rates("SGD:HKD:5.8,HKD:NOK:1.3,SGD:NOK:7.1")
    print(service.get_single_hop_rates("SGD", "NOK"))
    print(service.get_best_rate("SGD", "NOK"))
```
