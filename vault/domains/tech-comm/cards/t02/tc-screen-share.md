## Q
**Screen-share walkthrough · 共享屏幕讲解**｜原则 · 追问

线上 design review，你共享屏幕给大家讲代码和文档。你一边翻文件一边说，参会者不知道你在看哪里，几个人跟丢了。怎么办？

## A
**原则：** 共享屏幕时，你的话必须**为眼睛定位**：先说看哪、再说看什么。屏幕上的内容要**少、大、对准**，让没有你上下文的人也能跟上。

**怎么做：**
1. 开始前：说今天要走的路线，"I'll start with the doc, then show the main code path."
2. 共享前关掉无关的窗口和通知，字号放大。
3. 每次换位置先报位置："Now I'm in `order_service.py`, line 40."
4. 用光标圈出你说的位置，不要一直不动。
5. 滚动前先说，滚动慢。
6. 每隔几分钟停下，问："Is everyone with me?"
7. 有会议记录时，把文档链接放进聊天，不要让人记路径。

**常见错法：**
- **边翻边讲，不报位置。**
- **字号太小，看不清。**
- **跳来跳去：** 想到哪看哪。
- **屏幕上有私密内容：** 共享前先清理。
