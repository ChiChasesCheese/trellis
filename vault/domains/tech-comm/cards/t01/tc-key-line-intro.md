## Q
**Key Line & complex introductions · 复杂开场**｜原则 · 追问

你的文档较长，读者各有不同的预期：有人想先看结论，有人已经为问题着急，有人需要先看背景。开场怎么选顺序？

## A
**原则：** 文档顶点下面的第一层要点叫 **Key Line**。开场的 S、C、Q 不一定按 SCQA 顺序写，可以按读者的状态调整顺序，但内容仍是那几项。文档超过约七段，就在开场里把 Key Line 的要点也列出来。

| 开场 | 顺序 | 适合 |
|---|---|---|
| Standard | Situation → Complication → Answer | 读者平静，需要背景 |
| Direct | Answer → Situation → Complication | 读者忙，想先看结论 |
| Concerned | Complication → Situation → Answer | 读者已经为问题着急 |
| Aggressive | Question → Situation → Complication | 想先抓住读者的好奇心 |

**怎么做：**
1. 先把 S、C、Q、A 写成四句，再选顺序。
2. 开场里不要塞细节，细节属于 Key Line 之下。
3. 每一个 Key Line 要点前，用一小段过渡说明它在回答什么。
4. 有疑问时用 Standard，最稳。

**常见错法：**
- **开场写成大段背景：** Situation 只写读者已经认同的。
- **没有 Complication：** 读者不知道为什么要读。
- **Key Line 与开场的答案对不上。**

**出处：** Minto p. 57–64（Ch.4 Fine Points of Introductions：Basic Structure / Variations）；p. 185–208（Ch.10：Key Line points）
