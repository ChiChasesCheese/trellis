## Q
**Common Chinglish fixes · 常见中式英语**｜惯用说法 · 追问

你的英文面试回答里，母语者听得懂，但有几处听着别扭："I very like this design"、"I have done this last year"、"Open the light"。怎么改成自然的说法？

## A
**对照：**

| 听着别扭 | 自然的说法 | 原因 |
|---|---|---|
| I very like it. | I really like it. | very 不修饰动词；用 really、a lot |
| I have done this last year. | I did this last year. | 有明确过去时间用一般过去式 |
| Open the light. | Turn on the light. | 电器用 turn on / off |
| I have a question want to ask. | I have a question. / I'd like to ask a question. | 不重复 |
| The system have a problem. | The system has a problem. | 第三人称单数加 s |
| Let me introduce my project. | Let me walk you through my project. | introduce 多用于介绍人 |
| I want to know the reason. | I'd like to understand why. | want 太直接，换成 I'd like |
| Do you understand? | Does that make sense? | 前者像在考对方 |

**冠词与单复数：** 第一次提到的可数名词用 a；已经提到的或唯一的用 the；"The cache is full."（特定的），"A cache stores data."（泛指）。

**语气：** 这些错误不影响沟通，但集中出现会让对方多费力；挑你最常犯的三四个，刻意练到不用想。

**出处：** 惯用说法，非引用；语法点为通用英语规则
