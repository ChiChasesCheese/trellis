## Q
**Clear-sentence techniques · 三个改写套路**｜原则 · 追问

评审人给你的文档批了一句："太虚，读不出谁做什么。" 你有三句原文要改。分别用什么套路？

## A
**原则：** 三个机械的套路就能改掉大部分模糊句：**换强动词**、**删掉 there is/there are**、**用事实代替主观形容词**。

| 症状 | 套路 | Before → After |
|---|---|---|
| 动词弱（occur、happen、be） | 找出真正的动作，用精确动词 | A warning occurs → The system issues a warning |
| There is/are 开头 | 删掉，让真正的主语当主语 | There is a cache that stores results → A cache stores results |
| 主观形容词副词 | 换成可量化的事实 | very fast → 4 s to 1 s |
| 名词化 | 变回动词 | perform an analysis of → analyze |

**怎么做：**
1. 先圈出每句的动词；是 be 或者名词化的，就改。
2. 句子以 there is/are 开头就重写。
3. 每个形容词副词问："能用数字或事实代替吗？"
4. 改完念一遍：谁做了什么，是否一眼可见？

**常见错法：**
- **把所有形容词都删光：** 可量化的描述性词是需要的，删的是空洞的。
- **改成被动再去掉 actor。**
- **营销腔：** 技术文档是教人，不是推销。

**出处：** Google Technical Writing One《Clear sentences》（developers.google.com/tech-writing/one/clear-sentences）；Short sentences（in order to → to；is able to → can）
