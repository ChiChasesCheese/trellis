## Q
**One idea per sentence · 短句**｜原则 · 必会

发布说明里有这样一句："The release fixed two crashes, added YAML support, and the docs were also updated, which took the team two weeks because the build was slow." 读者读完不知道重点。怎么拆？

## A
**原则：** 一个句子只放**一个主要想法**。读者要同时握住一个句子里的所有成分，想法越多越吃力。

**怎么做：**
1. 一个句子里有第二个想法，就拆成两个句子。
2. 句子里有"A，B，C 或 D"这样的并列，改成 bulleted list；有先后的步骤，改成 numbered list。
3. 删掉 "in order to"、"is able to" 这类冗词：in order to → to，is able to → can。
4. 从句只在**扩展主句**时保留；引入新想法的从句，独立成句。
5. 非限定补充用 which（前面逗号，读时停顿），限定范围用 that（不加逗号）。

**常见错法：**
- **一句话讲完三件事：** 读者记不住任何一件。
- **用分号硬接不相关的想法：** 用句号。
- **拆得太碎：** 一连串三个词的句子同样难读，拆到每句一个想法即可。

**改写示例：**
- Before: "The release fixed two crashes, added YAML support, and the docs were also updated."
- After: "The release fixed two crashes and added YAML support. The docs were updated too."
- Before: "The parser reads XML files, which were standardized in 1998 by a working group that also defined schemas."
- After: "The parser reads XML files. XML was standardized in 1998."
