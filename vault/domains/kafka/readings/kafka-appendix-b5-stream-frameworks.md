# Kafka生态外的流式处理框架

本节介绍Samza、Spark、Flink、Beam这几个Kafka之外的流式处理框架/模型各自的定位——Samza与Streams同源但运行在Yarn上、Spark以微批处理见长、Flink专注低延迟、Beam提供批流统一的编程模型，是选型时的补充参考。
