## Q
**挑战。** 朋友说：「模型快免费了，DeepSeek 每百万 token 输出只要 0.28 美元，所以做 AI 编程助手的创业公司没有护城河，真正赚钱的只有英伟达。」用产业四层的结构评价这句话，并说出你会在哪一层找护城河。

## A
**评分点（答出 3 条算过）：**

1. 模型便宜不等于应用没价值：应用层的价值在上下文、工作流和可验证的结果，编程应用里独立公司（不含实验室自家产品）一年仍增长约 2.9 倍，规模约 100 亿美元。
2. 真正的威胁在上游做应用：实验室自家的 Claude Code 和 Codex 拿走编程支出的约七成，不是模型免费。
3. 便宜的模型主要在小模型和开放权重，企业的花费仍向最强模型集中（旗舰在企业 AI 花费中的占比一年内约从 35% 升到 63%），所以"模型免费"并不成立。
4. 英伟达的利润来自瓶颈（先进封装、高带宽内存），瓶颈松动、云厂商自研芯片或需求回落都会削弱它，不是永久的。
5. 给出护城河的位置：私有数据与系统集成、工作流里的验证环节、分发渠道，以及对多个模型的路由能力。

<details class="pt"><summary>参考答案</summary>这句话把四层混在一起了。模型单价下降对应用层是成本下降，而不是价值消失；编程应用的价值来自代码库上下文、测试验证和工作流，这些不是模型公司随手能复制的。真正要防的是模型公司自己做应用，Claude Code 和 Codex 已占编程支出的七成。英伟达赚钱靠封装和内存瓶颈，会随产能和自研芯片变化。所以护城河应放在私有上下文、验证环节和模型路由上，并且假设上游随时可能降价或涨价。</details>
