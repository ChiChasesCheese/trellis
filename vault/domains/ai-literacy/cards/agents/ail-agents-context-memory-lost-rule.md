## Q
智能体干到一半"忘了"你开头交代的规则，是怎么回事？怎么避免？

## A
**对话里的规则会被压缩成摘要，摘要可能没有带上它；而写在 CLAUDE.md 里的内容每次都会重新读入。**

**场景：** 会话开头你说"不要改 `migrations/` 目录"。两个小时后窗口压缩了两次，智能体顺手改了一个迁移文件。摘要里留的是"在做订单模块重构"，那条禁令没有进去。

**为什么会这样：**
- 压缩是有损的，早期的详细指令最容易丢。
- 窗口很满时，处在中间位置的内容更容易被忽略。
- 智能体没有别的记忆，窗口里没有就等于不知道。

**修法，由硬到软：**
- **权限规则或钩子（hook，在特定事件前后自动运行的脚本）：** 直接禁止写 `migrations/**`，不依赖模型记得。
- **CLAUDE.md：** 持久规则写进去；还可以加一节"压缩时要保留什么"。
- **进度文件：** 长任务把已做完和待办写在 `progress.md`，每次开头先读。
- **拆会话：** 按模块分开，每个会话上下文短。

**陷阱：** 一个超大文件或工具输出让窗口压缩后又立刻满，Claude Code 几次后会停止自动压缩并报错，而不是无限循环；要自己换成分段读取，或让子智能体去处理。
