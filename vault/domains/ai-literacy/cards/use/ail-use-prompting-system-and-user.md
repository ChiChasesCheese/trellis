## Q
一次请求里，系统提示（system prompt）和用户消息各放什么？为什么写清楚提示词就能改变模型的行为？

## A
**系统提示放"长期有效的角色和规则"，用户消息放"这一次的任务和数据"；模型是读完整段文字后续写的，所以提示词越清楚，续写越准。**

```json
{
  "system": "你是支付客服助手。只依据资料回答，不知道就说不知道。",
  "messages": [
    {"role": "user",
     "content": "<资料>退款 7 天内到账</资料>\n退款多久到？"}
  ]
}
```

| 写法 | 要点 |
|---|---|
| 角色 | 一句话就有用："你是支付客服助手" |
| 说明原因 | "回答要短，因为显示在手机弹窗里"，比只写"要简短"更能让模型取舍 |
| 分隔 | 资料、指令、例子各用标签包起来（如 `<资料>`），避免混淆 |
| 位置 | 长文档放前面，问题放最后；多文档输入时，问题放末尾在 Anthropic 的测试中最多提升 30% |

提示词是最便宜的调整手段：改一行文字，立刻生效，不用训练。
