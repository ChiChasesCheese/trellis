## Q
大模型 API 怎么计费？输入和输出为什么分开标价，输出为什么更贵？现在三个档位大概多少钱？

## A
**按 token 计费，输入和输出分开标价，输出通常是输入的 5 倍：输入可以一次并行读完，输出要一个 token 一个 token 串行生成。**

**一次请求怎么算（Sonnet 5.5，每百万输入 2 美元、输出 10 美元）：** 输入 3,000 token + 输出 500 token = 3,000 × 2 ÷ 1,000,000 + 500 × 10 ÷ 1,000,000 = 0.006 + 0.005 = **0.011 美元**。

**截至 2026 年 11 月，每百万 token（输入 / 输出）：**

| 档位 | Anthropic | OpenAI |
|---|---|---|
| 旗舰 | Fable 5.2：8 美元 / 40 美元 | GPT-6 Astra：10 美元 / 50 美元 |
| 中档 | Sonnet 5.5：2 美元 / 10 美元 | GPT-6.1 Sol：2 美元 / 10 美元 |
| 小档 | Haiku 5.5：0.10 美元起 / 0.50 美元起 | GPT-6 Luna：0.10 美元 / 0.50 美元 |

- **隐藏的计费项：** 思考 token 按输出价；工具定义、历史对话、检索结果按输入价。
- **价差：** 同一家里，旗舰对小档相差约 80 倍。

**新进展（2026 年 9 月）。** 同一档位的价格在下降：OpenAI 的 GPT-6 Sol 比上一代 GPT-5.6 Sol 便宜一半（输入从 4 美元降到 2 美元）；Anthropic 的 Opus 5.5 比 Opus 5 便宜 20%（输入 4 美元对 5 美元）。输入输出的 1 比 5 结构没变。

<details class="pt"><summary>想一想：一个代码智能体每天 1 亿输入 token、2,000 万输出 token，用 Sonnet 5.5 一天多少钱？输出占 token 的比例和占成本的比例各是多少？</summary>输入 1 亿 × 2 美元每百万 = 200 美元，输出 2,000 万 × 10 美元每百万 = 200 美元，共 400 美元；输出只占 token 的约 17%，却占成本的 50%。</details>
