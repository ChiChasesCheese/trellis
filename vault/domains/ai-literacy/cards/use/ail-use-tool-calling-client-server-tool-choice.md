## Q
工具到底由谁执行？tool_choice 的几种取值分别是什么意思？带工具的请求多花多少 token？

## A
**工具有两类：客户端工具由你的程序执行；服务端工具（如网页搜索、代码执行）由模型提供商替你执行。tool_choice 决定模型"可以"还是"必须"调用。**

| 取值 | 含义 |
|---|---|
| auto（默认） | 模型自己判断要不要调用 |
| any | 必须调用某一个工具 |
| tool | 必须调用指定的那个工具 |
| none | 不许调用 |

- **并行调用：** 一轮回复里可以有多个调用请求，互不依赖的可以同时执行，结果一起交回。
- **服务端工具要另外收费：** Claude 的网页搜索每 1,000 次 10 美元，另加搜索结果占用的 token。
- **额外 token：** 只要带了工具，系统会自动加一小段工具说明（约 290 token，因模型而异），工具定义本身和每次的 tool_use、tool_result 都按输入或输出 token 计费。
- **强制与引导：** 想让模型先查再答，可以在系统提示里写"先用工具调查再回答"；要保证调用，用 tool_choice。

**案例：** 订单助手把 tool_choice 设成指定"查订单"，用户无论说什么都会被迫调用一次查询；换成 auto，闲聊就不会白白调用工具。
