## Q
**挑战。** 公司的会员客服机器人对"开通后 7 天能退款吗"回答："可以，依据服务条款第 4.2 条。"但条款里根本没有 4.2 条。产品经理说："把 temperature 调成 0 就不会编了。"你怎么回应，并给出修复方案？

## A
**评分点（答出 3 条算过）：**

1. 反驳：temperature 0 只是去掉抽样随机性，不会给模型增加事实；它可能稳定地编出同一个 4.2 条。
2. 根因：条款没有进入上下文，模型凭记忆"写"出条款，应该先检索真实条款（RAG）再回答。
3. 提示约束：只依据资料回答，引用条款编号，资料中没有就回答"没有"并转人工。
4. 程序校验：检查引用的条款编号存在于知识库，引用的原文真是库中文字的子串；不通过就降级为"转人工"。
5. 评测：建一批"条款里没有答案"的负例，量化拒答率和引用准确率，上线前后各跑一次。

<details class="pt"><summary>参考答案</summary>temperature 0 只会让输出更稳定，不会让模型知道它不知道的东西，所以它仍然可能稳定地编出"第 4.2 条"。真正的根因是条款没有进入上下文，应该先检索真实条款并放进提示，要求答案标注条款编号，资料里没有就明说没有。再加一层程序校验：编号必须存在于知识库，引用的话必须是原文的子串，不通过就转人工。最后用包含"条款里没有答案"的负例测试集量化拒答率和引用准确率。</details>
