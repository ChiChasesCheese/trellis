## Q
新闻里的"价格降 20%""错误少一半""就业下降 13%"，这些数字有哪些常见的单位陷阱？

## A
**读数字先换成单位：每 token 还是每任务，百分点还是百分比，相对还是绝对。**

| 新闻说 | 要还原成 |
|---|---|
| 价格降 20% | Claude Opus 5.5 把每百万 token 从 5/25 美元降到 4/20 美元：这是每 token。每任务成本还取决于模型要用多少 token |
| 从 91% 涨到 96% | 错误率从 9% 降到 4%，错误少了一半多；从 99% 到 99.5% 看着只涨 0.5，错误也是减半 |
| 年轻程序员就业下降 13% | 斯坦福用工资单数据比较：22 到 25 岁的人在 AI 暴露度高的岗位上，相对暴露度低的岗位下降 13%，不是 13% 的人失业 |
| 50% 时间跨度 12 小时 | 这类任务一半会失败 |

**新进展（2026 年 10 月）。** Artificial Analysis 的指数 v5 里，每个任务的输出 token 中位数从 v4.3 的 3.5 万升到 5.9 万；智能体类评测占 55% 的权重，却产生约 90% 的输出 token。

<details class="pt"><summary>想一想：若每 token 价格降 20%，而每任务的 token 数涨 70%，每任务成本怎么变？</summary>0.8 乘 1.7 约等于 1.36，每任务成本反而涨约 36%。所以"每 token 降价"不等于"账单降价"，尤其在会多想、多调用工具的智能体任务上。</details>
