# Next.js static exports

The official, end-to-end account of what runs at build time, which artifacts appear, and which server features cannot exist in a fully static deployment.

**Extract on read:**
- One HTML output per route changes delivery and JavaScript cost versus a strict SPA.
- Build-time execution requires deterministic inputs and complete route discovery.
- Dynamic request data, ISR, and default image optimization require a runtime rather than plain object hosting.
