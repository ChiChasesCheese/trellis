## 2. Briefings returned with the bank (1P3A synthesis of the threads; readable one only)

`loop-structure-timeline` (readable). Confidence: medium (secondary synthesis; cites the 28 threads of section 3).

- Default loop: strict one-round-at-a-time funnel; fail a round and the later rounds are cancelled. Recruiter call (optional) -> phone screen / R1 60 min (project deep dive 15-30 min + 1-2 coding) -> R2 60 min (second coding or system / ML design) -> R3 60 min, often HM (behavioural + one more coding / design) -> team-match call. Typical 3-6 weeks first contact to verbal offer.
- Org variants: TikTok USDS (SRE) = 4 rounds booked in one batch (coding, network/linux, system design, HM), finishes in about 2 weeks. Intern / NG SWE = 3 rounds + HR, third round sometimes code-reading + design. MLE / Monetization / E-Commerce = 3 technical rounds (project + ML 八股 + 1 coding). TikTok Backend / Live Service Arch = 1 HR + 1 coding, frequent ghosting, drops after 1 round.
- Friction: rounds rebooked 2-3 times; HR silence of 1-2 weeks; JD-to-org mismatch; a separate team-match gate; HC can vanish after positive feedback (threads 1177482, 1182254-style).
- 2026 Q2: conceptual follow-up depth gates the pass even when the code is correct (example: what to do when a cache's miss rate is high). Ads / Growth loops: tech screen -> system design -> HM; Growth second round can pivot to recommendation-engine design.
- 2026 Q3 dense loop: five rounds in two days plus a sixth extra round (two hard coding, one data-structure, recommendation system design, behavioural + resume, one more coding check). Compressed second round: 30 min resume + 15 min system design + 15 min coding. 2027 summer intern screen: 5/25/25/5 split (intro / resume + design fundamentals / coding / questions).
- Sept 2026 USDS JV senior MLE: two consecutive 1-hour rounds after the recruiter call (intro + project + coding, then background / technical fit). Another USDS loop: one round per week, two coding rounds then HM that still includes coding. A planned HM round can be cancelled for business reasons.
- Sept 2026 three-design-round variant: a ByteDance loop of three system-design rounds in Chinese, HM leads round 1, rounds 1-2 include live AI-assisted implementation after writing the design; next-round invitation about 2 days after each round.
- Late Sept-Oct 2026: USDS SWE three rounds = (1) two-problem coding, (2) one modified coding problem then monitoring / tracing / telemetry questions, (3) quick high-level system design + project deep dive; extra HR call on immigration status afterwards is logistics only. 2027 NG SWE: graph / topological-sort coding then system design. 2027 summer e-commerce backend intern: apply 08-06, OA 08-07, HR 08-23, one-hour technical 09-11, reject 09-26.
- Oct 2026 USDS SWE onsite: two coding rounds (a fast two-problem round, then one tree problem that took the hour) then a system-design round that drilled consistency and failure cases further than expected. USDS MLE loop billed "coding, coding, ML system design": ML 八股 + NumPy transform, ML system design + data parser, ML system design + hand-written attention; no LeetCode-style problems. Recruiter descriptions of round types are not reliable.
