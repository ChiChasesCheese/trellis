   files; drop `own_decks`, `deck_moves`, `study`, and any key that only Anki needs; keep `domain`, `title`, `lang`,

   node is removed. Write a header comment saying it is generated and from what. Idempotent.
   Before writing, run the private-term check the way `scripts/private_guard.py` does (import its `terms()` and
   `pattern()`) on every title and summary; if anything matches, drop that node and print it (count only, never the
   term). Print kept/dropped node counts.

   Card folders = the skeleton's `vault` plus its `include` (check `_content_folders` already handles `include`).
   A card is published only if its node is in the projection (cards of dropped nodes are not, even if tracked).
